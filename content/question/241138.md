  body_markdown: "I suspect that Gazebo page is out of date. The [migration page](http://wiki.ros.org/kinetic/Migration#Gazebo_Simulator)\
    \ for ROS Kinetic says: \n\n> The Gazebo official versions supported in ROS Kinetic\
    \ are the 7.x series.\n\nAlso Kinetic is currently the recommended ROS release,\
    \ so right now the recommended setup is Ubuntu 16.04 Xenial Xerus + ROS Kinetic\
    \ Kame + Gazebo 7.1. \n\nEnd of Life (EOL) simply means that support ends for\
    \ that version, in other words, the developers are no longer going to spend any\
    \ time updating, patching, adding features, troubleshooting etc. that version.\
    \ The reason they do this is so they can spend their time wisely on supporting\
    \ more current versions and working on new features for future versions rather\
    \ than fix things that most people aren't using anymore. \n\nYou are free to use\
    \ something that is EOL, but if you find a bug the developers are probably not\
    \ going to fix it for you. You could fix it yourself on your local copy, put up\
    \ with the bug, or upgrade to the current version."
