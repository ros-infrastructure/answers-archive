    This [netpbmfile library](https://pypi.org/project/netpbmfile/) could help you generate your PGM map file with *.yaml file too ([documentation of YAML format for ROS](http://wiki.ros.org/map_server))- then you can go with steps from [this YT tutorial](https://www.youtube.com/watch?v=lWrvDUYAFBI) to load this map inside ROS1 Navigation stack.
