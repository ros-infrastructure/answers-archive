  body_markdown: "Hi,\nThese are just msgs in a structured way so that they can be\
    \ published or subscribed by a node. They are just values. It depends on the node\
    \ which actually uses them to manipulate robot.\nIt depends on how you want to\
    \ use it. For example in teleop_base package the teleop_base_keyboard.cpp takes\
    \ the msgs from keyboard and uses them as m/sec. If your node takes this msgs\
    \ as mm/sec then the node execution will be accordingly.\n\nYou can know the msg\
    \ types by the following command.\n\n    rosmsg show geometry_msgs/Twist\n\nwhose\
    \ output is \n\n    geometry_msgs/Vector3 linear\n      float64 x\n      float64\
    \ y\n      float64 z\n    geometry_msgs/Vector3 angular\n      float64 x\n   \
    \   float64 y\n      float64 z\n\nHope this helps, Karthik\n\n"
