    \ may differ. \n\n> set up a package to connect with a KUKA KR180 R2900 via RSI\
    \ with KRC4\n\nIt is essential to check the moments, and rotation is perfect.\
    \ In some cases, the rotation of the real robot and your URDF robot may differ.\
    \ Moreover, you also need to check the angle of moments of each axis makes it\
    \ the same as Kuka real robot. You can check by importing the URDF file to RVIZ\
    \ and check each axis working.\n\nYou can follow these steps to check links: \n\
    \n 1. https://github.com/ros/urdf_tutorial Clone It\n 2. Copy display.launch file\
    \ from urdf_tutorial/launch folder.\n 3. In your launch folder, where you have\
    \ built the package, create a launch file and paste display. Just change the URDF\
    \ path and file name.\n 4. Test the above details.\n\n> I could control the robot\
    \ but the movement was so jerky. \n\nOver here you can check your axis degree\
    \ from the robot and from rviz and compare it whether it is different to not.\
    \ If yes, then you need to fix your links from the URDF file.\n\nYou can check\
    \ so: In your smart pad goto setting -> Display -> Actual position\n\n![image\
