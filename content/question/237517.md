    `sizeof()` returns the [size in bytes of the object representation of the respective type](http://en.cppreference.com/w/cpp/language/sizeof). Thus, on a 64bit system (I'm assuming you have this), this is 24 bit for a vector (see e.g. [this blog post, first bullet point](http://info.prelert.com/blog/stl-container-memory-usage)), if it is empty.

    If you want to have the number of elements, use `res.poses.size()` ([see here](http://www.cplusplus.com/reference/vector/vector/size/)).
