  body_markdown: "You need to have your `.bashrc` environment properly sourced. As\
    \ stated in the documentation, you should load your `.bashrc` environment with\
    \ Eclipse, by launching it from the command line via `$ bash -i -c \"eclipse\"\
    ` . For convenience, you can also set this automatically by changing the `Exec=`\
    \ line in your *eclipse.desktop* launcher. \n\nFor example, I did\n\n    $ vim\
    \ ~/.local/share/applications/eclipse.desktop`\n\nFor example, my *eclipse.desktop*\
    \ file contains this:\n\n    Exec=bash -i -c /MY_PATH_TO_ECLIPSE/eclipse\n\nThen,\
    \ you may drag this *eclipse.desktop* file to the side bar.\n"
