  body_markdown: "Or simpler, if you are using openni. \n\n[EDIT] : the [pi_tracker](http://www.ros.org/wiki/pi_tracker)\
    \ is the one I meant. Openni tracker only gives transforms, not coordinate of\
    \ the joints.\n\nIf you have a look at the tracker file, you'll see that you can\
    \ access to the points coordinates. Then computing a velocity is the easy part.\
    \ However, I have no idea how to command your motors (but I hope you know it ;-)\
    \ )\n\nTo access the points, it easy : make a listener, then access the parts\
    \ you are interested in :\n\nfor each joint (here corresponding to index k), you\
    \ have the following fields\n\n    msg.position[k].x\n    msg.position[k].y\n\
    \    msg.position[k].z\n    msg.orientation[k].x\n    msg.orientation[k].y\n \
    \   msg.orientation[k].z\n    msg.orientation[k].w\n\n\n[EDIT 2 ] = the pi_tracker\
    \ has already something to command velocity for a robot, based on joint velocity....\n\
    \n\nI hope it'll help you,\n\nBests,\n\nSteph"
