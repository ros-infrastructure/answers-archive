    It seems the CMake find script for the PA-10 library is unable to locate the necessary files. Do you have the library and headers installed/present (seems like a manual step outside of ROS, see [pa10controller](http://www.ros.org/browse/details.php?name=pa10controller) package page)?

    According to [this](http://cmu-ros-pkg.svn.sourceforge.net/viewvc/cmu-ros-pkg/trunk/pa10controller/FindPA10.cmake?revision=435&view=markup), the `FindPA10` script looks in a number of locations (the list starting at line 56). You could either add your paths there, or define the CMake variables `PA10_INCLUDE_DIRS` and `PA10_LINK_DIRS` on the command line somehow. See also the CMake documentation for the [find_path](http://www.cmake.org/cmake/help/cmake2.6docs.html#command:find_path) command (especially bullet 2).

    Also, are you sure the pa10controller package is compatible with Fuerte? Last commit to [cmu-ros-pkg/trunk/pa10controller](http://cmu-ros-pkg.svn.sourceforge.net/viewvc/cmu-ros-pkg/trunk/pa10controller/) was 23 months ago, which seems to be from before Fuerte was even planned.
