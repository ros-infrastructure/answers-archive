  body_markdown: "The wagon ruts layer was never released, since if I recall correctly,\
    \ it was for a beta version of layered costmaps. \n\nThe easiest way to implement\
    \ it now would be a static layer with some added cost on the nonhighway cells.\
    \ You cannot set a value in a costmap to a negative value, although you could\
    \ (theoretically) make a layer that subtracted from whatever values were already\
    \ in a previous layer. "
