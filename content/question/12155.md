  body_markdown: "Generating odometry information from a camera or depth-sensor like\
    \ a Kinect is an incredibly difficult problem. [Vslam](http://www.ros.org/wiki/vslam)\
    \ is an attempt to generate visual odometry data from a stereo-camera setup. The\
    \ Kinect can provide you with the same information as a stereo camera system,\
    \ in that it publishes an image and a depth map. I believe there have been attempts\
    \ to use vslam with the Kinect before, but I'm not sure what kind of reliability\
    \ people have been getting. \n\nBuilding a 3D obstacle map using SLAM and gmapping\
    \ can easily be done with the Kinect, however.  You can find an example [here](http://www.ros.org/wiki/turtlebot_navigation/Tutorials/Build%20a%20map%20with%20SLAM). "
