    As an altermative to AMCL localization, you can take a look at:

     - [iris_lama_ros](https://github.com/iris-ua/iris_lama_ros) which uses [LaMa](https://github.com/iris-ua/iris_lama) library for localization (based on scan matching)
     - [slam_toolbox](https://github.com/SteveMacenski/slam_toolbox) also offers localization.

    Edit:
    I don't know if it is possible to get such (sub 1cm) precision for global localization (i.e. localization on map), but it is possible for "local" localization, for example docking, where you compare your current scan to some reference scan at final docked position. For this you can use:

     - Point Cloud Library has ICP algorithm implemented - an example is [here](https://github.com/PointCloudLibrary/pcl/tree/master/doc/tutorials/content/sources/iterative_closest_point). To use it you first have to transform LaserScan message to PCL format. PCL already has some functions implemented to do that. Transform chain is something like geometry_msgs::LaserScan -> geometry_msgs::PointCloud2 -> pcl::PointCloud<pcl::PointXYZ>

     - Andrea Censi's canonical scan matcher - [csm](http://wiki.ros.org/csm). An example how it is used can be seen in [laser_scan_matcher](https://github.com/ccny-ros-pkg/scan_tools/tree/indigo/laser_scan_matcher/src) package
