  body_markdown: "ROS is designed, as far as I know, to not care whether Topics exist\
    \ or not.  ROS will let Subscribers sit all day waiting for data on non-existant\
    \ Topics.  \n\nOne solution is to set up a watchdog style timer that looks for\
    \ data on the topic and lets you know if a certain period of time occurs without\
    \ any new data coming in.  "

    The subscriber knows to how many publishers it is connected to:
    [getNumPublishers](http://docs.ros.org/jade/api/roscpp/html/classros_1_1Subscriber.html)
    Or you use rospy to directly get a list of published topics: [get_published_topics](http://docs.ros.org/jade/api/rospy/html/rospy-module.html#get_published_topics).
