  body_markdown: "@cmeaclem,\n\nIf, in Rviz, you navigate to the Motion Planning tab\
    \ 'Scene Object' there is a window and button that lets you import a file. Once\
    \ the file is loaded you can move your object in the world using the gui or imarkers\
    \ and then save the config.\n\nHope this helps\n\n**Update:** You can follow [this](http://moveit.ros.org/wiki/Environment_Representation/Rviz#Saving.2FImporting_From_a_Database)\
    \ to save the scene to the warehouse database. Then you can load from the same\
    \ tab after launching. The connect button does need to be clicked a few times\
    \ in order to connect and you may need to change the [warehouse database path](http://moveit.ros.org/wiki/Benchmarking#Starting_the_MoveIt_Warehouse)\
    \ to save. From then on, you should just need to load the scene from the Motion\
    \ Planning > Stored Scene tab. "
