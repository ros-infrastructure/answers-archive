    This problem is being caused because you're using euler_from_quaternion. This function converts a quaternion object into a list containing three Euler angles as [described here](http://docs.ros.org/jade/api/tf/html/python/transformations.html). As @gvdhoorn pointed out the pose object stores the orientation as a quaternion not Euler angles, so you're altering the data structure which is the cause of the error you posted.

    You can simply copy the translation and rotation from the transform object into the pose object, no conversion is necessary. This should solve the problem you're having here.
