    The [hector_geotiff](http://wiki.ros.org/hector_geotiff) package provides a node for saving RoboCup Rescue compliant GeoTiff files. This is separate package from [hector_mapping](http://wiki.ros.org/hector_mapping) to facilitate separation and re-use. It could for example also be used together with gmapping (or any other source of grid maps). See also [this paper](http://www.gkmm.tu-darmstadt.de/publications/files/kohlbrecher2013opensource.pdf) for a high level overview and the [geotiff_mapper.launch](https://github.com/tu-darmstadt-ros-pkg/hector_slam/blob/master/hector_geotiff/launch/geotiff_mapper.launch) launch file for an example launch setup. This is also used in the hector_mapping [tutorial.launch](https://github.com/tu-darmstadt-ros-pkg/hector_slam/blob/master/hector_slam_launch/launch/tutorial.launch).
