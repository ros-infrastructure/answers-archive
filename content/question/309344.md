    \ There is a tip :\n\n**Not all devices support all operation modes. The driver\
    \ limits the set of available modes based on object 6502.** \n\nSo i check copley\
    \ manual to find object \"6502\", this canopen control support nine types modes,\
    \ and the expected value of this object 6502 is 0x000003ED.\n\nJust modefy the\
    \ edf file: set the default value of this object 6502 to 1005(DefaultValue=1005).\n\
    \nMaybe you will set some values in a yaml file loaded by canopen_motor_node,\
    \ and make sure that there objects' values will not cause this type error."
