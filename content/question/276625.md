    According to the documentation for `tf2_msgs/TFMessage` ([here](http://docs.ros.org/api/tf2_msgs/html/msg/TFMessage.html)), the `transforms` field is a list/array, so you'll need to index into it:

        geometry_msgs/TransformStamped[] transforms

    Something like `msg.transforms[0].transform.translation.x`.

    But realise that you may receive multiple `TransformStamped`s in a single message, so always using the first might not be what you want.
