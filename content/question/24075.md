    Yes, the keyword `world` is used to fix a joint to the world. If you name a model / link `world`, that should cause problems.

    [This tutorial](http://sdformat.org/tutorials?tut=pose_frame_semantics&cat=specification&#specifying-parent-and-child-link-names-for-joints-in-sdf-1-4) mentions the special treatment for the `world` keyword. The reason why that word is reserved is that we need some way to identify a fixed inertial frame.
