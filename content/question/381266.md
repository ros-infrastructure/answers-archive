    You could use the following command to install Gazebo:

        sudo apt-get install ros-noetic-gazebo-ros-pkg

    This will install gazebo and ros bindings for it. I am assuming that you are on Ubuntu Focal and have setup ROS noetic correctly. See also the official ROS instructions [ros-org - ROS noetic installation guide](http://wiki.ros.org/noetic/Installation/Ubuntu) .
