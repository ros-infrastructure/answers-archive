  body_markdown: " If you mean have multiple roscores on multiple machines then yes,\
    \ that is how ros works. You can have multiple laptops as long as they are mostly\
    \ listening(as in not actively competing with each other to command the other\
    \ nodes).  If you mean multiple roscore instances on one machine, then no, that\
    \ is not how ros works.  \n\nIf you want to be sure the roscore stays active on\
    \ the main machine, I suggest creating a script that would check and make sure\
    \ roscore is still active.  Here is an untested simplified version of what I have\
    \ used for this purpose.  \n \n    #! /bin/bash\n    keep_alive()\n      process=$(basename\
    \ $1)\n      process=\"${process%%.*}\" #remove timestamp\n      while [ true\
    \ ]\n      do\n        if pgrep \"$process\" > /dev/null\n        then\n     \
    \       local returnVal=0;\n        else\n            echo \"$process stopped\"\
    \n            $process &\n            local returnVal=1;\n        fi\n       \
    \ sleep 5\n      done\n    }\n    \n    keep_alive roscore\n\n\n In my case I\
    \ wrapped the launch file launch with a bash script that was easily pgrep-able. "
