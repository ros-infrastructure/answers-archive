  body_markdown: "I figured it out. Basically I was following PR2 tutorials to create\
    \ a realtime joint controllers. Since debian package is not available for ROS\
    \ jade for pr2 mechanism and simulator it was mentioned to manually install them\
    \ from source. What I did was update using rosdep and check what dependencies\
    \ are missing using following command\n\n    rosdep check --from-paths . --ignore-src\
    \ --rosdistro jade\n\nIt gave me list of missing dependencies which I installed\
    \ using apt and the issue resolved. Package compiled without any errors and its\
    \ working now.\n@gvdhoorn thnx alot for your suggestions . "
