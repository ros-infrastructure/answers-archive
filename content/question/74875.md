    Answered.  It is because I used the example launch file from the wiki page.  In that launch file, the parameter "output_frame" is set to value = "odom"
    The odom_estimation_node.cpp file uses that parameter to determine the topic advertised, with the default being "odom_combined"

    I found it confusing because I was thinking that "output frame" would refer to the tf frame not the published topic name.
  comments:
