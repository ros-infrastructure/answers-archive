    That is correct, if you use a [simple action state](http://www.ros.org/wiki/smach/Tutorials/SimpleActionState) Smach will construct the action client for you.


    Similarly, when you create a [action server wrapper](http://www.ros.org/wiki/smach/Tutorials/Wrapping%20a%20SMACH%20Container%20With%20actionlib) for a Smach container, Smach will construct the action server for you.
