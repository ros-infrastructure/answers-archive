  body_markdown: "On Windows, to use Visual Studio from the command-line you need\
    \ to be in a \"visual studio environment\".\n\nTo do so you can either:\n\n  -\
    \ open the visual studio prompt by hitting the windows key and then search for\
    \ `native`, it should offer you an application named something like `x64 Native\
    \ Tools Command Prompt for VS 2017`\n\nor:\n\n  - open a regular cmd window, and\
    \ setup the environment by running: \n\n        call \"C:\\Program Files (x86)\\\
    Microsoft Visual Studio\\2017\\Community\\VC\\Auxiliary\\Build\\vcvarsall.bat\"\
    \ x86_amd64\n\n\nNote that the exact path of the files or name of the application\
    \ can be different on your computer.\n"
