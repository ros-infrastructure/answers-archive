  body_markdown: "1. GzWeb currently doesn't support new versions of Node, so you'll\
    \ need to downgrade to 0.10 first. According to [these](https://github.com/nodesource/distributions)\
    \ instructions, first remove your current node:\n\n        sudo apt-get remove\
    \ nodejs\n\n    then install the 0.10 version:\n\n        curl -sL https://deb.nodesource.com/setup_0.10\
    \ | sudo -E bash -\n        sudo apt-get install -y nodejs\n\n    You can use\
    \ similar instructions to go back to node 4 if you need to. \n\n2. The default\
    \ branch of GzWeb has been compatible with Gazebo 7 for a while, but the latest\
    \ \"release\" version 1.2.0 was not. I just created a new branch `gzweb_1.3.0`\
    \ from default, which should build against gazebo7. So you could just pull and\
    \ use the new branch ;)"
