Dear everyone,

I got som trouble when trying to convert a *.pcap file into a *.bag file.

I try the method explained here :
https://answers.ros.org/question/213080/convert-raw-velodyne-vlp16-pcap-to-bagfile/

In a first terminal I launch :<br>
<code>roscore</code>
<br>Then in second one, I launch : <br>
<code>rosrun rosbag record -o your_vlp16_070815.bag /velodyne_packets</code> to open the recording file ?
<br>and finally in the third one, I launch :<br>
<code>rosrun velodyne_driver velodyne_node _model:=VLP16 _pcap:=bureau.pcap _read_once:=true</code> to play the pcap file.

I wait until the third command finish ("done" message), then CTRL+C the second command. I got a .*bag file.
After this, I try to view it using RVIZ following this method :
https://answers.ros.org/question/227205/how-to-display-bag-file-in-rviz/

<code>rosrun rviz rviz -f velodyne</code><br>
<code>rosrun velodyne_pointcloud cloud_node</code><br>
<code>rosbag play your_vlp16_070815.bag</code>

I work with ROS Kinetic on Ubuntu 16.04.
