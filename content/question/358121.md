    There is no predefined message to do this easily. You can do what @praskot suggested, or go one of many other ways.
    (Note, you can always check the other [common_msgs](https://wiki.ros.org/common_msgs?distro=noetic) if you want to use one of the generic types ones)

    In general, it is, however, advised to add [semantic meaning](https://discourse.ros.org/t/suggestions-for-std-srvs/1079/10) to messages and thus stay away from the `std_msgs` package as much as possible. See also #q255674.

    All in all, you have to create your own message type. The following are just some ways to do that, in addition to what @praskot suggested:

    `KeyValueLists.msg`

        std_msgs/String[] keys
        std_msgs/String[] values

    `Dictionary.msg` (using a message from the [diagnostic_msgs](https://wiki.ros.org/diagnostic_msgs?distro=noetic) package)

        diagnostic_msgs/KeyValue[] items

    of course, you could that create yourself too, if you don't want to depend on the `diagnostic_msgs` package


    `KeyValueString.msg`

        std_msgs/String key
        std_msgs/String value

    and thus:

    `StringDictionary.msg`

        KeyValueString[] items

    (obviously, the names are free to choose...)
