Hi,
 I found this issue of ros fuerte on opensuse. After installing ros rosmake fails to function as it calls to a rospkg python script os_detect.py function get_codename() which is not implemented for open suse. My temporary work around was to modify os_detect.py in class opensuse add a dummy function(i do not know python)

def get_codename(self):
	return ('opensuse-11_2')

Then uninstall rospkg
Lastly build and install modified rospkg from source
