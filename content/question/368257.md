    Hey, which driver are you using to control the robot? If you are using the official [ur_robot_driver](https://wiki.ros.org/ur_robot_driver), you should be able to control IO using the ```set_io``` service. For more information about all the services provided see their [ROS interface documentation](https://github.com/UniversalRobots/Universal_Robots_ROS_Driver/blob/master/ur_robot_driver/doc/ROS_INTERFACE.md#set_io-ur_msgssetio).

    The service uses the [ur_msgs/SetIO](https://docs.ros.org/en/melodic/api/ur_msgs/html/srv/SetIO.html) message type. When trying this out, it might make sense to look at the output from the ```io_states``` topic (type [ur_msgs/IO](https://docs.ros.org/en/melodic/api/ur_msgs/html/msg/IOStates.html)), as the pin numbers should match.

    Feel free to ask more if you have specific questions.
