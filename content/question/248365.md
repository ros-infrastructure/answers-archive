    \ nodes ? \n\nNo, only nodelets can exchange pointers*, as they share the same\

    \n(* this is not entirely true: with a suitable transport (such as [ethzasl_message_transport](http://wiki.ros.org/ethzasl_message_transport))\
    \ zero-copy msg exchange is also possible between nodes, but that is not out-of-the-box\
    \ supported and comes with some constraints)\n\n> 2 . Also is there a requirement\
    \ that the nodelets be launched from the same nodelet manager for the zero copy\
    \ to be true ?\n\nyes, again because they need to share an address space. Different\
    \ managers will each have their own address spaces.\n\n> 3 . Is there a way to\
    \ check/test whether there is zero copy happening in my implementation or my code\
    \ is using network resources ?\n\nI know of no other way than checking resource\
