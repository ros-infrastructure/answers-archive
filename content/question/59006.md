    The tip of the geometry stack has already been migrated to [catkin](http://www.ros.org/wiki/catkin). If you want to build it in ROS Groovy, you need to set up a catkin workspace. If you want to build the geometry stack from source in Fuerte, you'll need to use an older version like this one: https://kforge.ros.org/geometry/geometry/rev/cbfce76cb39f

    Also, the geometry source has (very) recently been migrated to github: https://github.com/ros/geometry so it would be best to clone from https://github.com/ros/geometry/tree/fuerte_devel
