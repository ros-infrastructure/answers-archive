     The `JointTrajectoryPoint` contains individual arrays for `position`, `velocity`, `accelerations`, and  `effort`.  Array types under CPP are vector types (see [here](http://wiki.ros.org/msg#Fields)).  If any of these arrays are empty (i.e. vector.empty()), then they can be considered invalid.
