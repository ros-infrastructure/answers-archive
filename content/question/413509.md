**Edit and Solution,** In case this can help someone else :

I'm using ros2 but this package was for ros1. There is one for ROS2 here that isn't linked by the company's website : https://github.com/YDLIDAR/ydlidar_ros2_driver (EAIBOT seems to be the old name).

Yet, this driver is full of compilation errors that you'll have to correct by yourself.
