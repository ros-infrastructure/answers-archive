    Firstly, hector_slam is independent of /tf for laser ([watch this video](https://www.youtube.com/watch?v=F8pdObV_df4)). You can simply have a laser attached to a computer and walk around to create a 2D map. I haven't used the bag file that you mentioned before, but usually the bag file should contain time stamped /tf data, or simply create a urdf.xacro config file for your system and load it using [robot_state_publisher](http://wiki.ros.org/robot_state_publisher) to publish transforms.
