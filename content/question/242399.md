  body_markdown: "I think it technically *is possible* but the video will have very\
    \ very high latency (i.e. unusable). It looks like that camera has USB 2.0 which\
    \ really isn't fast enough for HD video, but you could try simply using the [usb_cam](http://wiki.ros.org/usb_cam)\
    \ package to see things working. Also ROS uses TCP by default which is not good\
    \ for transmitting large video over wireless, there is [UDPROS](http://wiki.ros.org/ROS/UDPROS)\
    \ that uses UDP instead, but I don't know how well it is supported. \n\nI think\
    \ in reality if you wanted to have a usable video feed, you would need special\
    \ hardware like a [Connex Prosight from Amimon](http://www.getfpv.com/the-connex-prosight-hd-vision-kit.html)\
    \ that connects to the camera's HDMI. I don't know much about DJI, there might\
    \ be something on board the drone that does something similar like letting you\
    \ send your own video over the Lightbridge link if it has one? "
