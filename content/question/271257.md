  body_markdown: "I believe that it's in the `PREEMPTED` state. According to the [message\
    \ definition](http://docs.ros.org/diamondback/api/actionlib_msgs/html/msg/GoalStatus.html)\
    \ found at the api:\n\n    GoalID goal_id\n    uint8 status\n    uint8 PENDING\
    \         = 0   # The goal has yet to be processed by the action server\n    uint8\
    \ ACTIVE          = 1   # The goal is currently being processed by the action\
    \ server\n    uint8 PREEMPTED       = 2   # The goal received a cancel request\
    \ after it started executing\n                                #   and has since\
    \ completed its execution (Terminal State)\n    uint8 SUCCEEDED       = 3   #\
    \ The goal was achieved successfully by the action server (Terminal State)\n \
    \   ... # edited for brevity\n\nIt's a constant. You can always find this sort\
    \ of information out by running \n\n    $ rosmsg show actionlib_msgs/GoalState\n\
    \nbut just change `actionlib_msgs/GoalState` with whatever message you're trying\
    \ to examine."
