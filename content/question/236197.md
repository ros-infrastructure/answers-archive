    The `name` field in the <node> tag of a launch file is for specifying the [graph resource name](http://wiki.ros.org/Names). It will override the value in any call to `ros::init` or `rospy.init_node`. The `type` field is for specifying which node from a given package to run. If your node is a Python node, this name should be the name of the executable Python script. If the node is a compiled C++ node, then this name should come from the executable created by `catkin`; this is specified in the CMakeLists.txt.

    If you've created new C++ nodes, be sure you are giving them unique names in your CMakeList.txt file, be sure you have compiled your workspace, and be sure that you are using the executable names in the `type` field of your launch files.
