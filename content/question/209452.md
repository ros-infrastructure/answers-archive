  body_markdown: "The exception is because Internally ros::Time objects use int64_t\
    \ variables and cast to uint32_t when returning the result.  When a time value\
    \ is negative, the value exceeds what an uint32_t variable can represent. The\
    \ result is the exception you are seeing is thrown. \n\nThis sample code that\
    \ generates the exception you are seeing.\n\n    try {\n      ros::Time test =\
    \ ros::Time::now() - ros::Duration(0.01);\n    }\n    catch(std::runtime_error&\
    \ ex) {\n      ROS_ERROR(\"Exception: [%s]\", ex.what());\n    }\n\nPossible solutions:\n\
    \n 1. Wrap your code in try-catch blocks and deal with the resulting issues\n\
    \ 1. Call toSec() on time/duration objects and do the math manually\n\nTL;DR\n\
    -------\nHere's where the exception is thrown (source [here](https://github.com/ros/roscpp_core/blob/indigo-devel/rostime/src/time.cpp#L487))\n\
    \n    void normalizeSecNSecUnsigned(int64_t& sec, int64_t& nsec)\n    {\n    \
    \  int64_t nsec_part = nsec % 1000000000L;\n      int64_t sec_part = sec + nsec\
    \ / 1000000000L;\n      if (nsec_part < 0)\n      {\n          nsec_part += 1000000000L;\n\
    \          --sec_part;\n      }\n    \n      if (sec_part < 0 || sec_part > UINT_MAX)\n\
    \        throw std::runtime_error(\"Time is out of dual 32-bit range\");\n   \
    \ \n      sec = sec_part;\n      nsec = nsec_part;\n    }\n\nThis code is one\
    \ of several places where the exception might be generated. Subtraction is implemented\
    \ as \"negative addition\". (source [here](https://github.com/ros/roscpp_core/blob/indigo-devel/rostime/include/ros/impl/time.h#L83))\n\
    \n    template<class T, class D>\n    T TimeBase<T, D>::operator-(const D &rhs)\
    \ const\n    {\n      return *static_cast<const T*>(this) + ( -rhs);\n    }\n\
    \    \n    template<class T, class D>\n    T TimeBase<T, D>::operator+(const D\
    \ &rhs) const\n    {\n      int64_t sec_sum  = (int64_t)sec  + (int64_t)rhs.sec;\n\
    \      int64_t nsec_sum = (int64_t)nsec + (int64_t)rhs.nsec;\n    \n      // Throws\
    \ an exception if we go out of 32-bit range\n      normalizeSecNSecUnsigned(sec_sum,\
    \ nsec_sum);\n    \n      // now, it's safe to downcast back to uint32 bits\n\
    \      return T((uint32_t)sec_sum, (uint32_t)nsec_sum);\n    }\n\n"
