 Hi,

I am working with the point grey camera and am using the flycap package with ROS on the jackal.
Once I capture the image I use cv_bridge with bgr8 encoding to convert the raw image.

The code in the ROS callback function for the topic "/camera/image_color" is:

     cv_bridge::CvImagePtr cv_ptr;
     std::vector<cv::Mat> channels;
     std::vector<cv::Mat> a_ch(3);
     static int iter = 0;
  
     try
     {
        cv_ptr = cv_bridge::toCvCopy(msg, sensor_msgs::image_encodings::BGR8);
     }
     catch (cv_bridge::Exception& e)
     {
        ROS_ERROR("cv_bridge exception: %s", e.what());
        return;
     }
     size_t rows = cv_ptr->image.rows; // this is 480
     size_t cols = cv_ptr->image.cols;  // this is 752

However, the size of the image is 480x752 which is a non standard size. 
When images are captured with just the flycap on ubuntu, the size is the standard 480x600.

Why does cv_bridge give odd image sizes? Is there some setting I need to add?
