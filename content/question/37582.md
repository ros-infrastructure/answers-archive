  body_markdown: "When you use namespaces for a node all parameters used by this node\
    \ get the namespace as well. So when launch like the example in the above answer,\
    \ the node *spawn_quad0* looks for a parameter *first_pelikan/quad_urdf* (and\
    \ not just *quad_urdf*). \n\nYou can solve this in two ways:\n\n    <group ns=\"\
    first_pelican\">\n       <param name=\"quad_urdf\" value=\".....\" />\n      \
    \ <node name=\"spawn_quad0\" pkg=\"gazebo\" type=\"spawn_model\" args=\"-urdf\
    \ -param quad_urdf -model quad0 -x 0 -y 0 -z 3\" respawn=\"false\" output=\"screen\"\
    />\n    </group>\n    \n    <group ns=\"second_pelican\">\n       <param name=\"\
    quad_urdf\" value=\".....\" />\n       <node name=\"spawn_quad1\" pkg=\"gazebo\"\
    \ type=\"spawn_model\" args=\"-urdf -param quad_urdf -model quad1 -x 1 -y 1 -z\
    \ 3\" respawn=\"false\" output=\"screen\"/>\n    </group>\n\nOr, to avoid duplication\
    \ of parameter, declare it outside the group, but use fully-qualified name when\
    \ using the param (i.e with the slash at the beginning). \n\n    <param name=\"\
    quad_urdf\" value=\".....\" />\n     \n    <group ns=\"first_pelican\">\n    \
    \  <node name=\"spawn_quad0\" pkg=\"gazebo\" type=\"spawn_model\" args=\"-urdf\
    \ -param /quad_urdf -model quad0 -x 0 -y 0 -z 3\" respawn=\"false\" output=\"\
    screen\"/>\n    </group>\n    \n    <group ns=\"second_pelican\">\n      <node\
    \ name=\"spawn_quad1\" pkg=\"gazebo\" type=\"spawn_model\" args=\"-urdf -param\
    \ /quad_urdf -model quad1 -x 1 -y 1 -z 3\" respawn=\"false\" output=\"screen\"\
    />\n    </group>\n\nThe same is valid if you declare namespaces without the group,\
    \ like:\n\n    <node name=\"foo\" ns=\"first_pelican\">\n      <!-- becomes /first_pelican/param1\
    \ -->\n      <param name=\"param1\" value=\"0\" />\n    </node>\n    \n    <!--\
    \ all params in the included files gets the prefix of /first_pelican -->\n   \
    \ <include file=\"file_to_include\" ns=\"first_pelican\" />\n\nHope that helps."
