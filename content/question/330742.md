  body_markdown: "RTAB-Map is a SLAM approach. When navigation is mentioned, `move_base`\
    \ is always used under the hood. RTAB-Map can do planning in its graph (i.e.,\
    \ topological planning) but still rely on `move_base` (i.e., metrical planning)\
    \ to make the robot move and avoid dynamic obstacles. The SLAM+planning capability\
    \ is described in this [paper](https://introlab.3it.usherbrooke.ca/mediawiki-introlab/images/8/87/LabbeAURO2017.pdf):\n\
    \n> M. Labb\xE9 and F. Michaud, \u201CLong-term\n> online multi-session graph-based\
    \ SPLAM\n> with memory management,\u201D in Autonomous\n> Robots, vol. 42, no.\
    \ 6, pp. 1133-1150,\n> 2018.\n\nFor SLAM alone, rtabmap can do visual and lidar\
    \ SLAM. See this [paper](https://introlab.3it.usherbrooke.ca/mediawiki-introlab/images/7/7a/Labbe18JFR_preprint.pdf)\
    \ focusing only on the SLAM part:\n\n> M. Labb\xE9 and F. Michaud, \u201CRTAB-Map\
    \ as\n> an Open-Source Lidar and Visual SLAM\n> Library for Large-Scale and Long-Term\n\
    > Online Operation,\u201D in Journal of Field\n> Robotics, vol. 36, no. 2, pp.\
    \ 416\u2013446,\n> 2019.\n\n**EDIT**: A list of ros nodes are described on [rtabmap_ros](http://wiki.ros.org/rtabmap_ros)\
    \ page, along with some demos including rosbags. Some ROS tutorials are [here](http://wiki.ros.org/rtabmap_ros/Tutorials).\
    \ For tools, the [DatabaseViewer](https://github.com/introlab/rtabmap/wiki/Tools#database-viewer)\
    \ may be the most useful tool to analyse the map."
