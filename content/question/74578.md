  body_markdown: "Since the pi_face_tracker package works with your laptop camera,\
    \ it sounds like your msi star cam clip is not supported by the uvc_cam driver.\
    \  You might try the [camera_umd](http://ros.org/wiki/camera_umd) driver instead\
    \ as follows.  I see you are using ROS Fuerte so you can install the camera_umd\
    \ package using the commands:\n\n    $ sudo apt-get install ros-fuerte-camera-umd\n\
    \    $ rospack profile\n\nI have added a suitable launch file for this driver\
    \ to the pi_face_tracker package.  To get the update run the commands:\n\n   \
    \ $ roscd pi_vision\n    $ svn update\n    $ rospack profile\n\nYou can now try\
    \ this launch file with your msi camera which is probably /dev/video1 on your\
    \ laptop.  Assuming the camera is plugged in to a USB port, run the command:\n\
    \n    $ roslaunch pi_face_tracker camera_node.launch device:=/dev/video1\n\nThen\
    \ test to see if you have an image by running the command:\n\n    $ rosrun image_view\
    \ image_view image:=/camera/image_raw\n\nIf you do not see an image, it is possible\
    \ you camera is not uvc-compatible.  If you do see an image, you can try pi_face_tracker.\
    \  Ctrl-C out of the image_view process then run:\n\n    $ roslaunch pi_face_tracker\
    \ face_tracker_uvc_cam.launch \n\n\n--patrick\n\nhttp://www.pirobot.org\n"
