  body_markdown: "The line extraction node is trying to publish the markers in the\
    \ `laser` frame, which doesn't exist because you probably haven't provided a transform.\
    \ You should set the `frame_id` parameter (see package parameter definitions [here](https://github.com/kam3k/laser_line_extraction#parameters))\
    \ to a frame which is defined in your [tf_tree](http://wiki.ros.org/tf/Debugging%20tools#Viewing_TF_trees). "
