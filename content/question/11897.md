  body_markdown: "The [erratic_description](http://www.ros.org/wiki/erratic_description)\
    \ package is a good and complete example for a moving mobile base using the DiffDrivePlugin\
    \ as a gazebo controller. Especially in `urdf/erratic_base.xacro` you can see\
    \ how to use the plugin in your urdf model.\n\nTo see a running example run:\n\
    \n    roslaunch erratic_description erratic_empty_world.launch\n\nThis starts\
    \ gazebo and spawns the erratic model. Then run\n\n    rosrun erratic_teleop erratic_keyboard_teleop\
    \ \n\nYou can now move the robot using the keys WASD.\n"
