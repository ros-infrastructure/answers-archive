I just finished a package for the serial dual motor driver board [MD49](http://www.robot-electronics.co.uk/htm/md49tech.htm), designed to use with two [EMG49 motors](http://www.robot-electronics.co.uk/htm/emg49.htm). 

The package can be used as a base_controller for a robot, driven with that board. It is for that publishing the encoder values and other information from the driver board and subscribing to /cmd_vel to steer drives.

So first i created a [upstream-repo](https://github.com/Scheik/md49_base_controller) (the one i develop in) and a release repo of that package, as suggested. Than i "bloom-released" the package as described in [this](http://wiki.ros.org/bloom/Tutorials/FirstTimeRelease) tutorial. The pull request was merged already.

First thing i stumbled about now, was the the following section in the README of the [release repo](https://github.com/Scheik/md49_base_controller-release), that was changed automatically by bloom:

    Version of package(s) in repository md49_base_controller:

 - upstream repository: https://github.com/Scheik/md49_base_controller.git
 - release repository: unknown
 - ...

As you can see above the release repo is unknown, although in the pull request it shows up correct:

    Increasing version of package(s) in repository md49_base_controller to 0.1.1-0:
    

 - upstream repository: https://github.com/Scheik/md49_base_controller.git
 - release repository: https://github.com/Scheik/md49_base_controller-release.git
 - ...

I am afraid, that something went wrong or is there no reason to be worried?
