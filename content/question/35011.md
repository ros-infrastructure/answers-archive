    The tutorial here works with Fuerte using the ros-fuerete-pr2 Ubuntu packages
    [http://www.ros.org/wiki/pr2_simulator/Tutorials/BasicPR2Controls](http://www.ros.org/wiki/pr2_simulator/Tutorials/BasicPR2Controls)

    Assuming you have set up the ROS environment, e.g.
    <pre>
      source /opt/ros/fuerte/setup.bash
    </pre>
    Then running the following commands should bring up a simulation in an
    empty world.
    <pre>
      export ROBOT=sim
      roslaunch pr2_gazebo pr2_empty_world.launch
    </pre>
    Then you can start keyboard teleop to drive it around
    <pre>
      roslaunch pr2_teleop teleop_keyboard.launch
    </pre>
