  body_markdown: "if you want to call the function motor_position in a regular basis\
    \ (let's say every x Hz) you call it during a loop in the main function. In this\
    \ case use a variable in the callback to save the value for later use in the main\
    \ function.\nIf you want to call it just once ever time you get a message from\
    \ the subscriber then call it in the Callback function.\nAs your code lets me\
    \ guess you want to do the first solution.\nYour problem is that you do not have\
    \ a while loop in the main.\n\nThe main should look somehow like this:\n\n   \
    \ int main(int argc, char **argv) {\n      ros::init(argc, argv, \"subscriber\"\
    );\n      ros::NodeHandle n;\n    \n      ros::Subscriber sub = n.subscribe(\"\
    topicname\", 1000, chatterCallback);\n    \n      ros::Rate loop_rate(10);\n \
    \     while (ros::ok()) {\n        motor_position(a);\n        ros::spinOnce();\n\
    \        loop_rate.sleep();\n      }\n      return 0;\n    }\n\n"
