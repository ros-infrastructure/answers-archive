  body_markdown: "Hi there Stef,\nregarding you question, what do you want to implement?\
    \ Do you need a planner? \nYou don't need PCL to use the navigation packages if\
    \ you build it yourself, but to do so you need to define what you want from the\
    \ navigation package, do you want planning? If you do just go [into the repository\
    \ ](https://github.com/ros-planning/navigation) and use one of the planners like:\n\
    \n - Carrot planner (this is mentioned in the tutorials)\n - Local planner \n\
    \ - Others ...\n\nand many others. Usually, the planner will just take the occupancy\
    \ grid, the costmap2D and the odometry of the robot.\nWhat PCL will do is build\
    \ the occupancy grid of the environment.\n\nIf you want to build the navigation\
    \ package yourself just download the repository, edit the `CMakeList` and the\
    \ `package.xml` to edit out the PCL but make sure to remove the packages where\
    \ it's being used!\n\nAll the best!!!"
