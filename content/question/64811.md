  body_markdown: "There are certainly other ways to make the pioneers move. You might\
    \ consider the [vanderbilt-p2os](http://www.ros.org/wiki/p2os-vanderbilt) stack.\
    \ It has been updated to be used with Groovy. We use it on the three pioneer robots\
    \ at Vanderbilt. \n\nThe velocity can be sent to the p2os stack by publishing\
    \ a `geometry_msgs::Twist` message to the topic `/base_controller/command`. You\
    \ can read the odometry with the topic `/pose`, which is of type `nav_msgs::Odometry`.\
    \ \n\nIf you need a Tutorial, this [one](http://www.ros.org/wiki/p2os-vanderbilt/Tutorials/C%2B%2B%20Pose%20Listener%20For%20P2OS)\
    \ will supply code for reading the position data, and this [one](http://www.ros.org/wiki/p2os-vanderbilt/Tutorials/C%2B%2B%20Velocity%20Controller%20for%20P2OS%20Robots)\
    \ will supply code for sending velocity commands. \n\n\n----------\n\n\nAccording\
    \ to the pastebin output, you checked out the package vanderbilt-ros-pkg... You\
    \ need to check out vanderbilt-p2os. It also appears you are trying to build from\
    \ your Downloads directory. \n\nSo, you need to make yourself a workstation. This\
    \ should create a workstation and download the code. \n\n\n    mkdir -p ~/ros_ws/src\n\
    \    cd ~/ros_ws/src\n    catkin_init_workspace\n    cd ~/ros_ws/\n    catkin_make\n\
    \    source devel/setup.bash\n    echo \"source ~/ros_ws/devel/setup.bash\" >>\
    \ ~/.bashrc\n    cd src && git clone https://github.com/allenh1/p2os.git\n   \
    \ source ../devel/setup.bash\n    rosmake p2os\n\n\n----------\n\nOk. The package\
    \ you mentioned is included within the PR2 packages. Easy fix, thankfully! I think\
    \ this should do it: \n\n    sudo apt-get install ros-groovy-pr2-controllers\n\
    \n\n----------\n\nThe error you got when you tried to run the above command is\
    \ a dependency problem. Do as the terminal says. You probably have some broken\
    \ packages on your system. As for trying the source, check to make sure you placed\
    \ the source in the `~/ros_ws/src` directory and built it there. If you failed\
    \ to put it within your ROS environment, ROS cannot find it. \n\n"
