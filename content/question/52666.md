    Hi, this is the same issue as [this question](http://answers.ros.org/question/28315/rosmake-pocketsphinx-issue/), and strangely enough, the same exact package.  ROS doesn't know where to look for the package you downloaded.  You have to set the environment variable ROS_PACKAGE_PATH to tell it where to look. Read about environment variables [here](http://www.ros.org/wiki/ROS/EnvironmentVariables).  Note that once you switch to the new ROS version, groovy, you won't have to do this.
