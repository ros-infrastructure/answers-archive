  body_markdown: "A static map gets loaded once during startup (or at least that\xB4\
    s the most common usage) and does not get modified over time. During Simultaneous\
    \ Localization and Mapping (SLAM), the map changes over time as the robot localizes\
    \ itself in the environment and updates the map.\n\nA .pgm map is essentially\
    \ just an image file and it does not matter in which way it was created ([gmapping](http://wiki.ros.org/gmapping),\
    \ [hector_mapping](http://wiki.ros.org/hector_mapping) or even just drawing it\
    \ yourself). You can open a map created with gmapping using some image editor,\
    \ change parts of it, save it and then use it as a static map for AMCL."
