  body_markdown: "A simple solution is to edit the openni_kinect/openni_launch/launch/includes/device.launch\
    \ file and add the following param setting to the driver nodelet\n\n    <param\
    \ name=\"depth_registration\" value=\"true\" />\n\nAn alternative solution which\
    \ works for me is to use the [dynparam command-line tool](http://www.ros.org/wiki/dynamic_reconfigure#dynparam_set)\
    \ from inside your own launch script, e.g.\n\n    <node pkg=\"dynamic_reconfigure\"\
    \ type=\"dynparam\" name=\"dynparam\" args=\"set /camera/driver depth_registration\
    \ true\" />\n    \nwhich avoids the need to edit the launch files in the openni_kinect\
    \ package."

Hello!

My problem is the following: I use the openni_kinect package to get rgb/depth feeds from my kinect. I start the ROS nodes for this by using

    roslaunch openni_launch openni.launch

My program needs depth registration to function properly (disabled by default), so far I have enabled this by running

    rosrun dynamic_reconfigure reconfigure_gui

and setting the parameter manually, but it is quickly getting old. Is there a way to turn the depth registration on by default in my roslaunch?
