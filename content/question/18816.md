  body_markdown: "The controller cannot stop the joint if the PID gains are set to\
    \ `common::PID(0, 0, 0)`.\n\nThe gains control how much torque the controller\
    \ will apply. All zeros means everything in the equation used to calculate the\
    \ torque applied by the controller is being multiplied by zero. Some torque needs\
    \ to be applied to stop a moving joint.\n\nOften the gains on the controller are\
    \ set once at startup.\n\n    if (update_num == 0)\n    {\n      // Initialize\
    \ the controller with the gains to use\n      this->jointController->SetPositionPID(name,\
    \ common::PID(100, 0, 0));\n    }\n    else if (update_num == X)\n    {\n    \
    \  // time to tell the joint to go to position 1.57\n      this->jointController->SetPositionTarget(name,\
    \ 1.57);\n    }\n    else if (update_num == Y)\n    {\n      // time to tell the\
    \ joint to go back to position 0\n      this->jointController->SetPositionTarget(name,\
    \ 0);\n    }\n    // The controller applies torque when it is updated.\n    //\
    \ This must be called every update that the controller should be controlling the\
    \ joint position\n    this->jointController->Update();\n\nYou might be interested\
    \ in reading \nhttps://en.wikipedia.org/wiki/PID_controller#Mathematical_form"
