    \ the position in the bash file and pass them as arguments in the launchfile:\
    \ \n\nFIRST: In the bashfile use, and replace [RANGE] with the numeric range.\n\
    \n    x_pos=$(bc <<< \"scale=2;$(($RANDOM % 10))*[RANGE]\")\n    y_pos=$(bc <<<\
    \ \"scale=2;$(($RANDOM % 10))*[RANGE]\")\n\nSECOND: Then call the roslaunch:\n\
    \n    roslaunch your_pkg project.launch x_pos:=$x_pos y_pos:=$y_pos&\n\nTHIRD:\
    \ In the project.lauch init the pos:\n\n      <!-- declare arg to be passed in\
    \ -->\n      <arg name=\"x_pos\" /> \n      <arg name=\"y_pos\" />\n\n    ...\
    \ other launch stuff ...\n\nLAST: Get the randomized parameter with:\n\n     \
    \  <node pkg=\"gazebo_ros\" type=\"spawn_model\" name=\"spawn_urdf\" args=\"-urdf\
    \ -model turtlebot3_waffle_pi -x $(arg x_pos) -y $(arg y_pos) -z 0 -Y 0 -param\
    \ robot_description\" />\n\n\nIt is also possible to write the generated values\
    \ in the terminal via `echo random x: $x_pos` in the bash file.\nThis works now\
    \ just fine and is also portable."
