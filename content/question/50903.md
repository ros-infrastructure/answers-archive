  body_markdown: "Your approach is going to run into some issues.  \n\nrospack exports\
    \ are manually written in your [manifest.xml](http://www.ros.org/wiki/Manifest).\
    \  They are the include directories which you need to export to packages which\
    \ depend on your package.  This is not necessarily all include directories needed\
    \ to compile the package itself.  \n\nIf you need include directories in your\
    \ own package you should be using include_directories in your [CMakeLists.txt](http://www.ros.org/wiki/rosbuild/CMakeLists)\n\
    \nAnd the correct thing to do is to add the target you want in cmake, and then\
    \ have the makefile invoke cmake && make mytarget like cmake.mk does.  "

Suppose I'd like to retrieve all the build flags to be able to integrate syntax checking into my favorite editor for the package my_vision. I'd need to add a check-syntax target to the cmake.mk file according to something like this:

    .PHONY: check-syntax
    check-syntax:
            gcc -Wall -fsyntax-only $(shell rospack export --lang=cpp --attrib=cflags) $(CHK_SOURCES)

`rospack export` does not list /home/me/ros/my_vision/include as a include directory, even though the headers I've place here will still be found during compilation. So:

 1. How does the ROS build system find my custom header files?
 
 2. Can I also use this functionality in the cmake.mk file?
