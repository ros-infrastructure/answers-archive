  body_markdown: "Presumably, you are using C++. If that is the case, you'd likely\
    \ want to look to the `doTransform` methods of tf2. For example, there is an [overload\
    \ of doTransform](http://docs.ros.org/melodic/api/tf2_geometry_msgs/html/c++/namespacetf2.html#abe5bbc43e831686558fcc1b8f1bc80cb)\
    \ specifically for `geometry_msgs/Point` types. So if you had your point expressed\
    \ in the B frame `P_b`, you could lookup the transform from A to B, and then apply\
    \ that to B to get the point in the A frame.\n\n**EDIT**\n\nAdding a small Python\
    \ example that assumes the `tf` tree already has a `frame_a` and a `frame_b` available.\n\
    \n    #!/usr/bin/env python\n    \n    import rospy\n    import tf\n    import\
    \ tf2_ros\n    import tf2_geometry_msgs\n    \n    rospy.init_node(\"demo_lookup\"\
    )\n    \n    tfbuffer = tf2_ros.Buffer()\n    listener = tf2_ros.TransformListener(tfbuffer)\n\
    \    \n    tf1_listener = tf.TransformListener()\n    \n    # give listeners time\
    \ to receive required transforms\n    rospy.sleep(1.0)\n    \n    # make Pose\
    \ in the 'b' frame\n    p_b = tf2_geometry_msgs.tf2_geometry_msgs.PoseStamped()\n\
    \    p_b.header.frame_id = 'frame_b'\n    p_b.pose.position.y = 0.5\n    p_b.pose.orientation.w\
    \ = 1.0\n    \n    # Use tf2 to transform pose to the 'a' frame and print results.\
    \ Best practice\n    # would wrap this in a try-except:\n    t_a_b = tfbuffer.lookup_transform('frame_a',\
    \ 'frame_b', rospy.Time.now(), rospy.Duration(1.0))\n    p_a = tf2_geometry_msgs.do_transform_pose(p_b,\
    \ t_a_b)\n    rospy.loginfo(\"Pose expressed in 'frame_a' using tf2: \\n%s\\n\"\
    , str(p_a))\n    \n    # Use tf to transform pose to the 'a' frame and print results.\
    \ Best practice\n    # would wrap this in a try-except:\n    p_a_tf1 = tf1_listener.transformPose('frame_a',\
    \ p_b)\n    rospy.loginfo(\"Pose expressed in 'frame_a' using tf: \\n%s\\n\",\
    \ str(p_a_tf1))"
