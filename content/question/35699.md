  body_markdown: "In your `.world` file, you can specify the desired update rate for\
    \ Gazebo using the `<updateRate>` tag. \n\n    <physics:ode>\n       ...\n   \
    \    <stepTime>STEP_TIME</stepTime>\n       <updateRate>UPDATE_RATE</updateRate>\n\
    \       ...\n    </physics:ode>\n\nThe value of `<updateRate>` has three configurations:\n\
    \n 1. UPDATE_RATE < 0: Gazebo will attempt to run the simulation in real time\n\
    \n 2. UPDATE_RATE = 0: Gazebo will attempt to run the simulation as fast as possible\n\
    \n 3. UPDATE_RATE > 0: This number will represent the desired physics update frequency.\
    \ In this case, Gazebo will run STEP_TIME*UPDATE_RATE times reality.\n\n\nIf Gazebo\
    \ is not able to update at your desired rate, it will update as fast as it can.\
    \ It's based on the system's computing power, so more nodes = less CPU time for\
    \ Gazebo. "
