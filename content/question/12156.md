     There's an [example world](https://bitbucket.org/osrf/gazebo/src/9444b31b21001415a2dff76c5532698dc0275161/worlds/lights.world?at=gazebo_3.1&fileviewer=file-view-default) from gazebo 3 which contains many lights, but only one of them is directional.

    Have you run gazebo in verbose mode to see if you get any errors? The `<origin>` tag for example seems not to be part of SDF, so you should see a warning like:

        XML Element[origin], child of element[light] not defined in SDF. Ignoring[origin]. You may have an incorrect SDF file, or an sdformat version that doesn't support this element.

    Another thing you can look at are the [previous versions](https://bitbucket.org/osrf/gazebo_models/src/e024fe922c810f468e2a7ab277750354465478cd/sun/model-1_2.sdf?at=default&fileviewer=file-view-default) of the `sun` model.

    In any case, if the problem is wrong SDF, Gazebo shouldn't crash. I suggest [ticketing an issue](https://bitbucket.org/osrf/gazebo/issues/new) for that.
