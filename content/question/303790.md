    The ROS [Master_API](http://wiki.ros.org/ROS/Master_API) will probably be your friend. Please also look at #q260633, which covers parts of your question.

    With `getPublishedTopics` you can create a list of all available topics. Then use `getTopicTypes` to create the subscribers accordingly.

    You might find a good code example for subscribers to unknown topic types in the source code of [rostopic echo]( ros_comm/tools/rostopic/src/rostopic/__init__.py ).
