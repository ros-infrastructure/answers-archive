  body_markdown: "Hi,\n\nTime in  ROS have a standard representation :\nhttp://wiki.ros.org/roscpp/Overview/Time\n\
    \nYou can test is with some simple command : \n\n    roscore&\n    rostopic pub\
    \ /topic_name geometry_msgs/PoseStamped \"header: auto\n    pose:\n      position:\n\
    \        x: 0.0\n        y: 0.0\n        z: 0.0\n      orientation:\n        x:\
    \ 0.0\n        y: 0.0\n        z: 0.0\n        w: 0.0\"  -r 1 &\n    rostopic\
    \ echo --offset /topic_name/header\n\nThe result of those commands will be : \n\
    \    \n\n    seq: 6\n    stamp:\n      secs: -71\n      nsecs: 997840166\n   \
    \ frame_id: ''\n    ---\n    seq: 7\n    stamp:\n      secs: -72\n      nsecs:\
    \ 998944997\n    frame_id: ''\n    ---\n    seq: 8\n    stamp:\n      secs: -73\n\
    \      nsecs: 998456955\n    frame_id: ''\n    ---\n\n\nThere is indeed 1 second\
    \ of offset between messages (1 second because of the `-r 1` in rostopic pub),\
    \ displayed as a negative value because the message stamp is behind the current\
    \ timestamp.\nIf you fill the stamp with 'now' value every 1 second, the duration\
    \ will be -1 secs everytime.\n\n\n"
