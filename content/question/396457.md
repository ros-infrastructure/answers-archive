Hi,

I am writing a MicroROS subscriber for the sensor_msgs/msg/Joy message type, running on an ESP32 board.

I can see in RQT that the subscriber is subscribed to the /joy topic. I have given it the following callback function:

    void subscription_callback(const void * msgin)
    {
    	const sensor_msgs__msg__Joy * msg = (const sensor_msgs__msg__Joy *)msgin;
    	gpio_set_level(BLINK_GPIO, msg->buttons.data[0]);
    }

This should turn on of off the GPIO pin depending on the state of button 0. However I get no response, so I think I might be accessing the joy message type incorrectly. Can anybody confirm this?
