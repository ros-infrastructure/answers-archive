  body_markdown: " Hi,\n\nThe map disappears because there are two nodes publishing\
    \ the same topic `/map`: [map_server](http://wiki.ros.org/map_server) and [rtabmap](http://wiki.ros.org/rtabmap_ros#rtabmap).\
    \ Remap to different topic name or use only the one published by rtabmap. When\
    \ launching the node with a previous map (localization mode), the map published\
    \ by rtabmap is empty until a localization is found (look the warnings on the\
    \ console for possible reasons of localization rejection). The simulated environment\
    \ doesn't have a lot of visual features, I tuned the parameters to get more visual\
    \ features (using GFTT/BRIEF instead of ORB) so that it is easier to relocalize,\
    \ here is a simplified `turtlebot_rtabmap_navigation.launch`:\n\n    <!-- Turtlebot\
    \ navigation simulation with RTAB-Map -->\n    <launch>\n    \n      <arg name=\"\
    database_path\"     default=\"rtabmap.db\"/>\n      <arg name=\"localization\"\
    \      default=\"true\"/>\n    \n      <!-- Mapping -->\n      <group ns=\"rtabmap\"\
    >\n        <node name=\"rtabmap\" pkg=\"rtabmap_ros\" type=\"rtabmap\" output=\"\
    screen\">\n    \t  <param name=\"database_path\"       type=\"string\" value=\"\
    $(arg database_path)\"/>\n    \t  <param name=\"frame_id\"            type=\"\
    string\" value=\"base_footprint\"/>\n    \t  <param name=\"odom_frame_id\"   \
    \    type=\"string\" value=\"odom\"/>\n    \t  <param name=\"subscribe_laserScan\"\
    \ type=\"bool\"   value=\"true\"/>\n    \t\n    \t  <!-- inputs -->\n    \t  <remap\
    \ from=\"scan\"            to=\"/scan\"/>\n    \t  <remap from=\"rgb/image\" \
    \      to=\"/camera/rgb/image_raw\"/>\n      \t  <remap from=\"depth/image\" \
    \    to=\"/camera/depth/image_raw\"/>\n      \t  <remap from=\"rgb/camera_info\"\
    \ to=\"/camera/rgb/camera_info\"/>\n    \n    \t  <!-- outputs -->\n         \
    \     <remap from=\"grid_map\" to=\"/map\"/> <!-- input for move_base costmap\
    \ -->\n    \t\n    \t  <!-- RTAB-Map parameters -->\n    \t  <param name=\"RGBD/LocalLoopDetectionSpace\"\
    \ type=\"string\" value=\"true\"/>\n    \t  <param name=\"RGBD/OptimizeSlam2D\"\
    \          type=\"string\" value=\"true\"/>      \n    \t  <param name=\"Kp/MaxDepth\"\
    \                  type=\"string\" value=\"4.0\"/>\n    \t  <param name=\"Kp/DetectorStrategy\"\
    \          type=\"string\" value=\"6\"/> <!-- GFTT/BRIEF -->\n    \t  <param name=\"\
    GFTT/MinDistance\"             type=\"string\" value=\"5\"/>\n    \t  <param name=\"\
    LccIcp/Type\"                  type=\"string\" value=\"2\"/> <!-- ICP 2D -->\n\
    \    \t  <param name=\"LccIcp2/CorrespondenceRatio\"  type=\"string\" value=\"\
    0.1\"/> \n    \t  \n    \t  <!-- localization mode -->\n    \t  <param     if=\"\
    $(arg localization)\" name=\"Mem/IncrementalMemory\" type=\"string\" value=\"\
    false\"/>\n    \t  <param unless=\"$(arg localization)\" name=\"Mem/IncrementalMemory\"\
    \ type=\"string\" value=\"true\"/>\n    \t  <param name=\"Mem/InitWMWithAllNodes\"\
    \ type=\"string\" value=\"$(arg localization)\"/> \n        </node>\n      </group>\n\
    \    \n      <!-- ******* Navigation - Move Base ******* -->\n      <include file=\"\
    $(find turtlebot_navigation)/launch/includes/move_base.launch.xml\"/>\n    \n\
    \    \n      <!-- ******* Visualization of the Turtlebot on Rviz ******* -->\n\
    \      <node name=\"rviz\" pkg=\"rviz\" type=\"rviz\" args=\"-d $(find turtlebot_rviz_launchers)/rviz/navigation.rviz\"\
    />\n    \n    </launch>\n\nFor the second step in your instructions, use either:\n\
    \n    a) SLAM mode\n    $ roslaunch turtlebot_rtabmap_navigation.launch localization:=false\n\
    \    \n    b) Localization-only mode\n    $ roslaunch turtlebot_rtabmap_navigation.launch\
    \ localization:=true\n\ncheers"
