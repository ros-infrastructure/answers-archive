  body_markdown: "I came across this error as well when trying to compile the vision_opencv\
    \ package. The fix is on line 325 where it defines the 'dims' variable as a lont\
    \ int. \n\n    long int dims[] = {mat.rows, mat.cols, mat.channels()};\n\nChange\
    \ that to an int so it reads \n\n    int dims[] = {mat.rows, mat.cols, mat.channels()};\n\
    and it should compile without issue."
