  body_markdown: "From what I can tell, the core of your question is \"how can I find\
    \ the source code of a package?\" \n\n### Edit:\n\nA quicker way to do this, as\
    \ pointed out by @gvdhoorn, is to add the following line to `/etc/apt/sources.list.d/ros-latest.list`:\n\
    \n    + deb-src http://packages.ros.org/ros/ubuntu xenial main\n\nThen, you can\
    \ run \n\n    sudo apt-get source ros-ROSDISTRO-PACKAGE\n\nto download a copy\
    \ of all of the source code to the current directory. Now that you have the source,\
    \ follow step 4 to find the main.\n\n### Original:\n\nLike Jayess mentioned, installing\
    \ ROS packages from `apt` won't download the source code to your computer. This\
    \ is something I've ran into several times before, and I have a quick and dirty\
    \ procedure for it:\n\n 1. Figure out the name of the ROS package that I actually\
    \ want to look at. In this case, you already know it's `gmapping`.\n 2. Find the\
    \ package's page on http://wiki.ros.org. Usually a Google search brings this up.\
    \ For `gmapping`, this page is http://wiki.ros.org/gmapping. \n 3. On the wiki,\
    \ most packages link to their source code, usually right below the maintainer\
    \ list (see the [MoveIt page](http://wiki.ros.org/moveit) for an example).  `gmapping`\
    \ is unique in this case, because they are mostly external to ROS. However, they\
    \ provide a link on their page to the [external documentation](https://openslam-org.github.io/gmapping.html),\
    \ which contains a link to the [Github source code](https://github.com/OpenSLAM-org/openslam_gmapping).\n\
    \ 4. Now that you're at the source code, you probably want to find some launch\
    \ file, so you follow the code from the beginning. Again, `gmapping` is unique\
    \ because they aren't a native ROS project.  At this point, I just had to do some\
    \ smart Googling to find the real [Github](https://github.com/ros-perception/slam_gmapping),\
    \ specifically for the ROS gmapping code. Now, going to the [launch file](https://github.com/ros-perception/slam_gmapping/blob/hydro-devel/gmapping/launch/slam_gmapping_pr2.launch#L3),\
    \ we see that it starts a single node, named `slam_gmapping`.  This is the name\
    \ of the executable started, so if we go over to the [CMakeLists.txt](https://github.com/ros-perception/slam_gmapping/blob/hydro-devel/gmapping/CMakeLists.txt#L14),\
    \ we see that this executable is compiled from `slam_gmapping.cpp` and `main.cpp`.\
    \ Now you're at the start of the code!"
