    MoveIt has a database interface termed "warehouse", but this is not active by default because you need to run a database somewhere.
    At the moment, the only working implementation I'm aware of is https://github.com/ros-planning/warehouse_ros_mongo .

    So if you want to store your robot states or planning scenes, you will have to setup a MongoDB and use this plugin.

    Note that if you only want to store a small number of states, you can do that [in the srdf file of your moveit_config](https://github.com/TAMS-Group/tams_ur5_setup/blob/master/tams_ur5_setup_moveit_config/config/tams_ur5_setup.srdf#L31). The setup assistant also provides a panel to add these states there.
