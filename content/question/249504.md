    This is only a warning. Your Xtion should still work.

    > OpenNI tries to set the USB async
    > thread priority to critical. This
    > works on Linux only with root
    > privileges. For a normal user, the
    > program will throw this warning. To
    > get rid of this warning, run the
    > program as root. [source](https://codeyarns.com/2015/08/05/openni-usb-thread-priority-warning/)
