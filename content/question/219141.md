  body_markdown: "I haven't tried this solution myself. But this may work:\n\n1. Add\
    \ `--upstream` option to `rosinstall_generator ros_comm ..` command:\n\n<pre>\n\
    rosinstall_generator ros_comm --upstream --rosdistro indigo --deps --wet-only\
    \ > indigo-ros_comm-wet.rosinstall\n</pre>\n\n2. Modify `indigo-ros_comm-wet.rosinstall`\
    \ and change the URI of `ros_comm` repo to your own fork. Make sure to change\
    \ the `version` field to appropriate branch/tag of your fork. \n\n<pre>\n    -\
    \ git:\n    local-name: ros_comm\n    uri: https://github.com/asundaresan/ros_comm\n\
    \    version: 1.11.15\n</pre>\n\nTo ensure maximum compatibility, it is a good\
    \ practice to rebase your changes on top of the current stable version of `ros_comm`.\
    \ *1.11.15* in this case."

I want to compile ROS from source. To do this, I can follow the instructions from [http://wiki.ros.org/indigo/Installation/Source](http://wiki.ros.org/indigo/Installation/Source), specifically the lines

    rosinstall_generator ros_comm --rosdistro indigo --deps --wet-only > indigo-ros_comm-wet.rosinstall 
    wstool init -j8 src indigo-ros_comm-wet.rosinstall
However, I want to use my own forked version of ros_comm packages from [https://github.com/asundaresan/ros_comm](https://github.com/asundaresan/ros_comm)

It is not clear to me how I can build a bare-bones ROS from source using the above forked version. I'd be grateful for any pointers or instructions for the same. I could not find any.
