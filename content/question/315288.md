    I don't know of any way you can do this with the standard command line tools. However if you don't mind getting your hands dirty, you could use the [rosbag_api](http://wiki.ros.org/rosbag/Code%20API) to write a simple node that published the sensor messages from a bag at the desired rate.

    The example on the page I linked to prints every message out on the screen. But you would want to modify it so that it only publishes messages on the desired topic, and at the rate you want.

    Hope this helps.
