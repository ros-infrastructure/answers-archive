  body_markdown: "Hi, \n\nSome of the paths could be defined in `LD_LIBRARY_PATH`\
    \ too. If you have installed ROS from Debian packages these plugins are in `/opt/ros/<rosdistro>/`\
    \ or in your install directory if you installed ROS from sources. A command to\
    \ find the library could be:\n\n```\ndu -a /opt/ros/<rosdistro> | grep libgazebo_ros_multicamera.so\n\
    ```\n\nor \n\n```\ndu -a <path to your workspace> | grep libgazebo_ros_multicamera.so\n\
    ```\n"
