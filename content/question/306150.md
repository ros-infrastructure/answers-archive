  body_markdown: "With gmapping just adding a static frame for `odometry` isn't enough\
    \ because you have paramaters like :\n\n    ~linearUpdate (float, default: 1.0)\n\
    \        Process a scan each time the robot translates this far \n   \n    ~angularUpdate\
    \ (float, default: 0.5)\n        Process a scan each time the robot rotates this\
    \ far \n\nyour map would be updated only if you move, and I'm pretty sure there\
    \ are other params like that. You can check [#q63457](https://answers.ros.org/question/63457/gmapping-without-odom/),\
    \ they already discussed about `gmapping` without `odom`.\n\nSo yes, `hector_mapping`\
    \ is exactly what you are looking for."
