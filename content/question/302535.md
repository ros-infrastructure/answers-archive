  body_markdown: "There are few mistakes in your code :\n\n - You shouldn't initialize\
    \ the publisher inside the callback it can create errors. Initialize it in the\
    \ main function. \n\n - You don't have to subscribe to any topic if you only want\
    \ to publish a speed command.\n   \n - You are trying to publish data on the topic\
    \ \"/gazebo\" but it's actually the name of the gazebo node so it cannot work.\n\
    \n - Since you have a cmd_vel multiplexer you can publish data on the topic `/cmd_vel`\
    \ OR `/mobile_base/commands/velocity`\n\n -  You should set `vel_msg.linear.x`\
    \ to some value (1 for example) to directly see your robot moving (it will be\
    \ easier for you to debug)\n\nIt should work fine with those change.\n \n"

Hello! I'm runnning TurtleBot on rviz, and I want to publish Twist messages to the "/gazebo" node  in order to control robot's velocity.<br><br>
I wrote a publisher as below but it didn't work. <br>
How can I solve this ploblem? Could you tell me please?

my code↓↓

    #!/usr/bin/env python
    import rospy
    from geometry_msgs.msg import Twist
    def callback(data):
        pub=rospy.Publisher("/gazebo",Twist,queue_size=10)
        vel_msg=Twist()
        print(data.linear.x,data.angular.z)
        vel_msg.linear.x=0
        vel_msg.angular.z=0
        pub.publish(vel_msg)

    def main():
        rospy.init_node("GetVelocity")
        sub=rospy.Subscriber("/mobile_base/commands/velocity",Twist,callback)
        rospy.spin()
    
    if __name__== "__main__":
        try:
            main()
        except rospy.ROSInterruptException:
            pass
