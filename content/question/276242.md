    Like @clyde and @lucasw are pointing, the solution is at the wiki page.

    You basically have to use the `rosconsole` class of roscpp (ros.h) to change the logger level.
    After importing `console.h` you need to do the following code call:

        ros::console::set_logger_level(ROSCONSOLE_DEFAULT_NAME, ros::console::levels::Debug)

    As you can see, the last argument indicates the level of debug you want to have for that node.
    After that call, you must notify, that the logger level has changed. For that, do the following:

        ros::console::notifyLoggerLevelsChanged()

    That is all! That simple.

    Finally, have a look at [this video](https://youtu.be/jGA3RrNP7nk) that shows how to dynamically change the logger level for a node, showing how different messages get activated or deactivated based on the log level.

    Hope it helps!
