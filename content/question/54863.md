  body_markdown: "One ROS runtime work around (at least it works in Openni2) is this\
    \ in the next order (ideally in your Class destructor, or at the end of your main\
    \ function before the program ends) :\n\n    void StreamingClass::~StreamingClass()\n\
    \    {\n        ros::spinOnce();\n        /// close streaming\n        if (color_video_stream_.isValid()\
    \ == true)\n          color_video_stream_.stop();\n        if (depth_video_stream_.isValid()\
    \ == true)\n           depth_video_stream_.stop();\n\n         /// detroy video\
    \ streaming objects as good practice,\n         if (color_video_stream_.isValid()\
    \ == true)\n            color_video_stream_.destroy();\n         if (depth_video_stream_.isValid()\
    \ == true)\n            depth_video_stream_.destroy();\n \n         if (camera_device_.isValid()\
    \ == true)\n           camera_device_.close();\n         nite::NiTE::shutdown();\n\
    \         openni::OpenNI::shutdown();\n    }\n\nDo it in that order, and that\
    \ should take care of the problem, and will always shutdown the camera software.\n\
    One thing though, if your camera nodelet had crashed right before trying this\
    \ code, then unplug and plug the camera back in. Or better yet, restart your computer!!!!"
