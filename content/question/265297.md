    The rate at which tf_echo prints to the screen is a command line argument and does not reflect the underlying message rates.

    If you want to determine the rate of publishing you should use tf_monitor. There's a [tutorial on debugging](http://wiki.ros.org/tf/Tutorials/Debugging%20tf%20problems).
