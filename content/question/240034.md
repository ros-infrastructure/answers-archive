  body_markdown: "If images are streamed from another computer, I would suggest to\
    \ add `compressed:=true` to your line:\n\n    $ roslaunch rtabmap_ros rgbd_mapping.launch\
    \ rtabmap_args:=\"--delete_db_on_start\" rviz:=true rtabmapviz:=false compressed:=true\n\
    \nYour remote computer will then subscribe to compressed image topics instead\
    \ of the raw ones, saving a lot of network bandwidth. \n\nYou may also want to\
    \ reduce the frame rate of your camera to ~10/15 Hz to save even more bandwidth,\
    \ similar to this [example](http://wiki.ros.org/rtabmap_ros/Tutorials/SetupOnYourRobot#Remote_visualization:_bandwidth_efficiency).\
    \ You could use [rtabmap_ros/data_throttle](http://wiki.ros.org/rtabmap_ros#rtabmap_ros.2BAC8-data_throttle)\
    \ nodelet on adroid to reduce the frame rate, if the driver used for the camera\
    \ doesn't have the option. Here is an example loading the nodelet in the camera\
    \ nodelet manager of your camera:\n\n      <group ns=\"camera\">\n        <node\
    \ pkg=\"nodelet\" type=\"nodelet\" name=\"data_throttle\" args=\"load rtabmap_ros/data_throttle\
    \ camera_nodelet_manager\" output=\"screen\">\n          <param name=\"rate\"\
    \ type=\"double\" value=\"10.0\"/>\n    \n          <remap from=\"rgb/image_in\"\
    \       to=\"rgb/image_rect_color\"/>\n          <remap from=\"depth/image_in\"\
    \     to=\"depth_registered/image_raw\"/>\n          <remap from=\"rgb/camera_info_in\"\
    \ to=\"rgb/camera_info\"/>\n    \n          <remap from=\"rgb/image_out\"    \
    \   to=\"data_throttled_image\"/>\n          <remap from=\"depth/image_out\" \
    \    to=\"data_throttled_image_depth\"/>\n          <remap from=\"rgb/camera_info_out\"\
    \ to=\"data_throttled_camera_info\"/>\n        </node>\n      </group>\n\nThe\
    \ line above would be modified with the correct topics:\n    \n    $ roslaunch\
    \ rtabmap_ros rgbd_mapping.launch rtabmap_args:=\"--delete_db_on_start\" rviz:=true\
    \ rtabmapviz:=false compressed:=true rgb_topic:=/camera/data_throttled_image depth_registered_topic:=/camera/data_throttled_image_depth\
    \ camera_info_topic:=/camera/data_throttled_camera_info\n\n**EDIT**\n\nFor the\
    \ first example, you can verify that you are correctly receiving the compressed\
    \ topics on the laptop with:\n\n     $ rostopic hz /camera/rgb/image_rect_color/compressed\n\
    \     $ rostopic hz /camera/depth_registered/image_raw/compressedDepth\n\n**EDIT\
    \ 2**\n\nMaking sure that `ROS_IP` is set on both computers (to avoid a computer\
    \ not seeing topics of the other), it works if I do this (well openni2_launch\
    \ can be used instead of freenect_launch):\n\n A) computer A:\n\n    $ roslaunch\
    \ freenect_launch freenect.launch depth_registration:=true\n\n B) computer B:\n\
    \n    $ roslaunch rtabmap_ros rgbd_mapping.launch rtabmap_args:=\"--delete_db_on_start\"\
    \ rviz:=true rtabmapviz:=false compressed:=true\n\nMake sure to uncheck Image\
    \ display in RVIZ to avoid subscribing to raw image, which would results in **30\
    \ MB/sec** bandwidth!! Removing the Image display or setting `Transport hint`\
    \ to \"theora\" instead of \"raw\", I have **3.5 MB/sec** bandwidth. If I do the\
    \ `data_throttle` example with 10 Hz instead of 30 Hz framerate:\n\n A) computer\
    \ A:\n\n    $ roslaunch freenect_launch freenect.launch depth_registration:=true\n\
    \    $ roslaunch data_throttle.launch\n\n B) computer B:\n\n    $ roslaunch rtabmap_ros\
    \ rgbd_mapping.launch rtabmap_args:=\"--delete_db_on_start\" rviz:=true rtabmapviz:=false\
    \ compressed:=true rgb_topic:=/camera/data_throttled_image depth_registered_topic:=/camera/data_throttled_image_depth\
    \ camera_info_topic:=/camera/data_throttled_camera_info\n\nWith this setup, I\
    \ have now **1 MB/sec** bandwidth.\n\n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/1469207177199655.png)\n\
    \ncheers"
