 I'm trying to embed a visualisation of a robot into a custom program. To this end, I am using a structure similar to the librviz tutorial at the ROS wiki [here](http://wiki.ros.org/rviz/Tutorials/Librviz%3A%20Incorporating%20RViz%20into%20a%20Custom%20GUI). I've managed to get it rendering appropriately on its own in a separate window, however I want to embed it into our Qt QML based program. I can get a viewport embedded and rendering, however the QML frame is not updated since the QML scenegraph doesn't know it's been updated. 

I've got an [Ogre::RenderTargetListener](https://www.ogre3d.org/docs/api/1.9/class_ogre_1_1_render_target_listener.html) that tells me it's rendering, and I can save the rendered frame to a file from within the listener's [postRenderTargetUpdate()](https://www.ogre3d.org/docs/api/1.9/class_ogre_1_1_render_target_listener.html#a722f37475162c91ee0dd6cebf03e63a3) call, however I would like to instead save the rendered frame to memory so it can then be displayed via a QQuickPaintedItem's custom paint() function. The [Ogre::RenderTarget](https://www.ogre3d.org/docs/api/1.9/class_ogre_1_1_render_target.html) base class has [copyContentsToMemory()](https://www.ogre3d.org/docs/api/1.9/class_ogre_1_1_render_target.html#a6277cd30654d93dbfa7bb07275bbceb4) which takes an [Ogre::PixelBox](https://www.ogre3d.org/docs/api/1.9/class_ogre_1_1_pixel_box.html) which stores the size of an image and a pointer to where to place it, but trying to fill it out with the values of the render target causes an [Ogre::InvalidParametersException](https://www.ogre3d.org/docs/api/1.9/class_ogre_1_1_invalid_parameters_exception.html#ac6276640f16c331e952b71f3a174bd8f) due to no depth parameter returned from the render target's [getMetrics()](https://www.ogre3d.org/docs/api/1.9/class_ogre_1_1_render_target.html#ad4e95b76827cb41d936ccb4a8c308c6e) function. If there's no width or height, then it does not throw this exception, but it also doesn't do anything except return immediately.
