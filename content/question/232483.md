  body_markdown: "The `convert_pointcloud_to_image` node in [pcl_ros](http://wiki.ros.org/pcl_ros#convert_pointcloud_to_image)\
    \ does exactly what you're looking for.\n\n---\n\n**Edit:** The reason for that\
    \ crash you're seeing is that you put in an unorganized point cloud (i.e., height\
    \ = 1). The `convert_pointcloud_to_image` node can only process [organized point\
    \ clouds](http://pointclouds.org/documentation/tutorials/basic_structures.php).\
    \ For example, this is how the data from an Asus Xtion looks like:\n\n    $ rostopic\
    \ echo -n1 /camera/depth_registered/points | grep -v data\n    header: \n    \
    \  seq: 0\n      stamp: \n        secs: 1445245860\n        nsecs: 100976221\n\
    \      frame_id: camera_rgb_optical_frame\n    height: 240\n    width: 320\n \
    \   fields: \n      - \n        name: x\n        offset: 0\n        count: 1\n\
    \      - \n        name: y\n        offset: 4\n        count: 1\n      - \n  \
    \      name: z\n        offset: 8\n        count: 1\n      - \n        name: rgb\n\
    \        offset: 16\n        count: 1\n    is_bigendian: False\n    point_step:\
    \ 32\n    row_step: 10240\n    is_dense: False\n\nNotice that height !=1, which\
    \ means this is an organized point cloud."
