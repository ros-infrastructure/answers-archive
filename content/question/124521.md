  body_markdown: "This is probably happening because in your bag you have a map or\
    \ transformations that are also being created by the nodes you are running to\
    \ post-process the bag file. So, for example, you can have a map being published\
    \ from your bag and a map being published from hector_slam. \n\nYou may try to\
    \ create a bag file only with the laser topic:\n\n    rosbag record -O name /scan\n\
    \nIn resume: take a look at [hector_mapping](http://wiki.ros.org/hector_mapping),\
    \ it only subscribes to `/scan` and `/syscommand` (this is only used to send a\
    \ reset command, so you can disregard it). So if you want to create a bag file\
    \ to use with your hector_slam launch file, it only requires  information of the\
    \ `/scan` topic."
