  body_markdown: "I usually look at the API on Github for MoveIt commander [here](https://github.com/ros-planning/moveit/tree/kinetic-devel/moveit_commander/src/moveit_commander).\
    \ You will most likely be wanting move_group.py for planning.\n\nAs for importing\
    \ your robot files in the python script, you will already have move_group.launch\
    \ running from the package created by MoveIt setup assistant. Then you load a\
    \ planning group from the SRDF, which was launched from move_group.launch. \n\n\
    [Here](http://sdk.rethinkrobotics.com/wiki/MoveIt_Tutorial) is a MoveIt tutorial\
    \ for Baxter research robot. \n[Here](http://wiki.ros.org/ur5_moveit_config) is\
    \ one for UR5. \n\nAs for connecting to hardware, you usually just pass the trajectory\
    \ to your controller. Depending on your robot, there may already exist motor drivers\
    \ for it (i.e., Dynamixel motors)."
