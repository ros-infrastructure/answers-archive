  body_markdown: |-
    This is documented in the [ROS2 Developers Guide](https://github.com/ros2/ros2/wiki/Developer-Guide), specifically the [Language Versions and Code Format - Python](https://github.com/ros2/ros2/wiki/Developer-Guide#python) section:

    > We will target Python 3 for our development.

    and also the *Changes between ROS 1 and ROS 2* article on `design.ros2.org`, section [Platforms and dependencies - Languages - Python](http://design.ros2.org/articles/changes.html#c-standard), which is more specific:

    > ROS 1 is targeting Python 2. ROS 2 requires at least Python version 3.5.
