  body_markdown: "Check your the file that specifies the patterns you will use. It\
    \ contains the name, the marker to detect, its width and center position. If you\
    \ have the wrong size there, the algorithm will think the markers are closer/farther\
    \ then they really are.\nThis file will be loaded by the ar_pose package, for\
    \ example in your launch file:\n\n    <param name=\"marker_pattern_list\" type=\"\
    string\" value=\"$(find yourpackage)/yourpatterns\"/>\n\nyourpatterns file will\
    \ look like this:\n\n    #the number of patterns to be recognized\n    3\n   \
    \ \n    #pattern 1\n    #Sample1\n    #data/patt.sample1\n    #250.0\n    #0.0\
    \ 0.0\n    \n    #pattern 2\n    Sample2\n    data/patt.sample2\n    250.0\n \
    \   0.0 0.0\n    \n    #pattern 3\n    Hiro\n    data/patt.hiro\n    250.0\n \
    \   0.0 0.0\n    \n    #pattern 4\n    Kanji\n    data/patt.kanji\n    250.0\n\
    \    0.0 0.0\n\n You have to measure the size of your printed marker and write\
    \ it in mm in the third field of each pattern block (where you read 250.0 here)."
