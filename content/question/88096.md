  body_markdown: "I believe you can run the pointcloud_to_laserscan for any Sensor_msgs/PointCloud2\
    \ data by the following (in this case I've matched what you have put above for\
    \ the vrep):\n\n    <launch>\n      <!-- Fake Laser Standalone nodelet-->\n  \
    \    <node pkg=\"nodelet\" type=\"nodelet\" name=\"vrep_laser\" args=\"standalone\
    \ pointcloud_to_laserscan/CloudToScan\" respawn=\"true\">\n        <param name=\"\
    output_frame_id\" value=\"/vrep_frame\"/>\n        <param name=\"min_height\"\
    \ value=\"-0.15\"/>\n        <param name=\"max_height\" value=\"0.15\"/>\n   \
    \     <remap from=\"cloud\" to=\"/vrep/PointCloud2\"/>\n      </node> \n\n   \
    \ </launch>\n\nAdjust the \"output_frame_id\", \"min_height\", and \"max_height\"\
    \ as necessary for the vrep Sensor_msgs/PointCloud2 data.\n\n[This tutorial](http://wiki.ros.org/nodelet/Tutorials/Running%20a%20nodelet#Using_within_roslaunch_files)\
    \ has information on nodelets and running standalone nodelets and [this turtlebot\
    \ file](https://kforge.ros.org/turtlebot/turtlebot/file/b3cb9af986d8/turtlebot_bringup/kinect.launch)\
    \ shows an example for how to run the pointcloud_to_laserscan nodelet. The code\
    \ I have above follow these.\n\nHopefully this helps."
