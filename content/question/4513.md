    You can start by using the Nao urdf (which Gazebo can/should read).

    It might be easiest to look at example. We used URDF of the Atlas robot for both Gazebo and ROS.

    Here is the [Atlas description](https://bitbucket.org/osrf/drcsim/src/ec7d7c63e7b9d92a60edfa5e7057b9acbfebb570/atlas_description?at=default). In this example, the Atlas description is also a [Gazebo Model](http://gazebosim.org/user_guide/started__models__database.html).

    Here is an [example launch](https://bitbucket.org/osrf/drcsim/src/ec7d7c63e7b9d92a60edfa5e7057b9acbfebb570/drcsim_gazebo/launch/atlas.launch?at=default) file that will spawn Atlas.
