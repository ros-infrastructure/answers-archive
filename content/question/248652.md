  body_markdown: "**NOTE:** I stumbled upon this question when I had a question similar\
    \ to the original question. As the original question was asked in 2016, I thing\
    \ the original author already found his/her answer. The answer below is, therefore,\
    \ merely posted as a reference.\n\n# Answer\nThe `moveit_ros_planning_interface`\
    \ module is created by the the [boost::python](http://boost.cppll.jp/HEAD/libs/python/doc/tutorial/doc/quickstart.html)\
    \ wrapping library. [The documentation](http://boost.cppll.jp/HEAD/libs/python/doc/tutorial/doc/quickstart.html)\
    \ about this library says the following:\n\n>The Boost Python Library is a framework\
    \ for interfacing Python and C++. It allows you to quickly and seamlessly expose\
    \ C++ classes functions and objects to Python, and vice-versa, using no special\
    \ tools -- just your C++ compiler\n\nThis library, therefore, allows the `moveit`\
    \ developers to develop their package in C++ and afterwards expose the C++ package\
    \ as a python library.  \n\nTo see the wrapping in action, look at the [moveit_ros/planning_interface/CMakeLists.txt](https://github.com/ros-planning/moveit2/blob/master/moveit_ros/planning_interface/CMakeLists.txt)\
    \ file. This CMAKE description file in conjunction with the supplementary C++\
    \ wrapper files that can be found in the folder subdirectories makes sure the\
    \ C++ package is wrapped.\n\nTo answer the main question. As the moveit_ros_planning_interface\
    \ is merely a wrapper there is no API specially designed for the `moveit_ros_planning_interface`\
    \ interface. Instead, once should reference the [other C++ and Python API's](https://moveit.ros.org/documentation/source-code-api/).\n\
    \n## How to wrap your own C++ package using boost::python library\n\nA guide on\
    \ how to wrap a C++ package can be found [here](https://github.com/ethz-asl/programming_guidelines/wiki/Adding-python-bindings-to-your-cpp-catkin-package).\
    \ Note that nowadays, there are easier to used alternative wrapper libraries like\
    \ [pybind11](https://github.com/pybind/pybind11) available."
