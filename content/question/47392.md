    [robot_state_publisher](http://www.ros.org/wiki/robot_state_publisher) only publishes kinematic information (joint frames), not sensor information. If you are using the [gazebo_ros_prosilica](http://ros.org/wiki/pr2_gazebo_plugins#gazebo_ros_prosilica_node) plugin, then that plugin should be publishing the camera topics.
