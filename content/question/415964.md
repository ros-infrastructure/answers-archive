  body_markdown: "The best way to get code that's indexed is to leverage the tool\
    \ [`rosinstall_generator` documented here](http://wiki.ros.org/rosinstall_generator)\n\
    \nIn general git repositories don't support checking out specific subtrees so\
    \ we generally don't do partial checkouts, but if you really need to to that you\
    \ can put COLCON_IGNORE files in checked out packages that you want to skip before\
    \ you build. There are some other ignore logic available from colcon too. \n\n\
    The output of rosinstall_generator is then typically piped to `vcstool` https://github.com/dirk-thomas/vcstool\n\
    \nThe name is based on the previous downstrema tool `rosinstall`. \n\n"
