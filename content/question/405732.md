    \ Because this can be simply solved by `RotationShimController`.\n\nI suggest\

    \    \n\n    general_goal_checker:\n          plugin: \"nav2_controller::SimpleGoalChecker\"\
    \n          xy_goal_tolerance: 0.25\n          yaw_goal_tolerance: 0.25 <----\
    \ this is rad/4, so around 14 degrees, quite a lot!\n          stateful: True"
