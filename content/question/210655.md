The C++  [api](http://docs.ros.org/diamondback/api/tf/html/c++/transform__datatypes_8h.html) for `tf` provides many conversion utilities to convert messages to transforms (for example, `tf::poseMsgToTF`). 

Is there any way to use these within python? The closest I've found is to do:

            frame = tf_conversions.fromMsg(pose)

But this returns a `PyKDL.Frame` object, not a transform.
Ideally I'd like to go directly from a pose message to a `TF` transform.
