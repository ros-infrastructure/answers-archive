  body_markdown: "Sounds like you want to use the [image_geometry](http://wiki.ros.org/image_geometry)\
    \ package. It contains convenience functionality for working with standard ROS\
    \ camera models (initialized from a CameraInfo message). Specifically, the [PinholeCameraModel::fullProjectionMatrix](http://docs.ros.org/hydro/api/image_geometry/html/c++/classimage__geometry_1_1PinholeCameraModel.html#ac6503ef49e070ae83644fe20cc7017bb)\
    \ and [PinholeCameraModel::projectPixelTo3dRay](http://docs.ros.org/hydro/api/image_geometry/html/c++/classimage__geometry_1_1PinholeCameraModel.html#ad52a4a71c6f6d375d69865e40a117ca3)\
    \ methods sound like what you\xB4re looking for. See also the associated [tutorial](http://wiki.ros.org/image_geometry/Tutorials/ProjectTfFrameToImage)\
    \ for info on how to initialize things from a CameraInfo in a node."
