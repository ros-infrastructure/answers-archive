  body_markdown: "Here is the solution, that worked for me. Add a breakpoint to wahtever\
    \ you want to debug. Do so at the very beginning of the gdb command in gdbrun.\n\
    \n    gdb -ex \"set breakpoint pending on\"  -ex \"break <some source file from\
    \ plugin>:line_nr\" -x ${TMPFILE} \"${EXEC}\"\n\nFor debugging:\n\n 1. Only start\
    \ the gzserver in the roslaunchfile\n 2. Check in the output if the breakpoints\
    \ are set pending\n 3. start the gzclient manually in an extra window\n 4. set\
    \ additional breakpoints if required once gdb stops the gzserver\n 5. usual gdb\
    \ debugging \n\n"
