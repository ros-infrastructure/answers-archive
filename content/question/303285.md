  body_markdown: |-
    World file objects, like robots and maps usually have a parameter called *obstacle_return*, which makes them collide with other objects around or not. If set to 1, it will collide, and 0 it won't. Please take a look here for deeper info:
    https://player-stage-manual.readthedocs.io/en/latest/WORLDFILES/

    In the case of your simulation, I could see that the [pioneer_walle.world](https://github.com/rtv/Stage/blob/master/worlds/pioneer_walle.world) includes a [map.inc](https://github.com/rtv/Stage/blob/master/worlds/map.inc) file, and the map described has a obstacle_return parameter set to 0. I believe if you change it to 1, robots should collide with the obstacles.
