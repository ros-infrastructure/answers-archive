  body_markdown: "I use `launch.actions.ExecuteProcess` to launch Gazebo. \n\nSo let's\
    \ say your normal Gazebo process looks like this:\n```\n\n    ...\n    gz_process\
    \ = ExecuteProcess(cmd=`gazebo`, '--verbose', LaunchConfiguration('world'),\n\
    \                                    '-s', 'libgazebo_ros_factory.so'], output='screen')\n\
    \    ...\n       return LaunchDescription([\n         ...\n            DeclareLaunchArgument(name='world',\
    \ default_value=default_world_path,\n                                  description='Absolute\
    \ path to SDF world file'),\n            gz_process,\n         ...\n        ])\n\
    \n\n```\n\nInstead of calling `gazebo` there, you can call `gzserver`. You can\
    \ do this using a Launch Argument or just a seperate launch file all together.\
    \ \n"
