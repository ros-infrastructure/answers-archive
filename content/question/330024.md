  body_markdown: "I'm assuming, based on the frames reported, that this message\n\n\
    `Transform from base_link to map was unavailable for the time requested. Using\
    \ latest instead.`\n\nis coming from [this line](https://github.com/cra-ros-pkg/robot_localization/blob/cd5850a7d69261e0f03c8a8caf4cf846d404b4fb/src/navsat_transform.cpp#L503)\
    \ in `navsat_transform_node`.\n\nThe root of the issue is that the *map*->*base_link*\
    \ transform is not available as of the requested `transform_time`.\n\nThat value\
    \ was passed as a parameter [here](https://github.com/cra-ros-pkg/robot_localization/blob/cd5850a7d69261e0f03c8a8caf4cf846d404b4fb/src/navsat_transform.cpp#L487).\n\
    \nThat call came from [here](https://github.com/cra-ros-pkg/robot_localization/blob/cd5850a7d69261e0f03c8a8caf4cf846d404b4fb/src/navsat_transform.cpp#L718),\
    \ and so the stamp in question is `gps_odom.header.stamp`. \n\nThat value got\
    \ set when we called [this](https://github.com/cra-ros-pkg/robot_localization/blob/cd5850a7d69261e0f03c8a8caf4cf846d404b4fb/src/navsat_transform.cpp#L711),\
    \ specifically, [here](https://github.com/cra-ros-pkg/robot_localization/blob/cd5850a7d69261e0f03c8a8caf4cf846d404b4fb/src/navsat_transform.cpp#L406).\n\
    \nSo we're setting the value to `gps_update_time_`, which, in turn, is set [here](https://github.com/cra-ros-pkg/robot_localization/blob/cd5850a7d69261e0f03c8a8caf4cf846d404b4fb/src/navsat_transform.cpp#L572).\n\
    \nThat stamp is just the time stamp of your most recent GPS message.\n\nSo then\
    \ the problem is that `navsat_transform_node` is receiving a GPS message, and\
    \ it wants to convert it to an odometry message  (in this case, one that can be\
    \ consumed by the EKF itself). In order to do that, it needs to look up the robot's\
    \ pose in the map frame at that moment, but the `ekf_se_map` EKF hasn't produced\
    \ it yet.\n\nYour proposed solutions involved modifying parameters for the `ekf_se_odom`\
    \ node, but that won't produce the *map*->*base_link* transform; it's producing\
    \ *odom*->*base_link*. So you really want to change those settings for `ekf_se_map`\
    \ so that `navsat_transform_node` can get the transform it needs at the time it\
    \ needs it."
