    \ all looks correct. \n\nYou're using %d which is the [format specifier](http://www.cplusplus.com/reference/cstdio/printf/)\
    \ for an integer when the values in the pose message are double precision floats.\
    \ If you replace %d with %f or %e then you should start seeing the correct values. "
