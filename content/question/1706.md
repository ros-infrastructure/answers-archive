  body_markdown: "Hi,\n\nhere is an example of how to use different textures:\n\n\
    \                <material>\n                    <script>\n                  \
    \      <uri>file://media/materials/scripts/gazebo.material</uri>\n           \
    \             <name>Gazebo/Wood</name>\n                    </script>\n      \
    \          </material>\n<br><br>\nFor adding an image on a model you can create\
    \ a new material script, something similar to:\n\n\n    material pancake/2sides\n\
    \    {\n      receive_shadows on\n      \n      technique\n      {\n        pass\n\
    \        {\n          ambient 1 1 1 1.000000\n          diffuse 1 1 1 1.000000\n\
    \          specular 0.03 0.03 0.03 1.000000 \n          emissive 0.900000 0.900000\
    \ 0.900000 1.000000\n    \n          texture_unit\n          {\n            texture\
    \ pancake-sides.jpg\n          }\n        }\n      }\n    }\n\nWhere **texture\
    \ pancake-sides.jpg** is the line where you add the image.\n\nOr another possibility\
    \ you could create a collada file, and export it with the texture. And then add\
    \ it to the model as a mesh. [Here](http://gazebosim.org/wiki/Tutorials/beginner/mesh_import)\
    \ is a tutorial of how to load a mesh file.\n\nCheers, Andrei"
