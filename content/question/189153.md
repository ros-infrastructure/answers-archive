    Right, it seems now all poses get published over tf. Try this:
     rosrun tf tf_echo /world /girona500
    Also, to set the vehicle pose directly, use the setVehiclePosition example instead of setVehicleVelocity, like this:
     rosrun uwsim setVehiclePosition /dataNavigator 2 0 0 0 0 0
