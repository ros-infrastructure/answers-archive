  body_markdown: "Providing your two launch file could be nice but I see your issue\
    \ here.\n\nYour launch file is probably looking like that :\n\n    <launch>\n\
    \        <include file=\"$(find your_pkg)/launch/launchfile_1.launch\"/>\n   \
    \     <include file=\"$(find your_pkg)/launch/launchfile_2.launch\"/> \n    </launch>\n\
    \nIt creates an issue if there are nodes with the same name. To avoid that you\
    \ have different options :\n\n - Add a namespace in the include tag :\n\n    \
    \    <launch>\n            <include file=\"$(find your_pkg)/launch/launchfile_1.launch\"\
    \ ns=\"namespace1\"/>\n            <include file=\"$(find your_pkg)/launch/launchfile_2.launch\"\
    \ ns=\"namespace2\"/> \n        </launch>\n\nLike that you will have nodes from\
    \ the first include named `/namespace1/node` and from the second include `/namespace2/node`.\n\
    \n - You can set the name configurable with arguments. Inside yourlaunch files\
    \ instead of `<node pkg=\"node\" type=\"node\" name=\"your_node_name\"/>` you\
    \ can have :\n\n        <arg name=\"node_name_arg\" default=\"a_name\"/>\n   \
    \     <node pkg=\"node\" type=\"node\" name=\"$(arg node_name_arg)\"/>\n\nAnd\
    \ your launch file would be :\n\n    <launch>\n         <include file=\"$(find\
    \ your_pkg)/launch/launchfile_1.launch\">\n               <arg name=\"node_name_arg\"\
    \ value=\"node_name_1\"/>\n         </include>\n         <include file=\"$(find\
    \ your_pkg)/launch/launchfile_2.launch\">\n               <arg name=\"node_name_arg\"\
    \ value=\"node_name_2\"/>\n         </include>\n    </launch>\n\n\nThat is to\
    \ answer your question **BUT** you took `joint_state_publisher` as an exemple\
    \ but that means you try to launch it twice which is not right. It would be like\
    \ if you wanted to launch rviz for each of your launch files eventhough it will\
    \ gather the same data since it subscribes to topics. The right thing to do is\
    \ to clean up a little bit your launch files to contain only the different nodes,\
    \ the commons ones should be on the main launch file, like that :\n\n    <launch>\n\
    \         <!-- Launch all the commons nodes for exemple robot_state_publisher\
    \ and rviz -->\n\t     <node pkg=\"robot_state_publisher\" type=\"robot_state_publisher\"\
    \ name=\"spr\">\n\t\t    <param name=\"publish_frequency\" type=\"double\" value=\"\
    30.0\" />\n\t     </node>\n         <node name=\"rviz\" pkg=\"rviz\" type=\"rviz\"\
    />\n\n         <!-- Launch your launch files containing specifics packages -->\n\
    \         <include file=\"$(find your_pkg)/launch/launchfile_1.launch\"/>\n  \
    \       <include file=\"$(find your_pkg)/launch/launchfile_2.launch\"/>\n    </launch>\n\
    \nAnd you might want to create a `standalone` launch file launching the nodes\
    \ required for each of your different launch files."
