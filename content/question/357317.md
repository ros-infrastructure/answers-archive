  body_markdown: "You're missing a dependency on rcutils. You have an [`<exec_depend>`\
    \ only currently](https://github.com/lgsvl/ros2-lgsvl-bridge/blob/04e7e3bc1d49b0b06fe86724d5ee2924df9175ce/package.xml#L13)\
    \ which says that the package needs to be available at runtime but not at build\
    \ time. Thus rcutils is not provided when you try to build the package.\n\nYou\
    \ should probably be declaring `<depends>` to get it at buildtime and at runtime.\n\
    \nIf you have it in your workspace at build time CMake will find it. The debian\
    \ builds are strict about only provisioning your declared dependencies. "
