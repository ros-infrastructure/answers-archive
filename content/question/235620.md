    \  $ sudo apt-get update\n\nInstall newest version of Arduino from: https://www.arduino.cc/en/Guide/Linux\
    \ , download page : https://www.arduino.cc/en/Main/Software .\n\nROS and Arduino\
    \ Compatibility:\n\n    $ sudo apt-get install ros-kinetic-rosserial-arduino\n\
    \    $ sudo apt-get install ros-kinetic-rosserial\n\nTo Install the `ros_lib`\
    \ library in my Arduino folder which was built automatically (you may know it\
    \ as `/sketchbook`):\n\n    $ cd Arduino/libraries/\n    $ rosrun rosserial_arduino\
    \ make_libraries.py .\n\n*space .* is **VERY important** in the line above\n\n\
    now should have a newly built folder called ros_lib in that directory. You could\
    \ also validate it by navigating through Arduino IDE: \n\nOpen Arduino IDE:\n\
    **File -> Examples -> ros_lib**\n"
