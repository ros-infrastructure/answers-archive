  body_markdown: "When inheritting from a class you implicitly call its constructor\
    \ when you instantiante the base class, which mean here : `Move_operations_class\
    \ move_op;` You call the constructor (a default constructor since you didn't define\
    \ it for your class) and since you inherit from `moveit::planning_interface::MoveGroupInterface`\
    \ you also call its constructor, you didn't specify any parameters so the program\
    \ tries to call the constructor with no arguments : `moveit::planning_interface::MoveGroupInterface::MoveGroupInterface()`\
    \ as you can see in your error message.\n\nI haven't tried it but specifying the\
    \ parameters from your class constructor should solve the issue :\n\n    class\
    \ Move_operations_class : public moveit::planning_interface::MoveGroupInterface\n\
    \    {\n    \tpublic:\n    \t\t//Your constructor (that should get the string\
    \ too)\n    \t\t//And give the string to the MoveGroupInterface constructor\n\
    \    \t\t//Since the constructor of MoveGroupInterface can be called \n    \t\t\
    //with a string as parameter :\n    \t\tMove_operations_class(const std::string\
    \ &name) : \n    \t\t\tmoveit::planning_interface::MoveGroupInterface(name)\n\
    \    \t\t{\n    \t\t\t//Do constructor stuff\n    \t\t}\n    \n    \t\t//Your\
    \ other attributes/methods\n    };\n    \n    int main(int argc, char** argv)\n\
    \    {\n    \t//init ros\n    \t//Instantiate your object\n    \t//There is a\
    \ string variable because the constructor wants a reference\n    \tstd::string\
    \ name = \"arm_torso\";\n    \tMove_operations_class move_op(arm_torso);\n   \
    \ \treturn 0;\n    }\n\nThis should work since from the [documentation of MoveGroupInterface](http://docs.ros.org/melodic/api/moveit_ros_planning_interface/html/move__group__interface_8h_source.html)\
    \ you see that there is a constructor accepting only one string (and more parameters\
    \ but they have defaults values) :\n\n    MoveGroupInterface(const std::string&\
    \ group,\n          const std::shared_ptr<tf2_ros::Buffer>& tf_buffer = std::shared_ptr<tf2_ros::Buffer>(),\n\
    \          const ros::WallDuration& wait_for_servers = ros::WallDuration());\n\
    \n"
