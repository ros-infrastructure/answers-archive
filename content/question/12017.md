  body_markdown: "When you spawn it in a launch file it works like this:\n\n     <node\
    \ name=\"spawned_object_name\" pkg=\"gazebo\" type=\"spawn_model\" \n     args=\"\
    -urdf -file $(find rospackagename)/path/to/file.urdf -model \n     object_name_from_gazebo_perspective\
    \  -x 0.50 -y 0.05 -z 0.65\" \n     respawn=\"false\" output=\"screen\" /> \n\n\
    If you look at \n\nhttp://www.ros.org/wiki/simulator_gazebo/Tutorials/Gazebo_ROS_API\n\
    \nit tells you that there is also a ROS service gazebo/spawn_model which you can\
    \ call programmatically through a ROS message - this seems like the right way\
    \ to do it.\n\nHere is the documentation of the service:\n\nhttp://www.ros.org/doc/api/gazebo/html/srv/SpawnModel.html"
