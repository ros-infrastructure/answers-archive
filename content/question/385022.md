  body_markdown: "The `clock` topic being produced by LGSVL is designed to provide\
    \ a simulation clock for every node just like replaying a bag file would. For\
    \ this to work, it must be published in the root namespace (i.e. `/clock` - no\
    \ namespace). In addition, each node that is running must be told to use this\
    \ clock instead of the system clock with the parameter `use_sim_time`. Unfortunately,\
    \ in ROS2, this must be set for _every node_ individually in order for it to work\
    \ as expected. Additionally, each node must be using the `ROSTime` time source\
    \ (see [this design article](https://design.ros2.org/articles/clock_and_time.html)\
    \ for details). My recommendation is that you create a `LaunchArgument` in the\
    \ launch file for whether or not you want to use sim time and then add something\
    \ like the following for each node:\n\n    ... (beginning of launch file)\n  \
    \  use_sim_time_arg = DeclareLaunchArgument(\n        'use_sim_time',\n      \
    \  default_value=False,\n        description='Whether or not to use the /clock\
    \ topic'\n    )\n    ...\n    node_name = Node(\n        ...\n        parameters=[('use_sim_time',\
    \ LaunchConfiguration('use_sim_time'))]\n    ... (rest of launch file)\n\nDon't\
    \ forget to add `use_sim_time_arg` to the `LaunchDescription` at the bottom of\
    \ the file so you can use the argument. Then, just enable it with: \n\n    ros2\
    \ launch package_name launch_file.launch.py use_sim_time:=True"
