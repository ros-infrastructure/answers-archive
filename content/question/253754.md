    This has been asked before. See #q203760.

    And we could also look at the source: [ros::Duration::sleep()](https://github.com/ros/roscpp_core/blob/111977aa7869ad7e9381e7ea94c815ed4b285742/rostime/src/time.cpp#L392-L430) eventually calls [ros_wallsleep(..)](https://github.com/ros/roscpp_core/blob/111977aa7869ad7e9381e7ea94c815ed4b285742/rostime/src/time.cpp#L209-L222), which basically does:

        timespec req = { sec, nsec };
        timespec rem = {0, 0};
        while (nanosleep(&req, &rem) && !g_stopped)
        {
          req = rem;
        }

    and nothing more.

Say I have a ros rate of 10 Hz. Does `ros.spinOnce()` occur during `ros::Duration(2).sleep()` ? 

Example:

    void main(void){
      ros::nh;
      ros::rate r(10);
      while(ros::ok())
      {
        do something;
    
        ros::Duration(2).sleep();
        ros::spinOnce();
      }
    }
