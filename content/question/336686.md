  body_markdown: "You just to it on a single tag.\n\n    <remap from=\"rgb/image\"\
    \          to=\"/camera/rgb/image_raw\"/>\n\nA more complete example below. Note\
    \ the \"node\" tag, because you're launching a node and remapping it's topics.\n\
    \n    \n    <node name=\"rtabmap\" pkg=\"rtabmap_ros\" type=\"rtabmap\" output=\"\
    screen\">\n        <remap from=\"scan\" to=\"/scan\"/>\n        <remap from=\"\
    camera\" to=\"/camera1\"/>\n    </node>\n\n\nDoing it with an include file like\
    \ below WILL NOT work i don't think (someone correct me if im wrong).\n \n   \
    \ <include if=\"$(arg kinect)\"\tfile=\"$(find openni_launch)/launch/openni.launch\"\
    >\n        <remap from=\"camera\"\t\t\tto=\"/camera1\"/>\n    </include>\n\nAlso,\
    \ note that \"scan\" is different from \"/scan\".\nHaving only \"scan\" without\
    \ the \"/\" will place the topic under whatever namespace your node is running.\n\
    \nTake the rtabmap example above. Putting to=\"/scan\" will use the topic \"/scan\"\
    . Using to=\"scan\" will put it under \"/rtabmap/scan\"."
