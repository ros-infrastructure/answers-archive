  body_markdown: "1) Rather than using roscp as shown in section 1.5 of the tutorial\
    \ you linked, create a my_service.srv file in the srv directory. Edit this file\
    \ to have the fields you want, using the format described (request fields above\
    \ the ---, response fields below the ---). So long as your CMakeLists.txt file\
    \ includes the line:\n\n    rosbuild_gensrv()\nall the services defined in the\
    \ package's srv directory will be made.\n\n2) A service invocation is basically\
    \ a remote procedure call. The caller (normally) waits until the response is available.\n\
    \n\n3) I see the distinction between rosservice/rossrv (and rostopic/rosmsg) being\
    \ that rosservice provides you with tools to analyze and interact with the services\
    \ in your currently-running system, while rossrv only deals with what's defined\
    \ in the code. \n\n\n4) advertise() is for topics, advertiseService() is for services.\n"
