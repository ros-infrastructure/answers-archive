Hi! I am looking for a way to launch the same launch file multiple times sequentially with different parameters in python. After I am done with the launch file, I publish a message on the shutdown topic, after which I hope to kill everything launched by the launch file with parent.shutdown(). 

Below is the minimal reproducible example:

    import rospy
    import roslaunch
    from std_msgs.msg import String
    import time
    class MAIN_WRAPPER():
        def __init__(self, vel) -> None:
            cli_args = ['main_launch.launch',f'vel:={vel}']
            uuid = roslaunch.rlutil.get_or_generate_uuid(None, False)
            roslaunch.configure_logging(uuid)
            roslaunch_args = cli_args[1:]
            roslaunch_file = [(roslaunch.rlutil.resolve_launch_arguments(cli_args)[0], roslaunch_args)]
            self.parent = roslaunch.parent.ROSLaunchParent(uuid, roslaunch_file)
            self.parent.start()
            self.sub_once = rospy.Subscriber('shutdown', String, self.shutdown_cb)
    
        def shutdown_cb(self, msg):
            time.sleep(2)
            self.sub_once.unregister()
            self.parent.shutdown()
            self.parent = False
    
    rospy.init_node('example')
    for i in range(10):
        wr = MAIN_WRAPPER(i)
        while not rospy.core.is_shutdown() and wr.parent!=False:
            rospy.rostime.wallsleep(0.5)
    
The issue is that sometimes the code gets stuck on `"[included_node] killing on exit"`, where the included_node is the node that is started by the main_launch.launch file. Sometimes it takes a few minutes or even tenths of minutes for it to recover. I have a suspicion this could have something to do with the fact that I don't shut everything down properly after each iteration. When I re-run the code with the same roscore, the included_node always starts from `[included_node-1]`. Within the for loop, however, the nodes are launched with increasing indices:  
`[included_node-1]`, `[included_node-2]`, `[included_node-3]`... Would this be the case if I properly shut down `[included_node-1]` before launching `[included_node-2]`?

Another thing, could you help me identify why without time.sleep(2) in the callback I get KeyboardInterrupt errors. I wonder if there is something I should wait for instead of just waiting for 2 seconds each time.

Thank you!
