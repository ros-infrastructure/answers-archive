  body_markdown: "\nHi @MechLc!\n\nYou say it doesn't work because you can't see the\
    \ `example.yaml` file that should be generated, right?\n\nThe `rosparam dump example.yaml`\
    \ will generate the file on the current working directory. \n\nIn order to see\
    \ the current working directory, you can use the `pwd` command, like: `system(\"\
    \ echo 'ROS Params dumped at: ' $(pwd); rosparam dump example.yaml\");`\n\nOr\
    \ you can pass the full path of the yaml file, like: `rosparam dump /full/path/to/example.yaml`.\n\
    \nBelow I have attached a code of a ROS Node in CPP that just dumps the ros params.\n\
    \nIf you run the node using `roslaunch`, the file is going to be generated probably\
    \ on  `~/.ros/example.yaml`, as you can see on this video (https://youtu.be/w5cVKlhy37w).\n\
    \n    #include <ros/ros.h>\n    \n    int main(int argc, char **argv){\n     \
    \   \n        ros::init(argc, argv, \"tutorial_node\");\n        \n        system(\"\
    \ echo 'ROS Params dumped at: ' $(pwd); rosparam dump example.yaml\");\n     \
    \   \n        ros::spin();\n        \n        return 0;\n    }"
