    Hi @necip

        wheel_left_link
        No transform from [wheel_left_link] to [map]

    That warning probably comes from the fact that you have in your rviz- -> Global options --> Fixed frame the `map` frame which does not exist in your set up. Either you change the value of that field to the `base_footprint`  frame of your robot or generate a tf tree like `base_footprint` --> `odom` --> `map`.

    The second issue is related with the python code you are using. The [main process](https://github.com/aniskoubaa/ros_essentials_cpp/blob/3083b02b34f0f481dde1cfd797ad72272bc88cbc/src/topic02_motion/turtlebot/turtlebot_move.py#L131) is just rotating the robot so it is the behaviour you are commanding with that code.
