  body_markdown: "Ok. It seems there is a way to trick ROS CMakeFiles, since it seems\
    \ that rosbuild isn't linking the libraries properly.\n\nI added:\n\n    find_package(Boost\
    \ 1.46.1 COMPONENTS thread signals filesystem system)\n    \n    if(Boost_FOUND)\n\
    \        include_directories(${Boost_INCLUDE_DIRS})\n        target_link_libraries(ros\
    \ ${Boost_LIBRARIES})\n    endif()\n\nin the file:\n~/ros/ros_comm/clients/cpp/roscpp/src/libros/CMakeLists.txt\n\
    \nThat allowed me to go past the compilation. There is a similar problem with\
    \ rosbag CMakeLists.txt as well, but the same applies. This is probably a bug\
    \ and hopefully it will be fixed.\n\nUnfortunately it doesn't seem this is the\
