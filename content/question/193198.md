  body_markdown: "If you launch a single `roscore` prior to loading your launch files,\
    \ shouldn't they all reuse that running instance? \n\nFrom [wiki.ros.org/roscore](http://wiki.ros.org/roscore):\n\
    \n> NOTE: If you use roslaunch, it will automatically start roscore if it detects\
    \ that it is not already running.\n\nAs far as I know, the directory where logfiles\
    \ end up is determined at the start of `roscore` (see the `runid` parameter, and\
    \ [roscpp/Overview/Logging#Output](http://wiki.ros.org/roscpp/Overview/Logging#Output)),\
    \ so all subsequently started nodes' logs should be written to the `~/.ros/log/<runid>/whatever`\
    \ directories.\n"
