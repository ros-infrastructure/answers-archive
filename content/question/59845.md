    I have used RoboRealm with a Windows XP set up. It is more Windows friendly and may not work on a Linux Distribution. Also, in my opinion you can get most of the functionality of RoboRealm using various packages at ROS, so I will suggest that it may not be worth a buy. However, if you want to get some basic idea of robot vision in the Windows environment then it may be worth a try, it is a good software just that ROS is much better !

    Also, consider having a look here, [http://answers.ros.org/question/10379/how-can-i-use-roborealm-software-vision-for-machines-in-ros/](http://answers.ros.org/question/10379/how-can-i-use-roborealm-software-vision-for-machines-in-ros/).
