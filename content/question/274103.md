    \ \n\n2) Using FTDI driver https://github.com/HumaRobotics/dynamixel_hr   #This\

    \ used widely till the official SDK came out. However, it still may be useful.\
    \ https://github.com/arebgun/dynamixel_motor    #This has ROS documentation as\
    \ well.\n\nHope this helps. \n\n\nNote:- \n1) The header file called dynamixel.h\
    \ which we used in MATLAB does not work with Linux. So don't waste your time with\
    \ that for Linux. \n2) We are trying on the EX-106+ model but mostly it should\
