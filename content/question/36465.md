  body_markdown: "You can visualize both the incrementally built maps and the static\
    \ ones loaded from a .bt file in octomap_server in the same way (see the documentation\
    \ of [octomap_server/Published Topics](http://www.ros.org/wiki/octomap_server#Published_Topics)):\
    \ \n\nAdd a MarkerArray display in RViz on the topic \"occupied_cells_vis\" (without\
    \ the trailing _array, that's an RViz problem). Be sure to set the tf frame to\
    \ \"/map\" or whatever your mapping frame is.\n\nFor querying occupancy for localization\
    \ in the octomap stored in octomap_server, see http://octomap.sourceforge.net/doxygen/\
    \ (in particular castRay())."
