  body_markdown: "It's in the [colcon manual](https://colcon.readthedocs.io/en/released/user/how-to.html)\
    \ but it wasn't clear enough so I missed it the first time \n\n    colcon build\
    \ --packages-select my_pkg --event-handlers console_direct+\n\nAs an alternative,\
    \ it the package has already been built and `cmake` uses `make`, one can just\
    \ go to the build directory and invoke `make` directly\n\n    cd build/my_pkg\n\
    \    make \n\nWhen there is a lot of errors, it's useful to step through the colored\
    \ output of the compiler \n\n    unbuffer colcon build --packages-select mpc_follower\
    \ --event-handlers console_direct+ |& less -r\n\nthe `unbuffer` command is available\
    \ via `sudo apt install expect`"
