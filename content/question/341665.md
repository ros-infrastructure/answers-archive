  body_markdown: "\nFrom the database you shared in the comments, try this:\n\n  \
    \  Kp/MaxDepth=0                   # Should be 0 in general\n    Vis/MaxDepth=0\
    \                  # Should be 0 in general\n    RGBD/NeighborLinkRefining=false\
    \ # Don't refine T265 odometry, it should be already accurate\n    Optimizer/GravitySigma=0.1\
    \      #  Force graph optimization with gravity constraints\n    Mem/UseOdomGravity=true\
    \         # Get gravity constraints from odometry (assuming VIO from T265)\n\n\
    Example reprocessing the database with those parameters:\n\n    $ rtabmap-reprocess\
    \ --Kp/MaxDepth 0 --Vis/MaxDepth 0 --RGBD/NeighborLinkRefining false --Optimizer/GravitySigma\
    \ 0.1 --Mem/UseOdomGravity true rtabmap.db output.db\n\nAlso, it is better to\
    \ disable relocalisation feature of T265 if possible when using rtabmap. This\
    \ issue is explained [here](https://github.com/introlab/rtabmap/issues/409).\n\
    \nYou should also adjust the transform between the cameras based on your setup\
    \ (for better loop closure optimizations):\n\n    <node pkg=\"tf\" type=\"static_transform_publisher\"\
