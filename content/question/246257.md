  body_markdown: "Quaternion is different from euler angles, but as always you can\
    \ convert between one another.\n \nYou can check [here](http://answers.unity3d.com/questions/645903/please-explain-quaternions.html)\
    \ for sweet and short basic of quaternion.\nLet me quote from it:\n\n> A quaternion\
    \ rotation is made up of 4\n> numbers, whose values all have a\n> minimum of -1\
    \ and a maximum of 1, i.e\n> (0, 0, 0, 1) is a quaternion rotation\n> that is\
    \ equivalent to 'no rotation' or\n> a rotation of 0 around all axis.\n\nEuler\
    \ angle to Quaternion Given an\nEuler rotation (X, Y, Z) using orthogonal axes:\n\
    \n>  x =\n> sin(Y)sin(Z)cos(X)+cos(Y)cos(Z)sin(X) \n\n> y =\n> sin(Y)cos(Z)cos(X)+cos(Y)sin(Z)sin(X)\
    \ \n\n> z =\n> cos(Y)sin(Z)cos(X)-sin(Y)cos(Z)sin(X) \n\n> w =\n> cos(Y)cos(Z)cos(X)-sin(Y)sin(Z)sin(X)\n\
    \n\n- You don't need to implement those by yourself as there are also available\
    \ functions in ROS api for converting from quaternion to euler and vice versa\n\
    \n----\n\nYou might also want to check :\n\n- [coordinate conventions used within\
    \ ROS](http://www.ros.org/reps/rep-0103.html#derived-units)\n\n- [Quaternion orientation\
    \ representation](http://answers.ros.org/question/9772/quaternions-orientation-representation/)"
