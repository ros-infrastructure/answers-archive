  body_markdown: "The answer by jodafo sums up things pretty well. To add just a minor\
    \ point: The [mapping_default.launch](http://code.google.com/p/tu-darmstadt-ros-pkg/source/browse/trunk/hector_slam/hector_mapping/launch/mapping_default.launch)\
    \ file is an example launch file and has some parameters specified using the <[arg](http://ros.org/wiki/roslaunch/XML/arg)>\
    \ tag to facilitate reuse. If your robot for example uses 'my_base_frame' as a\
    \ base_frame and 'odom' as odom frame you can use the mapping_default.launch file\
    \ like so in your launch file:\n\n      <include file=\"$(find hector_mapping)/launch/mapping_default.launch\"\
    >\n        <arg name=\"base_frame\" value=\"my_base_frame\"/>\n        <arg name=\"\
    odom_frame\" value=\"odom\"/>  \n      </include>\n\nOf course, this is just optional.\
    \ You can write your own launch file or specify parameters using a shorter form\
    \ like [here](http://code.google.com/p/rosjava/source/browse/google_handheld_slam/launch/hector_mapping.launch?repo=google&r=8faae27a7b20ba5f99e0a932400c732eee2e4b16)."
