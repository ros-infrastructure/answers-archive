  body_markdown: "[camera_info_manager](http://ros.org/wiki/camera_info_manager) is\
    \ a ROS package on which freenect_stack depends. You need to either install it\
    \ on your system or add it to your catkin workspace.\n\nTo install on Ubuntu for\
    \ Groovy:\n\n    $ sudo apt-get install ros-groovy-camera-info-manager\n\nIf you\
    \ decide not to build freenect_stack yourself, you can install it similarly:\n\
    \n    $ sudo apt-get install ros-groovy-freenect-stack\n\n**Note**: the [freenect_camera](http://ros.org/wiki/freenect_camera)\
    \ package has other dependencies you will probably also need for building freenect_stack. "
