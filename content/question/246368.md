    Hi,

    [move_base](http://wiki.ros.org/navigation/Tutorials/RobotSetup) uses a 2D occupancy grid map to plan trajectories. The octomap topics are 3D occupancy maps, which would be used by some other 3D planning approach (e.g., [move_it](http://moveit.ros.org/)). They are not the same as `/grid_map` or `/proj_map` from [rtabmap_ros](http://wiki.ros.org/rtabmap_ros). You should use `/map` output topic of [octomap_server](http://wiki.ros.org/octomap_server#Published_Topics) with `move_base`. So for your second question, yes it needs the down projected 2D map.
