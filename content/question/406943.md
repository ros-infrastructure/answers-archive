  body_markdown: "For anyone else trying to troubleshoot this issue when following\
    \ along the tutorials. Please make sure that you set you ROS_DOMAIN properly.\
    \ \nAs in the first few sections of the tutorials ROS_DOMAIN is mentioned to default\
    \ to \"0\". So if any nodes, services, params, etc don't show up as expected,\
    \ ensure you are in deed using the right ROS_DOMAIN.\n\nOne easy way is adding\
    \ \"export ROS_DOMAIN=0\" to your ~/.bashrc at the bottom. Alternatively to editing\
    \ the file, you can also just execute the following line in the terminal:\n\n\
    \    echo \"export ROS_DOMAIN_ID=0\" >> ~/.bashrc\n\nDo one or the other, it won't\
    \ hurt doing both but it would be silly :-)\nHope this helps someone"
