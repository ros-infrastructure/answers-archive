Hi all,

I have a really weird situation. I created both a quadrotor model and mobile robot one. 
My problem is that if I use the method "quick" it does not work with my position quadrotor controller since it follows on ground (while if I set the "world" one it works perfectly). On the contrary, if I set the "world" method when I use the ground robot, it follows on the ground and the simulation crashes. Alternatevely, it crashes when the simulation starts (it may happen that the simulation crashes when the robot is falling down).

My opinion is that there is something strange during the contact ground-robot.
Every suggestion is welcome,

Neostek
