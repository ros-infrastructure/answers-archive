    I was able to get it fixed.

    I used 'model://' instead of 'file://'.
    Also the base path for the relative path is taken from the environment variable GAZEBO\_MODEL\_PATH.

    So finally the code looked this way.

        <mesh><uri>model://ua_ros_p3dx/p3dx_gazebo/worlds/map4.dae</uri></mesh>
  comments:
  - body_markdown: |-
      If the mesh file is in the same package, and you have the following directory structure:

      worlds

      |-- p3dx.world


      meshes

      |-- mesh1.dae

      |-- mesh2.dae


      Then in your .world file you can simply:
      `<uri>../meshes/mesh1.dae</uri>`

      [reference sdf API](https://ignitionrobotics.org/api/gazebo/4.3/migrationsdf.html)
