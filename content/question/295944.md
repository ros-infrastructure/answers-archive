  body_markdown: "Hi, \nI faced the same issue, I have solved the issue and want to\
    \ share with you.\n\nYou have to take care of the following link.\n\n1.  Create\
    \ a package that contains your msg. like in your case `marvelmind_nav`. You can\
    \ refer to [this tutoria](http://wiki.ros.org/ROS/Tutorials/catkin/CreatingPackage)l\
    \ to create the package.\n2. Then create the custom msg that you want to make.\
    \ In your case `position_control.msg`. You can refer to [this tutorial](http://wiki.ros.org/ROS/Tutorials/CreatingMsgAndSrv)\
    \ to create custom msg.\n3. Make sure you have edited the `CMakeLists.txt` for\
    \ custom msg.\n4. then run the following command to create the msg for Arduino\
    \ compatible.\n\n    rosrun rosserial_client make_libraries <arduino_library_folder_path>\
    \ marvelmind_nav/\n\nNote: if the above command not working remove the `build`\
    \ directory of workspace and `catkin_make` again.\n\nYou can refer [this answer](https://answers.ros.org/question/291312/how-to-create-a-custom-msg-for-arduino/)"
