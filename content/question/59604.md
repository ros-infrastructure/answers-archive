  body_markdown: "Unfortunately, the default CMake install location is **/usr/local**,\
    \ not a good destination for ROS packages. So, you need to [configure your catkin\
    \ workspace](http://www.ros.org/wiki/catkin/Tutorials/using_a_workspace#Configuring_Packages),\
    \ somewhat like this example: \n\n    $ cd ~/catkin_ws/build\n    $ cmake ../src\
    \ -DCMAKE_INSTALL_PREFIX=../install\n\nThen, you need to [add CMake **install()**\
    \ commands](http://www.ros.org/wiki/catkin/CMakeLists.txt#Optional_Step:_Specifying_Installable_Targets)\
    \ to your CMakeLists.txt.\n\nFor example, if you need to install C++ headers where\
    \ they can be found by other packages:\n\n    install(DIRECTORY include/\n   \
    \    DESTINATION ${CATKIN_PACKAGE_INCLUDE_DESTINATION}\n    )\n\nSimilarly, if\
    \ there is a shared libraries needed by other packages at runtime:\n\n    install(\n\
    \      TARGETS your_shared_library\n      LIBRARY DESTINATION ${CATKIN_PACKAGE_LIB_DESTINATION}\n\
    \    )\n\nNote that catkin library names have system-wide scope, so make sure\
    \ they clearly describe their role. Include names are less of an issue, since\
    \ they are usually in a subdirectory under your package name."
