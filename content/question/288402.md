    ROS and tensorflow are just coupled over the API.
    You can implement something with ROS and tensorflow if you want.

    As [tensorflow](https://www.tensorflow.org/api_docs/) as well as ROS contain APIs for C++ and Python, you should be able to implement something within ROS which uses tensorflow with GPU Support.
