  body_markdown: " Had the same problem and after a lot of websearches I ended up\
    \ writing an [ActionLib Server](http://wiki.ros.org/actionlib) for the [FollowJointTrajectoryAction](http://docs.ros.org/electric/api/control_msgs/html/action/FollowJointTrajectory.html)\n\
    \n- You get the list of goals for each link in [trajectory/points](http://docs.ros.org/jade/api/trajectory_msgs/html/msg/JointTrajectory.html)\n\
    \n- You should publish the feedback for each goal while also watching preempt_requested.\n\
    \n- Moveit expects you to return FollowJointTrajectoryResult.SUCCESSFUL in [FollowJointTrajectoryActionResult](http://docs.ros.org/electric/api/control_msgs/html/msg/FollowJointTrajectoryAction.html)\
    \ if all went well.\n\nIn case it helps I uploaded my implementation (python)\
    \ to [github](https://github.com/nxdefiant/arm_ros_conn/blob/master/scripts/arm_ros.py),\
    \ no guarantees given.\n\nThe new angle is send to hardware with the to_angle()\
    \ call (not in this repos). The interface is \n\n    def to_angle(axis, speed=255,\
    \ angle=0)\n\nwhere axis is the axis number (0..5), speed the motor pwm speed\
    \ and angle in rad."
