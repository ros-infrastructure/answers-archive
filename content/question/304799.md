  body_markdown: "The short answer is you can't.\n\nThe long answer is that if you\
    \ can make some additional assumptions then you can sometimes make a good estimate.\n\
    \nThe x and y position within the image when combined with a calibrated lens model\
    \ for the camera can tell you which 'direction' an object is in. If you know where\
    \ your camera is then you know that the object lies somewhere along a line, but\
    \ not where it is on that line.\n\nHowever if the size of the object is fixed\
    \ and known then you can use the width and height values to estimate it's range\
    \ from the camera, although this will not be very precise. "
