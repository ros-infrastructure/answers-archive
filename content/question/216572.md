    To see running nodes, use `rosnode list` instead. If there are no topics/messages published (since none show up with `rostopic list`, try to debug your VRPN connection. Try using the `vrpn_print_devices` command to receive messages from your VRPN Tracker over CLI. When this works, specify the Tracker name manually to the node in the `trackers` [parameter](https://github.com/clearpathrobotics/vrpn_client_ros/blob/indigo-devel/launch/sample.launch#L19). When this works, try automatic tracker detection.
