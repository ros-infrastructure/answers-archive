    \ is:\n\nThe Ethercat on the Youbot is of course connected to the PC inside the\
    \ robot (running the Ethercat Master) and the ARM(s) and the motors for the wheels.\n\
    \nI guess ROS has to run on the Youbot PC, so yes you need to enable it, also\
    \ the Motors you need (if you want the Robot\nto move). Also add a wireless network\
    \ adapter to the Youbot PC and connect over ssh to it.\n\nInstall ROS on your\
    \ PC and decide where you wil run the ROS master. \n\nOn the PC (either yours\
    \ or the Youbot) with the master you set up the master URI as http://localhost:11311\
    \ (you do not have to do anything there) on the other one you set it to http://hostname-of-the-other:11311.\n\
    \nBe sure to have either the hostnames in the host files, or a DNS running.\n\n\

  body_markdown: "There are two ways to do this:\n\n- - - -\n\n## Using the internal\
    \ PC\n\nAs cyborg-x1 already hinted, you can also use ROS with multiple nodes\
    \ over a network.\n\n* Start up the youbot as usual:\n\n    * start up power supply\n\
    \    * start up internal pc\n    * start up arm/motors\n\n* Connect network cable\
    \ or wireless adapter, configure as appropriate or your environment.\n* On the\
    \ youbot:\n\n    * find out your IP adress (via GUI or simply ``$ sudo ifconfig``),\
    \ e.g. YOUBOT_IP=123.456.789.123\n    * set ROS_MASTER_URI: ``export ROS_MASTER_URI=http://123.456.789.123:11311``\n\
    \    * set ROS_IP: ``export ROS_IP=123.456.789.123``\n\n* On the laptop/PC:\n\n\
    \    * find out your IP adress, e.g. LAPTOP_IP=789.456.123.789\n    * set ROS_MASTER_URI:\
    \ ``export ROS_MASTER_URI=http://123.456.789.123:11311``\n    * set ROS_IP: ``export\
    \ ROS_IP=123.456.789.123``\n\n* As you need to do the exports for every shell\
    \ that you start, you might want to put those lines into your ``.bashrc`` or somewhere\
    \ else that will be loaded.\n* Now go back to the youbot and start the driver\
    \ as usual.\n* Now everything should be ready. When you start nodes on the youbot\
    \ they will work. When you start nodes on the Laptop/PC they will also work and\
    \ communicate over your network.\n\n\n- - - - \n\n## Not using the internal PC\n\
    \n(Have not done this myself, as we wanted the youbot to work with a wireless\
    \ adapter, so no knowledge on mileage.)\n\n* Have ROS running on your PC.\n* Connect\
    \ your Laptop/PC via Ethernet cable to the base (Ethercat1).\n* Connect the Arm\
    \ to Ethercat2\n* Install the driver from [inside ROS](http://wiki.ros.org/youbot_driver)\
    \ or from [GitHub](https://github.com/youbot/youbot_driver)\n* Start up the youbot\
    \ power supply and motor, do _not_ start up the internal PC.\n* Start the driver\
    \ on your PC/laptop. Everything should work."
