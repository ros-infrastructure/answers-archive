I use Turtlebot(Kobuki) and Xbox One Kinect(Kinect v2) on Ubuntu16.04 and ROS Kinetic. I succeeded to SLAM and AMCL with [turtlebot_navigation package](http://wiki.ros.org/turtlebot_navigation). On the other hand, when turtlebot moved autonomously, it didn't avoid obstacles like walking human. I checked my costmap_common_params.yaml, but I couldn't find any mistakes. If you have some idea, could you please tell me?

When I attached and launch Kinect, I referred to [this page](https://github.com/bus710/sulcata). To start SLAM and AMCL, I type following commands. When I launched minimal.launch, 3 nodes(rocon_master, rocon_app_manager, interactions) failed to start. I understand rocon is just a interface to communicate with user, so 3 nodes wake up error don't relate not to avoid obstacles issue.

 1. roslaunch turtlebot_bringup minimal.launch
 2. roslaunch kinect2_bridge kinect2_bridge.launch publish_tf:=true
 3. rosrun depthimage_to_laserscan depthimage_to_laserscan image:=/kinect2/sd/image_depth_rect _output_frame_id:=/base_kinectv2_link
 4. roslaunch turtlebot_navigation gmapping_demo.launch / amcl_demo.launch

To succeed SLAM and AMCL, I mainly changed following files. I didn't change my local_costmap_params.yaml.

 1. [3dsensor.launch](https://github.com/graziegrazie/my_turtlebot/blob/550757defa872fc2263fc057aad3f001ceff015a/turtlebot/src/turtlebot/turtlebot_bringup/launch/3dsensor.launch)<br>
 I commented out from line 43 to the end of file.
 
 2. [turtlebot_library.urdf.xacro](https://github.com/graziegrazie/my_turtlebot/blob/master/turtlebot/src/turtlebot/turtlebot_description/urdf/turtlebot_library.urdf.xacro)<br>
 I added Kinect v2 model. I checked out Kinect v2 one from [here](https://github.com/code-iai/iai_robots/blob/master/iai_kinect2_description/urdf/kinect2.urdf.xacro) and named turtlebot_kinect2_rgb_optical_frame. Furthermore, I defined base_kinect2_link originally. This is because when I used turtlebot_kinect2_rgb_optical_frame, scan data is projected on Y-Z plane, not X-Y plane. I found the reason of this problem is that attitude of turtlebot_kinect2_rgb_optical_frame is not rotated for base_link and base_footprint. So I resolve the problem, I defined base_kinect2_link which attitude is same as base_link and the pose is same as turtlebot_kinect2_rgb_optical_frame.
 
 3. [costmap_common_params.yaml(1)](https://github.com/graziegrazie/my_turtlebot/blob/master/turtlebot/src/turtlebot_apps/turtlebot_navigation/param/costmap_common_params.yaml), [costmap_common_params.yaml(2)](https://github.com/graziegrazie/my_turtlebot/blob/master/turtlebot/src/turtlebot_apps/turtlebot_navigation/param/costmap_common_params_.yaml)
 I added "sensor_frame" in scan section. The name of the topic publishing Kinect v2 data is "scan".
