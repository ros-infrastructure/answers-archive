    You can export meshes from Blender either as DAE or OBJ files and use them in Gazebo. [Here](http://gazebosim.org/tutorials?tut=import_mesh)'s a tutorial on importing meshes. If you want the meshes to move with respect to each other, you should put each mesh in a different link. [This](http://gazebosim.org/tutorials?tut=build_model&cat=build_robot) tutorial has some information about the different parts of a model in Gazebo.

    Once you got your model working in Gazebo, you can control it with ROS as explained on [this](http://gazebosim.org/tutorials?tut=ros_control&cat=connect_ros) tutorial.
