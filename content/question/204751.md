  body_markdown: "If your cam driver topics are\n\n    \n    /camera/rgb/image_raw\n\
    \    \n    /camera/rgb/camera_info\n\nI guess you should start the image_proc\
    \ node like:\n\n    ROS_NAMESPACE=camera/rgb rosrun image_proc image_proc\n\n\
    Update with explanations:\n\nThe `ROS_NAMESPACE=camera/rgb` puts all topics of\
    \ the node into this namespace. Initially if you run\n\n    rosrun image_proc\
    \ image_proc\n\nit will listen to the topics\n\n\n    /image_raw\n    \n    /camera_info\n\
    \n. If you than change the call into \n\n    ROS_NAMESPACE=camera rosrun image_proc\
    \ image_proc\n\nas mentioned in the tutorial it will listen to\n\n    /camera/image_raw\n\
    \    \n    /camera/camera_info\n\n. However, your camera driver apparently publishes\
    \ to the /camera/rbg namespace so your call will be \n\n    ROS_NAMESPACE=camera/rgb\
    \ rosrun image_proc image_proc\n\nsuch that the image_proc node listens to the\
    \ topics of your camera driver which are:\n\n\n    /camera/rgb/image_raw\n   \
    \ \n    /camera/rgb/camera_info"
