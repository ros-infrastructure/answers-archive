    You might be able to find what you're looking for on the `local_plan` topic of the local planner plugin that you have configured ([docs](http://wiki.ros.org/base_local_planner#API_Stability)). Note that a local planner can (and will) change the plan many times as it's trying to execute the global plan as best as possible given the current state of the robot and the world.
