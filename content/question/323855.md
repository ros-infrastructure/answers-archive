 Hi all! I am using [cartographer_ros](https://google-cartographer-ros.readthedocs.io/en/latest/index.html) for SLAM.

Currently i am trying to extract the final trajectory of a robot after doing offline mapping in cartographer. By following issue [#332](https://github.com/googlecartographer/cartographer_ros/issues/332) in cartographer's github , and using this [code](https://gist.github.com/nobinov/594b1b54e60486adcb1c3c513c74c887), now I am able to access the pose of robot for each trajectory node.

I ran my cartographer_ros in my bagfile that generated from [KITTI raw dataset](http://www.cvlibs.net/datasets/kitti/raw_data.php) using [kitti2bag](https://github.com/tomas789/kitti2bag) and have 1101 frames on it. From the .pbstream file that generated, I got 526 trajectory nodes. From the number itself, it seems there's no correlation between amount of generated trajectory nodes and amount of scanning frames.

Is there any way to know at which frame each trajectory node was generated? Or what parameter(s) that can affect the amount of generated nodes?

Thank you!
