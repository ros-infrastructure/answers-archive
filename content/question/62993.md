  body_markdown: "This error is due to the fact that ROS cannot find the package.\
    \ By default ROS will search inside \"stack\" or \"share\" depending on the version\
    \ of ROS, for the package. Once you completed Step 5, the \"eddiebot\" folder\
    \ was probably placed in: \"/home/christopher/eddiebot\"\n\nYou need to move it\
    \ into: \"opt/ros/fuerte/share/\"\n\nThis can be done by the following: \n\n \
    \   sudo mv -i eddiebot opt/ros/fuerte/share"
