    \ anybody in the future is interested.\n\nThe code that really parses this XML\
    \ file is the sdformat library, source code can be found here:\nhttps://bitbucket.org/osrf/sdformat/src/default/\n\
    \nIn my case, I cloned the branch 6_to_default.  \nThe exact place where the parsing\
    \ takes place is in file src/parse_urdf.cc in function line 1215:    \n\n```void\
    \ URDF2SDF::ParseSDFExtension(TiXmlDocument &_urdfXml)```  \n\nHere you will be\
    \ able to read the exact tags that are supported and parsed. If you follow a suggested\
    \ answer in a thread and that does not work for you, take into account that some\
    \ of the examples I have seen are wrong, for example tag `self_collide` is not\
    \ parsed in the `gazebo` extension, the correct tag is `selfCollide`. Almost the\
    \ same, but not quite.\n\nCheers."
