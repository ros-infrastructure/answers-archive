  body_markdown: "I don't think you would be able to simulate the collision with every\
    \ single sand particle. The computation load would be too much. The practical\
    \ approach could be to set the physics parameters like friction very high so it\
    \ statistically simulated the sand surface. And if there is other phenomenon that\
    \ sand exhibits, then write a plugin to include this phenomenon inside the simulation.\n\
    \nWhen I simulate 1000 balls of 5 cm in radius, the RT factor on my 8 core computer\
    \ drops to 0.08. \n\n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/15744199911052893.png)\n\
    \nI spawn the 1000 balls into the simulation by putting following code into the\
    \ world file (gazebo 7).\n\n    <population name=\"ball_population1\">\n     \
    \ <model name=\"ball\">\n        <static>false</static>\n        <link name=\"\
    ball_body\">\n          <collision name=\"ball_collision\">\n            <geometry>\n\
    \              <sphere>\n                <radius>0.05</radius>\n             \
    \ </sphere>\n            </geometry>\n          </collision>\n          <visual\
    \ name=\"ball_visual\">\n            <geometry>\n              <sphere>\n    \
    \            <radius>0.05</radius>\n              </sphere>\n            </geometry>\n\
    \          </visual>\n        </link>\n      </model>\n      <pose>0 0 1 0 0 0</pose>\n\
    \      <box>\n        <size>4 4 4</size>\n      </box>\n      <model_count>1000</model_count>\n\
    \      <distribution>\n        <type>random</type>\n      </distribution>\n  \
    \  </population>\n\nAnd I had to restart my computer after that."
