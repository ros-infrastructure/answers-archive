  body_markdown: "Hi, First you might need to convert the image from ros message image\
    \ to open cv image using  [cv_bridge](http://wiki.ros.org/cv_bridge), then use\
    \ the available functions of Opencv to read color values, like \n\n    cv:: Mat\
    \ image ;\n    Point3_<uchar>* p =image.ptr< Point3_<uchar> > (y,x);\n    p->x\
    \ //B\n    p->y //R\n    p->z //G\nand probably you can find other methods [here](https://stackoverflow.com/questions/8932893/accessing-certain-pixel-rgb-value-in-opencv)\
