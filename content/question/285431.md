  body_markdown: "Well I think that there are 2 main problems in your code:\n\n1.\
    \ There is a redundancy in the instructions,  and if you will once need to send\
    \ more than 2 goals , say 5 or even 10 you'll get a huge code for no reason.\n\
    \n2. Your code doesn't care if the robot didn't succeed the first goal  and passes\
    \ to the second one anyway.\n\nA better practice would be to:\n\n    //create\
    \ a function taking care about reaching one goal and returning true if it succeed\n\
    \    bool one_move(goal) {\n          ...\n          ac.sendGoal(goal);\n    \
    \      ac.waitForResult();\n          if(ac.getState() == actionlib::SimpleClientGoalState::SUCCEEDED)\n\
    \               return true;\n          else\n               return false;\n \
    \           }\n                        \n    int main(int argc, char** argv){\n\
    \           ...\n         //define  a list of goals\n         //loop over the\
    \ entered goals and pass to the next goal if OK or break if not.\n          ...\n\
    \         return 0;\n            }\n\nGood luck!"
