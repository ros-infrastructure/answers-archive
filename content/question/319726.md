    This has been fixed with the help of @Sean Yen and @OoeyGUI. @Sean Yen worked through the issue with me via this [GitHub issue report](https://github.com/ms-iot/ROSOnWindows/issues/91).

    Short story: The following command fixed my install

        choco upgrade -y --force ros-melodic-desktop

    Afterward I noted that the command to install ROS for Windows under the Binary Package Installation section [here](https://ms-iot.github.io/ROSOnWindows/GettingStarted/Setup.html) changed from:

        choco upgrade ros-melodic-desktop -y

    to

        choco upgrade ros-melodic-desktop_full -y

    so it might have stemmed from not downloading the full package on the initial install.
