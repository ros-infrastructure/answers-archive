    You can orbit the view dragging the mouse wheel pressed. You could also left-click drag while holding the `Shift` key.

    Double-clicking a model to zoom in it is a useful feature in several occasions, for example if you have a world with several objects, maybe even moving, and you want to quickly move the view to one of them. But it's true that it might not be useful for every use case, so I created an [issue](https://bitbucket.org/osrf/gazebo/issue/1562/add-option-to-turn-off-zoom-on-model-on) to add an option to turn off this behaviour.
