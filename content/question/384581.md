  body_markdown: "The `rostopic --help` output may offer some guidance here:\n\n>\
    \       --nostr               exclude string fields\n      --noarr           \
    \    exclude arrays\n\nif you add `--noarr` to your `rostopic echo` command, you'll\
    \ be able to see the header and other non-array fields.\n\nAlternatively: `rostopic\
    \ echo` can \"subscribe\" to individual fields.\n\nI put \"subscribe\" in quotes\
    \ as in reality, it will still subscribe to the topic (so not to a field), but\
    \ it will only print the value of the field, instead of the entire message.\n\n\
    This is mentioned on [wiki/rostopic - echo](http://wiki.ros.org/rostopic#rostopic_echo):\n\
    \n> `echo <topic-name/field>`\n>\n> Display specific fields in a message.\n> \n\
    >     $ rostopic echo /my_topic/field_name"
