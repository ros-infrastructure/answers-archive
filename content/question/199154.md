    \ to select the header frame and child frame is:\n \n - subscribe to the `/tf`\
    \ topic, your callback function will get a message of the type `tf::tfMessageConstPtr`\
    \ let's call this message **msg_in**\n - msg_in will have information such as\
    \ (See [tfMessage.msg](http://docs.ros.org/indigo/api/tf/html/msg/tfMessage.html)):\n\
    \ - geometry_msgs/TransformStamped transforms\n      - std_msgs/Header header\n\
    \      - string child_frame_id\n      - geometry_msgs/Transform transform\n  \
    \      - geometry_msgs/Vector3 translation\n        - geometry_msgs/Quaternion\
    \ rotation\n\nYou are interested in the translation and rotation components so\
    \ you can access them with:\n\n - msg_in ->transforms[i].transform.rotation.(x,\
    \ y, z, or w)\n - msg_in ->transforms[i].transform.translation(x, y, or z)\n\n\
    Where `i` is the number of the transform message. You can store them in a `tf::Quaternion`\
    \ and a `tf::Vector3` respectively. Here is a portion of an algorithm that can\
    \ help you:\n\n    #include \"tf/tf.h\"\n    #include \"tf/tfMessage.h\"\n\n------------------------------\n\
    \n    void tfCB(const tf::tfMessageConstPtr msg)\n    {\n      //Go through all\
    \ the tf frame information and select the one you are interested in\n      for(int\

    \ == \"/name_of_your_child_frame\"){\n    \t  cout << \"Msg Size: \" << msg->transforms.size()\

    \ << endl;\n    \t  cout << \"Child Frame: \" << msg->transforms[i].child_frame_id\
