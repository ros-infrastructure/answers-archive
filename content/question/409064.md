  body_markdown: "> Will installing MotoPlus [..]\n\nFirst: on a YRC1000, you would\
    \ not be \"*installing MotoPlus*\". MotoPlus (the SDK at least) is a development\
    \ environment you'd install on a Windows PC. The runtime environment is already\
    \ present on the YRC1000. The only thing you would do is install *MotoROS*. That's\
    \ a MotoPlus *application*, and the part which runs on the YRC1000.\n\n> Will\
    \ installing MotoPlus have any effect on the \"standard\" functioning of the pendant?\
    \ \n\nNo.\n\n> Will the installation impact the behavior of other control methods?\n\
    \nNo.\n\nMotoROS1 uses a regular INFORM job to control when the ROS node would\
    \ have control over the robot. If that job isn't active, no external control is\
    \ possible.\n\nMotoROS1 will attempt to start the job though if the ROS node asks\
    \ it to. But it can only do that if the controller is in remote mode (ie: the\
    \ Programming Pendant is not the single point of control).\n\nAll other INFORM\
    \ programs can still run as normal and the robot would not start moving \"suddenly\"\
    \ just because a ROS node wants it to. You have to actively allow MotoROS1 to\
    \ take control."
