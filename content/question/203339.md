  body_markdown: "I am very new and I am answering with every doubt, but following\
    \ [fcl](http://github.com/flexible-collision-library/fcl):\n\n\n----------\n\n\
    // Given two objects o1 and o2\n\nCollisionObject* o1 = ...\n\nCollisionObject*\
    \ o2 = ...\n\n// set the collision request structure, here we just use the default\
    \ setting\n\nCollisionRequest request;\n\n// result will be returned via the collision\
    \ result structure\n\nCollisionResult result;\n\n// perform collision test\n\n\
    collide(o1, o2, request, result);\n\nBy setting the collision request, the user\
    \ can easily choose whether to return contact information (which is slower) or\
    \ just return binary collision results (which is faster).\n\n----------\n\n\n\
    \ I have come to understand that flag is necessary only to validate that collision\
    \ test was performed successfully. What you are looking for (the outcome of collision)\
    \ is the **result** variable.  "
