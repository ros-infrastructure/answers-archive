    This will set ``-g`` for you:

        catkin_make -DCMAKE_BUILD_TYPE=Debug

    I think ``-Wall`` is set automatically.

    Here are come useful CMake variables: http://www.cmake.org/Wiki/CMake_Useful_Variables
