  body_markdown: "I believe that move_base actually explicitly rejects messages received\
    \ in the base_link because it is not achievable to reach said goal. Since 2m forward\
    \ will always be 2m forward. I didn't find the logic in a quick search but think\
    \ you could find it if you looked. \n\nTo make it work relatively quickly you\
    \ could simply query for the current robot pose in odom, and then add the offset\
    \ you want to drive to in your script. This will allow move_base to persist the\
    \ goal in the odom frame and be able to reach it. "
