    \ only with one gazebo simualtion so that I can have more simulations in total\
    \ with different rosmasters?\n\nYes.\n\nThe Multimaster-FKIE package connects\
    \ the different ROS masters, checks for the activity on the master and copies\
    \ all the messages it finds to all of the connected ROS Masters (connects nodes\
    \ of the different ROS masters based on the topics they subscribe or publish to).\
    \ The Multimaster-FKIE package provides an **[ignore list](https://wiki.ros.org/master_sync_fkie#line-584)**\
    \ where you can specify the topics or the nodes that are not to be connected with\
    \ other ROS masters.\n\nBy default the **[/rosout, \"/*master_sync* node\", \"\
    remote /*master_discovery* node\", \"/*node_manager\", /*zeroconf]** nodes and\
    \ the **['/rosout', '/rosout_agg']** topics are ignored. But you can add your\
    \ own on top of that. \n\nI have successfully run two simulations on two different\
    \ ROS masters by adding the **['/gazebo*','/tf*','/clock']** topics into the **~ignore_topics**\
    \ list.\n\nHere are some notes I wrote for myself when exploring the Multimaster-FKIE\
    \ package:\n\n# Running Multiple Simulations Using Multiple ROS-Masters\n\n##\
    \ multimaster-FKIE package\nThe [multimaster-FKIE package](http://wiki.ros.org/multimaster_fkie)\
    \ provides two main nodes\n\n- `master_discovery`\n- `master_sync`\n\nThe `master_discovery`\
    \ node broadcasts the messages over the network and scans the network for broadcasts\
    \ of other `master_discovery` nodes. It then publishes the communication of other\
    \ `master_discovery` nodes to its own ROS-Master. The `master_sync` connects to\
    \ the discovered `master_discovery` nodes and requests the actual ROS state and\
    \ registers the topics and services of the other ROS-Master.\n\nIt is possible\
    \ to set whether to synchronize or ingore for each node, topic or service. This\
    \ way certain topics or nodes can be private for the ROS-Master and will not be\
    \ communicated to the other ROS-Masters.\n\n![image description](http://wiki.ros.org/multimaster_fkie?action=AttachFile&do=get&target=ros_multimaster.png)\n\
    \ source:ros.wiki.org\n\n## Simulation A and B example\n\nThere are two ROS-Masters\
    \ running at different ports (11311 and 11312). Both ROS-Masters run a `master_discovery`\
    \ node and a `master_sync` node. The `/gazebo`, `/gazebo_gui`, `/tf` and `clock`\
    \ topics are set private for each ROS-Master. \n\nThe Gazebo simulation A is launched\
    \ at the port 11345 and connected to the ROS-Master at the port 11311. \nThe Gazebo\
    \ simulation B is launched at the port 11346 and connected to the ROS-Master at\
    \ the port 11312. \n\n## How to install\n### install multimaster-fkie\n\n    sudo\
    \ apt-get install ros-kinetic-multimaster-fkie\n\n### check if multicast allowed\n\
    \n    cat /proc/sys/net/ipv4/icmp_echo_ignore_broadcasts\n\nif output 0, multicast\
    \ is allowed\n\n### allow multicast temporarily\n\n    sudo sh -c \"echo 0 >/proc/sys/net/ipv4/icmp_echo_ignore_broadcasts\"\
    \n\n### allow multicast permanently\nedit the `/etc/sysctl.conf` and add following\
    \ line\n\n    net.ipv4.icmp_echo_ignore_broadcasts=0\n\nand execute command\n\n\
    \    sudo service procps restart\n\n### Check which multicast groups are defined\
    \ in a computer\n\n    netstat -g\n\n## Running The Simulations A and B\n\n###\
    \ First terminal\n\n<b>tab 1</b>\n\n    roscore\n\n<b>tab 2</b>\n\nfind the group\n\
    \n    netstat -g\n\n![netstat](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/1569486919626591.png)\n\
    \nrun the `master_discovery`\n\n    rosrun master_discovery_fkie master_discovery\
    \ _mcast_group:=224.0.0.251\n\n<b>tab 3</b>\n\nrun master_sync\n\n    rosrun master_sync_fkie\
    \ master_sync _ignore_nodes:=['/gazebo*','/tf*','/clock'] _ignore_topics:=['/gazebo*','/tf*','/clock']\n\
    \n*Here the ignore nodes might be redundant but I didn't want to take chances.\
    \ You can experiment.*\n\n\n<b>tab 4 and more</b>\n\n    source ~/catkin_ws/devel/setup.bash\n\
    \nRun Simulation A and simulation A specific ROS nodes.\n\n### Second terminal\n\
    \n<b>tab 1</b>\n\n    roscore -p 11312\n\n<b>tab 2</b>\n\n    export ROS_MASTER_URI=http://localhost:11312\n\
    \    rosrun master_discovery_fkie master_discovery _mcast_group:=224.0.0.251\n\
    \n<b>tab 3</b>\n\nrun master_sync\n\n    export ROS_MASTER_URI=http://localhost:11312\n\
    \    rosrun master_sync_fkie master_sync _ignore_nodes:=['/gazebo*','/tf*','/clock']\
