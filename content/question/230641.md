  body_markdown: " Instead of `global_localization`, I'm using publishing to `/initialpose`\
    \ topic method in my custom package. Now I can set covariance matrix to disperse\
    \ particles in specific area.    `X_DEVIATION_WEIGHT`, `Y_DEVIATION_WEIGHT` and\
    \ `YAW_DEVIATION_WEIGHT` parameters are globally declared; \n\n    bool publishToInitialPose(geometry_msgs::PoseWithCovarianceStamped\
    \ msg, ros::Publisher publisher, bool last_publish = false)\n    {\n    \tmsg.header.stamp\
    \ = ros::Time::now();\n    \tmsg.header.frame_id = \"/\" + NAMESPACE + \"/map\"\
    ;\n    \tmsg.pose.pose.position.x = POS_X;\n    \tmsg.pose.pose.position.y = POS_Y;\n\
    \n    \tmsg.pose.pose.orientation.x = 0.0;\n    \tmsg.pose.pose.orientation.y\
    \ = 0.0;\n    \tmsg.pose.pose.orientation.z = ORI_Z;\n    \tmsg.pose.pose.orientation.w\
    \ = ORI_W;\n\n    \tmsg.pose.covariance[0] = X_DEVIATION_WEIGHT; \n    \tmsg.pose.covariance[7]\
    \ = Y_DEVIATION_WEIGHT; \n    \tmsg.pose.covariance[35] = YAW_DEVIATION_WEIGHT;\
    \ \n    \tpublisher.publish( msg );\n    }"
