  body_markdown: "One option could be to use relative param names in xyz.launch (instead\
    \ of absolute ones) and put the include file inside a group with a namespace:\n\
    \n    <launch>\n      <group ns=\"prefix\">\n    \t<include file=\"xyz.launch\"\
    />\n      </group>\n    </launch>\n\n    <launch>\n    \t<param name=\"a/hello\"\
    \ value=\"10\" />\n    </launch> \n\nNot exactly a remap, but if you just whant\
    \ to add a prefix, it should work."
