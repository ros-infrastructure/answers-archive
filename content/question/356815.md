  body_markdown: "One key thing to remember is that some robots (notably the PR2)\
    \ can move in both x and y directions, so many of the parameters allow for translation\
    \ in both x and y. Your robot can only move in x. \n\n`min_vel_x` is the minimum\
    \ value the robot will [generate in the x direction.](https://github.com/ros-planning/navigation/blob/b496f6891bfa8c6f471773bacb9b327e41bd36bb/base_local_planner/src/simple_trajectory_generator.cpp#L103).\
    \ If the value is negative, then the robot could drive backwards.\n\nIf you have\
    \ a holonomic robot, that value may be 0.0 to allowed to be 0 to allow for pure\
    \ translation in the Y direction. However, if you allow for both the x velocity\
    \ and y velocity to be zero, it may choose a velocity of 0 in BOTH directions.\
    \ That is often times unproductive, so you want to make sure its translating in\
    \ some direction. That is what `min_trans_vel` is for. However, with non-holonomic\
    \ robots, it doesn't make much difference. \n\n`min_rot_vel` serves the same general\
    \ function, but there's only one way to turn. \n\n`trans_stopped_vel` is only\
    \ used at the end of your navigation when the robot is stopping. At this point,\
    \ you do want to command your robot at a speed less than your `min_vel_x`. `trans_stopped_vel`\
    \ is the velocity at which we consider the robot to be [\"stopped\" ](https://github.com/ros-planning/navigation/blob/5fe08786d9058ea4dfe5b3292a6622efbb48a153/base_local_planner/src/latched_stop_rotate_controller.cpp#L70),\
    \ and when it is stopped, then we can mark the goal as succeeded. Similarly `rot_stopped_vel`\n\
    \n[There exists](https://github.com/ros-planning/navigation/blob/c7bcd005fde62d3eaa2069b96f33ba4c472eadb8/base_local_planner/include/base_local_planner/prefer_forward_cost_function.h)\
    \ code to have your robot prefer to move forward, but its not actually used anywhere\
    \ IIRC. \n\nI don't believe `min_in_place_vel_theta` is used by DWA. \n\nThere\
    \ may be additional [ros2 related answers here](https://navigation.ros.org/configuration/index.html)"
