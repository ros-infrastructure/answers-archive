    You cannot use `execfile` because it runs a python file. Launch files are xml files that describe which parameters to set and which nodes to run.

    To execute a launch file, you can use `subprocess.call` to execute roslaunch and give it either the absolute path to your launch file or two parameters where the first is the package of your launch file and the second is the name of the file.

  body_markdown: "In ROS 2 you need to follow these steps:\n\n 1. Create a `LaunchDescription`\
    \ object. If you have seen a regular python launch file, this is what `generate_launch_description()`\
    \ returns. This object contains information about nodes to be launched, etc.\n\
    \n 2. Create a `LaunchService` object from `launch` python module.\n\n 3. Pass\
    \ the `LaunchDescription` to `LaunchService` using `include_launch_description`\
    \ method of the `LaunchService` instance.\n\n 4. Use `run` method of the `LaunchService`.\
    \ (Use more advanced functions if you need async, etc. See more info [here.](https://github.com/ros2/launch/blob/master/launch/doc/source/architecture.rst))\n\
    \nHere's an example:\n\n    import launch\n    from launch.substitutions import\
    \ Command\n    import launch_ros\n    \n    \n    def generate_launch_description():\n\
    \        model_path = '/path/to/my/robot.urdf'\n    \n        robot_state_publisher_node\
    \ = launch_ros.actions.Node(\n            package='robot_state_publisher',\n \
    \           executable='robot_state_publisher',\n            parameters=[{'robot_description':\
    \ Command(['xacro ', model_path])}]\n        )\n    \n        spawn_entity = launch_ros.actions.Node(\n\
    \        \tpackage='gazebo_ros', \n        \texecutable='spawn_entity.py',\n \
    \           arguments=['-entity', 'sam_bot', '-topic', 'robot_description'],\n\
    \            output='screen'\n        )\n        \n        return launch.LaunchDescription([\n\
    \            launch.actions.ExecuteProcess(cmd=['gazebo', '--verbose', '-s', 'libgazebo_ros_factory.so'],\
    \ output='screen'),\n            robot_state_publisher_node,\n            spawn_entity,\n\
    \        ])\n    \n    \n    def main():\n        launch_description = generate_launch_description()\n\
    \        launch_service = launch.LaunchService()\n        launch_service.include_launch_description(launch_description)\n\
    \        launch_service.run()\n    \n    \n    if __name__ == '__main__':\n  \
    \      main()"
