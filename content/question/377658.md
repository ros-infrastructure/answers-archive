  body_markdown: "You can [certainly use a .dae file as a collision model in Gazebo](http://gazebosim.org/tutorials?tut=import_mesh).\
    \ A very simple `model.sdf` file for a *static* table could look like this:\n\n\
    \    <?xml version=\"1.0\"?>\n    <sdf version=\"1.4\">\n      <model name=\"\
    my_mesh\">\n        <pose>0 0 0  0 0 0</pose>\n        <static>true</static>\n\
    \        <link name=\"body\">\n          <visual name=\"visual\">\n          \
    \  <geometry>\n              <mesh><uri>file://my_mesh.dae</uri></mesh>\n    \
    \        </geometry>\n          </visual>\n          <collision name=\"collision\"\
    >\n            <geometry>\n              <mesh><uri>file://my_mesh.dae</uri></mesh>\n\
    \            </geometry>\n          </collision>\n        </link>\n      </model>\n\
    \    </sdf>\n\nYou can also model your table piece by piece if you really want,\
    \ but I see no point in doing so. If you want your table to move when your robot\
    \ bumps into it, you can set the `static` tag to `false` and add an [inertial](http://gazebosim.org/tutorials?tut=inertia&cat=build_robot)\
    \ block using solidworks values or otherwise generated values. \n\nI will also\
    \ make you aware of the [Solidworks to URDF exporter](http://wiki.ros.org/sw_urdf_exporter),\
    \ which can be handy for more advanced models (though I wouldn't bother for simple\
    \ rigid models like a table). "
