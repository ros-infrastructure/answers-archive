    You can install ROS Melodic on Ubuntu 18.04 (NOT ubuntu 16.04) according to [here](http://wiki.ros.org/melodic/Installation/Ubuntu). But if you want to use ROS kinetic, you will be suffered from installation. As far as I know, Ubuntu 18.04 does NOT support ROS kinetic ever. Just so you know, I've tried to install ROS kinetic on Ubuntu 18.04 but never succeeded so far. So if you have Ubuntu 18.04 only, I recommend choosing ROS melodic, else if you hope to use ROS kinetic, you should re-install Ubuntu 16.04 as dual booting and insert ROS kinetic. Have a nice day :)
