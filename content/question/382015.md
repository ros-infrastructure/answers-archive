  body_markdown: "Hi @electrophod\n\nHow about using the [Group](http://wiki.ros.org/roslaunch/XML/group)\
    \ option that provides the XML launch. Like so:\n\n    <?xml version=\"1.0\"?>\n\
    \    <launch>\n    \n      <arg name=\"ns0\" default=\"ares\"/> <!-- Namespace\
    \ 0 -->\n      <arg name=\"ns1\" default=\"ares\"/> <!-- Namespace 1 -->\n   \
    \ \n      <!-- Group namespace 0 Nodes -->\n      <group ns=\"$(arg ns0)\">\n\
    \        <!-- Include nodes that works in namespace 0 -->\n    \t<include...>\n\
    \    \t...\n    \t</include>\n      </group>\n    \n      <!-- Include nodes that\
    \ works in global namespace -->\n      <include...>\n      ...\n      </include>\n\
    \    \n      <!-- Group namespace 1 Nodes -->\n      <group ns=\"$(arg ns1)\"\
    >\n        <!-- Include nodes that works in namespace 1 -->\n    \t<include...>\n\
    \    \t...\n    \t</include>\n      </group>\n    \n    </launch>\n\nAnd call\
    \ it like this:\n\n    roslaunch package my_launch.launch ns0:=namespace_0 ns1:=namespace_1\n\
    \nI do not know if that is exactly what you want, if it not the case I will update\
    \ the answer.\n\n\n"
