  body_markdown: "Maybe you haven't defined correctly your workspace. The issue is,\
    \ you have to add your workspace path to the file .bashrc\nThe command is: **sudo\
    \ gedit ~/.bashrc**, and the end of the document you must write these lines:\n\
    \n1. First of all, you should write your source, I mean, for example: \n\n**source\
    \ ~/my_workspace**\n\n2. Then, you add to the ROS_PACKAGE_PATH the path of your\
    \ workspace, I mean, the path of the folder that you want to be your workspace,\
    \ for example:\n\n**export ROS_PACKAGE_PATH=/home/user/my_workspace:$ROS_PACKAGE_PATH**\n\
    \n3. Finally you must export your new workspace too. The command is\n\n**export\
    \ ROS_WORKSPACE=/home/user/my_workspace**\n\nI hope you solve your problem!"
