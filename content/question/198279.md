  body_markdown: "You can either use rosrun or manually execute the binary/script.\
    \ In the first case, run:\n\n    rosrun <package_name> <executable_name>\n\nIn\
    \ the second case look up the executable name (if you're using catking, it's usually\
    \ in \n\n    <catkin_workspace>/devel/lib/<executable_name>\n\n**EDIT**\n\nI see\
    \ what you want to do now! If you want the nodelet manager (that's the node you're\
    \ looking for), then you should look at manager.launch.xml in rgbd_launch. In\
    \ particular the lines that you're interested in are:\n\n    <!-- Nodelet manager\
    \ -->\n      <node pkg=\"nodelet\" type=\"nodelet\" name=\"$(arg name)\" args=\"\
    manager\"\n            output=\"screen\" launch-prefix=\"$(arg launch_prefix)\"\
    >\n         <param name=\"num_worker_threads\" value=\"$(arg num_worker_threads)\"\
    \ />\n      </node>\n\nwhere the name is set in the calling launch file (openni.launch,\
    \ https://github.com/ros-drivers/openni_launch/blob/hydro-devel/launch/openni.launch).\n\
    \nJust remember that all roslaunch does is to call processes, so if roslaunch\
    \ can do it then you can do it as well at the command line! For example if you\
    \ want to run the nodelet above, just type:\n\n    >> rosrun nodelet nodelet manager\
    \ _num_worker_threads:=4 "
