    \    import threading # Needed for Timer\n    from std_msgs.msg import String\n\
    \    \n    rospy.init_node(\"test\")\n    \n    def timeout():\n    \tprint(\"\
    No message received for 5 seconds\")\n        # Do something\n    \n    def callback(msg):\n\
    \    \tglobal timer\n    \tprint(\"Message received\")\n    \ttimer.cancel()\n\
    \    \ttimer = threading.Timer(5,timeout)\n    \ttimer.start()\n    \t# Do Other\
    \ thing\n    \n    rospy.Subscriber(\"/test\",String, callback) # When receiving\
    \ a message, call callback()\n    timer = threading.Timer(5,timeout) # If 5 seconds\
    \ elapse, call timeout()\n    timer.start()\n    \n    while not rospy.is_shutdown():\n\
    \    \t#Do something else\n    \trospy.sleep(1)\n\nThis code give you the idea,\
    \ by using a timer you can check when no message are received.\nIf a message is\
    \ received, you reset the timer (By cancelling and starting a new timer). If no\
    \ message are received, then you can do what you want in the `timeout()` function."
