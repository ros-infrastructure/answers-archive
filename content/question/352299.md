  body_markdown: "In order for the costmap to be able to clear obstacles, your observation\
    \ source needs to \"see\" a distance greater than the distance from the observation\
    \ source to the obstacle, this is part of the raytrace algorithm in the ROS Navigation\
    \ stack. \n\nBased on your parameters, it seems you have set all the right variables\
    \ correctly: \n\n- obstacle_range: 2.5 < raytrace_range: 3.0 (raytrace_range should\
    \ be more than obstacle_range) \n- marking and clearing are set to true \n- you\
    \ can also try adding observation_persistence: 0.0 to ensure that obstacles are\
    \ immediately cleared \n- check if your laser_scan_sensor has a maximum range\
    \ value instead of inf or nan values. You can check this by doing a rostopic echo\
    \ filtered_scan and inspecting the data (if you observe inf or nan values, you\
    \ can use the http://wiki.ros.org/laser_filters package and use the LaserScanRangeFilter.\
    \ Set the upper threshold to the max_range of your lidar and upper_replacement_value\
    \ to max_range of your lidar "
