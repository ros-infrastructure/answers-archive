  body_markdown: "Doing this using a launch file as you are is fairly straightforward.\
    \ \n\nIf you set the `required` attribute to true [(see here)](http://wiki.ros.org/roslaunch/XML/node#Attributes)\
    \ for the rosbag node which is playing the data then when it finishes and closes,\
    \ roslaunch will automatically shutdown all the other nodes, including the rosbag\
    \ node which is writing the new file.\n\nIf your nodes are capable of processing\
    \ the raw data much faster than they are played back in the bag then you scan\
    \ speed up the playback using the `-r <ratio>` argument as described [here](http://wiki.ros.org/rosbag/Commandline#rosbag_play).\n\
    \nHope this helps."
