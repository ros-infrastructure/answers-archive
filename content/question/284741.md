    If you look at [the implementation of the `SimpleActionServer`](https://github.com/RobotWebTools/roslibjs/blob/45792e1d90ac2c201513dc9f1f508d24c7da6b0c/src/actionlib/SimpleActionServer.js#L138), you'll see that you can use the `Date` object to get the time (in milliseconds):

        var currentTime = new Date();
        var secs = Math.floor(currentTime.getTime()/1000);
        var nsecs = Math.round(1000000000*(currentTime.getTime()/1000-secs));
        that.statusMessage.header.stamp.secs = secs;
        that.statusMessage.header.stamp.nsecs = nsecs;
