  body_markdown: "You can not plan for pose targets for multiple planning groups simultaneously\
    \ .You first need to find a fitting joint configuration for each robot using IK\
    \ and then set joint targets. I opened an Issue for a similar problem [here](https://github.com/ros-planning/moveit/issues/3082).\n\
    \n    bool rocket_found_ik = kinematic_state->setFromIK(rocket_joint_model_group,\
    \ rocket_pose, timeout);\n    bool groot_found_ik = kinematic_state->setFromIK(groot_joint_model_group,\
    \ groot_pose, timeout);\n    \n    kinematic_state->copyJointGroupPositions(rocket_joint_model_group,\
    \ rocket_joint_values);\n    kinematic_state->copyJointGroupPositions(groot_joint_model_group,\
    \ \n    \n    // planning group with rocket and groot\n    rng_group_interface.setJointValueTarget(rocket_joint_names,\
    \ \n    rng_group_interface.setJointValueTarget(groot_joint_names, \n    \n  \
    \  bool success = (rng_group_interface.plan(my_plan) == moveit::planning_interface::MoveItErrorCode::SUCCESS);\n\
    \n\nI create a demo project you can find [here](https://github.com/bi3ri/dual_arm_demo).\n\
