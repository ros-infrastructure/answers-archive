  body_markdown: "I faced a very similar issue with **gazebo citadel** on **Ubuntu\
    \ 20.04**. Turning off the firewall with `sudo ufw disable` solved the issue for\
    \ me but this is only a temporary solution. I suppose by default the ignition\
    \ gazebo server used my devices LAN IP to listen for incoming client requests,\
    \ which is why the firewall blocked it. In any case, shifting the address to local\
    \ loopback i.e. `127.0.0.1` with `export IGN_IP=127.0.0.1` is better than disabling\
    \ the firewall, provided you want to run both server and client on the same machine.\
