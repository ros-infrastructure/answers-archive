    Ok, found the important bit [here](https://answers.ros.org/question/237613/how-to-define-ros-kinetic-to-use-python3-instead-of-python27/?answer=331009#post-id-331009):
    I had to explicitly tell catkin build to use python version 3.7, i.e.:

        catkin build -DCATKIN_ENABLE_TESTING=0 -DCMAKE_BUILD_TYPE=Release -DPYTHON_VERSION=3.7

    Hope that helps someone in the future!
