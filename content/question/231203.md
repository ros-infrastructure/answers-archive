  body_markdown: "boost::bind() returns something that can be called like a function.\
    \ It doesn't actually call the function.\n\nIn your first example, you should\
    \ be able to reproduce the behavior with:\n\n    boost::bind(&show, boost::ref(letter))();\n\
    \ \nOr if you want it to call that function more than once (like the TF example\
    \ does), you could do:\n\n    boost::function f = boost::bind(&show, boost::ref(letter));\n\
    \    f();\n    f();"
