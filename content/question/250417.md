 I used usb_cam driver to run two usb_cam nodes. They are:

/camera1/image_view
/camera1/usb_cam1
/camera2/image_view
/camera2/usb_cam2
/rosout

Topic includes:
/camera1/usb_cam1/camera_info
/camera1/usb_cam1/image_raw
/camera2/usb_cam2/camera_info
/camera2/usb_cam2/image_raw

Then I try to calibrate the camera1 first. I type this command:
$ rosrun camera_calibration cameracalibrator.py --size 8x6 --square 0.108 image:=/camera1/usb_cam1/image_raw camera:=/camera1/usb_cam1

The calibration window opened.

Then I try to calibrate in stereo mode. I type this command:
$ rosrun camera_calibration cameracalibrator.py --size 8x6 --square 0.030 right:=/camera2/usb_cam2/image_raw left:=/camera1/usb_cam1/image_raw right_camera:=/camera2/usb_cam2 left_camera:=/camera1/usb_cam1

It failed to open up the window. No error messages. Pls help.
