On my docker I run:

    docker run --net host -it osrf / ros: foxy-desktop
And in my RASP:

    ros2 topic pub /barbarians std_msgs/String "data: Hello World!"
so, in the docker I run:

    ros2 topic lis
And  I don't see barbarians topic
