  body_markdown: "Based on a comment posted in the issue [https://github.com/ros2/launch/issues/469](https://github.com/ros2/launch/issues/469),\
    \ one way to make the eval substitution work is by adding extra quotes in the\
    \ evaluated expression, as described below:  \n\n      <let name=\"foo\" value=\"\
    $(eval '\\'a\\' + \\'_description\\'')\"/>\n\nFor the evaluation to work with\
    \ a predefined variable, the expression would look like this (you will need to\
    \ adapt for your own expression):\n\n      <let name=\"bar\" value=\"$(eval '\\\
    '$(var bar)\\' == \\'b\\'')\" />\n\nI couldn't find any other documentation about\
    \ this other than in the ticket mentioned above."

As a minimal test case I wanted to do string concatenation inside a `<let>` tag: `<let name="foo" value="$(eval 'a' + '_description')"/>` returns

>  eval substitution expects 1 argument

Variable evaluation also doesn't work:  `$(eval var('bar'))` prints

> Expecting: {'RPAR', 'SPACE', 'DOLLAR', 'UNQUOTED_RSTRING'}

I assumed that this should be supported, because it says `eval` substitutions haven't changed in [this official tutorial](https://index.ros.org/doc/ros2/Tutorials/Launch-files-migration-guide/#substitutions).
