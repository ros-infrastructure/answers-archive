  body_markdown: "Hi,\n\nThat line simply defines a string called `OPENCV_WINDOW`\
    \ with value \"`Image window`\". It is just the name of the OpenCV window that\
    \ is opened in line 26.\n\n    cv::namedWindow(OPENCV_WINDOW);\n\nIf you look\
    \ at the OpenCV documentation [here](http://docs.opencv.org/2.4/modules/highgui/doc/user_interface.html),\
    \ you can understand what the `namedWindow()` method does. To quote it, *\"The\
    \ function namedWindow creates a window that can be used as a placeholder for\
    \ images and trackbars. Created windows are referred to by their names.\"* \n\n\
    So you can use the string \"`Image window`\" (the value of `OPENCV_WINDOW` string\
    \ variable) to refer to this window. Eg : Line 31\n\n    cv::destroyWindow(OPENCV_WINDOW);\n\
    \nThis line is used to close the window opened in line 26. \n\nYou don't **HAVE\
    \ TO** declare a string variable. You can simply open and close the window like\
    \ this.\n\n    cv::namedWindow(\"Image window\");\n\n    cv::destroyWindow(\"\
    Image window\");\n\nHowever, it is a good practice to define these kind of values\
    \ at the top of your code so that if you ever want to change it to something else\
    \ (say, \"`Image window 1`\"), you don't have to comb through your code looking\
    \ for all appearances of it. If it were me, I would have set it as a constant\
    \ string so that I (or anyone else) accidentally (or intentionally) can't change\
    \ the value somewhere else (can lead to very hard to debug bugs). \n\nAs for a\
    \ good tutorial to subscribe to a topic, once you identify the topic you need\
    \ to subscribe to, look at the `roscpp` documentation on subscribers and publishers\
    \ [here](https://www.google.com.au/webhp?sourceid=chrome-instant&ion=1&espv=2&ie=UTF-8#q=roscpp%20subscriber)."
