    You should be able to use the cv_bridge package to convert an image to an OpenCV cv::Mat, and from there you can use [cv::imencode](https://docs.opencv.org/3.4/d4/da8/group__imgcodecs.html#ga461f9ac09887e47797a54567df3b8b63) to encode the image into PNG format.

    I'm not sure how you would pass that to a REST API, but I assume the REST library that you're using will have documentation which covers that.
