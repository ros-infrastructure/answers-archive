  body_markdown: "If you want a particular callback for a topic only to be run for\
    \ the first message received, you can unsubscribe from within the callback after\
    \ you've finished your processing. For example:\n\n    def cb_once(msg, subscriber):\n\
    \        #do processing here\n        subscriber.unregister()\n    \n    sub_once\
    \ = None\n    sub_once = rospy.Subscriber('my_topic,', MyType, cb_once, sub_once)\n\
    \nIn your case, however, you could have a single callback, and just keep a flag\
    \ around like `wrote_header`, which you can set to true after the first message\
    \ was received so you only write the header once. "
