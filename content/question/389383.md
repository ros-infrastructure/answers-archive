  body_markdown: "I had the same issue and managed to fix it running static_transform_publisher:\n\
    \n `ros2 run tf2_ros static_transform_publisher \"0\" \"0\" \"0\" \"0\" \"0\"\
    \ \"0\" \"map\" \"scan\"` \n\nAdding it to a launch file could also help if you\
    \ want to bring it up everytime:\n\n    import launch\n    from launch import\
    \ LaunchDescription\n    from launch_ros.actions import Node\n    \n    def generate_launch_description():\n\
    \    \n        return LaunchDescription([\n            Node(\n               \
    \ package='tf2_ros',\n                namespace = 'scan_to_map',\n           \
    \     executable='static_transform_publisher',\n                arguments= [\"\
    0\", \"0\", \"0\", \"0\", \"0\", \"0\", \"map\", \"scan\"]\n            )\n  \
    \      ])\n\nDon't forget to add your slam_toolbox online_sync_launch.py inside\
    \ the launch file."
