  body_markdown: "The one unfortunate thing on the RPLidar is that the serial number\
    \ of the shipped serial adapter is not really a serial number i guess.\nBut if\
    \ you know in which order you plugged your serial interfaces, it should work.\n\
    I have only one here so I can not really test.\n\nTo find the right serial port,\
    \ plug in your first rplidar.\n\ntype \"dmesg\" into console and it should give\
    \ you something like this:\n\n    [10481.535436] usb 1-1.2: new full-speed USB\
    \ device number 7 using ehci-pci\n    [10481.630018] usb 1-1.2: New USB device\
    \ found, idVendor=10c4, idProduct=ea60\n    [10481.630028] usb 1-1.2: New USB\
    \ device strings: Mfr=1, Product=2, SerialNumber=3\n    [10481.630034] usb 1-1.2:\
    \ Product: CP2102 USB to UART Bridge Controller\n    [10481.630039] usb 1-1.2:\
    \ Manufacturer: Silicon Labs\n    [10481.630043] usb 1-1.2: SerialNumber: 0001\n\
    \    [10481.672731] usbcore: registered new interface driver usbserial\n    [10481.672763]\
    \ usbcore: registered new interface driver usbserial_generic\n    [10481.672785]\
    \ usbserial: USB Serial support registered for generic\n    [10481.677505] usbcore:\
    \ registered new interface driver cp210x\n    [10481.677520] usbserial: USB Serial\
    \ support registered for cp210x\n    [10481.677545] cp210x 1-1.2:1.0: cp210x converter\
    \ detected\n    [10481.747400] usb 1-1.2: reset full-speed USB device number 7\
    \ using ehci-pci\n    [10481.840989] usb 1-1.2: cp210x converter now attached\
    \ to ttyUSB0\n\nThen do the same with the second one and do the steps again.\n\
    \nUnfortunately this is not really a good solution, because you would always have\
    \ to do this.\nA final solution would be to get other serial adapters might be\
    \ found here, so that you are able to change the device \ndescriptors, especially\
    \ the serial number...which requires a Windows PC/VM:\n\nhttp://www.silabs.com/Support%20Documents/TechnicalDocs/AN144.pdf\n\
    \nWhen you have a serial number you could do something like this for FTDI devices\n\
    http://hintshop.ludvig.co.nz/show/persistent-names-usb-serial-devices/\n\nOr you\
    \ could use another serial adapter, but I guess it might be a little bit complicated,\
    \ creating your own board ...\nA FT2232 for example, would provide 4 serial interfaces\
    \ at once.\n\nThe error:\nError, cannot bind to the specified serial port /dev/ttyUSB1\
    \ mostly happens when the interface is not available or already opened.\n\n"
