    The way you pass a Node from one C++ class to another is with `shared_from_this()` and `std::shared_ptr`.

    Example:

    Class A inherits from rclcpp::Node. Get the node pointer like this:

    `auto node_ptr = shared_from_this();`

    Pass to another class (Class B) like this:

    `shared_pointer_to_class_b_object = std::make_shared<ClassB>(node_ptr);`

    The constructor of Class B should take a `rclcpp::Node::SharedPtr node`:

        ClassB(rclcpp::Node::SharedPtr node) : node_(node)
        {
        }

    And it should have a private member variable:

          // Pointer to the ROS node
          std::shared_ptr<rclcpp::Node> node_;

    ROS2 documentation is still lacking and it helps to be a C++ guru  :/

  body_markdown: "Adding comments above from AndyZe, yes you need to get the node\
    \ pointer and pass it to another class. But if you do this in the class constructor,\
    \ a `bad_weak_ptr` error will always show up. You can prevent this by initiating\
    \ the class in callback. \n\nI'm gonna use ClassA and ClassB example above, say\
    \ you want to extend the node to ClassB to use ClassB functions from ClassA. Here's\
    \ the header code of ClassB:\n\n    class ClassB {\n      public:\n        ClassB(rclcpp::Node::SharedPtr\
    \ node); // constructor\n\n        // your code here\n    \n      private:\n \
    \       rclcpp::Node::SharedPtr node_;\n\n        // your code here\n\nand here's\
    \ the definition code of ClassB:\n    \n    // constructor\n    ClassB::ClassB(rclcpp::Node::SharedPtr\
    \ node) : node_(node) {\n        \n        // your code here\n    }\n    \nThen\
    \ in ClassA file:\n    \n    class ClassA : public rclcpp::Node {\n      public:\n\
    \        ClassA() : Node(\"class_a\") {\n\n          // your code here\n     \
    \   \n          // use one-time timer to initiate class B \n          timer =\
    \ this->create_wall_timer(500ms, std::bind(&ClassA::initialization, this));\n\
    \        }\n    \n      private:\n\n        rclcpp::TimerBase::SharedPtr timer;\n\
    \n        std::shared_ptr<ClassB> class_b;\n\n        void initialization() {\n\
    \          // get node pointer, pass into Class B\n          class_b = std::make_shared<ClassB>(shared_from_this());\n\
    \          \n          // replace timer with loop callback after initialization\
    \ finished\n          timer = this->create_wall_timer(500ms, std::bind(&UsingLibCpp::timer_callback,\
    \ this)); \n        }\n\n        void timer_callback() {\n          // your code\
    \ here\n\n          // use Class B function\n          class_b->class_b_function();\n\
    \        }\n\nI finally got it work after 2 weeks of digging. Too bad ROS2 documentation\
    \ is still lacking in program style like this. Hope it helps"
