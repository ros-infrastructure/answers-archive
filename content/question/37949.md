  body_markdown: "Hi rosmaker,\n\nIf you are using \n\n    roslaunch openni_launch\
    \ openni.launch\n\nthen the conversion is already being done for you.\n\nYou only\
    \ need to subscribe to the topic */camera/depth_registered/points*. This topic\
    \ is of type *sensor_msgs/PointCloud2* and represents the 3D point cloud of the\
    \ scene in meters.\n\nYou can find further information on how to access point\
    \ cloud data in [http://www.ros.org/wiki/pcl/Tutorials](http://www.ros.org/wiki/pcl/Tutorials)\n\
    \nI hope this helps"
