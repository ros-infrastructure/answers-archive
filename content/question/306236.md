  body_markdown: "You are referring to a tutorial with `roscpp`, there is the same\
    \ one using `rospy` [here](http://wiki.ros.org/ROS/Tutorials/WritingPublisherSubscriber%28python%29).\n\
    \nYou have to modify the `CmakeLists.txt` in `python` too but not as systematically\
    \ as with `roscpp`. \nIn python if you want to run a simple node with no dependencies\
    \ you just have to make sure to use the command `chmod +x your_node.py` to get\
    \ an executable that `rosrun` can use.\nIn cpp, whenever you create a node you\
    \ have to create the executable from the `CMakeLists.txt` like that (taken from\
    \ your tutorial) :\n\n    add_executable(talker src/talker.cpp)\n\n\nYou don't\
    \ need to do that in python.\n\nBut you will have to modify the `CMakeList` if\
    \ you want to create a custom message, to use a client/server and to list all\
    \ the dependencies of your package."
