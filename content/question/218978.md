  body_markdown: "I did this in Kinetic, but I think it's same in Jade.\n\n 1. Install\
    \ Ubuntu, ROS and MySQL Server (Please search instruction yourself)\n 2. Install\
    \ libmysqlclient-dev (sudo apt-get install libmysqlclient-dev)\n 3. Create catkin\
    \ package (follow tutorial)\n 4. Make sure following code in \"package.xml\"\n\
    \n<code>\n\n    <build_depend>cmake_modules</build_depend>\n    <build_depend>libmysqlclient-dev</build_depend>\n\
    \n    <run_depend>cmake_modules</run_depend>\n    <run_depend>libmysqlclient-dev</run_depend>\n\
    \    \n    <export>\n      <cpp lflags=\"-lmysqlclient\"/>\n    </export>\n</Code>\n\
    \ 5. Make sure following code in \"CMakeList.txt\" of your package, sequence is\
    \ important.\n\n<code>\n\n    set(CMAKE_MODULE_PATH ${CMAKE_CURRENT_LIST_DIR}/cmake-modules)\n\
    \    set(EXECUTABLE_OUTPUT_PATH ${PROJECT_SOURCE_DIR}/bin)\n    set(LIBRARY_OUTPUT_PATH\
    \ ${PROJECT_SOURCE_DIR}/lib)\n\n    find_package(MySqlClient REQUIRED)\n\n   \
    \ include_directories(${MYSQL_INCLUDE_DIRS})\n\n    add_definitions(${MYSQL_DEFINITIONS})\n\
    \n    target_link_libraries(package_name\n       ${catkin_LIBRARIES}\n       ${MYSQL_LIBRARIES}\n\
    \    )\n\n</code>\n6. Create a folder named \"cmake-modules\" in your package\
    \ folder. This name is follow 1st line of code in step 5.\n<br /><br />\n7. Copy\
    \ contents in this URL: https://cmake.org/Wiki/CMakeUserFindMySQL\n    save it\
    \ to \"FindMySqlClient.cmake\", in the folder you created in step 6.\n<br /><br\
    \ />\n8. In your .cpp file, add this include line:\n<code>\n\n        #include\
    \ <mysql/mysql.h>\n\n</code>\n<br />\n9. Here is a simple sample to get data from\
    \ sys database.\n<code>\n\n        MYSQL *connection;  \n        MYSQL_RES *result;\
    \  \n        MYSQL_ROW row; \n  \n        connection = mysql_init(NULL);\n   \
    \     connection = mysql_real_connect(connection, \"mysqlserver\", \"username\"\
    , \"password\", \"sys\", 0, NULL, 0);\n  \n        if(mysql_query(connection,\
    \ \"SELECT * FROM sys_config\"))  \n        {  \n            ROS_INFO(\"Query\
    \ Error: %s\", mysql_error(connection));  \n            exit(1);  \n        }\
    \  \n        else  \n        {  \n            \n            result = mysql_use_result(connection);\
    \ \n            for(int i=0; i < mysql_field_count(connection); ++i)  \n     \
    \       {\n                std::stringstream ss;  \n                row = mysql_fetch_row(result);\
    \  \n                if(row <= 0)  \n                {  \n                   \
    \ break;  \n                }  \n                for(int j=0; j < mysql_num_fields(result);\
    \ ++j)  \n                {  \n                    ss << row[j] << \" \";  \n\
    \                }  \n                ROS_INFO(\"%s\", ss.str().c_str());  \n\
    \            }\n            mysql_free_result(result);  \n        }    \n</code>"
