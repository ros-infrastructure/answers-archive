  body_markdown: "This really is a C++ question, you probably want to read up on how\
    \ pointers work in C++. Your \"cloud\" variable is allocated on the stack and\
    \ not via a pointer, so you cannot access it\xB4s elements using the `->` operator.\
    \ So everytime you access a member of cloud you have to use (for example)\n\n\
    \    cloud.points.size()\n\nas opposed to\n\n    cloud->points.size()"
