    Hi, there's not exactly a command, but the API is there. You can find it in the [TrackController](https://github.com/gazebosim/gz-sim/blob/ign-gazebo6/src/systems/track_controller/TrackController.cc) system. Some more related discussion is in the [Pull request adding track controller](https://github.com/gazebosim/gz-sim/pull/869).

    Basically, you will need to enable contact surface customization for all the collisions you want to alter (by setting the [EnableContactSurfaceCustomization component of the collisions](https://github.com/gazebosim/gz-sim/blob/270da60b9387d3751d8d65eafd60f6459b450b00/include/ignition/gazebo/components/Collision.hh#L58)). Then you will need to subscribe to event [CollectContactSurfaceProperties](https://github.com/gazebosim/gz-sim/blob/270da60b9387d3751d8d65eafd60f6459b450b00/include/ignition/gazebo/physics/Events.hh#L47) which passes you the contact object created and pre-filled by the physics engine and you can alter it in any way you like before passing it back to the physics engine.

    AFAIK this workflow is currently only supported with DART.

    If you're only trying to implement wheel slip, have a look at the WheelSlip system, which comes even with an Ign service you can call from command line to change the slip parameters.
