    I have had it [working](http://ibotics.ucsd.edu/trac/stingray/browser/trunk/stingray_model) for my robot by using

        #include <gazebo/ModelState.h>

    I think there is also an extra '_msgs' and 's' in your function, so try it as

        void ModelStatecallback(const gazebo::ModelState::ConstPtr& msg)
        {
        }

    Check out the [ROS Gazebo](http://www.ros.org/wiki/gazebo) and [ModelState definition](http://www.ros.org/doc/api/gazebo/html/msg/ModelState.html) pages for more details.
