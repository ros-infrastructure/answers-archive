I was trying to get the 3DM-GX3-25 Inertial sensor up and running on Ros Fuerte/Ubuntu Precise using the [Microstrain 3dM-GX2 IMU node](http://www.ros.org/wiki/microstrain_3dmgx2_imu/) in the Microstrain 3dM-gX2 package. 

When I run the node, I get the following error: 
______________________________

> jdavis@MyUbuntu:~/fuerte_workspace/sandbox/microstrain_3dmgx2_imu$
> rosrun microstrain_3dmgx2_imu imu_node

> [ INFO] [1345843227.742138299]:
> Connected to IMU [      3DM-GX3-25]

Any ideas on how I can get around this would be great!
