  body_markdown: "@ahendrix is correct. You need to have the `type` attribute for\
    \ the `node` tag be the name of the executable, which in your case, is `my_python.py`.\
    \ Therefore, `my_launch.launch` should be \n\n    <launch>\n      <node name=\"\
    my_python\" type=\"my_python.py\" pkg=\"my_package\" />\n    </launch>\n\nIf you\
    \ don't want to have the `.py`, then just remove it from the filename so that\
    \ it'll be `my_python`. \n\nFor more information, please see http://wiki.ros.org/roslaunch/XML/node"

    rosrun my_package my_python.py

    roslaunch my_package my_launch.launch

    ERROR cannot launch node of type [my_package/my_python.py]: can't locate node [my_python] in package [my_package]
    
    No processes to monitor

my launch file like this(my_launch.launch):

    <launch>
      <node name="my_python" type="my_python" pkg="my_package" />
    </launch>
