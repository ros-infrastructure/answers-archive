  body_markdown: "The `hw_positions_` store position values of the example hardware.\
    \ On a real hardware or simulation, you will also use something similar to store\
    \ the values. \n\nIn the specific scenario, `hw_positions_` store measured values,\
    \ so yes, you will need those in the `read` method. \n\nThe specific code `hw_positions_[i]\
    \ = hw_positions_[1] + dt * hw_commands_[i];` is just of exemplary purposes to\
    \ generate some \u201Cdynamics\u201D of movement when using this trivial simulations."
