    Transformations in ROS are handled with the tf library.

    For rviz you need to publish whatever entity you have using a known frame_id.
    In addition someone needs to publish a transformation from the currently set fixed_frame to this frame_id. rviz will then display correctly.

    The [`pcl_ros`](http://ros.org/wiki/pcl_ros) package provides transforms for PCL point clouds.

    Typically, you would add a `<depend package="pcl_ros"/>` to your `manifest.xml`, then:

         #include <pcl_ros/transforms.h>
