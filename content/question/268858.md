  body_markdown: "The reference point Solidworks uses for exporting can be confusing\
    \ sometimes. You can explicitly create a coordinate system as reference geometry\
    \ and tell Solidworks to export the part with respect to that coordinate system\
    \ to take out the guess work. There is an options button at the bottom of the\
    \ Save As window which brings you to another window that lets you set the \"Output\
    \ Coordinate System\". Pictures and more details can be found [here](https://www.gsc-3d.com/articles/2016/08/how-export-using-custom-coordinate-system-solidworks). "
