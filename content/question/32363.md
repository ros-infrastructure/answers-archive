    Stacks using Catkin in Fuerte are compiled using git-buildpackage, i.e. they are based on the common Debian build toolchain.

    As far as I know, classical ros stacks are compiled using some home brew scripts that can be found in [rosdeb](http://ros.org/wiki/rosdeb).

    I don't expect too much low-level documentation on how to exist, but at least [this](http://ros.org/wiki/rosdeb/DevelopersGuide) page might contain some valuable information.
