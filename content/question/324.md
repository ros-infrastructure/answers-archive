    Gazebo is a stand-alone package. Please do not use the version of Gazebo that ships with ROS. The version within ROS is old and unsupported.

    [http://gazebosim.org/wiki/install](http://gazebosim.org/wiki/Install) describes how to install Gazebo.

    Do not follow any of the Gazebo tutorials on the ROS website. They are old and unmaintained. Only use the tutorials on [http://gazebosim.org/wiki](http://gazebosim.org/wiki)

    You can still use ROS Fuerte, but you should install Gazebo from the repository hosted by OSRF.
