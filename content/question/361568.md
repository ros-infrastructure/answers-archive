  body_markdown: "**Step 1**: add\n\n\n    target_link_libraries(${PROJECT_NAME} \n\
    \      i2c\n    )\n\nTo your `CMakeList.txt`.\n\n**Step 2**: Declare the headers\
    \ as \"C\", \n\n    extern \"C\"\n    {\n        #include<linux/i2c-dev.h>\n \
    \       #include <i2c/smbus.h>\n    }\n\nBecause `libi2c.so` is a dynamic library\
    \ compiled with `gcc`. \n\nIf you does not declare it explicitly, the compiler\
    \ of ROS , which is `g++`, will generate different function names in the symbol\
    \ table thus the `ld` command cannot find any match in the `i2c` library.\n\n\
    Referece: https://en.wikipedia.org/wiki/Name_mangling\n"

    extern "C" {
    #include <linux/i2c-dev.h>
    #include <i2c/smbus.h>
    }
    #include <sys/ioctl.h>

    g++ -std=c++11 -Wall -c main.cpp
