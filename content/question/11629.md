    The ROS repository used to contain a backported libtinyxml2.6.2 for Natty, but it has been removed for some reason, although the built packages still need it. You can download it from [http://archive.ubuntu.com/ubuntu/pool/universe/t/tinyxml/](http://archive.ubuntu.com/ubuntu/pool/universe/t/tinyxml/). You need the libtinyxml2.6.2_2.6.2-1_*.deb file for your architecture (i386 or amd64).
