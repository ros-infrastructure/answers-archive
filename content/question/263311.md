    Per the [ROS Kinetic install page](http://wiki.ros.org/kinetic/Installation/Ubuntu), ROS Kinetic is only supported on Ubuntu 15.10 and 16.04 and Debian Jessie. It looks like Ubuntu/Lubuntu 17.04 has different package versions and isn't compatible.

    [ROS Lunar](http://wiki.ros.org/lunar/Installation/Ubuntu) is officially supported on Ubuntu 17.04, so I recommend that you install it instead.
