  body_markdown: "I think you are asking something that makes use of #q63991 , the\
    \ following example creates n subscribers and passes on information to the callback\
    \ to be able to distinguish them:\n\n    #include \"ros/ros.h\"\n    #include\
    \ \"std_msgs/String.h\"\n    \n    void chatterCallback2(const std_msgs::String::ConstPtr&\
    \ msg, const std::string topic)\n    {\n      ROS_INFO_STREAM(topic << \": I heard:\
    \ \" << msg->data);\n    }\n    \n    int main(int argc, char **argv)\n    {\n\
    \      ros::init(argc, argv, \"listener\");\n      ros::NodeHandle n;\n    \n\
    \      std::vector<ros::Subscriber> subs;\n    \n      int num = 10;\n      ros::param::get(\"\
    ~num\", num);\n      for (size_t i = 0; i < num; ++i)\n      {\n        std::stringstream\
    \ ss;\n        ss << \"topic_\" << i;\n        const std::string topic = ss.str();\n\
    \        ros::Subscriber sub = n.subscribe<std_msgs::String>(topic, 10,\n    \
    \        boost::bind(chatterCallback2, _1, topic));\n        subs.push_back(sub);\n\
    \      }\n      ros::spin();\n    \n      return 0;\n    }\n\nA typical pattern\
    \ a bit more complex than this would be to have a std::map using the topic names\
    \ as keys and data in the callback is stored or manipulate using that map."
