  body_markdown: "Yes, I think you've got the gist of it. You would want to create\
    \ a BrickPi_ROS package that handles the communication between ROS and the BrickPi.\
    \ Here is an examples of a similar ros driver for a motor controller. \n\nhttps://github.com/smd-ros-devel/kangaroo_x2_driver\
    \ \n\nIt would probably subscribe to a cmd_vel topic and publish encoder data\
    \ if there is any\n\n\nThen you may want to use a mapping package like [gmapping](https://www.google.com/webhp?sourceid=chrome-instant&ion=1&espv=2&ie=UTF-8#q=ros%20gmapping)\
    \ to turn your LIDAR data into a occupancy map\nAnd a package like [AMCL](http://wiki.ros.org/amcl)\
    \ to figure out where you are in the map\nAnd then finally a package like [move_base](http://wiki.ros.org/move_base)\
    \ to navigate around autonomously.\n\n\nHope that helps"
