  body_markdown: "A quite general version of this problem I came up with is attached:\n\
    \n    #! /usr/bin/env python\n    \n    import rospy\n    from geometry_msgs.msg\
    \ import Twist\n    from ackermann_msgs.msg import AckermannDriveStamped\n   \
    \ \n    class SendEmptyWatchdog(object):\n        def __init__(self, datatype,\
    \ topic, timeout=0.15, send_value=None):\n            self.timeout = timeout\n\
    \            self.datatype = datatype\n    \n            if send_value is None:\n\
    \                self.send_value = datatype()\n            else:\n           \
    \     self.send_value = send_value\n    \n            self.twist_subscriber =\
    \ rospy.Subscriber(topic, self.datatype, self.message_callback, queue_size=1)\n\
    \            self.twist_publisher = rospy.Publisher(topic, self.datatype, queue_size=1)\n\
    \            self.timer = rospy.Timer(rospy.Duration(self.timeout), self.timer_callback,\
    \ oneshot=True)\n            self.timeout_triggered = False\n    \n        def\
    \ message_callback(self, msg):\n            rospy.logdebug(\"SendEmptyWatchdog{}:\
    \ Message Callback\".format(self.datatype))\n            if self.timeout_triggered:\n\
    \                self.timeout_triggered = False\n            else:\n         \
    \       self.timer.shutdown()\n                self.timer = rospy.Timer(rospy.Duration(self.timeout),\
    \ self.timer_callback, oneshot=True)\n    \n        def timer_callback(self, event):\n\
    \            rospy.logwarn(\"SendEmptyWatchdog{}: Timeout Triggered. Received\
    \ no message for {} seconds\".format(self.datatype, self.timeout))\n    \n   \
    \         self.timeout_triggered = True\n            self.twist_publisher.publish(self.send_value)\n\
    \    \n    if __name__ == '__main__':\n        rospy.init_node(\"command_watchdog\"\
    )\n        twist_watchdog = SendEmptyWatchdog(Twist, \"cmd_vel\")\n        ackermann_watchdog\
    \ = SendEmptyWatchdog(AckermannDriveStamped, \"cmd_ackermann\")\n        rospy.spin()\n\
    \nWhat it does is to subscribe to the topic \"cmd_vel\" and reset a oneshot timer\
    \ to send a \"zero twist\" message once the time is expired. The timer.shutdown()\
    \ and reinitializing is to stop the previously generated timer from firing and\
    \ spamming \"zero twist\" messages `self.timeout` seconds after each received\
    \ message on \"cmd_vel\". \n\nTo avoid the reset of the timer with a published\
    \ \"zero twist\" message, no timer is started for the first message after a timeout\
    \ wast triggered.\n\nThe snippet works with Twists and basically any other datatype\
    \ (Example with \"AckermannDriveStamped\" in the code).\n\nSince by default all\
    \ numeric fields of a newly created message are set to 0 stopping the robot in\
    \ case of a timeout doesn't need a \"send_value\" specified. However you can do\
    \ so, if e.g. a frame has to be specified.\n\n\n"
