  body_markdown: "Filippo,\n\nHow are you bringing up the two cameras?  If you simply\
    \ launch the\nopenni.launch file twice, things won't work because you will launch\n\
    the same nodes with the same names twice. You have to pass a camera\nnamespace\
    \ argument to the launch file. For openni_camera_unstable,\nthis would look like:\n\
    \nroslaunch openni_camera_unstable openni.launch camera:=kinect_1\nroslaunch openni_camera_unstable\
    \ openni.launch camera:=kinect_2\n\nOr, if you want to create your own launch\
    \ file:\n\n<launch>\n    <include file=\"$(find openni_camera_unstable)/launch/openni.launch\"\
    >\n       <arg name=\"camera\" value=\"kinect_1\" />\n    </include>\n\n    <include\
    \ file=\"$(find openni_camera_unstable)/launch/openni.launch\">\n       <arg name=\"\
    camera\" value=\"kinect_2\" />\n    </include>\n</launch>\n\n\nHope this helps.\n\
    \nWim "
