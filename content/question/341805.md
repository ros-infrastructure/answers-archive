  body_markdown: "The converter options are designed in a way to easily convert incoming\
    \ messages with specified serialization format into another outgoing serialization\
    \ format.\nThis is to allow rosbag to record data in a middleware agnostic serialization\
    \ format. DDS has e.g. a serialization format called CDR, but other middleware\
    \ such as iceoryx [et al](https://discourse.ros.org/t/non-dds-based-rmw-implementation/5890)\
    \ might use a different one. The converter plugins in rosbag2 allow you to convert\
    \ from one into the other with these options.\n\nIf they are set equally and correspond\
    \ to the locally used RMW implementation, no conversion is being done. "
