- body_markdown: "In the same link you gave us there is a list of all the available\
    \ nodelets inside the package.\n\nEach nodelet ask for a defined topics to subscribe\
    \ and gives a defined result.\n\nLet's imagine you want to achieve a raw pointcloud\
    \ without color (depth_image_proc/point_cloud_xyz)\n\nyou need to send a topic\
    \ of type: \n\n    sensor_msgs/CameraInfo with the name /camera_info (which has\
    \ to be the needed data from the camera)\n\nand another with type:\n\n     sensor_msgs/Image\
    \ with the name /image_rect (which has to be the already rectified image).\n\n\
    If you send that, and the node is running, it should send back a pointcloud. you\
    \ could the check if its like that doing a rostopic echo, or visualizing the pointcloud\
    \ directly on rviz (maybe you will need to add a wolrd tf first)\n\nIf you have\
    \ more doubts do not hestitate to ask"
