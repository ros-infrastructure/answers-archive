    The `ConstWorldStatisticsPtr` type is a boost shared pointer pointer to the [world_stats.proto](http://gazebosim.org/msgs/1.9.1/world__stats_8proto.html) protobuf message and is defined in the autogenerated message code files `world_stats.pb.h`, `world_stats.pb.cc` in your build directory. Here's a snippet from one of my copies of `world_stats.pb.h`:
    <pre><code>
    typedef boost::shared_ptr<gazebo::msgs::WorldStatistics> WorldStatisticsPtr;
    ...
    typedef const boost::shared_ptr<gazebo::msgs::WorldStatistics const> ConstWorldStatisticsPtr;
    </code></pre>
