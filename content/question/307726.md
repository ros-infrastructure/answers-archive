  body_markdown: "These are not standard conditions that have tools available for\
    \ them.\n\nMy first approach to solving this would be to do the following:\n\n\
    - Determine the spanning set of frames that you're interested in\n- Subscribe\
    \ to the tf topics and look for new information on frames in you spanning set\n\
    - If there are new frames of interest query a TransformListener for the resultant\
    \ transform. \n- Keep the last result and publish the result if it's more than\
    \ some tolerance threshold.\n\nIn you second case you could set the tolerance\
    \ to zero so that it always publishes if there's a new frame information even\
    \ if it's the same. \n"
