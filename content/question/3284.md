    I don't have the karma to upvote Nate's answer, but I agree with it.

    I have used both Stage and Gazebo with ROS and real robots, both successfully.

    Currently, the ROS/Gazebo interface is more actively maintained than ROS/Stage. Knowing nothing specific about your system and its requirements, I would recommend Gazebo. But, there are valid reasons to use Stage, either instead of or in addition to Gazebo.

    Generally, I use different top-level [roslaunch](http://www.ros.org/wiki/roslaunch) scripts for running on Stage, Gazebo or the real robot. Best practice is to create a hierarchy of roslaunch scripts. Most components of your system should run the same in either case. Some specific low-level components like device drivers and the robot interface itself, will work differently or not be used at all when running in simulation.
