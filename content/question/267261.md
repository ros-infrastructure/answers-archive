  body_markdown: "Hi, I find a method to debug a C++ node usign VSCode on ROS2 Foxy\
    \ (Ubuntu). \n\n1) Compile your C++ package with the symbols: \n\n    colcon build\
    \ --symlink-install --cmake-args -DCMAKE_BUILD_TYPE=RelWithDebInfo\n\n2) Run the\
    \ GDB Server in a localhost:port\n\n    ros2 run --prefix 'gdbserver localhost:3000'\
    \ package_name executable_name\n\n3) Open VSCode on your workspace, open the debug\
    \ section (side bar) and create new launch.json configuration file for debugging.\
    \ Configure as follow:\n\n        {\n        \"version\": \"0.2.0\",\n       \
    \ \"configurations\": [\n            {\n                \"name\": \"C++ Debugger\"\
    ,\n                \"request\": \"launch\",\n                \"type\": \"cppdbg\"\
    ,\n                \"miDebuggerServerAddress\": \"localhost:3000\",\n        \
    \        \"cwd\": \"/\",\n                \"program\": \"[build-path-executable]\"\
    \n            }\n        ]\n    }\nChange [build-path-executable] by your executable\
    \ build file. You can find this path on the console when you launch the server.\n\
    \n4) Run the debugger and use VSCode to debug your code.\n\nHere is a more detail\
    \ explanation\nhttps://gist.github.com/JADC362/a4425c2d05cdaadaaa71b697b674425f"
