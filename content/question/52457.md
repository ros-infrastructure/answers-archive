  body_markdown: "I don't know why you're checking for existence, but if your node\
    \ provides an action, you can wait for the server to start with waitForServer.\
    \  You can also wait for a transform to become available with waitForTransform.\n\
    \nIf you have other reasons, there's apparently a package, interface tester, that\
    \ was designed to do this, but I can only find the [tutorial](http://ros.org/wiki/interface_testing),\
    \ not the source. Maybe you'll have better luck finding it. \n\nYou could also\
    \ use the [rosnode api](http://ros.org/doc/groovy/api/rosnode/html/). It's in\
    \ python, and there might be [zombie nodes](http://answers.ros.org/question/9521/rosnode-zombies/),\
    \ but it should give you what you need."
