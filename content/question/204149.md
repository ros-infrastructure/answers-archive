    I'm not sure I understand you correctly, but programmatically controlling camera viewpoint (and animating it) is possible using the [rviz_animated_view_controller](http://wiki.ros.org/rviz_animated_view_controller) plugin. This is a regular RViz plugin, so does not require you to use `librviz` at all, and you interact with it using ROS msgs.
