  body_markdown: "Be careful when looking to get a netbook, though they fit the purpose\
    \ with regards to running ROS, they can be painfully slow to work with, especially\
    \ if they only have 1GB of RAM.\n\nI use a MSI U180 and would in hindsight have\
    \ rather spent more and got a higher spec or investigated a laptop which was more\
    \ powerful but could fit.\n\nFor the most part all the turtlebot is going to run\
    \ is minimal.launch while the rest can be run on a workstation laptop, however\
    \ in the end you will still want to load it up and edit / create a few files on\
    \ the turtlebot netbook / laptop, which benefits from having a faster  / more\
    \ powerful one.\n\n- Also I have read of some incompatibilities with the MS Kinect\
    \ and USB 3, though it seems to not be a problem when i hook it up to my MacBook\
    \ :S.\n- If you want to attatch a robotic arm / manipulator you also may want\
    \ a laptop with 3 USB ports, though it is possible to use a USB splitter I haven't\
    \ got far enough with it to see if this may turn out to be a problem. "
