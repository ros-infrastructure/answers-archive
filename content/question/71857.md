    \ message doesn't show up in rosconsole or the terminal where you started the\
    \ node, then your cb is not being executed. \n\nThere are a few possible reasons\
    \ that your callback would not be executed... but I'm going to guess at a couple\
    \ likely reasons since you don't run into any build errors. I'm guessing that\
    \ this is a callback for a subscribed topic. The callback for a subscribed topic\
    \ is *only executed when new data is published* to the topic you've subscribed\
    \ to. \n\nThis suggests  that **A)** no data is being published to the topic you\
    \ are subscribed to, or **B)** you are subscribed to a topic that doesn't exist\n\
