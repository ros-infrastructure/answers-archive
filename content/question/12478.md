    \ source`. <s>No `deb-src` needed.</s> I documented it [here](http://wiki.ros.org/hydro/Installation/Ubuntu#groovy.2BAC8-Installation.2BAC8-PostInstall.Obtain_source_code_of_the_installed_packages).\n\
    \nUpdate 12/10/2014) `deb-src` seems to be required. I updated the link above\
    \ too.\n\n**Edit with full instructions:** \n\nYou just need to explicitly specify\
    \ deb-src entry in the apt sources:\n\nFor example update `/etc/apt/sources.list.d/ros_latest.list`\
    \ as follows:\n\n      deb http://packages.ros.org/ros/ubuntu precise main\n \
    \   + deb-src http://packages.ros.org/ros/ubuntu precise main\n\nThis assumes\
    \ precise substitute your applicable ubuntu distro. \n\n    $ apt-get source ros-hydro-laser-pipeline\n\
    \nThis downloads from the server all the files in the released version of the\
    \ package (i.e. things not installed in the installation rule (e.g. CMakeLists.txt)\
    \ are also included).\n"
