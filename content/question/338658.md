    If the plan fails, the `RobotTrajectory` is empty, so you can check it as described [here](https://answers.ros.org/question/304494/can-planning-success-be-checked-in-the-python-movegroupcommander/):

        plan = move_group.plan()
        if plan.joint_trajectory.points:  # True if trajectory contains points
          move_success = move_group.execute(plan)
        else:
          rospy.logerr("Trajectory is empty. Planning was unsuccessful.")
