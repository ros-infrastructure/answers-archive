    Assuming you're using a WorldPlugin, you can use the [World::InsertModelSDF](http://gazebosim.org/api/dev/classgazebo_1_1physics_1_1World.html#a7bce0d07b0753ef9a3515e3b05b7a998) or [World::InsertModelString](http://gazebosim.org/api/dev/classgazebo_1_1physics_1_1World.html#ad9d9829d116ad1d85d88cd0cd4fe7863) API's (see [example code](https://bitbucket.org/osrf/gazebo/src/d0b7914b286030a3901ba3204b390f93e6b23dc7/examples/plugins/factory/factory.cc?at=gazebo_2.2#cl-31) from [updated tutorial](http://gazebosim.org/wiki/Tutorials/2.2/plugins/Factory)). You can specify the model name as an attribute in the passed SDF object or SDF string. I'm updating the example to show how to do this ([pull request #957](https://bitbucket.org/osrf/gazebo/pull-request/957/fix-whitespace-in-factorycc-add-example/diff)).

    I don't think it's currently possible to specify a custom model name when spawning via a filename with a factory message, though it can be done when passing custom sdf strings (see numerous spawning functions in the [ServerFixture class](https://bitbucket.org/osrf/gazebo/src/b1dea9012cb37b5afc2336fce5d9f30e7cbc475f/test/ServerFixture.cc?at=default#cl-1087)).
