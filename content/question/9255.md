  body_markdown: "Ah\nI finally got my install working!\n\nTurns out I had the same\
    \ problem as this person:\nhttp://answers.ros.org/question/107/missing-dependency-roscpp\n\
    \nI am green with Linux so it took me a while as I was missing some of the basics.\
    \ I will do my best to explain what I did so others have a chance at fixing it.\n\
    \nSomeone above mentioned .bashrc, but I didn't even know what it is. Well, its\
    \ in your user folder (/home/taylor in my case) but it is hidden. So open up Nautilus\
    \ (the file browser), navigate to your user folder, and press Ctrl-h to toggle\
    \ hidden files if you don't see .bashrc. bashrc runs when you open up a new terminal\
    \ (I think) and it sets up the environment variables for the terminal session.\
    \ Anything put in there gets run.\n\nWell, the ROS installation wiki says to add\
    \ \"source /opt/ros/diamondback/setup.bash\" to the end of your .bashrc file.\
    \ So, /opt/ros/diamondback/setup.bash is a script that gets run when your terminal\
    \ opens. It runs a file in that same folder called setup.sh, which sets the ROS\
    \ environment variables.\n\nYou can't just set environment variables in your .bashrc\
    \ file because it will just overwrite some of the stuff that the setup.sh file\
    \ does. So, navigate to /opt/ros/diamondback/ and open setup.sh for editing. Unfortunately,\
    \ its set as read only for the user. I'm sure this isn't the right way, but I\
    \ fixed that by opening a Nautilus browser window as root, by typing \n\n    sudo\
    \ Nautilus\n\nin a terminal.\n\nWith a root Nautilus window, navigate back to\
    \ /opt/ros/diamondback/ and edit setup.sh to add the new folders that contain\
    \ the packages you want to use.\n\nSpecifically, there should be a line:\n\n \
    \   export ROS_PACKAGE_PATH=/opt/ros/diamondback/stacks\n\n \nadd your user folder\
    \ to that line like so (where you replace my name with your user name!)\n\n  \
    \  export ROS_PACKAGE_PATH=/opt/ros/diamondback/stacks:/home/taylor\n\nI also\
    \ saw another folder mentioned and decided to add it just to be safe, so my whole\
    \ line read like this:\n\n    export ROS_PACKAGE_PATH=/opt/ros/diamondback/stacks:/home/taylor:/home/user/ros/ros-pkg\n\
    \nNow close all your terminal windows and run\n\n    rosmake --rosdep-install\
    \ rgbdslam\n\nIt should find all your packages and build properly! It did for\
    \ me and I finally have it running. :) If there are any problems, run \n\n   \
    \ sudo apt-get update\n\nTo update your packages and try again.\n"
