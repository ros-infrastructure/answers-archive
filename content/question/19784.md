  body_markdown: "As far as I know, in ubuntu16.04. If you install ```ros-kinetic-desktop-full```,\
    \ gazebo7 will be installed too, which is not compatible with gazebo8 or gazebo9.\
    \ So it is better to install ```ros-kinetic-desktop``` first,then install gazebo\
    \ from source\nas follow\n\n    sudo sh -c 'echo \"deb http://packages.ros.org/ros/ubuntu\
    \ $(lsb_release -sc) main\" > /etc/apt/sources.list.d/ros-latest.list'\n    sudo\
    \ apt-key adv --keyserver hkp://ha.pool.sks-keyservers.net:80 --recv-key 421C365BD9FF1F717815A3895523BAEEB01FA116\n\
    \    sudo apt-get update\n    sudo apt-get install ros-kinetic-desktop\n    sudo\
    \ rosdep init\n    rosdep update\n    echo \"source /opt/ros/kinetic/setup.bash\"\
    \ >> ~/.bashrc\n    source ~/.bashrc\n    sudo apt-get install python-rosinstall\
    \ python-rosinstall-generator python-wstool build-essential\n    \n    \n    sudo\
    \ sh -c 'echo \"deb http://packages.osrfoundation.org/gazebo/ubuntu-stable `lsb_release\
    \ -cs` main\" > /etc/apt/sources.list.d/gazebo-stable.list'\n    wget http://packages.osrfoundation.org/gazebo.key\
    \ -O - | sudo apt-key add -\n    sudo apt-get update\n    wget https://bitbucket.org/osrf/release-tools/raw/default/jenkins-scripts/lib/dependencies_archive.sh\
    \ -O /tmp/dependencies.sh\n    ROS_DISTRO=kinetic . /tmp/dependencies.sh\n   \
    \ cd ~/Downloads/gazebo-8.0.0\n    mkdir build\n    cd build\n    cmake ../\n\
    \    make -j4\n    sudo make install\n    echo \"export LD_LIBRARY_PATH=/usr/local/lib:$LD_LIBRARY_PATH\"\
    \ >> ~/.bashrc\n    echo \"export PATH=/usr/local/bin:$PATH\" >> ~/.bashrc\n \
    \   echo \"export PKG_CONFIG_PATH=/usr/local/lib/pkgconfig:$PKG_CONFIG_PATH\"\
    \ >> ~/.bashrc\n    source ~/.bashrc\n    sudo apt-get install python-catkin-pkg\
    \ python-catkin-tools\n    \n    sudo apt-get install ros-kinetic-gazebo8-msgs\n\
    \    sudo apt-get install ros-kinetic-gazebo8-ros-control\n    sudo apt-get install\
    \ ros-kinetic-gazebo8-plugins\n    sudo apt-get install ros-kinetic-gazebo8-ros-pkgs\n\
    \    sudo apt-get install ros-kinetic-gazebo8-ros \n    \n    sudo apt-get install\
    \ ros-kinetic-ros-control\n    sudo apt-get install ros-kinetic-ros-controllers\n\
    \    sudo apt-get install ros-kinetic-controller-manager\n    sudo apt-get install\
    \ ros-kinetic-trac-ik\n    sudo apt-get install ros-kinetic-trac-ik-kinematics-plugin\n\
    \nThis work well for me."
