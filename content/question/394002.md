    \ tutorials!\n\nEdit 1(updated context):\nIn the case of a UR5 robot, you would\
    \ first need to look into the [UR robot driver](https://github.com/UniversalRobots/Universal_Robots_ROS_Driver)\
    \ as it is essential for using UR robots with ROS. \n\nFor using Python, you would\
    \ need to use `move_group = moveit_commander.MoveGroupCommander()` and with that\
    \ you would be able to plan in the joint space like so (copied from the tutorial):\
    \ \n\n`joint_goal = move_group.get_current_joint_values()`\n\n`joint_goal[0] =\
    \ 0 #[0] represents the joint of the robot, value is in radians`\n\n`move_group.go(joint_goal,\
    \ wait=True)`\n\nand in cartesian space like so (copied from the tutorial):\n\n\
    `waypoints = []`\n\n`wpose = move_group.get_current_pose().pose`\n\n`wpose.position.z\
    \ -= scale * 0.1  # First move up (z)`\n\n`wpose.position.y += scale * 0.2  #\
    \ and sideways (y)`\n\n`waypoints.append(copy.deepcopy(wpose))`\n\n`(plan, fraction)\
    \ = move_group.compute_cartesian_path(waypoints, 0.01, 0.0) # waypoints to follow\
    \  # eef_step # jump_threshold`\n\nAs for using gazebo for that, this is also\
    \ mentioned [here!](https://ros-planning.github.io/moveit_tutorials/doc/gazebo_simulation/gazebo_simulation.html)"
