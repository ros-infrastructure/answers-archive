    MoveIt uses [FCL](http://www.ros.org/wiki/fcl) for Collision Detection.  This library definitely supports returning the closest-point coordinates you're interested in.  See [fcl::distance()](http://ros.org/doc/fuerte/api/fcl/html/namespacefcl.html#ae384014e10430c6573a5aecaf1847793) and [fcl::DistanceResult](http://ros.org/doc/fuerte/api/fcl/html/structfcl_1_1DistanceResult.html).  I've used this library independently from MoveIt to retrieve closest-point pairs by scanning through different combinations of STL mesh data.  It works great, and is really fast!

    However, looking through the MoveIt code, I don't think you can get distance pairs "out of the box" with the current design.  You *can* get collision contact points  and a scalar value for the minimum distance between non-contacting parts, but not the closest-distance points you're looking for.

    See the MoveIt wiki for info on how to [Retrieve Contact Info](http://moveit.ros.org/wiki/Environment_Representation/C%2B%2B_API#Getting_Contact_Information).  That example checks for self-collisions, but a [similar call](http://moveit.ros.org/wiki/Environment_Representation/C%2B%2B_API#Full_Collision_Checking) is used for robot/world collision checks.  The result of this call is a [CollisionResult](http://moveit.ros.org/groovy/doxygen/structcollision__detection_1_1CollisionResult.html#a0c7af992e5bc7e62d81bc4ad6ccdb2a0), which contains a scalar `distance` field and a list of [Contact](http://moveit.ros.org/groovy/doxygen/structcollision__detection_1_1Contact.html) data that specifies collision points.  If we dig into the MoveIt collision detection code, we see that the FCL distance check is called [here](https://github.com/ros-planning/moveit_core/blob/hydro-devel/collision_detection_fcl/src/collision_common.cpp#L436) using a default [fcl::DistanceRequest](http://ros.org/doc/fuerte/api/fcl/html/structfcl_1_1DistanceRequest.html) object.  This default request does not include the nearest-point calculations (only the scalar distance).  And MoveIt only saves the closest distance value, as seen [here](https://github.com/ros-planning/moveit_core/blob/hydro-devel/collision_detection_fcl/src/collision_common.cpp#L445).

    So, it looks to me like you're going to need to call the FCL library directly to perform the distance checks you're looking for.  That being said, the MoveIt developers are fairly responsive, and may be able to add the functionality you're looking for.  Your best bet will be to send an email to the [MoveIt Developer's List](https://groups.google.com/forum/#!forum/moveit-users), as they follow that list closer than this website.
