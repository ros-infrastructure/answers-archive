    Figured it out.
    I have installed opencv 3.4.5 which has dependencies on some older versions of the libavcodec, libavformat, libswscale etc.. libraries - older than are available in the bionic repositories.

    Solution was to add the xenial repositories to my sources.list, apt update and then I could apt search for the missing libraries one by one and install the required older version.

      > Solution was to add the xenial repositories to my sources.list, apt update and then I could apt search for the missing libraries one by one and install the required older version.

      For future readers: this is not a solution, but at best a work-around.

      Mixing and matching libraries from different Ubuntu versions (or any OS really) is not a good idea, and can lead to all sorts of ABI compatibility problems which typically only manifest themselves in hard-to-diagnose `SEGFAULT`s and similar crashes.
