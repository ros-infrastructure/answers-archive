  body_markdown: "In the [publish/subscribe](http://wiki.ros.org/ROS/Tutorials/WritingPublisherSubscriber%28c%2B%2B%29)\
    \ example in the ROS tutorials, it shows about the simplest a subscriber can get\
    \ ([example](https://raw.githubusercontent.com/ros/ros_tutorials/kinetic-devel/roscpp_tutorials/listener/listener.cpp)).\n\
    \nThere are two things required for a subscription, that is the callback function,\
    \ and the subscriber handle. You can simply duplicate these as many times as you\
    \ need. A modified example could be:\n\n    #include \"ros/ros.h\"\n    #include\
    \ \"std_msgs/String.h\"\n    #include \"std_msgs/Int16.h\"\n\n\n    void fooCallback(const\
    \ std_msgs::String::ConstPtr& msg)\n    {\n      // process the string\n    }\n\
    \n    void barCallback(const std_msgs::Int16 msg)\n    {\n      // process the\
    \ int\n    }\n    \n    int main(int argc, char **argv)\n    {\n      ros::init(argc,\
    \ argv, \"listener\");\n      ros::NodeHandle n;\n    \n      ros::Subscriber\
    \ sub1 = n.subscribe(\"foo\", 1000, fooCallback);\n      ros::Subscriber sub2\
    \ = n.subscribe(\"bar\", 1000, barCallback);\n\n      ros::spin();\n    \n   \
    \   return 0;\n    }\n\nI haven't tested this, so you probably can't just copy\
    \ and run it."
