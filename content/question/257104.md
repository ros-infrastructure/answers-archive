    The [ROS install instructions](http://wiki.ros.org/kinetic/Installation/Ubuntu) specifically state that only Ubuntu 15.10 and 16.04 are supported; you cannot install ROS through apt on 16.10.

    I recommend that you switch to Ubuntu 16.04 (it's their long-term stable release anyway) or [install from source](http://wiki.ros.org/kinetic/Installation/Source).
