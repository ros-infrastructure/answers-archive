    Two ways:

    1. Implement the [rosserial](http://ros.org/wiki/rosserial) protocol on the PIC and use rosserial client to communicate with ROS. More generic and more work (you can probably reuse some code from rosserial_arduino).
    2. Implement your own simple protocol and write a client nodes that maps this to ROS. Limited to what you implement, but quick to do.
