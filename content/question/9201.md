  body_markdown: "ROS packages may have two kinds of dependencies: (1) system dependencies,\
    \ and (2) other ROS packages. The `rosdep` command is for system dependencies.\n\
    \nWhen you need a ROS package that is not currently available on your system:\n\
    \n * See what stack contains the package you need: \n  * Stacks are the basic\
    \ unit of release and installation in ROS. Installing individual packages often\
    \ works, but I do not recommend it.\n  * For this example, find [pr2_2dnav_gazebo](http://ros.org/wiki/pr2_2dnav_gazebo)\
    \ in the ROS wiki.\n  * The containing stack is [wg_robots_gazebo](http://www.ros.org/wiki/wg_robots_gazebo).\n\
    \n * Check whether that stack has a released binary package for your system (if\
    \ it's a supported Ubuntu distribution).\n\n * If so, `apt-get` the corresponding\
    \ Debian package name:\n\n    `$ sudo apt-get install ros-diamondback-wg-robots-gazebo`\n\
    \n * If not, download the stack from its source repository:\n  * The source URI\
    \ is listed on [the stack wiki page](http://www.ros.org/wiki/wg_robots_gazebo),\
    \ for this example `https://code.ros.org/svn/wg-ros-pkg/stacks/wg_robots_gazebo/trunk`.\n\
    \  * Use rosinstall like [the example here](http://answers.ros.org/question/165/for-new-package-downloading)\
    \ to add that stack to your ROS tree.\n  * Compile the new package and its dependencies:\n\
    \n    `$ rosmake pr2_2dnav_gazebo --rosdep-install`"
