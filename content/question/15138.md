    I have been running into this problem too, getting the exact same error. Interestingly enough, the problem magically goes away when I set the "verbose" argument to true in the .launch files.

        roslaunch gazebo_ros empty_world.launch                 # gzserver crashes immediately
        roslaunch gazebo_ros empty_world.launch verbose:=true   # works!!

    The other  .launch files in the gazebo_ros package aren't setup to take arguments and pass them on to empty_world.launch (which gets included in all the other .launch files), so I had to go in add one line to each file to sets the verbose argument to true. Once I did that, it worked. Not exactly a fix, but hopefully points someone more familiar with the software to a root cause somewhere.
