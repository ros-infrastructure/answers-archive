    The trimesh collision shapes currently use a different collision detection algorithm than the simple shapes (box, sphere, cylinder), which tends to cause different contact behavior. If you are able to build the latest version of gazebo from source (default branch), then you can try creating some objects with the collide\_without\_contact flag set and `View Contacts` enabled. The will allow you to see the location of contact points computed by the collision detection algorithm without generating contact forces. Here's an [example world that has objects with the collide\_without\_contact flag](https://bitbucket.org/osrf/gazebo/src/585c79e15341/test/worlds/collide_without_contact.world?at=default). For observing the contact points, you may want to turn off gravity and `View Transparent`.
