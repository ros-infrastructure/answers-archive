  body_markdown: "Got it. The mesh is located under:\n\n    /opt/ros/kinetic/share/rviz/ogre_media/models/rviz_sphere.mesh\
    \ \nor your cloned repository under the models folder and it is loaded from [shape.cpp](https://github.com/ros-visualization/rviz/blob/kinetic-devel/src/rviz/ogre_helpers/mesh_shape.cpp)\
    \ (github link)\n\nThe only issue is to create a new mesh, which can actually\
    \ be done using Blender and some tools. I used:\n\n - blender-2.79a-linux-glibc219-x86_64\
    \ ; from blender, I've created the new sphere (just press the Create tab and then\
    \ Sphere, then click F6 to change the number of \"faces\".  Then Export > Ogre3D\
    \ (activate the add-on following the instructions of blender2ogre). Save the sphereHD.mesh.xml\n\
    \ - blender2ogre [blender2ogre](https://github.com/OGRECave/blender2ogre) (follow\
    \ install instructions from the readme)\n - [OgreXmlConverter](http://wiki.ogre3d.org/OgreXmlConverter)\
    \ only for windows :-( Use it to convert the sphereHD.mesh.xml to something that\
    \ Ogre is able to use. Then \"change the filename under shape.cpp and compile\
    \ RVIZ again\". Ok it's not the best solution I know, but that's a start :-)\n\
