  body_markdown: "Hi! \n\nHere is a little trick that I used (if anyone knows a \"\
    cleaner\" way to do this, please let us know):\n\n1- Create a symbolic link to\
    \ */opt/ros/fuerte/lib/pkgconfig/opencv.pc* inside the directory */user/local/lib/pkgconfig*.\n\
    \n\n    cd /usr/local/lib/pkgconfig\n    ln -s /opt/ros/fuerte/lib/pkgconfig/opencv.pc\
    \ opencv.pc\n\n2- Create the appropriate .pro file for your Qt project\n\n\n \
    \   TARGET= MyQtProject\n    TEMPLATE = APP\n\n    SOURCES += main.cpp\n    \n\
    \    CONFIG += link_pkgconfig\n    PKGCONFIG += opencv\n\nIf the file */usr/local/lib/pkgconfig/opencv.pc*\
    \ already exists you can copy ROS's file with another name, for instance: */usr/local/lib/pkgconfig/opencv_fuerte.pc*\
    \ and then use *PKGCONFIG += opencv_fuerte*\n   "
