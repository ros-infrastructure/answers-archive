  body_markdown: "You must remap the mytele_keyboard/cmd_vel topic to the cmd_vel_mux/input/teleop,\
    \ same way keyboard_teleop.launch does. Change your launch file to something like:\n\
    \n    <launch>\n      <node pkg=\u201Cmytele\u201D type=\u201Cmytele_keyboard\u201D\
    \ name=\u201Cmytele_keyboard\u201D output=\u201Cscreen\u201D>\n        <remap\
    \ from=\"mytele_keyboard/cmd_vel\" to=\"cmd_vel_mux/input/teleop\"/>\n      </node>\n\
    \    </launch>\n\nIf it doesn't work, your teleop cmd_vel topic name must be something\
    \ different, so type\n\n    rostopic list -v | grep Twist\n\nto list all velocity\
    \ command topics and change the remap accordingly."
