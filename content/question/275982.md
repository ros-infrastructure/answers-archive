  body_markdown: "Basically, remap is a feature to rename topics, node names and some\
    \ special keys of ROS env. You can see in this [page](http://wiki.ros.org/Remapping%20Arguments)\
    \ what you can remap, like  a node name (__node), namespace (__ns), log file (__log),\
    \ etc.\n\nExample:\nI've a node that publishes Twist messages in a topic called\
    \ `turtlebot_vel`, but my robot listens to `cmd_vel`\n\nYou can remap using `rosrun`\
    \ command, like this: \n\n    rosrun my_pkg my_node.py turtlebot_vel:=cmd_vel\n\
    \nOr inside a launch file ([ref](http://wiki.ros.org/roslaunch/XML/remap)):\n\n\
    \    <launch>\n        <node pkg=\"my_pkg\" type=\"my_node.py\" name=\"my_node\"\
    >\n            <remap from=\"turtlebot_vel\" to=\"cmd_vel\"/>\n        </node>\n\
    \    </launch>\n\n"
