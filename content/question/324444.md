    > why cannot i run this code..?

    The code probably runs just fine, but to handle incoming messages (ie: process event queues), `rosserial` needs you to call `nh.spinOnce()` periodically.

    You're not doing that.

    You'll want to:

     1. call `nh.spinOnce()` in `loop()`, and
     1. add a `delay(..)` in there to control how often `loop()` is called

    Refer to the [Hello World](http://wiki.ros.org/rosserial_arduino/Tutorials/Hello%20World) tutorial on the [rosserial_arduino/Tutorials](http://wiki.ros.org/rosserial_arduino/Tutorials) page.
