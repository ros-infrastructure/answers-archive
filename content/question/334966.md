  body_markdown: "The solution which worked for me without building all  ROS PCL interfacing\
    \ packages from source is : \n\n 1. locate the `PCLConfig.cmake` of the appropriate\
    \ version (in my case version `1.8.1` which is the latest version supported by\
    \ ros-melodic) by typing in a terminal : `locate PCLConfig.cmake`\n 2.  help cmake\
    \ find this `PCLConfig.cmake` by adding this line in `CMakeLists.txt` :\n    \
    \  \n    set(PCL_DIR \"/path/to/PCLConfig.cmake/\")\n    \nbefore this one:\n\n\
    \    find_package(PCL 1.8 REQUIRED)\n\n 3.  delete devel and build folders and\
    \ rebuild"

    Ok. That is most likely why you get those `SEGFAULT`s.

    Because of ABI problems you cannot just link nodes against PCL `1.9.1`. You'll most likely have to build all ROS PCL interfacing packages from source. I've written something about that in #q289264.

    Note that this is not a ROS problem, but something you always need to keep in mind when reusing binary artefacts (such as libraries): if there is no ABI compatibility guarantee, you cannot (re)link different versions into the same binary.
