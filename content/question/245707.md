  body_markdown: "With help from a colleague:\n\nWhen a xacro property is read from\
    \ a yaml file, it is in a dictionary format. \n\nWhen used for xacro calculations,\
    \ the parameter needs to be extracted from the dictionary:\n\n    <?xml version=\"\
    1.0\"?>\n    <robot name=\"robot_name\" xmlns:xacro=\"http://ros.org/wiki/xacro\"\
    >\n      <xacro:property name=\"a\" value=\"${load_yaml('robot_parameters.yaml')}\"\
    \ />\n    \n      <link name=\"left_front_wheel_link\">\n        <visual>\n  \
    \        <origin xyz=\"0.123 0.456 0.101\" rpy=\"${a['PI']/2} 0 0\" />\n     \
    \     <geometry>\n            <cylinder radius=\"0.101\" length = \"0.0254\"/>\n\
    \          </geometry>\n        </visual>\n      </link>\n    </robot>"

Environment: Ubuntu 16, ROS Kinetic.

I have a robot_parameters.yaml file with robot parameters:
wheel_separation : 0.235
PI : 3.142


In a xacro file I have:

    <?xml version="1.0"?>
    <robot name="robot_name" xmlns:xacro="http://ros.org/wiki/xacro">
      <xacro:property name="PI" value="${load_yaml('robot_parameters.yaml')}" />
   
      <link name="left_front_wheel_link">
        <visual>
          <origin xyz="0.123 0.456 0.101" rpy="${PI/2} 0 0" />
          <geometry>
            <cylinder radius="0.101" length = "0.0254"/>
          </geometry>
        </visual>
      </link>
    </robot>


When I do a --check-order on the xacro, I get the following error:

    unsupported operand type(s) for /: 'dict' and 'int' 
    when evaluating expression 'PI/2'
    XacroException(None,)


How would I use an imported name(in this case, PI) via yaml and use it for xacro calculations.
