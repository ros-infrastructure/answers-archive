    \ built for Groovy. You can build them from source; for example `openni_camera`\
    \ clone its source repository in your catkin workspace, and build:\n\n    cd %YOUR_CATKINWS%/src\n\
    \    git clone https://github.com/ros-drivers/openni_camera.git && cd %YOUR_CATKINWS%\n\
    \    catkin_make\n\nBut better answer would be to use [ROSberryPi for Indigo](http://wiki.ros.org/ROSberryPi/Installing%20ROS%20Indigo%20on%20Raspberry%20Pi)\
    \ where better support can be expected for longer term, unless you have a reason\
    \ to stick to 2 generations older distro. "
