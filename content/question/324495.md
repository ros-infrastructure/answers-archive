    \ \n\ncorrect.\n\n> but what is `rcl_interfaces/ParameterEvent`? \n\nIt is the\
    \ *type* of the topic. So the message type published to it -- and conversely:\
    \ the message type a subscriber expects to receive on the topic.\n\n> I thought\
    \ it was a node that was publishing to `/parameter_events`, but it doesn't show\

    \ `rcl_interfaces/ParameterEvent` *is* actually a file a package called `rcl_interfaces`.\

    \ The exact file is: [ros2/rcl_interfaces/rcl_interfaces/msg/ParameterEvent.msg](https://github.com/ros2/rcl_interfaces/blob/bfa9c43dd7d8cfc5c6fcba8a164d8ef317a386d7/rcl_interfaces/msg/ParameterEvent.msg).\n\
