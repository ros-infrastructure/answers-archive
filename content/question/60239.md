    \nYou can implement the callback function however you like\n\n    void AutoExp::processLaserScan(const\
    \ sensor_msgs::LaserScan::ConstPtr& scan){\n         //scan->ranges[] are laser\
    \ readings\n         ...\n    }\n\nWhenever a new laser reading is published to\
    \ the \"/scan\" topic, your callback function is called, assuming that nothing\
    \ goes wrong.\n\nYou can always use commands like\n\n    rostopic info /scan\n\
    \    rosmsg show sensor_msgs/LaserScan\n\nto have a detailed information about\
    \ the topic and the message type. \n\nIf you read the documentation of the message\
