  body_markdown: "If you're in a nodelet use the multi threaded nodelet interface.\
    \  \nIf you're not use the Asynchronous spinner.  \n\nThe nodelet interface will\
    \ only work if you're inside a nodelet manager as a nodelet.  \n\nYou can add\
    \ your own threads on top of the callback threads in either case. If you do you\
    \ are in charge of cleaning up correctly.  \n\nFor portability Boost Thread is\
    \ recommended over pthreads.  \n\nIn most cases there will be no performance difference,\
    \ unless you are doing something very exotic.  And if you're doing that very exotic\
    \ thing you will know the performance differences.  The most common case is running\
    \ a single threaded process. \n\n"
