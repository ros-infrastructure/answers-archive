    According to [the wiki](http://wiki.ros.org/urg_node) it is supported from Groovy through Kinetic. To install [the source](https://github.com/ros-drivers/urg_node/tree/groovy-devel), you can clone the repo, checkout the `groovy-devel` branch and then compile it. I don't believe that you can use `apt` to install as this is quite old (the most recent commit for the `groovy-devel` branch was 5 years ago).
