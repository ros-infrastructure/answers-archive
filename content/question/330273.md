  body_markdown: "@jdlangs is correct that `shared_from_this()` is the correct way\
    \ to get a shared pointer to the node.\n\nBesides the compilation issue, your\
    \ code looks troublesome. `rclcpp::spin()` is a blocking function, so `this->loop()`\
    \ will only be called once. You could try using `rclcpp::spin_some()` instead,\
    \ but I suggest that you call `rclcpp::spin()` from outside your node, for example\
    \ in a `main` function like this:\n\n    int main(int argc, char ** argv)\n  \
    \  {\n      rclcpp::init(argc, argv);\n    \n      auto odom_node = std::make_shared<OdomNode>();\n\
    \      rclcpp::spin(odom_node);\n    \n      rclcpp::shutdown();\n      return\
    \ 0;\n    }\n\nAnd perhaps start a timer to replace your update method, for example\
    \ in the constructor:\n\n    OdomNode::OdomNode(rclcpp::Duration & loop_rate)\n\
    \    {\n      timer_ = this->create_wall_timer(loop_rate.to_chrono(), std::bind(&OdomNode::loop,\
    \ this));\n    }\n\nThis is the pattern you'll find in many of the [examples](https://github.com/ros2/examples/tree/master/rclcpp)\
    \ and [demos](https://github.com/ros2/demos).\nThis helps make your node more\
    \ flexible. For example, it leaves open the possibility to compose your node with\
    \ others into a single process, or easily change the type of executor or callback\
    \ group."
