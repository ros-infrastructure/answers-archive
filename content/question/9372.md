    Gazebo documentation is available as part of the player-stage project.  The specific main page is located here: [http://playerstage.sourceforge.net/doc/Gazebo-manual-svn-html/](http://playerstage.sourceforge.net/doc/Gazebo-manual-svn-html/).

    The documentation for the ROS side of things is, of course, located on the [ROS wiki](http://www.ros.org/wiki/gazebo).

    If you'd like a copy local, I'm not a wget genius, so someone please correct me if this is wrong, but I think you run `wget -r -p http://playerstage.sourceforge.net/doc/Gazebo-manual-svn-html/` and it should download all the needed files for the documentation...

    See the [wget documentation](http://www.gnu.org/software/wget/manual/wget.html) for better help.
