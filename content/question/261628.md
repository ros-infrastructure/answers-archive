  body_markdown: "In order to establish a connection of the Laserscanner SICK LMS111\
    \ to ROS Kinetic several steps have to be performed. \n\n1.Supply the Sensor and\
    \ connect it to the ethernet port a system running Windows.\n2. Install SICK SOPAS\
    \ Engineering tool and execute it. \n3. Configure the Paramters in the SICK Software\
    \ SOPAS. That means define a ethernet ip adress and adjust measuring parameters.\n\
    4.Install the sick toolbox wrapper:\n\n>  $ sudo apt-get install\n> ros-kinetic-lms1xx\n\
    \n5. In Ubuntu under Settings configure the wired connection to be different than\
    \ the IP of the laserscanner. The IP of the laserscanner can be obtained by \n\
    \n>$ sudo ifconfig\n\n6. Make sure that the connection between ubuntu and the\
    \ LMS is established in Ubuntu (You can see this in the Network Settings).\n\n\
    > $ roscore\n\n8. In order to establish a connection to ROS use a new terminal\
    \ and enter \n\n>$ rosrun lms1xx LMS1xx\\_node \\_\n> host:=[IP of the scanner\
    \ obtained from\n> sudo ifconfig]\n\n has to be used.\n\n9.When using rviz: the\
    \ fixed frame in global options has to be set to laser and a LaserScan display\
    \ has to be added with the topic /scan enabled."
