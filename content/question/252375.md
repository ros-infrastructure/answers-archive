  body_markdown: "I have encountered the exact same problem today and the solution\
    \ was not a straightforward one. Unfortunately XmlRpc API does not have a dedicated\
    \ method for the custom structs. Therefore, you need to write your own function\
    \ that validly constructs an XML from your struct. \n\nFollowing code constructs\
    \ a valid portion of your yaml file which affects the parameter server in the\
    \ exact same manner as yaml file would.\n\n    const string init_value = \"<value>\"\
    ;\n    const string end_value = \"</value>\";\n    const string init_struct =\
    \ \"<struct>\";\n    const string end_struct = \"</struct>\";\n\nThere are also\
    \ `<data>`, `<array>` and `<member>` tags. They should be defined as above. Then\
    \ for only the `mode` part: \n\n\n    XmlRpc::XmlRpcValue drive_config;\n    string\
    \ xml_body;\n    xml_body.append(init_value);\n    xml_body.append(init_struct);\n\
    \    xml_body.append(init_member);\n    xml_body.append(\"<name>mode</name>\"\
    );\n    xml_body.append(init_value);\n    xml_body.append(\"mecanum\");\n    xml_body.append(end_value);\n\
    \    xml_body.append(end_member);\n    xml_body.append(end_struct);\n    xml_body.append(end_value);\n\
    \n    int offset = 0;\n    int* offset_ptr = &offset;\n    drive_config.fromXml(xml_body,offset_ptr);\n\
    \    nh.setParam(\"/drive_config\",drive_config);\n\n \nAbove lines will upload\
    \ a parameter to ROS Parameter Server in the form of:\n\n    drive_config:\n \
    \       mode: mecanum\n\nAbove code can be optimized, automated and shortened\
    \ with struct tag retrievals, type resolvers and recursive calls. But for the\
    \ current task, na\xEFve implementation would suffice.\n\nI recommend first printing\
    \ the raw XML format of a known parameter uploaded through YAML file. Then, it\
    \ will be easier to construct arrays of arrays, arrays of dicts, dicts of arrays\
    \ and etc. "

    I found a way:

        XmlRpc::XmlRpcValue a;
        a.setSize(2);
        a[0] = 0;
        a[1] = 1;
        ros::param::set("param_name", a);

    Just keep nesting this and you can set any parameter structure you want.
