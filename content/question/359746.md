 As a preface, I am using ROS melodic with Ubuntu 18.04 on a Jetson Nano. I have no problems with Ros_lib, I can upload any of the examples to my Arduino Uno, launch roscore, and then successfully connect using the following command: rosrun rosserial_python serial_node.py /dev/ttyACM0

It automatically connects at 57600 baud and within 1-3 seconds sets up the publishers/subscribers successfully. The problem is, if I initialize the TLE9879 within my code and upload it, such that the shield's light is on, when I try using the rosrun command it gets stuck at "Requesting topics..." and after about every 15 seconds prints "Unable to sync with device; possible link problem or link software version mismatch such as hydro rosserial_python with groovy Arduino."

My intuition leads me to believe that somehow the TLE9879 is either hogging the serial connection or changing its baud rate? I've begun diving into their library to see if I can find anything useful to help.
