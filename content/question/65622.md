  body_markdown: "I've solved this issue with @theblackpearl over email; here's a\
    \ summary of the solution:\n\n* The mystery scanner in question is actually the\
    \ new TiM 510 (which is not sold yet), even though it was labeled as a TiM 310.\n\
    * It provides 91 measurements per scan over a 270\xB0 scan angle, instead of 271\
    \ (like the TiM 310 does). Also, it doesn't provide intensities. This is why each\
    \ datagram is only 124 instead of 580 bytes.\n* The specs for the datagram format\
    \ are yet to be released; I've written a [quick hack](https://github.com/uos/sick_tim3xx/tree/sick_tim510)\
    \ to make the scanner work until proper support can be added to the `sick_tim3xx`\
    \ package.\n\n**Edit 04/2022:** Apparently, I removed the \"quick hack\" branch\
    \ in 2013. If anybody is still looking for this, the contents of the branch were\
    \ merged in the main branches as the `sick_tim310_1130000m01` node."
