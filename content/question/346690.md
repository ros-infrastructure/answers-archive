  body_markdown: "I found the solution to the problem. \n\nI was wrongly not creating\
    \ a new message before each publishing.\n\nIn my particular case I had an IMU\
    \ message to be synchronized with camera images and I was creating the message\
    \ once in the `OnInit` function.\nInstead we must create each single shared pointer\
    \ message just before publishing it: `sensor_msgs::ImuPtr imuMsg(new sensor_msgs::Imu);`"
