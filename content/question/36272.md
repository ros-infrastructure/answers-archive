  body_markdown: "Not sure there is a package. I implemented a version of what you\
    \ describe myself though using the 'RangeImagePlanar' point cloud type, as that\
    \ preserves the locality information (x,y) of points and you only have to iterate\
    \ over the image once this way. Don't have the code in a public repo, but here\
    \ are the relevant bits (cobbled together, to give an idea on how one could do\
    \ it quickly):\n\nWe fill a range image for every depth image coming from a RGB-D\
    \ camera (given as depth_image_msg):\n\n    \n        range_image_planar->setDepthImage(reinterpret_cast<const\
    \ float*> (&depth_image_msg->data[0]),\n                                     \
    \     depth_image_msg->width, depth_image_msg->height,\n                     \
    \                     camera_info_msg->P[2],  camera_info_msg->P[6],\n       \
    \                                   camera_info_msg->P[0],  camera_info_msg->P[5]);\n\
    \    \n        range_image_planar->header = depth_image_msg->header;\n\n\nIf we're\
    \ in calibration mode, we update our reference image as needed (if the new distance\
    \ value is closer or was invalid before we store that in the reference image):\n\
    \n      void calibrateReferenceImage(RangeImagePlanar* range_image_planar_in)\n\
    \      {\n        //if first image..\n        if(range_image_planar_reference\
    \ == 0){\n          range_image_planar_reference = new RangeImagePlanar();\n \
    \         *range_image_planar_reference = *range_image_planar_in;\n        }else{\n\
    \          if ( pointcloudsSameSize(*range_image_planar_reference, *range_image_planar_in)){\n\
    \    \n            int width_ref = range_image_planar_reference->width;\n    \
    \        int height_ref = range_image_planar_reference->height;\n    \n      \
    \      for (int x = 0; x < width_ref; ++x){\n              for (int y = 0; y <\
    \ height_ref; ++y){\n    \n                if ( range_image_planar_in->isValid(x,y)){\n\
    \                  const pcl::PointWithRange& tmpCurr ( range_image_planar_in->getPoint(x,y));\n\
    \    \n                  pcl::PointWithRange& tmpRef (range_image_planar_reference->getPoint(x,y)\
    \ );\n    \n                  if ( (tmpRef.range > tmpCurr.range) || (tmpRef.range\
    \ < 0.3)){\n                    tmpRef = tmpCurr;\n                  }\n     \
    \           }\n              }\n            }\n          }else{\n            ROS_INFO(\"\
    Reference and current cloud not same size! Not merging.\\n\");\n          }\n\
    \        }\n      }\n\nFor getting pointclouds of only the foreground we just\
    \ compare the distance values between the current and the reference image:\n\n\
    \    int width_ref = range_image_planar_reference->width;\n    int height_ref\
    \ = range_image_planar_reference->height;\n\n    pc_foreground_->clear();\n  \
    \  pc_foreground_->header = range_image_planar->header;\n\n    //get Pointcloud\
    \ with objects in foreground (into pc_foreground_)\n    for (int x = 0; x < width_ref;\
    \ ++x){\n      for (int y = 0; y < height_ref; ++y){\n\n        if ( range_image_planar->isValid(x,y)\
    \ && range_image_planar_reference->isValid(x,y)){\n          const pcl::PointWithRange&\
    \ tmpCurr ( range_image_planar->getPoint(x,y));\n\n          const pcl::PointWithRange&\
    \ tmpRef (range_image_planar_reference->getPoint(x,y) );\n\n          if ((tmpRef.range\
    \ - threshold) > tmpCurr.range){\n            pc_foreground_->push_back(tmpCurr);\n\
    \          }\n        }\n      }\n    }\n\nNot sure this is the \"best\" way,\
    \ but it works pretty well and is reasonably fast. It of course only works with\
    \ the special case of a fixed RGB-D camera and a static scene, apart from the\
    \ moving objects of interest that one is interested in."
