upvote_count: 0

CAD models of an environment are created using 3DSMax. 
3DSMax supports the following export file formats (Autodesk(*.fbx); 3D Studio (*.3ds); Alembic(*.abs); Adobe Illustrator (*.ai); AutoCAD (*.dwg); Autodesk Collada (*.dae); AutoCAD (*.dxf); PhysicsX and APEX(*.pxproj); StereoLitho(*.stl); VRML97(*.wrl)....)
