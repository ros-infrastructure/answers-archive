  body_markdown: "It seems a bit complicated but I managed to instantiate `urdf::Model`\
    \ by following the below steps:\n\n 1. **Get the value of `robot_description`\
    \ as string:** This requires extra effort. Remember, ROS 2 does not have a centralized\
    \ parameter server. So, getting a parameter from another node is tricky. You can\
    \ read more about the procedure at [this link](https://answers.ros.org/question/340600/how-to-get-ros2-parameter-hosted-by-another-node/?answer=342528#post-id-342528).\n\
    \ 2. **Use the string as input to build URDF model:** We can use `initString()`\
    \ method.\n\nCode\n-------\n\n    // license removed for brevity\n    \n    #include\
    \ <urdf/model.h>\n    \n    #include <chrono>\n    #include <memory>\n    #include\
    \ <rclcpp/rclcpp.hpp>\n    \n    using namespace std::chrono_literals;\n    \n\
    \    class MinimalPublisher : public rclcpp::Node\n    {\n    public:\n      MinimalPublisher()\
    \ : Node(\"minimal_publisher\")\n      {\n        parameters_client_ = std::make_shared<rclcpp::SyncParametersClient>(this,\
    \ \"/robot_state_publisher\");\n        while (!parameters_client_->wait_for_service(1s))\n\
    \        {\n          if (!rclcpp::ok())\n          {\n            RCLCPP_ERROR(this->get_logger(),\
    \ \"Interrupted while waiting for the service. Exiting.\");\n            rclcpp::shutdown();\n\
    \          }\n          RCLCPP_INFO(this->get_logger(), \"Service not available,\
    \ waiting again...\");\n        }\n    \n        std::string urdf_string;\n  \
    \      auto parameters = parameters_client_->get_parameters({ \"robot_description\"\
    \ });\n        for (auto& parameter : parameters)\n        {\n          if (parameter.get_name()\
    \ == \"robot_description\")\n          {\n            urdf_string = parameter.value_to_string();\n\
    \            break;\n          }\n        }\n    \n        urdf::Model urdfModel;\n\
    \        urdfModel.initString(urdf_string);\n        RCLCPP_INFO_STREAM(this->get_logger(),\
    \ \"Name:\" << urdfModel.getName());\n      }\n    \n    private:\n      std::shared_ptr<rclcpp::SyncParametersClient>\
    \ parameters_client_;\n    };\n    \n    int main(int argc, char* argv[])\n  \
    \  {\n      rclcpp::init(argc, argv);\n      rclcpp::spin(std::make_shared<MinimalPublisher>());\n\
    \      rclcpp::shutdown();\n      return 0;\n    }\n\nRun\n-----\n\n 1. First,\
    \ I published a URDF using [urdf_tutorial](https://docs.ros.org/en/foxy/Tutorials/Intermediate/URDF/Building-a-Visual-Robot-Model-with-URDF-from-Scratch.html).\
    \ Please see the command below:\n\n        ravi@dell:~$ ros2 launch urdf_tutorial\
    \ display.launch.py model:=/opt/ros/foxy/share/urdf_tutorial/urdf/06-flexible.urdf\n\
    \n 2. Next, I confirmed that the `robot_description` is available as shown below:\n\
    \n        ravi@dell:~$ ros2 param list\n        /joint_state_publisher:\n    \
    \      delta\n          publish_default_efforts\n          publish_default_positions\n\
    \          publish_default_velocities\n          rate\n          source_list\n\
    \          use_mimic_tags\n          use_sim_time\n          use_smallest_joint_limits\n\
    \        /robot_state_publisher:\n          frame_prefix\n          ignore_timestamp\n\
    \          publish_frequency\n          robot_description\n          use_sim_time\n\
    \          use_tf_static\n        /rviz2:\n          use_sim_time\n\n 3. Finally,\
    \ I executed my node which prints URDF model name\n\n        ravi@dell:~/ros2_ws$\
    \ ros2 run  examples_rclcpp_minimal_publisher publisher_member_function \n   \
    \     Parsing robot urdf xml string.\n        [INFO] [1666688084.856405837] [minimal_publisher]:\
    \ Name:visual\n\n 4. Just for sake of completeness, below is the robot name queried\
    \ from the terminal:\n\n        ravi@dell:~$ ros2 param get /robot_state_publisher\
    \ robot_description | grep robot\n        <robot name=\"visual\">\n        </robot>\n"
