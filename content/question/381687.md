  body_markdown: "> Seeing existing ROS packages, it seems there are some rules for\
    \ formatting package.xml.\n> \n> - There should be a new line between mandatory\
    \ and optional tags.\n> - There should be a new line when the `depend` type has\
    \ changed.\n\nYour question seems to be about *formatting* of the file contents.\n\
    \nThere are no real guidelines or requirements for that specifically -- or at\
    \ least, not that I'm aware of.\n\nAs it's XML, formatting doesn't matter, as\
    \ long as it's valid XML.\n\nAdding newlines and other formatting would only help\
    \ *humans*, and the manifest is mostly meant for machine consumption (hence the\
    \ use of XML).\n\nAnd I know you tagged this `ros2`, but just for reference:\n\
    \n> Also, is there any way to check the rule automatically?\n\nSome aspects of\
    \ a package manifest can be checked automatically, at least in ROS 1. [catkin_lint](https://fkie.github.io/catkin_lint)\
    \ is a tool which checks for consistency between a package's build script and\
    \ `package.xml` contents. It also checks compliance with (some parts of) the REP\
    \ you mention (and its previous versions).\n\n`catkin_lint` does not support ROS\
    \ 2 right now, so that won't help you directly, but I thought to mention it.\n\
    \n> I think `ament_xmllint` doesn't support it.\n\nIIRC, `ament_xmllint` only\
    \ checks whether the files passed are valid XML. It uses `xmllint`, which will\
    \ parse the XML and complain about any violations (against a schema for instance).\n\
    \nFile formatting (as long as it doesn't prevent parsing of the file) is not checked."

Seeing existing ROS packages, it seems there are some rules for formatting package.xml.

- There should be a new line between mandatory and optional tags.
- There should be a new line when the `depend` type has changed.

However, I couldn't find the rules in [REP 149](https://www.ros.org/reps/rep-0149.html). (I'm sorry if I overlooked them.)

Where are the rules written?
Although I can guess it from [package_format3.xsd](https://github.com/ros-infrastructure/rep/blob/master/xsd/package_format3.xsd), I want a more clear explanation.

Also, is there any way to check the rule automatically? I think `ament_xmllint` doesn't support it.
