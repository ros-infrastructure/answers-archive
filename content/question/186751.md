  body_markdown: "Hello m1ckey,\n   The thing is that the depth_image_proc isn't a\
    \ package of nodes but one of nodelets. You can find out that by reading the documentation:\
    \ http://wiki.ros.org/depth_image_proc?distro=indigo . To use them, I recommend\
    \ using a .launch file. You first need a nodelet manager, and then the nodelets\
    \ that you need, which are listed on the documentation with their required topic\
    \ inputs and outputs. As you'll see on the following code, you may remap the standard\
    \ topic names to the ones you're using on your program.\n\n   Here, check out\
    \ this example for using the nodelet that transforms a RGB Image and a Depth Image\
    \ into a Point Cloud2.\n\n----------\n\n    <!-- Convert the depth image and the\
    \ rgb image into a xyzrgb Point Cloud -->\n          <launch>\n\t<arg name=\"\
    ns\" value=\"/your_namespace\"/>\n\t<arg name=\"sdepth_subfolder\" value=\"$(arg\
    \ ns)/sd\"/>\n\t<arg name=\"srgb_subfolder\" value=\"$(arg ns)/srgb\"/>\n\t \n\
    \t<arg name=\"pc2_subfolder\" value=\"$(arg ns)/point_cloud2\"/>\n\t<arg name=\"\
    sd_on_rgb_frame\" value=\"$(arg ns)/sd_on_rgb_frame\"/>\t\n\t\n\t <!-- Nodelet\
    \ manager for this pipeline -->\n\t<node pkg=\"nodelet\" type=\"nodelet\" args=\"\
    manager\" name=\"depth_transforms_manager\" output=\"screen\"/>\n\n\t <!-- Convert\
    \ to point cloud -->\n\t<node pkg=\"nodelet\" type=\"nodelet\" name=\"cloudify\"\
    \n\targs=\"load depth_image_proc/point_cloud_xyzrgb depth_transforms_manager --no-bond\"\
    >\n\t\n\t\t<!-- Input: Camera calibration and metadata.  (sensor_msgs/CameraInfo)\
    \ -->\n\t\t<remap from=\"rgb/camera_info\" \t   to=\"$(arg srgb_subfolder)/camera_info\"\
    /> \n\t\t<!-- Input: Rectified color image. (sensor_msgs/Image) -->\n\t\t<remap\
    \ from=\"rgb/image_rect_color\" to=\"$(arg srgb_subfolder)/scene_rgb_cam_wf\"\
    /> \n\t\t<!-- Input: Rectified depth image, registered to the RGB camera. (sensor_msgs/Image)\
    \ -->\n\t\t<remap from=\"depth_registered/image_rect\" to=\"$(arg sd_on_rgb_frame)/image_wf\"\
    /> \t\t\n\t\t<!-- Output: XYZ point cloud. If using PCL, subscribe as PointCloud<PointXYZ>.\
    \  (sensor_msgs/PointCloud2)  -->\n\t\t<remap from=\"depth_registered/points\"\
    \ to=\"$(arg pc2_subfolder)/points\"/>\n\n\t</node>\n          </launch>\n\n----------\n"
