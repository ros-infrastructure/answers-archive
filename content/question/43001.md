  body_markdown: "If you don't use a forward slash, \"ros::param::get\" gets a parameter\
    \ from the node's namespace, but not its private namespace. If you put that parameter\
    \ tag inside of a <node> tag, it will be in this private namespace. \n\nFor example,\
    \ the following roslaunch xml:\n \n    <param name=\"camera_topic_root\" value=\"\
    /camera/image_rect\">\n    <group ns=\"group_ns\">\n        <param name=\"camera_topic_ns\"\
    \ value=\"/camera/image_rect\">\n        <node name=\"node_name\" pkg=\"foo\"\
    \ type=\"bar\" >\n            <param name=\"camera_topic_private\" value=\"/camera/image_rect\"\
    >\n        </node>\n    </group>\n\nWould set the parameters:\n\n    /camera_topic_root\n\
    \    /group_ns/camera_topic_ns\n    /group_ns/node_name/camera_topic_private\n\
    \nTo get these parameters with the ros::param::get API, you could do each of the\
    \ following:\n\n    ros::param::get(\"/camera_topic_root\",camera_topic);    //\
    \ /camera_topic_root\n    ros::param::get(\"camera_topic_ns\",camera_topic); \
    \      // /group_ns/camera_topic_ns\n    ros::param::get(\"~camera_topic_private\"\
    ,camera_topic); // /group_ns/node_name/camera_topic_private\n\nThis is documented\
    \ slightly less succinctly [here](http://www.ros.org/wiki/roscpp/Overview/Parameter%20Server#Accessing_Private_Parameters)."
