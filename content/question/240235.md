  body_markdown: "I believe you have a catkin workspace set up already. If not you\
    \ can follow [this](http://wiki.ros.org/catkin/Tutorials/create_a_workspace).\
    \ Once that is done, you can go to the github page for your package. In this case,\
    \ I believe you are looking for [common_msgs](https://github.com/ros/common_msgs).\n\
    \nOpen terminal and navigate to src folder in your catkin workspace:\n\n    cd\
    \ ~/catkin_ws/src\n\nThen clone the repository using:\n\n    git clone -b <branch>\
    \ <address> \n\nFor example, if you are looking to run it in `ros hydro`, your\
    \ command could look like:\n\n     git clone -b hydro-devel https://github.com/ros/common_msgs.git\
    \ \n\nOnce it is completed, do the following:\n\n    cd ~/catkin_ws \n    catkin_make\n\
    \n\n\n\n"
