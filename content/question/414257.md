    \ you can always accomplish any arbitrary thing you want manually. Not sure if\
    \ you're looking for encryption of entire messages or just output files, but\n\
    \n - For message encoding - for example create your own \"EncryptedMessage.msg\"\
    \ type, performing any operations you want to do, then writing these messages\
    \ into the bag \n - For file encryption, write the bag file as normal, then encrypt\
    \ the file with whatever tooling after it is closed"
