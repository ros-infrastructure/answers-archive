    So you wonna use sensor_msgs::PointCloud2 (not sensor_msgs::PointCloud as it is deprecated) if you are passing messages between nodes in ROS (e.g. between kinect driver node and your pointcloud processing node). Once your pointcloud node receives the sensor_msgs::PointCloud2 msg you use pcl::fromROSMsg function to convert it to pcl::PointCloud<PointT> (note that it has to be templated) and that can then be used as input to all pcl algorithms.
