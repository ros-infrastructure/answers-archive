  body_markdown: "I believe this is what [message_filters/Cache](http://wiki.ros.org/message_filters#Cache)\
    \ was created for:\n\n> Stores a time history of messages.\n> \n> Given a stream\
    \ of messages, the most recent N messages are cached in a ring buffer, from which\
    \ time intervals of the cache can then be retrieved by the client. The timestamp\
    \ of a message is determined from its header field. \n\nthe page then shows a\
    \ couple of examples on how to use it.\n\n> Is there a way to get also x(t-h),\
    \ where h is the time delay.\n\nI believe so:\n\n> In this example, the `Cache`\
    \ stores the last 100 messages received on `my_topic`, and `myCallback` is called\
    \ on the addition of every new message. The user can then make calls like `cache.getInterval(start,\
    \ end)` to extract part of the cache. \n\nThere is also an improved version of\
    \ `message_filters` (according to the authors) which may offer similar functionality:\
    \ [fkie/message_filters](https://github.com/fkie/message_filters)."
