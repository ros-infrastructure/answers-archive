    \ a rosnode in Qtcreator:\nhttp://answers.ros.org/question/34966/debugging-ros-package-with-qtcreator/?answer=34977#post-id-34977\n\
    \nI think that the answer can be summarized to:\n\n 1. compile the node/package\
    \ that you want to compile in debug mode (add \"`set(CMAKE_BUILD_TYPE Debug)`\"\
    \ to your CMakeLists.txt) \n 2. start your roscore and everything else as usual,\
    \ except for the node you want to debug\n 3. start qtcreator with \"sudo\" (remember\
    \ to source correctly your catkin workspace)\n 4. in qtcreator start the debugging\
    \ mode for the rosnode by going to \"Debug\"->\"Start Debugging\"->\"Attach to\
    \ unstarted Application...\", look for your compiled node, it should be in: `\"\
    ${CATKIN_WORKSPACE_FOLDER}\"/devel/lib/package_name/node_name`\n and click \"\
    Start Watching\".\n 6. start the node in a terminal either with rosrun or roslaunch\n\
    \ 7. enjoy...\n\nNote: you need to run qtcreator with \"sudo\", otherwise you\
    \ get a \"ptrace operation not allowed\" problem. \nNote2: if you try to run qtcreator\
    \ as a normal user afterwards, you will have problems accessing some of the Qt\
    \ configuration files of your home folder, run these commands to get this back\
    \ to normal:\n\n    sudo chown -R ${USER}:${USER} .qt\n    sudo chown -R ${USER}:${USER}\
    \ .config/\n\n"
