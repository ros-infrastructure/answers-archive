  body_markdown: "This is definitely achievable using the [rosserial package as described\
    \ here](http://wiki.ros.org/rosserial) along with the [tutorials here](http://wiki.ros.org/rosserial_arduino/Tutorials).\n\
    \nUsing rosserial a pseudo node runs on the arduino and is able to publish and\
    \ receive messages itself, however it needs a regular ROS node running on the\
    \ device it is directly connected to using a serial (or serial over USB) the [rosserial_python\
    \ node](http://wiki.ros.org/rosserial_python) is generally used for this.\n\n\
    Since ROS is a distributed network system it does not matter which device on the\
    \ network is running roscore as long as every device can connect to it. \n\nIn\
    \ your use case you could run the roscore on either of the Raspberry PIs or the\
    \ laptop. Each of the PIs would need to run the rosserial_python node to connect\
    \ to their respective Arduinos. You would then write a [rosserial publisher node\
    \ as described here](http://wiki.ros.org/rosserial_arduino/Tutorials/Hello%20World)\
    \ on one Arduino and a [subscriber node](http://wiki.ros.org/rosserial_arduino/Tutorials/Blink)\
    \ on the other.\n\nHope this gives you a good idea how to do this."
