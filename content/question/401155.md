I have both robot models working, I'm able to program different trajectories and visualize them in each platform. I've seen the [gazebo-fmi](https://github.com/robotology/gazebo-fmi) functionality to add plugins to Gazebo, but I'm not sure if it's useful for this case and how to use it.
