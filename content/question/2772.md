    In more detail for sending velocity command to a pioneer3at robot in standalone gazebo, we should uncomment skidsteerdriveplugin part in SDF file of pioneer3at or add this plugin to [SDF file](https://bitbucket.org/osrf/gazebo_models/issue/9/add-skid-steer-plugin-to-pioneer3at-model), and we should write a publisher like [this](https://bitbucket.org/osrf/gazebo/src/5edc856de8ba/examples/stand_alone/publisher/publisher.cc?at=rtql8) that i explain in this [question](http://answers.gazebosim.org/question/2880/i-dont-have-vel_cmd-topic-in-my-gztopic-list/), now this publisher publish velocity command to vel_cmd topic and skidsteerdriveplugin subscribe to it and set velocity command to our pioneer3at robot in field.
