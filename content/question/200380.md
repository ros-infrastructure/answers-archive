    Since you're "very new" to ROS, you likely don't need <code>foreign_relay</code>. ROS is a distributed system that supports topic sharing between computers out-of-the-box -- you simply need to use the <code>ROS_MASTER_URI</code> environment variable (see the <a href="http://wiki.ros.org/ROS/Tutorials/MultipleMachines">Running ROS across multiple machines</a> tutorial).
