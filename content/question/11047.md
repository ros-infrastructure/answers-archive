  body_markdown: "Assuming you are talking about Gazebo, you can apply a force to\
    \ a body using this command on the command line:\n\n    rosservice call /gazebo/apply_body_wrench\
    \ '{body_name: \"object_1::object_1_base_link\", reference_frame: \"object_1::object_1_base_link\"\
    , wrench: { force: { x: 0, y: 0, z: -20.0 } }, start_time: 0, duration: -1 }'\n\
    \nOf course, you can also call the `apply_body_wrench` service from a program.\
    \ \n\n**Edit:** Another alternative is accessing the body from a Gazebo plugin.\
    \ I haven't done that yet, but I think it should run along these lines:\n\n- you\
    \ get a Gazebo [Model](http://playerstage.sourceforge.net/doc/Gazebo-manual-svn-html/classgazebo_1_1Model.html)\
    \ object in the constructor of your controller\n\n- use `Model->GetBody(const\
    \ std::string &name)` to get the body representing your link by name\n\n- use\
    \ `Body->SetForce(const Vector3 &force)` to apply the force\n\n\nI also found\
    \ looking at [turtlebot_gazebo_plugins](http://www.ros.org/wiki/turtlebot_gazebo_plugins)\
    \ as an example for some of these steps very helpful."

  body_markdown: "# Requrements: \n\nfrom gazebo_msgs.srv import ApplyBodyWrench\n\
    from geometry_msgs.msg import Wrench\n\n\n\n# Gazebo service call for applying\
    \ a force on a body \ndef applyForce(): \n    rospy.wait_for_service('/gazebo/apply_body_wrench')\n\
    \    force           = rospy.ServiceProxy('/gazebo/apply_body_wrench',ApplyBodyWrench)\n\
    \n    wrench          = Wrench()\n    wrench.force.x  = 0\n    wrench.force.y\
    \  = 0\n    wrench.force.z  = 0\n    wrench.torque.x = 0\n    wrench.torque.y\
    \ = 0\n    wrench.torque.z = 0\n    # You can also define the start time if necessary...\
    \ \n    force(body_name = \"base_link\",wrench = wrench, duration = rospy.Duration(10))"
