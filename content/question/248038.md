  body_markdown: "In terms of functionality for each approach, the [srdf wiki page](http://wiki.ros.org/srdf)\
    \ has descriptions for each.  \n\nIn short,\n\n - A link automatically includes\
    \ its parent joint\n - A joint automatically includes is child link\n - A chain\
    \ implicitly defines the joints based on the two selected links (Based on the\
    \ links in the chain, the set of joints in the chain is implicitly defined. The\
    \ joints that correspond to a chain are the parent joints for the links in the\
    \ chain, except the parent joint of the base_link)\n\nAs to why the ROS-I tutorial\
    \ specifically suggests using chains I can only guess that it is easier, less\
    \ error prone, and/or more suitable to the IK solvers..."
