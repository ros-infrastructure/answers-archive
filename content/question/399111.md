      I think the file is called "56-orbbec-usb.rules", not "orbbec-usb.rules", use

          sudo cp 56-orbbec-usb.rules /etc/udev/rules.d/

      The first command copies the file to "/etc/udev/rules.d/", where the udev rules reside.
      The second command makes udev reload its rules so it knowns about our new rule.
      udev then makes your camera accessible once its plugged in.
