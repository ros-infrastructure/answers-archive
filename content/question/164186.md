  body_markdown: "You need to add all of source files that will build an executable\
    \ to the add_executable command. \n\n    ## Declare a cpp executable\n    add_executable(executable_one\
    \ src/source_one.cpp src/source_two.cpp ... src/source_n.cpp) \n\nTo create multiple\
    \ executables, you just add multiple instances of that line:\n\n    ## Declare\
    \ a cpp executable\n    add_executable(executable_one src/source_one.cpp src/source_two.cpp\
    \ ... src/source_n.cpp) \n    add_executable(executable_two src/source_one.cpp\
    \ src/source_two.cpp ... src/source_n.cpp) \n    add_executable(executable_three\
    \ src/source_one.cpp src/source_two.cpp ... src/source_n.cpp) \n\nEach add_executable\
    \ is self-contained so it will only use the files you list to build the executable.\
    \ So make sure you list all source files needed, even they are also used for a\
    \ different executable. Also, make sure you have the target_link_library(executable\
    \ ${catkin_LIBRARIES}) for each executable."

  body_markdown: |-
    My problem of compiling with multiple executables was due to the fact that I was including 2 or more `main` functions within `add_library` because the `add_library` takes from the `file(GLOB ${PROJECT_NAME}_src..` part, and it had a regex that took 2 or more executables.

    The solution is to put your executables in a folder that isn't grabbed by the `file(GLOB ${PROJECT_NAME}_src..` part and when you declare executables using `add_executable`, make sure to include within `target_link_libraries` the `${PROJECT_NAME` variable, which is usually all non-executable .cpp files in your package.
