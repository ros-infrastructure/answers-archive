  body_markdown: "There are two normal ways to tell a node to shut down:\n\n - SIGINT\
    \ signal. Used by `roslaunch` or when you do `Ctrl-C`.\n - Shutdown XMLRPC call.\
    \ Used by `rosnode kill`.\n\nIf you want to cover all your bases, you need to\
    \ override roscpp's handlers for both. In practice, most people seem to just override\
    \ SIGINT, probably because it's actually documented and `rosnode kill` is less-used.\n\
    \nWhat roscpp really needs is an \"on shutdown\" callback. That's ticketed here:\
    \ https://code.ros.org/trac/ros/ticket/3417\n\nIn the meantime, it is possible\
    \ (if a little messy) to do this correctly. An example is the [nodelet.cpp](http://ros.org/doc/unstable/api/nodelet/html/nodelet_8cpp_source.html)\
    \ code. The relevant parts look like:\n\n    #include <signal.h>\n    #include\
    \ <ros/ros.h>\n    #include <ros/xmlrpc_manager.h>\n    \n    // Signal-safe flag\
    \ for whether shutdown is requested\n    sig_atomic_t volatile g_request_shutdown\
    \ = 0;\n    \n    // Replacement SIGINT handler\n    void mySigIntHandler(int\
    \ sig)\n    {\n      g_request_shutdown = 1;\n    }\n    \n    // Replacement\
    \ \"shutdown\" XMLRPC callback\n    void shutdownCallback(XmlRpc::XmlRpcValue&\
    \ params, XmlRpc::XmlRpcValue& result)\n    {\n      int num_params = 0;\n   \
    \   if (params.getType() == XmlRpc::XmlRpcValue::TypeArray)\n        num_params\
    \ = params.size();\n      if (num_params > 1)\n      {\n        std::string reason\
    \ = params[1];\n        ROS_WARN(\"Shutdown request received. Reason: [%s]\",\
    \ reason.c_str());\n        g_request_shutdown = 1; // Set flag\n      }\n   \
    \ \n      result = ros::xmlrpc::responseInt(1, \"\", 0);\n    }\n    \n    int\
    \ main(int argc, char** argv)\n    {\n      // Override SIGINT handler\n     \
    \ ros::init(argc, argv, \"MyNode\", ros::init_options::NoSigintHandler);\n   \
    \   signal(SIGINT, mySigIntHandler);\n    \n      // Override XMLRPC shutdown\n\
    \      ros::XMLRPCManager::instance()->unbind(\"shutdown\");\n      ros::XMLRPCManager::instance()->bind(\"\
    shutdown\", shutdownCallback);\n    \n      // Create publishers, subscribers,\
    \ etc.\n    \n      // Do our own spin loop\n      while (!g_request_shutdown)\n\
    \      {\n        // Do non-callback stuff\n    \n        ros::spinOnce();\n \
    \       usleep(100000);\n      }\n    \n      // Do pre-shutdown tasks\n    \n\
    \      ros::shutdown();\n    }\n\n"

I want to do some shutting down code for my node.
It is important that I am still fully connected to ROS while that is happening, so putting stuff just after the main loop is not an option.

Currently I would pass NoSigIntHandler to ros::init,
install my own SIGINT handler, do stuff there and then call ros::shutdown.

Is this correct, i.e. the intended way or is there a better solution?

Update: I tested this and it works fine for pressing Ctrl-C even from roslaunch. For me this is OK right now.

The only thing that does not work is what Lorenz hinted at: rosnode kill seems to use another method, I get:

[ WARN] [1329394338.937223749, 61.017000000]: Reason given for shutdown: [user request]</pre>
and my SIGINT handler is not called.
I could try to work around this by checking `ros::isShuttingDown` and trying to shutdown my stuff while that is happening, but that doesn't seem safe to me.
