  body_markdown: "Hi Ray,\n\nA [`geometry_msgs/Pose`](http://docs.ros.org/melodic/api/geometry_msgs/html/msg/Pose.html)\
    \ consits of a [`geometry_msgs/Point`](http://docs.ros.org/melodic/api/geometry_msgs/html/msg/Point.html)\
    \ **and** a [`geometry_msgs/Quaternion`](http://docs.ros.org/melodic/api/geometry_msgs/html/msg/Quaternion.html)\
    \ (click for details). Hence you can't convert a point to a pose, since the orientation\
    \ is missing. \n\nThat said, you can however write a node. Design a class where\
    \ you register a Subscriber and Publisher in the constructor by passing the NodeHandle\
    \ as argument. In the callback for the subscriber (Point-topic) you create a new\
    \ pose message and pass the point as *pose.position* and a add a custom quaternion\
    \ as *pose.orientation*. I would make the orientation a ROS-Parameter which i\
    \ can set in the launch file."

    /diagnostics /diagnostics_stamped diagnostic_msgs/DiagnosticArray \n       'diagnostic_msgs.msg.DiagnosticArray(header=std_msgs.msg.Header(\n\
    \        stamp=rospy.Time.now(), frame_id=m.name),\n        status=[diagnostic_msgs.msg.DiagnosticStatus(\n\
    \        level=m.level, name=m.name, message=m.message, hardware_id=m.hardware_id,\
    \ values=[])])' \n        --import diagnostic_msgs std_msgs rospy\"/>\n    </launch>\n\
