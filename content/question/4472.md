    Looks like a problem with the libbullet version needed by gazebo.

    While ubuntu ships 2.80, gazebo uses 2.81, so you will need to install debs from the OSRF repository. Two ways:

    * Download libbullet-dev and libbullet-2.81 manually from [OSRF package repository](http://packages.osrfoundation.org/gazebo/ubuntu/pool/main/b/bullet/).
    * Easier: [add the OSRF repository](http://gazebosim.org/wiki/1.9/install) to your system and install libbullet-dev from there.
