    The [robot_state_publisher](http://wiki.ros.org/robot_state_publisher) should be what you are asking for, if I understand your question correctly. Using a URDF robot model uploaded to the parameter server and joint states it receives via a topic, it publishes tf. This [tutorial](http://wiki.ros.org/robot_state_publisher/Tutorials/Using%20the%20robot%20state%20publisher%20on%20your%20own%20robot#Running_as_a_ROS_node) explains how to use it.
