    \ cat the following contents\n\n    Section: misc\n    Priority: optional\n  \
    \  Standards-Version: 3.9.2\n\n    Package: libogre1.8-dummy\n    Version: 1.8.0\n\

    \ libogre1.8-dev` to build the deb package. Install it with `sudo dpkg -i libogre1.8-dummy_1.8.0_all.deb`.\
