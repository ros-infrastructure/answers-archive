  body_markdown: "The return value of `move_group.plan()` may be `yaml.dump(..)`-able,\
    \ but the `yaml.load(..)`-ed version of that is just a `dict`, not an actual `Plan`\
    \ instance.\n\n`move_group.execute(..)` does not take a `dict`, hence the error\
    \ message when it tries to use whatever you're passing it as a `Plan`.\n\nFrom\
    \ the [move_group.py documentation](http://docs.ros.org/en/noetic/api/moveit_commander/html/move__group_8py_source.html#l00604):\n\
    \n     def plan(self, joints=None):\n         \"\"\"Return a tuple of the motion\
    \ planning results such as\n         (success flag : boolean, trajectory message\
    \ : RobotTrajectory,\n          planning time : float, error code : MoveitErrorCodes)\"\
    \"\"\n         if type(joints) is JointState:\n             self.set_joint_value_target(joints)\n\
    \  \n         elif type(joints) is Pose:\n             self.set_pose_target(joints)\n\
    \  \n         elif joints is not None:\n             try:\n                 self.set_joint_value_target(self.get_remembered_joint_values()[joints])\n\
    \             except MoveItCommanderException:\n                 self.set_joint_value_target(joints)\n\
    \  \n         (error_code_msg, trajectory_msg, planning_time) = self._g.plan()\n\
    \  \n         error_code = MoveItErrorCodes()\n         error_code.deserialize(error_code_msg)\n\
    \         plan = RobotTrajectory()\n         return (\n             error_code.val\
    \ == MoveItErrorCodes.SUCCESS,\n             plan.deserialize(trajectory_msg),\n\
    \             planning_time,\n             error_code,\n         )\n\nNote how\
    \ the return value is a tuple, with at least one element being a `RobotTrajectory`\
    \ instance.\n\nYou *might* be able to transform one of the members of the `dict`\
    \ you `yaml.load(..)` into a `RobotTrajectory` instance again using something\
    \ like [rospy_message_converter](http://wiki.ros.org/rospy_message_converter),\
    \ but no guarantees."
