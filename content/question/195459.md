  body_markdown: "You're correct that <code>openni_tracker</code> is incompatible\
    \ with <code>openni2_launch</code>. The issue comes down to the Openni <i>middleware</i>\
    \ NiTE. The <code>openni_tracker</code> uses NiTE v1.5 (I'm not sure if earlier\
    \ versions of NiTE work, as I've only used 1.5). NiTE v1.5 is still available\
    \ at various places (for instance, on the CD I received with a recently purchased\
    \ Asus XtionPRO Live). \n\nHowever, NiTE v2 is required for skeleton tracking\
    \ with <code>openni2</code>. My understanding is that Apple bought the company\
    \ that was developing NiTE and subsequently \"closed-sourced\" it -- that is,\
    \ pulled the distribution licences. This makes it difficult, to say the least,\
    \ to find a copy of NiTE2. And if you do, it's likely the source is in violation\
    \ of their license (again, this is just my understanding of the situation).\n\n\
    Now, if you can find a copy of the NiTE2 software, the <code>openni2_tracker</code>\
    \ ROS package found at <a href=\"https://github.com/futureneer/openni2-tracker\"\
    >https://github.com/futureneer/openni2-tracker</a> is functional, although it\
    \ could use some tweaking."
