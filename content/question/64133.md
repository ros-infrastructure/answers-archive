  body_markdown: "I've just had this problem. The problem is in the version on pyparsing\
    \ which is 2.0.0 and was designed for python 3.0. To resolve the problem you have\
    \ to downgrade the pyparsing module. If you actually run this line, it will build\
    \ pydot:\n\n    sudo pip install -U pydot  pyparsing==1.5.7\n\nBut I don't know\
    \ how to pass the parameter \"pyparsing==1.5.7\" to rosdep. Next time you run\
    \ rosdep install it will fetch again the same 2.0 version of pyparsing.\n\nThis\
    \ is what I did:\n*UPDATED\n    \n        1) sudo pip uninstall pyparsing\n  \
    \      2) sudo pip install https://pypi.python.org/packages/source/p/pyparsing/pyparsing-1.5.7.tar.gz\n\
    \        3) sudo pip install -U pydot pyparsing==1.5.7\n    try to rosmake, if\
    \ will not go through repeat above steps and do set 4:\n        4) remove this\
    \ line \"pyparsing\" from /Library/Python/2.7/site-packages/pydot-1.0.28-py2.7.egg-info/requires.txt\
    \ or where you store site-packages."
