  body_markdown: "There are following two ways to install `vision_visp`:\n\n 1. **Install\
    \ using `apt`:** I prefer this option as it takes care of installing dependencies\
    \ and takes less time. Please use the following command:\n\n        $ sudo apt-get\
    \ install ros-noetic-vision-visp\n\n 2. **Install from source:** This definitely\
    \ takes a considerable amount of time to compile. Furthermore, all the dependencies\
    \ must be installed before compilation. Please see below for more details:\n\n\
    \        ravi@dell:~/ros_ws$ source /opt/ros/noetic/setup.bash\n        \n   \
    \     ravi@dell:~/ros_ws$ git clone --branch noetic git@github.com:lagadic/vision_visp.git\n\
    \        \n        ravi@dell:~/ros_ws$ sudo rosdep init\n        \n        ravi@dell:~/ros_ws$\
    \ rosdep update\n        \n        ravi@dell:~/ros_ws$ rosdep install --from-paths\
    \ src --ignore-src --rosdistro noetic\n        executing command [sudo -H apt-get\
    \ install libdmtx-dev]\n        executing command [sudo -H apt-get install ros-noetic-visp]\n\
    \        executing command [sudo -H apt-get install libzbar-dev]\n        \n \
    \       ravi@dell:~/ros_ws$ catkin_make -DCMAKE_BUILD_TYPE=Release \n\n    You\
    \ can notice that we have quite a few dependencies to build this package!\n\n\
    Finally, the above steps are taken from [the wiki page](http://wiki.ros.org/vision_visp)\
    \ and confirmed on my machine (ROS Noetic in Ubuntu 20.04) "
