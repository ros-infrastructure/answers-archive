  body_markdown: "If you are using move_base to autonomously drive to a location,\
    \ then using the service provides a return message when it reaches the goal. Otherwise,\
    \ if you want to use the bool method, it is the same as any other callback. Make\
    \ a global variable to hold some flag, called reached below, and populate it with\
    \ the data value from the message.\n\n    bool reached = false;\n    \n    void\
    \ positionreached(const std_msgs::Bool::ConstPtr& Reached)\n    {\n      reached\
    \ = Reached->data;\n    }\n\n[EDIT]\n\nRight, Arduino. Try:\n\n    void positionreached(const\
    \ std_msgs::Bool Reached)\n    {\n      reached = Reached.data;\n    }\n\nAlso,\
    \ reached only needs to be bool, not std_msgs::Bool."
