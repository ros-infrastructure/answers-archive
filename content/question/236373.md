  body_markdown: "I realize this was asked a while back, but in case anyone is still\
    \ struggling with a similar issue, something like the following is working for\
    \ me...\n\n    glib_mainloop = g_main_loop_new (NULL, false);\n    glib_context\
    \ = g_main_context_default();\n    \n    while (ros::ok())\n     {\n        g_main_context_iteration(glib_context,\
    \ false);\n        ros::spinOnce();\n\n      // sleep for a while to avoid maxing\
    \ out CPU\n       std::this_thread::sleep_for(std::chrono::milliseconds(20));\n\
    \    }\n    \n    g_main_loop_unref (glib_mainloop);\n\nThe idea here is that\
    \ for each loop of the while statement, the glib main loop is iterated once, followed\
    \ by a single interation of the ROS loop."
