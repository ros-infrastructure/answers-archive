    \ laser scan conversions from `pointcloud_to_laserscan`/`laserscan_to_pointcloud`\
    \ from [there](https://github.com/ros-perception/pointcloud_to_laserscan/tree/lunar)\
    \ + [there](https://wiki.ros.org/pointcloud_to_laserscan)) that reads the laser\
    \ scans from all LiDAR scanners as pointclouds and merge them into a single laser\
    \ scan (360 degrees).\n\nEDIT:\nChanged answer to ROS1 version.\n\nPlease check\
    \ the @Mike Scheutzow comment below regarding the multi-plane lidar - you have\
    \ to filter the scans first if you wanted good results.\n\nI found more detailed\
    \ information here: \nhttps://www.cvlibs.net/datasets/kitti/raw_data.php \n\n\
    Perhaps you should check the suggested tools:\n\n> Yani Ioannou (University of\
    \ Toronto) has put together [some tools](https://github.com/yanii/kitti-pcl) for\
    \ working with KITTI raw data using [the PCL](https://pointclouds.org/)."
