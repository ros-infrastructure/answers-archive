  body_markdown: "Finally, I found out what was my problem. In [this Gazebo tutorial](http://gazebosim.org/tutorials?cat=install&tut=install_from_source&ver=7.0)\
    \ (this links to the Gazebo 7 version of the tutorial as Gazebo 7 is the last\
    \ version available on Ubuntu 14.04 Trusty), the first steps are the following\
    \ : \n\n    wget https://bitbucket.org/osrf/release-tools/raw/default/jenkins-scripts/lib/dependencies_archive.sh\
    \ -O /tmp/dependencies.sh\n    ROS_DISTRO=dummy . /tmp/dependencies.sh\n    sudo\
    \ apt-get install $(sed 's:\\\\ ::g' <<< $GAZEBO_BASE_DEPENDENCIES) $(sed 's:\\\
    \\ ::g' <<< $BASE_DEPENDENCIES)\n\nSo I looked at the file **/tmp/dependencies.sh**\
    \ in gedit and found out that I need to specify **GAZEBO_MAJOR_VERSION=7** prior\
    \ to running the script so that it does not look for libqwt-qt5-dev. So here is\
    \ what I suggest to those trying to build Gazebo from source on Ubuntu 14.04.\
    \ When installing the dependencies at the begining of the procedure in the tutorial,\
    \ do the following instead : \n\n    wget https://bitbucket.org/osrf/release-tools/raw/default/jenkins-scripts/lib/dependencies_archive.sh\
    \ -O /tmp/dependencies.sh\n    ROS_DISTRO=dummy GAZEBO_MAJOR_VERSION=7 DISTRO=trusty\
    \ . /tmp/dependencies.sh\n    sudo apt-get install $(sed 's:\\\\ ::g' <<< $GAZEBO_BASE_DEPENDENCIES)\
    \ $(sed 's:\\\\ ::g' <<< $BASE_DEPENDENCIES)\n\nJust added **GAZEBO_MAJOR_VERSION=7\
    \ DISTRO=trusty** to the second command line. \n\nThen, building Gazebo from source\
    \ (using gazebo7 branch) worked fine. \n"
