I followed the catkin instructions on the basic ROS msg tutorial for CreatingMsgAndSrv at http://wiki.ros.org/ROS/Tutorials/CreatingMsgAndSrv.  Everything worked just as it was explained in the tutorial: rosmg show &lt;custom_message&gt; returned the correct information.  But I couldn't figure out how to use the message in my python code.  The following tutorial goes right back to using std_msgs String message with code that looks like the following: from std_msgs.msg import String.  I tried to use my custom message in the following way: 

from custom_message.msg import custom_message.  

It didn't seem right, it didn't work, and I couldn't seem to find out how to do it correctly from the next tutorial.  The error I received was 

ImportError: No module named &lt;custom_message&gt;.msg.  

I believe I have found the solution though and wanted to share it.  You want to import the custom message from the module you are building, with the following code: 

from &lt;module&gt;.msg import &lt;custom_message&gt;

For instance, I have a module called webserver and I created a custom message called event that I put into a message file called event.msg.  So I would write

from webserver.msg import event

What I was most confused about was that webserver doesn't have a file name webserver.msg but I did have a file named event.msg.  Anyway, I thought this should have been added as part of the tutorials so that everyone would be clear on how to use their custom messages after creating it.

In addition, it is important to source the setup.bash file in your catkin workspace for this to work.  Please see the question and answers on the forum at this link: http://answers.ros.org/question/54579/creating-custom-message-and-service-for-groovy-using-them-with-python/
