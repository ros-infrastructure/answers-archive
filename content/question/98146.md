    Your CMakeLists.txt is very disordered, but I think that the generate_messages() command is missing.
    If your message away.msg depends on other messages (for example std_msgs) you should tell catkin in a similar way:

        generate_messages(
          DEPENDENCIES
          std_msgs
        )

    find_package(catkin REQUIRED COMPONENTS message_generation roscpp

    include_directories(${catkin_INCLUDE_DIRS})
    add_executable(away src/away.cpp) 
    add_dependencies(away uuv_words_generate_messages_cpp)
    target_link_libraries(away ${catkin_LIBRARIES})
