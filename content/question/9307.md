  body_markdown: "The simplest work around is to change the OSX definition of libusb\
    \ in the rosdep.yaml file.  You can set it to point to something already installed\
    \ or add a multiline script which is commented like below:\n\n      macports:\
    \ |\n        # Manually installed\n\nUpdate:\n\nyou will need to find the rosdep.yaml\
    \ file where it is getting the definition of libusb as needed by openni.  I'm\
    \ not sure what source you're running from but the following should find you the\
    \ file. \n\n`rosdep where_defined libusb1.0` "
