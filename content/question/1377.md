  body_markdown: "Hi, the gazebo api is very powerful and well designed.\n\nI try\
    \ to solve the problem using a VisualPlugin. The ModelPlugins exist to access\
    \ the physics features of a Model. Nowadays the tutorials says that exists four\
    \ kind of plugins: World, Model, Sensor and System. But the VisualPlugin exists\
    \ too, I don't know if there is no documentation about it.\n\nWell I copy the\
    \ code of \"ModelPush\" plugin example and modify to do a visual plugin that changes\
    \ the color of a box. [my_plugin.h](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/1361041844100905.h)\
    \ and [my_plugin.cpp](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/1361041893450122.cpp)\
    \ and finally the world file [teste.world](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/13610419305261473.world).\
    \ \n\nI don't know if there is another solution, this one is a little complicated,\
    \ but maybe it serves you.\n\nAfter you compile the code and run the gazebo with\
    \ the world file, you should see a static box that changes the color between red\
    \ and black.\n\nIf you need to change the color of things dynamically probably\
    \ you need some custom messages to communicate a \"physical event\" to the visual\
    \ plugin.\n\nI hope that answer helps you.\n\n----\n\nWell there is an example\
    \ in folder examples/plugins/model_visuals of gazebo source. Take a look: [Example\
    \ passing a message](https://bitbucket.org/osrf/gazebo/src/ff38b1f7b7a8d8decbdadc33a84a83eb7cc44b47/examples/plugins/model_visuals/model_visuals.cc?at=default)\n\
    \nThis way is the correct way, I think. Once you known the visual name that you\
    \ need to modify, you just need to create a visual message and sends it to gazebo.\
    \ The advantage is that you can keep entire code in the ModelPlugin and modify\
    \ the visuals through messages.\n"
