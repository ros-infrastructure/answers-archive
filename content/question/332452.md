    I think `ros2 run` uses the ament index to find packages, and it looks like the package `temoto_parser` isn't installing a marker file.

    Create a folder called `resource/` (this folder name doesn't really matter, it's just what's been used so far) in the same directory as your `setup.py` file. Next, create an empty file with the same name as your package in that folder: `resource/temoto_parser`. In your `setup.py` use the `data_files` keyword argument to install the marker file `temoto_parser` to `share/ament_index/resource_index/packages`.

    See the [ros2/examples repo](https://github.com/ros2/examples) for python packages that do this. [Here's the relevant part of the setup.py](https://github.com/ros2/examples/blob/898a753e8c6e8c6ba14cbf5eb3264113cf3b2bc7/rclpy/topics/minimal_publisher/setup.py#L9-L11), and [here's a marker file in a folder called `resource`](https://github.com/ros2/examples/tree/master/rclpy/topics/minimal_publisher/resource).

    Here's [a page with a little more info about the ament_index](https://index.ros.org//doc/ros2/Tutorials/Ament-CMake-Documentation/#the-ament-index-explained), though it's targeted at packages using CMake.
