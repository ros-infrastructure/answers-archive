  body_markdown: "Make sure the namespace is same in the gazebo plugin and the controllers.yaml\
    \ file. This namespace is equal to the name of the robot in your URDF file. Also\
    \ make sure the hardwareInterface type (eg. PositonJointInterface) matches the\
    \ corresponding controller of the joint in controllers.yaml file you created.\n\
    \n\nFor eg. my gazebo plugin has this tag:  <robotNamespace>/arm_mesh</robotNamespace>\
    \ \n\n\nwhere arm_mesh is the name specified in my URDF.\n\nMy controllers.yaml\
    \ file is like this:\n\n\n    arm_mesh:\n\n      robotic_arm_controller:\n\n \
    \         type: \"position_controllers/JointTrajectoryController\"\n\n       \
    \      .......\n\nMy launch file to activate controller manager:\n\n     <launch>\n\
    \n\t   <rosparam file=\"$(find PKG_NAME)/config/controllers.yaml\" command=\"\
    load\"/>\n\n          <node name=\"robotic_arm_controller_spawner\" pkg=\"controller_manager\"\
    \ type=\"spawner\" \n            respawn=\"false\"  output=\"screen\" ns=\"/arm_mesh\"\
    \ args=\"robotic_arm_controller\"/>\n\n\n     </launch>"
