  body_markdown: "So, out of the top of my head, \n\n - have you tried using picamera\
    \ (https://picamera.readthedocs.io/en/release-1.13/) on the raspberry pi itself\
    \ with the same configuration?  Its a good idea to test if the hardware is working\
    \ with native libraries outside of ROS before you try ROS packages. If the camera\
    \ isnt working outside of ROS then there is no way it will work with raspicam_node\n\
    \n\n- Since you are using a remote PC, you should ensure your ROS multiple machines\
    \ set up is working properly, publish a simple float topic on raspberry pi and\
    \ see if you can echo it from remote PC\n\n - If step one and two is working then\
    \ before using rqt_image_view on remote PC it is a good idea to rostopic echo\
    \ the raw camera feed first and check if the topic is not empty.\n\nHope this\
    \ helps."
