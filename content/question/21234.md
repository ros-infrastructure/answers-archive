    Every tutorial has an edit button on the top-right which takes you to where it is hosted on BitBucket. There's more information on [this tutorial](http://gazebosim.org/tutorials?tut=tutorial_contrib&cat=development#Modifyatutorial).

    In any case, I don't think you're right about the change you want to make. The `<joint>` tag must be within the `<model>` tag:

        <model...>
            <joint> </joint>
        </model>

    If you have a question about this, I suggest you create a new question.
