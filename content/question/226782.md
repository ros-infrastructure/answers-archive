     Yes, Gmapping allows for map growth. I also believe it uses a tiled map representation behind the scenes (see [HierarchicalArray2D](http://docs.ros.org/diamondback/api/gmapping/html/classGMapping_1_1HierarchicalArray2D.html)), so it should be multiple 1D arrays instead of one (with additional ones being added when the map grows).
