    RGBDSLAM V2 is available and works well. There is a decent amount of explanation and instructions here:
    http://felixendres.github.io/rgbdslam_v2/

    The documentation lists it as using [openni_launch](http://wiki.ros.org/openni_launch), but it works with [freenect_launch](http://wiki.ros.org/freenect_launch) as well.

    One note about installing RGBDSLAM V2 is that you may experience an error during compiling due to SiftGPU, such as `*** [build/CuTexImage.o] Error 1`. If this happens, you can adjust the CMakeLists.txt file to turn off SiftGPU by changing the line `set(USE_SIFT_GPU        1)` to `set(USE_SIFT_GPU        0)`.

    Hopefully this can get you started.
