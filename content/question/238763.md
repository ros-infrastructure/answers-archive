    The [Kinetic installation instructions](http://wiki.ros.org/kinetic/Installation/Ubuntu) clearly state that binary packages (`apt-get`) for ROS Kinetic are only available for Ubuntu Wily (15.10) and Xenial (16.04).

    I'd recommend that you use [ROS Indigo](http://wiki.ros.org/indigo/Installation/Ubuntu) instead (it is a long-term support release compatible with Ubuntu 14.04)

    If you have a specific package that you need, you can try to build it from source on Indigo (usually works), or you can build [Kinetic from source](http://wiki.ros.org/kinetic/Installation/Source), but the full source installation can take a while.
