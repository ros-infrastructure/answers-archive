 The problem is following:
I have one subsriber node and and 2 publishers node. I use liveliness policy to know, when publishing nodes are dead. 
So, for every subscriber I have `SubscriptionEventCallbacks` function. In case either one of the node dies or I run again, callback function works, but the strange thing is, that sometimes it calls other subscriber`SubscriptionEventCallbacks` function if that publisher of that topic is alive.

The result can achive by:

- running all 3 nodes
- terminate Barcode  node
- restart Barcode node
- trying now to terminate MGS node, it will execute Barcode 'self.subscribe_barcode_node' event callback. Which is not correct.

I appreciate any help.

ROS_VERSION=2
ROS_PYTHON_VERSION=3
ROS_DOMAIN_ID=1
ROS_LOCALHOST_ONLY=0
ROS_DISTRO=foxy
OS = Ubuntu 20.4 on Raspberry 4(64 bit)

I have tried to change QoS profile , but seems that somehow `SubscriptionEventCallbacks` gives previous subsriber 'event' parameter.

So, is the problem in my nodes or simple it is not allowed to have event callback for every subscriber?



This is subscriber node:

    class DoctorNode(Node):
    def __init__(self):
        super().__init__('doctor_node')
        # QOS profile
        qos_profile=QoSProfile(history=HistoryPolicy.KEEP_LAST, depth=10, reliability=ReliabilityPolicy.RELIABLE, durability=DurabilityPolicy.TRANSIENT_LOCAL,
                                lifespan=Duration(seconds=300),  liveliness=LivelinessPolicy.AUTOMATIC, liveliness_lease_duration=Duration(seconds=2.2))
        
        ### Subscribers ###
        self.subscribe_barcode_node = self.create_subscription(
            Bool, 'barcode_health', self.barcode_callback, qos_profile=qos_profile,
            event_callbacks=SubscriptionEventCallbacks(liveliness=lambda event: print(f'BARCODE: {event}')))

        self.subscribe_mgs_node = self.create_subscription(
            Bool, 'mgs_health', self.mgs_callback, qos_profile=qos_profile,
            event_callbacks=SubscriptionEventCallbacks(liveliness=lambda event: print(f'MGS: {event}')))

        self.get_logger().info(f'Doctor node started!')
    
    def barcode_callback(self, msg):
        pass

    def mgs_callback(self, msg):
        pass
