    I have needed to do a similar launching process,and I found two possible methods.
    Two possible methods:

     1. Roslaunch has an [API](http://docs.ros.org/hydro/api/roslaunch/html/), with which you can achieve your desired result. More specifically the Roslaunchrunner has function called launchnode. However this API is very experimental, and does occasionally crash
     2. Other alternative, make your own .launch file, and then have your node run it at command line.

    Obviously, 1 is more desirable. But I ended up using 2 as its more stable, at least that is what I found

    For 2, in C++ you could use the [system command](http://www.cplusplus.com/reference/cstdlib/system/).
    In python you can use os.system  or more advisably subprocess library
