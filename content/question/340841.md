  body_markdown: "For just using custom recovery behaviors it is really simple, you\
    \ just have to define them in the configuration of move_base :\n\n    recovery_behaviors:\n\
    \       - name: 'conservative_reset1'\n         type: 'clear_costmap_recovery/ClearCostmapRecovery'\n\
    \nFor the name you chose whatever you want but the type is the package where the\
    \ recovery behavior is defined.\n\nHowever if you want to write custom recovery\
    \ behaviors you will need to make them implement the \n`nav_core::RecoveryBehavior`\
    \ interface and create the dedicated ros package.\n\nI suggest you emulate what\
    \ is done for the rotate recovery behavior that can be found in the navigation\
    \ package:\n[rotate](https://github.com/ros-planning/navigation/tree/melodic-devel/rotate_recovery)\n\
    \nIf you use catkin you can easily create the package structure with: \n`catkin_create_pkg\
    \ my_recovery roscpp nav_core`"
