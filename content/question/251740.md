    Hi Bunberra,

    the current [rgbdslam_v2](https://github.com/felixendres/rgbdslam_v2/) uses the octomap library and can compute it internally. You can visualize it in rgbdslam's GUI or save it. You can visualize the saved file with octomap's viewer octovis, or by loading it on the octomap_server (see [this answer](http://answers.ros.org/question/12265/octomap_server/)).

    The use of octomap_server to accumulate the point clouds is therefore not required anymore. If you still want to see the file, I found [this one](https://github.com/felixendres/rgbdslam_v2/blob/c27b4c5799c692829510ab1db96ea779eab2ef9c/rgbdslam/launch/octomap_server.launch) in the history of above repository. However, I strongly recommend the procedure as described in the above paragraph.
