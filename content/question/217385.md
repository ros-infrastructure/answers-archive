    Well, it is not really converting it to a Quadtree.
    But as you are using ROS for 2D navigation, you should be able to use the `ocotmap_server_multilayer` [(LINK)](http://wiki.ros.org/octomap_server#octomap_server_multilayer) which publishes multilayered `nav_msgs::OccupancyGrid`s. Check out the [`3d_navigation`](http://wiki.ros.org/3d_navigation) for a demo video.

    Having a quick look at the [source code](https://github.com/OctoMap/octomap_mapping/blob/indigo-devel/octomap_server/src/OctomapServerMultilayer.cpp), I'd say that you would have to adjust it a bit.

    Maybe, using the downprojected map of the `octomap_server` is already enough for you, but I had problems with this (too much clutter)...

    If there are better ways, I'd be happy to know as well ;-)
