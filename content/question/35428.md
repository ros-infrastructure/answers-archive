  body_markdown: "Hi,\nI had the same problem (using Fuerte), but I was able to calibrate\
    \ my Asus Xtion by changing the launch call to:\n\nrosrun camera_calibration cameracalibrator.py\
    \ --size 10x7 --square 0.025 image:=/camera/rgb/image_mono camera:=/camera/rgb\
    \ --no-service-check\n\nfor the RGB camera, and:\n\nrosrun camera_calibration\
    \ cameracalibrator.py --size 10x7 --square 0.025 image:=/camera/ir/image_raw camera:=/camera/ir\
    \ --no-service-check\n\nfor the IR camera. \n\nHope this helps."
