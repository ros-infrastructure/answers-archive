    I solved it by creating my own launch file and calling the original launch file and setting the parameter there:

        <launch>
            <include file="$(find explore_lite)/launch/explore.launch" />
            <param name="/explore/costmap_topic" value="/rtabmap/grid_map" />
        </launch>

    This [wiki entry](http://wiki.ros.org/roslaunch/Tutorials/Roslaunch%20tips%20for%20larger%20projects)
    under part 6. Parameter overrides gave it in the format I understood and worked.
