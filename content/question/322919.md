    Map files in pgm format can be viewed just as any image editing in tools like GIMP. See for instance also this one here:

    ![image description](https://answers.ros.org/upfiles/14855444348565455.png)

    (Link taken from [Q/A 37762](https://answers.ros.org/question/37762/are-there-any-interesting-pgm-map-files-available-for-simulation/))

    The origin tag in the yaml states where the bottom left pixel of this image is located relative to the map's coordinate frame (supplied via the `frame_id` [param in map_server, defaults to "map"](https://github.com/ros-planning/navigation/blob/66fba702f6ac79ba9386f22d4bbc1e0f50afb5f6/map_server/src/main.cpp#L72)).
