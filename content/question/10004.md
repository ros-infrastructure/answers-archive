  body_markdown: "I've never come across anything in ROS itself but assuming you've\
    \ installed the `rxtools` package (`rx` stack) then you have `matplotlib` installed\
    \ since it's a dependency (used by `rxplot`) and you can use its [pyplot.hist](http://matplotlib.sourceforge.net/api/pyplot_api.html#matplotlib.pyplot.hist)\
    \ command. \n\nAs for how to get the data to plot, there are lots of ways but\
    \ you're looking for a quick, one-off solution you could use `rosh` (you probably\
    \ want to check [this page](http://www.ros.org/wiki/rosh/Overview/Topics) for\
    \ usage details). It could look something like this though:\n\n    # pop up a\
    \ histogram of the field `bar` from the \n    # last 100 messages on the topic\
    \ `foo`:\n    import matplotlib.pyplot as plt\n    import numpy as np\n    x =\
    \ np.array([m.bar for m in topics.foo[:100]])\n    plt.hist(x)\n    plt.show()\n\
    \n"
