  body_markdown: "That is not the way to build any ROS package, including the Velodyne\
    \ driver.\n\nROS packages are built using [catkin_make](http://wiki.ros.org/catkin/commands/catkin_make),\
    \ or some similar tool. See the [catkin documentation](http://wiki.ros.org/catkin),\
    \ many tutorials and API documents are listed there.\n\n**EDIT**: start with the\
    \ first three catkin tutorials:\n\n * [creating a workspace](http://wiki.ros.org/catkin/Tutorials/create_a_workspace)\n\
    \ * [creating a package](http://wiki.ros.org/catkin/Tutorials/CreatingPackage)\n\
    \ * [using a workspace](http://wiki.ros.org/catkin/Tutorials/using_a_workspace)\n\
    \nThat should teach you how build this or any other ROS package.\n\n**EDIT2**:\
    \ There are [instructions for installing ROS on OSX](http://wiki.ros.org/indigo/Installation/OSX/Homebrew/Source),\
    \ but I have only used Linux. OSX does not look easy, but some people do successfully\
    \ use it. \n\nThose instructions recommend homebrew rather than macports."
