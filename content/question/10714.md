  body_markdown: "Seems like\n\n    self.p = subprocess.Popen(command, stdin=subprocess.PIPE,\
    \ shell=True, cwd=dir_save_bagfile)\n\nstarts a shell which then starts the program\
    \ that does the job. One could see it with ps:\n\n    $ ps aux | grep record\n\
    \    sergey   17900  0.0  0.0   4272   584 pts/4    S    18:36   0:00 /bin/sh\
    \ -c rosbag record -O /home/ . . . \n    sergey   17901  7.3  0.1 288132  7124\
    \ pts/4    Sl   18:36   0:00 record --buffsize 256 -O /home/ . . . \n\nTherefore\
    \ killing the process with pid returned by subprocess.Popen does not kill the\
    \ actual bag recording. We also need to kill its child. There is a nice code snippet\
    \ [here](http://stackoverflow.com/questions/3332043/obtaining-pid-of-child-process)\
    \ for kill_child_processes(). Here is my modified version:\n\n    import subprocess,\
    \ os, signal\n    \n    def terminate_process_and_children(p):\n        ps_command\
    \ = subprocess.Popen(\"ps -o pid --ppid %d --noheaders\" % p.pid, shell=True,\
    \ stdout=subprocess.PIPE)\n        ps_output = ps_command.stdout.read()\n    \
    \    retcode = ps_command.wait()\n        assert retcode == 0, \"ps command returned\
    \ %d\" % retcode\n        for pid_str in ps_output.split(\"\\n\")[:-1]:\n    \
    \            os.kill(int(pid_str), signal.SIGINT)\n        p.terminate()\n\nThis\
    \ function expects a subprocess.Popen object."
