  body_markdown: " This is the reason why there are message-packages. If you have\
    \ a package foo that contains a lot of algorithms, dependencies and message definitions,\
    \ you should create a package foo-msgs that contains only the message-definitions.\n\
    The original foo package then depends on this foo-msgs. In your case, you'd then\
    \ only have to install the foo-msgs package on your machine so set up the communication. "
