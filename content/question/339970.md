    \n\n**Method 1:**\nYou can be sure about that you've installed the specific package\
    \ when you use the 'from the source' installation method by simply cheking the\
    \ installation folder of the packages.\nSo simply go to \"/opt/ros/kinetic/share\"\
    \ folder by typing this: \n\n    cd /opt/ros/kinetic/share\nif you want to list\
    \ all of the hector_slam metapackage packages, you can list them with grep:\n\
    \ \n    cd /opt/ros/indigo/share && ls | grep hector\n\n\n----------\n\n\n**Method\
    \ 2:**\nif you want see the packages are installed or not, you can use `rospack\

    \ try to search directly **hector_slam**, it will say it's not installed. Because\
    \ this command doesn't work with the metapackages. You can use this command to\
    \ find your manually installed or created packges.\n\n\n----------\n\n\n**Method\
    \ 3:**\nYou can use the `roscd` command to go directly to the installation directory\
    \ if the package is installed. For example:\n\n     roscd hector_mapping\n\nthen\
