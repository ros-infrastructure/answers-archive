  body_markdown: "rospy has a logger, use it\n\n \n\n    topic = 'sensor_msgs/LaserScan/topic'\n\
    \     rospy.loginfo(\"I will publish to the topic %s\", topic)\n\nand some latter\
    \ in the callback:\n\n    def callback(data):\n        rospy.loginfo(rospy.get_caller_id()\
    \ + \"I heard %s\", data.data)\n\n\nif you maybe need to collect the data to later\
    \ use it / reproduce it for analytics purposes then a Rosbag is the way to go\
    \ :)\n\n\n    import rosbag\n    from std_msgs.msg import Int32, String\n    \n\
    \    bag = rosbag.Bag('test.bag', 'w')\n    \n    try:\n        str = String()\n\
    \        str.data = 'foo'\n    \n        i = Int32()\n        i.data = 42\n  \
    \  \n        bag.write('chatter', str)\n        bag.write('numbers', i)\n    finally:\n\
    \        bag.close()"
