    Ok, so it looks like you first installed Gazebo 8 and all its dependencies, and then installed Gazebo 7 on top of that.

    The problem is, Gazebo 7 uses `sdformat4` and `ignition-math2`, while Gazebo 8 uses `sdformat5` and `ignition-math3`. And, unfortunately, these are all incompatible :(

    So I suggest you uninstall all of Gazebo and its dependencies once again, to have a clean start, and then install Gazebo 7, which should pull the correct dependencies only.

    This should perform the uninstallation:

    `sudo apt-get remove '.*gazebo.*' '.*sdformat.*' '.*ignition.*'`
