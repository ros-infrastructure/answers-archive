  body_markdown: |-
    You are loading an xacro file into `model_xml`, which should be the contents of a URDF file. You need to run the xacro file through the [xacro parser](http://wiki.ros.org/xacro) first.

    You are calling `spawn_urdf_model` but trying to use a Gazebo model description file (probably SRDF?). So the correct service to call is `spawn_sdf_model`.
