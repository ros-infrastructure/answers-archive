    Edit: seeing as this is a Docker build: the author/maintainer of `lgsvl/Autoware` is not basing his builds on the official OSRF docker images. He's importing the repository keys himself ([here](https://github.com/lgsvl/Autoware/blob/4fdb2f8d1aa87ca28f1f4f6a47bf2bf27951a7d5/docker/96boards/Dockerfile.kinetic#L41) fi), which requires updates to the `Dockerfile`s to use the new key

    Note that upstream (ie: `autowarefoundation/autoware`) has already changed things significantly and might not have this problem ([these files](https://github.com/autowarefoundation/autoware/tree/42aba1468490e2ed218f9295ab3e7490db864e54/docker)).
