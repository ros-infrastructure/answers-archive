  body_markdown: "In your launch file, include the following:\n\n    <node name=\"\
    map_node\" pkg=\"map_server\" type=\"map_server\" \n          args=\"$(find your_package)/config/map.yaml\"\
    \ \n          respawn=\"false\" output=\"screen\" /> \n\nThe file \"map.yaml\"\
    \ could look like this:\n\n    image: empty_map.png\n    resolution: 0.0500000000\n\
    \    origin: [0.0, 0.0, 0.0]\n    negate: 0\n    occupied_thresh: 0.65\n    free_thresh:\
    \ 0.196\n\nIn a file called global_costmap_params.yaml, you could include:\n\n\
    \    global_costmap:\n        publish_voxel_map: true\n        global_frame: map\n\
    \        robot_base_frame: base_link\n        update_frequency: 3.0\n        publish_frequency:\
    \ 0.0\n        static_map: true\n        rolling_window: false\n\nAnd finally,\
    \ in your launch file, you should put the following under move_base:\n\n    <node\
    \ pkg=\"move_base\" type=\"move_base\" respawn=\"false\" name=\"move_base_node\"\
    \ output=\"screen\">\n        ...\n        <rosparam file=\"$(find navigation_config)/config/global_costmap_params.yaml\"\
    \ command=\"load\" />\n    </node>\n    "
