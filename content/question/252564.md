  body_markdown: "**Implementation**\n==================\n\nImplementation of the\
    \ system is explained in the following list (bulleted list explains what is all\
    \ included in that particular element of the numbered list):\n\t\n 1. gazebo_multirobot.launch\n\
    \n  - empty_world.launch (starts Gazebo with empty_world)       \n  - view_navigation.launch\
    \ (starts Rviz)     \n  - multirobot.launch (explained in the 2nd element below)\n\
    \n 2. multirobot.launch (Launching one_robot.launch with different namespaces\
    \ multiple times. One might include as many robots as he/she wants as long as\
    \ the hardware allows)\n  - one_robot.launch (launches a single robot with a given\
    \ namespace. Details about what it all includes are given in the 3rd element)\n\
    \n 3. one_robot.launch\n  - kobuki.launch.xml (describes a kobuki robot and what\
    \ its pose should be in the world)\n  - tf (for necessary transforms between /world\
    \ and robot_namespace/map)\n  - map_server (loading the map file for a robot)\n\
    \  - robot_state_publisher (publishes the state of the robot to tf with given\
    \ frequency)\n  - move_base_gazebo.launch (starts move_base node with given costmap\
    \ config files)\n  - amcl.launch.xml (starts amcl node)\n  - laserscan_nodelet_manager\
    \ (generating fake laserscan messages)\n\n**Running the System**\n=======\nOnce\
    \ you have the \"multirobot\" file in your workspace, open a terminal window and\
    \ type:\n\n    roslaunch multirobot gazebo_multirobot.launch\n\nThis should start\
    \ Gazebo and Rviz with 2 turtlebots unless you edit launch files.\n\nI added 3\
    \ navigation buttons in Rviz to easily assign 2D Nav Goal for up to 3 robots.\
    \ If you need more robots in the system, you can either check '**multirobot->rviz->navigation.rviz**'\
    \ to add more buttons **or** simply right click on 2d nav goal and check '**tool\
    \ properties**'"

Hello all,

I recently took a Robotics course in Istanbul Technical University and worked on setting up a multi-robot system as my term project. I found the resources on that subject very limited (especially for beginners like me). Therefore, I am posting my answer to "how to set up a multi-robot system and navigation stack" here, hoping it might give some insight to people who are willing to work on this subject.

Thanks Jakub on the great QA [here](http://answers.ros.org/question/41433/multiple-robots-simulation-and-navigation/), I built my work on top of his. And special thanks to Damien Jade Duff for teaching and assisting me debugging the system.

The system was implemented and tested on Ubuntu 16.04 with Ros Kinetic.
You can download  the files [here](https://github.com/emrecanbulut/multirobot).
