  body_markdown: "If you're using `openni_tracker`, the general way to do this would\
    \ be to create a [tf listener](http://wiki.ros.org/tf/Tutorials/Writing%20a%20tf%20listener%20%28Python%29),\
    \ and in some sort of loop use the listener to lookup the transform between the\
    \ joints that you're interested in. This method will return a vector and a quaternion\
    \ representing the transform between the two frames. If all you're interested\
    \ in is distance, then you can simply calculate that using the transformation\
    \ vector. Here's a simple example adapted from the previously-linked tf listener\
    \ tutorial:\n\n    #!/usr/bin/env python  \n    import rospy\n    import tf\n\
    \    import geometry_msgs.msg\n    import numpy as np\n    \n    if __name__ ==\
    \ '__main__':\n        rospy.init_node('tf_lookup_example')\n    \n        listener\
    \ = tf.TransformListener()\n    \n        rate = rospy.Rate(10.0)\n        while\
    \ not rospy.is_shutdown():\n            try:\n                (trans,rot) = listener.lookupTransform('/right_hand_1',\
    \ '/left_hand_1', rospy.Time(0))\n                rospy.loginfo(\"Distance between\
    \ the hands is = {0:f}\".format(np.linalg.norm(trans)))\n            except (tf.LookupException,\
    \ tf.ConnectivityException, tf.ExtrapolationException):\n                continue\n\
    \    \n            rate.sleep()\n\nThe only key to making this example work is\
    \ ensuring that your tf tree is fully connected. My version of `openni_tracker`\
    \ uses, by default, `openni_depth_frame` as the frame it produces transforms in,\
    \ but the `openni.launch` file uses `camera` as its default name to define all\
    \ frames and topics. This inconsistency can be fixed, for example, by running\
    \ `openni.launch` in the following way:\n\n    roslaunch openni_launch openni.launch\
    \ camera:=openni\n\nThen `openni_tracker` could be started with just `rosrun openni_tracker\
    \ openni_tracker`"

      The "trans" part in my code is exactly the vector for translation. If you want, for example, the length of the right forearm simply lookup the transform from "/right_hand_1" to "/right_elbow_1". That will give you a translation between those frames. Then the Euclidean norm will give the distance.
