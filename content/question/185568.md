  body_markdown: "I figured it out, \n\nIt was an issue with the CMakeList.txt and\
    \ the OpenCV libraries. I had originally had the CMakeLists.txt addtarget to specific\
    \ folder inside my project which had the opencv libraries. But for whatever reason\
    \ when i did an update it would no longer let me do this so i just needed to remove\
    \ \n\n${CMAKE_CURRENT_SOURCE_DIR}/lib/libopencv_core.so\nAnd all others...\n\n\
    and replace with \n\n${OpenCV_LIBRARIES}\n\nAnd that fixed the problem\n "
