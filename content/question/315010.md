  body_markdown: "Yes it is possible you just need to be careful with the namespaces.\n\
    You will need two launch files : one to spawn a robot and one for the common configuration\
    \ and to call the other one.\nThe first one should be something like that :\n\n\
    **spawn.launch :**\n\n    <launch>\n    \n    \t<arg name=\"initial_pose_x\" default=\"\
    0.0\"/>\n    \t<arg name=\"initial_pose_y\" default=\"0.0\"/>\n    \t<arg name=\"\
    initial_pose_a\" default=\"0\"/>\n    \t<arg name=\"robot_name\" default=\"A_DEFAULT_NAME\"\
    />\n    \n    \t<!--  ******************** Robot Model ********************  -->\n\
    \    \t<param name=\"robot_description\" command=\"$(find xacro)/xacro --inorder\
    \ '$(find YOUR_PACKAGE_WITH_URDF_FILE)/urdf/$(arg robot_name).urdf'\"/>\n    \n\
    \    \t<node pkg=\"gazebo_ros\" type=\"spawn_model\" name=\"spawn_$(arg robot_name)\"\
    \ \n    \t\targs=\"-x $(arg initial_pose_x) -y $(arg initial_pose_y) -Y $(arg\
    \ initial_pose_a)\n    \t\t-unpause -urdf -param robot_description -model $(arg\
    \ robot_name)\" respawn=\"false\">\n    \t</node>\n    </launch>\n\nThen your\
    \ other launch file will start gazebo (and maybe rviz too if you want) and call\
    \ your other launch files in different namespaces (to allow make sure you have\
    \ different `cmd_vel` topics so that the three robots don't move the same).\n\n\
    **gazebo.launch :**\n\n    <launch>\n    \t<arg name=\"world_file\"     default=\"\
    YOUR_PATH_TO_A_WORLD_FILE\"/>\n    \t<arg name=\"gui\" default=\"true\"/>\n  \
    \  \t<arg name=\"initial_pose_x\" default=\"0.0\"/>\n    \t<arg name=\"initial_pose_y\"\
    \ default=\"0.0\"/>\n    \t<arg name=\"initial_pose_a\" default=\"0\"/>\n    \t\
    <arg name=\"robot_name\" default=\"A_DEFAULT_ROBOT_NAME\"/>\n    \t<param name=\"\
    /use_sim_time\" value=\"true\"/>\n    \n            <!--  ********************\
    \ Gazebo ********************  -->\n    \t<include file=\"$(find gazebo_ros)/launch/empty_world.launch\"\
    >\n    \t\t<arg name=\"use_sim_time\" value=\"true\"/>\n    \t\t<arg name=\"debug\"\
    \ value=\"false\"/>\n    \t\t<arg name=\"world_name\" value=\"$(arg world_file)\"\
    />\n    \t\t<arg name=\"gui\" value=\"$(arg gui)\"/>\n    \t</include>\n    \n\
    \n    <!-- Set different initial poses to avoid collision when spawning the model\
    \ -->\n    <group ns=\"THE_NAME_OF_FIRST_ROBOT\">\n    \t<include file=\"$(find\
    \ PACKAGE_WITH_SPAWN.LAUNCH)/launch/spawn.launch\">\n    \t\t<arg name=\"initial_pose_x\"\
    \ value=\"0.0\"/>\n    \t\t<arg name=\"robot_name\" value=\"THE_NAME_OF_FIRST_ROBOT\"\
    />\n    \n    \t</include>\t\n    </group>\n    \t\n    <group ns=\"THE_NAME_OF_SECOND_ROBOT\"\
    >\n    \t<include file=\"$(find PACKAGE_WITH_SPAWN.LAUNCH))/launch/spawn.launch\"\
    >\n    \t\t<arg name=\"initial_pose_x\" value=\"1.0\"/>\n    \t\t<arg name=\"\
    robot_name\" value=\"THE_NAME_OF_SECOND_ROBOT\"/>\n    \t</include>\n    </group>\
    \    \n\n    <group ns=\"THE_NAME_OF_THIRD_ROBOT\">\n    \t<include file=\"$(find\
    \ PACKAGE_WITH_SPAWN.LAUNCH))/launch/spawn.launch\">\n    \t\t<arg name=\"initial_pose_x\"\
    \ value=\"-1.0\"/>\n    \t\t<arg name=\"robot_name\" value=\"THE_NAME_OF_THIRD_ROBOT\"\
    />\n    \t</include>\n    </group>\n    \n    </launch>\n\nThat worked fine when\
    \ I tested it.\n\n**Note :**  From your question I assumed you had three different\
    \ robots (thus three different urdf files) but it is also possible to do the same\
    \ for three robots with the same urdf file, let me know if it's the case and I\
    \ will modify the launch files accordingly.\n"
