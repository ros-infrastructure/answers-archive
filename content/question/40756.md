  body_markdown: "[REP-0003](http://www.ros.org/reps/rep-0003.html) describes ROS\
    \ releases and for which Ubuntu distribution they are available. ROS releases\
    \ will probably get updated *at most* as long as their Ubuntu distribution [reaches\
    \ end-of-life](https://wiki.ubuntu.com/Releases). \n\nIn practice, once released\
    \ ROS versions will only get bug fixes, but there's no guaranteed date until that\
    \ happens. I would say it strongly depends on the stack maintainer. Bugfixes for\
    \ releases should at least be supplied as long as the current ROS release is the\
    \ latest one."
