  body_markdown: "You don't have the `controller_manager` package installed. \nAs\
    \ `ros_control` is not yet release for Jade, try to clone the `ros_control` repository\
    \ with `git clone https://github.com/ros-controls/ros_control.git -b jade_devel`\
    \ and try again.\n\nIf (when) it is release, you can install it using `sudo apt-get\
    \ install ros-jade-controller-manager'."
