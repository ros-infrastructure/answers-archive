  body_markdown: "While I dont know much about SolidWorks I will try help.\n\nYou\
    \ should have a tag known as a link (check for something like this in the exported\
    \ file)\n\n    <!-- Base Link -->\n      <link name=\"base_link\">\n        <visual>\n\
    \          <geometry>\n            <box size=\"1.91 0.680618 1.065022\"/>\n  \
    \        </geometry>\n          <material name=\"blue\"/>\n        </visual>\n\
    \        <collision>\n          <geometry>\n            <box size=\"1.91 0.680618\
    \ 1.065022\"/>\n          </geometry>\n        </collision>\n        <inertial>\n\
    \          <mass value=\"20.3\"/>\n          <inertia ixx=\"1.5\" ixy=\"0.0\"\
    \ ixz=\"0.0\" iyy=\"1.5\" iyz=\"0.0\" izz=\"1.5\"/>\n        </inertial>\n   \
    \   </link>\n\nYou will need to have links much like this for each of the components\
    \ on your robot i.e body, wheels, etc...\n\nNext you will joints. The purpose\
    \ of the joints tag is to describe how the components tie to each other. Look\
    \ for something in your exported file:\n\n    <joint name=\"left_steering_joint\"\
    \ type=\"revolute\">\n        <parent link=\"base_link\"/>\n        <child link=\"\
    left_steering_link\"/>\n        <axis xyz=\"0.0 0.0 0.1\"/>\n        <origin rpy=\"\
    0.0 0.0 0.0\" xyz=\"0.855 0.372059 -0.432511\"/>\n        <limit effort=\"100.00\"\
    \ lower=\"-0.30\" upper=\"0.30\" velocity=\"100.00\"/>\n      </joint>\n\nWhen\
    \ trying to use gazebo there is added complexity. You need transmissions. They\
    \ are to be included in your urdf file. You may not have those automatically with\
    \ the SolidWorks plugin. They should look something like this.\n\n    <transmission\
    \ name=\"left_steering_link_trans\">\n        <type>transmission_interface/SimpleTransmission</type>\n\
    \        <joint name=\"left_steering_joint\">\n          <hardwareInterface>hardware_interface/PositionJointInterface</hardwareInterface>\n\
    \        </joint>\n        <actuator name=\"left_steering_link_motor\">\n    \
    \      <hardwareInterface>hardware_interface/PositionJointInterface</hardwareInterface>\n\
    \          <mechanicalReduction>1</mechanicalReduction>\n        </actuator>\n\
    \      </transmission>\n\nYou will also need a yaml file to try and controll these\
    \ joints.\n\nThe yaml file might look something like this:\n\n    joint_state_controller:\n\
    \      type: joint_state_controller/JointStateController\n      publish_rate:\
    \ 50\n    \n      left_steering_link: left_steering_link\n      right_steering_link:\
    \ right_steering_link\n    \n      front_left_wheel: front_left_wheel\n      front_right_wheel:\
    \ front_right_wheel\n    \n      rear_left_wheel: rear_left_wheel\n      rear_right_wheel:\
    \ rear_right_wheel\n\nAnd finally you will to implement all of this in a launch\
    \ file:\n\n    <?xml version=\"1.0\"?>\n    <launch>\n    \n        <arg name=\"\
    namespace\" default=\"/ursa_bot\" />\n        <arg name=\"world_name\" default=\"\
    worlds/empty_world\" />\n        <arg name=\"cmd_timeout\" default=\"0.5\"/>\n\
    \        <arg name=\"x\" default=\"0.0\"/>\n        <arg name=\"y\" default=\"\
    0.0\"/>\n        <arg name=\"z\" default=\"1.0\" />\n        <arg name=\"roll\"\
    \ default=\"0.0\"/>\n        <arg name=\"pitch\" default=\"0.0\"/>\n        <arg\
    \ name=\"yaw\" default=\"0.0\"/>\n    \n        <group ns=\"$(arg namespace)\"\
    >\n    \n            <include file=\"$(find gazebo_ros)/launch/empty_world.launch\"\
    >\n                <arg name=\"world_name\" default=\"$(arg world_name)\"/>\n\
    \            </include>\n    \n    \n    \n            <rosparam file=\"$(find\
    \ ursa_bot_ctrl)/config/joint_states.yaml\" command=\"load\" ns=\"/ursa_bot\"\
    \ />\n            <rosparam file=\"$(find ursa_bot_ctrl)/config/mobile_base.yaml\"\
    \ command=\"load\" ns=\"/ursa_bot\" />\n            <rosparam file=\"$(find ursa_bot_ctrl)/config/ursa_bot_gazebo.yaml\"\
    \ command=\"load\" ns=\"/ursa_bot\" />\n            <rosparam file=\"$(find ursa_bot_ctrl)/config/pids.yaml\"\
    \ command=\"load\" ns=\"/ursa_bot\" />\n    \n    \n            <!-- Loading the\
    \ Ursa Bot into Gazebo -->\n            <param name=\"robot_description\" command=\"\
    $(find xacro)/xacro $(find ursa_bot_description)/urdf/ursa_bot_basic.urdf.xacro\"\
    />\n            <node name=\"spawn_vehicle\" pkg=\"gazebo_ros\" type=\"spawn_model\"\
    \ args=\"-urdf -param robot_description -model ursa_bot\n                    -gazebo_namespace\
    \ /$(arg namespace)/gazebo\n                    -x $(arg x) -y $(arg y) -z $(arg\
    \ z)\n                    -R $(arg roll) -P $(arg pitch) -Y $(arg yaw)\"/>\n \
    \   \n            <!-- Standard Publisher Bullshit here -->\n            <node\
    \ name=\"joint_state_publisher\" pkg=\"joint_state_publisher\" type=\"joint_state_publisher\"\
    \ />\n            <node name=\"robot_state_publisher\" pkg=\"robot_state_publisher\"\
    \ type=\"robot_state_publisher\">\n                <param name=\"publish_frequency\"\
    \ value=\"30.0\"/>\n            </node>\n    \n            <node pkg=\"controller_manager\"\
    \ type=\"spawner\" name=\"controller_spawner\" ns=\"/ursa_bot\" args=\"joint_state_controller\
    \ ackermann_steering_bot_controller ackermann_steering_bot_hw_sim\" output=\"\
    screen\" respawn=\"false\" />\n    \n        </group>\n    \n    \n    </launch>\n\
    \nWhile this is not a complete tutorial, and surely doesn't exactly relate to\
    \ your model I hope it helps. You will more than likely need to add some edits\
    \ to the exported URDF file and make a couple additional files for a full implementation.\
