  body_markdown: "As pointed out in tutorial CreatingMsgAndSrv for message/service\
    \ generation with catkin you need to:\n\n - Add to package.xml:\n\n   `<build_depend>message_generation</build_depend>`<br/>\n\
    \   `<run_depend>message_runtime</run_depend>`\n\n - Add message_generation in\
    \ CMakeLists.txt as REQUIRED catkin component (like any package, e. g. roscpp):<br/>\n\
    \n   `find_package( catkin REQUIRED COMPONENTS roscpp message_generation )`\n\n\
    \ - uncomment add_message_files in CMakelists.txt and add your msg files with\
    \ messages to be generated:<br/>\n\n    `add_message_files(\n      FILES\n   \
    \   my_message.msg\n    )`\n\n - uncomment add_service_files in CMakelists.txt\
    \ and add your srv files with services to be generated:<br/>\n\n    `add_service_files(\n\
    \      FILES\n      beginner_tutorials.srv\n    )`\n\n - uncomment generate_messages\
    \ in CMakeLists.txt with packages containing msgs depending on: <br/>\n\n  `generate_messages(\n\
    \  DEPENDENCIES\n  std_msgs \n)`\n\n - in CMakeLists.txt add ${PROJECT_NAME}_generate_messages_cpp\
    \ as dependency of your target that required the message to be generated before\
    \ being compiled (in C++, I am not sure if is also necessary for python)\n\n \
    \ `add_executable( foo_exec src/foo.cpp)`<br/>\n`target_link_libraries( foo_exec\
    \ ${catkin_LIBRARIES} )`<br/>\n`add_dependencies( foo_exec ${PROJECT_NAME}_generate_messages_cpp\
    \ )`"
