  body_markdown: "There are three ways to run a nodelet:\n\n1. Run the nodelet standalone\
    \ using `roslaunch`:\n\n        <launch>\n            <node name=\"my_nodelet\"\
    \ pkg=\"nodelet\" type=\"nodelet\" args=\"standalone tegra_stereo/TegraStereoProc\"\
    \ />\n        </launch>\n\n     or `rosrun`:\n\n        rosrun nodelet nodelet\
    \ standalone tegra_stereo/TegraStereoProc\n\n2. Run the nodelet as part of a nodelet\
    \ manager. This is described on the ROS wiki here: http://wiki.ros.org/nodelet/Tutorials/Running%20a%20nodelet\n\
    3. Write a node wrapper, and then build and run it as you would a node. Here's\
    \ what node wrapper code typically looks like:\n\n        #include <ros/ros.h>\n\
    \        #include <nodelet/loader.h>\n        \n        int main(int argc, char\
    \ **argv){\n          ros::init(argc, argv, \"tegra_stereo_node\");\n        \n\
    \          nodelet::Loader nodelet;\n          nodelet::M_string remap(ros::names::getRemappings());\n\
    \          nodelet::V_string nargv;\n          std::string nodelet_name = ros::this_node::getName();\n\
    \          nodelet.load(nodelet_name, \"tegra_stereo/TegraStereoProc\", remap,\
    \ nargv);\n          ros::spin();\n        \n          return 0;\n        }\n\
    \          \n\nIf any of these methods fail with an error message that pluginlib\
    \ can't find your nodelet, make sure that you defined your nodelet in an XML file\
    \ and exported it in your `package.xml`. Instructions to do so are on the ROS\
    \ wiki here: http://wiki.ros.org/nodelet/Tutorials/Porting%20nodes%20to%20nodelets\n\
    \n**Bonus Methods**\n\nIf you're willing to install another package, Southwest\
    \ Research Institute created `swri_nodelet` to make some of these tasks easier.\n\
    \n1. Run the nodelet standalone using `roslaunch`:\n\n        <launch>\n     \
    \       <node name=\"my_nodelet\" pkg=\"swri_nodelet\" type=\"nodelet\" args=\"\
    tegra_stereo/TegraStereoProc standalone\" />\n        </launch>\n\n     or `rosrun`:\n\
    \n        rosrun swri_nodelet nodelet  tegra_stereo/TegraStereoProc standalone\n\
    \n2. Run the nodelet with a nodelet manager using `roslaunch`:\n\n        <launch>\n\
    \          <node name=\"manager\" pkg=\"nodelet\" type=\"nodelet\" args=\"manager\"\
    \ />\n          <node name=\"my_nodelet\" pkg=\"swri_nodelet\" type=\"nodelet\"\
    \ args=\"tegra_stereo/TegraStereoProc my_manager\"/>\n        </launch>\n\n  \
    \  (Note that this syntax makes it easy to switch launch files back and forth\
    \ between manager and standalone using args.)\n\n3. Automatically create a node\
    \ wrapper using `swri_nodelet`. This takes a couple of steps but saves you from\
    \ writing boilerplate C++. Also, because it links the nodelet with the executable\
    \ at compile time, you catch linker errors at compile time, instead of dealing\
    \ with inscrutable runtime errors. Here's how to do it:\n\n    In your nodelet's\
    \ C++ file, replace the pluginlib macro with this:\n\n        #include <swri_nodelet/class_list_macros.h>\n\
    \        SWRI_NODELET_EXPORT_CLASS(tegra_stereo TegraStereoProc)\n\n    In your\
    \ CMakeList, build your library and add a nodelet executable like this:\n\n  \
    \      # (Add swri_nodelet to your find_package(catkin)\n        \n        add_library(my_nodelet_library\
    \ src/TegraStereoProc.cpp)\n        target_link_libraries(my_nodelet_library ${CATKIN_LIBRARIES})\n\
    \        \n        swri_nodelet_add_node(tegra_stereo_proc tegra_stereo TegraStereoProc)\n\
    \        target_link_libraries(tegra_stereo_proc my_nodelet_library)"
