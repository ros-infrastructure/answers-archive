  body_markdown: "The problem seems to be related with me using g++ and gcc < 5.0\
    \ as the default, while completely removing g++ and gcc > 5.0 (5.4 in my case)\
    \ from the priority list with the `update-alternatives` utility. \n\nAfter setting\
    \ up a fresh VirtualBox Machine everything worked out fine and I was able to reproduce\
    \ the behavior on my real Ubuntu 16.04 install - where the same default compiler\
    \ settings were made. \n\nAs a bonus I was then able to compile the V-REP RosInterface\
    \ and use it without producing segmentation faults. So the issue is most probable\
    \ related to the ROS Part of the process. \n\nI guess Simulink / Matlab will have\
    \ to live with the fact that the default compiler is not supported, at least they\
    \ can fallback to the older versions after producing some error messages."
