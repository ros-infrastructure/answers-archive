  body_markdown: "There was an issue with it not finding the correct path to the config.rviz\
    \ file. I realized it when it worked in a terminal window that was in the package\
    \ directory but not in one where it was not.  Adding a launchfile that specifies\
    \ the location of the file as a parameter fixes this problem.  \n\n    \t\timport\
    \ rospkg\nand in the init for the class we have\n\n\n\t\treader = rviz.YamlConfigReader()\n\
    \t\tconfig = rviz.Config()\n\n\t# We use rospack to find the filepath for the\
    \ package using rviz.\n\t\trospack = rospkg.RosPack()\n\t\tpackage_path = rospack.get_path('demo')\n\
    \t#Now you can grab this filepath from either roslaunch and using the launch file\
    \ or just rosrun with the file in a config folder\n\t\tconfig_file = rospy.get_param('demo/rviz_config',\
    \ package_path + \"/config/myConfig.rviz\")\n\t\treader.readFile( config, config_file\
    \ )\n\t\tself.frame.load( config )\n\n"
