    \ missing from the laser scan message:\n\n    angle_min: 0.0\n    angle_max: 0.0\n\
    \    angle_increment: 0.0\n\nWithout these values the ranges cannot be converted\
    \ to cartesian points, so the scan cannot be shown. \n\nThe tf motor output is\
    \ what we would expect, it is only concerned with the relationship between different\
    \ frames, if you're only using one frame as you are then you don't need any transforms.\n\
    \nFinally, are you sure there isn't a typo (even an extra space at the end) of\
    \ the RVIZ fixed frame. I can't see why you'd be getting a TF error if your scan\
    \ frame_id is the same as the fixed frame. \n\nHope this helps. "
