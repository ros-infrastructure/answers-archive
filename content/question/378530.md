 Hi all,

I have followed this tutorial: https://docs.ros.org/en/foxy/Tutorials/Quality-of-Service.html

When I use the Linux network traffic control utility, tc (http://linux.die.net/man/8/tc) to simulate 5% packet loss on Fast RTPS, both publisher and subscriber have not slowed down the rate at which images are transmitted.

    sudo tc qdisc add dev lo root netem loss 5%

However, when I switch to Cyclone DDS, I can see the decreasing rate in image transmission.

    export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp

In the tutorial, there is a warning: "This section of the demo won’t work on RTI’s Connext DDS. When running multiple nodes in the same host, the RTI Connext implementation uses shared memory along with the loopback interface. Degrading the loopback interface throughput won’t affect shared memory, thus traffic between the two nodes won’t be affected.", which is not mentioned Fast RTPS.

I have found that eprosima Fast DDS (formerly Fast RTPS) comes with five transports already implemented: https://fast-dds.docs.eprosima.com/en/latest/fastdds/transport/transport.html. One of them is SHM: Shared memory communication that RTI's Context DDS also has.

So I have tried to force Fast RTPS to use UDPv4 transport layer and get rid of SHM by creating and applying this XML profile but got the same result: the transmission of images has not slowed down.

    <?xml version="1.0" encoding="UTF-8" ?>
    <profiles xmlns="http://www.eprosima.com/XMLSchemas/fastRTPS_Profiles">
        <transport_descriptors>
            <transport_descriptor>
                <transport_id>udp_transport</transport_id>
                <type>UDPv4</type>     
                <non_blocking_send>true</non_blocking_send>
            </transport_descriptor>
        </transport_descriptors>
    
        <participant profile_name="UDPParticipant" is_default_profile="true">
            <rtps>
                <userTransports>
                    <transport_id>udp_transport</transport_id>
                </userTransports>
                <useBuiltinTransports>false</useBuiltinTransports>
            </rtps>
        </participant>
        
       <data_writer profile_name="data_writer_historyMemoryPolicy" is_default_profile="true">
            <historyMemoryPolicy>PREALLOCATED_WITH_REALLOC</historyMemoryPolicy>
       </data_writer>
    
       <data_reader profile_name="data_reader_historyMemoryPolicy" is_default_profile="true">
            <historyMemoryPolicy>PREALLOCATED_WITH_REALLOC</historyMemoryPolicy>
       </data_reader>
    </profiles>

My environment:

OS system: Ubuntu 20.04.2 LTS

ROS version: foxy

ROS installed from source

Fast RTPS 2.0.2

I want to use Fast RTPS and find a way to simulate packet loss on it.

Please help me! Thank you!
