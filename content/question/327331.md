  body_markdown: "The error itself is telling you that the linux linker cannot found\
    \ `libcaffe.so`.\n\n`/lib/vision_ssd_detect/vision_ssd_detect: error while loading\
    \ shared libraries: libcaffe.so.1.0.0-rc3`\n\nYou'll need to either\n1. add the\
    \ path where that `.so` file is located to the `LD_LIBRARY_PATH`, or \n2. \"install\"\
    \ or move caffe headers/libraries to the system path, and update the libraries\
    \ cache.\n\nSupponsing you cloned Caffe to `/home/YOUR_USER/caffe/`\n\nIf you\
    \ go for 1.\n`$ export LD_LIBRARY_PATH=/home/YOUR_USER/caffe/distribute/lib:$LD_LIBRARY_PATH`\n\
    \nIf you prefer 2.\n`$ cd /home/YOUR_USER/caffe && sudo make install && sudo ldconfig`\n\
    \nThen you should be able to run the node."
