    \ \n\nhttps://arxiv.org/pdf/1411.1086.pdf\n\n\"The generation of the merged laser\
    \ scan follows an initial phase in which\nall the laser scans to be merged are\
    \ flattened to a single plane, which is the\nscanning plane of the destination\
    \ (merged) laser scan. As a consequence,\nobjects that would not be observable\
    \ in the destination (merged) laser\nscan, but that are in some of the input scans,\
    \ will (wrongly) appear in the\nfinal merged scan\"\n\nSo you might need to process\
    \ the data, and decide how probable there is an obstacle, maybe, use 5 sampling\
    \ before making a decision."
