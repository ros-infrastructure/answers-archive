  body_markdown: "Led by [a similar issue](https://github.com/nestybox/sysbox/issues/383),\
    \ I mounted the `/dev` folder of the Docker host inside the container and, as\
    \ if by **miracle**, Ignition Fortress loaded with no black screen.\n\nI then\
    \ compared the logs of when it worked and when it didn't, and I found the following\
    \ error message when it does not work:\n\n    MESA: error: Failed to query drm\
    \ device.\n    libGL error: glx: failed to create dri3 screen\n    libGL error:\
    \ failed to load driver: crocus\n    libGL error: failed to open /dev/dri/card0:\
    \ No such file or directory\n    libGL error: failed to load driver: i965 \n\n\
    Then, instead of mounting the whole `/dev` inside the container, I mounted only\
    \ the `/dev/dri` folder and everything worked just nice.\n\nAwesome!!!\n\nBelow\
    \ is the `docker-compose.yaml` file used for testing:\n\n    version: '3'\n  \
    \  \n    services:\n      fortress:\n        image: my-docker-image/with-ignition:fortress\
    \  # Put your image name here\n        container_name: fortress\n        network_mode:\
    \ host\n        environment:\n          - DISPLAY=:0\n        volumes:\n     \
    \     - /tmp/.X11-unix:/tmp/.X11-unix\n          - /dev/dri:/dev/dri\n       \
    \ entrypoint: [ \"/bin/bash\", \"-c\" ]\n        command:\n          - ign gazebo\
    \ shapes.sdf -v4\n\n\n\nOf course, before running `docker-compose up`, I had to\
    \ run ` xhost +local:root` to make the Graphical apps from the docker container\
    \ appear on my desktop.\n\nIt is worth mentioning that sharing `/dev/dri` worked\
    \ on my local computer. When trying the same on AWS, the black screen was still\
    \ there.\n\n# On AWS with OpenGL 3.3 and Ogre1\n\nIn order to make it work on\
    \ AWS, I had to:\n\n* Keep OpenGL 3.3\n* Use the `--render-engine ogre` param\
    \ to force Ignition to use `Ogre 1`, following instructions on ignition [troubleshooting](https://gazebosim.org/docs/fortress/troubleshooting#unable-to-create-the-rendering-window)\
    \ \n\n# On AWS with Ogre2 and OpenGL 4.5\n\nTo make it work with Ogre2 `--render-engine\
    \ ogre2`, I had to compile it from the source after **disabling Anti-Aliasing**.\n\
    \nThe steps were detailed on [this issue](https://github.com/gazebosim/gz-sim/issues/1116#issuecomment-1142388038)\n\
    \nI first upgraded OpenGL using [these instructions](https://ubuntuhandbook.org/index.php/2021/07/install-latest-mesa-ubuntu-20-04-21-04/):\n\
