  body_markdown: "The issue is your use of whitespace in the Python launch file. Python\
    \ cares about whitespace.\n\nI believe what is happening is that the class `launch.LaunchDescription`\
    \ is being returned instead of an object instance. To fix your file, move the\
    \ opening parenthesis for the LaunchDescription constructor next to the type name.\
    \ It's probably best to do this for the Node as well:\n\n    def generate_launch_description():\n\
    \        return launch.LaunchDescription(\n            [\n                launch_ros.actions.Node(\n\
    \                    package='simple_test', \n                    node_executable='my_test',\n\
    \                    output='screen'\n                )\n            ]\n     \
    \   )\n\nGenerally, I'd recommend following the Python style guide, [PEP 8](https://www.python.org/dev/peps/pep-0008/),\
    \ when writing your launch files.\n"
