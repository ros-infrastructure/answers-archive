  body_markdown: "You have both a syntax error and a bug in your message definition.\
    \ To catch syntax errors, it's useful to run the JavaScript error console your\
    \ web browser provides.\n\n    var str = new ROSLIB.Message({\n      a:'hello'\n\
    \    });\n\nThe syntax error is that you are missing brackets `{` `}` around the\
    \ message data. \n\nSecondly, you have defined your message type as `std_msgs/String`\
    \ which does not have a field called `a` (see http://ros.org/doc/api/std_msgs/html/msg/String.html).\
    \ Instead, the field is called `data`:\n\n    var str = new ROSLIB.Message({\n\
    \      data : 'hello'\n    });\n\nWith the above change, everything should work.\n\
    \nTo publish an `std_msgs/Int16` message, simply change your data type:\n\n  \
    \  var testInt = new ROSLIB.Topic({\n      ros : ros,\n      name : '/ints',\n\
    \      messageType : 'std_msgs/Int16'\n    });\n    \n    var int = new ROSLIB.Message({\n\
    \      data : 5\n    });\n\n    testInt.publish(int);\n"
