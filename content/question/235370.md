  body_markdown: "The rosout topic allows you to see what's happening in nodes that\
    \ are running remotely and you potentially don't have access to the console. You\
    \ can launch the rqt plugin rqt_console http://wiki.ros.org/rqt_console to view\
    \ outputs. \n\nrqt_logger_level will let you set the logging level remotely as\
    \ well. : http://wiki.ros.org/rqt_logger_level \n\nThus you can make all the console\
    \ outputs available for debugging on any computer connected to the robot. Which\
    \ is very convenient when you want to connect your robot and debug from a laptop."
