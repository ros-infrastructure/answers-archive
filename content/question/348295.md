  body_markdown: "As discussed [here](https://stackoverflow.com/questions/52911986/difficulty-including-the-extra-intellisense-paths-in-the-python-linters-scope),\
    \ the following is needed:\n\n 1. Place your module in `<ws>/src/<pkg-name>/src/<pkg-name>`\n\
    \ 2. Create an empty file `<ws>/src/<pkg-name>/src/<pkg-name>/__init__.py`\n 3.\
    \ Create `<ws>/src/<pkg-name>/setup.py` with <pre><code>\n\n    from distutils.core\
    \ import setup\n    from catkin_pkg.python_setup import generate_distutils_setup\n\
    \    \n    setup_args = generate_distutils_setup()\n    setup_args['packages']\
    \ = ['<pkg-name>']\n    setup_args['package_dir'] = {'': 'src'}\n    \n    setup(**setup_args)\n\
    </pre></code>\n 4. Add `catkin_python_setup()` to `<ws>/src/<pkg-name>/CMakeLists.txt`\n\
    \ 5. Build workspace with `catkin_make`\n 6. Open `<ws>` in VS Code with ROS and\
    \ Pylint extensions installed\n 7. Add `src/<pkg-name>/src` to `\"python.autoComplete.extraPaths\"\
    ` in `<ws>/.vscode/settings.json`\n\nYou can then `from <pkg-name>.<module-name>\
    \ import <your-content>` from any node script (e.g. `<ws>/src/<pkg-name>/scripts/mynode`)"
