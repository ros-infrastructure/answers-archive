    The openni_camera package is really just a ROS wrapper around the openni libraries -- it doesn't actually provide the C++ functionality required to access the camera -- which I presume is what you are doing?

    Now, the package you want to install is libopenni-dev which should not remove your turtlebot packages (openni-dev is the older version, which is incompatible with many things). How to know the package is libopenni-dev? The package.xml for openni_camera specifies a dependency on libopenni-dev, which you can then look up in the rosdep yaml files.
