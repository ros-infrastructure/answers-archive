  body_markdown: "You've got a good start.  The right way to do this is to create\
    \ custom ROS messages for both the \"struct\" and the \"array of structs\".  In\
    \ the ROS .msg format, an undefined-length array is defined using the `int[] intArray`\
    \ syntax (with no size in the array-brackets).\n\nThe specifics of how arrays\
    \ are handled in ROS messages are described on [this](http://www.ros.org/wiki/msg)\
    \ wiki page.  In particular, the \"array handling\" section shows that variable-length\
    \ arrays are interpreted as `std::vector` in roscpp (C++).\n\nAs an example, see\
    \ the Joint Trajectory Action [tutorial](http://ros.org/wiki/pr2_controllers/Tutorials/Moving%20the%20arm%20using%20the%20Joint%20Trajectory%20Action).\
    \  In the `armExtensionTrajectory` function, the example builds up the `goal.trajectory`\
    \ message, which is of type [JointTrajectory](http://ros.org/doc/groovy/api/trajectory_msgs/html/msg/JointTrajectory.html)\
    \ and contains a variable-length array of [JointTrajectoryPoint](http://ros.org/doc/groovy/api/trajectory_msgs/html/msg/JointTrajectoryPoint.html)s.\
    \  As you can see, the variable-length array is built using the usual C++ `std::vector`\
    \ methods (`push_back`, `resize`, etc.).\n\nHere's a more specific example to\
    \ address your case above *(it's untested, so forgive any typos)*:\n\n    ---------------------------------------\n\
    \    imgData.msg\n      int32 upperLeft\n      int32 lowerRight\n      string\
    \ color\n      string cameraID\n\n    ---------------------------------------\n\
    \    imgDataArray.msg\n      imgData[] images\n\n    ---------------------------------------\n\
    \    demo_pub.cpp\n      ros::Publisher pub = n.advertise<my_pkg::imgDataArray>(\"\
    test\", 1000);\n\n      my_pkg::imgData data;\n      my_pkg::imgDataArray msg;\n\
    \      \n      data.upperleft=0; data.lowerRight=100; data.color=\"red\"; data.cameraID=\"\
    one\";\n      msg.images.push_back(data);\n      data.upperleft=1; data.lowerRight=101;\
    \ data.color=\"blue\"; data.cameraID=\"two\";\n      msg.images.push_back(data);\n\
    \n      pub.publish(msg);\n\n    ---------------------------------------\n   \
    \ demo_sub.cpp\n      void subCB(const my_pkg::imgDataArray::ConstPtr& msg)\n\
    \      {\n        for (int i=0; i<msg->images.size; ++i)\n        {\n        \
    \  const my_pkg::imgData &data = msg->images[i];\n          ROS_INFO_STREAM(\"\
    UL: \" << data.upperleft << \"UR: \" << data.upperright <<\n                 \
    \         \"color: \" << data.color << \"ID: \" << data.cameraID);\n        }\n\
    \      }\n      \n      int main(int argc, char **argv)\n      {\n        ...\n\
    \        ros::Subscriber sub = n.subscribe(\"test\", 1000, subCB);\n        ros::spin();\n\
    \      }"
