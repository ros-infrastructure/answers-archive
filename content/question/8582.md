    Links in a model can move with respect to each other unless you constrain the motion. If you don't want the links to move with respect to each other, you could create a fixed joint between them (a joint with joint limits equal to 0), but that's not recommended.

    If you want two different visual representations and collisions to stay fixed to each other at all times, you probably want to create one link with multiple visuals/collisions like this:

        <model>
          <link>
            <visual>...</visual>
            <collision>...</collision>
            <visual>...</visual>
            <collision>...</collision>
          </link>
        </model>

    Each `<link>` corresponds to a separate rigid body with its own inertial properties. If the thrusters are rigidly attached to your AUV, I would recommend using a single link and specifying thruster location in another manner, perhaps with `<collision>` elements for each one as @chapulina suggested.

    We don't currently have an `<actuator>` element, which would potentially be a nice thing for your use case.

upvote_count: 0

I assumed that

    <model>
       <link ... />
       <link ... />
    </model>

would create two links, rigidly connected to the model (that's the only way this construct makes sense to me ...). However, it seems that the first is connected to the model, but not the second (it is in freefall). Is that really the expected behaviour ?

**UPDATE**: here's my use case

I model an AUV, which has a bunch of thrusters. For that, we create a gazebo plugin that allow us to apply a force in the position and direction defined by some links in the model (the thruster's frame of reference). However, I obviously want the links to be rigidly attached to th e model.

The SDF currently looks like this. The addition of fixed joints for each link will obviously be a horrible pain. I could of course auto-add the joints in the plugin itself, but that also sounds hacky.
 
    <link name='thruster::left'>
      <pose>0 0.2 0 0 0 0</pose>
    </link>
    <link name='thruster::right'>
      <pose>0 -0.2 0 0 0 0</pose>
    </link>
    <link name='thruster::dive'>
      <pose>0 0 0 0 1.57 0</pose>
    </link>
    <!-- the plugin consider all links named thruster::NAME -->
    <plugin name='thrusters' filename='libgazebo_thruster.so'/>
