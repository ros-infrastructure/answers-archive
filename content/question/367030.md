      It is usually best practice to use `rosrun` [remap arguments](http://wiki.ros.org/Remapping%20Arguments) or a launch file with the `remap` [tag](http://wiki.ros.org/roslaunch/XML/remap) to specify topic/service/action connections, instead of hardcoding the value in source code.


      If your service client is setup using the following:

          ros::ServiceClient client = n.serviceClient<ifm3d::Trigger>("Trigger");

      You can reamp using rosrun:

          rosrun <your_package> <your_node> Trigger:=/ifm3d/camera/Trigger
