- body_markdown: "It's hard to help without more info. AMCL requires at least reasonable\
    \ accuracy from ODOM and the laser. I can see in the photo the robot has to work\
    \ on different surfaces. If ODOM accuracy is poor on one of the surfaces, you\
    \ could adjust ODOM tuning to work better on that surface. \n\nAMCL can also only\
    \ adapt to small position errors and it runs a scan based on changes in ODOM,\
    \ so if the ODOM is reporting small changes when there are actually large changes\
    \ in position, AMCL can quickly fail like I see in the photo. Set AMCL to scan\
    \ with smaller changes to ODOM.\n\nIt may also end being required to change HW.\
    \ If the wheels on the robot really can't be made to work on the carpet, no amount\
    \ of SW will fix it. Also, maybe the frame of the robot is dragging on the carpet\
    \ and the wheels are spinning. What have you tried? Does it work if the carpet\
    \ is removed? We could help more with more information."
