    As others have reported lately, rviz does not usually work well in a
    virtual machine. It seems to need access to real 3D graphics hardware
    for adequate performance.

    The usual workaround is installing Ubuntu in a separate partition with
    dual boot.

  body_markdown: "I have had better success using Parallels for RVIZ.  Parallels supports\
    \ OpenGL acceleration in the virtual machine, and has worked with RVIZ in the\
    \ past.\n\nOn older versions of Parallels (5), there was a slight workaround because\
    \ Parallels Tools didn't get OpenGL properly working.  I believe that it was due\
    \ to a library being incorrectly installed.  This workaround only works if you\
    \ currently have NO openGL acceleration (For example, Compiz doesn't work).\n\n\
    \ 1. Open terminal: sudo gedit /etc/ld.so.conf.d/GL.conf \n 2. In Gedit: delete\
    \ \"mesa\"\n 3. Line should read: /usr/lib/\n 4. Save and Close\n 5. Reboot"
