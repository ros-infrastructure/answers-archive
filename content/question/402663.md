Hi, 
System: ROS Melodic, Ubuntu 18.04
I am trying to create a custom inverse kinematics library for my robot arm (scara-like: a prismatic joint and planar 3 revolute joints) and load it into MoveIt using the pluginlib library. The repository containing my library is available [here](https://github.com/ashBabu/moveit_kinematics_plugin). Briefly the steps are

 * Created a  `TestKinematicsPlugin` class which extends `kinematics::KinematicsBase`
 * Implemented the methods `initialize()`, `getPositionIK()` and  `searchPositionIK()`. Basically these are adapted from [SrvKinematicsPlugin](https://github.com/ros-planning/moveit/blob/master/moveit_kinematics/srv_kinematics_plugin/src/srv_kinematics_plugin.cpp), [KDL](https://github.com/ros-planning/moveit/blob/master/moveit_kinematics/kdl_kinematics_plugin/src/kdl_kinematics_plugin.cpp) and an IKFast kinematics plugin.
 * The `getPositionIK` returns the `searchPositionIK` which calls one of my custom IK solver `bool getIKSolutions()`. This arm produces multiple solutions and I find the distance from the ik_seed_state to produce the solution nearest to the ik_seed_state.
 * Added `export` tag for the pluginlib export in `package.xml`, created a `plugin_description.xml` and modified the `CMakeLists.txt` to add this as a library
 * Modified the `arm_config_pkg-->kinematics.yaml` and added the `kinematic_solver:analytic/InHouseKinematicsPlugin`
 * Removed `build` and `devel` and did `catkin_make`

The `main()` is added as a [test](https://github.com/ashBabu/moveit_kinematics_plugin/blob/master/test/analytic_ik_test.cpp). The following is my terminal output
![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/16558332254900599.png)

I find that the constructor of `TestKinematicsPlugin()` is invoked three times with a `SEVERE WARNING` msg. It's definitely going inside the `initialize()` as seen from the console.

Any help to get it working would be really appreciated.
Thanks

Edit 2:
In the screen shot above, you can see the `Solution: 0.225, -1.5539, -0.584145, 1.44739`. This is actually achieved by doing `solutions.push_back({q1, q2, q3, q4})`. When I changed this to `solutions.push_back({q4, q3, q2, q1})`, everything started working as I expected. 
A blog describing my experience is available [here](https://ashbabu.github.io/blog/2022/Custom_Inverse_Kinematics_MoveIt_Plugin/)
