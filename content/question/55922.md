  body_markdown: "Hi Paulo\n\nThe following code worked for me in implementing a ServiceClient\
    \ in Android. Note that HMMv2/get_Joint_State.srv is a custom service of mine.\n\
    \nIn the OnStart(ConnectedNode node) method (but before you implement a cancellable\
    \ loop:\n\n    final ServiceClient<HMMv2.get_Joint_StateRequest, HMMv2.get_Joint_StateResponse>\
    \ client;\n    \t      \n    \t      \n    \t\t\ttry \n    \t\t\t{\n    \t\t\t\
    \tclient = node.newServiceClient(\"HMMv2Cont/JointState\", HMMv2.get_Joint_State._TYPE);\n\
    \    \t\t\t\n    \t\t\t} \n    \t\t\tcatch (ServiceNotFoundException e) \n   \
    \ \t\t\t{\n    \t\t\t\t// TODO Auto-generated catch block\n    \t\t\t\te.printStackTrace();\n\
    \    \t\t\t\tthrow new RosRuntimeException(e);\n    \t\t\t}\n    \t\t\n    \t\t\
    \tfinal HMMv2.get_Joint_StateRequest request=client.newMessage();\n    \t\t\t\
    \  \n    \t\t\trequest.setJointName(\"joints\");\n\nThen in the Cancellable loop,\
    \ loop() function the code to call the service is:\n\n    client.call(request,\
    \ new ServiceResponseListener<HMMv2.get_Joint_StateResponse>()    {\n\n      \
    \  \t\t\t\t\t\t\t@Override\n\t\t\t\t\t\t\t\tpublic void onFailure(RemoteException\
    \ arg0) \n\t\t\t\t\t\t\t\t{\n\t\t\t\t\t\t\t\t\tLog.d(\"Jointrequest Client\",\
    \ \"failed to call service\");\n\t\t\t\t\t\t\t\t\tthrow new RosRuntimeException(arg0);\n\
    \t\t\t\t\t\t\t\t\t// TODO Auto-generated method stub\n\n\t\t\t\t\t\t\t\t}\n\n\t\
    \t\t\t\t\t\t\t@Override\n\t\t\t\t\t\t\t\tpublic void onSuccess(HMMv2.get_Joint_StateResponse\
    \ message) \n\t\t\t\t\t\t\t\t{\n                                             \
    \                  //do something with the response\n\t\t\t\t\t\t\t\t\thPos.set(0,\
    \ 0, (message.getJointState().getPosition()[0]-512)*Math.PI/512);\t\t\t\t\n\t\t\
    \t\t\t\t\t\t\n\n\n\t\t\t\t\t\t\t\t}\n\n\t\t\t\t\t\t\t\t\t});\n\nhope this example\
    \ helps you. I think the main issue I found in implementing this was the declaration\
    \ of a final ServiceClient types. But I've used this format a couple of times\
    \ and it works. \n\ncheers\nPeter"
