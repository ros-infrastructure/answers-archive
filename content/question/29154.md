  body_markdown: "Refer to this [link](http://ompl.kavrakilab.org/core/genericPlanning.html).\
    \ There you 'll find some guidelines regarding setting state space/bounds, using\
    \ existing planners in ompl, setting start/goal states and find solution.\n\n\
    These are the following steps basically(for example SE2):-\n\n//1. construct the\
    \ instance of state space we are planning in->for mobile base SE2\n \n\n    ompl::base::StateSpacePtr\
    \ space(new ompl::base::SE2StateSpace());\n\n//2. get bounds from worldmap and\
    \ set it to bounds for the planner\n\n    ompl::base::RealVectorBounds bounds(2);\n\
    \    space->as<ompl::base::SE2StateSpace>()->setBounds(bounds);\n\n//3. Create\
    \ an instance of ompl::geometric::SimpleSetup\n\n    ompl::geometric::SimpleSetup\
    \ simple_setup(space);\n\n//4. Set state validity checker\n\n    simple_setup.setStateValidityChecker(boost::bind(&Function_Name,\
    \ this, _1));\n\n//7. set start and goal state to planner\n\n    simple_setup.setStartAndGoalStates(ompl_scoped_state_start,\
    \ ompl_scoped_state_goal);\n\n//8 Set Planner type\n\n    ompl::base::SpaceInformationPtr\
    \ si_ptr = simple_setup.getSpaceInformation();\n    ompl::base::PlannerPtr target_planner_ptr(new\
    \ ompl::geometric::EST(si_ptr));\n    simple_setup.setPlanner(target_planner_ptr);\n\
    \n//9. Solve\n\n    simple_setup.solve(1.0);\n\n\nHope this helps."
