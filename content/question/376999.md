  body_markdown: "I had a similar issue as well. If I understand your question correctly,\
    \ you want the planning scene topic to be published at a higher frequency.\nI\
    \ solved it by changing the parameter \"publish_planning_scene_hz\" in the \"\
    move_group\" node .\nIt was set to 4Hz by default. \n\nYou can do this from the\
    \ command line using:\n\n> ros2 param set /move_group publish_planning_scene_hz\
    \ 30.0\n\nor via the launch file by passing the following as a parameter to the\
    \ move_group node\n\n> {'publish_planning_scene_hz': 30.0}\n\nHope that helps"

Hi all,

I'm using Rviz to record the motion of collision objects that are attached and detached from the robot. 

The attaching and detaching is working perfectly, but I'm however experiencing a lag when using move_group/monitored_planning_scene has "Planning Scene Topic".
Using rostopic hz move_group/monitored_planning_scene I get that the topic is displayed with 4 Hz. 

RobotModel has very smooth motion for the robot and /planning_scene has smooth motion for the objects as "Planning Scene Topic", but when using those settings the attached objects are not displayed..

Does anyone know how to increase the frequency of move_group topic, or some workaround for increasing the frequency of the displayed object in Rviz?

Thanks in advance!
