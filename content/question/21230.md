  body_markdown: "It looks like you are using [URDF](http://wiki.ros.org/urdf) syntax\
    \ inside [SDF](http://sdformat.org/). You have:\n\n    <inertial>\n    <origin\
    \ rpy=\"0 0 0\" xyz=\"0.13606 0.00000 0.02002\"/>\n    <mass value=\"0.14867\"\
    />\n    <inertia ixx=\"0.00016\"\n              ixy=\"0.00000\"\n            \
    \  ixz=\"0.00030\"\n              iyy=\"0.00113\"\n              iyz=\"0.00000\"\
    \n              izz=\"0.00106\"/>\n    </inertial>\n\nInstead, it should be: \n\
    \n    <inertial>\n      <pose>0.13606 0.00000 0.02002 0 0 0</pose>\n      <inertia>\n\
    \        <ixx>0.00016</ixx>\n        <ixy>0</ixy>\n        <ixz>0.00030</ixz>\n\
    \        <iyy>0.00113</iyy>\n        <iyz>0</iyz>\n        <izz>0.00106</izz>\n\
    \      </inertia>\n      <mass>0.14867</mass>\n    </inertial>\n\nYou can find\
    \ out more about the SDF syntax [here](http://sdformat.org/spec?ver=1.6&elem=link)\n\
    \n"
