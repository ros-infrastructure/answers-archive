    \ for the syntax.\nTypically, once you have properly configured your list of repositories\
    \ in your .rosinstall file with their remote URI, you can pull with `wstool update`\
    \ in the folder where your file is located (http://docs.ros.org/independent/api/rosinstall/html/rosws.html#update)\n\
    \n**Edit:** Now I understand your problem seems related to the fact that `wstool`\
    \ uses the `origin` remote by default. You may want to have a look at [this ticket](https://github.com/vcstools/wstool/issues/59)\
    \ and the discussion therein. In short the suggestions so far are : \n\n 1. try\
    \ using `vcstool` instead of `wstool`\n 2. try out [this WIP branch](https://github.com/vcstools/vcstools/tree/allow_other_remote)\
    \ if you are willing to keep only one remote, or\n 3. make a patch yourself and\
    \ a pull request..."
