    \ vrpn_ros_cliet (not to be confused with ros_vrpn_client):  \nhttp://wiki.ros.org/vrpn_client_ros\n\
    \n- Install vrpn_client_ros:  \n    - gvdhoorn mentioned you can easily do this\
    \ with:  \n   `sudo apt-get install ros-kinetic-vrpn-client-ros`  \n   - I didn't\
    \ do it that way, because I found an explanation on the following before I knew\
    \ of that option, so I can't vouch for it working, what I did do is:  \n     \
    \   - Go to catkin src folder: `cd ~/catkin_ws/src`  \n        - clone the repository:\
    \ `git clone https://github.com/ros-drivers/vrpn_client_ros.git`\n        - update\
    \ my repos before installing dependencies: `sudo apt-get update`  \n        -\
    \ go to cloned reposetory and install dependencies using: `rosdep install --from-paths\
    \ .`  \n        - go to catkin home directory (may differ if you made it differently):\
    \ `cd ~/catkin_ws`\n        - make catkin: `catkin_make`\n\n- launch vrpn_client_ros:\
    \  \n`roslaunch vrpn_client_ros sample.launch server:=<ip_of_server_machine>`\n\
    \    - you should see a \"connection established\" line at the end\n- you can\
    \ check if the node is running using `rosnode list`\n- If you already set up motive\
    \ with the streaming configurations and you have a rigid body marked in your world\
    \ you can see if the data is passed to ros using:  \n`rostopic echo /vrpn_client_node/<name_of_rigid_body>/pose`\n\
    \n- Configuring Motive:  \n    - streaming data:  \n        - Basically I followed\
    \ instructions in http://wiki.ros.org/mocap_optitrack (even though they reference\
    \ an old version of motive) but I will explain what I did anyways.\n        -\
    \ In motive go to the streaming pane (icon looks like radio signal)\n        -\
    \ press on the three dots at the top and \"Show Advance\"\n        - not sure\
    \ if this is relavent, but \"local interface\" is on \"loopback\"\n        - make\
    \ sure \"Rigid Bodies\" is on\n        - set \"Transmission Type\" to \"Multicast\"\
    \n        - set \"Multicast Interface\" to your ros machines IP address\n    \
    \    - set \"Broadcast VRPN Data\" to on\n        - \"VRPN Broadcast Port\" should\
    \ stay 3883\n\n    - calibrate cameras:  \nI followed this video:\n    https://www.youtube.com/watch?time_continue=92&v=cNZaFEghTBU\n\
    \n    - creating rigid body:  \n   I followed the instructions in https://v20.wiki.optitrack.com/index.php?title=Rigid_Body_Tracking\
