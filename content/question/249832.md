  body_markdown: |
    > Problem: catkin_make install did not install ca_driver to install-dir.

    This is actually not a problem with `catkin_make`: the current `CMakeLists.txt` of `ca_driver` ([here](https://github.com/AutonomyLab/create_autonomy/blob/6a538fbaa492e3054fb9a1eabff8e24979751d01/ca_driver/CMakeLists.txt
    )) simply does not contain any `install(..)` statements.

    Running `catkin_make install` will therefore not install anything, as there are no instructions to do so.

    I'd report this to the `AutonomyLab` people over at their [issue tracker](https://github.com/AutonomyLab/create_autonomy/issues).
