  body_markdown: "The problem is the ambiguity of the char datatype. On x86 gcc it\
    \ defaults to signed, on ARM to unsigned. This results in negative values getting\
    \ flipped.\n\nSee here: http://www.arm.linux.org.uk/docs/faqs/signedchar.php\n\
    \nand here: https://github.com/sbpl/sbpl/blob/master/src/include/sbpl/discrete_space_information/environment_navxythetalat.h#L61\n\
    \none solution is to simply compile with the `-fsigned-char` switch, forcing all\
    \ chars to be signed\n\n<pre>\n## Compiler flags\nif(CMAKE_COMPILER_IS_GNUCXX)\n\
    \    ## signed char is default on x86 gcc, not on arm however.\n    set(CMAKE_CXX_FLAGS\
    \ \"-fsigned-char\")        \nendif()\n</pre>"
