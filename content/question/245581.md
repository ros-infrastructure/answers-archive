    Afaict, there's nothing really wrong, other than that your node(s) is (are) trying to contact a ROS master that isn't responding.

    Are you starting one before trying to run your node(s)?

    ---

    Edit:

    > How do I start a ROS Master?

    Well, typically you'd use a `roscore` instance, but that would require a ROS installation. I'm not a rosjava expert, but it does include a pure Java master implementation afaik. It's just slightly less straightforward to run it.

    The [wiki/android/RosActivity](http://wiki.ros.org/android/Tutorials/indigo/RosActivity) tutorial has some info on how to add a *Master Chooser* to your application, but that seems like it's Android only (the chooser also allows you to start a new local master).

    5 mins googling led me to [this](https://github.com/ros/ros_comm/issues/335#issuecomment-33024824) comment by Damon Kohler and [this](https://github.com/rosjava/rosjava_core/issues/207#issue-59070142) issue on how to create a minimal master in rosjava. Perhaps that is something you can use. It might be that this is no longer something you'd need to create yourself (ie: rosjava includes a stand-alone master already), but I can't find anything right now.

    PS: just to make sure the rest of your application is ok, I'd actually test against a 'normal' `roscore`. That would give you a proper baseline, after which you could look into the rosjava master. But it obviously depends on whether you have a ROS installation handy somewhere.
