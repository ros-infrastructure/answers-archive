    Are you publishing the same topic to yourself in the same node?

    In that case - especially as you are dealing with possibly large image data - the bottleneck might be serialization/deserialization that happens all the time. If you pass (publish/subscribe) data as a `shared_ptr` this does not happen as a special case, see [intraprocess publishing](http://wiki.ros.org/roscpp/Overview/Publishers%20and%20Subscribers#Intraprocess_Publishing).

    The generalization of this would be to use nodelets.
