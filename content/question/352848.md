    If you have specified your costmap layers using the hydro+ API, you can set the `map_topic` parameter under the `static_map` plugin namespace in your navigation configuration files. See the [staticmap]( http://wiki.ros.org/costmap_2d/hydro/staticmap) page for more information.

    You can learn more about the hydro version of the costmap_2d stack [here](http://wiki.ros.org/costmap_2d/hydro)

    This would often get placed in the `costmap_common_parameters.yaml` file in a hydro setup.  You can see an example of that [here](https://github.com/utexas-bwi/segbot/blob/feature/social_navigation_layer/segbot_navigation/config/segbotv2/costmap_common_params.yaml) on a branch I have worked on.

    Note that in the above case, you would add the following lines to the `costmap_common_params.yaml` file:

        static_layer:
            map_topic: /map_filtered

    because the staticmap plugin was specified to be in the `static_layer` namespace in the [global_costmap_params.yaml](https://github.com/utexas-bwi/segbot/blob/feature/social_navigation_layer/segbot_navigation/config/segbotv2/global_costmap_params.yaml) file on the same branch.
