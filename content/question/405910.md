  body_markdown: "You can try generating custom headers for arduino and compiling&uploading\
    \ the arduino code separately. These packages should probably be installed for\
    \ that (maybe some are optional):\n\n    sudo apt install ros-noetic-rosserial-arduino\
    \ ros-noetic-rosserial-python ros-noetic-rosserial-client ros-noetic-rosserial\n\
    \nBuild the headers for arduino:\n\n    # make sure that all messages have been\
    \ built in the workspace\n    roscd\n    catkin build\n    source setup.bash\n\
    \n    # cd ~/<sketchbook>/libraries\n    cd ~/Arduino/libraries\n    \n    # remove\
    \ old versions of the compiled headers (including installed from GUI)\n    # or\
    \ back them up just in case (but make sure they are not under the ~/<sketchbook>/libraries)\n\
    \    rm -rf ros_lib\n    rm -rf Rosserial_Arduino_Library\n    \n    # compile\
    \ common ros headers\n    rosrun rosserial_arduino make_libraries.py .\n    \n\
    \    # compile custom headers\n    rosrun rosserial_client make_libraries .\n\n\
    After his you should have a `~/<sketchbook>/libraries/ros_lib` directory with\
    \ `ros.h` header, some other common headers and directories, as well as directories\
    \ with your custom message headers.\n\nCompiling and uploading code to the arduino\
    \ can then be done either via the Arduino IDE or using [arduino-cli](https://github.com/arduino/arduino-cli).\n"
