  body_markdown: "For me, the 3dm-gx3-25 showed up on /dev/ttyACM0 by defualt. Try\
    \ typing `ls -l /dev/ttyACM0` (assuming the imu is the only usb sensor you have\
    \ connected), or you can try with process of elimination by disconnecting the\
    \ sensor (wait about 5-10 seconds for the usb device to unregister), typing `ls\
    \ -l /dev/tty` to view the whole list. Then connect the sensor, and view the list\
    \ again. You should either see a new /dev/ttyACM or a new /dev/ttyUSB .\n\nId\
    \ also recommend that you set up some udev rules. You can [use this one](https://github.com/KumarRobotics/imu_3dm_gx4/blob/master/script/imu_3dm_gx4.rules) "
