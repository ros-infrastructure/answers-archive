  body_markdown: "This can happen when using Fast-RTPS and Connext with a message\
    \ in a particular size range. Long term `rmw_fastrtps_cpp` should be updated to\
    \ use [this enhancement](https://github.com/eProsima/Fast-RTPS/issues/213) . In\
    \ the short term there are a couple options\n\n 1. Use `rmw_connext_cpp` for the\
    \ ROS2 rmw implementation by setting the environment variable `RMW_IMPLEMENTATION`,\
    \ or\n 2. Configure Connext to not send type matching messages larger than 5000\
    \ bytes. `rmw_connext_cpp` disables `TypeCode` to avoid this ([see this issue\
    \ ](https://github.com/ros2/rmw_connext/pull/288)). "
