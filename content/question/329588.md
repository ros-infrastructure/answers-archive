  body_markdown: "[Float32](http://docs.ros.org/api/std_msgs/html/msg/Float32.html)\
    \ is not a package but a data type and is part of [std_msgs](http://wiki.ros.org/std_msgs).\
    \ In your message/service definition you should use `float32` (for example: float32\
    \ data ).  In order to use the Float32 message and your custom messages/services\
    \ you need to include them in your script:\n\n    from std_msgs.msg import Float32\n\
    \    from your_pkg.msg import YourMsg\n\nAlso you need to add std_msgs as a dependency\
    \ in your `package.xml` along with message generation and runtime for your custom\
    \ message:\n\n      <depend>std_msgs</depend>\n      <build_depend>message_generation</build_depend>\n\
    \      <exec_depend>message_runtime</exec_depend>\nIn your `CMakeLists .txt` you\
    \ will need the following:\n\n    find_package(catkin REQUIRED COMPONENTS\n  \
    \    rospy\n      message_generation\n      std_msgs\n    )\n    \n    ## Uncomment\
    \ this if the package has a setup.py\n    #catkin_python_setup()\n    \n    add_message_files(\n\
    \      FILES\n      YourMsg.msg\n    )\n    \n    add_service_files(\n      FILES\n\
    \      YourSrv.srv\n    )\n    \n    generate_messages(\n      DEPENDENCIES\n\
    \      std_msgs\n    )\n    \n    catkin_package(\n      CATKIN_DEPENDS message_runtime\
    \ std_msgs\n    )\n    ...\n\n"
