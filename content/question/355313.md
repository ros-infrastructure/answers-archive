    Most of the time these are dependency-issues.  Python.h is used by GNU Compiler Collection (gcc) to build applications. You need to install a package called python-dev for building Python modules, extending the Python interpreter or embedding Python in applications.  You encounter "[Python.h](http://net-informations.com/python/err/pyh.htm): No such file or directory" error while trying to build a shared library using the file extension of another language ( e.g. 'C' ). If you are trying to build a shared library using the file extension of another language, you need to install the correct development version of Python.

    Reason for this error:

     - You haven't properly installed the header files and static libraries for python dev.
     - Also, sometimes include files might not be default in the include path.

    How to solve this error:

     - Install the missing files and
     -  libraries. Include Path and Library.
     -  Finally, Compile it.
