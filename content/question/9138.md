  body_markdown: "In your model for the kinect you need to create a fixed joint between\
    \ the link that represents your model and the frame_id being published by the\
    \ kinect node.\n\nfor example:\n    \n    <link name=\"kinect_link\">\n      <visual>\n\
    \        <geometry>\n          <box size=\"0.064 0.121 0.0381\" />\n        </geometry>\n\
    \        <material name=\"Blue\" />\n      </visual>\n      <inertial>\n     \
    \     <mass value=\"0.0001\" />\n          <origin xyz=\"0 0 0\" />\n        \
    \  <inertia ixx=\"0.0001\" ixy=\"0.0\" ixz=\"0.0\"\n                   iyy=\"\
    0.0001\" iyz=\"0.0\" \n                   izz=\"0.0001\" />\n      </inertial>\n\
    \    </link>\n    \n    <joint name=\"kinect_depth_joint\" type=\"fixed\">\n \
    \     <origin xyz=\"0 0.028 0\" rpy=\"0 0 0\" />\n      <parent link=\"kinect_link\"\
    \ />\n      <child link=\"kinect_depth_frame\" />\n    </joint>\n    \n    <link\
    \ name=\"kinect_depth_frame\">\n      <inertial>\n          <mass value=\"0.0001\"\
    \ />\n          <origin xyz=\"0 0 0\" />\n          <inertia ixx=\"0.0001\" ixy=\"\
    0.0\" ixz=\"0.0\"\n                   iyy=\"0.0001\" iyz=\"0.0\" \n          \
    \         izz=\"0.0001\" />\n      </inertial>\n    </link>\n    \n    <joint\
    \ name=\"depth_optical_joint\" type=\"fixed\">\n      <origin xyz=\"0 0 0\" rpy=\"\
    ${-M_PI/2} 0 ${-M_PI/2}\" />\n      <parent link=\"kinect_depth_frame\" />\n \
    \     <child link=\"kinect_depth_optical_frame\" />\n    </joint>\n    \n    <link\
    \ name=\"kinect_depth_optical_frame\">\n      <inertial>\n          <mass value=\"\
    0.0001\" />\n          <origin xyz=\"0 0 0\" />\n          <inertia ixx=\"0.0001\"\
    \ ixy=\"0.0\" ixz=\"0.0\"\n                   iyy=\"0.0001\" iyz=\"0.0\" \n  \
    \                 izz=\"0.0001\" />\n      </inertial>\n    </link>\n\nThen based\
    \ on the above urdf launch the kinect node with the following parameteres:\n\n\
    \      <node pkg=\"openni_camera\" type=\"openni_node\" name=\"openni_camera\"\
    \ output=\"screen\" respawn=\"true\" >\n        <param name=\"device_type\" value=\"\
    1\" />\n        <param name=\"registration_type\" value=\"1\" />\n        <param\
    \ name=\"point_cloud_resolution\" value=\"1\" />\n        <param name=\"openni_depth_optical_frame\"\
    \ value=\"kinect_depth_optical_frame\" />\n        <param name=\"openni_rgb_optical_frame\"\
    \ value=\"kinect_rgb_optical_frame\" />\n        <param name=\"image_input_format\"\
    \ value=\"5\" />\n        <rosparam command=\"load\" file=\"$(find openni_camera)/info/openni_params.yaml\"\
    \ />\n      </node>"
