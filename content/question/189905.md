  body_markdown: "This depends on your actual setup, but if you follow the most standard\
    \ approach, you should have controllers specified as [described here](http://moveit.ros.org/wiki/PR2/Gazebo/Quick_Start#controller_setup_quick_start).\
    \ You\xB4ll thus probably want to check if controllers are set in the \"config/controllers.yaml\"\
    \ file in your robot\xB4s MoveIt! setup package. The standard controllers are\
    \ commonly using a [control_msgs/FollowJointTrajectory](http://docs.ros.org/electric/api/control_msgs/html/action/FollowJointTrajectory.html)\
    \ Action interface, so multiple topics are used for coordinated execution. One\
    \ easy way of finding out what topics are actually used is doing a\n\n    rosnode\
    \ info move_group\n\nand inspecting the output, looking for trajectory related\
    \ publishers. The other way is looking at the controllers.yaml file and figuring\
    \ out the topic names from there (which requires consideration of namespaces in\
    \ launch files etc.)"

Hi all,

When MoveIt computes and executes a trajectory, it does the following steps:

1. Compute the desired joints trajectories (i.e. the path)
2. Publish the desired path on topic **/move_group/display_planned_path**
 * The desired is provided as a set of samples of desired joint angles
3. Execute this desired path
 * In order to execute the path, the desired path samples are input into the joints controllers (arm_controller)

Do you know which topic is used to provide the controllers with the desired angles?
