    A ROS node *is* a Linux application (or at least: when compiled for and run on a Linux OS).

    Anything you can do in a "normal" Linux application you can do in a ROS node.

    So writing to a (shared) memory segment from a ROS node is perfectly possible.

    Do you see a limitation or a difference in ROS nodes that caused you to post this question?
