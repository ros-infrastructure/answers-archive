Edit:
Initially I had the problem that the robot was moving unexpectedly when planning to 'random_valid' using rviz.
With the help of @gvdhoorn I realised this is because the Universal Robot has default joint limits of -pi.
The ros_industrial/universalRobots packages has a parameter for this (limited:=true) but the package I'm using (which is recommended for melodic) doesn't have this option so I modified my urdf. (so this problem is fixed, and I updated this post to focus on my pose planning problem).
