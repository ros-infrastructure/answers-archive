  body_markdown: "> The question being how do I distinguish/separate the two joysticks\
    \ from each other in the joy topic \n\nYou can't. The [Joy](http://docs.ros.org/latest/api/sensor_msgs/html/msg/Joy.html)\
    \ message has no field for that (theoretically `header.frame_id` *could* be used,\
    \ but no consumer checks that).\n\n> I thought one solution would be to make each\
    \ `joy_node` publish to a different topic namespace \n\nYes, that would be one\
    \ way to make sure they don't publish to the same topic.\n\n> but couldn't find\
    \ any solutions or tutorials for this\n\nWell, \"topic namespace[s]\" don't exist.\
    \ Perhaps that is why you couldn't find something.\n\nYou have two options:\n\n\
    \ 1. use remapping (with [roslaunch](http://wiki.ros.org/roslaunch/XML/remap)\
    \ or with [rosrun](http://wiki.ros.org/Remapping%20Arguments)) to make each `joy_node`\
    \ instance publish to a different topic\n 1. put both `joy_node`s in a different\
    \ namespace (either directly on the [node](http://wiki.ros.org/roslaunch/XML/node)\
    \ or via a [group](http://wiki.ros.org/roslaunch/XML/group))\n\nWhich one would\
    \ be more convenient depends on whether you already are using `.launch` files\
    \ or not."
  comments:
  - body_markdown: "Thank you, I found that creating a roslaunch file then remapping\
      \ within it was exactly what i was looking for. Although took me a while to\
      \ figure out the correct `<param>` definitions to separate the controllers in\
      \ a launch file.\n\nHere is my Roslaunch file code for anybody who struggles\
      \ with the same issue\n\n    <launch>\n\n\t<group>\n\t\t<remap from='joy' to='j0'/>\n\
      \t\t<node pkg='joy' name='joy0' type='joy_node'>\n\t\t\t<param name='dev' type='string'\
      \ value='/dev/input/js0'/>\n\t\t</node>\n\t</group>\n\n\t<group>\n\t\t<remap\
      \ from='joy' to='j1'/>\n\t\t<node pkg='joy' name='joy1' type='joy_node'>\n\t\
      \t\t<param name='dev' type='string' value='/dev/input/js1'/>\n\t\t</node>\n\t\
      </group>\n\n</launch>"

Hi, I'm currently working on a project that requires the use of multiple xbox 360 controllers to control a single robot (multi-master single-slave system). I can currently create two **joy_nodes**  that receive inputs from the separate controllers distinguishing themselves from each other by changing their names to **js0** and **js1**.

The issue is that both nodes publish to the **joy** topic so when subscribing to the topic (or using rostopic echo) it receives the inputs from both joysticks simultaneously. The question being how do I distinguish/separate the two joysticks from each other in the **joy** topic (I thought one solution would be to make each **joy_node** publish to a different topic namespace but couldn't find any solutions or tutorials for this).

Any help would be appreciated, thank you.
