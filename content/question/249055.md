  body_markdown: "This is more a generic CMake question than really ROS specific (ie:\
    \ setting up your include path is not something that is any different whether\
    \ you do it for a ROS node or for a non-ROS application / build target).\n\nIn\
    \ the general case, in your `CMakeLists.txt`:\n\n    include_directories(/path/to/the/include/dir)\n\
    \nFor a ROS package, you probably want the `include` sub directory of your package\
    \ to be on the include path, so:\n\n    # note: this path is relative to the current\
    \ CMakeLists.txt\n    include_directories(include)\n\nIf you have used `find_package(catkin\
    \ COMPONENTS ..)`, you probably want something like:\n\n    include_directories(include\
    \ ${catkin_INCLUDE_DIRS})\n\nThe `x_INCLUDE_DIRS` (where `x` is a package name)\
    \ is a general pattern: most CMake Find scripts will set these variables for you,\
    \ but do check the documentation.\n\nSee [How to do common tasks \xBB Package\
    \ format 2 (recommended) \xBB C++ system library dependencies](http://docs.ros.org/indigo/api/catkin/html/howto/format2/system_library_dependencies.html)\
    \ for some more info on resolving and using *system dependencies* with Catkin\
    \ (but again, really: CMake).\n\n"
