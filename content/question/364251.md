  body_markdown: "Note that snapcraft currently only supports building workspaces\
    \ into snaps, not individual ROS packages. This is a [known shortcoming](https://bugs.launchpad.net/snapcraft/+bug/1902090)\
    \ and is slated to be fixed this cycle. The easiest workaround for this is to\
    \ use a rosinstall file, which will cause snapcraft to create a workspace on your\
    \ behalf instead of requiring you to do it.\n\nTo describe how this is done, I'll\
    \ alter the snap tutorial you're using to use a rosinstall file. First of all,\
    \ let's create our snapcraft yaml:\n\n    $ mkdir ~/my-snap\n    $ cd ~/my-snap\n\
    \    $ snapcraft init\n    Created snap/snapcraft.yaml.\n    Go to https://docs.snapcraft.io/the-snapcraft-format/8337\
    \ for more information about the snapcraft.yaml format.\n\nEdit the `snap/snapcraft.yaml`\
    \ and make it look like this:\n\n    name: ros-talker-listener\n    version: '0.1'\n\
    \    summary: ROS Talker/Listener Example\n    description: |\n      This example\
    \ launches a ROS talker and listener.\n    \n    confinement: devmode\n    base:\
    \ core18\n    \n    parts:\n      ros-tutorials:\n        plugin: catkin\n   \
    \     source: .\n        rosinstall-files: [ros_tutorials.rosinstall]\n      \
    \  catkin-packages: [roscpp_tutorials]\n        build-packages: [lsb-release]\
    \  # I needed this in LXD, you may not\n    \n    apps:\n      ros-talker-listener:\n\
    \        command: roslaunch roscpp_tutorials talker_listener.launch\n\nNote the\
    \ use of `rosinstall-files`. Let's create a `ros_tutorials.rosinstall` file alongside\
    \ the `snap/` directory:\n\n    $ touch ~/my-snap/ros_tutorials.rosinstall\n\n\
    Make that file look like the following:\n\n    - git: {local-name: ros_tutorials,\
    \ uri: 'https://github.com/ros/ros_tutorials.git', version: melodic-devel}\n\n\
    Save, and build the snap. Note the installation of wstool and the workspace merging\
    \ happening before fetching dependencies and whatnot:\n\n    $ snapcraft\n   \
    \ <snip>\n    Pulling ros-tutorials \n    Installing wstool...\n    <snip>\n \
    \   Initializing workspace (if necessary)...\n    Merging /root/parts/ros-tutorials/src/ros_tutorials.rosinstall\n\
    \    Updating workspace...\n    <snip>\n    Installing apt dependencies...\n \
    \   <snip>\n    Building ros-tutorials\n    <snip>\n    Snapped ros-talker-listener-test_0.1_amd64.snap"
