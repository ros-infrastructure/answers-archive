  body_markdown: "Hello. \n\nBrowse and work through the tutorials in the documentation\
    \ [there](https://docs.ros.org/en/galactic/) and [there](https://roboticsbackend.com/category/ros2/),\
    \ then read A LOT of code. \n\nTry to find examples, demo projects and packages\
    \ on GitHub that suit your needs, also try to build something yourself too, with\
    \ simulation and hardware too if you can, e.g. (this base project [dolly](https://github.com/chapulina/dolly))\
    \ - with this approach you can see overall picture of the ROS2 and profits of\
    \ it's modularity. You have to learn by doing there. \n\nGood practices will come\
    \ over time, now focus on building something that will work :)\n\nYou can later\
    \ try to work with some open-source projects and maybe even help in development."
