  body_markdown: "If you are just trying to use a different robot with MoveIt!, you\
    \ don't need a new IK plugin. The IK plugin is what Moveit uses for computing\
    \ the inverse kinematics and the default one uses [KDL](http://www.orocos.org/kdl)\
    \ which is a generic solver that should work for any kind of robot arm. \n\nAll\
    \ Moveit! needs to work with a new robot is your robot's URDF file and you have\
    \ to go through the MoveIt! setup wizard. \n\nIf you already knew this and have\
    \ tried the default plugin and are not happy with the performance, there are two\
    \ easy alternative IK plugins that I am aware of, the OpenRave [IKFast plugin](http://docs.ros.org/indigo/api/moveit_ikfast/html/doc/ikfast_tutorial.html)\
    \ and the [Trac-IK](https://bitbucket.org/traclabs/trac_ik.git) one. The IKFast\
    \ method creates a solver that is custom to your robot since it is an analytical\
    \ solver, Trac-IK is similar to the KDL one (both are numerical solvers) which\
    \ *should* work for all robots. \n\nIf you have went through the trouble of solving\
    \ the analytical IK solution for your arm by hand, you can make you own plugin\
    \ from scratch, but that is not too easy. \n\nLong story short: You shouldn't\
    \ need to make your own plugin unless you've tried the default one and are not\
    \ happy with it. "
