  body_markdown: "The only packages in ROS-Industrial released into Jade at this moment\
    \ are those in [industrial_core](http://wiki.ros.org/industrial_core). Those packages\
    \ can be installed using `apt-get` (at least on Ubuntu).\n\nAs to the rest of\
    \ ROS-Industrial: that has not been released, but as the differences between Indigo\
    \ and Jade are relatively minor, most -- if not all -- packages should be usable\
    \ under Jade. The only drawback is that you'd need to build them from source.\n\
    \n> Is there any place where to find the compatibilities between the different\
    \ UBUNTU-ROS-ROSI releases?\n\nIf with \"compatibilities\" you mean: into which\
    \ ROS releases ROS-Industrial packeges have been released, then I'm afraid there\
    \ is (currently) not a single location that displays that information.\n\nYou\
    \ can however find out in multiple places if a package is released for a specific\
    \ platform and ROS release:\n\n 1. look at the green 'badges' at the top of the\
    \ wiki pages for the package: switch to the ROS release that you are interested\
    \ in (using the version rocker at the top of the page), and look for a `\u2714\
    \ Released` badge. If you can't find that, or the package doesn't have a button\
    \ in the rocker for the ROS release you are interested in, then it's safe to assume\
    \ it hasn't been released.\n 1. use any of the available *release status* pages,\
    \ such as [ROS Jade - release status](http://repositories.ros.org/status_page/ros_jade_default.html)\
    \ for Jade. Those pages can be filtered: [here](http://repositories.ros.org/status_page/ros_jade_default.html?q=industrial)\
    \ is a query for `industrial` in Jade. See [here](http://repositories.ros.org/status_page/)\
    \ for all status pages. If a package is not listed on that page, it's safe to\
    \ assume it hasn't been released.\n\n> because I cant find it in all the different\
    \ ros-wiki's\n\n(slightly pedantic) but there is only a single \"ROS wiki\", the\
    \ one at `wiki.ros.org`.\n"
