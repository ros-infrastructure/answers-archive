  body_markdown: "All you need to do is define the frame of the IMU relative to the\
    \ base_link with the correct rotation and orientation.\nIf the IMU would already\
    \ be using the REP-103 coordinate system the very basic urdf would look something\
    \ like this:\n\n    <?xml version='1.0'?>\n    <robot name=\"basic\" xmlns:xacro=\"\
    http://www.ros.org/wiki/xacro\">\n      <link name=\"base_link\">\n        <pose>0\
    \ 0 0 0 0 0</pose>\n      </link>\n      <link name=\"imu\"/>\n      <joint name=\"\
    imu_joint\" type=\"fixed\">\n        <origin rpy=\"0 0 0\" xyz=\"0 0 0.3\"/>\n\
    \        <parent link=\"base_link\" />\n        <child link=\"imu\"/>\n      </joint>\n\
    \    </robot>\nWould produce the output as (red=x, green=y, blue=z):\n\n![image\
    \ description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/15910946325911342.png)\n\
    \nIn the linked repository the orientation of the IMU is depicted as Z down and\
    \ Y to the \"right\". You need to take that orientation into account in the definition\
    \ of your frames. To do that you need to rotate it around the X axis.\n\nThe rotation\
    \ is in radians so rotate it by PI for 180 degrees. `<origin rpy=\"3.1416 0 0\"\
    \ xyz=\"0 0 0.3\"/>`\nThe basic robot would look like this:\n\n    <?xml version='1.0'?>\n\
    \    <robot name=\"basic\" xmlns:xacro=\"http://www.ros.org/wiki/xacro\">\n  \
    \    <link name=\"base_link\">\n        <pose>0 0 0 0 0 0</pose>\n      </link>\n\
    \      <link name=\"imu\"/>\n      <joint name=\"imu_joint\" type=\"fixed\">\n\
    \        <origin rpy=\"3.1416 0 0\" xyz=\"0 0 0.3\"/>\n        <parent link=\"\
    base_link\" />\n        <child link=\"imu\"/>\n      </joint>\n    </robot>\n\
    Output and the image in the linked git repo:\n\n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/15910950386089833.png)\n\
    ![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/15910950631215433.png)\n\
    \n_______\nTo easily inspect your urdf you might want to install the package [urdf_tutorial](http://wiki.ros.org/urdf_tutorial).\
    \ \n\nreplace `<ros_distro>` with your distribution\n\n`sudo apt install ros-<ros_distro>-urdf-tutorial`\n\
    \nfor kinetic:\n\n`sudo apt install ros-kinetic-urdf-tutorial`\n\nThen assuming\
    \ you saved the above robot description as `basic.xacro` you could just run:\n\
    \n    cd /path/to/saved/xacro\n    roslaunch urdf_tutorial display.launch model:=basic.xacro\n\
    \  \nTo verify that everything seems to be working normally you could install\
    \ some plugins to visualize the IMU output in rviz. One example would be [rviz_imu_plugin](http://wiki.ros.org/rviz_imu_plugin).\
    \ Have not used that plugin in a long time, you would probably need to have your\
    \ URDF \"running\" and change the fixed_frame to base_link in Rviz to get sensible\
    \ output."
