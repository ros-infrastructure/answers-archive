  body_markdown: "MultiArray messages are for publishing multi-dimensional arrays;\
    \ not for publishing multiple arrays within the same message.\n\nFor example,\
    \ a vector or list is a one-dimensional array, and a matrix would be a two-dimensional\
    \ array.\n\nYou need to set up the `dim` array with the dimensions of your array.\
    \ For a 1-d array, one element with the length. For a 2-d array or matrix, your\
    \ `dim` array would have two elements; one for the height of the matrix, and a\
    \ second for the width of the matrix.\n\nOnce you have `dim` set up, you store\
    \ your data in the `data` field in row-major order.\n\nAs an example, if you wanted\
    \ to put your `vec1` in a MultiArray, you would do:\n\n    vector<double> vec1\
    \ = { 1.1, 2., 3.1};\n    std_msgs::Float64MultiArray msg;\n\n    // set up dimensions\n\
    \    msg.layout.dim.push_back(std_msgs::MultiArrayDimension());\n    msg.layout.dim[0].size\
    \ = vec1.size();\n    msg.layout.dim[0].stride = 1;\n    msg.layout.dim[0].label\
    \ = \"x\"; // or whatever name you typically use to index vec1\n    \n    // copy\
    \ in the data\n    msg.data.clear();\n    msg.data.insert(msg.data.end(), vec1.begin(),\
    \ vec1.end());\n\n"
