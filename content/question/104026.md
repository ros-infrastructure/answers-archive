  body_markdown: "That\xB4s not easily possible because of the way a scan is represented\
    \ in the [sensors_msgs/LaserScan](http://docs.ros.org/api/sensor_msgs/html/msg/LaserScan.html)\
    \ message. The distance measurements are given in a vector and the position of\
    \ scan endpoints can be computed using the other fields in the message (angle_min\
    \ etc.). This representation obviously is only valid when using the actual frame_id\
    \ of the LIDAR.\n\nThe easiest way to transform it to another frame is converting\
    \ it to a pointcloud using the tools provided in [laser_pipeline](http://wiki.ros.org/laser_pipeline)."
