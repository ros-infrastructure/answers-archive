  body_markdown: "If you have previously built Autoware.Auto on your system or have\
    \ not updated your `ade` in a while, this can happen because the action messages\
    \ for the Record/Replay Planner used to exist in the package `recordreplay_planner_actions`\
    \ and are now in `autoware_auto_msgs`. To make sure you are using the latest `ade`:\n\
    \n- exit `ade` and run `ade stop`\n- run `ade start --update --enter`\n\nIf you\
    \ are building from source, clear out your build environment and pull the latest\
    \ external dependencies: \n\n    cd to your Autoware.Auto folder\n    rm -r src/external/*\
    \ build/ install/ log/\n    git pull\n    vcs import < autoware.auto.foxy.repos\n\
    \    colcon build\n\nIf you are using your own fork of Autoware, see [How to Develop\
    \ in a Fork](https://autowarefoundation.gitlab.io/autoware.auto/AutowareAuto/develop-in-a-fork.html)\
    \ for instructions on updating your fork from the upstream."
