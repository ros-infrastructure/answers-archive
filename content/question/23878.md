  body_markdown: "You can do it in [WORLD file](http://sdformat.org/spec?ver=1.6&elem=world#gui_camera).\
    \ \n\n    <world>\n        ...\n        <gui>\n          <camera name='gzclient_camera'>\n\
    \            <pose>-13.0 -9.0 8.0 0 0.4 1.3</pose>\n          </camera>\n    \
    \    </gui>\n    </world>\n\nThere is a method of UserCamera object in Gazebo\
    \ 9 API called [MoveToPosition](http://osrf-distributions.s3.amazonaws.com/gazebo/api/9.0.0/classgazebo_1_1rendering_1_1Camera.html#a317fb7aff6ff9b9843d7ea6ebc46cf5c).\
    \ Maybe that would work for you but I haven't try this myself."
