  body_markdown: "The laser_assembler node publishes to the `assembled_cloud` topic.\
    \ You can then subscribe to this topic to gain access to the data in a ROS node.\
    \ The `assembled_cloud` message is of the type sensor_msgs/PointCloud. You could\
    \ use something like: \n\n    cloud_sub_ = node_.subscribe<sensor_msgs::PointCloud>\
    \ (\"/assembled_cloud\", 100, &MyNode::CloudCallback, this);"
