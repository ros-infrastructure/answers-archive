    \ what you want for the moment, I would recommend you to follow the [basic ros\
    \ tutorials](http://wiki.ros.org/ROS/Tutorials) first. \n\nJust a few hints :\
    \ \n\n> I don't know where to use a pyhton script or how a script can even be\
    \ attached with any simulation\n\nIn ROS you write scripts (when using `rospy`)\
    \ to create `nodes`, the `nodes` are executables that can interract with each\
    \ others thanks to a `ros master`. \nThe simulation you are talking about is a\
    \ `launch file` where you declare all the `nodes` you want to use. \n\n> I want\
    \ to add a camera\n\nThis will be done within the `URDF` file of your robot, where\
    \ you define the model of your robot (shape, joints, sensors, etc...)\n\n> The\
    \ object detection would be through a pyhton script\n\nThe object detection algorithm\
    \ doesn't require to be a ros `package`, you can have your own but in that case\
    \ it should be wrapped inside a `node`."
