  body_markdown: "For source code to find header files, the CMakeLists.txt needs to\
    \ be changed.\n\nFor example if your package formate is\n\n    dummy_pkg/\n  \
    \     src/\n       include/\n       CmakeLists.txt\n       package.xml\n  \n\n\
    Then in your CMakeLists.txt, you need to add \n\n    include_directories(\n  \
    \    include\n    )\n\nwill include header files in the include/ directory. If\
    \ you are looking for headers in other ros packages then also add `${catkin_INCLUDE_DIRS}`\
    \ inside those brackets.\n\n"
