  body_markdown: |-
    I believe [ardrone_autonomy](https://github.com/AutonomyLab/ardrone_autonomy) has already been converted to a catkin package, and has been released for ROS Indigo. Just enter `sudo apt-get install ros-indigo-ardrone-autonomy` into a terminal. Failing that, grab the indigo-devel branch from the Git repository.

    As for tum_simulator, it looks like @Gary Servin submitted a [pull request](https://github.com/tum-vision/tum_simulator/pull/4) to get that updated to catkin and Indigo as well.

    EDIT: for future reference, see this [tutorial](http://wiki.ros.org/catkin/migrating_from_rosbuild) on migrating from rosbuild to catkin.
