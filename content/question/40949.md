    The controller manager is probably not running.

    `pr2_controller_manager` is just a library that provides a few services and the infra structure for running controller plugins in a loop. Gazebo or the real hardware (package [pr2_etherCAT](http://ros.org/wiki/pr2_etherCAT)) link against that library and provide the interface between the controllers and the hardware.

    If you just want to play around with pr2_controller_manager, run the PR2 in simulation with:

        roslaunch pr2_gazebo pr2_empty_world.launch
