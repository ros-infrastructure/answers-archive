  body_markdown: "Basically you need to implement an algorithm for **robot control**.\n\
    It could be an open-loop controller, where you command your robot to turn for\
    \ a certain amount of time and then stop the motion, this will not be precise,\
    \ but if error is not an issue it will certainly be the easiest way of implementing\
    \ what you described. All you need in that case is a publisher for applying control\
    \ signals (velocity commands) and logic for generating the stop command based\
    \ on a timer.\n\nA better way of doing it is with closed loop (feedback) control.\
    \  \nIf you have a way to input your goal you will need at least the following\
    \ three components:\n\n- A publisher for applying control signals (velocity commands)\n\
    - A subscriber for measuring the results (the robot's odometry)\n- Logic for comparing\
    \ the results with the goal and generate new control signals if required\n\nAs\
    \ a start you can take a look at this video:\n\n[[ROS Q&A] 053 - How to Move a\
    \ Robot to a Certain Point Using Twist](https://www.youtube.com/watch?v=eJ4QPrYqMlw)\n\
    \n"
