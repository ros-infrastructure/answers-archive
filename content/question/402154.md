  body_markdown: "In the end, I solved the problem. I used a launch file to open several\
    \ instances of ROS2 and it works quite well, to be honest. \n\nIn order to have\
    \ different instances you can have a launch file like this:\n\n    import os\n\
    \    \n    from ament_index_python.packages import get_package_share_directory\n\
    \    from launch import LaunchDescription\n    from launch_ros.actions import\
    \ Node\n    \n    def generate_launch_description():\n        config_camera_1\
    \ = \"config_1.rviz\"\n        config_camera_2 = \"config_2.rviz\"\n        config_lidar_1\
    \ = \"config_3.rviz\"\n        config_lidar_2 = \"config_4.rviz\"\n        config_lidar_3\
    \ = \"config_5.rviz\"\n    \n        print(\"SHARE_dir: \", get_package_share_directory('offline_sensor_data_server'))\n\
    \        \n        return LaunchDescription([\n            Node(package='rviz2',\n\
    \                executable='rviz2',\n                name='rviz2_camera_1',\n\
    \                arguments=['-d', config_camera_1],\n                output='screen'\n\
    \            ),\n            Node(package='rviz2',\n                executable='rviz2',\n\
    \                name='rviz2_camera_2',\n                arguments=['-d', config_camera_2],\n\
    \                output='screen'\n            ),\n            Node(package='rviz2',\n\
    \                executable='rviz2',\n                name='rviz2_2',\n      \
    \          arguments=['-d', config_lidar_1],\n                output='screen'\n\
    \            ),\n            Node(package='rviz2',\n                executable='rviz2',\n\
    \                name='rviz2_3',\n                arguments=['-d', config_lidar_2],\n\
    \                output='screen'\n            ),\n            Node(package='rviz2',\n\
    \                executable='rviz2',\n                name='rviz2_4',\n      \
    \          arguments=['-d', config_lidar_3],\n                output='screen'\n\
    \            ),\n        ])\n\n\nI hope it helps someone in the same situation. "
