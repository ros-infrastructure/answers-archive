  body_markdown: "Always keep tuned in the package wiki ( [http://wiki.ros.org/navigation](http://wiki.ros.org/navigation)\
    \ )\n\nROS Navigation - MoveBase\n![image description](http://wiki.ros.org/move_base?action=AttachFile&do=get&target=overview_tf_small.png)\n\
    \nAs you can see the only thing that **ros navigation** is taking care of is what\
    \ is inside the white box. The velocities commands are exposed as `/cmd_vel |\
    \ geometry_msgs/Twist`.\nTwist has the following struct: [Twist](http://docs.ros.org/en/melodic/api/geometry_msgs/html/msg/Twist.html)\n\
    \nUsually, a wheeled robot just cares about `linear.x` and `angular.z`, so **YOU**\
    \ should subscribe to this topic and create your personal kinematic model. \n\n\
    However, there are some already builds alternatives ( [Differential Driver](http://wiki.ros.org/diff_drive_controller)\
    \ )\n\nTo create your own method you can use [Hardware Interface](http://wiki.ros.org/hardware_interface),\
    \ but this is your choice.\n\n"
