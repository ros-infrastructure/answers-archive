  body_markdown: "Hi Kaldo,\nI'm also using the \"libgazebo_ros_gpu_laser.so\" plugin\
    \ on my model, but my model is in URDF format (I would not think that it matters).\
    \ I initially had problems getting my laser to work but somewhere I found an answer\
    \ from someone (I don't remember who answered or where I found it).\n\nHere is\
    \ what I have in my URDF file:\n\n    <gazebo reference=\"base_link\">\n     \
    \ <sensor type =\"gpu_ray\" name=\"hoyuko\">\n        <pose>0.19391 0.00126 0.28877\
    \ 0 0 0</pose>\n        <visualize>true</visualize>\n        <update_rate>20</update_rate>\n\
    \        <ray>\n          <scan>\n            <horizontal>\n              <samples>720</samples>\n\
    \              <resolution>1</resolution>\n              <min_angle>-1.570796</min_angle>\n\
    \              <max_angle>1.570796</max_angle>\n            </horizontal>\n  \
    \        </scan>\n          <range>\n            <min>0.10</min>\n           \
    \ <max>2.5</max>\n            <resolution>0.01</resolution>\n          </range>\n\
    \        </ray>\n        <plugin name=\"gpu_laser\" filename=\"libgazebo_ros_gpu_laser.so\"\
    >\n          <topicName>/scan</topicName>\n          <frameName>base_link</frameName>\n\
    \        </plugin>\n      </sensor>            \n    </gazebo>\n\nIn your file\
    \ try changing `<plugin name=\"laser_plugin\" filename=\"libgazebo_ros_gpu_laser.so\"\
    \ />` to `<plugin name=\"gpu_laser\" filename=\"libgazebo_ros_gpu_laser.so\">`.\n\
    \nI tried several different combinations before mine worked, but I think it was\
    \ this change that actually did the trick. Give it a try and see what happens.\
    \ Hopefully it will work for you.\n\nMike"

 Hello,

My sdf model contains an included [Hokuyo laser](https://bitbucket.org/osrf/gazebo_models/src/6cd587c0a30e/hokuyo/model.sdf?at=default&fileviewer=file-view-default), and I tried to attach the rather standard `libgazebo_ros_gpu_laser.so` plugin, as follows:

    <model name="my_laser">
        <include>
            <uri>model://hokuyo</uri>
            <pose>-0.22 0 0.10500000000000001 0 0 3.141592653589793</pose>
            <plugin name="laser_plugin" filename="libgazebo_ros_gpu_laser.so" />
        </include>
    </model>

I get this error:

    Model[my_laser] is attempting to load a plugin, but detected an incorrect plugin type.

Indeed, from what I see in the [example](http://gazebosim.org/tutorials?tut=ros_gzplugins#RRBotExample17), the plugin is meant for `<sensor>` elements.

So can I access the sensor itself, and attach the plugin to it directly?

If not, how do you suggest I use the plugin?
