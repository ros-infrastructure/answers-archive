  body_markdown: "Here is an explanation of how you could have an arduino control\
    \ your motors in a general way:\n\nComponents required:\n\n - An arduino with\
    \ code that can control your motor\n - A computer running ROS and a node that\
    \ publishes data to a topic, such as an integer that corresponds to a motor value\
    \ that you would like to use as a throttle value for your motor\n\nIf you have\
    \ those two things you can modify the arduino code by adding ROS functionality\
    \ to it. Do the first of these 3 tutorials: http://wiki.ros.org/rosserial_arduino/Tutorials/Arduino%20IDE%20Setup\
    \ \n\n - [Arduino IDE Setup](http://wiki.ros.org/rosserial_arduino/Tutorials/Arduino%20IDE%20Setup)\n\
    \ - [Hello World (example publisher)](http://wiki.ros.org/rosserial_arduino/Tutorials/Hello%20World)\n\
    \ - [Blink (example subscriber)](http://wiki.ros.org/rosserial_arduino/Tutorials/Blink)\n\
    \nWith these examples you will gain the knoweledge to allow you to send AND receive\
    \ data to/from your arduino. With this knoweldge you can have your arduino serve\
    \ a motor controller, by sending it throttle values and having it convert those\
    \ throttle values to whatever signals are required to control your motors. Easy\
    \ peazy lemon squeezy!"
