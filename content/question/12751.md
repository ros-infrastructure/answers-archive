    \ doing already, but here's how I would do it: \n\n    #!/bin/bash\n\n    rosbag\
    \ play my_bag.bag \n\n    while [ ! \"$(ps aux | grep bag | grep -v grep)\" ]\
    \ # or $(rosnode list | grep play)\n    do\n        sleep 1;\n    done\n\n   \
    \ if [ \"$(ps aux | grep ros | grep -v grep | awk '{print $2}')\" ]; then # or\
    \ $(rosnode list)\n        for i in $(ps aux | grep ros | grep -v grep | awk '{print\
    \ $2}')\n        do\n            kill -2 $i;\n        done\n    fi\n\nI use this\
    \ because according to the rosnode kill documentation, it's not guaranteed to\
    \ actually kill a node, especially when it's set to respawn. This function guarantees\
    \ that they all die. You'd then be free to launch again. You could even put this\
    \ all in a loop. \n    "
