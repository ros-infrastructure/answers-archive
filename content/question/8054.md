  body_markdown: "I also had the same problem, but the other answers didn't work for\
    \ me. I solved the issue by declaring an empty `robotNamespace` tag inside the\
    \ `plugin` tag\n\n    <!-- hokuyo_model.sdf -->\n    ...\n    <plugin name=\"\
    laser_controller\" filename=\"libgazebo_ros_laser.so\">\n      <robotNamespace></robotNamespace>\n\
    \      <topicName>sensor</topicName>\n      <frameName>link</frameName>\n    </plugin>\n\
    \    ...\n\nThen, if you attach it to a robot \n\n    <!-- my_robot_with_laser.sdf\
    \ -->\n\n    <?xml version=\"1.0\" ?>\n    <sdf version=\"1.5\">\n      <model\
    \ name=\"pioneer3at\">\n\n        <include>\n          <uri>model://pioneer3at</uri>\n\
    \        </include>\n\n        <include>\n          <uri>model://hokuyo</uri>\n\
    \          <pose>0 0 0.3 0 0 0</pose>\n        </include>\n\n        <joint name=\"\
    laser_joint\" type=\"revolute\">\n          <parent>pioneer3at::chassis</parent>\n\
    \          <child>hokuyo::link</child>\n          <axis>\n            <xyz>0 0\
    \ 1</xyz>\n            <limit>\n              <lower>0</lower>\n             \
    \ <upper>0</upper>\n            </limit>\n          </axis>\n        </joint>\n\
    \n        ... <!-- maybe other plugins -->\n\n      </model>\n    </sdf>\n\nit\
    \ will make the sensor take the name of the model on which is attached as its\
    \ namespace when spawning the model from a launch file\n\n    <launch>\n     \
    \ ...\n      <group ns=\"my_namespace\">\n        <node pkg=\"gazebo_ros\" type=\"\
    spawn_model\"\n              respawn=\"false\"\n              name=\"spawn_model\"\
    \n              args=\"-file my_robot_with_laser.sdf -sdf -model my_namespace\"\
    \ />\n\n        ... <!-- maybe other nodes -->\n      </group>\n      ...\n  \
    \  </launch>\n\nBe aware that the `group` tag doesn't have any effect over the\
    \ Hokuyo sensor ( it's the `-model my_namespace` what's doing the trick), but\
    \ you'll need it if you have other plugins or nodes defined and want them to be\
    \ namespaced."
