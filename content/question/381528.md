  body_markdown: "> In the launch file\n\nWhich launch file are you talking about\
    \ ? You should include it in your question, or at least tell the node you are\
    \ trying to launch. \n\nI'm assuming that you want to launch a turtlebot simulation,\
    \ so it's the node `spawn_model`  from the package `gazebo_ros` that will handle\
    \ the initial position. You should have something like this in your launch file\
    \ :\n\n    <node pkg=\"gazebo_ros\" type=\"spawn_model\" name=\"spawn_urdf\" \
    \ args=\"-urdf -model turtlebot3_$(arg model) -x $(arg x_pos) -y $(arg y_pos)\
    \ -z $(arg z_pos) -param robot_description\" />\n\nNow if you look at all the\
    \ arguments of the script `spawn_model` [here](https://github.com/ros-simulation/gazebo_ros_pkgs/blob/kinetic-devel/gazebo_ros/scripts/spawn_model#L42-L68)\
    \ you will see this :\n\n    -x <x in meters> - optional: initial pose, use 0\
    \ if left out\n    -y <y in meters> - optional: initial pose, use 0 if left out\n\
    \    -z <z in meters> - optional: initial pose, use 0 if left out\n    -R <roll\
    \ in radians> - optional: initial pose, use 0 if left out\n    -P <pitch in radians>\
    \ - optional: initial pose, use 0 if left out\n    -Y <yaw in radians> - optional:\
    \ initial pose, use 0 if left out\n\nSo you just have to add this in the `args`\
    \ of the node `spawn_model`, after  `-z $(arg z_pos)` for example : `-R $(arg\
    \ ROLL)` , with `ROLL` being the argument name that you should define at the beginning\
    \ of your launch file.\n\n\n----------\n\nEdit :\nYou seem to have a little confusion\
    \ with the arguments of a launch file, the name isn't relevant at all, it's like\
    \ declaring a variable. The important part is the value you assign to it. You\
    \ should have a look at the [wiki](http://wiki.ros.org/roslaunch/XML/arg) for\
    \ more explanations.\n\nIn your case you have this :\n\n    <node pkg=\"gazebo_ros\"\
    \ type=\"spawn_model\" name=\"spawn_urdf\"  args=\"-urdf -model turtlebot3_$(arg\
    \ model) -x $(arg x_pos) -y $(arg y_pos) -z $(arg z_pos) -param robot_description\"\
    \ />\n\nYou give to the node `spawn_model` a list of arguments, for example you\
    \ specify the `x` value by adding -`x VALUE` where `VALUE` is set at the beginning\
    \ of your launch file like this :\n\n    <arg name=\"x_pos\" default=\"-1.0\"\
    />\n\nSo if you want to set the roll, pitch or yaw you have to add in the list\
    \ `-R` for the roll, `-P` for the pitch and `-Y` for the yaw. Like this :\n\n\
    \    <arg name=\"roll\" default=\"0.0\"/>\n    <arg name=\"pitch\" default=\"\
    0.0\"/>\n    <arg name=\"yaw\" default=\"0.0\"/>\n    <node pkg=\"gazebo_ros\"\
    \ type=\"spawn_model\" name=\"spawn_urdf\"  args=\"-urdf -model turtlebot3_$(arg\
    \ model) -x $(arg x_pos) -y $(arg y_pos) -z $(arg z_pos) -R $(arg roll) -P $(arg\
    \ pitch) -Y $(arg yaw) -param robot_description\" />\n\n(you can name the arguments\
    \ whatever you want, you just need to use them properly)"
