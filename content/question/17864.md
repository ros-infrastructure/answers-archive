  body_markdown: "You need to put a light inside your world, as @chapulina told.\n\
    \nPlease try to insert a custom light inside your world, like this one:\n\n> \
    \    <light type=\"spot\" name=\"test_light\">\n        <pose>0 0 0 0 0 0</pose>\n\
    \        <diffuse>1 1 1 0.5</diffuse>\n        <specular>.1 .1 .1 1</specular>\n\
    \        <attenuation>\n            <range>10</range>\n            <linear>0.5</linear>\n\
    \            <constant>0.8</constant>\n            <quadratic>0.01</quadratic>\n\
    \        </attenuation>\n        <cast_shadows>true</cast_shadows>\n    </light>\n\
    \nAfter this, try using the gazebo tag inside your robot (you missed the gazebo\
    \ tag):\n\n>     <gazebo>\n        <plugin name=\"attach_light\" filename=\"libAttachLightPlugin.so\"\
    >\n            <link>\n                <link_name>${namespace}/light${suffix}_link</link_name>\n\
    \                <light>\n                    <pose>${light_pose}</pose>\n   \
    \                 <light_name>${light_name}</light_name>\n                </light>\n\
    \            </link>\n        </plugin>\n    </gazebo> \n\nThat worked fine by\
    \ me. Note that I was succeeded only after I updated Gazebo to the 7.14 version.\n\
    \n\n    \n\n"
