Hello,

I have 2 nodes works at the same time. One node captures image via opencv VideoCapture and the other node subscribes the first node to fetch the images and do deep learning inference. If I start the nodes and Gazebo with roslaunch everything seems to working fine. However, if I start the nodes via rosrun and start the roscore from a different terminal the image callback in deep learning node is starting to slow down drastically. Below you can find the specifications for the nodes and the dummy roslaunch Im using. 
Thanks for the help.

Video Capture Node:
- Video FPS: 30FPS
- Publisher Queue Size: 1 ( To prevent caching)
- Ros Rate: 30hz

Deep Learning Node:
- Deep Learning Inference: 80hz
- Subscriber Queue Size: 1 (To prevent caching)
- Ros Rate: 30hz
