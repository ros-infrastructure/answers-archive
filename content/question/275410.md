  body_markdown: "Hi there, this is a quite common task that is solved with the ROS\
    \ Navigation Stack (http://wiki.ros.org/navigation)\nYou can install it like this:\n\
    \n`sudo apt-get install ros-indigo-navigation` \n\nassuming you have Ros Indigo\
    \ installed, if you have Kinetic, just change it to kinetic.\n\nSince you have\
    \ a Kinect XBOX you also want to look into the Turtlebot navigation package (http://wiki.ros.org/turtlebot_navigation)\n\
    \nYou'll end up with something looking like this:\n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/15102369505977575.png)\n\
    \nBut for that t happen you need to convert your pointcloud to a laserscan, good\
    \ luck for you there is a package for that ;) \nCheck it here: http://wiki.ros.org/pointcloud_to_laserscan\n\
    \nAfterwards, you use the navigation stack and create your map with the laser\
    \ scan, it'll be as easy as publishing a 2D Nav Goal for your robot to navigate.\
    \ Good luck!\n\n"
