  body_markdown: "For the callback to be called, `ros::spin()` or `ros::spinOnce()`\
    \ have to be called (for the simple single threaded case). In your code, this\
    \ is missing from your `while(ros::ok())` loop. The `spin()` call only gets called\
    \ when you abort your program (as soon as `ros::ok()` returns false). \n\nSee\
    \ [Callbacks and Spinning](http://wiki.ros.org/roscpp/Overview/Callbacks%20and%20Spinning#Single-threaded_Spinning).\
    \ You're basically looking at the second option and should call execute `ros::spinOnce`\
    \ inside your loop, for instance like this:\n\n    while(ros::ok()) {\n      \
    \  ros::spinOnce();\n      \n        //ROS_INFO(\"state: %d  \",state);\n    \n\
    \        ss << \"State is: \" << state << \" y: \" << y;// << \" Battery is: \"\
    \ << battery;\n        state_s.data = ss.str();\n    \n        pub_s.publish(state_s);\n\
    \    \n        if(state==2) {\n            pub_t.publish(emp);\n        }\n  \
    \      else\n            pub_f.publish(msg);\n    \n        loop_rate.sleep();\n\
    \    }"
