  body_markdown: "So, it would appear that we're just using too much RAM for the 168:\n\
    \n    $ avr-size HelloWorld.cpp.elf\n    text\t   data\t    bss\t    dec\t   \
    \ hex\tfilename\n    5132\t    144\t   1345\t   6621\t   19dd\tHelloWorld.cpp.elf\n\
    \nThe ATMEGA168 has only 1K of SRAM, but our bss and data is about 1.5k.\n\nYou\
    \ could do the following:\n\n  * checkout from hg, build and copy to your libraries\
    \ directory as usual.\n  * edit line 48 of your <sketchbook>/libraries/ros_lib/ros.h\
    \ to read:\n\n    `typedef NodeHandle_<ArduinoHardware, 5, 5, 100, 100> NodeHandle;`\n\
    \    \nWhen I did this, I had the following for size:\n\n    avr-size HelloWorld.cpp.elf\n\
    \    text\t   data\t    bss\t    dec\t    hex\tfilename\n    5120\t    144\t \
    \   441\t   5705\t   1649\tHelloWorld.cpp.elf\n\nThis will limit you to only 5\
    \ publishers, 5 subscribers, and messages must be <100 bytes long. The buffers\
    \ we maintain use a lot of memory since many messages can get quite large. \n\n\
    Please let me know if this does solve your problem, if it does, I'll get a tutorial\
    \ up on ros.org so that others can tune the performance of rosserial to their\
    \ hardware. \n"
