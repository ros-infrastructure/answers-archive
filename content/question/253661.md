    \ or subscribe to a topic\n- call a service or action\n- read to or write from\
    \ the Parameter server\n- and apparently all ROS logging does not work either.\n\
    \nIf you replace the ROS_INFO with a `std::cout`, you see that this is actually\
    \ handled. However, all code with ROS functionality is, in the end, a noop, due\
    \ to the missing connections. \n\n"
