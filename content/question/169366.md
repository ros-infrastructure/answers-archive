  body_markdown: "I have fixed this error. I explain this:\nMy Arduino's program is\
    \ equal than yours. But I have one line different: \n\n    nh.getHardware()->setBaud(57600);\n\
    \nThis is because ROS works with 57600 bauds and if you use less bauds, you'll\
    \ lose many packages.\nSo in terminal, I  eject for the conection:\n\nsudo rfcomm\
    \ connect rfcomm1 MAC_DEVICE NUMBER_CHANNEL\nIn my case would be:\n\n    sudo\
    \ rfcomm connect rfcomm1 98:D3:31:B2:D8:EB 1\n\nThus the bluetooth's led will\
    \ remain fixed, no flash.\n\nThe last, I eject ros with:\n\n    rosrun rosserial_python\
    \ serial_node.py _port:=/dev/rfcomm1 _baud:=57600\n\nAnd in other terminal:\n\
    rostopic echo chatter\n\nAnd bual\xE1! jajajajajaja :) \nHope this helps someone\

Can not run rosserial via bluetooth.<br>
Arduino Uno<br>
Blutooth module HC-06<br>
Notebook with bluetooth Ubuntu 12.04 Ros Hydro<br>
Arduino sketch:

    #include <ros.h>
    #include <std_msgs/String.h>
    
    ros::NodeHandle  nh;
    
    std_msgs::String str_msg;
    ros::Publisher chatter("chatter", &str_msg);
    
    char hello[13] = "hello world!";
    
    void setup()
    {
      nh.getHardware()->setBaud(9600);
      nh.initNode();
      nh.advertise(chatter);
    }
    
    void loop()
    {
      str_msg.data = hello;
      chatter.publish( &str_msg );
      nh.spinOnce();
      delay(1000);
    }

In terminal:

    sudo rfcomm connect 0 98:D3:31:20:03:19 1
