    If you write your ROS 2 node(s) using `rclpy`, then all ROS based communication (ie: publishing, invoking services and sending goals to action servers) will be using whichever RMW (ROS MiddleWare abstraction) is active.

    In the default configuration, that would mean a DDS implementation, which by default is Fast RTPS.

    As to tutorials/documentation: [index/ ROS 2 Overview > Tutorials > Writing a simple publisher and subscriber (Python)](https://index.ros.org/doc/ros2/Tutorials/Writing-A-Simple-Py-Publisher-And-Subscriber/) should help you get started.

    Other Python examples may be found in [ros2/examples](https://github.com/ros2/examples). There's also the [ros2/demos](https://github.com/ros2/demos) repository which contains Python examples.
