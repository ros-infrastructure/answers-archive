    Perhaps you can create a static, transparent model (sphere?) without the collision geometry (just visuals and inertials) and set position for it on every coordinate update.

    You would probably use a [gazebo-ros model plugin](http://gazebosim.org/tutorials?cat=write_plugin) and you would use method like [SetWorldPose()](http://osrf-distributions.s3.amazonaws.com/gazebo/api/7.1.0/classgazebo_1_1physics_1_1Entity.html#ac8eefcc7635536d1b2d95275f04a9b1f) (here for Gazebo7, you didn't specify your version so you have to look this up yourself) to set the position of the sphere on every coordinate update.
