  body_markdown: "To do this, begin by installing apt-mirror on your Ubuntu system.\n\
    \n    sudo apt-get update\n    sudo apt-get install apt-mirror\n\nThen edit the\
    \ mirror.list (/etc/apt/mirror.list) file so that the ROS repositories will be\
    \ mirrored, here is an example for both x86 and amd64 systems.\n\n    #############\
    \ config ##################                                                  \
    \                                                                            \
    \                                                \n    #\n    # set base_path\
    \    /var/spool/apt-mirror\n    #\n    # set mirror_path  $base_path/mirror\n\
    \    # set skel_path    $base_path/skel\n    # set var_path     $base_path/var\n\
    \    # set cleanscript $var_path/clean.sh\n    # set defaultarch  <running host\
    \ architecture>\n    # set postmirror_script $var_path/postmirror.sh\n    # set\
    \ run_postmirror 0\n    set nthreads     20\n    set _tilde 0\n    #\n    #############\
    \ end config ##############\n    \n    #deb http://packages.ros.org/ros/ubuntu\
    \ jaunty main\n    deb http://packages.ros.org/ros/ubuntu karmic main\n    deb\
    \ http://packages.ros.org/ros/ubuntu lucid main\n    deb http://packages.ros.org/ros/ubuntu\
    \ maverick main\n\n    #deb-i386 http://packages.ros.org/ros/ubuntu jaunty main\n\
    \    deb-i386 http://packages.ros.org/ros/ubuntu karmic main                 \
    \                                                                            \
    \                                                                 \n    deb-i386\
    \ http://packages.ros.org/ros/ubuntu lucid main\n    deb-i386 http://packages.ros.org/ros/ubuntu\
    \ maverick main\n\n\nOnce apt-mirror is set up, you can mirror the repository\
    \ by running the command:\n\n    sudo su - apt-mirror -c apt-mirror\n\nThis may\
    \ take a while the first time that you run it.  This will download a copy of the\
    \ ROS repository to /var/spool/apt-mirror by default.\n\nYou can now set up Apache\
    \ to point to the mirror so that it is accessible through http.\n\nAs an example,\
    \ here is my Apache configuration (/etc/apache2/sites-available/mirror.<+YOURDOMAIN+>.com)\n\
    \n    <VirtualHost *:80>                                                     \
    \                                                                            \
    \                                                                  \n        ServerName\
    \ mirror.<+YOURDOMAIN+>.com\n        ServerAlias www.mirror.<+YOURDOMAIN+>.com\n\
    \        ServerAdmin XXXXXXX@ieee.org\n        DocumentRoot \"/var/www/mirror.<+YOURDOMAIN+>.com\"\
    \n\n        ErrorLog /var/log/apache2/mirror.<+YOURDOMAIN+>.com/error_log\n\n\
    \         <Directory \"/var/www/mirror.<+YOURDOMAIN+>.com\">\n               \
    \ Options +Indexes\n                Order allow,deny\n                Allow from\
    \ all\n        </Directory>\n\n\n        <IfModule log_config_module>\n      \
    \          TransferLog /var/log/apache2/mirror.<+YOURDOMAIN+>.com/access_log\n\
    \        </IfModule>\n    </VirtualHost>\n\nThen you may enable the site and create\
    \ a symlink to the apt-mirror directory:\n\n    sudo a2ensite mirror.<+YOURDOMAIN+>.com\n\
    \    sudo ln -s /var/spool/apt-mirror/mirror/code.ros.org /var/www/mirror.<+YOURDOMAIN+>.com/archive-ros\n\
    \nYour mirror will be available at http://mirror.<+YOURDOMAIN+>.com/archive-ros/\n\
    \nYou can add it to your local apt repository using the following command:\n\n\
    \    sudo sh -c '. /etc/lsb-release && echo \"deb http://mirror.<+YOURDOMAIN+>.com/archive-ros/packages/ros/ubuntu\
    \ $DISTRIB_CODENAME main\" > /etc/apt/sources.list.d/ros-latest.list'\n\nAnd then\
    \ follow the rest of the ROS install guide.\n\nIt also helps to set up a cron\
    \ task to keep the repository synced, do this by uncommenting the line in /etc/cron.d/apt-mirror\n\
    \n    #                                                                      \
    \                                                                            \
    \                                                                  \n    # Regular\
    \ cron jobs for the apt-mirror package\n    #\n    0 4 * * *   apt-mirror  /usr/bin/apt-mirror\
    \ > /var/spool/apt-mirror/var/cron.log\n\n\n\n"
