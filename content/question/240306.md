    \    import rospy\n    from std_msgs.msg import String, Float64\n\n    rospy.init_node(\"\
    spam\")\n    publishers = []\n    for i in range(6):\n        publishers.append(rospy.Publisher(\"\
    /thermal_zone\"+str(i), Float64))\n\n    def callback(msg):\n        for s, p\
    \ in zip(msg.data.split('\\n'), publishers):\n            p.publish(float(s.split(':')[1]))\
    \        \n    \n    rospy.Subscriber(\"/string_topic\", String, callback)\n \
    \   rospy.spin()\n\nThis is not tested as I do not have the data but it creates\
    \ 6 publishers which are called `thermal_zone0` to `thermal_zone5` like in your\
    \ data. In the callback it tries to split the incoming string based on the line\
    \ break `\\n` which I assume is in there but might be wrong. It then splits the\
    \ string again based on the `:` and takes the right part of it which should be\
    \ the number and then publishes it as a float on the specified topic. In `rqt_plot`\
    \ you have to add all 6 topics and then you get your data.\n\nIf it doesn't work,\
    \ try to add a few `print` statements to the callback and have a look at `s` and\
    \ the result of `s.split(':')`."
