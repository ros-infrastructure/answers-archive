  body_markdown: "`sd`, `qhd` and `hd` are resolutions of the image. Details are given\
    \ in [iai_kinect2 repo](https://github.com/code-iai/iai_kinect2/tree/master/kinect2_bridge#topics).\n\
    \nFor topic names, \n\n`_ir`: infrared image\n\n`_color`: color image\n\n`_depth`:\
    \ depth_image\n\nadditional `_rect` is for rectified image.\n\nIf you use [depth_image_proc](http://wiki.ros.org/depth_image_proc),\
    \ with `point_cloud_xyzrgb` nodelet, you can convert depth images to point clouds.\n\
    \n**Update:**\n\nFor the depth values, asked in comments below, you need to check\
    \ encoding. Encoding given in the question is: `encoding: 16UC1` . This means\
    \ 16-bits unsigned short with 1 channel. So each depth is represented with 2 bytes.\
    \ To convert these bytes to depth, you should also check `is_bigendian: 0` . In\
    \ this question byte order is *little-endian*. As a result, `depth = data[i] +\
    \ (data[i + 1] << 8)` which is also mentioned in comments below.\n\nThe point\
    \ is, you need to check *encoding* and *endianness*."
