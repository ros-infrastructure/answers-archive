    If you are looking to write a device driver, then you probably just want a serial library.  This depends on the language that you want to use.

    For Python, I would use [pyserial](https://pypi.python.org/pypi/pyserial).

    In C++, I would recommend @William's [serial library](https://github.com/wjwwood/serial).  It has an API similar to pyserial, and it is cross-platform and well maintained.  I have used it in several projects.

    If you are looking to communicate with an Arduino or embedded linux, then stick to rosserial
