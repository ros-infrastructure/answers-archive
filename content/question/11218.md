  body_markdown: "org.ros.android comes from the rosjava.android packages (http://code.google.com/p/rosjava/source/checkout?repo=android).\
    \  The other missing jars are most likely built when you build the rosjava package.\
    \  The manifest.xml file of a package specifies dependencies and when you run\
    \ \"rosmake\" on the package it will generate the jar files for each of those\
    \ dependencies.\n\n\nI recommend installing rosjava and rosjava.android from source.\
    \  Here's (hopefully) a helpful guide:\n\n1)\tInstall ROS electric, unstable,\
    \ or later\n        \n        a.\t\u2018sudo apt-get install ros-electric-desktop-full\u2019\
    \ (for electric)\n\n2)\tClone the latest rosjava source from googlecode into a\
    \ directory in your ROS_PACKAGE_PATH\n\n        Install Mercurial (hg) : \u2018\
    sudo apt-get install hg\u2019\n\n        Go to http://code.google.com/p/rosjava/source/checkout\
    \ and Follow \u201CCommand-line access\u201D instructions\n\n3)\tRun \u2018rospack\
    \ profile\u2019 to update your environment\n\n4)\tBuild rosjava\n\n        \u2018\
    rosmake rosjava\u2019\n\n\n**Continue for Andorid setup**\n\n\n1)\tInstall eclipse\n\
    \n        \u2018sudo apt-get install eclipse\u2019\n\n2)\tInstall the Andorid\
    \ SDK\n\n        Follow the instructions at http://developer.android.com/sdk/index.html\n\
    \n3)\tClone the latest rosjava.android source from googlecode into a directory\
    \ in your ROS_PACKAGE_PATH\n\n        Go to http://code.google.com/p/rosjava/source/checkout?repo=android\
    \ and Follow \u201CCommand-line access\u201D instructions\n\n4)\tRun \u2018rospack\
    \ profile\u2019 to update your environment\n\n5)\tBuild rosjava.android \n\n \
    \       \u2018rosmake rosjava.android\u2019\n\n\nFrom here you should have a working\
    \ environment.  To run the tutorials, run \"rosmake\" on the one you want, then\
    \ import it into eclipse.  If you're doing Android dev you may need to import\
    \ android_gingerbread or android_honeycomb_mr2 into eclipse also, and add them\
    \ as project references.\n\nandroid_gingerbread and android_honeycomb_mr2 are\
    \ the packages (eclipse projects) that provide org.ros.rosjava.android.\n\n\n\n\
    To create a new rosjava package you can follow the instructions here : http://www.ros.org/wiki/rosjava/Build\n\
    \nThe only difference for android is that the build.xml file should be : \n\n\
    \    <?xml version=\"1.0\" encoding=\"UTF-8\"?>\n    <project>\n      <property\
    \ file=\"ros.properties\"/>\n      <include file=\"${ros.pkg.rosjava_bootstrap.dir}/android.xml\"\
    />\n    </project>\n\nYou'll also need to set up the right exports.  Add this\
    \ to your manifest.xml file:\n\n    <export>\n      <rosjava-android-lib target=\"\
    android-9\" />\n      <rosjava-src location=\"src\" />\n      <rosjava-src location=\"\
    gen\" />\n      <rosjava-src location=\"res\" />\n    </export>\n\n\nAfter running\
    \ rosmake you should be able to import your the package into eclipse and begin\
    \ development. \n"
