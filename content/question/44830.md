    \ use the new code. \nThe new classes as shown on that wiki page make it easier\
    \ for you to create a custom local planner.\n\nYou can use the sources for 1.9/1.10\
    \ with ros 1.8 as well, the APIs did not change.\n\nAnd to get it, just download\
    \ the sources.\n\n    $ hg pull https://kforge.ros.org/navigation/navigation\n\
    \nwill get you the sources, if you use rosws, you can do\n\n    $ roslocate info\
    \ navigation \n    - hg:\n        local-name: navigation\n        meta:\n    \
    \      repo-name: rosdistro_fuerte\n        uri: https://kforge.ros.org/navigation/navigation\n\
    \        version: navigation-1.8\n\nCopy this to your rosinstall file replacing\
    \ version navigation-1.8 with navigation-1.9.1\n\nAnother way to do this is to\
    \ call\n\n    $ rosws set navigation --hg https://kforge.ros.org/navigation/navigation\
    \ --version=navigation-1.9.1\n"
