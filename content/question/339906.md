  body_markdown: "> it contains a cpp program in the src folder called algorithm_1.cpp\
    \ which I need to run. \n\nthis would appear to be the cause of your problem:\
    \ `.cpp` files are not programs. They are source files which must be compiled\
    \ into binaries first before they can be executed.\n\nSpecifying a `.cpp` file\
    \ as the `type` of a `node` element in a `.launch` file will not work.\n\n>  \
    \   project(dijkstra)    \n>     ...\n>     add_executable(${PROJECT_NAME} src/algorithm_1.cpp)\n\
    \n`dijkstra.cpp` is the *source file*, not the name of the binary (ie: the compiled\
    \ program). That would be `dijkstra`.\n\nIf you remove the `.cpp` from the `type`\
    \ attribute of the `node` element in your `.launch` file, things will probably\
    \ start working (assuming the rest of the `.launch` file is correct)."
