  body_markdown: "You can try the [Carrot Planner](http://wiki.ros.org/carrot_planner),\
    \ it will move the robot straight to the goal position and stop it in front of\
    \ any obstacle.\n\nTo test it you just have to add the following code to the launch\
    \ file where you start move_base:\n\n    <param name=\"base_global_planner\" value=\"\
    carrot_planner/CarrotPlanner\" />\n\nThis is an exemplary launch file:\n\n\n \
    \   <?xml version=\"1.0\"?>\n    <launch>\n    \n      <!-- Start move_base (nav\
    \ stack) node and load config files -->    \n      <node pkg=\"move_base\" type=\"\
    move_base\" respawn=\"false\" name=\"move_base\" output=\"screen\">\n        <rosparam\
    \ file=\"$(find your_pkg)/config/costmap_common_params.yaml\" command=\"load\"\
    \ ns=\"global_costmap\" />\n        <rosparam file=\"$(find your_pkg)/config/costmap_common_params.yaml\"\
    \ command=\"load\" ns=\"local_costmap\" />\n        <rosparam file=\"$(find your_pkg)/config/local_costmap_params.yaml\"\
    \ command=\"load\" />\n        <rosparam file=\"$(find your_pkg)/config/global_costmap_params.yaml\"\
    \ command=\"load\" />\n        <rosparam file=\"$(find your_pkg)/config/base_local_planner_params.yaml\"\
    \ command=\"load\" />\n      \n        <!-- Set the global planner: -->\n    \
    \    <param name=\"base_global_planner\" value=\"carrot_planner/CarrotPlanner\"\
    \ /> \n\n      </node>\n    \n    </launch>\n\n"
