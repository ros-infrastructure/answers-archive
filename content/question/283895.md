  body_markdown: "You have a few options:\n\n - You can use the [ROS parameter server](http://wiki.ros.org/Parameter%20Server)\
    \ with the rosbridge according to [this](http://wiki.ros.org/rosapi). The parameter\
    \ server is more for setting parameters that do not change during the operation\
    \ of the nodes.\n - If you need the parameters to constantly change throughout\
    \ operation then publishing a custom message with all your parameters in it should\
    \ work. Or publishing multiple primitive types (ints, floats) to various subtopics\
    \ such as `/image_params/width` and `/image_params/height` could work if the rosbridge\
    \ doesn't allow custom messages.\n - I would suggest [dynamic reconfigure](http://wiki.ros.org/dynamic_reconfigure),\
    \ but I'm not sure if rosbridge supports it "
