  body_markdown: "I just figured out to solve this, the tutorial in the wiki was pretty\
    \ vague about it. \n\nBasically, what you need to do is to add C:\\Python27\\\
    \ and C:\\Python27\\Scripts to the PATH IN the Setup.bat. Not the path for python\
    \ when you install it the first time.\n\nEdit your PATH in setup.bat so that it\
    \ looks like this -\nset PATH=C:/opt/ros/fuerte/x86/bin;C:\\Python27\\;C:\\Python27\\\
    Scripts;%PATH%\n\nRemember to move the files out from the external Scripts folder(not\
    \ the original Scripts folder found in Python27)."
