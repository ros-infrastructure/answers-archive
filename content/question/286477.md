  body_markdown: "Hello tolga-uni-lu,  \nunfortunately, it is not easy to debug this\
    \ issue. I have also experienced some difficulties while trying to enable RealSense\
    \ products for the first time. \n\nThere are few pieces of advice that may help\
    \ you...\n\n 1. unplug the camera and plug it back again. Try it a couple of times\
    \ while changing USB ports (it has to be USB 3.0). Seems stupid, but it helps\
    \ sometimes.\n 2. Which kernel are you using? I was having difficulties with the\
    \ newest version (4.13) and everything worked fine on 4.8 and 4.4. To be able\
    \ to find out which kernel you are using, you could type `uname -r` in terminal.\
    \ If your kernel is higher version than 4.8, try choosing another when booting.\
    \ In grub menu, you can choose Advanced options and choose which kernel version\
    \ you like. \n 3. `sudo adduser \"username\" plugdev` - I found this [here](https://github.com/intel-ros/realsense/issues/237)\
    \ and the same problem is also mentioned [here](https://github.com/IntelRealSense/librealsense/issues/44)\n\
    \nHowever, if you are using **Creative BlasterX Senz3D**, which should be an **SR300**\
    \ camera. You could **try** the **newer version** of the software. If you take\
    \ a look at RealSense [github](https://github.com/IntelRealSense/librealsense),\
    \ it says:\n\n> Intel\xAE RealSense\u2122 **SDK 2.0** is a cross-platform library\
    \ for Intel\xAE RealSense\u2122 depth cameras (D400 series and the SR300).\nFor\
    \ other Intel\xAE RealSense\u2122 devices (F200, R200, L200 and ZR300), please\
    \ refer to the latest legacy release.\n\nTherefore, if I were you, I would try\
    \ advice 1) and 2). If it does not help, I would follow the instructions [here](http://wiki.ros.org/librealsense2)\
    \ and install the newer version of the software. You just have to have in mind\
    \ that, if you are using librealsense2, you should use [this](http://wiki.ros.org/realsense2_camera)\
    \ ROS package.\n\nThere are many discussions on the realsense [forum](https://communities.intel.com/community/tech/realsense/content?filterID=contentstatus%5Bpublished%5D~category%5Bissues%5D)\
    \ and their github [issues](https://github.com/IntelRealSense/librealsense/issues).\
    \ If the problem persists, you can always post questions there since maybe more\
    \ RealSense users are watching. \n\nHowever, if you have any further questions,\
    \ feel free to ask here. :)\n"
