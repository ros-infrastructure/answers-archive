  body_markdown: "This is fallout from the mechanism we used to create release repositories\
    \ for the Rolling distribution. Contacting affected package maintainers is still\
    \ a pending task of mine but I'll start here and make sure I contact other affected\
    \ packages after. The technical explanation for this error is that the release\
    \ repository configured for rolling is https://github.com/ros2-gbp/system_modes-release.git\
    \ is missing changes from https://github.com/microROS/system_modes-release.git\n\
    \nIn order to be automatically released from Foxy to Rolling, and in order automatically\
    \ release from Rolling to future distributions, the Rolling Release automation\
    \ needs to be able to push to release repositories. For this reason, and as specified\
    \ in [REP 2002](https://www.ros.org/reps/rep-2002.html#managing-build-farm-writable-release-repositories)\
    \ release repositories were created in ros2-gbp if they existed elsewhere. \n\n\
    I'll set up the team for https://github.com/ros2-gbp/system_modes-release and\
    \ add the maintainers of system_modes with the necessary privileges to fully administer\
    \ the release repository and, if you're interested, help transitioning any content\
    \ to the new release repository location from the existing one.\n\n"
