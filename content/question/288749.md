  body_markdown: "It might seem a bit redundant, but that's how I would do it.  \n\
    (I'm assuming you want to keep everything except the position array)   \n1- Define\
    \ a new message. I'm defining it in package `myPkg` and calling it `newMsg`. \n\
    \n    Header header  \n    string[] name\n    float64[] velocity\n    float64[]\
    \ effort\n2- Write a node that on receiving a message (callback), publishes the\
    \ data you want.  \n\n    import rospy  \n    from myPkg.msg import newMsg  \n\
    \    from sensor_msgs.msg import JointState  \n    \n    def callback(msg):  \n\
    \           out.header = msg.header  \n           out.velocity = msg.velocity\
    \  \n           out.effort = msg.effort  \n           pub.publish(out) \n    \n\
    \    \n    rospy.init_node('Scraper')  \n    sub = rospy.Subscriber('in', JointState,\
    \ callback)  \n    pub = rospy.Publisher('out', newMsg)  \n    rospy.spin()  \n\
    Note: If concerned about performance, implement this in the node you're subscribing\
    \ to."
