  body_markdown: "I had the same problem Running Electric on Ubuntu 10.04 with an\
    \ overlay workspace. The problem occured when I moved my ros workspace. Inspecting\
    \ the system with roswtf or rosrun tf tf_monitor failed. \nMy solution was to\
    \ create a symlink from /etc/ros/setup.bash to <ros_workspace>/setup.bash\nAfterwards\
    \ restart turtlebot service.\n\nExplanation:\n\nThe turtlebot service uses the\
    \ file in /etc for configuration. Which points to specific directories.\n\nContent\
    \ of /etc/ros/setup.bash coming from .../turtlebot_bringup/upstart/install.sh\n\
    '. /opt/ros/electric/setup.bash; export ROS_PACKAGE_PATH=/home/turtlebot/ros:${ROS_PACKAGE_PATH}'\n\
    \nThis thread helped me out:\n[http://answers.ros.org/question/28020/difference-between-turtlebot_bringup-minimallaunch-and-turtlebot-service/](http://answers.ros.org/question/28020/difference-between-turtlebot_bringup-minimallaunch-and-turtlebot-service/)\n\
    \nThe install script in fuerte is somewhat more sophisticated but is from my point\
    \ of view also not able to work with overlays."
