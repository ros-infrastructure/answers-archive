    For new windows/widgets/buttons, [GUIOverlays](http://gazebosim.org/api/dev/classgazebo_1_1rendering_1_1GUIOverlay.html) should allow you to put GUI elements like this on top of the World View ([example 1](https://www.youtube.com/watch?v=3ReqYOmt9vo),[2](https://www.youtube.com/watch?v=cFRzn5AgaUo)). I think you're looking to add GUI elements to the main window, but I suspect this cannot be done with plugins.

    **Edit:**
    For key presses, I just found `gui::Events::ConnectKeyPress` in [/examples/plugins/presentation.cc](https://bitbucket.org/osrf/gazebo/src/af4e4e3ee77053e6b960a7ad2211586aa7fe37ad/examples/plugins/presentation.cc?at=default) that looks like it does what you need.
