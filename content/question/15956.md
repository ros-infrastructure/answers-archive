    The `JointController` class uses the [SetVelocityTarget](http://osrf-distributions.s3.amazonaws.com/gazebo/api/5.0.0/classgazebo_1_1physics_1_1JointController.html#aa955b4b4ce49e67a8154d7d174ef8619) function to set a target velocity for a joint's axis. If that joint is rotational, that will be an angular velocity given in rad/s. If it's a prismatic joint, that will be a linear velocity given in m/s.
