    It seems that you do not have installed the joystick drivers package [joy](http://wiki.ros.org/joy). Try to install it using the command

        sudo apt-get install ros-hydro-joy

    I added it as a run dependency to [hector_quadrotor_teleop](http://wiki.ros.org/hector_quadrotor_teleop) to have it automatically installed in future releases of hector_quadrotor (see [commit](https://github.com/tu-darmstadt-ros-pkg/hector_quadrotor/commit/8674bbcacfe3b66c9832d347be6d462bcf490ee0)).

    The left stick controls vertical velocity and yaw rate, while the right stick controls x and y velocity (mode 2). The joystick/gamepad buttons are currently unused.
