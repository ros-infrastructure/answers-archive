  body_markdown: "Below is the configuration that I used to successfully launch two\
    \ observation sources in my costmaps. I'd guess you may have forgotten to add\
    \ the second source to the list of sources in the `observation_sources` parameter.\
    \ \n\n    observation_sources: sick_lms_1 sick_lms_2\n\n    sick_lms_1: {sensor_frame:\
    \ sick_1,\n            data_type: LaserScan,\n            topic: /scan_1,\n  \
    \          expected_update_rate: 0.4,\n            observation_persistence: 0.0,\n\
    \            marking: true,\n            clearing: true,\n            min_obstacle_height:\
    \ 0.0,\n            max_obstacle_height: 2.0,\n            obstacle_range: 9.0,\n\
    \            raytrace_range: 10.0}\n\n    sick_lms_2: {sensor_frame: sick_2,\n\
    \            data_type: LaserScan,\n            topic: /scan_2,\n            expected_update_rate:\
    \ 0.4,\n            observation_persistence: 0.0,\n            marking: true,\n\
    \            clearing: true,\n            min_obstacle_height: 0.0,\n        \
    \    max_obstacle_height: 2.0,\n            obstacle_range: 9.0,\n           \
    \ raytrace_range: 10.0}"
