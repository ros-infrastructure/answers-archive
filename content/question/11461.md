  body_markdown: "@DimitriProsser is right, but you need to use [xacro](http://www.ros.org/wiki/xacro)\
    \ for this to work. Your urdf file should look like this (let's say it's called\
    \ `wam_description/wam.urdf.xacro`):\n\n    <robot\n      xmlns:xacro=\"http://ros.org/wiki/xacro\"\
    \n      name=\"wam\">\n    \n      <include filename=\"$(find wam_gazebo)/urdf/your_file.urdf\"\
    \ />\n    </robot>\n\nNow you can load the URDF file into the `robot_description`\
    \ parameter using this launch file:\n\n    <launch>\n        <param name=\"robot_description\"\
    \ command=\"$(find xacro)/xacro.py '$(find wam_description)/wam.urdf.xacro'\"\
    \ />\n    </launch>"
