    \ The callback won't be called if the topic is never published by another node.\n\
    \n- If you still have issue despite correct publication, create a simple node\
    \ that does only the subscription to \n\"goal_pose\" and callback to make sure\
    \ everything is fine on the ROS side. \n\n- You have lots of code in your callbacks.\
    \ Start by keeping it simple - for example, display a message. You might block\
    \ your node for too long. I'd personally advise to keep callbacks simple - use\
