  body_markdown: "It should look similar to this:\n\n* In your launch files:\n\n \
    \    `remappings = [('/tf', 'tf'), ('/tf_static', 'tf_static')]`\n\n* and then\
    \ in each of your nodes using `/tf`:\n\n        Node(\n            package='your_package',\n\
    \            executable='your_package_executable',\n            namespace=namespace,\n\
    \            parameters=[parameters],\n            remappings=remappings\n   \
    \     ),\n\n* in your `urdf.xacro` you should have:\n\n`<xacro:property name=\"\
    robot_namespace\" value=\"/$(arg namespace)\"/>`\n\n* in your YAML config files\
    \ for e.g. Nav2 and in Python launchers - use `from launch.substitutions import\
    \ LaunchConfiguration, PythonExpression, Command, TextSubstitution` and `from\
    \ nav2_common.launch import ReplaceString, RewrittenYaml`, something like:\n\n\
    `odom_topic: /namespace/odom` etc. in YAML and `namespaced_params= ReplaceString(source_file=param_dir,\
    \ replacements={\"/namespace\":(\"/\",namespace)})` in Python launch files. \n\
    \n\n\nI used it to distinguish themes, services and actions for two and more robots\
    \ in ROS2 Gazebo simulation. It works ok, so I think such a thing should be at\
    \ least acceptable :)"
