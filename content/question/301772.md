  body_markdown: "Hey there,\n\nI kind of faced a similar situation earlier but was\
    \ able to fix it with a slight change without any installation/uninstallation.\
    \ \n\nYou might have figured this out already but I'll put the fix here as it\
    \ might be helpful for others.\n\nThe problem is the gzclient's `setup_path` variable.\
    \ \n\nEdit the `/opt/ros/kinetic/lib/gazebo_ros/gzclient` file by replacing this\
    \ line:\n\n    setup_path=$(pkg-config --variable=prefix gazebo)/share/gazebo/\n\
    \nwith this line:\n\n    setup_path=/usr/share/gazebo/\n\nThen everything worked\
    \ well for me. "
