  body_markdown: "You have to use the `message_filter` package.\n\nAmong the other\
    \ things, this allows you to create synchronized callbacks.\nYou can use it to\
    \ define callbacks which takes more than 1 message as argument.\nNote that all\
    \ messages must have an `header` field with the timestamp.\n\n    void sync_callback(const\
    \ StampedStringMsg::SharedPtr string_msg, const StampedBooleanMsg::SharedPtr bool_msg)\n\
    \    {\n      std::cout<<\"Received msg: \"<< string_msg->data<< \" and msg \"\
    \ << bool_msg->data<<std::endl;\n    }\n\n\nYou need to choose a synchronization\
    \ strategy: exact or approximate. The first one will require that both messages\
    \ have the exact same timestamp in order for the callback to be triggered. The\
    \ other will use heuristics to try to match messages with slightly different timestamps.\n\
    \n\n      // create subscribers to the topics of interest\n      message_filters::Subscriber<StampedStringMsg>\
    \ string_sub(node, \"stamped_string_topic\", qos_profile);\n      message_filters::Subscriber<StampedBooleanMsg>\
    \ bool_sub(node, \"stamped_boolean_topic\", qos_profile);\n    \n      // exact\
    \ time policy\n      typedef message_filters::sync_policies::ExactTime<StampedStringMsg,\
    \ StampedBooleanMsg> exact_policy;\n      message_filters::Synchronizer<exact_policy>syncExact(exact_policy(10),\
    \ string_sub, bool_sub);\n    \n      // register the exact time callback\n  \
    \    syncExact.registerCallback(sync_callback);\n\n\nYou can find a full working\
    \ example here https://github.com/alsora/ros2-code-examples#time-synchronization-message-filters"
