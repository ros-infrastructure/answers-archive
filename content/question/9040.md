  body_markdown: "From the tf wiki page on [tf/data types](http://www.ros.org/wiki/tf/data%20types)\n\
    \n[tf](http://ros.org/wiki/tf) can be used either with the underlying Bullet transform\
    \ types or with the transform types available in the geometry_msgs package. Since\
    \ tf deals with coordinate frames, every datatype that tf uses needs to be stamped,\
    \ i.e. extra information is added to the datatype to represent the name of the\
    \ frame in which it lives and a timestamp. The timestamp typically represents\
    \ the time at which the data was created/ last valid.\n\ntf can directly operate\
    \ on the following messages or Bullet datatypes:\n\n* Pose - tf can transform\
    \ poses by using the [tf::transformPose](http://www.ros.org/doc/api/tf/html/classtf_1_1TransformListener.html#502cbf4e7d4aa2ad822c830629957bdf/)\
    \ function. The transformPose function can operate on:\n * [geometry_msgs/PoseStamped](http://www.ros.org/doc/api/geometry_msgs/html/msg/PointStamped.html)\
    \ - A stamped representation of a pose expressed in a particular frame\n * `tf::Stamped<tf::Pose>`\
    \ - A templated stamped representation of the underlying Bullet datatype btTransform.\
    \ \n*  Position - tf can transform positions (or points) using the [tf::transformPoint\
    \ ](http://www.ros.org/doc/api/tf/html/classtf_1_1TransformListener.html#502cbf4e7d4aa2ad822c830629957bdf/)function.\
    \ The transformPoint function can operate on:\n * [geometry_msgs/PointStamped](http://www.ros.org/doc/api/geometry_msgs/html/msg/PointStamped.html)\
    \ - Represents a stamped point in 3D.\n * `tf::Stamped<tf::Point>` - A stamped\
    \ version of the underlying Bullet datatype [btVector3](http://www.bulletphysics.com/Bullet/BulletFull/classbtVector3.html).\
    \ \n* Rotation - tf can transform a rotation using the [tf::transformQuaternion](http://www.ros.org/doc/api/tf/html/classtf_1_1TransformListener.html#502cbf4e7d4aa2ad822c830629957bdf/)\
    \ function. The transformQuaternion function can operate on:\n * [geometry_msgs/QuaternionStamped](http://www.ros.org/doc/api/geometry_msgs/html/msg/QuaternionStamped.html)\
    \ - A stamped representation of a quaternion.\n * `tf::Stamped<tf::Quaternion>`\
    \ - A stamped version of the underlying Bullet datatype [btQuaternion](http://www.bulletphysics.com/Bullet/BulletFull/classbtQuaternion.html).\
    \ \n* Vector - tf can transform a free vector using the [tf::transformVector](http://www.ros.org/doc/api/tf/html/classtf_1_1TransformListener.html#502cbf4e7d4aa2ad822c830629957bdf/)\
    \ function. The tranformVector function can operate on:\n * [geometry_msgs/VectorStamped](http://www.ros.org/doc/api/geometry_msgs/html/msg/VectorStamped.html)\
    \ - A stamped representation of a free vector.\n * `tf::Stamped<tf::Vector3>`\
    \ - A stamped version of the underlying Bullet datatype [btVector](http://www.bulletphysics.com/Bullet/BulletFull/classbtVector3.html).\
    \ \n\n* PointCloud - tf can transform point clouds directly using the [tf::transformPointCloud](http://www.ros.org/doc/api/tf/html/classtf_1_1TransformListener.html#502cbf4e7d4aa2ad822c830629957bdf/)\
    \ function. This function operates on:\n * [sensor_msgs/PointCloud](http://www.ros.org/doc/api/sensor_msgs/html/msg/PointCloud.html)\
    \ - A representation of a 3D point cloud. "
