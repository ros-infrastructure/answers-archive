  body_markdown: "For now, the best thing to do is to follow the [template provided\
    \ in gazebo_plugins](https://code.ros.org/svn/ros-pkg/stacks/simulator_gazebo/trunk/gazebo_plugins/src/gazebo_ros_template.cpp)\
    \ or mimic any of the examples in [gazebo_plugins](http://ros.org/wiki/gazebo_plugins).\
    \  Also take a look at [gazebo configuration page](http://www.ros.org/wiki/simulator_gazebo/GazeboConfiguration)\
    \ to see how to setup plugin paths in your own packages. \n\n<strong>Please keep\
    \ in mind, plugin API's will change soon in F-Turtle, and will require some significant\
    \ migratory changes/rewrites.</strong>\n\nProceeding on with the current setup,\
    \ if you take a look at the template presented, there are 4 relevant member functions,\n\
    \n - constructor - this is called once when the plugin is instantiated in `Model::Load(...)`\n\
    \ - InitChild() - this is called once during `Model::Init()`\n - UpdateChild()\
    \ - this is called once per `Model::Update()` call\n - FiniChild() - this is called\
    \ once when a Model / Body is deleted, or simulator is shutting down, before destruction\
    \ happens\n - destructor\n\nThe new plugin API for gazebo 1.0.0 RC to be released\
    \ with Fuerte is described on the [new gazebo wiki](http://gazebosim.org/wiki/plugins).\
    \  Conversion from old plugin to the new format requires [rewrite work described\
    \ here](http://gazebosim.org/wiki/plugins/converting_old_plugins)."
