  body_markdown: "The reason for this is probably the fact, that the move_base node\
    \ is looking for `base_footprint` in the global namespace. My solution for this\
    \ was to overwrite the parameters in the `yaml` files you load in via `rosparam`\
    \ with `params`:\n\n    <group ns=\"$(arg robot_name)\">\n            <param name=\"\
    tf_prefix\" value=\"$(arg robot_name)\" />\n    \n            <!-- Other stuff\
    \ like loading in the model etc. -->\n    \n            <node pkg=\"fake_localization\"\
    \ type=\"fake_localization\" name=\"fake_localization\" respawn=\"false\" output=\"\
    screen\">\n                <param name=\"odom_frame_id\" value=\"$(arg robot_name)/odom\"\
    \ />\n                <param name=\"base_frame_id\" value=\"$(arg robot_name)/base_footprint\"\
    \ />\n                <remap from=\"base_pose_ground_truth\" to=\"/$(arg robot_name)/odom\"\
    />\n                <param name=\"global_frame_id\" value=\"/map\"/>\n       \
    \     </node>\n    \n            <node pkg=\"move_base\" type=\"move_base\" respawn=\"\
    false\" name=\"move_base\" output=\"screen\">\n                <param name=\"\
    base_local_planner\" value=\"dwa_local_planner/DWAPlannerROS\" />\n          \
    \      <rosparam file=\"$(find [package_name])/param/costmap_common_params_$(arg\
    \ model).yaml\" command=\"load\" ns=\"global_costmap\" />\n                <rosparam\
    \ file=\"$(find [package_name])/param/costmap_common_params_$(arg model).yaml\"\
    \ command=\"load\" ns=\"local_costmap\" />\n                <rosparam file=\"\
    $(find [package_name])/param/local_costmap_params.yaml\" command=\"load\" />\n\
    \                <rosparam file=\"$(find [package_name])/param/global_costmap_params.yaml\"\
    \ command=\"load\" />\n                <rosparam file=\"$(find [package_name])/param/move_base_params.yaml\"\
    \ command=\"load\" />\n                <rosparam file=\"$(find [package_name])/param/dwa_local_planner_params_$(arg\
    \ model).yaml\" command=\"load\" />\n    \n                <param name=\"controller_frequency\"\
    \ value=\"10.0\" />\n                <param name=\"global_costmap/robot_base_frame\"\
    \ value=\"$(arg robot_name)/base_footprint\"/>\n                <param name=\"\
    local_costmap/robot_base_frame\" value=\"$(arg robot_name)/base_footprint\"/>\n\
    \                <param name=\"local_costmap/global_frame\" value=\"$(arg robot_name)/odom\"\
    />\n\n                <remap from=\"map\" to=\"/map\" />\n            </node>\n\
    \    </group>\n\nwhere the argument with name `robot_name` is the name of the\
    \ robot.\nHope that helps :)"

Timed out waiting for transform from base_footprint to map to become available before running costmap, tf error: canTransform: source_frame base_footprint does not exist.. canTransform returned after 0.101 timeout was 0.1.

I've messed with a bunch of different things and originally followed this ([https://answers.ros.org/question/41433/multiple-robots-simulation-and-navigation/]) answer but haven't been able to make any progress.
