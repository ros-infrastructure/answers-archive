    \ the Windows SDK, not the Linux one, which means that it's the same for ROS users\
    \ to use Kinect for XBOX or Kinect for PC (unless you are using ROS for Windows\
    \ which is not a stable version)\n\nMy advice, if you want to buy a new Kinect,\
    \ is to prefer the Kinect v2 for XBOX ONE, which is better than Kinect v1 for\
    \ XBOX 360 :\n\n - HD resolution: 1960x1028 30fps (compared to 640x480 for v1)\n\
    \ - Larger range depth sensor: 512x424 (compared to 320x240)\n - Larger field\
    \ of view: 70x60 degrees (compared to 57x43)\n - USB 3.0 support\n\nAnd of course,\
    \ this version is [compatible with ROS](http://www.ros.org/news/2014/09/microsoft-kinect-v2-driver-released.html)\n\
