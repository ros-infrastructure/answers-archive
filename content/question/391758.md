  body_markdown: "First you need to be able to listen to the joystick in a separate\
    \ node to listen when the button is pressed, so assuming you already have that,\
    \ then you can use the `roslaunch api`: http://wiki.ros.org/roslaunch/API%20Usage\n\
    \nBelow the example shown in tutorial:\n\n    import roslaunch\n    \n    package\
    \ = 'rqt_gui'\n    executable = 'rqt_gui'\n    node = roslaunch.core.Node(package,\
    \ executable)\n    \n    launch = roslaunch.scriptapi.ROSLaunch()\n    launch.start()\n\
    \    \n    process = launch.launch(node)\n    print process.is_alive()\n    process.stop()\n\
    \nOf course you will replace `rqt_gui` with your package and executable applicable\
    \ to your application."
