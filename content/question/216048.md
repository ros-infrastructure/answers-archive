    I found the problem: for some reason, the `catkin_find` command which is executed in rosrun script was not installed. A bit weird, since other packages depend on this one.

    Anyway, [installing catkin](http://wiki.ros.org/catkin), in my case `opkg install catkin` solved the problem.

    *EDIT*: I had the problem again on a different platform and I had to do:
    `source /opt/ros/indigo/share/rosbash/rosbash` to make it work.
