  body_markdown: "You are correct. The data you get from your sensors are in their\
    \ own frame of reference. For distance / range measurements, its often a good\
    \ idea to have them in the frame of reference of your robot; usually `base_link`.\n\
    Fortunately ROS provides the tf library for this purpose. You can find [more information\
    \ here](http://wiki.ros.org/tf).\n\nI highly recommend you go through their [tutorials](http://wiki.ros.org/tf/Tutorials)\
    \ but the one you are looking for is a tf listener [python](http://wiki.ros.org/tf/Tutorials/Writing%20a%20tf%20listener%20%28Python%29)\
    \ / [C++](http://wiki.ros.org/tf/Tutorials/Writing%20a%20tf%20listener%20%28C%2B%2B%29).\n\
    \nOnce you have this transform, you can apply it to your scan. Unfortunately laserscans\
    \ aren't very easy to work with and I'd suggest you convert your scan to a PointCloud2\
    \ msg and use the features PCL has to offer. \n\n**EDIT:** Based on your LiDAR\
    \ scan msg type, here are my suggestions:\n\nUse the `laserscan_to_pointcloud`\
    \ package to convert your `laserscan` to `PointCloud2` type. You can just include\
    \ this into your launch file:\n\n    <node pkg=\"pointcloud_to_laserscan\" type=\"\
    laserscan_to_pointcloud_node\" name=\"laserscan_to_pointcloud\">\n        <remap\
    \ from=\"scan_in\" to=\"/<your scan topic>\"/>\n        <remap from=\"cloud\"\
    \ to=\"/<your cloud topic>\"/>\n    </node>\n\nThen, in your LiDAR callback, convert\
    \ from ROS type to PCL type, lookup tf and apply it to your data. This is a simple\
    \ pipeline\n\n    void CloudCallback(const sensor_msgs::PointCloud2ConstPtr &cloud_in)\
    \ \n    {\n    // copy point cloud\n    pcl::PointCloud<pcl::PointXYZ>::Ptr cloud(new\
    \ pcl::PointCloud<pcl::PointXYZ>);\n    pcl::fromROSMsg(*cloud_in, *cloud);\n\
    \    \n    // Transform point cloud\n    try {\n      transform_stamped = tf_buffer.lookupTransform(\"\
    base_link\",\n                                                cloud_in->header.frame_id,\n\
    \                                                ros::Time(0),\n             \
    \                                   ros::Duration(1));\n    } catch (tf2::TransformException\
    \ &ex) {\n      ROS_ERROR(\"%s\", ex.what());\n      return;\n    }\n    \n  \
    \  // apply transform to point cloud\n    Eigen::Affine3d pc_to_base_link = tf2::transformToEigen(transform_stamped);\n\
    \    pcl::transformPointCloud(*cloud, *cloud,\n                             pc_to_base_link);\n\
    \    \n    /* \n    Use cloud as you normally would \n    */\n    \n    // convert\
    \ back to ROS\n    sensor_msgs::PointCloud2 cloud_out;\n    pcl::toROSMsg(*cloud,\
    \ cloud_out);\n    cloud_out.header.frame_id = cloud_in->header.frame_id;\n  \
    \  cloud_out.header.stamp = ros::Time::now();\n    \n    // publish\n    publisher.publish(cloud_out);\n\
    \    \n    }"
