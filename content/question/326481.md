  body_markdown: "The colors of objects shown in the moveit visualisations are defined\
    \ by the RVIZ plugin. You cannot define specific colors for individual objects.\
    \ \n\nYou could use a [visualisations marker topic](http://wiki.ros.org/rviz/DisplayTypes/Marker)\
    \ to achieve what you want though. If you add a marker that uses the frame of\
    \ the robots end effector and set it's `frame_locked` parameter to true then it\
    \ will move as the robot moves. However this object will not be visible in the\
    \ planning preview.\n\nHope this helps. "
