  body_markdown: "If you're having any issues with the publishing, part of the problem\
    \ may be that you're creating your publisher inside of your callback function.\
    \ What you should do is create it inside your `listener` function so you're not\
    \ re-instantiating it every time your a message is published on the `/ccc` topic.\
    \ \n\nFor example:\n\n    #!/usr/bin/env python\n    import rospy\n    from std_msgs.msg\
    \ import String\n    #added\n    from geometry_msgs.msg import Twist \n    \n\
    \    \n    def callback(data):\n        global msg\n        global pub\n     \
    \   if data.data==\"Unknown\":\n            rospy.loginfo(\"Classifiers output:\
    \ %s in unknown\" % data.data)\n            msg.linear.x = 2\n            msg.linear.y\
    \ = 2\n            msg.angular.z = 0\n            speed = 0.4 \n            rospy.loginfo(\"\
    checking for cmd\" + str(msg.linear))\n            pub.publish(msg)\n        elif\
    \ data.data==\"Check\":\n            rospy.loginfo(\"Classifiers output: %s in\
    \ check\" % data.data)\n        else:      \n            rospy.loginfo(\"Classifiers\
    \ output: %s and not unknown or check\" % data.data)\n    \n    \n    \n    def\
    \ listener():\n         global msg\n         rospy.init_node('listener', anonymous=True)\n\
    \         msg = Twist()\n         rospy.Subscriber(\"ccc\", String, callback)\n\
    \         global pub\n         pub = rospy.Publisher('cmd_vel', Twist, queue_size=10)\
    \ # move instantiation of publisher\n         rospy.spin()\n    \n    \n    if\
    \ __name__ == '__main__':\n        listener()\n\nAlthough, what you most likely\
    \ would want to do is create a class to do this since the use of globals isn't\
    \ always the greatest of ideas."
