  body_markdown: "Copying my answer from http://answers.ros.org/question/10714/start-and-stop-rosbag-within-a-python-script/#219520\
    \ (which wasn't really answering it for python, it really belongs here)\n\nThe\
    \ best solution to programmatic rosbag recording I've found is to wrap rosbag::Recorder\
    \ in a C++ node.  There isn't a way to shutdown recording in Recorder, but there\
    \ can be a subscriber in the recorder wrapper node which calls ros::shutdown which\
    \ will cleanly close the current recording bag file, and then the the node can\
    \ be set to respawn=true.  The exclude list can be passed in as a parameter and\
    \ then useful other parameters set like below, or have params override defaults\
    \ as desired:\n\n      recorder_options_.exclude_regex = some_string_from_ros_param;\n\
    \      ROS_INFO_STREAM(\"exclude list \\\"\" << recorder_options_.exclude_regex\
    \ << \"\\\"\");\n    \n      recorder_options_.record_all = true;    \n      recorder_options_.trigger\
    \ = false;\n      recorder_options_.regex = false;\n      recorder_options_.do_exclude\
    \ = true;\n      recorder_options_.quiet = false;\n      recorder_options_.append_date\
    \ = true;\n      recorder_options_.verbose = false;\n      recorder_options_.buffer_size\
    \ = 1048576 * 512;\n      recorder_options_.chunk_size = 1024 * 768;\n      recorder_options_.limit\
    \ = 0; // 0 is unlimited\n      recorder_options_.split = true;\n      recorder_options_.max_size\
    \ = 1024 * 1024 * 1024;\n      recorder_options_.min_space = 1024 * 1024 * 1024;\n\
    \      recorder_options_.min_space_str = \"Recording space is running out\";  "
