I am working with the ROS2 tutorial here https://emanual.robotis.com/docs/en/platform/turtlebot3/ros2_simulation/#turtlebot3-simulation-using-fake-node. I am using the default configuration file from the turtlebot3 package, '[turtlebot3_lds_2d.lua](https://github.com/ROBOTIS-GIT/turtlebot3/blob/master/turtlebot3_slam/config/turtlebot3_lds_2d.lua)'. Unfortunately, the map generated is quite incorrect and seems to be changing quite frequently.
