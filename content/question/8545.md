    Due to large inertia ratio, you'll have to either:

     1. increase `iters` parameter [see this example snippet](https://bitbucket.org/osrf/gazebo/src/7c6a01286318e41ff16b1535aae344a67437fb3b/test/worlds/force_torque_test.world?at=default#cl-9), here iters is set to 1000. You may want to start with order of magnitude test, try 100, 1000, 10000, etc.
     1. use inertia ratio reduction in ode. [see this example](https://bitbucket.org/osrf/gazebo/src/7c6a01286318e41ff16b1535aae344a67437fb3b/test/worlds/inertia_ratio_pendulum.world?at=default#cl-12)
     1. use a different solver/physics engine. See [this tutorial on profiles](http://gazebosim.org/tutorials?tut=preset_manager&cat=physics)
