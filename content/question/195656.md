  body_markdown: "I think you should have a look at these links ([freenect_camera](http://wiki.ros.org/freenect_camera),\
    \ [openni_camera](http://wiki.ros.org/openni_camera), [freenect_stack](http://wiki.ros.org/freenect_stack)).\
    \ You can `apt-get install` these packages directly if you have a debian Hydro\
    \ already installed. alternatively you can also `clone and build` each package\
    \ in your `catkin workspace` and source the `devel/setup.bash` to work with these\
    \ packages. \n\nFor. eg:\n> mkdir -p ~/catkin_ws/src\n\n> cd  ~/catkin_ws/src\
    \ \n\n> git clone https://github.com/ros-drivers/openni_camera.git\n\n> cd ..\
    \ \n\n> catkin_make\n\n> source ~/catkin_ws/devel/setup.bash\n\nand finally you\
    \ can do\n\n> roscd openni_camera \n\nto check if your ROS is able to see this\
    \ package or not. Hope this helps.\n\n"
