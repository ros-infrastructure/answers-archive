  body_markdown: "RGBDSLAM requires /camera/depth/image (which contains float values\
    \ in meter), not /camera/depth/image_raw (which provides 16bit integer values\
    \ in mm).\nIf you don't want to re-record the data and know C++, you can add a\
    \ conversion in src/openni_listener.cpp in the method \n\n    void OpenNIListener::noCloudCallback\
    \ (const sensor_msgs::ImageConstPtr& visual_img_msg,...)\n\nThere are two lines:\n\
    \n    cv::Mat depth_float_img = cv_bridge::toCvCopy(depth_img_msg)->image;\n\n\
    Add changes s.t. the image is converted to float and meter there.\n\nPlease try:\n\
    \n    cv::Mat depth_float_img2;\n    depth_float_img.convertTo(depth_float_img2,CV_32FC1);\n\
    \    depth_float_img = depth_float_img2 * 0.001\n\nThis should avoid all problems\
    \ with casting and inplace. Hope that helps with the crash. Otherwise try setting\
    \ the debug-flag in the launchfile (line 9) and see where (and hopefully why)\
    \ it crashes."
