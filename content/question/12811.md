  body_markdown: "Probably the best example of integration between a 3rd-party program\
    \ and ROS is [Gazebo](http://ros.org/wiki/gazebo). The situation depends on your\
    \ external library though. \n\nIf your C program provides a communication API,\
    \ you could write a ROS node that will interface with that API. Essentially, it\
    \ would be a bridge between ROS and your C program. In this case, it would be\
    \ very similar to writing a ROS driver for devices and very similar to Gazebo.\
    \ \n\nIf your C program does not expose any methods of communication, you're going\
    \ to have to modify the source code such that it does. For that, you can see [this](http://answers.ros.org/question/3277/wrap-existing-crrcsim-project-in-ros)\
    \ question for some help. \n\n**EDIT**:\n\nYou cannot include ROS's libraries\
    \ in your C program because ROS is written in C++ and depends heavily on other\
    \ C++ libraries (Boost, Eigen, etc.). What you need to do is expose the functions\
    \ of your C program and wrap them in C++. This would allow you to use ROS with\
    \ your application easily. Essentially, you would write a C++ application that\
    \ instantiates and instance of your C application and collects and sends data\
    \ via function calls. \n\nHere is a quick, and very simplified example:\n\n  \
    \  // My ROS application\n    #include \"C_application_header.h\"\n\n    class\
    \ My_New_App\n    {\n        My_New_App()\n        {\n            C_Application\
    \ my_c_application;\n            my_c_application->start();\n        }\n    }\n\
    \    "
