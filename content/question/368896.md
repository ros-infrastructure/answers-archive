  body_markdown: "Hi there, I found a solution here : https://roboticsbackend.com/ros-import-python-module-from-another-package/\
    \ \n\n**edit :**\n\nAs mentioned in the blog :\n**Step 1:** create a **setup.py**\
    \ file inside my Package (**myPkg**) folder and posted this code :\n\n    from\
    \ distutils.core import setup\n    from catkin_pkg.python_setup import generate_distutils_setup\n\
    \    d = generate_distutils_setup(\n        packages=['myPkg'],\n        package_dir={'':\
    \ 'src'}\n    )\n    setup(**d)\n\nand just save the file without executing it.\n\
    \n**Step 2:** Create a Folder inside *./myPkg/src/*  with the same name as the\
    \ pakage (myPkg).\n\n**Step 3:** Go to *./myPkg/src/myPkg/* and Create a new file\
    \ **__init__.py** and save it as an empty file.\n\n**Step 4:** In the same folder,\
    \ Create and save the python module files (**myModule.py**) you want to import\
    \ in your node later. *Note : Make sure to `import rospy` in that module*\n\n\
    **Step 5:** Go back to the package folder *./myPkg/* , open `CMakeLists.txt` and\
    \ uncomment the line `catkin_python_setup()` and save the file.\n\n**Step 6:**\
    \ Go back to your catkin workspace folder where myPkg package is, say `cd ~/catkin_ws/`\
    \ and do `catkin_make`.\n\nNow, if I create a python node in *./myPkg/src/* ,\
    \ I can import **myModule.py** using the line `from myPkg import myModule`.\n\n\
    Tried it, and it worked perfectly for me.\n\nHope it helps."
