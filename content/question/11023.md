    \ tried to run rosserial_python from within the package of a custom message. \
    \ Python automatically adds the working directory of a python executable to the\
    \ python sys.path.  As a result, when rosserial_python went to check if it had\
    \ the package in its sys.path, it found the current working directory. I just\
    \ updated the code to check for the src directory of the package instead of just\
    \ the package name.  It should work now.\n\nJust pull the latest repo. "
