    Hi Skhan,
    sorry for the late reply, one way to do this is to create a model plugin, for example, see [this tutorial on how to create a model plugin](http://gazebosim.org/wiki/Tutorials/1.5/plugins/model_manipulation_plugin).  In the plugin update loop, you can get the force torque information from one of the joints in the model by calling:

    <pre>
        physics::JointWrench wrench = this->model->GetJoint("...your model joint name...")->GetForceTorque(0u);
    </pre>

    On the [SDF](http://gazebosim.org/sdf/dev.html) side, in your model, you must set `<provide_feedback>` to true for this to work.
