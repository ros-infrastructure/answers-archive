  body_markdown: "With the release version the robot is not moving because there is\
    \ a conflict with the cmd_vel topic name. The navigation publishes the twist command\
    \ to /base_controller/command and gazebo is subscribed to /base/twist_controller/command.\
    \ \n\nThe problem is already fixed but, at the moment, you have to use the actual\
    \ source version. \nYou can create a cob3-2_navigation.rosinstall file with the\
    \ following lines:\n\n     - git:\n        uri: 'https://github.com/ipa320/cob_common.git'\n\
    \        local-name: cob_common\n        version: indigo_dev\n    - git:\n   \
    \     uri: 'https://github.com/ipa320/cob_control.git'\n        local-name: cob_control\n\
    \        version: indigo_dev\n    - git:\n        uri: 'https://github.com/ipa320/cob_driver.git'\n\
    \        local-name: cob_driver\n        version: indigo_dev\n    - git:\n   \
    \     uri: 'https://github.com/ipa320/cob_robots.git'\n        local-name: cob_robots\n\
    \        version: indigo_dev\n    - git:\n        uri: 'https://github.com/ipa320/cob_navigation.git'\n\
    \        local-name: cob_navigation\n        version: indigo_dev\n    \n     \n\
    And install the necessary packages using the commands:\n\n    rosinstall ~/YourWorkSpace/src\
    \ cob3-2_navigation.rosinstall\n    rosdep install --from-path ~/YourWorkSpace/src\
    \ -i -y\n    source ~/YourWorkSpace/devel/setup\n\n\n"
