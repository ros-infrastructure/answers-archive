  body_markdown: "In response to [your comment here](http://answers.ros.org/question/246095/publish-on-my_robotcmd_vel-using-teleop/?comment=246132#post-id-246132),\
    \ running multiple robots off of multiple joysticks is a different issue entirely,\
    \ but luckily something you can do without source changes. (Note that the group\
    \ namespace is the same as apply the same namespace to each node in the group,\
    \ or remapping each topic and parameter to \"ns/<topic>\". If you have a launchfile\
    \ that works for one joy instance, you can also `<include>` that file in each\
    \ group instead.\n\n      <group ns=\"js0\">\n          <node name=\"joy\" pkg=\"\
    joy\" type=\"joy_node\" output=\"screen\">\n            <param name=\"dev\" value=\"\
    /dev/input/js0\"/>\n          </node>\n    \n          <node name=\"$(anon teleop_twist_joy)\"\
    \ pkg=\"teleop_twist_joy\" type=\"teleop_node\">\n            <rosparam command=\"\
    load\" file=\"$(find locus_joy)/config/joy.yaml\"/>\n          </node>\n     \
    \ </group>\n    \n      <group ns=\"js1\">\n          <node name=\"joy\" pkg=\"\
    joy\" type=\"joy_node\" output=\"screen\">\n            <param name=\"dev\" value=\"\
    /dev/input/js1\"/>\n          </node>\n    \n          <node name=\"$(anon teleop_twist_joy)\"\
    \ pkg=\"teleop_twist_joy\" type=\"teleop_node\">\n            <rosparam command=\"\
    load\" file=\"$(find locus_joy)/config/joy.yaml\"/>\n          </node>\n     \
    \ </group>\n\nIf you wanted to run multiple robots off of a single joystick, you\
    \ could stickto one joy node, but launch multiple teleop_twist_joy nodes with\
    \ complimentary configurations and different cmd_vel remaps.\n"
