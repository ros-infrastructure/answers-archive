    Those tutorials were created for using CloudSim with Amazon Web Services. The current version of CloudSim only works with SoftLayer cloud provider. If you are using CloudSim for the DARPA VRC, read the [VRC User Guide](http://gazebosim.org/wiki/CloudSim/VRCUserGuide) for detailed instructions of how to use the latest version of CloudSim with SoftLayer.

    As Pedro suggested, 1.4.0 should work with Amazon.
