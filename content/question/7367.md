    [Here](http://osrf-distributions.s3.amazonaws.com/gazebo/api/4.0.0/group__gazebo__event.html) is the API documentation for the event system.

    [Here](https://bitbucket.org/osrf/gazebo/src/a929e28fed25615d7eb60be9a78e627fea11dbec/gazebo/common/Events.hh?at=default) is a set of example event definitions.

    Basic usage:

    1. Define an event (see `gazebo/common/Events.hh` for examples).

    1. Create a Connection, which registers a callback to an Event. Make sure to keep the Connection alive (don't destroy it), until you are done.

    1. Trigger the event, and the callback will be run.
