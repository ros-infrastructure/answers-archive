 I am trying to release [third-party](https://github.com/eclipse/paho.mqtt.c) package. Building the package only requires a [package.xml](https://github.com/eclipse/paho.mqtt.c/pull/1083) file.

This will increase the maintenance burden of those developers because they have to bump the version in the package.xml file on every release. While the remainder of the project uses (parses) three files `version.major`, `version.minor` and `version.patch`. 

How can I uses these files in the package.xml?

Considerations: bloom can use the [`<version>:{version}</version>`](http://wiki.ros.org/bloom/Tutorials/ReleaseThirdParty) notation. But I am not sure this only works when it's a patch. Also this means people cannot clone and build from source using catkin.
