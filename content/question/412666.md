System:
Ubuntu 20.04, Foxy. Using cyclone_dds implementation, all nodes run locally on same PC.

Following packages built from source:

- image_common packages: https://github.com/ros-perception/image_common/tree/foxy

- image_transport_plugins: https://github.com/ros-perception/image_transport_plugins/tree/foxy-devel

- image_transport_tutorials: https://github.com/ros-perception/image_transport_tutorials/tree/foxy

To stream images from webcam:

> ros2 run image_transport_tutorials
> publisher_from_video 0

To subscribe to images:

> ros2 run image_transport_tutorials
> my_subscriber --ros-args --remap
> __name:=compressed_listener -p _image_transport:=compressed

Launching RVIZ2:

> rviz2
