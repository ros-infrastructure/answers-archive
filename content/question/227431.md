  body_markdown: "I found a solution here:\n[How to specify trajectory points with\
    \ 6D pose?](https://github.com/ros-industrial-consortium/descartes/issues/134)\n\
    \nThe method is to specify a {X, Y, Z} position with Orientation vector. \nHere's\
    \ the code snippet:\n\n    using namespace Eigen;\n    Matrix3d m;\n    m =  \
    \ AngleAxisd(0, Vector3d::UnitX())\n        * AngleAxisd(-M_PI/2, Vector3d::UnitY())\n\
    \        * AngleAxisd(0, Vector3d::UnitZ());\n    pose.linear() = m;\n"
