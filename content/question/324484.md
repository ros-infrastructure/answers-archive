  body_markdown: "Actually I solve this problem. The steps was:\n\n1 - Followed Exactly\
    \ this tutorial: [tutorial](https://www.youtube.com/watch?v=j6bBxfD_bYs&t=175s)\n\
    \n2 - I realized that my **demo.launch** provided by Moveit! Setup Assistant have\
    \ those commands that are not shown in ANY tutorial:\n\n      <!-- By default,\
    \ we do not start a database (it can be large) -->\n      <arg name=\"db\" default=\"\
    false\" />\n      <!-- Allow user to specify database location -->\n      <arg\
    \ name=\"db_path\" default=\"$(find manipulator_h_moveit)/default_warehouse_mongo_db\"\
    \ />\n    \n      <!-- By default, we are not in debug mode -->\n      <arg name=\"\
    debug\" default=\"false\" />\n    \n      <!--\n      By default, hide joint_state_publisher's\
    \ GUI\n    \n      MoveIt!'s \"demo\" mode replaces the real robot driver with\
    \ the joint_state_publisher.\n      The latter one maintains and publishes the\
    \ current joint configuration of the simulated robot.\n      It also provides\
    \ a GUI to move the simulated robot around \"manually\".\n      This corresponds\
    \ to moving around the real robot without the use of MoveIt.\n      -->\n    \
    \  <arg name=\"use_gui\" default=\"false\" />\n\n      <!-- If database loading\
    \ was enabled, start mongodb as well -->\n      <include file=\"$(find manipulator_h_moveit)/launch/default_warehouse_db.launch\"\
    \ if=\"$(arg db)\">\n        <arg name=\"moveit_warehouse_database_path\" value=\"\
    $(arg db_path)\"/>\n      </include>\n\nSo I copied those commands and put in\
    \ my **moveit_planning_execution.launch** and then Works finally!"
