    There are a few ROS packages/libraries that support raycasting into (their respective) map representations. I'm not aware of a ready-made tool for generating virtual LIDAR scans, but it would be relatively easy to create one using for instance [grid_map](https://github.com/ANYbotics/grid_map)'s line iterator for 2D map data or [octomap_ros](http://wiki.ros.org/octomap_ros)'s [castRay](https://octomap.github.io/octomap/doc/classoctomap_1_1OccupancyOcTreeBase.html#afc368d6ff93f40ee33eca3df0b8d1967) for 3D map data.
