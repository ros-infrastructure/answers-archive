  body_markdown: "The SVG import only works on SVG paths. It also assumes that path\
    \ sections don't cross each other. Paths don't have to be closed: a contour can\
    \ be made of multiple paths.\n\nAlso, the importer does not support SVG transforms\
    \ yet. If the string \"transform\" appears in your SVG file, try to remove it,\
    \ tweak the image with the SVG editor, and save it again.\n\nAttaching the SVG\
    \ file is a good idea, because there are multiple ways to generate the same geometry\
    \ with SVG. "
