  body_markdown: "Hi ahmed charef! I think that you're trying to link your URDF robot\
    \ model to a world and launch it in gazebo.\n\nIf is that case it's explain in\
    \ gazebo tutorials [link](http://gazebosim.org/tutorials/?tut=ros_roslaunch),\
    \ but i'm going to try to explain to you.\n\nIn the model.config file\n\n \n\n\
    \     <?xml version=\"1.0\"?>\n      <model>\n        <name>MYROBOT</name>\n \
    \       <version>1.0</version>\n        <sdf>urdf/MYROBOT.urdf</sdf> <--- **Here\
    \ you must specify where is your urdu file** -->\n        <author>\n         \
    \ <name>My name</name>\n          <email>name@email.address</email>\n        </author>\n\
    \        <description>\n          A description of the model\n        </description>\n\
    \      </model>\n\nAnd then, in the world file you must include it as the rest\
    \ of things in the world\n\n\n    <?xml version=\"1.0\"?> \n    <sdf version=\"\
    1.4\">\n      <world name=\"default\">\n        <!-- Ground Plane -->\n      \
    \  <include>\n            <uri>model://ground_plane</uri>\n        </include>\n\
    \        <include>\n            <uri>model://sun</uri>\n        </include>\n \
    \       <!-- Your URDF file -->\n        <include>\n            <uri>model://MYROBOT</uri>\
    \  <!-- The name that you write in the model.config -->\n        </include>\n\
    \      </world>\n    </sdf>\n\nI hope this can help you.\n"
