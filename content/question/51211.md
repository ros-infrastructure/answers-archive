    What you want to do is basically try to run each of the different C++ snippets\

    \ to examine after compiling them with the correct flags. I'll run through the\
    \ block for SSE3 detection in that CMake file.\n\n    if(CMAKE_COMPILER_IS_GNUCC\

    \        int main ()\n        {\n            __m128d a, b;\n            double\
    \ vals[2] = {0};\n            a = _mm_loadu_pd (vals);\n            b = _mm_hadd_pd\

    \    }\"\n        HAVE_SSE3_EXTENSIONS)\n\nYou should copy-paste the C++ code\

    \ -o sse3_test` to generate the file to run. The `-msse3` flag was picked because\
    \ it was the flag set in the block just before this check_cxx_source_runs command.\
