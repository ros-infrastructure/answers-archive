     If by *some form of link* you mean ethernet and TCP/IP, then yes (any other transport could also work, but would require (much) more work). This would simply be a matter of setting the `ROS_MASTER_URI` and `ROS_HOSTNAME` / `ROS_IP` variables correctly. See [ROS/Tutorials/MultipleMachines](http://wiki.ros.org/ROS/Tutorials/MultipleMachines) for more info.

    Also, be sure to have a working network before attempting to do anything more than simple tests (diagnosing network issues can become quite complex if you're running a full application). See [ROS/NetworkSetup](http://wiki.ros.org/ROS/NetworkSetup) and make sure all tests pass and return valid results.

    An alternative to a single master would be to run a multi-master setup. This is much more involved though, and if all your CPUs are on the same physical network, not wireless and connected by reliable links, a single master setup probably makes more sense. In any case, see [wiki/sig/Multimaster](http://wiki.ros.org/sig/Multimaster), [multimaster_fkie](http://wiki.ros.org/multimaster_fkie) (just one example) and [rocon](http://wiki.ros.org/rocon) (robotics in concert) for a start.
