    As of ROS2 humble there is also `read_points_numpy` (see [here](https://github.com/ros2/common_interfaces/blob/60df44894caafa67767da4c71d91f8c5eb7abf38/sensor_msgs_py/sensor_msgs_py/point_cloud2.py#L134)) which would give you directly a 2D NumPy array. For example:

        cloud = point_cloud2.read_points_numpy(
            msg, field_names=['x', 'y', 'z', "intensity"], skip_nans=True)

    Note that there also exists a `read_points_list` (see [here](https://github.com/ros2/common_interfaces/blob/60df44894caafa67767da4c71d91f8c5eb7abf38/sensor_msgs_py/sensor_msgs_py/point_cloud2.py#L165)) at least for galactic, foxy, and humble which would have simplified the code of the other answers.
