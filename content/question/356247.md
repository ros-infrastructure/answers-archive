  body_markdown: "    ROS Master does not appear to be running.\n\nYou might have\
    \ another issue with your `ROS_MASTER_URI`, if all was propperly set up you shouldn't\
    \ get this message.\n\nAbout your issue with `openni2` it comes from the fact\
    \ that `roswtf` automatically load plugins  as soon as a package has this in its\
    \ `package.xml` :\n\n    <roswtf plugin=\"PLUGIN_NAME\" />\n\nGrepping \"roswtf\
    \ plugin\" in `/opt/ros/DISTRO/share` gives you two results which corresponds\
    \ to the first two lines of roswtf ouput  :\n\n    tf/package.xml:    <roswtf\
    \ plugin=\"tf.tfwtf\" />\n    openni2_launch/package.xml:    <roswtf plugin=\"\
    openni2_launch.wtf_plugin\" />   \n\nAnd now you can locate the file `wtf_plugin`\
    \ in your system and find the script in `/opt/ros/kinetic/lib/python2.7/dist-packages/openni2_launch/`.\
    \ Looking into the script there is this line 81 :\n\n    num_sensors_expected\
    \ = rospy.get_param(\"openni2_num_sensors_expected\", 1)\n\nso the default value\
    \ is set to 1, since you are just running `roscore` the param isn't set which\
    \ directly lead to the error message.\n\nYou can uninstall the package `openni2_launch`\
    \ to get rid of this if you don't use it.\nOr you can set the param to `0` with\
    \ `rosparam set openni2_num_sensors_expected 0` after running `roscore` or by\
    \ adding `<param name=\"openni2_num_sensors_expected\" value=\"0\"/>` in your\
    \ launch file.\n\nOr you can also run `roswtf --no-plugins` but then it would\
    \ mean that you don't use the `tf` plugin which can be useful. \n"
