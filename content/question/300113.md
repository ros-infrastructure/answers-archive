    \nWe had to modify the script a bit to make it work:\n\n    # If not working,\
    \ first do: sudo rm -rf /tmp/.docker.xauth\n    # It still not working, try running\
    \ the script as root.\n    \n    XAUTH=/tmp/.docker.xauth\n    \n    echo \"Preparing\
    \ Xauthority data...\"\n    xauth_list=$(xauth nlist :0 | tail -n 1 | sed -e 's/^..../ffff/')\n\
    \    if [ ! -f $XAUTH ]; then\n        if [ ! -z \"$xauth_list\" ]; then\n   \
    \         echo $xauth_list | xauth -f $XAUTH nmerge -\n        else\n        \
    \    touch $XAUTH\n        fi\n        chmod a+r $XAUTH\n    fi\n    \n    echo\
    \ \"Done.\"\n    echo \"\"\n    echo \"Verifying file contents:\"\n    file $XAUTH\n\
    \    echo \"--> It should say \\\"X11 Xauthority data\\\".\"\n    echo \"\"\n\
    \    echo \"Permissions:\"\n    ls -FAlh $XAUTH\n    echo \"\"\n    echo \"Running\
    \ docker...\"\n    \n    docker run -it \\\n        --env=\"DISPLAY=$DISPLAY\"\
    \ \\\n        --env=\"QT_X11_NO_MITSHM=1\" \\\n        --volume=\"/tmp/.X11-unix:/tmp/.X11-unix:rw\"\
    \ \\\n        --env=\"XAUTHORITY=$XAUTH\" \\\n        --volume=\"$XAUTH:$XAUTH\"\
    \ \\\n        --net=host \\\n        --privileged \\\n        --runtime=nvidia\
    \ \\\n        our-nvidia-based-ros-melodic-image-plus-nvidia-env-vars-from-the-guide:latest\
    \ \\\n        bash\n\n    echo \"Done.\"\n\n**Note 1:** We added the `tail -n\
    \ 1` into the `xauth` sequence since the original command resulted in two identical\
    \ lines after the `sed` replacement. So we only took one of them.\n\n**Note 2:**\
    \ The `--net=host` and `--privileged` are only needed if you want to join the\
    \ host pc network. We added it to test communication with RViz by playing a bag-file\
    \ from the outside using `rosbag play` and seeing the images being received by\

       - `$ docker-compose up -d`: to spin the container
