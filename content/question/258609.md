    When I want to do something like that, I mainly use two techniques:

    - (This is more ROS-formal) Use the respawn="true" roslaunch parameter.

    e.g.

        <node pkg="rospy_tutorials" type="listener" name="listener"  respawn="true" />

    [You can check the official roslaunch wiki page for more info.](http://wiki.ros.org/roslaunch/XML)

     - (This is more hacky, but works like a charm) Use the rosnode command-line tool inside python.

    e.g.

        nodes = os.popen("rosnode list").readlines()
        for node in nodes:
            # Make your tests here

  body_markdown: "You could use a [bond](http://wiki.ros.org/bondpy):\n\n    #! /usr/bin/python\n\
    \    \n    import rospy\n    from bondpy import bondpy\n    \n    def formed():\n\
    \    \tprint \"We got a bond\"\n    \n    def broken():\n    \tprint \"SOMEONE\
    \ DIED\"\n    \n    rospy.init_node(\"A\", anonymous=True)\n    b = bondpy.Bond(\"\
    heartbeat_topic_name\",\"bond_name\", on_broken=broken, on_formed=formed)\n  \
    \  b.start()\n    if not b.wait_until_formed(): \n    \traise Exception('Bond\
    \ could not be formed')\n    \n    rospy.spin()\n\nJust start this node twice,\
    \ wait for the bond to be established and kill one of the nodes. After a short\
    \ timeout (4 seconds) the other node will notice the missing partner. With this\
    \ method, you don't need to poll rosnode list or even know the name of the other\
    \ node, you just have to use the same topic and bond_name to establish the connection\
    \ and have a callback triggered as soon as one node does not send its heartbeat\
    \ anymore. "
