  body_markdown: "This is not a bug but a check that is done in that package to guarantee\
    \ that the version of Qt used to build `rosbag_controller` is the exact same version\
    \ that was used to build `rviz`. Somehow you have a newer version of some `libqt5`\
    \ packages than are available in the Xenial repositories (they are all 5.5.1)\
    \ which is causing the problem. There is no easy fix. You will have to remove\
    \ the 5.6.1 version you have installed and install the version from the Ubuntu\
    \ repositories. "
