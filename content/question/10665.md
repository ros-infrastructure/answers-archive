    \ properly.\n\nThe lib.a files seemed not to have been built by the cross-compiler\
    \ as when I checked their contents using nm, they looked like .so libraries. This\
    \ would explain why ros::init or any ros function called in the qt program was\
    \ generating a link error. \nI built them again, making sure the cross-compiler\
    \ was being called and this time the output from nm was showing .obj contents\
    \ in each lib.a, which is correct. \n\nqtalker.exe and other exes were produced\
    \ fine and they run on Windows.\n\nT"
