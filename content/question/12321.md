    Here is an example yaml file you can use to specify topic names to be connected to:

        topics:
            - topic1
            - topic2
            - topic3
            - topic4

    What you see here is a map with one key "topics", its value is a list with 4 string elements. That's pretty much all you need to know about yaml syntax to cover 90% use cases in ROS (both reading and writing config files).

    To read those topic names in a ROS node using roscpp, see [this](http://www.ros.org/wiki/roscpp/Overview/Parameter%20Server) page. Scroll all the way down to "Retrieving Lists".

  body_markdown: "First of all, ROS itself uses yaml-cpp, so that's not a bad way\
    \ to go about it. \n\nSecond, I'd like to propose an alternative way to solve\
    \ your problem (since I've just done the same thing myself). `roslaunch` supports\
    \ all forms of XmlRpc values, including lists. Therefore, you can use the following\
    \ code:\n\n    XmlRpc::XmlRpcValue topicList;\n    std::vector<std::string> topics;\n\
    \n    if (private_nh.getParam(\"topics\", topicList))\n    {\n      std::map<std::string,\
    \ XmlRpc::XmlRpcValue>::iterator i;\n      for (i = topicList.begin(); i != topicList.end();\
    \ i++)\n      {\n        std::string topic_name;\n        std::string topic_type;\n\
    \n        topic_name = i->first;\n        topic_type.assign(i->second[\"topic_type\"\
    ]);\n\n        topics.push_back(topic_name);\n      }\n    }\n\nEssentially, this\
    \ code will read all parameters that are under the \"topics\" namespace into a\
    \ single list. You then iterate through that list to grab all topic names. Each\
    \ new topic can have as many sub-fields (topic_type) as you desire. Here's an\
    \ example launchfile statement for the above code. \n\n    <launch>\n        <node\
    \ pkg=\"my_package\" type=\"my_node\" name=\"my_node\" output=\"screen\">\n  \
    \          <param name=\"topics/topic1/topic_type\" type=\"string\" value=\"sensor_msgs/LaserScan\"\
    \ />\n            <param name=\"topics/topic2/topic_type\" type=\"string\" value=\"\
    sensor_msgs/PointCloud2\" />\n        </node>\n    </launch\n\n"

  body_markdown: "You can use yaml-cpp along with ROS2. Just add following codes to\
    \ your `package.xml`, `CMakeLists.txt` and `source file`:\n\n**Package.xml:**\n\
    \n    <build_depend>yaml-cpp</build_depend>\n    <build_export_depend>yaml-cpp</build_export_depend>\n\
    \    <exec_depend>yaml-cpp</exec_depend>\n\n**CMakeLists.txt:**\n\n    find_package(yaml-cpp\
    \ REQUIRED)\n    include_directories(HEADERS_EXECUTABLE\n        ${YAML_INCLUDE_DIRS}\n\
    \    )\n    target_link_libraries(${CMAKE_PROJECT_NAME}\n        yaml-cpp\n  \
    \  )\n\n**main.cpp:**\n\n    #include <yaml-cpp/yaml.h>\n    \n    int main(int\
    \ argc, char const *argv[])\n    {\n        YAML::Node config = YAML::LoadFile(\"\
    [Name Of File].yaml\");\n    \n        if (config[\"SOMETHING\"]) {\n        \
    \  std::cout << config[\"SOMETHING\"] << \"\\n\";\n        }\n        return 0;\n\
    \    }\n\nYou can find more information about yaml-cpp [here](https://yaml-cpp.docsforge.com/master/tutorial/)."
