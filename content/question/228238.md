  body_markdown: "Here is a list of things that, if not done, could make the marker\
    \ not show up as expected:\n\n - Set the scale of the marker.  By default, the\
    \ scale is (0,0,0), which will make the marker infinitesimal and therefore invisible.\n\
    \ - Make sure the transparency is set.  By default, the 'a' field of the marker\
    \ color is 0, which will make the marker completely transparent.\n - Set the orientation\
    \ of the marker.  By default, all quaternion parameters are zero, which is an\
    \ invalid quaternion.  Set w to 1 to initialize the orientation.\n - Update the\
    \ time stamp of the marker when you update its properties.\n - Make sure the frame\
    \ ID of the marker exists in the TF tree, or is the same frame as the fixed frame\
    \ in Rviz.\n - If publishing a marker array, make sure the 'id' field of each\
    \ array element is unique.  Otherwise, only the marker that was added last will\
    \ appear.\n \nIf all of the above points are verified, then do a sanity check\
    \ on the position of the marker.  The simplest way is to 'rostopic info' the marker\
    \ topic.  Make sure the coordinates make sense.\n\nI hope this helps!"
