  body_markdown: "You should initalise ros node with:\n\n    rospy.init_node()\n\n\
    for explanation check [here](http://wiki.ros.org/rospy/Overview/Initialization%20and%20Shutdown).\n\
    \nSo you should write something like this:\n\n    if __name__ == '__main__':\n\
    \       \n        rospy.init_node('xbox_controller')\n\n        try:\n       \
    \     loop = asyncio.get_event_loop()\n            loop.add_reader(xboxc, partial(read_events,\
    \ xboxc))\n            loop.run_until_complete(summarize())\n     \n        except\
    \ rospy.ROSInterruptException:\n    \n                pass\n\nBut if you use xbox\
    \ controller with ROS probably you want to use [joy](http://wiki.ros.org/joy)\
    \ package.\n"
