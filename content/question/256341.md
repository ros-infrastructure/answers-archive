  body_markdown: "It is usually the very first errors in the error output that are\
    \ important and all you need to post- `error: no match for \u2018operator==\u2019\
    \ (operand types are \u2018Point2dc\u2019 and \u2018const Point2dc\u2019)` means\
    \ you haven't defined the `==` operator for your class.  If there is an operator\
    \ == in your point2dc.cpp file (and it compiles until you include ros.h?) then\
    \ something else is preventing it from getting compiled properly.\n\nPossibly\
    \ it is the using namespace std and ros in the header (see http://stackoverflow.com/questions/5849457/using-namespace-in-c-headers\
    \ )."
