  body_markdown: "According to [REP 3](http://www.ros.org/reps/rep-0003.html#kinetic-kame-may-2016-may-2021)\
    \ (which defines the target platforms for each ROS Distribution Release):\n\n\
    > **Kinetic Kame (May 2016 - May 2021)**\n> \n> Required Support for:\n> \n> \
    \ - Ubuntu Wily (15.10)\n>  - Ubuntu Xenial (16.04)\n\nSo, it's not supported\
    \ meaning you can't use `apt` to install it on Ubuntu 17 (Zesty). You can, however,\
    \ install [Lunar Loggerhead on Ubuntu 17 (Zesty)](http://www.ros.org/reps/rep-0003.html#lunar-loggerhead-may-2017-may-2019)."
