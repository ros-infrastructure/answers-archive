    You will need to write a node that listens to that particular topic and publishes your required tf. With a static transform publisher only fixed transforms can be published.

    If it is not a topic but a parameter stored in the parameter server, then yes, you can use that parameter and load it to the static transform publisher. Take a look [here](http://www.ros.org/wiki/roslaunch/XML/param).
