  body_markdown: "Yes, you can call a non-class callback from a subscriber that's\
    \ within another class. As a minimal example, something like this works:\n\n \
    \   #include \"ros/ros.h\"\n    #include \"std_msgs/Empty.h\"\n    \n    void\
    \ emptyCallback(const std_msgs::Empty::ConstPtr& msg) {\n      ROS_INFO(\"Got\
    \ empty message!\");\n    }\n    \n    class Listener {\n      ros::NodeHandle\
    \ nh_;\n      ros::Subscriber sub_;\n    public:\n      Listener(): nh_(\"\")\
    \ {\n        sub_ = nh_.subscribe(\"empty_msg\", 1000, &emptyCallback);\n    \
    \    ROS_INFO(\"done constructing Listener!\");\n      };\n      ~Listener() {};\n\
    \    };\n    \n    int main(int argc, char ** argv) {\n      ros::init(argc, argv,\
    \ \"test_cb_node\");\n      Listener my_listener = Listener();\n      ros::spin();\n\
    \      return 0;\n    }\n\n"
