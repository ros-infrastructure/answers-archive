Edit:
-------

Lorenz answer is the solution to the problem. I used `$ sudo easy_install rospkg` and then added  

    export ROS_HOSTNAME=localhost  
    export ROS_MASTER_URI=http://localhost:11311

to my .bashrc

There is now a failure msgs about 

`Exception AttributeError: AttributeError("'_DummyThread' object has no attribute '_Thread__block'",) in <module 'threading' from '/usr/lib/python2.7/threading.pyc'> ignored`

but this shouldn't be an issue. ([reference](http://answers.ros.org/question/34304/exception-attributeerror-when-starting-roscore/))
