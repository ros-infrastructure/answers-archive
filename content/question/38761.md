  body_markdown: "OK I found the fix from a related posting on a sparkfun site, apparently\
    \ BYTE has been deprecated in the Serial package\nhttp://forum.sparkfun.com/viewtopic.php?f=32&t=30991\
    \ \n\nThus \n\n    Serial.print(value, BYTE);\n\nneed to be replaced with:\n\n\
    \     Serial.write(value);\n\n    So to fix this, edit the ros.pde file and remove\
    \ all BYTE entries, (after backing it up first) then save it and it compiles perfectly!\n\
    \    -Scott"
