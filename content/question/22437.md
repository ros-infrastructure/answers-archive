    Gazebo supports using COLLADA files as meshes (and their textures) for parts of a robot, and as skeleton animations. All other COLLADA features, including cameras, are currently ignored, so you can't use the COLLADA file as the world.

    So, If you are using Blender to generate the .dae file, u can add that dae file to my_gazebo>models>model_name>meshes. Save your .dae file in the meshes folder. Then create model.config and model.sdf. In the model.sdf just highlight the .dae file like this ![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/15570488964651044.png).

    Remember if you have textures in your collada file, the export as .obj and not as .dae
