    There seems to be a bug in the script responsible to set the speed of the robot because you do have the topic `/mobile_base/commands/velocity`publishing data (this is the topic that moves the robot) but this data is always only `0` eventhough you press some keys and the script prints different speeds. So you can either investigate the script `turtlebot_teleop_key` or instead you can use another launch file that is working fine that use the mobile_base of the turtlebot directly (i.e. `kobuki`).

    Try:

        roslaunch kobuki_keyop keyop.launch
