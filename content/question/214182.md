    You need to set the `ROS_MASTER_URI` to the IP of the PC running the (single) `roscore`.
    So if the `roscore` is running on the turtlebot it should be

        ROS_MASTER_URI=http://192.168.7.2:11311

    (and don't forget the Port!). And obviously, if the `roscore` is running on the RPI, set it to this IP.
