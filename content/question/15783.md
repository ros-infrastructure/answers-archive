    Yes, you can get it with a [GUI plugin](http://gazebosim.org/tutorials?tut=gui_overlay&cat=user_input).

    [Here](https://github.com/chapulina/gazebo_plugins/blob/e1be58cbfa9fcf79befe7c654eb8c2ba15663bbf/Dominoes/DominoesPlugin.cc#L122-L134)'s an example which gets the mouse position on mouse move.

    It uses `gui::MouseEventHandler::AddMoveFilter` and gives it a callback which is called whenever the mouse is moved on the 3D scene.

    Then it uses [Scene::FirstContact](http://gazebosim.org/api/8.0.0/classgazebo_1_1rendering_1_1Scene.html#afe0662050a8152eb261a774fdeb03cf1) to get the coordinates of that point in 3D.
