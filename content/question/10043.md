  body_markdown: "I take some minutes to find a solution for the problem :\n\n----------------------------------------------------------------\n\
    Add a new file association for .launch files\n\n 1. General -> Editors -> File\
    \ Association ... add a new file type with the suffix *.launch assign the XML\
    \ Editor to the new file type\n 2. General -> Appearance -> Content Types ...\
    \ roll off entry for TEXT in the menu go to XML and add *.launch\n\nNow a .launch\
    \ file will be opened by the XML Editor, if you have installed it.\n\n-----------------------------------------------------------------------------------\n\
    In a second step you have to define a new external tool launch. \n\n 1. Run ->\
    \ External Tools -> External Tools Configurations\n 2. choose PROGRAM and add\
    \ a new lauch configuration by clicking the left button \n 3. write a name like\
    \ \u201CLaunch_ROS\u201D to NAME\n 4. integrate the path of roslaunch into LOCATION\
    \ (usually something like ../ros/ros_comm/tools/roslaunch/bin/roslaunch)\n 5.\
    \ add as ARGUMENTS your ROS package name and .launch file name (for a more general\
    \ use you can take ${project_name} ${resource_name}, but in this case your focus\
    \ has to be on your launch file while starting !!!)\n 6. then you can start the\
    \ ROS application by Run -> External Tools -> Launch ROS\n\t\n\nAnyone feels free\
    \ to improve the chain ! \n\nBest wishes from Germany\n\nPoseidonius"
