  body_markdown: "The [image_view](http://wiki.ros.org/image_view) package has functions\
    \ to aid in storing images to disk. \n\nIf you just want to save single images\
    \ you can use the image_view node and\n\n> You may save the current image by\n\
    > right-clicking on the display window.\n> By default, images will be saved as\n\
    > frame0000.jpg, frame0001.jpg, ....\n\nfor storing all images image_view provides\
    \ an `image_saver` tool that can be configured to save *all* images, or only to\
    \ save when a service is called. This allows you to programmatically set what\
    \ images are stored to disk.\n\nAn alternative would be to use [rosbag](http://wiki.ros.org/rosbag)\
    \ to store the image topics and extract them later using [Exporting Image and\
    \ Video Data](http://wiki.ros.org/rosbag/Tutorials/Exporting%20image%20and%20video%20data).\
    \ Note that if you are making a rosbag of all topics, including pointcloud data,\
    \ the bags will become quite large."
