  body_markdown: "You can know the know the distance of each point in the world from\
    \ the camera centered co-ordinate frame. Just subscribe to the topic /camera/depth/points\
    \ . It is a sensor_msgs::PointCloud2 topic where you have points with [x, y, z]\
    \ distance from the camera centered coordinate frame. \n\nThe package depth_image_proc\
    \ implements the method to convert the depth image to point cloud [x, y, z] format.\
    \ Going through the internals of this package can help you in understanding more\
    \ on how the image is converted to point cloud.\n\nTo completely understand and\
    \ gain access to each point in the point cloud, you need to understand basics\
    \ of point cloud library and point cloud format. This can be learnt from \n\n\
    http://wiki.ros.org/pcl/Tutorials\n\nhttp://wiki.ros.org/pcl\n\n\n***EDIT 1 :***\
    \ \n\nHere is something which can be done. First convert the 32\n\n` const std::string&\
    \ enc = depth_msg->encoding; `\n\n`  if (enc.compare(\"16UC1\") == 0)`\n\n`  \
    \  depth_img = cv_bridge::toCvShare(depth_msg)->image;`\n\n`  else if (enc.compare(\"\
    32FC1\") == 0)`\n\n`    depthImageFloatTo16bit(cv_bridge::toCvShare(depth_msg)->image,\
    \ depth_img);`\n\n`// get raw z value (in mm)`\n\n  `uint16_t z_raw = depth_img.at<uint16_t>(v,\
    \ u);`\n\n ` // z [meters]`\n\n  `z_mean = z_raw * 0.001;`\n\nLook here for better\
    \ understanding : \nhttp://docs.ros.org/groovy/api/ccny_rgbd/html/rgbd__frame_8cpp_source.html\n\
    \nGo through in detail and you can completely find what you are asking for."
