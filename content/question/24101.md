Hi all,

I'm trying to customize the gzclient menus.

I see the menus are added on [MainWindow.cc](https://bitbucket.org/osrf/gazebo/src/a9352854ba1da2d2ddbad60e43f5bcbc7484e23e/gazebo/gui/MainWindow.cc?at=default#lines-1864)

It seems they are customized at runtime by loading the [:/style.qss](https://bitbucket.org/osrf/gazebo/src/a9352854ba1da2d2ddbad60e43f5bcbc7484e23e/gazebo/gui/GuiIface.cc?at=default#lines-237) file at runtime.

I tried to find that file in the `osrf/ros:kinetic-desktop-full` docker with `find / -name style.qss` but I couldn't find the file.

Does anybody know where that file is located? I didn't understand the `:` in the filename when loading with [QFile file(":/style.qss");](https://bitbucket.org/osrf/gazebo/src/a9352854ba1da2d2ddbad60e43f5bcbc7484e23e/gazebo/gui/GuiIface.cc?at=default#lines-237)


PS: I saw a [similar question](http://answers.gazebosim.org/question/5896/is-it-possible-to-extend-the-gui-with-own-menus-and-buttons/), but there was no answer there, that is why I asked here.

**EDIT 1:**
Thanks to @chapulina we have the [custom_gazebo_style](https://github.com/chapulina/custom_gazebo_style) that should do the job.

However, to be able to Compile I had to modify the `CMakeLists.txt` to:


    cmake_minimum_required(VERSION 2.8 FATAL_ERROR)
    set(CMAKE_AUTOMOC ON)
    set(CMAKE_CXX_FLAGS "-std=c++11")
    
    find_package(Qt5Core REQUIRED)
    find_package(Qt5X11Extras REQUIRED)
    find_package(Qt5Widgets REQUIRED)
    find_package(Qt5Gui REQUIRED)
    find_package(gazebo REQUIRED)
    
    QT5_ADD_RESOURCES(resources_RCC resources.qrc)
    
    include_directories(SYSTEM ${GAZEBO_INCLUDE_DIRS})
    link_directories(${GAZEBO_LIBRARY_DIRS})
    
    add_library(custom_gazebo_style SHARED
      CustomGazeboStyle.cc
      ${resources_RCC}
    )
    target_link_libraries(custom_gazebo_style ${GAZEBO_LIBRARIES}
        ${Qt5Widgets_LIBRARIES}
        ${Qt5X11Extras_LIBRARIES}
        ${Qt5Gui_LIBRARIES}
        ${Qt5Core_LIBRARIES}
        ${Qt5Widgets_LIBRARIES})
