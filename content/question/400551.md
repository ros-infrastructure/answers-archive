  body_markdown: "Maybe you could use `message_filters` package?\n\nhttp://wiki.ros.org/message_filters\n\
    \n> ###Overview\n> \n> `message_filters` is a utility library\n> for use with\
    \ roscpp and rospy. It\n> collects commonly used message\n> \"filtering\" algorithms\
    \ into a common\n> space. A message filter is defined as\n> something which a\
    \ message arrives into\n> and may or may not be spit back out of\n> at a later\
    \ point in time.\n> \n> An example is the time synchronizer,\n> which takes in\
    \ messages of different\n> types from multiple sources, and\n> outputs them only\
    \ if it has received a\n> message on each of those sources with\n> the same timestamp.\n\
    \nThis will allow you to get the output at the same time, but I'm not sure about\
    \ the execution start time in these nodes..."
