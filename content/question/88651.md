    The rviz moveit plugin GUI reads the `Robot Description` from the `/robot_description` rosparam by default. You can change this to another rosparam in the gui if need be. Also, be sure that the planning scene topic is correct.

    ![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/15735896218462432.png)


    Please see the [tutorial for using the rviz GUI](https://ros-planning.github.io/moveit_tutorials/doc/quickstart_in_rviz/quickstart_in_rviz_tutorial.html) for more info.
