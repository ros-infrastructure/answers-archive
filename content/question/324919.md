    \ so after figuring it out myself I decided I should help the next poor sucker\
    \ to find themselves in this position too.\n\nI followed the comments and installed\
    \ [kdl_parser](http://wiki.ros.org/kdl_parser/Tutorials/Start%20using%20the%20KDL%20parser).\
    \ I followed the instructions to convert my .xacro into an _actual_ urdf file:\
    \ \n\n    rosrun xacro xacro.py `rospack find pr2_description`/robots/pr2.urdf.xacro\
    \ > pr2.urdf\n\nFrom there I installed [orocos_kdl](https://orocos.org/wiki/Installation_Manual.html)\
    \ by following [these](https://orocos.org/wiki/Installation_Manual.html) instructions.\
    \ I will admit that i'm fairly new to ROS/Catkin, so to figure out how to actually\
    \ add these packages to my own wasn't very obvious. I modified the CMakeLists.txt\
    \ and added the packages to the `find_package` portion of the CMake, as well as\
    \ adding to the package.xml as the documentation instructs.\n\nI was able to confirm\
    \ I got everything working by building a simple executable to test to make sure\
    \ that I was able to make a tree from my urdf file:\n\n    #include <kdl_parser/kdl_parser.hpp>\n\
    \    #include <kdl/tree.hpp>\n    #include <ros/console.h>\n    #include <iostream>\n\
    \    \n    int main(){\n    \n      KDL::Tree my_tree;\n      if(!kdl_parser::treeFromFile(\"\
    src/robot_arm/src/urdf/robot_arm.urdf\", my_tree)){\n        ROS_ERROR(\"Failed\"\
    );\n      }\n      std::cout << \"Worked!\" << std::endl;\n    \n    }"
