  body_markdown: "Hello, actions should be usable in Galactic in Arduino but you [will\
    \ need to rebuild the library](https://github.com/micro-ROS/micro_ros_arduino#how-to-build-the-precompiled-library)\
    \ in order to adjust [the number of entities required](https://github.com/micro-ROS/micro_ros_arduino/blob/b8ce03d5e6a93be32fe027502ebba42d81fae891/extras/library_generation/colcon.meta#L43-L48):\
    \ Action server will need and an Action client will need 2 subscriptions and 3\
    \ service clients and Action server will need 3 service servers. \n\nIn any case,\
    \ in Galactic you will need to use the RCL API, meanwhile, in Rolling (and in\
    \ future releases) you have a new RCLC API, take a look [here](https://github.com/micro-ROS/micro-ROS-demos/blob/main/rclc/fibonacci_action_server/main.c).\n\
    \nRegarding the C++ examples, they are **not** applicable. The micro-ROS API is\
    \ RCLC and it's C99. In fact those examples [has been deprecated](https://github.com/micro-ROS/micro-ROS-demos/pull/61)."
