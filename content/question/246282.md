  body_markdown: "Two tips: \n\n1. You can use any existing messages to create a service.\
    \ More info on that can be found [here](http://wiki.ros.org/ROS/Tutorials/CreatingMsgAndSrv).\
    \ \n2. When you use numpy_msg, you're messages are actually going to be passed\
    \ along as float32[] messages. The numpy_msg package just provides a nice way\
    \ to serialize and deserialize float32[] messages directly into numpy arrays.\
    \ More info on that [here](http://wiki.ros.org/rospy_tutorials/Tutorials/numpy).\
    \ \n\nSo you could have a service that, for example, takes a numpy array and int\
    \ in the request, and responds with a new numpy array, that would look something\
    \ like this: \n\n    int32 an_integer\n    float32[] input_array\n    ---\n  \
    \  float32[] output_array\n "
