  body_markdown: |-
    The operation to gather a list of available ROS packages is an expensive operation because it needs to crawl recursively through the file system. Therefore the tools cache the result for a certain amount of time. The command line option `--force-discover` enforces a crawling (ignoring the cache) and therefore ensures that you get an up-to-date result.

    `rospack` has a rather short maximum age for the cache ([60s](https://github.com/ros/rospack/blob/205f5bc7da190e7c021956fff6092e932b191a6e/src/rospack.cpp#L116)). `rqt` on the other hand reuses the cache for a pretty long time of ([1 day](https://github.com/ros-visualization/qt_gui_core/blob/49e51b95d95451565cccea77cab4a74ec7e8aa42/qt_gui/src/qt_gui/plugin_manager.py#L60)).
