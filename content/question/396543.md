I am try to make ROS2 foxy working on an embeded board which NAND flash size is limited.  I've done the cross-compile, however I found the install folder size is too large about 164MB。 I‘ve tried to remove some unnecessary packages by touch COLCON_IGNORE. However it is still too large for me. Is there some other ways to make install folder small. only contain the necessary libraries?
The build command I used is : colcon build   --merge-install   --cmake-force-configure   --cmake-args     --no-warn-unused-cli     -DCMAKE_TOOLCHAIN_FILE=`pwd`/aarch64_toolchainfile.cmake     -DTHIRDPARTY=ON     -DBUILD_TESTING:BOOL=OFF     -DCMAKE_BUILD_RPATH="`pwd`/build/poco_vendor/poco_external_project_install/lib/;`pwd`/build/libyaml_vendor/libyaml_install/lib/"
