 I am trying to run the Husky simulation in ROS-Kinetic. Though the simulation is now working, I tried to apply another package that runs the simulation for outdoor environment with GPS. This package also launches in Gazebo but any publication in the "/cmd_vel" related failed to move the robot. The publication moves up to "/gazebo" node successfully and then no changes.

The message I receive is as follows:

[ERROR] [1558517048.621148803, 1298.480000000]: GazeboRosControlPlugin missing <legacyModeNS> while using DefaultRobotHWSim, defaults to true.
This setting assumes you have an old package with an old implementation of DefaultRobotHWSim, where the robotNamespace is disregarded and absolute paths are used instead.
If you do not want to fix this issue in an old package just set <legacyModeNS> to true.
