  body_markdown: "You need to put a phyton script like the following into your package\
    \ `rqt_mypkg` and name it after the package `rqt_mypkg`:\n\n    #!/usr/bin/env\
    \ python\n    \n    import sys\n    \n    from rqt_gui.main import Main\n    \n\
    \    main = Main()\n    sys.exit(main.main(sys.argv, standalone='rqt_mypkg'))\n\
    \n\nNow you can run you `rosrun rqt_mypkg rqt_mypkg` in oder for starting your\
    \ plugin stand-alone, i. e. independent from rqt_gui; otherwise, you may want\
    \ to load your plugin into rqt_gui....\n\nNote, that the script file also needs\
    \ to be executable; Maybe you need to run `chmod +x rqt_mypkg` in the folder where\
    \ you have placed the rqt_mypkg script file. E. g. for an error msg like:\n\n\
    \    Couldn't find executable named rqt_mypkg below /home/alan/catkin_ws/src/rqt_mypkg\n\
    \    Found the following, but they're either not files, or not executables:\n\
    \     /home/alan/catkin_ws/src/rqt_mypkg\n     /home/alan/catkin_ws/src/rqt_mypkg/src/rqt_mypkg\n\
    \ngo into the folder where the python script is placed in:\n\n    cd /home/alan/catkin_ws/src/rqt_mypkg/src/\n\
    \nand run there:\n\n    chmod +x rqt_mypkg"
