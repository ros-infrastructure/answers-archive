Edited(19.01.2017):

The summarisation of [Universal Robot report](http://orbit.dtu.dk/files/117833332/Universal_Robot_report.pdf) article is: use `ros_control` with `speedj`, it's most reliable any accurate method to manipulate with objects. 
I've tryed to control just with `movej`, `movel`, all effects (jerky stops behavior, singularity problems) as described in [ur10 permormance analysis](http://orbit.dtu.dk/files/105275650/ur10_performance_analysis.pdf) are taking place.

Summary: I want to use moveit with `ros_control` functionality. So I don't need gazebo, but I need everything else.


Edited(24.01.2017): My sources: 

    $cat /etc/apt/sources.list:
    deb http://ports.ubuntu.com/ xenial main restricted universe multiverse
    deb-src http://ports.ubuntu.com/ xenial main restricted universe multiverse

The same for `xenial-updates`, `xenial-security`, `xenial-backports`.
