  body_markdown: "This can be done using either local variables (ie: store incoming\
    \ messages in variables in the scope outside the callback), or (and this would\
    \ be preferable): use [message_filters/Cache](http://wiki.ros.org/message_filters#Cache):\n\
    \n> Stores a time history of messages.\n> \n> Given a stream of messages, the\
    \ most recent `N` messages are cached in a ring buffer, from which time intervals\
    \ of the cache can then be retrieved by the client. The timestamp of a message\
    \ is determined from its `header` field. \n\nYou tagged this `rospy`, but just\
    \ to mention them: [fkie_message_filters](http://wiki.ros.org/fkie_message_filters)\
    \ offers an improved version of `message_filters` but is C++, and [fetchrobotics/flow_ros](https://github.com/fetchrobotics/flow_ros)\
    \ is an even more complex/complete implementation of something which could still\
    \ be considered similar to `message_filters`.\n"
