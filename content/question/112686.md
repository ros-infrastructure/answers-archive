  body_markdown: "Hope this helps: There are several problems with your `CMakeLists.txt`.\n\
    \nThe biggest one: You need to `find_package` all the ROS packages you depend\
    \ on. This is how the variables `catkin_INCLUDE_DIRS` and `catkin_LIBRARIES` are\
    \ set up.\n\nSo do a \n\n    find_package(catkin REQUIRED COMPONENTS\n      roscpp\n\
    \      std_msgs\n      image_transport\n      sensor_msgs\n      tf\n      camera_info_manager\n\
    \      dynamic_reconfigure\n      driver_base\n    )\n(best sort this alphabetically).\
    \ Maybe this resolves your problem already.\n\nOther issues:\n\n - You shouldn't\
    \ link against a library with the full path, but just against the library name\
    \ minus the `lib` part, i.e. `mesasr`\n - the `add_dependencies` call is not what\
    \ you want. You need this if you need messages to be built before, but better\
    \ use `${<packagename>_EXPORTED_TARGETS}` or `${catkin_EXPORTED_TARGETS}`\n -\
    \ in `catkin_package`: The `LIBRARIES` part is not correct, this is only for exporting\
    \ libraries that you build\n - in `catkin_package`: exchange `mesasr` with `libmesasr`\
    \ (the same name as in the `package.xml`)\n\nAlso, there already exists a swissranger\
    \ driver, have you checked out the [OpenPTrack swissranger_camera package](https://github.com/OpenPTrack/open_ptrack/tree/master/swissranger_camera)?"
