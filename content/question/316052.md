    The bagfile you use doesn't have the topic map, if you do rostopic list while playing the bagfile you'll see :

        /base_scan
        /clock
        /rosout
        /rosout_agg
        /tf

    The `map_saver` node try to read the topic `/map` to save a map, since it doesn't exist it stays idle and wait for this topic to be published.
