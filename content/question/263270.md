  body_markdown: "The class Path is ill-formed. All class variables should be instantiated\
    \ in the `__init__` constructor. It looks like you have variables defined in between\
    \ the `class Path:` line and the `__init__` constructor. Take these out: nothing\
    \ inside a class should ever be defined outside functions. Class-wide variables\
    \ are defined in the `__init__` constructor. The variables inside the `__init__`\
    \ look correct, including the prepended `self.` which people often forget. \n\n\
    Just to be sure, is `path` a member of another class, which has the function `computePathWithoutWaypoints`?\
    \ Also, the line `for waypoint in path` seems odd to me, as you're iterating over\
    \ a class?"
