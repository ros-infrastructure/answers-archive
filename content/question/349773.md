    As strange as it sounds, this happened to me while I try to install ROS over teamviewer on a live USB. Yes, teamviewer.

    From the start menu, find the software / updates section. Open this tab:
    ![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/1589665532947398.png)
    Select all first 4 checkboxes.* Then click on [close]  an then [close].

    Go to terminal and run

        sudo apt update && sudo apt install ros-melodic-desktop full

    * All of those four might not be necessary but click anyway.
