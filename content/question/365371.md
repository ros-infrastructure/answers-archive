  body_markdown: "So I have figured out a way to accomplish this:  \n\n 1.  In URDF,\
    \ add a subgroup called `object_arm` with a kinematic chain of \"dummy joints\
    \ and links\" to allow for 6 dof motion of the object: 3 prisimatic joints, 3\
    \ revolute joints and 6 links \n 2. Attach a collision object to `object_arm`\n\
    \ 3. In Rviz, make sure each robot works with Moveit! like shown above, enable\
    \ `allow_external_comm` in the planning section.  \n 4. In your `move_group_interface`,\
    \ set up a subscriber to `/rviz_moveit_motion_planning_display/robot_interaction_interactive_marker_topic/update`\
    \ to listen for marker position updates of  `object_arm` end effector. \n 5. In\
    \ the subscriber callback, calculate the three robot's end-effector position given\
    \ an update of  `object_arm` end effector.  \n 6. In the same subscriber callback,\
    \ update each robot's end-effector goal query pose by calling `/rviz/moveit/move_marker/goal_*`\
    \ . This is the best way that I found to update goal queries in the Rviz plugin.\
    \ \n\nI hope this will be helpful to people who are looking to plan with multiple\
    \ robots simultaneously using Moveit! Also, please let me know if there are other\
    \ alternatives."
