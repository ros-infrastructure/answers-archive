  body_markdown: "OpenCV's setMouseCallback does not support calling into non-static\
    \ class member functions (http://docs.opencv.org/modules/highgui/doc/user_interface.html?highlight=setmousecallback#cv.SetMouseCallback).\n\
    \nA work around for this could be declaring a static method that calls into the\
    \ non-static method:\n\nDeclaration:\n\n    class object_tracker\n    {    \n\
    \    public:\n        ...\n    private:\n        static void onMouseStatic( int\
    \ event, int x, int y, int flags, void* that );\n        void onMouse( int event,\
    \ int x, int y, int flags );\n\nDefinition:\n\n    void object_tracker::onMouseStatic(\
    \ int event, int x, int y, int flags, void* that )\n    {\n        that->onMouse(\
    \ event,  x, y, flags );\n    }\n    \n    void object_tracker::onMouse( int event,\
    \ int x, int y, int flags )\n    {\n    ...\n    }\n\nAnd add this rather than\
    \ 0 if you want to the callback:\n\n    setMouseCallback( \"CamShift Demo\", object_tracker::onMouseStatic,\
    \ this );\n\n"
