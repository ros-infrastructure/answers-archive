    ROS uses YAML for this, and according to the [YAML 1.1 Reference card](http://www.yaml.org/refcard.html) the value should be `.NAN` (all caps, with the dot):

    >     Language Independent Scalar types:
          ...
          [ .inf, -.Inf, .NAN ]    : [ Infinity (float), Negative, Not a number ]

    The following seems to work for me:

        rostopic pub -r 1 /some_topic std_msgs/Float64 '.NAN'

    velocity: [0.0, 0.0]
    effort: [nan, nan]"

    Unable to publish message. One of the fields has an incorrect type:
