    Gazebo itself is multi-threaded, including several threads for sensors, message passing, and rendering, though currently just one thread for physics. The new bullet3 API supports GPU acceleration, but it has not yet been integrated into Gazebo (using bullet 2 api still). Please [vote for the issue here](https://bitbucket.org/osrf/gazebo/issue/963/add-support-for-bullet3-gpu-accelerated) if you want to see bullet3 support in Gazebo.
