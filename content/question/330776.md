  body_markdown: "Your node execution is blocked by `wait = client.wait_for_result()`\
    \ which waits for one of [actionlib](http://wiki.ros.org/actionlib/DetailedDescription)\
    \ states to be returned. \nOne way to solve your problem is to cancel the current\
    \ navigation goal. Here is an [example](https://answers.ros.org/question/57772/how-can-i-cancel-a-navigation-command/)\
    \ how to do this. This will cancel the current goal and then you can send a new\
    \ one. You can either cancel it \"manually\" as in the suggested answer or just\
    \ write your own logic based on which you can publish to the same topic to cancel\
    \ the goal."
