    `cv::Mat` is not an array, it's a very complex class used to describe openCV image matrices. You cannot pass it directly to the XmlRpc functions.

    By the looks of it you're trying to send an OpenCV image to an Rpc client or server. This can be done but you'll need to do a bit more work yourself.

    There is an XmlRpc constructor which accepts arbitrary length data buffers, it's [described here](http://docs.ros.org/melodic/api/xmlrpcpp/html/classXmlRpc_1_1XmlRpcValue.html#a98f03dd11f19390b801d77f68332d29e).

    You'll need to first serialise your opencv image, effectively writing it to an image file in memory. You will use the [imencode function](https://docs.opencv.org/2.4/modules/highgui/doc/reading_and_writing_images_and_video.html#imencode) to do this. You can then send the image using the XmlRpc constructor I described above.

    The receiving side will need to use the opencv function [imdecode](https://docs.opencv.org/2.4/modules/highgui/doc/reading_and_writing_images_and_video.html#imdecode) to extract the original cv::Mat from the serialised data.

    Hope this helps.
