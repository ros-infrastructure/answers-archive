I am trying to do error handling. I have a sensor that is critical to the system when it fails I have a central behavior tree that needs to switch into an error state. Im not sure what the standard way to do this is, and I can think of a number of ways to do it.

 - having a second topic for reporting
   errors.
 - stop publishing and if no data has
   been received used that to trigger
   the error
 - add to the sensor msg, but I don't
   see any messages with that so I don't
   think it is the recommended way.
 - use
   rcl_subscription_get_publisher_count()
   and remove the publisher when there
   is an error.

I'm not sure which is the way that makes the most sense, and avoids the most pitfalls
