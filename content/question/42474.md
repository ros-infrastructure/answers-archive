  body_markdown: "Have you considered using stage simulation? That way you have the\
    \ ground truth pose (exactly where the robot is in the simulated world) which\
    \ you can compare against the amcl pose. \n\nFor example, you can compare the\
    \ euclidean distance between the two poses after moving the robot on a fixed path.\
    \ Run this for both laser inputs, and whichever has the lowest (average!) distance\
    \ is presumably the better one."
