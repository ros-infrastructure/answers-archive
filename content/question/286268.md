    You need to \"activate\" your workspace after you've built it using `catkin_make`,\

    \ the new packages that you just built.\n\n---\n\nEdit: I only now see this:\n\
    \n>     $ roslaunch openpose_ros_node\n\n`roslaunch` takes either one or two arguments:\n\
    \n 1. a direct path to a `.launch` file\n 1. a package name and a (package relative\
    \ path to a) `.launch` file\n\nYour invocation is neither: `openpose_ros_node`\
    \ is not a package name (that would probably be `openpose_ros`), and it's also\
    \ not a launch file name.\n\nFrom the build output you show, it would appear `openpose_ros_node`\
    \ is a ROS node (ie: an executable binary). \n\nThose you should start with `rosrun\
    \ $pkg $node_name`, not `roslaunch`."
