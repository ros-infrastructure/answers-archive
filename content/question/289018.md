    There is a `pkg` verb inside the ros2 command line tools.
    To create a new package, you can run the following command:

    `ros2 pkg create --dependencies [deps]`

    It is not as feature complete as `catkin_create_pkg` and currently only supports `cmake` and `ament_cmake` packages. Pure Python packages are not yet supported.

    EDIT:

    The `create` verb is not available in Ardent and has to be built from source (at the time of writing). IMO, the best way of doing so is to [create an overlay workspace](https://github.com/ros2/ros2/wiki/Ament-Tutorial#create-an-overlay)
    and then checkout the latest master release of `ros2cli` [here](https://github.com/ros2/ros2cli/tree/master/ros2pkg/ros2pkg).
