  body_markdown: "set_camera_info is the service that \"talks\" between ROS and the\
    \ camera driver to set calibration params. No, I don't *think* it is possible\
    \ to use a nonstandard driver. \n\nIt's not terribly difficult to modify a camera\
    \ driver, especially an open source one. See [camera_info_manager](http://wiki.ros.org/camera_info_manager)\
    \ (especially the example at the bottom) for help on that.\n\nIf you're not up\
    \ to changing the driver, you might be able to use another calibration setup (through\
    \ OpenCV, for example) and then c[onvert that output](http://stackoverflow.com/questions/33736558/using-ros-camera-calibration-in-opencv)\
    \ to a ROS-compatible yaml file"
