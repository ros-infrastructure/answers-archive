  body_markdown: "With a topic_tools mux you can feed both inputs into a node and\
    \ select which gets published out with a service call:\n\nhttp://wiki.ros.org/topic_tools/mux\n\
    \nSo instead of \n\n    node1 -> topicA \n    node2 -> topicA\n    topicA -> node3\n\
    \nit would be\n\n    node1 -> topicB -> mux\n    node2 -> topicC -> mux\n    mux\
    \ -> topicA  (which is a copy of either B or C depending on mux selection)\n \
    \   topicA -> node3\n\n\n"
