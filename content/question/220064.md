  body_markdown: "Quoting from [here](http://wiki.ros.org/jade/Installation/Ubuntu),\
    \ Jade only supports \"Trusty (14.04), Utopic (14.10) and Vivid (15.04) for debian\
    \ packages.\" Reading the [ROS Release Policy](http://wiki.ros.org/Distributions/ReleasePolicy)\
    \ we see that \n\n> ROS releases will also not add support\n> for new Ubuntu releases\
    \ after its\n> release date.\n\nThis means that Jade will not ever support Wily\
    \ (15.10) with debian packages. Next May when ROS K is released, it will likely\
    \ support 15.10, but only through the end of July (when 15.10 reaches EOL). ROS\
    \ K will be an LTS release paired with Xenial (16.04) as its LTS distribution.\n\
    \nYou can always try [building ROS from source](http://wiki.ros.org/jade/Installation/Source)\
    \ if you are stuck on 15.10."

  body_markdown: "I managed to build ROS jade on Ubuntu Willy compiling from sources.\
    \ Until the moment It works nice:\n\nI installed many packages, among them: navigation\
    \ rviz gmapping hector_slam  rqt\n\n> rosinstall_generator gmapping hector_slam\
    \ navigation rviz rqt ros_comm --rosdistro jade --deps --wet-only --exclude roslisp\
    \ --tar > my_application.rosinstall\n\nThe dependencies I had to install were:\n\
    \n> sudo apt-get install libtinyxml-dev lz4 liblz4-dev BZip2 libz2-dev libbz2-dev\
    \ liburdf-dom-headers-dev libgtest-dev libsdl-image1.2-dev liburdfdom-dev libogre1.8-dev\
    \ libassimp-dev python-netifaces\n\nDownload it\n>wstool init -j10 src my_application.rosinstall\n\
    \nCompile it\n> ./src/catkin/bin/catkin_make_isolated --devel devel_isolated --devel-space\
    \ devel_isolated -DCMAKE_BUILD_TYPE=Release\n\nInstall it\n> ./src/catkin/bin/catkin_make_isolated\
