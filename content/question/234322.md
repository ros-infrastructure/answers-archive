  body_markdown: "I finally solve the problem changing the compiler from gcc-5  to\
    \ clang. It is not an optimal solution but it works for me:\n\nUbuntu 14.04 have\
    \ GCC-4.X and in ubuntu 16.04 the default version is GCC-5.X. first, I try to\
    \ change the default version using \"sudo update-alternatives --config gcc\" and\
    \ selecting GCC-4.8 but it doesn't work for me.\n\nSo, simply I add this lines\
    \ to CMakeLists.txt\n\nset(CMAKE_CXX_COMPILER \"clang++\")\n\nset(CMAKE_C_COMPILER\
    \ \"clang\") \n\nif you need to install clang in ubuntu 16.04:\nsudo apt-get install\
    \ clang\n\nI hope It helps you."
