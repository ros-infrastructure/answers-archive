  body_markdown: "\nTo use OmniCppComplete with ROS, you have to generate a set of\
    \ tags for the ROS stacks.  There are probably better ways of doing this, but\
    \ I was successful with find and grep.\n\nFirst, generate a list of files that\
    \ you want to generate tags from:\n\n    find /opt/ros/diamondback/stacks | grep\
    \ -E '*/include/*/.*\\.(h|hpp)' > /tmp/ros.filelist\n\nThen use ctags to generate\
    \ a tags database from this list:\n\n    ctags --sort=foldcase --c++-kinds=+p\
    \ --fields=+iaS --extra=+q -f /tmp/ros.tags -L /tmp/ros.filelist\n\nOnce you have\
    \ done this, you can move your tags file into your ~/.vim directory\n\n    mv\
    \ /tmp/ros.filelist ~/.vim/tags/ros\n\nAnd edit your ~/.vimrc file accordingly\n\
    \n    set tags+=~/.vim/tags/ros\n    \" OmniCppComplete settings to be tweaked\n\
    \    let OmniCpp_NamespaceSearch=1                                           \
    \                                              \n    let OmniCpp_GlobalScopeSearch=1\n\
    \    let OmniCpp_ShowAccess=1\n    let OmniCpp_MayCompleteDot=1\n    let OmniCpp_MayCompleteArrow=1\n\
    \    let OmniCpp_MayCompleteScope=1\n    let OmniCpp_DefaultNamespaces=[\"std\"\
    ,\"_GLIBCXX_STD\"]\n    \" Hotkey to generate tags for you current project\n \
    \   map <F5> :!/usr/bin/ctags -R --c++-kinds=+p --fields=+iaS --extra=+q .<cr>\n\
    \nHope this helps."

  body_markdown: "The following .vimrc snippet is mostly from [here](http://en.kioskea.net/faq/2367-the-autocompletion-c-c-in-vim).\
    \ Visit the link to see how to create stl, qt, sdl and qt4 tags (or deactivate\
    \ the \"set\"-lines).\n\nThe only ros-specific part is \\`rospack cflags-only-I`\
    \ in the third line, which lists all the include directories of the ros package\
    \ in which you are editing files for the ctags command (this assumes the current\
    \ working dir of vim is your projects directory, see below, which btw also allows\
    \ you to use :mak). With this, hitting F11 will generate completion tags for your\
    \ current file's project.\n\nIn contrast to the solution of mjcarroll this creates\
    \ a tagfile in your project's directory, which is specific to the dependencies\
    \ of your project. Therefore you need to create the tags (F11) for each of the\
    \ packages in which you are editing files. On the other hand vim should be faster\
    \ looking up its tag database.\n\n<pre>\nmap <F12> :!ctags -R --languages=c++\
    \ --c++-kinds=+p --fields=+iaS --extra=+q .<CR>\n\"This is to tag the include\
    \ for ros packages the current project depends on\nmap <F11> :!ctags -R --languages=c++\
    \ --c++-kinds=+p --fields=+iaS --extra=+q . `rospack cflags-only-I`<CR>\n\"map\
    \ <F11> :!ctags -R --c++-kinds=+p --fields=+iaS --extra=+q ~/local/usr/include/<CR>\n\
    \" configure tags - add additional tags here or comment out not-used ones\nset\
    \ tags+=~/.vim/tags/stdlibtags\nset tags+=~/.vim/tags/gltags\n\"set tags+=~/.vim/tags/sdl\n\
    set tags+=~/.vim/tags/qt4tags\n\" OmniCppComplete\nlet OmniCpp_NamespaceSearch\
    \ = 1\nlet OmniCpp_GlobalScopeSearch = 1\nlet OmniCpp_ShowAccess = 1\nlet OmniCpp_MayCompleteDot\
    \ = 1\nlet OmniCpp_MayCompleteArrow = 1\nlet OmniCpp_MayCompleteScope = 1\n\"\
    let OmniCpp_DefaultNamespaces = [\"std\", \"_GLIBCXX_STD\"]\n\n\" automatically\
    \ open and close the popup menu / preview window\nau CursorMovedI,InsertLeave\
    \ * if pumvisible() == 0|silent! pclose|endif\nset completeopt=menuone,menu,preview\
    \ \",longest \n\"END Omnicompletion\n\n</pre>\nVim's present working dir (:pwd)\
    \ needs to be the root directory of your package (i.e., the output of `rospack\
    \ find <yourpackage>`) because calling \"rospack cflags-only-I\" without package\
    \ name argument will use the current dir as package name. This is the case if\
    \ you start vim in that directory or use :cd to change there. Alternatively you\
    \ could somehow (I do not know how, though) find out the package name of the project\
    \ your file belongs to, to give it to the rospack call."
