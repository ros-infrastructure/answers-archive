  body_markdown: "### EDITED\n\n**NOTICE** by @gvdhoorn  \n\nThe EXACT argument is\
    \ there to avoid incompatibilities between the version of Qt5 being linked by\
    \ the tutorial package and the packages that it depends on (ie: RViz). If you\
    \ don't use the same version, there is a risk of running into ABI incompatibilities,\
    \ which are hard to diagnose.\n\n\n---\n\n\nHello, I solved this problem by myself.\n\
    \nI remove the `EXACT` option on `CMakeList.txt` placed on each packages.\nlike\
    \ \n\n*Before*  \n\n    ...\n      find_package(Qt5 ${rviz_QT_VERSION} EXACT REQUIRED\
    \ Core Widgets)\n    ...\n\n*After*\n  \n    ...\n      find_package(Qt5 ${rviz_QT_VERSION}\
    \ REQUIRED Core Widgets)\n    ...\n\nThe point of those is that you need to do\
    \ every package which have same error."
