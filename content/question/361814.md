    This build failure is in the tests, which aren't critical to building the `nav2_util` package.  Comment out the [three lines][0] configuring the broken `test_actions.cpp` test in `nav2_util/test/CMakeLists.txt` and try again.  (I actually haven't tried this repo, but fixed a [similar issue][0.1] in the `ros-controls/realtime_tools` repo; it's possible this isn't the only issue.)

    [0]: https://github.com/ros-planning/navigation2/blob/foxy-devel/nav2_util/test/CMakeLists.txt#L20-L22
    [0.1]: https://github.com/ros-controls/realtime_tools/issues/65

    This problem actually originates in a maze of little problems; here's a summary and links to the gory details:

    - The compiler error is a result of the `fibonacci` action headers in the `ros-foxy-test-msgs` Debian package being [generated by a newer version][1] of the `rosidl_runtime_cpp` ROS package (v. `1.1.0`+) than the actual `ros-foxy-rosidl-runtime-cpp` package currently shipped in Foxy (v. `1.0.1`)
    - [It's a miracle][2] the `fibonacci` action even exists in the `ros-foxy-test-msgs` v. `1.0.0` package, given that the now-obsolete action was removed from the `test_msgs` source in git tag `0.7.2`
    - Now there are issues in the [`ros-planning/navigation2` repo][3] and [`ros-controls/realtime_tools` repo][4] noting that the obsolete action needs to be removed in ROS2 branches to avoid build failures

    [1]: https://github.com/ros2/rosidl/issues/544
    [2]: https://github.com/ros2/rcl_interfaces/issues/114
    [3]: https://github.com/ros-planning/navigation2/issues/2069
    [4]: https://github.com/ros-controls/realtime_tools/issues/65
