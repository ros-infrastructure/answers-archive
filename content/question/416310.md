    \ to be the name of a <s>branch</s> \"version\" on that repo, which means, yes\
    \ it'll fetch the latest on that branch.\n\nYou can create your own `.repos` file\
    \ (to e.g. modify version fields) and supply it to `vcs import` command by e.g.\
    \ \n\n    vcs import src < ./foo/baa.repos"
