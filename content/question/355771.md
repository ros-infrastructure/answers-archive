    I compiled my project with [compileall](https://docs.python.org/3/library/compileall.html)
    <br>File mentioned in node launch should have execution permission (chmod +x)
    <br>Renamed module files in ____pycache____ from ModuleName.cpython-37.pyc to ModuleName.pyc (otherwise it throws Import error)
    <br>Changed type to .pyc file in launch file:

        <node name="rest_api" pkg="hspr" type="rest.cpython-37.pyc" output="screen">

    Then it works OK, even after original python files deleted
