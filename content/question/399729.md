  body_markdown: "Let's say you've declared a `LaunchConfiguration` substitution for\
    \ the file path argument, you would have to resolve the provided (possibly relative)\
    \ path to an absolute path, after which you can just read the file.\n\n    from\
    \ pathlib import Path\n    \n    file_path = LaunchConfiguration('file_path')\n\
    \    file_path_arg = DeclareLaunchArgument('file_path')\n    \n    absolute_file_path\
    \ = Path(file_path).resolve()\n    with open(absolute_file_path, mode='r') as\
    \ file_handle:\n        file_contents = file_handle.read()"
