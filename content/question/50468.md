    \ python-rosinstall. Just updating both should solve this. The error message will\
    \ be changed soon.\n\nDo not mix apt-get installs with easy_install/pip stuff.\
    \ \nPlease remove all vcstools from /usr/local/lib/..., because it interferes\
    \ with the apt-get install of python-vcstools.\n\napt-get installs rosinstall\
    \ and vcstools to /usr/share/...\neasy_install/pip install them to /usr/local\n\
    \nIf you install both, the binary from /usr/share will attempt to load the libraries\
    \ from /usr/local, so all kinds of problems occur."
