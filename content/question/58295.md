    In [rosbuild](http://www.ros.org/wiki/rosbuild), to build the library you use `rosbuild_add_library` [shown here](http://www.ros.org/wiki/rosbuild/CMakeLists#rosbuild_add_library), which is similar to the standard CMake `add_library` function. Then to make it available to other ros packages, you add the library linker arguments to a  `<cpp>` export tag in the package's manifest.xml [shown here](http://www.ros.org/doc/independent/api/rospkg/html/manifest_xml.html#export-cpp).

    In [catkin](http://www.ros.org/wiki/catkin), you use the normal `add_library` CMake function to build the library. Then to make the library available to other ros packages, you add the library target to the `LIBRARIES` arguments of a call to the `catkin_package` CMake macro, [shown here](http://www.ros.org/wiki/catkin/CMakeLists.txt#catkin_package.28.29).
