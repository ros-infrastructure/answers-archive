Hi, I have been trying to write a publisher in pygazebo in order to change the fog level in my gazebo world. I have been using a modified version of pygazebo that works with Python3 from this github (https://github.com/robogeekcanada/STEMClub/tree/master/pygazebo) that @osilva wrote. When I use the example given in pygazebo for a publisher, I get the error `AttributeError: '_asyncio.Future' object has no attribute 'publish'`. I have been trying to fix this, but have come up with no solution. I have attached my code below:
    
    import asyncio
    
    import pygazebo
    from pygazebo.msg.v11 import world_stats_pb2, fog_pb2, color_pb2
        
    async def publisher_loop():
        manager = await pygazebo.connect()
        
        publisher = manager.advertise('/gazebo/default/fog', 'gazebo.msgs.Fog')
    
        fog_color = color_pb2.Color()
        fog_color.r = 1
        fog_setting = fog_pb2.Fog(type=2, color=fog_color, start=0)
        fog_setting.density = 1000
    
        await publisher.publish(fog_setting)
        await asyncio.sleep(1.0)
    
    if __name__ == "__main__":
        loop = asyncio.get_event_loop()
        loop.run_until_complete(publisher_loop())

Any help would be greatly appreciated!
