  body_markdown: "You have an issue because you can't give the `yaml` file as an argument\
    \ in the `node` tag. As discussed in [#q274609](https://answers.ros.org/question/274609/is-there-a-way-to-read-from-a-text-or-yaml-file-and-pass-its-data-to-arg-tag/),\
    \ you have to modify your launch file like this model (the arg part isn't mandatory\
    \ but useful if you have to include your launchfile in another one) :\n\n    <launch>\n\
    \        <arg name=\"file_name\" default=\"$(find my_package)/my_yaml.yaml\"/>\
    \   \n        <rosparam command=\"load\" file=\"$(arg file_name)\"/>\n    </launch>\n\
    \nSo in your case it should look like this :\n\n    <launch>\n       <node name=\"\
    SLAM\" pkg=\"SLAM\" type=\"SLAM\">\n        <rosparam command=\"load\" file=\"\
    $(find YOUR_PACKAGE_NAME_WITH_DATA_FOLDER)/Data/Asus.yaml\"/>\n        <rosparam\
    \ command=\"load\" file=\"$(find YOUR_PACKAGE_NAME_WITH_DATA_FOLDER)/Data/ORBvoc.yaml\"\
    />\n       </node>\n    </launch>\n\n**Note 1 :** You can add the `rosparam` tags\
    \ outside the `node` tag if you want to share your parameters with other nodes.\n\
    \n**Note 2 :** If you didn't notice, I changed `ORBvoc.txt` to `ORBvoc.yaml`.\
    \ I don't know what your `txt` file is but if you have to load parameters from\
    \ this file too you can't pass another file than a `yaml` one so you'll have to\
    \ change your file extension to `yaml`, see [#q12284](https://answers.ros.org/question/12284/how-to-use-txt-file-as-a-parameter-to-roslaunch-file/)."
