    \ Similar to building on Ubuntu 16.04, try adding a package ignore flag (`--packages-ignore\
    \ qt_gui_cpp rqt_gui_cpp`) to the `colon build` command:\n\n\n  \n\n    colcon\
    \ build \\\n       --symlink-install \\\n       --packages-ignore qt_gui_cpp rqt_gui_cpp\
    \ \\\n       --cmake-force-configure \\\n       --cmake-args \\\n         --no-warn-unused-cli\
    \ \\\n         -DCMAKE_TOOLCHAIN_FILE=`pwd`/aarch64_toolchainfile.cmake \\\n \
    \        -DTHIRDPARTY=ON \\\n         -DBUILD_TESTING:BOOL=OFF \\\n         -DCMAKE_BUILD_RPATH=\"\
