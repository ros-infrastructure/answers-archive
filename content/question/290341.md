  body_markdown: |-
    The correct (as in recommended) way is using a [CameraSubscriber](http://docs.ros.org/kinetic/api/image_transport/html/classimage__transport_1_1CameraSubscriber.html). Using this approach, a callback is triggered that provides both the Image and the CameraInfo simultaneously.

    Example usage for instance [here](https://github.com/tu-darmstadt-ros-pkg/hector_vision/blob/kinetic-devel/hector_qrcode_detection/src/qrcode_detection.cpp#L59).

    Often, a lazy model subscription model is used, that only subscribes to camera data data when a output topic is subscribed at least once. An example of that approach can be seen [here in the rectify nodelet](http://docs.ros.org/jade/api/image_proc/html/rectify_8cpp_source.html). It's a little bit harder to read/understand, though.
