    Hi,

    I figured out the solution to my problem.
    The thing is, after having an `apt-get dist-upgrade` my gazebo simulator was upgraded to `gazebo 2.1` (previously it was `gazebo 1.9` the stable version). It looks like the newer version is having some problems with `hydro`.

    I had to uninstall the new version of gazebo i.e v2.1 by `apt-get remove gazebo-current`.
    After that I installed the earlier version i.e v1.9 [http://gazebosim.org/wiki/1.9/install](http://gazebosim.org/wiki/1.9/install) and then had to run these commands:

        $ sudo apt-get install ros-hydro-turtlebot-simulator
        $ source /opt/ros/hydro/setup.bash
        $ roslaunch turtlebot_gazebo turtlebot_empty_world.launch

    And it started publishing and subscribing again.

    Cheers!
