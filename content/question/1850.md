  body_markdown: "Hi,\n\nOn a **joint** you can only apply a force, with SetForce.\
    \ See [here](http://gazebosim.org/api/1.5.0/classgazebo_1_1physics_1_1Joint.html#a8da0e864018bc0810bbfcf1e930183a7).\n\
    \n    model->GetJoint(\"joint_name\")->SetForce(int _index,double _force); \n\n\
    \nIf you want to apply torque, you apply it with SetTorque to the **link**. See\
    \ [here](http://gazebosim.org/api/1.5.0/classgazebo_1_1physics_1_1Link.html#a85cab66b9c9ba07d411478efab212d5a).\n\
    An example:\n<br>\n\n    model->GetLink(\"link_name\")->SetTorque(vector3);\n\n\
    \n---UPDATE---\n\nI took the example from [this](http://gazebosim.org/wiki/Tutorials/1.5/plugins/model_manipulation_plugin)\
    \ tutorial, you can check it out.\n\n    ...\n    public: void Load(physics::ModelPtr\
    \ _parent, sdf::ElementPtr /*_sdf*/) \n    {\n      this->model = _parent;\n\n\
    \      this->updateConnection = event::Events::ConnectWorldUpdateBegin(\n    \
    \      boost::bind(&ClassName::OnUpdate, this, _1));\n    }\n\n    public: void\
    \ OnUpdate(const common::UpdateInfo & /*_info*/)\n    {\n        // Check duration\
    \ here, something like:\n        // if ((common::Time dt = this->model->GetWorld()->GetSimTime()\
    \ - last_saved_time) < 5 )\n        model->GetLink(\"link_name\")->SetTorque(math::Vector3(0,\
    \ 0, 0));\n    }\n    ...\n\nCheers, Andrei"

std::map<std::string, common::NumericAnimationPtr> anim;

      // Create a new animation for the "my_joint" define in the SDF file.
      // The animation will last for 5.0 seconds, and it will repeat
      anim["box::my_joint"].reset(new common::NumericAnimation(
            "my_animation", 5.0, true));

      // Create a key frame for the starting position of the joint
      common::NumericKeyFrame *key = anim["box::my_joint"]->CreateKeyFrame(0.0);
      key->SetValue(0.0);

      // Create a key frame half-way through the animation
      key = anim["box::my_joint"]->CreateKeyFrame(2.5);
      key->SetValue(-3.14);

      // Create the end key frame to be at the same position as the start
      // for a smooth animation
      key = anim["box::my_joint"]->CreateKeyFrame(5.0);
      key->SetValue(0.0);

     // Attach the animation to the model
      _model->SetJointAnimation(anim);
