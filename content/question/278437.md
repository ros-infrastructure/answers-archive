  body_markdown: "Check out the [`urdf` tutorials](http://wiki.ros.org/urdf/Tutorials)\
    \ and learn how `urdf` and `xacro` files work. Then, you can use this [R200 `xacro`\
    \ file](https://github.com/IntelRealSense/realsense_samples_ros/blob/kinetic-devel/realsense_ros_camera/urdf/_r200.urdf.xacro)\
    \ to replace the kinect in the drone you found. \n\nYou can probably do this by\
    \ using the [quadrotor base `xacro` file](https://github.com/tu-darmstadt-ros-pkg/hector_quadrotor/blob/HEAD/hector_quadrotor_description/urdf/quadrotor_base.urdf.xacro)\
    \ in the [`hector_quadrotor_description` package](http://wiki.ros.org/hector_quadrotor_description)\
    \ and adding that R200 `xacro` file that I linked to.\n\nIf you call this new\
    \ file `quadrotor_r200.xacro` then you can load this into Gazebo by using a launch\
    \ file (let's call it `spawn_quadrotor.launch`) similar to\n\n    <launch>\n \
    \     <!-- load model -->\n      <param name=\"robot_description\" command=\"\
    $(find xacro)/xacro.py $(arg model) myvar:=true\"/>\n      <!-- Spawn a robot\
    \ into Gazebo -->\n      <node name=\"spawn_urdf\" pkg=\"gazebo_ros\" type=\"\
    spawn_model\" args=\"-param robot_description -urdf -model quadrotor\"/>\n   \
    \ </launch>\n\nThe run this launch file as\n\n    roslaunch my_package spawn_quadrotor.launch\
    \ model:=/path/to/quadrotor_r200.xacro"
