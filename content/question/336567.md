  body_markdown: "just create a new xacro file where you include the two urdfs,\n\
    something like:\n\n \n      <?xml version=\"1.0\"?>\n      <robot xmlns:xacro=\"\
    http://ros.org/wiki/xacro\" name=\"robot\">\n   \n      <xacro:include filename=\"\
    $(find ur_description)/urdf/ur10_robot.urdf.xacro\" />\n    \n      <xacro:include\
    \ filename=\"$(find robotiq_85_description)/urdf/robotiq_85_gripper.xacro\" />\n\
    \    \n      </robot>\n\nmake sure to connect the first frame of the gripper with\
    \ the last frame of the UR (should be tool0).\nOnce you load the new urdf with\
    \ the setup assistant you can see graphically if you have succeeded."
