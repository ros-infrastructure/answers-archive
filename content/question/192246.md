  body_markdown: "You need to set up a wifi access point and set that as the ros master.\
    \ \nYou probably want to set this access point in your robot which has roscore\
    \ running and connect to its network with your laptop. \nMore info on how to make\
    \ a ros master here: http://wiki.ros.org/ROS/NetworkSetup\n\n**EDIT**\n\n1. Figure\
    \ out where roscore is running in. (It is probably in your robot)\n2. Set up a\
    \ single wireless network. (In your case if the robot has the roscore running\
    \ you want to set up a wireless access point in the robot and connect to the wireless\
    \ network with your computer)\n3. Configure the Ros master URI so that you can\
    \ see all of the ros topics in your computer: info here http://wiki.ros.org/ROS/NetworkSetup\
    \ (you need to edit the robot's .bashrc and your computers .bashrc according to\
    \ the wiki)\n"
