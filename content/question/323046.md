    \ order to get their specific coordinate? \n\nTo get the coordinates of a joint\
    \ you need a fixed frame (such as `world` or `map`) otherwise any joint could\
    \ have any coordinates depending the frame you are reading the coordinates from.\n\
    \n    rosrun tf tf_echo /world /joint\n\nThis command can give you the coordinates\
    \ of a specific joint in the world (can be `map` or any other frame that is fixed\
    \ in your world). You will be able to read those coordinates in the terminal but\
    \ given what you said I assume you actually want to get those coordinates in your\
    \ code to process them.\n\nYou will achieve that using `tf` by checking the transformation\
    \ between your reference frame and your desired joint. Here's an example using\
    \ `geometry_msgs::PoseStamped` (to get `x`, `y`, `z`) to constantly get the coordinates\
    \ of a joint :\n\n    //Required includes\n    #include <tf2_geometry_msgs/tf2_geometry_msgs.h>\n\
    \    #include <tf2_ros/transform_listener.h>\n    \n    tf2_ros::Buffer tf_; \n\
    \    geometry_msgs::PoseStamped joint_global_frame_pose_stamped;\n    geometry_msgs::PoseStamped\
    \ joint_pose_stamped;\n    //Just an initialization\n    tf2::toMsg(tf2::Transform::getIdentity(),\
    \ joint_global_frame_pose_stamped.pose);\n    tf2::toMsg(tf2::Transform::getIdentity(),\
    \ joint_pose_stamped.pose);\n    ros::Rate rate(10.0);\n    while(ros::ok())\n\
    \    {\n        //The frame you want to get the pose \n        joint_pose_stamped.header.frame_id\
    \ = \"joint\";\n        joint_pose_stamped.header.stamp = ros::Time();\n     \
    \   //Catch exceptions\n        try\n        {\n            //3rd param = The\
    \ global frame\n            tf_.transform(joint_pose_stamped, joint_global_frame_pose_stamped,\
    \ \"map\");  \n        }\n        catch (tf2::LookupException& ex)\n        {\n\
    \            ROS_ERROR_THROTTLE(1.0, \"No Transform available Error looking up\
    \ joint pose: %s\\n\", ex.what());\n        }\n        catch (tf2::ConnectivityException&\
    \ ex)\n        {\n            ROS_ERROR_THROTTLE(1.0, \"Connectivity Error looking\
    \ up joint pose: %s\\n\", ex.what());\n        }\n        catch (tf2::ExtrapolationException&\
    \ ex)\n        {\n            ROS_ERROR_THROTTLE(1.0, \"Extrapolation Error looking\
    \ up joint pose: %s\\n\", ex.what());\n        }\n    \n        ROS_INFO(\"The\
    \ joint position is { %.2f; %.2f; %.2f}\", \n                joint_global_frame_pose_stamped.pose.postion.x,\n\
    \                joint_global_frame_pose_stamped.pose.postion.y,\n           \
    \     joint_global_frame_pose_stamped.pose.postion.z);\n    }\n\n"

      \ they give \n> is not my joint 3 coordinate is it?\n\nAs said previsously it's\
      \ a translation and rotation so that you can use it to transform coordinates\
      \ from a frame to another.\nIf you want your joint coordinates, since the joint\
      \ is the origin of the related frame then the translation from `tf_echo` is\
      \ directly the coordinates of the joint.\n\nSo if your `joint3` has `child_link`\
      \ to `/arm_link4` and you want its coordinates in `/arm_link_0` frame you just\
      \ have to get the translation from `rosrun tf tf_echo /arm_link0 /arm_link4`.\
      \ This will give you the coordinates of `/arm_link4` frame (i.e. your `joint3`\
      \ coordinates) within `/arm_link0` frame."
