    \ would be no need for two way communication and no ROS on the arduino all i needed\
    \ to do was basically pass three integers over the serial port. Turned out there\
    \ was a much simpler way to do that, simply by importing the \"Serial\" library\
    \ in the python script in ROS. \n\n**The transmitting end in python(ROS):**\n\n\
    `import serial`\n\n`import time`\n\n`arduino = serial.Serial(dev/ttyUSB0, 115200,\
    \ timeout = 1)`\n\n`time.sleep(2)`\n\n`arduino.write(integer)`\n\n**Receiving\
    \ end on arduino:**\n\n`if (Serial.available() > 0) {`\n\n`    Serial.read();`\n\
    \n`    integer = Serial.parseInt();`\n\n`}`\n\nHope this can help others in the\
    \ future."
