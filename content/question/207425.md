- accepted: true
  body_markdown: "The scan angles depend on the angle_increment and angle_min values\
    \ stored into the topic (as you can see [here](http://docs.ros.org/api/sensor_msgs/html/msg/LaserScan.html)).\
    \ i.e.: if angle_increment is set to 0.1 (rad) the first range measurement is\
    \ refered to `angle_min + 0*0.1`  , the second to `angle_min + 1*0.1` rad, the\
    \ third to `angle_min+2*0.1` rad and so on. \nIn general, the angle refered to\
    \ a particular range measurement is\n\n    angle = angle_min + index*angle_increment\n\
    \nwhere `index` is refered to the index of the vector's element containing that\
    \ range measurement."
