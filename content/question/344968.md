- body_markdown: "Hi @Dallas_doublewide,\n\n**Question**: You can use the plugins\
    \ provided with [hector_gazebo_plugins](http://wiki.ros.org/hector_gazebo_plugins)\
    \ to add a GPS and IMU sensor to the URDF description of your robot.\n**Q2**:\
    \ Rviz provides several displays for what you want to achieve. You can use the\
    \ `Odometry` display type for GPS and IMU display type for IMU data; you can find\
    \ it in [rviz_plugin_tutorials](http://wiki.ros.org/rviz_plugin_tutorials) package.\n\
    Q3: I am sure this set up will not be sufficient to follow GPS waypoints, you\
    \ will need precise localization and probably a fusion of odometries. I would\
    \ set up first a RTK correction for the GPS and a [kalman filter](http://wiki.ros.org/robot_localization)\
    \ to fuse IMU, GPS and robot odometry since in the real platform you will have\
    \ problems with orientation. \n**Q4**: Why not use [rosbags](http://wiki.ros.org/rosbag)?\
    \ With it you will be able to record data and save it for a future usage without\
    \ the need of moving the robot.\n**Q4**: It depends on the target sensor yo are\
    \ using."
