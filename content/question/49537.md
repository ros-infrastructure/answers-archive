  body_markdown: |-
    Last time I looked into this, you could either get all model states via the "/gazebo/model_states" topic (as you suggested) or use the "/gazebo/get_model_state" service as described [here](http://www.ros.org/wiki/simulator_gazebo/Tutorials/Gazebo_ROS_API), if you need information for a specific model. This service-based method probably isn't the nicest option if you have to retrieve the state at high updates rates, though.

    If you're using the [hector_quadrotor](http://www.ros.org/wiki/hector_quadrotor) stack for simulation you're in luck though, as the ground truth pose is already provided on the "/ground_truth/state" topic through the use of the "libgazebo_ros_p3d.so" plugin. Corresponding gazebo xacro file [here](http://code.google.com/p/tu-darmstadt-ros-pkg/source/browse/fuerte/trunk/hector_quadrotor/hector_quadrotor_controller/urdf/quadrotor_sensors.urdf.xacro) (at the bottom).
