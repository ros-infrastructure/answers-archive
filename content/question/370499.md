    colcon provides an `--install-base` option that will place the installed files anywhere in the filesystem. Be careful with this though because the files won't be managed by the system package manager and there's no guarantee old files will get replaced if you ever reinstall, for example. If you go this route, I would advise using `/opt/ros` over `/usr/local` and fully deleting it prior to each installation.
