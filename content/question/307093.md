  body_markdown: "I would suggest using `ackermann_msgs` as:\n\n 1. it's a message\
    \ that is used by many other nodes and controllers\n 1. `clearpath_msgs` is old,\
    \ unused and unmaintained\n\nIf you must use `clearpath_msgs`, you can find it\
    \ [here](https://github.com/clearpathrobotics/clearpath_base).\n\nYou'll have\
    \ to `git clone ..` it to your Catkin workspace, make sure to have all dependencies\
    \ installed (see #q252478 for the general procedure) and then build the workspace.\n\
    \n> Problems with ackermann_msgs are its variable names can be misleading to someone\
    \ \n\nThis I don't understand.\n\n> and its data types are 'float', I prefer 'double'.\n\
    \nIt's up to you, but for values this small I would be surprised it really makes\
    \ a difference."
