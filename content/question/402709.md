    \ it is possible to switch between 2 configs A/B with `SetLaunchConfiguration`\
    \ like this:\n    \n    launch_configuration.append(SetLaunchConfiguration(\"\
    yaml_config\", \"config_A.yaml\", condition=UnlessCondition(LaunchConfiguration(\"\
    some_option\"))))\n    launch_configuration.append(SetLaunchConfiguration(\"yaml_config\"\
    , \"config_B.yaml\", condition=IfCondition(LaunchConfiguration(\"some_option\"\
    ))))\n\n    my_node = Node(\n        package='my_pkg',\n        name='my_node',\n\
    \        executable='my_node',\n        parameters=[\n            PathJoinSubstitution([FindPackageShare('my_pkg'),\
    \ 'config', LaunchConfiguration('yaml_config')])\n        ]\n    )\n\nThere is\
    \ also `LaunchConfigurationEquals` for non boolean tests:\n    \n    condition=IfCondition(LaunchConfigurationEquals(\"\
    config_type\", \"config_A\"))\n\nAnd to trigger loading with a bool, the full\
    \ path could be set into a `SetLaunchConfiguration` like this:\n\n    launch_configuration.append(SetLaunchConfiguration(\"\
    yaml_config\",  PathJoinSubstitution([FindPackageShare('my_pkg'), 'config', 'config_X.yaml'),\
    \ condition=IfCondition(LaunchConfiguration(\"load_config_X\"))))\n    # ...\n\
    \    my_node = Node(\n        # ...\n        parameters=[\n            LaunchConfiguration('yaml_config'),\n\
    \        ]\n    )\n\nAt the end of the day, it was not complicated, unfortunately\

    <arg name="load_config_X" default="true"/>
    <arg name="config_type" default="config_A"/>
