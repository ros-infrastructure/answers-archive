  body_markdown: "Solution (for **ROS groovy and Ubuntu 12.04LTS 64bit**):\n\nYou\
    \ need to edit your bashrc file by doing the next in terminal:  $gedit ~/.bashrc\
    \     \n\nAfter that you need to specify the path like this (just copy and paste\
    \ somewhere inside):\n\n*export ROS_PACKAGE_PATH=/home/YOURNAME_PROBABLY/catkin_ws/install/share:/home/YOURNAME_PROBABLY/catkin_ws/install/stacks:/home/YOURNAME_PROBABLY/catkin_ws:$ROS_PACKAGE_PATH*\n\
    \nInfo: catkin_ws is the catkin workspace that you should have settled up during\
    \ ROS installation\n\nAfter that I had also the problem while running:\nrosrun\
    \ rosserial_python serial_node.py /dev/ttyUSB0\n\nThat USB0 should be ACM0 (for\
    \ arduino)\n\nThat was it in short!"
