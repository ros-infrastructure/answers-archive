    \ need to be in the dialout group. \nI had a similar issue with the iRoomba create\
    \ 2 and I fixed it by doing:\n\n> sudo adduser <*your-username*> dialout\n\nand\
    \ **very,very,VERY important:** don't forget to logout and login back on your\
    \ machine for the changes to be applied :)"
