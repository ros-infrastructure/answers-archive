    As I also answered on the ROS-Industrial mailing list, this is a known issue. Compatibility with newer system software versions has not been maintained for the `ur_driver` package. See also [wiki/universal_robot](http://wiki.ros.org/universal_robot), [ros-industrial/universal_robot#183](https://github.com/ros-industrial/universal_robot/issues/183) and [ros-industrial/universal_robot#199](https://github.com/ros-industrial/universal_robot/issues/199).

    We recommend people try out the newer [ur_modern_driver](https://github.com/ThomasTimm/ur_modern_driver) which has better compatibility with these recent controller versions.
