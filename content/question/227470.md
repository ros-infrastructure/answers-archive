    Note that if you want to keep it simple, you don't actually need to implement another 'planner' in the sense of building a planner plugin for `move_base`. What you need is a node that simply maintains a queue of goals (your waypoints) which you could provide via a topic or service, and sends them successively to `move_base` (see [this tutorial](http://wiki.ros.org/navigation/Tutorials/SendingSimpleGoals)) after each one is completed.
