  body_markdown: "Hello, I have had the same issue and for me (on Eloquent) the following\
    \ works:\n    \n    logger = launch.substitutions.LaunchConfiguration(\"log_level\"\
    )\n    launch.LaunchDescription([\n          launch.actions.DeclareLaunchArgument(\n\
    \                \"log_level\",\n                default_value=[\"debug\"],\n\
    \                description=\"Logging level\",\n          ),\n         launch_ros.actions.Node(\n\
    \             package='demo_nodes_cpp',\n             executable='talker',\n \
    \            output='screen', \n             arguments=['--ros-args', '--log-level',\
    \ logger]\n        )\n    ])\n\nI got this idea from this open issue: https://github.com/ros2/launch/issues/383\
    \ and hopefully a more elegant solution will be available soon. \n\nIf anyone\
    \ has an idea for a better solution in the meantime, please share!"
