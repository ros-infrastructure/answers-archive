     If you need the symbolic Jacobian of your robot you should calculate it in symbolic form using Matlab for example. It allows symbolic calculation as exemplified in [this](http://it.mathworks.com/help/symbolic/jacobian.html) page. Moreover, the Matlab  [Robotic Toolbox](http://www.petercorke.com/Toolboxes.html) has a C code generator useful to directly output the calculated symbolic quantities in C format.

    On the other hand, KDL library allows you to numerically compute the matrices of the robot dynamic model (e.g. Inertia, Coriolis, Gravity) starting from robot state (joint positions, velocities). You can find the detailed implementation [here](https://people.mech.kuleuven.be/~eaertbel/expressiontrees/api_full/orocos_kdl/html/chaindynparam_8cpp_source.html).

    Hope this can help.
