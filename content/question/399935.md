    > System: Ubunut 22.04 LTS, distribution Ros2 Galactic

    As you can see in [REP-2000: ROS 2 Releases and Target Platforms](https://www.ros.org/reps/rep-2000.html), specifically the [Galactic Geochelone (May 2021 - November 2022)](https://www.ros.org/reps/rep-2000.html#galactic-geochelone-may-2021-november-2022) section, Ubuntu `22.04` is not listed as a supported version of Ubuntu for ROS 2 Galactic.

    The only Ubuntu distribution which gets binary packages created for it is Ubuntu Focal (`20.04`):

    ![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/16514188889885051.jpg)

    It's also clearly stated on the installation page you link:

    ![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/16514189896702851.jpg)

    `apt` is completely correct when it tells you it cannot find `ros-galactic-desktop`.
