  body_markdown: "you can use the [`args`](http://wiki.ros.org/roslaunch/XML/node)\
    \ flag to pass in the arguments as you would from the command line:\n\n    <node\
    \ pkg=\"rosbag\" type=\"record\" args=\"-O <PATH_TO_BAGFILE>\" name=\"record\"\
    \ output=\"screen\"/>\n\n---\n**EDIT**\n\nEven though this is probably not the\
    \ way it is intended, you could also go with the prefix (note, lower case o):\n\
    \n    <node pkg=\"rosbag\" type=\"record\" args=\"-o <PATH_TO_BAGFILE>\" name=\"\
    record\" output=\"screen\"/>\n\ne.g. `-o ~/Desktop/` would result in the file\
    \ `/home/mig/Desktop/_2016-10-12-17-06-59.bag` on my system. But this is rather\
    \ a workaround then a proper solution.\n\n---\n**EDIT2**\n\n\t\nwhoops, soory\
    \ about that. Seems like the `~` shortcut for the users home directory cannot\
    \ be resolved from the launch file. So you need to specify the full path, i.e.\
    \ `/home/<USER>/...` for it to work."
