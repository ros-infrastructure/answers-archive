  body_markdown: "For your first point, if you need a message from another package,\
    \ add that package as a dependency.\n\nFor the second point, as stated [in the\
    \ docs](https://docs.ros.org/melodic/api/catkin/html/user_guide/setup_dot_py.html),\
    \ Python dependencies should be listed in your `package.xml` file\n\n> If you\
    \ have written non-ROS Python packages before, you have probably used the `requires`\
    \ field in the distuils setup function. This field, however, *has no meaning*\
    \ in ROS.\n>\n> All your Python dependencies should be specified in `package.xml`\
    \ as e.g. `<run_depend>python-numpy</run_depend>` (for older version 1 of `package.xml`)\
    \ or `<exec_depend>python-numpy</exec_depend>` (if you use format 2 of `package.xml`\n\
    > \n> Not all Python or pip packages are mapped to ROS dependencies. For a quick\
    \ check, try running `rosdep resolve python-mypackage` or `rosdep resolve python-mypackage-pip`\
    \ if you want to add a dependency on mypackage Python package. If these calls\
    \ return error, you may want to search through the [python.yaml file in rosdep](https://github.com/ros/rosdistro/blob/master/rosdep/python.yaml)\
    \ for similar names.\n\nIf you list your dependencies in  your `package.xml` file,\
    \ then `rosdep` should be able to list them and install them using the user's\
    \ package manager, if available (as far as I'm aware)."
