    You could use [embedded ruby](https://en.wikipedia.org/wiki/ERuby) to generate parametrized models.

    * [Here](http://answers.gazebosim.org/question/8753/algorithmic-world-generation/)'s an example of an SDF model with embedded ruby.

    * [Here](https://bitbucket.org/osrf/gazebo/src/39e64e7a40f12702cd2ed1cb80d219e3a7ecd4b2/worlds/torsional_friction_demo.world.erb?at=default&fileviewer=file-view-default)'s an example of an SDF world with embedded ruby.

    To regenerate the SDF from the erb template in the command line:

        erb model.rsdf > model.sdf

    Obs: see [this](http://answers.gazebosim.org/question/8753/algorithmic-world-generation/) answer.
