  body_markdown: "Creating and destroying (allowing them to go out of scope) publishers\
    \ and timers is thread-safe right now. For Subscriptions, Service Servers, and\
    \ Service Clients, creation is currently thread-safe, and destroying them was\
    \ intended to be, but there are some on going issues about that here:\n\nhttps://github.com/ros2/rclcpp/issues/349\n\
    \nand\n\nhttps://github.com/ros2/rclcpp/pull/431\n\nLong term hopefully all of\
    \ the actions will be thread-safe (that's the goal). Also we hope to improve the\
    \ documentation soon too, but anyone could help with that I think.\n\nOn a related\
    \ note, adding and removing nodes to/from executors is also thread-safe. So you\
    \ could do something like this:\n\n    #include <thread>\n    \n    #include <rclcpp/rclcpp.hpp>\n\
    \    #include <std_msgs/msg/string.hpp>\n    \n    using namespace std::chrono_literals;\n\
    \    \n    int main(int argc, char ** argv) {\n      rclcpp::init(argc, argv);\n\
    \    \n      rclcpp::executors::SingleThreadedExecutor executor;\n    \n     \
    \ auto node = std::make_shared<rclcpp::Node>(\"test\");\n      executor.add_node(node);\n\
    \    \n      std::thread t([&executor]() {\n        executor.spin();\n      });\n\
    \    \n      {\n        std::this_thread::sleep_for(1s);\n        auto pub = node->create_publisher<std_msgs::msg::String>(\"\
    chatter\");\n        std::this_thread::sleep_for(1s);\n        pub.reset();\n\
    \      }\n    \n      {\n        std::this_thread::sleep_for(1s);\n        auto\
    \ sub = node->create_subscription<std_msgs::msg::String>(\n          \"chatter\"\
    ,\n          [](const std_msgs::msg::String::SharedPtr msg) {(void)msg;});\n \
    \       std::this_thread::sleep_for(1s);\n        sub.reset();\n      }\n    \n\
    \      {\n        std::this_thread::sleep_for(1s);\n        executor.remove_node(node);\n\
    \        std::this_thread::sleep_for(1s);\n        executor.add_node(node);\n\
    \        std::this_thread::sleep_for(1s);\n        node.reset();\n        std::this_thread::sleep_for(1s);\n\
    \      }\n    \n    \n      executor.cancel();\n      t.join();\n    }\n\n"
