    Hi,

    ok I understand the idea now, currently I don't have access to a PC with gazebo installed to test a code snippet, but here is the idea how you should try to implement it via a plugin:

    [Here]( http://gazebosim.org/api/dev/classgazebo_1_1rendering_1_1Light.html) is the Light class with all the methods you need to control the light.

     You should be able to access it with [this](http://gazebosim.org/api/dev/classgazebo_1_1rendering_1_1Scene.html#a6c157551562ad3e4a39ce8bd28d58fa4) function. After accessing the Scene.

    In order to access the visual part of gazebo (eg Scene) you need to create a visual plugin, this way you get access to the GUI and the rendering engine. [Here](http://gazebosim.org/wiki/Tutorials/1.4/plugins/system_gui_plugin) is a tutorial how to create such a plugin.

    If you still have problems implementing it, let me know and I could write some code snippets.
