    Visualising and storing it are two different things, but both should be possible.

    For a live 3D visualisation of the data, you can use the [rviz_imu_plugin](http://wiki.ros.org/rviz_imu_plugin) in RViz.

    For plotting the data, you could look at [rqt_plot](http://wiki.ros.org/rqt_plot) or one of the alternatives that exist, like [rqt_multiplot](https://github.com/ethz-asl/rqt_multiplot_plugin) or [PlotJuggler](https://github.com/facontidavide/PlotJuggler).

    For recording the data, take a look at [rosbag](http://wiki.ros.org/rosbag). That will also allow you to play it back later.

Edit: thank you for your response. There is a manual how to show data for other users. I hope it should be useful.

1. install ROS + other features

2. sudo su
3. roscore

4. second terminal
5. sudo su
6. cd /root/catkin_ws   (or place where you have a catkin workspace)
7. source devel/setup.bash
8.  rosrun um7 um7_driver _port:=/dev/ttyAMA0 

A) show data in RVIZ

9. Third console
10. rosrun rviz rviz (you need rviz_imu_plugin)
11. add module IMU
12. fixed frame : imu_link
13 in module IMU fill topic /imu/data
14. rviz should show data from IMU

B) show RAW data in console

9. third console
10. sudo su
11. rostopic echo /imu/data (or show another type using rostopic list)
