  body_markdown: "The OccupancyGrid message contains three parts:\n\n1) The Header\
    \ information. This will include the frame_id of the map. When specifying the\
    \ origin of the map in the MapMetaData, the Pose that you use will be in this\
    \ frame. \n\n2) The meta data tells you the map resolution, the height, the width,\
    \ and the time it was created. It also contains the origin of the map in the frame\
    \ specified in the header's frame_id.\n\n3) The actual data for the map. It's\
    \ in row-major order, which means you will fill the data array like so: [row0,\
    \ column0, row1, column1, row2, column2 ...]. \n\nNOTE: The catch with this message\
    \ is that the data array only supports signed 8-bit integers (i.e. char) and can\
    \ only be filled with values from -128 to +127. I'm not sure what you're trying\
    \ to do with this map, but keep that in mind. "
