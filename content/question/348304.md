  body_markdown: "You can record any ROS data you want using `rosbag record`:  [http://wiki.ros.org/rosbag/Commandline](http://wiki.ros.org/rosbag/Commandline)\n\
    \nThen you can play that data back later.  While playing back recorded data, it\
    \ looks basically like it did originally, so you can use any tools and utilities\
    \ you want to look at and analyze the playback data.  Same as you could do with\
    \ the live data.  \n\nAll ROS data has timestamps, I believe. I think you get\
    \ that for free with ROS.  But some sensor plugins might also embed their own\
    \ special timing information into the streaming data if they feel it necessary."
