- body_markdown: "Yes, the navigation2 stack is a group of packages that contain all\
    \ building blocks of navigation. Localization is just one of those blocks. Currently\
    \ only 2D laser localization using AMCL is implemented in that localization block.\
    \ However you can solve that localization part running any other ros 2 node on\
    \ your side. The other navigation blocks (controller, planning, etc) should work\
    \ as expected. It is more a task of getting your environment ready.\n\nOf course,\
    \ it is possible using Python, in ROS (1 and 2) you can run one node in python\
    \ for example and others in C++ or Rust or Javascript. They would perfectly communicate\
    \ to each other. \n\nIn my opinon, one good way to do what you aim, could be to\
    \ start testing the navigation 2 as it is, then test the robot_localization package\
    \ as it is, once you understand how they work you are able to try what you are\
    \ asking. They both have a good documentation online."
