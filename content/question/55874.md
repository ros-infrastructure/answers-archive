    }\n\n\t\t\tnodeMainExecutorService.setMasterUri(uri);\n\t\t\tnew AsyncTask<Void,\
    \ Void, Void>() {\n\t\t\t\t@Override\n\t\t\t\tprotected Void doInBackground(Void...\
    \ params) {\n\t\t\t\t\tCustomActivity.this.init(nodeMainExecutorService);\n\t\t\
    \t\t\treturn null;\n\t\t\t\t}\n\t\t\t}.execute();\n\t}\n\nROS_MASTER_URI is your\
    \ fixed URI.\n\nCustomActivity is your original activity class.\n"

  body_markdown: "Thanks to Kazuto for the lead, but there are a few issues with his\
    \ answer. I was able to solve them with the included code. First, I changed startMasterChooser\
    \ in RosActivity.java to public, and then pasted this code into my activity:\n\
    \n    @Override\n\t  public void startMasterChooser() {\n\t\t\n\t\tSharedPreferences\
    \ prefs = PreferenceManager.getDefaultSharedPreferences(getBaseContext());\n\t\
    \tString masterURI = prefs.getString(\"masterURI\", \"http://192.168.1.113:11311\"\
    );\n\t\t\n\t\tIntent data = new Intent();\n\t\tdata.putExtra(\"ROS_MASTER_URI\"\
    , masterURI);\n\t    onActivityResult(0, RESULT_OK, data);\n\t    \n\t  }\n\n\
    Alternatively, you can just hardcode the masterURI...I chose to have it as a preference.\
    \ Hopefully changing the RosActivity code doesn't have any effect on future work."
