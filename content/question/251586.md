  body_markdown: "Here's an example with the Bash multiline syntax: \n\n    rostopic\
    \ pub /test geometry_msgs/PoseArray \"header:\n      seq: 0\n      stamp:\n  \
    \      secs: 0\n        nsecs: 0\n      frame_id: ''\n    poses:\n    - position:\n\
    \        x: 1.0\n        y: 2.0\n        z: 3.0\n      orientation:\n        x:\
    \ 0.0\n        y: 0.0\n        z: 0.0\n        w: 0.0\n    - position:\n     \
    \   x: 4.0\n        y: 5.0\n        z: 6.0\n      orientation:\n        x: 0.0\n\
    \        y: 0.0\n        z: 0.0\n        w: 0.0\"\n\nHere's an example using the\
    \ [YAML command line dictionary](http://wiki.ros.org/ROS/YAMLCommandLine#Command-line_and_messages_.28dictionaries.29)\
    \ syntax:\n\n    rostopic pub /test geometry_msgs/PoseArray \"{header: auto, poses:\
    \ [{position: [1,2,3]}, {position: [4,5,6]}]}\"\\\n\nYou can also use the `-f`\
    \ option to read the message contents from a YAML file. For example, imagine `tmp.yaml`\
    \ had the following contents:\n\n    poses:\n    - position:\n        x: 1.0\n\
    \        y: 2.0\n        z: 3.0\n      orientation:\n        x: 0.0\n        y:\
    \ 0.0\n        z: 0.0\n        w: 0.0\n    - position:\n        x: 4.0\n     \
    \   y: 5.0\n        z: 6.0\n      orientation:\n        x: 0.0\n        y: 0.0\n\
    \        z: 0.0\n        w: 0.0\n\nThis could be published using \n\n    rostopic\
    \ pub /test geometry_msgs/PoseArray -f tmp.yaml\n\nNote that when reading from\
    \ a file if you would like to publish the message continuously at a set rate,\
    \ you need to have multiple messages in the file separated by `---` lines.\n\n\
    Personally when the messages get this complicated, I generally just write a short\
    \ Python script to publish the desired message at whatever rate I want to avoid\
    \ having to mess with this complicated syntax at the command line."
