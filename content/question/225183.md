  body_markdown: "Hello, I was just having this problem and thanks to your comments\
    \ I got a decent solution, so I thought I should share it here. I modified the\
    \ laserscan_topic_parser to retry to read the topics listed after a delay, so,\
    \ here's my modification:\n\n    bool LaserscanMerger::laserscan_topic_parser(){\n\
    \n\tbool success = false;\n\t// LaserScan topics to subscribe\n\tros::master::V_TopicInfo\
    \ topics;\n\tros::master::getTopics(topics);\n\n    istringstream iss(laserscan_topics);\n\
    \tvector<string> tokens;\n\tcopy(istream_iterator<string>(iss), istream_iterator<string>(),\
    \ back_inserter<vector<string> >(tokens));\n\n\tvector<string> tmp_input_topics;\n\
    \n\tfor(int i=0;i<tokens.size();++i)\n\t{\n\t        for(int j=0;j<topics.size();++j)\n\
    \t\t{\n\t\t\tif( (tokens[i].compare(topics[j].name) == 0) && (topics[j].datatype.compare(\"\
    sensor_msgs/LaserScan\") == 0) )\n\t\t\t{\n\t\t\t\ttmp_input_topics.push_back(topics[j].name);\n\
    \t\t\t}\n\t\t}\n\t}\n\n\tsort(tmp_input_topics.begin(),tmp_input_topics.end());\n\
    \tstd::vector<string>::iterator last = std::unique(tmp_input_topics.begin(), tmp_input_topics.end());\n\
    \ttmp_input_topics.erase(last, tmp_input_topics.end());\n\n\n\t// Do not re-subscribe\
    \ if the topics are the same\n\tif( (tmp_input_topics.size() != input_topics.size())\
    \ || !equal(tmp_input_topics.begin(),tmp_input_topics.end(),input_topics.begin()))\n\
    \t{\n\n\t\t// Unsubscribe from previous topics\n\t\tfor(int i=0; i<scan_subscribers.size();\
    \ ++i)\n\t\t\tscan_subscribers[i].shutdown();\n\n\t\tinput_topics = tmp_input_topics;\n\
    \t\tif(input_topics.size() > 0)\n\t\t{\n            scan_subscribers.resize(input_topics.size());\n\
    \t\t\tclouds_modified.resize(input_topics.size());\n\t\t\tclouds.resize(input_topics.size());\n\
    \            ROS_INFO(\"Subscribing to topics\\t%ld\", scan_subscribers.size());\n\
    \t\t\tfor(int i=0; i<input_topics.size(); ++i)\n\t\t\t{\n                scan_subscribers[i]\
    \ = node_.subscribe<sensor_msgs::LaserScan> (input_topics[i].c_str(), 1, boost::bind(&LaserscanMerger::scanCallback,this,\
    \ _1, input_topics[i]));\n\t\t\t\tclouds_modified[i] = false;\n\t\t\t\tcout <<\
    \ input_topics[i] << \" \";\n\t\t\t}\n\t\t\tsuccess = true;\n\t\t}\n\t\telse\n\
    \            ROS_INFO(\"Not subscribed to any topic.\");\n\t}\n\treturn success;}\n\
    \nSo, basically, I only changed the return type from void to bool and created\
    \ a local variable (called \"success\") to determine if any topic was found. Then\
    \ I added a while loop on the LaserscanMerger class constructor to retry every\
    \ X seconds:\n\n    ros::Rate loop_rate(0.5); //-- 0.5 [Hz] -> 2.0 [s]\n    while(\
    \ !this->laserscan_topic_parser() )\n    {\n    \tROS_DEBUG(\"LaserscanMerger:\
    \ Retrying to detect the topics to subscribe to...\");\n    \tloop_rate.sleep();\n\
    \    }\n\nHope this helps someone =)."
