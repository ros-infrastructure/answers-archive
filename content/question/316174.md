  body_markdown: "> a tilde character this character is not recognized properly and\
    \ does not get converted to /home/username/. \n\nthe problem is that you're assuming\
    \ this is a generic bit of functionality or behaviour (\"in Linux\"), but it's\
    \ actually `bash` that substitutes `/home/username` for things like `~` and `$HOME`.\n\
    \n`roslaunch` does not do this, or at least not in the way you're currently using\
    \ it.\n\nYou *could* consider using the `env` [substitution arg](http://wiki.ros.org/roslaunch/XML#substitution_args)\
    \ for this specific case (with `$HOME`).\n"
