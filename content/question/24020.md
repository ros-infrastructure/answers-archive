    \ from packages.ros.org for a [few platforms](http://packages.ros.org/ros/ubuntu/pool/main/g/gazebo9/),\
    \ which does not include Ubuntu Bionic 18.04.\n\nI believe the tutorial may be\
    \ mixing `gazebo` with `gazebo_ros_pkgs`. ROS Melodic gets [gazebo9 from Ubuntu\
    \ official packages](https://packages.ubuntu.com/bionic/gazebo9), and [gazebo_ros_pkgs\
    \ from packages.ros.org](http://packages.ros.org/ros/ubuntu/pool/main/r/ros-melodic-gazebo-ros-pkgs/).\n\
    \n---\n\nTo summarize: you shouldn't be having any problems using `gazebo9` from\
    \ packages.osrfoundation.org together with `ros-melodic-gazebo-ros-pkgs` from\
    \ packages.ros.org."
