  body_markdown: "Try this at the end of your ~/.bashrc file. The way you have it\
    \ may be problematic in a few aspects. Keep it simple!\n\n    source /opt/ros/electric/setup.bash\n\
    \    export ROS_MASTER_URI=http://192.168.0.214:11311\n    export ROS_IP=192.168.0.214\n\
    \    export ROS_PACKAGE_PATH=~/ros_workspace:${ROS_PACKAGE_PATH}\n    export ROS_WORKSPACE=~/ros_workspace\n\
    \nYou shouldn't need to change anything else. No setup file should be needed.\
    \ The issues I saw with your configuration: \n\n1. ROS_HOSTNAME should be used\
    \ when you want it to detect an actual hostname, so I have it here as ROS_IP.\
    \ When both are present, ros defaults to hostname. \n\n2. The PATH environment\
    \ variable can be sensitive. Avoid changing it when possible. \n\nAlso, you should\
    \ check your write permissions in that directory. From the user you want to make\
    \ the package with, run the following: \n\n    sudo chown robolab -R ~/ros_workspace\n\
    \nHope this was helpful for you! "
