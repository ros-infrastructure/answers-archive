For normal unbounded vector<uint8>, its cdr_serialize() is like:

    cdr << ros_message.data; [which means memcopy(size * sizeof(uint8)) in fastCdr]

But for BoundedSequence<uint8>,

    cdr << static_cast<uint32_t>(size);
    for (size_t i = 0; i < size; i++) {
      cdr << ros_message.data[i];
    }
I find it is much more slower to serialize bounded vector by every single element.
So why we have to serialize bounded vector like that?
