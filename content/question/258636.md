  body_markdown: "Hi, \n\nIt seems to be a bit late but if anyone else need this.\
    \ I followed your method and after getting bad results too, I changed two things.\
    \ \n\nThe first, which I think cause your problem is the condition `!segmnt.getJoint().getName().compare(initJoints->name[i])`,\
    \ which I transform as `segmnt.getJoint().getName().compare(initJoints->name[i]\
    \ == 0)`, because String1.compare(String2) does not return a bool.\n\nThe second,\
    \ which is not important for good results (but I'm telling it to understand my\
    \ code below), is the order of your loops. If your joint_state message, like me,\
    \ is not necessarily ordered like the chain and could include other joints, it\
    \ is more \"optimized\" i think to invert these two loops \"for\" and break when\
    \ you find the match. Anyway, this doesn't really matter and this is my code which\
    \ seems to work :\n\n    \turdf::Model model;\n\tif (!model.initParam(\"robot_description\"\
    ))\n\t\treturn -1;\n\n\tKDL::Tree tree;\n\tif (!kdl_parser::treeFromUrdfModel(model,\
    \ tree)) {\n\t\tROS_ERROR(\"Failed to extract kdl tree from xml robot description\"\
    );\n\t\treturn -1;\n\t}\n\n\tconst sensor_msgs::JointStateConstPtr initJoints\
    \ = ros::topic::waitForMessage<sensor_msgs::JointState>(\"/joint_states\", n);\n\
    \n\tKDL::Chain chain;\n\ttree.getChain(\"base_link\", \"xtion_wrist_link\", chain);\n\
    \n\tKDL::JntArray joint_pos= KDL::JntArray(chain.getNrOfJoints());\n\t\n\tint\
    \ k = 0;\n\tfor(int i = 0; i < chain.getNrOfSegments(); i++)\n\t{\t\n\t\tKDL::Segment\
    \ segment = chain.getSegment(i);\n\t\tfor (int j = 0; j < initJoints->name.size();\
    \ j++)\n\t\t{\n\t\t\tif (segment.getJoint().getName().compare(initJoints->name[j])\
    \ == 0)\n        \t{\n\t\t\t\tif(segment.getJoint().getType() != KDL::Joint::None)\n\
    \t\t\t\t{\n\t\t\t\t\tjoint_pos(k) = initJoints->position[j];\n\t\t\t\t\tk++;\n\
    \t\t\t\t\tbreak;\n\t\t\t\t}\n\t\t\t}\n\t\t}\n\t}\n\n\tKDL::ChainFkSolverPos_recursive\

    \ frame);\n\tif (kinematics_status >= 0)\n\t{\n\t\tcout << \"fk ->    x : \" <<\
