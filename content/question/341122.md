  body_markdown: "[sensor_msgs::PointCloud2](http://docs.ros.org/melodic/api/sensor_msgs/html/msg/PointCloud2.html)\
    \ is already defined [sensor message](http://wiki.ros.org/sensor_msgs) but an\
    \ array of `sensor_msgs::PointCloud2` is not. Therefore you will need to define\
    \ your own custom message. Check the [tutorials](http://wiki.ros.org/ROS/Tutorials/CreatingMsgAndSrv)\
    \ on how to create and use a custom message.\n<br>\nYour `.msg` file (for example\
    \ you can name it `PointClouds.msg`) should look something like this: <br>\n\n\
    \    sensor_msgs::PointCloud2[] pointclouds\nOnce you have created and included\
    \ your msg, the following should work:\n\n    #include \"your_pkg_name/PointClouds.h\"\
    \n    ...\n    pcl::PointCloud<ClassPoint> out;\n     ....\n    sensor_msgs::PointCloud2\
    \ out_msg;\n    pcl::toROSMsg(out, out_msg);\n    \n    your_pkg_name::PointClouds\
    \ clouds_msg(2); \n    clouds_msg.pointclouds[0] = out_msg; // or just clouds_msg.pointclouds.push_back(out_msg);\n\
    \    out_msg.header.frame_id = corner_frame_name;\n    \n    pub_merged_clouds.publish(clouds_msg);\n\
    \nand your publisher:\n\n    pub_merged_clouds = nh.advertise<your_pkg_name::PointClouds>(merged_clouds_topic,\
    \ 1);"

    To add on to @stevemacenski's comment, have a look at [ROS tutorial](http://wiki.ros.org/ROS/Tutorials/CreatingMsgAndSrv ) . The custom msg will have an array of `sensor_msgs::PointCloud2`, e.g. in a `filename.msg`,  `sensor_msgs/PointCloud2[ ] clouds`. Then, in your code  declare `packagename::filename clouds` and `clouds.push_back(cloud)` each cloud. Include the new header file for the custom msg in your code. It would be better to build the new msg package first then your other package.
