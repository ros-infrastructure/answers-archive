  body_markdown: "if you use the OccupancyGrid (according to the map_server node)\
    \ in order to navigate the robot , \n\nyou might need the map in PGM format and\
    \ a description file in YAML ,with the data on the blueprint\n transformed into\
    \ a grid (in fact , an array)  which contains occupancy value.\n\n\n\n=> You may\
    \ convert the pdf into image file like bitmap and recreate the map by drawing\
    \ things manually\n (eg. wall , static obstacle , free area) \n\n[Make sure that\
    \ the resolution of the converted image is measured , it must be written in the\
    \ description file.]\n\nFrom image editing app like photoshop , you need to draw\
    \ everything according to color definition .\n\n  [Black = Occupied , White =\
    \ Free , Dark Grey = Unknown Area]\n\n\nMap examples can be found easily on many\
    \ repos as well as description file(YAML) ~ :D \n\n\n\n\n\n\n"
