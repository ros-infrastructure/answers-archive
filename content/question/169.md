    Hello,

    Gazebo 1.2 throttles itself to about 1.0 real-time. You can change this using the [update_rate](http://gazebosim.org/sdf/1.2.html#update_rate) SDF parameter. When the update_rate = 1/dt, which is the default, then Gazebo runs at realtime. Set the update_rate = 0 and Gazebo will run as fast as it can.

    The next major release of Gazebo has better sleep behavior, and will not use 100% of your CPU.

    The model database format is not necessary, and you don't have to name everything model.sdf. Gazebo does use URIs for everything, as described [here](http://gazebosim.org/wiki/Uri). So you can use `file://path_to_my_model.sdf`.
