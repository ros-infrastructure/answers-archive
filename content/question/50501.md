  body_markdown: "Hi \xC0ngel,\n\nYes I think you can see \"joining\" of robots in\
    \ various stacks, e.g. you might find something like the mobile WAM robot.  Also\
    \ it's practically the same principle as describing the manipulator once, but\
    \ using Xacro to include it twice to create a dual-arm robot, e.g. DARPA ARM or\
    \ Schunk dual-arm robot.\n\nFirstly make copies of the xacro files of the base\
    \ and the manipulator. <BR>\nYou might need to edit one to make sure the 2nd file\
    \ (manipulator) doesn't have a 'base_link' in it.\n\nMake a new xacro: <BR>\n\n\
    \    <?xml version=\"1.0\"?>\n    <robot name=\"joinedrobot\">\n        \n   \
    \ <!-- include xacro file containing a link where you want to attach the manipulator\
    \ -->\n    <include filename=\"$(find mobilerobot_description)/urdf/robot.urdf.xacro\"\
    />\n    \n    <joint name='jointhem_fixed_joint' type='fixed'>\n    <!-- you can\
    \ specify xyz offset to locate the manipulator -->\n    <origin xyz=\"0 0 0\"\
    \ rpy=\"0 0 0\" />\n    <parent link='location_for_arm_link' />\n    <child link='manipulator_base_link'>\n\
    \    \n    <!-- include xacro file where there first link is called manipulator_base_link\
    \ -->\n    <include filename=\"$(find manipulator_description)/urdf/manipulator_no_baselink.urdf.xacro\"\
    />\n    \n    </robot>\n\nWhen you load the xacro file, it will merge all the\
    \ code together.\n\nHere's a good launch file example, that will load the URDF\
    \ model in Rviz and allow you to test the joint movements using a GUI:\n\n   \
    \ <?xml version=\"1.0\"?>\n    <launch>\n        <param name=\"robot_description\"\
    \ command=\"$(find xacro)/xacro.py '$(find joinedrobot_description)/urdf/joinedrobot.urdf.xacro'\"\
    \ />\n    \n        <node name=\"robot_state_publisher\" pkg=\"robot_state_publisher\"\
    \ type=\"state_publisher\" />\n    \n        <param name=\"use_gui\" value=\"\
    true\" />\n        <node pkg=\"joint_state_publisher\" type=\"joint_state_publisher\"\
    \ name=\"joint_state_publisher\"/>\n    \n        <node name=\"rviz\" pkg=\"rviz\"\
    \ type=\"rviz\" args=\"-d $(find joinedrobot_description)/rviz/joinedrobot.vcg\"\
    \ />\n    </launch> \n\nOnce you're happy with this \"new\" robot, spawn it as\
    \ a single robot. <BR><BR>\n\n"
