Are there any known downsides of  using the packages hosted at [https://packages.ubuntu.com/](https://packages.ubuntu.com/), vs. those at [http://packages.ros.org/ros/ubuntu](http://packages.ros.org/ros/ubuntu)?

Some background:
Noetic is only supported on Ubuntu Focal, by design. We'd *like* to run Noetic on Jammy.

I notice that [https://packages.ubuntu.com/](https://packages.ubuntu.com/) hosts a bunch of apt packages like [jammy/ros-desktop-full](https://packages.ubuntu.com/jammy/ros-desktop-full). I've installed that package into a container, and it seems to work fine (`roscore` starts, anyway). I'm surprised that I have never seen anyone suggest simply installing the Ubuntu metapackages (which *seems* much simpler).
