    Importing a floorplan image has been added in [pull request 1214](https://bitbucket.org/osrf/gazebo/pull-request/1214/building-editor-import-background-image) to the gazebo default branch and will be released in gazebo 5.0. Until gazebo 5.0 is released, you must [build from source](http://gazebosim.org/tutorials?tut=install_from_source&cat=install) to use this feature.
