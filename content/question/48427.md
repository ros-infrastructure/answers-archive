I'm trying to use the [object_manipulator](http://www.ros.org/wiki/object_manipulator) node on a non-PR2 robot, but it crashes when loading the `PR2ArmKinematicsPlugin`, which is unsurprising because I don't have a PR2 arm. [This changeset](https://code.ros.org/trac/wg-ros-pkg/changeset/53923) suggests that one can exchange the `PR2ArmKinematicsPlugin` for a generic one, but I can't figure out how exactly. There doesn't seem to be a parameter to specify a different IK plugin.

It would be great if I could either

* completely disable using the IK inside `object_manipulator`,
* or even better, configure `object_manipulator` to use the [arm_kinematics_constraint_aware](http://ros.org/wiki/arm_kinematics_constraint_aware) plugin

At the moment, both options don't work because `object_manipulator` crashes on startup. Any hints?
