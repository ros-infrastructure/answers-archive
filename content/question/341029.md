    \nThat is not the correct URL, and it looks like something went wrong during the\
    \ previous steps where you add the repository information (ie: \"Setup your sources.list\"\
    ). The `$(lsb_release/-sc)` part is obviously incorrect.\n\nSimplest way to fix\
    \ this is to re-run the command to add the repository, but this time, make sure\
    \ it is completely correct:\n\n    sudo sh -c 'echo \"deb http://packages.ros.org/ros/ubuntu\
    \ $(lsb_release -sc) main\" > /etc/apt/sources.list.d/ros-latest.list'\n\nMake\
    \ sure you execute this as a single command (ie: no line-breaks). And make sure\
    \ there are no additional slashes added anywhere.\n\nFinally, just to avoid having\
    \ to diagnose this later, make sure `lsb_release -c` actually returns something\
    \ (and does not error out).\n"
