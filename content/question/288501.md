    In ROS 2 this information is provided by the [resource index](https://github.com/ament/ament_cmake/blob/master/ament_cmake_core/doc/resource_index.md) which is populated at compile time (rather then by crawling the filesystem as in ROS 1). This index can be queried in various ways:

    * Command line: `ros2 pkg prefix rclcpp`
    * [Python API](https://github.com/ament/ament_index/blob/d9f7f2783dedc5687a5bdaf3ce5252dce5c073c5/ament_index_python/ament_index_python/resources.py#L22-L34):

      ```
      import ament_index_python
      ament_index_python.get_resource('package', 'rclcpp')
      ```
    * [C++ API](https://github.com/ament/ament_index/blob/d9f7f2783dedc5687a5bdaf3ce5252dce5c073c5/ament_index_cpp/include/ament_index_cpp/get_resource.hpp#L27) (no example code out of my head...)

    In either of the cases the result is the prefix path where the specific package is being installed. Depending on that information you are looking for you can construct derived paths manually. E.g. the manifest is in the location `<prefix>/share/<pkgname>`, the include directory is in `<prefix>/include` etc.

  body_markdown: "The closest equivalent to what `ros::package::getPath()` returns\
    \ in ROS 1 is what we call the package's \"share directory\", which is essentially\
    \ the package's \"install prefix\" plus a standard (FHS based) relative path of\
    \ `share/<package name>`. This is where we put the `package.xml` and where you\
    \ should install architecture independent resources like images, launch files,\
    \ config files, etc...\n\nSo, as an example, if your package is called `foo` and\
    \ you installed to `/home/user/my_ros2_ws/install`, then the package share directory\
    \ would be `/home/user/my_ros2_ws/install/share/foo`. But to get to that path\
    \ you need to know (at runtime) where the package was installed to.\n\nIn ROS\
    \ 2 this information is provided by the resource index:\n\nhttps://github.com/ament/ament_cmake/blob/master/ament_cmake_core/doc/resource_index.md\n\
    \nThis index is populated at compile time (rather then by crawling the filesystem\
    \ at runtime as in ROS 1).\n\nThis index can be queried in various ways, but it\
    \ can be used to get the installation prefix of a package (i.e. something like\
    \ `/opt/ros/ardent/` or `~/my_ros2_ws/install/`), if it is installed on the system.\n\
    Once you know that you can easily add the relative share directory path to the\
    \ install prefix yourself.\nHowever, there are convenience API's in both C++ and\
    \ Python to get the \"share directory\" of a package directly:\n\n### Python\n\
    \nAPI:\n\nhttps://github.com/ament/ament_index/blob/d9f7f2783dedc5687a5bdaf3ce5252dce5c073c5/ament_index_python/ament_index_python/packages.py#L56-L69\n\
    \nExample:\n\n    from ament_index_python.packages import get_package_share_directory\n\
    \    # may raise PackageNotFoundError\n    package_share_directory = get_package_share_directory('my_package_name')\n\
    \n### C++\n\nAPI:\n\nhttps://github.com/ament/ament_index/blob/d9f7f2783dedc5687a5bdaf3ce5252dce5c073c5/ament_index_cpp/include/ament_index_cpp/get_package_share_directory.hpp#L25-L33\n\
    \nExample:\n\n    #include <ament_index_cpp/get_package_share_directory.hpp>\n\
    \    // may throw ament_index_cpp::PackageNotFoundError exception\n    std::string\
    \ package_share_directory = ament_index_cpp::get_package_share_directory(\"my_package_name\"\
    );\n\n### Command-line\n\nWith the command line you can only get the package install\
    \ prefix right now, but it would be simple to add the share directory as well.\n\
    \nDocs (only in `-h` for now):\n\n    % ros2 pkg prefix -h\n    usage: ros2 pkg\
    \ prefix [-h] package_name\n    \n    Output the prefix path of a package\n  \
    \  \n    positional arguments:\n      package_name  The package name\n    \n \
    \   optional arguments:\n      -h, --help    show this help message and exit\n\
    \nExample:\n\n    % ros2 pkg prefix rclcpp\n    /Users/william/ros2_ws/install_debug\n\
    \nI made an issue to add the share directory to the command line tool, help welcome\
    \ :)\n\nhttps://github.com/ros2/ros2cli/issues/89"
