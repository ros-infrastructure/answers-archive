  - body_markdown: |-
      Generally, a catkin workspace has many repositories checked out in the `src` directory, and the `src/CMakeLists.txt` is automatically generated by catkin.
      <br/>
      Each repository may contain one or many packages, each of which contains a `package.xml` and a `CMakeLists.txt` (the package may have more internal `CMakeLists.txt`, but generally they do not).
      <br/>
      The `package.xml` and `CMakeLists.txt` for a package must declare all of the dependencies for that package, and the `CMakeLists.txt` contains cmake rules to build all of the nodes within that package. Generally, dependencies in one package do not affect other packages, unless a package explicitly exports dependencies to the other packages that depend on it.
      <br/>
      There can be a lot going on here, and the best way to get help with build issues in the future is to clearly describe you workspace directory structure and to paste the contents of your CMakeLists.txt in your question.
