  body_markdown: "Transforming a pose from one fixed coordinate frame to another seemed\
    \ like a trivial problem. But I ended up spending lot of time researching the\
    \ solution and came up with the following, I hope it helps others like me. \n\
    There are couple of things that tripped me up.  1) Ensure that the PoseStamped\
    \ that you are passing to transform() is from tf2_geometry_msgs and not geometry_msgs.\
    \  2) Use rospy.Duration() to wait for the listener to start listening.  \n\n\
    \    # Transform a given input pose from one fixed frame to another\n    import\
    \ rospy\n    from geometry_msgs.msg import Pose\n    \n    import tf2_ros\n  \
    \  import tf2_geometry_msgs  # **Do not use geometry_msgs. Use this instead for\
    \ PoseStamped\n    \n    \n    def transform_pose(input_pose, from_frame, to_frame):\n\
    \n        # **Assuming /tf2 topic is being broadcasted\n        tf_buffer = tf2_ros.Buffer()\n\
    \        listener = tf2_ros.TransformListener(tf_buffer)\n    \n        pose_stamped\
    \ = tf2_geometry_msgs.PoseStamped()\n        pose_stamped.pose = input_pose\n\
    \        pose_stamped.header.frame_id = from_frame\n        pose_stamped.header.stamp\
    \ = rospy.Time.now()\n    \n        try:\n            # ** It is important to\
    \ wait for the listener to start listening. Hence the rospy.Duration(1)\n    \
    \        output_pose_stamped = tf_buffer.transform(pose_stamped, to_frame, rospy.Duration(1))\n\
    \            return output_pose_stamped.pose\n    \n        except (tf2_ros.LookupException,\
    \ tf2_ros.ConnectivityException, tf2_ros.ExtrapolationException):\n          \
    \  raise\n    \n    \n    # Test Case\n    rospy.init_node(\"transform_test\"\
    )\n    \n    my_pose = Pose()\n    my_pose.position.x = -0.25\n    my_pose.position.y\
    \ = -0.50\n    my_pose.position.z = +1.50\n    my_pose.orientation.x = 0.634277921154\n\
    \    my_pose.orientation.y = 0.597354098852\n    my_pose.orientation.z = 0.333048372508\n\
    \    my_pose.orientation.w = 0.360469667089\n    \n    transformed_pose = transform_pose(my_pose,\
    \ \"fixture\", \"world\")\n    \n    print(transformed_pose)\n"

I have a Pose message defined in a user preferred fixed reference frame. For planning, I would like to chance the reference coordinate system to "world" (which again is a fixed reference frame). 
Since these reference frames are part of robot definition in URDF - is there a simple way to transform pose from one reference frame to another without having to go through broadcasting and listening tf transformations? 
Even if I have to use the tf, does it require one to calculate the transforms and broadcast it? I tried using tf2_ros.Buffer.transform() method - but this does not seem to work unless, there is an explicit transform being broadcasted between the two frames?  Thank you.
