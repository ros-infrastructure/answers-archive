  body_markdown: "You have some misunderstandings.\n\nAt startup AMCL loads an initial\
    \ pose that defaults to (0, 0, 0) from the param server, as detailed [here](http://wiki.ros.org/amcl#Parameters).\
    \ That is when AMCL initializes the particle filter.\n\nThe odometry is not used\
    \ as you have stated. \nThe initialpose is not a **nav_msgs/Odometry**, but a\
    \ **geometry_msgs/PoseWithCovarianceStamped**. The AMCL will subscribes to that\
    \ topic and reinitialize the particle filter if a pose is published on that topic.\n\
    \nYou are wrong assuming odometry is not required. AMCL is very dependent on it,\
    \ but it uses the odometry from your TF tree, not from a topic, as shown [here](http://wiki.ros.org/amcl#Transforms).\n\
    \nThe source code can be found [here](https://github.com/ros-planning/navigation).\n"
