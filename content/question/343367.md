    I faced a similar issue recently when running `apt upgrade` on a RaspberryPi 2 running Raspbian Buster.
    What worked for me was to remove the conflicting packages by hand and run `apt --fix-broken` after

        sudo apt remove python-rospkg
        sudo apt remove python-catkin-pkg
        sudo apt --fix-broken install

    Edit:
    I didnt face the SIP issues in my setup.

        rosdep install --from-paths src --ignore-src --rosdistro melodic -y

    installed all the dependencies successfully including these sip packages: `python-sip` `python-sip-dev` `sip-dev`
