  body_markdown: "This is fully documented on the wiki. See [wiki/ROS/EnvironmentVariables\
    \ - ROS_LANG_DISABLE](http://wiki.ros.org/ROS/EnvironmentVariables#ROS_LANG_DISABLE):\n\
    \n> A colon-separated list of package names for message generators / client libraries\
    \ that should be disabled. Message-generation will not happen for languages in\
    \ this list.\n\n> For packages build with **catkin** you need to list the names\
    \ of the message generators which should be ignored, e.g.:\n\n>     export ROS_LANG_DISABLE=genlisp\n\
    \nIt then goes on to say:\n\n> Note that before disabling a language, you should\
    \ first be very sure that none of the code you're using requires that language's\
    \ bindings. \n"
