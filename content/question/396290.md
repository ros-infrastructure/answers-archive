  body_markdown: "In ROS1 you cannot source multiple workspaces at the same time (in\
    \ the same environment or same terminal). You can only source one workspace at\
    \ a time along with the `setup.bash` of ROS. \n\nSo what I usually do is create\
    \ an alias in my `.bashrc` file with the name of every workspace commanding to\
    \ source that workspace when that specific alias is run. \n\nFor e.g. I have a\
    \ workspaces `abc_ws` and `xys_ws`. I will create aliases `abc_ws` and `xyz_ws`\
    \ in my `.bashrc` file as follows : \n\n`alias abc_ws='source <path_to_abc_ws>/devel/setup.bash'`\n\
    \n`alias xyz_ws='source <path_to_xyz_ws>/devel/setup.bash'`\n\nAnd call them whenever\
    \ I need the source the workspaces (one in a single environment or terminal)\n\
    \nNote : You can have more than one terminals open at the same time with different\
    \ ROS workspaces sourced in them."
