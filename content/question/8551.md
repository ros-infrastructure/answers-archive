    If you are looking for a native bridge from gazebo transport system to the ROS transport system, I don't think that it currently exist.

    For integration between a Gazebo plugin and the ROS transport layer, you can probably look at [DRCSim gazebo\_ros\_plugins](https://bitbucket.org/osrf/drcsim/src/d071b62409e72247739ebf6ddef40d363ed14f16/drcsim_gazebo_ros_plugins/?at=default) which interacts with ROS. For example, the [IRobotHandPlugin](https://bitbucket.org/osrf/drcsim/src/d071b62409e72247739ebf6ddef40d363ed14f16/drcsim_gazebo_ros_plugins/include/drcsim_gazebo_ros_plugins/IRobotHandPlugin.h?at=default).
