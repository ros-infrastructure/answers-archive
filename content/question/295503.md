    You can manage nodes from a Python program using the [roslaunch API](http://wiki.ros.org/roslaunch/API%20Usage). Keep in mind that this API is listed as "very unstable", although it has been in that state since forever and to be honest I don't think it will change that much from now on.

    The [`rosmon` tool](http://wiki.ros.org/rosmon) might also interest you. It replaces `roslaunch`, and as well as several other useful features, it provides a ROS service that you can use to start and stop nodes.
