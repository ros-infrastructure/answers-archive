  body_markdown: "The issue was the import statement.\n\nMy .cfg file was named `Pcl.cfg`\n\
    \nAnd had the following in it -\n`exit(gen.generate(PACKAGE, \"test_package\"\
    , \"Pcl\"))`\n\nI thought, as per the tutorials, I should import it based on the\
    \ 3rd argument above.\n\nSo my import statement was\n`from Pcl.cfg import PclConfig`\n\
    \nWhich was wrong. It was instead supposed to be -\n`from test_package.cfg import\
    \ PclConfig`\n\nMy fault for not thoroughly going through the tutorial on this\
    \ one. "
