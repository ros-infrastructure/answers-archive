  body_markdown: "LSE communication is currently not available as a Debian binary\
    \ release.\n\nYou will have to install it manually via version control.\n\nYou\
    \ can do this one of two ways, a rosinstall file, like this:\n\n     - svn:\n\
    \         uri: http://isr-uc-ros-pkg.googlecode.com/svn/trunk/unstable/lse_sensor_network/\n\
    \         local-name: lse-sensor-network\n\nAnd then simply do a rosinstall\n\n\
    \    rosinstall <TARGET DIRECTORY> <ROS DIRECTORY> <ROSINSTALL FILE>\n    rosinstall\
    \ ~/devel/ros /opt/ros/electric ~/Downloads/automow.rosinstall\n\nAnd then source\
    \ the generated file, for bash, this would be:\n    \n    source ~/devel/ros/setup.bash\n\
    \nYou can also add this to your `~/.bashrc` file.\n\nYour other option is to actually\
    \ check it out in your ROS directory:\n\n    cd /opt/ros/electric/stacks/\n  \
    \  svn co http://isr-uc-ros-pkg.googlecode.com/svn/trunk/unstable isr-uc-ros-pkg\n\
    \    rosmake -i lse_communication\n\nYou may have to perform some of these actions\
    \ with sudo, and the -i flag to rosmake will mark the packages as built, so you\
    \ won't have to rebuild them again (making it easier to work with user priviledges).\n\
    \    \n\n"
