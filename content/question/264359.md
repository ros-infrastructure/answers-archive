  body_markdown: "Minutes after posting this question I managed to resolve it:\n\n\
    First of all you have to remove the namespace tag from the .xacro/urdf file in\
    \ order for the robots to get a namespace you specify, like so:\n\n     <gazebo>\n\
    \        <plugin name=\"gazebo_ros_control\" filename=\"libgazebo_ros_control.so\"\
    >\n        </plugin>\n      </gazebo>\n\nSecond, you have to specify the namespace\
    \ almost everywhere even if you have the group tag, and I'll give an example for\
    \ one robot:\n\n    <group ns=\"/robot1\">\n      <param name=\"tf_prefix\" value=\"\
    atlas1\" />\n       <rosparam file=\"$(find YOUR_PACKAGE)/config/control.yaml\"\
    \ command=\"load\" ns=\"/robot1\" /> \n       <param name=\"/robot1/robot_description\"\
    \ command=\"$(find xacro)/xacro --inorder $(arg model)\"/>\n    \t  <node name=\"\
    urdf_spawner_1\" pkg=\"gazebo_ros\" type=\"spawn_model\"\n    \t\targs=\"-z 1.0\
    \ -unpause -urdf -model robot1 -param robot_description \" respawn=\"false\" output=\"\
    screen\">\n    \t  </node>\n    \n    \t  <node pkg=\"robot_state_publisher\"\
    \ type=\"robot_state_publisher\"  name=\"robot_state_publisher_1\">\n    \t  \
    \  <param name=\"publish_frequency\" type=\"double\" value=\"30.0\" />\n    \t\
    \  </node>\n    \n    \t  <node name=\"robot1_controller_spawner\" pkg=\"controller_manager\"\
    \ type=\"spawner\" \n    \t    args=\"--namespace=/robot1\n    \t    joint_state_controller\n\
    \            tri_wheel_controller\n    \t    arm_controller\n    \t    --shutdown-timeout\
    \ 3\">\n    \t  </node>\n    \n    \t  <node name=\"rqt_robot_steering1\" pkg=\"\
    rqt_robot_steering\" type=\"rqt_robot_steering\">\n    \t    <param name=\"default_topic\"\
    \ value=\"/robot1/tri_wheel_controller/cmd_vel\"/>\n    \t  </node>\n      </group>\n\
    \nAnd so on for another robot.\nKeep in mind that I redefined the **robot_description**\
    \ each time in order for the controller to find it in the same namespace. It didn't\
    \ work for me to define it outside and the use it in the group like **/robot_description**\n\
    \n**tf_prefix** is used in order to see all the robots in rviz. I am not sure\
    \ how does it work without it, or how to use something else as tf_prefix is deprecated.\
    \ For now it does not work to see it in rviz so I figured it does not calculate\
    \ the tf for the link. I don't know how to solve this"

I have a problem when trying to start controllers for multiple robots that they cannot find the controller_manager

    [WARN] [1498038782.062813, 84.949000]: Controller Spawner couldn't find the expected controller_manager ROS interface.

I am using the plugin in the .xacro file like so:

    <gazebo>
        <plugin name="gazebo_ros_control" filename="libgazebo_ros_control.so">
          <robotNamespace>/</robotNamespace>
        </plugin>
    </gazebo>

and then launching each robot in a group with a different namespace.

What am I doing wrong?
