  body_markdown: "As @joq says, this is a common problem.\n\nHowever, it's such a\
    \ common problem that we've (sort of) fixed it. Install the `ros-fuerte-perception-pcl-fuerte-unstable`\
    \ package. This adds `pcl16` and `pcl16_ros` packages that track PCL 1.6 (not\
    \ quite to PCL 1.6.0 yet; I haven't had the chance to bump the version lately;\
    \ soon!). \n\nThe namespacing, filenames, and everything else have been changed\
    \ from `pcl` to `pcl16`, so you'll need to make some minor changes to your code.\
    \ For example, `pcl::PointCloud<pcl::PointXYZRGB>` becomes `pcl16::PointCloud<pcl16::PointXYZRGB>`.\
    \ Doing it this way lets the two PCL versions coexist nicely.\n"
