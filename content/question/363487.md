  body_markdown: "I think an incorrect static transform somewhere is causing this.\
    \ Make sure that your laser_link to base_link tf is correct.\n\nAlso does this\
    \ continue happening when you are moving? AMCL does not update when stationary\
    \ (unless you explicitly call [/request_nomotion_update](http://wiki.ros.org/amcl))\
    \ and therefore, if there is motion after the last update before stopping sometimes\
    \ the laser scan will be offset from the static map. \n\nBut in all cases the\
    \ offset is the same, then I think a static transform might be off."
