  body_markdown: "I know this question is a couple years old but it looks it's frequently\
    \ viewed so decided to answer it.\n\nThings have improved a lot when running ROS\
    \ on Windows in the last few years. Yes there are still a few limitations and\
    \ compatibility issues to deal with but no show stoppers in my opinion. \n\nIt\
    \ may be confusing for someone new to ROS1 or ROS2 on Windows what direction to\
    \ take as there are more than one:\nAs of December 2021, this is a response on\
    \ direction from ROS on Windows:\n\n    ros.org is the source of truth for ROS\
    \ development. the aka.ms/ros documentation was designed to bootstrap Windows\
    \ development for ROS1 and help bootstrap ROS2. It also documents our first party\
    \ ROS nodes and development tooling. It does need a refresh.\n    \n    RoboStack,\
    \ Open Robotics and Microsoft have collaborated on making RoboStack a first class\
    \ citizen for ROS2; for all platforms. It needs to be represented on the ros.org\
    \ website; there is work happening for that.\n    \n    Windows 11 + WSL2 is a\
    \ fantastic way of developing simulation if your ultimate target is a Linux based\
    \ Robot. However, WSL cannot talk directly to hardware (even with the new USB\
    \ bridge), so it is limited to simulated robots.\nSource: https://github.com/ms-iot/ROSOnWindows/issues/332\
    \ by @ooeygui\n\n\nFor information on how to use WSL2 in Windows 10 and 11, recommend\
    \ to follow this tutorial where ROS1 or ROS 2 can be installed: https://www.windowscentral.com/how-install-wsl2-windows-10\n\
    \nFor installation of ROS on Windows with Visual Studio, follow this tutorial:\
    \ http://wiki.ros.org/Installation/Windows\n\nFor using `RoboStack` for ROS 1\
    \ and ROS 2, suggest to visit: https://robostack.github.io/\n\nAlso it's possible\
    \ to use great tools such as `VSCode` using ROS extension and is not limited to\
    \ Windows: https://marketplace.visualstudio.com/items?itemName=JaehyunShim.vscode-ros\
    \ accompanied by many great tutorials: https://github.com/ms-iot/vscode-ros\n\n\
    In summary, if you want to develop ROS in Windows, thing have improved immensely\
    \ in the last few years. For community support, you can visit: https://github.com/ms-iot/ROSOnWindows\
    \ as well. \n\nI am not sponsored or work for Microsoft, just a big fan on working\
    \ on the Windows operating system as I used Visual Studio for many years.\n\n\
    And perhaps I am not answering the original question but hope this helps someone\
    \ navigate using ROS on Windows."
