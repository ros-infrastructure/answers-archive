  body_markdown: |-
    You need a valid tf tree that also contains the frame `/openni_rgb_optical_frame`. This is normally done by creating a urdf file of your robot (have a look at [these tutorials](http://ros.org/wiki/urdf/Tutorials)) and running the [robot_state_publisher](http://ros.org/wiki/robot_state_publisher). The state publisher will read your urdf file and publish the links in it as tf frames. Then rviz will visualize the point cloud in the right frame.
