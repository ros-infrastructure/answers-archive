In [RMF](https://github.com/open-rmf), when a launch file is launched with Rviz, there is only one topic (/floorplan) for publishing the maps. If there are multiple floors in *building.yaml* file (say L1 and L2), all of them are embedded in one topic. So, even if multiple RViz windows are open, one can only run either L1 or L2 at a time, not both. 

Inside common.launch.xml

    <launch>
        ..
        .
        .
        .
      <arg name="viz_config_file" default="$(find-pkg-share rmf_demos)/include/robo/robo_L1.rviz"/>
      <arg name="viz_config_file_2" default="$(find-pkg-share rmf_demos)/include/robo/robo_L2.rviz"/>
      <arg name="initial_map" default="L1"/>
      <arg name="second_map" default="L2"/>
    .
    .
    .
    . 

    <!-- Visualizer -->
     <group>
        <include file="$(find-pkg-share rmf_visualization)/visualization.launch.xml">
          <arg name="use_sim_time" value="$(var use_sim_time)"/>
          <arg name="map_name" value="$(var initial_map)"/>
          <arg name="viz_config_file" value ="$(var viz_config_file)"/>
          <arg name="headless" value="$(var headless)"/>
        </include>
     </group>

     <group>
          <include file="$(find-pkg-share rmf_visualization)/visualization.launch.xml">
            <arg name="use_sim_time" value="$(var use_sim_time)"/>
            <arg name="map_name" value="$(var second_map)"/>
            <arg name="viz_config_file" value ="$(var viz_config_file_2)"/>
            <arg name="headless" value="$(var headless)"/>
          </include>
      </group>
    .
    .
    </launch>
When I launched with these changes, it launches 2 Rviz windows and either with L1 map or L2 map is being displayed in both the windows. I could not run both L1 and L2 simultaneously.

How can I simultaneously visualize multiple maps(floors) in Rviz?
