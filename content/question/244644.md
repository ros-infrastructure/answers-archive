    The problem is that Conda is now in your path before system python (for which you probably have installed ros libraries).
    In their [troubleshooting section](http://conda.pydata.org/docs/troubleshooting.html) check the section *Issue: Programs fail due to invoking conda Python and not system Python* : they suggest few solutions, the simplest of which is to remove conda from the path, and use conda later on with the full path names (such as *~/miniconda3/bin/conda*)
