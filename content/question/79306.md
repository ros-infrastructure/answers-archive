  body_markdown: "The AR.Drone Autonomy package publishes the video captured by the\
    \ cameras in the topic `/ardrone/image_raw` topic. I have prepared a simple code\
    \ that works with opencv so that you get the idea:\n\n    #include <ros/ros.h>\n\
    \    #include <image_transport/image_transport.h>\n    #include <sensor_msgs/image_encodings.h>\n\
    \    #include <cv_bridge/cv_bridge.h>\n    #include <cv_bridge/CvBridge.h>\n \
    \   #include <opencv2/highgui/highgui.hpp>\n        \n    using namespace std;\n\
    \    using namespace cv;\n       \n    static const char WINDOW[]=\"RGB Image\"\
    ;\n    static const char WINDOW2[]=\"Gray Image\";\n    \n    void process(const\
    \ sensor_msgs::ImageConstPtr& cam_image){\n       sensor_msgs::CvBridge bridge;\
    \ \n       Mat img_rgb = bridge.imgMsgToCv(cam_image,\"bgr8\"); \n       Mat img_gray;\n\
    \    \n       cvtColor(img_rgb,img_gray,CV_RGB2GRAY);\n    \n       imshow(WINDOW,img_rgb);\n\
    \       imshow(WINDOW2,img_gray);\n       cvWaitKey(1);\n    }\n    \n    int\
    \ main(int argc, char **argv){\n      ros::init(argc,argv,\"Display_Images\");\n\
    \      ros::NodeHandle n;\n      image_transport::ImageTransport it(n);\n    \
    \  image_transport::Subscriber image_sub = it.subscribe(\"/ardrone/image_raw\"\
    ,1,process);\n     \n      cv::namedWindow(WINDOW);\n      cv::namedWindow(WINDOW2);\n\
    \        \n      cv::destroyWindow(WINDOW);\n      cv::destroyWindow(WINDOW2);\n\
    \    \n      ros::spin();\n      return 0;\n    }\n\nIf  you are interesed in\
    \ switching between the front and bottom cameras you can use the command:\n\n\
    \    rosservice call /ardrone/togglecam\n\nYou can also subscribe to `/ardrone/bottom/image_raw`\
    \ if you want to work only with the bottom camera.\n\nI hope this helps."
