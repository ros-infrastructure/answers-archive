  body_markdown: "The error that you are getting says that you are trying to perform\
    \ a transform to/from a frame that does not exist. This is most likely because\
    \ your laser topic contains a frame_id named \"/laser\", but your static transform\
    \ publisher is publishing a transform from \"base_laser\" instead. You need to\
    \ make sure that the frame_id on this incoming message is correct. \n\nThe string\
    \ \"base_link\" in `transformLaserScanToPointCloud` is the frame_id that you want\
    \ to transform the cloud into. This is simply declared by you based on what you\
    \ want to do. There is no default value. "
