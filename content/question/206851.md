    \ files you want to merge. If there are all in sequence, you will wacht them all\

    \ do the next steps:\n\n    rostopic echo \"topic_name\" -b \"bag_name\" -p >\
    \ \"file.csv\"\n\nThis will create a csv, then import the data in matlab.\n\n\
    If you want to know only the time lapse and not the final value of time\n\nVarName1\
    \ (wich is the current time sec+nsec)\n\n    time = VarName1 / 10\u2079\n    time\
    \ = time - time[0] --> this is the first element in the time array in seconds.\n\
    \nThen you have your time variable in lapse time and not in total amount format."
