  body_markdown: "In your common costmap params file, you've only listed one sensor:\n\
    \n    observation_sources: laser_scan_sensor\n    laser_scan_sensor: {sensor_frame:\
    \ camera_link, data_type: LaserScan, topic: scan, marking: true, clearing: true}\n\
    \nIf you're publishing depthimage as laser scan on /scan topic, then only the\
    \ kinect will be taken into account.\n\nBasically you need to write down both\
    \ point_cloud sensor (kinect) and laser_scan sensor (lidar) in the file. Something\
    \ like this:\n\n    observation_sources: laser_scan_sensor point_cloud_sensor\n\
    \    \n    laser_scan_sensor: {sensor_frame: frame_name, data_type: LaserScan,\
    \ topic: topic_name, marking: true, clearing: true}\n    \n    point_cloud_sensor:\
    \ {sensor_frame: frame_name, data_type: PointCloud, topic: topic_name, marking:\
    \ true, clearing: true}"
