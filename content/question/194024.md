  body_markdown: "Here would be the [place to look.](http://gazebosim.org/tutorials?tut=ros_gzplugins&ver=1.9%2B&cat=connect_ros)\
    \ It is part of the gazebo_ros_pkgs which you can either apt-get the debian, or\
    \ download the source for github and compile it yourself. Many gazebo plugin's\
    \ are listed here, and what you are look for (if your drivetrain system is what\
    \ i think it is) is the SkidSteerDrive plugin which you will find towards the\
    \ bottom of the page. \n\n    <gazebo>\n       <plugin name=\"skid_steer_drive_controller\"\
    \ filename=\"libgazebo_ros_skid_steer_drive.so\">\n       <updateRate>100.0</updateRate>\n\
    \       <robotNamespace>/</robotNamespace>\n       <leftFrontJoint>front_left_wheel_joint</leftFrontJoint>\n\
    \       <rightFrontJoint>front_right_wheel_joint</rightFrontJoint>\n       <leftRearJoint>back_left_wheel_joint</leftRearJoint>\n\
    \       <rightRearJoint>back_right_wheel_joint</rightRearJoint>\n       <wheelSeparation>0.4</wheelSeparation>\n\
    \       <wheelDiameter>0.215</wheelDiameter>\n       <robotBaseFrame>base_link</robotBaseFrame>\n\
    \       <torque>20</torque>\n       <topicName>cmd_vel</topicName>\n       <broadcastTF>false</broadcastTF>\n\
    \     </plugin>\n    </gazebo>\n\nJust keep in mind, this format is for a URDF\
    \ formatted file. If you are using SDF, You should just take out the gazebo tags."
