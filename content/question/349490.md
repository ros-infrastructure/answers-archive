  body_markdown: "The dependencies of one package are all the other packages needed\
    \ to build, execute or test the package of interest. \n\nIf you are writing and\
    \ compiling a package, you would need to install the packages listed in the dependencies\
    \ or clone and compile them.\n\nIf you are talking about a released packaged (debian\
    \ file) the dependencies are the other debian files that will be automatically\
    \ installed so you can properly run the package of interest. "
