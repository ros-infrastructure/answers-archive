  body_markdown: "you must have both computers on the same local network, then **on\
    \ each terminal** you have to do: \n\n     1. export ROS_IP=IP_OF_THIS_MACHINE\
    \  (e.g. 192.168.1.1)\n     2. export ROS_MASTER_URI=http://IP_OF_THE_MASTER_MACHINE:11311\
    \ (e.g. http://192.168.1.0:11311)\n\nThe master machine is the machine that launches\
    \ the `roscore` command (or in case of launch files, the first machine that launch\
    \ a file).\n\nYou should now be able to see the topic published by Gazebo on the\
    \ other computer.\n\nSome more informations [here](http://wiki.ros.org/ROS/Tutorials/MultipleMachines)."
