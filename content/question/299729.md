  body_markdown: |-
    Colcon always ignores folders containing `COLCON_IGNORE`. If `colcon-ros` is installed then it will also ignore folders [containing `CATKIN_IGNORE` or `AMENT_IGNORE`](https://github.com/colcon/colcon-ros/blob/d938fcbe386f7efc9f0731b6ff20c885d72b476a/colcon_ros/package_identification/ros.py#L50-L53).

    As far as I know `ament_tools` doesn't support `COLCON_IGNORE`, so using the `AMENT_IGNORE` marker file allows building with either `ament` or `colcon`.
