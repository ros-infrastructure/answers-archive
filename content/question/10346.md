    \n---\n\nEdit (by @jayess ):\n\nJust so you don't have to go clicking around for\
    \ the answer (from @bhaskara's link):\n\n> A subscriber can get access to a\n\
    > \"connection header\", which includes\n> debugging information such as who sent\n\
    > the message, as well information like\n> whether or not a message was latched.\n\
    > This data is stored as the\n> `_connection_header` field of a received message.\n\
    > \n> e.g.\n\n>     print m._connection_header\n    {'callerid': '/talker_38321_1284999593611',\n\
    \     'latching': '0',\n     'md5sum': '992ce8a1687cec8c8bd883ec73ca41d1',\n \
    \    'message_definition': 'string data\\n\\n',\n     'topic': '/chatter',\n \
    \    'type': 'std_msgs/String'}\n\n> We do not recommend using `callerid`\n> information\
    \ beyond debugging purposes,\n> as it can lead to brittle code in an\n> anonymous\
    \ publish/subscribe\n> architecture."
