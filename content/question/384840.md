  body_markdown: "Webots R2021b comes with a `ros_control` integration, that allows\
    \ you to utilize `JointStateController` and `JointTrajectoryController` controllers.\
    \ Those two controllers are enough to get MoveIt running. There is no need to\
    \ code anything, just use the `--use-ros-control` flag:  \nhttps://cyberbotics.com/doc/guide/using-ros#using-the-standard-ros-controller\n\
    \nThere is a `tiago.launch` simulation that you can use as an example:  \nhttps://github.com/cyberbotics/webots_ros/blob/master/launch/tiago.launch\n\
    \nP.S. If possible, I recommend you to switch to ROS 2 as Cyberbotics invests\
    \ more efforts in the [Webots ROS 2 interface](https://github.com/cyberbotics/webots_ros2)."
