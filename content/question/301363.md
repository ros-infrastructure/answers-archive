  body_markdown: "As a simple recap from all the comments (@Karsten, @gvdhoorn). In\
    \ order to communicate between two machines using ROS2 DDS:\n\n - Update the configuration\
    \ to allow the communication in your Firewall (or disable it) \n - Look at the\
    \ different networking interfaces (`ifconfig` on ubuntu, `Ipconfig /all` on windows)\n\
    \ - Make sure to have the two machines under the same subnetwork (same network\
    \ mask,.. )\n - Make sure that the DDS libraries are using the correct interface\n\
    \ - Make sure that the DDS libraries are not using shared memory communication\
    \ (versus multicast)\n - Enable your network switch to use multicast\n - Try pinging\
    \ the two machines between each others\n - Export the same ROS_DOMAIN_ID (https://discourse.ros.org/t/how-to-run-example-talker-listener-on-2-machines-with-different-ipaddr/2106)"
