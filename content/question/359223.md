    In short, there are no 32 bit packages for Debian Buster. Building from source is your only option. If you're looking for 32bit arm packages, there are `arm32` packages available for Ubuntu Focal.

    [REP 3 ](https://www.ros.org/reps/rep-0003.html#noetic-ninjemys-may-2020-may-2025) is the reference for what platforms and architectures are supported by ROS 1 release. It's not very clear here. What happened is it was decided that since Debian Buster is only a recommended support platform, building `arm32` packages for Debian Buster is not currently worthwhile. I've opened a PR to make what platforms and architectures have packages more clear: https://github.com/ros-infrastructure/rep/pull/286
