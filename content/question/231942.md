  body_markdown: "The kinematic equations can be found for example by searching for\
    \ differential drive robots.\nE.g. one of the first results: [diff-drive kinematics](https://chess.eecs.berkeley.edu/eecs149/documentation/differentialDrive.pdf).\n\
    \nYour velocities at the left and right wheel are denoted as v_l and v_r respectively.\n\
    \n**Velocities in the robot frame** (which are located in the center of rotation,\
    \ e.g. `base_link` frame)\n\n    v_rx = ( v_right + v_left ) /2;\n    v_ry = 0;\
    \ // we have a non-holonomic constraint (for a holonomic robot, this is non-zero)\n\
    \    omega_r = ( v_right - v_left ) / d; // d denotes the distance between both\
    \ wheels (track)\n\nSubscript r indicates the robot frame.\n\nNote, after converting\
    \ your encoder values to rotational velocities at each wheel (`omega_left`, `omega_right`),\n\
    you can transform them to the translational velocity at each wheel using the radius\
    \ of the wheel: `v_left = omega_left * radius`.\n\n**Velocities in the odom frame**\n\
    \nThe velocities expressed in the robot base frame can be transformed into another\
    \ coordinate system (e.g. odom).\nFor transforming velocities (in this simple\
    \ setting with scalar values), we only need to rotate them according\nto the current\
    \ robot orientation. Here we apply the [2D rotation matrix](https://en.wikipedia.org/wiki/Rotation_matrix)\
    \ (we are operating in the x-y plane).\nWe assume that we already know the current\
    \ orientation (theta).\n\n    v_wx = v_rx * cos(theta) - v_ry * sin(theta);\n\
    \    v_wy = v_rx * sin(theta) + v_ry * cos(theta);\n    thetadot = omega_r;\n\n\
    For your robot kinematics it is `v_ry=0`. Subscript w indicates the world/odom\
    \ frame.\n\n**Computing the current robot pose**\n\nIn order to obtain the current\
    \ robot position, numerical integration can be applied.\nThe velocities are integrated\
    \ in order to achieve the current pose (x, y, theta).\nWe define the pose in the\
    \ `odom` frame, and start with `x=y=theta=0` (origin of the `odom` frame).\n\n\
    Applying [Explicit/Forward Euler Integration](https://en.wikipedia.org/wiki/Euler_method)\n\
    leads to\n\n    x_kp1 = x_k + v_wx * dt; // kp1 := k+1\n    y_kp1 = y_k + v_wy\
    \ * dt; // by the way, the last term is delta_y from the equations in your comment\n\
    \    theta_kp1 = theta_k + thetadot * dt;\n\nIn your implementation, you can simply\
    \ share the same variables for `x_kp1` and `x_k` etc.\n`dt` denotes the step width\
    \ and should be choosen according to the time elapsed since the last integration\
    \ step (here you might see, that your *rate* significantly influences your integration\
    \ accuracy. But the integration rate is limited by the rate of your sensors (wheel\
    \ encoders).\n\n**Composing your odometry message**\n\nThe [odometry message](http://docs.ros.org/jade/api/nav_msgs/html/msg/Odometry.html)\
    \ contains the pose and the twist information.\nNow you should have everything\
    \ to compute the values.\nThe pose represents your current robot pose w.r.t the\
    \ odom frame (x_k, y_k, theta_k). You must convert theta_k to a Quaternion, e.g.\
    \ by calling the related functions of the tf package.\nThe twist part usually\
    \ contains the velocities expressed in your robot frame (there is an extra parameter\
    \ where you can insert the frame name (`child_frame_id`), but not all drivers\
    \ are filling it with a value.\nHere you just need the linear velocity (`linear.x\
    \ = v_rx` and the angular velocity (around the z-axis, `angular.z = omega_r`).\
    \ \nAll other values are zero.\n\nYou can find much information on those things!\n\
    \n - kinematics: just search with google for *differential drive kinematics*.\
    \ Or have a look in one of the great robotic books.\n - ROS Implementation: Check\
    \ code of other ros drivers/simulators for differential drive robots (e.g. p2os,\
    \ rosaria, stage_ros, ...). Or the important things mentioned here are also part\
    \ of the [Odom-Tutorial](http://wiki.ros.org/navigation/Tutorials/RobotSetup/Odom)\
    \ you already refered to.\n\nHope that helps.\n\n**Update:** I added many details\
    \ to the answer after receiving the first comment."
