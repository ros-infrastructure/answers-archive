    It looks like you've somehow set the "[use_sim_time](http://wiki.ros.org/Clock#Using_Simulation_Time_from_the_.2BAC8-clock_Topic)" parameter to true, but you don't have a clock source (ie: [rosbag play --clock](http://www.ros.org/wiki/rosbag/Commandline#play) or some other source, like Gazebo).

    Since you're using tf, [WallTime](http://www.ros.org/wiki/roscpp/Overview/Time#Wall_Time) isn't an option.

    You can check the status of the use_sim_time parameter by using [rosparam](http://www.ros.org/wiki/rosparam#rosparam_command-line_tool).

        rosparam get use_sim_time

    And if it is set somehow, you can reverse it by running:

        rosparam set use_sim_time false
