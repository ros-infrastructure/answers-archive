  body_markdown: "If you would like to echo (i.e. see the data in the terminal), you\
    \ want to use:\n   \n    $rostopic echo laser_scan_topic \nWhere you replace laser_scan_topic\
    \ with the name of the topic that your laser is publishing to.\nTo record, you\
    \ want to use the rosbag tool, as described in this tutorial: http://wiki.ros.org/rosbag/Tutorials/Recording%20and%20playing%20back%20data\n\
    \n     $rosbag record laser_scan_topic\n     $rosbag play <bagfile-name>\n\nThe\
    \ tutorials also have alot of other, helpful tools to understanding topics, nodes,\
    \ etc.\n\nMost lasers publish in polar coordinates, but if you want to sense objects\
    \ you will need to install and run another package that uses the laser scan info\
    \ (or write your own :))."
