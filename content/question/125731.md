Hi, 
I don't if I should post this here, but it could save someone a lot of time.
I've been struggling with the key_teleop not moving the robot in Fuerte
and looking at the code in Hydro I noticed a topic changed name somewhere
    <remap from="turtlebot_teleop_keyboard/cmd_vel" to="cmd_vel_mux/input/teleop"/>

So I added that line to the launch file and now it works
I also noticed that the source in turtlebot_apps doesn't match the binaries,
in cpp the arrows are used, in bin u,i,o, etc
