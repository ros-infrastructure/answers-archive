    I do not understand this completely, but as noted in [this](https://stackoverflow.com/questions/21936597/blocking-and-non-blocking-subprocess-calls) answer, `call` is likely spawning a subprocess that will in turn spawn another subprocess to execute your script. Now if the  subscriber gets a new msg before the processing of the other script is complete, it is likely to mess things up!

    I'd suggest you ditch the additional script and combine it into one node.

Inside of **mainscript.py**, I have this line <code>call('path/to/slavescript.py')</code> that excecutes **slavescript.py**.

Although running my node using <code>rosrun $(package name) mainscript.py</code> doesn't throw an error, I noticed some operations inside **slavescript.py** are not being excecuted, for example <code>cv2.imwrite()</code> or creating/writing to files using <code>write()</code>. 

The proper way is probably to make **slavescript.py** into a node, but I'm just wondering why this operation wouldn't work? (Here is a code snippet with the major components)
