    You're missing the command that tells CMake where to look for C++ header files when compiling `tester.cpp`: either `target_include_directories` or `include_directories`. See section 7.3 in the [catkin docs](http://wiki.ros.org/catkin/CMakeLists.txt). It recommends using `include_directories`, but `target_include_directories` is the modern preferred style. CMake reference [here](https://cmake.org/cmake/help/latest/command/target_include_directories.html).
