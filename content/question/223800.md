  body_markdown: "> It only starts if I Ctrl-C the hanging roscore, then it suddenly\
    \ starts.\n\nIt normally takes care of this by itself, but sometimes ROS needs\
    \ a little help: run a `rosclean check` and see if it also hangs (or takes a very\
    \ long time to complete). That is the program that is run first by `roscore`:\
    \ it keeps tabs on the nr of log files (and their total size). On a regular HDD\
    \ (so not an SSD), that can take quite some time.\n\nIf `rosclean check` also\
    \ 'hangs', you can either run `rosclean purge`, or manually `rm ~/.ros/log/*.log`.\
    \ In both cases make sure you have nothing there you'd like to keep.\n "
