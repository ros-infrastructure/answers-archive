  body_markdown: "I am pretty new to ros and even to linux. I faced the same error.\
    \ What I did is the following:\n1. go to the location provided in the error '/opt/ros/indigo/share/rgbd_launch/launch/includes/'\
    \ and using nano or any other editor open the file 'processing.launch.xml'.\n\
    2. There will be several sections in there. Under the section 'Remapping Arguments',\
    \ add this line \n\n<arg name=\"depth_registered_filtered\" default=\"depth_registered\"\
    \ />\n\n(just like the several others already there.)\n\n3. Then try to run 'roslaunch\
    \ openni_launch openni.launch' again and see if this works.\n\nIt solved the error\
    \ for me, but I do not know why this works.\n"
