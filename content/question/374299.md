  body_markdown: "If you upgrade to [navigation2](https://github.com/ros-planning/navigation2),\
    \ things could get more convenient for you. There is a dedicated package named\
    \ `nav2_waypoint_follower`, which employs an action server that accepts way points\
    \ and follow them consecutively. \nThe action definition goes as; \n\n    #goal\
    \ definition\n    geometry_msgs/PoseStamped[] poses\n    ---\n    #result definition\n\
    \    int32[] missed_waypoints\n    ---\n    #feedback\n    uint32 current_waypoint\n\
    \nas you can see, it is possible to feed this server with an vector of poses(aka\
    \ your waypoints). \nLastly see an example [here](https://github.com/ros-planning/navigation2/blob/3bf1f7a93d740c54b4c7ef7fc6dd914175bf46be/nav2_rviz_plugins/src/nav2_panel.cpp#L302)\
    \ on how you can create a client to this action"
