  body_markdown: "By default, gmapping triggers the scan process after the robot has\
    \ moved 1.0m away or rotated 0.5 radians since the last pose where the scan process\
    \ was triggered.\n\nMake sure that you move the robot far enough or set the [parameter](http://wiki.ros.org/gmapping#Parameters)\
    \ ~/temporalUpdate to something greater than 0:\n\n    ~temporalUpdate (float,\
    \ default: -1.0)\n      Process a scan if the last scan processed is older than\
    \ the update time in seconds. A value less than zero will turn time \n      based\
    \ updates off.\n\nAlso, set the fixed frame in rviz to map instead of odom so\
    \ that you get a correct visualization of your robot's state"
