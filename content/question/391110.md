I want this, without everything going bad.

    home/
    ├─ usr/
    │  ├─ ROS2_WSs/
    │  │  ├─ ros2_foxy/
    │  │  ├─ px4_ros_com_ros2/
    │  │  ├─ Fast-RTPS-Gen/
    │  │  ├─ FastDDS/
