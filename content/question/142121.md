  body_markdown: "If you want the last message on a topic to be \"remembered\" and\
    \ getting sent to new subscribers, [latching a topic](http://wiki.ros.org/roscpp/Overview/Publishers%20and%20Subscribers#Publisher_Options)\
    \ provides that capability.\n\nTo keep track of when messages arrive, you can\
    \ update a \"last_received\" timestamp inside the topic callback (for example\
    \ your \"cmd_vel\" callback). This way, your node always knows when the last message\
    \ arrived. You can then have a [Timer](http://wiki.ros.org/roscpp/Overview/Timers)\
    \ running and in it\xB4s callback check if the \"last_received\" timestamp is\
    \ within a tolerance threshold of current time. If it is not, you send a motor\
    \ stop command.\nThat\xB4s one way of doing things. You could also use Threads,\
    \ but using Timers and callbacks appears easier."
