  body_markdown: "I had exactly the same problem. Basically until move_base receives\
    \ its first goal the status_list[] is empty. Thus, when you try to access it creates\
    \ a memory problem as status_list[] is empty/not allocated. You can use the ```vector.empty()```\
    \ function that returns 1 if the vector is empty...for example ```status_list.empty()```\
    \ will return 1 if a goal was not given to move_base. \n\nHere is my example code\
    \ on how to protect your callback:\n\n \n\n    void StatusPublisher::navStatusCallBack(const\
    \ actionlib_msgs::GoalStatusArray::ConstPtr& status)\n    {\n     if (!status->status_list.empty())\n\
    \       {\n         actionlib_msgs::GoalStatus goalStatus = status->status_list[0];\n\
    \      testing_pub.publish(goalStatus);\n       } "
