    I suspect it's on the sensor link's inertia. The default values written [here](http://sdformat.org/spec?ver=1.7&elem=link#inertial_inertia) are the identity matrix `[1 0 0; 0 1 0; 0 0 1]`, which is quite imbalance to the other parts of your robots (about 100 times or more). Wrong mass and inertia can cause the model to fly from my experience.
