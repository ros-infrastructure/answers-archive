  body_markdown: "Looks like the problem is that when you receive a laser scan, its\
    \ timestamp is later than all the available /tf data.  This is a common issue\
    \ in a distributed system, and is what [message filters](http://www.ros.org/wiki/tf/Tutorials/Using%20Stamped%20datatypes%20with%20tf%3A%3AMessageFilter)\
    \ were designed to address.  You should try using a message filter.\n\nIn the\
    \ meantime, to help understand the problem, below is a slightly modified version\
    \ of the [code you pointed to](http://answers.ros.org/question/11232/how-to-turn-laser-scan-to-point-cloud-map).\
    \  In this version, I added a sleep to the laser scan callback to allow for /tf\
    \ data to be received before trying to transform the latest scan.  By default,\
    \ this sleep would block receipt of all data, including /tf; so I created a [multithreaded\
    \ spinner](http://www.ros.org/wiki/roscpp/Overview/Callbacks%20and%20Spinning#Multi-threaded_Spinning).\
    \  What you should see if you run this program is that at first transforms will\
    \ fail as your /tf subscriber hooks up and starts getting data; then they'll start\
    \ succeeding.\n\nAgain, don't use the code here; use [message filters](http://www.ros.org/wiki/tf/Tutorials/Using%20Stamped%20datatypes%20with%20tf%3A%3AMessageFilter)\
    \ instead.\n\n    #include <ros/ros.h>\n    #include <tf/transform_listener.h>\n\
    \    #include <laser_geometry/laser_geometry.h>\n \n    class My_Filter {\n  \
    \       public:\n            My_Filter();\n            void scanCallback(const\
    \ sensor_msgs::LaserScan::ConstPtr& scan);\n         private:\n            ros::NodeHandle\
    \ node_;\n            laser_geometry::LaserProjection projector_;\n          \
    \  tf::TransformListener tfListener_;\n \n            ros::Publisher point_cloud_publisher_;\n\
    \            ros::Subscriber scan_sub_;\n    };\n \n    My_Filter::My_Filter(){\n\
    \            scan_sub_ = node_.subscribe<sensor_msgs::LaserScan> (\"/multisense_sl/laser/scan\"\
    , 100, &My_Filter::scanCallback, this);\n            point_cloud_publisher_ =\
    \ node_.advertise<sensor_msgs::PointCloud2> (\"/cloud\", 100, false);\n      \
    \      tfListener_.setExtrapolationLimit(ros::Duration(0.1));\n    }\n    \n \
    \   void My_Filter::scanCallback(const sensor_msgs::LaserScan::ConstPtr& scan){\n\
    \        // Sleep a little so that we have a better chance of having current /tf\
    \ data\n        // before trying to transfrom this latest /scan.\n        ros::Duration(0.1).sleep();\n\
    \        sensor_msgs::PointCloud2 cloud;\n        try\n        {\n          projector_.transformLaserScanToPointCloud(\"\
    pelvis\", *scan, cloud, tfListener_);\n        }\n        catch(tf::TransformException&\
    \ e)\n        {\n          printf(\"failed to transform: %s\\n\", e.what());\n\
    \          return;\n        }\n        printf(\"success\\n\");\n        point_cloud_publisher_.publish(cloud);\n\
    \    }\n    \n    int main(int argc, char** argv)\n    {\n        ros::init(argc,\
    \ argv, \"my_filter\");\n    \n        My_Filter filter;\n    \n        // Start\
    \ up two threads, one to handle /tf messages and the other for /scan\n       \
    \ // messages.\n        ros::MultiThreadedSpinner spinner(2);\n        spinner.spin();\n\
    \    \n        return 0;\n    }\n"
