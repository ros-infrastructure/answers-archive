    The latest version of that package depends on unreleased software (`abb_rws_interface`). It appears that the changes that introduced that dependency were merged into `master` by accident.

    [21833bb1](https://github.com/OrebroUniversity/yumi/commit/21833bb1dd03fbc5e66666cc287224f73647c98f) reverts that, so `master` should build again.

    See also [OrebroUniversity/yumi#15](https://github.com/OrebroUniversity/yumi/issues/15) for a related issue.
