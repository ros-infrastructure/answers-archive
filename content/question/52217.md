    The run.py script hasn't been used in a long time. You'll need to use the Gradle `installApp` task (see [documentation](http://www.gradle.org/docs/current/userguide/application_plugin.html)) and then configure your launch file to execute the generated binary/script. This will hopefully become easier in the future.
