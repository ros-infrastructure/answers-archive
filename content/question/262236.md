  body_markdown: "Its like publishing anything else.\n\nSetup a Publisher, fill in\
    \ the Message and publish it. \n\nHere is a completely senseless example but gives\
    \ you perhaps an idea:\n\n    #include \"ros/ros.h\"\n    #include <diagnostic_msgs/DiagnosticArray.h>\n\
    \    #include <diagnostic_msgs/DiagnosticStatus.h>\n    #include <diagnostic_msgs/KeyValue.h>\n\
    \    \n    int main(int argc, char **argv)\n    {\n      ros::init(argc, argv,\
    \ \"diagnostics\");\n      ros::NodeHandle nh;\n    \n      ros::Publisher diagnostic_pub\
    \ = nh.advertise<diagnostic_msgs::DiagnosticArray>(\"/diagnostics\", 1);\n   \
    \ \n      ros::Rate loop_rate(10);\n      while (ros::ok())\n      {\n       \
    \ diagnostic_msgs::DiagnosticArray dia_array;\n        diagnostic_msgs::DiagnosticStatus\
    \ robot_status;\n        robot_status.name = \"Robot\";\n        robot_status.level\
    \ = diagnostic_msgs::DiagnosticStatus::OK;\n        robot_status.message = \"\
    Everything seem to be ok.\";\n        diagnostic_msgs::KeyValue emergency;\n \
    \       emergency.key = \"Emgergencystop hit\";\n        emergency.value = \"\
    false\";\n        diagnostic_msgs::KeyValue exited_normally;\n        emergency.key\
    \ = \"Exited normally\";\n        emergency.value = \"true\";\n    \n        robot_status.values.push_back(emergency);\n\
    \        robot_status.values.push_back(exited_normally);\n    \n        diagnostic_msgs::DiagnosticStatus\
    \  eth_status;\n        eth_status.name = \"EtherCAT Master\";\n        eth_status.level\
    \ = diagnostic_msgs::DiagnosticStatus::OK;\n        eth_status.message = \"Running\"\
    ;\n    \n        dia_array.status.push_back(robot_status);\n        dia_array.status.push_back(eth_status);\n\
    \    \n        diagnostic_pub.publish(dia_array);\n    \n        ros::spinOnce();\n\
    \    \n        loop_rate.sleep();\n      }\n    \n      return 0;\n    }\n\n"

    If you running a full ROS (and not rosserial on an Arduino) you can use the [diagnostic_updater](http://wiki.ros.org/diagnostic_updater) package to automatically fill in the diagnostics message and publish it.

    The diagnostics_updater package also includes diagnosed publishers that you can use to make sure that you're publishing at your desired rate.

    The diagnostics_updater package ships with some fairly good examples: http://docs.ros.org/api/diagnostic_updater/html/example_8cpp_source.html
