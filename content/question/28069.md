  body_markdown: "The map in the video was generated using the [hector_geotiff](http://www.ros.org/wiki/hector_geotiff)\
    \ node. This node retrieves the map and trajectory via services as stated at the\
    \ wiki page. The trajectory is tracked via the [hector_trajector_server](http://www.ros.org/wiki/hector_trajectory_server)\
    \ package, which provides a node that saves a tf based trajectory given a source\
    \ and target frame. The trajectory is published on a topic as well as available\
    \ as a service.\n\nHave you looked at the ['Mapping using logged data'](http://www.ros.org/wiki/hector_slam/Tutorials/MappingUsingLoggedData)\
    \ tutorial? The process of mapping and saving to geotiff is described there. Note\
    \ that the map saving functionality works with maps generated by gmapping or other\
    \ SLAM systems as well.\n\n/edit: This example launch file should work for you:\n\
    \n    <?xml version=\"1.0\"?>\n    \n    <launch>\n      \n      <node pkg=\"\
    hector_trajectory_server\" type=\"hector_trajectory_server\" name=\"hector_trajectory_server\"\
    \ output=\"screen\">\n        <param name=\"target_frame_name\" type=\"string\"\
    \ value=\"/map\" />\n        <param name=\"source_frame_name\" type=\"string\"\
    \ value=\"/base_link\" />\n        <param name=\"trajectory_update_rate\" type=\"\
    double\" value=\"4\" />\n        <param name=\"trajectory_publish_rate\" type=\"\
    double\" value=\"0.25\" />\n      </node>\n    \n    \n      <node pkg=\"hector_geotiff\"\
    \ type=\"geotiff_node\" name=\"hector_geotiff_node\" output=\"screen\" launch-prefix=\"\
    nice -n 15\">\n        <remap from=\"map\" to=\"/dynamic_map\" />\n        <param\
    \ name=\"map_file_path\" type=\"string\" value=\"$(find hector_geotiff)/maps\"\
    \ />\n        <param name=\"map_file_base_name\" type=\"string\" value=\"hector_slam_map\"\
    \ />\n        <param name=\"draw_background_checkerboard\" type=\"bool\" value=\"\
    true\" />\n        <param name=\"draw_free_space_grid\" type=\"bool\" value=\"\
    true\" />\n      </node>\n    \n    </launch>\n\nThe geotiff map image will be\
    \ saved every time you publish on the syscommand topic like this:\n\n    rostopic\
    \ pub syscommand std_msgs/String \"savegeotiff\" \n\n"
