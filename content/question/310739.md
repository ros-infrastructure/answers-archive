    (ros.ament_cmake)\n    rviz_assimp_vendor\t/Users/william/ros2_ws/src/ros2/rviz/rviz_assimp_vendor\t\
    (ros.ament_cmake)\n    rviz_common\t/Users/william/ros2_ws/src/ros2/rviz/rviz_common\t\
    (ros.ament_cmake)\n    rviz_default_plugins\t/Users/william/ros2_ws/src/ros2/rviz/rviz_default_plugins\t\
    (ros.ament_cmake)\n    rviz_ogre_vendor\t/Users/william/ros2_ws/src/ros2/rviz/rviz_ogre_vendor\t\
    (ros.ament_cmake)\n    rviz_rendering\t/Users/william/ros2_ws/src/ros2/rviz/rviz_rendering\t\
    (ros.ament_cmake)\n    rviz_rendering_tests\t/Users/william/ros2_ws/src/ros2/rviz/rviz_rendering_tests\t\
    (ros.ament_cmake)\n    rviz_visual_testing_framework\t/Users/william/ros2_ws/src/ros2/rviz/rviz_visual_testing_framework\t\
    (ros.ament_cmake)\n\nFor the latter there is `ros2 pkg ...` commands, e.g.:\n\n\
    \    % ros2 pkg list | grep rmw\n    rmw\n    rmw_connext_cpp\n    rmw_connext_shared_cpp\n\
    \    rmw_fastrtps_cpp\n    rmw_fastrtps_dynamic_cpp\n    rmw_fastrtps_shared_cpp\n\
    \    rmw_implementation\n    rmw_implementation_cmake\n    rmw_opensplice_cpp\n\
    \nOr this:\n\n    % ros2 pkg prefix rclcpp\n    /Users/william/ros2_ws/install/rclcpp\n\
    \nIf you're looking for something to do the grep for you, then we'd have to add\
    \ a verb for that, but I think it would probably be accepted if a pr was made\
    \ to that effect (after some iteration probably)."
