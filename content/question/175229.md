    What you want to do does not work. Messages/commands are not send **to** a topic, they are send **over** a topic to a node, where the topic is only a common name to connect over. There is simply nothing in between that could "hold" a message, besides your node.

    So you have to make sure that you send the message in a high enough frequency, so the robot keeps on moving. This could be achieved easily with your code structure if you just change your `==` to `<=`. This will also fix this code which compares doubles with `==` that probably wouldn't have worked anyways.
    It's also a good idea to use `ros::Time` instead of clock cycles.
