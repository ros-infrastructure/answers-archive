    quick comment: just create a publisher publishing [rosgraph_msgs/Clock](http://docs.ros.org/en/melodic/api/rosgraph_msgs/html/msg/Clock.html), making sure to keep track of whatever time you want to publish.

    Make sure there is only one, publish to the correct topic (ie: `/clock`) and set `use_sim_time` to `true` for all involved nodes.

    That'd be it.

    See also [wiki/Clock](http://wiki.ros.org/Clock).
