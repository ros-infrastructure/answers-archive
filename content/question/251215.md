I've been making a client library, and this is one of the last elements before this thing is ready to be used extensively. The [Slave API](http://wiki.ros.org/ROS/Slave_API) listing just gives a general format, but doesn't explain what all the individual elements should be.

Every 3rd party client library I've dug through just left this as a "todo", even the [NodeJS](https://github.com/RethinkRobotics-opensource/rosnodejs/blob/2eabdce2185df76402b42fb02302370834794ccd/lib/RosNode.js#L521-L527) one which is part of message generation, so it must be used by *someone*.
