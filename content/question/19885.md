I have a custom model which I want to record while in simulator. I use the command 'gz log -d 1' to start and 'gz log -d 0' to stop the recording. Rarely the log files are playable without any hassle, but most times gazebo either crash when starting up, or the model is mashed together and you cant see what is happening.
Command I use for playing the log files are 'gazebo -p logfile.log'.

Not sure which files are interesting so will edit when asked for.
