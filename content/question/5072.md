  body_markdown: "You mesh imports are incorrect.  To import meshes from ROS packages\
    \ in Gazebo, you need to use the syntax:\n\n`<uri>model://my_package/meshes/foo.STL</uri>`\n\
    \nFor Gazebo to find your package, you also need to include the code block below\
    \ in your `package.xml`.  See [this answer](http://answers.gazebosim.org/question/6568/uri-paths-to-packages-in-the-sdf-model-file/)\
    \ for more information.\n\n    <export>\n    <!-- gazebo_ros_paths_plugin automatically\
    \ adds these to\n        GAZEBO_PLUGIN_PATH and GAZEBO_MODEL_PATH when you do\
    \ this export inside\n        the package.xml file. You can than use URIs of type\
    \ model://my_package/stuff. -->\n        <gazebo_ros                         \
    \                                        \n            gazebo_plugin_path=\"${prefix}/lib\"\
    \n            gazebo_model_path=\"${prefix}/..\" /> \n    </export>\n\n\n"
