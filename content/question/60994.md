  body_markdown: "Both of those lines are correct for now, but the latter will be\
    \ deprecated.\n\nThe `_gencpp` is the old style, the `_generate_messages_cpp`\
    \ target is the new name (more descriptive). \n\nThese targets are created by\
    \ the `generate_messages(DEPENDENCIES ...)` CMake macro call. Calling `add_dependencies(my_bin\
    \ ${PKG_NAME}_generate_messages_cpp)` just tells CMake that the `${PKG_NAME}_generate_messages_cpp`\
    \ target should be built before the `my_bin` target. It does not instruct CMake\
    \ to *generate* your messages. So, if you are expecting this line to cause your\
    \ services to be built, then that's incorrect.\n\nSee the ROS tutorials about\
    \ how to get services generated:\n\nhttp://www.ros.org/wiki/ROS/Tutorials/CreatingMsgAndSrv#Using_srv"
