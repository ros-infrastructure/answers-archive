 I am using two instances of `robot_localization` package to get the local and global odometry. In the local one, I am fusing `IMU` and `twist` messages. It is working fine. But when I use the second instance where `map` and `odom` frame both should be fixed points, one of them is moving. I set `map` as the fixed frame, then `odom` is moving. Why is that? `Odom` should remain fixed at the initial starting point. `base_link` with respect to `odom` is working fine but since `odom` is moving, `base_link` with respect to `map` is not working.
