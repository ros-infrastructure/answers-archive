  body_markdown: "sourcing a 'setup.bash' file, whether the base ROS one in /opt/ros/indigo,\
    \ or the one in you workspace (devel/setup.bash), is only necessary once per terminal\
    \ (instance of bash shell) that you open. This will load the ROS environment,\
    \ giving you access to ros* and catkin* commands. \n\nTherefore, if you add it\
    \ to ~/.bashrc, you will only need to run source if you want to SWITCH workspaces."
