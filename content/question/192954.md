    Generally, running multiple copies of the same system is easy enough, since each node has it's own private [namespace](http://wiki.ros.org/Names).

    However, having used [gscam](http://wiki.ros.org/gscam), this might be tricky because it's very un-ROS in the way it reads the device name from an environment variable.

    If you use [usb_cam](http://wiki.ros.org/usb_cam), you should be able to specify the input device for each node with the `video_device` parameter.
