  body_markdown: "My suggestion would be to install the Turtlebot packages to see\
    \ an example of how the Navigation Stack can be setup. In the [turtlebot_bringup](http://wiki.ros.org/turtlebot_bringup)\
    \ package they have the option to the set the base as the Create as well, which\
    \ could be useful for you. \n\nSpecifically, look in the [turtlebot_navigation](http://wiki.ros.org/turtlebot_navigation)\
    \ package at the `amcl_demo.launch` and `gmapping_demo.launch` files to see how\
    \ the nodes for `amcl`, `gmapping`, or `move_base` can be started. Also, if you\
    \ look at the includes for the launch files and in the param folder you'll find\
    \ examples for all the parameter settings for `amcl`, `gmapping`, and `move_base`.\
    \ \n\nYou can follow the [Turtlebot Navigation Tutorials](http://wiki.ros.org/turtlebot/Tutorials/indigo)\
    \ for Navigation and Simulation for an example of how to use the above, and if\
    \ you haven't already done so take a look at the [Navigation Stack Tutorials](http://wiki.ros.org/navigation)\
    \ as well.\n\nHope this helps."
