  body_markdown: "Finally I could solve that problem. The steps that I followed are\
    \ the next, I hope it help:\n\n1. Clear the maven cache: \n   $ rm -rf ~/.m2/repository/ros\n\
    \n2. Delete the rosjava folder (if already installed) and create it again:\n \
    \  $ rm -r Workspace\n   $ mkdir -p Workspace\n\n3. Install rosjava:\n   $ rosinstall\
    \ ~/Workspace https://kforge.ros.org/appmanandroid/hg/raw-file/tip/appman.rosinstall\n\
    \n4. Install android_core:\n   $ cd ~/Workspace\n   $ rosws merge http://android.rosjava.googlecode.com/hg/.rosinstall\n\
    \   $ rosws update\n\n5. Build rosjava_core:\n   $ roscd rosjava_core\n   $ ./gradlew\
    \ install\n   -- optionals\n      $ ./gradlew docs\n      $ ./gradlew test\n \
    \     $ ./gradlew eclipse\n\n6. Install google:\n   $ roscd google\n   $ ./gradlew\
    \ install\n\n6. Install android_core:\n   $ roscd android_core\n   $ ./gradlew\
    \ debug"
