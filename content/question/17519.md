    On that tutorial you're making a wide-angle camera, and unfortunately, that doesn't have built-in support for visualization in the 3D scene yet.

    It doesn't look like it would be too complicated to add support for it, basically we'd need to do the same that is done for the normal camera. I ticketed an issue on Gazebo:

    https://bitbucket.org/osrf/gazebo/issues/2361/3d-visualization-for-non-standard-cameras

    ## Update

    After some clarifications in the comments, I understood the question was about displaying a camera image as a widget attached to the main window, as opposed to a pop-up dialog.

    One way would be to create a [GUI overlay](http://gazebosim.org/tutorials?tut=gui_overlay) plugin which reimplements the logic used on the [topic viewer](https://bitbucket.org/osrf/gazebo/src/e26144434b93/gazebo/gui/viewers/?at=default) "pop-ups". Unfortunately, I can't think of a simpler way, unless someone has already implemented such a plugin and made it available.
