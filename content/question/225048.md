  body_markdown: " Check out [the wiki page](http://wiki.ros.org/gmapping) (maybe\
    \ you want to have a look at wiki pages before asking questions about parameters)\
    \ and the parameter `map_update_interval` which is by default set to 5.0.\n\n\
    Note that the visualization(!) of the map is actually not when scans are integrated,\
    \ but only when a new gridmap is assembled and sent out over the topic. Also note,\
    \ that the robot needs to move for scans to be integrated.\n\n\n----------\n**EDIT**\n\
    \nWell, if the maps are distorted and it still takes a long time, you probably\
    \ have some problem with the mapping process itself. Maybe also not enough processing\
    \ power?\nParameters that might lower computational requirements: `throttle_scans`,\
    \ `maxUrange`, `linear/angularUpdate`, `temporalUpdate`, `particles`.\n\nHowever,\
    \ note that some of those parameters might result in even worse maps. "
