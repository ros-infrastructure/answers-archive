  body_markdown: "I don't know if it is what you want to do but if you kill the roscore,\
    \ you kill at the same time all nodes.\n\nBut if you want to kill all nodes without\
    \ killing the roscore, you can create your own script like this:\n\n    #!/usr/bin/env\
    \ python\n    import os\n    \n    nodes = os.popen(\"rosnode list\").readlines()\n\
    \    for i in range(len(nodes)):\n    \tnodes[i] = nodes[i].replace(\"\\n\",\"\
    \")\n    \n    for node in nodes:\n    \tos.system(\"rosnode kill \"+ node)\n\n\
    I have written this script in python. I tested it, it works properly. You can\
    \ modify it as you wish.<br/>\nI want to notice that the node <em>/rosout</em>\
    \ will relaunch itself automatically after being killed by this script.\n\nI hope\
    \ it helps you,<br/>\nlfr"
