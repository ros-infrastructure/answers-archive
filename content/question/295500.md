    This is not possible with the `effort_controllers/JointPositionController`. This is intended for a single joint.

    However, there is also [an `effort_controllers/JointGroupPositionController`.](http://docs.ros.org/lunar/api/effort_controllers/html/classeffort__controllers_1_1JointGroupPositionController.html) I don't have personal experience, but this might do what you want.

    Syntax for the yaml is (according to [this example](https://github.com/personalrobotics/herb_launch/blob/master/config/ros_control_controllers.yaml)) :

        type: "position_controllers/JointGroupPositionController"
        joints:
         - joint_1
         - joint_2
        pid_gains:
          joint_1: {p: 100.0, i: 0.01, d: 10.0}
          joint_2: {p: 100.0, i: 0.01, d: 10.0}
