    I updated the SDK files on another computer:

     1. copy and extract the new SDK file (in my case it was 'Vicon_SDK_1.3_Linux.tar') to the folder vicon_sdk;
     2. open the file 'CMakeLists.txt' and replace the line set(VICON_SDK     vicon_sdk/vicon_datastream_SDK_1.2.59611_x64) with       set(VICON_SDK             vicon_sdk/Vicon_SDK_1.3_Linux/Linux64-boost-1.53.0/20130523_60242h/Release)
    and set(VICON_SDK             vicon_sdk/vicon_datastream_SDK_1.2.59611_x86) with set(VICON_SDK             vicon_sdk/Vicon_SDK_1.3_Linux/Linux32-boost-1.53.0/20130524_60250h/Release);
     3. rosmake

    then it should be fixed ;)
