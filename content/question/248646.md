  body_markdown: "As the error says, you are trying to do a relative import (i.e.\
    \ using `..`). Instead, since you are already setting `service` as a package in\
    \ your `setup.py` file you can used that package name directly by changing:\n\n\
    \ `from ..srv import * `  in `service_def.py` to  `from service.service_def import\
    \ *`.\n\nHere's an MWE for the: \n\n**Structure:**\n\n    service/\n    \u251C\
    \u2500\u2500 CMakeLists.txt\n    \u251C\u2500\u2500 package.xml\n    \u251C\u2500\
    \u2500 src\n    \u2502\_\_ \u2514\u2500\u2500 service_node\n    \u2514\u2500\u2500\
    \ srv\n        \u251C\u2500\u2500 get.srv\n        \u251C\u2500\u2500 __init__.py\n\
    \        \u2514\u2500\u2500 set.srv\n\n**CMakeLists.txt**\n\n    cmake_minimum_required(VERSION\
    \ 2.8.3)\n    project(service)\n    \n    find_package(catkin REQUIRED\n     \
    \  rospy\n       std_msgs\n       message_generation\n    )\n    \n    add_service_files(\n\
    \      FILES\n       get.srv\n       set.srv\n    )\n    \n    generate_messages(\n\
    \      DEPENDENCIES\n      std_msgs\n    )\n    \n    catkin_package(\n    )\n\
    \n**package.xml**\n\n    <?xml version=\"1.0\"?>\n    <package>\n      <name>service</name>\n\
    \      <version>0.0.0</version>\n      <description>The service package</description>\n\
    \    \n      <maintainer email=\"jsanch@todo.todo\">jsanch</maintainer>\n    \n\
    \      <license>TODO</license>\n      <buildtool_depend>catkin</buildtool_depend>\n\
    \    \n      <build_depend>rospy</build_depend>\n      <build_depend>message_generation</build_depend>\n\
    \    \n      <run_depend>rospy</run_depend>\n      <run_depend>message_runtime</run_depend>\n\
    \    </package>\n\n**service_node**\n\n    #!/usr/bin/env python\n    #-*- encoding:\
    \ utf-8 -*-\n    \n    import rospy\n    import service.srv\n    \n    \n    def\
    \ main():\n        print(\"Creating set\")\n        x = service.srv.set\n    \
    \    print(\"Creating get\")\n        y = service.srv.get\n    \n    if __name__\
    \ == '__main__':\n        rospy.init_node('service_node', anonymous=True)\n  \
    \      main()"
