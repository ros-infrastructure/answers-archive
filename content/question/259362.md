  body_markdown: "Have you looked through the [urdf tutorials](http://wiki.ros.org/urdf/Tutorials)?\
    \ \n\nThey show you how to launch a urdf in rviz: \n\n    $ roslaunch urdf_tutorial\
    \ display.launch model:='$(find urdf_tutorial)/urdf/01-myfirst.urdf'\nIf you don't\
    \ want to use the urdf_tutorial package (I think that's what you're saying) simply\
    \ copy the display.launch file from the urdf_tutorial package and paste it in\
    \ your own package, then you're free to edit it if you like. You'll see there's\
    \ not much in there: \n\n    <launch>\n\n      <arg name=\"model\" default=\"\
    $(find urdf_tutorial)/urdf/r2d2.xacro\"/>\n      <arg name=\"gui\" default=\"\
    true\" />\n      <arg name=\"rvizconfig\" default=\"$(find urdf_tutorial)/rviz/urdf.rviz\"\
    \ />\n\n      <param name=\"robot_description\" command=\"$(find xacro)/xacro.py\
    \ $(arg model)\" />\n      <param name=\"use_gui\" value=\"$(arg gui)\"/>\n\n\
    \      <node name=\"joint_state_publisher\" pkg=\"joint_state_publisher\" type=\"\
    joint_state_publisher\" />\n      <node name=\"robot_state_publisher\" pkg=\"\
    robot_state_publisher\" type=\"state_publisher\" />\n      <node name=\"rviz\"\
    \ pkg=\"rviz\" type=\"rviz\" args=\"-d $(arg rvizconfig)\" required=\"true\" />\n\
    \n    </launch>\n\nIt's just starting all the nodes you'll need to show the robot\
    \ in Rviz (and move the joints)"
