  - body_markdown: "you can unsubscribe by iterating over each message_filter's subscription\n\
      \nAssuming you subscribed like this:\n\n    self.subs = [message_filters.Subscriber(topic,\
      \ mtype) for topic, mtype in zip(self.topics, self.types)]\n    self.ts = message_filters.ApproximateTimeSynchronizer(\n\
      \                self.subs,\n                5,  # queue size\n            \
      \    0.2,\n                allow_headerless=False\n    )  \n    self.ts.registerCallback(self.cb_logger)\n\
      \nYou can unsubscribe like this:\n\n    for sub in self.subs:\n            \
      \    sub.sub.unregister()"
