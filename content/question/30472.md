    In electric, a `<laserRetro>` element can be declared under gazebo's `<geom:xxx>` element, and was used to set the [LaserScan](http://ros.org/doc/api/sensor_msgs/html/msg/LaserScan.html) `intensities` field when a simulated ray hits a surface.  As pointed out by PKG, this is not correct, but an extreme simplification.  This feature should be improved in Fuerte with the upcoming GPU version of laser range scanners currently being constructed.
