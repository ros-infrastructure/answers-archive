    ROS by itself doesn't simulate things, but using a simulator, it is possible to do what you want: the simulator (or a plugin for it) should then 'sense' the simulated world and construct the appropriate ROS messages, so your ROS application receives the correct data.

    Gazebo is one simulator for which this is possible. See [Tutorial: Using Gazebo plugins with ROS](http://gazebosim.org/tutorials?tut=ros_gzplugins) for information on how to do that with various simulated sensors. A virtual depth camera is one of them (see [Openni Kinect](http://gazebosim.org/tutorials?tut=ros_gzplugins#OpenniKinect)).
