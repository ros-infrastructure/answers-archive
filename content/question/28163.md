  body_markdown: "I would first copy your warehouse_viewer launch file to a new file,\
    \ as you'll be making several changes, and the result will no longer work without\
    \ a real robot in the loop.\n\nIn the copy, first these lines in your planning_scene_warehouse_viewer\
    \ launch file:\n\n     <include file=\"$(find planning_environment)/launch/environment_server.launch\"\
    >\n        <arg name=\"use_monitor\" value=\"false\" />\n        <arg name=\"\
    use_collision_map\" value=\"false\" />\n      </include>\n\nIf you are running\
    \ with real robot data, you'll need to change the \"use_monitor\" parameter to\
    \ true - this will actually subscribe to the /joint_states message to populate\
    \ the current position of the robot.  \n\nYou'll also need to delete these two\
    \ lines in the launch file:\n\n    <node pkg=\"planning_environment\" name=\"\
    wall_clock_server\" type=\"fake_time.py\" />\n\n    <node pkg=\"robot_state_publisher\"\
    \ type=\"state_publisher\" name=\"rob_st_pub\" />\n\nIf you like, you can also\
    \ set your trajectory action parameter in this new file (use the entries for the\
    \ left arm) and set this parameter so that you don't have to mess with the configuration\
    \ screen:\n\n    <param name=\"use_robot_data\" value=\"true\"/>"
