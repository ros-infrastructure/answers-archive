      > The IP address that you saw in the SICK software is not a valid ip address

      I'm not sure this is entirely correct. IPs in the range `169.254.x.x` are in the [APIPA or *link local* range](https://en.wikipedia.org/wiki/Link-local_address). They're certainly valid IP addresses. They may change next tim the device is started though, so configuring a static IP address may be a good idea.
