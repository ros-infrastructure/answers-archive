  body_markdown: "You can use `rosparam dump` to save parameters to a yaml file. \
    \ \nhttp://wiki.ros.org/rosparam\n\nI use a script to save all parameters right\
    \ before recording a bag.\n\n    #!/bin/bash\n    rosparam dump `date +%Y-%m-%d-%H-%M-%S`.yaml\n\
    \    rosbag record /topic1 /topic2 /topic3\n\nEdit: Removed -u option from date."
