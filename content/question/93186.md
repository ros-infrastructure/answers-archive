  body_markdown: "In order to export python libraries you need to do two things:\n\
    \n- Setup a `setup.py` file describing which Python packages your package has\n\
    - Call the `catkin_python_setup()` macro in your `CMakeLists.txt`\n\nReference:\
    \ http://docs.ros.org/api/catkin/html/user_guide/setup_dot_py.html\n\nThe `setup.py`\
    \ should be in the root of your package and look like this:\n\n    from distutils.core\
    \ import setup\n    from catkin_pkg.python_setup import generate_distutils_setup\n\
    \    \n    d = generate_distutils_setup(\n        packages=['mypkg'],\n      \
    \  package_dir={'': 'src'}\n    )\n    \n    setup(**d)\n\nWhere...\n\n      \
    \  packages=['mypkg'],\n\n'mypkg' is the name of the python package you want,\
    \ in your case probably 'hrl_lib', and...\n\n        package_dir={'': 'src'}\n\
    \n'src' is the folder in your package where you keep these packages, so your folder\
    \ structure would be:\n\n    /path/to/my/package\n                       /setup.py\n\
    \                       /src\n                           /hrl_lib\n          \
    \                         /__init__.py\n                                   ...\n\
    \nAnd in your `CMakeLists.txt` you need to call before `catkin_package(...)`:\n\
    \n    catkin_python_setup()\n\nAlso, get rid of these lines:\n\n    set(EXECUTABLE_OUTPUT_PATH\
    \ ${PROJECT_SOURCE_DIR}/bin)\n    set(LIBRARY_OUTPUT_PATH ${PROJECT_SOURCE_DIR}/lib)\n\
    \nThis was someting that rosbuild had you do, but you shouldn't do this in catkin.\n\
    \n**EDIT:**\n\nI would expect your `setup.py` to look like this:\n\n    from distutils.core\
    \ import setup\n    from catkin_pkg.python_setup import generate_distutils_setup\n\
    \    \n    d = generate_distutils_setup(\n        packages=['hrl_hokuyo', 'hrl_lib'],\n\
    \        package_dir={'': 'src'}\n    )\n    \n    setup(**d)"

    setup(**d)
