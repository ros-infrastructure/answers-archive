  body_markdown: "An example configuration. Assuming you have, let's say, 3 sonars\
    \ publishing sensor_msgs/Range messages on /mobile_base/sensors/sonars/sonar1,\
    \ /mobile_base/sensors/sonars/sonar2 and /mobile_base/sensors/sonars/sonar3:\n\
    \ncostmap_common_params.yaml\n\n    robot_radius: 0.18\n    \n    inflation_layer:\n\
    \    ...\n    obstacle_layer:\n    ...\n    \n    range_sensor_layer:\n      clear_threshold:\
    \    0.46\n      mark_threshold:     0.98\n      no_readings_timeout: 2.0\n  \
    \    ns:     /mobile_base/sensors/sonars\n      topics: [\"sonar1\", \"sonar2\"\
    , \"sonar3\"]\n\nand in local_costmap_params.yaml (and global_costmap_params.yaml,\
    \ if you want to use the sonars also in the global costmap):\n\n    ...\n    plugins:\n\
    \      - {name: range_sensor_layer, type: \"range_sensor_layer::RangeSensorLayer\"\
    }\n         .... # any other plugins you use, typically:\n      - {name: obstacle_layer,\
    \     type: \"costmap_2d::VoxelLayer\"}\n      - {name: inflation_layer,    type:\
    \ \"costmap_2d::InflationLayer\"}\n      - {name: footprint_layer,    type: \"\
    costmap_2d::FootprintLayer\"}\n\nHope this helps."
