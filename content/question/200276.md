    ROS Electric does not officially support -i.e. there is no pre-built for- Ubuntu 14.10 as can be seen in [REP 3 - Target Platforms](http://www.ros.org/reps/rep-0003.html#electric-emys-aug-2011) since it is released in 2011. You can install ROS Electric on Ubuntu 10.04/10.10/11.04/11.10.
