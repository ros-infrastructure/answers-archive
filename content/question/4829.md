  body_markdown: "When objects jitter, it's usually because the inertia values are\
    \ bad or the physics timestep size is too large.\n\nYou can cause a sphere to\
    \ slowly stop rolling by applying a velocity decay value.\n\nI modified your test.world\
    \ a bit, and the box seems stable:\n\n    <sdf version='1.4'>\n      <world name='default'>\n\
    \        <include>\n          <uri>model://sun</uri>\n        </include>\n   \
    \ \n        <include>\n          <uri>model://ground_plane</uri>\n        </include>\n\
    \    \n        <physics type='ode'>\n          <max_step_size>0.001</max_step_size>\n\
    \          <real_time_factor>1</real_time_factor>\n          <real_time_update_rate>1000</real_time_update_rate>\n\
    \          <gravity>0 0 -9.8</gravity>\n        </physics>\n    \n    \n     \
    \   <model name='batterie'>\n          <pose>5.486 2.3746 0.5 0 -0 0</pose>\n\
    \          <link name='link'>\n            <inertial>\n              <inertia>\n\
    \                <ixx>1</ixx> <ixy>0</ixy> <ixz>0</ixz>\n                <iyy>1</iyy>\
    \ <iyz>0</iyz>\n                <izz>1</izz>\n              </inertia>\n     \
    \         <mass>1</mass>\n            </inertial>\n    \n            <collision\
    \ name='collision'>\n              <geometry>\n               <box>\n        \
    \          <size>0.15 0.3 0.075</size>\n                </box>\n             \
    \ </geometry>\n              <max_contacts>10</max_contacts>\n            </collision>\n\
    \    \n            <visual name='visual'>\n              <geometry>\n        \
    \        <box>\n                  <size>0.15 0.3 0.075</size>\n              \
    \  </box>\n              </geometry>\n            </visual>\n          </link>\n\
    \        </model>\n    \n      </world>\n    </sdf>\n\n"
