  body_markdown: "Assuming you have already set up the controllers through configuration\
    \ yaml files and modified the urdf to add transmission interfaces then you can\
    \ use rqt_gui to send commands to each controller. \n\nOnce you launch the robot\
    \ with it's controllers then you can open the rqt gui with a new terminal using\
    \ \n\n    rosrun rqt_gui rqt_gui\n\nFrom here, there is a drop-down box to select\
    \ the topic you would like to publish on, it should be something like `effort_controllers/JointPositionController/command`.\
    \ Use the plus to add it to the list, modify the rate and expression you would\
    \ like to publish and repeat for every controller. \n\n"
