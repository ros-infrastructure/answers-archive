    you can install turtlebot2 for melodic using this distribution in the following video it especially solves this problem:[solution vedio](https://www.youtube.com/watch?v=rniyH8dY5t4![image description)

    or for short answer:

    >  cloning:

        $ curl -sLf https://raw.githubusercontent.com/gaunthan/Turtlebot2-On-Melodic/master/install_all.sh | bash

    > install dep:

        sudo apt-get install ros-melodic-move-base*
        sudo apt-get install ros-melodic-map-server*
        sudo apt-get install ros-melodic-amcl*
        sudo apt-get install ros-melodic-navigation*
