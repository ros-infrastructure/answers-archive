  body_markdown: "Okay, based on @tfoote's response and [this answer](http://stackoverflow.com/a/4870905/346814)\
    \ to a related question, I *think* this does the job:\n\n    # rotate vector v1\
    \ by quaternion q1 \n    def qv_mult(q1, v1):\n        # comment this out if v1\
    \ doesn't need to be a unit vector\n        v1 = tf.transformations.unit_vector(v1)\n\
    \        q2 = list(v1)\n        q2.append(0.0)\n        return tf.transformations.quaternion_multiply(\n\
    \            tf.transformations.quaternion_multiply(q1, q2), \n            tf.transformations.quaternion_conjugate(q1)\n\
    \        )[:3]"
