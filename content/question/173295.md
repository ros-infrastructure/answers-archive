    \ your node. Nodes can call command line tools. Unfortunately, there doesn't seem\
    \ to be a an easier way to find this info through the C++ or Python API. I just\
    \ scrape the output of `rostopic list <topic> --verbose` in my custom nodes.\n\
    \nIt will output something like:\n\n    Published topics:\n     * <topic> [std_msgs/String]\
    \ 1 publisher\n    \n    Subscribed topics:\n     * <topic> [std_msgs/String]\
    \ 1 subscriber\n\nThe number before publisher/subscriber is the number of nodes\
    \ publishing to or subscribing to that topic respectively. You can easily use\
    \ regexp or simple string parsing to extract that number."
