  body_markdown: "Gravity does not apply on an object if it's being moved by a `SetLinearVel`\
    \ call because setting the velocity of an object overrides any forces being applied\
    \ on the object. Instead, you need to use `AddForce` on the links of the model.\
    \ You can choose to apply the force on all the links or one designated link (or\
    \ multiple links). In your case, the easiest thing might be to apply it on the\
    \ very first link:\n\n    class ModelPush : public ModelPlugin\n    {\n      public:\
    \ void Load(physics::ModelPtr _parent, sdf::ElementPtr /*_sdf*/)\n      {\n  \
    \      // Store the pointer to the model\n        this->model = _parent;\n   \
    \     this->baseLink = _parent->GetLinks()[0];\n    \n        // Listen to the\
    \ update event. This event is broadcast every\n        // simulation iteration.\n\
    \        this->updateConnection = event::Events::ConnectWorldUpdateBegin(\n  \
    \          std::bind(&ModelPush::OnUpdate, this));\n      }\n    \n      // Called\
    \ by the world update start event\n      public: void OnUpdate()\n      {\n  \
    \      // Apply a small linear velocity to all the base link the model.\n    \
    \    this->baseLink->AddForce(ignition::math::Vector3d(.3, 0, 0));\n      }\n\
    \    \n      // Pointer to the model\n      private: physics::ModelPtr model;\n\
    \      private: physics::LinkPtr baseLink;\n    \n      // Pointer to the update\
    \ event connection\n      private: event::ConnectionPtr updateConnection;\n  \
    \  };\n\n"
