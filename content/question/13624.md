    I got the solution. Took longer as I just started using Linux.
    **gazebo7** has depends on **gazebo7-common with version 7.0.0+dfsg-2**. But when **gazebo7-common** is installed, it always installs the latest version which is **7.2.0-1~xenial**, and this has caused the install issue. When I forced installed the **gazebo7-common 7.0.0+dfsg-2**, I could install **gazebo7** without a glitch.
