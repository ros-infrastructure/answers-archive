    This is similar to [a previous question](http://answers.ros.org/question/438/how-to-recieve-an-array-over-publisher-and). There is a good answer there that has some example code and points to [this tutorial](http://www.ros.org/wiki/rospy_tutorials/Tutorials/numpy).     For [C++ vectors](http://www.cplusplus.com/reference/stl/vector/) you can do something like the following (someone correct my C++ if I'm wrong please):

        std::vector<double>::iterator my_iterator;
        int i = 0;
        for (my_iterator = msg.vector_field.begin(); msg.vector_field.end(); my_iterator++)
        {
            my_local_battery_value[i] = msg.vector_field[my_iterator];
            i++;
        }
    or follow [this page](http://www.cplusplus.com/forum/general/33912/).
