  body_markdown: "ar_track_alvar publishes by default the detected markers to the\
    \ topic : ar_pose_marker\n\nYou can see in this topic that the pose contains the\
    \ distance from the camera to the marker in the variable pose.position.z\n\nAlternatively,\
    \ since you are using a kinect, you could recalculate the pixel at which the marker\
    \ is centered and get its corresponding depth from the kinect.\n\nIn both cases\
    \ you will get a distance from the marker to the camera and you need to use tf\
    \ to transform it such that you get the distance from the marker to the create\
    \ base. "

    \ to lookup the transform from whatever robot frame you're interested in (e.g.\
    \ base_link) to the tag's frame. \n\nSee:\n\n - ar_track_alvar [provided tf\n\
