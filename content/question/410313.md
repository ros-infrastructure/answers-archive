  body_markdown: "The error message here is pretty self explanatory: You have mismatched\
    \ XML tags. You can see this with basically anything that parses XML, my favourite\
    \ cloud based one is https://jsonformatter.org/xml-parser.\n\nSpecifically there\
    \ are 2 wrong things here. You don't close your run_depend tag properly, and the\
    \ whole string you have with the <a> tag in the maintainer is wrong. It looks\
    \ like you're trying to create a hyperlink for your email, but you really don't\
    \ need to do that. All the maintainer tag really needs is an email and a name.\
    \ \n\n    <maintainer email=\"bob@workplace.com\"> Bob Workplace </maintainer>\n\
    would be just fine for a maintainer tag. "
