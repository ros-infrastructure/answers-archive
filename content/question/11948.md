  body_markdown: "I use [Blender](http://www.blender.org/), an open-source 3D modelling\
    \ and animation program, to create my terrains. For example, you could try [this\
    \ tutorial](http://blender101.blogspot.com/2009/11/terrain-via-height-map-tutorial-blender.html)\
    \ to get you started. There is also the option to use the [sculpt tool](http://www.youtube.com/watch?v=IhLuA5kpn2Y)\
    \ to create terrains. You can also use Blender to create other meshes. \n\nOnce\
    \ I create my terrain, I then export the terrain to Collada 1.4 (.dae) using the\
    \ built-in Blender Collada exporter. This format is readable by Gazebo. \n\nFinally,\
    \ to get the terrain into Gazebo, I copy the .dae file to my Gazebo \"models\"\
    \ directory (see below). I then add the terrain to the .world file so that it\
    \ is guaranteed to be static. \n\n      <model:physical name=\"hill\">\n     \
    \  <xyz>5.0 -5.0 0.1</xyz>\n       <rpy>0 0 0</rpy>\n       <static>true</static>\n\
    \       <body:trimesh name=\"hill\">\n          <geom:trimesh name=\"hill\">\n\
    \            <scale>1.0 1.0 1.0</scale>\n            <mesh>ground_profile_test.dae</mesh>\n\
    \            <visual>\n               <scale>1.0 1.0 1.0</scale>\n           \
    \    <mesh>ground_profile_test.dae</mesh>\n            </visual>\n          </geom:trimesh>\n\
    \      </body:trimesh>\n     </model:physical>\n\n**NOTE**: You must configure\
    \ your Gazebo media paths correctly. See [here](http://www.ros.org/wiki/simulator_gazebo/GazeboConfiguration).\
    \ \n\n\n"
