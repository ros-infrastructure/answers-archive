  body_markdown: "HI,\n\nIn my case, I included iSAM library in my ROS package.\n\n\
    I created a new package, with catkin_creat_package, and add the following lines\
    \ to the CMake file \n\n    add_executable(my_node src/my_node.cpp   )\n    target_link_libraries(my_node\
    \ ${catkin_LIBRARIES} isam cholmod)\n    add_dependencies(my_node my_package)\n\
    \nI installed iSAM library on /usr/include."
