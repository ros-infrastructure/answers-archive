    I only gave it a quick look, but at first sight it seems that you will have to:

    1. Create an ImageFOVDistortionModel.cc similar to [ImageBrownDistortionModel.cc](https://github.com/gazebosim/gz-sensors/blob/gz-sensors7/src/ImageBrownDistortionModel.cc),
    2. Adapt [DistortionFactory::NewDistortionModel()](https://github.com/gazebosim/gz-sensors/blob/7b4387fc64b12f72a39e7c7efafcbc8cc4230766/src/Distortion.cc#L44-L47) to support also your new FOV distortion model,
    3. Adapt [CameraSensor.cc](https://github.com/gazebosim/gz-sensors/blob/7b4387fc64b12f72a39e7c7efafcbc8cc4230766/src/CameraSensor.cc#L260-L268) to support also your new distortion model.

    </br>

    EDIT:

    Step 2. is rather "Adapt [ImageDistortionFactory::NewDistortionModel()](https://github.com/gazebosim/gz-sensors/blob/7b4387fc64b12f72a39e7c7efafcbc8cc4230766/src/ImageDistortion.cc#L33)" instead.

    [This remark](https://github.com/gazebosim/gz-sensors/blob/7b4387fc64b12f72a39e7c7efafcbc8cc4230766/src/ImageDistortion.cc#L56-L58) suggests that you could also define it as a 'custom' distortion model, but I find no references to `SetCustomDistortionCallback` anywhere in the code, so I think this has not been implemented...

    </br>

    EDIT 2:

    This issue [#107](https://github.com/gazebosim/gz-sensors/issues/107) and pull request [#192](https://github.com/gazebosim/gz-sensors/pull/192) suggest that changes to `gz-rendering` might also be required. This is the corresponding `gz-rendering` pull request: [#502](https://github.com/gazebosim/gz-rendering/pull/502). E.g. the [current implementation](https://github.com/gazebosim/gz-rendering/pull/502/files) has 'radial' and 'tangential distortion coefficients' but maybe your FOV model needs others?

Hi! I see that gazebo garden is using the Brown Conrady radian distortion model. For my research however, I would need to use the FOV distortion model from "Devernay, F., Faugeras, O. Straight lines have to be straight. Machine Vision and Applications 13, 14–24 (2001). https://doi.org/10.1007/PL00013269".

How would I go about doing that? The implementation location seems fairly straightforward in [gazebo-classic](https://github.com/gazebosim/gazebo-classic/blob/e2436b3a2b32713e2b069f23689b62786273d773/gazebo/rendering/Distortion.cc#L385) but I can't find it in gazebo garden's [ImageBrownDistortionModel.cc](https://github.com/gazebosim/gz-sensors/blob/gz-sensors7/src/ImageBrownDistortionModel.cc) and [BrownDistortionModel.cc](https://github.com/gazebosim/gz-sensors/blob/gz-sensors7/src/BrownDistortionModel.cc).

Help on how to implement this would be much appreciated!
