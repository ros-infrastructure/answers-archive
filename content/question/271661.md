    \ for doing that is to use the odom topic. For that, you can create a simple subscriber\
    \ in Python that gets the data you need, which is, position and orientation respect\
    \ to an starting point. The code for a simple subscriber could be like this:\n\
    \n    #! /usr/bin/env python\n    \n    import rospy\n    from nav_msgs.msg import\
    \ Odometry\n\n    def callback(msg):\n        print msg.pose.pose\n\n    rospy.init_node('check_odometry')\n\
    \    odom_sub = rospy.Subscriber('/odom', Odometry, callback)\n    rospy.spin()\n\
    \nThis code basically subscribes to the odom topic, and prints the pose component\
    \ of the message, which contains the position and orientation values. I've also\
    \ created a video with a quick demonstration, which may be helpful:\nhttps://www.youtube.com/watch?v=kPsrOQrzkaM\n\
