      Based on this [Unity forum discussion](https://forum.unity.com/threads/how-much-easier-would-games-be-to-develop-in-unity-if-it-used-python-instead-of-c.871948/), it's possible but not necessarily easy.  Obviously, it depends on your ability and what you're trying to do, but personally, I think it's better to just learn C# as there are so many tutorials specifically for Unity.  If it's a simple project, there may already be a how-to.  If it's more complicated, trying to do it through an extra interface layer seems like it would just make troubleshooting more difficult.  Long-term, it would be easier to develop and make changes in C#, so why not start learning now? BTW, here's the [Roll-a-ball tutorial](https://www.youtube.com/watch?v=W_fAidYRGzs) I followed when I started with Unity, but note there's a link to an update in its description.  Everyone's different though, so do what's right for you.  You can always switch course later, too.
