    > Below code is from [official wiki](http://wiki.ros.org/rosbag/Code%20API) and clearly explains what needs to be done to get bag data with python. Hope it helps!

        import rosbag
        bag = rosbag.Bag('test.bag')
        for topic, msg, t in bag.read_messages(topics=['chatter', 'numbers']):
            print(msg)
        bag.close()
