    \ that \n\nThe solution there was to make a link for the library to a known lib\
    \ location:\n\n    sudo ln -s /usr/lib/x86_64-linux-gnu/libOpenCV.so.1 /usr/lib/libOpenCV.so\n\
    \nAnother option:\n\nAssuming that **OpenCV** library located in `/usr/lib/x86_64-linux-gnu/`\
    \ you can also add the library folder to the Libraries path:\n\n    export LD_LIBRARY_PATH=\"\
    $LD_LIBRARY_PATH:/usr/lib/x86_64-linux-gnu/\"\n\nYou may need to update the \"\
    **Dynamic Linker**\":\n\n    sudo ldconfig"
