    \ the ROS ARM basic method via cheating the sources.list when installing ROS via:\n\
    \n    sudo sh -c 'echo \"deb http://packages.ros.org/ros/ubuntu bionic main\"\
    \ > /etc/apt/sources.list.d/ros-latest.list'\n\nThis is essentially cheating \"\
    $(lsb_release -sc)\" by replacing with \"bionic\" (for Ubuntu 18.04)."
