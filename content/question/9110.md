  body_markdown: "If you are running the recognizer node from tod_detecting and are\
    \ seeing text output like \n\n     \"Object name = \" << object.objectName <<\
    \ \", imageId = \" << object.imgIdx\nthen that is generated from line 167 of [recognizer.cpp](http://www.ros.org/doc/api/tod_detecting/html/recognizer_8cpp_source.html#l00167).\n\
    \nEach of the ObjectInfo objects referenced there have rvec and tvec members (see\
    \ [this](http://www.ros.org/doc/api/tod_detecting/html/structtod_1_1ObjectInfo.html))\
    \ which presumably store the pose of the object. You could modify that loop to\
    \ print out or otherwise output the pose as well as the name."
