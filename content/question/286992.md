    \ would help you understand what's behind the `param` tag. \n\nTo use your example\
    \ with the `robot_state_publisher` node you can use the param tag because [here](https://github.com/ros/robot_state_publisher/blob/kinetic-devel/src/joint_state_listener.cpp#L58)\
    \ line 58 you define a variable that can be set whitin the launch file using the\
    \ `param` tag and if you don't define it you still have a default value. And you\
    \ can see that there are two others parameters than can be set so this is possible\
    \ too :\n\n\t<node pkg=\"robot_state_publisher\" type=\"robot_state_publisher\"\
    \ name=\"robot_state_publisher\">\n\t\t<param name=\"publish_frequency\" type=\"\
    double\" value=\"30.0\" />\n\t\t<param name=\"use_tf_static\" type=\"bool\" value=\"\
    false\" />\n\t\t<param name=\"ignore_timestamp\" type=\"bool\" value=\"true\"\
    \ />\n\t</node>\n\n\n\n"
