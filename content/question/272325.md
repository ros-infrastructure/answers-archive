    Sounds like the setup of your JointTrajectoryController for Gazebo has too narrow tolerances and/or the PID values for the arm do not allow it to reach the goal position within the specified tolerances. See [the parameters description here](http://wiki.ros.org/joint_trajectory_controller#Parameters) for a description of parameters for the controller.

    A example Gazebo ros control setup for another arm is this one: [default_controllers.yaml](https://github.com/tu-darmstadt-ros-pkg/hector_tracker_gazebo/blob/master/hector_tracker_gazebo_ros_control/config/default_controllers.yaml#L42). Yours should look somewhat similar.
