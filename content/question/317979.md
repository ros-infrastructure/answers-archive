  body_markdown: "You have two ways of doing this :\n\n - By calculations :\n\nYou\
    \ have to define the acceleration you want (well in your case this is a deceleration).\
    \ Taking your example, you want to go from `0.2 m/s` to `0.05 m/s` in `20 seconds`\
    \ meaning you have `dv = -0.15` and `dt = 20`. (`dv = vfinal - vinitial` that's\
    \ why it's negative). Since `a = dv/dt` you know you want a **constant** acceleration\
    \ of `-0.0075 m/s\xB2` (or a deceleration of `0.0075 m/s\xB2`). \n\nNow if you\
    \ integrate the equation of the acceleration and assume the acceleration is **constant**\
    \ you get `v = a * t + K` (`K` is another constant from the integration). You\
    \ know `v(t=0)=0.2` so you have `v = a * 0 + K = 0.2 => K = 0.2.`\nYou also know\
    \ that `a = -0.0075` so that's it you have the linear relationship between velocity\
    \ and time :\n\n    v = -0.0075 * t + 0.2\n\n\n - Another option is to use a `velocity\
    \ smoother` which basically do all those calculations for you. You can set limits\
    \ for the acceleration and velocity. There is a package compatible with the turtlebot\
    \ (with the mobile base `kobuki` to be accurate) : [yocs_velocity_smoother](http://wiki.ros.org/yocs_velocity_smoother).\
    \ You will need to use a launch file with a `nodelet manager` and define a `yaml`\
    \ file to set your parameters and then call the `nodelet`. I can give you a launch\
    \ file example if you want.\n\n\n----------\n\n**Edit :** \n\n> I tried to solve\
    \ by the first way, my\n> issue is in how to find (t,t0) in\n> python with rospy\
    \ because of lacking\n> my experience in ROS\n\nYou will need to save the starting\
    \ time when you start decelerating and then just substract the current time to\
    \ get the value for `t`. It can be done like that :\n\n    #global variable outside\
    \ your callback\n    starting_time = rospy.get_rostime().to_sec()\n    save_time\
    \ = True \n    ...\n    if(save_time == True):\n        save_time = False  #Condition\
    \ only the first time\n        starting_time = rospy.get_rostime().to_sec() #save\
    \ the current time\n    now = rospy.get_rostime().to_sec()\n    t = now - starting_time\
    \           \n    self.twist.linear.x = -0.0075 * t + 0.2\n    self.cmd_vel_pub.publish(self.twist)\n\
    \n\nFor the second method you can go to the wiki I've linked and select the `indigo`\
    \ version, I just saw that there is no documentation for the `melodic` distribution.\
    \ Moreover you can see an example by looking at [standalone.launch](https://github.com/yujinrobot/yujin_ocs/blob/devel/yocs_velocity_smoother/launch/standalone.launch)\
    \ and check the `standalone.yaml` file too. This package allows you to set speed\
    \ limits and acceleration limits so with your example you don't have to change\
    \ your code, just to use the `velocity_smoother_nodelet` and set the parameter\
    \ `accel_lim_v` to `0.0075`.\n\n**Edit 2:**\n\n>I need to recount from zero when\
    \ lost my face\n\nYou just need to reset your flag `save_time` when you don't\
    \ see the face anymore with an else condition for example :\n\n    if(type(faces)\

    \ t + 0.2\n        self.cmd_vel_pub.publish(self.twist)\n    else:\n    \tsave_time\
