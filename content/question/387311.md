  body_markdown: "As the name implies, `fiducial_msgs::FiducialTransformArray` is\
    \ an array (or list).\n\nYou cannot access the field of a single element without\
    \ first indexing into the array.\n\n`h.transforms.fiducial_id` does indeed not\
    \ exist.\n\n`h.transforms[i].fiducial_id`, where `i \u2208 \u2115`, does exist.\
    \ It would mean you're accessing the `fiducial_id` field of the `i`-th element\
    \ in `h.transforms`.\n\nFor a related question (but with `rospy`), see #q359824.\n"
