    \ sensor_msgs.msg.Image and cvbridge instead of the numpy message. OpenCV Mats\

    \ same size every time you publish them, so that gives you a lot of flexibility.\
    \ Here is a sample code for this idea:\n\n    import rospy\n    import numpy as\
    \ np\n    from cv_bridge import CvBridge, CvBridgeError\n    from sensor_msgs.msg\
    \ import Image\n\n    def talker():\n        rospy.init_node('talker', anonymous=True)\n\
    \        mat_pub = rospy.Publisher(\"matrix\", Image, queue_size=1)\n        mybridge\
    \ = CvBridge()\n        rate = rospy.Rate(1) \n\n        mymat = np.ones([1,4],dtype=np.int16\n\
    \n        while not rospy.is_shutdown():\n            try:\n                 mat_pub.publish(mybridge.cv2_to_imgmsg(mymat))\n\
    \                 rate.sleep()\n            except CvBridgeError as e:\n     \
    \            rospy.logerr(e)\n\n    if __name__ == '__main__':\n        try:\n\
    \            talker()\n        except rospy.ROSInterruptException:\n         \

Hi!

I want to publish a custom message including some numpy arrays using python.

I am aware of the numpy_msg and all it's examples, they do however only cover publishing just one array. 

My example message is:

    header 
    int16[] array1 
    int16[] array2

My publisher looks approximatly like this:

    import rospy
    from std_msgs.msg import String
    from test_publisher.msg import test_msg
    from rospy.numpy_msg import numpy_msg
    import numpy as np
    
    
    def talker():
        pub = rospy.Publisher('chatter', numpy_msg(test_msg), queue_size=10)
        rospy.init_node('talker', anonymous=True)
    
        rate = rospy.Rate(1) #
        while not rospy.is_shutdown():
    
            my_msg = test_msg()
            my_msg.array_1 = np.ones([1,4],dtype=np.int16)
            my_msg.array_2 = np.ones([4,4],dtype=np.int16)
    
            pub.publish(my_msg)
            rate.sleep()
    
    if __name__ == '__main__':
        try:
            talker()
        except rospy.ROSInterruptException:
            pass

When i run this code and enable a listener, the following exception occurs:

    rospy.exceptions.ROSSerializationException: field array1 must be a list or tuple type

If i just define one array in the message and directly publish that, it works however.

Can anyone provide me with some insight?
