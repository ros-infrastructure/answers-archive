    Yes. This was apparently changed so that the same URDF can be used in ROS/RViz and Gazebo, and Gazebo apparently fixed this bug recently:

     - https://github.com/ros-visualization/rviz/commit/e4711c55b4aa083494d936b005bfe88a901911a9

     - https://github.com/ros-visualization/rviz/commit/b913d973a1c60cb038d9d9cb0fc269d57579d3de
