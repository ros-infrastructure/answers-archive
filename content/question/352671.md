    Observation: `MultiThreadedSpinner` does not deal with threads you create. It will internally use multiple threads to service the callback queues associated with `Publisher`s and `Subscriber`s, but all of that is invisible to user-level code.

    Also: you typically don't create spinners yourself in nodelets. That's all taken care of for you by the manager (which you already refer to).

    It would be good to show code as we can then see whether you are doing something unsupported.
