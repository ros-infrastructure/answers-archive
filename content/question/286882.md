  body_markdown: "Just tried myself, this is the short version of how I reproduced\
    \ the setup.\n\nMake sure all dependencies are there:\n\n    sudo apt-get install\
    \ ros-kinetic-hector-gazebo ros-kinetic-gazebo-plugins ros-kinetic-gazebo-ros-control\
    \ ros-kinetic-hector-models ros-kinetic-geographic-msgs ros-kinetic-joy\n\nMake\
    \ sure there is no workspace setup sourced from your .bashrc file or so (e.g.\
    \ `env | grep ROS` should give a empty response when executed in the terminal\
    \ where you run the commands below). Then run:\n\n    cd~\n    mkdir hector_quad\n\
    \    cd hector_quad\n    source /opt/ros/kinetic/setup.bash\n    catkin init\n\
    \    mkdir src\n    cd src\n    git clone https://github.com/tu-darmstadt-ros-pkg/hector_localization.git\n\
    \    git clone https://github.com/tu-darmstadt-ros-pkg/hector_quadrotor.git\n\
    \    cd ..\n    catkin build -DCMAKE_BUILD_TYPE=Release\n    source devel/setup.bash\n\
    \    roslaunch hector_quadrotor_demo outdoor_flight_gazebo.launch \n\nThis makes\
    \ the outdoor demo run for me. The fact that the gazebo ui crashes suggests that\
    \ we are probably looking at a graphics card related issue.\n\n\nTo test if the\
    \ issue is related to gazebo itself, you can run it standalone (note you need\
    \ to do `source devel/setup.bash` for every terminal if you haven't added it the\
    \ `.bashrc` file):\n\n    roslaunch gazebo_ros empty_world.launch\n\nIf that also\
    \ crashes, this is an issue between your computer (most likely graphics driver)\
    \ and gazebo. If it works, you can spawn a quadrotor into the world:\n\n    roslaunch\
    \ hector_quadrotor_gazebo spawn_quadrotor.launch\n\n Note you can edit your original\
    \ question or post comments to this answer, please do not post an answer in reply\
    \ to this one yourself.\n\n"
