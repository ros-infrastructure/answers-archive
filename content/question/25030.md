    Hey, @Ismaiel welcome to the forum. As can be seen in this [issue](https://github.com/ros-industrial/universal_robot/issues/412) this error is probably caused because the `~/.ignition/fuel/config.yaml` file still points to the old ignition fuel domain. This error can be solved by replacing `url: https://api.ignitionfuel.org` by `url: https://api.ignitionrobotics.org` inside the `~/.ignition/fuel/config.yaml` file.
