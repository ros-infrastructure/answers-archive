  body_markdown: "I use the following api from the robotino: [here](https://doc.openrobotino.org/download/RobotinoAPI2/rec_robotino_api2/classrec_1_1robotino_1_1api2_1_1_gyroscope.html)\n\
    \nAlso i write my own header and my own cpp-File and include it on the robotino_node\n\
    \n    #include \"GyroROS.h\"\n\n    GyroROS::GyroROS()\n    {\n       gyroscope_pub_\
    \ = nh_.advertise<sensor_msgs::Imu>(\"gyroscope\",1, true);\n    }\n\n    GyroROS::~GyroROS()\n\
    \    {\n        gyroscope_pub_.shutdown();\n    }\n\n    void GyroROS::setTimeStamp(ros::Time\
    \ stamp)\n    {\n        stamp_ = stamp;\n    }\n\n    void GyroROS::gyroscopeEvent(float\
    \ angle, float anglevel)\n    {\n    \n        XAngle = 0.0;\n        YAngle =\
    \ 0.0;\n        ZAngle = angle;\n\n        quat = Eigen::AngleAxisf(XAngle, Eigen::Vector3f::UnitX())\n\
    \               * Eigen::AngleAxisf(YAngle, Eigen::Vector3f::UnitY())\n      \
    \         * Eigen::AngleAxisf(ZAngle, Eigen::Vector3f::UnitZ());\n    \n     \
    \  gyro_msg_.orientation.x = quat.x();\n       gyro_msg_.orientation.y = quat.y();\n\
    \       gyro_msg_.orientation.z = quat.z();\n       gyro_msg_.orientation.w =\
    \ quat.w();\n\n       gyro_msg_.angular_velocity.z = -anglevel;\n       gyro_msg_.header.stamp\
    \ = stamp_;\n       gyro_msg_.header.frame_id = \"base_link\";\n    \n       //\
    \ Covariance Matrix in Orientation\n       gyro_msg_.orientation_covariance[0]\
    \ = 0.0;\n       gyro_msg_.orientation_covariance[4] = 0.0;\n       gyro_msg_.orientation_covariance[8]\
    \ = 0.0;\n\n       // Covariance Matrix in Angule Velocity\n       gyro_msg_.angular_velocity_covariance[0]\
    \ = 0.0;\n       gyro_msg_.angular_velocity_covariance[4] = 0.0;\n       gyro_msg_.angular_velocity_covariance[8]\
    \ = 0.0;\n\n       gyroscope_pub_.publish(gyro_msg_);\n    }\n\n\n\n\n"
