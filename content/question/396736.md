    gazebo is complaining that the urdf/xacro files are missing information that is required. It may be that this git repo was developed for an older version of ROS (and older version of gazebo.) The files are from June 2020, so it was likely developed for melodic.

    In that git repo, the files are probably the ones in directory `skbot/skbot_description/urdf/`. To use noetic, you need to update the .urdf / .xacro files with the additional `<inertial>` xml tag that it wants to see.

    Update: Yes, the pdf says it is a melodic ros package.
