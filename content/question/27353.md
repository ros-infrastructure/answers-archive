  body_markdown: "I found the way to insert them inside Citadel. \nSince there is\
    \ no official plugin for ultrasonic or infrared sensor. I will be more than happy\
    \ to share on here for anyone in future! \n\n**Ultrasonic:**\nThis is being used\
    \ as in lidar. It is included the setting of ultrasonic. Here is what I wrote:\n\
    \n      <sensor name='gpu_lidar' type='gpu_lidar'>\n          <always_on>1</always_on>\n\
    \          <visualize>true</visualize>\n          <topic>ultrasonic</topic>\n\
    \          <update_rate>10</update_rate>\n          <lidar>\n              <scan>\n\
    \                  <vertical>\n                    <samples>5</samples>\n    \
    \                <resolution>1</resolution>\n                    <min_angle>0.00</min_angle>\n\
    \                    <max_angle>0.25</max_angle>\n                  </vertical>\n\
    \              </scan>\n          <range>\n            <min>0.120000</min>\n \
    \           <max>4</max>\n            <resolution>0.015000</resolution>\n    \
    \      </range>\n          <noise>\n            <type>gaussian</type>\n      \
    \      <mean>0.0</mean>\n            <stddev>0.01</stddev>\n          </noise>\n\
    \        </lidar>\n\nWhich this will results as one \"cone\" acting like ultrasonic.\n\
    \nUse sensor_msgs/msg/range to get the range in ros2 foxy (i don't know about\
    \ ros1 since I joined ros2 only)\n\n**Infrared sensor:**\nThis is one of the most\
    \ fun challenge ever I had! \nSince there is no official plugin for infrared sensor,\
    \ I used the alternative plugin called Depth camera which is display on [github](https://github.com/ignitionrobotics/ros_ign/tree/foxy/ros_ign_gazebo_demos)\n\
    \nSince depth camera code in sdf is a little too long. Here is the code in github!\
    \ It's open source as well! Feel free to explore as well since there will be a\
    \ lot of documents involves Foxy (ros2) and Citadel (LTS atm) \n\nI'm going to\
    \ mark this as my official answer since it solved my issue.\n\n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/1631903367484753.png)\n\
