    Hi, I created a demo trying to solve this question.
    I created a World plugin for Gazebo that launches particles in a desired direction. You just have to add it to your worls with the number of particle models you want to be and that's quite it.

    Here a Leave a [Video](https://youtu.be/etCTIAa7NYI) explaining a bit all the code

    Here I leave you the [ROSJECT](https://goo.gl/8ki7iT)

    Here the [Git](https://bitbucket.org/theconstructcore/particle_shooter/src/master/) with the code

    And here I leave the main cpp file that makes everything work. It essentially we reset the positions of the particles ( particles are considered any model with the name particle in it )  in the world and then apply a force in the desired direction. All the particles have their gravity disconnected.

    [particle_shooter_plugin.cpp](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/15410010288511598.cpp)

    [particle_shooter.world](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/15410010488133026.world)
