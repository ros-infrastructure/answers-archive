So now I add header includes, for example

    #include "HardwareSerial.h"

But the appropriate .cpp file cannot  be viewed by compiler automatically.
So I write the following in my CMakeLists.txt

    add_library(hardwareserial src/HardwareSerial.cpp)
    target_link_libraries(talker ${catkin_LIBRARIES} hardwareserial)

And it works.
