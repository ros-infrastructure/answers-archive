  body_markdown: "The beautiful soup package can be downloaded by the following:\n\
    \n    sudo apt-get install python-beautifulsoup\n\nThis should not require any\
    \ additional updates to the PYTHONPATH variable.  It should just work from here.\n\
    \nAs an aside, the universal robot package is also available for groovy using:\n\
    \n    sudo apt-get install ros-groovy-universal-robot \n\nBy downloading the package\
    \ using sudo apt-get, the dependencies like Beautiful Soup should be taken care\
    \ of.  However, there are some features in the github groovy version that are\
    \ not in the debian version."
