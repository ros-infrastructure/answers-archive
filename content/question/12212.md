     The problem is on this line:

        gazebo::math::Pose pose = this->model->gazebo::physics::ModelState::GetPose();

    The `ModelState` class is different from the `Model` class.

    You probably want to use [this->model->GetWorldPose()](http://osrf-distributions.s3.amazonaws.com/gazebo/api/6.1.0/classgazebo_1_1physics_1_1Entity.html#a074b74720ca1f35c057cf30260313a94)

    \    gazebo::math::Pose pose;     \n    pose = this->model->GetWorldPose();\n\
    \    math::Vector3 v(0, 0, 0);\n    v = pose.pos;\n    x = v.x; // x coordinate\n\
    \    y = v.y; // y coordinate\n    z = v.z; // z coordinate"
