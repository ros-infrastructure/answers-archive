  body_markdown: "You have to set publishWheelTF and publishWheelJointState tags to\
    \ true inside differential drive controller, \nlike this \n\n`<publishWheelTF>true</publishWheelTF>`\n\
    \n    <publishWheelJointState>true</publishWheelJointState>.\n\n For more information\
    \ you can go through  [gazebo__ros__diff__drive_8cpp_source.](http://docs.ros.org/indigo/api/gazebo_plugins/html/gazebo__ros__diff__drive_8cpp_source.html).\n\
    After adding this, check whether odom is publishing properly using rviz."
