    Open the file in SolidWorks and export to URDF using [this](http://wiki.ros.org/sw_urdf_exporter) plug-in. This URDF file can be read in Gazebo. You can find the details and procedure in following links

    You can either make your stl part of a SDF (Gazebo) model or of a URDF model. The first method is fully independent of ROS and [described here on gazebosim.org](http://gazebosim.org/tutorials?tut=build_model&cat=build_robot).

    An example for spawning a stl via a URDF model is [here](https://github.com/tu-darmstadt-ros-pkg/environment_models). The `urdf`  folder contains the model (which is referencing a stl file in the `Media` folder) and the `launch` folder contains launch files for spawning the model into a Gazebo scene.
