  body_markdown: "Building from Source for ROS2 on Windows:\nReference tutorial: https://docs.ros.org/en/foxy/Tutorials/Colcon-Tutorial.html\n\
    \nCreate workspace, source and build\n\n    md \\dev\\ros2_example_ws\\src\n \
    \   \n    cd \\dev\\ros2_example_ws\n    \n    git clone <repo-address>\n    \n\
    \    colcon build --symlink-install --merge-install\n\n\nTo source environment\
    \ back:\n\n    call install\\setup.bat\n\n**Warning**: Not everything will compile\
    \ as some libraries were written for Linux environment but if you run into those\
