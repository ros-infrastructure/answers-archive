 The default image type is 32FC1.  How to export the image to CV image type? After change the format to 8UC1 and 16 UC1. The result is the same

![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/15985961994672504.jpg)

Here is the code:

count = 0;
def callback(ros_image):
    bridge = CvBridge()
    cv_image = bridge.imgmsg_to_cv2(ros_image, '8UC1')
    global count
    count = count +1
    img_title = "image"+str(count)+".jpg"
    cv2.imwrite(img_title, cv_image)
