    Update
    ----

    It is possible to install and use ROS Lunar on Windows 10 thanks to WSL:
    http://wiki.ros.org/Installation/Windows

    This is the best way to use ROS on Windows right now, though it is not perfect.

    -----

    The [Windows installation page](http://www.ros.org/wiki/diamondback/Installation/Windows) links to useful information regarding ROS on Windows. Please be aware that ROS on Windows is still very experimental. If you want the full "ROS experience", you should consider installing Linux.
