  body_markdown: "I don't think it's possible to print text directly form the roslaunch\
    \ xml (w/o passing it into a node as a param / arg).\n\n**Best solution** would\
    \ be to put\n\n    print(\"Please keep this running in a separate tab.\")\n  \
    \  \n**in your node script.**\n\n----------\n\nIn your *.launch script, if you\
    \ set the [node's output attribute to \"screen\"](http://wiki.ros.org/roslaunch/XML/node),\
    \ the message will be printed to the terminal window.\n\n\n    <node name=\"PrintToScreenNode_1\"\
    \ pkg=\"my_package\" type=\"print_to_screen.py\" output=\"screen\"/>\n\n----------\n\
    Note: You can also start your nodes in their own separate terminal windows using\
    \ the [launch-prefix attribute](http://wiki.ros.org/roslaunch/XML/node).\n\n\n\
    \    <node name=\"PrintToScreenNode_2\" pkg=\"my_package\" type=\"print_to_screen.py\"\
    \ output=\"screen\" launch-prefix=\"xterm -e\"/>\n\n----------\nEDIT:\n\nHere's\
    \ an example script that just prints to the terminal:\n\n    #!/usr/bin/env python\n\
    \    # -*- coding: utf-8 -*-\n    \n    '''\n    # Name: print_to_screen.py\n\
    \    # Author: Joseph Coombe\n    '''\n    \n    # Uncomment lines 10, 13, 15\
    \ if you're running this node in its own separate\n    # terminal window. Otherwise\
    \ the script will immediately exit and its terminal window will close.\n    #import\
    \ rospy\n    \n    def main():\n        #rospy.init_node('print_to_screen', anonymous=True)\n\
    \        print(\"Please keep this running in a separate tab.\")\n        #rospy.spin()\n\
    \    \n    if __name__ == '__main__':\n        main()\n\nYou'll want to un-comment\
    \ the `rospy` lines if you're launching this script in its own terminal (by using\
    \ the launch-prefix attribute in your *.launch file). Otherwise, it'll immediately\
    \ exit and close its terminal window (and as a result nobody will see the message)."

  body_markdown: |-
    rostopic echo:

        <?xml version="1.0"?>
        <launch>
          <arg name="msg" default="Please keep this running in a separate tab." />
          <node name="pub_text" pkg="rostopic" type="rostopic"
             args="pub /msg std_msgs/String '$(arg msg)'"
             output="screen" />
          <node name="print_text" pkg="rostopic" type="rostopic"
             args="echo /msg" output="screen" />

    yields:

        data: Please keep this running in a separate tab.

    Though maybe the `data:` is undesirable

    Adding a -p to the echo yields:

        %time,field.data
        1510939080429253101,Please keep this running in a separate tab.
