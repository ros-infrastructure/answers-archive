  body_markdown: "You probably installed `cv2` via `pip`, which does not contain any\
    \ non-free modules.\n\nThis topic is discussed there: \n\nhttps://stackoverflow.com/questions/37039224/attributeerror-module-object-has-no-attribute-xfeatures2d-python-opencv-2\n\
    \nPeople propose the use of:\n\n> - Uninstall:\n> \n> `pip3 uninstall opencv-contrib-python`\n\
    > \n> `pip3 uninstall opencv-python`\n> \n> - And then install:\n> \n> `pip3 install\
    \ opencv-contrib-python`\n> \n> `pip3 install opencv-python`"
