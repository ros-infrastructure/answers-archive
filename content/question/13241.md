    You could add a texture with a dot to your cube. For Gazebo's default box geometry, the texture will be repeated for every face though. See [this](https://bitbucket.org/osrf/gazebo_models/pull-requests/199/simple-shapes-with-texture-to-be-given-as/diff) pull request for an example.

    If you want the dot to be on only one face, you'll need to use a COLLADA mesh with UV coordinates mapping, similar to [this](https://bitbucket.org/osrf/gazebo_models/src/d583e3a80162c1464ed3cdd31148d10cd9e583db/endpad/?at=aero_testing_john) model.
