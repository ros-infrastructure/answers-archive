    The hokuyo_node is not started in the launch files, as the LIDAR configuration is highly dependent on the specific setup (which LIDAR, which serial port etc.). By default, most examples use the "/scan" topic for the LIDAR, which also happens to be the default setting for hokuyo_node, so no special treatment is required. Note that you'll have to supply the necessary tf transforms as described [here](http://www.ros.org/wiki/hector_slam/Tutorials/SettingUpForYourRobot).
