    This is more a Python problem than anything else, but:

    >     self.msg = MultiDOFJointTrajectory()
        [..]
        self.msg.points(i) = p

    From the documentation on `MultiDOFJointTrajectory` ([here](http://docs.ros.org/melodic/api/trajectory_msgs/html/msg/MultiDOFJointTrajectory.html)) we see that `points` is an unbounded list of [trajectory_msgs/MultiDOFJointTrajectoryPoint](http://docs.ros.org/melodic/api/trajectory_msgs/html/msg/MultiDOFJointTrajectoryPoint.html) instances.

    Those are lists in Python as well, so you'll need to use the regular ways to interact with `list` types in Python, such as `[]` and `append(..)`, `insert(..)`, etc.

    In this case you'll probably want to use `append(..)`:

        self.msg.points.append(p)
