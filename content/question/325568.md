  body_markdown: "You need to run that command from the root of your *workspace*,\
    \ not from the root of your *package*. In other words, `cd` to the root of your\
    \ workspace and run that command:\n\n    cd ~/catkin_ws\n    catkin_make\n\n\n\
    ----------\nUpdate:\n\nThe part of that tutorial that says\n\n    $ cd ~/catkin_ws/src/turtlesim_cleaner\
    \ \n    $ mkdir src \n    $ catkin_make\n\nis incorrect. You should [only call\
    \ `catkin_make` from the root of your workspace](https://wiki.ros.org/catkin/commands/catkin_make#Usage).\
    \ I've updated the tutorial. What it should (and does now) read is\n\n    $ cd\
    \ ~/catkin_ws/src/turtlesim_cleaner\n    $ mkdir src\n    $ cd ~/catkin_ws\n \
    \   $ catkin_make"
