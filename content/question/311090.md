    The most recent source version of STOMP can now plan to [cartesian goals](https://github.com/ros-industrial/industrial_moveit/pull/46) so feel free to try that out, report any issues in github if you encounter any. STOMP was only able to take joint goals and so you had to use IK to convert your cartesian goal request into a joint one.
