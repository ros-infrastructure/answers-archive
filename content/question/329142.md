  body_markdown: "The problem is that the \"sync\" dataset doesn't have exactly the\
    \ same stamps for left and right images. You may copy the stamps from one timestamps.txt\
    \ to all others so that the image/camera_info contained in the generated bag have\
    \ the same stamps (if so, use  `approx_sync:=false` and  `approx_rgbd_sync:=false`\
    \ in examples below). Otherwise, we should set `approx_sync` to true. I recommend\
    \ to use `rtabmap.launch` directly. Example for stereo:\n\n    $ roslaunch rtabmap_ros\
    \ rtabmap.launch \\\n       stereo:=\"true\" \\\n       left_image_topic:=/kitti/camera_color_left/image_raw\
    \ \\\n       right_image_topic:=/kitti/camera_color_right/image_raw \\\n     \
    \  left_camera_info_topic:=/kitti/camera_color_left/camera_info \\\n       right_camera_info_topic:=/kitti/camera_color_right/camera_info\
    \ \\\n       rtabmap_args:=\"--delete_db_on_start --Grid/CellSize 0.3 --Grid/ClusterRadius\
    \ 1\" \\\n       approx_sync:=true \\\n       use_sim_time:=true\\\n       frame_id:=base_link\n\
    \    \n    $ rosbag play --clock kitti_2011_09_26_drive_0001_synced.bag\n\n![image\
    \ description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/15639111239135527.png)\n\
    \n**Velodyne**: you can also record the velodyne clouds at the same time:\n\n\
    \    $ roslaunch rtabmap_ros rtabmap.launch \\\n       stereo:=\"true\" \\\n \
    \      left_image_topic:=/kitti/camera_color_left/image_raw \\\n       right_image_topic:=/kitti/camera_color_right/image_raw\
    \ \\\n       left_camera_info_topic:=/kitti/camera_color_left/camera_info \\\n\
    \       right_camera_info_topic:=/kitti/camera_color_right/camera_info \\\n  \
    \     rtabmap_args:=\"--delete_db_on_start --Grid/CellSize 0.3 --Grid/ClusterRadius\
    \ 1\" \\\n       approx_sync:=true \\\n       use_sim_time:=true \\\n       frame_id:=base_link\
    \ \\\n       rgbd_sync:=true \\\n       approx_rgbd_sync:=true \\\n       subscribe_scan_cloud:=true\
    \ \\\n       scan_cloud_topic:=/kitti/velo/pointcloud\n\n    $ rosbag play --clock\
    \ kitti_2011_09_26_drive_0001_synced.bag\n\n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/15639112258983683.png)\n\
    \n**IMU, Ground truth and GPS**\nFirst we need to modify TF `/world -> /base_link`\
    \ in the bag to `/world -> /base_link_gt`. This can be done with a script like\
    \ this (called `filterTF.py`):\n\n    import rosbag\n    from tf.msg import tfMessage\n\
    \    with rosbag.Bag('kitti_2011_09_26_drive_0001_synced_out.bag', 'w') as outbag:\n\
    \    \tfor topic, msg, t in rosbag.Bag('kitti_2011_09_26_drive_0001_synced.bag').read_messages():\n\
    \    \t\tif topic == \"/tf\" and msg.transforms:\n    \t\t\tnewList = [];\n  \
    \  \t\t\tfor m in msg.transforms:\n    \t\t\t\tif m.header.frame_id == \"world\"\
    :\n    \t\t\t\t\tm.child_frame_id = \"base_link_gt\"\n    \t\t\t\tnewList.append(m)\n\
    \    \t\t\tif len(newList)>0:\n    \t\t\t\tmsg.transforms = newList\n    \t\t\t\
    \toutbag.write(topic, msg, t)\n    \t\telse:\n    \t\t\toutbag.write(topic, msg,\
    \ t)\n\nThen:\n\n    $ python filterTF.py\n\n    $ roslaunch rtabmap_ros rtabmap.launch\
    \ \\\n       stereo:=\"true\" \\\n       left_image_topic:=/kitti/camera_color_left/image_raw\
    \ \\\n       right_image_topic:=/kitti/camera_color_right/image_raw \\\n     \
    \  left_camera_info_topic:=/kitti/camera_color_left/camera_info \\\n       right_camera_info_topic:=/kitti/camera_color_right/camera_info\
    \ \\\n       rtabmap_args:=\"--delete_db_on_start --Grid/CellSize 0.3 --Grid/ClusterRadius\
    \ 1 --Optimizer/GravitySigma 0.3\" \\\n       approx_sync:=true \\\n       use_sim_time:=true\
    \ \\\n       frame_id:=base_link \\\n       rgbd_sync:=false \\\n       approx_rgbd_sync:=false\
    \ \\\n       subscribe_scan_cloud:=true \\\n       scan_cloud_topic:=/kitti/velo/pointcloud\
    \ \\\n       imu_topic:=/kitti/oxts/imu \\\n       gps_topic:=/kitti/oxts/gps/fix\
    \ \\\n       wait_imu_to_init:=true \\\n       ground_truth_frame_id:=world \\\
    \n       ground_truth_base_frame_id:=base_link_gt\n\n    $ rosbag play --clock\
    \ kitti_2011_09_26_drive_0001_synced_out.bag\n\n\ncheers,<br/>\nMathieu"
