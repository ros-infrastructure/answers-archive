  body_markdown: "Solution I got:\n\nCreate a file named cyclonedds.xml in your present\
    \ working directory.\nAdd the following lines in file.\n\nThis is for Host Computer:\n\
    \n    <CycloneDDS>\n  \n     <Domain>\n\n     <General>\n\n\t  <NetworkInterfaceAddress>wlo1</NetworkInterfaceAddress>\n\
    \n        <DontRoute>true</DontRoute>\n\n    </General>\n\n    </Domain>\n\n \
    \   </CycloneDDS>\n\n\nThis is for Raspberry Pi:\n\n\n    <CycloneDDS>\n\n   \
    \  <Domain>\n\n     <General>\n\n\t  <NetworkInterfaceAddress>wlan0</NetworkInterfaceAddress>\n\
    \n        <DontRoute>true</DontRoute>\n\n    </General>\n\n     </Domain>\n\n\
    \    </CycloneDDS>\n\n\n\n\nUse iwconfig to find your NetworkInterfaceAddress\
    \ for both raspberry pi and host computer.\n\n\nOpen .bashrc file by\n\n    gedit\
    \ .bashrc\n\n\nAdd the following two lines somewhere else( Don\u2019t put last)\n\
    \n\texport RMW_IMPLEMENTATION=rmw_cyclonedds_cpp\n    export CYCLONEDDS_URI=cyclonedds.xml\n\
    \n\t\n\t\nNow enter the following in terminal\n\n\tros daemon stop\n\n\tsource\
    \ .bashrc\n\n\tros daemon start\n\n\nNow everything set, you are ready to go.\
    \ Do this in both raspberrypi and host computer."
