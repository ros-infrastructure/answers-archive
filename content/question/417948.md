    \ that the doc build is using [Exhale](https://exhale.readthedocs.io/en/latest/).\n\
    \nThere's a design doc here that discusses the requirements for the build tool:\n\
    \nhttp://design.ros2.org/articles/per_package_documentation.html#documentation-system\n\
    \n> All packages will need a Sphinx configuration file. If a package doesn\u2019\
    t have one, the tool can use a default one. Python packages will need Sphinx directives\
    \ explicitly integrated into the source code to produce API documentation (standard\
    \ for Sphinx API documentation).\n\nwhich I think is `rosdoc2`:\n\nhttps://github.com/ros-infrastructure/rosdoc2#set-up-a-ros-2-package-to-be-used-with-this-tool\n\
    \n> It aims to support two main cases:\n\n> - zero configuration generation of\
    \ C++ and Python API documents with a landing page for simple packages\n- custom\
    \ Doxyfile (for C++) and Sphinx conf.py file for more extensively configured documentation\n\
    \n> The goal for the first case is to allow almost no configuration in packages\
    \ while still providing some useful documentation, even if there is no Doxyfile,\
    \ Sphinx conf.py file, or any free form documentation.\n\nSo it looks like you\
    \ can add a `conf.py` if you wish, but you don't need to."

### Question

I accessed [the latest rclcpp documentation](http://docs.ros.org/en/humble/p/rclcpp/) through the link in the README of the [ros2/rclcpp](https://github.com/ros2/rclcpp) repository and found that it was built by Sphinx. Based on my understanding:

* If a documentation is built by [Sphinx](https://github.com/sphinx-doc/sphinx), there should be a `conf.py` configuration file in its repository.
* If a documentation is built by [Doxygen](https://github.com/doxygen/doxygen), there should be a `Doxyfile` configuration file in its repository.
* If a documentation needs to extract content from Doxygen and input it into Sphinx documentation, the Python package [Breathe](https://github.com/breathe-doc/breathe) would be required.

However, I only see the `Doxyfile` in the ros2/rclcpp repository, and I do not find the `conf.py` file. How does rclcpp convert its documentation from Doxygen to Sphinx?
