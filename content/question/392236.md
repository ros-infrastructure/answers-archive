  body_markdown: "After some digging, removing `m.lib` from LINK_LIBRARIES  located\
    \ in the `build.ninja` file in the `build` folder fixed the problem, and I was\
    \ able to compile successfully.\n\n    #############################################\n\
    \    # Link the executable C:\\ivcon_ws\\devel\\lib\\ivcon\\ivcon.exe\n    \n\
    \    build C$:\\ivcon_ws\\devel\\lib\\ivcon\\ivcon.exe: C_EXECUTABLE_LINKER__ivcon_RelWithDebInfo\
    \ ivcon\\CMakeFiles\\ivcon.dir\\src\\ivcon.c.obj\n      FLAGS = /DWIN32 /D_WINDOWS\
    \ /W3 /MD /Zi /O2 /Ob1 /DNDEBUG\n      LINK_FLAGS = /machine:x64 /debug /INCREMENTAL\
    \ /subsystem:console\n      LINK_LIBRARIES = kernel32.lib user32.lib gdi32.lib\
    \ winspool.lib shell32.lib ole32.lib oleaut32.lib uuid.lib comdlg32.lib advapi32.lib\n\
    \      OBJECT_DIR = ivcon\\CMakeFiles\\ivcon.dir\n      POST_BUILD = cd .\n  \
    \    PRE_LINK = cd .\n      TARGET_COMPILE_PDB = ivcon\\CMakeFiles\\ivcon.dir\\\
    \n      TARGET_FILE = C:\\ivcon_ws\\devel\\lib\\ivcon\\ivcon.exe\n      TARGET_IMPLIB\
    \ = C:\\ivcon_ws\\devel\\lib\\ivcon.lib\n      TARGET_PDB = C:\\ivcon_ws\\devel\\\
    lib\\ivcon\\ivcon.pdb"

 I am trying to compile the old PR2 libraries to run on ROS on Windows 10 with Visual Studio 19.

One of the dependencies `ivcon` fails to compile giving the following error:

`LINK : fatal error LNK1104: cannot open file 'm.lib`

I searched for an answer and I understand the main issue is one of C programs calling for `m.lib` that is not present.
I tried to replace the library named 'msvcrt' with m as suggested: https://stackoverflow.com/questions/36121570 but it didn't work.

Appreciate to get any advise on how to solve this issue. Thank you in advance.
