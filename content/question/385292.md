  body_markdown: "Add prefix command to your node declaration in file. \n\n    node\
    \ = Node(\n        package='planning',\n        executable='planner_server',\n\
    \        name='planner_server_rclcpp_node',\n        namespace='',\n        output='screen',\n\
    \        prefix=['xterm -e gdb -ex run --args'],\n        parameters=[params],\n\
    \    )\n\nThis will start your node in gdb in a seperate `xterm` Terminal. So\
    \ you need have that installed with `sudo apt install xterm`."
