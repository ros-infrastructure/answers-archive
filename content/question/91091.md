     1. Decaying in RViz should look just like it was correct moments before. Read about *tf and time* in [tf tutorials](http://wiki.ros.org/tf/Tutorials/), assuming you read the general tf docs.

     2. *I sometimes stumble upon, but now cannot find, that usually you are not allowed to modify a message that you gave to a publisher. But if your tf tree is clean, it's ok.*

     3. [gmapping](http://wiki.ros.org/gmapping) publishes only `/map -> /odom`. What you need is `/base_link -> /hokuyo..`, that could be done manually in code, by [robot_state_publisher](http://wiki.ros.org/robot_state_publisher) or [static_transform_publisher](http://wiki.ros.org/tf#static_transform_publisher).

    But as RViz does display the scan, that transform must exist. EXCEPT you set the base frame in RViz to `/hokuyo..`, then it obviously would yield that result, as the RViz-View does rotate with the laserscanner!
