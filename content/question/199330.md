    There is a [rosdep key for bullet](https://github.com/ros/rosdistro/blob/985704f77fcafae41ba02d1b70fbebfc5779cc20/rosdep/base.yaml#L329-L343) which is defined on Precise. You should be able to resolve it if you run `rosdep update`.

    That said, it looks like the packaged version of bullet on 12.04 is version 2.8, which isn't the version you want. In that case, you should probably just remove the dependency on bullet from your manifest.xml altogether.
