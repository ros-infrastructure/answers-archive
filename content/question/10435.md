    \ xM running Ubuntu 11.04 from Source  \nThis is a work in progress and is only\
    \ meant to supplement the existing TurtleBot tutorials.   \n\n## Install Ubuntu\
    \ packages on BeagleBoard xM\nsudo apt-get install build-essential python-yaml\
    \ cmake subversion wget python-setuptools mercurial\n\n## Install rosinstall\n\
    sudo easy_install -U rosinstall\n\n## Install ROS diamondback variant turtlebot-robot:\n\
    rosinstall ~/ros \"http://packages.ros.org/cgi-bin/gen_rosinstall.py?rosdistro=diamondback&variant=turtlebot-robot&overlay=no\"\
    \n\n## Set up your environment.\necho \"source ~/ros/setup.bash\" >> ~/.bashrc\n\
    \n## Use rosmake to build the various ROS and TurtleBot packages:\nI am still\
    \ working on the best way the make all the necessary packages.\n\n## You may want\
    \ to install the following Ubuntu packages in advance:\nsudo apt-get install python-serial\
    \ libglut3-dev libcppunit-dev graphviz libxext-dev python-sip-dev libcurl4-openssl-dev\
    \ unzip libxml2-dev python-wxgtk2.8 libqhull-dev libhdf5-serial-dev joystick libusb-1.0-0-dev\
    \ flex autoconf libusb-dev automake bluez bison python-bluez libgtk2.0-dev libbluetooth-dev\n\
    \n## Missing packages from Ubuntu natty arm repositories:\nThe openni-dev, ps-engine\
    \ (I'm sure that there are others) packages are not currently available from Ubuntu\
    \ natty arm repositories. Without these packages the Kinect does not work but\
    \ you can drive the TurtleBot around using the keyboard or joystick."
