  body_markdown: "`rossrv` offers exactly the same sub-commands as `rosmsg`. See [its\
    \ wiki](http://wiki.ros.org/rosmsg#rossrv).\n\nFor your particular case,\n\n \
    \   $ rossrv \n    list      md5       package   packages  show      \n    $ rossrv\
    \ show turtlesim/TeleportAbsolute\n    float32 x\n    float32 y\n    float32 theta\n\
    \    ---\n\nOr without package name:\n\n    $ rossrv show TeleportAbsolute   \
    \                                                                            \
    \                                                                            \
    \ \n    [turtlesim/TeleportAbsolute]:\n    float32 x\n    float32 y\n    float32\
    \ theta\n    ---\n    \n"
