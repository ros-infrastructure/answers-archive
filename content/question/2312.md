The Gazebo model caching process leaves the files
<pre>
/tmp/gz_model.tar
/tmp/gz_model.tar.gz
</pre>
in /tmp. This blocks subsequent users from downloading more models automatically from your library. The files are write protected so administrative priveleges are needed to get rid of them.
It would be nice if the model download process deleted these files.
