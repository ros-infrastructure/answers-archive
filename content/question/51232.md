  body_markdown: "As the error states, a frequent cause is that you have an old version\
    \ of rosinstall in /usr/local/lib, as well as a newer version somewhere.\n\nAnother\
    \ source is when you have updated rosinstall, but not vcstools.\n\nSo first try\
    \ to update rosinstall and vcstools:\n\n    $ sudo apt-get update python-rosinstall\
    \ python-vcstools\n\nIf that works, all is well. Else on Ubuntu, you can do \n\
    \n    $ sudo rm -rf /usr/local/lib/python2.7/dist-packages/rosinstall*\n    $\
    \ sudo rm -rf /usr/local/lib/python2.7/dist-packages/vcstools*\n    $ sudo rm\
    \ -rf /usr/local/bin/rosws /usr/local/bin/roslocate /usr/local/bin/rosinstall\
    \ /usr/local/bin/rosco\n\nThis might be \"python2.6\" instead of \"python2.7\"\
    \ on some systems.\n\nIf you never had them installed via apt-get, do so:\n\n\
    \    $ sudo apt-get install python-rosinstall python-vcstools\n\nEDIT: Please\
    \ comment on my question what caused this for you if you find out, it can help\
    \ us improve the support."
