    There was a typo in the tutorial; thank you for catching it! There should be no space between Const and WorldStatisticsPtr, so line 15 should actually be:

    void printMsg(ConstWorldStatisticsPtr &_msg)

    Also, you can't use the 'this' keyword from a main function. I suggest you try integrating this code with one of the [example plugins](https://bitbucket.org/osrf/gazebo/src/dd23b2695e3a8d8539b4f48ae35cad6801c775b8/examples/plugins/custom_messages?at=default).
