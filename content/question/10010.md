  body_markdown: "**UPDATE: This has been deprecated and is officially documented\
    \ at: http://wiki.ros.org/Mirrors on the wiki.**\n\n\nA dump of the wiki and api\
    \ can be found at http://www.ros.org/wiki_dump/\nThe files in [here](http://ros.informatik.uni-freiburg.de/rostheme.tgz)\
    \ help to get the look right.\n\nI setup a wiki-mirror at [http://ros.informatik.uni-freiburg.de/roswiki/](http://ros.informatik.uni-freiburg.de/roswiki/),\
    \ but it is rather outdated. Will fix that next week.\n\nThe below script is what\
    \ I use now. **The previous version had a bug, always reusing the first download\
    \ of the tarballs!**\n\n    #!/bin/bash\n    pushd /var/www/\n    echo Downloading\
    \ Wiki-Dump\n    if wget -N http://www.ros.org/wiki_dump/roswiki.tar.gz; then\
    \ #-N triggers timestamping, i.e., only fetch if newer, then overwrite existing\n\
    \      rm -rf roswiki-old\n      mv roswiki roswiki-old\n      echo Extracting\
    \ Wiki-Dump\n      pv roswiki.tar.gz|tar xz \n      echo Extracting Wiki-Theme\n\
    \      tar xzf rostheme.tgz -C roswiki\n    \n      echo Downloading API-Dump\n\
    \      if wget -N http://www.ros.org/wiki_dump/doc.tar.gz; then\n        echo\
    \ Extracting API-Dump\n        pv doc.tar.gz|tar xz -C roswiki\n      fi\n   \
    \ fi\n\nIt assumes your web root is /var/www and you want it in the subdirectory\
    \ \"roswiki\". Also you need to have placed rostheme.tgz from the link above in\
    \ /var/www\n\nThe pv pipes serve to show progress, which is nice to have for big\
    \ file. pv is apt-gettable, but you can also coust omit it and give the file directly\
    \ to tar, as done for rostheme.tgz"
