  body_markdown: "To publish cv::Mat to ROS topic do tjhe following:\n\n1) Include\
    \ cv_bridge and sensor_msgs Image (You already did that=) )\n\n    #include <cv_bridge/cv_bridge.h>\n\
    \    #include <sensor_msgs/image_encodings.h>\n    #include <sensor_msgs/Image.h>\n\
    \n2) Set up image publisher for sensor_msgs/Image somewhere:\n\n    ros::Publisher\
    \ out_img_pub =nh.advertise<sensor_msgs::Image>(\"image_out\", 2, false);\n\n\
    3) In your conde where you have filled your cv::Mat convert it to sensor_msgs/image\
    \ and publish:\n\n\n    // assuming you have declared and filled cv::Mat your_mat\
    \ with data in colorspace \"bgr8\"\n      cv_bridge::CvImage lo_img;\n      \n\
    \      lo_img.encoding = \"bgr8\";                        // or which enconding\
    \ your data has\n      lo_img.header.stamp = ros::Time::now();          //  or\
    \ whatever timestamp suits here;\n      lo_img.header.frame_id = \"whatever_frame\"\
    ;       // frame id as neededby you\n      lo_img.image = your_mat;          \
    \                // point cv_bridge to your object\n\n    // publishing data\n\
    \    out_img_pub.publish( lo_img.toImageMsg() );\n\n\n\n\n"
