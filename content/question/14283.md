  body_markdown: "As I indicated in my edit, this problem has nothing to do with any\
    \ plugins. It was caused by attempting, in `.bashrc`, to modify environment variables,\
    \ `GAZEBO_MODEL_PATH` and `GAZEBO_RESOURCE_PATH`, that had never been set. As\
    \ Steven Peters pointed out in the [bug tracker issue](https://bitbucket.org/osrf/gazebo/issues/2044/gazebo-731-gzserver-gzclient-results-in),\
    \ this entire problem can be fixed by putting the line \n\n    source /usr/share/gazebo/setup.sh\n\
    \n above any lines that customize the Gazebo paths, such as \n\n    export GAZEBO_MODEL_PATH=${GAZEBO_MODEL_PATH}:<new_path>\n\
    \    export GAZEBO_RESOURCE_PATH=${GAZEBO_RESOURCE_PATH}:<new_path>\n\nin `.bashrc`.\
    \ The [Getting Started tutorial](http://gazebosim.org/tutorials?tut=components&cat=get_started#EnvironmentVariables)\
    \ mentions the need to do this."
