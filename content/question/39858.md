  body_markdown: "You have to make sure that you also set the size of the rolling\
    \ window appropriately:\n\n    rolling_window: true\n    width: 15.0\n    height:\
    \ 15.0\n    resolution: 0.05\n    origin_x: 0.0\n    origin_y: 0.0\n\nWhen using\
    \ a static map, the width and height are determined using the loaded image. In\
    \ a rolling window, you must manually specify these parameters for your robot.\
    \ Just know that it places your robot in the center of the rolling window, so\
    \ the robot can only see things that are `height/2` meters away. "
