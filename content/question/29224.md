  body_markdown: "So my mistake was jumping into Model Editor mode directly after\
    \ importing the model. This doesn't specify that the recently imported model is\
    \ model that is being edited. To edit an existing model, we need to right click\
    \ on the model > Choose Edit Model. \n\n- Out of the Model Editor mode, the parts\
    \ of a model would seem to be a single unit (which makes sense since the model\
    \ parts make up a single model eg: wheel parts on a car model make up the car\
    \ model)\n- We can regain control over individual objects of our current model\
    \ by jumping into edit mode of that particular model.  \n\nReference Image:\n\
    https://i.imgur.com/v3gYZIh.png\n\nThis is already documented in Gazebo: https://classic.gazebosim.org/tutorials?tut=model_editor#Editexistingmodels"
