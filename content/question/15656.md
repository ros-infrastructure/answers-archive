  body_markdown: "Found the way to do it. This works for me:\n\n\nWell in the package.xml\
    \ you need:\n\n    <run_depend>gazebo_ros</run_depend>\n  \n    <export>\t\n \
    \     <gazebo_ros gazebo_media_path=\"${prefix}\"/>\t  \t\t  \t\t  \t\t  \n  \
    \  </export>  \n\n${prefix} == package directory\n\nand the folder structure is\
    \ like this:\n\n - media\n    - materials\n       - scripts\n       - texture\n\
    \nin the xacro file:\n\n    <gazebo reference=\"link\">\t\t\t\t\t\t\t\n\t<material>YourMaterial</material>\n\
    \    </gazebo>\n\n\nI guess in the process I changed the folder structure multiple\
    \ times, maybe I first missed the media folder."
