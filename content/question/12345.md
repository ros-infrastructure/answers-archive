  body_markdown: "Hi,\nAccording to \n[http://www.ros.org/wiki/ROS/Tutorials/InstallingandConfiguringROSEnvironment](http://www.ros.org/wiki/ROS/Tutorials/InstallingandConfiguringROSEnvironment)\n\
    you are not supposed to edit the setup.sh file in the \"/opt/ros/electric/\" path\
    \ but setup in your ros_workspace folder created by you.\nThe idea behind setting\
    \ up the workspace is to have the packages fetched by ros automatically. \nOnce\
    \ you download or create a package in this workspace in the future, the ros commands\
    \ like roscd, rosmake, rosed etc would be able to lookup in this path.\nOnce you\
    \ setup the environment/workspace, your \n\n    echo $ROS_PACKAGE_PATH \n\nwould\
    \ give the following output\n\n    /home/user/ros_workspace:/opt/ros/electric/stacks\n\
    \nYou have to source this path to your ~/.bashrc file so that it gets picked up\
    \ every time you run the terminal.\n\n\nHope this helps,\nKarthik\n\n"
