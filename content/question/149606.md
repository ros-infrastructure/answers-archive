    By using the libgazebo_ros_gpu_laser plugin as for example [here](https://github.com/ros-simulation/gazebo_ros_demos/blob/master/rrbot_description/urdf/rrbot.gazebo). See also [this explanation on the gazebo wiki](http://gazebosim.org/wiki/Tutorials/1.9/ROS_Motor_and_Sensor_Plugins#GPU_Laser).

    /edit: For Blender, your best bet is either using [MORSE](http://www.openrobots.org/wiki/morse/) which [apparently can generate ROS LaserScan messages](http://www.openrobots.org/morse/doc/stable/_modules/morse/middleware/ros/laserscanner.html) or using [Blensor](http://www.blensor.org/).
