  body_markdown: "Basically, you can access the HeightmapShape, and use it to compute\
    \ the height :\n\n<!-- language: lang-cpp -->\n\n\t// Get the HeightmapShape\n\
    \tphysics::ModelPtr model = parent->GetModel( \"heightmap\" );\n\tphysics::HeightmapShape*\
    \ hm = dynamic_cast<physics::HeightmapShape*>( model->GetLink(\"link\")->GetCollision(\"\
    collision\")->GetShape().get() );\t\t\n\t\n\t// The HeightmapShape does not work\
    \ with the same coordinate system, so get some data:\n\tmath::Vector3 size = hm->GetSize();\
    \ \n\tmath::Vector2i vc = hm->GetVertexCount();\n\tdouble ss = static_cast<double>(\
    \ hm->GetSubSampling() );\n\n\t// And finally get your z from your x and y:\n\t\
    double z = hm->GetHeight( (x + size.x/2)/size.x*vc.x - 1, (y + size.y/2)/size.y*vc.y\
    \ - 1);\n\n\n----------\n\nBe careful, this example\n\n - makes no safety checks\n\
    \ - suppose the heightmap orgin is 0,0,0\n\n"
