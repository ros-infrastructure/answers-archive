  body_markdown: "Hi,\n\nAccording to [this](http://answers.gazebosim.org/question/488/remapping-joint-states-from-simulator/)\
    \ remapping of gazebo topics is not yet possible.\n\nNote that `/odom`, `/joint_state`s\
    \ and `/tf` are not published from gazebo. To publish `/joint_states` in your\
    \ preferred namespace you can spawn the `joint_state_controller` from spawner\
    \ node in `controller_manager` while changing the namespace as follows:\n\n  \
    \  <node name=\"controller_spawner\" pkg=\"controller_manager\" type=\"spawner\"\
    \ respawn=\"false\"\n\toutput=\"screen\" ns=\"/robot1\" args=\"joint_state_controller\"\
    \n    </node>\n\nAlso, remember to change the namespace in the plugin inside URDF/SDF\
    \ file:\n\n    <gazebo>\n      <plugin name=\"gazebo_ros_control\" filename=\"\
    libgazebo_ros_control.so\">\n       <robotNamespace>/robot1</robotNamespace>\n\
    \      </plugin>\n    </gazebo>\n\nTo publish `/tf` you need the `robot_state_publisher`.\
    \ Do remapping:\n\n    <node name=\"robot_state_publisher\" pkg=\"robot_state_publisher\"\
    \ type=\"robot_state_publisher\"\n\trespawn=\"false\" output=\"screen\">\n   \
    \   <remap from=\"/joint_states\" to=\"/robot1/joint_states\" />\n    </node>\n\
    \nSo, for the multiple robots you may want to repeat the above again.\n\nYou can\
    \ also wanna try \n\n    <group ns=\"robot1\"> include robot1 stuff here </group>\
    \ \n\n[check this, too](http://wiki.ros.org/roslaunch/XML/group)\n\nCheers!"
