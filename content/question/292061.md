 The actionlib tutorial on [Writing a Callback Based Simple Action Client](http://wiki.ros.org/actionlib_tutorials/Tutorials/Writing%20a%20Callback%20Based%20Simple%20Action%20Client) shows how to do it in C++, but there isn't a tutorial for Python. 

The [Writing a Simple Action Client (Python)](http://wiki.ros.org/actionlib_tutorials/Tutorials/Writing%20a%20Simple%20Action%20Client%20%28Python%29) tutorial only demonstrates synchronous behavior with `client.wait_for_server()`, which does not allow for actionlib feedback.

A simple example would be much appreciated.
