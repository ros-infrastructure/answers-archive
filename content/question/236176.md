  body_markdown: "The current solution is to remove the following packages installed\
    \ via .deb and manually build them. Run\n\nsudo apt-get remove ros-<distro>-gazebo-ros-control\n\
    sudo apt-get remove ros-<distro>-gazebo-plugings \n\nand also any other gazebo\
    \ pkgs you want to remove, but these two do the trick. Notice that you'd have\
    \ to add version number next to gazebo above is you are not using the default\
    \ gazebo for your distro. I am using gazebo7 with Indigo so I replaced gazebo\
    \ with gazebo7.\n\nafterwards, clone the following in your own catkin_ws, and\
    \ checkout the branch which corresponds to your gazebo version. Default should\
    \ work with Indigo.\nhttps://github.com/ros-simulation/gazebo_ros_pkgs.git\n\n\
    just build them by catkin_make and source your workspace. Hopefully Gazebo won't\
    \ crash now.\n\nThis worked for me.\n "
