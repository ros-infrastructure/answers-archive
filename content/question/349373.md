      \ at mpc_follower and pure_pursuit nodes. mpc_follower publishes twist command\
      \ (velocity and angular velocity/steering) as follows: \n\n     ros::Publisher\
      \ pub_twist_cmd_;          //!< @brief topic publisher for twist command\n \
      \     /**\n       * @brief publish control command as geometry_msgs/TwistStamped\
      \ type\n       * @param [in] vel_cmd velocity command [m/s] for vehicle control\n\
      \       * @param [in] omega_cmd angular velocity command [rad/s] for vehicle\
      \ control\n       */\n\n      void publishTwist(const double &vel_cmd, const\
      \ double &omega_cmd);\n\n**no promises and I don't have enough experience/knowledge**\
      \ on this but you should be able to do a simple command in terminal to test\
      \ if this is correct:\n\n     rostopic pub geometry_msgs/TwistStamped twist_cmd\
      \ \"your desired input\"\n\nIf you are not using twist you could do the same\
      \ with the following messages:\nautoware_msgs/BrakeCmd brake_cmd"
