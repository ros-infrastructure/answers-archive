 Hi,

first of all we like to say that we started working in September 2022 with ROS2, Orin and PX4, so we're not having a lot of experience.

We tried the following user guide with Ubuntu 20.04 and ROS2 foxy on a Nvidia Orin, as well as a normal desktop  PC workstation:
https://docs.px4.io/main/en/ros/ros2_comm.html

Regarding the Sanity Check of the installation, we were not able to run the simulation in neither gazebo, nor 
jMAVSim on the Orin (arm architecture). However, the simulation runs perfectly on the workstation. After some research on the internet, we found out that such problems are not unusual. In order to get the px4 installed using the *ubuntu.sh*of the user guide, we finally found out that applying the following steps let us install the px4-ros bridge:

 1. run in terminal: "git clone https://github.com/PX4/PX4-Autopilot.git --recursive"
 2. delete g++-multilib and gcc-multilib lines in ~/PX4-Autopilot/Tools/setup/ubuntu.sh
 3. open terminal and run "bash ./PX4-Autopilot/Tools/setup/ubuntu.sh"
 4. reboot your computer
 5. make ...
