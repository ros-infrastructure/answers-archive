  body_markdown: |-
    The instructions on [gazebosim.org](http://gazebosim.org) are for standalone system install of gazebo. (see my comment below about the ros-ified gazebo stack).  Your problem above might be fixed by the updated step 2 in [quick_start](http://gazebosim.org/wiki/quick_start)

        source /usr/share/gazebo-[gazebo version]/setup.sh

    should configure environment variables necessary for things to work correctly.  In this case, your system is missing the correct `OGRE_RESOURCE_PATH`.

    On another note, it looks like you are trying to install gazebo simulator directly on your system (outside of ros context) for using it with ROS.  Let me try to clarify a little bit about the difference between the [ros simulator_gazebo stack](http://ros.org/wiki/simulator_gazebo) and the [gazebosim project](http://gazebosim.org).

    The [ros simulator_gazebo stack](http://ros.org/wiki/simulator_gazebo) wraps a hand-picked stable version of gazebo from the [gazebo simulator project](http://gazebosim.org), and provides additional ros plugins/tools for using gazebo inside the ros environment.  By installing ros-fuerte-simulator-gazebo, you don't have to worry about installing gazebo via instructions on gazebosim.org, but rather, just follow along the [ros wiki tutorials](http://ros.org/wiki/simulator_gazebo/Tutorials).  However, if you are interested in helping out with testing/developing the underlying simulator software, then proceed with the system install as described on the [gazebo simulator project installation instruction page](http://gazebosim.org/wiki/install) and try out the [quick start steps](http://gazebosim.org/wiki/quick_start).  Note the two installs can exist side by side with some careful finessing of installation locations and system paths.

    Hope this is not too confusing.
