    Here's a quick way:

        rosbag play mybag.bag
        rostopic echo /foo > output.txt

    This will output all message in the topic `/foo` to a yaml-formatted text file. You can then parse the file. It might be useful to output to multiple files for different fields. Let's say the message type on `/foo` is [Pose](http://www.ros.org/doc/api/geometry_msgs/html/msg/Pose.html):

        rosbag play mybag.bag
        rostopic echo /foo/position/x > output_x.txt
        rostopic echo /foo/position/y > output_y.txt
        rostopic echo /foo/position/z > output_z.txt

    You can also look into [bagys](http://www.ros.org/wiki/rosh/Overview/Bagys), which are an extension of the concept above.

  body_markdown: "A more flexible way of doing this could be with Pandas. After you\
    \ record your data, you can sift through it to gather the information you need,\
    \ add it to a dataframe, perform any operations on it, and save it to a .csv.\
    \ For example, lets consider some points.\n\n    import rosbag\n    from geometry_msgs.msg\
    \ import Point\n    import pandas as pd\n    \n    # The bag file should be in\
    \ the same directory as your terminal\n    bag = rosbag.Bag('./recorded-data.bag')\n\
    \    topic = '/your_topic'\n    column_names = ['x', 'y']\n    df = pd.DataFrame(columns=column_names)\n\
    \    \n    for topic, msg, t in bag.read_messages(topics=topic):\n        x =\
    \ msg.x\n        y = msg.y\n    \n        df = df.append(\n            {'x': x,\n\
    \             'y': y},\n            ignore_index=True\n        )\n    \n    df.to_csv('out.csv')"
