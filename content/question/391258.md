  body_markdown: "There are different solutions to work with uneven grounds while\
    \ performing SLAM.\n\nFor example there is  ROS package from ANYbotics for elevation\
    \ mapping:  \nhttps://github.com/ANYbotics/elevation_mapping\n\n> The software\
    \ is designed for (local)\n> navigation tasks with robots which are\n> equipped\
    \ with a pose estimation (e.g.\n> IMU & odometry) and a distance sensor\n> (e.g.\
    \ structured light (Kinect,\n> RealSense), laser range sensor, stereo\n> camera).\
    \ The provided elevation map is\n> limited around the robot and reflects\n> the\
    \ pose uncertainty that is\n> aggregated through the motion of the\n> robot (robot-centric\
    \ mapping).\n\nAnother solution is to use 3D octomap to capture elevation information\
    \ as well:\nhttps://octomap.github.io/\n\n> The OctoMap library implements a 3D\n\
    > occupancy grid mapping approach,\n> providing data structures and mapping\n\
    > algorithms\n\nYou may also look at another ROS package Cartographer. \n\n> Cartographer\
    \ is a system that provides\n> real-time simultaneous localization\n> and mapping\
    \ (SLAM) in 2D and 3D across\n> multiple platforms and sensor\n> configurations."
