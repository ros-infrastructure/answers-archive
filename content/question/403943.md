  body_markdown: "The bumper plugin needs to be inside a `<sensor>` element in your\
    \ urdf:\n\n    <gazebo reference=\"front_bumper\">\n        <sensor name=front_bumper_sensor\"\
    \ type=\"contact\">\n            <update_rate>10.0</update_rate>\n           \
    \ <contact>\n                <!-- These collision names need to match the names\
    \ used in the generated -->\n                <!-- SDF, not the urdf names or this\
    \ still won't work! -->\n                <collision>front_bumper_collision</collision>\n\
    \            </contact>\n            <plugin name=\"bumper_plugin\" filename=\"\
    libgazebo_ros_bumper.so\">\n                <ros>\n                    <namespace>demo</namespace>\n\
    \                    <remapping>bumper_states:=bumper_demo</remapping>\n     \
    \           </ros>\n            </plugin>\n        </sensor>\n    </gazebo>\n\n\
    To find the actual collision name you should use in the collision element look\
    \ at https://answers.ros.org/question/277175/gazebo_ros_bumper_controller-not-updating-bumper-states/?answer=286184#post-id-286184\n\
    \nIn summary, run `gz sdf -p <your_filename>.urdf` and check to see the collision\
    \ name it generates for the front bumper collision, then put that name into the\
    \ `<collision>` element.\n\nYou'll also need to give an actual name to the collision:\n\
    \n        <collision name=\"front_bumper_collision\">\n            <geometry>\n\
    \                <box size=\"0.03 0.400 0.03\"/>\n            </geometry>\n  \
    \      </collision>\n    "
