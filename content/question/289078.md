    \ planner's node code to see that the costmap used there is called \"costmap\"\
    \ and not \"global_costmap\" as shown in the [tutorial](http://wiki.ros.org/navigation/Tutorials/RobotSetup).\
    \ when it comes to the yaml parameters file you have to use the right name. Here\
    \ is what I mean: \n\nParameters file loaded onto global planner. \n\n    costmap:\
    \ #This name is the name of the costmap, and needs to match the one given in the\
    \ code\n      global_frame: /map\n      robot_base_frame: base_link\n      update_frequency:\
    \ 5.0\n      publish_frequency: 1.0\n    \n    #set if you want the voxel map\
    \ published\n      publish_voxel_map: true\n    \n    #set to true if you want\
    \ to initialize the costmap from a static map\n      static_map: true\n    \n\
    \    #begin - COMMENT these lines if you set static_map to true\n    #rolling_window:\
    \ true\n    #width: 3.0\n    #height: 3.0\n    #resolution: 0.025\n    #end -\
    \ COMMENT these lines if you set static_map to true\n    \n    #START VOXEL STUFF\n\
    \      map_type: voxel\n      origin_z: 0.0\n      z_resolution: 0.2\n      z_voxels:\
    \ 10\n      unknown_threshold: 10\n      mark_threshold: 0\n    #END VOXEL STUFF\n\
    \    \n      transform_tolerance: 0.3\n      obstacle_range: 2.5\n      max_obstacle_height:\
