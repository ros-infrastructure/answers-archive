  body_markdown: "Hi @TCIII:\n\nI believe if you install: `sudo apt-get install ros-noetic-joy`\
    \ should work with Xbox One.\n\nTo test your joystick, check the tutorial: http://wiki.ros.org/joy/Tutorials/ConfiguringALinuxJoystick\n\
    \n\nIn Linux:\n\n    ls /dev/input/  #to check if Linux detecting input\n    sudo\
    \ jstest /dev/input/jsX  #replace X with your joystick number such as joy0 or\
    \ joy1\n    ls -l /dev/input/jsX   #test the joystick\n\nIn ROS:\n\n    rosparam\
    \ set joy_node/dev \"/dev/input/jsX\"\n    rosrun joy joy_node\n    rostopic echo\
    \ joy\n\n\n\nTake a look at this example of implementation: \nhttps://github.com/2788west/cerusbot/tree/master/ROS\n\
    https://johanschwind.medium.com/mobile-robot-teleoperation-with-the-jetson-nano-and-ros-d72b4b57e9be\n\
    \nThe Xbox One controller has slight changes in the button naming convention compared\
    \ to the Xbox 360 version.\n\nCheck this link for the table: \nhttps://ritchielozada.com/2016/01/16/part-11-using-an-xbox-one-controller-with-unity-on-windows-10/\n\
    \nI believe the wiki link needs to be updated with this info."
