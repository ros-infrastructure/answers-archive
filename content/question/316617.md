  body_markdown: "If you are using the default \"global_planner/GlobalPlanner\" plugin,\
    \ you have the option to toggle between 2 different types of global planners,\
    \ A* and Dijkstra's. \nIf you are not already using the GlobalPlanner plugin,\
    \ you can do so by first going over to \"*turtlebot3_navigation/launch/move_base.launch*\"\
    \ and adding the following line to your move_base node as follows:\n\n    <node\
    \ pkg=\"move_base\" type=\"move_base\" respawn=\"false\" name=\"move_base\" output=\"\
    screen\">\n       <param name=\"base_local_planner\" value=\"dwa_local_planner/DWAPlannerROS\"\
    \ />\n       <param name=\"base_global_planner\" value=\"global_planner/GlobalPlanner\"\
    />\n       <rosparam file=\"$(find turtlebot3_navigation)/param/global_planner.yaml\"\
    \ command=\"load\" ns=\"GlobalPlanner\"/>\n       ...\n\nYou can then toggle between\
    \ A* and Dijkstra's in your global_planner.yaml file. Please create this param\
    \ file according to the [global_planner documentation](http://wiki.ros.org/global_planner).\
    \ An example is provided below:\n\n    allow_unknown: true \n    default_tolerance:\
    \ 0.0 \n    visualize_potential: false \n    use_dijkstra: true\n    use_quadratic:\
    \ true \n    use_grid_path: false \n    old_navfn_behavior: false \n    lethal_cost:\
    \ 253 \n    neutral_cost: 50\n    cost_factor: 1.0\n    publish_potential: True\n\
    \    orientation_mode: 1 \n    orientation_window_size: 1 \n    outline_map: true\
    \ \n\n\nIf you would like to try out alternative global planners aside from the\
    \ defaults, you can check out [sbpl_lattice_planner](https://github.com/ros-planning/navigation_experimental/tree/melodic-devel/sbpl_lattice_planner)\
    \ from the [navigation_experimental repo](https://github.com/ros-planning/navigation_experimental).\n\
    \nAlternatively, if you need to write your own global planner plugin to suit your\
    \ needs, you can refer to [Writing A Global Path Planner As Plugin in ROS](http://wiki.ros.org/navigation/Tutorials/Writing%20A%20Global%20Path%20Planner%20As%20Plugin%20in%20ROS/)\n"
