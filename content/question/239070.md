  body_markdown: "To launch all together you have simply to include all the launch\
    \ files into a single launch file. (Take a look to [this](http://wiki.ros.org/ROS/Tutorials/Roslaunch%20tips%20for%20larger%20projects)\
    \ ). \n\nRegarding the rosbag check this [answer](http://answers.ros.org/question/62811/how-to-play-rosbag-using-launch-file/),\
    \ the xml syntax for `rosbag record -a`is: `<node pkg=\"rosbag\" type=\"record\"\
    \ name=\"recorder\" output=\"screen\" args=\"-a\"/> ` (in \"args\" you can put\
    \ all the arguments for that command)\n\nSo the whole launch file to launch all\
    \ you need is:\n\n    <launch>\n\n       <include file=\"$(find turtlebot_gazebo)/launch/turtlebot_world.launch\"\
    />\n       <include file=\"$(find turtlebot_gazebo)/launch/gmapping_demo.launch\"\
    />\n       <include file=\"$(find turtlebot_rviz_launchers)/launch/view_robot.launch\"\
    />\n       <include file=\"$(find turtlebot_teleop)/launch/keyboard_t.launch\"\
    />\n\n       <!-- \n         The rosbag will be saved in the ~./ros folder\n \
    \      -->\n       <node pkg=\"rosbag\" type=\"record\" name=\"recorder\" output=\"\
    screen\" args=\"-a\"/>    \n    </launch>\n    \nNow you can launch it from the\
    \ terminal as a normal launch file. \n\n"
