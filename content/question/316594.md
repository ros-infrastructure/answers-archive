    I would report what worked for me:

    Due to initial rotation of robot around z axis i was not able to approach the object exactly as i wanted.
    Below is the orientation which can help you to approach the object in y axis direction if you dont have any initial rotation.

        orientation.setRPY(-M_PI / 4, -M_PI/2 , -M_PI /4);

Hello,

I’m trying to achieve pick and place in gazebo by sending trajectory from moveit.
I noticed in moveit pick and place tutorial that orientation is given as follows:

    orientation.setRPY(-M_PI / 2, -M_PI / 4, -M_PI / 2)

This orientation tries to pick the object from x-axis direction ( considering x axis is forward, y axis is pointing to the left and z axis is upwards.) Below image demonstartes how my robot arm positions itself when given above orienatation

![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/15511031625995238.png)
![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/15511031918544046.png)

I want to grasp the object from y axis side i.e parallel to the yellow axis shown in the image. What can be the orientation of the robot??

I have came till this orientation:

    orientation.setRPY(-M_PI / 4, -M_PI/2 , -M_PI /4)

below is the image representing robot arm with this orientation.
![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/1551103415786332.png)
![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/15511034992474081.png)

if you see then gripper is still inclined and not exactly horizontal. 
can anyone tell me what can be orientation to grasp the object from y axis direction??
