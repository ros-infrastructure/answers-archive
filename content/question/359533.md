  body_markdown: "Qt supports cmake and in the latest version of Qt, it is highly\
    \ recommended to stick with cmake and discard qmake since cmake will be the future\
    \ for Qt. This is good news since ROS also uses cmake. The c++ ROS libraries are\
    \ just normal c++ libraries which means you need only to add them in Qt CMakeLists.txt.\
    \ Follow the steps shown below\n\n    1- Start Qt Creator from termina (i.e. this\
    \ is crucial) \n    2- Add the following in Qt CMakeLists.txt\n       find_package(roscpp\
    \ REQUIRED)\n       find_package(std_msgs REQUIRED)    # if you are using std_msgs\
    \ of course.\n       include_directories(include ${roscpp_INCLUDE_DIRS})\n   \
    \    include_directories(include ${std_msgs_INCLUDE_DIRS})      \n       target_link_libraries(\
    \ ${roscpp_LIBRARIES} ${std_msgs_LIBRARIES}\n\nNow include ros header files and\
    \ compile the project. That's it. \n"
