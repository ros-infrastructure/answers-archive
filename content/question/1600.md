    We experimented with Gazebo on OSX a while back too, but ran out of time. You can enable weak linking as follows:
    In the top CMakeLists.txt, change

        # OS Specific initialization
        if (UNIX)
          gz_setup_unix()
        else (WIN32)
          gz_setup_windows()
        else (APPLE)
          gz_setup_apple()
        endif()

    to

        # OS Specific initialization
        if (UNIX)
          gz_setup_unix()
        else (WIN32)
          gz_setup_windows()
        endif()
        if (APPLE)
          gz_setup_apple()
        endif()

    This is necessary because OSX is considered a UNIX system too!

    `brew install qt protobuf-c`

    `brew tap ros/groovy && brew install ogre tinyxml`

    `brew install curl`

    `export PKG_CONFIG_PATH=/usr/local/opt/curl/lib/pkgconfig:$PKG_CONFIG_PATH`
