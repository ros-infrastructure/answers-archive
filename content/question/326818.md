    There is an example message package [pendulum_msgs](https://github.com/ros2/demos/tree/master/pendulum_msgs) which is used by [pendulum_control](https://github.com/ros2/demos/tree/master/pendulum_control). It [does publish the custom messages](https://github.com/ros2/demos/blob/f78dcc981cc783aad162e2a8530a7aa23c4fda21/pendulum_control/src/pendulum_demo.cpp#L159-L161).

    I found them from this [stub tutorial](https://index.ros.org/doc/ros2/Tutorials/Defining-custom-interfaces-(msg-srv)/). That example shows having messages in a dedicated package (which is considered good practice). I don't know of an example where messages are both generated and used in the same package.
