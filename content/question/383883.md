    >  what():  $find(nanotec_ros)/config/C5-E-1-09.eds: cannot open file

    This is a very specific error message.

    It looks like your roslaunch syntax is wrong. At this stage (in the driver) the path should already be expanded.
    I think it should be `$(find nanotec_ros)/config/C5-E-1-09.eds`
  comments:
