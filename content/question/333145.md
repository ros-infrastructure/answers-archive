    \ is running roscore on board + the rest of the basic ROS Stack. The robot has\
    \ a domain name, say r1.brandeis.edu. On the robot,  \n\n- ROS_MASTER_URI=http://r1.brandeis.edu:11311\n\
    - ROS_HOSTNAME is set to r1.brandeis.edu.\n\nA wifi connected laptop has \n\n\
    - ROS_MASTER_URI=http://r1.brandeis.edu:11311\n- ROS_IP=ip-address-of-laptop\n\
    \nThis set up works. The problem I had which seemed to be causing the failure\
    \ was caused by not following that setup. \n\nI remain confused about the interaction\
    \ between ROS_IP and ROS_HOSTNAME. For example, if on the laptop I setup ROS_HOSTNAME=localhost,\
