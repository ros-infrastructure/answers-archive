    According to the [`pointcloud_to_laserscan` README on GitHub](https://github.com/ros-perception/pointcloud_to_laserscan/tree/foxy), the `scan_time` parameter in your launch file has no functional effect; it just adds that value to the outgoing scan message:

    > scan_time (double, default: 1.0/30.0) - The scan rate in seconds. Used to populate the output laser scan.

    Indeed, the [source code](https://github.com/ros-perception/pointcloud_to_laserscan/blob/024e70ae2e0e845bf6525c5fcc540f7b4cc9d08c/src/pointcloud_to_laserscan_node.cpp#L149) only uses the parameter once after declaring it--to populate the message field:

        scan_msg->scan_time = scan_time_;

 Hi,
I'm having a bit of trouble understanding the "scan_time" parameter from poincloud_to_laserscan package.

I was supposing that it was the publish rate of the output (laser_scan). However, I have it set at 0.333 seconds (so 3Hz), but the publishing frequency of the scan is nearly 10Hz (as the pointcloud topic).

Do I misunderstand the meanning of this parameter?

Thanks a lot in advance

Felix
