I'm thinking about how to link certain components together in a network, rather than the FPGA model all on a single board. If I were to say have numerous independent components (arms, legs etc) the obvious thing is fieldbus comms, but is there not a generic asynchronous API or scripting language (DSL) for controlling things?

Here is some odd psuedo language that's a mix of javascript, lisp and ruby:
ISO 10218. TS 15066 

        require "iso10218"
        arm1 = Arm.new(dof: 5, limits: TS15066, joint_follow: J_LOOSE, url: "tcprobot://192.168.10.5")
        arm1.alert = lambda (signal) {
        if (signal == TORQUE_EXCEEDED) do
           emergency_stop()
           do_something()
       end
    
       arm1.follow_sequence([
          "G01 X 100 Y 100 Z 100 F 1600",
          "G01 A 355 B 10",
          "G01 A 210 Y 120 X 0"
       ])

There must be a finite set of conditions around the robot mechanisms that would lend themselves to such a scripting language ... any ideas?
