    The easiest option is to create a URDF model for your robot and publish joint_state data to a robot_state_publisher ([tutorial](http://wiki.ros.org/urdf/Tutorials/Using%20urdf%20with%20robot_state_publisher)). This will generate tf transform data for all frames, which is the same as forward kinematics. This is really meant for representing the current robot state however.

    A very convenient option is [generating a MoveIt! config](http://docs.ros.org/hydro/api/moveit_setup_assistant/html/doc/tutorial.html) for the robot. The kinematics capabilities can then be used programmatically as described in the [kinematics tutorial](http://docs.ros.org/hydro/api/pr2_moveit_tutorials/html/kinematics/src/doc/kinematics_tutorial.html).

    There are also other options like using [KDL](http://kdl), but I believe MoveIt! is probably the easiest to use.
