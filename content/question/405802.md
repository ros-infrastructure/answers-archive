  body_markdown: "You can run two instances of your node which spawns the robot under\
    \ two namespaces. \n\nEdit 1 :\nThis can be done in multiple ways. The best way\
    \ is to make a roslaunch file and add nodes in there. By using the   \u201Cns\u201D\
    \ attribute you can define the namespace.  You can find details [here](http://wiki.ros.org/roslaunch/XML/node)\n\
    \nExample: \n\n    <launch>\n        <node pkg=\u201C\u2026\u201D type=\u201D\u2026\
    \u201D name=\u201D\u2026\u201D  ns=\u201D\u2026\u201D/>\n    </launch>"
