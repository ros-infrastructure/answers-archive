    \ value (for example, **\"/camera/rgb/image_raw\"**). You\n    can find possible\
    \ values click\n    on the drop-down list on the\n    **\"Image\"->\"Image Topic\"\
    **. It works only for this session.\n    \n    If you want to make changes to\
    \ all\n    sessions, edit this parameter in the\n    config: **robot.rviz**. You\
    \ can find\n    the path in\n    **File->Open Config**. In **robot.rviz** find\
    \ **\"Class: rviz/Image\"** and edit **\"Image Topic\"**.\n\n 2. Secondly, I'd\
    \ like to add other decision. You can use current Topic (at least **\"/camera/rgb/image_rect_color\"\
    **). Install \"openni\" and launch\n    it:\n    \n     1. sudo apt-get install\n\

    \  roslaunch\n        openni_launch openni.launch\n        load_driver:=false\n\
