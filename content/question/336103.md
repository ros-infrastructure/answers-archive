  body_markdown: "I've got something working here: https://github.com/lucasw/frei0r_image/blob/master/.github/workflows/ubuntu_20_04.yml\n\
    (see also https://github.com/lucasw/frei0r_image/actions for how the results are\
    \ reported)\n\n    name: Noetic Ubuntu 20.04\n\n    on:\n      push:\n      pull_request:\n\
    \      workflow_dispatch:\n    \n    jobs:\n      build:\n        runs-on: ubuntu-20.04\n\
    \        env:\n          ROS_CI_DESKTOP: \"`lsb_release -cs`\"  # e.g. [trusty|xenial|...]\n\
    \          ROS_DISTRO: noetic\n        steps:\n          - uses: actions/checkout@v2\n\
    \          - name: Install Non-ROS Dependencies\n            run: |\n        \
    \        ls -l $GITHUB_WORKSPACE\n                sudo apt-get install -y frei0r-plugins-dev\n\
    \          - name: Install ROS\n            run: |\n                sudo sh -c\
    \ \"echo \\\"deb http://packages.ros.org/ros/ubuntu $ROS_CI_DESKTOP main\\\" >\
    \ /etc/apt/sources.list.d/ros-latest.list\"\n                sudo apt-key adv\
    \ --keyserver 'hkp://keyserver.ubuntu.com:80' --recv-key C1CF6E31E6BADE8868B172B4F42ED6FBAB17C654\n\
    \                sudo apt-get update -qq\n                sudo apt-get install\
    \ dpkg\n                sudo apt-get install -y python3-catkin-pkg\n         \
    \       sudo apt-get install -y python3-catkin-tools\n                sudo apt-get\
    \ install -y python3-osrf-pycommon\n                sudo apt-get install -y python3-rosdep\n\
    \                sudo apt-get install -y python3-wstool\n                sudo\
    \ apt-get install -y ros-cmake-modules\n                sudo apt-get install -y\
    \ ros-$ROS_DISTRO-catkin\n                source /opt/ros/$ROS_DISTRO/setup.bash\n\
    \          - name: Install ROS packages with rosdep\n            run: |\n    \
    \          source /opt/ros/$ROS_DISTRO/setup.bash\n              sudo rosdep init\n\
    \              rosdep update\n              mkdir -p ~/catkin_ws/src\n       \
    \       ln -s $GITHUB_WORKSPACE ~/catkin_ws/src/frei0r_image\n              cd\
    \ ~/catkin_ws\n              rosdep install --from-paths src --ignore-src -r -s\
    \  # do a dry-run first\n              rosdep install --from-paths src --ignore-src\
    \ -r -y\n          - name: catkin build\n            run: |\n              source\
    \ /opt/ros/$ROS_DISTRO/setup.bash\n              cd ~/catkin_ws\n            \
    \  catkin build --no-status\n              source devel/setup.bash\n         \
    \ - name: lint\n            run: |\n              cd ~/catkin_ws\n           \
    \   catkin build frei0r_image --no-deps --catkin-make-args roslint\n\n\nIt would\
    \ be fantastic if there was a `ubuntu-20.04` target image that already has noetic\
    \ on it to speed up the build.  (In other contexts I've seen downloading a large\
    \ custom pre-installed image is slower than starting with a clean base image and\
    \ installing everything from highly available apt repos, but I'm sure that can\
    \ vary wildly)."
