    \ filename=\"libgazebo_ros_camera.so\">\n\nas well as camera names\n\n    <cameraName>camera_x</cameraName>\
    \   \n\n<br>\nEdit:\n\nTo spawn multiple instances of your model, you need to\
    \ remove the robotNamespace parameter from the model. Then you can spawn unique\
    \ models by adding a namespace to the spawn_model node:\n\n    <node name=\"spawn_urdf\"\
    \ pkg=\"gazebo_ros\" type=\"spawn_model\" args=\"-urdf -model $(arg robot_name)\
    \ -param robot_description\" ns=\"$(arg robot_name)\" />\n\nAlternatively, although\
    \ not recommended, you can add an argument for the robot name in your urdf:\n\n\
    \    <xacro:arg name=\"robot_name\" default=\"robot_0\" />\n    <plugin name=\"\
    camera_controller\" filename=\"libgazebo_ros_camera.so\">\n      ...\n      <robotNamespace>$(arg\
    \ robot_name)</robotNamespace>    \n    </plugin>\n\nThen, you need to create\
    \ individual urdf descriptions for each robot:\n\n    <param name=\"$(arg robot_name)/robot_description\"\
    \ command=\"rosrun xacro xacro /path/to/xacro/file robot_name:=$(arg robot_name)\"\
    \ />\n    <node name=\"spawn_urdf\" pkg=\"gazebo_ros\" type=\"spawn_model\" args=\"\
    -urdf -model $(arg robot_name) -param $(arg robot_name)/robot_description\" />"
