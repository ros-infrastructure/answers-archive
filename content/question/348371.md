> function with argument 'alpha'=0.0

But this is not true right? K' = K if alpha=0. The camera matrix, i.e. the focal lenghts and principal points change only if `alpha > 0`. I think this can also be seen in the code of [`getOptimalNewCameraMatrix()`](https://github.com/opencv/opencv/blob/3.4/modules/calib3d/src/calibration.cpp#L2505), assuming image size doesn't change.
