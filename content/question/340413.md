  body_markdown: "The topic you are seeing belongs to an action. And yes, you can\
    \ definitely control the robot this way, without using moveit.\n\nIf you look\
    \ at your current setup, probably you start somewhere the \n[joint_trajectory_controller](https://wiki.ros.org/joint_trajectory_controller).\
    \ You can use it to control your robot directly in the joint space. There is also\
    \ an rqt plugin for this controller. YOu could use it for a first try.\nOr see\
    \ [here for a Tutorial](https://wiki.ros.org/pr2_controllers/Tutorials/Moving%20the%20arm%20using%20the%20Joint%20Trajectory%20Action)\
    \ including source code.\n\nJust keep in mind that there is no obstacle avoidance\
    \ or anything, then. The robot just moves where you ask it to go to."
