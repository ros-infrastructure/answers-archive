Hi,
In company I work for there's a Web UI to manually control our AGV. The Web UI uses 'rosbridge_websocket' and inside that it initializes 'teleop_keyboard' node. However the problem arises from the commands recevied in 'cmd_vel' topic. The back and forth commands are working well as in 'linear.x' message, however to turn the AGV it publishes both 'angular.z' and 'linear.z' messages. There's no need to have 'linear.z' message and it causes problems for motor driver to work normally. I cannot find a way to eliminate 'linear.z' message. There's no file or anything to change teleop_keyboard node as far as I know.

***rostopic echo /cmd_vel*** command gives this:


    ---
    linear: 
      x: 0.5
      y: 0.0
      z: -1.0   // this one I don't need
    angular:
      x: 0.0
      y: 0.0
      z: -1.0
    ---
