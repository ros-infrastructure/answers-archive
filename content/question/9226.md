  body_markdown: "sudo apt-get remove ros-cturtle-ros will remove all cturtle packages\
    \ in /opt/ros but not do anything in your home directory.  \n\nTo remove things\
    \ from your home directory `rm -rf ~/ROS` or whatever path you want to remove\
    \ will work.  Or, if you wish, you can delete the directories from a file browser\
    \ GUI.  \n\nNote: There's no undo for rm so make sure you get the path right. "
