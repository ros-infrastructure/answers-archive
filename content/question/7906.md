    COLLADA files describe 3D meshes, while [SDF](http://sdformat.org/spec) (Simulation Description Format) describes various aspects of the simulation, including how your COLLADA meshes are linked to each other and so on.

    If you're looking for a way to use COLLADA files in your simulation, [this tutorial](http://gazebosim.org/tutorials?tut=import_mesh&cat=build_robot) should help.

    But if you actually meant contributing with a model to the [gazebo_models](https://bitbucket.org/osrf/gazebo_models) repository,  you should probably first read about the [model database structure](http://gazebosim.org/tutorials?tut=model_structure&cat=build_robot) to know how it all fits together.
