    The reason is that you need *stamp* (time and initial frame) information to transform a point into a different frame, otherwise it has no context. If you want to apply the transform directly, just apply the same operations as the [transformPoint function](https://github.com/ros/geometry/blob/bee989f3f4ab39e7ecf5c1bfe61d73d255b84c69/tf/src/tf/listener.py#L98), using the 4x4 matrix.
