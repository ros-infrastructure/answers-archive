  body_markdown: "Based on personal experience, there are a couple things you can\
    \ try:\n\n - Set [**maximum velocity impulse (max_vel)**](http://www.sdformat.org/spec?ver=1.6&elem=collision#ode_max_vel)\
    \ to 0 to enforce pure position correction with no added momentum from interpenetration\
    \ correction. [[Source]](http://answers.gazebosim.org/question/13506/preventing-bouncing-of-object/)\
    \   \nAlternatively, set to max_vel to some small, non-zero value *(e.g 1-10 m/s)*\
    \ to limit the added momementum from position correction\n\n - Set a [**finite\
    \ minimum allowable interpenetration depth (min_depth)**](http://www.sdformat.org/spec?ver=1.6&elem=collision#ode_min_depth)\
    \ of 0.001 [m] (more generally a small value relative to the scale of the colliding\
    \ objects. [[Source]](http://answers.gazebosim.org/question/13506/preventing-bouncing-of-object/)\n\
    \n----------\nIf that doesn't make a difference, you may also try **decreasing\
    \ the physics simulation step size** to get a better solution as explained [here](https://answers.ros.org/question/12695/gazebo-freaks-when-joints-hit-limits/).\
    \ This will reduce numerical instability but also slow down your simulation."
