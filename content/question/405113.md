    For the robot-description you should maybe add the line

        <param name="robot_description" command="$(find xacro)/xacro.py '$(find mybot_description)/urdf/mybot.xacro'"/>

    which is included in  mybot_ws/src/mybot_description/launch/mybot_rviz_amcl.launch.
    Also in order to receive laser data you need either a simulated map (using gazebo) or there has to be some recorded laser_data somewhere.

    Since there is a directory called "mybot_gazebo" I suggest you include the launch file in your code and see what happens:

        <include  file="$(find mybot_gazebo)/mybot_world.launch/>
    If not everything works at once, maybe try to figure out which launch file work for you from the cold.
    Cheers, Lascho
