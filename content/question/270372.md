  body_markdown: "Thx for the update, I can see the problem. `rtabmap_ros` cannot\
    \ subscribe to scan topics when using stereo topics (for synchronization issue).\
    \ We should use rgb/depth interface instead. \n\nTo make sure we are using exactly\
    \ synchronized camera topics while we are subscribing to a scan topic (approximately\
    \ synchronized), we need to use the [rtabmap_ros/rgbd_sync](https://github.com/introlab/rtabmap_ros/blob/master/src/nodelets/rgbd_sync.cpp)\
    \ nodelet prior to rtabmap node. Here is an example using direclty rgb/depth images\
    \ from [zed_wrapper](https://github.com/stereolabs/zed-ros-wrapper) (`zed_rgbd_mode:=true`)\
    \ or using [stereo_image_proc](http://wiki.ros.org/stereo_image_proc) to generate\
    \ depth image from left/right images of [zed_wrapper](https://github.com/stereolabs/zed-ros-wrapper)\
    \ (`zed_rgbd_mode:=false`). You will need latest version of [rtabmap.launch](https://github.com/introlab/rtabmap_ros/blob/master/launch/rtabmap.launch)\
    \ and this is tested with this [version](https://github.com/stereolabs/zed-ros-wrapper/commit/3ea5cd16c9bd70694d284d1085d200e791ad9ac9)\
    \ of [zed_wrapper](https://github.com/stereolabs/zed-ros-wrapper) (we should apply\
    \ an optical rotation for the stereo mode).\n\n    <launch>\n       \n       <arg\
    \ name=\"zed_rgbd_mode\"        default=\"false\"/>\n       <arg name=\"subscribe_scan_cloud\"\
    \ default=\"true\"/>\n       <arg name=\"frame_id\"             default=\"base_link\"\
    />\n       <arg name=\"rtabmap_args\"         default=\"--delete_db_on_start\"\
    />\n    \n       <arg name=\"pi/2\" value=\"1.5707963267948966\" />\n       <arg\
    \ name=\"optical_rotate\" value=\"0 0 0 -$(arg pi/2) 0 -$(arg pi/2)\" />\n   \
    \    <node     if=\"$(arg zed_rgbd_mode)\" pkg=\"tf\" type=\"static_transform_publisher\"\
    \ name=\"camera_base_link\" \n           args=\"0 0 0 0 0 0 $(arg frame_id) zed_center\
    \ 100\" /> \n       <node unless=\"$(arg zed_rgbd_mode)\" pkg=\"tf\" type=\"static_transform_publisher\"\
    \ name=\"camera_base_link\" \n           args=\"$(arg optical_rotate) $(arg frame_id)\
    \ zed_center 100\" /> \n    \n       <group ns=\"/zed\" >\n    \n          <include\
    \ file=\"$(find zed_wrapper)/launch/zed_camera.launch\">\n             <arg name=\"\
    publish_tf\" value=\"false\"/>\n          </include> \n    \n          <node unless=\"\
    $(arg zed_rgbd_mode)\" pkg=\"stereo_image_proc\" type=\"stereo_image_proc\" name=\"\
    stereo_image_proc\">\n             <remap from=\"left/image_raw\"    to=\"left/image_rect_color\"\
    />\n             <remap from=\"left/camera_info\"  to=\"left/camera_info\"/>\n\
    \             <remap from=\"right/image_raw\"   to=\"right/image_rect_color\"\
    />\n             <remap from=\"right/camera_info\" to=\"right/camera_info\"/>\n\
    \             <param name=\"disparity_range\" value=\"200\"/>\n          </node>\n\
    \    \n          <node pkg=\"nodelet\" type=\"nodelet\" name=\"camera_nodelet_manager\"\
    \  args=\"manager\"/>\n          <node unless=\"$(arg zed_rgbd_mode)\" pkg=\"\
    nodelet\" type=\"nodelet\" name=\"disparity2depth\" \n             args=\"load\
    \ rtabmap_ros/disparity_to_depth camera_nodelet_manager\"/>\n          \n    \
    \      <node     if=\"$(arg zed_rgbd_mode)\" pkg=\"nodelet\" type=\"nodelet\"\
    \ name=\"rgbd_sync\" args=\"load rtabmap_ros/rgbd_sync camera_nodelet_manager\"\
    >\n             <remap from=\"rgb/image\"       to=\"rgb/image_rect_color\"/>\n\
    \             <remap from=\"depth/image\"     to=\"depth/depth_registered\"/>\n\
    \             <remap from=\"rgb/camera_info\" to=\"rgb/camera_info\"/>\n     \
    \        <param name=\"approx_sync\"     value=\"false\"/>\n          </node>\n\
    \          <node unless=\"$(arg zed_rgbd_mode)\" pkg=\"nodelet\" type=\"nodelet\"\
    \ name=\"rgbd_sync\" args=\"load rtabmap_ros/rgbd_sync camera_nodelet_manager\"\
    >\n             <remap from=\"rgb/image\"       to=\"left/image_rect_color\"/>\n\
    \             <remap from=\"depth/image\"     to=\"depth\"/>\n             <remap\
    \ from=\"rgb/camera_info\" to=\"left/camera_info\"/>\n             <param name=\"\
    approx_sync\"     value=\"false\"/>\n          </node>\n       </group>\n    \
    \              \n       <include file=\"$(find rtabmap_ros)/launch/rtabmap.launch\"\
    >\n          <arg name=\"frame_id\"                value=\"$(arg frame_id)\"/>\n\
    \          <arg name=\"subscribe_rgbd\"          value=\"true\"/>\n          <arg\
    \ name=\"subscribe_scan_cloud\"    value=\"$(arg subscribe_scan_cloud)\" />\n\
    \          <arg name=\"approx_sync\"             value=\"true\"/>\n          <arg\
    \ name=\"rgbd_topic\"              value=\"/zed/rgbd_image\" />\n          <arg\
    \ name=\"scan_cloud_topic\"        value=\"/velodyne_points\" />\n          <arg\
    \ name=\"rtabmap_args\"            value=\"$(arg rtabmap_args)\"/>\n    \n   \
    \       <arg name=\"rtabmapviz\"              value=\"false\"/>\n          <arg\
    \ name=\"rviz\"                    value=\"true\"/>\n       </include>\n    \n\
    \    </launch>\n\nAnother optimization would be to use the zed nodelet inside\
    \ the camera nodelet manager to avoid some serialization/deserialization.\n\n\
