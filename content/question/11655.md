    \ the message type just happens to be a string, whereas the message type you want\
    \ to be publishing is not a string, but a geometry_msgs/Twist. At the top of your\
    \ while loop, you should have something like \n\n    geometry_msgs::Twist msg;\n\
    \nthen you need to fill in the message's data fields:\n\n    msg.linear.x = 10;\n\
    \    msg.angular.z = 5;\n\nThe syntax you're using is only for the command line\
    \ tool *rostopic pub*.\n\n\nTo visualize a laser scan, you should check out [rviz](http://www.ros.org/wiki/rviz/UserGuide)."
