    It should be possible to do it from a GUI plugin. Just get the user camera:

    [rendering::UserCameraPtr camera = gazebo::gui::get_active_camera();](http://osrf-distributions.s3.amazonaws.com/gazebo/api/7.1.0/namespacegazebo_1_1gui.html#a1cc301f227f0717038ae271fa789bd06)

    And set the new clip distances:

    [camera->SetClipDist(near, far);](http://osrf-distributions.s3.amazonaws.com/gazebo/api/7.1.0/classgazebo_1_1rendering_1_1Camera.html#a36b189060fbbaf495e16751364367718)
