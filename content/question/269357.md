  body_markdown: "`.srdf` != `.sdf`.\n\n`srdf` files are MoveIt Robot Semantic Description\
    \ files. `sdf` is Gazebo's Simulation Description Format.\n\nThose are not related\
    \ and you cannot load an `srdf` file in Gazebo.\n\n> What doesn't make sense is\
    \ why the tutorial tells me I should be able to **simply load up a SRDF file**\n\
    \nI don't believe it actually tells you that SRDF is supported.\n\n> This spawns\
    \ the robot in Gazebo but not without fidgeting completely (possibly due to self-collisions)\
    \ and jumping 1000 ft in the air. \n\nOne thing to check is that you have your\
    \ robot linked to the `world` frame using a `fixed` joint."
