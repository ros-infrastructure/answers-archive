  body_markdown: |
    You need to install and run the [URG node](http://wiki.ros.org/urg_node) (URG is the protocol the hokuyo sensors use) which will connect to the hardware and publish the laser scan messages to the ROS system. You should be able to install this easily using apt-get.

    By default this node publishes laser scan messages on the `/scan` topic, you can change this using a [remap](http://wiki.ros.org/roslaunch/XML/remap) in your launch file to any topic name you want.

    Hope this helps.
