  body_markdown: "If you just upgraded you need to make sure that all generated and\
    \ itermediate files are removed before recompiling. The build system cannot track\
    \ changes to system libraries, you need to force it to refind them and remove\
    \ all references to the old files. Typically this involves an rm -rf of build\
    \ devel and install folders. Or the isolated versions if using isolated builds.\
    \ \n\nEdit: \n\nThe missing files are installed by libboost-regex1.54-dev on my\
    \ system: \n\n    $ dpkg -L libboost-regex1.54-dev\n    /.\n    /usr\n    /usr/share\n\
    \    /usr/share/doc\n    /usr/share/doc/libboost-regex1.54-dev\n    /usr/share/doc/libboost-regex1.54-dev/copyright\n\
    \    /usr/lib\n    /usr/lib/x86_64-linux-gnu\n    /usr/lib/x86_64-linux-gnu/libboost_regex.a\n\
    \    /usr/share/doc/libboost-regex1.54-dev/changelog.Debian.gz\n    /usr/lib/x86_64-linux-gnu/libboost_regex.so\n\
    \nYou need to make sure that cmake can find boost correctly and invalidate any\
    \ cmake caches if the version or location of boost has changed. (rm -rf of build\
    \ and devel are the recommended way to make sure to invalidate those caches. If\
    \ you're linking against other things compiled from source you will need to rebuild/link\
    \ them as well.)"
