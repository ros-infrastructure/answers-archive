    Assuming that you are using Ubuntu and installed ROS following the [instructions on the wiki](http://wiki.ros.org/kinetic/Installation/Ubuntu), the sources are not installed in your computer. Just the binaries.

    If you want to modify the code on base_local_planner, you will have to clone the source code from the [github repository](https://github.com/ros-planning/navigation/tree/kinetic-devel/base_local_planner) into your workspace, do your modifications and compile.

    Hope this helps
