  body_markdown: "If you have a ROS project and you want to use SIFT algorithm, there\
    \ is an implementation in OpenCV library. \n\nIf you choose the OpenCV 3, you\
    \ will need to download an external modul [opencv_contrib](https://github.com/opencv/opencv_contrib)\
    \ and give it as a flag to the cmake [while installing](https://www.youtube.com/watch?v=JLohXMh6XZY)\
    \ the  OpenCV 3 library. I haven't manage to make this solution work, since other\
    \ packages in my project requested OpenCV 2.\n\nI used [OpenCV 2.4.8](https://github.com/opencv/opencv/releases/tag/2.4.8).\
    \ \n\n 1. Download the source code\n 2. Make a new folder inside the OpenCV 2.4.8\
    \ folder. Name it 'build'\n 3. In console, go into 'build' folder and run following\
    \ commands\n\nCommands:\n\n 1. cmake -D CMAKE_INSTALL_PREFIX=/usr/include/ ..\n\
    \ 2. make\n 3. sudo make install\n\nthe '/usr/include/' is the path where the\
    \ OpenCV will be installed. \n\n'..' tells the cmake where to find the source\
    \ code for the OpenCV (that means one folder up).\n\nWhen you have the OpenCV\
    \ installed, you have to link it with your ROS project. In the 'CMakeLists.txt'\
    \ of your project add following lines:\n\n     find_package(OpenCV 2.4.8 EXACT\
    \ REQUIRED)\n      \n     SET(OpenCV_LIBRARIES opencv_core opencv_highgui opencv_imgproc\
    \ opencv_nonfree opencv_features2d)\n     \n     catkin_package(\n     DEPENDS\
    \ system_lib opencv2\n     ...\n     )\n      \n     include_directories(\n  \
    \   ${OpenCV_INCLUDE_DIRS}\n     ...\n     )\n      \n     target_link_libraries(\
    \ ${PROJECT_NAME}_my_node ${catkin_LIBRARIES} ${OpenCV_LIBRARIES})\n\nWhen you\
    \ set 'OpenCV_LIBRARIES' you can only set those that you actually need. I left\
    \ there all the other libraries because I think you will use then in your project\
    \ anyway. \n\nYou have to include the header files into your project source file.\n\
    \n    #include <opencv2/opencv.hpp>\n    #include <opencv2/nonfree/nonfree.hpp>\n\
    \nNow you can use one of the many examples to use SIFT in your project. For example\
    \ [here](https://fahmifahim.com/2012/12/11/opencv-sift-implementation-in-opencv-2-4/),\
    \ [here](https://gist.github.com/thorikawa/3398619) or [here](https://stackoverflow.com/a/22723961/1869157)."
