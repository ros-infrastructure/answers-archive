  body_markdown: "The [usual way](http://www.ros.org/wiki/roslocate) to find the correct\
    \ source *should* be:\n\n    $ roslocate info ros_comm --distro=fuerte\n\nHowever,\
    \ that does not seem to work for `ros_comm` in Fuerte.\n\nOn my system, leaving\
    \ off the `--distro` option yields this:\n\n    $ roslocate info ros_comm \n \
    \   - svn:\n        local-name: ros_comm\n        uri: https://code.ros.org/svn/ros/stacks/ros_comm/trunk\n\
    \nThat is probably not the exact version released with Fuerte. Assuming that the\
    \ repository is at least correct, I'd recommend checking this out, instead:\n\n\
    \    https://code.ros.org/svn/ros/stacks/ros_comm/tags/fuerte/\n\nThe recommended\
    \ way to manage source overlays is with [rosws](http://www.ros.org/doc/api/rosinstall/html/rosws.html).\
    \ There are already answers for questions about `rosws` on this same Q&A site."
