  body_markdown: |-
    Gazebo's API is quite extensive, so it's probably not viable to "learn" all the functions. Depending on your use case, only a fraction of the functions will be relevant. For example, if you want to apply forces and velocities to parts of your robot, you'd need some functions from [gazebo::physics::Link](http://gazebosim.org/api/dev/classgazebo_1_1physics_1_1Link.html) API. To tune a camera sensor, you'd look at [gazebo::sensors::CameraSensor](http://gazebosim.org/api/dev/classgazebo_1_1sensors_1_1CameraSensor.html) and so on.

    Instead of going through the API, I suggest you search for keywords related to the problem you're trying to solve and go through some related tutorials and examples first. This way, you naturally start becoming familiar with the functions.
