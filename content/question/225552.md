  body_markdown: "Looks like you have both the binary version (in /opt/ros/indigo/...)\
    \ and the source version (in /home/hjt/catkin_ws/src/...) installed. So make sure\
    \ you build using catkin so the source version can correctly override the binary\
    \ version.\n\n    cd /home/hjt/catkin_ws\n    source /opt/ros/indigo/setup.bash\n\
    \    catkin_make\n    source /home/hjt/catkin_ws/devel/setup.bash\n\nNow after\
    \ you build your workspace, you always have to source the setup.bash from this\
    \ workspace in order to use it, not the one from /opt/ros/... \nTry this first,\
    \ because as far as I know it should be no problem to have a package both as binary\
    \ and source installed. Only if it doesn't work, try uninstalling the nav2d-binaries.\n\
    \nAnd yes, you shouldn't manually change anything in /opt/ros/.... But it is no\
    \ problem to remove packages using the package manager of your choice (e.g. Synaptic)\
    \ or just apt-get on the command line:\n\n    sudo apt-get remove ros-indigo-nav2d\n"
