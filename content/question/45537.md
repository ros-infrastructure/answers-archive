    1. There is a package named arm_kinematics_constraint_aware under ros/fuerte/stacks/arm_navigation. it can do both forward and inverse kinematics.
    2. according to my understanding, simulation is used mainly for checking. for example, i'd like to do a manipulation first in the simulation to see if it works well. if it does, then i do it with the real robot.
    3. to import your robot into gazebo or rviz, you MUST create URDF first.
    4. the stack [arm_navigation](http://www.ros.org/wiki/arm_navigation) can do most of the things for you. There all also plenty of [tutorials](http://www.ros.org/wiki/arm_navigation/Tutorials). For the preception with camera, you need other packages, e.g., [tod](http://www.ros.org/wiki/tod), [object_recognition](http://www.ros.org/wiki/object_recognition).

    besides, i strongly recommend this tutorial [IROS 2011 Tutorial: Motion Planning for Real Robots](http://www.kavrakilab.org/iros2011). you can read this tutorial first to get a whole picture.
