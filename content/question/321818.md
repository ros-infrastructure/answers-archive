  body_markdown: "On the arduino side, array messages have an extra variable added\
    \ to their class definitions used to define their length. In our case, this means\
    \ that the `Float32MultiArray` msg has a `data` and `data_length` field; in order\
    \ to set the `data` field we first need to set the `data_length` field:\n\n  \
    \  #include <ros.h>\n    #include <std_msgs/Float32MultiArray.h>\n    \n    int\
    \ array_length = 3;\n    float values[array_length] = {1.0, 2.0, 3.0};\n    \n\
    \    ros::NodeHandle nh;\n    std_msgs::Float32MultiArray array_msg;\n    ros::Publisher\
    \ pub(\"array_publisher\", &array_msg);\n    \n    void setup() {\n      nh.initNode();\n\
    \      nh.advertise(pub);\n    }\n    \n    void loop(){\n      array_msg.data_length\
    \ = array_length;\n      array_msg.data = values;\n      pub.publish(&array_msg);\n\
    \      nh.spinOnce();\n      delay(1000);\n    }\n\nFor more information, see\
    \ the [array section of the rosserial limitations page](https://wiki.ros.org/rosserial/Overview/Limitations#Arrays)."

title: Unable to update data field of Float32MultiArray std msg
upvote_count: 0
---
 I am trying to publish a float array. To do this, I am utilizing the Float32MultiArray std message:

    #include <ros.h>
    #include <std_msgs/Float32MultiArray.h>
        
    float values[3] = {1.0, 2.0, 3.0};

    ros::NodeHandle nh;
    std_msgs::Float32MultiArray array_msg;
    ros::Publisher pub("array_publisher", &array_msg);
    
    void setup() {
      nh.initNode();
      nh.advertise(pub);
    }

    void loop(){
      array_msg.data = values;
      pub.publish(&array_msg);
      nh.spinOnce();
      delay(1000);
    }

However, when I rostopic echo the publisher, the message is empty i.e. the data field is unpopulated:

    rostopic echo /array_publisher
    layout:
      dim: []
      data_offset: 0
    data: []
