    \ improve your performance. [Radial Outlier Removal](http://pointclouds.org/documentation/tutorials/remove_outliers.php#remove-outliers)\
    \ might also work. \n\n**EDIT**:\n\nIn order to get a ROS `sensor_msgs/PointCloud2`\
    \ to a pcl cloud, use the following code:\n\n    sensor_msgs::PointCloud2 cloud_in;\n\
    \    pcl::PointCloud<pcl::PointXYZ>::Ptr cloud(new pcl::PointCloud<pcl::PointXYZ>);\n\
    \    pcl::fromROSMsg(cloud_in, *cloud);\n\nThe `cloud` variable will now contain\
    \ a pcl cloud that you can use with the PCL built-in functions. "
