  body_markdown: "**This can be done in two simple steps :**\n\n \n\n 1. Set the operating\
    \ mode to [extended position control mode](http://support.robotis.com/en/product/actuator/dynamixel/mx_series/mx-106(2.0).htm#bookmark5)\
    \ (multi-turn). This can be done by setting the operating_Mode(11) to value 4\
    \ (considering prorocol 2.0). It supports 512 total turns (-256 to +256) however\
    \ these values needs to be mapped in radians or in multiple of resolution according\
    \ to the interface you are using to control the motor. for eg if you use dynamixel\
    \ controller package to control the motor it takes the goal position in radians.\n\
    \    .\n\n 2. Now you can simply use the [goal_position](http://support.robotis.com/en/product/actuator/dynamixel/mx_series/mx-106(2.0).htm#bookmark29)\
    \ to give multi turn value.\n\nA single turn takes the values from 0 to 4096 and\
    \ in multiturn it can take -1,048,575 ~ 1,048,575\n\nif you are using a gui to\
    \ control dynamixel then multi-turn might not be possible because it limits the\
    \ angle values but you can do it by chnaging the [clock-wise](http://support.robotis.com/en/product/actuator/dynamixel/mx_series/mx-106(2.0).htm#bookmark15)\
    \ and [anti-clockwise](http://support.robotis.com/en/product/actuator/dynamixel/mx_series/mx-106(2.0).htm#bookmark15)\
    \ angle limits or check it using the [dynamixel workbench controller](https://github.com/ROBOTIS-GIT/dynamixel-workbench/tree/master/dynamixel_workbench_controllers)\
    \ package. \n\n\n"
