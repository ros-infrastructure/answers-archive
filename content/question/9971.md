  body_markdown: "Ok, problem solved!  The issue was that my device needed a udev\
    \ rule.  I created one, and the camera works great now.  Here was what I did:\n\
    \nFirst, I used `lsusb` with the camera plugged in to determine the USB Vendor\
    \ and Product IDs for my camera:\n\n    bradpowers@bp-rosdev:~$ lsusb\n    Bus\
    \ 002 Device 009: ID 1e10:2000 Point Grey Research, Inc. \n    Bus 002 Device\
    \ 008: ID 093a:2510 Pixart Imaging, Inc. Optical Mouse\n    Bus 002 Device 007:\
    \ ID 05ac:0220 Apple, Inc. Aluminum Keyboard (ANSI)\n    Bus 002 Device 006: ID\
    \ 05ac:1006 Apple, Inc. Hub in Aluminum Keyboard\n    Bus 002 Device 005: ID 05ac:921c\
    \ Apple, Inc. \n    Bus 002 Device 004: ID 0cf3:3002 Atheros Communications, Inc.\
    \ \n    Bus 002 Device 003: ID 05ac:911c Apple, Inc. \n    Bus 002 Device 002:\
    \ ID 8087:0024 Intel Corp. Integrated Rate Matching Hub\n    Bus 002 Device 001:\
    \ ID 1d6b:0002 Linux Foundation 2.0 root hub\n    Bus 001 Device 002: ID 8087:0024\
    \ Intel Corp. Integrated Rate Matching Hub\n    Bus 001 Device 001: ID 1d6b:0002\
    \ Linux Foundation 2.0 root hub\n\nThe device I'm concerned with is the Point\
    \ Grey Research device at the top.  I copied down the ID number, `1e10:2000`.\n\
    \nFrom there, I needed to create a udev rule to add the device to the `plugdev`\
    \ group when plugged in:\n\n    bradpowers@bp-rosdev:~$ sudo gedit /etc/udev/rules.d/10-pointgrey.rules\n\
    \nIn this file, I entered the following:\n\n    # udev rules file for Point Grey\
    \ Firefly-MV\n    BUS==\"usb\", SYSFS{idVendor}==\"1e10\", SYSFS{idProduct}==\"\
    2000\", GROUP=\"plugdev\"\n\nAfter saving, and a reboot, launching my roslaunch\
    \ file worked great.  Thanks to [Andy Barry](http://abarry.org) for a phone call\
    \ and solution so quickly.  \n\n\n\n\n  "
