    \ useful :\n\n    * line 161,what does \u201C *float *potarr \u201D mean, What\
    \ it is used for? What is the difference between \u201Cpotarr array\u201Dand \u201C\
    cost array\u201D?\n\nLiterally speaking, Cost array are the raw cost values for\
    \ each cell from the 2D cost map and Potarr is the potential that the navfn propogation\
    \ function assigns to each cell during traversal which can be later used to find\
    \ the final path using gradient descent.\n\n     line 167*\uFF0Cwhat does \u201C\
    \ int *curp \uFF0C int *nextp \uFF0Cint *overp \u201Dmean,what are they used for?\n\
    \nThe propogation function uses three priority buffers namely current buffer,\
    \ next buffer and over buffers, these three pointer variables that you have mentioned\
    \ point to elements inside the three buffers\n\n    n the navfn/include/navfn/navfn.cpp,\
    \ I think like Astar algorithm (basically understand its principle), in the code\
    \ \uFF0Cthere are two lists, OPEN and CLOSED,where are they ,how does the \"updateCell\
    \ function\"line 472,update ?\n\nUpdate cell function in navfn has the following\
    \ steps in brief :\n\n 1. ensure cell does not have lethal obstacle cost\n 2.\
    \ Find potentials of the four neighbouring cells from potarr (potarr is initialised\
    \ to  inifinity by default) and find the lowest potential among them\n 3. Calculate\
    \ new potential of the cell using this lowest potential and the traversibility\
    \ factor\n 4. If this calculated potential is lower than the existing potential\
    \ of the cell in potarr, assign this potential then use this to calculate the\
    \ new potentials for neighbouring cells as well and push the neighbours to next/over\
    \ buffer accordingly\n\n"
