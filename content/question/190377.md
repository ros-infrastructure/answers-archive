    Xtion 0601 runs using openni2, and 0600 runs using openni. If you want to use the former with ROS, let the [openni2_launch](http://wiki.ros.org/openni2_launch) wrapper run the driver and setup all the topics for you. It will also install all the correct dependencies:

    `sudo apt-get install ros-hydro-openni2-launch`

    If you're looking for Openni2 specific documentation, it's now hosted by Occipital (http://structure.io/openni).
