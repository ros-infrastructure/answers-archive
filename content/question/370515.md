    If you check the Jenkins jobs tab on the [smach docs](http://wiki.ros.org/smach) under kinetic you'll notice a binary for buster is missing, meaning you won't find it as an apt package. Is there a reason you're still working with Kinetic? You should see the binaries exist for Noetic. I'd recommend upgrading your ROS distro, if for nothing else than in anticipation of Kinetic reaching EOL in a few months. I have smash (as a dependency of [flexbe](http://wiki.ros.org/flexbe)) working in a [docker](https://www.docker.com/) container using Noetic on a RPi4. So it's possible, but you  may need to do some major changes
  comments:
  - body_markdown: |-
      Or, if you are set on kinetic for whatever reason, you could try building smach from [source](https://github.com/ros/executive_smach). Just create a catkin_ws/src in your home directory and clone the above repo into it. You should then be able to use `catkin build` to make smach.
