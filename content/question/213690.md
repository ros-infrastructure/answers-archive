  body_markdown: "No, you **have to** specify this in the `CMakeLists.txt` manually.\
    \ How should the compiler know which src and header files to compile together\
    \ (besides magic. thanks for pointing this out in the comments ;-) )?\n\n----------\n\
    \nA problem I see in your `CMakeLists.txt` is the target name for your executables\
    \ and libraries.\nThey should not start with a `$` sign. The dollar sign with\
    \ curly brackets is for getting the values of variables, as it is done correctly\
    \ below when linking against the `${catkin_LIBRARIES}` (I'm not sure if the other\
    \ two exist).\n\nso it should be:\n\n      add_library(image_convert src/image_converter.cpp)\n\
    \      target_link_libraries(image_convert\n        ${avcodec_LIBRARIES}\n   \
    \     ${swscale_LIBRARIES}\n        ${catkin_LIBRARIES}\n      )\n    \n     \
    \ add_executable(image_convert_node src/image_converter.cpp)\n      target_link_libraries(image_convert_node\n\
    \        image_convert\n        ${avcodec_LIBRARIES}\n        ${swscale_LIBRARIES}\n\
    \        ${catkin_LIBRARIES}\n       )\n    \n       add_library(image_invert\
    \ src/image_invert.cpp)\n       target_link_libraries(image_invert\n         ${avcodec_LIBRARIES}\n\
    \         ${swscale_LIBRARIES}\n         ${catkin_LIBRARIES}\n       )\n    \n\
