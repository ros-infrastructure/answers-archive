  body_markdown: "If you play back the bag, you can use: \n\n    rostopic echo -p\
    \ /topic_name\n\nto display the data in a MatLab-friendly format. You can output\
    \ this to a text file with:\n\n    rostopic echo -p /topic_name > data.txt\n\n\
    Or, you can even convert a topic directly to CSV with:\n\n    rostopic echo -b\
    \ file.bag -p /topic\n\nNOTE: This will only work with simple message types. LaserScans,\
    \ PointClouds, arrays, etc won't work very well because the entire message is\
    \ rendered to text. \n\nThe other option would be to use the rosbag API, located\
    \ [here](http://www.ros.org/wiki/rosbag/Code%20API#cpp_api) to load the data into\
    \ a C++ program and manipulate it that way. "
