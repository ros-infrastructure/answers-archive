 [Subscribers](http://docs.ros.org/en/melodic/api/rospy/html/rospy.topics.Subscriber-class.html) in rospy can be optionally passed callback_args on creation. This is really handy when you have one callback for multiple incoming topics and you want to do topic-specific stuff for a given message. Equivalent functionality does not appear to be built into c++ [subscribers](http://docs.ros.org/en/melodic/api/roscpp/html/classros_1_1Subscriber.html)

Is there some way to achieve the same thing in C++?

Context:

I have arbitrary number of multiple incoming topics each with corresponding outgoing topics - and a single callback that does the computation for an incoming topic and needs to publish the results to the correct outgoing topic.
