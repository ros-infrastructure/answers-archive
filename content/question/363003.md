  body_markdown: "As far as I can remember, in `roscpp` arrays in messages' attributes\
    \ are actually `vector`s (I'd appreciate it if someone can help me with the docs\
    \ on this or a correction), so you'd treat any message attribute that's an array\
    \ as a `vector`.\n\n> 1). How to assign data from the publisher to the `my_struct[].data`\
    \ member in `my_msg` ? \n\nJust like you would with a vector (e.g., use the vector's\
    \ `push_back` method).\n\n> 2). How to subscribe this data from a different ROS\
    \ node ?\n\nJust like you would with any other subscriber., create a callback\
    \ function and and create a subscriber.\n\nCallback: \n\n    void myCallback(const\
    \ std_msgs::my_struct::ConstPtr& msg)\n    {\n      // process data here\n   \
    \ }\n\nSubscriber:\n\n    ros::Subscriber sub = n.subscribe(\"my_struct_topic\"\
    , 1000, myCallback);\n\n> 3). What should be the changes in `CMakeLists.txt` (apart\
    \ from adding `my_msg.msg` & `my_struct.msg`) ?\n\nWithout seeing your `CMakeLists.txt`\
    \ it's impossible to say *exactly* but you'd need to use the `genmsg` and `std_msgs`,\
    \ add your message files, and then generate the messages that you added\n\n  \
    \  # include any other packages you're using\n    find_package(catkin REQUIRED\
    \ COMPONENTS roscpp std_msgs genmsg)\n\n    # Declare ROS messages (assuming the\
    \ message files are in a directory called msg\n    add_message_files(DIRECTORY\
    \ msg FILES my_struct.msg my_struct.msg)\n\n    # Generate added messages\n  \
    \  generate_messages(DEPENDENCIES std_msgs)\n\nBy the way, this all found in the\
    \ [tutorials](http://wiki.ros.org/ROS/Tutorials/CreatingMsgAndSrv) that @duck-development\
    \ pointed you to (specifically [this one](http://wiki.ros.org/ROS/Tutorials/WritingPublisherSubscriber%28c%2B%2B%29)).\
    \ I'm not currently at a computer with ROS installed, so if there's any issues\
    \ here please let me know. This is basically the gist of it though."
