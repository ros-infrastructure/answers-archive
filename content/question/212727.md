  body_markdown: "There are several ways to do this, and the best and the simplest\
    \ one is to write your own package for this, as per your requirement; \nHere you\
    \ need two exactly synchronized images at any given moment so subscribe to both\
    \ the topics using [msg_filter](http://wiki.ros.org/message_filters)  (see the\
    \ section 7.2). once you are in call-back function convert both the images to\
    \ cv::Mat and save them using imwrite(\"filenam\",cv::Mat var) function. this\
    \ way you can be sure about their time stamp.\n\nanother way is, using image_view\
    \ package which comes with image_pipeline. \n>>rosrun image_view extract_images\
    \ _sec_per_frame:=0.01 image:=(image_topic_name)  [tLink](https://coderwall.com/p/qewf6g/how-to-extract-images-from-a-rosbag-file-and-convert-them-to-video)\n\
    \ \nyou will have to run this package for both the topics separately, but be sure\
    \ that both the time you get same number of images (in your case 171 images).\
    \ (otherwise they arent stereo-images). one issue here is, this package save the\
    \ images in jpg format which can have some data loss due to jpg compression.\n\

    \n--------------------------------------  EDIT  -------------------------------------------------\
    \   \nAfter googling around a bit I have found two possible solutions that are\
    \ already available to extract synched stereo_pairs from a rosbag.\n\nMethod 1)\
    \ Use the rospy node that comes inside image_view from the image_pipeline. It\
    \ can be run with  \nrosrun image_view extract_images_sync _inputs:='[/camera/left/image_raw,/camera/right/image_raw]'\
    \  \n\nJust modify the topic names and the rospy node according to your needs.\
    \  \n\nMethod 2) Use this package    http://wiki.ros.org/bag_tools?distro=indigo\
    \   \nIt has some nice tools for working with rosbags acquired with stereo_cameras.\n\
    \nI hope this can be helpful to other ROS users!\n\nCheers!"
