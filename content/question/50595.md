  body_markdown: "You cannot edit this file because this file belongs to user postgres,\
    \ you didn't have privilege to edit this file.This can be verified by using\n\n\
    \    ls -l /etc/postgresql/9.1/main/pg_ident.conf \n\nYou can edit this file in\
    \ two ways.\n\n1.Change to user postgres\n\n    sudo su - postgres\n\nThen edit\
    \ the file by\n\n    vim /etc/postgresql/9.1/main/pg_ident.conf\n\n2.Use root\
    \ privilege to edit the file\n\n    sudo vim /etc/postgresql/9.1/main/pg_ident.conf\n\
    \nIf you didn't have vim installed yet, use\n\n    sudo apt-get install vim \n\
    \nOnce you enter vim editor, press \"i\" to become INSERT mode, and you can edit\
    \ the file. When you finished editing, type \":wq\" to save the file and leave\
    \ vim editor."
