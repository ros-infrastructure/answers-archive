  body_markdown: "If you use Time(0) construction it asks for the \"latest valid time\"\
    . If you stop publishing a transform the transform still exists at the older time\
    \ and tf will return it. \n\nIt is good practice to bounds check the timestamp\
    \ of the returned transform if there is some expected valid range.  You can see\
    \ it through `listener.getLatestCommonTime`"
