  body_markdown: "Yes, I think you'll have to implement a plugin for this. But note\
    \ that cutting power is different from braking as the robot may continue to move\
    \ due to its momentum if you just cut power from the motors. If you want to brake,\
    \ you can use the `HaltMotion` component (https://github.com/gazebosim/gz-sim/blob/gz-sim7/include/gz/sim/components/HaltMotion.hh)\
    \ \n\nAnother option is to use the [TriggeredPublisher](https://gazebosim.org/api/sim/7/triggeredpublisher.html)\
    \ plugin to publish a 0 velocity command to the joint controllers when the safety\
    \ scanner detects the robot (e.g. Lidar value is below a threshold). This option\
    \ would avoid writing a plugin."
