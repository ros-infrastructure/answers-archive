    \ from the `build` directory of the gtsam package, as described [here](https://github.com/borglab/gtsam/issues/562).\n\
    \ - I deleted the whole gtsam package directory with `sudo rm -r gtsam/`\n - I\
    \ downloaded again the gtsam package by cloning the repository from [here](https://github.com/borglab/gtsam):\
    \ `git clone https://github.com/borglab/gtsam.git`\n - I reinstalled the package\
    \ from source, as described [here](https://gtsam.org/get_started/).\nNote: I changed\
