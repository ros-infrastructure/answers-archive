Because alot of the time, all it takes is for me to manually teleop the robot for a couple seconds and the robot is able to autonomously move to the goal by itself. Basically all it takes is that the robot is jolted back into motion and then the path planner resolves itself. What I'm doing right now running my protocol algorithm at the same time as my motion algorithm(which a series of  goals, one at a time) via same launch file.
