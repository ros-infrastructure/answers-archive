  body_markdown: |-
    You've mixed up the parameters to `tf2_ros.TransformListener`. The first parameter should should be the buffer and the second parameter should be the node ([reference](https://github.com/ros2/geometry2/blob/0304f4822734b1bceeb377d0fdf72ece11f4ccec/tf2_ros_py/tf2_ros/transform_listener.py#L52-L53)). Try changing your code to:



            self.listener = tf2_ros.TransformListener(self.buffer, self)
