I am using ROS_CANOpen to control a differential drive robot, and using the "profiled position" drive mode.  I used schunk_lwa4p as a template:
https://github.com/ipa320/schunk_robots/tree/indigo_dev/schunk_lwa4p

When I publish my target position to the topic /arm/joint_group_position_controller/command, sometimes my motors do not start at the same time.  Checking my logs, I found that sometimes one motor will begin moving one sync interval later than the other.  This is very noticeable because I am having to run at a very slow sync interval of 200ms as a result of this ROS_CANOpen issue: https://github.com/ipa320/schunk_robots/issues/59 and the seemingly related https://github.com/ros-industrial/ros_canopen/issues/102 (which increasing tx queue length helps but doesn't resolve). 

It may be notable that I could not reproduce this problem using "profile velocity" mode.
