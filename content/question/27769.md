  body_markdown: "With the following commands (see repo) you can start the gazebo\
    \ environment and rviz (ros visualization) gui.\n\n - roslaunch myrobot_gazebo\
    \ myrobot_world.launch (3D environment - gazebo)\n - roslaunch myrobot_description\
    \ myrobot_rviz.launch ( visualization gui for visualizing ROS topics)\n\nOffcourse\
    \ ROS should be installed to do so.\n\n> What exactly are these files?\n\nThese\
    \ are the files describing your robot. If you want to change the appearance of\
    \ the robot. That's the place.\n\n>What exactly is the world folder and what does\
    \ it contain?\n\nThe .world file describes your  gazebo world. A first look you\
    \ are using an empty world.\n\nIf you want to control the robot you will have\
    \ to publish a rostopic ( [cmd_vel](http://wiki.ros.org/turtlesim/Tutorials/Moving%20in%20a%20Straight%20Line))\
