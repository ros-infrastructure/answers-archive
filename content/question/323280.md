    AMCL needs a map in order to localize the robot. A common tactic is using gmapping to create this map, save it using map_server, and then serve it to AMCL.

  body_markdown: "I believe the Gmapping node just uses a particle filter with a fixed\
    \ number of particles.  The pose estimate generated by the gmapping node is basically\
    \ not published but internally estimates the position. To increase localization\
    \ while mapping you can increase the particles at the cost of computation. AMCL\
    \ basically works on a generated map and dynamically assigns particles based on\
    \ KL Distance. Hope it helps. "
