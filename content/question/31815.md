  body_markdown: "The best way to get the current location of the Turtlebot is using\
    \ [TF](http://ros.org/wiki/tf). Assuming you are in C++ and already have a tf::TransformListener\
    \ object as `listener`, that your robot's local frame is `base_link` and your\
    \ map frame is `map`, you could use a block of code like the following:\n\n  \
    \  geometry_msgs::PoseStamped pBase, pMap;\n    pBase.header.frame_id = \"base_link\"\
    ;\n    pBase.pose.position.x = 0.0;\n    pBase.pose.position.y = 0.0;\n    pBase.pose.orientation\
    \ = tf::createQuaternionMsgFromYaw(0.0);\n    ros::Time current_transform = ros::Time::now();\n\
    \    listener.getLatestCommonTime(pBase.header.frame_id, \"map\", current_transform,\
    \ NULL);\n    pBase.header.stamp = current_transform;\n    listener.transformPose(\"\
    map\", pBase, pMap);\n    // pMap now contains the pose of the robot transformed\
    \ into map \n    // coordinates according to the TF data available at time \"\
    current_transform\"\n\nIf you are unfamiliar with the TF library, you should read\
    \ through the tutorials."
