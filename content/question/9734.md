  body_markdown: "Right now I'm just replacing the RPATH prefixes in the freshly created\
    \ binaries by this little script which is part of the deployment.\ncall it this\
    \ way\n\n`> script /path/to/ros_node1 /path/to/ros_node2`\n\nand your executables\
    \ will be replaced with new rpaths.\n \n\n    SEARCH_PATH=\"/home/phil/ros/cturtle\"\
    \n    REPLACE_PATH=\"/opt/ros/cturtle\"\n\n    which chrpath > /dev/null\n   \
    \ if [ $? != 0 ]; then\n        echo \"Couldn't find the program 'chrpath'. Maybe\
    \ it's existant but not found in the PATH searchpath\"\n        echo \"exit...\"\
    \n        exit 1\n    fi\n\n    if [ $# -lt 1 ]; then\n        echo \"Please specifiy\
    \ a list of files which you want to work on...\"\n        echo \"e.g: \\$ replace_rpath\
    \ program1 program2\"\n        exit 1\n    fi\n\n    for FILE in $@ ; do\n   \
    \     echo \"-- Preparing $FILE\"\n        if [ ! -e \"$FILE\" ] || [ ! -f \"\
    $FILE\" ]; then\n                echo \"'$FILE' is either not a file or doesn't\
    \ exist!\"\n        else\n                chrpath -l $FILE  | sed -e \"s+.*=++g\"\
    \ -e \"s+${SEARCH_PATH}+${REPLACE_PATH}+g\" | xargs -I {} chrpath -r {} $FILE\n\
    \                if [ $? != 0 ]; then\n                        echo \"chrpath\
    \ failed!\"\n                fi\n        fi\n    done\n\nNot nice, but at least\
    \ a starting point.\nI'm still looking forward for other - not so brutal - solutions."
