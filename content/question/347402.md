    This worked for me:

        sudo apt-get install python3-catkin-pkg-modules
        sudo apt-get install python3-rospkg-modules



    Refer: Gustavo's answer - https://answers.ros.org/question/245967/importerror-no-module-named-rospkg-python3-solved/?answer=298221#post-id-298221
