    A bit mask is basically a binary representation using 1s and 0s as switch values like `ON` and `OFF`. So for example if you have a byte(8bits) 0000 0000, you will say all your 8 bits of the byte are set to 0 or `OFF`. If you perform and OR operation between bytes, only those bits that are different will set to 1, thus is a quick way to find out what has changed instead of checking each parameter. For more information on bitwise operations: https://www.clivemaxfield.com/masking-and-the-c-c-bitwise-operators/
