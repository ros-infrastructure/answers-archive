  body_markdown: "> I understand how to make nodes, but how can I access to lidar\
    \ data ...\n\nThis sentence is confusing in a sense. Anyway, let's break your\
    \ problem into pieces and solve them:\n\n 1. detect an object from 1.0[m] to 1.5[m],\
    \ using a lidar\n    \n  To do this task, we need to create a subscriber first,\
    \ and then inside the callback, we can pick the angles based on our criteria.\
    \ In this case, the criteria is the distance of the object.\n 2. send angle information\
    \ to another node\n\n  To do this task, we need to create a publisher that can\
    \ publish the angle data. Then, the published data can be acquired by other nodes\
    \ easily.\n\nPlease see the complete code below:\n\n    #!/usr/bin/env python\n\
    \    # -*- coding: utf-8 -*-\n    \n    import rospy\n    from sensor_msgs.msg\
    \ import LaserScan\n    from std_msgs.msg import Float32MultiArray\n    \n   \
    \ pub = rospy.Publisher('/detected_object', Float32MultiArray, queue_size=1)\n\
    \    \n    \n    def callback(msg):\n        # let's define a range\n        distance_min\
    \ = 1.0\n        distance_max = 1.5\n    \n        result = Float32MultiArray()\n\
    \        for i, r in enumerate(msg.ranges):\n            # we need object in 1\
    \ to 1.5 m range\n            if distance_min < r < distance_max:\n          \
    \      angle = msg.angle_min + i * msg.angle_increment\n                result.data.append(angle)\n\
    \        pub.publish(result)\n    \n    \n    def objectDetector():\n        rospy.init_node('object_detector',\
    \ anonymous=True)\n        rospy.Subscriber('/base_scan', LaserScan, callback)\n\
    \        rospy.spin()\n    \n    \n    if __name__ == '__main__':\n        objectDetector()\n\
    \n\nI used [a recorded bag file](http://classes.engineering.wustl.edu/cse550/data/Mapping1.bag)\
    \  file mentioned in [this wiki page](http://wiki.ros.org/laser_pipeline/Tutorials/IntroductionToWorkingWithLaserScannerData)\
    \ to run the above code. Please see below an example: Please see below a demonstration:\n\
    \n    $ rosrun my_package object_detector.py \n    $ rostopic echo /detected_object\n\
