  body_markdown: "The following instructions work for me on OS X 10.9 after patching\
    \ a few packages. This builds, but I haven't tested running it. `avahi` seems\
    \ to be a Linux-only thing, so we won't install related packages. I guess you\
    \ don't need them for you purpose.\n\n**Edit:** forgot one patch.\n\n    mkdir\
    \ turtlebot_ws\n    cd turlebot_ws\n    . /opt/ros/hydro/setup.bash\n\n    # download\
    \ source, but exclude zeroconf_avahi since this seems to be linux only thing\n\
    \    rosinstall_generator turtlebot_gazebo --rosdistro hydro --deps --wet-only\
    \ --tar --exclude RPP zeroconf_avahi > turtlebot.list\n    wstool init -j8 src\
    \ turtlebot.list\n    \n    # manually install dependencies (rosdep rules are\
    \ not complete on osx)\n    brew install libftdi0 libusb-compat\n    \n    # the\
    \ following is a dependency, but not needed for compiling. So you might need them\
    \ to execute, or you might not.\n    brew install redis\n    \n    # check what\
    \ rosdep has to say\n    rosdep check --from-path src -i --skip-keys \"avahi-utils\
    \ ftdi-eeprom libftdi-dev avahi-daemon libusb-dev redis-server\"\n    # this should\
    \ only tell you to install \"gcc\" and \"ros/hydro/zeroconf_avahi_suite\", ignore\
    \ those. \n    # Install any additional packages coming up here by hand.\n\n \
    \   # apply patches\n    pushd src/openni_camera\n    curl https://github.com/ros-drivers/openni_camera/pull/22.patch\
    \ | patch -p1\n    popd\n\n    pushd src/ecl_core\n    curl https://github.com/stonier/ecl_core/pull/36.patch\
    \ | patch -p1\n    popd\n\n    pushd src/ecl_lite\n    curl https://github.com/stonier/ecl_lite/pull/5.patch\
    \ | patch -p1\n    popd\n\n    pushd src/kobuki_desktop\n    curl https://github.com/yujinrobot/kobuki_desktop/pull/30.patch\
    \ | patch -p1\n    popd\n\n    pushd src/turtlebot_create_desktop\n    curl https://github.com/turtlebot/turtlebot_create_desktop/pull/14.patch\
    \ | patch -p1\n    popd\n\n    pushd src/kobuki_core\n    curl https://github.com/yujinrobot/kobuki_core/pull/14.patch\
    \  | patch -p1\n    popd\n\n    # build\n    catkin_make -DCMAKE_BUILD_TYPE=Release"
