    Each action server publishes 5 topics (my server is named `test` below):

        /test/cancel
        /test/feedback
        /test/goal
        /test/result
        /test/status

    So you can e.g. use `grep` to the output of `rostopic list` to get the list of available actions, e.g.

        rostopic list | grep -o -P '^.*(?=/feedback)'
