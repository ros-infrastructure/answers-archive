    Ok. It seems like the debians are really missing for Oneiric i386 (64bit seems to be available btw.). I hope Willow can resolve that soon. As a temporary solution, you can use the shadow-fixed repository instead of the normal debian repository. Just replace the content of /etc/apt/sources.list.d/ros-latest.list with the following:

        deb http://packages.ros.org/ros-shadow-fixed/ubuntu oneiric main

    Note that the repository contains the debian packages that go into the next official update. There is a certain chance that updates break so you should switch back to the actual repository as soon as it contains the packages again.
