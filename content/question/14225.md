  body_markdown: "Alright, I found out how. You apparently have to create a plugin\
    \ to do this; I didn't find a way to do it from the model plugin in which I use\
    \ the Space Navigator. But it works if you create a visual plugin and refer to\
    \ it in a &lt;plugin&gt; element within a &lt;visual&gt; element in the SDF file.\
    \ Here's the plugin code I used:\n\n    #include <gazebo/gazebo.hh>\n    #include\
    \ <gazebo/common/common.hh>\n    #include <gazebo/rendering/rendering.hh>\n  \
    \  \n    namespace gazebo\n    { class MyVisualPlugin : public VisualPlugin\n\
    \      { public: \n          void Load( rendering::VisualPtr _visual, sdf::ElementPtr\
    \ /*_sdf*/)\n          { // Turn off the SpaceNavigator's default camera control\n\
    \            rendering::UserCameraPtr cam = _visual->GetScene()->GetUserCamera(\
    \ 0 );\n            cam->SetJoyPoseControl( false );\n            cam->SetJoyTwistControl(\
    \ false );\n          }\n      };\n    \n      // Register this plugin with the\
    \ simulator\n      GZ_REGISTER_VISUAL_PLUGIN( MyVisualPlugin )\n    };\n\n\n"

    There is a much easier way: Just adapt the configuration in ~/.gazebo/gui.ini

        [spacenav]
        deadband_x = 0.1
        deadband_y = 0.1
        deadband_z = 0.1
        deadband_rx = 0.1
        deadband_ry = 0.1
        deadband_rz = 0.1
        topic=~/spacenav/remapped_joy_topic_to_something_not_used

    Just change the topic to something you are going to listen in your own plugin and it will not interfere with the gui, which listens to ~/spacenav/joy

    Best regards!
