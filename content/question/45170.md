  body_markdown: "Keep in mind that setting *msg->width* and *msg->height* has no\
    \ effect over *msg->points*.\nThe problem is that you are trying to iterate over\
    \ *msg->points* when it is still empty.\n\nYou can verify that actually, the inside\
    \ of the *for* loop is never being executed and *msg->points.size()* will be 0.\
    \ *msg->width* * *msg->height* will be equal to *pc.points.size()* and hence the\
    \ assertion failure.\n\nYou should iterate over the correct variable. Probably\
    \ *pc.points*\n\nI might be wrong, but I hope this helps. "

after storing each points' coordinates of a point cloud in an array, then converting them to a ROSmessage and publishing them I get the following error message while running:

Aborted (core dumped)

What does the last part about size, width and height mean?

The array's declared as 'field' with x,y,z as its elements.

    msg->header.frame_id = "some_tf_frame";

    for(i = msg->points.begin();i != msg->points.end();++i){

    sensor_msgs::PointCloud2 output;
