    For runtime, I think a topic as you mentioned is your best bet.

    Not exactly run-time, but you can expose parameters via SDF, so the user can modify them **before** running Gazebo, but without recompiling the plugin. See for example how the `RandomVelocityPlugin` parses the SDF [here](https://bitbucket.org/osrf/gazebo/src/cc5101392ae32616bf9bf39b6fc051104836aeb1/plugins/RandomVelocityPlugin.cc?at=default&fileviewer=file-view-default#RandomVelocityPlugin.cc-49) and is used [here](https://bitbucket.org/osrf/gazebo/src/cc5101392ae32616bf9bf39b6fc051104836aeb1/worlds/random_velocity.world?at=default&fileviewer=file-view-default#random_velocity.world-55).
