    \nhttps://github.com/ros/ros_comm/commit/60be2504d5341eb3bc80d86e5d16f1c53dc97ccd\n\
    \nFrom trying it out and looking at the code throttle_identical behaves like throttle\
    \ except if the message text changes.  The timer doesn't reset if the message\
    \ changes, it will stay on the previous throttle phase.\n\nThis can be demonstrated\
    \ on the python shell (every line must have the same caller id):\n\n    python\n\
    \    rospy.init_node('test')\n    rospy.loginfo_throttle_identical(10.0, \"test1\"\
    );\n    rospy.sleep(5.0);\n    rospy.loginfo_throttle_identical(10.0, \"test1\"\
    );  # doesn't log  'test1' == 'test1'\n    rospy.loginfo_throttle_identical(10.0,\
    \ \"test2\");  # does log, 'test2' != 'test1'\n    rospy.loginfo_throttle_identical(10.0,\
    \ \"test1\");  # does log, 'test1' != 'test2'\n    rospy.sleep(6.0);\n    rospy.loginfo_throttle_identical(10.0,\
    \ \"test1\");  # does log, time elapsed since first log expired\n\nHere it hashes\
    \ on the message (as opposed to a string comparison) and uses the caller_id (probably\
    \ source function + line number)\n\n    class LoggingIdentical(object):\n    \n\
    \        last_logging_msg_table = {}\n    \n        def __call__(self, caller_id,\
    \ msg):\n            \"\"\"Do logging specified message only if distinct from\
    \ last message.\n            - caller_id (str): Id to identify the caller\n  \
    \          - msg (str): Contents of message to log\n            \"\"\"\n     \
    \       msg_hash = md5(msg).hexdigest()\n    \n            if msg_hash != self.last_logging_msg_table.get(caller_id):\n\
    \                self.last_logging_msg_table[caller_id] = msg_hash\n         \
    \       return True\n            return False\n\nThere's no loginfo_identical\
    \ but the same could be accomplished with a very long throttle period `loginfo_throttle_identical(1000000.0,\
    \ ...)`.\n\n(What I'd like is a throttle with an exponential falloff parameter,\
    \ it would repeat but at an increasingly long period until reset.  Also it would\
    \ be nice to get a bool feedback from the log throttle call if a log occurred\
    \ or not.)"
