    Two other 'alternatives':

     1. make use of `catkin_tools`' profiles to store CMake and / or `make` flags (this basically adds some convenience to @dornhege's suggestion)
     1. create a catkin package that exports your shared build flags in a `CFG_EXTRAS` file (see [catkin - Developers Guide - Extracted CMake API reference - catkin_package()](http://docs.ros.org/jade/api/catkin/html/dev_guide/generated_cmake_api.html#catkin-package) and [this](http://answers.ros.org/question/173947/export-gcc-flags-though-catkin-cfg_extras/?answer=173955#post-id-173955) answer for some more information). This approach would require all of your other packages that need to use those flags to `build_depend` on your 'shared-flags' package and add them to their `CMAKE_CXX_FLAGS` variable though (but most of that can be automated).
