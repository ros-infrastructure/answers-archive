  body_markdown: "The `ros::spinOnce()`, where the callback is actually called, is\
    \ not in your main while loop! Further the subscriber should be set up only once\
    \ before the while loop. Should be like:\n\n\n    int main(int argc, char** argv){\n\
    \      ros::init(argc, argv, \"turtle_tf_listener\");\n    \n    ros::NodeHandle\
    \ n;\n    \n     ros::Subscriber sub = n.subscribe (\"/chatter\", 10, cb);\n\n\
    \      ros::Rate rate(10.0);\n      while (node.ok()){\n    \n    \n     ROS_INFO_STREAM(message);\n\
    \        ros::spinOnce(); // this is where the magic happens!!\n        rate.sleep();\n\
    \      }\n    \n      return 0;\n\n};"
