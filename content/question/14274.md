  body_markdown: "Take a look at the [physics::Gripper](https://bitbucket.org/osrf/gazebo/src/bb6cc0893c9b6b160d46734c4fe9dbcbed1a1656/gazebo/physics/Gripper.hh?fileviewer=file-view-default)\
    \ class for an example. The gripper creates a fixed joint between one of its links\
    \ and an object which is in contact with it for a certain time. Here are some\
    \ key points in the code:\n\n1. A fixed joint is created, but not attached to\
    \ anything yet\n\n        this->fixedJoint =\n            this->world->GetPhysicsEngine()->CreateJoint(\"\
    fixed\", this->model);\n\n2.  Subscribe to contact updates\n\n          this->contactSub\
    \ = this->node->Subscribe(topic,\n              &Gripper::OnContacts, this);\n\
    \n3. Call OnUpdate at the end of every physics iteration\n\n        this->connections.push_back(event::Events::ConnectWorldUpdateEnd(\n\
    \              boost::bind(&Gripper::OnUpdate, this)));\n\n4. `OnUpdate`, check\
    \ if the conditions for attachment have been fulfilled. That is, if the minimum\
    \ number of contact points `minContactCount` has been satisfied for a minimum\
    \ number of physics iterations `attachSteps`.\n\n5. If so, call `HandleAttach`,\
    \ which loads the fixed joint between the gripper's palm link and the link to\
    \ be grasped:\n\n          this->fixedJoint->Load(this->palmLink,\n          \
    \    cc[iter->first]->GetLink(), math::Pose());\n          this->fixedJoint->Init();\n\
    \    \n6. For detaching, on `HandleDetach`:\n\n        this->fixedJoint->Detach();\n\
    \n\nYou could either use the existing gripper class, or copy the code and adapt\
    \ it to your needs in a [ModelPlugin](http://gazebosim.org/tutorials?tut=plugins_model&cat=write_plugin)."
