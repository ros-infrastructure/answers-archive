  body_markdown: "If you want to interact with Arduino from ROS you have to do it\
    \ by serial communication. I think the simplest way is python scripting.\nI did\
    \ it a few years ago. I had implement a protocol with SYNC, OP_ID, PARAMETERS\
    \ and CHECKSUM between the PC (ROS) and Arduino\n\nThis was my Python script imports:\n\
    \  \n\n      ...\n        import rospy\n        import os\n        import comm\n\
    \        from datetime import datetime\n        ....\n\nwhere comm is the python\
    \ file wich manages communication with arduino board\n\nHere I am reading a message\
    \ from arduino in my ros node file (this is the arduino objetc: ArdIfc)\n\n  \
    \  ...\n      newMsg = ArdIfc.recv()\n                if newMsg != None:\n   \
    \                 if newMsg.mod == comm.MOD_SENSORS: \n                      \
    \  if newMsg.op == comm.OP_GETCURRENTDIST:\n                            torsoPos\
    \ = newMsg.param[0]\n    ...\n\nHere I am sending a message to the Arduino from\
    \ my ros node file\n\n    ...\n     rospy.loginfo(\"Torso-> Stop message.\")\n\
    \                    msgMotor = comm.Msg(comm.ARDUINO_ID, comm.MOD_MOTORS, comm.OP_STOP_MOTOR,\
    \ [], 0)\n                    ArdIfc.send(msgMotor)\n                    msgMotor_ack_received\
    \ = False \n    ...\n\nIf you want the code I can send it to you.\n\nbest,\nFedeico"
