      See [the wiki tutorial](http://wiki.ros.org/ROS/Tutorials/BuildingPackages) for building. When it is a cmake package (there is a CMakeLists.txt file), my standard approach is to source the workspace it is in, go to the package directory and execute `mkdir build; cd build; cmake ..; make -j4`. That will configure your build and compile it in the "build" folder. To install, you can use `make install`. The file build/install_manifest.txt will tell you which files were installed where.
