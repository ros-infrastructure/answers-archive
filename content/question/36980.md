    By [REP 3 - Target Platforms](http://ros.org/reps/rep-0003.html) there is no ROS electric pre-built for Ubuntu 12.04. You will have to either use a machine with Ubuntu 11.10 (oneiric), upgrade your code to Fuerte, or build ROS electric from source.

    Since electric was released in 2011, it couldn't possibly be compatible to Ubuntu 12.04 in advance.
