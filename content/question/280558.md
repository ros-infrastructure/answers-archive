  body_markdown: "As far as I know the built-in rqt_reconfigure (the gui for dynamic\
    \ reconfigure) only really has support for sliders (and maybe pull down menus\
    \ and check boxes but I'm not sure). \n\nBut, you don't have to limit yourself\
    \ to using rqt or even dynamic reconfigure. You can really use ROS with any GUI\
    \ library you like (C++ or Python ones will be easiest of course). \n\nFor example,\
    \ if you use python, you can use [TkInter](https://wiki.python.org/moin/TkInter)\
    \ (the easiest Python GUI library in my opinion/experience, also it ships with\
    \ Python by default most of the time) and make the callback for the button press\
    \ publish a message to a topic. \n\nHere is a quick example of a Tkinter button:\
    \ \n\n    from Tkinter import *\n\n    master = Tk()\n\n    def callback():\n\
    \        print \"click!\"\n\n    b = Button(master, text=\"OK\", command=callback)\
    \  \n    b.pack()\n\n    mainloop()\n\nYou would just make the callback function\
    \ publish a ROS message instead of printing \"click!\". More info about Tkinter\
    \ buttons can be found [here](http://effbot.org/tkinterbook/button.htm). "
