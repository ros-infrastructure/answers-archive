  body_markdown: "No one answered this, so I'll post my own solution. Suppose you\
    \ have a device driver with unit tests that only work on a machine with that device\
    \ attached. It will fail, if run as a regression test by the build farm.\n\nSo,\
    \ in the catkin CMakeLists.txt, wrap `add_rostest()` inside a CMake `if ()` block,\
    \ like this:\n\n    if (${DEVICE_TEST})\n      add_rostest(tests/camera_node_hz.test)\n\
    \      add_rostest(tests/camera_nodelet_hz.test)\n    endif (${DEVICE_TEST})\n\
    \nThose tests will only run when explicitly configured via CMake:\n\n    $ cd\
    \ build\n    $ cmake ../src -DDEVICE_TEST=true \n    $ make run_tests\n"
