  body_markdown: "These are NOT replacements for each other. Gazebo, ROS, and MoveIt\
    \ serve completely different purposes.\n\nGazebo is a simulator, it doesn't do\
    \ any motion planning.\nROS is (in this context) the middleware that allows gazebo\
    \ to talk to other software.\nMoveIt is a motion planning framework that uses\
    \ ROS to talk to Gazebo.\n\nIf you want to do motion planning, use moveit.\n\n\
    If you want to test these motion plans without an actual robot, replace that robot\
    \ with a simulated one in gazebo. "
