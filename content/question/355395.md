Hi, I git coned a repository from https://github.com/ros-industrial/universal_robot. when I tried to roslaunch the U5 robotic arm I got the following error:

    Unable to contact my own server at [http://user-devil:45261/].
    This usually means that the network is not configured properly.
    
    A common cause is that the machine cannot ping itself.  Please check
    for errors by running:
    
    	ping user-devil
    
    For more tips, please see
    
    	http://www.ros.org/wiki/ROS/NetworkSetup
    
    The traceback for the exception was written to the log file
