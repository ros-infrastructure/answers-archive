  body_markdown: "**rospy**\n\nYou can unregister a service by calling `shutdown()`\
    \ on the `rospy.Service` object ([doc here](http://ros.org/rosdoclite/groovy/api/rospy/html/rospy.impl.tcpros_service.Service-class.html)).\
    \ It looks like this isn't done automatically on destruction like in the ros c++\
    \ implementation. Maybe it should do that. \n\n**roscpp**\n\nAre you seeing a\
    \ service persist even after it's been destroyed? The way to unregister  a service\
    \ manually is to call `shutdown()` on the `ServiceServer` object ([doc here](http://www.ros.org/doc/api/roscpp/html/classros_1_1ServiceServer.html#a080073670c5010c6c293a204f3234e7a)),\
    \ but this should happen automatically when the `ServiceServer` object is destroyed.\
    \ Maybe you're not actually destroying the server object."
