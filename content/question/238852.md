  body_markdown: "To solve this problem I had to add this line in morse_2dnav/nav.launch:\n\
    \n    <param name =\"/use_sim_time\" value=\"true\"/>\n\nMoreover, I add to add\
    \ these lines in the nav_tutorial/default.py \n\n    clock = Clock()\n    robot.append(clock)\n\
    \    clock.add_interface('ros',topic='/clock')\n\nI guess that the problem had\
    \ to do with a poor synchronization between MORSE and ROS.\nI hope this helps\
    \ others.\n"
