    First of all, you are trying to install a package from ROS kinetic, which is released [for Ubuntu 16.04](https://www.ros.org/reps/rep-0003.html#kinetic-kame-may-2016-may-2021).

    On Ubuntu 20.04 the official ROS release would be noetic. However, the `universal_robots` package is not released for ROS noetic, yet.

    There have been (I think successful) attempts to build it from source using the [`melodic-devel-staging` branch](https://github.com/ros-industrial/universal_robot/tree/melodic-devel-staging) of the package. See [this issue](https://github.com/ros-industrial/universal_robot/issues/537) for details.
