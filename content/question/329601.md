  body_markdown: "It seems like you are mixing kinetic and melodic sources.\nThe method\n\
    \n    virtual void initialize(std::string name, tf2_ros::Buffer* tf, costmap_2d::Costmap2DROS*\
    \ costmap_ros) = 0;\n\nfrom `nav_core` ([see here](https://github.com/ros-planning/navigation/blob/melodic-devel/nav_core/include/nav_core/base_local_planner.h#L78))\
    \ is pure virtual and not implemented in teb_local_planner according to your build\
    \ log.\nThe method indicates the tf2 dependency which was introduced to ROS navigation\
    \ and teb_local_planner in `melodic`.\nSo it seems that you are trying to compile\
    \ the `kinetic` version of teb_local_planner with the `melodic` version of the\
    \ navigation stack. \nMake sure to clone the correct branch, e.g. for melodic:\n\
    \n    git clone -b melodic-devel https://github.com/ros-planning/navigation.git\n\
    \    git clone -b melodic-devel https://github.com/rst-tu-dortmund/teb_local_planner.git\n\
    \nOr use the correct ROS distribution for your APT repositories."
