    \n    #!/usr/bin/env python\n\n    import rospy\n    from moveit_msgs.srv import\
    \ GetStateValidityRequest, GetStateValidity\n    from moveit_msgs.msg import RobotState\n\
    \    from sensor_msgs.msg import JointState\n\n\n    class StateValidity():\n\
    \        def __init__(self):\n            # subscribe to joint joint states\n\
    \            rospy.Subscriber(\"joint_states\", JointState, self.jointStatesCB,\
    \ queue_size=1)\n            # prepare service for collision check\n         \
    \   self.sv_srv = rospy.ServiceProxy('/check_state_validity', GetStateValidity)\n\
    \            # wait for service to become available\n            self.sv_srv.wait_for_service()\n\
    \            rospy.loginfo('service is avaiable')\n            # prepare msg to\
    \ interface with moveit\n            self.rs = RobotState()\n            self.rs.joint_state.name\
    \ = ['joint1','joint2']\n            self.rs.joint_state.position = [0.0, 0.0]\n\
    \            self.joint_states_received = False\n            \n\n        def checkCollision(self):\n\
    \            '''\n            check if robotis in collision\n            '''\n\
    \            if self.getStateValidity().valid:\n                rospy.loginfo('robot\
    \ not in collision, all ok!')\n            else:\n                rospy.logwarn('robot\
    \ in collision')\n\n\n        def jointStatesCB(self, msg):\n            '''\n\
    \            update robot state\n            '''\n            self.rs.joint_state.position\
    \ = [msg.position[0], msg.position[1]]\n            self.joint_states_received\
    \ = True\n\n\n        def getStateValidity(self, group_name='acrobat', constraints=None):\n\
    \            '''\n            Given a RobotState and a group name and an optional\
    \ Constraints\n            return the validity of the State\n            '''\n\
    \            gsvr = GetStateValidityRequest()\n            gsvr.robot_state =\
    \ self.rs\n            gsvr.group_name = group_name\n            if constraints\
    \ != None:\n                gsvr.constraints = constraints\n            result\
    \ = self.sv_srv.call(gsvr)\n            return result\n\n\n        def start_collision_checker(self):\n\

    There are python bindings for the Bullet Physics engine, called PyBullet. PyBullet comes with various collision checking facilities that are fast. The python bindings also have some functionality to spawn URDFs and geometric primities. For a quick script, that should do the job.

     - [Main Website](https://pybullet.org/wordpress/)
     - [Quickstart Guide](https://docs.google.com/document/d/10sXEhzFRSnvFcl3XxNGhnD4N2SedqwdAvK3dsihxVUA/edit)
     - [Github](https://github.com/bulletphysics/bullet3)

    My experiences with PyBullet are:

    PRO:

     - It is easy to set up a simple experimental application.
     - The framework is fast, considering that you are coding the top part in Python.
     - The developers are responsive and helpful on github. They have quickly responded to issues, merged PRs, and even fixed bugs that we encountered.

    CON:

     - PyBullet has not been designed with ROS integration in mind. So as a ROS developer, at some time frustration sets in.
     - The way the python bindings are done, it feels a lot like coding good-old C and not pythonic, at all.
     - Not all Bullet features are wrapped for Python. So, sometimes you hit a brick wall because you're missing an essential feature.
     - The architecture of the framework is complicated with a Client-Server setup and Python-C-C++-Wrappings. Hence, you need a lot of expertise to provide new features or further wrappings.

Hello everyone!
I would like to ask a simple question.

**How can we detect collisions in Python? (as simple as possible)** My goal is as follows:

- Want to check a state validity and a trajectory validity by evaluating self-collision and collision with obstacles.
- Want to use a PR2 robot.
- Want to add some simple primitives like a box, a cylinder, etc. to the scene.
- Want to attach simple primitives to the robot body (assuming that the robot is grasping an object).
- Not want to implement too much.

I found several solutions as follows, but I want simpler solutions.

1. Using the /environment_server node through the services.
  - This is slow, and has *a problem to detect collisions between cylinders* as reported [here](http://answers.ros.org/question/192829/collision-is-not-detected-with-cylinder-model/).
1. Using MoveIt!.
  - This is nice, but the [collision detection tutorial](http://moveit.ros.org/documentation/tutorials/) seems to be only for C++.
  - I found a [Python API and its tutorial](http://docs.ros.org/indigo/api/pr2_moveit_tutorials/html/planning/scripts/doc/move_group_python_interface_tutorial.html), but the moveit_commander does not provide a collision check interface.
1. Using [FCL](http://wiki.ros.org/fcl).
  - Only has a C++ interface.

Hence, to the best of my knowledge, I need to implement a python interface to call C++ functions (by using either the [Python/C interface](https://docs.python.org/2/c-api/) or the ROS communication), which sounds a bit complicated.

If anyone can suggest simpler solutions, please tell me.

Thanks in advance.
