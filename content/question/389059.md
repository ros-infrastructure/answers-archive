  body_markdown: "WSL2 (WSL1 is different) runs Linux inside a VM.\n\nSo you should\
    \ follow the regular Linux-based install tutorial for your version of Linux.\n\
    \nAs you mention Ubuntu, that would be the Ubuntu based install tutorials.\n\n\
    > Install ROS2 for Windows, since my background OS is Windows? \n\n*Inside* WSL,\
    \ there is no Windows. It's all Linux.\n\nYou only install ROS 2 using the Windows\
    \ guides if you intend to write Windows applications using ROS 2. Those don't\
    \ involve Linux, so no ROS-for-Linux."
