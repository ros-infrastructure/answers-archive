    newmtl RockCol
    Ka 0.1 0.1 0.1
    Kd 0.4 0.4 0.4
    Ks 0.7 0.7 0.7
    Ns 300
    Ni 1.0
    d 1.0
    illum 0

In Paint 3D, for example, it looks like this:

![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/16571305067256975.png)

In Gazebo (11.10.2), I've tried a bunch of different things to get it to display the faces/colors correctly, but no matter what I try, the rock always displays as one solid color, so you can't tell it has multiple faces (default gray box is included for reference):

![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/16571315878368217.png)

![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/16571316676227799.png)

Referencing the .mtl file directly:

    <visual name='visual'>
      <pose>0 0 0 0 -0 0</pose>

      <material>

      </material>
      <transparency>0</transparency>

Specifying the colors in the sdf:

      <material>
