I'm using:

- Windows 10
- ROS noetic on Windows
- Unity v2021.3.23f1 + `ros-sharp` (https://github.com/siemens/ros-sharp)
- `rosbridge_suite` built from source in a local catkin workspace

I'm publishing a `PoseArray` from Unity to ROS using ros-sharp. The ROS-connector in Unity is configured as 

- Serializer: Newtonsoft_JSON
- Protocol: Web Socket NET

With the same setup I have been successful transmitting primitive message types such as an `std_msgs/Int32`, and also a `std_msgs/Float32MultiArray` (`rostopic echo` shows the transmitted messages correctly).

But when I try to transmit a `geometry_msgs/PoseArray`, I get an error after launching the rosbridge_server with 
`roslaunch rosbridge_server rosbridge_websocket.launch`:

    [ERROR] [1683636575.384166]: [Client 10] [id: /joint_poses] publish: geometry_msgs/PoseArray message requires a geometry_msgs/Pose for field poses, but got a <class 'NoneType'>

What am I missing here?
