  body_markdown: "Check the tutorial for multiple machines: http://wiki.ros.org/ROS/Tutorials/MultipleMachines\n\
    \nBut to answer your question yes, both machines must be on the same network or\
    \ reachable via the internet (vpn counts too). To check that the IP you are using\
    \ is ok, try ssh-ing to the MASTER machine from your node machine, and vice-versa,\
    \ if both ssh-ing attempts work then ROS should also work.\n\nYou can also ping\
    \ that IP and check if it's on the network. I'm guessing you are just having an\
    \ issue of IPs. \n\nBest of luck!"
