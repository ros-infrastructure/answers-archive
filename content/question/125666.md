    Currently there is a bug in ueye_cam's calibration parser, where it loads a yaml file, but parses the format of a Videre INI file instead. This will be fixed very soon. For the time being, you can manually modify the contents of your .yaml file according to the [Videre INI specs](http://wiki.ros.org/camera_calibration_parsers#File_formats) (yuk, I know, sorry).
