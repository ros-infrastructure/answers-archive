  body_markdown: "That actually doesn't look too bad, my starting experience with\
    \ Blender based COLLADA was much worse, as you can read about [here](http://answers.ros.org/question/12699/modeling-urdf-files-using-blender-and-exporting-to).\
    \ Quoting the answer by @stefan-osswald there:\n\n\"There is a bug in RViz that\
    \ replaces the ambient color of Collada materials by light gray if at least one\
    \ component of the specified ambient color is 0.0 (see Ticket [#5237](https://code.ros.org/trac/ros-pkg/ticket/5237)).\
    \ According to the changelog, this bug is fixed in robot_model 1.6.4, which seems\
    \ to be not in the electric .deb repository yet.\"\n\nWhat you for instance can\
    \ try is manually editing your .dae files and setting non-zero ambient components\
    \ for the used materials.\n\n/edit: Update to be more specific:\nEntries like\
    \ this: \n\n       <ambient>\n          <color sid=\"ambient\">0.4 0.4 0 1</color>\n\
    \        </ambient>\n\nhave to be changed so all components are non-zero, for\
    \ example:\n\n       <ambient>\n          <color sid=\"ambient\">0.4 0.4 0.1 1</color>\n\
    \        </ambient>"
