  body_markdown: "You can skip frames to reduce frame rate. \n\nWrite this line in\
    \ the terminal \n\n set param name=\"camera/driver/data_skip\" value=\"10\"\n\n\
    and then run \n\nroslaunch openni_launch openni.launch \n\nThis will drop 10 frames\
    \ and output 2-3Hz data, whereas default value is 0 (which output 30 frames/sec\
    \ without any dropping)"
