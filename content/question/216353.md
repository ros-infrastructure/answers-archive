     You can use the [urg_node](http://wiki.ros.org/urg_node). All you have to do is to run this node and you can create then another node with a subscriber to a message of type `sensor_msgs/LaserScan`. The topic name will be most probably `/scan`.

    Before writing the subscriber, I recommend you to plug the Hokuyo, ron the `urg_node` and then try to visualize it in RViz.

    Actually, after googling for 5 seconds I found [this](http://answers.ros.org/question/60239/how-to-extract-and-use-laser-data-from-scan-topic-in-ros-using-c/) with a much more detailed answer.
