    It seems like the problem is with wrong inertial values (moments and center of mass).

    These values can be edited directly in the model's SDF or URDF files, look for the `<inertial>` tag.

    Depending on your version of Gazebo, if you're using SDF you can edit the model using the [model editor](http://gazebosim.org/tutorials?tut=model_editor&cat=model_editor_top).
