  body_markdown: "Problem solved!\nI was getting errors while starting move_base with\
    \ DWA in a classical way because i forgot to install the proper package:\n\n \
    \    sudo apt-get install ros-kinetic-dwa-local-planner \n\nNow everything is\
    \ working well.\n\nFor reference i set the local planner as DWA by adding this\
    \ line to my move_base.launch file:\n\n    <param name=\"base_local_planner\"\
    \ value=\"dwa_local_planner/DWAPlannerROS\"/>\n\nI can then set the params with\
    \ a *.yaml file:\n\n    DWAPlannerROS:\n      max_vel_x: 0.4\n      min_vel_x:\
    \ 0.1\n    \n      max_trans_vel: 0.4\n      min_trans_vel: 0.1\n      \n    \
    \  etc....\n\nSorry for shooting to fast. But to be fair the documentation of\
    \ the navigation stack is not very clear on this point...\n\n"
