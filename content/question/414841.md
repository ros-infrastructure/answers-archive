  body_markdown: "To programmatically check if the Gazebo GUI is fully loaded and\
    \ the scene is visible, you can use the `gzclient` tool to check if the Gazebo\
    \ client process is running. Here's an example Python code that you can use:\n\
    \n    import subprocess\n    import time\n    \n    def is_gazebo_ready():\n \
    \       ps_output = subprocess.check_output(['ps', 'aux'])\n        ps_output_str\
    \ = ps_output.decode('utf-8')\n        if 'gzclient' in ps_output_str:\n     \
    \       return True\n        else:\n            return False\n    \n    if __name__\
    \ == '__main__':\n        while not is_gazebo_ready():\n            time.sleep(1)\n\
    \        print('Gazebo is ready')\n\nThis code uses the subprocess module to execute\
    \ the ps command and get the list of running processes. It then checks if the\
    \ gzclient process is running by searching for it in the process list. If the\
    \ gzclient process is found, it means that the Gazebo GUI is fully loaded and\
    \ the scene is visible. Otherwise, the code waits for one second and checks again.\n\
    \nYou can customize the sleep duration (currently set to 1 second) to fit your\
    \ specific use case.\n"
