    Your first task will be to write a c++ or python program that can access the signal strength information you need. If you can monitor it over HTTP can you send a [CURL](https://curl.haxx.se/libcurl/c/example.html) request and receive a text response that contains the signal strength? Your program will then need to parse this text and extract the raw strength reading.

    When you have this working you can adapt the [simple publisher example](http://wiki.ros.org/ROS/Tutorials/WritingPublisherSubscriber%28c%2B%2B%29) to publish the data to a topic.

    Hope this gives you enough to get started.
