  body_markdown: "You shouldn't have to use the NaoQi SDK. Hokuyo lasers are very\
    \ well supported in ROS, due to their popularity. You can find documentation for\
    \ the Hokuyo node [here](http://ros.org/wiki/hokuyo_node). To use it, do the following:\
    \ \n\n    rosrun hokuyo_node hokuyo_node /dev/ttyACM0\n\nIf there are permission\
    \ errors, run the below command and try the above again. \n\n    sudo chmod 777\
    \ -R /dev/ttyACM0\n\n\n----------\n\nHowever, if you are interested in writing\
    \ your own driver (understandable, for it's a good exercise), you need to publish\
    \ the laser inside a `sensor_msgs/LaserScan` [message](http://ros.org/doc/api/sensor_msgs/html/msg/LaserScan.html).\
    \ \n\nIn order to do so, you will need to fill in the header with the current\
    \ ROS time and frame_id (probably `laser`).\n\nYou will need to fill in the `angle_min`\
    \ and `angle_max` with the start and end angles of the scan with respect to the\
    \ positive Z-axis. You will need to include the `angle_increment` and `scan_time`\
    \ (time between scans).\n\nThen, you will need to set the `range_min` and `range_max`\
    \ to the shortest measurable distance and largest measurable distance respectively.\
    \  \n\nThe next container is the ranges array. Fill the array with each individual\
    \ range measurement from `angle_min` to `angle_max`. Then, the intensities (if\
    \ provided). If your laser does not have intensities, then you may omit this array.\
    \ \n\nBest of luck! "
