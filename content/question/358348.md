  body_markdown: "As of Foxy Fitzroy `ament_export_interfaces` is deprecated, replaced\
    \ with `ament_export_targets`. The documentation was outdated and has been updated\
    \ in https://github.com/ros2/ros2_documentation/pull/804.\n\nThere's a recommendation\
    \ in the [tutorial](https://index.ros.org/doc/ros2/Tutorials/Ament-CMake-Documentation/)\
    \ to use a different EXPORT name than the library:\n\n> The `EXPORT` notation\
    \ of the install call requires additional attention: It installs the CMake files\
    \ for the `my_library` target. It is named exactly like the argument in `ament_export_interfaces`\
    \ and could be named like the library. However, this will then prohibit using\
    \ the `ament_target_dependencies` way of including your library. To allow for\
    \ full flexibility, it is advised to prepend the export target with something\
    \ like `export_<target>`.\n\nI don't know if it solves your issue, but you could\
    \ try making the following changes to your first CMakeLists.txt:\n\n    ament_export_targets(export_ftd2xx\
    \ HAS_LIBRARY_TARGET)\n    \n    ament_export_targets(export_EposCmd HAS_LIBRARY_TARGET)\n\
    \    \n    install(\n      DIRECTORY include/\n      DESTINATION include\n   \
    \ )\n    \n    install(\n      TARGETS ftd2xx\n      EXPORT export_ftd2xx\n  \
    \    LIBRARY DESTINATION lib\n      ARCHIVE DESTINATION lib\n      RUNTIME DESTINATION\
    \ bin\n      INCLUDES DESTINATION include\n    )\n    \n    install(\n      TARGETS\
    \ EposCmd\n      EXPORT export_EposCmd\n      LIBRARY DESTINATION lib\n      ARCHIVE\
    \ DESTINATION lib\n      RUNTIME DESTINATION bin\n      INCLUDES DESTINATION include\n\
    \    )\n\n"
