  body_markdown: "You can run simulation paused and call to the `/world/world_name/control`\
    \ Ignition service to step the simulation. Note that this is an Ignition Transport\
    \ service, not a ROS service. \n\nWhile running the simulation, I suggest you\
    \ inspect this service using the command line, i.e.:\n\n\n    $ ign service -l\n\
    \    ...\n    /world/default/control\n    ...\n\nAnd check the service info with\
    \ \n\n    $ ign service -i -s /world/default/control\n\nResetting the simulation\
    \ is not fully supported yet. Some systems can be reset, but physics can't. See\
    \ [this issue](https://github.com/ignitionrobotics/ign-gazebo/issues/203)."
