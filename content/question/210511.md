  body_markdown: "Is <code>stereo_nodelet</code> exist? If not, you have two choices:\
    \ you create a nodelet manager for the two nodelets or create them as standalone\
    \ nodelets:\n\n    <node pkg=\"nodelet\" type=\"nodelet\" name=\"nodelet_manager\"\
    \  args=\"manager\"/>\n\n    <!-- Generate a point cloud from the disparity image\
    \ -->\n    <node pkg=\"nodelet\" type=\"nodelet\" name=\"disparity2cloud\" args=\"\
    load rtabmap_ros/point_cloud_xyz nodelet_manager\">\n        <remap from=\"disparity/image\"\
    \       to=\"$(arg camera)/disparity\"/>\n        <remap from=\"disparity/camera_info\"\
    \ to=\"$(arg camera)/right/camera_info\"/>\n        <remap from=\"cloud\"    \
    \            to=\"cloudXYZ\"/>\n\n        <param name=\"voxel_size\" type=\"double\"\
    \ value=\"0.05\"/>\n        <param name=\"decimation\" type=\"int\" value=\"4\"\
    />\n        <param name=\"max_depth\" type=\"double\" value=\"10\"/>\n    </node>\n\
    \n    <!-- Create point cloud for the local planner -->\n    <node pkg=\"nodelet\"\
    \ type=\"nodelet\" name=\"obstacles_detection\" args=\"load rtabmap_ros/obstacles_detection\
    \ nodelet_manager\">\n        <remap from=\"cloud\" to=\"cloudXYZ\"/>\n      \
    \  <remap from=\"obstacles\" to=\"/planner/planner_cloud\"/>\n\n        <param\
    \ name=\"frame_id\" type=\"string\" value=\"artemisBody\"/>\n        <param name=\"\
    map_frame_id\" type=\"string\" value=\"map\"/>\n        <param name=\"min_cluster_size\"\
    \ type=\"int\" value=\"20\"/>\n        <param name=\"max_obstacles_height\" type=\"\
    double\" value=\"0.0\"/>\n    </node>\n\n or \n\n    <!-- Generate a point cloud\
    \ from the disparity image -->\n    <node pkg=\"nodelet\" type=\"nodelet\" name=\"\
    disparity2cloud\" args=\"standalone rtabmap_ros/point_cloud_xyz\">\n        <remap\
    \ from=\"disparity/image\"       to=\"$(arg camera)/disparity\"/>\n        <remap\
    \ from=\"disparity/camera_info\" to=\"$(arg camera)/right/camera_info\"/>\n  \
    \      <remap from=\"cloud\"                to=\"cloudXYZ\"/>\n\n        <param\
    \ name=\"voxel_size\" type=\"double\" value=\"0.05\"/>\n        <param name=\"\
    decimation\" type=\"int\" value=\"4\"/>\n        <param name=\"max_depth\" type=\"\
    double\" value=\"10\"/>\n    </node>\n\n    <!-- Create point cloud for the local\
    \ planner -->\n    <node pkg=\"nodelet\" type=\"nodelet\" name=\"obstacles_detection\"\
    \ args=\"standalone rtabmap_ros/obstacles_detection\">\n        <remap from=\"\
    cloud\" to=\"cloudXYZ\"/>\n        <remap from=\"obstacles\" to=\"/planner/planner_cloud\"\
    />\n\n        <param name=\"frame_id\" type=\"string\" value=\"artemisBody\"/>\n\
    \        <param name=\"map_frame_id\" type=\"string\" value=\"map\"/>\n      \
    \  <param name=\"min_cluster_size\" type=\"int\" value=\"20\"/>\n        <param\
    \ name=\"max_obstacles_height\" type=\"double\" value=\"0.0\"/>\n    </node>\n\
    \nWell, the first choice is preferred if cloudXYZ is used only by obstacles_detection\
    \ nodelet (to keep transferred messages in memory).\n\n**EDIT**\nBeware that the\
    \ nodelets are in \"/stereo_camera\" namespace. If you want to remap disparity/image\
    \ to artemis/navCam/disparity, make sure you set your argument \"camera=/artemis/navCam\"\
    \ with leading slash. Otherwise, it may try to subscribe to \"/stereo_camera/artemis/navCam/disparity\"\
    ."
