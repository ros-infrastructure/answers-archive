  body_markdown: "Hi moody,\n\nthere are three major problem sources:\n\n1) Frame\
    \ rate: viso2 works better with high framerates or small displacements. It was\
    \ originally designed for a forward looking camera.\n\n2) Computation time: check\
    \ that the computer where the node is running is not 100% busy.\n\n3) Texture/Illumination\
    \ conditions: not only the disparity image has to be good, but also the texture\
    \ in order to extract good features.\n\nIn a nutshell, it is a visual odometer\
    \ and it will drift over time. It is better that you fuse it with other sensors\
    \ than using it alone.\n "
