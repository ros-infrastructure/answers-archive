  body_markdown: "I'm not sure what can be the exact cause of your error. However\
    \ I'd say you're using the wrong tool for this job. From the [ROS wiki](http://www.ros.org/wiki/Parameter%20Server):\
    \ \n\n> As *the Parameter Server* is not designed for high-performance, it is\
    \ best used for static, non-binary data such as configuration parameters.\n\n\
    Instead I would try to set-up a [ROS service](http://www.ros.org/wiki/ROS/Tutorials/WritingServiceClient%28python%29)\
    \ using code similar to this:\n\n    from std_srvs.srv import Empty\n    class\
    \ Bar:\n        def sync_callback(self, req):\n            self.foo = False\n\
    \        def __init__(self):\n            rospy.init_node(\"example\")\n     \
    \       self.foo = True\n            self.sync_service = rospy.Service(\"sync\"\
    , Empty, self.sync_callback)\n        def run(self):\n            while self.foo:\n\
    \               #rest of code as usual\n        \n    if __name__ == '__main__':\n\
    \        b = Bar()\n        b.run()\n\nHope this helps!\n\n"
