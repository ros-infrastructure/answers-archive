    \  I'd recommend looking into how to solve that problem before you look into solving\

    \ be able to use the same instance of that program with more than one entity you're\
    \ trying to localize.\n\nSee this post for a good amount of information: \nhttps://answers.ros.org/question/41433/multiple-robots-simulation-and-navigation/?answer=41434?answer=41434#post-id-41434\n\
