    Hello Ivan,

    What robot are you using this for? Do you have a collision checker?
    It seems to me what you can do is just use OMPL directly. Define a SE3StateSpace (which represents a position in space + orientation) or RealVectorStateSpace(3) (to represent just a 3D point), set the bounds for the space and plan there directly. You do need to specify your collision checker directly however. Check http://ompl.info for tutorials on how to do this, or post questions here again.

  body_markdown: "Hello Ivan,\n\nThe code you show looks almost ok. \nWhen you initialize\
    \ OMPL, you do this:\n    bounds_=&vb;\nwhich is a problem, because vb will go\
    \ out of scope and bounds_ will end up pointing to an invalid location. Just make\
    \ bounds_ a copy of vb, not a pointer to it.\n\nThe way you set goal_pose_ompl_\
    \ is not correct. The message you use as input uses a quaternion as the representation\
    \ of the rotation, not as axis-angle. You should just set the x,y,z and w individually,\
    \ instead of using setAxisAngle().\n\nThe last thing I see is that you are missing\
    \ the definition of a StateValidityChecker. You can follow this tutorial: http://ompl.kavrakilab.org/core/stateValidation.html\n\
    \nWhat is the problem you see exactly? Is the code crashing, or throwing an exception?\n\
    \nIoan"
