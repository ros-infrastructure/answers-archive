  body_markdown: "Ok. I finally managed to solve this. I can run now multiple instances\
    \ of rosmaster and Gazebo!\n\nSince the envioremental variables are \"local\"\
    \ to each shell (terminal instance), you need to be careful with this. First,\
    \ for running different rosmaster instances you need to change the ROS_MASTER_URI\
    \ enviorement variable for each one. You also need to change the GAZEBO_MASTER_URI\
    \ for each INDEPENDENT Gazebo instance you want to run. I tried it, and at first\
    \ it didn't work. That's because according to [THIS](https://bitbucket.org/osrf/simulator_gazebo/pull-request/7/do-not-overwrite-gazebo_master_uri-if-one/diff),\
    \ you have to edit your /usr/share/gazebo/setup.sh and replace\n\n    export GAZEBO_MASTER_URI=http://localhost:11345\n\
    for\n\n    export GAZEBO_MASTER_URI=${GAZEBO_MASTER_URI:-\"http://localhost:11345\"\
    }\n\nThen save. **If you dont do this change, the GAZEBO_MASTER_URI won't chance\
    \ properly!!**\n\nNow, for running different instances of rosmaster:\n\n**First\
    \ shell:** \n\n`export ROS_MASTER_URI=http://localhost:11315` 11315 is just an\
    \ example. **The default is 11311**.    \n    `roscore -p 11315` or roslaunch\
    \ some package. It'll run on the specified port ( localhost:11315 )\n\n**Second\
    \ shell:** \n\n   `export ROS_MASTER_URI=http://localhost:11316` A different one\
    \ from before!  \n   `roscore -p 11316` or roslaunch some package. It'll run on\
    \ the specified port ( localhost:11316 )\n\nNow, for running multiple Gazebo instances\n\
    \n**Third shell:** \n\n   `export GAZEBO_MASTER_URI=http://localhost:11355` 11355\
    \ is just an example. **The default is 11345**.\n\n   `gazebo`\n\n**Fourth shell:**\
    \ \n\n   `export GAZEBO_MASTER_URI=http://localhost:11356` A different one from\
    \ before!  \n\n   `gazebo`\n\nAnd voil\xE0!"
