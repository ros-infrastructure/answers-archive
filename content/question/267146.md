  body_markdown: "The method to setup the tb3 involves setting up the PC as the master.\
    \ This allows all topics to be accessed by both the TB3 and the PC. \n\n1. In\
    \ terms of what is running on what, the tutorial only has the bringup running\
    \ on the tb3. The gmapping is run on the PC, but it takes in data through the\
    \ tb3 bringup launch through the topics of scan and odom.\n\n2. By cloning the\
    \ tb3 repository on both the tb3 and your remote PC, you can run any of the launch\
    \ files from either machine (except bringup which is on the tb3). If you launch\
    \ on the tb3, it runs on the tb3; if you launch on your PC, it runs on the PC.\n\
    \nHope this helps!!"
