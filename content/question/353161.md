  body_markdown: "Hi @KoalaDangerous,\n\nThe following command: `export GAZEBO_PLUGIN_PATH=$GAZEBO_PLUGIN_PATH:~/catkin_ws/devel/lib`\
    \ is to inform Gazebo about the location of custom Gazebo plugins.\n\nThis one:\
    \ `export GAZEBO_MODEL_PATH=$GAZEBO_MODEL_PATH:~/.gazebo/models` explicitly tells\
    \ Gazebo where to find its model to spawn in the world.\n\nYou have to take into\
    \ account multiple things:\n\n 1. You will have to [source](http://wiki.ros.org/ROS/Tutorials/InstallingandConfiguringROSEnvironment)\
    \ properly your workspace.\n 2. These are envirtomental variables that are only\
    \ set within the scope of one terminal. Meaning that the will be set and used\
    \ on those bash enviroments you performed the `export` command.\n 3. The second\
    \ command redirects to a hidden folder where Gazebo stores its model. Either you\
    \ copy/move the model folder of the `ainstein_radar_gazebo` to this folder or\
    \ you export the variable with the project folder containing the radar model.\
    \ \n\nE.g.: `export GAZEBO_MODEL_PATH=$GAZEBO_MODEL_PATH:~.../ainstein_radar_gazebo_plugins/models`"
