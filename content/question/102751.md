You used to be able to use backticks for `inline code`, * for *italics* and **bold**, and even [name links](http://answers.ros.org) in comments on this site, but lately, all of these characters just show up as literals in comments.

How can this be fixed?

**EDIT**

According to answer from @georgebrindeiro there is a github site for reporting these kinds of bugs.  Perusing that issue tracker revealed [this bug report](https://github.com/ros-infrastructure/answers.ros.org/issues/42) complaining about this same issue.  It was closed with the argument being that significant formatting isn't really expected in the comments.
