    From what I've seen, the existing C++ libraries in ROS that expose QT widgets don't do anything special to expose the MOC'd files that are generated from headers.

    Between reading the [qt_gui_cpp CMakeLists.txt](https://github.com/ros-visualization/qt_gui_core/blob/groovy-devel/qt_gui_cpp/src/qt_gui_cpp/CMakeLists.txt) and some [MOC documentation](http://qt-project.org/doc/qt-4.8/moc.html) it looks like MOC creates C++ implementation files only (My interpretation of the documentation is that MOC does not generate header files). These generated C++ files are then compiled into a library within the source project. Downstream projects then include the original headers and link against the compiled library.

    In your case, you'd want to make sure that the `${PROJECT_NAME}` library contains both your source and the MOC-generated files.
