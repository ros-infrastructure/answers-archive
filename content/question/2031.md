    \ subscribe linear and angular velocity from a ROStopic with  geometry_msgs/Twist\
    \ (http://ros.org/doc/api/geometry_msgs/html/msg/Twist.html).\n\nYou should research\
    \ about message types for rostopics, publishing and subscribing to ROStopics with\
    \ diferent message types before trying to create your own plugin to talk with\
    \ ROS\n\nSIDE NOTE:\nonce you have some insight of the tutorials this might be\
    \ usefull to save you sometime later on if you are not familiar with quaternions\
    \ (i wasn't), so remember this when you try to get a robot Roll Pitch Yaw angles:\n\
    \n    math::Quaternion r = model->GetWorldPose().rot;\n    //from quaternion to\
    \ roll pitch yaw, in radians\n    qw=r.w; \tqx=r.x; \tqy=r.y; \tqz=r.z;\n    Rrad=atan2(\
    \  2*(qw*qx+qy*qz),  1-2*(qx*qx+qy*qy)  ); //roll\n    Prad=asin(2*(qw*qy-qz*qx));\
    \                          //pitch\n    Yrad=atan2(  2*(qw*qz+qx*qy),  1-2*(qy*qy+qz*qz)\
    \  ); //yaw\n\nthis might also be usefull in the model plugin (not joint velocity\
    \ commands tho):\n\n    //set velocities\n    float Vlin=0.5; //Linear velocity\
    \ wanted\n    float Vang=1.0; //Angular velocity wanted\n    float velx=Vlin*cos(Yrad);\n\
    \    float vely=Vlin*sin(Yrad);\t\n    this->model->SetLinearVel(math::Vector3(velx,\
    \ vely, 0));\n    this->model->SetAngularVel(math::Vector3(0, 0, Vang));\n\nthe\
    \ above code will make the robot move in a circle.\nyou can then, with laser data\
    \ for example, change Vlin and Vang to your will.\n\ni hope the above code examples\
    \ will save you time instead of spending to much time trying to learn everything\
