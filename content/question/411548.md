  body_markdown: "Your question is not entirely clear. topics are of type message\
    \ - not class.\n\nAs described in [ROS2 Manual](https://docs.ros.org/en/foxy/Tutorials/Beginner-CLI-Tools/Understanding-ROS2-Topics/Understanding-ROS2-Topics.html#ros2-topic-list):\
    \ If you want to know the type of message, you can use:\n \n\n    ros2 topic list\
    \ -t\n\nwhich will result in a similar output:\n\n> `/parameter_events [rcl_interfaces/msg/ParameterEvent]\n\
    ...`\n\nso that /parameter events is the topic/message name and rcl_interfaces/msg/ParameterEvent\
    \ is the type.\n\nHope this helps."
