  body_markdown: "I think the key problem is that the example of rrbot uses a hardware\
    \ interface of joint effort.\nIf you want to implement MoveIt to it, you need\
    \ to build a joint trajectory controller.\n\n - Add a trajectory controller to\
    \ your robot:\n\n> rrbot_control/config/rrbot_control.yaml\n    \n    arm_controller:\n\
    \    type: effort_controllers/JointTrajectoryController\n    joints:\n       -\
    \ joint1\n       - joint2\n    constraints:\n        goal_time: 0.0\n        stopped_velocity_tolerance:\
    \ 0.01\n        joint1: {trajectory: 0.01, goal: 0.01}\n        joint2: {trajectory:\
    \ 0.01, goal: 0.01}\n    gains:\n       joint1: {p: 100.0, d: 75.0, i: 0.0, i_clamp:\
    \ 0.0}\n       joint2: {p: 100.0, d: 25.0, i: 0.0, i_clamp: 0.0}\n    state_publish_rate:\
    \  100\n    action_monitor_rate: 100\n    stop_trajectory_duration: 0.0\nnotice\
    \ that you should maunally setup these parameters to have a good performance,\
    \ especially pid.\n\n - Remap the controller topic to MoveIt topic\n> rrbot_gazebo/launch/rrbot_world.launch\n\
    \n    <remap from=\"/rrbot/arm_controller/follow_joint_trajectory\" to=\"/joint_trajectory_action\"\
    \ />\n    <remap from=\"/rrbot/arm_controller/state\" to=\"/feedback_states\"\
    \ />\n    <remap from=\"/rrbot/arm_controller/command\" to=\"/joint_path_command\"\
    />\n\n\nIf you just want to learn how to set-up MoveIt with a simple robot, I\
    \ suggest you change the hardware interface  to joint position interface. It's\
    \ at the bottom of the description of rrbot. Tag hardwareInterface of joint and\
    \ actuator both should be PositionJointInterface. And then in the joint trajectory\
    \ controller, you don't have to tune pid any more.\n\nHope this would help.\n"
