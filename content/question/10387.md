  body_markdown: "The Beableboard runs on an arm processor.  You cannot install force\
    \ amd64 or i386 debians onto it you will have to install from source.  If you\
    \ compile [ros from source](http://www.ros.org/wiki/diamondback/Installation/Ubuntu/Source)\
    \ several people have done it successfully, it is quite slow.  \n\nNatty has pretty\
    \ good package coverage for arm architecture, I don't think it goes up as far\
    \ as ogre.  But you do not need ogre to use the Kinect, you only need ogre for\
    \ rviz etc which is likely too heavy to run on the Beagleboard.  "
