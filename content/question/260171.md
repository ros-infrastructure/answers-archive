    The gmapping package requires you to publish the transform from your sensor link to your `base_link`, as well as provide odometry data (see [here][gmap]).  You would need to set this up before using gmapping.

    Alternatively, you can use the [hector_mapping][hect] package, which does not require odometry.

    Both packages require you to have a transform between the link that is getting the laser data and your base link/frame.  This is accomplished with a [URDF][urdf] and [robot_state_publisher][rsp], or a tf [static_transform_publisher][stp].

    [gmap]: http://wiki.ros.org/gmapping#Required_tf_Transforms
    [hect]: http://wiki.ros.org/hector_mapping
    [stp]: http://wiki.ros.org/tf#static_transform_publisher
    [rsp]: http://wiki.ros.org/robot_state_publisher
    [urdf]: http://wiki.ros.org/urdf
