  body_markdown: "I can't give you any specific advice (hopefully someone else here\
    \ can), but I can tell you where to look for more info.\n\nIf you want to find\
    \ out what aerial drones are *officially* supported by ROS, I suggest you check\
    \ out the [ROS Robots](http://robots.ros.org/) page, and specifically the [ROS\
    \ Aerial Robots](http://robots.ros.org/category/aerial/) page. This page might\
    \ need to be updated as it looks like [Erle-Copter](http://erlerobotics.com/blog/erle-copter/)\
    \ and [DJI](https://github.com/dji-sdk/Onboard-SDK-ROS) now have official/semi-official\
    \ support for ROS as well. \n\nFor more unofficial support, I suggest you read\
    \ a [similar question](https://answers.ros.org/question/224557/ros-programmable-dronesuavs-in-the-market/)\
    \ already here on ROS Answers and read through the [ROS news section](http://www.ros.org/news/robots/uavs/).\n\
    \nIn general though, I'd always recommend using an officially supported ROS robot\
    \ over an unofficially supported one. Using ROS code provided by the platform\
    \ manufacturers will almost always be easier and less stressful to use than code\
    \ written by yourself or a third party.\n\n"
