  body_markdown: "You are createing a local subscriber in your function call back:\n\
    \n\n    void ccgui::clickLabelhelpBtn_timeout(){\n    this->deactiveSpeechCommand(\"\
    move\");\n    ros::Subscriber sub = getNodeHandle().subscribe(\"/speech_control_interface/cmd\"\
    , 10, &ccgui::receiveSpeechCommand, this);\n    ROS_INFO(\"topics %s %d\", sub.getTopic().c_str(),\
    \ sub.getNumPublishers());\n    // int ret = QMessageBox::information(widget_,\
    \ QString(\"About timeout\"),\n    // QString(\"Timeout between two commands.\\\
    n\"\n    // \"in [ms]\"),\n    // QMessageBox::Close);\n    }\n\n`sub` is destructed\
    \ and deleted from stack when the at the end function's code; thereby the subscriber\
    \ is also shut down and the callback will never be called!\n\nTo solve this do\
    \ the following:\n\nDeclare your subscriber somewhere in the header file:\n\n\n\
    \    class ccgui\n    : public rqt_gui_cpp::Plugin\n    {\n    Q_OBJECT\n    public:\n\
    \    <..............>\n    \n    private:\n    Ui_Form ui_;\n    ros::Subcriber\
    \ sub;\n    <....................>\n    }\n\nThen subscribe as you did but without\
    \ declaring the object\n\n    void ccgui::clickLabelhelpBtn_timeout(){\n    this->deactiveSpeechCommand(\"\
    move\");\n    sub = getNodeHandle().subscribe(\"/speech_control_interface/cmd\"\
    , 10, &ccgui::receiveSpeechCommand, this);\n    ROS_INFO(\"topics %s %d\", sub.getTopic().c_str(),\
    \ sub.getNumPublishers());\n    // int ret = QMessageBox::information(widget_,\
    \ QString(\"About timeout\"),\n    // QString(\"Timeout between two commands.\\\
    n\"\n    // \"in [ms]\"),\n    // QMessageBox::Close);\n    }\n\nand shut it down\
    \ somewhere, at the latest in plugin shutdown() (this is important because the\
    \ nodehandle your retrieved by `getNodeHandle`) might live longer than your plugin\
    \ so if you do not shut down the subscriber your callback might even be called\
    \ after your plugin was shut down!!\n\n\n    void ccgui::shutdownPlugin()\n  \
    \  {\n       sub.shutdown();\n    }"
