    \ limits, especially the theta acceleration, are too low. I have found that if\
    \ i set the theta acceleration limit very low, TEB will try to reverse more often\
    \ than just rotate in place. This makes sense intuitively because the system will\
    \ have to spend more time rotating then reversing. Also try upping your max_vel_theta\
    \ limit. \n\nBy allowing the robot to rotate more freely you should find that\
    \ it will stop trying to back up as much. You should also be able to relax the\
    \ weight_kinematics_forward_drive to allow for reverse movements that are sometimes\
    \ necessary. \n\nAlso, you have a whole bunch of footprint types listed. You should\
    \ only have two lines, the footprint_model type and its corresponding option.\
    \ For example if you want to use a polygon, have:\n\n    footprint:\n        type:\
