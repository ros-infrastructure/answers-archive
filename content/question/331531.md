    \ link to your URDF to represent the laser and then add a joint from the `base_footprint`\
    \ to it. Something like this should work, although it won't have a visualisation\
    \ of the sensor itself and you will need to fix the actual location of the sensor\
    \ on the robot:\n\n    <joint name=\"base_to_laser\" type=\"fixed\">\n      <parent\
    \ link=\"base_footprint\"/>\n      <child link=\"laser\"/>\n      <origin xyz=\"\
    0 0 0\" rpy=\"0 0 0\"/>\n    </joint>\n    \n    <link name=\"laser\"/>"

    I solved it.

    The problem was that the publisher of laser scan, set the frame id to "odom" and not to "scan".

    I solved tring this:

        scan = LaserScan()
        **scan.header.frame_id = "base_scan" #fake_laser_frame"**
        ...#code to set object's param
        scan.ranges = ranges
        self._scan_pub.publish(scan)
