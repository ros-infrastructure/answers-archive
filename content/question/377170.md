    \n> Eureka! I found a solution although it's not an ideal one. As mentioned in\
    \ the question, I noticed that `libvdo_slam.so` was not listed as a shared library\
    \ when running `$ readelf <on_my_library.so>`. So I manually added `-lvdo_slam`\
    \ in the CMakeList.txt so it looks like:\n> \n>     target_link_libraries(ros_vdoslam_node\
    \  \n>       ${catkin_LIBRARIES}  \n>       ${OpenCV_LIBS}    \n>       ${PROJECT_NAME}\
    \  \n>       -lvdo_slam  \n>       )  `\n> \n> Moreover, since \"vdo_slam\" also\
    \ uses a modified \"g2o\" library, the same procedure had to be done in the VDO_SLAM\
    \ library's CMakeList.txt(which is adding `-lvdo_slam_g2o` in a similar place).\n\
    > \n> Although it builds successfully now, I still wonder why this happened. From\
    \ my understanding, `-lvdo_slam` is the same as `${vdo_slam_LIBS}`, and the latter\
    \ should be valid after using `find_package(vdo_slam REQUIRED)`"
