    Using the pr2_mechanism model is preferred because it provides a ROS interace to Gazebo. Without this interface, you have no acess to the information from your ROS nodes. The pr2_mechanism stack provides some good tutorials for writing your own controller. A tutorial can be found [here](http://www.ros.org/wiki/pr2_mechanism/Tutorials/Writing%20a%20realtime%20joint%20controller).
