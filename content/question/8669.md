Hello everyone, 

I am well aware of the GUI Overlay tutorial, and I have been able to use it in a number of different applications. However now I am involved in a project where we must use an older version of Gazebo which is tied to ROS Indigo (which happens to be Gazebo 2.2). This version of Gazebo does not have the GUIPlugin.hh file, or seem to have the functionality to create these additional widgets.

I was wondering if it was possible to create a QT GUI which is separate (i.e. not overlaid) to Gazebo, but has buttons which we can use to send ROS messages which activate model and world plugins in our Gazebo environment. 

Has anyone been able to do this? I have searched a bit online, but not much information is available.

Thanks again!
