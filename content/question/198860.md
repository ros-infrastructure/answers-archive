  body_markdown: "Blender export materials with a null ambient lightning, this is\
    \ probably why your meshes don't look like expected.\n\nManually\n---\n\nI do\
    \ not know what to change in the Blender material to set the ambient so I manually\
    \ edit the exported `dae` files; Replace\n\n\n    <ambient>\n      <color sid=\"\
    ambient\">0 0 0 1</color>\n    </ambient>\n\nwith\n\n    <ambient>\n      <color\
    \ sid=\"ambient\">0.1 0.1 0.1 1</color>\n    </ambient>\n\nPython script\n-------------\n\
    \nHere is a script that copies the diffuse color to the ambient color, first edit\
    \ a new script file (this is for Nemo, not Nautilus):\n\n    gedit ~/.local/share/nemo/scripts/RViz\\\
    \ collada\n\nUse the following script:\n\n    #!/bin/bash\n    \n    # Check if\
    \ xml-twig-tools is installed\n    pkg_ok=$(dpkg-query -W --showformat='${Status}\\\
    n' xml-twig-tools|grep \"install ok installed\")\n    if [ \"\" == \"$pkg_ok\"\
    \ ]; then\n        notify-send \"Missing package\" -t 1 \"Please install xml-twig-tools\"\
    \n        exit 0\n    fi\n    \n    count=0\n    \n    # Reads Nautilus / nemo\
    \ arguments to detect which file have to processed\n    # Processes only selected\
    \ files with .dae extension (case insensitive)\n    for file in $(find ${NEMO_SCRIPT_SELECTED_FILE_PATHS}\
    \ -iname '*.dae'); do\n    \t# Fetches all \"diffuse\" properties from materials\
    \ accross the file into a single string\n    \tdiffuse_properties=`xml_grep 'diffuse'\
    \ $file --text_only`\n    \n    \t# Splits diffuse_properties string into an array\
    \ of strings\n    \treadarray -t properties_array <<<\"$diffuse_properties\"\n\
    \    \n    \t# Replaces only the first occurence in the file each time\n    \t\
    for element in \"${properties_array[@]}\"\n    \tdo\n    \t\tsed -i \"0,/ambient\\\
    \">0\\ 0\\ 0\\ 1/s//ambient\\\">$element/\" $file\n    \tdone\n    \n    \t((count++))\n\
    \    done\n    \n    # Notify user\n    notify-send \"RViz collada\" -t 1 \"$count\
    \ files tweaked\"\n    exit 0\n\nMake the script executable:\n\n    chmod +x ~/.local/share/nemo/scripts/*"
