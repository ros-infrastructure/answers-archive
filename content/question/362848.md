  body_markdown: "I haven't been able to find a way to rotate the camera plugin on\
    \ Ubuntu 20, ROS 2 Foxy, but it is worth noting that the plugin faces towards\
    \ the positive X direction. So you can either design the link acting as your camera\
    \ accordingly, or you can make a special link with no physics attributes, and\
    \ create a joint connecting the camera sensor link to your actual link you have\
    \ to represent the camera. \n\nExample a camera sensor rotated 90 degrees (from\
    \ yaw/z axis) than that of the link:\n\n    <?xml version=\"1.0\" encoding=\"\
    UTF-8\"?>\n    \n    <robot name=\"camera_bot\" xmlns:xacro=\"http://www.ros.org/wiki/xacro\"\
    \ >\n    \n     <!-- Just the sensor, nothing else -->\n    <link name=\"camera_sensor_link\"\
    >\n    \n          <sensor type=\"camera\" name=\"sensor_name\">\n           \
    \   <always_on>0</always_on>\n              <update_rate>1</update_rate>\n   \
    \ \n              <camera name=\"camera_name\">\n                <distortion>\n\
    \                  <k1>0.1</k1>\n                  <k2>0.2</k2>\n            \
    \      <k3>0.3</k3>\n                  <p1>0.4</p1>\n                  <p2>0.5</p2>\n\
    \                  <center>0.5 0.5</center>\n                </distortion>\n \
    \             </camera>\n    \n              <plugin name=\"plugin_name\" filename=\"\
    libgazebo_ros_camera.so\">\n    \n                <ros>\n                  <namespace>custom_ns</namespace>\n\
    \                  <argument>image_raw:=custom_img</argument>\n              \
    \    <argument>camera_info:=custom_info</argument>\n                </ros>\n \
    \   \n                <camera_name>custom_camera</camera_name>\n             \
    \   <frame_name>custom_frame</frame_name>\n                <hack_baseline>0.07</hack_baseline>\n\
    \              </plugin>\n            </sensor>\n    \n    </link>\n    \n   \
    \  <!-- This would be your actual link you wanted to attach the camera sensor\
    \ too -->\n    <link name=\"camera_link\">\n    \n        <!-- Camera Link Inertia\
    \ -->\n        <inertial>\n          <mass value=\"1\"/>\n          <inertia\n\
    \            ixx=\"0.166667\" ixy=\"0\" ixz=\"0\"\n            iyx=\"0\" iyy=\"\
    0.166667\" iyz=\"0\"\n            izx=\"0\" izy=\"0\" izz=\"0.166667\"\n     \
    \       />\n        </inertial>\n    \n        <!-- Camera Link Visual -->\n \
    \       <visual name='visual'>\n          <geometry>\n            <box size=\"\
    0.1 0.2 0.1\" />\n          </geometry>\n        </visual>\n    \n        <!--\
    \ Camera Link Collision -->\n        <collision name='collision'>\n          <geometry>\n\
    \            <box size=\"0.1 0.2 0.1\" />\n          </geometry>\n        </collision>\n\
    \      </link>\n    \n    <joint name='robot_footprint_joint' type='fixed'>\n\
    \        <parent link=\"camera_link\" />\n        <child link=\"camera_sensor_link\"\
    \ />\n        <origin xyz=\"0.1 0 0\" rpy=\"0 0 1.570795\" />\n      </joint>\n\
    \    \n    </robot>\n\n\n"
