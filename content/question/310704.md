    Found my problem
    I did not use connect, signal and slot command.

    To connect a button interaction with C++ a connection signal and slot command is required.
    Something like **connect(ui_.button, SIGNAL(clicked()), this, SLOT(Load_object()));**.
    The connection part connect the button with the action, signal set the type of trigger (this example it is a action wen clicked) and slot select the function, that will be activated.
