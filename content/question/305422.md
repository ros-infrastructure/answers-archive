  body_markdown: "Hi @rezenders,\n\nThe error is because the class you are trying\
    \ to execute is not in the classpath. \n\n> Also, is it necessary to use catkin_create_rosjava_project\
    \ my_pub_sub_tutorial ? Is it possible to run programs the same way it is done\
    \ with python? Like just creating a file.py and adding permissions to run?\n\n\
    The short answer is no.\n\nLet me explain a bit: every Java program has a fixed\
    \ entrypoint (aka `main` method) that is the first thing executed. In rosjava\
    \ you regularly write a ROS node overriding `AbstractNodeMain`, so you need some\
    \ main method to actually run the node for you. That is provided in [RosRun](https://github.com/rosjava/rosjava_core/blob/kinetic/rosjava/src/main/java/org/ros/RosRun.java)\
    \ class, which is the standard entrypoint for any rosjava application (look at\
    \ the project level `build.gradle` file; you should see `mainClassName` declared\
    \ there). When you execute the command `rosrun [package] [project] [class name]`\
    \ you are actually calling an executable script generated by Gradle, which runs\
    \ `RosRun` class (which is part of rosjava), which in turn loads your node to\
    \ the classpath and executes it. There are some more details around all of this,\
    \ but as you can guess it's not the same as executing a python script.\n\nDid\
    \ you follow the steps of the [tutorial](http://wiki.ros.org/rosjava_build_tools/Tutorials/indigo/WritingPublisherSubscriber%28Java%29)\
    \ one by one without skipping anything? You shouldn't encounter any errors there.\
    \  "
