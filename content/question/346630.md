 Autoware 1.13.0 installation with CUDA on from the source code can be achieved by following these steps below:

**Installation of CUDA 10.0 and setting up NVIDIA graphics card**

 1. Download gcc 6 first from [here](https://debian.pkgs.org/9/debian-main-amd64/gcc-6_6.3.0-18+deb9u1_amd64.deb.html). (I had to redo everything as I had gcc 9. Make sure you have gcc <= 6)
 2. Download CUDA 10.0 from [here](https://developer.nvidia.com/cuda-10.0-download-archive?target_os=Linux&target_arch=x86_64&target_distro=Ubuntu&target_version=1804&target_type=deblocal)  and
    follow [this](https://www.videogames.ai/Install-CUDA-10-Ubuntu-18-04-18-10) (skip the machine learning step). Also while installing cuda use  `sudo apt-get install cuda-10.0`. Used [this](https://docs.nvidia.com/cuda/archive/10.0/cuda-installation-guide-linux/index.html#pre-installation-actions) as a complete installation guide. 
 3. Download nvidia 430 driver from [here](https://www.linuxbabe.com/ubuntu/install-nvidia-driver-ubuntu-18-04).  
 4. Run the benchmark using Unigine Heaven 4.0 to test the GPU.
 5. Verify the installation from [here](https://xcat-docs.readthedocs.io/en/stable/advanced/gpu/nvidia/verify_cuda_install.html)

**Installation of Ros Melodic, installing system dependencies, updating eigen values and installing Autoware**

 6. Install Ros Melodic from [here](http://wiki.ros.org/melodic/Installation/Ubuntu)

 7. Check for ros installation using this command rosversion -d

 8. Install all the system dependencies from [here](https://gitlab.com/autowarefoundation/autoware.ai/autoware/-/wikis/Source-Build) and follow along to download and install Autoware.

Thanks!
