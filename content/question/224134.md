  body_markdown: "The tab-completion for roscd eventually calls rospack; and that\
    \ startup for rospack tries to query if the current directory is within a ROS\
    \ package or not, by walking up from the current directory to /, looking for a\
    \ package.xml. \n\nIt looks like this is a bug in rospack, and I don't see a good\
    \ way to suppress it without modifying rospack. You should file an issue on the\
    \ [rospack issue tracker](https://github.com/ros/rospack/issues)."
