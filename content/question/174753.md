  body_markdown: " Hi, the urdf description is loaded and parsed in robot_self_filter::SelfMask::configure(const\
    \ std::vector<LinkInfo> &links). The urdf is accessed though the parameter \"\
    robot_description\", so throw that sucker in your launch file like so:\n\n \n\n\
    \        <launch>\n        <!--   <include file=\"$(find 3dnav_pr2)/launch/pr2_planning_environment.launch\"\
    \ /> -->\n    \n            <!-- Robot Model -->\n            <arg name=\"model\"\
    \     default=\"<my_robot>\" />\n    \n            <!-- Robot Self Filter -->\n\
    \              <node pkg=\"robot_self_filter\" name=\"robot_self_filter\" type=\"\
    self_filter\" respawn=\"true\" output=\"screen\">   \n              ...\n    \
    \          </node>\n        \n            <!-- Specify URDF file -->\n       \
    \       <param name=\"robot_description\"\n                    textfile=\"$(find\
    \ robot_self_filter)/urdf/$(arg model).urdf\"/>\n         </launch>\n\n  \nAlso,\
    \ for others, you might get this warning:\n\n    [ WARN] [1439998460.539715578]:\
    \ Self see links need to be an array\nwhen specifying the self_see_links parameter\
    \ in the launch file. One thing you can try is 1) create a yaml file, 2) add the\
    \ following array of dictionaries:\n\n    self_see_links: [{\"name\":\"l_upper_arm_link\"\
    ,\"padding\":0.02,\"scale\":0.1},\n                 {\"name\":\"l_upper_arm_roll_link\"\
    ,\"padding\":0.02,\"scale\":0.1},\n                 {\"name\":\"l_elbow_flex_link\"\
    ,\"padding\":0.02,\"scale\":0.1},\n                 {\"name\":\"l_elbow_flex_link\"\
    ,\"padding\":0.02,\"scale\":0.1}]\n\n and 3) load it in the launch file by replacing\
    \ \"< param name=\"self_see_links\" type=\"string\"... />\" with the following:\n\
    \n     <!-- Load self_see_links -->\n     <rosparam command=\"load\" file=\"$(find\
    \ robot_self_filter)/launch/<my_self_see_links>.yaml\"/>\n"
