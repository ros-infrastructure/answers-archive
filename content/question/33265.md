  body_markdown: |-
    I assume you have a feature/landmark based map if you're using classic EKF-based localization? In that case, the [OccupancyGrid](http://ros.org/doc/api/nav_msgs/html/msg/OccupancyGrid.html) message format used by gmapping and other occupancy grid mapping approaches probably doesn't make much sense.
    The easiest option is to publish your feature/landmark locations using [Marker](http://www.ros.org/wiki/rviz/DisplayTypes/Marker) messages.
