  body_markdown: |-
    1. The `gazebo_ros_pkgs` that you get from the ROS buildfarm depend on the Gazebo version that is available upstream on [Ubuntu](https://packages.ubuntu.com/search?keywords=gazebo&searchon=sourcenames). Since we're planning on releasing Gazebo 11 into Ubuntu 20.04, that should be the version that comes with Foxy (and Noetic).
    1. We also [release](http://gazebosim.org/tutorials?tut=ros_wrapper_versions&cat=connect_ros) other combinations of Gazebo / ROS versions into the [OSRF packages](http://packages.osrfoundation.org/gazebo/ubuntu-stable/pool/main/r/) as needed. So far, no one has asked to use ROS 2 with Gazebo 10, so we haven't released that. If you're interested, you could make sure it compiles, and ticket an [issue](https://github.com/ros-simulation/gazebo_ros_pkgs/issues) asking for the release and we'll work on it as soon as we can.
