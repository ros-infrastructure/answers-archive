    \nThe `stamp` looks fine to me.\n\nRemember that it actually represents *seconds\
    \ since epoch* (from [docs.ros.org/std_msgs/Header](http://docs.ros.org/jade/api/std_msgs/html/msg/Header.html)):\n\
    \n> Two-integer timestamp that is expressed as:\n\n>  * stamp.sec: seconds (stamp_secs)\
    \ since epoch (in Python the variable is called 'secs')\n * stamp.nsec: nanoseconds\
    \ since stamp_secs (in Python the variable is called 'nsecs')\n\n> time-handling\
    \ sugar is provided by the client library\n\nSo in your case, `1453724932` is\
    \ actually `Mon, 25 Jan 2016 12:28:52 GMT` and some nanoseconds (converted using\
    \ [epochconverter.com](http://www.epochconverter.com/)).\n"
