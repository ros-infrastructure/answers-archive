I know I can use the builtin_interfaces but there is no corresponding package for builtin in the dds world which is also a part of the project. So I tried a couple of things:

1. Mapping header.stamp fields to individual fields so

    header.stamp.secs = seconds # defined seconds as an int64 in the corresponding msg
    header.stamp.nsecs = nanoseconds # defined nanoseconds as an uint32 in the corresponding msg

But this throws a key error (because secs and nsecs are part of another message Time)

    File "/home/dev/avante_ros_bridge/bridge_ws/src/ros1_bridge/ros1_bridge/__init__.py", line 956, in ros1_get_from_field

2. Created a separate message that will act as a structure for these 2 data types

HeaderStamp.msg

    int32 sec
    uint32 nanosec

Used this in the message as 

    HeaderStamp stamp

 and then mapped it to header.stamp

    fields_1_to_2:
          header.stamp: 'stamp'

but it still doesn't get mapped and throws the following stderr while compiling the bridge

    1 mappings can not be generated due to missing dependencies:
    - <ros1-pkg-name>/<ros1-msg-name> <-> <ros2_pkg_name><ros2-msg-name>
       - <ros2-pkg-name>/HeaderStamp

I am sourcing both ros1 and ros2 underlay and overlay workspaces and the rest of the messages are getting mapped, let me know what am I missing here or if there is another way to go about this
