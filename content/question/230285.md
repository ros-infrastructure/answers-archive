    You may need the following two steps:
    First, you launch a camera driver node, which publishes image topic. Meanwhile, the raw image topic should be rectified with image_proc node, which may need a calibration file provided by you.
    Second, compile the ROS mono example in ORB-SLAM2,  and then run this node and set its subscribed topic to the above rectified image topic.
