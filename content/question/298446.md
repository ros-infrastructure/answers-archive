  body_markdown: "The quick fix would be to just publish a static transform from `base_footprint`\
    \ \u2192 `bot1_tf/bot1/base_footprint`, like this:\n\n    rosrun tf static_transform_publisher\
    \ 0 0 0 0 0 0 base_footprint bot1_tf/bot1/base_footprint 10\n\nThe more elegant\
    \ solution would be to make the node that publishes `odom` \u2192 `base_footprint`\
    \ to publish `odom` \u2192 `bot1_tf/bot1/base_footprint` instead. It looks like\
    \ that node is called `bot1/turtlebot3_core`. In the launch file that launches\
    \ that node, try adding the following parameter:\n\n    <param name=\"tf_prefix\"\
    \ value=\"bot1_tf/bot1/\" />\n\nIf that doesn't work, read the documentation or\
    \ source code for that node to figure out if there is a parameter that allows\
    \ you to set the output frame to `bot1_tf/bot1/base_footprint`."
