  body_markdown: "I just solved the issue. I'm going to drop the answer here.\n\n\n\
    ----------\n\nSo ROS 2 Galactic default rmw implementation is **Eclipse Cyclone\
    \ DDS** which does not enable multicast by default. Unfortunately I was not able\
    \ to get **Eclipse Cyclone DDS** working. \n\nSo I changed to **eProsima Fast\
    \ DDS** with `export RMW_IMPLEMENTATION=rmw_fastrtps_cpp`\nAfter changing I learned\
    \ that multicast is not enabled by default in  **eProsima Fast DDS** either...\
    \ So I needed to create a file named `fastrtps-profile.xml` with the following\
    \ content inside:\n\n    <?xml version=\"1.0\" encoding=\"UTF-8\" ?>\n    <profiles\
    \ xmlns=\"http://www.eprosima.com/XMLSchemas/fastRTPS_Profiles\" >\n    <transport_descriptors>\n\
    \        <transport_descriptor>\n            <transport_id>CustomUdpTransport</transport_id>\n\
    \            <type>UDPv4</type>\n        </transport_descriptor>\n    </transport_descriptors>\n\
    \n    <participant profile_name=\"participant_profile\" is_default_profile=\"\
    true\">\n        <rtps>\n            <userTransports>\n                <transport_id>CustomUdpTransport</transport_id>\n\
    \            </userTransports>\n\n            <useBuiltinTransports>false</useBuiltinTransports>\n\
    \        </rtps>\n    </participant>\n    </profiles>\n\nThis enabled multicast\
    \ in **eProsima Fast DDS**. To  make DDS use this configuration file, you do:\
    \ `export FASTRTPS_DEFAULT_PROFILES_FILE=<path_to_config_file_created>`. \n\n\
    Do this in both machines and it should work!"
