    \ things as plain vanilla as possible, meaning use the correct version of Ubuntu\
    \ to match the ROS release you are targeting. If you start with the appropriate\
    \ version of Ubuntu installed onto your Pi 3, then you can simply follow the standard\
    \ ROS install instructions and they will work! \n\nhttp://wiki.ros.org/kinetic/Installation/Ubuntu\n\
    \nFor ROS Kinetic, you'll want to target the Ubuntu 16.04 (Xenial) release. For\
    \ other versions of ROS, check the page:\n\nhttp://wiki.ros.org/Distributions\n\
    \nKeeping things vanilla means you'll get the most stable configuration, as it's\
    \ the one many others are using, albeit on different hardwares. \n\nFor Ubuntu\
    \ install:\n\nhttps://ubuntu.com/download/raspberry-pi\n\nKeep in mind that unless\
    \ you have a specific reason for targeting Kinetic, you might prefer to use a\
    \ newer version of ROS/Ubuntu, like Melodic/18.04.\n\nFinally, you could find\
