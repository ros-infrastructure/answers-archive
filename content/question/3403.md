  body_markdown: "Found one solution (not the best way, but it worked for me)</br>\
    \ While installing gazebo\\_ros\\_pkgs on groovy (any distro that is non-hydro)\
    \ if an error of the following form comes up during catkin\\_make :</br></br>`/usr/include/gazebo-1.9/gazebo/physics/State.hh:26:22:\
    \ fatal error: sdf/sdf.hh: No such file or directory\n`</br>\nNote: the sdf/sdf.hh\
    \ part may come up more than once.</br></br> Let the catkin_make fail, then navigate\
    \ to </br></br> `~/catkin_ws/build` </br></br> You will find a file `CMakeCache.txt`\
    \ open it in any editor and then use search to find all instances of </br></br>\
    \ `-I/usr/include/sdf-1.4` and `/usr/include/sdf-1.4` in the file. </br></br>\
    \ To these **add(do not replace)** another command that will include `;/usr/include/sdf-1.4/sdf`\
    \ (note the extra **/sdf**) so that it should look like </br></br> `GAZEBO_STATIC_INCLUDE_DIRS:INTERNAL=/usr/include/gazebo-1.9;/usr/include/gazebo-1.9/gazebo;/usr/include/sdf-1.4;/usr/include/sdf-1.4/sdf`\
    \ and </br></br>`GAZEBO_STATIC_CFLAGS:INTERNAL=-I/usr/include/gazebo-1.9;-I/usr/include/gazebo-1.9/gazebo;-I/usr/include/sdf-1.4;-I/usr/include/sdf-1.4/sdf`\
    \ </br></br>Do this for all instances. </br> </br> Now go back to ~/catkin\\_ws\
    \ and run catkin\\_make, it should build without errors. \n"
