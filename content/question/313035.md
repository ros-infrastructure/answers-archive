  body_markdown: |-
    As has been mentioned by @Isha Dijcks the `detect_marker` function in your code is a message callback. It gets executed every time your node receives a message on it's topic, in this case it's own execution takes an insignificant amount of time so the rate it is executed at is entirely depended on the rate of messages being published on that topic.

    If you want to speed this up you don't need to do anything to this code, you need to change the settings for [ar_track_alvar](http://wiki.ros.org/ar_track_alvar) that controls the rate at which it publishes marker pose detection messages.

    There is a non-documented (as far as I can tell) configuration parameter [(see source code)](https://github.com/ros-perception/ar_track_alvar/blob/melodic-devel/ar_track_alvar/nodes/IndividualMarkers.cpp#L530) for this node called `max_frequency` which defaults to 8 (Hz). By adjusting this you should be able to increase the rate of your callback function.

    Hope this helps.
