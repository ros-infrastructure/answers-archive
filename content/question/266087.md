    **UPDATE**

    > I want to know how I can add the necessary dependencies if I can't use the metapackages as dependencies as listed in the tutorial.

    Looking at the tutorial you referred to, IMO your question is valid. I've [suggested](https://bitbucket.org/osrf/gazebo_tutorials/pull-requests/438/both-ros_control-and-ros_controllers-are/diff) a possible fix. You must pass explicit dependencies.

    ----

    Not sure if I understand your question correctly but if you're asking if it's possible for your_package to depend on `metapackage`s, <s>yes, and your_package can include all direct dependency defined in a metapackage as well as transitive ones</s> **no** normal catkin package cannot depend on metapackages (ref. [REP-0127](http://www.ros.org/reps/rep-0127.html#metapackage)).

    Only metapackages can depend on other metapackages.
    E.g. `ros-kinetic-desktop-full`, which is a metapackage that [includes standard packages](http://www.ros.org/reps/rep-0142.html#desktop-variants), depends on [another metapackage ros-kinetic-desktop](https://github.com/ros/metapackages/blob/d56a5d422d02300ce6ce3cc50846053f9195bcd6/desktop_full/package.xml#L13), which [depends on another metapackages](https://github.com/ros/metapackages/blob/d56a5d422d02300ce6ce3cc50846053f9195bcd6/desktop/package.xml#L16_L20).
