  body_markdown: "You didn't say which error you actually get. I assume the problem\
    \ is that you pass a SerializedMessage to publisher which actually expects something\
    \ that can be serialized into a SerializedMessage. To publish a message, you need\
    \ to implement a Serializer struct, specialized on your data type as explained\
    \ [here](http://www.ros.org/wiki/roscpp/Overview/MessagesSerializationAndAdaptingTypes).\
    \ For just a pure byte array, the implementation should be pretty trivial, something\
    \ like the following:\n\n    class Foo {\n     public:\n      Foo(const char *buffer,\
    \ size_t length) \n          : buffer_(buffer), length_(length) {}\n      const\
    \ char byte(size_t i) { \n        return buffer[i]; \n       }\n       size_t\
    \ length() {\n         return length_;\n       }\n      private:\n       const\
    \ char *buffer_;\n       size_t length_;\n    };\n\n    namespace serialization\
    \ {\n    template<>\n    struct Serializer<Foo> {\n      template<typename Stream,\
    \ typename T>\n      inline static void write(Stream& stream, T t) {\n       \
    \ for (size_t i = 0; i < t.length(); i++) {\n          stream.next(t.byte(i));\n\
    \        }\n      }\n      inline static uint32_t serializedLength(const Foo &foo)\
    \ {\n        return foo.length();\n      }      \n    };\n    }  //namespace serialization\n\
    \nNote that the code doesn't implement any code for deserializing the message\
    \ which is (hopefully) not necessary for publishing messages.\n"
