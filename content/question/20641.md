    Hi,

    I give you here two ways that you could achive a "plannar like" movement:

    1) With two primsatic joints in tandem
    2) With a plugin that taps into the speed of an object that moves on the plane

    I leave you here with the [CodeGit](https://bitbucket.org/theconstructcore/plannar_mover/src/master/) for each one, a [Video](https://www.youtube.com/watch?v=mtSpqObg9X4) explaining all the process and a [ROSJECT](https://goo.gl/bSxigu) with the code ready to go.

    1) Two prismatic Joints:

    The URDF that we spawn that has the two prismatic joints and at the end the elemnt that you want to move in the plane:
    ( Its a urdf but because of the platform limitations it had to have the sdf extension)
    [plannar_mover.urdf](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/15392413289595272.sdf)

    The launch files to spawn the URDF and the empty world:

    [C:\fakepath\kinetic_main.launch](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/15392414663748702.launch)

    [C:\fakepath\spawn_with_controlers_plannar_mover.launch](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/15392414762536521.launch)

    [C:\fakepath\spawn_robot_urdf.launch](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/15392414842534126.launch)

    [C:\fakepath\spawn_plannar_mover.launch](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/15392414969994355.launch)

    [C:\fakepath\plannar_mover_control.launch](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/15392415064026872.launch)

    [C:\fakepath\plannar_mover_empty.world](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/1539241716557395.world)

    The main disavantage of this method is that you have phisical elements moving, which give always problems and worst is that prismatic joints don't behave very well, they bend and do some strange stuff. Sure that if you play around with the weights and physical properties of the links you can improve the performance.

    ![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/1539242453532482.gif)

    2) Create a plugin and add seting speed capabilities to any model that has this plugin:

    This is in my opinion the method that works best, the only downside is that the model has to have zero friction with the ground or it has to have some kind of wheels to avoid it flipping.

    This is the code for the model plugin:

    [C:\fakepath\plannar_mover.cpp](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/15392416439558533.cpp)

    The world with the plugin in a box dummy model:

    [C:\fakepath\plannar_mover.world](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/15392416851621225.world)
