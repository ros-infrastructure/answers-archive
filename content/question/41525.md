  body_markdown: "Though not a complete answer, here are some advantages of using\
    \ `qt_create` pkg in `qt_ros` stack:\n\n  * Upon creating pkg, `CMakeLists.txt`\
    \ will be modified, which allows you to build pkg (by `rosmake`) that uses `Qt`\
    \ on the fly\n    * MOC files will be generated automatically\n    * include paths,\
    \ library paths are filled. \n    * `Qt`'s `resource` files will be integrated.\n\
    \  * A class automatically generated called `QNode` provides interface between\
    \ `ROS` and your `Qt` codes.\n\nAlthough `qt_create` is deprecated in `fuerte`(http://www.ros.org/wiki/qt_create),\
    \ it still works fine on my environment. HTH."
