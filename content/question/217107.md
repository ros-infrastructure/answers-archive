  body_markdown: "Yes, it does. If there is no `roscore` already running.\n\nAs per\
    \ Wiki on [roslaunch](http://wiki.ros.org/roslaunch#roscore):\n\n> roscore is\

    \ system.\n\nAnd on [roscore](http://wiki.ros.org/roscore) itself:\n\n> NOTE:\
    \ If you use roslaunch, it will\n> automatically start roscore if it\n> detects\
    \ that it is not already\n> running. "
