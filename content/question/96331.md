    \nHi Unais,\n\nFor starters: http://answers.ros.org/question/74776/cartesian-controller-for-ros/\n\
    \nConstructing a pose message:\n\n    #include <tf/transform_broadcaster.h>\n\n\
    \    // translate roll, pitch and yaw into a Quaternion\n    double roll \t= 0.0;\n\
    \    double pitch \t= 0.0;\n    double yaw \t    = 1.5707;\n    tf::Quaternion\
    \ q;\n    q.setRPY(roll, pitch, yaw);\n    geometry_msgs::Quaternion odom_quat;\n\
    \    tf::quaternionTFToMsg(q, odom_quat);\n\n    geometry_msgs::Pose pose;\n \
    \   pose.position.x  = 0.0;\n    pose.position.y  = 0.15;\n    pose.position.z\
    \  = 0.40;\n    pose.orientation = odom_quat;\n\nYou have to push the different\
    \ poses into a list and pass them to computeCartesianPath(), example:\n\n    std::vector<\
    \ geometry_msgs::Pose > poses;\n    moveit_msgs::ExecuteKnownTrajectory srv;\n\
    \    srv.request.wait_for_execution = true;\n    ros::ServiceClient executeKnownTrajectoryServiceClient\
    \ = node_handle.serviceClient<moveit_msgs::ExecuteKnownTrajectory>(\"/execute_kinematic_path\"\
    );\n  \n    poses.push_back(pose.pose);\n    poses.push_back(pose2.pose);\n  \
    \  poses.push_back(pose3.pose);\n    poses.push_back(pose4.pose);\n\n    group.computeCartesianPath(poses,\
    \ 0.005, 1000.0, srv.request.trajectory);\n    executeKnownTrajectoryServiceClient.call(srv);\n\
    \n'eef_step' is the step size used to generate the intermediate points, the 'jump_threshold'\
    \ is explained here (see last reply): [Linear gripper movement](https://groups.google.com/forum/?hl=nl#!searchin/moveit-users/linear$20grpper/moveit-users/f-Ah9O9xJhw/V86D3d-PqJIJ).\
    \ Passing 0.0 for jump_treshold effectively disables the jump threshold test.\n\

    \ path_constraints = moveit_msgs::Constraints(); \n    path_constraints.name =\
    \ \"orientation_constraint\";\n    \n    moveit_msgs::OrientationConstraint orientation_constraint\
    \ = moveit_msgs::OrientationConstraint();\n    orientation_constraint.header.frame_id=\"\
    base_link_1\";\n    orientation_constraint.orientation.x = x;\n    orientation_constraint.orientation.y\
    \ = y;\n    orientation_constraint.orientation.z = z;\n    orientation_constraint.orientation.w\

    \ = 10.0f;\n    orientation_constraint.link_name = \"gripper_link_1\";\n    path_constraints.orientation_constraints.push_back(orientation_constraint);\n\
