  body_markdown: "If you are interested in a special topic you can use rostopic bw\n\
    \n    rostopic bw --help\n    Usage: rostopic bw /topic\n    \n    Options:\n\
    \      -h, --help            show this help message and exit\n      -w WINDOW,\
    \ --window=WINDOW\n                            window size, in # of messages,\
    \ for calculating rate\n\nUnfortunately it does only support a single topic, so\
    \ you may need multiple calls into it for monitoring more than one topic.\n\n\
    Also a nice tool for monitoring your network interfaces useage and additional\
    \  information is bmon. However, this will not explizitly so you the `ROS-part`\
    \ of your network load:\n\n    sudo apt-get install bmon\n    bmon\n\n"
