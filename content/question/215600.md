    I think this is the *ROS way* to do it:

        import roslaunch
        uuid = roslaunch.rlutil.get_or_generate_uuid(options_runid=None, options_wait_for_master=False)
        roslaunch.configure_logging(uuid)
        launch = roslaunch.parent.ROSLaunchParent(uuid, roslaunch_files=[], is_core=True)
        launch.start()
        #  --- your code ---
        launch.shutdown()

    You can specify your launch files as a list of string in the `ROSLaunchParent` constructor.
    Check the [doc](http://docs.ros.org/en/melodic/api/roslaunch/html/) if needed.
