- body_markdown: "The reason why you are unable to read the ros param set under node\
    \ is because, the name got changed i.e. attached with the name of node.\n\nFor\
    \ example, if you consider the following\n\t<node name=\"testnode\" pkg=\"asdf\"\
    \ type=\"a.py\">\n\t\t<param name=\"params\" value=\"4\" />\n\t</node>\n\nThen\
    \ your parameter name will be /testnode/params. So now if you read using rospy.get_param('\
    \ /testnode/params'), you should be able to read it without any issue."
