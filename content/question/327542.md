    Almost all navigation packages rely on localization, which is usually provided by either a SLAM algorithm (like `gmapping`, `slam_karto`, ...) creating the map or localization algorithm like `amcl` which needs a map to work, that is usually published from the `map_server`.

    There are quite [some tutorials](http://wiki.ros.org/navigation#Tutorials) available that explain both cases.

    Please follow up with more concrete questions (and a link to the tutorial you are following) if this is not sufficient.
