  body_markdown: "You should provide us your `urdf` model, it would be easier to help\
    \ you.\n\nAnyway, you have probably defined something like that :\n\n     <joint\
    \ name=\"my_joint\" type=\"fixed\">\n        <origin xyz=\"0 0 1\" rpy=\"0 0 0\"\
    />\n        <parent link=\"base_link\"/>\n        <child link=\"odom\"/>\n   \
    \  </joint>\n\nThe line `<origin xyz=\"0 0 1\" rpy=\"0 0 0\"/>` here is the important\
    \ part, it should be `0 0 0` if you want your frames to be at the same position.\n\
    \n\n----------\n\n**EDIT :** You have the offset because of your mesh file. The\
    \ plugin set odom at `z=0` in order to have your robot at the level of the ground.\
    \ Since you use mesh files but don't change the origin within the `visual` and\
    \ `collision` tags of your urdf the frame is created at the middle of your mesh\
    \ file, so in order to have odom at `z=0` the frame base_link is created at `z=your_mesh_height/2`.\n\
    \nSince you know that you always have an offset of `0.06` between the frames (I\
    \ guess your mesh height is then `0.12`) all you have to do is changing from:\n\
    \n     <origin xyz=\"0.0 0.0 0.0\" rpy=\" 0 0. 1.570796\" /> \nTo :\n\n    <origin\
    \ xyz=\"0.0 0.0 0.06\" rpy=\" 0 0. 1.570796\" />\n\nWithin the tags `collision`\
    \ and `visual`.\n\n**Note :**\nA better way to do this would be to create another\
    \ link `base_footprint` in your urdf and set a joint between `base_link` and `base_footprint`\
    \ defining the offset between the two frames. You can see it in the [gazebo tutorials\
    \ (section Planar Move Plugin)](http://gazebosim.org/tutorials?tut=ros_gzplugins).\
    \ You'll just have to change the `robotBaseFrame` to `base_footprint`."
