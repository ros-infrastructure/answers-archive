  body_markdown: "I had the same issue, to solve it you need to do the following:\n\
    1- check the output type format for the USB camera you're working with. \n2- Mine\
    \ was mjpeg so I had to modify the usb_cam-test.launch which can be found under\
    \ the following directory: /opt/ros/noetic/share/usb_cam/launch/usb_cam-test.launch\n\
    3- Change \"yuyv\" to \"mjpeg\" in the launch file\n4- Run the following node\
    \ rosrun usb_cam usb_cam_node _pixel_format:=mjpeg\n5- It should be working well\
    \ right now. You can double-check by doing: rosrun image_view image_view image:=/usb_cam/image_raw"
