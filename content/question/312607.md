 I use ros kinetic with Ubuntu 16.04 and I am currently following the gazebo tutorial on the ros wiki website: http://wiki.ros.org/simulator_gazebo/Tutorials/Gazebo_ROS_API

I have no problem to run a box.urdf file in gazebo with the following command:

rosrun gazebo_ros spawn_model -urdf -file `rospack find gazebo_ros`/objects/desk1.model -z 1 -model myBox

The problem is I cannot run the file myFile.model by typing:

rosrun gazebo_ros spawn_model -gazebo -file `rospack find gazebo_ros`/objects/desk1.model -z 1 -model myDesk.

The desk1.model is described on https://bitbucket.org/osrf/simulator_gazebo/src/595f9360af4fa9e9fb4262623314ce947495c4db/gazebo_worlds/objects/desk1.model?at=default&fileviewer=file-view-default
