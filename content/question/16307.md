  body_markdown: "ModelPtr is a custom type declaration. [Here](https://bitbucket.org/osrf/gazebo/src/bae84f76b4ad7a6a7cecaeb3e76e545b8c8d5f3e/gazebo/physics/PhysicsTypes.hh?at=default&fileviewer=file-view-default#PhysicsTypes.hh-91),\
    \ you can see the `typedef` and how `ModelPtr` is equivalent to `boost::shared_ptr<Model>`.\
    \ In a nutshell, a `ModelPtr` is a shared pointer to a model object. [Here's a\
    \ quick tutorial](http://www.drdobbs.com/cpp/smart-pointers-in-boost/184401507)\
    \ about boost smart pointers.\n\nAn `ElementPtr` is also a custom type, another\
    \ shared pointer to an `sdf::Element`. [Here](https://bitbucket.org/osrf/sdformat/src/4ecab3417a5be2ecdc3394db523ef9a47dddcf6b/include/sdf/Element.hh?at=default&fileviewer=file-view-default#Element.hh-43),\
    \ you can see the `typedef` in SDFormat. "
