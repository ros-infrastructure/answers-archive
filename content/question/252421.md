  body_markdown: "## Not recommended\n\nTo run any shell commands from a cpp program,\
    \ you can use the `std::system` function. ie\n\n    #include <cstdlib>  // I think\
    \ 'system' is in here?\n\n    int main(void) {\n        std::system(\"rosrun [package]\
    \ [node]\");  // replace [package] and [node] with the relevant text\n\n     \
    \   return EXIT_SUCCESS;\n    }\n\nThis won't work unless the master node is running\
    \ (i.e you have called `roscore` or `roslaunch` first) \n\n## Recommended\n\n\
    Normally when you want to start a node, you run all the nodes you'll need in the\
    \ program using a [launch file](http://answers.ros.org/question/12216/launch-file-how-to-write-it/).\
    \  Instead of generating new nodes during runtime, you could also create [services](http://wiki.ros.org/Services).\
    \ The [Cpp API](http://wiki.ros.org/roscpp) gives you basically all the interfaces\
    \ you'll need.\n\nI would highly recommend doing the [tutorials](http://wiki.ros.org/ROS/Tutorials).\
    \ They take ages, but go a long way to understanding ROS.\n\nAlso, before posting\
    \ a question next time, [look](https://www.google.co.nz/search?channel=fs&q=open+a+rosnode+in+cpp&ie=utf-8&oe=utf-8&gfe_rd=cr&ei=9SqBWKahI8_r8Af9_7_wDQ)\
    \ [for](http://answers.ros.org/question/223090/start-or-stop-the-ros-node-in-another-node/)\
    \ [the](http://answers.ros.org/question/12260/terminate-launch-other-node-from-code/)\
    \ [answer](http://ros-users.122217.n3.nabble.com/how-to-run-a-node-from-another-node-td2439377.html)\
    \ [first](http://answers.ros.org/question/208574/using-rosnodes-api-c/), and if\
    \ these don't answer your question, follow the [support guidelines](http://wiki.ros.org/Support).\
    \ A more descriptive title might be \"How to execute rosrun command from cpp\"\
    , then the informal text can go in the text body."
