  body_markdown: "The code below shows a node written in python, that will set the\
    \ `my_robot`'s position to the origin of the map. The service requires a message\
    \ of type `gazebo_msgs::ModelState`.\n\n    import rospy \n    import rospkg \n\
    \    from gazebo_msgs.msg import ModelState \n    from gazebo_msgs.srv import\
    \ SetModelState\n    \n    def main():\n        rospy.init_node('set_pose')\n\
    \    \n        state_msg = ModelState()\n        state_msg.model_name = 'my_robot'\n\
    \        state_msg.pose.position.x = 0\n        state_msg.pose.position.y = 0\n\
    \        state_msg.pose.position.z = 0.3\n        state_msg.pose.orientation.x\
    \ = 0\n        state_msg.pose.orientation.y = 0\n        state_msg.pose.orientation.z\
    \ = 0\n        state_msg.pose.orientation.w = 0\n    \n        rospy.wait_for_service('/gazebo/set_model_state')\n\
    \        try:\n            set_state = rospy.ServiceProxy('/gazebo/set_model_state',\
    \ SetModelState)\n            resp = set_state( state_msg )\n    \n        except\
    \ rospy.ServiceException, e:\n            print \"Service call failed: %s\" %\
    \ e\n\n    if __name__ == '__main__':\n        try:\n            main()\n    \
    \    except rospy.ROSInterruptException:\n            pass"
