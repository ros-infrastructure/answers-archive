    For my hydro install I have the file `gazebo_rosConfig.cmake` in `install/share/gazebo_ros/cmake/`. Possibly gazebo_ros has not been properly built/installed before the build of `robot_gazebo` has started.

    You could try invoking `catkin_make_isolated` with additional `--only-pkg-with-deps gazebo_ros` and after that has finished invoke it again to build everything.

    It seems that the `rrbot_gazebo` is missing some `build_depends` in its [package.xml](https://github.com/ros-simulation/gazebo_ros_demos/blob/master/rrbot_gazebo/package.xml), but I wounder why you are building this package at all. At some point it seems you are deviating from the tutorial, because for me I don't see `rrbot_gazebo` as part of `desktop_full` on hydro.
