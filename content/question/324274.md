    \  find_package(catkin REQUIRED COMPONENTS\n      geometry_msgs\n      roscpp\n\
    \      tf\n    )\n\nThese lines are correct.\n\n>     catkin_package(\n      #INCLUDE_DIRS\
    \ include\n      #LIBRARIES robot_setup_tf\n      #CATKIN_DEPENDS geometry_msgs\
    \ roscpp tf\n      #DEPENDS system_lib\n    )\n    \n>     # include\n      ${catkin_INCLUDE_DIRS}\n\
    \    )\n\nThese lines are clearly not correct and I don't understand how you could\
    \ not have gotten complaints from CMake about this. As is, this will not setup\
    \ the include path correctly, so `ros/ros.h` is not on the include path, leading\
    \ to the compiler error you show.\n\nThe correct statement would be:\n\n    include_directories(\n\
    \      # include\n      ${catkin_INCLUDE_DIRS}\n    )\n\nSome other observations:\n\
    \n>     link_directories(${catkin_LIBRARY_DIRS})\n\nThis is not needed and should\
    \ be removed.\n\n>     ${catkin_EXPORTED_TARGETS})\n    \n>     ${catkin_EXPORTED_TARGETS})\n\
    \nThese statements do nothing and should be removed or fixed.\n\nThe tutorial\
    \ you mention does not instruct you to change the `CMakeLists.txt` other than\
    \ adding a few lines to get the binaries to build. Did you edit the `CMakeLists.txt`\
    \ yourself?\n\nFinally: if you haven't, I would recommend you follow the TF2 version\
    \ of this tutorial (ie: [this one](http://wiki.ros.org/tf2/Tutorials/Writing%20a%20tf2%20broadcaster%20%28C%2B%2B%29)),\
