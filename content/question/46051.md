    You can use the [ROS Logging mechanism](http://www.ros.org/wiki/roscpp/Overview/Logging) for that. Just output what you're interested in using the ROS_INFO or ROS_DEBUG mechanisms and record /rosout using rosbag, e.g.

        rosbag record /rosout
    you can then later play back all data with timestamps provided, and view them for example using [rxconsole](http://www.ros.org/wiki/rxconsole).
