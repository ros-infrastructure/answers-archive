  body_markdown: ">  Is it true that I say: we have \u201C/teleop_turtle\u201D node\
    \ that publishes the arrow keys pushed \n\nyes, at a high level that is certainly\
    \ what happens.\n\nIn reality though, it's not *keys* that get published, but\
    \ [geometry_msgs/Twist](http://docs.ros.org/api/geometry_msgs/html/msg/Twist.html),\
    \ so velocities ([here](https://github.com/ros/ros_tutorials/blob/2b1de43ba413bf59bbb7eb0578bf79e1721049de/turtlesim/tutorials/teleop_turtle_key.cpp#L122-L129)).\n\
    \nKeystrokes are much too specific to this one application, while velocities generalise\
    \ and can be used with all sorts of robots.\n\n> and \u201C/turtlesim\u201D node\
    \ that shows it's subscribe by moving the turtle?\n\nagain correct.\n\n`turtlesim`\
    \ implements a simple simulation of a 2D platform and how that would/should move\
    \ upon receiving `geometry_msgs/Twist` messages. In fact a lot of mobile bases\
    \ with ROS compatibility use the exact same control interface as `turtlesim`."
