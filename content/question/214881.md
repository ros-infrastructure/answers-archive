    The software architecture is the same as most robots in ROS: you have stacks, packages, and nodes.
    The hierarchy is like this:

        Turtlebot Stack|(Stack)
                       |-Turtlebot Teleop(Package)--------|- Keyboard teleop(node)
                       |-Turtlebot Bringup                |-logitech teleop

    All of the turtlebot code is in multiple github repositories here: [https://github.com/turtlebot](https://github.com/turtlebot). If you are planning on porting the software to another robot, you might want to consider somehting like the arbotix drivers as they deal with a simpler protocol as the turtlebot uses the Kobuki base protocol.
    Hope that helps,
