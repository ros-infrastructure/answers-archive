    \ working with a manipulator arm:\n\n- https://github.com/joshnewans/urdf_example\n\
    \n- https://articulatedrobotics.xyz/ready-for-ros-7-urdf/\n\n- https://www.youtube.com/watch?v=laWn7_cj434\n\
    \nYou have to have a fixed link to the world, like below.\n\nA part of the URDF\
    \ (check the links for the rest):\n\n    <!-- This first link called \"world\"\
    \ is empty -->\n    <link name=\"world\"></link>\n \n \n    <!-- A simple fixed\
    \ joint from our empty world link, to our base. -->\n    <!-- The base origin\
    \ is offset from the world origin. -->\n    <joint name=\"base_joint\" type=\"\
    fixed\">\n        <origin xyz=\"1.5 1.0 0\" rpy=\"0 0 0\"/>\n        <parent link=\"\
    world\"/>\n        <child link=\"base_link\"/>        \n    </joint>\n \n \n \
    \   <!-- base_link is a large rectangular plate. Some things to note: -->\n  \
    \  <!-- - We set the visual origin Z to half the box height, so that the link\
    \ origin sits at the bottom of the box -->\n    <!-- - We set the collision to\
    \ be identical to the visual -->\n    <!-- - We specified the colour manually\
    \ (but still need to enter a name) -->\n    <!-- - We specified all the inertial\
    \ parameters manually -->\n    <link name=\"base_link\">\n        <visual>\n \
    \           <origin xyz=\"0 0 0.05\" rpy=\"0 0 0\"/>\n            <geometry>\n\
    \                <box size=\"2.5 1.5 0.1\" />\n            </geometry>\n     \
    \       <material name=\"green\">\n                <color rgba=\"0.2 1 0.2 1\"\
    />\n            </material>\n        </visual>\n        <collision>\n        \
    \    <origin xyz=\"0 0 0.05\" rpy=\"0 0 0\"/>\n            <geometry>\n      \
    \          <box size=\"2.5 1.5 0.1\" />\n            </geometry>\n        </collision>\n\

    \ ixz=\"0.0\" iyy=\"6.26\" iyz=\"0.0\" izz=\"8.5\" />\n        </inertial>\n \
