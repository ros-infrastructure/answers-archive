  body_markdown: "Hello, \n\n> Question: Is there any ways to hide some CollisionObject's\
    \ visuals in Rviz, but keep others?\n\nYes, there is a way to hide Collision objects\
    \ you can hide them by the object name. You just have to change the color of the\
    \ collision box and while adding color you have to put RGBA values during that\
    \ set A values to 0.001. Your collision box will be not visible over here and\
    \ it will also prevent your robot from colliding. \n\nI am adding code for setting\
    \ color in the RVIZ object:\n\nImports and variables add this at the time of initializing.\n\
    \n    from moveit_msgs.msg import PlanningScene, ObjectColor\n    \n    # Create\
    \ a scene publisher to push changes to the scene\n    self.scene_pub = rospy.Publisher('planning_scene',\
    \ PlanningScene, queue_size=10)\n    # Create a dictionary to hold object colors\n\
    \    self.colors = dict() \n\n\nAdd these lines for the calling function and put\
    \ this line after or below the scene.add_box function calling.    \n  \n    ###\
    \ Make the target purple ###\n    self.setColor(target_id, 0.6, 0, 1, 1.0)  #\
    \ X, Y, Z (normalized RGB) and A value\n    \n    # Send the colors to the planning\
    \ scene\n    self.sendColors()\n\n\nAdd both function in your class\n\n      \
    \  # Set the color of an object\n        def setColor(self, name, r, g, b, a =\
    \ 0.9):\n            # Initialize a MoveIt color object\n            color = ObjectColor()\n\
    \    \n            # Set the id to the name given as an argument\n           \
    \ color.id = name\n    \n            # Set the rgb and alpha values given as input\n\
    \            color.color.r = r\n            color.color.g = g\n            color.color.b\
    \ = b\n            color.color.a = a\n    \n            # Update the global color\
    \ dictionary\n            self.colors[name] = color\n    \n        # Actually\
    \ send the colors to MoveIt!\n        def sendColors(self):\n            # Initialize\
    \ a planning scene object\n            p = PlanningScene()\n    \n           \
    \ # Need to publish a planning scene diff        \n            p.is_diff = True\n\
    \    \n            # Append the colors from the global color dictionary \n   \
    \         for color in self.colors.values():\n                p.object_colors.append(color)\n\
    \    \n            # Publish the scene diff\n            self.scene_pub.publish(p)\n\
    \n\nIf you are using CPP here is a link for you [Link](http://docs.ros.org/en/jade/api/moveit_python/html/classmoveit__python_1_1planning__scene__interface_1_1PlanningSceneInterface.html)\n\
    \n\nNote: over here you have to put RGB values into a normalized form. You can\
    \ have a look at this [website](https://doc.instantreality.org/tools/color_calculator/)\
    \  for converting RGB color to normalized decimal color that will be used into\
    \ RVIZ. \n\nTo sum up: Yes, there is a way to hide the collision box and it also\
    \ avoids a collision. You have to set color and in color, you have to make A (of\
    \ RGBA) to 0.001, which means the brightness for that particular color. If you\
    \ are not stratified with the answer or you are not clear, please! comment I will\
    \ do my best to answer you.\n\n\nJust check this image: You can see in image 3,\
