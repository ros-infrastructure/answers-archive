  body_markdown: "The turtlesim window is a separate executable. Typically, C++ does\
    \ not support running executable from code. Typically you have to use the `system()`\
    \ command to do so. But, there is also a system called [rosspawn](http://www.ros.org/wiki/rosspawn)\
    \ that might just do what you want it to do. \n\nI'm not sure what the end goal\
    \ is, but there are a couple of options I can think of:\n\nIf you're trying to\
    \ launch turtlesim at the same time as one of your own executables, I would suggest\
    \ [roslaunch](http://ros.org/wiki/roslaunch). \n\nIf you're looking to do something\
    \ that you cannot do via turtlesim's topics and services, I would suggest looking\
    \ at the code for turtlesim in the turtlesim package (probably in the `src` directory).\
    \ You might be able to modify it to your needs. \n\nIf you edit your question\
    \ to be more specific as to the goal, I might be able to help further. "
