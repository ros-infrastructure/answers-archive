    As of the Bouncy release, the closest functionality to what you are looking for is that a list of launch files that are in a specific package will tab-complete once `ros2 launch <package_name>` has already been typed. There isn't currently an equivalent to `ros2 pkg executables` (the functionality [is there](https://github.com/ros2/launch/blob/9ee4cc65863ddc353decbd8f8f5fed6d425de5f0/ros2launch/ros2launch/api/api.py#L137) but it's currently only used for argument auto-complete), nor is there currently a way to list all packages that have launch files (see [this tracking issue](https://github.com/ros2/launch/issues/98)).
