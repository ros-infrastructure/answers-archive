    \ folder. \nSteps:\n\n1) `cd ~/catkin_ws/src`\n\n2) `git clone https://github.com/ros-teleop/teleop_twist_keyboard`\n\
    \n3) `cd ~/catkin_ws`\n\n4) `catkin_make`\n\n5) `source ~/catkin_ws/devel/setup.bash`\n\
    \n6) `source ~/.bashrc` \n\nI also assume you have your ros environment in your\
    \ bashrc file. It should contain the following lines :\nsource /opt/ros/indigo/setup.bash\
    \ and you should add the following lines to your bashrc script by running :\n\n\
    `gedit ~/.bashrc` and add :\n\n     source ~/catkin_ws/devel/setup.bash\n\nNew\
    \ terminals will pick up when you open it. Also, you will need to remap linear\
    \ and angular velocity for your robot to the /cmd_vel topic to use the keyboard\
    \ for teleoperation. I would suggest looking into [turtlebot_teleop](https://github.com/turtlebot/turtlebot_apps/tree/indigo/turtlebot_teleop)\
    \ package for details.\n\n\n"
