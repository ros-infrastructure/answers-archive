  body_markdown: "Had the same problem and landed here googling for a solution. Eventually\
    \ I found out that you have to set an environment variable to tell the GUI which\
    \ host and user to connect to.\n\nSee [Gazebo environment variables](https://gazebosim.org/api/transport/11.0/envvars.html).\n\
    \nMy Setup: \n\n - Gazebo Fortress\n - The simulation is running on machine 1,\
    \ the GUI is running on machine 2. \n - Both machines are in the same subnet (192.168.0.xyz).\n\
    \nMachine 1 (simulation): \n\n - user: user1 \n - hostname: host1\n \nMachine\
    \ 2 (GUI): \n\n - user: user2 \n - hostname: host2\n\nStart the simulation on\
    \ machine 1:\n\n - $ ign gazebo -v 4 shapes.sdf -s\n\nSet environment variable\
    \ and start GUI on machine 2:\n\n - $ export IGN_PARTITION=host1:user1\n - $ ign\
    \ gazebo -v 4 -g\n\nThe default setting for UDS multicast works for me (see [IGN_DISCOVERY_MULTICAST_IP](https://gazebosim.org/api/transport/11.0/envvars.html)).\n\
    \nHope that helps!"
