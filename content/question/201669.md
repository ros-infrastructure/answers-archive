    \ yet.\n\nYou mention that you're \"relatively new to ROS\": have you done the\
    \ ROS [introductory tutorials](http://wiki.ros.org/ROS/Tutorials)? I think especially\
    \ the [Understanding ROS Nodes](http://wiki.ros.org/ROS/Tutorials/UnderstandingNodes)\
    \ tutorial should help here, and [ros/wiki/Master](http://wiki.ros.org/Master):\n\
    \n> The ROS Master provides naming and registration services to the rest of the\
    \ [nodes](http://wiki.ros.org/Nodes) in the ROS system. It tracks publishers and\
    \ subscribers to [topics](http://wiki.ros.org/Topics) as well as [services](http://wiki.ros.org/Services).\
    \ The role of the Master is to enable individual ROS nodes to locate one another.\
    \ Once these nodes have located each other they communicate with each other peer-to-peer.\n\
    \n> The Master also provides the [Parameter Server](http://wiki.ros.org/Parameter%20Server).\n\
    \n> The Master is most commonly run using the `roscore` command, which loads the\
    \ ROS Master along with other essential components. \n"
