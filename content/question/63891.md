  body_markdown: "I think that your best start would be to look into the [openni_launch](http://www.ros.org/wiki/openni_launch)\
    \ package this will help you to get the raw data from the kinect. The next thing\
    \ I would recommend is to look into the [Point Cloud Library](http://pointclouds.org/).\
    \ They are very heavily tied to ROS and provide a very robust library for handling\
    \ RGB-D data. \n\nFinally PCL offers many tutorials that discuss the topics you\
    \ want to look into check out the following: \n\n - [ICP](http://pointclouds.org/documentation/tutorials/iterative_closest_point.php#iterative-closest-point)\n\
    \ - [Localization](http://docs.pointclouds.org/trunk/group__registration.html)\
    \ (map building)\n - As for robot_pose_ekf I do not know what this is but there\
    \ is a ROS page [here](http://www.ros.org/wiki/robot_pose_ekf) that seems to cover\
    \ the concept and the use of the ROS node pretty well so please check that out.\
    \ \n\nHope this helps. \nBadRobot"
