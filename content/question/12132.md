  body_markdown: "although an old question, i met the same problem. after i dig into\
    \ it, i find that this is a bug in trajectory_filter_server/trajectory_filter_server.cpp.\n\
    in the method getLimits(), there is:\n\n    limits.min_position = urdf_joint->limits->lower;\n\
    \    limits.max_position = urdf_joint->limits->upper;\n\nif the urdf has continuous\
    \ joint, this will cause a problem because continuous joints has no lower/upper\
    \ limits defined. so the solution is simple, just add a check if(urdf_joint->type\
    \ == urdf::Joint::CONTINUOUS) before \n\n    limits.min_position = urdf_joint->limits->lower\n\
    \    limits.max_position = urdf_joint->limits->upper;\n"
