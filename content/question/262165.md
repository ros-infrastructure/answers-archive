    This seems be not strictly related to ROS and is a known (but apparently not yet fixed) issue. See for instance [this bug report on launchpad](https://bugs.launchpad.net/ubuntu/+source/qtcreator/+bug/1577213). It appears two possible workarounds are

     - Install QtCreator from a PPA (I think [this one](https://launchpad.net/~adrozdoff/+archive/ubuntu/qtcreator-git) is meant in the bug report I linked above).
     - Install QtCreator using the [installer script from the Qt website](https://www.qt.io/download-open-source/#section-9).
