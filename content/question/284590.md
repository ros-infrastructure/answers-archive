  body_markdown: "CLion is a nice tool but for me it did not work out of the box.\
    \ This should be a beginner (primary targeting students) friendly guide on how\
    \ to use CLion with ROS.\n\nHow to setup CLion with ROS (kinetic) [as simple as\
    \ possible]:\n========================================\n\nNote: this how-to is\
    \ tested with ROS kinetic running on Ubuntu 16.04 with CLion 2017.1.3 and 2017.3.2,\
    \ the process might be different with other versions.\n\nI recommend to check\
    \ if `catkin_make` runs properly in your workspace before you start with this\
    \ guide. In this way you know CLion is the problem, not ROS.*\n\n - Start CLion\
    \ from the terminal to ensure everything is sourced properly. You can alternatively\
    \ edit the `.desktop` file, see below).\n - Click \"Import Project from Sources\"\
    \n - Select the `<your workspace path>/src` folder in your workspace\n - Click\
    \ \"Open Project\" - code editor should open\n - Go to \"File\" - \"Settings\"\
    \ - \"Build, Execution, Deployment\" - \"CMake\"\n - Set the generation Path to\
    \ `<your workspace path>/build` and apply\n - Finally you should right-click on\
    \ your top level `CMakeList.txt` file in CLion and select \"Reload CMake Project\"\
    \n\nCLion should work properly now.\n\nIf CLion shows you the info \"This file\
    \ does not belong to any project target\" right-click the `includes` folder an\
    \ click \"Mark Directory as\" and select \"Project Sources and Headers\". \n\n\
    **Always start CLion from terminal unless you changed the `.desktop` file!**\n\
    \nAt the restart of CLion the Project will be shown at the recent projects with\
    \ the name \"src\". You can change this name by adding a `.name` (containging\
    \ only a name for the project) to `<your workspace path>/src./idea`.\n\nSetup\
    \ debugging:\n----------------------------------------\n\n - Go to \"Run\" - \"\
    Edit Configurations\" and click the add button\n - Set a name\n - Select a \"\
    Target\" and the according \"Executable\", keep the \"Configuration\" on Debug\
    \ and apply\n\nNow you can use the run and debug function in CLion. This does\
    \ not work with `.launch` files\n\nHighlighting in `.launch` files:\n----------------------------------------\n\
    \nCLion does not recognize `.launch` files as XML files by default.\n\n - Go to\
    \ \"File\" - \"Settings\" - \"Editor\" - \"File Types\"\n - Search for XML in\
    \ the recognized files list\n - add `*.launch`\n\n`.launch` files should now have\
    \ proper highlighting and auto-complete\n\nChange the `.desktop` file:\n----------------------------------------\n\
    \n - Go to `<your home folder>/.local/share/applications`\n - change the according\
    \ line the `.desktop` file for your CLion version to:\n\n    `Exec=bash -i -c\
    \ \"<clion installation path/bin/clion.sh>\" %f`\n\nNote:\n----------------------------------------\n\
    \nCLion is free for students:  [students click here](https://www.jetbrains.com/student/)\n"
