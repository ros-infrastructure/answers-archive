  body_markdown: "If you set your resources path to any folder with a structure\n\n\
    \    media\n    -materials\n    --scripts\n    --textures\n\nyou can use any material\
    \ you define in those folders just as if you were using the material form the\
    \ `/usr/share/gazebo-x` folder.\n\nJust add \n\n    export $GAZEBO_RESOURCE_PATH=/path/to/your/resource/folder\n\
    \nto the ~/.bashrc file. I, for example, use the `~/.gazebo` folder for my materials\
    \ and models.\n___\nEDIT\nToday I have found more convenient way how to set environment\

    \ <env name=\"GAZEBO_MODEL_PATH\" value=\"$(find robot_gazebo)/models\"/>\n  \

I am using ROS Kinetic with Gazebo 7.x and I know that I can use gazebo materials with

    <gazebo reference="link">
      <material>Gazebo/Orange</material>
    </gazebo>

I did manage to use a custom .jpg file as a texture on my model by 

 - editing the gazebo.materials script from usr/share/gazebo-7/media/materials/scripts

      <export>
        <gazebo gazebo_media_path="${prefix}"/>
      </export>

 - test_gazebo
  - package.xml
  - CMakeList.txt
  - launch/
  - media/
     - materials/
         - scripts/
             - test.materials
         - textures/
             - test.jpg
  - models/

Do I need to change the .urdf if I am using a different media path also? What I tried is using the in my script asigned name like
