  body_markdown: "Hi, you can use the following piece of code to publish tf between\
    \ two frames. For example tf between \"base_link\" to \"scans\" in 2D -> [x,y,theta]\n\
    \n \n    import tf\n\n    def handle_transform(parent, child, tr):\n\t    br.sendTransform((tr[0],\
    \ tr[1], 0), tf.transformations.quaternion_from_euler(0, 0, tr[2]), rospy.Time.now(),\
    \ child,parent)\n    \n    if __name__ == \"__main__\":\n\t\t\n\t    rospy.init_node('main',\
    \ anonymous=True) #make node \n\t    rate = rospy.Rate(5) # 5hz\t\n\t    br =\
    \ tf.TransformBroadcaster() \n\t\t    \n\t    while not rospy.is_shutdown():\n\
    \t\t\t\t\t\t\n\t\t\thandle_transform(\"base_link\", \"scans\", [0,0,0])\n\t\t\t\
    rate.sleep()"

  body_markdown: "If your first task is to find out if the TFs are being broadcast\
    \ at all then I'd recommend staring **rviz** and subscribing to the TF topic.\
    \ If you select an active frame_id from the drop down list in rviz then you should\
    \ see any frames that are being broadcast by any nodes currently running. \n\n\
    This check will find out if they are being broadcast in the first place and what\
    \ their frame_id's are. Then if you find out the TFs are there in the first place\
    \ you can start writing a node to query them, it's not the same as subscribing\
    \ to a topic in this case. There are good tutorials [here for c++](http://wiki.ros.org/tf2/Tutorials/Writing%20a%20tf2%20listener%20%28C%2B%2B%29)\
    \ and [here for python](http://wiki.ros.org/tf2/Tutorials/Writing%20a%20tf2%20listener%20%28Python%29)."
