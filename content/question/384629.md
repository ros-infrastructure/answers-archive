  body_markdown: "I think you can implement this just by iterating through the points\
    \ and checking points direction with atan2. \n\nLet\u2019s say that you will like\
    \ to filter points in between theta1 and theta2. Then simply iterate through each\
    \ point and perform a check; \n\n    If(theta1 <= atan2(point.y, point.x) <= theta2)\
    \ {\n      //  Skip this point } else { \n      Filteredcloud.points.push_back(point)\
    \ } \nNote that this code has not been tested and is provided only for illustrating\
