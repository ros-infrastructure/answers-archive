  body_markdown: "I found the problem!\n\nActionLib is actually hosted at https://github.com/ros-gbp/actionlib-release\
    \ and no longer at it://github.com/wg-debs/actionlib-release.git \u2013 when it\
    \ didn't install properly, gitinstall simply wouldn't create the CMakeLists.txt\
    \ file.\n\nThe fix is to install ActionLib manually. Go into ~/ros-underlay and\
    \ use\n\n    git clone --recursive git://github.com/ros-gbp/actionlib-release.git\
    \ /Users/YOURUSERNAME/ros-underlay/actionlib\n\nThen run \n\n    rosinstall --catkin\
    \ ~/ros-underlay http://ros.org/rosinstalls/fuerte-ros-full.rosinstall\n\nAnd\
    \ hit skip when the install asks whether you want to replace actionlib. Problem\
    \ solved!"
