  body_markdown: "Would [image_publisher](http://wiki.ros.org/image_publisher) be\
    \ sufficient? From its wiki page:\n\n> Contains a node [to] publish an image stream\
    \ from single image file or avi motion file. \n\n---\n\nEdit: note:\n\n> to an\
    \ camera stream\n\nthere are no \"camera stream\"s, only topics carring `sensor_msgs/Image`\
    \ (or any of the compressed variants).\n\nThat's what `image_publisher` does:\
    \ it reads a file and publishes it as a `sensor_msgs/Image`.\n\n---\n\nEdit2:\n\
    \n>     [ERROR] [1588603210.289589342]: Failed to load image (mix.bmp): cap_.isOpened()\
    \ onInit /home/nils-ros/ws_moveit/src/image_pipeline/image_publisher/src/nodelet/image_publisher_nodelet.cpp\
    \ 147\n\nI'm going to guess before you show us the full output of the `roslaunch`\
    \ of your `.launch` file: the path you specify to the image is not correct / complete.\n\
    \nThe error message mentions the filename as being `mix.bmp`. According to [this\
    \ line](https://github.com/ros-perception/image_pipeline/blob/7bfe50c49a2ca9ee3c98b42bfe35ad87fe5528f9/image_publisher/src/nodelet/image_publisher_nodelet.cpp#L155)\
    \ in `image_publisher_nodelet.cpp` that error message should contain the *full\
    \ path* to the image it's trying to open. `mix.bmp` is not a full path. So it's\
    \ likely that [this line](https://github.com/ros-perception/image_pipeline/blob/7bfe50c49a2ca9ee3c98b42bfe35ad87fe5528f9/image_publisher/src/nodelet/image_publisher_nodelet.cpp#L145)\
    \ fails, as it cannot find the image, causing the error your report to be printed.\n\
    \nAssuming this is indeed the cause, you'll need to make sure to pass an absolute\
    \ and complete path as the first argument to the `image_publisher` node, or if\
    \ using the nodelet, the `filename` parameter.\n\nOnly a name of the file will\
    \ not work. Neither will a relative path.\n\n---\n\nEdit 3:\n\n>     <node pkg=\"\
    image_publisher\" type=\"image_publisher\" name=\"mix_image\" args=\"~/mix.bmp\"\

    \ in my earlier edit, you'll have to provide an absolute path.\n\nIf you can place\
