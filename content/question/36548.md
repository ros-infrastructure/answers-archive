  body_markdown: "I would gess that this is caused by the high data amount of both\
    \ devices. The Data is to much for one single USB-Bus (not ports).\nTry to check\
    \ which bus the devices are connectet to by `$lsusb` .\nThen simply try to connect\
    \ the devices to different buses. Another idea would be that the webcam is claiming\
    \ the hole bandwith of to USB-port. Webcams request a whole load of bandwidth,\
    \ usually more than they need. \nThe uvcvideo kernel module can be set to ignore\
    \ the requested bandwidth, and to calculate the right bandwidth. Try:\n\n    $sudo\
    \ rmmod uvcvideo\n    $sudo modprobe uvcvideo quirks=128\n\nThis will be reset\
    \ every reboot. If this works, create the following file: \n\n    $sudo vi /etc/modprobe.d/uvcvideo.conf\
    \ \n\ncontaining the line:\n\n    options uvcvideo quirks=128\n\n*reference:*\
    \  \nhttp://comments.gmane.org/gmane.linux.drivers.uvc.devel/5510\n\nhttps://www.linuxquestions.org/questions/linux-kernel-70/facecam-312-kernel-10-10-conflagration-help-853934/"
