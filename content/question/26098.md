    If you want to create complex geometries (i.e. geometries that cannot be obtained by combining full cubes, full cylinders or full spheres), such as an empty cylinder, the only way is by extruding an SVG file. In this case, you have to extrude a circular crown. SVG files can be obtained using several apps, for example **Inkscape**. I recommend you to follow this tutorial ([Extrude SVG files](http://gazebosim.org/tutorials?tut=extrude_svg&cat=model_editor_top)).
