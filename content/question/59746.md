    The way you have defined it, `obstacles` is a `Points` msg, not a vector of `Point`s, and thus has only one member: `points`.  You would access it with `res.obstacles.points[0]`.  Since `points` is a vector, make sure you `resize` it first or `push_back` the element instead.
