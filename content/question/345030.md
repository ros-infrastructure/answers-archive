    \ to server, rc: -1. Error: 'Connection refused' (errno: 111)`\n\n<P> My issue\
    \ was accidentally using the Teach Pendant's (TP) IP Address while overwriting\
    \ the Controller's IP as that of my Linux machine.\n\n<P> **Suggested Steps**\
    \ for connecting to controller using a direct computer-to-controller connection:\n\
    <br> - Check the Controller (host) IP address and Subnet mask of your controller\
    \ under System Info>Network\n<br> - Check the Teach Pendants IP address and Subnet\
    \ mask\n<br> - Setup your computer's network connection as a static IP address.\
    \ Select a DIFFERENT IP address than that of the Controller and Teach Pendant.\
    \ \n<br> - Be sure to use the SAME SUBNET MASK as the controller!! This is often\
    \ 255.255.255.0\n\n<P>The Yaskawa Motoman FS100 Controller has the following defaults:\n\
    <br>   Controller IP:         10.0.0.2\n<br>   Teach Pendant IP:  10.0.0.4\n<br>\
    \   Subnet Mask:          255.255.255.0\n\nIf you are new to using TCP/IP... I\
    \ would suggest reading [this article by Microscoft](https://support.microsoft.com/en-us/help/164015/understanding-tcp-ip-addressing-and-subnetting-basics)."

Hello!

I am getting an error when attempting to connect my **Yaskawa Motoman MH5 robot w/ FS100 Controller** to my ROS Linux system. I am using a direct ethernet connection from the computer to the controller.

**SETUP**
<br>ROS Melodic w/ Dashing bridge running on Unbuntu 18.04 LTS. Bionic.
<br>Full Desktop Install. Some package additions, but mostly default configuration.

Installed MotoPlus server code following tutorial: https://wiki.ros.org/motoman_driver/Tutorials/indigo/InstallServer
<br> - Used PreBuilt Binary
<br> - Successfully loaded Inform Job via Standard Pendant
<br> - Set input #82015 on FS100 "CMD REMOTE SEL" to "ON"

**USAGE ATTEMPT**
<br> Following tutorial at https://wiki.ros.org/motoman_driver/Tutorials/Usage
<br> - Set Pendant to "REMOTE" mode. 
<br> - Manually set computer's IP & Subnet mask.
<br> - Confirmed connection by pinging robot's IP address (10.0.0.4). Received full packet return at an average of ~1.0 ms latency.

Called
<br>
`roslaunch motoman_mh5_support robot_interface_streaming_mh5.launch robot_ip:="10.0.0.4" controller:="fs100"`

Error
<br>` [ERROR] [_ . _]: Failed to connect to server, rc: -1. Error: 'Connection refused' (errno: 111)`

<br>*I also attempted the `robot_state_visualize_mh5.launch` command to find the same error.
