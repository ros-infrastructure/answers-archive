    Hi,

    I answer to myself: You can add more robots editing the .world file of the stage that you are using. For example, if you are using willow-erratic it would be willow-erratic.world. This file is located at /opt/ros/<distribution>/share/stage_ros/world/

    You need to add the following definition to the file:

    erratic( pose [ -13.277 23.266 0 180.000 ] name "Quasi" color "blue")

    Best,
