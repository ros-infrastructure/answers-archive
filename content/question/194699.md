Hello,

when I'm trying to use pcl::registration::CorrespondenceRejectorSampleConsensus class in my ROS node, I got  Segmentation fault even before the node is initialized. I prepared [minimal example pakage showing this problem](http://www.stud.fit.vutbr.cz/~xvelas00/sac_segmentation_fault.zip). Some additional information:

 - I've installed ROS Indigo on my Ubuntu 14.04 using [standard installation guide](http://wiki.ros.org/indigo/Installation/Ubuntu) 
 - I verified this issue on two independent machines with ROS Indigo installation
 - I've already asked for the help on [PCL forum](http://www.pcl-users.org/Segmentation-fault-when-using-CorrespondenceRejectorSampleConsensus-td4035393.html)  but I've got the response that it's not an issue of the latest PCL released
 - the strangest thing is that event the segfault occurs even before the initialisation is done

To run the problem example:

 1. unzip the package into your workspace
 2. use catkin_make to build it
 3. execute: rosrun sac_segmentation_fault seg_fault
 4. you should obtain the segmentation fault and nothing else is printed into the console

Thank you in advance for any help or advices,
Martin.
