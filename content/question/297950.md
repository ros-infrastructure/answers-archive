    Both ROS 2 distros ([Bouncy](https://github.com/ros2/ros2/wiki/Release-Bouncy-Bolson), [Ardent](https://github.com/ros2/ros2/wiki/Release-Ardent-Apalone)) mention in the wiki that they are only providing Debian packages for Ubuntu (Bouncy for Bionic, Ardent for Xenial).
    So there are neither Debian packages available for Debian Jessie nor for any ARM platform. You can either build ROS 2 from source or try the `aarch64` [fat archive](https://github.com/ros2/ros2/releases) provided.
