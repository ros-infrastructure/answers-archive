  body_markdown: "It sounds like you're using the [ROS Qt Creator Plugin](https://ros-qtc-plugin.readthedocs.io/en/latest/_source/How-to-Install-Users.html).\
    \ Note that the plugin won't work correctly if you open an individual .cpp file\
    \ outside a project.\n\n- Have you run `catkin init` in your `catkin_ws` directory?\n\
    - Have you [imported the ROS workspace into Qt Creator](https://ros-qtc-plugin.readthedocs.io/en/latest/_source/Import-ROS-Workspace.html)?\n\
    - Have you built the project from within Qt Creator (ctrl-B, or the hammer icon\
    \ in the lower left corner of the window). \n\nYou'll get lots of warnings if\
    \ you haven't built the workspace from within Qt Creator. The plugin does some\
    \ behind-the-scenes work when you build the package within Qt Creator in order\
    \ to generate the code model, which enables syntax highlighting, autocompletion,\
    \ and other quality-of-life features."
