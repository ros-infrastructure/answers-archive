  body_markdown: "Well, basically you just have to repeat the syntax given for the\
    \ doneCB.  As far as i understood, you need the binder because you cannot use\
    \ the () operator to indicate if your function has inputs.\n\nThe first parameter\
    \ references your function, the second one to which object the function belongs\
    \ to. Afterwards, you just need parameters if you have inputs. \n\nHere's n' example\
    \ how i implemented this. \n ac.sendGoal(goal,\n                boost::bind(&MyNode::doneCb,\
    \ this, _1, _2),\n                boost::bind(&MyNode::activeCB,this),\n     \
    \           boost::bind(&JacoClient::feedbackCb, this, _1));\n\nIf you want more\
    \ details, you can check out the boost documentation ( it's quite good documented). "
