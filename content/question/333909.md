  body_markdown: "As far as I'm aware there isn't a standard message type for an Array\
    \ of [PoseWithCovariance](http://docs.ros.org/api/geometry_msgs/html/msg/PoseWithCovariance.html)\
    \ or RVIZ plugin to display them. \n\nIf you need to build this yourself it would\
    \ be simpler to make a node which generates a [TriangleList Marker message](http://wiki.ros.org/rviz/DisplayTypes/Marker#Triangle_List_.28TRIANGLE_LIST.3D11.29_.5B1.1.2B-.5D)\
    \ from the set of covariances than it would be to build a new RVIZ plugin. This\
    \ would not be as clean and tidy, but it will get something working faster. If\
    \ this is something that you'll be using for a long time and want to share back\
    \ to the ROS community then it would be worth making a custom message type and\
    \ RVIS plugin. \n\nHope this helps.\n\n"
