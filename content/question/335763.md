    According to [husky_control/config/control.yaml](https://github.com/husky/husky/blob/677120693643ca4b6ed3c14078dedbb8ced3b781/husky_control/config/control.yaml#L29-L42) which is shipped by Clearpath themselves, the max linear acceleration is `3.0` m/s^2:

          # Velocity and acceleration limits
          # Whenever a min_* is unspecified, default to -max_*
          linear:
            x:
              has_velocity_limits    : true
              max_velocity           : 1.0   # m/s
              has_acceleration_limits: true
              max_acceleration       : 3.0   # m/s^2
          angular:
            z:
              has_velocity_limits    : true
              max_velocity           : 2.0   # rad/s
              has_acceleration_limits: true
              max_acceleration       : 6.0   # rad/s^2

    This is not necessarily the *real* acceleration limit, but is what they configure the ROS-side controllers with.

    Note that this same file is used with the simulated version (by [husky_control/launch/control.launch](https://github.com/husky/husky/blob/677120693643ca4b6ed3c14078dedbb8ced3b781/husky_control/launch/control.launch) from [husky_gazebo/launch/spawn_husky.launch](https://github.com/husky/husky/blob/677120693643ca4b6ed3c14078dedbb8ced3b781/husky_gazebo/launch/spawn_husky.launch). So the official simulation uses the same limits.
