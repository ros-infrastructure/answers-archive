  body_markdown: "That's because `roscd` takes you to the `share` folder of a package,\
    \ but the binaries live somewhere else. \n\n    > ls /opt/ros/melodic/lib/robot_localization\n\
    \    ekf_localization_node  robot_localization_listener_node\n    navsat_transform_node\
    \  ukf_localization_node\n\nReplace `melodic` with the name of your distro if\
    \ you are on a different one.\n\nOf course, you don't actually need to know where\
    \ they are if you just want to run them. `rosrun robot_localization ekf_localization_node`\
    \  will know where to find the binary and run it.\n\n"
