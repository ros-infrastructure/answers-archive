  body_markdown: "The (likely) problem here is that ROS uses peer-to-peer transport,\
    \ so adding a second subscriber (the rosbag) doubles the number of bits that need\
    \ to get pushed over your wireless link. \n\nYou can use a [republish node](http://www.ros.org/wiki/image_transport#republish)\
    \ to solve this; run it on machine #2, and then run the viewer and rosbag record\
    \ on machine #2, but subscribed to the republish node, not the actual data topic.\
    \ Then you move the bits over the wireless link once (machine #1 -> republish\
    \ node), and then twice on the loopback interface (republish -> viewer and republish\
    \ -> rosbag)."
