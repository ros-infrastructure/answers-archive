  body_markdown: "your .bashrc has some duplicates.\nIt should probaly look something\
    \ like \n\n    ...\n    source /opt/ros/kinetic/setup.bash\n    source ~/my_ws/devel/setup.bash\n\
    \nAs to why roscd still takes you to your old ws, this would happen if you are\
    \ not using a terminal loaded without the changes in place.  So for the changes\
    \ you made to take effect you will need to reload .bashrc.\n\nEither open a new\
    \ terminal and try there.\n\nOr type `exec bash` into the already open terminal\
    \ to reload .bashrc."
