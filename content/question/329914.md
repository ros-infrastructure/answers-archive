  body_markdown: "It looks like you're trying to publish the OpenCV image directly.\
    \ From what I can recall, you need to convert it to an `Image` message before\
    \ you can publish it. To do that use, `cv_bridge`. Here's a brief example that\
    \ should help you get started (I've included only the bare minimum, for more info\
    \ see the [tutorial on the wiki](https://wiki.ros.org/cv_bridge/Tutorials/ConvertingBetweenROSImagesAndOpenCVImagesPython#An_example_ROS_node))\n\
    \n    from cv_bridge import CvBridge\n    \n    ...\n    \n    bridge = CvBridge()\n\
    \    \n    ...\n    \n    pub.publish(bridge.cv2_to_imgmsg(frame, \"bgr8\"))"
