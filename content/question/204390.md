  body_markdown: "Yep it is (as simple as it should be)! Just create a counter and\
    \ increment and assign it i update()\n\nSnippet of the migration rules class,\
    \ ( see http://wiki.ros.org/rosbag/migration ) :\n\n\n\tmigrated_types = [  ]\n\
    \n\tvalid = True\n\t\n\tcounter = 0\n      \n\tdef update(self, old_msg, new_msg):\n\
    \t\tself.counter += 1\n\t\tnew_msg.obj_id = self.counter"
