  body_markdown: "Hi narcispr,\n\nif you launch rqt_gui when not all topics are being\
    \ published yet, the plugins that depend on a topic will require you to set that\
    \ topic again, but if you launch rqt_gui at the end, when everything is published,\
    \ then your saved setup will keep track of the same topics.\n\n 1. First, open\
    \ all nodes and rqt_gui\n    and set it up as you like.  \n 2. Then, close rqt_gui\
    \ first, then all nodes.\n    \n 3. When you need to work again, run\n    first\
    \ all nodes, then rqt_gui.\n\nThat works for me."
