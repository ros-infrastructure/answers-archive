  body_markdown: "Hi,\n\nIt looks like it can't find the headers.\nAre you sure you\
    \ have installed the `rosserial_arduino` and `Sabertooth/SyRen` libraries properly?\n\
    You should be able to find them in your `sketchbook/libraries` folder.\n\n\nIf\
    \ it is not the case, here is a quick reminder on setting up rosserial_arduino:\n\
    \nDownload the `rosserial` and `rosserial_arduino` packages for your ROS distro.\n\
    \n    sudo apt-get install ros-kinetic-rosserial-arduino\n    sudo apt-get install\
    \ ros-kinetic-rosserial\n\n\nCreate a *sketchbook* folder and its *libraries*\
    \ folder in your home.\nThen, type:\n\n    cd sketchbook/libraries\n    rm -rf\
    \ ros_lib\n    rosrun rosserial_arduino make_libraries.py .\n\nThis should create\
    \ the `sketchbook/libraries/ros_lib` folder.\nRestart your IDE if it was open,\
    \ and you should find the `Rosserial Arduino Library` in your `Manage Libraries`\
    \ tab.\n\nAnd now for the Sabertooth libraries:\n\nDownload the libraries from\
    \ the *Dimension Engineering* website, and copy the folders in `sketchbook/libraries`,\
    \ next to the ros_lib folder.\nLaunch the IDE again. You should now find the Sabertooth\
    \ libraries in your Examples and Manage Libraries tabs.\n\nAfter you do this,\
    \ your project should compile the headers properly. Please, tell me if it is not.\n\
    \nBest regards, \n\nRic"
