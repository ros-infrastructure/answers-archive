  body_markdown: "\nBy default ros map_saver subscribes to topic name `\"map\"` to\
    \ save grid map.\n\nAnd by default crsm_slam publishes map on topic   `\"/slam/occupancyGridMap\"\
    ` .    [check here](https://github.com/etsardou/crsm-slam-ros-pkg/blob/hydro-devel/crsm_slam/config/crsm_slam/crsm_slam_parameters.yaml)\n\
    \n\nSo, to save map \n\n     rosrun map_server map_saver map:=/slam/occupancyGridMap\
    \ -f map"
