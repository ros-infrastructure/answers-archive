    \ request data via subscribers. It does not affect publishers like described in\
    \ [257361](https://answers.ros.org/question/257361/what-is-the-actual-meaning-of-rosspin/).\n\
    \nI guess your publisher publishes the velocity only once. So we introduce a while\
    \ loop that repeats at a fixed rate as long as the rosmaster node is active.\n\
    \nplease try the following:\n\n    ros::Rate loop_rate(10);\n    geometry_msgs::Twist\
    \ msg;\n    while(ros::ok())\n    {\n       msg.linear.x = 1;\n       msg.linear.y\
    \ = 0;\n       msg.linear.z = 0;\n       msg.angular.x = 0;\n       msg.angular.y\
    \ = 0;\n       msg.angular.z = 0;\n       chatter.publish(msg);\n       loop_rate.sleep();\
    \ //if you want to have somewhat fixed rate publishing \n       ros::spinOnce();\
    \           \n    }\n\nfurthermore try removing the first \"/\" at your frame_id\
