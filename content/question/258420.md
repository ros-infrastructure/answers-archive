  body_markdown: "The problem occurs because of two reasons:\n\n- Gazebo \"merges\"\
    \ child links to their parent when they are connected via a fixed joint, creating\
    \ only one link with the name of the parent link;\n- Gazebo ignores links without\
    \ inertial properties\n\nIn the first case you have one link that has no inertia:\
    \ \"junta1\". However, Gazebo merges all the links that are created by the \"\
    barra_model\" macro into the \"junta1\" link, because they are all connected through\
    \ fixed joints. Then \"junta1\" \"gains\" inertia, since the inertia objects of\
    \ its child links now belong to it. Then it is not ignored.\n\nIn the second case,\
    \ you have two links without inertia, \"junta1\" and \"junta2\". They are connected\
    \ through a continuous joint, so Gazebo will not merge them. This lets \"junta1\"\
    \ without inertia, and it gets ignored. Since there is no \"junta1\", all its\
    \ children (i.e the whole bar) are not created. That's why the bar disappears.\n\
    \nThe solution is to give a simple inertial block to the links, with a small mass.\
    \ In the code below, I copied the same inertial properties from the spheres in\
    \ the bar, and added the third link to create the ball joint.\n\n    <?xml version=\"\
    1.0\"?>\n    \n    <robot xmlns:xacro=\"http://www.ros.org/wiki/xacro\">\n\n \
    \   <xacro:macro name=\"junta_model\" params=\"name parent child *origin\">\n\t\
    \t\n      <joint name=\"${name}_joint\" type=\"continuous\">\n        <parent\
    \ link=\"base_link\"/>\n        <child link=\"junta1\"/>\n        <axis xyz=\"\
    0 1 0\" />\n      </joint>\n\n      <link name=\"junta1\">\n        <inertial>\n\
    \          <mass value=\"0.025\" />\n          <inertia ixx=\"5.8083e-4\" ixy=\"\
    0\" ixz=\"0\" iyy=\"3.0833e-5\" iyz=\"0\" izz=\"5.9083e-4\" />\n        </inertial>\n\
    \t  </link>\n      \n      <joint name=\"${name}_joint2\" type=\"continuous\"\
    >\n        <parent link=\"junta1\"/>\n        <child link=\"junta2\"/>\n     \
    \   <axis xyz=\"0 0 1\" />\n      </joint>\n\n      <link name=\"junta2\">\n \
    \       <inertial>\n          <mass value=\"0.025\" />\n          <inertia ixx=\"\
    5.8083e-4\" ixy=\"0\" ixz=\"0\" iyy=\"3.0833e-5\" iyz=\"0\" izz=\"5.9083e-4\"\
    \ />\n        </inertial>  \n\t  </link>\n\t  \n\t  <joint name=\"${name}_joint3\"\
    \ type=\"continuous\">\n        <parent link=\"junta1\"/>\n        <child link=\"\
    junta3\"/>\n        <axis xyz=\"1 0 0\" />\n      </joint>\n\n      <link name=\"\
    junta3\">\n        <inertial>\n          <mass value=\"0.025\" />\n          <inertia\
    \ ixx=\"5.8083e-4\" ixy=\"0\" ixz=\"0\" iyy=\"3.0833e-5\" iyz=\"0\" izz=\"5.9083e-4\"\
    \ />\n        </inertial>  \n\t  </link>\n\n    <joint name=\"${name}_jointfixed\"\
    \ type=\"fixed\">\n        <xacro:insert_block name=\"origin\" />    \n      \
    \  <parent link=\"junta3\"/>\n        <child link=\"${child}\"/>\n      </joint>\n\
    \    </xacro:macro>\n    \n    </robot>\n\n\nI hope it helps."
