  body_markdown: "I just figured this out with joystick_remapper. The problem is joy/Joy\
    \ msg type is deprecated and you should use sensor_msgs/Joy instead. However,\
    \ (in my case) joystick_remapper still subscribes to the old joy/Joy type. I made\
    \ the change in joystick_remapper.py line 43: \n\n    from sensor_msgs.msg import\
    \ Joy \n\nThen in manifest.xml in the joystick_remapper package, remove \n\n \
    \   <depend package=\"joy\"/>\n\nand add\n\n    <depend package=\"sensor_msgs\"\
    /> \n\nDo rosmake the package. Then you're good to run the joy_remap node."
