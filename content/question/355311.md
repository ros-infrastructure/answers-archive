  body_markdown: "The way that I have found to solve this issue is remove the joint_state_publisher\
    \ from launch file and put it in the xacro file like this:\n\n    <gazebo>\n \
    \   \t<plugin name=\"joint_state_publisher\" filename=\"libgazebo_ros_joint_state_publisher.so\"\
    >\n    \t\t<robotNamespace>/mm</robotNamespace>\n    \t\t<jointName>${base_link}__${frame},\
    \ \n                       ${frame}__${crank}, \n                       ${crank}__${coupler},\
    \ \n                       ${fork}__${wheel}, \n                       ${frame}__${rocker}\n\
    \            </jointName>\n    \t</plugin>    \n    </gazebo>\n\nNow the robot's\
    \ movements in Rviz are the same as in Gazebo and the TF tree is made correctly."
