  body_markdown: "First of all, there exist multiple Euler Angle conventions.\n\n\
    URDF and SDF use the **X-Y-Z (Tait\u2013Bryan) Extrinsic** Euler Angle convention\
    \ - 3 consecutive rotations around the X, Y, and Z coordinate axes of the original\
    \ (fixed) coordinate system. [1]\n\nThere are several gotcha edge cases when dealing\
    \ with Euler Angles, so I recommend using a library like Christoph Gohlke's transformations.py\
    \ (https://www.lfd.uci.edu/~gohlke/code/transformations.py.html).\n\n----------\n\
    \nTry something like this *(untested)*:\n\n - Assume you have two unit vectors,\
    \ vector **a** lies on axis of the previous cylinder, and vector **b** lies on\
    \ the axis of the current cylinder.\n - Assume that length(**a**)==length(**b**)\
    \ > 0.\n - Calculate the cross product of **a** and **b**: **v** = **a** x **b**.\
    \ **v** is the **axis** of rotation between **a** and **b** [2]. If **a** and\
    \ **b** are colinear, this will fail but that means they lie on the same axis\
    \ and there's no rotation between them (technically, there could be a 180 degree\
    \ rotation but let's assume that no branches go 'backwards').\n - Calculate the\
    \ dot product of **a** and **b**: cos(angle)=dot(**a**, **b**)/(length(**a**)+length(**b**)).\
    \ The result is the cosine of the **angle of rotation**. [2]\n - Calculate the\
    \ acos of cos(angle) from previous step: angle=acos(cos(angle)). angle is the\
    \ **angle of rotation**. [2]\n - Now, you have an **axis angle representation**\
    \ of **a rotation** between **a** and **b**.\n - Using the [transformations.py\
    \ library](https://www.lfd.uci.edu/~gohlke/code/transformations.py.html), you\
    \ can calculate **X-Y-Z extrinsic Euler Angles** from the **axis angle representation**.\n\
    \  - Given axis of rotation **v** and angle of rotation a.\n  - **R** = rotation_matrix(a,\
    \ **v**):\n  - x, y, z = euler_from_matrix(**R**, axes='sxyz'):\n\n----------\n\
    References:\n\n - [1] Euler Angles: https://en.wikipedia.org/wiki/Euler_angles\n\
    \ - [2] Euler angles between two 3d vectors: https://stackoverflow.com/a/15109028/8670609\n\

 Hi !

I'm trying to build SDF tree models from a description file.
The branches are modeled by cylinders.
For each cylinder, I have : x, y, z : coords of the cylinder, vx, vy, vz : vector supporting the cylinder.

Since the `<pose>` takes roll, pitch and yaw angles to build a cylinder, I have to compute them from the direction vector (vx, vy, vz).

Here's how I do it, using `numpy`:

`roll = np.arctan2(vz, vy)`

`pitch = np.arctan2(vx, vz)`

`yaw = np.arctan2(vy, vx)`

I'm not getting the results I want, some of the branches are clearly misplaced. I noticed that Gazebo places a cylinder along the z axis if you provide yaw, pitch, roll = 0, so I tried to rotate by 90° on the x axis like so :

`roll = np.arctan2(vz, vy) + 1.5708`

without success.

If you have any advice on how to get these Euler angles right, feel free to share !
