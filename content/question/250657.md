  body_markdown: "I think it is because you accidentally look for you map in the namespace.\
    \   \nIn the launch file for you nodes you should look whether your nodes subscribe\
    \ to \"map\" or \"/map\".   \n\"/map\" is the global topic for the map which you\
    \ want to use as the map_server should not be launched in a namespace.   \nFrom\
    \ the error it seems that the issue is with amcl, so I would probably look in\
    \ the amcl launch file and change \"map\" to \"/map\".   \nWhen you only write\
    \ \"map\" amcl tries to subscribe to \"robot_0/map\" topic because of the namespace,\
    \ but as map_server is global the topic does not exist."
