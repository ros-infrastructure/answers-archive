    Any time you set the pose, the non-pose variables should also get reset. This is the code for the `setPoseCallback`:

     1. [Create a measurement that is the size of the entire state](https://github.com/cra-ros-pkg/robot_localization/blob/e1ea727ab8b9a2ba2a458948e3b77aae52f64b7d/src/ros_filter.cpp#L1992)
     2. [Zero it out](https://github.com/cra-ros-pkg/robot_localization/blob/e1ea727ab8b9a2ba2a458948e3b77aae52f64b7d/src/ros_filter.cpp#L1997)
     3. [Update only the pose portion to non-zero values](https://github.com/cra-ros-pkg/robot_localization/blob/e1ea727ab8b9a2ba2a458948e3b77aae52f64b7d/src/ros_filter.cpp#L2005)
     4. [Reset the filter state](https://github.com/cra-ros-pkg/robot_localization/blob/e1ea727ab8b9a2ba2a458948e3b77aae52f64b7d/src/ros_filter.cpp#L2008)
