  body_markdown: "Have a look at the [convenience macro file in the `melodic-devel-staging`\
    \ branch](https://github.com/ros-industrial/universal_robot/blob/melodic-devel-staging/ur_description/urdf/ur5.xacro).\n\
    \nThis you can expand to add your own camera as shown [in the gazebo tutorials](http://gazebosim.org/tutorials?tut=ros_gzplugins#Camera)\n\
    \nYou will end up with something like this:\n\n\n\n    <?xml version=\"1.0\"?>\n\
    \    <robot xmlns:xacro=\"http://wiki.ros.org/xacro\" name=\"ur5_robot\">\n  \
    \  \n      <!-- Add plain robot -->\n      <xacro:include filename=\"$(find ur_description)/urdf/inc/ur5_macro.xacro\"\
    />\n      <xacro:ur5_robot prefix=\"\" />\n\n      <joint name=\"camera_joint\"\
    \ type=\"fixed\">\n        <axis xyz=\"0 1 0\" />\n        <origin xyz=\"${camera_link}\
    \ 0 ${height3 - axel_offset*2}\" rpy=\"0 0 0\"/>\n        <parent link=\"tool0\"\
    />\n        <child link=\"camera_link\"/>\n      </joint>\n      \n      <!--\
    \ Camera -->\n      <link name=\"camera_link\">\n        <collision>\n       \
    \   <origin xyz=\"0 0 0\" rpy=\"0 0 0\"/>\n          <geometry>\n        <box\
    \ size=\"${camera_link} ${camera_link} ${camera_link}\"/>\n          </geometry>\n\
    \        </collision>\n      \n        <visual>\n          <origin xyz=\"0 0 0\"\
    \ rpy=\"0 0 0\"/>\n          <geometry>\n        <box size=\"${camera_link} ${camera_link}\
    \ ${camera_link}\"/>\n          </geometry>\n          <material name=\"red\"\
    />\n        </visual>\n      \n        <inertial>\n          <mass value=\"1e-5\"\
    \ />\n          <origin xyz=\"0 0 0\" rpy=\"0 0 0\"/>\n          <inertia ixx=\"\
    1e-6\" ixy=\"0\" ixz=\"0\" iyy=\"1e-6\" iyz=\"0\" izz=\"1e-6\" />\n        </inertial>\n\
    \      </link>\n      <!-- camera -->\n      <gazebo reference=\"camera_link\"\
    >\n        <sensor type=\"camera\" name=\"camera1\">\n          <update_rate>30.0</update_rate>\n\
    \          <camera name=\"head\">\n            <horizontal_fov>1.3962634</horizontal_fov>\n\
    \            <image>\n              <width>800</width>\n              <height>800</height>\n\
    \              <format>R8G8B8</format>\n            </image>\n            <clip>\n\
    \              <near>0.02</near>\n              <far>300</far>\n            </clip>\n\
    \            <noise>\n              <type>gaussian</type>\n              <!--\
    \ Noise is sampled independently per pixel on each frame.\n                  \
    \ That pixel's noise value is added to each of its color\n                   channels,\
    \ which at that point lie in the range [0,1]. -->\n              <mean>0.0</mean>\n\
    \              <stddev>0.007</stddev>\n            </noise>\n          </camera>\n\
    \          <plugin name=\"camera_controller\" filename=\"libgazebo_ros_camera.so\"\
    >\n            <alwaysOn>true</alwaysOn>\n            <updateRate>0.0</updateRate>\n\
    \            <cameraName>rrbot/camera1</cameraName>\n            <imageTopicName>image_raw</imageTopicName>\n\
    \            <cameraInfoTopicName>camera_info</cameraInfoTopicName>\n        \
    \    <frameName>camera_link</frameName>\n            <hackBaseline>0.07</hackBaseline>\n\
    \            <distortionK1>0.0</distortionK1>\n            <distortionK2>0.0</distortionK2>\n\
    \            <distortionK3>0.0</distortionK3>\n            <distortionT1>0.0</distortionT1>\n\
    \            <distortionT2>0.0</distortionT2>\n          </plugin>\n        </sensor>\n\
    \      </gazebo>\n      \n    </robot>\n\nWith this you can create your custom\
    \ launch file to launch your setup in gazebo similar to [this](https://github.com/ros-industrial/universal_robot/blob/melodic-devel-staging/ur_gazebo/launch/inc/ur_control.launch.xml)\
    \ and add loading the description similar to [here](https://github.com/ros-industrial/universal_robot/blob/9d02ccadc8fb9b5cfeaf0d5b0c0c7708d2461447/ur_gazebo/launch/inc/load_ur.launch.xml#L33)\
    \ (with skipping all the parameters as you used the specific `ur5` macro already.\n\
    \nNote: I didn't test the above and you will have to do some figuring out in the\
    \ launch files to make this work, but I think this should give you the necessary\
    \ hints."
