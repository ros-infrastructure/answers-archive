  body_markdown: "I found the answer, the pr2_controller_msgs/JointTrajectoryActionGoal\
    \ is an old method of using the joint trajectory action control. I changed over\
    \ the tutorial code to use:\n\n    #include <control_msgs/FollowJointTrajectoryAction.h>\n\
    \ninstead of:\n\n    #include <pr2_controllers_msgs/JointTrajectoryAction.h>\n\
    \nand any calls like:\n\n    pr2_controllers_msgs::JointTrajectoryGoal \n\nto:\n\
    \n    control_msgs::FollowJointTrajectoryGoal\n\nWorks fine but now I'm encountering\
