  body_markdown: "  I got it working by using this code. This is for subscribing to\
    \ the foot bumpers. For subscribing to other sensors should be the same concept.\n\
    \n    #include \"ros/ros.h\"\n    #include \"nao_msgs/Bumper.h\"\n    \n    void\
    \ bumperCallback(const nao_msgs::Bumper::ConstPtr &msg)\n    {\n        ROS_INFO(\"\
    I heard: %u and %u\", msg->bumper, msg->state);\n    }\n    \n    int main(int\
    \ argc, char **argv)\n    {\n        ros::init(argc, argv, \"nao_bumper_listener\"\
    );\n        ros:: NodeHandle n;\n        ros::Subscriber bump= n.subscribe(\"\
    bumper\", 1000, bumperCallback);\n        ros::spin();\n        return 0;\n  \
    \  }\n\n"
