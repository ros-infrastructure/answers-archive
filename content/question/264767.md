  body_markdown: "I ended up doing the following. It works in real time as long as\
    \ pyplot can keep up with the messages. \n    \n    #!/usr/bin/env python \n \
    \   import numpy as np\n    from matplotlib import pyplot as plt\n    import rospy\n\
    \    from qualisys.msg import Subject\n\n    def plot_x(msg):\n        global\
    \ counter\n        if counter % 10 == 0:\n\t\t    stamp = msg.header.stamp\n\t\
    \t    time = stamp.secs + stamp.nsecs * 1e-9\n\t\t    plt.plot(msg.position.y,\
    \ msg.position.x, '*')\n\t\t    plt.axis(\"equal\")\n\t\t    plt.draw()\n\t\t\
    \    plt.pause(0.00000000001)\n\t\n\t    counter += 1\n\t\n    if __name__ ==\
    \ '__main__':\n        counter = 0\n\t\n        rospy.init_node(\"plotter\")\n\
    \        rospy.Subscriber(\"position_measurements\", Subject, plot_x)\n      \
    \  plt.ion()\n        plt.show()\n        rospy.spin()"

  body_markdown: "Since this is an old post and still seems to be active in the community,\
    \ I am going to provide an example, in general, how can we do real-time plotting.\
    \ Here I used matplotlib [FuncAnimation][1] function.   \n\n\n    import matplotlib.pyplot\
    \ as plt\n    import rospy\n    import tf\n    from nav_msgs.msg import Odometry\n\
    \    from tf.transformations import quaternion_matrix\n    import numpy as np\n\
    \    from matplotlib.animation import FuncAnimation\n\n\n    class Visualiser:\n\
    \        def __init__(self):\n            self.fig, self.ax = plt.subplots()\n\
    \            self.ln, = plt.plot([], [], 'ro')\n            self.x_data, self.y_data\
    \ = [] , []\n\n        def plot_init(self):\n            self.ax.set_xlim(0, 10000)\n\
    \            self.ax.set_ylim(-7, 7)\n            return self.ln\n        \n \
    \       def getYaw(self, pose):\n            quaternion = (pose.orientation.x,\
    \ pose.orientation.y, pose.orientation.z,\n                    pose.orientation.w)\n\
    \            euler = tf.transformations.euler_from_quaternion(quaternion)\n  \
    \          yaw = euler[2] \n            return yaw   \n\n        def odom_callback(self,\
    \ msg):\n            yaw_angle = self.getYaw(msg.pose.pose)\n            self.y_data.append(yaw_angle)\n\
    \            x_index = len(self.x_data)\n            self.x_data.append(x_index+1)\n\
    \        \n        def update_plot(self, frame):\n            self.ln.set_data(self.x_data,\
    \ self.y_data)\n            return self.ln\n\n\n    rospy.init_node('lidar_visual_node')\n\
    \    vis = Visualiser()\n    sub = rospy.Subscriber('/dji_sdk/odometry', Odometry,\
    \ vis.odom_callback)\n\n    ani = FuncAnimation(vis.fig, vis.update_plot, init_func=vis.plot_init)\n\
    \    plt.show(block=True) \n\n\n  [1]: https://matplotlib.org/api/_as_gen/matplotlib.animation.FuncAnimation.html"
