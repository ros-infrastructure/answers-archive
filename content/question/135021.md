  body_markdown: "The problem is that the .desktop doesn\u2019t run the .bashrc sources,\
    \ so your application doesn't know what ROS is along with all of its function\
    \ (rosrun, roslaunch, etc.)\n\nOne way getting around it is adding to the exec\
    \ command the source of ROS.\n\n    [Desktop Entry]\n    Version=1.0\n    Type=Application\n\
    \    Terminal=true\n    TerminalOptions=bash\n    Exec=bash -c \"source /opt/ros/indigo/setup.bash;source\
    \ ~/YOUR/CATKIN/WORKSPACE/devel/setup.bash;/path/to/script.sh\"\n    Icon=/if/you/want/one/icon.png\n\
    \    Name=rosapp"
