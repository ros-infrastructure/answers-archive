    rxplot can only plot numeric values. The "/kirim_ke_servo/position" argument you are using is an array of numeric values, hence rxplot complains. Off the top of my head,

        rxplot /kirim_ke_servo/position[0]

    should work. This way, the argument points to the first numeric_value in the array. You can of course also plot multiple values simultaneously as described on the [rxplot wiki page](http://www.ros.org/wiki/rxplot). There's also [rqt_plot](http://ros.org/wiki/rqt_plot), last time I checked it didn't work with array values like yours though (might have changed now).
