  body_markdown: "Hello.\nAs you noticed, first you need to install it from its repository.\n\
    \n    sudo apt-get install ros-%YOUR_ROS_DISTRO%-navigation\n\nAnyway it is already\
    \ installed by default.\nThen you should install the tutorials for that package:\n\
    \n    sudo apt-get install ros-%YOUR_ROS_DISTRO%-navigation-tutorials \n\nthen\
    \ go to that directory, and execute a node:\n\n    roscd navigation_tutorials\n\
    \    rosrun robot_setup_tf_tutorial tf_broadcaster\n\nIn another terminal roscd\
    \ again to that package and:\n\n    rosrun robot_setup_tf_tutorial tf_listener\n\
    \n---\nIf you want to make that package by yourself, you should go to your workspace\
    \ directory, and create a package, then create the two .cpp files, modify the\
    \ CMakeLists.txt and rosmake.\n\nHope this helps.\n\nPlease consult these links\
    \ for further information:\n[TF Setup](http://www.ros.org/wiki/navigation/Tutorials/RobotSetup/TF)\n\
    [Navigation Package](http://www.ros.org/wiki/navigation)"
