    (note: this answer is for Catkin. For rosbuild, I don't know)

    Afaik, there are three parts to this (I'll use `gencpp` as an example):

     1. a CMake 'extras' file that provides two macros that know how to take in a list of msg or srv defs and pass them on to your generator ([gencpp/cmake/gencpp-extras.cmake.em](https://github.com/ros/gencpp/blob/e5acaf690d6276d427f6b0ecaab67b52f55bbe8a/cmake/gencpp-extras.cmake.em))
     1. exporting from your manifest the language that you'll be generating code for ([gencpp/package.xml](https://github.com/ros/gencpp/blob/b73943de42d78a734dc3228ada0d9e9b29b1320f/package.xml#L23))
     1. a few bits in your `CMakeLists.txt` that add a required file ([gencpp/CMakeLists.txt](https://github.com/ros/gencpp/blob/1b8325e3341166702653d80fb389bc605e143ad3/CMakeLists.txt#L12-L14))

    And make sure to depend on the correct package(s) as well (`genmsg` among others).

I'm currently developing a ROS Client Library for the Rust programming language. The development has been done sporadically in my free time for the last several months. The source code being here:
[https://github.com/adnanademovic/rosrust](https://github.com/adnanademovic/rosrust)

I pretty much followed the Wiki page for [implementing client libraries](http://wiki.ros.org/Implementing%20Client%20Libraries) and the "At a minimum, a client library MUST:" part is feature complete (though not error paths are done yet - I've focused on making the code very concurrent, and in some places I just tell a thread to crash without telling what happened).

Anyways, to be usable, I need to make a .msg file compiler. I'm aware of the existence of gendeps for md5 and message definition. The thing that confuses me is what depending on "roslang" does and how to integrate with rosbuild or catkin to generate .msg files for all dependencies too. So could anyone please shed some light on what the right thing to do here is?

Just to stress this - I already have the rosmsg compiler that takes a *.msg and spits out a .rs file. What I want to know is what the general ROS pipeline is - how to tell ROS, when I say catkin_make, to take a hierarchy of .msg files and put them through my compiler?
