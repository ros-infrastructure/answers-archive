    It seems that you're having trouble with your ROS networking, and the associated Linux environment variables that allow bi-directional ROS communication. The `./baxter.sh` script is a convenience script to help you set these viarables. Please see [this tutorial from Rethink on how to set up the `baxter.sh` script](http://sdk.rethinkrobotics.com/wiki/Workstation_Setup#Step_6:_Configure_Baxter_Communication.2FROS_Workspace)

    If you'd like a deeper dive into Baxter ROS networking, Rethink has a [Networking Page that describes the ROS Naming conventions](http://sdk.rethinkrobotics.com/wiki/Networking#Baxter_ROS_Naming_Conventions) according to your networked environment. Finally, it might be useful to check out the [ROS Environment variables page](http://wiki.ros.org/ROS/EnvironmentVariables), looking at `ROS_MASTER_URI` and `ROS_IP / ROS_HOSTNAME` in particular.
