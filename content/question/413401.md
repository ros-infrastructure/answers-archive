  body_markdown: "If you only need to specify the order, then launch will already\
    \ respect the order you specify nodes in. But if you need to have node1 wait for\
    \ until nodes 2, 3, and 4 are present and running then read on.\n\nI'm not sure\
    \ exactly what criteria you have for \"when a node starts\", so I'm just going\
    \ to use the built-in events. If you require more specific start-up conditions,\
    \ you may have to write your own event, event handler, and event emitter.\n\n\
    Here's my python launch script to have node1 started only after nodes 2, 3, and\
    \ 4 have been started. In this example \"started\" means that launch has processed\
    \ that action, and the `ProcessStarted` event has been emitted.\n\n    from rclpy.node\
    \ import Node\n    from launch import LaunchContext, LaunchDescription, LaunchService\n\
    \    from launch.actions import RegisterEventHandler\n    from launch.events.process\
    \ import ProcessStarted\n    from launch.event_handlers.on_process_start import\
    \ OnProcessStart\n    from launch_ros.actions import Node\n    \n    \n    def\
    \ generate_launch_description():\n        node1 = Node(package='demo_nodes_cpp',\n\
    \                     executable='talker',\n                     name='node1',\n\
    \                     exec_name='node1')\n        node2 = Node(package='demo_nodes_cpp',\n\
    \                     executable='listener',\n                     name='node2',\n\
    \                     exec_name='node2')\n        node3 = Node(package='demo_nodes_cpp',\n\
    \                     executable='listener',\n                     name='node3',\n\
    \                     exec_name='node3')\n        node4 = Node(package='demo_nodes_cpp',\n\
    \                     executable='listener',\n                     name='node4',\n\
    \                     exec_name='node4')\n    \n        already_started_nodes\
    \ = set()\n    \n        def start_next_node(event: ProcessStarted, context: LaunchContext):\n\
    \            print(f'node {event.process_name} started.')\n            already_started_nodes.update([event.process_name])\n\
    \            if len(already_started_nodes) == 3:\n                print(f'all\
    \ required nodes are up, time to start node1')\n                return node1\n\
    \    \n        return LaunchDescription([\n            RegisterEventHandler(event_handler=OnProcessStart(target_action=node2,\n\
    \                                                              on_start=start_next_node)),\n\
    \            RegisterEventHandler(event_handler=OnProcessStart(target_action=node3,\n\
    \                                                              on_start=start_next_node)),\n\
    \            RegisterEventHandler(event_handler=OnProcessStart(target_action=node4,\n\
    \                                                              on_start=start_next_node)),\n\
    \            node2,\n            node3,\n            node4,\n        ])\n    \n\
    \    \n    if __name__ == '__main__':\n        ls = LaunchService()\n        ls.include_launch_description(generate_launch_description())\n\
    \        ls.run()\n\nThe three `RegisterEventHandler` actions will call `start_next_node`\
    \ after the specific node has been started. Once three nodes have already been\
    \ started, then we'll start node1. We could do something to look at which node\
    \ actually was started, So if we needed node3 to wait until node2 to start, and\
    \ node 4 to wait for node3 to start, we could do that kind of logic there.\n\n\
