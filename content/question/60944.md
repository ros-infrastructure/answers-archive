  body_markdown: " \n\n**Here's a procedure I always use...make sure you calibrate\
    \ the RGB and IR cameras separately**\n\nKinect Calibration: RGB and IR Cameras\
    \ \n\n \n\nPackages Needed: \n\ngit clone https://github.com/ros-perception/image_pipeline.git\
    \ \n\ngit clone https://github.com/ros-perception/image_common.git \n\n \n\nInstall\
    \ dependences: rosdep install ______ \n\nMake packages: rosmake ______ \n\n \n\
    \nProcedure: \n\nFor RGB Camera \n\n1.) roscore \n\n\n \n\n2.) rosrun openni_camera\
    \ openni_node \n\n\n \n\n3.) rosrun camera_calibration cameracalibrator.py --size\
    \ 8x6 --square 0.059 image:=/rgb/image_raw \nrgb:=/rgb \n\n\nNote: Size is number\
    \ of rows of boxes-1 by number of columns of boxes-1. \n\nSquare is size of boxes\
    \ in meters. \n\n \n\n4.) Make sure Kinect is stationary. Move the checkerboard\
    \ around slowly, changing the 6 degrees of \nfreedom: x, y, z, roll, pitch, yaw.\
    \ \n\n\n \n\n5.) Keep changing the position of the checkerboard until the X, Y,\
    \ Size, and Skew green bars on the right side \nof the screen are at a maximum.\
    \ \n\n\n \n\n6.) When the \u201CCalibrate\u201D button is lit, click it. \n\n\n\
    \ \n\n7.) When the \u201CSave\u201D button is lit, click it. \n\n\n \n\n8.) This\
    \ saves a .tar file in your system\u2019s \u2018tmp\u2019 folder. Find it and\
    \ extract the files somewhere handy. Inside \nthe extracted folder will be pictures\
    \ and a ost.txt file. Change the file extension to ost.ini and copy it to \nyour\
    \ sandbox/workspace. \n\n\n \n\n9.) rosrun camera_calibration_parsers convert\
    \ ost.ini cal.yml \n\n\n10.) This saves the cal.yml in your sandbox/workspace.\
    \ Change the extension to .yaml. Also, change the file \nname corresponding to\
    \ what openni_node refrenced in the terminal when it was trying to find the calibration\
    \ \nfile. It\u2019s usually something like \u201CRGB_A00366812242050A\u201D. Once\
    \ the file name is changed, open the file in a \ntext editor and change the default\
    \ camera_name to \u201CRGB_A00366812242050A\u201D, or whatever name \nopenni_node\
    \ refrenced. \n\n11.) Now, copy this .yaml file to home/.ros/camera_info folder\
    \ \n\nNote: The .ros folder might be a hidden folder \n\n \n\n\f\nFor IR Camera\
    \ \n\n1.) Procedure is the same except: \n\na.) Cover the IR projector with tape/paper\
    \ \n\nb.) Make sure you are in a low light environment with incandescent or halogen\
    \ lighting. \nFluorescent lighting interferes with the IR calibration. Also, make\
    \ sure there is minimal \nmovement\u2026the IR camera is very finicky. \n\nc.)\
    \ rosrun camera_calibration cameracalibrator.py --size 8x6 --square 0.059 \nimage:=/ir/image_raw\
    \ ir:=/ir \n\n \n\n \n\n \n\n\f\n"
