    I presume you want to simultaneously run nodes on both the robot and your workstation. In that case, you need to install Fuerte on the workstation as well.

    Never combine nodes compiled for different ROS distributions in the same roscore execution graph. Sometimes it may work, but it is not supported and not a good idea.
