 Hello everybody,

I'm quite new to ROS system and I'm trying to build an autonomous robot using a Jetson Nano (Ubuntu 18.04) with an YDLIDAR X4 Lidar.

I've managed to build the ROS environment and managed to configure hector_slam in order to create "live" map in Rviz following this tutorial : [create.arduino.cc](https://create.arduino.cc/projecthub/361126/autonomous-uv-robot-with-slam-215203).

Now I want to save the map created after scanning my environment with the combo lidar/hector_slam using the following lines  to launch the process :

 1. roslaunch ydlidar lidar.launch
 2. roslaunch hector_slam_launch tutorial.launch

However when I enter the code for saving a .tif image (rostopic pub syscommand std_msgs/String "savegeotiff") the terminal used to start the mapping process tells me the following error :

> GeoTiff created in 0,252163 seconds
