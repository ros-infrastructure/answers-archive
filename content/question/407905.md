  body_markdown: "As part of the standard set of linters that you get when you use\
    \ `ament_lint_auto` or call the linters manually from the CLI is one that checks\
    \ for copyrights in all of your source code files. This will check C / C++ / CMake\
    \ / Python files for a header containing a software license as good general practice\
    \ in software development (for some licenses, like BSD and Apache 2.0 that require\
    \ it in every source file). There's nothing special about launch files, they're\
    \ still python files that have copyrights attached to them like any other type\
    \ of software - so you're probably just seeing that error because you have copyrights\
    \ everywhere else but didn't include them in your launch files. \n\n"
