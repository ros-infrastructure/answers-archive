  body_markdown: "Hello,\n\nI assume that you want to use the map generated by RTAB-Map\
    \ for simulation experiments using Stage. It is possible to create a `.world`\
    \ for Stage referencing an image (e.g. black pixels are walls). Here is an example\
    \ to generate such images from an already built database. Using [IROS14-kinect-challenge.db](https://drive.google.com/open?id=0B46akLGdg-uaeFFWUUZWX2hsaVE&authuser=0)\
    \ from [this RTAB-Map's tutorial](https://github.com/introlab/rtabmap/wiki/IROS-2014-Kinect-Challenge#updated-results):\n\
    \n    $ roscore\n    $ rosrun rtabmap_ros rtabmap _database_path:=IROS14-kinect-challenge.db\n\
    \    $ rosrun map_server map_saver map:=proj_map\n    $ rosservice call /publish_map\
    \ 1 1 0\n\nThis takes some time for rtabmap node to build the projection map,\
    \ but you should see this in the terminal of the map_saver:\n\n    [ INFO] [1441403556.668234515]:\
    \ Waiting for the map\n    [ INFO] [1441403565.477020944]: Received a 508 X 420\
    \ map @ 0.050 m/pix\n    [ INFO] [1441403565.477108000]: Writing map occupancy\
    \ data to map.pgm\n    [ INFO] [1441403565.482476945]: Writing map occupancy data\
    \ to map.yaml\n    [ INFO] [1441403565.482683795]: Done\n\nYou may need to convert\
    \ the PGM to a BMP for stage and change all the grey pixels to white.\nThe map.pgm:\
    \ \n\n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/1441403845607041.png)\n\
    \nmap.yaml:\n\n    image: map.pgm\n    resolution: 0.050000\n    origin: [-9.033475,\
    \ -11.844757, 0.000000]\n    negate: 0\n    occupied_thresh: 0.65\n    free_thresh:\
    \ 0.196\n\ncheers"
