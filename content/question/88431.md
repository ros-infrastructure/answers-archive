  body_markdown: "This function should do the trick and accounts for many cases, such\
    \ as endianness and the raw and rectified depth image.\n\nOf course, if you know\
    \ the endianness of your system (and the image endianness doesn't change) as well\
    \ as which depth image you are subscribed to (raw or rect) then this can be simplified\
    \ a lot.\n\nNote: the function returns the depth in millimeters.\n\n    typedef\
    \ union U_FloatParse {\n        float float_data;\n        unsigned char byte_data[4];\n\
    \    } U_FloatConvert;\n\n    int ReadDepthData(unsigned int height_pos, unsigned\
    \ int width_pos, sensor_msgs::ImageConstPtr depth_image)\n    {\n        // If\
    \ position is invalid\n        if ((height_pos >= depth_image->height) || (width_pos\
    \ >= depth_image->width))\n            return -1;\n        int index = (height_pos*depth_image->step)\
    \ + (width_pos*(depth_image->step/depth_image->width));\n        // If data is\
    \ 4 byte floats (rectified depth image)\n        if ((depth_image->step/depth_image->width)\
    \ == 4) {\n            U_FloatConvert depth_data;\n            int i, endian_check\
    \ = 1;\n            // If big endian\n            if ((depth_image->is_bigendian\
    \ && (*(char*)&endian_check != 1)) ||  // Both big endian\n               ((!depth_image->is_bigendian)\
    \ && (*(char*)&endian_check == 1))) { // Both lil endian\n                for\
    \ (i = 0; i < 4; i++)\n                    depth_data.byte_data[i] = depth_image->data[index\
    \ + i];\n                // Make sure data is valid (check if NaN)\n         \
    \       if (depth_data.float_data == depth_data.float_data)\n                \
    \    return int(depth_data.float_data*1000);\n                return -1;  // If\
    \ depth data invalid\n            }\n            // else, one little endian, one\
    \ big endian\n            for (i = 0; i < 4; i++) \n                depth_data.byte_data[i]\
    \ = depth_image->data[3 + index - i];\n            // Make sure data is valid\
    \ (check if NaN)\n            if (depth_data.float_data == depth_data.float_data)\n\
    \                return int(depth_data.float_data*1000);\n            return -1;\
    \  // If depth data invalid\n        }\n        // Otherwise, data is 2 byte integers\
    \ (raw depth image)\n       int temp_val;\n       // If big endian\n       if\
    \ (depth_image->is_bigendian)\n           temp_val = (depth_image->data[index]\
    \ << 8) + depth_image->data[index + 1];\n       // If little endian\n       else\n\
    \           temp_val = depth_image->data[index] + (depth_image->data[index + 1]\
    \ << 8);\n       // Make sure data is valid (check if NaN)\n       if (temp_val\
    \ == temp_val)\n           return temp_val;\n       return -1;  // If depth data\
    \ invalid\n    }\n\nHopefully this helps."
