    In the mean time this function has been added to `rosbag2` (see [PR #388](https://github.com/ros2/rosbag2/pull/388)). However, as far as I can tell the feature has not been back-ported to the `eloquent` branch so far. So if you need this you might need to build `rosbag2` from source (including the PR mentioned above).

    With this changes, that are already in the latest ROS `foxy` release, you can now remap topics when playing bagfiles as:

        ros2 bag play my_bagfile --remap old_topic:=new_topic
