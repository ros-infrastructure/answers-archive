    \ \n\nBasically, the API appears to have changed in the tf::Quaternion constructor\
    \ with RPY as parameters to YPR as parameters. So the broadcaster is broadcasting\
    \ the wrong rotation in its transform.\n\nYou shouldn't use that constructor anymore,\
    \ though, as it's been deprecated.  Use something else from the [API](http://ros.org/doc/fuerte/api/tf/html/c++/classtf_1_1Quaternion.html)\
    \ to set your rotation, and make sure the order is right, and it should work fine."
