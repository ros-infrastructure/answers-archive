    There's a similar API on the parameter clients [method 'on_parameter_event'](https://github.com/ros2/rclcpp/blob/1a604b0c280475ceebf8e2571383bbe436963b61/rclcpp/include/rclcpp/parameter_client.hpp) that I'd recommend looking at for subscribing to parameter events.

    You can see an example of using it in conjunction with the [`ParameterEventsFilter` helper class](https://github.com/ros2/rclcpp/blob/master/rclcpp/include/rclcpp/parameter_events_filter.hpp) in the [`TimeSource` implementation](https://github.com/ros2/rclcpp/blob/6129a12df5ec21b7ccbf6879036281b1374db0fb/rclcpp/src/rclcpp/time_source.cpp)

    The `register_param_change_callback` should also work directly on the node object.
