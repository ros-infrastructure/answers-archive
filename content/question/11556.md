    From the documentation on the [sensor_msgs::PointCloud2](http://www.ros.org/doc/api/sensor_msgs/html/msg/PointCloud2.html) type, the 'data' member contains the actual data of the point cloud message, and the type is determined dynamically by reading the 'fields' member.

    I suggest you determine what sort of data you're hoping to extract from your input point clouds, and use [pcl::fromROSMsg()](http://docs.pointclouds.org/1.2.0/namespacepcl.html#abc8688665cb9e229c199344d767684f6) to convert your ros message into a [pcl point cloud](http://docs.pointclouds.org/1.2.0/classpcl_1_1_point_cloud.html), at which point you can use the supplied iterators to iterate over your point cloud.

    \ to iterate the fields (like \"x\" for the x-coordinate, or \"r\" for the red\
    \ color). And for creating/basic manipulation with PointCloud2 clouds, there is\
    \ the [sensor_msgs::PointCloud2Modifier](http://docs.ros.org/jade/api/sensor_msgs/html/classsensor__msgs_1_1PointCloud2Modifier.html#details)\
    \ class, which allows you to conveniently set the fields structure, resize or\
    \ clear a point cloud.\n\nExample usage of the C++ interface (taken and simplified\
    \ from ros-perception/image_pipeline):\n\n    #include <sensor_msgs/PointCloud2.h>\n\
    \    #include <sensor_msgs/point_cloud2_iterator.h>\n    \n    using namespace\
    \ sensor_msgs;\n    \n    PointCloud2Ptr points_msg = boost::make_shared<PointCloud2>();\n\
    \    points_msg->header = ...; // TODO fill in header\n    points_msg->height\
    \ = mat.rows; // if this is a \"full 3D\" pointcloud, height is 1; if this is\
    \ Kinect-like pointcloud, height is the vertical resolution\n    points_msg->width\
    \  = mat.cols;\n    points_msg->is_bigendian = false;\n    points_msg->is_dense\
    \ = false; // there may be invalid points\n    \n    sensor_msgs::PointCloud2Modifier\
    \ pcd_modifier(*points_msg);\n    // this call also resizes the data structure\
    \ according to the given width, height and fields\n    pcd_modifier.setPointCloud2FieldsByString(2,\
    \ \"xyz\", \"rgb\");\n    \n    sensor_msgs::PointCloud2Iterator<float> iter_x(*points_msg,\
    \ \"x\");\n    sensor_msgs::PointCloud2Iterator<float> iter_y(*points_msg, \"\

    \    sensor_msgs::PointCloud2Iterator<uint8_t> iter_r(*points_msg, \"r\");\n \
    \   sensor_msgs::PointCloud2Iterator<uint8_t> iter_g(*points_msg, \"g\");\n  \
    \  sensor_msgs::PointCloud2Iterator<uint8_t> iter_b(*points_msg, \"b\");\n   \
    \ \n    for (...) // TODO get/generate point coordinates and colors\n    {\n \
