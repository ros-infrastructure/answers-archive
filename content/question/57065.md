    \ for bag_to_pcd you have to provide the message topic, not the message type,\
    \ e.g. put there \n\n    rosrun pcl_ros bag_to_pcd PATH/TO/BAGFILE.bag /my_sensor/my_points2_topic\
    \ OUTPUT_DIR\n\nFurthermore, you'll need to provide a valid tf from the sensor\
    \ frame id to the frame id /base_link as it is hardcoded in the bag_to_pcd. You\
    \ can do that with a [static transform publisher](http://www.ros.org/wiki/tf#static_transform_publisher).\n\
    \nif you don't know the topic, do a \n\n    rosbag info PATH/TO/BAGFILE.bag\n\n\
    and check which topic is a sensor_msgs/PointCloud2"
