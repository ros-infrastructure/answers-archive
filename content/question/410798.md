  body_markdown: "RVIz in and of itself doesn't really know how to display the angle\
    \ of an arbitrary joint. Typically you have a robot_state_publisher (https://github.com/ros/robot_state_publisher/tree/humble)\
    \ node that reads in the urdf robot description and subscribes to joint states.\
    \ Then it publishes the tfs for each of the robot links base on their joint_states.\n\
    \nSo instead of \n\n    [joint_publisher] -> (/joint_states) -> [rviz]\n\nwe would\
    \ have something like\n\n    [joint_publisher] -> (/joint_states) -> [robot_state_publisher]\
    \ -> (/tf, /tf_static, /robot_description)) -> [rviz]"
