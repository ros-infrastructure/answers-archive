    \ not work in the following **BOLDED** images does not work get from the command:\n\
    % ls -l .aderc*\n\n **.aderc-amd64-dashing**\n\n.aderc-amd64-dashing-lgsvl\n\n\
    **.aderc-amd64-foxy**\n\n.aderc-amd64-foxy-lgsvl\n\nThere is some line missing\
    \ on .aderc configuration file or Dockerfile when these images are built through\
    \ the command:\n\n    $ade --rc .aderc-amd64-dashing start      or     $ade --rc\
    \ .aderc-amd64-foxy start\n\nJust the images built with lgsvl simulator have the\
    \ correct code and configuration files written for ubuntu 20.04 that allows rviz2\
    \ works. Then it is required to build ros-distro with the lgsvl internal simulator:\n\
    \n    ade --rc .aderc-amd64-dashing-lgsvl start\n    or \n    ade --rc .aderc-amd64-foxy-lgsvl\
    \ start\n\nIn my case I am using foxy as it is the most recent ros distro available\
    \ for ubuntu 20.04.\n\nThere is just one way to make rviz2 work without trigger\
    \ the lgsvl simulator image. It is setting the --privileged flag to build the\
    \ images:\n\n    ade --rc .aderc-amd64-dashing start --privileged\n    ade --rc\
    \ .aderc-amd64-foxy start --privileged \n    or just\n    ade start --privileged\
    \ \n\nthat will start the standard ros-distro image without the lgsvl simulator\
    \ \n\nHowever it is not recommended use --privileged flags to run docker for security\
    \ reasons...\nThis was the way I have worked around to launch rviz2 successfully.\n\
