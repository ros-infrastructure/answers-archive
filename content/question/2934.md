    As mentioned in the [DRCSim User Guide](http://gazebosim.org/wiki/DRC/UserGuide#AtlasSimInterface_Behaviors), **Stand** mode is the hub to all the behavioral modes, I've added a diagram to clarify this point.  So to recover from a fall, you must first go back to **User** mode, then to **Stand** mode.  Below is an example path to recovery:

    1. Put the robot under PID control, (i.e. set [`k_effort[0:28]`](https://bitbucket.org/osrf/drcsim/src/367704bdd08af4f8471da3d647f0119afeef6f32/ros/atlas_msgs/msg/AtlasSimInterfaceCommand.msg?at=default#cl-38) to 255 for all joints), then
    1. Get the robot back on to its feet with your own controller.  Drive Atlas into PID controlled `Stand` pose (for example, see [`VRCPlugin::SetPIDStand()`](https://bitbucket.org/osrf/drcsim/src/367704bdd08af4f8471da3d647f0119afeef6f32/ros/atlas_msgs/VRCPlugin.cpp?at=default#cl-1250) for approximate target joint positions taken from a snapshot of joint states while standing).
    1. Once the robot stabilizes, you can then switch to [BDI `STAND` mode](https://bitbucket.org/osrf/drcsim/src/367704bdd08af4f8471da3d647f0119afeef6f32/ros/atlas_msgs/msg/AtlasSimInterfaceCommand.msg?at=default#cl-10) mode and set all [`k_effort[0:28]`](https://bitbucket.org/osrf/drcsim/src/367704bdd08af4f8471da3d647f0119afeef6f32/ros/atlas_msgs/msg/AtlasSimInterfaceCommand.msg?at=default#cl-38) to 0 simultaneously (for example, see [`SetBDIStand()`](https://bitbucket.org/osrf/drcsim/src/367704bdd08af4f8471da3d647f0119afeef6f32/ros/atlas_msgs/VRCPlugin.cpp?at=default#cl-1356) for reference).
