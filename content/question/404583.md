  body_markdown: "Looking at your code, it seems you want to subscribe to RGB and\
    \ depth images. Please use the [message_filters](http://wiki.ros.org/message_filters).\
    \ A sample code taken from the wiki page is shown below:\n\n\n    import message_filters\n\
    \    from sensor_msgs.msg import Image\n    \n    def callback(rgb_image, depth_image):\n\
    \      # Solve all of perception here...\n    \n    image_sub = message_filters.Subscriber('rgb_topic_here',\
    \ Image)\n    depth_sub = message_filters.Subscriber('depth_topic_here', Image)\n\
    \    \n    ts = message_filters.TimeSynchronizer([image_sub, depth_sub], 10)\n\
    \    ts.registerCallback(callback)\n    rospy.spin()\n\n\n\nI recommend checking\
    \ the [message_filters](http://wiki.ros.org/message_filters) to apply additional\
    \ filters such as Time Synchronizer etc."
