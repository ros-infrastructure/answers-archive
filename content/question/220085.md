    \ turned out that the problem was being caused by a bug in the 1.3.7 gmapping\
    \ release. thanks to @stevenwaslander answer, the fix for the problem that i explained\
    \ in my question above, is as follows:\n\n    $ wget http://packages.ros.org/ros/ubuntu/pool/main/r/ros-indigo-gmapping/ros-indigo-gmapping_1.3.8.orig.tar.gz\n\
    \    $ cd ~/catkin_ws/src\n    $ tar xvf ../../ros-indigo-gmapping_1.3.8.orig.tar.gz\
    \   \n    $ mv ros-indigo-gmapping-1.3.8/ gmapping\n    $ catkin_make\n    $ sudo\
    \ cp devel/lib/gmapping/slam_gmapping* /opt/ros/indigo/lib/gmapping/"
