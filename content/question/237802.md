  body_markdown: "Use cv_bridge and make sure to set the encoding to 16-bit\n\nFor\
    \ example \n\n    cv_bridge::CvImage img16;\n    // copy raw image into img16.image\n\
    \    img16.encoding = sensor_msgs::image_encodings::MONO16;\n    // img16.header\n\
    \    image_pub.publish(img16);\n\nJust remember to convert it into a 8-bit before\
    \ displaying it.\n\n    image_callback(const snesor_msgs::ImageConstPtr& img)\n\
    \    {\n        cv_bridge::CvImagePtr cv_ptr;\n        cv_ptr = cv_bridge::toCvCopy(img,\
    \ sensor_msgs::image_encodings::MONO16);  \n        cv::Mat img8(HEIGHT, WIDTH,\
    \ CV_8UC1);\n        cv_ptr->image.convertTo(img8, CV_8UC1);\n        cv::imshow(\"\
    8-bit Mono\", img8);  \n        cv::waitKey(1);\n    }\n\n\n"
