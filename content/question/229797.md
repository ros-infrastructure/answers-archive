    No, to my knowledge ROS doesn't make those methods available.

    You need to better define what *between two frames* means, though. Assuming you can treat Frame1 as the origin (that is, position <code>(x,y,z)=(0,0,0)</code> and orientation <code>(x,y,z,w)=(0,0,0,1)</code>), calculating the azimuth/elevation to another frame can be accomplished using only Frame2's relative-to-Frame1 <code>(x2,y2,z2)</code> location:
    <pre><code>magnitude = sqrt((x2*x2) + (y2*y2) + (z2*z2));
    azimuth   = atan2(y2, x2);
    elevation = asin(z2 / magnitude);
    </code></pre>
    Note that angles should be normalized to <code>-M_PI <= val < M_PI</code>.

    If you're going to be working with spherical coordinates, two sites I've found invaluable are [Aviation Formulary](http://williams.best.vwh.net/avform.htm) and [Calculate distance, bearing and more between Latitude/Longitude points](http://www.movable-type.co.uk/scripts/latlong.html).
