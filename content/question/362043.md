  body_markdown: "The error is showing that in SerialClient.py, line 41 imports the\
    \ queue module, but apparently there can be a version mismatch between python\
    \ 2/3 calling the module \"Queue\" vs \"queue\".\n\nIn your catkin workspace,\
    \ src/rosserial/rosserial_python/src/rosserial_python/SerialClient.py, try changing\
    \ the line \"import queue\" to the following:\n\n    try: \n        import queue\n\
    \    except ImportError:\n        import Queue as queue"
