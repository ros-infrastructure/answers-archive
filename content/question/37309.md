  body_markdown: "Hi BeuBeu,\n\nThe remote lab project has a number of cool widgets\
    \ to do with robot visualization and control.  However, some of these are written\
    \ in a manner that makes them difficult to reuse.  There is a current effort (within\
    \ the last few weeks) at Bosch and Willow to begin to modularise many of the web\
    \ components that we have til now written.  We are not writing new widgets per\
    \ se, but they are being split up so it should make it a lot easier for people\
    \ to, for example, throw on a PR2 visualization onto their web page.\n\nWith regards\
    \ to the robots that they work for - that's on a per-widget basis.  Some of the\
    \ widgets, such as the simple joystick widget, merely publish to a particular\
    \ topic.  Other widgets are clearly PR2 specific, such as the PR2 visualization.\
    \  This will only work if it's receiving PR2 info on the /tf topic.\n\nThe best\
    \ places to keep up to date are the following:\n\n - rosbridge.org: We are working\
    \ on a\n   new, industrial-strength rosbridge,\n   that will be released with\n\
    \   first-class support from Willow. \n   rosbridge.org is a good place to keep\n\
    \   up to date for news regarding the\n   release schedule and protocol\n   enhancements\n\
    \   \n - https://github.com/rosjs/rosjs: This\n   is where the heavyweight ros.js\
    \ and\n   javascript widgets will be mostly\n   hosted.\n   \n - rosbridge conf.\
    \ call: There is a\n   weekly conference call for interested\n   parties.  If\
    \ you wish to contribute\n   to the effort, then you're very\n   welcome to join!\n\
    \   \n - ROSDojo: Many of the Brown ROS web\n   interfaces can be found in the\n\
    \   experimental/ROSDojo project in the\n   brown-ros-pkg\n\nThere will be a few\
    \ announcements towards the end of the summer relating to rosbridge, rosjs, and\
    \ javascript widgets.\n\nCheers,\n\nJon"
