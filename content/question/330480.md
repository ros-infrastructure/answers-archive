    This question appears to be very similar to [this previous Q/A (278458)](https://answers.ros.org/question/278458/export-topic-from-bag-at-different-rate/). Unfortunately, it appears there is no one-liner solution to this, but using the rosbag API lets you do anything.

    A straightforward option to use when your application involves playing back the bag data would be running a [topic_tools/throttle](http://wiki.ros.org/topic_tools/throttle) node on the topic(s) and feed those to subscribers instead of the original one(s).
