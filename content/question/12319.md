    nao_driver depends on the [common_msgs](http://www.ros.org/wiki/common_msgs) stack, which contains the missing files mentioned in the output. nao_driver also depends on [humanoid_msgs](http://www.ros.org/wiki/humanoid_msgs) and [nao_msgs](http://www.ros.org/wiki/nao_msgs), so make sure that you install these dependencies first.
