    \ image topic and save the received images to files using rosjava (no Android\
    \ required):\n\n    @Override\n    public void onStart(ConnectedNode node) {\n\
    \      final Log log = node.getLog();\n      latch = new CountDownLatch(0);\n\
    \      Subscriber<CompressedImage> subscriber = node.newSubscriber(topic, \"sensor_msgs/CompressedImage\"\
    );\n      log.info(\"Subscribed to \" + topic);\n      \n      subscriber.addMessageListener(new\
    \ MessageListener<CompressedImage>() {\n          @Override\n          public\
    \ void onNewMessage(CompressedImage message) {\n              log.info(\"New image\
    \ is here! Format: \" + message.getFormat());\n              \n              if\
    \ (!message.getFormat().contains(\"jpeg\")) {\n                  log.warn(\"Only\
    \ jpeg images are supported\");\n                  return;\n              }\n\n\
    \              // The latch allows the node to finish saving the image before\
    \ a new one arrives.\n              if (latch.getCount() == 0) {\n           \
    \       latch = new CountDownLatch(1);\n                  ChannelBuffer buffer\
    \ = message.getData();\n                  log.info(\"Array length: \" + buffer.array().length);\n\
    \                  try {\n                      // Look for the start of the image\
    \ inside the buffer\n                      // In the tests with TangoRosStreamer,\
    \ the offset is always 0x3F,\n                      // perhaps it's not necessary\
    \ to search for the index every time.\n                      int imageStart =\
    \ Bytes.indexOf(buffer.array(), JPG_START);\n                      if (imageStart\
    \ < 0) {\n                          throw new Exception(\"Invalid JPG format:\
    \ start not found\");\n                      }\n                      \n     \
    \                 File outputFile = new File(\"image_\" + Integer.toString(imgNumber)\
    \ + \".jpg\");\n                      OutputStream outStream = new FileOutputStream(outputFile);\n\
    \                      outStream.write(buffer.array(), imageStart, buffer.array().length\
    \ - imageStart);\n                      log.info(\"Wrote file\");\n          \
    \            outStream.close();\n                      imgNumber++;\n        \

    Listener exception: \" + e.getClass() + \" msg: \" + e.getMessage());\n      \

    \         }\n              }\n          }\n      });\n    }\n\nThe byte array\

Like it says on the tin, we need to process a compressed_image transport from Java code. We aren't developing on Android and so can't leverage any of the Android-specific stuff packaged in to rosjava.

Specifically, we need to go from a CompressedImage message to a native AWT BufferedImage.  But to do this, we need a lot of information required to decompress the image that we can't seem to get a hold of (things like width and height, which I suppose we could get from the CameraInfo but we're trying to keep the number of subscription handlers to a minimum because they seem to be pretty heavyweight in all of our benchmarks).
