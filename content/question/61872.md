  body_markdown: "I had the same problem so I used standalone pcl library. I compiled\
    \ PCL from source and added the following lines to CMakeLists.txt in the package\
    \ (remember to create a package that does not depend on pcl_ros):\n\n    find_package(PCL\
    \ 1.6 REQUIRED)\n    \n    include_directories(${PCL_INCLUDE_DIRS}) \n    link_directories(${PCL_LIBRARY_DIRS})\
    \ \n    add_definitions(${PCL_DEFINITIONS})\n\n    rosbuild_add_executable(example\
    \ src/example.cpp)\n    target_link_libraries(example ${PCL_LIBRARIES})\n\nI successfully\
    \ executed some of the examples.\nIf your purpose is to execute pcl tutorial examples,\
    \ then you do not need to create a ROS package. However, if your purpose is to\
    \ view the pcl data you can use the following procedure:\n\n    1. roslaunch openni_launch\
    \ openni.launch\n    2. convert sensor_msgs::PointCloud2 data to pcl::PointCloud<pcl::PointXYZ>\n\
    \    3. Then create a pcl::visualization::CloudViewer object to view the pcl::PointCloud\
    \ data.\n\nIn this case you will not need OpenNIGrabber."
