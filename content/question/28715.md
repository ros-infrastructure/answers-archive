ROS2 Humble and Gazebo Garden are installed in Linux 22.04 aarch64/arm64 (VM on MAC M1)

I edited my original Jan 18, 2023 as with further investigation, I discovered that ros_gz can be installed directly from posted binaries, once ¨gazebo sim Garden¨ was installed on my MAC M1 Ubuntu 22.04 arm64 Parallels Virtual Machine  from Binary Installation on Ubuntu, (https://gazebosim.org/docs/garden/install_ubuntu ). With the local repositories updated, the two installation commands for gz-garden and ros_gz are $ sudo apt install gz-garden and $ sudo apt install ros-humble-ros-gz. So the https://github.com/gazebosim/ros_gz/tree/humble instructions for this case of Binaries procedure can be significantly simplified and no compiling from source is necessary.
