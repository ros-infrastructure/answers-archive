    You either use gmapping or amcl. Both do particle-filtering based localization. While gmapping also builds a map, amcl requires an already built map on the [map server](http://ros.org/wiki/map_server). You cannot use amcl and gmapping at the same time.

    After you built a map using gmapping and saved it to a file, you need to stop gmapping, start the map server to provide your map and run amcl.
