    Well, I guess the correct action would be to make sure the mesh uses metres as the unit of distance, as that is what [REP 103](https://ros.org/reps/rep-0103.html#units) prescribes. This is likely what MoveIt also expects and the model of the robot you are using is also scaled to.

    There is a *Scale* slider there, but that would only get you to centimetre range.
