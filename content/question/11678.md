  body_markdown: "The way that I find the easiest is like suggested: creating your\
    \ own \"vector\" and \"repainting\" it.\n\nIn fact, a `Path` is simply a collection\
    \ of `Pose`s. Normally, only one path is displayed; therefore, if you send a new\
    \ one, whatever was displayed before gets erased. So, you can create one path\
    \ object locally, and keep adding new points to it.\n\nHere is a skeleton of an\
    \ algorithm that should do what you want:\n\n\n    nav_msgs::Path pathMsg;\n \
    \   \n    while (node.ok())\n    {\n        ros::spinOnce();\n    \n        geometry_msgs::PoseStamped\
    \ poseMsg;\n\n        // Fill the poseMsg with whatever pose you want (the point\
    \ on your path)\n    \n        pathMsg.poses.push_back(poseMsg);\n    \n     \
    \   pathPublisher.publish(pathMsg);\n    \n        // Waits a little before adding\
    \ another pose to the path\n        rate.sleep();\n    \n    } // end loop"
