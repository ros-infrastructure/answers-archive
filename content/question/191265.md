    A good place to start is the [API](http://docs.pointclouds.org/trunk/) documentation.

    For example, the [pcl::Poincloud](http://docs.pointclouds.org/trunk/classpcl_1_1_point_cloud.html) doc shows you that you can get any point by indexing into the cloud with the [] operator, like an array.

    The [PointXYZRGB](http://docs.pointclouds.org/trunk/structpcl_1_1_point_x_y_z_r_g_b.html) description isn't as clear, but it does tell you it's a struct (meaning all members are public), and you'll find you can access the values via point.x, .y, .z, etc.

    \ is no clear cut instruction anywhere. Anyhow, I wanted to convert 2D pixel coordinates\
    \ (u,v) to X,Y,Z from a point cloud that I got from kinect. I wrote a function\
    \ to do it, I pass in the point cloud message, u and v coordinates (for a feature\
    \ in 2D image) and pass a reference to a geometry_msgs point which will get the\
    \ X,Y,Z values. These X,Y,Z values are in the camera's frame, (X is seen as going\
    \ from left to right in the image plane, Y is top to bottom and Z pointing into\
    \ the world).\n\n\n    #include <ros/ros.h>\n    #include <geometry_msgs/Point.h>\n\
    \    #include <sensor_msgs/PointCloud2.h>\n        \n    /**\n        Function\
    \ to convert 2D pixel point to 3D point by extracting point\n        from PointCloud2\
    \ corresponding to input pixel coordinate. This function\n        can be used\
    \ to get the X,Y,Z coordinates of a feature using an \n        RGBD camera, e.g.,\
    \ Kinect.\n        */\n        void pixelTo3DPoint(const sensor_msgs::PointCloud2\
    \ pCloud, const int u, const int v, geometry_msgs::Point &p)\n        {\n    \
    \      // get width and height of 2D point cloud data\n          int width = pCloud.width;\n\
    \          int height = pCloud.height;\n        \n          // Convert from u\
    \ (column / width), v (row/height) to position in array\n          // where X,Y,Z\
    \ data starts\n          int arrayPosition = v*pCloud.row_step + u*pCloud.point_step;\n\
    \        \n          // compute position in array where x,y,z data start\n   \
    \       int arrayPosX = arrayPosition + pCloud.fields[0].offset; // X has an offset\
    \ of 0\n          int arrayPosY = arrayPosition + pCloud.fields[1].offset; //\
    \ Y has an offset of 4\n          int arrayPosZ = arrayPosition + pCloud.fields[2].offset;\
    \ // Z has an offset of 8\n        \n          float X = 0.0;\n          float\

    \ sizeof(float));\n          memcpy(&Y, &pCloud.data[arrayPosY], sizeof(float));\n\
    \          memcpy(&Z, &pCloud.data[arrayPosZ], sizeof(float));\n        \n   \
    \      // put data into the point p\n          p.x = X;\n          p.y = Y;\n\
    \          p.z = Z;\n        \n        }"
