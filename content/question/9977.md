    The tutorial you linked above is for using standalone PCL in your own CMake based project. It is not for using PCL within ROS.

    If you are looking for how to use PCL in your own ROS nodes, see the [pcl_ros](http://www.ros.org/wiki/pcl_ros) docs. In a nutshell, create a package as usual (this is described in the beginner tutorials elsewhere on ros.org), add a dependency on the `pcl_ros` package and then you should be able to include `pcl` headers into your package.

    If you are trying to use standalone PCL in your own CMake based project outside of ROS and are having trouble, you should send an email to the pcl-users mailing list detailing the issues you are having.

    \    link_directories(${PCL_LIBRARY_DIRS})\n    add_definitions(${PCL_DEFINITIONS})\n\
    \    find_package(catkin REQUIRED COMPONENTS\n    \tgeometry_msgs\n    \tnav_msgs\n\
    \    \troscpp\n    \t:\n    \t:\n    \tlaser_geometry\n    )\n    add_executable(xyz\
