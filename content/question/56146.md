  body_markdown: "What exactly did not work with the tf broadcaster? If the origin\
    \ is supposed to stay the same, all you need to do is find the right rotation\
    \ between the frames and broadcast like so:\n\n    tf::TransformBroadcaster br;\n\
    \    tf::Transform transform;\n    transform.setOrigin( tf::Vector3(0,0,0)); \n\
    \    transform.setRotation( tf::Quaternion(x,y,z,w) ); \n    br.sendTransform(tf::StampedTransform(transform,\
    \ ros::Time::now(), \"optical\", \"base_link\"));"
