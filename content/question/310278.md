Hi all,

I am trying to install the point cloud library in ROS Indigo, Ubuntu 14.04. I tried several different ways, but no one works.

First, I created the package in a workspace, followed [here](http://wiki.ros.org/pcl/Tutorials), and execute the command showed [here](https://answers.ros.org/question/201516/installing-pcl-for-ros-indigo/)

    rosdep install --from-paths ~/Documents/Projects/catkin_ws/src/my_pcl_tutorial --ignore-src -r --rosdistro indigo -y

However, it shows this

    ERROR: the following packages/stacks could not have their rosdep keys resolved

    ERROR: the following rosdeps failed to install
      apt: command [sudo -H apt-get install -y libpcl-dev] failed
      apt: Failed to detect successful installation of [libpcl-dev]

The problem remains if I execute

    sudo add-apt-repository ppa:v-launchpad-jochen-sprickerhof-de/pcl
    sudo apt-get update

I also followed the answer [here](https://answers.ros.org/question/201516/installing-pcl-for-ros-indigo/), the same problem occurred. I was confused that I thought it should install libpcl-all, but not libpcl-dev, because I was in Ubuntu 14.04, Indigo.

Then, I tried to follow the instructions from [the pcl official site](http://www.pointclouds.org/downloads/linux.html). Remove `/etc/apt/sources.list.d/v-launchpad-jochen-sprickerhof-de-*`, and execute

    sudo add-apt-repository ppa:v-launchpad-jochen-sprickerhof-de/pcl
    sudo apt-get update
    sudo apt-get install libpcl-all

After that, I 'catkin_make' in my workspace where I created a pcl package like [this](http://wiki.ros.org/pcl/Tutorials), but it shows 'Could not find a package configuration file provided by "pcl_conversions'. 

Can anyone please help me to solve the problem? many thanks.
