  body_markdown: "Yes, you can attach a sensor using SDF (that's what the tutorial\
    \ uses, not URDF). \n\nThe `<actor>` tag can have `<link>`s just like the `<model>`\
    \ tag can.\n\nTake the box example world in the tutorial for example and add a\
    \ camera sensor to the box link:\n\n    <link name=\"box_link\">\n      ...\n\
    \      <sensor name=\"camera\" type=\"camera\">\n        <camera>\n        </camera>\n\
    \        <visualize>true</visualize>\n      </sensor>\n    </link>\n\nTo do the\
    \ same for the animated person, you could add a link to it. See more documentation\
    \ on SDF [here](http://sdformat.org/spec).\n\nAlso see [this](http://answers.gazebosim.org/question/14006/links-with-animated-dae-files-possible/)\
    \ related question."
