  body_markdown: "Let's say you know how a function call works as in the following\
    \ example:\n\n    int main(int argc, char **argv) {\n\n     ros::Rate loop(50);\n\
    \    \n      while(ros::ok()) {\n       callmyfunction();   // <= do that until\
    \ the end of the world or ros kaputt\n       loop.sleep();\n     }\n    }\n\n\
    where \n\n    void callmyfunction() {\n    // function body\n    }\n\nis your\
    \ function defined somewhere in your code. That's the most usual way\n\nOk, now\
    \ let's say you have a situation where you need to do other things in your main\
    \ while() or for some reasons you don't want to call that function every loop\
    \ (maybe because it has another rate or frequency). An example could be a function\
    \ that publishes points to RViz. It does every 0.5 seconds but yur main routine\
    \ (your robot) works much more faster (with a frequency of 100 Hz for istance).\
    \ \n\nIn this case you can use timers and your code changes like following:\n\n\
    \    ros::Timer my_desired_frequency;\n\n    int main(int argc, char **argv) {\n\
    \n    my_desired_frequency = nh_.createTimer( ros::Duration(2.0), callmyfunction);\
    \ // Automatically calls every 2.0 seconds the function\n\n     ros::Rate loop(50);\n\
    \    \n      while(ros::ok()) {\n\n       // Here the main code for your Terminator\
    \ T1000\n\n       /* callmyfunction(); */ // Not needed anymore since it runs\
    \ indipendently\n       ros::spinOnce;  // NEEDED since callbacks for timers,\
    \ publishers and listeners must be executed\n       loop.sleep();\n     }\n  \
    \  }\n\n    void callmyfunction(const ros::TimerEvent& event) {  // <= New signature\
    \ here... for the same function\n    // function body same as above\n    }\n\n\
    Using that timer the function is going to be called indipendently and at another\
    \ (or you want the same) frequency than your main routine. It doesn't need to\
    \ be with the main synchronized. Keep it simple: you can think it is running in\
    \ background and you don't need to call the function directly in your code.\n\n\
    UPDATE: this is not the only way to use a timer. You can create a timer as a member\
    \ function/variable in a class or as a functor. For the right syntax can you check\
    \ the following [link](http://wiki.ros.org/roscpp/Overview/Timers) and ask if\
    \ yu have questions.\n\nHope my explanation helps.\nRegards"
