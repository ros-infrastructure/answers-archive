    This looks like you may have missed section 1.6 from the installation [instructions here](http://wiki.ros.org/kinetic/Installation/Ubuntu). Try executing the following command in your terminal before `catkin_make`

    Add this command to your .bashrc file as described will mean that `catkin_make` will always be available in any terminal.
