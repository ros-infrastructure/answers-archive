  body_markdown: "You should set `publish_tf` parameter of [rgbd_odometry](http://wiki.ros.org/rtabmap_ros#Visual_Odometry)\
    \ node to false. \n\n    <node package=\"rtabmap_ros\" type=\"rgbd_odometry\"\
    \ name=\"rgbd_odomerty\">\n       <param name=\"publish_tf\" type=\"bool\" value=\"\
    false\"/>\n       ...\n    </node>\n\nOdometry topic is mandatory for [rtabmap](http://wiki.ros.org/rtabmap_ros#rtabmap),\
    \ not for [rtabmapviz](http://wiki.ros.org/rtabmap_ros#rtabmapviz). The odometry\
    \ topic is used by [rtabmap](http://wiki.ros.org/rtabmap_ros#rtabmap) only if\
    \ `odom_frame_id` parameter is set:\n\n> ~odom_frame_id (string, default: \"\"\
    )\n\n> The frame attached to odometry. If\n> empty, rtabmap will subscribe to\
    \ odom\n> topic to get odometry. If set,\n> odometry is got from tf (in this case,\n\
    > a covariance of 1 is used).\n\ncheers"
