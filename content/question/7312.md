  body_markdown: "I don't think it's well-documented anywhere yet. It's kind of informal;\
    \ there isn't a master list of things that can be requested. There's just a standard\
    \ topic `~/request` the request providers subscribe to and that requesters can\
    \ advertise.\n\nI grepped for `Subscribe.*~/request` in gazebo and found the following\
    \ list of request providers:\n\n<pre><code>\n./gazebo/gui/GLWidget.cc\n./gazebo/gui/ModelListWidget.cc\n\
    ./gazebo/gui/ModelRightMenu.cc\n./gazebo/physics/HeightmapShape.cc\n./gazebo/physics/PhysicsEngine.cc\n\
    ./gazebo/physics/World.cc\n./gazebo/rendering/Scene.cc\n</code></pre>\n\nTo see\
    \ the requests provided by a given provider, you have to look at the code. For\
    \ example, see [World::ProcessRequestMsgs in World.cc](http://build.osrfoundation.org/view/gazebo/job/gazebo-any-devel-trusty-amd64-gpu-nvidia/270/)\
    \ to see some of the following:\n\n<pre><code>\n    if ((*iter).request() == \"\
    entity_list\")\n\u2026\n    else if ((*iter).request() == \"entity_delete\")\n\
    \u2026\n    else if ((*iter).request() == \"entity_info\")\n...\n</code></pre>\n\
    \nThis is only a partial answer, but I'll add more if there are further questions."
