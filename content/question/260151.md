    You need to set up both your Raspberry Pi and Ubuntu (running in VMWare) to use a time synchronisation service.

    Ubuntu should be set up automatically, I think, but [here is the documentation so you can check](https://help.ubuntu.com/lts/serverguide/NTP.html).

    For the Raspberry Pi, it depends on which OS you have installed. Are you using Raspbian? [Chrony](https://chrony.tuxfamily.org/) is often mentioned as being both easy to set up and reliable on wifi connections (the original Turtlebot instructions [explicitly discuss it](http://wiki.ros.org/Robots/TurtleBot/Robot%20Setup/ntp)).
