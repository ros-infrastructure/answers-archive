  body_markdown: |-
    You seem to build only one package, `rosaria_client`, which has a dependency to `rosaria`.

    You probably haven't put the client into the same ROS workspace, i.e. the same `src` folder, where you did the first build (see [1.4](http://wiki.ros.org/ROSARIA/Tutorials/How%20to%20use%20ROSARIA#Install_ARIA_and_Build_ROSARIA) of the tutorial).

    Put the `rosaria_client` pkg next to the `rosaria` pkg, and it should work
