  body_markdown: "I think the main problem is the feedback velocity from the simulator.\
    \ \n\nif the velocity feedback is correct and the topic frequency is 10 hz or\
    \ more , this should work fine. \n\nincrease deceleration to -5 m/s2 and BrakingPushRatio\
    \ to 20. so you can find how early the vehicle will stop. \n\nThis distance should\
    \ be consistent any time you run the simulation with any max velocity value. \n\
    \nYou can control this distance using two parameters: distance-to-goal , additional-braking-distance.\
    \ \n\nOnce you fixed that, you start decrease the deceleration and braking-push-ratio\
    \ to achieve smooth braking. \n\n"
