    Worked it out! Just need to set the `material` option like this:

        let frontLaserScan = new ROS3D.LaserScan({
            ros : this.ros,
            tfClient : tfClient,
            topic : '/lidar_scan',
            rootObject : viewer.scene,
            material : { size: 0.1, color: 0xff0000 }
        });
