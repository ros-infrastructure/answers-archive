    - For `ICMP` ping, you can also run [rosping](http://wiki.ros.org/rosping) node from your launch.
    - For `xmlrpc` ping in ROS network level, in [rosnode](http://wiki.ros.org/rosnode) Python API there are some methods, e.g. [rosnode_ping](http://docs.ros.org/api/rosnode/html/rosnode-module.html#rosnode_ping). In the simplest form you can run a command like:

            python -c "import rosnode; rosnode.rosnode_ping('/rosout', verbose=True)"
