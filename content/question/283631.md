  body_markdown: "Do not use `Serial.println` with rosserial --> serial connection\
    \ is used for the communication for the serial node with the device, so other\
    \ outputs will cause trouble and won't end up to the console. Use `nh.log_in`fo\
    \ , `nh.log_warn` etc. if you want to print something to the console of the serial_node.py\
    \ and to rosout.\n\nSee: http://wiki.ros.org/rosserial/Overview/Logging\n\nFurther\
    \ it would be better not to delay for such a long time as serial_node and device\
    \ have to sync. This is done in `nh.spinOnce()`. If you want something to be done\
    \ e.g. only each second, remember a time stamp and then enter in the loop only\
    \ accordingly but call spinOnce each time.\n\nE.g.:\n\n    uint last_time_action_done_millis\
    \ = 0;\n    \n    void loop()\n    {\n      if ( millis() > last_time_action_done_millis\
    \ + 1000 )\n      {\n         last_time_action_done_millis = millis();\n\n   \
    \      // do stuff you want to do once per second\n      }\n    \n      // call\
    \ nh.spinOnce() each time in loop\n      nh.spinOnce();\n    }\n\n"
