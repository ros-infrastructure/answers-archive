    I would guess that it's this line:

        odom.pose.pose.orientation = odom_quat

    odom.pose.pose.orientation is a [quaternion message](http://www.ros.org/doc/api/geometry_msgs/html/msg/Quaternion.html), but odom_quat is a numpy array (which is what transformations.py uses natively)  You need to convert the data type before assigning it.  The numpy array uses index notation, while the message uses .x .y .z and .w
