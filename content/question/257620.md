  body_markdown: "If you created a custom message then you need to create a Publisher\
    \ that uses that custom message type. Right now your publisher is using a [`std_msgs/Int64`](http://docs.ros.org/jade/api/std_msgs/html/msg/Int64.html)\
    \ type which only has a single field named `data`.\n\nLet's say your custom message\
    \ is in a package called `my_custom_msgs` and that the file is named `Custom.msg`.\
    \ Then you would need to declare your publisher like\n\n    ros::NodeHandle n;\n\
    \    ros:Publisher pub = n.advertise<my_custom_msgs::Custom>(\"chatter\", 1000);\n\
    \nNow you can declare a message using the custom data type, populate each of the\
    \ fields in your message, and publish.\n\n    my_custom_msgs::Custom msg;\n  \
    \  msg.intensity = 15;\n    msg.location = 100;\n    msg.duration = 37;\n    pub.publish(msg);\n\
    \nLater, if you change your message to include a string so that it becomes\n\n\
    \    int64 intensity \n    int64 location\n    int64 duration\n    string note\n\
    \nThen you will create the publisher the same way, but populating the fields and\
    \ publishing will be\n\n    my_custom_msgs::Custom msg;\n    msg.intensity = 15;\n\
    \    msg.location = 100;\n    msg.duration = 37;\n    msg.note = \"Hello\";\n\
    \    pub.publish(msg);"
