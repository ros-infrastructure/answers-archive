  body_markdown: "Hi,\nI created a simulation using Jackal robot from clearpath that\
    \ has already a bumblebee, in this case the version 2.\nYou can see the video\
    \ response [here](https://youtu.be/uXwTAg__2oA).\n\n\nIt has all the image topics\
    \ running and you just have to start the stereo vision package. Fro that I used\
    \ the ROS package [stereo_image_proc](http://wiki.ros.org/stereo_image_proc).\
    \ It can be used for any stereo vision camera. You may have to tweek the parameters,\
    \  but in the case of the bumblebee, it worked out of the box.\n\nSo there are\
    \ two steps to have it all working:\n\n- The first one is launch the **stereo_image_proc**\
    \ node. To do so you just have to remap the topics to the ones of your robot in\
    \ particular. The file is **start_stereovision.launch**, see below.\n- The second\
    \ step is to launch the ImageDisparity visualiser. RVIZ doesnt support that type\
    \ of image and tehrefore you will have to use a node specificaly for that. This\
    \ is from the package **image_view**, the node **stereo_view**. The file is **start_stereovision_disparityimage.launch**,\
    \ see below.\n\n### **start_stereovision.launch**<br>\n    <launch>\n        <node\
    \ pkg=\"stereo_image_proc\" type=\"stereo_image_proc\" name=\"\" respawn=\"true\"\
    >\n            <remap from=\"left/image_raw\" to=\"/front/left/image_raw\" />\n\
    \            <remap from=\"left/camera_info\" to=\"/front/left/camera_info\" />\n\
    \            <remap from=\"right/image_raw\" to=\"/front/right/image_raw\" />\n\
    \            <remap from=\"right/camera_info\" to=\"/front/right/camera_info\"\
    \ />\n        </node>\n    </launch>\n\n\nAnd here is the launch file for the\
    \ disparity Gui.\n\n### **start_stereovision_disparityimage.launch**<br>\n   \
    \ <launch>\n        <node pkg=\"image_view\" type=\"stereo_view\" name=\"\" respawn=\"\
    true\" output=\"screen\">    \n            <remap from=\"stereo\" to=\"/\"/>\n\
    \            <remap from=\"image\" to=\"image_rect\"/>\n        </node>\n    </launch>\n\
    \n\n\n\nHoped it was usefull ;) ."
