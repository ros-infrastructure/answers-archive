  body_markdown: "You have to use a list of TFMessage to create the TFMessage. This\
    \ works for ROS2 Dashing:\n\n    from geometry_msgs.msg import TransformStamped\n\
    \    from tf2_msgs.msg import TFMessage\n    \n    tf_msg = TransformStamped()\n\
    \    # ... do stuff with this transform\n\n    # Instead of this:\n    # broadcaster\
    \ = TransformBroadcaster(self)\n    # broadcaster.sendTransform(tf_msg)\n\n  \
    \  # Use this:\n    publisher = self.create_publisher(msg_type=TFMessage, topic=\"\
    /tf\")\n    tf_msg = TFMessage()\n    tf_msg.transforms = [transform_stamped_msg]\n\
    \    publisher.publish(tf_msg)\n\nThis essecially equivalent of the source code\
    \ of TFBroadcaster in ROS2 Foxy. Tested with ROS2 Dashing and RVIZ. If you want\
    \ to broadcast a static transform, make sure to use /tf_static and the right QOS\
    \ TRANSIENT_LOCAL."
