  body_markdown: "The images are passed as `sensor_msgs::Image` messages. You can\
    \ definitely access the contents of the header in those messages. The header contains\
    \ seq, stamp and frame_id. If for example you have a callback `imageCb`, then\
    \ you can follow the code snippet to access the contents of the header.\n\n  \
    \     void imageCb(const sensor_msgs::ImageConstPtr& msg){  \n              std::cout\
    \ << msg->header.seq <<  std::endl;\n              std::cout << msg->header.stamp\
    \ <<  std::endl;\n              std::cout << msg->header.frame_id <<  std::endl;\n\
    \       }\n\nIs this what you want?"
