  body_markdown: "It's a bit late -- but I'd might as well leave an answer here.\n\
    \nYou can modify the colour by changing the appropriate tag in the URDF file of\
    \ the model/object you're playing with. \n\nIn the example posted [here](http://www.ros.org/wiki/simulator_gazebo/Tutorials/SpawningObjectInSimulation),\
    \ you can change the tag \n\n> <material>Gazebo/Blue</material>\n\nTo whatever\
    \ you want.\n\nFor fuerte, the list of available materials is in the file:\n\n\
    > /opt/ros/fuerte/stacks/simulator_gazebo/gazebo/gazebo/share/gazebo-1.0.2/Media/materials/scripts/Gazebo.material\n\
    \n"
