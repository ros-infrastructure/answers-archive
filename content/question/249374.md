  body_markdown: "Hi Chengwei, \n\nI already fix this problem and I can share my experience\
    \ to you.\n\n1. You can visualize the pointcloud2 points by choose the topic on\
    \ RVIZ. You can check the obstacle which cannot clear whether is caused by noise\
    \ points from original pointcloud2 topic.\n\n2. If yes, you may need to calibration\
    \ the sensor which produce pointcloud2 data(maybe camera, or others).\n\n3. If\
    \ no, please change below parameters:\n(1) z_resolution\n(2) z_voxels\n(3) max_obstacle_height\n\
    \nFor max_obstacle_height, I suggest you to set it as slightly higher than the\
    \ height of your robot.\n\nFor z_resolution and z_voxels, I suggest you to set\
    \ them as below condition.\nz_resolution * z_voxels = max_obstacle_height\n\n\
    (ex. If the max_obstacle_height set to 1.00, z_resoultion and z_voxels should\
    \ set 0.2 and 5. Because 0.2 * 5 = 1.00)\n\nHope these suggestion can help you."
