    You should be able to view the camera images in ROS the same way you would a real camera. The usual ROS utility for that is [image_view](http://wiki.ros.org/image_view).

    You can run a command like this:

        rosrun image_view image_view image:=/camera/image_raw

    Provide your correct topic name for the image parameter.
