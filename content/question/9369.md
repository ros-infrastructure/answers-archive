    You could launch the node in debug mode by adding the following line to the <node> tag in the launch file: launch-prefix="xterm -e gdb --args" (see this [tutorial](http://www.ros.org/wiki/roslaunch/Tutorials/Roslaunch%20Nodes%20in%20Valgrind%20or%20GDB)).  If you are not comfortable with a console based gdb you can use a front end interface like ddd.

    You could configure Eclipse to use remote debugging, even if I think it's a long shot. You can find more instructions [here](http://stackoverflow.com/questions/81194/remote-debugging-with-eclipse-cdt).
