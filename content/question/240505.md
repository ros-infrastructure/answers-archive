  body_markdown: "More or less. Gmapping subscribes to the /scan topic, so you will\
    \ need to remap /my_robot/laser/scan to /scan or vice versa. \n\nFor the tf, you\
    \ need a transform from the laser sensor to the robot base. You can add the sensor\
    \ to the URDF model if you want a visualization of it in RVIZ or you can use a\
    \ static transform publisher. \n\nGmapping requires an odometry source. You don't\
    \ state if you have one or not so I figured I would just point it out. "
