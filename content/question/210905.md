  body_markdown: " I got it to work. I was giving it a camera location, but it needs\
    \ a video to be passed as a topic. I added `<remap from=\"image\" to=\"/image_raw_0\"\
    \ />` were image_raw_0 was being passed by a uvc camera node. I set it all up\
    \ in a launch file:\n\n\n----------\n\n    <launch>\n      <node pkg=\"uvc_camera\"\
    \ type=\"uvc_camera_node\" name=\"uvc_camera\" output=\"screen\">\n        <param\
    \ name=\"width\" type=\"int\" value=\"640\" />\n        <param name=\"height\"\
    \ type=\"int\" value=\"480\" />\n        <param name=\"fps\" type=\"int\" value=\"\
    30\" />\n        <param name=\"frame\" type=\"string\" value=\"wide_stereo\" />\n\
    \    \n        <param name=\"auto_focus\" type=\"bool\" value=\"False\" />\n \
    \       <param name=\"focus_absolute\" type=\"int\" value=\"0\" />\n        <!--\
    \ other supported params: auto_exposure, exposure_absolute, brightness, power_line_frequency\
    \ -->\n    \n        <param name=\"device\" type=\"string\" value=\"/dev/video0\"\
    \ />\n        <remap from=\"/image_raw\" to=\"/image_raw_0\"/>\n        <param\
    \ name=\"camera_info_url\" type=\"string\" value=\"file://$(find uvc_camera)/example.yaml\"\
    \ />\n      </node>\n      <node name=\"cameracalibrator\" pkg=\"ptam\" type=\"\
    cameracalibrator\" clear_params=\"true\" output=\"screen\" respawn=\"true\">\n\
    \        <remap from=\"image\" to=\"/image_raw_0\" />\n        <remap from=\"\
    pose\" to=\"pose\"/>\n        <rosparam file=\"$(find ptam)/PtamFixParams.yaml\"\
    />\n      </node>\n    </launch>\n\n"
