    There are [CAD files for the Sick LMS200](https://www.mysick.com/saqqara/cad.aspx?ord=1015850&lang=en) on mysick.com and you can use the [make a model tutorial](http://gazebosim.org/tutorials?tut=build_model&cat=build_robot) to make the SDF model. For the sensor parameters, you can use the [hokuyo model](https://bitbucket.org/osrf/gazebo_models/src/2f154a1630aeb019a27e950836d5d8f769d7d3d4/hokuyo/model.sdf#cl-33) as an example and refer to the [SDF sensor documentation](http://osrf-distributions.s3.amazonaws.com/sdformat/api/dev.html#ray320).
