The envelope icon next to the username on the askbot site is stuck red.  I cleared my inbox (dismissed all notifications) but the icon is still red (it used to be white). 

**Update**: This is a bug. A bug has been filed [upstream](http://askbot.org/en/question/371/why-is-my-inbox-icon-still-red-even-when-my-inbox). A fix was checked into askbot April 25th to prevent further occurances. However to fix stale inbox counts on the current install the following command must be run:

    python manage.py fix_inbox_counts

Can some admin please run this?
