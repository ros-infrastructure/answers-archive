  body_markdown: |-
    The `message_definition` is only exchanged when creating a [TCPROS connection](http://wiki.ros.org/ROS/Connection%20Header). For UDP transport there is no such information. Also the master doesn't store this information.

    Depending on your scenario you might be able to load the message definition based on the topic type at runtime (in Python) if you can ensure that the system has the message package installed.
