    Looking at [ros/rosdistro/rosdep/base.yaml](https://github.com/ros/rosdistro/blob/1a9fda299e71f1b0dbe670516420fb05986b7214/rosdep/base.yaml), the `eigen` key maps to Eigen 3 ([here](https://github.com/ros/rosdistro/blob/1a9fda299e71f1b0dbe670516420fb05986b7214/rosdep/base.yaml#L667-L685)), `eigen2` maps to Eigen 2 ([here](https://github.com/ros/rosdistro/blob/1a9fda299e71f1b0dbe670516420fb05986b7214/rosdep/base.yaml#L686-L692)) and the `eigen3` mapping ([here](https://github.com/ros/rosdistro/blob/1a9fda299e71f1b0dbe670516420fb05986b7214/rosdep/base.yaml#L693-L697)) is a bit ambiguous and incomplete (perhaps @tfoote can explain that one).

    If you don't need v2, you should just depend on `eigen`, otherwise on `eigen2`.

    Note btw that (at least in Indigo and Jade) in addition to `build_depend`ing on `eigen`, you should also add a `build_depend` on `cmake_modules` to be able to use `find_package(Eigen3 ..)`, as that package provides the find script for it.
