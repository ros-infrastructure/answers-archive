    > I tired a single line invocation like follows but got an `yaml.scanner.ScannerError`

    Probably because you're providing invalid markup: abbreviated yaml dictionaries (ie: key-val on a single line) should be structured like so:

        { p : 1.0, i : 1.0, d : 1.0 }

    Note the accolades (`{}`) and item separators (`,`).

    ---

    Edit: Btw: you could also use `rospy.set_param(..)`. As it's an XMLRPC call, it can be used without creating a ROS node.

    I would not be surprised if you could use a bare XMLRPC call with the yaml dictionary directly. No ROS needed in that case (but I haven't tried it). See [wiki/ROS/Technical Overview - Parameter Server](http://wiki.ros.org/ROS/Technical%20Overview#Parameter_Server) and [wiki/ROS/Parameter Server API](http://wiki.ros.org/ROS/Parameter%20Server%20API).

    ...

        p: 1.0 i: 1.0 d: 1.0
            ^
