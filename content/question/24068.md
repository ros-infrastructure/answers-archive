    > I'm spawning my SDF model with static parameter as false

    How are you setting the model to static at spawn time?

    Setting a model to static after it's been spawned [doesn't work](https://bitbucket.org/osrf/gazebo/issues/1526/entity-setstatic-does-not-work-after-the), so the model should be static from startup. As far as I know, the only way of doing this is having `<static>true</static>` inside your model's SDF.
