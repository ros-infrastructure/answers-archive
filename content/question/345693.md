  body_markdown: "I guess you misunderstood something. (Or I might be misunderstanding\
    \ what you try to do).\n\nComparing the performance of 2 lidars by doing localization\
    \ in a given map should be doable by running two `amcl` instances side by side.\
    \ You only need to make sure to set `tf_broadcast` to false for at least one of\
    \ the two nodes.\n\nHowever, this then has nothing to do with `amcl` taking in\
    \ multiple `odom`s (as you say). `amcl` retrieves the `odom`->`base_link` transform\
    \ via `tf`. And then outputs the transform from  `map`->`odom` (if enabled). \n\
    \nYou then need to compare the published `amcl_pose` and `particle_cloud` topics\
    \ (make sure to remap those to unique names)."
