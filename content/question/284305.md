  body_markdown: "In order to perform `SLAM` or `Localization`, you need both `Proprioceptive\
    \ sensors` (Internal state like an odometer, IMU, wheel encoder) and `Exteroceptive\
    \ sensors` (external state like laser scanners). You need to use internal measurements\
    \ to perform prediction with a given motion model. For correction step, you need\
    \ to use external measurements like laser scans. \n\nIn localization problem,\
    \ particles are drawn according to internal measurements and motion model. Then,\
    \ resampling is performed using external sensor measurements and observation model.\
    \ If you are able to detect fiducial markers in the map, you can use a particle\
    \ filter."
