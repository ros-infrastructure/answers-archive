How we can run gcov in catkin ?

In Linux i tried below mentioned option and it worked and in same way i am looking gcov in catkin .

Ubuntu comes with gcov.
To find coverage of a cpp code add the flags while compiling:
Steps:
Compile and execute:
-- g++ -fprofile-arcs –ftest-coverage sample.cpp
--./a.out
--gcov sample.cpp
Result:
File sample.c
Lines Executed:87.50% of 8
Creating sample.cp.gcov
