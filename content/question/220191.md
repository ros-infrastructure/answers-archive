  body_markdown: "Yes; you should be adding to the CMakeLists from the previous tutorial.\n\
    \nYou shouldn't be trying to combine multiple statements from the different tutorials.\n\
    \nFor example, each call to `add_executable()` in cmake defines a new executable\
    \ that you're trying to compile, and you want to compile each tutorial, so you\
    \ should have two separate calls to `add_executable()`\n\n Your final CMakeLists\
    \ should look something like:\n\n    cmake_minimum_required(VERSION 2.8.3)\n \
    \   project(learning_actionlib)\n    \n    find_package(catkin REQUIRED COMPONENTS\
    \ roscpp actionlib actionlib_msgs)\n    find_package(Boost REQUIRED COMPONENTS\
    \ system)\n    \n    add_action_files(\n      DIRECTORY action\n      FILES Fibonacci.action\n\
    \    )\n    \n    generate_messages(\n      DEPENDENCIES actionlib_msgs std_msgs\n\
    \    )\n    \n    catkin_package(\n      CATKIN_DEPENDS actionlib_msgs\n    )\n\
    \    \n    include_directories(include ${catkin_INCLUDE_DIRS} ${Boost_INCLUDE_DIRS})\n\
    \    \n    add_executable(fibonacci_server src/fibonacci_server.cpp)\n    \n \
    \   target_link_libraries(\n      fibonacci_server\n      ${catkin_LIBRARIES}\n\
    \    )\n    \n    add_dependencies(\n      fibonacci_server\n      ${learning_actionlib_EXPORTED_TARGETS}\n\
    \    )\n    \n    add_executable(fibonacci_client src/fibonacci_client.cpp)\n\
    \    \n    target_link_libraries( \n      fibonacci_client\n      ${catkin_LIBRARIES}\n\
    \    )\n    \n    add_dependencies(\n      fibonacci_client\n      ${learning_actionlib_EXPORTED_TARGETS}\n\
    \    )"
