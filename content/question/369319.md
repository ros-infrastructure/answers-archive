- body_markdown: "By `external_map`, I mean any map that is being published on the\
    \ `/map` topic.\n\nWhenever you are running a program (i.e. node) that publishes\
    \ on the `/map` topic, and you want to use that `/map` topic to build your `global_costmap`,\
    \ you would need to set the `global_frame` parameter to `/map`. \n\nSometimes,\
    \ it could also happen that you don't really care about the `map`, and just want\
    \ to operate the bot in the `odom` frame. In such cases, you would need to set\
    \ the `global_frame` (for your `global_costmap`) to `/odom`. You would also need\
    \ to manually set the `width` and `height` for the `global_costmap`. \n\nDoes\
    \ that make sense? \n\nYou could also try to visualize the `global_costmap` on\
    \ `Rviz` for more clarity."
