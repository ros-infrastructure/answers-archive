    It is actually not that easy. You first need to read in the robot description from urdf, there is a [library](ros.org/wiki/urdf) for doing so. Then you to load all meshes. rviz used to use [assimp](http://ros.org/wiki/assimp) for doing that. Finally, you need a tf listener to get the current pose of all links specified in the urdf.

    I implemented the functionality for rendering the PR2 in common lisp, stack [cram_physics](ros.org/wiki/cram_physics) and I think Bosch's [pr2_camera_self_filter](http://www.ros.org/wiki/pr2_camera_self_filter) contains some code for rendering the PR2 in C++.
