  body_markdown: "Hi, \n\nI actually have solved the problem by now. I think the solution\
    \ was mentioned somewhere in ROSAnswer already so I would not take credit for\
    \ it.\n\nThe solution is to set ROS_IP in the host PC to its IP address so that\
    \ it can communicate.\n\nThis step is simple but can be easily overlooked. As\
    \ I got the rosjava pub_sub tutorial to work, I ignored setting ROS_IP because\
    \ I think I do not need to do so. However, a colleague aptly reminded me that\
    \ the pub_sub tutorial only tested one way connection from the Android tablet\
    \ to PC but not the other way round. For the other way to work (e.g sending images\
    \ from host PC to the android device), you will need to set ROS_IP.\n\nIn order\
    \ to set ROS_IP: \n$export ROS_IP=ip_adress\n\nTo check whether IP has been set:\n\
    $echo $ROS_IP\nYou should see your computer IP address.\n\n\nHopefully this will\
    \ help someone else with the same problem as well."
