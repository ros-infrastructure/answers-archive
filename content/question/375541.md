    For anyone interested in using these V(I)O (or older software in general), I have solved the issue by using docker.
    This allows me to run the algorithms on an older version of Ubuntu/ros (Xenial/kinetic in my case). Afterwards, I set up a network between this docker container and my host OS (Focal/noetic). For more info you can check out these tutorials: http://wiki.ros.org/docker/Tutorials

    I would recommend first looking at some tutorials about docker in general. Otherwise the used concepts will be quite foreign.
