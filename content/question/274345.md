  body_markdown: "You should create your own node that will do this. You can do this\
    \ in c++ or python. \n\nFollow the **Writing a Simple Publisher and Subscriber**\
    \ tutorial that teaches you how to make a publisher and subscriber node. You are\
    \ only concerned with making a publisher node, but if you haven't done these tutorials,\
    \ you should. \n\nHere's the c++ version: http://wiki.ros.org/ROS/Tutorials/WritingPublisherSubscriber%28c%2B%2B%29\n\
    \nHere's the python version: http://wiki.ros.org/ROS/Tutorials/WritingPublisherSubscriber%28python%29\n\
    \nHere is an example with UNTESTED CODE of how you would do this in c++:\n\n \
    \   #include \"ros/ros.h\"\n    #include \"geometry_msgs/Twist.h\"\n    \n   \
    \ \n    int main(int argc, char **argv)\n    {\n     \n      ros::init(argc, argv,\
    \ \"talker\");\n    \n      ros::NodeHandle n;\n      \n      // Advertize the\
    \ publisher on the topic you like\n      ros::Publisher pub = n.advertise<geometry_msgs::Twist>(\"\
    my_topic_name\", 1000);\n    \n      while (ros::ok())\n      {\n        /**\n\
    \         * This is a message object. You stuff it with data, and then publish\
    \ it.\n         */\n        geometry_msgs::Twist myTwistMsg\n    \n    \t// Here\
    \ you build your twist message\n        myTwistMsg.linear.x = 1;\n    \tmyTwistMsg.linear.y\
    \ = 2;\n    \tmyTwistMsg.linear.z = 3;\n    \t\n    \tros::Time beginTime = ros::Time::now();\n\
    \    \tros::Duration secondsIWantToSendMessagesFor = ros::Duration(3); \n    \t\
    ros::Time endTime = beginTime + secondsIWantToSendMessagesFor;\n    \twhile(ros::Time::now()\
    \ < endTime )\n    \t{\n    \t\tpub.publish(msg);\n    \t\t\n    \t\t// Time between\
    \ messages, so you don't blast out an thousands of \n    \t\t// messages in your\
    \ 3 secondperiod\n    \t\tros::Duration(0.1).sleep();\n    \t}\n    \n      return\
    \ 0;\n    }"
