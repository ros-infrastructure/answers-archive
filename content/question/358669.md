  body_markdown: "If you check the QoS profile for `sensor_data` you will see that\
    \ reliability is set to the best effort:\nhttps://github.com/ros2/rclcpp/blob/f160a8bc1d2b4f9a9fb0bba23d0b5d0f8c1afaab/rclcpp/include/rclcpp/qos.hpp#L168\n\
    \nNow, if you add a new visualization to RViz2 it will have reliability policy\
    \ set to `Reliable` by default: \n\n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/15965701539503181.png)\n\
    \ \nTherefore, just change reliability to `Best Effort`:  \n\n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/15965701797764096.png)\n\
    \n\nIf you want to test, you can set `--qos-profile` to `ros2 topic pub` as: \
    \ \n\n    ros2 topic pub --qos-profile=sensor_data /topic sensor_msgs/Range '{\
    \ range: 1, header: { frame_id: base_link } }'"
