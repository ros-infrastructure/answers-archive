    Hi,

    That message is not an error but a warning of the `freenect_launch` Kinect driver. It is just stating that the driver is using default parameters for camera calibrations because it was unable to find a yaml config file.
    Furthermore, since you are using a virtual machine, it is possible that you have conflict with the USB connection of the Kinect.
    To start the debug process I would look first at the image provided for the Kinect (with [image_view](http://wiki.ros.org/image_view) you can do that) and then, at the laser scan provided by the node `depthimage_to_laserscan` (/scan). When you are sure those nodes and topics are working properly you can continue to debug why there is no map generation...
    If those topics are enabled and correct there is the possibility you do not have a proper tf tree. You can look at the tf tree by [tf debug tools](http://wiki.ros.org/tf/Debugging%20tools). It is possible the map frame does not exists or you have no Base_footprint -> Odom -> Map transform
