  body_markdown: "Are you talking about a local cost map?  If you are using the [obstacles\
    \ layer](http://wiki.ros.org/costmap_2d/hydro/obstacles), there is a `footprint_clearing_enabled`\
    \ parameter, which defaults to `true`.  Make sure it is not set accidentally set\
    \ to `false`.  If it's still not clearing, ensure that your footprint is properly\
    \ defined.  This is also important for avoiding obstacles in general.\n\nThat\
    \ said, the [`laser_filters` package](http://wiki.ros.org/laser_filters#LaserScanRangeFilter)\
    \ (as Proc\xF3pio suggested) is probably also useful as it will remove the pillars\
    \ from the data stream completely.  This will likely improve the quality of SLAM\
    \ and other applications of your lidar data."
