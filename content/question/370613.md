  body_markdown: "Not sure whether this is what you describe as \"categorizing\",\
    \ but there is support for \"named loggers\". See [roscpp/Overview/Logging](http://wiki.ros.org/roscpp/Overview/Logging):\n\
    \n> The named versions output to a logger that is a child of the default one.\
    \ This allows you to configure different logging statements to be enabled/disabled\
    \ based on their name. For example: \n> \n    #include <ros/console.h>\n    ROS_DEBUG_NAMED(\"\
    test_only\", \"Hello %s\", \"World\");\n    ROS_DEBUG_STREAM_NAMED(\"test_only\"\
    , \"Hello \" << \"World\");\n\nYou won't be able to change the way *other* nodes\
    \ log with that though.\n\nOnly how your own nodes log things.\n\n"
