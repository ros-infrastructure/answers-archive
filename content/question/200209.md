    ROS has Qt-based GUI framework and toolset called [rqt](http://wiki.ros.org/rqt). I recommend to browse through first the list of [some existing tools](http://wiki.ros.org/rqt/Plugins) and see if there's anything that might fit your needs, before starting your own GUI tools from scratch. For mobile robots in particular, I can think of [rqt_robot_steering](http://wiki.ros.org/rqt_robot_steering) for operating wheels at minimum.

    `rqt` provides set of [tutorials](http://wiki.ros.org/rqt#Instructions) to build your own GUI based on rqt framework.
