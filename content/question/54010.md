  body_markdown: "In the client package you need to find_package your 'HeaderProjectName',\
    \ something like this will add the includes path from HeaderProjectName:\n\n \
    \   find_package(catkin REQUIRED COMPONENTS HeaderProjectName <other packages\
    \ here>)\n    include_directories(${catkin_INCLUDE_DIRS})\n\nAn alternative method\
    \ is that you can find_package HeaderProjectName directly:\n\n    find_package(HeaderProjectName\
    \ REQUIRED)\n    include_directories(${HeaderProjectName_INCLUDE_DIRS}) "
