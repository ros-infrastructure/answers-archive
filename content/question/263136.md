  body_markdown: "I think, I have found the problem.\n\nI was making the ros launch\
    \ and all the other process through ssh, in order to control it remotely. \n\n\
    Therefore, it was needed to use a local network. If the connection is broken,\
    \ the ssh will wait unit the connection is reestablished. Because if that it stops\
    \ the process and put in a queue all the commands, which were not received by\
    \ the ssh connection.\n\nThe answer is to implement an ethernet connection, or\
    \ run  the nodes directly on the raspberry.\n\nWith this method is was able to\
    \ run 2 days long. "
