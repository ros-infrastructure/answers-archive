  body_markdown: "Ok, with just a bit of effort I managed this problem in this way.\
    \ I will post the solution I figured out in a sort of pseudocode. I have a class\
    \ in which I make different things. i just added a client: \n\n    class WHATEVER\
    \ : public rclcpp::Node{\n      private:\n         //stuff...\n          rclcpp::Client<gazebo_msgs::srv::SetEntityState>::SharedPtr\
    \ _client;\n\n      public:\n         WHATEVER() : Node(\"whatever\"){\n     \
    \      //stuff...\n          _client = this->create_client<gazebo_msgs::srv::SetEntityState>(\"\
    set_entity_state\");\n          }\n          void client_request();\n        \
    \  //stuff...\n    };\n    void  WHATEVER::client_request(){\n        auto request=std::make_shared<gazebo_msgs::srv::SetEntityState::Request>();\n\
    \        request->state.name=\"small_box_1\";\n        request->state.pose.position.x=0.41;\n\
    \        request->state.pose.position.y=0.00;\n        request->state.pose.position.z=0.75;\n\
    \        request->state.pose.orientation.x=0.00;\n        request->state.pose.orientation.y=0.00;\n\
    \        request->state.pose.orientation.z=0.00;\n        request->state.pose.orientation.w=1.00;\n\
    \        request->state.twist.linear.x=0.00;\n        request->state.twist.linear.y=0.00;\n\
    \        request->state.twist.linear.z=0.00;\n        request->state.twist.angular.x=0.00;\n\
    \        request->state.twist.angular.y=0.00;\n        request->state.twist.angular.z=0.00;\n\
    \        request->state.reference_frame=\"world\";\n        _client->async_send_request(request);\n\
    \    }\n\nAnd the game is done! You can call this function `client request()`\
    \ whenever you want or also call it periodically threating it as a  `rclcpp::TimerBase::SharedPtr`\
    \ callback!\n\n"
