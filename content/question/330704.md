    There is no such thing as a single version for a ROS distro. Each distro consists of [many packages](http://repositories.ros.org/status_page/ros_melodic_default.html) that have completely different version numbers.

    If you are refering to the [latest sync](https://discourse.ros.org/t/new-packages-for-melodic-2019-08-14/10288) and want to update this: Assuming you have followed the standard install instructions using debian packages, a simple `sudo apt update && sudo apt upgrade` will be sufficient.
