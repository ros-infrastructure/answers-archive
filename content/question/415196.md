  body_markdown: "It is not necessary to store a reference to a Subscriber (but you\
    \ can!). It will keep working even after that the `__init__` has been completed\
    \ (of course as long as an instance of `SomeClass` is defined and the node is\
    \ running).\n\nAs for the Publisher, in general, yes you should store a reference\
    \ to it. In this way, you can publish also from outside the function in which\
    \ you have defined it.\n\nI hope that this example can help you:\n\n    class\
    \ SomeClass:\n        def __init__(self):\n\n            # Defined Subscriber\
    \ without reference\n            rospy.Subscriber(\"/some/topic1\", SomeMessageType,\
    \ self.some_topic1_callback)\n\n            # Defined Publisher with reference\n\
    \            self.my_pub = rospy.Publisher(\"/some/topic2\", SomeMessageType,\
    \ queue_size=1)\n\n    \n        def some_topic1_callback(self, msg):\n      \
    \      \n            # Do something with your message\n            new_msg = self.great_function_doing_stuff(msg)\n\
    \            \n            # Publish the result\n            self.my_pub.publish(new_msg)"

Do I need to store a reference to rospy subscribers and publishers to avoid these objects to be garbage collected?

    class SomeClass:
        def __init__(self):
    
            # option 1, without reference
            rospy.Subscriber("/some/topic1", SomeMessageType, self.some_topic1_callback)
    
            # option 2, with reference
            self.my_subscriber = rospy.Subscriber("/some/topic2", SomeMessageType, self.some_topic2_callback)
