  body_markdown: "Hi Parth2851,\n\nAs you mentioned, the map message consists on a\
    \ 1D array containing all the information.\n\nIf you want to convert this to a\
    \ 2D matrix, you can extract the positions using the map info metadata, where\
    \ the height, width and resolution of the map are provided.\n\nA simple function\
    \ to extract a given position (in pixels) of the map, can be like this\n\n   \
    \     int getMapValue(int height, int width, const nav_msgs::OccupancyGrid& map)\n\
    \    {\n    \tint position = map.info.width * height + width;        // Finds\
    \ the position in the data vector.\n    \treturn map.data[position];\t\t\t\t \
    \   // Gets the value from the position\n    }\n\nif you want to extract a position\
    \ on meters, then you should take into account the resolution of the map, also\
    \ available on the map info message.\n\n\nRegards,\n"
