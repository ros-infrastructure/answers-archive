    \ has explanation for all the variables.  \n\nLooking at the code [Publish_a_LaserScan_Message](http://wiki.ros.org/navigation/Tutorials/RobotSetup/Sensors#Writing_Code_to_Publish_a_LaserScan_Message)\
    \ will gives good picture of variables.\n\n\n\nlaser scanner view of  [hokuyo\
    \ URG-04LX-UG01 laser scanner ](https://www.hokuyo-aut.jp/02sensor/07scanner/urg_04lx_ug01.html)\
    \ \n\n\n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/14177210732958238.jpg)\n\
    \nred,green are x,y-axes\n\n----------\nValues for above scanner \n\n        angle_min=\
    \ -135 * (pi/180); //angle correspond to FIRST beam in scan ( in rad)\n      \
    \  angle_max= 135 * (pi/180); //angle correspond to LAST beam in scan ( in rad)\n\
    \        angle_increment =0.25 * (pi/180); // Angular resolution i.e angle between\
    \ 2 beams\n\n       // lets assume sensor gives 50 scans per second. i.e every\
    \ 20 milli seconds 1 scan with 1081 beams.\n       // Each beam is measured in\
    \  (20 ms/ 1081 ) ~ = 0.0185 ms\n\n        time_increment  = (1 / 50) / (1081);\
    \ \n                                                               \n        scan_time\
    \ = ;   // scan is collected at which time\n        range_min =0 ; // in meters\n\
    \        range_max = 20; // scan can measure upto this range\n        // ranges\
    \ is array of 1081 floats for each laser beam\n        ranges[0] = //distance\
    \ measure corresponds to angle -135 deg\n        ranges[1] = //distance measure\
    \ corresponds to angle -134.75 deg\n        .\n        .\n        .\n        ranges[1080]\
    \ = //distance measure corresponds to angle +135 deg\n\n\n        //To understand\
    \ Intensities \n        //if a laser beam hits reflective surface like glass it\
    \ will have intensity 1. \n        //And if beam hit some surface which absorbs\
    \ laser , then intensity is zero. \n        //Middle values are different surfaces\
    \ in between.\n     \n\n----------\n\n\n    Header header            # timestamp\
    \ in the header is the acquisition time of \n                             # the\
    \ first ray in the scan.\n                             #\n                   \
    \          # in frame frame_id, angles are measured around \n                \
    \             # the positive Z axis (counterclockwise, if Z is up)\n         \
    \                    # with zero angle being forward along the x axis\n      \
    \                       \n    float32 angle_min        # start angle of the scan\
    \ [rad]\n    float32 angle_max        # end angle of the scan [rad]\n    float32\
    \ angle_increment  # angular distance between measurements [rad]\n    \n    float32\
    \ time_increment   # time between measurements [seconds] - if your scanner\n \
    \                            # is moving, this will be used in interpolating position\n\
    \                             # of 3d points\n    float32 scan_time        # time\
    \ between scans [seconds]\n    \n    float32 range_min        # minimum range\
    \ value [m]\n    float32 range_max        # maximum range value [m]\n    \n  \
    \  float32[] ranges         # range data [m] (Note: values < range_min or > range_max\
    \ should be discarded)\n    float32[] intensities    # intensity data [device-specific\
    \ units].  If your\n                             # device does not provide intensities,\
    \ please leave\n                             # the array empty.\n\n\n----------\n\
    Obstacle distance calculation is easy\n\n![image description](http://www.physics.hmc.edu/courses/p057/pmwiki/uploads/Physics/Euler2.png)\n\

    \ = ( rcos\u03B8, rsin\u03B8 )  in laser frame.\n\n\nTo make sense about \u03B8\
    \ , here imagine your laser has 180 deg view and now looking towards x-axis and\
