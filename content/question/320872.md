  body_markdown: "As you can see, an error occurred when the function 'getattr(mod,\
    \ attr_name)' is called:  \n&emsp;parameter 'mod' should be the path of the 'module'.\
    \  \n&emsp;parameter 'attr_name' should be the name of the 'object'.  \nFor example:\
    \   \n&emsp;If we want to:`from openai_ros.task_envs.turtlebot2.turtlebot2_wall\
    \ import TurtleBot2WallEnv`  \n&emsp;We should:`getattr(openai_ros.task_envs.turtlebot2.turtlebot2_wall,TurtleBot2WallEnv)`\
    \  \nBefore you called the function:`env = gym.make('TurtleBot2Maze-v0')`.  \n\
    You should:  \n```\nfrom gym.envs.registration import register  \nregister(  \n\
    \        id='TurtleBot2Maze-v0',  \n        entry_point='openai_ros.task_envs.turtlebot2.turtlebot2_maze:MyTurtleBot2MazeEnv',\
    \  \n        timestep_limit=timestep_limit_per_episode,  \n    )  \nfrom openai_ros.task_envs.turtlebot2.turtlebot2_maze\
    \ import TurtleBot2MazeEnv\n```  \nWhere the `id` should be given as same as `env\
    \ = gym.make('TurtleBot2Maze-v0')`.  \nThe `entry_point` should be given like:`aaa:bbb`:\
    \  \n&emsp;`aaa` is the path of the module 'turtlebot2_maze.py'  \n&emsp;`bbb`\
    \ is the name of class `MyTurtleBot2MazeEnv` in module 'turtlebot2_maze.py'  \n\
    Sometimes `timestep_limit=timestep_limit_per_episode` is needless,and we can:\
    \  \n`#timestep_limit=timestep_limit_per_episode`  \nThe `turtlebot2_maze.py`\
    \ is part of models in 'openai_ros' package , the [version2  openai_ros](https://bitbucket.org/theconstructcore/openai_ros/src/version2/openai_ros/src/openai_ros/)\
    \ can automatically download the model.\n\n"
