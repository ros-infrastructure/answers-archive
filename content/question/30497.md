    \ load the .vcg config file specified in the launch file. This seems to happen\
    \ occasionally for no particular reason in electric. You can restart rviz afterwards\
    \ and try to manually load the [indoor SLAM](http://code.google.com/p/tu-darmstadt-ros-pkg/source/browse/trunk/hector_quadrotor/hector_quadrotor_demo/rviz_cfg/indoor_slam.vcg)\
