  body_markdown: " If a node publishes on a topic and also has a subscriber for it,\
    \ it will receive \"it's own\" message. This is a feature, as components in the\
    \ publish/subscribe system should not need to care about where a message originates\
    \ from. \n\nEven though this probably is best avoided, you can check for the origin\
    \ of a message using the [MessageEvent](http://docs.ros.org/diamondback/api/roscpp/html/classros_1_1MessageEvent.html#_details)\
    \ mechanism (e.g. if it originates from the same node) as in [this example](https://github.com/tu-darmstadt-ros-pkg/vehicle_controller/blob/master/src/controller.cpp#L233)."
