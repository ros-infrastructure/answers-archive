  body_markdown: "Hello Juan,\n\nI've recently been working with a 3-finger gripper,\
    \ and I've used the Smart Grasping simulation provided by Shadow Robot, which\
    \ provides a 3-finger gripper mounted on an UR10 arm. The repo for this simulation\
    \ is here: https://github.com/shadow-robot/smart_grasping_sandbox\n\nI just wanted\
    \ the 3-finger gripper in my simulation, so I did a couple of basic modifications\
    \ to the URDF in order to have it. What I basically did was:\n\n1) Remove from\
    \ the model.urdf file all the stuff related to the UR arm.\n\n2) Add some basic\
    \ URDF code in order to have a platform where I place the gripper.\n\n\n    <link\
    \ name=\"table\">\n      <visual>\n        <geometry>\n          <box size=\"\
    0.6 0.6 0.05\"/>\n        </geometry>\n      </visual>\n      <collision>\n  \
    \      <geometry>\n          <box size=\"0.6 0.6 0.05\"/>\n        </geometry>\n\
    \      </collision>\n    </link>\n      \n    <joint name=\"world_to_table\" type=\"\
    fixed\">\n      <parent link=\"world\"/>\n      <child link=\"table\"/>\n    \
    \  <origin xyz=\"0.0 0.0 0.5\" rpy=\"0.0 0.0 0.0\"/>\n    </joint>\n      \n \
    \   <joint name=\"table_to_hand\" type=\"fixed\">\n      <parent link=\"table\"\
    />\n      <child link=\"H1_base_attach\"/>\n      <origin xyz=\"0.0 0.0 0.05\"\
    \ rpy=\"0.0 0.0 0.0\"/>\n    </joint>  \n\n  \n3) Remove from the launch file\
    \ all the controllers related to the arm, and make sure that is taking my new\
    \ URDF file, which contains only the hand data.\n\nI have created this [video](https://www.youtube.com/watch?v=dnjP0z333-k&t=2s)\
    \ showing the whole process, which really just takes like 5 minutes. \n\nHope\
    \ this helps you!"
