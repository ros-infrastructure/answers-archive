  body_markdown: "That world file is meant for ROS Electric (Stage 3.2.2) and not\
    \ for ROS Fuerte and ROS Groovy (both employ Stage 4.1.1). The code fails because\
    \ in Stage 4.1.1, every point is defined by 4 parameters (x,y,z,theta) and not\
    \ by 3 parameters. Hence the buggy part of the code is \n\n\n        size [0.33\
    \ 0.33 0.1]\n\n        # This block approximates the circular shape of a Roomba\n\
    \        block\n        ( \n           points 16\n           point[0]  [ 0.225\
    \ 0.000 ]\n           point[1]  [ 0.208 0.086 ]\n           point[2]  [ 0.159\
    \ 0.159 ]\n           point[3]  [ 0.086 0.208 ]\n           point[4]  [ 0.000\
    \ 0.225 ]\n           point[5]  [ -0.086 0.208 ]\n           point[6]  [ -0.159\
    \ 0.159 ]\n           point[7]  [ -0.208 0.086 ]\n           point[8]  [ -0.225\
    \ 0.000 ]\n           point[9]  [ -0.208 -0.086 ]\n           point[10] [ -0.159\
    \ -0.159 ]\n           point[11] [ -0.086 -0.208 ]\n           point[12] [ -0.000\
    \ -0.225 ]\n           point[13] [ 0.086 -0.208 ]\n           point[14] [ 0.159\
    \ -0.159 ]\n           point[15] [ 0.208 -0.086 ]\n        \n           color\
    \ \"gray50\"\n        )\n\nAlso this code uses laser and not ranger, the API changed\
    \ from Stage 3.X.X to Stage 4.X.X. For help on that have a look here -- [http://blog.aus10.org/?p=125](http://blog.aus10.org/?p=125).\n\
    \nSo, you may have to put in some labour to make that world file work in ROS Groovy\
    \ (Stage 4.1.1)."
