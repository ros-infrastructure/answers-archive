  body_markdown: "rosparam is not failing silently, it's doing exactly what you're\
    \ telling it to. As \u03A6Xoc\u0119 \uC6C3 \u041Fepe\xFApa \u30C4 said, you're\
    \ actually *setting* the parameter to that value. According to [the rosparam wiki](http://wiki.ros.org/rosparam#rosparam_set),\
    \ the syntax for setting a parameter via the command line is:\n\n`rosparam set\
    \ parameter_name value`\n\nwhere, in your case, `parameter_name` is `/background_r`\
    \ and `value` is `\"foo\"`. If you were to call \n\n`rosparam get /background_r`\
    \ \n\nafter running the command that \"silently fails\" you would see that it\
    \ actually has the value of `\"foo\"`. The parameter server just stores a bunch\
    \ of dictionary values that you can set, use, and even delete."
