    Seems in melodic there are only [realsense2](http://wiki.ros.org/realsense2_camera) packages. If this is what you need, you can install it with:

     `$ sudo apt-get install ros-melodic-librealsense2 ros-melodic-realsense2-camera`

    Otherwise, if you really need realsense instead of realsense2, you could clone the [repository](https://github.com/IntelRealSense/realsense-ros), choosing the "indigo-devel" branch, and build it with catkin. Though in this case you would need to build and install the librealsense binaries manually.
