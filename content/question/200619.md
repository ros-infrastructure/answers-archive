  body_markdown: "The ROS package `slam_gmapping`depends on another package `openslam_gmapping`.\
    \ As of this writing, if you are on melodic distro, you need to install these\
    \ packages from source since they are not released into melodic yet. For ROS packages\
    \ installing from source implies cloning their repositories in the `src` directory\
    \ of your workspace.\n\n    cd your_work_space/src\n    git clone https://github.com/ros-perception/slam_gmapping.git\n\
    \    git clone https://github.com/ros-perception/openslam_gmapping.git\n\n   \
    \ # [comment] navigate back to your_work_space directory\n    cd ..    \nNext,\
    \ Install missing dependencies if any:\n\n    \n    \n    rosdep install --from-paths\
    \ src --ignore-src\n\nNext: Build your project\n\n    catkin_make"
