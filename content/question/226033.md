  body_markdown: "The Gazebo plugin takes in the Twist message and turns it into a\
    \ virtual left motor and right motor command to make the simulated robot move\
    \ in the simulation. \n\nYour real robot code will need to take in the Twist message\
    \ and turn it into a real left motor and right motor command to make the real\
    \ robot move. The details of that really depends on your robot hardware. "
