I'm experiencing some trouble regarding the content of the topics of a TurtleBot3. 

The **setup**:

The TurtleBot is equipped with an OpenCR 1.0, LDS-01 and DYNAMIXEL XL430-W250-T (with the latest firmware). The TurtleBot is controlled by a Raspberry Pi 3 model B running the ROBOTIS disk image for ROS Kinetic. 
The **TurtleBot is set to be a ROS-HOST** and a **laptop** (running Ubuntu16, also with Kinetic) **is set as the ROS-MASTER**. 
Furthermore, **no firewall is present** on neither the laptop, Raspberry or the router. 

The **problem**:

A roscore is then started on the laptop and the turtlebot3_robot.launch is launched on the TurtleBot with no warnings. Running a rostopic list on the **laptop displays all the expected topics**. But when i run an **echo from the laptop, non of the topics contains any data**. However, **on the TurtleBot the topics contain the expected data**.
