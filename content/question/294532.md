    Yes, `colcon` is the new build tool replacing `ament_tools` as of the upcoming release ROS 2 Bouncy. You can find more information about it in the [design article](http://design.ros2.org/articles/build_tool.html).

    You will have to check / redo (part of) the instructions for setting up your machine which have been updated with steps to install `colcon` since you followed them.
