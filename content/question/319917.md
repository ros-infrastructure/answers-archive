  body_markdown: "You could take a look at the [ROS package generator](http://rosin-project.eu/tool/ros-package-generator)\
    \ created by Tecnalia as part of the [ROSIN project](http://rosin-project.eu/).\n\
    \nBased on something it calls an *interface specification* and a set of templates,\
    \ it generates what I believe would cover your bullets.\n\nFrom the readme:\n\n\
    > The following packages are about the automatic creation of ROS packages (so\
    \ far c++ and python).\n> \n> To do so the input needed are:\n> \n>  - A package\
    \ template: a template is created by a template Designer. It contains the list\
    \ of files to be automatically generated. The Developer just has to select the\
    \ template that best fits his needs.\n>  - An interface specification: a xml file\
    \ describing mainly the interface of the package to create, according to the template.\
    \ This file is to be filled by the Developer, using the interface proposed by\
    \ the template, according to the concrete needs of the package he is willing to\
    \ create"
