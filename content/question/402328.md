    By [this related question and its answer](https://answers.ros.org/question/303837/runtime-error-after-trying-to-set-parameters-in-ros2/):

    > The error `what(): Node has already
    > been added to an executor.` should
    > only occur if you add your node to an
    > `rclcpp::Executor` and/or pass it to
    > `rclcpp::spin` more than once

    You have both `rclcpp::spin` and `rclcpp::spin_until_future_complete` in your code here.

    There is a possibility for a race condition too, based on:

    - https://github.com/ros2/rclcpp/issues/206

    This thread there is quite helpful in recognizing the problem too, you should read it

  body_markdown: "I have managed to solve this issue.\n\nROS2 has defined new concepts\
    \ called **callback_groups** to enable calling of a service/action from within\
    \ a ROS2 callback. \nI have created a callback_group of type **Reentrant** as\
    \ shown below\n\n> **my_callback_group_** = this->create_callback_group(rclcpp::CallbackGroupType::**Reentrant**);\n\
    \nand then link the service_client to the above defined callback group\n\n> service_client_\
    \ = this->create_client<std_srvs::srv::Empty>(\"test_service\", rmw_qos_profile_services_default,\n\
    \                                                                **my_callback_group_**);\n\
    \nhttps://docs.ros.org/en/foxy/How-To-Guides/Using-callback-groups.html \n\nThe\
    \ link above provides a detailed explanation as to how this implementation can\
    \ be achieved! I hope this helps."
