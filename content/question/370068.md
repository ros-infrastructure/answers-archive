      In a bash script ? Technically yes it's possible. You can parse your output somehow, with awk for example and then publish your data with the `rostopic pub` command., for example like that : ``` $ rostopic pub /topic package/msg_type '{x: 1, y: 2, c: a, type: string}' ``` (Example from [here](https://answers.ros.org/question/218818/how-to-publish-a-ros-msg-on-linux-terminal/)). But I wouldn't call this a clean way to do it. Making a python node would be way better.
