    It depends a bit on what you mean exactly by *rosgraph output*, but if you're after the kind of diagram that `rqt_graph` shows, then that would be basically a rendering of a `dot` graph.

    I'm not aware of any stand-alone tools that will render those for you, but a good starting point would be the code in `rqt_graph`, specifically [RosGraph._update_rosgraph()](https://github.com/ros-visualization/rqt_graph/blob/90117a0b04c99d1baf4589dc97751fa3487883a4/src/rqt_graph/ros_graph.py#L208-L226), which calls [RosGraph._generate_dotcode()](https://github.com/ros-visualization/rqt_graph/blob/90117a0b04c99d1baf4589dc97751fa3487883a4/src/rqt_graph/ros_graph.py#L233-L260) which uses [RosGraphDotcodeGenerator.generate_dotgraph(..)](https://github.com/ros-visualization/rqt_graph/blob/90117a0b04c99d1baf4589dc97751fa3487883a4/src/rqt_graph/dotcode.py#L423-L439) to generate the actual `dot` markup.
