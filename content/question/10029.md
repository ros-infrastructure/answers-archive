    You should not use a static map from one source and the transformation from another. They don't match this way.
    If you want to use a static map from the map server, use localization.
    This tutorial shows how to use it: [Using custom maps](http://www.ros.org/wiki/pr2_simulator/Tutorials/UsingCustomMapForSimulation)
