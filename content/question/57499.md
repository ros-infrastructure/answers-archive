    As described on the [Ubuntu install page](http://www.ros.org/wiki/groovy/Installation/Ubuntu#Installation-1), released ROS packages are built to debs with the ROS distribution (ros-groovy-) and stack name for dry packages, or package name for wet packages.

    For example, if you were interested in installing [teleop_twist_keyboard](http://ros.org/wiki/teleop_twist_keyboard) for Groovy, you could visit the wiki, observe that it is a dry package inside of the brown_remotelab stack, and install the ros-groovy-brown-remotelab package.
