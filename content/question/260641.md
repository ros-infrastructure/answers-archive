  body_markdown: "System-wide libraries are resolved by `CMake` relative to  `/usr/local/lib`\
    \ if you are using a 32-bit architecture machine or `/usr/local/lib64` if you\
    \ are on a 64-bit architecture. \n\nSomething seems wrong with the location where\
    \ your library is domiciled. Either fix this by copying the appropriate library\
    \ file over to `usr/local/lib` or manually tell `cmake` to look in `usr/local/include`.\
    \ The first option is more standard and I would choose that over the latter."
