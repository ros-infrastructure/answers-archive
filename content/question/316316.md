  body_markdown: "    int main(int argc, char** argv)\n    {\n      [..]\n\n     \
    \ std::string urdfName;\n    \n      urdf::Model urdfModel;\n      urdfModel.initParam(urdfName)\n\
    \n      [..]\n    }\n\nThe problem here is this line: `urdfModel.initParam(urdfName)`\
    \ (note also the missing semi-colon).\n\nFrom the [documentation](http://docs.ros.org/melodic/api/urdf/html/classurdf_1_1Model.html#a0e3b0a0974fb948dd9228c50c5d6783c):\n\
    \n> Load `Model` given the name of a parameter on the parameter server.\n\nThe\
    \ \"name of a parameter\" is passed into this function with the `param` argument,\
    \ which you are passing `urdfName`.\n\nBut you don't initialise `urdfName` with\
    \ an actual name, so it's just an empty string.\n\nI would've expected `urdf::Model::initParam(..)`\
    \ to complain about that, but it doesn't seem to do that.\n\nYou probably want\
    \ to do something like this:\n\n    urdfModel.initParam(\"robot_description\"\
    );\n\nYou don't need `urdfName`, you can just pass in a string directly.\n"
