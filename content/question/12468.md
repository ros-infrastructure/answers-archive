  body_markdown: "http://wiki.ros.org/urdf/XML/joint\nYou need to set the hard limits\
    \ in the urdf file, and make sure the joint is not set to continuous.\n\nIt sounds\
    \ like you only have \"safety limits\" set, or the limits for the ros_controller\
    \ set and not the physical limits.\n\nSee this example from https://bitbucket.org/osrf/drcsim/src/583228ebd72677c36a393b3260f0c5f0bc7b0f87/atlas_description/urdf/atlas_v5.urdf?at=default&fileviewer=file-view-default\n\
    \nNote the difference between lower/upper hard limits of revolute joint, and the\
    \ soft_*_limits.\n\n  \n\n     <joint name=\"back_bkx\" type=\"revolute\">\n \
    \   <origin rpy=\"0 0 0\" xyz=\"0 0 0.05\"/>\n    <axis xyz=\"1 0 0\"/>\n    <parent\
    \ link=\"mtorso\"/>\n    <child link=\"utorso\"/>\n    <dynamics damping=\"0.1\"\
    \ friction=\"0\"/>\n    <limit effort=\"300\" lower=\"-0.523599\" upper=\"0.523599\"\
    \ velocity=\"12\"/>\n    <safety_controller k_position=\"100\" k_velocity=\"100\"\
    \ soft_lower_limit=\"-10.5236\" soft_upper_limit=\"10.5236\"/>\n  </joint>\n\n\
    \n "
