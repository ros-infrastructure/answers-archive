    Is there any particular reason you wouldn't like to create your own message type? Create a file, say `Yaw_Alt.msg` in `msg` folder of your package and fill it with:

        time time
        float32 yaw
        float32 altBaro

    Then read [here](http://www.ros.org/wiki/ROS/Tutorials/DefiningCustomMessages) for further instructions. Generally you'll need to add / uncomment `genmsg()` in your `CMakeLists.txt`. The message will be generated when you call make (rosmake) on the package. You will find generated header files under `msg_gen`.
