  body_markdown: "Hello, you should have a laser link which represents the origin\
    \ of your laser hardware attached to base_link or etc.. in your model such as\
    \ in turtlebot 's urdf \n\n        <joint name=\"laser_joint\" type=\"fixed\"\
    >\n        <origin xyz=\"-0.065 0 0.075\" rpy=\"0 0 0\" />\n        <parent link=\"\
    base_link\" />\n        <child link=\"laser\" />\n      </joint>\n\n  <link name=\"\
    laser\">\n    <visual>\n      <geometry>\n        <box size=\"0.02 0.035 0.002\"\
    \ />\n      </geometry>\n      <material name=\"Green\" />\n    </visual>\n  \
    \  <inertial>\n      <mass value=\"0.001\" />\n      <origin xyz=\"0 0 0\" />\n\
    \      <inertia ixx=\"0.0001\" ixy=\"0.0\" ixz=\"0.0\"\n        iyy=\"0.0001\"\
    \ iyz=\"0.0\"\n        izz=\"0.0001\" />\n    </inertial>\n  </link>\n\nthen in\
    \ order to use this laser scanner in gazebo you should add laser scanner plugin\
    \ \n\n        <xacro:macro name=\"turtlebot_sim_laser\">\n      <gazebo reference=\"\
    laser\">\n        <sensor:ray name=\"laser\">\n          <rayCount>180</rayCount>\n\
    \          <rangeCount>180</rangeCount>\n          <laserCount>1</laserCount>\n\
    \          \n          <origin>0.0 0.0 0.0</origin>\n          <displayRays>false</displayRays>\n\
    \          \n          <minAngle>-130</minAngle>\n          <maxAngle>130</maxAngle>\n\
    \          \n          <minRange>0.08</minRange>\n          <maxRange>10.0</maxRange>\n\
    \          <resRange>0.01</resRange>\n          <updateRate>20</updateRate>\n\
    \          <controller:gazebo_ros_laser name=\"gazebo_ros_laser_controller\" plugin=\"\
    libgazebo_ros_laser.so\">\n    \t<gaussianNoise>0.005</gaussianNoise>\n    \t\
    <alwaysOn>true</alwaysOn>\n    \t<updateRate>20</updateRate>\n    \t<topicName>scan</topicName>\n\
    \    \t<frameName>laser</frameName>\n    \t<interface:laser name=\"gazebo_ros_laser_iface\"\
    \ />\n          </controller:gazebo_ros_laser>\n        </sensor:ray>\n      </gazebo>\n\
    \    </xacro:macro>"
