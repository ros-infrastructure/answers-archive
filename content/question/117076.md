Browsing ROS software is interesting but it is not clear which programs will be useful for my unique robot which is not on your list.  A flowchart would help me understand which programs and versions are most suitable for my robot and which must be created.  If all your software addresses wheeled robots for example, then other software must be developed for humanoids. If all of your vision system software addresses a specific camera for example, then I may need to modify it or find other open source software to operate generic cameras.  If your vision system recognizes landmarks based on a GPS Lat/Lon location does it also place visible transients like people and their projected paths on the same grid?  Similarly helpful documentation could guide a robot developer to useful software starting points and identify needs for further development.

One page of documentation says ROS is not a real time control system but Willow Garage has its own real time system for a specific robot.  Yet it appears Willow Garage is closed. Is a real time system needed for a humanoid?  Other documentation mentions "localhost" does that mean an internet connection is required or can the robot operate in stand alone mode?
