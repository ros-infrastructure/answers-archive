  body_markdown: "So, the topic `/cmd_vel` topic should have the message type [Twist](http://www.ros.org/doc/api/geometry_msgs/html/msg/Twist.html)\n\
    \nLooking at the message description, we can see that each incoming message should\
    \ have a `linear` component, for the (x,y,z) velocities, and an angular component\
    \ for the angular rate about the (x,y,z) axes.\n\nI'm going to give you some example\
    \ code in Python, but this could just as easily be done in C++.\n\n    #!/usr/bin/env\
    \ python\n    import roslib; roslib.load_manifest('YOUR_PACKAGE_NAME_HERE')\n\
    \    import rospy\n    import tf.transformations\n    from geometry_msgs.msg import\
    \ Twist\n\n    def callback(msg):\n        rospy.loginfo(\"Received a /cmd_vel\
    \ message!\")\n        rospy.loginfo(\"Linear Components: [%f, %f, %f]\"%(msg.linear.x,\
    \ msg.linear.y, msg.linear.z))\n        rospy.loginfo(\"Angular Components: [%f,\
    \ %f, %f]\"%(msg.angular.x, msg.angular.y, msg.angular.z))\n\n        # Do velocity\
    \ processing here:\n        # Use the kinematics of your robot to map linear and\
    \ angular velocities into motor commands\n\n        v_l = ...\n        v_r = ...\n\
    \n        # Then set your wheel speeds (using wheel_left and wheel_right as examples)\n\
    \        wheel_left.set_speed(v_l)\n        wheel_right.set_speed(v_r)\n\n   \
    \ def listener():\n        rospy.init_node('cmd_vel_listener')\n        rospy.Subscriber(\"\
    /cmd_vel\", Twist, callback)\n        rospy.spin()\n    \n    if __name__ == '__main__':\n\
    \        listener()\n\nIn this example, we create a node called `cmd_vel_listener`\
    \ that subscribes to the `/cmd_vel` topic.  We can then create a callback function\
    \ (called `callback`), which accepts the message as a parameter `msg`.\n\nFrom\
    \ here, it is as simple as reading the named fields from the message, and using\
    \ that data in whatever way that you want in your application.\n\nHope this helps."
