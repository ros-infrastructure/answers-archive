    \nAlso:\n\n>     add_executable(opencv_test2 script/opencv_test2.py)\n\nYou can\
    \ (and should) use a `CMakeLists.txt` for ROS Python nodes, but you don't use\
    \ `add_executable(..)` then. See [catkin 0.6.14 documentation \xBB How to do common\
    \ tasks \xBB Package format 2 (recommended) \xBB Installing Python scripts and\
    \ modules](http://docs.ros.org/indigo/api/catkin/html/howto/format2/installing_python.html)\
    \ for more info on using `catkin` with Python.\n\nNote that you don't need to\
    \ install your script / node in order to be able to `rosrun` or `roslaunch` it.\
    \ You only need a minimal `CMakeLists.txt` to build your package, `catkin` will\
    \ do the rest.\n\n---\n\nEdit:\n\n> i revised my cmakelist.txt\n\n> but occur\
    \ the error that ' cannot speify link libraries for target \" scripts/opencv_test1.py\"\
    \ which is not built by this project.\n\nHave you read the documentation I linked?\
    \ You **cannot link Python nodes to anything** using `target_link_libraries(..)`.\
    \ That is for C/C++/other compiled languages only. There is nothing to link with\
    \ Python.\n\nAlso: `include_directories(..)` is useless with Python nodes. The\
    \ `PYTHONPATH` is setup by sourcing the correct `setup.(bash|sh|zsh)` after building\
    \ your workspace.\n\nA minimal `CMakeLists.txt` for a Python only package is probably\
    \ something like:\n\n    cmake_minimum_required(VERSION 2.8.3)\n    project(your_project_name)\n\
    \    \n    find_package(catkin REQUIRED)\n    \n    # depending on whether you\
