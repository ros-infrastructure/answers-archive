  body_markdown: "This filtering would be fairly straightforward to implement in your\
    \ own node, or in a [custom pcl-ros::Filter](http://wiki.ros.org/pcl_ros/Tutorials/filters#Developers)\
    \ if you want to extend that framework. I've modified the voxel-grid example callback\
    \ so that it will filter out points within 0.5 units of the origin to get you\
    \ started.\n\nHope this helps.\n\n...\n\n    void \n    cloud_cb (const sensor_msgs::PointCloud2ConstPtr&\
    \ cloud_msg)\n    {\n      float depthThreshold = 0.5;\n      float threshold2\
    \ = depthThreshold*depthThreshold;\n    \n      // Container for original & filtered\
    \ data\n      pcl::PCLPointCloud2* cloud = new pcl::PCLPointCloud2; \n      pcl::PCLPointCloud2ConstPtr\
    \ cloudPtr(cloud);\n      pcl::PCLPointCloud2 cloud_filtered;\n    \n      //\
    \ Convert to PCL data type\n      pcl_conversions::toPCL(*cloud_msg, *cloud);\n\
    \    \n      // Perform the actual filtering\n      for (int p=0; p<cloud->points.size();\
    \ ++p)\n      {\n        // find the squared distance from the origin.\n     \
    \   float pointDepth2 = (cloud->points[p].x * cloud->points[p].x) +\n        \
    \                   (cloud->points[p].y * cloud->points[p].y) + \n           \
    \                (cloud->points[p].z * cloud->points[p].z));\n    \n        //\
    \ remove point if it's within the threshold range\n        if (pointDepth2 < threshold2)\n\
    \        {\n          cloud->points[p] = cloud->points[cloud->points.size()-1];\n\
    \          cloud->points.resize(cloud->points.size()-1);\n          --p;\n   \
    \     }\n      }\n    \n      pcl::VoxelGrid<pcl::PCLPointCloud2> sor;\n     \
    \ sor.setInputCloud (cloudPtr);\n      sor.setLeafSize (0.1, 0.1, 0.1);\n    \
    \  sor.filter (cloud_filtered);\n    \n      // Convert to ROS data type\n   \
    \   sensor_msgs::PointCloud2 output;\n      pcl_conversions::fromPCL(cloud_filtered,\
    \ output);\n    \n      // Publish the data\n      pub.publish (output);\n   \
    \ }\n\n"
