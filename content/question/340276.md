  body_markdown: "If I understand [the `message_filter`](https://wiki.ros.org/message_filter)\
    \ correctly, the messages that you're using need to have a header because\n\n\
    > [The `TimeSequencer` filter](https://wiki.ros.org/message_filters#Time_Sequencer)\
    \ guarantees that messages will be called in temporal order according to their\
    \ header's timestamp.\n\nA [`Float32` message](https://docs.ros.org/api/std_msgs/html/msg/Float32.html)\
    \ only has a `data` field and no header. Since it's expecting a header where there\
    \ isn't one, it throws an error. You'll need to use a message type that has a\
    \ header.\n\nEdit:\n\nAlso look into using [an `ApproximateTimeSynchronizer`](https://wiki.ros.org/message_filters#ApproximateTime_Policy)\
    \ which \n\n> uses current ROS time in place of any missing `header.stamp` field:"
