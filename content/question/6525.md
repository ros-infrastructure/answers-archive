    \n`<pose>1 2 3 0 0.785 1.571</pose>` "

  body_markdown: "Ahh, the current method to calculate the pose of each link is cumbersome.\
    \ The pose of each model is in the global frame, and the pose of each link is\
    \ in the model frame. You currently have to calculate the poses by hand. \n\n\
    Here is an [issue](https://bitbucket.org/osrf/sdformat/issue/66) to make pose\
    \ calculations a bit easier."
