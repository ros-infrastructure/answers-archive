    It looks like [rc_usefulincludes.h](https://github.com/StrawsonDesign/Robotics_Cape_Installer/blob/1dfcf302a5f76e68dc005673d411002181b73ce9/libraries/rc_usefulincludes.h#L58) redefines the `min` macro, and this is incompatible with `std::min` that is defined by the C++ standard library: http://www.cplusplus.com/reference/algorithm/min/ . When other STL libraries try to call the standard 3-argument version of `min`, they fail. (This is valid even for C++98, so switching C++ versions will result in the same incompatibility)

    You should probably either file a bug about this with that library, or fix it yourself by removing that line from that header, and updating the library to use `std::min` instead.
