  body_markdown: "Hi, \n\nYes it is now available on ROS. It is mainly used for more\
    \ robust graph optimization and loop closure detection. See this post: https://github.com/introlab/rtabmap/wiki/Robust-Graph-Optimization#multi-session\n\
    \nThe input gps topic to `rtabmap` node is called `/rtabmap/gps/fix`, which is\
    \ a [sensor_msgs::NavSatFix](http://docs.ros.org/melodic/api/sensor_msgs/html/msg/NavSatFix.html)\
    \ type.\n\nNote that rtabmap >=0.18.1 is required. Right now, only binaries in\
    \ ROS melodic have the option (kinetic will be also updated soon), otherwise rtabmap\
    \ should be built [from source](https://github.com/introlab/rtabmap_ros#build-from-source).\n\
    \ncheers,<br/>\nMathieu"
