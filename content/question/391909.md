Hello everyone.

**Problem description**

 - When I run the `action_tutorials_cpp` example on a machine of my lab's network (Machine_1), everything works well for the first client/server interaction, but when I run the client a second time, the server terminates after the reception of the goal request:

`[INFO] [1638266057.197163364] [fibonacci_action_server]: Received goal request with order 10
terminate called after throwing an instance of 'std::runtime_error'
  what():  Failed to accept new goal`

 - If I keep the server running on Machine_1 and move the client execution to another machine in the net (Machine_2), then everything works just fine.

 - If I run the server from `action_tutorials_cpp` and the client from `action_tutorials_py`, all in Machine_1, then again, everything works just fine.

**Question**

Has anyone ever experienced similar problems? Any hints on what may cause this behavior or on how to investigate it further?

**Config details**

Here are some config details for Machine_1: Ubuntu 20.04.3 LTS, kernel 5.11.0-40-generic x86_64. Tested with both `ROS_DISTRO=foxy` and `ROS_DISTRO=galactic`, both built from sources (for both distributions the other ROS envs are `ROS_VERSION=2`, `ROS_PYTHON_VERSION=3`, `ROS_LOCALHOST_ONLY=0`).

Do not hesitate to ask for additional details if you think it may help.
