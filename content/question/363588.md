  body_markdown: "Hello! Yes, you need set up an odometry and tf to do mapping with\
    \ gmapping. Your tf tree have to look like odom->base_link->laser. You have to\
    \ make launch files, for the rplidar node specifying the frame and the topic,\
    \ for the gmapping node also you have to specify the topic and the frames of the\
    \ laser and the odom. In this link you have a guide to obtain the best results\
    \ from a rplidar on gmapping http://geduino.blogspot.com/2015/04/gmapping-and-rplidar.html.\
    \ For setting up the tf you have to make a tf broadcaster that make the tf link\
    \ from base_link to laser, an example code in c++:\n\n    #include <ros/ros.h>\n\
    \    #include <tf/transform_broadcaster.h>\n    int main(int argc, char** argv){\n\
    \    ros::init(argc, argv, \"tina_tf_publisher\");\n    ros::NodeHandle n;\n\n\
    \    ros::Rate r(100);\n\n    tf::TransformBroadcaster broadcaster;\n\n    while(n.ok()){\n\
    \    broadcaster.sendTransform(\n      tf::StampedTransform(\n        tf::Transform(tf::Quaternion(0,\
    \ 0, 0, 1), tf::Vector3(0.25, 0.0, 0.2)),\n        ros::Time::now(),\"base_link\"\
    , \"laser\"));\n    r.sleep();\n    }\n    } \nAlso you have a program to compute\
    \ odom, in our robot we have a topic from an arduino that publish the velocity\
    \ and from that we have the odom, the code in python is: \n\n \n\n    #!/usr/bin/env\
    \ python\n\n    import math\n    from math import sin, cos, pi\n    import rospy\n\
    \    import tf\n    from nav_msgs.msg  import Odometry\n    from std_msgs.msg\
    \  import Float64\n    from geometry_msgs.msg import Twist, Point, Quaternion,\
    \ Vector3, Pose\n    v_x = 0\n    v_y = 0\n    vth = 0\n\n\n    def callback_x(msg):\n\
    \       global v_x\n       v_x = msg.data\n    def callback_y(msg):\n       global\
    \ v_y\n       v_y = msg.data\n\n\n    rospy.init_node('odometry')\n    rospy.Subscriber('velo_x',\
    \ Float64, callback_x)\n    rospy.Subscriber('velo_y', Float64, callback_y)\n\
    \    odom_pub = rospy.Publisher(\"odom\", Odometry, queue_size=50)\n    odom_broadcaster\
    \ = tf.TransformBroadcaster()  \n    x = 0.0\n    y = 0.0\n    th = 0.0\n    vx\
    \ = (v_x+v_y)/2\n    vy = 0.0\n    vth = (v_x-v_y)/0.5\n    current_time = rospy.Time.now()\n\
    \    last_time = rospy.Time.now()\n    r = rospy.Rate(10.0)\n    while not rospy.is_shutdown():\n\
    \       vx = (v_x+v_y)/2\n       vy = 0.0\n       vth = (v_x-v_y)/0.5\n\n    \
    \   current_time = rospy.Time.now()\n       dt = (current_time - last_time).to_sec()\n\
    \       delta_x = (vx * cos(th))*dt\n       delta_y = (vx * sin(th))*dt\n    \
    \   delta_th = vth * dt\n\n        x += delta_x\n        y += delta_y\n      \
    \  th += delta_th\n        \n       odom_quat = tf.transformations.quaternion_from_euler(0,0,th)\n\
    \n       odom_broadcaster.sendTransform((x,y,0.),odom_quat,current_time,\"base_link\"\
    ,\"odom\")\n\n       odom = Odometry()\n       odom.header.stamp = current_time\n\
    \       odom.header.frame_id = \"odom\"\n\n       odom.pose.pose = Pose(Point(x,y,0.),Quaternion(*odom_quat))\n\
    \n       odom.child_frame_id = \"base_link\"\n       odom.twist.twist = Twist(Vector3(vx,vy,0),\
    \ Vector3(0,0,vth))\n\n       odom_pub.publish(odom)\n\n       last_time = current_time\n\
    \       r.sleep()\n\nI hope that it helps!\n\n   \n    \n"
