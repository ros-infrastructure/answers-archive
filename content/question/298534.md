  body_markdown: "I solved the problem by following the solution given [here](https://askubuntu.com/questions/909024/how-to-run-script-in-rc-local).\
    \ \n\nI used to call `roslaunch` in my **rc.local** file as\n\n`su ubuntu -c \"\
    source /home/nvidia/catkin_ws/devel/setup.sh ; roslaunch my_ros my_launch_file.launch\
    \  > /dev/null 2>&1 &\"`\n\nNow, I replaced it with `/home/nvidia/auto.sh` where\
    \ content **auto.sh** file is\n\n    #!/bin/bash    \n    cd $home    \n    source\
    \ /home/nvidia/catkin_ws/devel/setup.bash    \n    roslaunch my_ros my_launch_file.launch\
    \    \n    exit 0\n\nRestarting the Jetson after making the **auto.sh** file executable\
    \ with the command `$ sudo chmod u+x /home/username/auto.sh`, I managed to save\
    \ the image files. They are read-only though it not a problem for me. \n\n\n\n\
