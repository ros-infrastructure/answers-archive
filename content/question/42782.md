    The [map_name].yaml file only contains metadata about the map, which is given as a separate [map_name].pgm image file. You can create maps by using a SLAM algorithm and saving it using the map_saver tool. In principle, you can also edit maps by editing .pgm files with a graphics editing program of your choice.

    Most relevant information can be found on the [map_server](http://ros.org/wiki/map_server) wiki page.

    How to generate maps with SLAM algorithms is described [here (gmapping)](http://www.ros.org/wiki/slam_gmapping/Tutorials/MappingFromLoggedData) and [here (hector_mapping)](http://www.ros.org/wiki/hector_slam/Tutorials/MappingUsingLoggedData).
