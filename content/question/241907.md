  body_markdown: "AFAIK, you cannot do this via `catkin_make`. You can however check\
    \ with `rosdep check <PACKAGE_NAME>` if all packages are installed, or install\
    \ them via `rosdep install <PACKAGE_NAME>`.\nThe `-v` flag turns on verbose output.\n\
    \nNote, however, that in the package.xml you need to have the respective rosdep\
    \ keys, which are defined (here)[https://github.com/ros/rosdistro/blob/master/rosdep/python.yaml].\
    \ Many of the modules you specified are available in the python [standard library](https://docs.python.org/2/library/),\
    \ thus you probably would not need to specify those. \n\nFor the `requests` module,\
    \ you have to specify [`python-requests`](https://github.com/ros/rosdistro/blob/master/rosdep/python.yaml#L1778-L1802)\
    \ which gets resolved via `rosdep` for the different distributions."
