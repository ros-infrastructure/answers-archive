  body_markdown: "Hi @muttidrhummer!\n\nI have created a [video](https://youtu.be/V7OMyxxhbVM)\
    \ that answer exactly this question.\n\nSummarizing, this can be accomplished\
    \  by loading a URDF file, parsing it and calling the [getName()](https://github.com/ros/urdfdom_headers/blob/master/urdf_model/include/urdf_model/model.h#L73)\
    \ method of the C++ Urdf model.\n\nTo see how to load and parse a URDF file, you\
    \ can follow the [Parse a urdf file](http://wiki.ros.org/urdf/Tutorials/Parse%20a%20urdf%20file)\
    \ tutorial.\n\nAfter you create your `parser.cpp`, before the `return 0;` you\
    \ should add \n\n`ROS_INFO(\"The robot name is: %s\", model.getName().c_str());`\
    \ \n\nto print the name of the robot on the URDF file,  as we can see on the code\
    \ below:\n\n\n    #include <urdf/model.h>\n    #include \"ros/ros.h\"\n    \n\
    \    int main(int argc, char** argv){\n      ros::init(argc, argv, \"my_parser\"\
    );\n      if (argc != 2){\n        ROS_ERROR(\"Need a urdf file as argument\"\
    );\n        return -1;\n      }\n      std::string urdf_file = argv[1];\n    \n\
    \      urdf::Model model;\n      if (!model.initFile(urdf_file)){\n        ROS_ERROR(\"\
    Failed to parse urdf file\");\n        return -1;\n      }\n      ROS_INFO(\"\
    Successfully parsed urdf file\");\n      ROS_INFO(\"The robot name is: %s\", model.getName().c_str());\n\
    \      return 0;\n    }\n\nAfter compile the code and generate the executable\
    \ called `parser` following the [Parse a urdf file](http://wiki.ros.org/urdf/Tutorials/Parse%20a%20urdf%20file)\
    \ tutorial, you can call it with the path of the URDF file as argument.\n\nSomething\
    \ like:\n`rosrun your_package_name parser /path/to/your/file.urdf`\n\nIf you still\
    \ have any doubt, just check the [video](https://youtu.be/V7OMyxxhbVM).\n\n\n"
