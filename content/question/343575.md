    `colcon` doesn't install any dependencies (see the [docs](https://colcon.readthedocs.io/en/released/developer/design.html#explicitly-out-of-scope)). The expectations is that you have installed all necessary dependencies before you try to build a package (e.g. using `rosdep`).
