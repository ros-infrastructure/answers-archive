  body_markdown: "I finally ended up setting the parameter by using a launch file\
    \ for my node.\n\nExample:\n\nLaunch file:\n\n    <launch>\n        <rosparam\
    \ param=\"x_vector\">[1.0, 2.0,\n    3.0]</rosparam>\n        <node name=\"my_node\"\
    \ pkg=\"my_package\" type=\"my_node\" />\n    </launch>\n\nThen in your node,\
    \ get the vector like this:\n\n    std::vector<double> x_vec;\n    std::vector<double>\
    \ x_vec_default = {1.0, 0.5, 0.5, 1.0};\n    \n    n.param<std::vector<double>\
    \ >(\"x_vector\", x_vec, x_vec_default);\n\nAnd `x_vec` will hold the values given\
    \ in the launch file, or the contents in `x_vec_default` if the `x_vector` is\
    \ not available as a parameter (for example if launching the node without the\
    \ launch file)."
