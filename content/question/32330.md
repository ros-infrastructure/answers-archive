    I guess you didn't install openrave. For electric, there doesn't seem to be a debian package containing the openrave ros package. There is a ros package [here] though (http://ros.org/wiki/openrave).

    Normally, openrave doesn't really need to be a ros package to be used in your ros nodes. You can remove the dependency on openrave in manifest.xml and install it from a PPA as explained [here](http://openrave.programmingvision.com/en/main/install.html#install).

    **Edit**: According to [this](http://openrave.programmingvision.com/en/coreapihtml/writing_plugins.html) page you need to add something like the following to your ROS package's CMakeLists.txt:

        find_package(OpenRAVE REQUIRED)
        include_directories(${OpenRAVE_INCLUDE_DIRS})
        link_directories(${OpenRAVE_LIBRARY_DIRS})
