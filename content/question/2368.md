    In atlas\_utils/scripts, there are several scripts that invoke gazebo with plugins (for example [run_gazebo](https://bitbucket.org/osrf/drcsim/src/bc8a56f09eff03fc79f909a9f67467bc23a0dd3d/ros/atlas_utils/scripts/run_gazebo?at=default) calls `gazebo -s libgazebo_ros_api_plugin.so`. For the moment, you can edit these scripts, but there is a better fix in the works in [drcsim pull request #198](https://bitbucket.org/osrf/drcsim/pull-request/198).
