  body_markdown: "First build and install the Ogre version you want (1.8 in this case).\
    \ You can use cmake-gui to specify the install locations. Or if you don't, it\
    \ will probably go into /usr/lib.\n\nThen make sure the you have the .pc files\
    \ for Ogre (these files can be used to tell gazebo through cmake modules where\
    \ to find the Ogre installation). And finally make sure the location of these\
    \ .pc files is included in the PKG_CONFIG_PATH env variable or set it during your\
    \ cmake call. \n\n "
