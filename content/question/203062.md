  body_markdown: |-
    Per default, octomap only cares about the geometric information, not the additional field like intensity or rgb data that is contained in some point clouds. There is functionality in Octomap for also using color information (see [here](http://answers.ros.org/question/45836/colored-octomaps/) for instance), but I think what you'll want is either prefiltering the cloud and throw out intensities you don't in your octomap, or using the Octomap API and update the octomap manually with more control over how the update is performed.
