  body_markdown: "Ros and std are C++ namespaces. These namespaces are comprised of\
    \ many different files. \n\nstd: The standard C++ library. When programers use\
    \ this line: \n\n    using namespace std;\n\nThey are stating that they are using\
    \ the standard namespace (allows you to use the variables without putting std::\
    \ in front of them). \n\nFor example: \n\n    std::cout<<\"Hello world!\";\n\n\
    \ \n\nbecomes: \n\n    cout<<\"Hello world!\";\n\nWhen mixing namespaces, it is\
    \ of bad practice to do the following: \n\n    using namespace std; \n    using\
    \ namespace ros;\n\nReason being, you may overload some methods you don't intend\
    \ to. You can read more about this [here](http://stackoverflow.com/questions/1452721/why-is-using-namespace-std-considered-a-bad-practice-in-c).\
    \ \n\n \n\n "
