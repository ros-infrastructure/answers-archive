  body_markdown: "I managed to avoid this error like this: I changed the lifetime\
    \ of the text marker to `lifetime=rospy.Duration()` (unlimited) and I publish\
    \ a marker that deletes the text marker (same namespace and id) right before I\
    \ publish the text. So at each iteration, whatever was sent in the previous iteration\
    \ is deleted and the new text is published. The delete marker looks like this:\n\
    \n    def delete_visible_faces(marker_publisher):\n        print \"delete_visible_faces\"\
    , '\\n'\n        marker_del_visible_faces = Marker(\n            ns='visible_faces',\n\
    \            type=Marker.TEXT_VIEW_FACING,\n            action=Marker.DELETE,\n\
    \            id=1,\n            pose=Pose(Point(0.0, 0.0, 0.0), Quaternion(0,\
    \ 0, 0, 1)),\n            scale=Vector3(0.1, 0.0, 0.0),\n            header=Header(frame_id='hokuyo_link'),\n\
    \            color=ColorRGBA(0.0, 0.0, 1.0, 0.8),\n            frame_locked=False,\
    \ \n            )\n        marker_publisher.publish(marker_del_visible_faces)\n\
    \nI don't know if that was the cause of the problem, but at least this makes my\
