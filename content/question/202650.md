  body_markdown: "The package [ros_arduino_bridge](http://wiki.ros.org/ros_arduino_bridge)\
    \ is probably what you are looking for if you want to combine Arduino and ROS.\
    \ See also related blogpost by the author [here](http://www.pirobot.org/blog/0027/).\
    \ \n\nAlso, I suggest picking up [ROS By Example - Volume 1](http://www.lulu.com/shop/r-patrick-goebel/ros-by-example-indigo-volume-1/ebook/product-22015937.html)\
    \ as a general introduction to ROS. While not focused on Arduino, it is the best\
    \ ROS introduction I know (and accidentally, is written by the same author as\
    \ ros_arduino_bridge).\n\nEDIT: \nI should also point out that ros_arduino_bridge\
    \ is basically a ROS driver for Arduino - it allows you to control your Arduino\
    \ board from within the ROS framework. You will still need an additional, higher-end\
    \ system to run the actual ROS nodes (Arduino hardware is not sufficiently powerful\
    \ for that).\n\n"
