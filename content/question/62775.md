    There is no `joystick` package currently defined for OSX. That's why you can't build the `joy` package.

    If there is an equivalent package for OSX, then you can [contribute the missing rosdep rules](http://ros.org/doc/independent/api/rosdep/html/contributing_rules.html) to fix this problem.

    Otherwise, you probably won't be able to use the `joy` package on your system.
