  body_markdown: " ROS and OpenCV are two seperate things, which in general do not\
    \ interfere. So yes, everything will work on ROS. \n\nThe only problem (I can\
    \ think of) that you might get is with the OpenCV version. If you install a ROS\
    \ package that depends on OpenCV 3, it might be hard to use OpenCV 2.x instead\
    \ (if you insist on using 2.x in your code)."
