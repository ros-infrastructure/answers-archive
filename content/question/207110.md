    It's not an answer but comment don't seem to work these days :s. Here are some leads to explore:

    Can you see move base in the list when you run <code>ls /opt/ros/indigo/lib/move_base/</code> ?<br>
    If not, this means that move base has not been properly installed. So try:
    <code>sudo apt-get install ros-indigo-move-base</code> <br>
    then you should see move base in /opt/ros/indigo/lib/move_base/
    If yes, run <code>rospack profile</code> to update you package list and then you can try to run your node move_base again.

    Hope this helps,
