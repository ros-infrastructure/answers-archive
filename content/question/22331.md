  body_markdown: "As far as I know, running Gazebo with ROS is little more complicated.\
    \ I have seen the projects generarly organized into 3 packages\n\n    - robot_description\n\
    \    - robot_gazebo\n    - robot_control\n\nYou would put your URDF robot description\
    \ into the `robot_description` package.\n\nDefinition of the gazebo world and\
    \ launching files would be inside `robot_gazebo` package.\n\nAnd the definition\
    \ of the controllers inside `robot_control` package.\n\n[This repository](https://github.com/ros-simulation/gazebo_ros_demos)\
    \ is a perfect example of how it should look like.\n\nWhen speaking specifically\
    \ about the project in the repository, to launch the thing you have to use ROS\
    \ command and launch the `robot_gazebo/launch/rrbot_world.launch'. You can change\
    \ the 'robot' (in my explanation) or 'rrbot' (in this repository) to the name\
    \ of your robot. \n\nThe launch command would be:\n\n    roslaunch robot_gazebo\
    \ rrbot_world.launch \n\nWhen you launch the gazebo this way, the gazebo_ros package\
    \ starts to publish gazebo messages onto ROS topics and you can send commands\
    \ through this gazebo_ros package inside Gazebo and control the robot in the simulation. "
