  body_markdown: "I had the same problem, using electric, and I finally solved it,\
    \ I can't tell exactly how, but I'll tell you the steps I followed\n\n1- Remove\
    \ everything in folder CMakeList and file CMakeCache.txt\n2- If you called on\
    \ the that package \"make eclipse-project\", then remove .cprojet and .project\
    \ files\n3- My dependancy in manifest.xml is as follows: \n<depend package=\"\
    roslib\"/>\n  <depend package=\"roscpp\"/>\n  <depend package=\"std_msgs\"/>\n\
    \  <depend package=\"eigen\" />\n  <depend package=\"pcl\"/>\n  <depend package=\"\
    pcl_ros\"/>\n  <depend package=\"geometry_msgs\"/>\n  <depend package=\"sensor_msgs\"\
    />\nand yes I know there are some redundancies, but maybe this is what helped\
    \ in my case\n\n4- After that call the following inside your package:\nrosmake\
    \ --pre-clean --rosdep-install\n\n5- Finally call:  cmake -G\"Eclipse CDT4 - Unix\
    \ Makefiles\"\n6- Then import the project into eclipse. In my case it worked\n\
    \nGood luck\n"
