  body_markdown: "After some digging, I found a patch for the melodic-devel branch\
    \ that is applicable to kinetic-devel too. The merge request for that patch is\
    \ [here](https://github.com/ros-planning/moveit_tutorials/pull/273), and the relevant\
    \ commit is [89f3257](https://github.com/ros-planning/moveit_tutorials/commit/89f3257b99a3c1aab55e21c2eb101f8b110f73ab).\
    \ From the command line, navigate to the `moveit_tutorials` package and run this\
    \ command:\n\n    git checkout kinetic-devel\n    git cherry-pick 89f3257\n\n\
    You might need to resolve a few minor conflicts depending on the state of your\
    \ working directory. It's probably a good idea to `git stash` your changes before\
    \ your start. Once you get the patch applied, run `catkin_make` on your workspace\
    \ and you should be good to go. \n\nNote that after the patch you now need to\
    \ run two launch scripts for this demo, in order:\n\n    roslaunch panda_moveit_config\
    \ demo.launch\n    roslaunch moveit_tutorials motion_planning_api_tutorial.launch\n\
    \nI have created a [pull request](https://github.com/ros-planning/moveit_tutorials/pull/320)\
    \ to officially backport this patch to the kinetic-devel branch."
