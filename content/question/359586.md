    The [comment on github has the answer](https://github.com/ros-infrastructure/rosdep/issues/772#issuecomment-668015914). Uninstall `python3-rosdep2`, and install `python3-rosdep` or `python-rosdep`. `python3-rosdep2` is an older version. See this question for more info.


    https://answers.ros.org/question/353082/missing-packages-after-installing-rosdep-based-on-python3-rosdep2-in-noetic/

        sudo apt-get purge python-rosdep2 python3-rosdep2
        sudo apt-get install python3-rosdep
