  body_markdown: "I found a \"reasonable\" way of doing this. **This method assumes\
    \ that you built ros2 using**  `colcon build --merge-install` but you can extrapolate\
    \ this logic in case you used `colcon build --symlink-install`, you only need\
    \ to modify the BUILD file for this.\n\n**1)** Register the ROS2 install folder\
    \ as a new_local_repository in the bazel WORKSPACE file by adding the following\
    \ lines (located in the main nvidia isaac folder):\n\n    new_local_repository(\n\
    \    name = \"ros2\",\n    path = \"(full path to the build folder) /ros2_foxy/install\"\
    ,\n    build_file = \"(full path to the build folder) /ros2_foxy/install/BUILD\"\
    ,\n)\n\n**2)** Add a BUILD file inside the ros2/install folder with the following\
    \ content: `https://gist.github.com/dHofmeister/698c787cab9622c89b1a97ea878afac9`\n\
    \n**3)** Add the depency of your isaac module to ros2:\n\n    isaac_cc_module(\
    \ ... deps = [\"@ros2//:ros2\"],)\n\n**4)** include the rclcpp library header\
    \ in your isaac_cc_module:\n\n    #include \"rclcpp/rclcpp.hpp\"\n    #include\
    \ \"geometry_msgs/msg/pose_stamped.hpp\"\n\n**4)** Make sure you disable rclcpp's\
    \ bind on the system SIGINT signal as it conflicts with isaac's sigint handler:\n\
    \n    int argc = 1;\n    char const *const argv[] ={ \"Bridge\" };\n    rclcpp::InitOptions\
    \ options{};\n    options.shutdown_on_sigint = false;\n    rclcpp::init(argc,\
    \ argv, options);\n    ros_node = std::make_shared<MinimalPublisher>();\n\nThis\
    \ code is implemented in the `::start()` function of your isaac_cc_module. make\
    \ sure you initialise the ros_node variable in the node header `std::shared_ptr<MinimalPublisher>\
    \ ros_node;`. \n\nYou now have the ros_node class nested in the isaac_node class\
    \ and can use them.\n   \n\n    void Bridge::tick() {\n        geometry_msgs::msg::PoseStamped\
    \ msg{};\n        ros_node->callback();\n        LOG_INFO(\"ping\");\n    }"
