  body_markdown: "Hello everyone,\n\n\nI'm coming back with a solution to the problem\
    \ mentioned in this post regarding the segmentation fault occurring randomly when\
    \ calling the function physics::Joint::Detach().\n\n\nAfter some investigation,\
    \ I realized that the segmentation fault occurred when the call to the Detach\
    \ function was done during an update of the physics engine. In this situation,\
    \ a joint that was present in the beginning of the iteration of the physics engine\
    \ is suddenly erased by the call to the Detach function, resulting in a segmentation\
    \ fault.\n\n\nTo avoid this situation, you can use a workaround that consists\
    \ in pushing the calls to the Detach function in a list and to execute effectively\
    \ those Detach just before the physics engine is updated. This can be done using\
    \ an event of type ConnectBeforePhysicsUpdate. We can hence link a callback function\
    \ 'OnUpdate' that executes the Detach that are stored in a list, if any, just\
    \ before the physics engine is updated.\nBy doing so, we make sure that a call\
    \ to Detach will no longer be executed during an update of the physics engine.\n\
    \n\nCode:\n-\n\nAdd the following variables in the constructor of your class:\n\
    \n    std::vector<fixedJoint> vect;\n    this->detach_vector = vect;\n    this->beforePhysicsUpdateConnection\
    \ = Event::Events::ConnectBeforePhysicsUpdate(std::bind(&YourClass::OnUpdate,\
    \ this));\n\nIn your function where you call Detach(), push back those calls in\
    \ the detach_vector\n\n    \n    bool YourClass::detach(std::string model1, std::string\
    \ link1,\n                                         std::string model2, std::string\
    \ link2)\n      {\n          // search for the instance of joint and do detach\n\
    \          fixedJoint j;\n          if(this->getJoint(model1, link1, model2, link2,\
    \ j)){\n              this->detach_vector.push_back(j);\n              ROS_INFO_STREAM(\"\
    Detach joint request pushed in the detach vector\");\n              return true;\n\
    \          }\n        return false;\n      }\n\n(the function getJoint just returns\
    \ the joint between the two links)\n\n\nCreate a callback function \"OnUpdate\"\
    \ that will be executed each time just before the physics engine is updated, and\
    \ where you effectively execute the call to Detach(), if there are any in the\
    \ detach_vector:\n\n\n    void YourClass::OnUpdate()\n      {\n        if(!this->detach_vector.empty())\n\
    \        {\n          ROS_INFO_STREAM(\"Received before physics update callback...\
    \ Detaching joints\");\n          std::vector<fixedJoint>::iterator it;\n    \
    \      it = this->detach_vector.begin();\n          fixedJoint j;\n          while\
    \ (it != this->detach_vector.end())\n          {\n            j = *it;\n     \
    \       j.joint->Detach();\n            ROS_INFO_STREAM(\"Joint detached !\");\n\
    \            ++it;\n          }\n          detach_vector.clear();\n        }\n\
    \      }\n\nHope this can help.\n\nBest regards.\n\n\n\n\n"
