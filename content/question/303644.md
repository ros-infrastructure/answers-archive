  body_markdown: "I've dealt with the same issue; I ended up using the occupancy_grid_utils\
    \ library to calculate the cost of the cells inscribed in the footprint.\n\n \
    \   #include \"occupancy_grid_utils/coordinate_conversions.h\"\n    #include \"\
    occupancy_grid_utils/geometry.h\"\n\n    namespace ogu = occupancy_grid_utils;\n\
    \    namespace gm = geometry_msgs;\n    namespace nm = nav_msgs;\n\n    bool isValidPosition(const\
    \ gm::Polygon& oriented_footprint, const nm::OccupancyGrid& occupancy_grid,\n\
    \                         const double grid_cost_cuttoff_p)\n    {\n      try\n\
    \      {\n        auto cells = ogu::cellsInConvexPolygon(occupancy_grid.info,\
    \ oriented_footprint);\n        for (auto& cell : cells)\n        {\n        \
    \  auto grid_idx = ogu::cellIndex(occupancy_grid.info, cell);\n          auto\
    \ occupied_p = occupancy_grid.data[grid_idx];\n          if (occupied_p >= grid_cost_cuttoff_p)\n\
    \            return false;\n        }\n        return true;\n      }\n      catch\
    \ (ogu::CellOutOfBoundsException e)\n      {\n        ROS_DEBUG(\"Cell out of\
    \ bounds %s\", e.what());\n      }\n      catch (ogu::GridUtilsException e)\n\
    \      {\n        ROS_ERROR(\"Error validating pose %s\", e.what());\n      }\n\
    \      return false;\n    }\n\nNote I used \n\n    costmap2d::transformFootprint()\n\
    \nto get the oriented footprint"
