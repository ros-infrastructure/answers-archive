    \n\n   void \tInsertModelFile (const std::string &_sdfFilename)\n \n   void \t\
    InsertModelSDF (const sdf::SDF &_sdf)\n \n   void \tInsertModelString (const std::string\
    \ &_sdfString)\n\n\n\nSo the easiest way to implement this would be to write a\
    \ world plugin(or access the wolrd object from an existing plugin). And use one\
    \ of those methods. I'm not sure if InsertModelFile needs an .sdf or .model file.\
    \ But the API says its sdf... If you can't load the sdf directly read it from\
