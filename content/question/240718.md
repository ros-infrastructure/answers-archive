  body_markdown: "You can not install indigo on Ubuntu 16.04. I had a similar problem\
    \ in which I had to downgrade to indigo from kinetic. However, I found out that\
    \ ROS Indigo ONLY supports Saucy (13.10) and Trusty (14.04) for Debian packages.\
    \ . So I got it from here.\n\n> http://releases.ubuntu.com/14.04/\n\nI had Ubuntu\
    \ 16.04 with dual boot with Windows 10. As there was no other way to downgrade\
    \ Ubuntu 16.04 to 14.04, I had to erase ubuntu 16.04 and install a fresh Ubuntu\
    \ 14.04. \nAfter that I installed Indigo>\nAnd everything was working well :)\n\
    \nSo to answer your question, you have to install Ubuntu 14.04 to get indigo!\
    \ \nHave fun :)"
