  body_markdown: "In ROS, [killing a node is as follows](http://wiki.ros.org/rosnode#rosnode_kill)\n\
    \n    rosnode kill node_name\n\nWhat the `rosnode kill` does is send a `SIGINT`\
    \ to the NodeHandle, and what the node should do is deconstruct its classes and\
    \ free the NodeHandle (in correctly written code).\n\nYou can use `os.system`\
    \ with it too. \n\nFor Custom `SIGINT` Handler (in C++) you can use this tutorial:\n\
    \n- http://wiki.ros.org/roscpp/Overview/Initialization%20and%20Shutdown#Shutting_Down"
