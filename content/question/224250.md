  body_markdown: " \nI tried the bag with your modified `rgbd_mapping.launch`. Did\
    \ you record the bag with only `realsense_r200_launch.launch`? If yes, the realsense\
    \ camera node publishes already transforms `/realsense_frame->/camera_depth_optical_frame`\
    \ and `/realsense_frame->/camera_color_optical_frame`. The warning you are getting\
    \ is because there are static_transform_publishers publishing also the same transforms\
    \ when launching `rgbd_mapping.launch`.\n\nUse this:\n\n    <!-- Frames: tf  -->\n\
    \    <node pkg=\"tf\" type=\"static_transform_publisher\"  name=\"base_to_realsense\"\
    \n          args=\"0 0 0 -1.5707963 0 -1.5707963 /base_link /realsense_frame 100\"\
    \ />    \ninstead of\n\n    <!-- Frames: tf  -->\n    <node pkg=\"tf\" type=\"\
    static_transform_publisher\"  name=\"base_to_color\"\n          args=\"0 0 0 -1.5707963\
    \ 0 -1.5707963 /base_link /camera_color_optical_frame 100\" /> \n    <node pkg=\"\
    tf\" type=\"static_transform_publisher\" name=\"color_to_depth\"\n          args=\"\
    -0.1325 -0.1975 0.0 -1.570796327 0.0 0.0 /camera_color_optical_frame /camera_depth_optical_frame\
    \ 100\" /> \n  \nSo with your rosbag:\n\n    $ rosbag info 2016-01-18-16-14-41.bag\n\
