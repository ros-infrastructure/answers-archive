  body_markdown: "Even if your service definition has no fields in the request portion,\
    \ a request class is still created and your server callback must still adhere\
    \ to the function signature required of the callback. The signature is described\
    \ in the [API docs](http://docs.ros.org/api/rospy/html/rospy.impl.tcpros_service.Service-class.html).\
    \ The function should take a request and return a response.\n\nSo your code could\
    \ be roughly updated as:\n\n    from pytorch_ros.srv import Classification\n \
    \   from pytorch_ros.srv import ClassificationRequest\n    from pytorch_ros.srv\
    \ import ClassificationResponse\n    \n    class PytorchNode(object):\n      \
    \  def __init__(self):\n            classification_service = rospy.Service('classify',\n\
    \                                                   Classification,\n        \
    \                                           self.classify_handle)\n    \n    \
    \    def classify_handle(self, request):\n            # do some stuff\n      \
    \      # to get the classification\n            # .....\n    \n            # construct\
    \ msg and return\n            classification_response = ClassificationResponse()\n\
    \            classification_response.class_name = self.names[classification]\n\
    \            classification_response.confidence = confidence\n    \n         \
    \   return classification_response\n    \nNote: This is very much what is presented\
    \ in the [Writing a Simple Service and Client (Python)](http://wiki.ros.org/ROS/Tutorials/WritingServiceClient%28python%29)\
    \ tutorial."

The client

      #!/usr/bin/env python
      from __future__ import division
      from __future__ import print_function
    
      import rospy 
      from pytorch_ros.srv import Classification
     
      rospy.wait_for_service('classify_container')
      
      try:
          srv_classify_container = rospy.ServiceProxy('classify_container', Classification)
          classification = srv_classify_container()
          print(classification.class_name)
          print(classification.confidence)
      except rospy.ServiceException as e:
          print("Service call failed: %s" % e)
