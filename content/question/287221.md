    \ you'll see that it doesn't have a `world` argument.\n\n    <?xml version=\"\
    1.0\"?>\n    \n    <launch>\n      <arg name=\"paused\" default=\"false\"/>\n\
    \      <arg name=\"use_sim_time\" default=\"true\"/>\n      <arg name=\"gui\"\
    \ default=\"true\"/>\n      <arg name=\"headless\" default=\"false\"/>\n     \
    \ <arg name=\"debug\" default=\"false\"/>\n    \n      <include file=\"$(find\
    \ gazebo_ros)/launch/empty_world.launch\">\n        <arg name=\"paused\" value=\"\
    $(arg paused)\"/>\n        <arg name=\"use_sim_time\" value=\"$(arg use_sim_time)\"\
    />\n        <arg name=\"gui\" value=\"$(arg gui)\"/>\n        <arg name=\"headless\"\
    \ value=\"$(arg headless)\"/>\n        <arg name=\"debug\" value=\"$(arg debug)\"\
    />\n      </include>\n    \n      <include file=\"$(find hector_quadrotor_gazebo)/launch/spawn_quadrotor.launch\"\
    \ />\n    </launch>\n\nSo, what you'll want to do is create a new launch file\
    \ in your package that's similar to the one that you're using and include your\
    \ custom world instead. You can make it a little more flexible by add a `world`\
    \ argument that you're trying to use (let's call it `world_name` to be consistent\
    \ with [the `empty_world.launch` file](https://github.com/ros-simulation/gazebo_ros_pkgs/blob/kinetic-devel/gazebo_ros/launch/empty_world.launch)):\n\
    \n    <launch>\n      <arg name=\"paused\" default=\"false\"/>\n      <arg name=\"\
    use_sim_time\" default=\"true\"/>\n      <arg name=\"gui\" default=\"true\"/>\n\
    \      <arg name=\"headless\" default=\"false\"/>\n      <arg name=\"debug\" default=\"\
    false\"/>\n      <arg name=\"world_name\"/>\n    \n      <include file=\"$(find\
    \ gazebo_ros)/launch/empty_world.launch\">\n        <arg name=\"world_name\" value=\"\
    $(arg world_name)\"/>\n        <arg name=\"paused\" value=\"$(arg paused)\"/>\n\
    \        <arg name=\"use_sim_time\" value=\"$(arg use_sim_time)\"/>\n        <arg\
    \ name=\"gui\" value=\"$(arg gui)\"/>\n        <arg name=\"headless\" value=\"\
    $(arg headless)\"/>\n        <arg name=\"debug\" value=\"$(arg debug)\"/>\n  \
    \    </include>\n    \n      <include file=\"$(find hector_quadrotor_gazebo)/launch/spawn_quadrotor.launch\"\
    \ />\n    </launch>\n\nNow, you should be able use it similarly to how you're\
    \ currently trying to use it:\n\n    roslaunch my_package my_world.launch world_name:=2.world\n\
    \nOne caveat is indicted in the `empty_world.launch` file\n\n> the `world_name`\
    \ is with respect to `GAZEBO_RESOURCE_PATH` environmental variable\n\nso you might\
    \ have to work that out. Hopefully, this at least gives you something to go off\
    \ of.\n\n\n----------\n**Update:**\n\nFrom the [Gazebo tutorials](http://gazebosim.org/tutorials?tut=components),\n\
    \n> `GAZEBO_RESOURCE_PATH`: colon-separated set of directories where Gazebo will\
    \ search for other resources such as world and media files."
