  body_markdown: "Thanks to the sharp observation of @gvdhoorn, I had to look it back\
    \ to create a [minimal reproducible example](https://en.wikipedia.org/wiki/Minimal_reproducible_example).\
    \ \n\nIt is an interesting problem. In summary, in the second case, the subscriber,\
    \ i.e., `rgb_sub`, is in local scope. Therefore after the construction call, it\
    \ does not exist. So we must make it a class member to make it work. \n\nPlease\
    \ see a minimal reproducible example below:\n\n    #include <ros/ros.h>\n    #include\
    \ <message_filters/subscriber.h>\n    #include <sensor_msgs/Image.h>\n    \n \
    \   using namespace sensor_msgs;\n    using namespace message_filters;\n    \n\
    \    class ClientHandler\n    {\n    public:\n      ClientHandler(ros::NodeHandle&\
    \ nh, std::string& topic_name);\n      void CamImgCb(const ImageConstPtr& image);\n\
    \    \n    private:\n      ros::NodeHandle n;\n      std::string topic;\n    \
    \  message_filters::Subscriber<Image> rgb_sub;\n    };\n    \n    ClientHandler::ClientHandler(ros::NodeHandle&\
    \ nh, std::string& topic_name) : n(nh), topic(topic_name)\n    {\n      // the\
    \ following declaration does not work. hence it is commented.\n      // the subscriber\
    \ is in a local scope\n      // message_filters::Subscriber<Image> rgb_sub(n,\
    \ topic, 1);\n    \n      // let's make it a class member and then call subscribe\
    \ as shown below\n      rgb_sub.subscribe(n, topic, 1);\n    \n      // now bind\
    \ a callback\n      rgb_sub.registerCallback(boost::bind(&ClientHandler::CamImgCb,\
    \ this, _1));\n    }\n    \n    void ClientHandler::CamImgCb(const ImageConstPtr&\
    \ image)\n    {\n      ROS_INFO(\"Sequence: [%d]\", image->header.seq);\n    }\n\
    \    \n    int main(int argc, char** argv)\n    {\n      ros::init(argc, argv,\
    \ \"image_listener\");\n      ros::NodeHandle n;\n    \n      std::string topic\
    \ = \"/usb_cam/image_raw\";\n      ClientHandler ClientHandler(n, topic);\n  \
    \  \n      ros::spin();\n      return 0;\n    }\n\nI used the `usb_cam` package\
    \ to publish my webcam and used the above node to subscribe, as shown below:\n\
