  body_markdown: "From the database you shared, the depth image seems strange because\
    \ the trees are mostly big polygons with texture. But with this input data, the\
    \ occupancy grid is generated correctly though. \n\nUsing rtabmap-databaseViewer,\
    \ raw point cloud with RGB+depth image (on left all local occupancy grids assembled)\
    \ :\n\n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/15268351414942889.png)\n\
    \n3D Segmentation based on `Grid/` parameters (note that as `Grid/RangeMax` is\
    \ 4 meters, the cloud is cut up to 4 meters):\n\n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/15268351725447563.png)\n\
    \nThen the projected 2D grid for this image:\n\n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/15268352485820235.png)\n\
    \n**EDIT**\n\nIn your `obstacle_layer`, you take the whole point cloud of `/quad/camera_/depth/points`\
    \ as obstacle, including the ground. It is why the ground is seen as an obstacle\
    \ in the costmap. You may use a filtered cloud from  `/quad/camera_/depth/points`\
    \ without the ground instead. If the drone is flying always at the same height,\
    \ it would not be so difficult to filter the ground (like with a pcl_ros [passthrough](http://wiki.ros.org/pcl_ros/Tutorials/PassThrough%20filtering)).\
    \ In contrast to this [example](http://wiki.ros.org/rtabmap_ros/Tutorials/StereoOutdoorNavigation)\
    \ with a ground robot, if the drone is moving also in Z and/or the ground is not\
    \ flat, you may want to keep the ground as obstacle and use the 3D map/OctoMap\
    \ output of rtabmap for 3D navigation (with [moveit](https://moveit.ros.org/)?).\n\
    \nFor the `Grid/RangeMax` parameter, if you have an older rtabmap version, the\
    \ parameter is called `Grid/DepthMax` (`Grid/DepthMax` is automatically converted\
    \ to `Grid/RangeMax` if the version supports it). To have more points to project\
    \ at longer distance, you can also set `Grid/DepthDecimation` to 1 (default 4)\
    \ at the cost of more computation time.\n\ncheers,<br/>\nMathieu"
