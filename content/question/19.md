  body_markdown: "It's suggested that an external program link against the Gazebo\
    \ libraries, specifically the transport library, and send messages using the interface\
    \ provided by Gazebo Nodes.\n\nYou can send messages to Gazebo using your own\
    \ transport mechanism. Construct your message with:\n\n1. An 8byte header that\
    \ is the size of the message\n2. The message data (which must be a serialized\
    \ protobuf message that Gazebo understands).\n\nThe following is a simple example\
    \ in Python. Here we are assuming the python script is waiting for incoming requests\
    \ from Gazebo, and then responds with a new message.\n\n    #!/usr/bin/env python\n\
    \    \n    import socket\n    import struct\n    from sys import *\n    from xml.dom\
    \ import minidom\n    \n    import request_pb2\n    \n    TCP_IP = '127.0.0.1'\n\
    \    TCP_PORT = 50199\n    BUFFER_SIZE = 1024\n    \n    models = {}\n    \n \
    \   #################################################\n    # Read the main manifest\
    \ file\n    def read_manifest():\n      xmldoc = minidom.parse('manifest.xml')\n\
    \      model_list = xmldoc.getElementsByTagName(\"model\")\n    \n      for model\
    \ in model_list:\n        model_name = model.getElementsByTagName(\"name\")[0].childNodes[0].data\n\
    \        model_path = model.getElementsByTagName(\"path\")[0].childNodes[0].data\n\
    \        models[model_name] = model_path\n    \n    read_manifest()\n    \n  \
    \  print 'here'\n    s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)\n \
    \   s.bind((TCP_IP, TCP_PORT))\n    s.listen(1)\n    print 'here2'\n    \n   \
    \ conn, addr = s.accept()\n    print 'Connection address:', addr\n    while 1:\n\
    \      request = request_pb2.Request()\n      data = conn.recv(BUFFER_SIZE)\n\
    \      if not data:\n        break\n    \n      request.ParseFromString(data)\n\
    \    \n      print \"Request: \", request.request\n    \n      response = request_pb2.Response()\n\
    \      response.id = request.id\n      response.request = request.request\n  \
    \  \n      if request.request == \"models\":\n        response.response = \"success\"\
    \n    \n        model_list_msg = request_pb2.ModelList()\n        response.type\
    \ = model_list_msg.DESCRIPTOR.full_name\n        for key in models:\n        \
    \  model_list_msg.model.append(key)\n        response.data = model_list_msg.SerializeToString()\n\
    \    \n      print \"Response Size:\", len(response.SerializeToString())\n   \
    \   hex_size = hex(len(response.SerializeToString()))\n      conn.send(hex_size.rjust(8))\n\
    \      conn.send(response.SerializeToString())  # echo\n    conn.close()\n\n"
