I am trying to view an interactive marker in a web GUI using `ros3djs`. I am following the tutorial [here](http://wiki.ros.org/ros3djs/Tutorials/VisualizingInteractiveMarkers) but I am not able to see any markers.

The topic I am trying to subscribe to is `/twist_marker_server/update`, which works on `RViz`. I am wondering if my problem is related to the `update` bit and maybe I'm subscribing to the wrong thing?

Does anyone have any ideas? Here's a code snippet:

    let imClient = new ROS3D.InteractiveMarkerClient({
                    ros : this.ros,
                    tfClient : tfClient,
                    topic : '/twist_marker_server/update',
                    camera : viewer.camera,
                    rootObject : viewer.selectableObjects
                });

**EDIT:** I've just noticed in the documentation [here](http://robotwebtools.org/jsdoc/ros3djs/current/interactivemarkers_InteractiveMarkerClient.js.html#line53) that `'/tunneled/update'` is appended to the topic name I specify resulting in the above code trying to subscribe to `'/twist_marker_server/update/tunneled/update'`, which does not exist. I thought that `/twist_marker_server/update` was the right topic to specify as this works on RViz. Is there some way I can stop `ROS3D.InteractiveMarkerClient` from appending anything to the topic name so it doesn't break it?
