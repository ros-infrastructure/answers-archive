    A ros node is initialized by the [gazebo_ros_api](https://github.com/ros-simulation/gazebo_ros_pkgs/blob/kinetic-devel/gazebo_ros/src/gazebo_ros_api_plugin.cpp#L122) system plugin. It's the `/gazebo` you see on the node list. Since the plugins are run in the same process, you can only have 1 node, the /gazebo one.

    Having another node for your plugin is not necessary. If you want to keep your plugin independent from everything else, you can just configure the ros backend accordingly

        ros::NodeHandle nh;
        ros::CallbackQueue callback_queue;
        ros::AsyncSpinner spinner(1, &callback_queue);
        nh.setCallbackQueue(&callback_queue);
        spinner.start();
