    It should be theoretically possible but is not currently a supported configuration. However, I have been able to build and test it outside of `ade`. If you want the same setup as ADE (because some paths in Autoware assume an ADE environment), the installation instructions would look something like this, after installing ROS Dashing:

        cd ~
        source /opt/ros/dashing/setup.bash
        sudo apt update && rosdep update
        sudo apt install -y python3-colcon-common-extensions git clang-tidy
        git clone https://gitlab.com/autowarefoundation/autoware.auto/AutowareAuto.git
        cd AutowareAuto
        git lfs pull --include="*" --exclude=""
        rosdep install --from-paths src --ignore-src -y
        sudo colcon build --merge-install --install-base /opt/AutowareAuto
        sudo chmod -R og-w /opt/AutowareAuto

    Autoware.AUTO will then be installed in `/opt/AutowareAuto` and you should be able to `source /opt/AutowareAuto/setup.bash` and run commands just like in the Docker containers.

    Again, this is an unsuported configuration until after we finish implementing the AVP ODD later this year.

    If you have problems with this setup and would like to continue discussion, please create a login on Gitlab and continue on our [Issue 244](https://gitlab.com/autowarefoundation/autoware.auto/AutowareAuto/-/issues/244).

      @kcassis Of the 3 architectures you mentioned, we build native Docker containers for `x86_64` and `aarch64` (not sure whether the containers are endian-specific or not).

      To test the `aarch64`/`arm64` Docker container on your `aarch64` board, just follow the [regular instructions](https://autowarefoundation.gitlab.io/autoware.auto/AutowareAuto/installation.html) for installing Docker and `ade` and setting up your `adehome` folder. Then, when you're about to start `ade`, run `ade --rc .aderc-arm64 start --update --enter`. The key part is the `--rc .aderc-arm64` as that tells `ade` to use a custom ADERC file (also in the AutowareAuto repository) which points to the `arm64` Docker images.

      The `x86_64` images are the ones defined in the default `.aderc` file so you can use the [regular instructions](https://autowarefoundation.gitlab.io/autoware.auto/AutowareAuto/installation.html) for that architecture.
