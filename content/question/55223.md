  body_markdown: "I'll try to explain using an example from my experience.\n\nThe\
    \ plane's parameters is the normal and the distance to the plane from a fixed\
    \ reference frame.  The model's (plane) coefficients, in this case, are the normal\
    \ vector (x,y,z) and the offset.\n\nThe model's coefficients are estimated using\
    \ a least-squares method inside RANSAC to find the best-fit model.  Once those\
    \ coefficients are found; an optimization is performed over the estimated coefficients\
    \ to minimize or reduce the mean-squared-error with respect the all of the 3D\
    \ points.\n\nThe optimization a bit longer and can fail if you have a large percentage\
    \ of outliers.\n\nThis method is optional due to the fact that if you know you\
    \ have no outliers and no noise, then the least-squares solution will be the same\
    \ as the optimized (refined) solution. (Saves computational time)  \n\nHowever,\
    \ if you know that your points are affected by noise and you had to remove outliers,\
    \ then optimizing the model's coefficients will give a better solution with respect\
    \ to the least-squares solution. (More time, but better solution)\n\nIts a trade-off\
    \ between time and quality of the solution."

    \n> The algorithm works as follows:\n> >  1. randomly select samples from the\
    \ cloud, just as many as needed to\n> > determine a model \n> >  2. compute the\
    \ coefficients of the model from the samples \n> >  3. count how many points of\
    \ the cloud belong to the model, given a\n> > threshold. These are called inliers\
    \ \n> >  4. repeat until a good model has been found or a max number of\n> iterations\n\
    > > has been reached \n> >  5. return the model with the most inliers\n\nI believe\

    \ if setOptimizeCoefficients is true, is refined to fit all inliers, instead of\
    \ using the original parameters that were fitted in stage 2 for the random samples\
