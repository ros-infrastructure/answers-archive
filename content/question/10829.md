  body_markdown: "Hi Ringo,\n\nThe following works for me in Diamondback.\n\nFirst\
    \ add a dependency on sound_play to your package manifest.xml file:\n\n    <depend\
    \ package=\"sound_play\"/>\n\nand re-run rosmake in your package directory.\n\n\
    Then launch the soundplay node from the command line or your launch file:\n\n\
    \    $ rosrun sound_play soundplay_node.py\n\nor\n\n    <launch>\n      <node\
    \ name=\"soundplay_node\" pkg=\"sound_play\" type=\"soundplay_node.py\"/>\n  \
    \  </launch>\n\nFinally, add the following Python snippets to your main speech\
    \ script.\n\n    from sound_play.libsoundplay import SoundClient\n    \n    self.soundhandle\
    \ = SoundClient()\n    rospy.sleep(1)\n    self.soundhandle.say('Take me to your\
    \ leader.')\n\n--patrick\n"
