  body_markdown: "According to [sensor_msgs/Range.msg](http://ros.org/doc/api/sensor_msgs/html/msg/Range.html),\
    \ the data is in `msg->range`. The range is a float32 (a single number). \n\n\
    If you were to use the [sensor_msgs/LaserScan.msg](http://ros.org/doc/api/sensor_msgs/html/msg/LaserScan.html)\
    \ instead, the set of ranges would be found in `msg->ranges`. Then `msg->range.size()`\
    \ would have some meaning (since it's a vector)."
