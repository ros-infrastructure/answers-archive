  body_markdown: "The use of future dating for static and approximately static transforms\
    \ is a tool used to avoid latency prior to the addition of truely static transforms\
    \ in tf2. \n\nThere's more info in the [tf/FAQ](http://wiki.ros.org/tf/FAQ)\n\n\
    I'd recommend moving to a [tf2 static transform](http://wiki.ros.org/tf2?distro=noetic#Adding_static_transform_support)\
    \ instead which will be more robust and lower overhead."
