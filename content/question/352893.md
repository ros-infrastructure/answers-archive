  body_markdown: "The way I made it work is by specifying the full path to the nodelet\
    \ manager when loading a nodelet from a namespace\n\nfor example\n\n    <node\
    \ pkg=\"nodelet\" type=\"nodelet\" name=\"my_nodelet_manager\" args=\"manager\"\
    \ cwd=\"node\" output=\"screen\" />\n    \n    <group ns=\"camera1\">\n      <node\
    \ node pkg=\"nodelet\" type=\"nodelet\" name=\"my_nodelet\" args=\"load pkg_name/nodelet_name\
    \ /my_nodelet_manager\" />\n    </group>\n\nadding the slash in front of my_nodelet_manager\
    \ in the nodelet loading command will make sure it won't look for the nodelet\
    \ manager inside the namespace \"camera1\" but will try finding it using its global\
    \ path. This also works with subnamespaces. If you want your camera and also the\
    \ nodelet manager to be inside the slam namespace just do \n\n    <group ns=\"\
    slam\">\n        <node pkg=\"nodelet\" type=\"nodelet\" name=\"my_nodelet_manager\"\
    \ args=\"manager\" cwd=\"node\" output=\"screen\" />\n        <group ns=\"camera1\"\
    >\n          <node node pkg=\"nodelet\" type=\"nodelet\" name=\"my_nodelet\"\n\
    \           args=\"load pkg_name/nodelet_name /slam/my_nodelet_manager\" />\n\
    \        </group>\n\n</group>"
