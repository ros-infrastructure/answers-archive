  body_markdown: "The mesh problem that is causing this mess on screen is a known\
    \ [issue](https://github.com/ignitionrobotics/ign-rendering/issues/101) with locales.\n\
    \nSetting this environment variable will solve it:\n\nexport LC_NUMERIC=\"C\"\n\
    \nThe \"Warning [Model.cc:170] Non-unique names detected in XML children of model\
    \ with name[demo_name]\" is related to a link/joint/tag in the SDF model with\
    \ same name that other link/joint/tag. It is not exactly a problem and the simulation\
    \ will work fine. You could open the SDF model and try to search which one have\
    \ the same name and change it, or just ignore this warning. "
