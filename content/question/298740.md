    It is possible to create a package having multiple programming languages. [rclpy](https://github.com/ros2/rclpy/tree/bouncy/rclpy) is a ROS 2 package containing both python and C. The same could be done with C++ and python.

    In ROS 1 using `catkin` and calling `catkin_python_setup()` in a `CMakeLists.txt` causes a `setup.py` file to be called, but the CMake code has to be there even if the package has no C or C++ code. In ROS 2 a package can be pure python.

  body_markdown: "It is by now easily possible. \n\nYou create an cpp package as usual\
    \ and add the package structure of a normal python package.\n\nThe difference\
    \ is, that you don't need the setup.cfg and setup.py files as this is now all\
    \ handled by CMakeList.txt.\n\nYou have to make small adjustments as adding \n\
    \n    find_package(ament_cmake_python REQUIRED)\n    find_package(rclpy REQUIRED)\n\
    and modify the package.xml to support building with python: \n\n    <buildtool_depend>ament_cmake_python</buildtool_depend>\n\
    \nFor more detailed explanations please look at these ressources:\n\n[ros2-package-for-both-python-and-cpp-nodes](https://roboticsbackend.com/ros2-package-for-both-python-and-cpp-nodes/)\n\
    \n[creating-a-mixed-cpp-and-python-package](https://github.com/bponsler/ros2-support/blob/master/tutorials/creating-a-mixed-cpp-and-python-package.md)\n\
    \nIn short your structure has to look like this:\n\n    my_example_package/\n\
    \    CMakeLists.txt\n    package.xml\n    include/\n        my_example_package/\n\
    \            some_file.hpp\n    src/\n        some_file.cpp\n    my_example_package/\n\
    \        __init__.py\n        some_module.py\n        another_module.py\n    scripts/\n\
    \        my_executable\n\npackage.xml like this: \n\n    <?xml version=\"1.0\"\
    ?>\n    <?xml-model href=\"http://download.ros.org/schema/package_format3.xsd\"\
    \ schematypens=\"http://www.w3.org/2001/XMLSchema\"?>\n    <package format=\"\
    3\">\n      <name>my_cpp_py_pkg</name>\n      <version>0.0.0</version>\n     \
    \ <description>TODO: Package description</description>\n      <maintainer email=\"\
    your@email.com\">Name</maintainer>\n      <license>TODO: License declaration</license>\n\
    \n      <buildtool_depend>ament_cmake</buildtool_depend>\n      <buildtool_depend>ament_cmake_python</buildtool_depend>\n\
    \n      <depend>rclcpp</depend>\n      <depend>rclpy</depend>\n\n      <test_depend>ament_lint_auto</test_depend>\n\
    \      <test_depend>ament_lint_common</test_depend>\n\n      <export>\n      \
    \  <build_type>ament_cmake</build_type>\n      </export>\n    </package>\n\nand\
    \ CMakeList.txt like this:\n\n    cmake_minimum_required(VERSION 3.5)\n    project(my_cpp_py_pkg)\n\
    \    # Default to C++14\n    if(NOT CMAKE_CXX_STANDARD)\n      set(CMAKE_CXX_STANDARD\
    \ 14)\n    endif()\n    if(CMAKE_COMPILER_IS_GNUCXX OR CMAKE_CXX_COMPILER_ID MATCHES\
    \ \"Clang\")\n      add_compile_options(-Wall -Wextra -Wpedantic)\n    endif()\n\
    \n    # Find dependencies\n    find_package(ament_cmake REQUIRED)\n    find_package(ament_cmake_python\
    \ REQUIRED)\n    find_package(rclcpp REQUIRED)\n    find_package(rclpy REQUIRED)\n\
    \n    # Include Cpp \"include\" directory\n    include_directories(include)\n\n\
    \    # Create Cpp executable\n    add_executable(cpp_executable src/cpp_node.cpp)\n\
    \    ament_target_dependencies(cpp_executable rclcpp)\n\n    # Install Cpp executables\n\
    \    install(TARGETS\n      cpp_executable\n      DESTINATION lib/${PROJECT_NAME}\n\
    \    )\n\n    # Install Python modules\n    ament_python_install_package(${PROJECT_NAME})\n\
    \n    # Install Python executables\n    install(PROGRAMS\n      scripts/py_node.py\n\
    \      DESTINATION lib/${PROJECT_NAME}\n    )\n\n    ament_package()\n\n"
