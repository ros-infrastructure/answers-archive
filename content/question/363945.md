  body_markdown: "I do not know a ROS2 equivalent of the command you described . However\
    \ a simple workaround to get a similar behavior could be to use `grep` for this\
    \ purpose. You can specify the number of lines that should be visible after your\
    \ search key with the `-A [num lines after match]` option. Just set it to the\
    \ size of the data field of interest.\n\nFor example to view the linear acceleration\
    \ of an sensor_msgs/msg/Imu one could write:\n\n    ros2 topic echo /imu_topic\
    \ | grep -A 3 \"linear\"\n     linear:\n       x: 0.0\n       y: 0.0\n       z:\
    \ 0.0\n    (...)\n \n\n"

  body_markdown: "You can use the `--field` flag of the `ros2 topic echo` command.\
    \ Here is an example:\n\n    ros2 topic echo /imu_test --field linear_acceleration\n\
    \nwhich will give the output \n\n    x: 0.0\n    y: 0.0\n    z: 0.0\n    ---\n\
    \nYou can go further into the field by putting periods after each subsection,\
    \ so \n\n    ros2 topic echo /imu_test --field linear_acceleration.x\n\nwill give\
    \ you \n\n    0.0\n    ---\n\n"
