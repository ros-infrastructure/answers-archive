  body_markdown: "The `SetLinearAccel` function will not cause the model to move.\
    \ It only sets the linear acceleration attribute on each Link. \n\nThis is because\
    \ Gazebo would have to do the conversion from acceleration to velocity outside\
    \ of the standard physics update loop, and we haven't implemented that yet. \n\
    \nHere is a related [issue](https://bitbucket.org/osrf/gazebo/issues/878) in our\
    \ tracker."
