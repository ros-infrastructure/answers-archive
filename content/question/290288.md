  body_markdown: "I found the answer to that in amcl code.\n\n1. First you convert\
    \ map to base position into a transform.\n2. Then you get tf::Stamped<tf::Pose>\
    \ object of it \n3. Then you reverse it\n4. After that you transform the reverse\
    \ to \"odom\" frame\n5. Then you make a temporary transform object from above\
    \ result\n6. Reverse of transform is result and you broadcast it. \nBelow is the\
    \ code.\n\n  tf::Stamped<tf::Pose> map_to_base (map_position_transform.inverse(),\n\
    \                                              msg->header.stamp,\n          \
    \                                    \"base_footprint\");\n        listener.transformPose(\"\
    odom\",\n                                 map_to_base,\n                     \
    \            odom_to_map);\n\n        latest_tf_ = tf::Transform(tf::Quaternion(odom_to_map.getRotation()),\n\
    \                                 tf::Point(odom_to_map.getOrigin()));\n\n   \
    \     tf::StampedTransform map_to_odom(latest_tf_.inverse(),\n               \
    \                             ros::Time::now(),\n                            \
    \                \"map\", \"odom\");\n        br.sendTransform(tf::StampedTransform(map_to_odom,\
    \ ros::Time::now(), \"map\", \"odom\"));"
