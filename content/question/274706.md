  body_markdown: "The `abb_driver` package was not written with YuMi in mind, meaning\
    \ that it targets single group robots only. Both the motion and joint state servers\
    \ have no concept of multiple motion groups.\n\nThat said it is possible to run\
    \ *two* instances of the two tasks, edited slightly to use different port nrs,\
    \ and assigned to the two separate groups (on the controller). This has been done\
    \ by many groups already, and the official ABB driver is set to receive an upgrade\
    \ to support this (multiple motion groups) as well as add EGM support soon.\n\n\
    One example of a fork that you could use already would be the fork of \xD6rebro\
    \ University: [OrebroUniversity/yumi](https://github.com/OrebroUniversity/yumi).\n"
