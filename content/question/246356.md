  body_markdown: "Download the gmapping package `sudo apt-get install ros-[version]-gmapping`.\
    \ Then I would suggest launching both nodes using a launch file like so:\n\n \
    \   <launch>\n    \n        <!--- Depth image to laser scan -->\n        <node\
    \ pkg=\"depthimage_to_laserscan\" type=\"depthimage_to_laserscan\" name=\"depthimage_to_laserscan\"\
    \ >\n            <param name=\"scan_height\" value=\"3\"/> \n            <param\
    \ name=\"output_frame_id\" value=\"base_link\"/>\n            <remap from=\"image\"\
    \ to=\"camera/depth/image_rect_color\" />\n        </node>\n    \n        <!--\
    \ Maping Node -->\n        <node pkg=\"gmapping\" type=\"slam_gmapping\" name=\"\
    gmapping_node\" output=\"screen\" >\n            <remap from=\"odom\" to=\"your/odom/topic\"\
    \ />\n        </node>\n    \n    </launch>"
