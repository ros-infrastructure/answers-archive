  body_markdown: ">     Unable to enable drive power (5006)\n\nFrom the robot controller's\
    \ perspective, the ROS nodes are no different from other \"external\" sources\
    \ of control (a PLC fi).\n\nSo all the same safety systems are in place and you\
    \ need to take care of all the same safety requirements.\n\nThe error message\
    \ tells you that the controller has determined that it cannot enable motor power\
    \ and therefore the `robot_enable` service call returns an error.\n\nThe [Usage:\
    \ Robot Controller](http://wiki.ros.org/motoman_driver/Tutorials/Usage#Robot_Controller)\
    \ section of the *Using the Motoman FS/DX/YRC ROS Interface* tutorial lists the\
    \ minimum requirements for external control to be possible:\n\n> Prior to executing\
    \ ROS motion:\n\n>   1. Make sure the robot controller is ready:\n>     - Installation\
    \ and setup of MotoROS driver must be complete\n>     -  Pendant key switch must\
    \ be in Remote mode\n>     - The E-stop latch must be released \n\nFurthermore\
    \ the standard safety conditions must be met: any fences closed, all e-stops released\
    \ (also external ones), and no inhibiting devices (ie: a PLC) can be actively\
    \ keeping the robot in an error state.\n\n"
