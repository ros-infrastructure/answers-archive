    I know you posted this on [ros-users](https://code.ros.org/lurker/message/20110223.213801.6f1e1f5c.en.html), but I'll chime in again that when we do not want to download, like Nicola Fioraio mentioned, we install on one computer and then find and copy the archives from `/var/cache/apt/archives`.

    This saves some time, since we can transfer over gigabit/flashdrive and then put the packages on a new computer. Then we just run the sudo apt-get install with all/most of the packages already present.

    You might also want to look into [setting up your own local ros mirror](http://answers.ros.org/question/131/how-do-i-set-up-a-ros-mirror).  Downloading at 50 MB/s makes things nice. :D
