  body_markdown: "I realized that the Lidar on our husky is \"hokuyo lidar\" while\
    \ the one mentioned in Clearpath installation guide is (Sick LMS1XX Lidar). I\
    \ managed to turn on my laser by:\n1) Install urg_node (sudo apt-get install ros-melodic-urg-node)\n\
    2) creating this laser.launch file and adding it to /opt/ros/melodic/share/husky_navigation/launch\n\
    \nlaser.launch:\n\n<launch>\n\n    <node pkg=\"urg_node\" type=\"urg_node\" name=\"\
    urg_node\">\n\n        <param name=\"serial_port\" value=\"/dev/ttyACM0\" />\n\
    \        <param name=\"frame_id\" value=\"laser_link\" />\n        <param name=\"\
    calibrate_time\" value=\"true\"/>\n        <param name=\"publish_intensity\" value=\"\
    false\"/>\n        <param name=\"angle_min\" value=\"-1.5\"/>\n        <param\
    \ name=\"angle_max\" value=\"1.5\"/>\n    </node>\n<node pkg=\"tf\" type=\"static_transform_publisher\"\
    \ name=\"robot_to_kinect\" args=\"0.393 0 .155 0 0 3.14159 /base_link /laser_link\
    \ 20\" />\n\n</launch>\n\nI also added this line of code at the top in gmapping_demo.launch:\n\
    \n<!--  demo1 -->\n<launch>\n\n<include file=\"$(find husky_navigation)/launch/laser.launch\"\
    />\n\n.\n.\n.\n\n3) Also make sure when you run rviz to change global_option fixed\
    \ frame to \"map\" instead of \"odom\"\nIt works now :) \n\n"
