  body_markdown: "Hi,\nfirst, in order to move your robot joints you can use Gazebo\
    \ or ROS. I recommend to use ROS because it is very well integrated, several controllers\
    \ already provided, and it is a lot easier. However, if you want to learn how\
    \ to do it with Gazebo itself, have a look at [this git](https://github.com/JenniferBuehler/jaco-arm-pkgs/wiki/Jaco-example-in-Gazebo).\n\
    \nIf you want to control the robot with ROS, then you need to do first a translation\
    \ of your model to URDF. Sorry SDF does not work with ROS, specially if you want\
    \ to show the robot in Rviz. So, go for the translation of format. To do a translation\
    \ from SDF to URDF watch [this video](https://www.youtube.com/watch?v=8g5nMxhi_Pw).\n\
    \nSo now I will assume that you have a robot model in URDF which includes some\
    \ joints. In order to keep the discussion sound I have created a simple URDF for\
    \ a two joints robot. That is the URDF.\n\n\n    <?xml version=\"1.0\"?>\n   \
    \ <robot name=\"simple_example\">\n      <link name=\"base_link\">\n        <inertial>\n\
    \            <mass value=\"10\" />\n            <inertia ixx=\"0.4\" ixy=\"0.0\"\
    \ ixz=\"0.0\" iyy=\"0.4\" iyz=\"0.0\" izz=\"0.2\"/>\n        </inertial>\n   \
    \     <collision>\n          <geometry>\n            <cylinder radius=\"0.05\"\
    \ length=\"0.24\" />\n          </geometry>\n            </collision>\n      \
    \  <visual>\n          <geometry>\n            <cylinder radius=\"0.05\" length=\"\
    0.24\" />\n          </geometry>\n        </visual>\n      </link>\n    \n   \
    \   <link name=\"second_link\">\n        <inertial>\n            <mass value=\"\
    0.18\" />\n            <inertia ixx=\"0.0002835\" ixy=\"0.0\" ixz=\"0.0\" iyy=\"\
    0.0002835\" iyz=\"0.0\" izz=\"0.000324\" />\n        </inertial>\n        <origin\
    \ rpy=\"0.0 0.0 0.0\" xyz=\"0.0 0.0 0.0\" />\n        <collision>\n          <geometry>\n\
    \            <box size=\"0.05 0.05 0.15\" />\n          </geometry>\n        </collision>\n\
    \        <visual>\n          <geometry>\n            <box size=\"0.05 0.05 0.15\"\
    \ />\n          </geometry>\n        </visual>\n      </link>\n    \n      <joint\
    \ name=\"base_to_second_joint\" type=\"continuous\">\n        <parent link=\"\
    base_link\"/>\n        <child link=\"second_link\"/>\n        <axis xyz=\"1 0\
    \ 0\"/>\n        <origin xyz=\"0.0 0.0 0.2\" rpy=\"0.0 0.0 0.0\"/> \n      </joint>\n\
    \      \n      <!--                GAZEBO RELATED PART                       \
    \      -->\n    \n      <!-- ROS Control plugin for Gazebo -->\n      <gazebo>\n\
    \        <plugin name=\"gazebo_ros_control\" filename=\"libgazebo_ros_control.so\"\
    >\n          <robotNamespace>/simple_model</robotNamespace>\n        </plugin>\n\
    \      </gazebo>\n\n      <!-- transmission -->\n      <transmission name=\"base_to_second_trans\"\
    >\n        <type>transmission_interface/SimpleTransmission</type>\n        <actuator\
    \ name=\"motor1\">\n          <mechanicalReduction>1</mechanicalReduction>\n \
    \       </actuator>\n        <joint name=\"base_to_second_joint\">\n         \
    \ <hardwareInterface>EffortJointInterface</hardwareInterface>\n        </joint>\n\
    \      </transmission>\n    </robot>`\n\nNow that URDF has the key elements you\
    \ must use in any kinematic chain to be able to control it using ROS. Basically\
    \ you do the following:\n\n 1. Add a `link` for each movable element of the robot\n\
    \ 2. For each `link` add a `joint` which describes the union between the different\
    \ links, which type of union is, and how one element moves in relation to the\
    \ other.\n 3. To be able to control with ROS you need to add the `gazebo_ros_control`\
    \ plugin\n 4. Finally, you have to include a `transmission` part, that is the\
    \ one that actually indicates the controller to be used and for which joint.\n\
    \nOnce you have all that, you need to create a config file that must be loaded\
    \ at launch time, which contains the configuration of the controller itself. Here\
    \ it is an example for the previous URDF.\n\n    simple_model:\n    joint_state_controller:\n\
    \        type: joint_state_controller/JointStateController\n        publish_rate:\
    \ 20\n        \n    base_to_second_joint_position_controller:\n        type: effort_controllers/JointPositionController\n\
    \        joint: base_to_second_joint\n        pid: {p: 1.0, i: 1.0, d: 0.0}\n\n\
    Finally, you need to create a launch file that launches everything, loads the\
    \ configuration and publishes the status in ROS. Here an example of such a file:\n\
    \n    <launch>\n    <param name=\"robot_description\" textfile=\"$(find simple_example_description)/urdf/robot.urdf\"\
    \ />\n    <node name=\"urdf_spawner\" pkg=\"gazebo_ros\" type=\"spawn_model\"\
    \ respawn=\"false\" output=\"screen\" args=\"-urdf -model simple_model -param\
    \ robot_description -y -6\"/>\n    <!-- loads the controllers -->\n    <rosparam\
    \ file=\"$(find simple_example_description)/config/config.yaml\" command=\"load\"\
    \ />\n    <node name=\"controller_spawner\" pkg=\"controller_manager\" type=\"\
    spawner\" ns=\"/simple_model\" args=\"base_to_second_joint_position_controller\
    \ joint_state_controller --shutdown-timeout 3\"/> \n    <!-- converts joint states\
    \ to TF transforms -->\n    <node name=\"robot_state_publisher\" pkg=\"robot_state_publisher\"\
    \ type=\"robot_state_publisher\" respawn=\"false\" output=\"screen\">\n      \
    \  <remap from=\"/joint_states\" to=\"/simple_model/joint_states\" />\n    </node>\n\
    \    </launch>\n\n(sorry for the bad formatting, but this editor for questions\
    \ is really bad, and presents a lot of problems when copy pasting files to keep\
    \ the indentation and format).\n\nSo, you organize all that info in a package\
    \ and you are done!\n[I have created this video](https://youtu.be/3qCh-p-hzCM)\
    \ that shows more details about this example. In the video you can see how this\
    \ example is able to move by publishing in a control topic.\n\nMore suggested\
    \ tutorials that you should study:\n\n - [How to integrate ROS control with a\
    \ Gazebo simulation](http://gazebosim.org/tutorials/?tut=ros_control), Gazebo\
    \ tutorial\n - [How to create the URDF of your robot](https://www.youtube.com/watch?v=UUwHK5ONTAQ),\
    \ video tutorial\n - [How to understand ROS control](https://www.youtube.com/watch?v=AZGNIVFqXI8),\
    \ video tutorial\n\n"
