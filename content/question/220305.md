  body_markdown: "I've open-sourced my .travis.yml file for using travis-ci for continuous\
    \ integration on ROS packages:\nhttps://github.com/felixduvallet/ros-travis-integration\n\
    \nIt works with Ubuntu 14.04 and ROS indigo by default, but in principle could\
    \ be used with other ubuntu/ros distributions. \n\nTo enable continuous integration\
    \ for your ROS package, just:\n\n1. Sign up for [travis-ci.org](https://travis-ci.org)\
    \ and enable CI for your repository.\n2. Copy this [.travis.yml](https://github.com/felixduvallet/ros-travis-integration/blob/master/.travis.yml)\
    \ file into your repository and commit it.\n3. Push to github!\n\nNote: At this\
    \ time, Travis-CI only works with github.\n\n## What Travis does each time you\
    \ push:\n\n1. Installs a barebones ROS distribution (indigo by default) on a *fresh*\
    \ ubuntu virtual machine.\n2. Creates a catkin workspace and puts your repository\
    \ in it.\n3. Uses wstool to check out any from-source dependencies (i.e. other\
    \ repositories).\n4. Resolves package dependencies using rosdep (i.e. install\
    \ packages using apt-get).\n5. Compiles the catkin workspace\n6. Runs all available\
    \ unit tests\n\nIf any of the steps fail, the build is marked as a failure and\
    \ you'll hear about it.\n\n## Dependencies:\n\nThis script handles two types of\
    \ dependencies:\n\n - ROS package: Packages that can be installed using apt-get\
    \ (resolved using rosdep).\n - source: Other repositories that must be checked\
    \ out into the workspace (resolved using wstool).\n\nThis means that all your\
    \ dependencies must be explicitly declared (in the package.xml files) so they\
    \ can be resolved (NOTE: this is a good thing!).\nSource depencies are (by default)\
    \ listed in a file named `dependencies.rosinstall` in the root of your repository.\n\
    If you don't have dependencies to list, this file can safely be ignored.\n\n##\
    \ Advanced use:\nIf you want to pass additional options to catkin_make, you can\
    \ use the `catkin.options` file to specify any command-line options.\n\n## Private\
    \ repositories:\nThese can be handled by travis-ci.com (the 'pro' version of travis-ci.org),\
    \ provided you set up the correct permissions to the repository and its dependencies.\
    \ Beta instructions are provided [here](https://github.com/felixduvallet/ros-travis-integration#private-repositories).\n\
