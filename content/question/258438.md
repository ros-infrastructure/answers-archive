  body_markdown: "I found a workaround for the problem.\n\nI created a python script\
    \ named as \"set_components_config.py\", it is responsible of mapping the global\
    \ parameters to the parameters of each component (e.g. rosplan_scene_database).\
    \ \n\n    #! /usr/bin/env python\n\n    import rospy\n    \n    rospy.set_param(\"\
    rosplan_scene_database/database_path\",\n        rospy.get_param(\"/rosplan/database_path\"\
    ))\n    \n    rospy.set_param(\"rosplan_planning_system/problem_path\",\n    \
    \    rospy.get_param(\"/rosplan/problem_path\"))\n    rospy.set_param(\"rosplan_planning_system/data_path\"\
    ,\n        rospy.get_param(\"/rosplan/data_path\"))\n    rospy.set_param(\"rosplan_planning_system/strl_file_path\"\
    ,\n        rospy.get_param(\"/rosplan/strl_file_path\"))\n\nAnd this script is\
    \ called by the launch file after loading the global parameters and before starting\
    \ the nodes that use them.\n\n    <launch>\n    \t<!-- load configuration -->\n\
    \    \t<include file=\"$(find pepito_organizes_boxes)/launch/load_system_config.launch\"\
    \ />\n        <node name=\"update_config\" pkg=\"pepito_organizes_boxes\" type=\"\
    set_components_config.py\" output=\"screen\" />\n    \n     \t<!-- knowledge base\
    \ -->\n        <node name=\"rosplan_knowledge_base\" pkg=\"rosplan_knowledge_base\"\
    \ type=\"knowledgeBase\" respawn=\"false\" output=\"log\" />\n        <node name=\"\
    rosplan_scene_database\" pkg=\"mongodb_store\" type=\"mongodb_server.py\" respawn=\"\
    false\" output=\"screen\" />\n    \t<node name=\"rosplan_scene_message_store\"\
    \ pkg=\"mongodb_store\" type=\"message_store_node.py\" respawn=\"false\" output=\"\
    log\" />    \n    </launch>"
