**EDIT -4**
**Solution**

   

 The front of robot when we create it with urdf should be aligned to the x- axis of the environment so that when you localise the robot the pose array direction aligns with front direction  of the robot (i.e , pose array overlaps with x axis of robot).In my case, I faultly aligned robot's front to y-axis . So if I localise the robot with 2d pose estimate the robot will always be aligned at 90 deg to pose array ( since angle between x and y axis is 90 deg)
