  body_markdown: "rosdep interacts with package managers only.  So you cannot point\
    \ it to a specific file/folder. \n\nYou can override the rosdep rule by creating\
    \ your own rosdep file, which will set the rosdep resolution to an empty list\
    \ if you want to manage the dependency manually. \n\nWhen you have the file add\
    \ it's path to your rosdep sources in /etc/ros/rosdep/\n\nThen rosdep will not\
    \ try to install pcl for you."
