    Yes and no.

    You can run the same node (i.e. even the same executable) multiple times, if you give them different names in `roslaunch` (check the [roslaunch syntax](http://wiki.ros.org/roslaunch/XML/node)).

    You cannot launch two nodes (does not matter if it is the same or another executable) with the same name
