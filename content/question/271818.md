  body_markdown: "If you install the IMU on a lead and then pull it away from the\
    \ mounting location to perform the calibration, then you're defeating much of\
    \ the purpose of the calibration.  The calibration should be done with the IMU\
    \ mounted in its operational location and with the robot powered on.  Maybe even\
    \ with the robot moving.  That way, any magnetic fields and metallic parts that\
    \ can affect the IMU can attempt to be calibrated out.  "
