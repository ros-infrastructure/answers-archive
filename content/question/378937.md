    Unfortunately ROS-Kinetic does not support python-3. There are some [ros-bridges](https://dhanoopbhaskar.com/blog/2020-05-07-working-with-python-3-in-ros-kinetic-or-melodic/) to python 3 which you may try, but these almost always cause issues. You only have two reliable options here:

     1. Either port your code to python 2 (which as you said isn't a real option now)
     2. Per @Ranjit 's comment, ROS-Noetic also supports python 3 and you think about upgrading to noetic
     3. Use ROS2. ROS2 natively supports python 3, is newer and the support will last for longer!
