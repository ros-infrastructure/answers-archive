  body_markdown: "To be able to print messages on terminal, in launch file you should\
    \ add `output=\"screen\"` to the relevant `<node>` tag.\n\nAlso you can view `ROS_INFO`\
    \ messages on `rqt_console`. \n\n**In reply to OP's comment:**\n\nIt should be\
    \ like this:\n\n    <node name=\"SelfLocalizer\" pkg=\"nav2d_localizer\" type=\"\
    localizer\" output=\"screen\">\n      <remap from=\"scan\" to=\"base_scan\"/>\n\
    \      <param name=\"min_particles\" type=\"int\" value=\"5000\"/>\n    </node>"
