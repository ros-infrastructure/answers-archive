- body_markdown: "Hi Ktysai. Thanks for answering. Sorry for the delay, but i was\
    \ abroad.  To get my odometry i am using two encoders. With each tick of each\
    \ encoder I generate an interruption and using timers i count how many counts\
    \ of the timer i have (with the TCNTx register). with this counts i calculate\
    \ the speed as:   Input2 = 2 * PI / 1120 / paso2 / 5 * 10000000 (where paso2 is\
    \ the number of counts and \" /5 * 10000000 \" is because i set the timers to\
    \ have a count each 500ns). \n\n\nOnce i calculate the speed of each motor, i\
    \ use the following relationships:\n\nvx = R / 2 * (Input1 + Input2) * cos(th);\n\
    \nvy = R / 2 * (Input1 + Input2) * sin(th);\n\nvth = R / L * (Input1 - Input2);\n\
    \n\n//Calculo posicion\n\nx = x + vx * deltat;\n\ny = y + vy * deltat;\n\nth =\
    \ th + vth * deltat;\n\n\nWhere deltat is the loop time."
