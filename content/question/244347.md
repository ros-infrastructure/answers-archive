    A face detection feature in [opencv_apps](http://wiki.ros.org/opencv_apps#People.2BAC8-Face_Detection_Nodes) package takes in a [sensor_msgs/Image](http://docs.ros.org/api/sensor_msgs/html/msg/Image.html), which doesn't have to be stereo afaik.
