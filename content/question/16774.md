    Be sure you upgrade to a version of Gazebo which is currently supported, that's either Gazebo 7 or 8. Then you could do it like this:

    1. Insert a simple shape into simulation

    2. Right-click -> `Edit model`

    3. Double click -> Open the `Visual` tab

    4. Expand `visual`

    5. Under `geometry`, type in the desired values

    6. Repeat 3~5 for collision

    7. `File` -> `Exit model editor`

    8. `Save and Exit`

    Voila :)

    Another way of doing it is through code using ROS. There you can customise the simple geometry objects as you want and have finer control.

    I've done it for Gazebo 7, but it will work for previous versions for sure. Here I leave you the video response: [VideoResponse](https://youtu.be/5RqLprd5C8Q)

    ![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/1504517024430773.png)


    The code you need is: a urdf file (**simple_box.urdf**) with the object deffinition. Because its a simple geometry its really simple. You also need a launch file that spawns the object (**spawn_robot_urdf.launch, spawn_simple_box.launch**)  into the scene. You will need also a script that calculates the inertias (**inertial_calculator.py**) of the object based on its geometry. Or you could also state the formulas in a XACRO file, and it will recalculate based on the dimensions ( but thats perhaps outside the scope here).

    [inertial_calculator.py](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/15045164598070524.py)

    [spawn_robot_urdf.launch](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/15045164699957448.launch)

    [spawn_simple_box.launch](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/15045164806514931.launch)

    The file is an urdf, but the system doesnt allow these files, sorry for that, just remove the sdf extension.
    [simple_box.urdf.sdf](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/15045165201151286.sdf)

    Hope it helps.
