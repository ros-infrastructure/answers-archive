  body_markdown: "  \nThe plugin in `libgazebo_ros_state.so` is not a system plugin.\
    \ Inside the source code, you need to extend your plugin class from `gazebo::SystemPlugin`\
    \ and add something like\n\n    GZ_REGISTER_SYSTEM_PLUGIN(gazebo_ros_state_plugin)\n\
    \nwhere the `gazebo_ros_state_plugin` is the name of your class. See more from\
    \ https://classic.gazebosim.org/tutorials?tut=system_plugin&cat=write_plugin"
