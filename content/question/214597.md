  body_markdown: "All versions of `NodeHandle::advertiseService()` function are templated\
    \ (except for one) and template magic fails to deduce the right types. That happens\
    \ because `convert()` can be found in the base class, while the object itself\
    \ is of derived class. So, as I understand, compiler comes to the following substitution\
    \ (**Note T1 and T2**):\n\n    advertiseService (const std::string &service, bool(T1::*srv_func)(MReq\
    \ &, MRes &), T2 *obj)\n\nwhile `NodeHandle` class has only the prototypes that\
    \ expect the `srv_func` parameter to belong to the same type of object, as passed\
    \ with `obj`, i.e.\n\n    advertiseService (const std::string &service, bool(T::*srv_func)(MReq\
    \ &, MRes &), T *obj)\n\nWhat you can do here is explicitly cast the pointer to\
    \ the base class:\n\n    ros::ServiceServer srv_ = nh.advertiseService(\"pos2lin\"\
    , &convert_pos2lin::convert, (convert*) &asd);\n\nTo make sure virtual functions\
    \ are overloaded properly (if you have any), here is a small demo based on modified\
    \ [AddTwoInts tutorial](http://wiki.ros.org/roscpp_tutorials/Tutorials/UsingClassMethodsAsCallbacks#Service_Servers):\n\
    \n    #include \"ros/ros.h\"\n    #include \"roscpp_tutorials/TwoInts.h\"\n  \
    \  \n    class Base\n    {\n    public:\n      virtual bool add(roscpp_tutorials::TwoInts::Request&\
    \ req,\n                       roscpp_tutorials::TwoInts::Response& res)\n   \
    \   {\n        res.sum = op(req.a, req.b);\n        ROS_INFO(\"request: x=%ld,\
    \ y=%ld\", (long int)req.a, (long int)req.b);\n        ROS_INFO(\"  sending back\
    \ response: [%ld]\", (long int)res.sum);\n    \n        return true;\n      }\n\
    \    \n      virtual int op(int a, int b)\n      {\n        ROS_INFO(\"calling\
    \ base op()\");\n        return a + b;\n      }\n    };\n    \n    class AddTwo:\
    \ public Base\n    {\n    public:\n      virtual int op(int a, int b)\n      {\n\
    \        ROS_INFO(\"calling derived op()\");\n        return a - b;\n      }\n\
    \    };\n    \n    int main(int argc, char **argv)\n    {\n      ros::init(argc,\
    \ argv, \"add_two_ints_server\");\n      ros::NodeHandle n;\n    \n      AddTwo\
    \ a;\n      ros::ServiceServer ss = n.advertiseService(\"add_two_ints\", &AddTwo::add,\
    \ (Base*) &a);\n    \n      ros::spin();\n    \n      return 0;\n    }\n\n"
