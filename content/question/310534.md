    Yes is it necessary to calibration any camera for it to be used with ar_track_alvar. This is because it uses the lens model of the camera to be able to project the 2D marker features in the image into 3D. Every camera (even of the same make and model) will have slightly different calibration parameters so they all need individual calibration.

    Hope this makes sense.
