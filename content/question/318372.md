  body_markdown: "After some attempts to reveal the source of problem I found a solution.\
    \ There are no correct realizations of `SteadyTimer` system entity on some VLIW\
    \ and SPARC-like platforms. This leads any function using `SteadyTimer` to return\
    \ immediately after calling. In threaded implementation such fun\u0441tions consume\
    \ all CPU time just for continuous function calls. This issue can be solved with\
    \ replacement of all SteadyTimer-related calls to equivalents which use `WallTimer`.\
    \ \n\nThere is brilliant solution on GitHub made by Christopher Wecht: https://github.com/cwecht/ros_comm/tree/fix_subscription_busy_wait-melodic\
    \ His solution makes ROS core true platform-independent on the described case.\n\
    \nTo integrate Christopher's solution into the existing ROS sources it is only\
    \ needed to replace `src/ros_comm/roscpp` directory with variant from [here](https://github.com/cwecht/ros_comm/tree/fix_subscription_busy_wait-melodic/clients).\
    \ After that compiled ROS works properly on VLIW platforms."
