    \ (e.g using `attachInterrupts`) which is described in the [notes of the arduino\
    \ docs](https://www.arduino.cc/reference/en/language/functions/time/delay/):\n\
    > Certain things do go on while the delay() function is controlling the Atmega\
    \ chip, however, because the delay function does not disable interrupts. Serial\
    \ communication that appears at the RX pin is recorded, PWM (analogWrite) values\
    \ and pin states are maintained, and interrupts will work as they should."
