  body_markdown: "Make sure you're setting the virtual joint with the correct robot\
    \ base link.\nAssuming you're using the WidowX arm from [RobotnikAutomation](http://wiki.ros.org/widowx_arm),\
    \ you should be using [base_footprint](https://github.com/RobotnikAutomation/widowx_arm/blob/master/widowx_arm_description/robots/widowx_arm.urdf.xacro#L5)\
    \ as the child frame name. You can check the root link for a robot URDF/Xacro\
    \ using e.g.\n\n    check_urdf <(xacro --inorder $(rospack find widowx_arm_description)/robots/widowx_arm.urdf.xacro)\n\
    \n[Source](https://answers.ros.org/question/9208/how-to-check-xacro-syntax-like-check_urdf/)\n\
    \nOften, Gazebo-specific code is placed in a separate `.xacro` file that incorporates\
    \ the original URDF. Such a file might look like:\n\n    <?xml version=\"1.0\"\
    \ ?>\n    <robot name=\"widowx_arm\" xmlns:xacro=\"http://ros.org/wiki/xacro\"\
    >\n      <xacro:include filename=\"$(find widowx_arm_description)/robots/widowx_arm.urdf.xacro\"\
    />\n    \n      <!-- Used for fixing robot to Gazebo 'base_link' -->\n      <link\
    \ name=\"world\"/>\n      <joint name=\"fixed\" type=\"fixed\">\n        <parent\
    \ link=\"world\"/>\n        <child link=\"base_footprint\"/>\n      </joint>\n\
    \    </robot>\n\n"
