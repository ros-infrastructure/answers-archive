  - body_markdown: "If you have a `roslaunch` binary/script in `/usr/bin`, then you\
      \ must likely have the `python3-roslaunch` package installed.\n\nThat's not\
      \ the same package as `ros-noetic-roslaunch`, which would place `roslaunch`\
      \ in `/opt/ros/noetic/bin`.\n\nDoes `dpkg -l | grep roslaunch` return both `python3-roslaunch`\
      \ and `ros-noetic-roslaunch` for you, or just `python3-roslaunch`? If the latter,\
      \ that's why you don't have `roslaunch`.\n\nAs to how you ended up in this situation,\
      \ I don't know.\n\n>  Can I uninstall everything ROS? \n\nYes, you'd essentially\
      \ remove all `ros-noetic-*` packages, and afterwards probably all packages which\
      \ are then no longer needed (`apt` should tell you).\n\nFor the upstream packages,\
      \ you'd have to figure out which packages you have installed. I don't have any\
      \ specific advice on how to do that.\n\n> Would I have to reformat my hard drive\
      \ and re-install Ubuntu?\n\nThat would be the nuclear option, and technically\
      \ not necessary. As long as you have the right pkgs installed, it should work."
