  body_markdown: |-
    ROS is not special in terms of cpu usage. It does not control which core does what job, your OS will manage that via a scheduler. If the scheduler was the problem, you would notice it on all other applications. See [stackoverflow](https://stackoverflow.com/questions/12880606/how-to-run-each-thread-on-other-core).

    However, you can allow ROS to use multiple *threads*. This is done via specifying the executor for your nodes, see [documentation on executors](https://docs.ros.org/en/foxy/Concepts/About-Executors.html), and in turn their callback groups. There was a [recent writeup on how it works](https://discourse.ros.org/t/how-to-use-callback-groups-in-ros2/25255), I recommend reading it if you are interested in it.
