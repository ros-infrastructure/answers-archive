  body_markdown: "This is a bug in versioning for drcsim nightly releases.\n\nDebian\
    \ versioning policy (and Ubuntu) considers *5.1.10* greater than *5.1.10~hgxxx*\
    \ so the system is complaining about now having a valid sandia-hand *>=5.1.10*\
    \ version.\n\nA [fix](https://bitbucket.org/osrf/drcsim-release/commits/81463c3f3bcb60deba42520c89f66384f5a1b641)\
    \ is already in the repo and should make tomorrow nightly build to not suffer\
    \ from this error.\n\n**Workaround:**\n\nDownload manually drcsim-nightly package\
    \ from [gazebosim.org](http://gazebosim.org/assets/distributions/) and install\
    \ it ignoring sandia-hand dependency:\n\n> sudo apt-get install sandia-hand-nightly\
    \ # to be sure of have it installed\n\n> sudo dpkg -i --ignore-depends=sandia-hand-nightly\
    \ drcsim-nightly_*.deb\n\n \n "

      By the way, you can't mix drcsim/gazebo installations using apt-get and those where you compile source. Unless you intervene, apt-get installations install to /usr/share, bin, include, lib while compiling by source installs to /usr/local/share, bin, include, lib. Unless you are very careful with your $PATH, these two installations interfere with each other. So no compiling by source if you want to use the nightly versions.
