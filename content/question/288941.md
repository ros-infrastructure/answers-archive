  body_markdown: "Based on your code, the request to `service` is processed at `ros::spinOnce()`,\
    \ and `client.call()` is waiting the response from `service`. Then a deadlock\
    \ happens and your program gets stuck at `client.call()` as you found.\n\nUsing\
    \ two different nodes, or two processes, is the best way to implement this example\
    \ because the purpose of `ServiceServer` is to provide service to any clients.\
    \ If you still require to implement this example in a node, I would suggest you\
    \ create a thread to handle either `ros::spinOnce()` or `client.call`.\n\n   \
    \ #include<thread>\n    void spin_wrapper()\n    {\n      ros::spin();\n    }\n\
    \    ...\n    int main(int argc, char *argv[])\n    {\n      ...\n      //create\
    \ and start a thread\n      std::thread spin_thread(spin_wrapper);\n      //send\
    \ request\n      if(client.call(srv))\n      {\n        ROS_INFO(\"Sum: %ld\"\
    , (long int)srv.response.sum);   \n      \n      }\n      else\n      {\n    \
    \    ROS_ERROR(\"Failed to call service add_two_ints\");\n        return 1;\n\
    \      }\n      //ros::spinOnce();\n    }\n\nNote that `thread` works since C++11\
    \ so your `CMakeLists.txt` file should add `add_compile_options(-std=c++11)` to\
    \ enable the function.\n\nUpdate\n\nThank @gvdhoorn for better solutions of multi-threaded\
    \ spinners. \nI update the solution using `ros::AsyncSpinner`.\n\n    int main(int\
    \ argc, char *argv[])\n    {\n      ...\n      //create and start a thread\n \
    \     ros::AsyncSpinner spinner(1); // Use 1 thread\n      spinner.start();\n\
    \      //send request\n      if(client.call(srv))\n      {\n        ROS_INFO(\"\
    Sum: %ld\", (long int)srv.response.sum);   \n      \n      }\n      else\n   \
    \   {\n        ROS_ERROR(\"Failed to call service add_two_ints\");\n        return\
    \ 1;\n      }\n      //ros::spinOnce();\n    }"
