 Hi, I have an Ubuntu installation with ROS Melodic, and I am trying to build my packages using [bloom](https://wiki.ros.org/bloom).
ROS Melodic is running on python2, but the python code in my package is running on python3.

I can `catkin_make` my package with the argument `-DPYTHON_EXECUTABLE="/usr/bin/python3"`, but if I run `bloom-generate` and then `fakeroot debian/rules binary`, the build fails.
I solve this by manually adding the argument `-DPYTHON_EXECUTABLE="/usr/bin/python3"` in `override_dh_auto_configure` in the *debian/rules* file, and now my build succeeds.

Is there a way to add this line automatically, using bloom?
