    I've just had a look at the source code for the mapviz image plugin and you're right, you can [see here](https://github.com/swri-robotics/mapviz/blob/indigo-devel/mapviz_plugins/src/image_plugin.cpp#L391) that it doesn't currently support RGBA image rendering. There are two parts which will need to be modified in order to get this working if you want to adapt it.

    Firstly the [image callback function here](https://github.com/swri-robotics/mapviz/blob/indigo-devel/mapviz_plugins/src/image_plugin.cpp#L315) will need to detect and handle images with transparency as well as normal BGR images.

    Secondly the [DrawIplImage function](https://github.com/swri-robotics/mapviz/blob/indigo-devel/mapviz_plugins/src/image_plugin.cpp#L391) here will need modifiying so that it detects images with transparency and uses the GL_RGBA format as described in the [OpenGL documention here](https://lmb.informatik.uni-freiburg.de/people/reisert/opengl/doc/glDrawPixels.html).

    If you're up for modifying this plugin it doesn't seem like that much work to get it to support images with alpha channels. Let me know if you have any other questions about getting this working.
