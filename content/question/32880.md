  body_markdown: "Here is a snippet of code I have used to do this and the full code\
    \ is [here](https://github.com/walchko/camera_node). It is a package that also\
    \ uses opencv to grab images and publish them. Some of the variables are:\n\n\
    \    image_transport::ImageTransport transport;\n    image_transport::CameraPublisher\
    \ image_pub;\n    camera_info_manager::CameraInfoManager info_mgr;\n\nAnd the\
    \ code:\n            \n            // if subscribers, pub images\n           \
    \ if(image_pub.getNumSubscribers() >  0) {\n\n                ros::Time time =\
    \ ros::Time::now();\n\n                // convert OpenCV image to ROS message\n\
    \                cv_bridge::CvImage cvi;\n                cvi.header.stamp = time;\n\
    \                cvi.header.frame_id = \"image\";\n                cvi.encoding\
    \ = \"bgr8\";\n                cvi.image = cv_image;\n\n                // get\
    \ camera parameters \n                sensor_msgs::CameraInfo info = info_mgr.getCameraInfo();\n\
    \                info.header.stamp = cvi.header.stamp;\n                info.header.frame_id\
    \ = cvi.header.frame_id; // whatever it is called\n                info.width\
    \ = cv_image.cols;\n                info.height = cv_image.rows;\n\n         \
    \       sensor_msgs::Image im;\n                cvi.toImageMsg(im);\n        \
    \        image_pub.publish(im,info);\n            }"
