  body_markdown: "Hi @Patrickelectric ,\n\nthat happens because you have to call `ros::init()`\
    \ BEFORE the instantiation of your `ros::NodeHandle`.\n\nAs an example, If you\
    \ compile the code below (from [Writing a Simple Publisher and Subscriber ](http://wiki.ros.org/ROS/Tutorials/WritingPublisherSubscriber%28c%2B%2B%29)\
    \ tutorial ), as is, it will work because `ros::init` is being called first. But\
    \ if you uncomment the `nodeBeforeRosInitWillFail` node, you will see that this\
    \ error happens since `ros::init` is called AFTER `nodeBeforeRosInitWillFail`.\n\
    \n    #include \"ros/ros.h\"\n    #include \"std_msgs/String.h\"\n    \n    #include\
    \ <sstream>\n    \n    int main(int argc, char **argv)\n    {\n    \n      /**\n\
    \       * Definining a ros::NodeHandle before ros::init causes the error\n   \
    \    * To confirm that, just uncomment the  nodeBeforeRosInitWillFail node below\n\
    \       */\n      //ros::NodeHandle nodeBeforeRosInitWillFail;\n    \n      ros::init(argc,\
    \ argv, \"talker\");\n    \n      ros::NodeHandle n;\n    \n      ros::Publisher\
    \ chatter_pub = n.advertise<std_msgs::String>(\"chatter\", 1000);\n    \n    \
    \  ros::Rate loop_rate(10);\n    \n      int count = 0;\n      while (ros::ok())\n\
    \      {\n    \n        std_msgs::String msg;\n    \n        std::stringstream\
    \ ss;\n        ss << \"hello world \" << count;\n        msg.data = ss.str();\n\
    \    \n        ROS_INFO(\"%s\", msg.data.c_str());\n    \n        chatter_pub.publish(msg);\n\
    \    \n        ros::spinOnce();\n    \n        loop_rate.sleep();\n        ++count;\n\
    \      }\n      return 0;\n    }\n\nYou can see this example in the following\
    \ video (https://youtu.be/UsuQwUkzNII) if you prefer."
