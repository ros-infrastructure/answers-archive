    \ API](http://wiki.ros.org/ROS/Slave_API) would be more efficient (and perhaps\
    \ less error prone). Specifically the `getPid(..)` service.\n\n---\n\nEdit: try\
    \ this. It prints the PIDs of all nodes known to a specific ROS master.\n\nIf\
    \ you don't specify a XMLRPC URI of a specific ROS master, it will use whatever\
    \ is currently configured in your shell (ie: the value of the `ROS_MASTER_URI`\
    \ env var).\n\nThe same information can be retrieved using a bare-bones XMLRPC\
    \ (Python) client, but it would be a bit more work. It would avoid the dependency\
    \ on `rosgraph` and `rosnode`, so could work from any OS with a suitable XMLRPC\
    \ client.\n\n    #!/usr/bin/env python\n    import rosnode\n    import rosgraph\n\
    \    import sys\n    import argparse\n    \n    # lots of things 'borrowed' from\
    \ rosnode\n    \n    try:\n        from xmlrpc.client import ServerProxy\n   \
    \ except ImportError:\n        from xmlrpclib import ServerProxy\n    \n    parser\
    \ = argparse.ArgumentParser()\n    parser.add_argument('ROS_MASTER_URI', type=str,\
    \ nargs='?', metavar='URI', help='ROS master URI to use.')\n    args = parser.parse_args()\n\
    \    \n    ID = '/rosnode'\n    master = rosgraph.Master(ID, master_uri=args.ROS_MASTER_URI)\n\
    \    print (\"Using master at {}\".format(master.getUri()))\n    \n    nodes =\
    \ rosnode.get_node_names()\n    print (\"Known nodes: \" + ', '.join(nodes))\n\
    \    \n    for node in nodes:\n        print (\"  \" + node)\n    \n        node_api\
    \ = rosnode.get_api_uri(master, node)\n        if not node_api:\n            print(\"\
    \    API URI: error (unknown node: {}?)\".format(node))\n            continue\n\
    \        print (\"    API URI: \" + node_api)\n    \n        node = ServerProxy(node_api)\n\
    \        pid = rosnode._succeed(node.getPid(ID))\n        print (\"    PID   \
    \ : {}\".format(pid))\n\nMost of this is done by `rosnode` as well, so I used\
    \ that as a reference. See [ros_comm/rosnode/src/rosnode/__init__.py](https://github.com/ros/ros_comm/blob/1e67842d7624205d94ed697c830c455d3f099db1/tools/rosnode/src/rosnode/__init__.py)."

    With `rosnode list` you have the list of nodes.

    `rosnode info /rosout 2>/dev/null | grep Pid| cut -d' ' -f2`

    If a node named `/rosout` exists, the PID (like 5027) will be shown. Otherwise, nothing will be printed because we are redirecting the error to `/dev/null`
