  body_markdown: |-
    1. Inside `populated-_shelf.dae`, make sure the texture URI (a png file perhaps?) is correct, it's a good idea if it starts with `model://` or `file://`
    1. You said your model is set static, but the code says it isn't: `<static>0</static>`. This means the shelf should move. Maybe you're not bumping strong enough? Try pushing it with the [Force / Torque tool](http://gazebosim.org/tutorials?tut=apply_force_torque&cat=tools_utilities). Note that the shelf and the boxes are being treated as a single solid mass, you'll need to tweak some things if you want the boxes to move independently.

    ### Update

    For the boxes to move independently, they must consist of separate links on SDF, each with its own mass, visual and collision.

    I recommend you look at an example, such as [Polaris Ranger EV](https://bitbucket.org/osrf/gazebo_models/src/605a402bd4c23232002b4a2ba7113ae885051bbe/polaris_ranger_ev/model.sdf?at=default&fileviewer=file-view-default) or [Zephyr Delta Wing](https://bitbucket.org/osrf/gazebo_models/src/605a402bd4c23232002b4a2ba7113ae885051bbe/zephyr_delta_wing/model.sdf?at=default&fileviewer=file-view-default). Look for the `submesh` tags and see how they correspond to geometries / nodes on the COLLADA file.
