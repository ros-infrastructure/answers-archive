  body_markdown: "I assume you want the latitude and longitude values from one message\
    \ in your main thread?\n\nYou can wait on a result from the subscriber using a\
    \ threading.Event object. The \"InfoGetter\" is better contained in a class than\
    \ global variables and a function. Here is working code.\n\n    import rospy\n\
    \    from sensor_msgs.msg import NavSatFix\n    import threading\n       \n  \
    \      \n    class InfoGetter(object):\n        def __init__(self):\n        \
    \    #event that will block until the info is received\n            self._event\
    \ = threading.Event()\n            #attribute for storing the rx'd message\n \
    \           self._msg = None\n        \n        def __call__(self, msg):\n   \
    \         #Uses __call__ so the object itself acts as the callback\n         \
    \   #save the data, trigger the event\n            self._msg = msg\n         \
    \   self._event.set()\n    \n        def get_msg(self, timeout=None):\n      \
    \      \"\"\"Blocks until the data is rx'd with optional timeout\n           \
    \ Returns the received message\n            \"\"\"\n            self._event.wait(timeout)\n\
    \            return self._msg\n     \n    if __name__ == '__main__':\n       \
    \ rospy.init_node('infoGetter', anonymous=True)\n        #Get the info\n     \
    \   ig = InfoGetter()\n        rospy.Subscriber(\"/novatel/fix\", NavSatFix, ig)\n\
    \        #ig.get_msg() Blocks until message is received\n        msg = ig.get_msg()\n\
    \        print msg\n\n\nYou can test that this code works by starting a roscore,\
    \ running this script, and executing the following command\n\n    rostopic pub\
    \ /novatel/fix sensor_msgs/NavSatFix \"{latitude: 4.0, longitude: 5.0}\""
