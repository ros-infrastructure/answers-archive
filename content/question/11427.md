  body_markdown: "To get this working, you have to use a better skelaton build.xml\
    \ file than provided on the ROSJAVA wiki.  The one I used is below.  It basically\
    \ adds the jar information to the build settings.\n\nYou must build the jar file\
    \ from the ANT window in eclipse in order to create a new jar file each time you\
    \ want to recompile. I haven't found a way to automate that part yet. \n\n   \
    \ <?xml version=\"1.0\" encoding=\"UTF-8\"?>\n    <project name=\"my_second_package\"\
    \ default=\"default\">\n    \n      <property file=\"ros.properties\" />\n   \
    \   <property name=\"build\" location=\"build\" />\n    \n      <property name=\"\
    dist\" location=\"dist\" />\n      <property name=\"build\" location=\"build\"\
    \ />\n      <property name=\"src\" location=\"src\" />\n      <property name=\"\
    jar\" location=\"${ros.artifact.built}\" />\n    \n      <path id=\"classpath\"\
    >\n        <pathelement path=\"${ros.compile.classpath}\" />\n      </path>\n\
    \    \t\n    \t<echo message=\"${toString:classpath}\" />\n    \n      <target\
    \ name=\"default\" depends=\"init, compile, jar\" />\n    \n      <target name=\"\
    init\">\n        <fail unless=\"ros.compile.classpath\" message=\"ros.properties\
    \ is missing.  Please type 'rosmake' first \"/>\n        <mkdir dir=\"${build}\"\
    \ />\n        <mkdir dir=\"${dist}\" />\n      </target>\n    \n      <target\
    \ name=\"compile\" depends=\"init\">\n    \n        <javac destdir=\"${build}\"\
    >\n          <classpath refid=\"classpath\" />\n          <src path=\"${src}\"\
    \ />\n        </javac>\n      </target>\n    \n    \t  <target name=\"jar\" depends=\"\
    compile\">\n    \t    <jar destfile=\"${jar}\">\n    \t      <fileset dir=\"${build}\"\
    \ />\n    \t    </jar>\n    \t  </target>\n    \t\n      <target name=\"clean\"\
    >\n        <delete dir=\"${build}\" />\n        <delete dir=\"${dist}\" />\n \
    \     </target>\n    \n      <!-- required entry point -->\n      <target name=\"\
    test\" />\n    \n    </project>\n\n"
