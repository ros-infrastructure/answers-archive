  body_markdown: "To get path of your package you can use `rospack` package. Take\
    \ a look at examples [here](http://wiki.ros.org/Packages#Client_Library_Support).\n\
    \nThis is basically it:\n\n    import rospkg \n    rospack = rospkg.RosPack()\n\
    \    # get the file path for rospy_tutorials\n    rospack.get_path('rospy_tutorials')\n\
    \n\nIn order to install your scripts you need to use cmake's [install](https://cmake.org/cmake/help/v3.0/command/install.html).\n\
    \nFor example like this:\n\n    install(PROGRAMS\n      \"scripts/my_script\"\n\
    \      DESTINATION bin\n    )\n\nThen it depends on if you're using catkin_make\
    \ or catkin build command. To install the script you run `catkin_make install`.\
    \ Or if you're using catkin build you need to config your package with catkin\
    \ `config config --install` and then run `catkin build`.\n\nThis should install\
    \ your script to install directory of your root's workspace."

I have created a `/csv` and `/scripts` directories in my `/src` directory. The `/csv` directory contains a csv file and `/scripts` directory contains a Python script to parse the csv file. The first few lines of the script is as follows -

    import csv
    with open('/home//default_ws/src/<package_name>/csv/alarms.csv', 'rb') as csvfile:
        reader = csv.reader(csvfile)
        for row in reader:

How can I add a generic location path for the csv file in my Python script? And what modifications do I need to make in my `CMakelists.txt` in order to install the `/csv` and `/scripts` directories?

*** CORRECT ANSWER ***

    import csv
    import os, rospkg
    rospack = rospkg.RosPack()
    with open(os.path.join(rospack.get_path("package_name"), "csv", "alarms.csv"), 'rb') as csvfile:
        reader = csv.reader(csvfile)
        for row in reader:
