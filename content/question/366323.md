  body_markdown: "In Nav2, you can have `N` different plugins in the controller server,\
    \ rather than just 1. So you can load both of your plugins to use in the controller\
    \ server and have them individually callable by their \"name\" namespace using\
    \ the BT nodes for follow path. There's a `controller_id` field that defaults\
    \ to the default ID we assign in the controller server, but that can be set to\
    \ a different value in the section of the behavior tree that requires another\
    \ controller. \n\n"
