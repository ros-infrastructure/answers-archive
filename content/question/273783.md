  body_markdown: "Hi rozoalex,\n\nYou can find an overview of how the ROS navigation\
    \ stack works here: http://wiki.ros.org/nav_core?distro=lunar\n\nDetails of the\
    \ local planner here: http://wiki.ros.org/base_local_planner?distro=lunar\n\n\
    Details of the global planner here: http://wiki.ros.org/global_planner?distro=lunar\n\
    \nThis is the basic scheme: \n\n![image description](http://wiki.ros.org/nav_core?action=AttachFile&do=get&target=move_base_interfaces.png)\n\
    \nAs you can see, both the local planner and the global planner use a [costmap](http://wiki.ros.org/costmap_2d?distro=lunar)\
    \ (a 2D o 3D representation of free/occupied space) constructed using sensor information.\n\
    \nIf you want to add information from new sensors for the local costmap to consider\
    \ you should do so by adding new layers to the local costmap. The layer type will\
    \ depend on the sensor type. You should check the tutorials and documentation\
    \ of the costmap_2d package.\n\nI hope this helps "
