  body_markdown: "It would help us if you could also identify the goal of seeing this\
    \ information. If you're trying to see this information in a terminal, you can\
    \ use:\n\n    rosrun tf view_frames /map /odom\n\nor \n\n    rosrun tf view_frames\
    \ /map /base_link\n\nIf you're trying to do this in code, you can perform this\
    \ lookup in code as well. \n\n      // Look up transform between base link and\
    \ the map frame.\n      tf::StampedTransform xform;\n      try\n      {\n    \
    \    // The waypoint frame is the source frame\n        tf_.lookupTransform(\"\
    /map\", \"/base_link\", ros::Time(0), xform);\n      }\n      catch (tf::TransformException\
    \ ex)\n      {\n        ROS_ERROR(\"%s\", ex.what());\n      }"
