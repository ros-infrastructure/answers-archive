  body_markdown: "I figured out how to calculate joint efforts from gravity using\
    \ KDL's Python API.\n\nThe kdl.ChainDynParam class provides a JntToGravity method\
    \ which will produce the joint torques needed to counteract the effects of gravity.\n\
    \n\nExample:\n\n    import PyKDL as kdl\n    \n    # Given: kdl_tree, base_link,\
    \ end_link\n    \n    chain = kdl_tree.getChain(base_link, end_link)\n    # Assuming:\
    \ chain contains 3 rotational joints\n    \n    grav_vector = kdl.Vector(0, 0,\
    \ -9.81)  # relative to kdl chain base link\n    dyn_kdl = kdl.ChainDynParam(chain,\
    \ grav_vector)\n    jt_positions = kdl.JntArray(3)\n    jt_positions[0] = 0.0\n\
    \    jt_positions[1] = 0.0\n    jt_positions[2] = 0.0\n    \n    grav_matrix =\
    \ kdl.JntArray(3)\n    dyn_kdl.JntToGravity(jt_positions, grav_matrix)\n\n   \
    \ gravity_compensating_jt_torques = [grav_matrix[i] for i in range(grav_matrix.rows())]\n\
    \    \n----------\nOrocos KDL repository: https://github.com/orocos/orocos_kinematics_dynamics\
    \  \nPyKDL Documentation *(incomplete)*: http://docs.ros.org/diamondback/api/kdl/html/python/"
