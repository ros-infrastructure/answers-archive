    \ command\n\n ``` sudo apt-get install ros-melodic-turtlebot3-* ```\n\n2) The\
    \ second method is to install the package from source. For that you need to clone\
    \ the following Github package \nhttps://github.com/ROBOTIS-GIT/turtlebot3\ninto\
    \ the 'src' folder of you catkin workspace and build the workspace using ```catkin\
