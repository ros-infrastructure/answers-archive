    The build tools can't find the `android` command.

    You need to install the android developer tools and make sure they are on your PATH. See [these instructions](http://www.ros.org/wiki/ApplicationsPlatform/Clients/Android#line-31) for a more detailed description of how to do this.

    If you can't run `android` from a command prompt, the build tools won't be able to either.
