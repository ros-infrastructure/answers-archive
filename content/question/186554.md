  body_markdown: "You can run\n\n    rosrun tf tf_monitor\n\nto see which nodes publish\
    \ which frames to tf. Alternatively, you can run\n\n \n\n      rosrun tf view_frames\n\
    \nand view the resulting PDF. \n\nThere is no generic way to know which frames\
    \ are used inside a node, however. All nodes with tf TransformListeners receive\
    \ all messages published on the tf topic, so from a ROS communication layer view\
    \ there is no way to know."
