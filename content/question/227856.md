  body_markdown: "You are trying to acces the MultiArray directly over the `[]` operator.\n\
    Check the [message definition here](http://docs.ros.org/api/std_msgs/html/msg/Int32MultiArray.html).\n\
    \nYou need to do a\n\n    vec.data[i++] = temp; \n\nas, the `data` field is actually\
    \ the vector representation.\nAlso, make sure that the vector is big enough, so\
    \ you don't get an index error. Use either the respective `resize` function or\
    \ do `push_back` the new values."
