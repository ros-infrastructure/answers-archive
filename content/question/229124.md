  body_markdown: "It works for me. \n\nRun the driver in one terminal (with a PCAP\
    \ or using the raw device):\n\n    roslaunch velodyne_pointcloud 32e_points.launch\
    \ pcap:=~/Downloads/velodyne/32e.pcap\n \nRun ``rviz`` in another. \n\nIn a third\
    \ terminal run ``rqt``.\n\n* select Plugins>>Configuration>>Dynamic Reconfigure\n\
    * click on the ``cloud_nodelet``\n* set ``view_width`` to something less than\
    \ 2*PI\n* set ``view_direction`` to the desired angle (0 is straight ahead)"
