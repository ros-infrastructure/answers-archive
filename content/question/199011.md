  body_markdown: "[Line List](http://wiki.ros.org/rviz/DisplayTypes/Marker#Line_List_.28LINE_LIST.3D5.29)\
    \ is to draw lines for you case. Push start and end point of each line to line\
    \ list variable in order. \n\n> It will draw a line between each pair\n> of points,\
    \ so 0-1, 2-3, 4-5, ...\n\nThis [puslihing rviz marker lines](http://wiki.ros.org/rviz/Tutorials/Markers%3A%20Points%20and%20Lines)\
    \ tutorial is helpful.\n\n----------\n\n        //some code with comments\n  \
    \  \n        //publisher for line list marker\n        ros::Publisher marker_pub\
    \ = n.advertise<visualization_msgs::Marker>(\"visualization_marker\", 10);\n \
    \       \n       //variable for line list marker    \n        visualization_msgs::Marker\
    \ line_list;\n    \n       // frame in which you have cluster coordinates\n  \
    \      line_list.header.frame_id = \"/world_frame\";  \n      \n       //marker\
    \ type , scale,colour\n        line_list.type = visualization_msgs::Marker::LINE_LIST;\n\
    \        \n       line_list.scale.x = 0.1;\n        \n        line_list.color.r\
    \ = 1.0;\n        line_list.color.a = 1.0;\n    \n        // assume you have 5\
    \ lines \n        for (int  i = 0; i < 5; ++i) \n            {\n             \
    \ geometry_msgs::Point line_start,line_end;\n\n             // fill start and\
    \ end coordinates \n              line_start.x = sx[i];\n              line_start.y\
    \ = sy[i];\n              line_start.z = sz[i];\n    \n              line_end.x\
    \ = ex[i];\n              line_end.y = ey[i];\n              line_end.z = ez[i];\n\
    \       \n              // The line list needs two points for each line\n    \
    \          line_list.points.push_back(line_start);\n              line_list.points.push_back(line_end);\n\
    \            }\n\n            // publish marker\n            marker_pub.publish(line_list);"
