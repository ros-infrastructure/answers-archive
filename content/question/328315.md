    \ GUI.  \nHere is how to reconfigure AMCL using rqt_reconfigure's graphical user\
    \ interface:\n\nStart AMCL and pass the laser scans topic and robot base_frame_id\
    \ as parameters.\nIn my case it is:\n\n    $ rosrun amcl amcl scan:=/kobuki/laser/scan\
    \ base_frame_id:=/base_footprint\n\nOr create an amcl launch file and use that\
    \ launch file to start the amcl node.\n\nThen launch rqt_reconfigure:\n\n    $\
    \ rosrun rqt_reconfigure rqt_reconfigure\n\nYou will see the screen as follows:\n\
    \n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/1598355820371372.png)\n\
    \nClick on **amcl** on the left side panel.\n  \n  \nTo modify the parameters\
    \ on the fly, click and drag any of the sliders.\n\n\n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/15983561928458193.png)"
