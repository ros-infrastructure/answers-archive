  body_markdown: "> Can robot_localization be used with Noetic?\n\nYes.\n\nBelow are\
    \ the two ways to install [robot_localization](http://wiki.ros.org/robot_localization)\
    \ in ROS Noetic:\n\n1. **Install from Pre-built Binaries (Preferred):** Please\
    \ use the following command:\n\n        $ sudo apt install ros-noetic-robot-localization\n\
    \n2. **Install from Source:** To answer you completely, I tried this approach\
    \ as well. Please see below:\n\n        $ cd ros_ws/src\n        $ git clone https://github.com/cra-ros-pkg/robot_localization.git\
    \ --branch noetic-devel\n        $ cd ros_ws/\n        $ rosdep install --from-paths\
    \ src --ignore-src -r -y\n        $ catkin_make -DCMAKE_BUILD_TYPE=Release\n \
    \       \n\n"
