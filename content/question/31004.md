  body_markdown: "There's a vital, but subtle, distinction between a *package* and\
    \ a *stack*. It goes like this: a stack is an installation-level construct, while\
    \ a package is a user-level construct.\n\nThat is: a package never \"uses\" a\
    \ stack: it only uses other packages. Groups of packages that \"belong together\"\
    \ are *distributed* as stacks.\n\nTo have one package use another, you add the\
    \ appropriate `<depend>` tag to your `manifest.xml`; you can then `#include` headers\
    \ provided by the package you're using, link against libraries, and so on. \n\n\
    For the specific example of OpenCV, you want to add \n\n`<depend package=\"opencv2\"\
    />` \n\nto your package's `manifest.xml`, and then you can use OpenCV just as\
    \ if you'd installed the library and dealt with the various compile flags yourself."
