  body_markdown: |-
    The issue is not a direct dependency on geometry_msgs, but the message generation script ([rosserial_client/src/rosserial_clientmake_library.py](https://kforge.ros.org/rosserial/trac/browser/rosserial_client/src/rosserial_client/make_library.py)) that creates libraries for messages on the arduino. The script fails on geometry_msgs/PoseStamped.

    This issue is described in greater detail in this [ticket](https://kforge.ros.org/rosserial/trac/ticket/56), and a patch is attached to the ticket.
