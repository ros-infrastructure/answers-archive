  body_markdown: "First, install moveit on your computer\n\n    sudo apt update\n\
    \    sudo apt install ros-noetic-moveit\n\nThen you need to have a `.urdf.xacro`\
    \ file for the manipulator you are trying to setup. This is the most important\
    \ part, so make sure you have the correct file. \n\nYou can launch the assistant\
    \ with \n\n     roslaunch moveit_setup_assistant setup_assistant.launch\n\nThese\
    \ are the tabs that you need to setup for the most basic setup:\n\n 1. Start:\
    \ Create New MoveIt Configuration Package\n 2. Load your robot URDF file\n 3.\
    \ Self-Collisions: Generate Collision Matrix\n 4. Virtual Joint: Create a virtual\
    \ joint between your robot's base link and the world frame\n 5. Planning Groups:\
    \ select KDLKinematicsPlugin and add the necessary joints to the group\n 6. Robot\
    \ Poses: add desired robot poses that Moveit will have \n 7. ROS Control: setup\
    \ Joint Trajectory Controller\n 8. Finally, generate the package in your workspace.\n\
    \nYou can then test your MoveIt setup by launching the file\n\n    roslaunch [your_moveit_config_pkg]\
    \ demo.launch\n\nIf you need a video describing these steps, you can watch this\
    \ video that takes you through the process above:\n\nhttps://www.youtube.com/watch?v=QdzmMRXAks4&ab_channel=TheConstruct\n\
    \n\n\n"
