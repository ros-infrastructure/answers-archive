  body_markdown: "There is no \"full\" installation of ROS as ROS supports many different\
    \ types of robots.  It sounds like you installed the \"pr2all\" version of ROS\
    \ C Turtle, which comes with many PR2-specific capabilities.  \n\nIn Diamondback,\
    \ we have tried to streamline the stacks that you get when you install.  The packages\
    \ themselves are also about half their size in C Turtle.\n\nThe following are\
    \ the sizes of some recommended installs:\n\n442MB ros-diamondback-desktop  \n\
    1.1GB ros-diamondback-desktop-full\n\nNOTE: you have to install drivers separately.\n\
    \nIf you need to use arm navigation, which is still experimental, it will add\
    \ about 500MB to your installation."
