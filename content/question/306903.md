    This [obstacle_detector](https://github.com/tysik/obstacle_detector) package does exactly what you're looking for. I think you'll have to build this from source to get it running, apart from that you should be able to get it up and running pretty quickly.

    Just a note, this will always be detecting arcs, never circles because a laser scanner by definition can at most see half a circle at single point in time. So strictly speaking this will detect lines and arcs.

    Hope this helps.
