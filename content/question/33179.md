  body_markdown: "Hi,\nYes you can see that Kinect cloud in the rviz. But this will\
    \ only be the depth cloud and rgb cloud will not be present. \n\nFirst run the\
    \ gazebo using\n\n    roslaunch gazebo_worlds <your_world>.launch\n\nThen launch\
    \ the turtlebot_gazebo using\n\n    roslaunch turtlebot_gazebo robot.launch\n\n\
    Now try visualizing the same on rviz\n\n    rosrun rviz rviz\n\nYou can see both\
    \ images and pointclouds published by the simulated kinect in rviz. \nMake sure\
    \ your world has some objects to be scanned by the kinect.\n\nHope it helps,\n\
    \nKarthik"
