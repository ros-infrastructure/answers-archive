    \ ROS release timing is based on need and available resources\n>   - All future\
    \ ROS 1 releases are LTS, supported for five years\n>   - ROS releases will drop\
    \ support for EOL Ubuntu distributions, even if the ROS release is still supported.\
    \ \n>\n> Side effects of the release policy:\n>\n>   - Every ROS release will\
    \ be supported on exactly one Ubuntu LTS.\n>   - LTS releases will not share a\
    \ common Ubuntu release with any previous releases.\n>   - ROS releases will not\
    \ add support for new Ubuntu distributions after their release date. \n\nBuilding\
