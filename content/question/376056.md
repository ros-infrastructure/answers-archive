  body_markdown: "Hi, \n\nabout how to guide the actor, you should have a look to\
    \ the Actor plugin or better to the [AutonomousActorPlugin](https://github.com/BruceChanJianLe/gazebo-plugin-autonomous-actor).\
    \ They are written in C++, but you should be able to use them at least. \n\nAbout\
    \ the pose, actually in [C++ Gazebo API](http://osrf-distributions.s3.amazonaws.com/gazebo/api/9.0.0/classgazebo_1_1physics_1_1Entity.html#a736a629303b996ed3fd62a90ede62d0b)\
    \ there exists a method `WorldPose()`. I didn't find similar API in Phyton, but\
    \ you can read the `gazebo_msgs/ModelStates` topics that contains poses of all\
    \ model in your simulation. \n\nHope I helped you."
