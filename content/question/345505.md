    From [Melodic installation page](http://wiki.ros.org/melodic/Installation):

    > ... ROS Melodic Morenia distribution,
    > which is available for Ubuntu Artful
    > (17.10), Bionic (18.04 LTS) ...

    Official packages are not available for Ubuntu 19.04. If you need the combination of ROS Melodic + Ubuntu 19.04 you will need to install ROS from [source code](http://wiki.ros.org/melodic/Installation/Source).

    If you want a smooth ride, then install Ubuntu 18.04. Or if you really require <s>19.04</s> 20.04 (thanks for tip @gvdhoorn) and want a smooth ride then wait a couple of months until [Noetic Ninjemys](http://wiki.ros.org/Distributions#List_of_Distributions) is released.
