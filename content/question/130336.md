  body_markdown: "So you see the trajectory in rviz? That indicates that the trajectory\
    \ server indeed runs and generates data correctly. [hector_geotiff](http://wiki.ros.org/hector_geotiff)\
    \ requests the robot trajectory from [hector_trajectory_server](http://wiki.ros.org/hector_trajectory_server)\
    \ via a service, so to see if this service provides reasonable data you can execute\n\
    \n    rosservice call trajectory\n\nDoes this service call work? What is the output?\
    \ If you post output, please add to your original question by editing it.\n\n\
    /edit: Ok, it turns out that the trajectory is indeed not visible for the tutorial\
    \ launch file, as we changed things so plugins are used for adding visualization\
    \ to hector_geotiff. To get trajectory visualization make sure to set the \"plugins\"\
    \ parameter where you launch the hector_geotiff node, for example:\n\n      <node\
    \ pkg=\"hector_geotiff\" type=\"geotiff_node\" name=\"hector_geotiff_node\" output=\"\
    screen\" launch-prefix=\"nice -n 15\">\n        <param name=\"map_file_path\"\
    \ type=\"string\" value=\"$(find hector_geotiff)/maps\" />\n        <param name=\"\
    map_file_base_name\" type=\"string\" value=\"\" />\n        <param name=\"geotiff_save_period\"\
    \ type=\"double\" value=\"45\" />\n    \n        <param name=\"plugins\" type=\"\
    string\" value=\"hector_geotiff_plugins/TrajectoryMapWriter\" />\n      </node>"
