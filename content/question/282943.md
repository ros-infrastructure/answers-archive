  body_markdown: "Short answer. `rospy` nodes do not have a direct equivalent to `roscpp`\
    \ `ros::NodeHandle`.\n\nSee (almost) duplicate question and answer - including\
    \ way to resolve names relative to a rospy node's name - [here](https://answers.ros.org/question/261862/rospy-equivalent-to-rosnodehandle-nhnamespace/?answer=261999#post-id-261999).\n\
    \n---\n\nEdit:    \nYes, for rospy, in order to have `rosparam list` generate\
    \ this:\n\n    /tester/foo     \n    /rosdistro     \n    /roslaunch/uris/host_knxps13_local__35409\
    \     \n    /rosversion   \n    /run_id    \n\nYou will need to set the `foo`\
    \ as a private parameter of the `tester` rospy node:\n\n    import rospy\n   \
    \ \n    rospy.init_node('tester')\n    rospy.set_param('~foo', 1)\n    rospy.spin()\n\
    \n---\n\nAdditional info:  \nhttp://wiki.ros.org/rospy/Overview/Parameter%20Server\
    \  \nhttp://wiki.ros.org/rospy_tutorials/Tutorials/Parameters  \nhttp://wiki.ros.org/Names#Resolving"

I got the impression that a node per default has a namespace matching the node name.

Mini example, I run this node:

    import rospy
    
    rospy.init_node('tester')
    rospy.set_param('foo', 1)
    rospy.spin()

I then run `rosparam list`, I get:

    /foo
    /rosdistro
    /roslaunch/uris/host_knxps13_local__35409
    /rosversion /run_id

Why don't I get:

     /tester/foo

Why is the namespace of the node `/` and not `/tester`?
