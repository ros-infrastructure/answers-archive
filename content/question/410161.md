    \ should use conditions such as pointed by Christophe in another answer.\n\nNote\
    \ that several types of conditions exists, such as `IfCondition`, `UnlessCondition`,\
    \ `LaunchConfigurationEquals` and `LaunchConfigurationNotEquals`\n\nFor example,\
    \ to migrate the following ROS1 XML code\n\n    <include file=\"$(find pkg_1)/launch/my_file.launch\"\
    \ if=\"$(eval points != '/points')\">\n\nIn python ROS2\n\n    from ament_index_python\
    \ import get_package_share_directory\n    from launch import LaunchDescription\n\
    \    from launch.actions.include_launch_description import IncludeLaunchDescription\n\
    \    from launch.conditions import LaunchConfigurationNotEquals\n    from launch.launch_description_sources\n\
    \    import PythonLaunchDescriptionSource\n    import os\n        \n    launch_description\
    \ = LaunchDescription() \n       \n    pkg_1_include = IncludeLaunchDescription(\n\
    \      PythonLaunchDescriptionSource(\n        os.path.join(get_package_share_directory('pkg_1'),\
    \ 'launch/my_file.launch')),\n      condition=LaunchConfigurationNotEquals('points',\
    \ \"/points\"),\n    )\n    launch_description.add_action(pkg_1_include)\n\n"

 Hi,

I migrate some packages to ROS2 (humble) and I don't find an equivalent of the `if` and `unless` arguments I had in ROS1 (noetic) XML launch files for python ROS2 launchers.
I know I could achieve that with XML in ROS2 too, but I was curious to make it in python since it seems to be a more "ROSish" way to do it, nowadays. 

A very simple example ROS1 snippet  XML

     <launch>
       <arg name="viz" default="false"/>
       <node if="$(arg viz)" pkg="rviz" name="rviz" type="rviz"/>
     </launch>

Now In ROS2, I have the following python file, but the rviz node run is not conditioned to the value of `viz` anymore.

    from launch import LaunchDescription
    from launch.actions import DeclareLaunchArgument
    from launch.substitutions import TextSubstitution
    from launch_ros.actions import Node
    
    def generate_launch_description():
      launch_description = LaunchDescription()
    
      viz_arg = DeclareLaunchArgument("viz", default_value=TextSubstitution(text="false"))  
      launch_description.add_action(viz_arg)
    
      rviz_node = Node(
        package='rviz2',
        executable='rviz2',
        name='rviz2',
      )
      # I'd like condition the following line with an if, I guess
      launch_description.add_action(rviz_node)
    
      return launch_description

Thanks for your help.
