  body_markdown: "Hi,\nit is currently not implemented in the stage_ros node. But\
    \ it can be implemented rather easily using the stage API. (If you do, please\
    \ make a pull request, I was planning to do something similar ;) ).\nI already\
    \ made a pull request for something similar, namely resetting the robots to their\
    \ initial position when stage started:\nhttps://github.com/ros-simulation/stage_ros/pull/19/files\n\
    \nYou would need to implement a \"MoveRobot\" service or something similar, i.e.\
    \ create a new service in which has the robot name/number and the target position\
    \ and then move to corresponding robot.\n\nThis is the code snippet I used to\
    \ replace the robots (the initial poses are saved at startup, see [here](https://github.com/ros-simulation/stage_ros/pull/19/files#diff-85d0e0c7dc1f3bd834819d2137cba2c0R237)):\n\
    \n    StageNode::cb_reset_srv(std_srvs::Empty::Request& request, std_srvs::Empty::Response&\
    \ response){       ROS_INFO(\"Resetting stage!\"); \n    for (size_t r = 0; r\
    \ < this->positionmodels.size(); r++) {\n        this->positionmodels[r]->SetPose(this->initial_poses[r]);\n\
    \        this->positionmodels[r]->SetStall(false); }\n    return true; }"
