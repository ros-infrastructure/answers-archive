  body_markdown: |-
    base\_caster\_joint is fixed, so caster\_wheel cannot rotate. The friction between it and the ground probably is keeping the robot from moving. You can try setting caster\_wheel's friction to zero. Alternatively, you can add a gazebo element and set base\_caster\_joint's type to "ball". See http://answers.ros.org/question/138736/urdf-alternative-of-sdf-revolute2-joint-type.
