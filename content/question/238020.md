  body_markdown: "Assuming you are at least on ROS Indigo with Gazebo 2.x.\n\nThe\
    \ colors in ROS URDF and Gazebo SDF are not of the same flavour. Citing from [URDF\
    \ in Gazebo](http://gazebosim.org/tutorials?tut=ros_urdf&cat=connect_ros#Materials:Usingpropercolorsandtextures)\
    \ tutorial:\n\n> A standard URDF can specify colors using a tag such as in the\
    \ RRBot:\n>\n>     <material name=\"orange\"/>\n> With the color orange defined\
    \ separately such\n> as in the file `materials.xacro`:\n> \n>     <material name=\"\
    orange\">\n>       <color rgba=\"${255/255} ${108/255} ${10/255} 1.0\"/>\n>  \
    \   </material>\n>\n> Unfortunately, this method of\n> specifying link colors\
    \ does not work\n> in Gazebo as it adopts OGRE's material\n> scripts for coloring\
    \ and texturing\n> links. Instead, a Gazebo material tag\n> must be specified\
    \ for each link, such\n> as:\n> \n>     <gazebo reference=\"link1\">\n>      \
    \ <material>Gazebo/Orange</material>\n>     </gazebo>\n\nThese `<gazebo reference=...>`\
    \ tags allow to embed native SDF commands for model links into URDF.\n\nSo, you\
    \ should include in your URDF something like:\n\n    <gazebo reference=\"base_link\"\
    >\n      <material>Gazebo/Yellow</material>\n    </gazebo>\n\nIt is a good idea\
    \ to keep color statements both for URDF and SDF if you are going to visualize\
    \ the model both in RViz and Gazebo.\n\nIf you are only interested in Gazebo without\
    \ ROS integration, then you may prefer to use SDF to describe your robot.\n\n\
    Please refer to the [tutorial](http://gazebosim.org/tutorials?tut=ros_urdf)."

    \ to add a color on Gazebo\nbased on  this tutorial: http://gazebosim.org/tutorials/?tut=ros_urdf\n\

    \ built-in gazebo colors from *gazebo.materials* which you can find this link:\n\
    https://github.com/osrf/gazebo/blob/master/media/materials/scripts/gazebo.material\n\
    \nI wanted to add a red sphere but there was no pure red color in the built-in\
    \ ones. The present colors had either dark or light gradients. \nTo solve this\
    \ I added a custom color to the *gazebo.materials* \nI found it on my computer\
    \ on this path:(I am runing Ubuntu 20.04)\n*/usr/share/gazebo-11/media/materials/scripts/gazebo.material*\n\
    \nTo insert pure red, i added this code:\n\n    material Gazebo/RED\n        \
    \  {\n            technique\n            {\n              pass\n             \
    \ {\n                texture_unit\n                {\n                  colour_op_ex\
    \ source1 src_manual src_current 1 0 0\n                }\n              } \n\
    \            }\n          }\nThen you have to save as sudo. I used visual studio\
    \ to do that. It is possible that with other code editor it does't allow you save.\n\
