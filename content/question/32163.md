  body_markdown: "I believe you are asking two questions here:\n\n #1. How to build\
    \ a ROS package/stack - You are correct that your ROS_PACKAGE_PATH needs to be\
    \ updated to include the location where you placed ROS-Industrial.  It should\
    \ looks something like: \n\nROS_PACKAGE_PATH=<ROS-Industrial path>:~/ros_workspace:/opt/ros/electric/stacks:$ROS_PACKAGE_PATH.\
    \  Once this is set you should be able to run rosmake from the stack of interest.\n\
    \n #2. How to build the server application (which resides on the Motoman controller)\
    \ - This requires MotoPlus and associated documentation.  This is available from\
    \ Motoman.  This part should make more sense when you get familiar with MotoPlus.\n\
    \nFYI...It appears you are using ROS Electric.  Some parts of ROS-Industrial rely\
    \ on Fuerte functionality.  I suggest you upgrade ( http://ros.org/wiki/fuerte/Installation/Ubuntu\
    \ )\n\n"
