  body_markdown: "Hello,\n        I faced the same problem earlier and I could solve\
    \ the same by manipulating the signs of the encoder and thus getting proper direction\
    \ reflected. That is for the robot moving forward, both the encoders must have\
    \ the same positive sign and increment. Similarly for rotation the clockwise rotation\
    \ will have left encoder positive and right encoder negative and vice versa. \n\
    If your are using `ros_arduino_bridge` try changing the signs of the encoder data\
    \ in the `encoder_driver` file. It looks something like this\n\n    long readEncoder(int\
    \ i) {\n        if (i == LEFT) 0-return left_enc_pos;\n        else return right_enc_pos;\n\
    \      }\nFor example change the `0-return left_enc_pos` to  `return left_enc_pos`\
    \ and try to match the convention for encoder as stated above."
