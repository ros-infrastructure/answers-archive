    \ empty markfile at compile/deployment is to create it in src folder then transfer\
    \ it to the share folder. \n\n\n"

I am curious about the importance of the `resource` folder in the package branch. In most cases package consist empty file called same as package name in `resource` directory. But for example [here](https://github.com/ros2/ros2cli/tree/master/ros2cli/resource) and [here](https://github.com/ros2/rosidl_dds/tree/master/rosidl_generator_dds_idl/resource) it has some specific files. Is there any documentation about it? I couldn't find any information, [usually](https://docs.ros.org/en/foxy/Tutorials/Creating-Your-First-ROS2-Package.html) `resource` is just skipped. I would like to know the usefulness of this part package design.
