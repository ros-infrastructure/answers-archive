  body_markdown: "You will need to include the [geometry_msgs/Point](http://docs.ros.org/melodic/api/geometry_msgs/html/msg/Point.html)\
    \ message, which resides in the geometry_msgs package. This is a header generated\
    \ automatically from the Point.msg file in that package.\n\n    #include \"geometry_msgs/Point.h\"\
    \n\nAlso dont forget to add the geometry_msgs in your package.xml and CMakeLists.txt<br>\n\
    In package.xml add:\n\n    <depend>geometry_msgs</depend>\n\nIn CMakeLists.txt\
    \ add:\n\n    find_package(catkin REQUIRED COMPONENTS\n      geometry_msgs\n \
    \   )\n    \n    catkin_package(\n      CATKIN_DEPENDS geometry_msgs\n    )"
