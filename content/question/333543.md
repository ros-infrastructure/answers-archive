  body_markdown: "You created a publisher for the `/cmd_vel` topic, but you're not\
    \ using it. You need to publish a speed at which you want to move, in the direction\
    \ that you want to move using a `geometry_msgs::Twist` message.\n\nSo, in this\
    \ case you need to set the `linear.z` to a value greater than `0` and  up to`1`.\
    \ Once you reach your desired altitude, then publish a `geometry_msgs::Twist`\
    \ message with every value (`linear.{x,y,z}` and `angular.{x,y,z}`) set to `0`\
    \ which will enable the auto-hover mode and let your drone hover in (hopefully)\
    \ one spot. (See [the docs](https://ardrone-autonomy.readthedocs.io/en/latest/commands.html)\
    \ for more information about sending commands to your drone).\n\nAgain, the `Command_directions`\
    \ method needs to *publish* these commands otherwise you'll see the behavior that\
    \ you've described. For example,\n\n    def Command_directions(self, lin_x=0,lin_y=0,lin_z=0,ang_x=0,ang_y=0,ang_z=0):\n\
    \            self.Control = Twist()\n    \n            self.Control.linear.x =\
    \ lin_x \n            self.Control.linear.y = lin_y\n            self.Control.linear.z\
    \ = lin_z\n            self.Control.angular.x = ang_x\n            self.Control.angular.y\
