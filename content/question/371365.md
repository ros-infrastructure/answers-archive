  body_markdown: "Since `last_update>0`, `(now-last_update)` is calculated every time,\
    \ and both `now` and `last_update` are updated in seconds, `dt` is usually set\
    \ to `0` (zero).\n\n`dt=(now-last_update);` itself should be done every time,\
    \ but it is better to use `ros::Time::now()` instead of `ros::Time::now().toSec()`.\n\
    \nFor example, the following\n\n    ros::Time now;\n    ros::Time last_update;\n\
    \    ros::Duration dt;\n    \n    void estimate::getTime(){\n      now= ros::Time::now();\n\
    \      dt=(now-last_update);\n      last_update=now;\n      /* dt.sec : Time difference\
    \ in seconds */\n      /* dt.nsec : Time difference in nanoseconds */\n    }"
