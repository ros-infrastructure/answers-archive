    The compilation is not able to find the ignition-math lib headers.

    Be sure that you have run the `../configure` script before running cmake (as the tutorial describes it). If this does not work, please check that from your build directory you can access to the path `..\..\ign-math\build\install\%build_type%\include\ignition\math2` which is the path used in [the configure script](https://bitbucket.org/osrf/sdformat/src/3cb37c57698b5dd265677e99c4dd0e2c694b6bff/configure.bat?at=default&fileviewer=file-view-default)
