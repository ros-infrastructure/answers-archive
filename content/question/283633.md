  body_markdown: "You can send navigation goals as follows:\n\n    from geometry_msgs.msg\
    \ import Pose, Point, Quaternion\n\n    goal = MoveBaseGoal()\n    goal.target_pose.pose\
    \ = Pose(Point(1.5, -4.85, 0), Quaternion(0.0, 0.0, 0.6, 0.77))\n    goal.target_pose.header.frame_id\
    \ = \"map\" \n    goal.target_pose.header.stamp = rospy.Time() \n    self.sac.send_goal(goal,\
    \ active_cb=self.active_callback, done_cb=self.done_callback, feedback_cb=self.feedback_callback)\n\
    \nYou can define the callback functions, which you provide while sending the goal,\
    \ as follows:\n\n    def done_callback(self):\n         rospy.loginfo(\"done callback\"\
    )\n\nThe rest is up to you."
