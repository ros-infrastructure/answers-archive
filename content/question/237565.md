  body_markdown: " You can use OpenCV to do this task. You can get your disparity\
    \ map using StereoSGBM, then your depth map using reprojectImageTo3D. Once you\
    \ have your depth map, you can reconstruct your 3D scene using something like\
    \ this:\n\n    pcl::PointCloud<pcl::PointXYZRGB>::Ptr cloud (new pcl::PointCloud<pcl::PointXYZRGB>);\n\
    \t\n\t//Reconstruct PointCloud with the depthmap points\n\tfor (int i = 0; i <\
    \ depth.rows; ++i)\n\t{\n\t\tfor (int j = 0; j < depth.cols; ++j)\n\t\t{\n\t\t\
    \tpcl::PointXYZRGB p;\n\n\t\t\t//The coordinate of the point is taken from the\
    \ depth map\n\t\t\t//Y and Z  taken negative to immediately visualize the cloud\
    \ in the right way\n\t\t\tp.x = depth.at<Vec3f>(i,j)[0];\n\t\t\tp.y = -(depth.at<Vec3f>(i,j)[1]);\n\
    \t\t\tp.z = -(depth.at<Vec3f>(i,j)[2]);\n\n\t\t\t//Coloring the point with the\
    \ corrispondent point in the rectified image\n\t\t\tp.r = static_cast<uint8_t>(color.at<Vec3b>(i,j)[2]);\n\
    \t\t\tp.g = static_cast<uint8_t>(color.at<Vec3b>(i,j)[1]);\n\t\t\tp.b = static_cast<uint8_t>(color.at<Vec3b>(i,j)[0]);\n\
    \n\t\t\t//Insert point in the cloud, cutting the points that are too distant\n\
    \t\t\tif(( abs( p.x ) < 500 )&&( abs( p.y ) < 200 )&&( abs( p.z ) < 500 ))\n\t\
    \t\t\tcloud->points.push_back(p);\n\t\t}\n\t}\n\tcloud->width = (int) cloud->points.size();\n\
    \  \tcloud->height = 1;\n\n"
