    Only suggestion I can think of, is to re-run rosdep, to make sure tf2_geometry_msgs gets installed correctly. It is listed as a dependency correctly in [package.xml of rviz](https://github.com/ros2/rviz/blob/60a7269a5b88266969fd24cf154f5b2c04a8ca6a/rviz_default_plugins/package.xml#L49).

    Try running below, taken from this [step of installation procedure](https://docs.ros.org/en/rolling/Installation/Ubuntu-Development-Setup.html#install-dependencies-using-rosdep)

    In your workspace,

    ```
    rosdep update
    ```

    ```
    rosdep install --from-paths src --ignore-src --rosdistro rolling -y --skip-keys "console_bridge fastcdr fastrtps rti-connext-dds-5.3.1 urdfdom_headers"
    ```

    And re-run the colcon build command.
