    The [publisher/subscriber tutorial](http://wiki.ros.org/ROS/Tutorials/WritingPublisherSubscriber%28python%29) will get you started interacting with ROS topics, and the [`LaserScan` documentation](http://docs.ros.org/en/api/sensor_msgs/html/msg/LaserScan.html) indicates the message structure.  The rest is more of a Python question, but here's one way:

        condition_met = false  # Set outside scan_callback scope, so it's shared between callbacks

        scan_callback(msg):
            if not condition_met:  # Don't need to do anything after condition met
                for value in msg.ranges:
                    if value < 0.5:
                        condition_met = true
                        comm_pub.publish('hello')
                        return  # Don't need to check the rest
