  body_markdown: "I was able to successfully install ROS on an IGEPv2 board, which\
    \ is very similar to the original Beagleboard. Here's a rough list of steps:\n\
    \n 1. You'll have to get a working Ubuntu\n    10.10 install on the Beagleboard.\n\
    \    \n 2. Next, do an SVN-based install. You\n    can find directions for Cturtle\
    \ at\n    [Installing on Ubuntu from\n    SVN](http://www.ros.org/wiki/cturtle/Installation/Ubuntu/SVN).\n\
    \    This will take some time to install,\n    as it will have to build a lot\
    \ from\n    source on the Beagleboard. You may\n    also have to skip installing\
    \ certain\n    packages that include GUI things.\n    For example, I don't remember\
    \ if\n    Ogre compiled successfully on my\n    IGEPv2 board - if it didn't, then\n\
    \    anything that depends on Ogre such\n    as rviz would fail to compile.\n\
    \    However, since I intended the board\n    to be a headless computer, I didn't\n\
    \    really care much if visualization\n    tools failed to compile and install.\n\
    \nIf you prefer to cross-compile, checkout the docs for [eros](http://www.ros.org/wiki/eros),\
    \ which is a set of packages and tools for cross-compiling and install ROS on\
    \ embedded systems."
