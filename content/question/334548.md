    \ showed and it still compiles.\n\nThank you everyone for your help and time! "

I am trying to convert my code from using a vector of particles to a proper point cloud implementation. I want to use the octree module of PCL for radius based searches. However, when compiling the code, I get undefined references to Octree library functions.

I am using Ubuntu 18.04.3 LTS with ROS-melodic. I tried including PCL-1.8 under /usr/include in my CMakeLists.txt file as well as downloading and adding PCL-1.9.1 under my ros package (which crashes my PC during compilation). I am also not able to <code>find_package()</code> the pcl library.

Any help would be greatly appreciated.


    cmake_minimum_required(VERSION 2.8.3)
