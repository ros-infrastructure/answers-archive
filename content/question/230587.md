  body_markdown: "You can read environment variables from a launch file using `$(env\
    \ VAR)`. You could use this to read the HOSTNAME variable if that is useful, or\
    \ you could set a custom environment variable on a per-host basis and use that.\n\
    \nA more complete example would be:\n\n    <arg name=\"host\" value=\"$(env HOSTNAME)\"\
    /> "
