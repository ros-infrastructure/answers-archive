  body_markdown: "Ok. This could be a couple things. You didn't finish a bag file,\
    \ so fix the bag: \n\n    rosbag reindex 2012-07-06-11-13-31.bag.active\n\nTo\
    \ take the bag file and make it record to a different name, try this:\n\n    rosbag\
    \ record /camera/depth/points -O Camera.bag\n\nThe first command makes the bag\
    \ file playable (the laptop probably shut down in the middle of a run). \n\nThe\
    \ second one tells rosbag to record to a different file name.\n\nThis could also\
    \ be a problem with your version of rosbag. Which rosbag are you using? Which\
    \ OS? Ros version? \n\nOr, you could be recording your bag file in a place you\
    \ don't have write permissions. Try recording it in the home directory. \n\nHope\
    \ this helps!"
