  body_markdown: "Hello everyone!\nI got this working!\nAs gvdhoorn sad, the machines\
    \ where not in sync!\nTo solve this:\n\ntry `ntpdate -q <IP of your time server>`\
    \ \n\nif you get ` no server suitable for synchronization found` \n\ndo on both\
    \ machines: `    apt-get install chrony`\n\nchoos one machine as time server.\
    \ do on this machine: `sudo nano /etc/chrony/chrony.conf`\n\nAdd these lines:\
    \ \n\n    # make it serve time even if it is not synced (as it can't reach out)\n\
    \    local stratum 8\n    # allow the IP of your peer to connect\n    allow <IP\
    \ of your time-clinet>\n\nThen do on the time clinet(machine that changes its\
    \ time towards the server): `sudo nano /etc/chrony/chrony.conf`\n\n\nAdd these\
    \ lines: \n\n    server <server_ip> minpoll 0 maxpoll 5 maxdelay .05\n\nchange\
    \ maxdelay as you wish. 0.05 worked for me!\n\nrestart both machines\n\ncheck\
    \ with `ntpdate -q <IP of your time server>`\n\nif they still have a big offset\
    \ do:\n\n    sudo /etc/init.d/chrony start\n    sudo /etc/init.d/chrony stop\n\
    \ncheck again. The offset should now get better.\n\nhope that helps!"
