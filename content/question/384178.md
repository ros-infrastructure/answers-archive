    \ docs, `std::chrono::steady_clock` is used,\n\n    using \tWallTimer = GenericTimer<\

    \ docs,\n\n> Class std::chrono::steady_clock\n> represents a monotonic clock.\
    \ The time\n> points of this clock cannot decrease\n> as physical time moves forward\
    \ and the\n> time between ticks of this clock is\n> constant. This clock is not\
    \ related to\n> wall clock time (for example, it can\n> be time since last reboot),\
    \ and is\n> most suitable for measuring intervals.\n\nSo to answer your question,\
    \ **Yes, it is guaranteed never to jump backwards** (or forwards) due to midnight,\
    \ daylight savings time, user changing the system clock, clock adjustments via\
    \ NTP, etc"
