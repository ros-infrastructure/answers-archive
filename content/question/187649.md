  body_markdown: "cv_ptr->image is an instance of cv::Mat (http://docs.opencv.org/modules/core/doc/basic_structures.html#mat).\
    \ There are serveral ways to access the channels, e. g.:\n\nsplit up to entire\
    \ image separate images:\n\n    std::vector<cv::Mat> channels;\n    cv::split(\
    \ cv_ptr->image, channels );\n    \n    cv::imshow(\"OpenCV viewer uEye RGB Blue\"\
    , channels[0] );\n    cv::imshow(\"OpenCV viewer uEye RGB Red\", channels[1] );\n\
    \    cv::imshow(\"OpenCV viewer uEye RGB Green\", channels[2] );\n    cv::waitKey(3);\n\
    \nor access one pixel:\n\n    cv::Vec3b rgb_pix = cv_ptr->image.at<cv::Vec3b>(\
    \ 10, 10 );\n    \n    ROS_INFO_STREAM( \"Blue value at pos 10, 10\" << static_cast<int>(\
    \ rgb_pix[0] ) );\n    ROS_INFO_STREAM( \"Green value at pos 10, 10\" << static_cast<int>(\
    \ rgb_pix[1] ) );\n    ROS_INFO_STREAM( \"Red value at pos 10, 10\" << static_cast<int>(\
    \ rgb_pix[2] ) );\n\nor iterate the entire image, manipulating the pixels\n\n\
    \    cv::MatIterator_<cv::Vec3b> iter = cv_ptr->image.begin<cv::Vec3b>();\n  \
    \  cv::MatIterator_<cv::Vec3b> iter_end = cv_ptr->image.end<cv::Vec3b>();\n  \
    \  \n    for ( ; iter != iter_end ; ++iter )\n    {\n       (*iter)[2] = 255;\
    \ // set red channel to 255, i. e. maxium value, for every pixel\n    }\n\n  \
    \   cv::imshow(\"OpenCV viewer uEye RGB manipulated\", cv_ptr->image);\n     cv::waitKey(3);\n\
    \n\n\nSee: http://docs.opencv.org/"
