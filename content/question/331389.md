  body_markdown: "Your issue arises from not having a localisation in the map frame.\
    \ You are localising yourself in the odom frame but not in the map frame. The\
    \ transform should be as per [ROS REP 105](https://www.ros.org/reps/rep-0105.html).\
    \ To solve this since you cannot use amcl to localise in the map frame, you should\
    \ run the map in the odom frame. From default, you will be loading the map with\
    \ [map server](http://wiki.ros.org/map_server) of which has the parameter `frame_id`\
    \ which specifies what frame to load the map in. Use case will be:\n\ncommand\
    \ line\n\n    rosrun map_server map_server mymap.yaml frame_id:=odom\n\nlaunch\n\
    \n    <launch>\n    \n      <arg name=\"map_file\" default=\"$(find [package where\
    \ your map is])/mymap.yaml\"/>\n    \n      <!-- Run the map server -->\n    \
    \  <node name=\"map_server\" pkg=\"map_server\" type=\"map_server\" args=\"$(arg\
    \ map_file)\" >\n            <param name=\"frame_id\" value=\"odom\"/>\n     </node>\n\
    \    \n    </launch>"
