    The `pcl::PointCloud` object has a [header](http://docs.pointclouds.org/1.8.1/structpcl_1_1_p_c_l_header.html) with almost the same structure as a ROS message, so you can manually set the frame_id to be the same as one of the original point clouds, as below:

        newPointCloud.header.frame_id = oldPointCloud.header.frame_id;

    Hope this helps.
