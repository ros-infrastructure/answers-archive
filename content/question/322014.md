  body_markdown: "I was able to build the 3d map by the help of a position joint controller\
    \ and then using Rtab or Cartographer 3d to build the required 3d map.\n\nTo setup\
    \ rotating 2d lidar make the joint continuous and add transmission\n\n       \
    \   <joint name=\"base_to_laser_joint\" type=\"continuous\">\n            <axis\
    \ xyz=\"0 1 0\" />\n            <origin xyz=\"0.150 0 0.097\" rpy=\"-1.57 0 0\"\
    />\n            <parent link=\"top_plate\"/>\n            <child link=\"laser_link\"\
    />\n         \n          </joint>\n    \n      <transmission name=\"base_to_laser_trans\"\
    >\n        <type>transmission_interface/SimpleTransmission</type>\n        <actuator\
    \ name=\"motor1\">\n          <mechanicalReduction>1</mechanicalReduction>\n \
    \       </actuator>\n        <joint name=\"base_to_laser_joint\">\n          <hardwareInterface>hardware_interface/EffortJointInterface</hardwareInterface>\n\
    \        </joint>\n      </transmission>\n\nTo create the controller add the following\
    \ config file for your robot accordingly and then call it to launch file\n\n \
    \   marvin:\n        joint_state_controller:\n            type: joint_state_controller/JointStateController\n\
    \            publish_rate: 20\n            \n        base_to_laser_joint_position_controller:\n\
    \            type: effort_controllers/JointPositionController\n            joint:\
    \ base_to_laser_joint\n            pid: {p: 1.1, i: 1.0, d: 1.0}\n\nLaunch:\n\n\
    \    <!-- loads the controllers -->\n    <rosparam file=\"$(find marvin_description)/config/rotating_laser_control.yaml\"\
    \ command=\"load\" />\n    <node name=\"controller_spawner\" pkg=\"controller_manager\"\
    \ type=\"spawner\" ns=\"/marvin\" args=\"base_to_laser_joint_position_controller\
    \ joint_state_controller --shutdown-timeout 3\"/>\n\nFinally, publish position\
    \ values to the position command and you can see the laser rotating smoothly.\
    \ If not tune the PID dynamically for a smooth scan.\n\n  "
