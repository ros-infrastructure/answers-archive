ROS Community, I am a mentor for a high school FIRST Robotics team. We are attempting to cross compile ROS 2 dashing for our arm cortex a9 based real time linux controller (NI RoboRio). So far we have managed to build a docker container that is able to build a dashing installation from source for ubuntu 1804. When we switched to using the cross compilation instructions from `https://index.ros.org/doc/ros2/Tutorials/Cross-compilation/` we began to receive strange errors. 

So far, we have created two cmake toolchain files from scratch. The first one, which has an incorrect path for the compiler (we think) errors out while trying to find tinyxml2. Our second cmake file, which has a correct path to the valid toolchain, gives a cmake error message that that our compiler is invalid and cannot build a test program. I have included a link to the repository with all of the relevant files including the errors. 

Hopefully someone can point us in the right direction to get this working. We would be more than happy to provide any additional details.

As a note for those who are aware of previous efforts, we have also been aware of the work done by team 900 to bring melodic to the RoboRio.
