    According to the [viso2_ros wiki page](http://wiki.ros.org/viso2_ros), the input topic name for the monocular node is `image`.

    You can change the input topic name using [remapping](http://wiki.ros.org/Remapping%20Arguments).

    Try something like

        rosrun viso2_ros mono_odometer image:=/front_cam/camera/image

  body_markdown: "[viso2](http://wiki.ros.org/viso2_ros) needs rectified images, so\
    \ first you should [calibrate your camera](http://wiki.ros.org/camera_calibration/Tutorials/MonocularCalibration)\
    \ and run the node called [image_proc](http://wiki.ros.org/image_proc). After\
    \ that, you can subscribe viso2_ros mono_odometer to your rectified camera. \n\
    \nsensor_msgs/Image is the type of message, and /front_cam/camera/image is the\
    \ topic of the message. Viso2 expects this same kind of message, but in the topic\
    \ /image. That's why you have to remap it to your particular topic.\n"
