  body_markdown: "You cannot start a node using rosrun and the binary executable directly.\n\
    \nWhat you should do to deploy a node to a new target is to setup the installation\
    \ parameters in your CMakeLists.txt as [described here](http://wiki.ros.org/catkin/CMakeLists.txt#Optional_Step:_Specifying_Installable_Targets)\
    \ and run:\n\n    catkin_make install\n\nThen you can copy the package directory\
    \ containing only the install directory. If you then source this new work space\
    \ you'll be able to rosrun your node. "
