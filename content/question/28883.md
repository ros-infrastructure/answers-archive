  body_markdown: "The way the new Gazebo Garden loads models with textures is totally\
    \ different to how it used to be. See \"Textures\" towards the bottom of this\
    \ page: https://gazebosim.org/api/gazebo/3.7/migrationsdf.html \n\nTook some creative\
    \ google search to find this information. But the TLDR is instead of importanting\
    \ a model texture the old OGRE way where you defined a `.material` file that ogre\
    \ reads, you just import a MTL + OBJ or DAE file.\n\nIf you know how to use Blender\
    \ it isn't too bad. You can create your 3D model with blender and then export\
    \ it to MTL + OBJ (make sure you use PBR + Relative paths), or DAE (easier) file\
    \ format. Then include the model as\n\n    <geometry>\n      <mesh>uri://PATH_TO_MODEL</mesh>\n\
    \    <geometry>\n\n^ where PATH_TO_MODEL is the folder name of your model with\
    \ the appropriate model.sdf model.conf and other files."
