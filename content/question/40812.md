  body_markdown: "Provided the tf transforms are correctly set up and the scanner\
    \ is outputting laser_scan data, this should work. A few things you could check:\n\
    \n - Check that [tf is working](http://www.ros.org/wiki/tf/Tutorials/Debugging%20tf%20problems)\n\
    \n - Do you see other visualization\n   elements in the camera view? (i.e.\n \
    \  the grid, the arrow pointer when\n   giving a 2D nav goal etc.)\n   \n   \n\
    \ - Have you set the fixed frame in rviz\n   properly?\n   \n   \n - Does it work\
    \ with other robots/launch files? The Turtlebot or hector_quadrotor gazebo simulations\
    \ for instance can be used to quickly check that.\n\n - Is your camera calibrated\
    \ correctly? The camera view rectifies images, so this has to be correct.\n\n\
    \ - Finally, be sure that you have set the \"Overlay Alpha\" of your camera view\
    \ to something like 0.5."
