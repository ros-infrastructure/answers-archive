  body_markdown: "It doesn't really matter where `openni` is installed. As long as\
    \ your manifest, CMakeLists, and ROS environment variables are correct, you shouldn't\
    \ have a problem.  Also, you should not be having to include paths to get things\
    \ to compile.\n\nWhat you are trying to do doesn't really have much to do with\
    \ the `openni` package.  The `openni` package will connect to your depth camera\
    \ and produce the topic */camera/depth/points*.  It seems that you are trying\
    \ to subscribe to that topic.  So your package should depend on packages like\
    \ `sensor_msgs`, `pcl`, and maybe `pcl_ros`.  \n\nHere is a `manifest.xml`\n\n\
    \    <package>\n      <depend package=\"roscpp\"/>\t\n      <depend package=\"\
    sensor_msgs\"/>\n    </package>\n\nHere is a `CMakeLists.txt`\n\n    cmake_minimum_required(VERSION\
    \ 2.4.6)\n    include($ENV{ROS_ROOT}/core/rosbuild/rosbuild.cmake)\n    \n   \
    \ set(ROS_BUILD_TYPE Release)\n    \n    rosbuild_init()\n    \n    #set the default\
    \ path for built executables to the \"bin\" directory\n    set(EXECUTABLE_OUTPUT_PATH\
    \ ${PROJECT_SOURCE_DIR}/bin)\n    #set the default path for built libraries to\
    \ the \"lib\" directory\n    set(LIBRARY_OUTPUT_PATH ${PROJECT_SOURCE_DIR}/lib)\n\
    \    \n    rosbuild_add_executable(openni_subscriber src/openni_subscriber.cpp)\n\
    \nHere is a slightly modified version of your code that compiles and works correctly:\n\
    \n    #include <ros/ros.h>\n    #include <sensor_msgs/PointCloud2.h>\n    \n \
    \   void OpenniCallback(const sensor_msgs::PointCloud2ConstPtr &msg)\n    {\n\
    \        ROS_INFO(\"I heard\");\n    }\n    \n    int main(int argc, char **argv)\n\
    \    {\n        ros::init(argc, argv, \"openni_subscriber\");\n        ros::NodeHandle\
    \ n;\n        ros::Subscriber sub = n.subscribe(\"/camera/depth/points\", 1, OpenniCallback);\n\
    \        ros::spin();\n        return 0;\n    }\n\nCheck out [this page](http://wiki.ros.org/pcl/Overview)\
    \ to see examples of how to subscribe to Point Cloud messages, and [this page](http://wiki.ros.org/pcl/Tutorials)\
    \ for more complete examples on using `PCL` with ROS.\n\n\n"
