  body_markdown: "You will have to change the IP settings of one of your UST. After\
    \ that use a router to connect Lidars with your PC. Then change IPV4 settings\
    \ to manual and IP address to 192.168.0.100 (as told by hokuyo). After all this\
    \ you will be able to run both the lidars individually using the command `rosrun\
    \ urg_node urg_node _ip_address:=\"192.168.0.10\"` for the lidar with default\
    \ settings and `_ip_address:=\"192.168.0.x\"` for new settings. \n\nFor launching\
    \ both these together you can make a launch file. You can use:\n\n    <launch>\n\
    \      <node ns=\"lidar1\" pkg=\"urg_node\" type=\"urg_node\" name=\"lidar1\"\
    \ >\n        <param name=\"ip_address\" value=\"192.168.0.10\"/>\n      </node>\n\
    \      <node ns=\"lidar2\" pkg=\"urg_node\" type=\"urg_node\" name=\"lidar2\"\
    \ >\n        <param name=\"ip_address\" value=\"192.168.0.12\"/>\n      </node>\n\
    \    </launch>\n\n \nIt will work for sure. Cheers!\n"
