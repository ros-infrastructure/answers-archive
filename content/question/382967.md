    Hi,
    This is probably due to that parameters now are static per default:
    https://docs.ros.org/en/galactic/Releases/Release-Galactic-Geochelone.html#parameter-types-are-now-static-by-default

    So some clients have to be updated to handle the initialization of parameters in the correct way:
    https://github.com/ros2/rclcpp/blob/master/rclcpp/doc/notes_on_statically_typed_parameters.md

    We have also had a lot of struggle with this since many of our python clients failed and hade to be updated.
