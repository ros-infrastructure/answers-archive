    Gazebo is unable to find the "JMbot1" model, which means the directory containing JMBot1 is not in Gazebo's model path (GAZEBO_MODEL_PATH environment variable).

    Take a look at [this](http://gazebosim.org/tutorials?tut=model_structure&cat=build_robot) tutorial for more information.
