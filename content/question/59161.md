  body_markdown: "If this is for Fuerte then you will be using Gazebo 1.0. In your\
    \ [SDF](http://gazebosim.org/sdf/1.0.html) file, add a sensor element which is\
    \ a child of your link element. An example is below that includes two camera sensors\
    \ in the link called base_link\n\n    <link name = \"base_link\" >\n       <visual\
    \ name=\"base_link_visual\">\n\t  <geometry>\n\t\t<mesh filename=\"Base Assembly.stl\"\
    \ scale=\"1 1 1\"/>\n            </geometry>\n\t    \t\t<origin pose=\"0 0 0 0\
    \ 0 0\"/>\n\t    \t\t<material script=\"Gazebo/Grey\"/>\n\t  \t</visual>\n\t\t\
    <collision name=\"base_link_collision\">\n\t\t\t<geometry>\n\t\t\t\t<box size=\"\
    1.528 0.491 .825\"/>\n\t\t\t</geometry>\n\t\t\t<origin pose=\"0 0 0 0 0 0\"/>\n\
    \t\t</collision>\n\t\t<inertial mass =\"750.004\">\n\t\t\t<inertia ixx=\"67.5\"\
    \ ixy=\"0.022\" iyy=\"67\" ixz=\"-0.363\" iyz=\"-0.0352\" izz=\"25\"/>\n\t\t\t\
    <origin pose=\" 0.262 -0.005 0.053 0 0 0\" />\n\t\t</inertial>\t\n\t\t<sensor\
    \ name='cam_sensor2' type='camera' always_on='1' update_rate='15'>\n         \
    \     <origin pose='-1.25 0.4 0.5 0 0.7 1.0'/>\n              <camera>\n     \
    \           <horizontal_fov angle='1.57'/>\n                <image width='320'\
    \ height='240' format='R8G8B8'/>\n                <clip near='0.5' far='5'/>\n\
    \              </camera>\n              <plugin name='CameraPublisher' filename='libCameraPublisher.so'/>\n\
    \            </sensor>\n\t\t<sensor name='cam_sensor1' type='camera' always_on='1'\
    \ update_rate='15'>\n              <origin pose='1.25 0.4 0.5 0 0.7 2.0'/>\n \
    \             <camera>\n                <horizontal_fov angle='1.57'/>\n     \
    \           <image width='320' height='240' format='R8G8B8'/>\n              \
    \  <clip near='0.5' far='5'/>\n              </camera>\n              <plugin\
    \ name='CameraPublisher' filename='libCameraPublisher.so'/>\n            </sensor>\t\
    \n\t</link>\n\nto position your cameras use the <origin> element of the sensor.\
    \ this position is the difference compared to the link's origin.\n\nThe CameraPublisher\
    \ is a plugin that I copied probably from the Gazebo website. You shouldn't need\
    \ to change it as the configuring of the camera (size, framerate etc) occurs in\
    \ the SDF file. The CameraPublisher plugin's code is here:\n\ncamerapublisher.cpp:\n\
