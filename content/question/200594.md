  body_markdown: "Rosbag is telling you that in 4 seconds after all the publishers\
    \ are created, it will start to publish the data. This delay will allow all the\
    \ XMLRPC handshake\_to be done by the subscribers. \nIn pseudo code that look\
    \ like this : \n\n    Nodehandle n\n    pub = n.advertise(\"topic\")\n    sleep(4)\n\
    \    while(data to publish in bag file) {\n     pub.publish(data);\n     sleep(nextDataDate-now);\n\
    \    }\n\nIn the Talker / Listener sample [here](http://wiki.ros.org/ROS/Tutorials/WritingPublisherSubscriber(c%2B%2B))\
    \ the takler \"advertise\" roscore that a topic exists...\n\nWhen  Node Talker\
    \ Advertise that a topic exists, it is equivalent to say : \"Hi roscore, I am\
    \ Node \"Talker\", and I publish a data called \"chatter\", if some one is interested\
    \ (subscribing) for this data, I am reachable on this URI \"...\n\n"
