    Reading the documentation of [onInit](http://wiki.ros.org/nodelet#onInit) it should not block. Basically it prevent the surrounding nodelet manager to continue initializing the other nodelets.

    Instead you should create a timer in the `onInit` function and then publish your message in the triggered callback of the timer.
