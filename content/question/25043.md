    You need to fix the laser inertia (and fine tune the position of the model).

    Try this one (it's the inertia of the collision box)

        <inertial>
          <pose>0 0 0 0 0 0</pose>
          <mass>0.03</mass>
          <inertia>
            <ixx>2.21000000e-08</ixx>
            <ixy>0.000000</ixy>
            <ixz>0.000000</ixz>
            <iyy>6.01000000e-08</iyy>
            <iyz>0.000000</iyz>
            <izz>7.72000000e-08</izz>
          </inertia>
        </inertial>

    ![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/15890088268386394.gif)
