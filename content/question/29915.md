  body_markdown: "Is it possible that you're invoking publication of TF messages from\
    \ multiple threads? I would suggest to create a single thread per topic you are\
    \ publishing on and then interace that one with a BlockingQueue, e.g. LinkedBlockingQueue:\n\
    \n    \tBlockingQueue<tf2_msgs.TFMessage> outQueue = new LinkedBlockingQueue<tf2_msgs.TFMessage>();\n\
    \nand then in your publisher thread loop something along the lines of \n\n   \
    \ @Override\n\t\t\tprotected void loop() throws InterruptedException\n\t\t\t{\n\
    \t\t\t\tTFMessage msg = outQueue.take();\t\t\t\t\t\n\t\t\t\tpublisher.publish(msg);\n\
    \t\t\t}\n\nThis should make the publishing mechanics run in a single thread and\
    \ protect them from any concurrency issues."
