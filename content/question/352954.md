    I finally understand the problem and fixed it successfully: The main reason is `ros::package::xxx()` compatible with `boost-1.58` (installed by `sudo apt-get install libboost-all-dev`) while I was using `boost-1.70`(from source) [link](https://answers.ros.org/question/249017/rospack-segmentation-fault/). Return everything back to `boost-1.58`, everything's fine.
