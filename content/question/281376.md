    \ seems to work best with NVIDIA graphics cards. That is because it was tested\
    \ against NVIDIA graphics cards in development.\n\n----------\n\nSome thing you\
    \ can try:  \n1) Ctrl-C roslaunch window, then roslaunch again (repeat) (this\
    \ would work *most* of the time for me using an AMD graphics card).  \n\n2) Install\
    \ updates  \n\n    $ sudo apt-get dist-upgrade\n    $ sudo apt-get update\n  \
    \  $ sudo apt-get upgrade\n\n\n3) Use the proprietary driver for your graphics\
    \ card (if available)\n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/15174107871372726.png)\n\
    \n4) Get a NVIDIA graphics card - an older-ish one is fine. You're only using\
    \ it to render the scene.\n\n----------\n\nAdditional Info:  \n[Gazebo Answers](http://answers.gazebosim.org/questions/)\
