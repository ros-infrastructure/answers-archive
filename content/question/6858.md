  body_markdown: "Most of the teleop apps in ROS just send `geometry_msgs/Twist` messages.\
    \ This means a message containing a a rotation and a translation vector.\nOn gazebo\
    \ side you can implement a plugin(or use one of the existing ones)  to react on\
    \ that message.\nThere seems to be a convention to use the topic name `vel_cmd`\
    \ for this purpose. \n\n\n\nFor examples look at the movement plugins here(`skid_steering`,\
    \ `planar_move` etc...):\n\n[ros_gzplugins](http://gazebosim.org/tutorials?tut=ros_gzplugins&cat=connect_ros)\n\
    \n\nIt should be possible to use one of the existing teleop scripts to control\
    \ the robot(for example from turtlesim or pr2)\n\n"
