  body_markdown: "when you are dealing with angles you need to use quaternions. A\
    \ quaternion expresses the RPY values into 4 parameters (x,y,z,w). You should\
    \ use these in the set state commands.\nYou need to call following function to\
    \ convert RPY values into quaternion.\n    tf2::Quaternion myQuaternion;\n   \
    \ myQuaternion.setRPY( r, p, y )\nHere is a good tutorial for converting RPY values\
    \ into quaternion values. \nhttp://wiki.ros.org/tf2/Tutorials/Quaternions"
