- body_markdown: |-
    I would suggest adding a static transformer in your launch files for each robot like so:

        <node pkg="tf2_ros" type="static_transform_publisher" name="robot_world_broadcaster" args="0 0 0 0 0 0 world $(arg robot1)/base_link"/>

        <node pkg="tf2_ros" type="static_transform_publisher" name="robot2_world_broadcaster" args="0 0 0 0 0 0 world $(arg robot2)/base_link" />

    otherwise the `tf_tree`'s are not connected, so they both start at the same point. For this I would also suggest setting the position args for one of the static_transform_publisher as different, so they wouldn't overlap. For more info check out the [tf2 static_transform_publisher](http://wiki.ros.org/tf2_ros#static_transform_publisher) page.
