    Note: this *only* answers the question in the context of ROS 1.

    ---

    > On what factors is the communication protocol selected ? be it TCP or UDP

    Default is TCP (ie: `reliable`).

    Unless user specifies the *unreliable* [transport hint](http://wiki.ros.org/roscpp/Overview/Publishers%20and%20Subscribers#Transport_Hints).

    > Are there some other protocols supported as well ?

    No, not by default.

    There are some alternative transports available, but you'd have to install those yourself (they're old, but see [ethzasl_message_transport](http://wiki.ros.org/ethzasl_message_transport) fi).

    See also [ROS/Technical Overview - Topic Transports](http://wiki.ros.org/ROS/Technical%20Overview#Topic_Transports).
