    \ \n\nIn Raspberry pi add the following line to `~/.bashrc`, \n\n    export ROS_MASTER_URI=http://192.168.15.10:11311\n\
    \nand in the master ensure you do, \n\n    export ROS_IP=192.168.15.10\n\n(I usually\
    \ set IP as the hostname, i.e., `export ROS_HOSTNAME=192.168.15.10`.) \n\nFinally,\
    \ make sure you both the master desktop and raspberry pi are on the same network\
    \ and you are able to `ping` master from the raspberry pi. "
