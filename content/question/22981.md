  body_markdown: "Whenever this happend to me, the problem was the physics configuration\
    \ of the model. If you set extreme values (too big or too small) the physics engine\
    \ will run into some computational problems. \n\nHow did you arrive to the inertia\
    \ matrix for the model? Look at every place where you set some physics parameter\
    \ (mass, inertia, friction, force limits etc.) and check, whether it might cause\
    \ problems to the physics engine."
