    I believe that is because the calibration program currently does only rotation, so the parameters that can be corrected relate to the rotation readings. The linear portion is somewhat alluded to in the [main calibration page](http://www.ros.org/wiki/turtlebot_calibration) under "areas to improve". It is possible that the calibration program does not include this since rotations tend to be more of a problem in differential drive robots.

    For my own differential drive robot, I wrote my own calibration program to do linear corrections (but this does not use the laser scan - it calculates correction parameter based on "eyeballing" a 1m run and using the time taken vs the theoretical time)
