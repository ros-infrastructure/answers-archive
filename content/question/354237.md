    Maybe it's late to answer, but i couldn't find camera node too. But then i found camera as a topic with this command:

        rostopic list

    So i start to find which node publishes this camera topic.
    And logically it must be gazebo cause gazebo is producing the environment for us.

        rosnode info /gazebo

    As output you will see publications, subscriptions, services etc.
    as a publication there is a camera topic.

    So if you want to find and use camera i think you should use it from gazebo node
