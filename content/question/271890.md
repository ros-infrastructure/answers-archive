    I suppose you could set a vector of desired positions. Then calculate the required orientation at each of those positions with the [look_at_pose](http://wiki.ros.org/look_at_pose) package.

    Now that you have a position and an orientation, send the pose commands with the [MoveGroup interface](http://docs.ros.org/kinetic/api/moveit_tutorials/html/doc/pr2_tutorials/planning/src/doc/move_group_interface_tutorial.html#moving-to-a-pose-goal) or [URscript](https://answers.ros.org/question/245390/ur5-jogging-using-jacobian/).

  body_markdown: "I'm not sure how useful this is going to be, but I wanted to mention\
    \ it: there is a [VisibilityConstraint](http://docs.ros.org/kinetic/api/moveit_msgs/html/msg/VisibilityConstraint.html)\
    \ in the `moveit_msgs` package. From the msg documentation:\n\n> The constraint\
    \ is useful to maintain visibility to a disc (the target) in a particular frame.\n\
    > This disc forms the base of a visibiliy cone whose tip is at the origin of the\
    \ sensor.\n> Maintaining visibility is done by ensuring the robot does not obstruct\
    \ the visibility cone.\n> \n> Note:\n> \n> This constraint does NOT enforce minimum\
    \ or maximum distances between the sensor\n> and the target, nor does it enforce\
    \ the target to be in the field of view of\n> the sensor. A PositionConstraint\
    \ can (and probably should) be used for such purposes.\n\nI haven't used this\
    \ myself, but I have the impression this would come closest to what you describe\
    \ in your OP.\n\nThe reason I started my answer with \"I'm not sure how useful\
    \ this is going to be\" is that constraints are non-trivial to get working correctly\
    \ with MoveIt plan requests, so starting with this might lead you down a path\
    \ where you have to spend quite some effort to get it to do what you want.\n\n\
    It could also \"just work\".\n\n---\n\nI'm not entirely sure whether it will help,\
    \ but you could also take a look at the [bio_ik](https://github.com/TAMS-Group/bio_ik)\
    \ package created by the TAMS group at Hamburg University. It also supports a\
    \ nr of constraints that could potentially do what you are after."
