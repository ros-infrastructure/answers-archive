  body_markdown: "You should just be able to set the -std=c++11 flag in CMakeLists.txt\
    \ of the package:\n\n    set(CMAKE_CXX_FLAGS \"-std=c++0x ${CMAKE_CXX_FLAGS}\"\
    )\n\nIf you want to enable it only when possible, I use this to do so:\n\n   \
    \ # check c++11 / c++0x\n    include(CheckCXXCompilerFlag)\n    CHECK_CXX_COMPILER_FLAG(\"\
    -std=c++11\" COMPILER_SUPPORTS_CXX11)\n    CHECK_CXX_COMPILER_FLAG(\"-std=c++0x\"\
    \ COMPILER_SUPPORTS_CXX0X)\n    if(COMPILER_SUPPORTS_CXX11)\n    \tset(CMAKE_CXX_FLAGS\
    \ \"-std=c++11\")\n    elseif(COMPILER_SUPPORTS_CXX0X)\n    \tset(CMAKE_CXX_FLAGS\
    \ \"-std=c++0x\")\n    else()\n    \tmessage(FATAL_ERROR \"The compiler ${CMAKE_CXX_COMPILER}\
    \ has no C++11 support. Please use a different C++ compiler.\")\n    endif()\n\
    \nIf you don't want to stop when 11 or 0x is not detected, simply comment out\
    \ those lines."
