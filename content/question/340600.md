  body_markdown: "In ROS 2 parameters are available via service interfaces:\n\n  \
    \  root@d0a03d7984eb:/# ros2 run demo_nodes_cpp listener &\n    root@d0a03d7984eb:/#\
    \ ros2 service list\n    /listener/describe_parameters\n    /listener/get_parameter_types\n\
    \    /listener/get_parameters\n    /listener/list_parameters\n    /listener/set_parameters\n\
    \    /listener/set_parameters_atomically\n\nIn `rclpy` I believe there is no helper\
    \ and you need to create a service client yourself and call it, similar to [what\
    \ is done in `ros2 service`](https://github.com/ros2/ros2cli/blob/c00dec0a72c049d3a4a8a80f1324ea24dc8373c6/ros2param/ros2param/api/__init__.py#L122)\n\
    \nIn `rclcpp` there is are [ParameterClient classes](https://github.com/ros2/rclcpp/blob/fdaf96f2171e70f3e013610aa44df2d7e9c866a3/rclcpp/include/rclcpp/parameter_client.hpp)\
    \ \non which you can call functions like `get_parameters` and it will handle the\
    \ service calls\n\nthe use looks like:\n\n    auto parameters_client = std::make_shared<rclcpp::SyncParametersClient>(my_node,\
    \ \"remote_node_name\");\n    while (!parameters_client->wait_for_service(1s))\
    \ {\n      if (!rclcpp::ok()) {\n        RCLCPP_ERROR(this->get_logger(), \"Interrupted\
    \ while waiting for the service. Exiting.\");\n        rclcpp::shutdown();\n \
    \     }\n      RCLCPP_INFO(this->get_logger(), \"service not available, waiting\
    \ again...\");\n    }\n    auto parameters = parameters_client->get_parameters({\"\
    remote_param1\", \"remote_param2\"});\n\nyou can then access them:\n\n    std::stringstream\
    \ ss;\n    // Get a few of the parameters just set.\n    for (auto & parameter\
    \ : parameters)\n    {\n      ss << \"\\nParameter name: \" << parameter.get_name();\n\
    \      ss << \"\\nParameter value (\" << parameter.get_type_name() << \"): \"\
    \ <<\n        parameter.value_to_string();\n    }\n\nThere is also a non-blocking\
    \ / asynchronous version `rclcpp::AsyncParametersClient`"
