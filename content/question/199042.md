    The `spawner` script is one of the command-line tools offered by the controller_manager ROS package ([doc](http://wiki.ros.org/controller_manager#spawner)), and it does _not_ start a `controller_manager` instance.

    The `controller_manager`is typically instantiated inside your robot hardware abstraction (`hardware_interface::RobotHW` specialization). If using `gazebo_ros_control`, this is already done by the existing plugins ([Tutorial](http://gazebosim.org/tutorials?tut=ros_control)), but if using on a custom abstraction, you have to do the setup yourself.
