  body_markdown: "There's no convenient way to do this. I recommend you explain what\
    \ you're trying to do. There's likely a better way than using `if(my_arg == \"\
    hello\"):` style logic.\n\nAlso, I recommend using XML where you can. The Python\
    \ API was not designed to be used directly, and as a result it is not very ergonomic.\n\
    \nEdit:\n\nYou can control when things are actually included using \"conditionals\"\
    , for example (based on your comment):\n\n    <launch>\n      <arg name=\"a_not_b\"\
    \ default=\"true\" />\n      <!-- argument a_option is required because it does\
    \ not have a default value -->\n      <arg name=\"a_option\" if=\"$(var a_not_b)\"\
    \ />\n      <group unless=\"$(var a_not_b)\">\n        <arg name=\"b_option1\"\
    \ default=\"true\" />\n        <arg name=\"b_option2\" default=\"true\" />\n \
    \     </group>\n    \n    </launch>\n\nIn this example, you have a required argument\
    \ `a_option`, which if you don't supply it you get:\n\n    % ros2 launch /tmp/example.launch.xml\n\
    \    [INFO] [launch]: All log files can be found below /Users/william/.ros/log/2022-07-28-13-17-55-361895-markook.local-67414\n\
    \    [INFO] [launch]: Default logging verbosity is set to INFO\n    [ERROR] [launch.actions.declare_launch_argument]:\
    \ Required launch argument \"a_option\" (description: \"no description given\"\
    ) was not provided\n    [ERROR] [launch]: Caught exception in launch (see debug\
    \ for traceback): Required launch argument \"a_option\" was not provided.\n\n\
    But then, due to the condition \"if=\" attribute on it, you can avoid that with\
    \ the option `a_not_b`:\n\n    % ros2 launch /tmp/example.launch.xml a_not_b:=false\n\
    \    [INFO] [launch]: All log files can be found below /Users/william/.ros/log/2022-07-28-13-18-03-013500-markook.local-67418\n\
    \    [INFO] [launch]: Default logging verbosity is set to INFO\n\nHowever, since\
    \ launch cannot know which arguments will be included until you actually run it,\
    \ when you ask it to show the arguments, every possible argument will be shown,\
    \ with only a `*` for the ones that may be conditionally used:\n\n    % ros2 launch\
    \ /tmp/example.launch.xml --show-arguments\n    Arguments (pass arguments as '<name>:=<value>'):\n\
    \    \n        'a_not_b':\n            no description given\n            (default:\
    \ 'true')\n    \n        'a_option':*\n            no description given\n    \n\
    \        'b_option1':*\n            no description given\n            (default:\
    \ 'true')\n    \n        'b_option2':*\n            no description given\n   \
    \         (default: 'true')\n    \n    * argument(s) which are only used if specific\
    \ conditions occur"
