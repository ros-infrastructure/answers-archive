  body_markdown: "I assume your circle shape marker is working.   \nThis solution\
    \ creates a new coordinate frame called \"marker1\" and then assigns that coordinate\
    \ frame to your custom marker. This will translate and rotate the center of the\
    \ circle shape that you have defined.  \n\nIn order to create a new coordinate\
    \ frame use `tf2`.  \nA quick solution is to add a static transform publisher\
    \ to your launch file. Set the translation/rotation arguments and frame names\
    \ as required.  \n\n    <launch>\n    <node pkg=\"tf2_ros\" type=\"static_transform_publisher\"\
    \ name=\"marker_tf_broadcaster\" args=\"5 0 0 0 0 0 1 map marker1\" />\n    </launch>\n\
    \nIn your python script assign the coordinate frame to the marker.  \nSet **marker.header.frame_id\
    \ = \"marker1\"**  or whatever frame name you've set via the static_transform_publisher\
    \ above.  \n  \nWith respect to scale, it really depends on what you want to scale:\
    \ if it is the line width, then just modify the **marker.scale** attribute in\
    \ your existing script for scaling. If scaling means modifying the radius of your\
    \ marker circle or the circle radius and the line width then you will have to\
    \ write this part yourself.  \n\nIf the tf2 translation/rotation approach works\
    \ for you, you can also include a (dynamic) tf2 transform broadcaster directly\
    \ into your script:  \n[Writing a tf2 broadcaster (Python)](http://wiki.ros.org/tf2/Tutorials/Writing%20a%20tf2%20broadcaster%20%28Python%29)"
