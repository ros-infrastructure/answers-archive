    SDFormat is not a catkin package; it is a plain cmake package. [Gazebo uses pkg-config](https://bitbucket.org/osrf/gazebo/src/default/cmake/SearchForStuff.cmake#cl-71) to find sdformat and [explicitly links against the sdformat libraries](https://bitbucket.org/osrf/gazebo/src/default/gazebo/common/CMakeLists.txt#cl-146) where necessary.

    If you also want to build sdformat from source in a catkin workspace, you will need to add a package.xml file (see the [package_xml branch in sdformat](https://bitbucket.org/osrf/sdformat/src/package_xml/package.xml) for an example).

  body_markdown: |
    Normally, you would [add a system dependency](http://docs.ros.org/api/catkin/html/howto/system_library_dependencies.html) on **sdformat**, which *is* released with Hydro. Unfortunately, it does not seem to have been defined via **rosdep** yet. You should probably [contribute the missing definition](http://docs.ros.org/independent/api/rosdep/html/contributing_rules.html) to fix that problem.

    Then, in your **package.xml**, add:

        <build_depend>sdformat</build_depend>
        <run_depend>sdformat</run_depend>

    With **sdformat** installed, in your **CMakeLists.txt**, find the SDF system library:

        find_package(PkgConfig REQUIRED)
        pkg_check_modules(SDF sdformat REQUIRED)
        include_directories(include ${SDF_INCLUDE_DIRS})

    Then your own code will need something like this to build with it:

        add_executable(your_node ${YOUR_NODE_SOURCES})
        target_link_libraries(your_node
                              ${catkin_LIBRARIES}
                              ${SDF_LIBRARIES})
