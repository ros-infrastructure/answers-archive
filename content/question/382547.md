    You could take a look at [tork-a/melfa_robot](https://github.com/tork-a/melfa_robot), which contains a [ros_control](wiki.ros.org/ros_control) compatible `hardware_interface` implementation for Mitsubishi controllers which support `MXT`.

    The driver is manipulator agnostic, so even if that repository does not contain packages for your specific robot models / variants, you could still use it (provided you can use `MXT`).
