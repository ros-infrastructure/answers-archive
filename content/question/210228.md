  body_markdown: " In the while loop you have to wait for the images to arrive. By\
    \ default your ptrs will be initialized to NULL, so accessing them before the\
    \ call backs are called will fail; and you are guaranteed to do so at least in\
    \ your first loop iteration of your while loop. Try something like:\n\n\n    \
    \ int count = 0;\n      while (ros::ok())\n      {\n        if ( cv_ptr1 && cv_ptr2\
    \ )\n        {\n            //Here is usually your stitching-routine. \n     \
    \      // Error won't occur here:\n           image1 = cv_ptr1->image;     //Load\
    \ the cv_bridge image into an OpenCV Matrix\n    \n           //Convert cv::Mat\
    \ stitched to ROS image\n    \n    \n           image_pub.publish(stitching_output);\n\
    \n           // after you have processed the image your might want to release\
    \ them\n           // so your node does not process the same images multiple times\n\
    \           // reset the ptrs and wait for the callbacks to fill them again\n\
    \           cv_ptr1.reset();\n           cv_ptr2.reset();\n        }\n       \
    \ else\n        {\n           // nothing can be done here; we have to spin and\
    \ wait for images to arrive\n        }\n\n\n        ros::spinOnce();\n    \n \
    \       loop_rate.sleep();\n        ++count;\n      }"
