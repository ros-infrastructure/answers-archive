  body_markdown: "To expand on the answer of [#q216036](https://answers.ros.org/question/216036/rostopic-node-in-launch-files/)\
    \ : you can use `rostopic` in your launch file exactly like you are using it in\
    \ command line. You just need to set the attributes `pkg` and `type` to `rostopic`,\
    \ then you can use the attribute `args` to pub/echo/info/list etc..with the propper\
    \ arguments corresponding.\n\nFor example you can do :\n\n        \n    <node\
    \ pkg=\"rostopic\" type=\"rostopic\" name=\"name\" args=\"list\" output=\"screen\"\
    />\n\nThis will simply output the result of `rostopic list`.\n\nIf you want to\
    \ `echo` a topic, the template would be :\n\n    <arg name=\"topic_name\"    \
    \ default=\"A_TOPIC_NAME\"/>\n    <node pkg=\"rostopic\" type=\"rostopic\" name=\"\
    name\" \n        args=\"echo $(arg topic_name)\" output=\"screen\"/>\n\nLike that\
    \ you can call your launch file and specify the topic in command line :\n\n  \
    \  roslaunch YOUR_PACKAGE YOUR_LAUNCH_FILE topic_name:=YOUR_TOPIC"
