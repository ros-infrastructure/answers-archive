What are the cons of using single camera which will generate point cloud generation while moving? Will it be useful as rgbd camera like intel realsense? Our purspoe:
1. Generate a 3d point cloud from single camera as described [here](https://ieeexplore.ieee.org/document/5539794). 
2. Use this point cloud for obstacle avoidance and detection in autonomous navigation eg move base.
3. When dynamic obstacle comes infront of camera since it the obstacle is moving itself the camera will generate the 3d point cloud of this also and able to recalculate the path around it.
