  body_markdown: "The error looks like there is something wrong with the `<param>`\
    \ tag that sets the `/robot_description` parameter in your launch file. My guess\
    \ is that you should just remove the `.py` extension from this chunk of your launch\
    \ file: `command=\"$(find xacro)/xacro.py`. For a long time, there a has been\
    \ a push to deprecate the `xacro.py` executable. On older versions you'd often\
    \ see a warning like \n\n    xacro.py is deprecated; please use xacro instead\n\
    \nI just spun up a Noetic Docker container and verified that they have removed\
    \ the `xacro.py` executable. So the correct line in your launch file would be:\n\
    \n    <param name=\"robot_description\" command=\"$(find xacro)/xacro '$(find\
    \ mybot_description)/urdf/mybot.xacro'\"/>"

The noetic migration guide mentions exactly this problem, even linking an example of the required change.
