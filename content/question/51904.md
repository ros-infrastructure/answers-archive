    Sam you'll need to write an sdf script for your box, and have it listed in a models folder in one of your packages. The box is one of the basic primitives used in gazebo. Once it is written you should be able to place it in the gazebo environment. For ROS the packaged gazebo distribution is 1.0, though the latest distribution is 1.3. The list of gazebo tutorials is listed [here](http://gazebosim.org/wiki/Tutorials).

    I think one of their first tutorials models involves drawing a box.
