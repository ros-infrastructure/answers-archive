  body_markdown: "This is not a feature in ROS1 but this is a feature in ROS2.\n[Interface\
    \ definition using .msg / .srv / .action files](https://design.ros2.org/articles/legacy_interface_definition.html)\n\
    Scroll down to the \"Default values\" section\n\nIn this ROS2 tutorial [Creating\
    \ custom msg and srv files](https://docs.ros.org/en/humble/Tutorials/Beginner-Client-Libraries/Custom-ROS2-Interfaces.html)\n\
    They have you put the following in a .msg file\n\n    int64 num\n\nBy default\
    \ the default value of a numerical datatype is 0. If you want to change the default\
    \ value then put the desired default value after the name separated by a space.\
    \ For example if you want to make the default value 1 then put the following in\
    \ the .msg file.\n\n    int64 num 1\n\nNow when you publish your message without\
    \ defining the value of num it will publish num with a value of 1 instead of 0.\n\
    \n    ros2 topic pub /numtopic tutorial_interfaces/msg/Num '{}'\n\nYou can confirm\
    \ this by using ros2 topic echo.\n\n    ros2 topic echo /numtopic\n    \n    num:\
    \ 1\n    ---"
