  body_markdown: "`rqt_plot` will only plot one entry in an array so, if you want\
    \ to use it, you need to specify which entry you want to plot. Therefore, you\
    \ should try something like:\n\n    rqt_plot /robo/io[5]\n\nor \n\n    rqt_plot\
    \ /robo/io[6]\n\nAlternatively, you can start `rqt_plot` and at the top enter\
    \ the topic name and index of the array.\n\n[Note that I didn't download your\
    \ bag file because I don't download random files from random sites on the internet.\
    \ So, you may have to play around with what you need to type in order to get the\
    \ plot but this should be a starting point for you.]\n\n\n----------\n\n**Update**\n\
    \nAs @Dirk Thomas pointed out in the comments you can combine the two commands:\n\
    \n    rqt_plot /robo/io[5] /robo/io[6]\n\n\n----------\n**Update 2:**\n\nAs @gvdhoorn\
    \ noted in the comments, you're trying to plot an `std_msgs/String` value which\
    \ will not work. Plotting numbers makes sense. Plotting strings? Not so much.\
    \ \n\nIf you're publishing the data then maybe you want to re-think how you're\
    \ doing it (i.e., publish numerical data types). If you're not publishing and\
    \ only subscribing, then you'll want to transform this data from a string into\
    \ a numerical data type."
