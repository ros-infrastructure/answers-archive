    \ back\"? I fixed my issue by  running \n\n> sudo apt-get install < packages-held-back\
    \ >\n\nwhich installs the packages and all of its dependencies. From what I've\
    \ read, individually installing the packages is safer than running \n\n> sudo\
    \ apt-get dist-upgrade\n\nI also had an issue with openni not configuring but\
    \ the following commands solved the issue\n\n> sudo apt-get remove libopenni0\
    \ \n\n> sudo apt-get purge libopenni*\n\nand finally, running\n\n> sudo apt-get\

    \ software.\n 1. `Universe` - Community-maintained free and open-source software.\n\
    \ 1. `Restricted` - Proprietary drivers for devices.\n 1. `Multiverse` - Software\
    \ restricted by copyright or legal issues. \n\nTo install these repositories one\
    \ method is to go through the \"Ubuntu Software Center\". Open the software center,\
    \ then from the Edit menu select `\"Software Sources\"` and select checkboxes\
    \ next to the repository names. Complete Instruction can be found here: [https://help.ubuntu.com/community/Repositories/Ubuntu](https://help.ubuntu.com/community/Repositories/Ubuntu)\n\
    \nHowever, when I controlled the \"Ubuntu Software Center\" these repositories\
    \ were already checked! When I tried to close the window it throw an error that\
    \ cannot update. I solved that problem by changing the `Download From` to `Main\

    Well, I recommend you to install this "dependencies", and do it over and over again, to find out what kind of package that blocks your installtion.

    In my case, I realized "ros-kinetic-simulators" was blocked by "ros-kinetic-gazebo-ros-pkgs" which depends on "ros-kinetic-gazebo-dev", "ros-kinetic-gazebo-plugins" and "ros-kinetic-gazebo-ros".
    Then I installed "ros-kinetic-gazebo-dev", after getting wrong answer on "gazebo7" and "libgazebo7-dev", and noticed that gazebo9 I installed conflicted with gazebo7 which required by "ros-kinetic-desktop-full".

    Eventually, I removed gazebo9 and everthing worked fine!

    The following packages have unmet dependencies:  ros-kinetic-desktop-full :
