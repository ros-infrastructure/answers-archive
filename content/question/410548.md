  body_markdown: "Amazon Workspaces supports Amazon Linux, Ubuntu and Windows 10 as\
    \ operating systems. From your question I understand that  you are running Amazon\
    \ Linux. ROS Noetic officially supports installation on Ubuntu and Debian, and\
    \ experimental installations on Windows and Arch Linux ([source](http://wiki.ros.org/noetic/Installation)).\
    \  Amazon Linux is not supported by ROS, but it is possible to build it from source\
    \ following the instructions [here](http://wiki.ros.org/noetic/Installation/Source).\
    \ \n\nAnother way to go about it is to use Docker. You can install Docker on AWS\
    \ Linux, and then use the [ROS Docker image](https://hub.docker.com/_/ros/)."
