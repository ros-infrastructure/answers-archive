  body_markdown: "The python tf API has `transformPoint`, and `transformPointCloud`.\
    \ I'm not sure why they don't show up in the API docs, but here's how they work:\n\
    \n    transformPoint(self, target_frame, ps) method of tf.listener.TransformListener\
    \ instance\n        :param target_frame: the tf target frame, a string\n     \
    \   :param ps: the geometry_msgs.msg.PointStamped message\n        :return: new\
    \ geometry_msgs.msg.PointStamped message, in frame target_frame\n        :raises:\
    \ any of the exceptions that :meth:`~tf.Transformer.lookupTransform` can raise\n\
    \        \n        Transforms a geometry_msgs PointStamped message to frame target_frame,\
    \ returns a new PointStamped message.\n\n\n    transformPointCloud(self, target_frame,\
    \ point_cloud) method of tf.listener.TransformListener instance\n        :param\
    \ target_frame: the tf target frame, a string\n        :param ps: the sensor_msgs.msg.PointCloud\
    \ message\n        :return: new sensor_msgs.msg.PointCloud message, in frame target_frame\n\
    \        :raises: any of the exceptions that :meth:`~tf.Transformer.lookupTransform`\
    \ can raise\n        \n        Transforms a geometry_msgs PoseStamped message\
    \ to frame target_frame, returns a new PoseStamped message.\n\n\nYou'll have to\
    \ either loop over your vector and create `PointStamped` objects, or pack all\
    \ the points into a `PointCloud`."

    \ TF as follows\n\n    listener = tf.TransformListener()\n    listener.waitForTransform(\"\
    /base_link\", \"/odom\", rospy.Time(0),rospy.Duration(4.0))\n    laser_point=PointStamped()\n\
    \    laser_point.header.frame_id = \"base_link\"\n    laser_point.header.stamp\
    \ =rospy.Time(0)\n    laser_point.point.x=1.0\n    laser_point.point.y=1.0\n \
    \   laser_point.point.z=0.0\n    p=listener.transformPoint(\"odom\",laser_point)\n\

     (tran, rot) = self.tf_listener.lookupTransform('/body', '/map', rospy.Time(0.0))

Anyway Is there a method in the python api  to convert my vector of points to another frame?
