  body_markdown: "**Problem:** When playing back a bag file in rqt_bag some data values\
    \ (such as NMEA sentences) are cut off after a certain length, even if the window\
    \ is expanded so that there is plenty of room for the full value to be displayed\
    \ eg:\n\n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/1462329648891826.jpg)\
    \ \n\n**Cause:** rqt_bag automatically truncates displayed data after 50 characters,\
    \ regardless of window space.\n\n**Solution:** A work-around is to edit the raw_view.py\
    \ file in rqt_bag's source files to change the truncation limit. But before you\
    \ make any changes, clone rqt_bag into your workspace so you have a safe version\
    \ to work on. The file path should be similar to: \n\n    ~/rqt_bag/plugins/raw_view.py\n\
    \nThen, open raw_view.py in any python editor and look for the following code\
    \ segment:\n\n    # Truncate long representations\n    if len(obj_repr) >= 50:\n\
    \        obj_repr = obj_repr[:50] + '...'\n\nChange both \"50\" entries to be\
    \ any larger number you want (e.g. 100) and then save the file. Open rqt_bag,\
    \ load your rosbag and the problem should be fixed:\n\n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/14623307983243826.jpg)\n\
    \n"
