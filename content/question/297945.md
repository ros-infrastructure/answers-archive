    [bloom](https://github.com/ros-infrastructure/bloom/) is the tool in ROS which generates the Debian control files based on the metadata available in the package manifest.

    [ros_buildfarm](https://github.com/ros-infrastructure/ros_buildfarm/) is the Python package which drives the buildfarm which actually produces the `.deb` files. But uultimately it simply invokes `gbp buildpackage` and `apt-src build`.
