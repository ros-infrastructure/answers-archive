  body_markdown: "Instead of including the .rosinstall file, it is a much better practice\
    \ to include the original rosinstall file (no dot prefix).  The .rosinstall file\
    \ encodes information about a specific installation on a specific machine.  The\
    \ original rosinstall file can be safely used to generate any number of installations\
    \ on multiple machines.\n\nMost VCSs allow you to pull individual files by url.\
    \  \n\nThen you can write your install instructions like this:\n\n    rosinstall\
    \ ~/my_project /opt/ros/diamondback 'http://my_vcs_server/path_to_file.rosinstall'"
