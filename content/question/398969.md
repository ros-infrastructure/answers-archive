I want to implement unit tests for a python package that I have, and I'd like to make it compatible with colcon test.

    if (CATKIN_ENABLE_TESTING)
      catkin_add_nosetests(test)
    endif()

 
However, it seems colcon allows me to pass the tests as if it's not even there. Note I am using the following command to run the test: `colcon test --python-testing pytest`

The test runs fine when I use pytest (`python3 -m pytest src/pkg/test/my_test.py`) so I'm not sure why colcon isnt recognizing it.

I suspect it has to do with my CMakeLists and Package.xml. I tried finding documentation or examples on how to structure the package for testing using colcon on ROS 1 but I couldn't find any helpful resources. For example the colcon documentation does not mention how to do so:

https://colcon.readthedocs.io/en/released/reference/verb/test.html
