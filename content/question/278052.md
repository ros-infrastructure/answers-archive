  body_markdown: "Hi @icywhite!\n\nI think that your question involves many steps.\
    \ You will probably have to:\n\n1. Read the `velodyne_msgs/VelodyneScan` messages\
    \ from a bag file\n2. Convert those `velodyne_msgs/VelodyneScan` messages to `sensor_msgs/PointCloud2`\n\
    3. Read X, Y, Z values from PointCloud\n\nYou probably could extract X Y Z directly\
    \ from the `velodyne_msgs/VelodyneScan`, but I'm not sure how to do that, then\
    \ let's see by converting to PontoCloud2.\n\n1. Reading a bag file\n---\nTo read\
    \ from a bag file we can follow [http://wiki.ros.org/rosbag/Code%20API](http://wiki.ros.org/rosbag/Code%20API)\
    \ that has the following example: \n\n    import rosbag\n    bag = rosbag.Bag('test.bag')\n\
    \    for topic, msg, t in bag.read_messages(topics=['chatter', 'numbers']):\n\
    \        print msg\n    bag.close()\n\nIn the example above, the topics `chatter`\
    \ and `numbers` are being read from the `test.bag` file.\n\n2. Converting `velodyne_msgs/VelodyneScan`\
    \ messages to `sensor_msgs/PointCloud2`\n---\nTo convert Velodyne messages to\
    \ PointCloud, you can take a look at the [velodyne_pointcloud](http://wiki.ros.org/velodyne_pointcloud)\
    \ package.\n\nOr if you want to convert manually by yourself, you can take a look\
    \ on the function [processScan](https://github.com/ros-drivers/velodyne/blob/34d1dad3ea2fd6a1f30bf2a80441c792e0e7b199/velodyne_pointcloud/src/conversions/transform.cc#L70)\
    \ that converts `velodyne_msgs::VelodyneScan` to PointCloud.\n\n3. Read XYZ from\
    \ PointCloud2\n---\nTo read XYZ from PointClouds, you could use the example below\
    \ that is shown in [another question](https://answers.ros.org/question/230680/extracting-the-xyz-coordinates-from-pointcloud2-data-in-python/):\n\
    \n    import sensor_msgs.point_cloud2\n    ...\n    for point in sensor_msgs.point_cloud2.read_points(msg,\
    \ skip_nans=True):\n                pt_x = point[0]\n                pt_y = point[1]\n\
    \                pt_z = point[2]\n\nCheers.\n\n\n"
