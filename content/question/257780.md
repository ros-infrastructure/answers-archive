  body_markdown: "The best way to install a ROS package, if you just want to use it,\
    \ is to install it with <code>apt-get</code> under Ubuntu.\n\n    sudo apt-get\
    \ install ros-kinetic-PACKAGE\n\ne.g.\n\n    sudo apt-get install ros-kinetic-slam-gmapping\n\
    \nTo see, whether the package you are looking for is availabe through apt, just\
    \ type:\n\n    apt-cache search ros-kinetic\n\nIf there is no apt package available,\
    \ you typically have to go to the <code>src</code> directory in your catkin workspace,\
    \ clone the git repository, that contains your package and run <code>catkin_make</code>\
    \ from the root of your workspace.\nYou can get the URL to clone the repo from\
    \ GitHub.\n\nStep-by-step:\n\n 1. Go to the ROS-wiki page of your package and\
    \ click on the GitHub link under the \"Source:\" bullet point.\n 2. On GitHub\
    \ click on the green \"Clone or Download\" button and copy the URL from the text\
    \ field.\n 3. Open a terminal and got to the <code>src</code> directory of your\
    \  catkin workspace.\n 4. Type: \n\n<pre>\n# Clone the repository\ngit clone https://github.com/PATH-TO-YOUR-PACKAGE.git\n\
    cd ..\n\n# Install dependencies via rosdep. Be sure to use the correct\n# 'rosdistro'\
    \ string, that fits to your ROS version.\nrosdep update\nrosdep install --from-paths\
    \ src/ --ignore-src --rosdistro kinetic\n\n# Run catkin\ncatkin_make\n</pre>\n\
    \nHopefully, the package will build without errors. Sometimes you will have to\
    \ install some additional packages or libraries via apt first which your package\
    \ depends on.\n\nAfterwards, you should probably source your setup.bash:\n<pre>source\
    \ PATH-TO-YOUR-WORKSPACE/devel/setup.bash</pre> \n\nNow you are ready to run the\
    \ nodes in your package, by using <code>rosrun</code> or <code>roslaunch</code>.\
    \ But the usage of each package varies individually. Hopefully you will find the\
    \ specific documentation on the ROS wiki.\n\nA good example is IMHO the [Pepperl&Fuchs\
    \ R2000](http://wiki.ros.org/pepperl_fuchs_r2000) driver."
