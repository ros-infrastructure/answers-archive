    This could be a classic ROS-on-Android network configuration issue. See:

     - [Network configuration ros <--> android_core](http://answers.ros.org/question/44211/network-configuration-ros-android_core/)
     - [Android subscriber can get msg but "rostopic echo" cannot?](http://answers.ros.org/question/197034/android-subscriber-can-get-msg-but-rostopic-echo-cannot/)
     - [Node on RosAndroid is not receiving images from PC.](http://answers.ros.org/question/200400/node-on-rosandroid-is-not-receiving-images-from-pc/)

    for some other questions about this.

    In short: make sure that you either have a properly setup DNS (where both your Android device and your ROS master can resolve each other's hostnames), or force the ROS master to use bare IPs for everything, using appropriate values for `ROS_IP` and `ROS_MASTER_URI`.
