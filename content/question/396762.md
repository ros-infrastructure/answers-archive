    \ \"PX4-Autopilot\" and y should be able to call the directory with \"roscd px4\"\
    .\n\n`roscd` takes *package names* as input.\n\nNot directory names.\n\nThat's\
    \ why you can `roscd px4` even if the directory you end up in has a different\
    \ name.\n\nSee also [wiki/rosbash: roscd](http://wiki.ros.org/rosbash#roscd):\n\
    \n> `roscd` allows you to change directories using a package name, stack name,\
    \ or special location.\n> \n> Usage:\n> \n>     roscd <package-or-stack>[/subdir]\n\
    > \n> For example:\n> \n>     roscd roscpp\n> \n> You can continue to use a relative\
    \ path after the package name to go further into the package:\n>\n>     roscd\
    \ roscpp/include/ros\n"
