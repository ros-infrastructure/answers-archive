  body_markdown: "For command line usage you can run `rostopic info <topic-name>`\
    \ and that will show the message type along with other information. Here's an\
    \ example with just `roscore` running.\n\n    $ rostopic info /rosout\n    Type:\
    \ rosgraph_msgs/Log\n    \n    Publishers: None\n    \n    Subscribers: \n   \
    \  * /rosout (http://127.0.0.1:41588/)\n\nNotice the section that says \n\n  \
    \  Type: rosgraph_msgs/Log\n\nthis shows that this topic carries messages of the\
    \ type `rosgraph_msgs/Log`. You can read more about this on the [wiki](http://wiki.ros.org/rostopic#rostopic_info_.28ROS_0.10.29).\n\
    \n-----\n\n**Edit:**\n\nAs @gvdhoorn pointed out in the comments, a great shortcut\
    \ is\n\n    rostopic type /my_topic | rosmsg show\n\nwhich will then show (from\
    \ my above example)\n\n    $ rostopic type /rosout | rosmsg show\n    \n    byte\
    \ DEBUG=1\n    byte INFO=2\n    byte WARN=4\n    byte ERROR=8\n    byte FATAL=16\n\
    \    std_msgs/Header header\n      uint32 seq\n      time stamp\n      string\
    \ frame_id\n    byte level\n    string name\n    string msg\n    string file\n\
    \    string function\n    uint32 line\n    string[] topics\n\nwhich gives the\
    \ definition of the message."
