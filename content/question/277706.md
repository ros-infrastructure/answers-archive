  body_markdown: "The answer is telling you that you don't have a module (folder)\
    \ named `msg`. You need to change the `import` statement to reflect the name of\
    \ the directory that your custom messages are stored in. For example, if your\
    \ package's directory structure looked like this\n\n    \u251C\u2500\u2500 CMakeLists.txt\n\
    \    \u251C\u2500\u2500 launch\n    \u2502\_\_ \u2514\u2500\u2500 face_detection.launch\n\
    \    \u251C\u2500\u2500 my_messages\n    \u2502   \u251C\u2500\u2500 TwoPoints.msg\n\
    \    \u2502\_\_ \u2514\u2500\u2500 pt.msg\n    \u251C\u2500\u2500 nodes\n    \u2502\
    \_\_ \u2514\u2500\u2500 face_detection_node\n    \u251C\u2500\u2500 package.xml\n\
    \    \u251C\u2500\u2500 README.md\n    \u251C\u2500\u2500 setup.py\n    \u251C\
    \u2500\u2500 src\n    \u2502\_\_ \u2514\u2500\u2500 face_detection\n    \u2502\
    \_\_     \u2514\u2500\u2500 face_detection_lib.py\n\nAs you can see, the custom\
    \ messages are stored in the `my_messages` directory. So, your `import` statement\
    \ would look like\n\n    from face_detection.my_messages import TwoPoints"
