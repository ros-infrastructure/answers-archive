  body_markdown: "You need to modify your URDF. Add this for each joint you want to\
    \ control:\n\n     <transmission type=\"pr2_mechanism_model/SimpleTransmission\"\
    \ name=\"kinect_trans\">\n        <actuator name=\"kinect_motor\" />\n       \
    \ <joint name=\"kinect_joint\" />\n        <mechanicalReduction>1.0</mechanicalReduction>\n\
    \        <motorTorqueConstant>1.0</motorTorqueConstant>\n     </transmission>\n\
    \n     <gazebo reference=\"kinect_joint\">\n        <erp>0.1</erp>\n        <stopKd\
    \ value=\"100000000.0\" />\n        <stopKp value=\"100000000.0\" />\n       \
    \ <fudgeFactor value=\"0.5\" />\n     </gazebo>\nThen you will need one manager:\n\
    \n    <gazebo>   \n         <controller:gazebo_ros_controller_manager name=\"\
    gazebo_ros_controller_manager\" plugin=\"libgazebo_ros_controller_manager.so\"\
    >\n              <alwaysOn>true</alwaysOn>\n              <updateRate>1000.0</updateRate>\n\
    \              <robotNamespace></robotNamespace>\n              <robotParam>robot_description</robotParam>\n\
    \              <interface:audio name=\"gazebo_ros_controller_manager_dummy_iface\"\
    \ />\n         </controller:gazebo_ros_controller_manager>\n    </gazebo>\nThen,\
    \ create configuration (yaml) file like this one:\n\n    kinect_controller:\n\
    \      type: robot_mechanism_controllers/JointPositionController\n      joint:\
    \ kinect_joint\n      pid: &kinect_position_gains\n        p: 2.0\n        i:\
    \ 0.5\n        d: 0.1\n        i_clamp: 10.0\nAnd finally, put this into your\
    \ launch file:\n\n    <rosparam file=\"$(find your_package)/config/conf_file.yaml\"\
    \ command=\"load\" />\n        \n    <param name=\"pr2_controller_manager/joint_state_publish_rate\"\
    \ value=\"100.0\" />\n    \n    <!-- Spawn some controllers stopped/started -->\n\
    \    <node pkg=\"pr2_controller_manager\" type=\"spawner\" args=\"kinect_controller\"\
    \ name=\"spawn_dynamix\" output=\"screen\"/>\nThat should be all... You will get\
    \ command topic for each joint. If you want also follow joint action, you try\
    \ to write simple script on your own - here is example which I'm using and it\
    \ works somehow: <a>http://pastebin.com/HaKtegR4</a>. Good luck :-)"
