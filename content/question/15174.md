    There are a few options for colors:

    1. You can use any color by specifying its RGBA values in [SDF](http://sdformat.org/spec?ver=1.6&elem=material#material_ambient), for example:

             <material>
              <ambient>0.46 0.46 0.46 1.0</ambient>
              <diffuse>0.46 0.46 0.46 1.0</diffuse>
              <specular>0.46 0.46 0.46 1.0</specular>
              <emissive>0.46 0.46 0.46 1.0</emissive>
            </material>

    1. You can refer to one of the ogre [materials](https://bitbucket.org/osrf/gazebo/src/a1fb370811b64723827c4e40fa3867ccbd8fd584/media/materials/scripts/gazebo.material?fileviewer=file-view-default) which come defined with Gazebo:

            <material>
                <script>Gazebo/Orange</script>
            </material>

    1. You can create your own ogre material as explained in [this](http://gazebosim.org/tutorials?tut=lightmap&cat=rendering) tutorial

    1. If you want to use textures which are not uniformly placed on your model, you will need to create a COLLADA file (with Blender for example) which references the texture within it. [Here](https://bitbucket.org/osrf/gazebo_models/src/f8f2f9af8a59da5f5c60416a29eecdfae5f90125/number1/?at=default)'s an example model, the COLLADA file goes in the `/meshes` directory and the texture goes in the `/materials/textures` directory. The COLLADA file must reference the texture within itself.
