  body_markdown: "I finally found a way to simplify my approach. If you pass `--stopped`\
    \ as an argument to the  [spawner](http://wiki.ros.org/controller_manager#spawner),\
    \ you can load a controller without starting it. So I ended up spawning the position\
    \ controller as usual and the effort controller with the `--stopped` argument.\
    \ Now I can switch from one controller to the other by just calling the `switch_controller`\
    \ service.\n\nI needed to add the following two lines to my launch file:\n\n<pre><code>\n\
    <node name=\"controller_spawner\" pkg=\"controller_manager\" type=\"spawner\"\n\
    \          respawn=\"false\" ns=\"/mybot\" args=\"flipper_position_controller\"\
    \ />\n\n<node name=\"controller_spawner_stopped\" pkg=\"controller_manager\" type=\"\
    spawner\" \n          respawn=\"false\" ns=\"/mybot\" args=\"--stopped flipper_effort_controller\"\
    \ />\n</code></pre>\n\nThe code to switch from position controller to effort controller\
    \ looks like that:\n\n<pre><code>\nfrom controller_manager_msgs.srv import SwitchController\n\
    ...\nrospy.wait_for_service('/mybot/controller_manager/switch_controller')\ntry:\n\
    \   switch_controller = rospy.ServiceProxy(\n                       '/mybot/controller_manager/switch_controller',\
    \ SwitchController)\n   ret = switch_controller(['flipper_effort_controller'],\
    \ \n                           ['flipper_position_controller'], 2)\n   except\
    \ rospy.ServiceException, e:\n      print \"Service call failed: %s\"%e\n</pre></code>"

Is there an easy way to switch between different controllers for a single resource?
I would like to control a joint of my Gazebo model either by <code>effort_controllers/JointPositionController</code> or <code>effort_controllers/JointEffortController</code>. I want to switch between these controllers during runtime by pressing a joystick button.

Right now, I make 4 service calls:

 1. Stop the current controller (by calling <code>controller_manager/switch_controller</code>)
 2. Unload the current controller (by calling <code>controller_manager/unload_controller</code>)
 3. Load the new controller (by calling <code>controller_manager/load_controller</code>)
 4. Start the new controller (by calling <code>controller_manager/switch_controller</code> again)

Is there an easier way to do that, like loading both controllers at the same time and only start/stop the corresponding controllers by a single <code>switch_controller</code> call? As the [SwitchController Service](http://docs.ros.org/api/controller_manager_msgs/html/srv/SwitchController.html) has parameters for both start_controllers and stop_controllers, this seems to be supported somehow. But if I try to spawn both controllers in a launch file, I get a "resource conflict" error.
