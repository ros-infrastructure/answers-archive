    \ as well.\n\n\n    from launch.substitutions import FindExecutable\n    from\
    \ launch.actions import ExecuteProcess\n    \n    ...\n    \n    ld.add_action(\n\
    \        ExecuteProcess(\n            cmd=[[\n                FindExecutable(name='ros2'),\n\
    \                \" service call \",\n                \"/namespace/service_to_call\
    \ \",\n                \"example_msgs/srv/ExampleMsg \",\n                '\"\
    {param_1: True, param_2: 0.0}\"',\n            ]],\n            shell=True\n \
    \       )\n    )\n\n\nNote the following:\n\n* `ld` here is a variable containing\
    \ an instance of `LaunchDescription`\n* `/namespace/service_to_call` is replaced\
    \ with the service you're looking to call (don't forget any appropriate namespaces)\
    \ and can be found with `ros2 service list`\n* `example_msgs/srv/ExampleMsg` is\
    \ the message type used by that service, which you can get with `ros2 service\
    \ info /namespace/service_to_call`\n* `\"{param_1: True, param_2: 0.0}\"` is the\
    \ dictionary defining the message data. To find the parameters you need to set,\
    \ you may need to consult the `.srv` file or documentation.\n\nDon't forget to\
    \ include the `shell=True` argument, as the command will fail with a confusing\
    \ \"File not found\" error without it.\n"
