  body_markdown: "manifest.xml is used in the legacy rosbuild build system while package.xml\
    \ is used in the catkin build system\n\nIn package.xml, you need to add the following\
    \ lines:\n\n    <build_depend>nav_msgs</build_depend>\n    <build_depend>tf</build_depend>\n\
    \n    <run_depend>nav_msgs</run_depend>\n    <run_depend>tf</run_depend>\n\nIn\
    \ addition, you can find the complete code for this tutorial at this link: \n\n\
    https://github.com/ros-planning/navigation_tutorials/tree/indigo-devel/odometry_publisher_tutorial"
