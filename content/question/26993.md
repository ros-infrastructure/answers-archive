  body_markdown: "Hi, I had the same problem when attaching to a static model!\nChanging\
    \ the model to \n\n    <static>false</static>\n\nand instead applying a joint\
    \ to the world (in the .sdf file) did the trick for me!\n\nWhen doing this I experience\
    \ oscillations between the attached models - I was able to remove this by applying\
    \ damping to the (previously static) model:\n\n      <velocity_decay>\n      \
    \  <linear>1</linear>\n        <angular>1</angular>\n      </velocity_decay>\n\
    \n"
