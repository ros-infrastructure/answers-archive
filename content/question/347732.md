  body_markdown: "It looks like Catkin detects Python 3 as the default interpreter.\
    \ ROS Python packages are installed for the default version of Python which is\
    \ Python 2 on Ubuntu Bionic (since you tagged `melodic`). Please see #q337135\
    \ and #q340510. The answers are clear and comprehensive.\n\nIn short, you will\
    \ either need to make Catkin use the Python 2 interpreter (recommended) or install\_\
    `catkin_pkg`\_for the Python 3 interpreter."
