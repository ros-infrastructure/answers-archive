    The easiest way to do so is by creating two separate LINE_STRIP markers, inserting them both in a [MarkerArray](http://docs.ros.org/api/visualization_msgs/html/msg/MarkerArray.html) and publishing that. There are a few sentences about the MarkerArray in the [rviz/DisplayTypes/Marker](http://wiki.ros.org/rviz/DisplayTypes/Marker#Example_Usage_.28C.2B-.2B-.2BAC8-roscpp.29) page, but there doesn't seem to be a specific tutorial. Anyhow, it's identical to how you deal with Markers, but you have to publish a MarkerArray now and load the corresponding plugin in RVIZ.

  body_markdown: "As mentioned here above, you can use a MarkerArray for this. Here\
    \ is my example:\n\n \n\n    ros::Publisher viz_linearconstraints_pub_;\n    viz_linearconstraints_pub_\
    \ = nh.advertise<visualization_msgs::MarkerArray>(\"/linearconstraints_viz\",\
    \ 1);\n\n    visualization_msgs::MarkerArray linear_constraints;\n\n    for (int\
    \ i = 0; i < linear_constraints_.halfspaces.size() - 4; i++){\n        visualization_msgs::Marker\
    \ line;\n        line.type = visualization_msgs::Marker::LINE_STRIP;\n       \
    \ line.ns = \"linear_constraints\";\n\n        line.id = i;\n        line.action\
    \ = visualization_msgs::Marker::ADD;\n        line.scale.x = 1;\n        line.color.g\
    \ = 1.0;\n        line.color.a = 1.0;\n\n        geometry_msgs::Point p;\n   \
    \     p.x = -20*i;\n        p.y = 10;\n        p.z = 0;\n        line.points.push_back(p);\n\
    \n        p.x = 20*i;\n        p.y = -10;\n        p.z = 0;\n        line.points.push_back(p);\n\
    \n        line.header.frame_id = \"map\";\n        linear_constraints.markers.push_back(line);\n\
    \    }\n    viz_linearconstraints_pub_.publish(linear_constraints);\n"
