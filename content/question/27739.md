  body_markdown: "Found a way to import a model from other model.\n\nThere was a lot\
    \ of errors that prevented it from import other file.\n\nFirst of all, in `blanket.sdf`\n\
    \n1. It had ` <pose relative_to='world'>` in the sdf file when there is no world\
    \ model in it. \n2. I removed <world> since blanket.sdf is designed to be a model\
    \ only without anything else.\n3. I learned that you need to `set  SDF_PATH and\
    \ IGN_FILE_PATH`. It's explained in [here](https://ignitionrobotics.org/docs/citadel/sdf_worlds#download-the-model)\n\
    \nAs for the blanket_in_the_world.sdf,\nyou need to give it a right path. So here\
    \ is what I did:\n\n    <include>\n      <uri>model://blanket.sdf</uri>\n    </include>\n\
    \nJust like that. I did this in Fortress only. \n\nFeel free to ask me to clarify.\
    \ I'm more than happy to clarify for you in future. (even if this is closed or\
    \ marked as answer) "
