Hi,<br>

It took me a while to run the sample code for down-sampling a point cloud using voxel grid, as given in tutorial page at : http://wiki.ros.org/pcl/Tutorials?action=AttachFile&do=view&target=example_voxelgrid.cpp, tutorial link : http://wiki.ros.org/pcl/Tutorials<br>
I am using ROS Hydro on Ubuntu12.04, and catkin build. I am thinking of updating these links and add code for Hydro. Kindly let me know if some changes I made are redundent etc. Specifically I made the following changes:-
<ol>
<li>Code : 
<ul>
<li>Deleted : #include &lt;pcl/ros/conversions.h&gt;<br>
Added: #include &lt;pcl_conversions/pcl_conversions.h&gt;<br>
&nbsp;&nbsp;#include &lt;sensor_msgs/PointCloud2.h&gt;
</li>

<li>Modified the callback function to use pcl::PCLPointCloud2 instead of sensor_msgs::PointCloud2 as:-<br>
(It's given at hydro migration : http://wiki.ros.org/hydro/Migration)
<code>
<pre>

void 
cloud_cb (const pcl::PCLPointCloud2ConstPtr& input)
{
  pcl::PCLPointCloud2 cloud_filtered;
  pcl::VoxelGrid&lt;pcl::PCLPointCloud2&gt; sor;
  sor.setInputCloud (input);
  sor.setLeafSize (0.01, 0.01, 0.01);
  sor.filter (cloud_filtered);

  // Publish the dataSize 
  pub.publish (cloud_filtered);
}
</pre>
</code>
</li>
</ul>
</li>


<li>IN package.xml (from <a href='http://wiki.ros.org/hydro/Migration'>http://wiki.ros.org/hydro/Migration</a> <br>
(....pcl is no longer packaged by the ROS community as a catkin package, so any packages which directly depend on pcl should instead use the new rosdep rules libpcl-all and libpcl-all-dev...... )<br>
 and understood it (I think) by seeing the post at <a href='http://www.pcl-users.org/How-do-I-use-PCL-from-ROS-Hydro-td4029613.html'>http://www.pcl-users.org/How-do-I-use-PCL-from-ROS-Hydro-td4029613.html</a> (3rd comment : given by, Matteo Munaro Sep 12, 2013; 3:46pm), and also <a href='https://github.com/ros-perception/pcl_conversions/commit/a868e1a16e442c135f66a9738619d290bc4ee896'>https://github.com/ros-perception/pcl_conversions/commit/a868e1a16e442c135f66a9738619d290bc4ee896</a>) <br>
Removed:  build_depend>pcl&lt;/build_depend&gt;<br>
&nbsp;&nbsp; &nbsp; &nbsp; &lt;run_depend>pcl&lt;/run_depend&gt;<br>
Added:   &lt;build_depend&gt;libpcl-all-dev&lt;/build_depend&gt;<br>
&nbsp;&nbsp; &nbsp; &nbsp;  &lt;run_depend&gt;libpcl-all&lt;/run_depend&gt;<br>
I am wondering if the addition of libpcl-all-dev and libpcl-all, could automatically be done while creting the package.
</li>

<li>In CMakeList.txt <br>
Removed: pcl dependency
Added:   pcl_conversions dependency<br>
Again seeing the above mentioned link. Note: This could also be achieved by changing the package creation line to : catkin_create_pkg my_pcl_tutorial pcl_conversions pcl_ros roscpp sensor_msgs
</li>
</ol>
I am quite sure that these changes must be done by many ppl who have run this tutorial and quite sad that they were not updated. Changes are a bit trivial once you understand, but still tutoral should run without giving any error, so that ppl like me could understand things easily :-).<br>
Also is there a way to get libpcl-all-dev and libpcl-all directly in package.xml while creating the package.
