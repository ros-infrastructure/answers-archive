  body_markdown: "I have built several 3D LiDAR scanners for our lab using the technique\
    \ you describe. There are a few factors to consider when choosing an actuator:\n\
    \n 1. It needs to be able to accurately\n    report its position in space and\n\
    \    time. You'll need to precisely\n    register each 2D LiDAR scan with the\n\
    \    position of the actuator when that\n    scan was captured, so this position\n\
    \    feedback is very important however\n    it is achieved.\n    \n 2. You'll\
    \ also want something which\n    already has good ROS support; nobody\n    want\
    \ to re-invent the wheel.\n    \n 3. The actuator also needs to be strong\n  \
    \  and precise enough to repeatedly\n    follow exactly the same path, so\n  \
    \  that your 3D scans are consistent.\n\nThese requirements can be achieved just\
    \ as well by a stepper motor system or a DC motor with an encoder, but I would\
    \ recommend avoiding building something from parts if you can.\n\nWe use the [FLIR\
    \ ptu-46](http://www.flir.co.uk/mcs/view/?id=63554) for our 3D LiDAR scanners,\
    \ there is a [ROS driver](http://wiki.ros.org/flir_ptu_driver) avilable for this\
    \ too. It's not the cheapest I have to say but it's strong, reliable and has very\
    \ good position feedback."
