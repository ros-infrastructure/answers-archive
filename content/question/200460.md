    Remapping is done with the [remap](http://wiki.ros.org/roslaunch/XML/remap) tag. Running image_view from within a launch file would look something like this:

        <node name="image_view" type="image_view" pkg="image_view">
          <remap from="image" to="/camera/depth/image"/>
        </node>
