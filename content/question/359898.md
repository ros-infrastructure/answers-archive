  body_markdown: "I don't see a different way. One slight enhancement tho. In the\
    \ post mentioned, the node waits 2 seconds. You can also write a function that\
    \ checks the planning scene and makes sure your update got noted. I saw a snippet\
    \ on the internet with something similar to this:\n\n    # Ensuring Collision\
    \ Updates Are Received\n    def wait_till_updated(pl_scene, obj_name, attached,\
    \ known, sleep_duration=0.5):\n        \"\"\"\n        Wait until the planning\
    \ scene was updated\n        :param pl_scene: planning scene\n        :param obj_name:\
    \ name of the object to be updated\n        :param attached: is the object now\
    \ attached\n        :param known: is the object now known\n        :param sleep_duration:\
    \ sleep between checks\n        :return: success\n        \"\"\"\n        start\
    \ = rospy.get_time()\n        seconds = rospy.get_time()\n        timeout = 5\n\
    \        while (seconds - start < timeout) and not rospy.is_shutdown():\n    \
    \        # Test if the object is in attached objects\n            attached_objects\
    \ = pl_scene.get_attached_objects([obj_name])\n            is_attached = len(attached_objects.keys())\
    \ > 0\n            rospy.logdebug(\"[wait_till_updated] Attached Objects: %s\"\
    \ % attached_objects.keys())\n    \n            # Test if the object is in the\
    \ scene.\n            # Note that attaching the box will remove it from known_objects\n\
    \            is_known = obj_name in pl_scene.get_known_object_names()\n      \
    \      rospy.logdebug(\"[wait_till_updated] Known Objects: %s\" %  \n        \
    \                   pl_scene.get_known_object_names())\n    \n            # Test\
    \ if we are in the expected state\n            if (attached == is_attached) and\
    \ (known == is_known):\n                return True\n    \n            # Sleep\
    \ so that we give other threads time on the processor\n            rospy.logdebug(\"\
    [wait_till_updated] Waiting ...\")\n            rospy.sleep(sleep_duration)\n\
    \            seconds = rospy.get_time()\n\n"

 Hi all,

Currently when trying to disable the collision check among (gripper, object, octomap) before grasping the object and enable the collison check among (gripper, object, octomap) after the object is grasped, I use the method mentioned in [this pose](https://answers.ros.org/question/352656/disabling-collision-in-allowedcollisionmatrix-removes-attached-object-from-the-scene/).

It works well. But it takes some time to complete these operations on planning_scene_interface. Therefore the gripper always waits for a few seconds to grasp the object and wait for a few seconds to move again..

Is there an easier way to do this?
