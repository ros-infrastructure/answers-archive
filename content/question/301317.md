  body_markdown: "You have a white-space gap in the path for the husky_empty_world.launch\
    \ file so roslaunch is looking for the wrong file.\n\n    <include file=\"$(find\
    \ husky_gazebo)<------ white space\n                 -------->/launch/husky_empty_world.launch\"\
    >\n\nThis should be as below instead:\n\n    <include file=\"$(find husky_gazebo)/launch/husky_empty_world.launch\"\
    >\n\nHope this helps.\n\n**UPDATE :** \n\nWell this is progress, the first error\
    \ is fixed. The error is telling you that the `husky_empty_world.launch` file\
    \ doesn't use the arguments [debug, physics] so you can't pass them to it, roslaunch\
    \ is very strict on this. If you remove the lines below, it should solve this\
    \ error:\n\n       <arg name=\"debug\" value=\"$(arg debug)\"/>\n       <arg name=\"\
    physics\" value=\"$(arg physics)\"/>"
