    I've had a lot of success using the [rtabmap_ros](http://wiki.ros.org/rtabmap_ros) package for obstacle avoidance, and it does have several features like path planning.

    However for local planners I'd recommend these two, but it will be dependent on your specific drive style: For holonomic there is [dwa](http://wiki.ros.org/dwa_local_planner), and for diff or skid steer there is [TEB](http://wiki.ros.org/dwa_local_planner)
