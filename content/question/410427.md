  body_markdown: "These parameters are used for the occupancy grid.\n\n    rtabmap\
    \ --params | grep Cluster\n    Param: Grid/ClusterRadius = \"0.1\"   [[Grid/NormalsSegmentation=true]\
    \ Cluster maximum radius.]\n    Param: Grid/MinClusterSize = \"10\"   [[Grid/NormalsSegmentation=true]\
    \ Minimum cluster size to project the points.]\n\nThey are used when `Grid/NormalsSegmentation=true`:\n\
    \n    rtabmap --params | grep Grid/NormalsSegmentation\n    Param: Grid/NormalsSegmentation\
    \ = \"true\" [Segment ground from obstacles using point normals, otherwise a fast\
    \ passthrough is used.]\n\nThen to know more about this approach, look at the\
    \ code here: https://github.com/introlab/rtabmap/blob/a4761ad397ce195c254f65be10f7e8e2810facd0/corelib/include/rtabmap/core/impl/util3d_mapping.hpp#L54\n\
    \nSo specifically for your question, the cluster parameters are used to cluster\
    \ the point clouds into multiple surfaces. This can also filter some noise.\n\n\
    Some examples of results:\n\n - http://wiki.ros.org/rtabmap_ros#rtabmap_ros.2Fobstacles_detection\n\
    \   \n - http://wiki.ros.org/rtabmap_ros/Tutorials/StereoOutdoorNavigation#Global_costmap\n\

    \n - https://github.com/introlab/rtabmap_ros/issues/304#issuecomment-484716536\n\
