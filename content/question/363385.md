    Bloom and the ROS build farm do not currently support releasing for Windows or Mac. The macOS and Windows binaries for ROS 2 are built using ROS 2's CI system at https://ci.ros2.org. Those binaries only include the ROS 2 system defined by the [ros2.repos](https://github.com/ros2/ros2/blob/master/ros2.repos).
