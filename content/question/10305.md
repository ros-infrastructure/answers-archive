    The navigation stack uses [actionlib](http://www.ros.org/wiki/actionlib) to set the 2D nav goal pose. [This tutorial](http://www.ros.org/wiki/navigation/Tutorials/SendingSimpleGoals) explains how to do that programatically. For debugging, it is often useful to [set navigation goals using RViz](http://www.ros.org/wiki/rviz/UserGuide#A2D_Nav_Goal_.28Keyboard_shortcut:_g.29).
