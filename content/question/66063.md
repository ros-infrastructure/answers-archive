    If running on a BeagleBoard Black, you'll probably want the ARM builds of Ubuntu. Instructions to install can be found on the [ROS Ubuntu ARM install page](http://www.ros.org/wiki/groovy/Installation/UbuntuARM).

    The big difference is using:

        deb http://packages.ros.org/ahendrix-mirror/ubuntu precise main

    instead of:

        deb http://packages.ros.org/ros/ubuntu precise main
