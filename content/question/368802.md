  body_markdown: "This can be done as of ROS Foxy.\n\nTo set a single parameter on\
    \ all nodes in the same scope of a launch file, you can use the [SetParameter](https://github.com/ros2/launch_ros/blob/2f09c6414c58f0a4a34305bd44be30b850af2b60/launch_ros/launch_ros/actions/set_parameter.py#L33)\
    \ action. The parameter will be set on all nodes launched after the `SetParameter`\
    \ action, also applying to any included launch files.\n\nFor example, to set the\
    \ ROS parameter `use_sim_time` for all nodes in a launch file, you can something\
    \ like\n\n    import launch\n    import launch_ros.actions\n    \n    def generate_launch_description():\n\
    \        return launch.LaunchDescription([\n            launch_ros.actions.SetParameter(name='use_sim_time',\
    \ value=True),\n            # 'use_sim_time' will be set on all nodes following\
    \ the line above\n        ]) \n\nThis is also supported in front-end launch files,\
    \ for example XML:\n\n    <launch>\n      <set_parameter name=\"use_sim_time\"\
    \ value=\"true\" />\n      <!-- 'use_sim_time' will be set on all nodes following\
    \ the line above -->\n    </launch>\n\nNote, you can use a launch \"group\" to\
    \ scope the `SetParameter` action. In the following example, the talker node does\
    \ not have the `use_sim_time` parameter set, but the listener node does:\n\n \
    \   <launch>\n      <group>\n        <set_parameter name=\"use_sim_time\" value=\"\
    true\" />\n        <node name=\"listener\" pkg=\"demo_nodes_cpp\" exec=\"listener\"\
    \ output=\"screen\" />\n      </group>\n      <node name=\"talker\" pkg=\"demo_nodes_cpp\"\
    \ exec=\"talker\" output=\"screen\" />\n    </launch>\n\n\nI'll add that it's\
    \ currently **not** possible to set parameters from a parameters file in a similar\
    \ way, though it would be interesting to add such a feature."
