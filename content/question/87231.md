  body_markdown: "The culprit is the \"autocompute value bounds\" option. This means\
    \ that for every scan the min/max values for coloration are computed in isolation,\
    \ so coloring is not consistent across multiple scans. Switching off the autocompute,\
    \ you can set the bounds yourself manually. It\xB4s of course advisable that you\
    \ are using some reasonable fixed frame for this to work as intended."

I tried various and I'm currently using:

 - Topic: /scan 
 - Queue Size: 10
 - List item
 - Selectable: yes
 - Style: Points
 - Alpha:10
 - Decay Time: 10
