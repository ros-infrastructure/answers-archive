    \ of it.  I have found that this error comes up if you try to include it as a\
    \ package instead of just pointing to it as a header directory. \n\nTry removing\
    \ the references in cmakelists.txt for the package and point the include_directories()\
    \ routine to the folder that has Eigen in it. \n\nIn my system this is /usr/include/eigen-3/\n\

    \ built as part of rasparian repos for install from apt."
