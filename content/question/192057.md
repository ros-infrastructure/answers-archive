  body_markdown: "I believe there is no pre-made plugin that does exactly what you\xB4\
    re asking for. You basically have two practical options:\n\n - Write your own\
    \ Gazebo plugin,\n   possibly based on a existing one like\n   [gazebo_ros_camera](https://github.com/ros-simulation/gazebo_ros_pkgs/blob/hydro-devel/gazebo_plugins/src/gazebo_ros_camera.cpp).\n\
    \   This gives you most control over what\n   is actually done in Gazebo (short\
    \ of\n   diving into Gazebo\xB4s sources\n   themselves)\n - Create a ROS node\
    \ that subscribes to (stream)\n   data from a existing camera plugin\n   and just\
    \ forward data selectively.\n\nThe latter option certainly is the easier one to\
    \ implement and would be preferred if you can live with a few wasted CPU cycles."
