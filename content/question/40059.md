  body_markdown: "follow this:\n\n1. 1st built ros package g2o in the proper ros package\
    \ path. don't make any change in paths. Nothing you have to edit in g2o.\n\n2.\
    \ next edit manifest.xml in rgbdslam package. delete the line '<depend package=\"\
    eigen\" />' and add the following\n\n<rosdep name=\"eigen\" />\n\nthen you can\
    \ find something similar to loop starting and ending with <export>. within that\
    \ add the following line without editing other lines:\n\n<cpp cflags=\"`pkg-config\
    \ --cflags eigen3` -I${prefix}/include `rosboost-cfg --cflags`\" \n         lflags=\"\
    -Wl,-rpath,${prefix}/lib -L${prefix}/lib -lplanning_models\"/>\n\n3.then install\
    \ qt4. simply, use ubuntu software centre. In devoloper tools -> IDE. you can\
    \ find it (most probably in the name qt creator).\n\n4.then\n\n$ sudo apt-get\
    \ install libglew1.5-dev libdevil-dev libsuitesparse-dev\n\n$ sudo apt-get install\
    \ libgsl0-dev\n\n5.then do $ rosmake rgbdslam. Incase, if you find any error try\
    \ it with $ rosmake --pre-clean rgbdslam. \n\nI hope it should work.\n \n"
