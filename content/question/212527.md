  body_markdown: "With the Hokuyo UTM-30LX-EW connected through ethernet, you can\
    \ use the [urg_node](http://wiki.ros.org/urg_node), setting the **ip_address**\
    \ parameter value. Default factory Hokuyos come with IP 192.168.0.10.\n\n    rosrun\
    \ urg_node urg_node _ip_address:=192.168.0.10\n\n-- Edit 1: \n\nPC and laser must\
    \ be on the same net 192.168.0.XX. Then, you should be able to ping the laser\
    \ first,\n\n    ping 192.168.0.10\n\n-- Edit 2: \n\nIf it does not work on a PC\
    \ with IP 192.168.0.XX, maybe your Hokuyo laser has a different IP address. \n\
    \nTo be sure, you can reset the laser IP address to the default one (192.168.0.10),\
    \ following the instructions from the Laser [specification](https://www.hokuyo-aut.jp/02sensor/07scanner/download/pdf/UTM-30LX-EW_spec_en.pdf)\
    \ (last page, *section 9 - Ethernet settings - IP Initialization* ), provided\
    \ at the Hokuyo [webpage](https://www.hokuyo-aut.jp/02sensor/07scanner/download/products/utm-30lx-ew/).\n\
    \nIf you manage to make it work with the default IP address but then you need\
    \ to work in a different sub net, in the Hokuyo [webpage](https://www.hokuyo-aut.jp/02sensor/07scanner/download/products/utm-30lx-ew/)\
    \ there is a tool (for Windows) to change the laser IP address. "
