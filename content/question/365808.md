    Hello:
    I tell you how I solve the problem.
    I install ROS 2 following this instructions:
    https://ms-iot.github.io/ROSOnWindows/GettingStarted/SetupRos2.html#installing-ros-2-binaries

    After that, when I need to run the rqt_graph comand I install the pydot extension writing the following comand:
    pip install pydot

    After although the rqt_gui_cpp errors remain the rqt_graph works.
