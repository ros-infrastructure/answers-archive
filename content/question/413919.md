  body_markdown: "Correct me if I'm mistaken but in ROS2 `/cmd_vel` does not provide\
    \ a callback message. Meaning, you need to run `spin_once() ` instead of `spin()`.\
    \ This is because `spin_once()` dosn't wait for a termination message unlike `spin()`,\
    \ which ends the cycle if and only if it's explicitly interrupted or a termination\
    \ signal is received. "
