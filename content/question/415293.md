  body_markdown: "There is a general solution which can also apply to ros2 nodes.\
    \ Do this by using `killall` on Linux:\n\n * Install `psmisc`:\n\n        sudo\
    \ apt install psmisc\n\n * Create an alias for killing all processes to facilitate\
    \ ease. Attached is just a sample of what you can include for repeated killing.\
    \ \n\n        alias killros2='killall -9 \\\n          ros2 \\\n          _ros2_daemon\
    \ \\\n          rviz2 \\\n          gzserver \\\n          robot_state_publisher\
    \ \\\n          gzclient controller_server \\\n          lifecycle_manager'\n\n\
    \ * Add the above snippet to your `~./bashrc` file. <br/> In a separate terminal,\
    \ run:\n\n        killros2\n\n   This should kill all ros2-related processes and\
    \ provide you with a log on the screen showing which processes have been found\
    \ and killed."
