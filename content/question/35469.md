  body_markdown: "The [API documentation](http://www.ros.org/doc/api/camera_info_manager/html/classcamera__info__manager_1_1CameraInfoManager.html#a8944fe301b12d38ed33ac6ccb3d9b63b)\
    \ specifies `nh` to be a `ros::NodeHandle` for the camera's streaming name space.\
    \ You seem to have passed a node handle for the driver node, instead. \n\nThe\
    \ second (`cname`) parameter has a different purpose. It attempts to identify\
    \ which physical device the associated calibration describes. For that, a UUID\
    \ or make, model and serial number [are recommended](http://www.ros.org/doc/api/camera_info_manager/html/classcamera__info__manager_1_1CameraInfoManager.html#_details).\n\
    \nTry something like this:\n\n    camera_info_manager::CameraInfoManager cinfo(ros::NodeHandle(\"\
    webcam\"));\n\nThat will advertise `/webcam/set_camera_info`."

I create my info manager like follows :

    camera_info_manager::CameraInfoManager info_mgr(nh, "webcam");
