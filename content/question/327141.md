    This doesn't address your question, but:

    > If I want to create a C++ node to control the robot with the keyboard.

    If you're using a standard interface for your controllers (such as a [geometry_msgs/Twist](http://docs.ros.org/api/geometry_msgs/html/msg/Twist.html)), you should be able to reuse something like [teleop_twist_keyboard](http://wiki.ros.org/teleop_twist_keyboard) (or perhaps even [teleop_twist_joy](http://wiki.ros.org/teleop_twist_joy)). That would save you writing it yourself, and reuse *is* a best practice.
