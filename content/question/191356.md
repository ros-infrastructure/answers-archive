    Creating this contact is completely unrelated from ROS.

    The drone hosts its own WiFi-Network, which you have to connect to. Once this is done, you should read the documentation from [here](https://github.com/AutonomyLab/ardrone_autonomy). Also, have a look into this [tutorial](http://robohub.org/up-and-flying-with-the-ar-drone-and-ros-getting-started/). It might not be completly compatible with the current AR-Drone-Driver, but when you use the virtual machine everythink should work. Nonetheless, it is a great introduction to accessing and programming the drone with ROS.

    Good Luck!
