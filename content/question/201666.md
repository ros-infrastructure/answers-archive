  body_markdown: " \n- ardrone/navdata topic.\n======================\n\n**Information\
    \ received from the drone will be published to the ardrone/navdata topic. The\
    \ message type is ardrone_autonomy::Navdata and contains the following information:**\n\
    \n \n\n- **header**: ROS message header\n- **batteryPercent**: The remaining charge\
    \ of the drone's battery (%)\n- **state**: The Drone's current state: * 0: Unknown\
    \ * 1: Inited * 2: Landed * 3,7: Flying * 4: Hovering * 5: Test (?) * 6: Taking\
    \ off * 8: Landing * 9: Looping (?)\n- **rotX**: Left/right tilt in degrees (rotation\
    \ about the X axis)\n- **rotY**: Forward/backward tilt in degrees (rotation about\
    \ the Y axis)\n- **rotZ**: Orientation in degrees (rotation about the Z axis)\n\
    - **magX**, magY, magZ: Magnetometer readings (AR-Drone 2.0 Only) (TBA: Convention)\n\
    - **pressure**: Pressure sensed by Drone's barometer (AR-Drone 2.0 Only) (Pa)\n\
    - **temp** : Temperature sensed by Drone's sensor (AR-Drone 2.0 Only) (TBA: Unit)\n\
    - **wind_speed**: Estimated wind speed (AR-Drone 2.0 Only) (TBA: Unit)\n- **wind_angle**:\
    \ Estimated wind angle (AR-Drone 2.0 Only) (TBA: Unit)\n- **wind_comp_angle**:\
    \ Estimated wind angle compensation (AR-Drone 2.0 Only) (TBA: Unit)\n- **altd**:\
    \ Estimated altitude (mm)\n- **motor1**..4: Motor PWM values\n- **vx, vy, vz:**\
    \ Linear velocity (mm/s) [TBA: Convention]\n- **ax, ay, az:** Linear acceleration\
    \ (g) [TBA: Convention]\n- **tm**: Timestamp of the data returned by the Drone\
    \ returned as number of micro-seconds passed since Drone's boot-up."
