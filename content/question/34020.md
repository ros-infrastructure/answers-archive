  body_markdown: "I found out what is causing the problems.\nApparently rosdoc was\
    \ never used before with a doxygen version containing a build number (i.e. major.minor.patch.build).\
    \ \nI adapted the source of rosdoc to cover the extra build number in the doxygen\
    \ version.\n\nI filed a bug in trac and also submitted the patch there (https://code.ros.org/trac/ros-pkg/ticket/5451).\n\
    \nPatch:\nIndex: doxygenator.py\n===================================================================\n\
    --- doxygenator.py      (revision 16732)\n+++ doxygenator.py      (working copy)\n\
    @@ -196,7 +196,7 @@\n     # doxygen not available\n     if doxygen_version is\
    \ None:\n         return None\n-    major, minor, patch = doxygen_version.split('.')\n\
    +    major, minor, patch, build = doxygen_version.split('.')\n     # > 1.7.3 doxygen\
    \ changed the template syntax\n     if int(major) > 1 or int(minor) > 7 or int(patch)\
    \ > 3:\n         return 'header-1.7.4.html'\n\n\nTinne"
