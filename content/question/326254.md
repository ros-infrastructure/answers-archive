  body_markdown: "I think I figured it out after looking at the [arguments/options\
    \ differences between `catkin_tools` and `colcon`](https://colcon.readthedocs.io/en/released/migration/catkin_tools.html).\
    \ \n\nHere is an example of what I did using`ros2_example_ws`, which is assumed\
    \ to have been *already cloned and built* previously with just `colcon build`\
    \ as specified in the [Using Colcon to build packages Tutorial](https://index.ros.org//doc/ros2/Tutorials/Colcon-Tutorial/).\
    \ My **additional steps** were:\n\nFrom a terminal:\n\n    ~/ros2_example_ws$\
    \ . install/setup.bash\n    ~/ros2_example_ws$ colcon build --cmake-force-configure\
    \ --cmake-args -G\"Eclipse CDT4 - Unix Makefiles\" -DCMAKE_BUILD_TYPE=Debug\n\n\
    Then, from another terminal:\n\n- Source the workspace again (e.g. `~/ros2_example_ws$\
    \ . install/setup.bash`)\n\n- launch eclipse (I haven't tried launching Eclipse\
    \ outside of the terminal yet)\n\n- In Eclipse, do the `Import > Existing Project`\
    \ and navigate to the project of interest (e.g. `~/ros2_example_ws/build/examples_rclcpp_minimal_subscriber/`),\
    \ and import this.\n\n- The executable will show in the Project's `Binaries` view,\
    \ so the \"node\" can be run from there or modified within the `Run/Debug Configurations`\
    \ as needed.\n \n**NOTE**: The `-DCMAKE_BUILD_TYPE=Debug` in the `--cmake-args`\
    \ is only needed if building with Debug flags is desired. \n"
