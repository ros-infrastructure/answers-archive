    Gazebo currently supports .STL and .DAE mesh formats (see for example, the [COLLADA mesh loader](https://bitbucket.org/osrf/gazebo/src/72909f41da03/src/common/ColladaLoader.hh) and [STL mesh loader](https://bitbucket.org/osrf/gazebo/src/72909f41da03/src/common/STLLoader.hh) in source tree.  If you have recommendations for additional mesh format support, please file a [feature request ticket / patch](https://bitbucket.org/osrf/gazebo/issues/new).

    Alternatively, you can use mesh utilities such as [ivcon](http://ros.org/wiki/ivcon) to convert your WRL meshes to STL/DAE first.
