    > I know the question is about a transport API, but I'll just point out [this tutorial](http://gazebosim.org/tutorials?tut=set_velocity&cat=#SettingVelocityonLinks) on several ways of doing it via the C++ API.

    There's no transport API for *link velocity*, but there are for:

    ### Link force

    Publish a wrench message to `~/<model_name>/<link_name>/wrench`, see an example [here](https://bitbucket.org/osrf/gazebo/src/f4e51e8f64001beda70615ab8982a7d5a4e65b18/gazebo/gui/ApplyWrenchDialog.cc?fileviewer=file-view-default#ApplyWrenchDialog.cc-631).

    ### Joint position / velocity / force

    Publish a joint cmd message to `~/<model_name>/joint_cmd`, see an example [here](https://bitbucket.org/osrf/gazebo/src/f4e51e8f64001beda70615ab8982a7d5a4e65b18/gazebo/gui/JointControlWidget.cc?fileviewer=file-view-default#JointControlWidget.cc-604).
