    If you already have a map in YAML format and as an PGM file (or other compatible format)  you need to run [map_server](http://wiki.ros.org/map_server) to publish the map on a ros topic.

    To add it to your launch file include this:

        <node name="map_server" pkg="map_server" type="map_server" args="$(find your_package_name)/map/your_map_name.yaml"/>
