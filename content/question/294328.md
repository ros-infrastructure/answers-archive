    I believe there is no "official" value of reprojection error since theoretically, you would want it to be zero. Hence, all those "recommended" values are for reference only. And as rule of thumb, the lower reprojection error is, the better. I would suggest you check out [kalibr](https://github.com/ethz-asl/kalibr/wiki/multiple-camera-calibration). It is widely used and well-maintained package for camera-imu calibration.
