  body_markdown: "You can take a look at this example of one of my packages. Where\
    \ I create a library \"costmap2d\" out of my source files costmap.cpp and cnmap.cpp\
    \ then I share it in my workspace so i would be able to use it by other packages.\n\
    here I assumed you lib depends on an example external lib named xxx. \n\n    cmake_minimum_required(VERSION\
    \ 2.8.3)\n    project(costmap)\n    \n    \n    find_package(catkin REQUIRED COMPONENTS\n\
    \      geometry_msgs\n      nav_msgs\n      roscpp\n      std_msgs\n      tf\n\
    \      xxx\n    )\n    \n    \n    catkin_package(\n      INCLUDE_DIRS include\n\
    \      LIBRARIES costmap2d\n      CATKIN_DEPENDS geometry_msgs nav_msgs roscpp\
    \ std_msgs tf xxx\n      DEPENDS system_lib\n    )\n    \n    include_directories(\n\
    \      ${catkin_INCLUDE_DIRS}\n    )\n    \n    add_library(costmap2d include/${PROJECT_NAME}/costmap.cpp\
    \ include/${PROJECT_NAME}/cnmap.cpp)\n    target_link_libraries(costmap2d   xxx\n\
    \       ${catkin_LIBRARIES}\n    )\n\n    install(TARGETS costmap2d\n       ARCHIVE\
    \ DESTINATION ${CATKIN_PACKAGE_LIB_DESTINATION}\n       LIBRARY DESTINATION ${CATKIN_PACKAGE_LIB_DESTINATION}\n\
    \       RUNTIME DESTINATION ${CATKIN_PACKAGE_BIN_DESTINATION}\n     )\n\nnote\
    \ that here I am sharing this lib across the ws meaning that other packages of\
    \ mine can also use it. if you just want to use if inside your package you don't\
    \ need to install"
