  body_markdown: |-
    `SetForce()` sets the force for one time step only. It must be called every time step to keep applying a force. The [PID class](https://bitbucket.org/osrf/gazebo/src/cddf2613ce88d814cbe599aded96b356a5ffefd0/gazebo/common/PID.hh?at=gazebo7&fileviewer=file-view-default) does the math for a PID controller, but doesn't call any methods to set forces. You'll need to calculate the error each time step and use the output of the [Update method](https://bitbucket.org/osrf/gazebo/src/cddf2613ce88d814cbe599aded96b356a5ffefd0/gazebo/common/PID.hh?at=gazebo7&fileviewer=file-view-default#PID.hh-138) as the force.

    If you want to control the velocity of joints there will soon be a tutorial about the different ways to do it: https://bitbucket.org/osrf/gazebo_tutorials/pull-requests/427/set-velocity-tutorial/diff
