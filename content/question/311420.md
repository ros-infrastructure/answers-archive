  body_markdown: "First, you need to install [Qt creator](https://wiki.qt.io/Install_Qt_5_on_Ubuntu)\
    \ and  [ViSP](https://visp.inria.fr/install/). Then you can create a normal package,\
    \ then in the CMake list you need to add ViSP directory as follow:\n\n......\n\
    \nfind_package(VISP REQUIRED)\n\n....\n\ninclude_directories(\n  include\n  ${VISP_INCLUDE_DIRS}\n\
    \  ${roscpp_INCLUDE_DIRS}\n)\n\n......\n\ntarget_link_libraries(YOUR_NODE ${VISP_LIBRARIES})\n\
    \n....\n\n\nFinally, you can open Qt creator and choose the CMake list to open\
    \ the corresponding package and do whatever calculation you want !\n\n\n\n \n\n"
