  body_markdown: "Can you copy and paste the terminal output instead of a screenshot\
    \ please ? It's not searchable like that.\n\nFor your issue, you launch Gazebo\
    \ with `pause` set to `true` so you son't start the service, this will start it\
    \ :\n\n    roslaunch my_gazebo my_world.launch pause:=false\n\nThe proper solution\
    \ is to modify this value in your launch file. Moreover you tried with `verbose\
    \ :=true`, yet you didn't defined the arg `verbose` in your launch file so it's\
    \ basically doing nothing. \n\nFinally I don't know if you are aware of it but\
    \ you also set `gui` to `false` so you won't have the `Gazebo GUI` with your launch\
    \ file, set it to `true` in your launch file to launch it or simply type the command\
    \ `$gzclient` after your roslaunch."
