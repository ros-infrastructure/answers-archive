  body_markdown: "Just to expand on my comment (I'll reiterate it first):\n\n[Metapackage](https://wiki.ros.org/Metapackages)\n\
    \n> [...] do not install files (other than their package.xml manifest) and they\
    \ do not contain any tests, code, files, or other items usually found in packages.\n\
    \nand \n\n> A metapackage simply references one or more related packages which\
    \ are loosely grouped together.\n\nSo, it's a package of packages and isn't meant\
    \ to be depended on. You should depend on one of the packages that's contained\
    \ *in* the metapackage, not the metapackage itself.\n\nLook at one of the tests\
    \ in `ros_control`, for example the [controller_manager_tests](https://github.com/ros-controls/ros_control/tree/melodic-devel/controller_manager_tests)\
    \ package. You'll notice that in its [CMakeLists.txt file](https://github.com/ros-controls/ros_control/blob/melodic-devel/controller_manager_tests/CMakeLists.txt),\
    \ it doesn't depend on the `ros_control` *metapackage*. Instead, it depends on\
    \ the package that it's using (testing in this case).\n\nSo, you need to depend\
    \ on the package that you're using not the metapackage."
