my solution:

I uninstalled ros, without deleting my workspace:

    sudo apt-get purge ros-kinetic-*

    sudo apt-get autoremove

and reinstalled ros again following wiki

If you do catkin_make you will end up with this error:

Invoking "make cmake_check_build_system" failed

So you have first to install the dependencies needed:

    rosdep install --ignore-src --from-paths src/

and then catkin_make works without problems and the system find the packages you need .
