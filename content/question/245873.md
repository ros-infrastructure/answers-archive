    Hi,

    For loop closure detection, see this [paper](https://introlab.3it.usherbrooke.ca/mediawiki-introlab/images/b/bc/TRO2013.pdf). The code follows pretty much the algorithms shown.

    For the 3D map, we simply assemble point clouds of each node in the graph, as described loosely in the [paper](https://introlab.3it.usherbrooke.ca/mediawiki-introlab/images/e/eb/Labbe14-IROS.pdf) your referred:

    > Fig. 9 shows the resulting global map by assembling  the  RGB-D  point  clouds  from  the  Kinect  using the optimized poses of the graph.

    Search **Graph-Based SLAM** to learn more about the map structure used in RTAB-Map.
