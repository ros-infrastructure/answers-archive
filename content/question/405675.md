  body_markdown: "> The build has no errors, but it doesn't run.\n\nFor readers, in\
    \ the above quote, \"it\" is referring to the robot (not the code). \n\nAnyways,\
    \ it is better to add a print statement (for debugging purposes only) to see what\
    \ values are exactly being commanded to the robot.\n\n    std::cout << \"commanded\
    \ values: \" << msg << std::endl; // for debugging purposes only\n    vel_pub.publish(msg);\n\
    \nThe above print statement should give you a great hint about the problem. Next,\
    \ let's see the following snippet taken from your code:\n\n    geometry_msgs::Twist\
    \ msg;\n    sensor_msgs::LaserScan lsr;\n    msg.linear.x = 0;\n    msg.angular.x\
    \ = 0;\n\n    if (lsr.ranges[0] < 1.0) {\n      msg.linear.x = 0;\n      msg.angular.x\
    \ = 0.5;\n    } else {\n      msg.linear.x = 0.5;\n      msg.angular.x = 0;\n\
    \    }\n\nThe conditional statement checks the first element of the range attribute\
    \ in the laser scan message. However, this laser scan message is not received\
    \ from the sensor. Instead, it is created manually. Thus the `lsr` variable contains\
    \ default values (probably all zero or null potentially). This is why the conditional\
    \ statement is not making much sense.\n\nLet see another issue with the code.\
    \ Please see the following snippet taken from your code:\n\n    while (ros::ok())\
    \ {\n      geometry_msgs::Twist msg;\n      // code removed for brevity\n    \
    \  vel_pub.publish(msg);\n      ros::spin();\n    }\n\nThe `ros:spin()` is being\
    \ called inside a `while` statement. This is a red flag. It will block the `while`\
    \ loop, and thus twist messages can not be published. Instead, you should move\
    \ your logic from the `while` loop to the callback. You can publish the twist\
    \ directly from the callback.\n\nFinally, it would be worth spending time understanding\
    \ the ROS simply by going through [ROS Tutorials](http://wiki.ros.org/ROS/Tutorials).\
    \ The authors have put immense effort into making these easy-to-understand tutorials.\n"

topics_quiz_node.cpp

    #include "geometry_msgs/Twist.h"
    #include "ros/init.h"
    #include "ros/node_handle.h"
    #include "ros/publisher.h"
    #include <ros/ros.h>
    #include <sensor_msgs/LaserScan.h>
    // float vel_pub;
    
    void FuncCall(const sensor_msgs::LaserScan::ConstPtr &msg) {
      ROS_INFO("LaserScan (val,angle)=(%f,%f", msg->range_min, msg->angle_min);
    }
    
    int main(int argc, char **argv) {
      ros::init(argc, argv, "topics_quiz_node");
      ros::NodeHandle robot;
      ros::Publisher vel_pub =
          robot.advertise<geometry_msgs::Twist>("/cmd_vel", 100);
      ros::Subscriber laser_sub =
          robot.subscribe("/kobuki/laser/scan", 10, FuncCall);
    
      while (ros::ok()) {
        geometry_msgs::Twist msg;
        sensor_msgs::LaserScan lsr;
        msg.linear.x = 0;
        msg.angular.x = 0;
    
        if (lsr.ranges[0] < 1.0) {
          msg.linear.x = 0;
          msg.angular.x = 0.5;
        } else {
          msg.linear.x = 0.5;
          msg.angular.x = 0;
        }
        msg.linear.y = 0;
        msg.linear.z = 0;
        msg.angular.y = 0;
        msg.angular.z = 0;
        vel_pub.publish(msg);
        ros::spin();
      }
      return 0;
    }
