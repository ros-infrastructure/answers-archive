  body_markdown: "Rosbridge is probably the better answer, but just in case, here's\
    \ a method that will at least work on messages whose content can be rendered as\
    \ a string with the python `str()` function. \n\n    import json\n    import yaml\n\
    \    \n    def msg2json(msg):\n       ''' Convert a ROS message to JSON format'''\n\
    \       y = yaml.load(str(msg))\n       return json.dumps(y,indent=4)\n\n    if\
    \ __name__ == \"__main__\":\n        from geometry_msgs.msg import PoseStamped\n\
    \        P = PoseStamped()\n        print msg2json(P)\n\n-------------------\n\
