  body_markdown: "This is definitely possible. You would need to create your custom\
    \ service which will contain the pose array msg as a response. A service [description](http://wiki.ros.org/srv)\
    \ file consists of a request and a response msg type. Since in your case you just\
    \ need to receive the array on a service call you will not need a request (it\
    \ will act as trigger srv) and the response should contain the pose array. For\
    \ example this can be your bare bone service description: \n\n    ---\n    geometry_msgs/PoseArray\
    \ arr\n\nYou can name this srv file as `getPoseArray.srv` (check again the service\
    \ creation [tutorial](http://wiki.ros.org/ROS/Tutorials/CreatingMsgAndSrv) for\
    \ this).<br>\n\nThe  [geometry_msgs/PoseArray](http://docs.ros.org/melodic/api/geometry_msgs/html/msg/PoseArray.html)\
    \ msg contains a header and array of poses. When you create/save the array of\
    \ poses in script1.py (I guess you are using a global variable for this, for example\
    \ `my_array`) and you can also populate the header (especially the `frame_id`\
    \ since you are dealing with poses). You will need to advertise the service where\
    \ in the service callback you will just return the pose array (check again the\
    \ service/client [tutorials](http://wiki.ros.org/ROS/Tutorials/WritingServiceClient(python))).\
    \ In python it will look something like this:\n\n    #!/usr/bin/env python\n \
    \   \n    import rospy\n    from your_package.srv import getPoseArray\n    from\
    \ geometry_msgs.msg import PoseArray\n    \n    def handle_get_pose_array(req):\n\
    \        return getPoseArrayResponse(my_array)\n    \n    def get_pose_array_server():\n\
    \        rospy.init_node('get_pose_array_server')\n        s =rospy.Service('get_pose_array',\
    \ getPoseArray, handle_get_pose_array)\n\n       my_array = PoseArray()\n    \
    \   my_array.header.frame_id = some_frame\n       my_array.poses = ... # assign/populate\
    \ here\n\n        rospy.spin()\n    \n    if __name__ == \"__main__\":\n     \
    \   get_pose_array_server()\n\nOn the other side in script2.py you need to create\
    \ the client and call the service:\n\n    #!/usr/bin/env python\n    \n    import\
    \ rospy\n    from your_package.srv import getPoseArray\n    from geometry_msgs.msg\
    \ import PoseArray\n    \n    def get_pose_array_client():\n        rospy.wait_for_service('get_pose_array')\n\
    \        try:\n            client_handle = rospy.ServiceProxy('get_pose_array',\
    \ getPoseArray)\n            resp1 = client_handle()\n            return resp1.arr\n\
    \        except rospy.ServiceException, e:\n            print \"Service call failed:\
    \ %s\"%e\n\n    if __name__ == \"__main__\":\n        get_pose_array_client()"
