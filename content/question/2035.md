MultiSense SL sensor head updates.<BR>
    Image generation default changed to 1MP (1536 X 816 pixels) @ 30FPS per documentation.<BR>

<pre>
image
          width 1024
          height 544
...
</pre>

And imagerMode is initialized to 2 in MultiSenseSLPlugin.cpp<br>
<pre>
    width = 1024;
    height = 544;

in MultiSenseSLPlugin.cpp, which is different from 1536 X 816.
