    \ when compilation failed.  rosdep doesn't have files in Fuerte yet for the debian\
    \ squeeze packages.  I had an Electric install before this one so I just assumed\
    \ that I had some of these packages.  In the short future, I'll probably file\
    \ a bug which includes a reasonable rosdep.yaml file.\n\nSome of the ones here\
    \ are obvious, but pcl and flann I had to compile from the sources.  They are\
    \ available at https://github.com/wg-debs - you clone the repository you need\
    \ and then you can install the build dependencies for the package.\n\nFor each\
    \ of the two (I installed flann first, because it was needed for pcl): \n\n1.\
    \ `git clone https://github.com/wg-debs/flann.git`\n1. Remove \"unneeded\" dependencies\
    \ from `debian/control` Build-Dependencies (the ones that start with ros- are\
    \ the only ones I removed)\n1. `dpkg-source --commit` (to commit the \"extra files\"\
    \ that are there)\n1. `git-buildpackage -us -uc --git-ignore-new`\n1. `dpkg -i\
    \ ../*.deb`\n\nThere were other small hurdles as well, but they are less of an\
    \ issue than these two libraries which are custom installed. "
