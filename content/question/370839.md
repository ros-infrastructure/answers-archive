    \ you need to use `diff_drive_controller` to generate /odom topics from urdf.\n\
    \nAlso, even if you can generate an /odom topic, it may not create a map.\n\n\
    Even if you can generate an /odom topic, the map may not be created, because `amcl`\
    \ and `gmapping` are not usually handled at the same time.\n`amcl` is a package\
    \ that uses `/map` and `/scan` for localization.\n`gmapping` is a package that\
    \ uses `/scan` to localize while issuing `/map`.\n\n 1. Generate /map by running\
    \ `gmapping`without using `amcl`.\n 2. Save it with `map_saver`. \n 3. Read the\
    \ saved map with `map_server` and publish a /map topic.\n 4. Localization with\
    \ `amcl`.\n\nYou can probably get what you want by proceeding as follows.\n\n"

    \ data to. See below :\n\n    <node pkg=\"gmapping\" type=\"slam_gmapping\" name=\"\
    gmapping\" output=\"screen\">\n       <param name=\"map_frame\" value=\"map\"\
    />\n       <param name=\"base_frame\" value=\"chasis\"/> \n       <param name=\"\
    odom_frame\" value=\"odom\"/> \n    </node>\nAll available parameters are listed\
    \ at [http://wiki.ros.org/gmapping](http://wiki.ros.org/gmapping)."
