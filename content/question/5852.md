    [Here](https://github.com/fsuarez6/labrob) you can find 2 mazes. In **Testing the installation** better execute this command:

        roslaunch labrob_worlds crazy_maze.launch show_rviz:=0

    The idea behind this implementation is to have a custom [world file](https://github.com/fsuarez6/labrob/blob/master/labrob_worlds/worlds/crazy_maze.world) and a custom [model](https://github.com/fsuarez6/labrob/tree/master/labrob_worlds/models/crazy_maze).

    Check the repository files and you will see the needed parts for you application.
