    In the meantime we have switched from using `ament_tools` for ROS 2 to use `colcon` (see [design article](http://design.ros2.org/articles/build_tool.html)). For the upcoming ROS 2 release Bouncy we recommend using the new tool - even though `ament_tools` will still be available in that release.

    Unfortunately that mean that we will not spend any effort on fixing issues in the deprecated tool. If you want to look into the problem and try to fix it we would certainly be happy to review / merge fixes. I think the problem is very similar to what was fixed in `catkin_pkg` recently. Maybe [this diff](https://github.com/ros-infrastructure/catkin_pkg/pull/221) helps.

    Using the new build tool you can get a list of all `build`, `run`, and `test` dependencies: `colcon info <pkgname>`
    The result will consider group dependencies.
