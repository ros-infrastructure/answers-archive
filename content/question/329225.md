    Hi.

    If you are publishing a point cloud topic, you can use the [costmap_2d package](http://wiki.ros.org/costmap_2d).

    There you can understand more how to use and config costmap layers to create an obstacle map using some message types as Laserscan and PointCLoud2.

    On the costmap_2d tutorial and ROS navigation repository, there are examples for launch files and config. They are not the best example, but it is a start.

    [costmap_2d tutorial/Config Obstacle Layer](http://wiki.ros.org/costmap_2d/Tutorials/Configuring%20Layered%20Costmaps)

    [ROS costmap_2d node launch](https://github.com/ros-planning/navigation/blob/melodic-devel/costmap_2d/launch/example.launch)

    [ROS costmap_2d node config yaml](https://github.com/ros-planning/navigation/blob/melodic-devel/costmap_2d/launch/example_params.yaml)
