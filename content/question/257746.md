Catkin gives me an error on some third-party header files, which I included in my code. The error message says, the code was using old-style casts. 
I know, that the error results from the compiler option <code>-Werror=old-style-cast</code>, but I wasn't able to find an easy workaround without removing the flag from my CMakeLists.txt. 
I would like to allow old-style casts temporarily by passing the right compiler option to <code>catkin_make</code> or <code>catkin build</code>, but all my attempts have failed so far.
