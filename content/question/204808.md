    Use

        #include <pcl_ros/transforms.h>

    You can find documentation for `pcl_ros` in ROS Inidigo at [docs.ros.org](http://docs.ros.org/indigo/api/pcl_ros/html/namespacepcl__ros.html#aad20af010640a41f1898e75f6a6121ad). I found that page by googling for `pcl_ros transformpointcloud`. The linked file says that the function `pcl_ros::transformPointCloud()` is defined in `transforms.hpp`.
