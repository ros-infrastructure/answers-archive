  body_markdown: "There are a number of drivers for FLIR and pointgrey cameras in\
    \ ROS that I know of, of which only the pointgrey_camera_driver looks like it\
    \ is maintained: \n\n- [pointgrey_camera_driver]( http://wiki.ros.org/pointgrey_camera_driver)\n\
    - [flir_camera_driver](https://github.com/ros-drivers/flir_camera_driver)\n- [spinnaker_sd_camera_driver](http://wiki.ros.org/spinnaker_sdk_camera_driver)\n\
    \nThe other option is to write your own node using PySpin (the spinnaker python\
    \ interface). There are some basic wrappers around PySpin like [simple_pyspin](https://pypi.org/project/simple-pyspin/).\
    \ \n\nI've always had some issues with the drivers and I only now realized that\
    \ the pointgrey_camera_driver has a Noetic version  so I resorted to using PySpin\
    \ in a custom node."
