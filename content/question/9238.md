    You can set the [user camera pose](http://sdformat.org/spec?ver=1.5&elem=world#gui_camera) in the SDF as follows:

        <world name="default">
          <gui>
            <camera name="user_camera">
              <pose>0 0 0 0 0 0</pose>
            </camera>
          </gui>
        ...
        </world>

    From Gazebo 6, you can find out the [current camera pose](https://bitbucket.org/osrf/gazebo/pull-requests/1649/get-set-user-camera-pose-in-gui-1595/diff) on the World tab, under GUI. Then you can use that value in your SDF.

    On older versions of Gazebo, you can save your world with the desired camera pose and find the pose in the saved SDF.
