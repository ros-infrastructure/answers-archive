    Hey Christian,

    thank you for your interest in FlexBE! We are aware of the Chrome App EOL, [see statement here](https://github.com/pschillinger/flexbe_chrome_app/issues/11). There is already a standalone version of the App:

    https://github.com/FlexBE/flexbe_app#flexbe-app

    It is currently in beta, but has already all the features and as far as feedback reaches me, it mostly works at least as good as the old Chrome App. It has mostly been tested on Ubuntu, but [let me know](https://github.com/FlexBE/flexbe_app/issues) if you should encounter any problems on OS X.

    **EDIT:** To run the existing Chrome App without Chrome, you can download [nw.js](https://nwjs.io/) and clone [flexbe_chrome_app](https://github.com/pschillinger/flexbe_chrome_app). Assuming you downloaded and extracted both into the same folder, run something like the following command to start the App:

        nwjs-v0.xx-.../nw flexbe_chrome_app/FlexBE

    There should be no difference compared to running it with Chrome.
