  body_markdown: "Hi there\n\nIf you want to use ncurses++ (in electric) you should\
    \ add the following to your CMakeList.txt:\n\n    find_package( PkgConfig REQUIRED\
    \ )\n    pkg_check_modules ( ncurses++ REQUIRED ncurses++ )\n\n    add_executable\
    \ ( my_exec path_to_my_exec/my_exec.cpp )\n    target_link_libraries ( my_exec\
    \ ${ncurses++_LIBRARIES} )\n\nAnd then modify the manifest.xml of your package\
    \ to let know ROS that you are using an external library:\n\n    <rosdep name=\"\
    ncurses++\"/>\n\nI hope this helps \n"
