  body_markdown: "I'm not sure what you mean by \"enabling\" multiple cameras. Autoware.AI\
    \ uses a decentralized sensor processing architecture so the data from each sensor\
    \ is processed independently into abstract items like \"objects\" or\" obstacles\"\
    \ before being used.\n\nIf you want to use multiple cameras to, for example, detect\
    \ objects, each camera will have its own object detection pipeline and you'll\
    \ have to come up with a way to combine the objects detected by all of the cameras\
    \ before they are used, for example, in the obstacle avoidance node.  The object\
    \ fusion functionality is not available out-of-the-box but it shouldn't be too\
    \ difficult to implement. "
