    \ from Gazebo, you have three options:\n\n 1. Use a [pre-existing Gazebo Plugin/Sensor\
    \ that publishes the data to ROS](https://github.com/ros-simulation/gazebo_ros_pkgs)\n\
    \ 2. Use a pre-existing [Gazebo Plugin](https://bitbucket.org/osrf/gazebo/src/default/plugins/)\
    \ or [Sensor](https://bitbucket.org/osrf/gazebo/src/default/gazebo/sensors/) that\
    \ publishes the data to the Gazebo Transport Layer. You'll have to access this\
    \ data (e.g. from a ROS Node) via the [Gazebo Transport Library](http://gazebosim.org/tutorials?cat=transport).\n\
    \ 3. Write your own [custom Gazebo Plugin](http://gazebosim.org/tutorials?tut=guided_i1#Intro)\
    \ that publishes sensor data using either of the above methods.\n\n \n\n"
