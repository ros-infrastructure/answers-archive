    Moving the comment to an answer. The solution is to source Gazebo's setup file, i.e.:

    ```
    . /usr/share/gazebo/setup.sh
    ```

    This is needed to set some necessary environment variables in case they're going to be overridden, which is a common use case. More context in [this issue](https://github.com/osrf/gazebo/issues/1949).
