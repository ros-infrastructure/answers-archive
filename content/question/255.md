    Yes. See [here](http://www.gazebosim.org/user_guide/started_commandlineinterface.html).
    You just need to make sure that the network settings permit both machines to resolve the network names (or IP addresses) used.  Gazebo seems to borrow alot from the ROS [NetworkSetup](http://www.ros.org/wiki/ROS/NetworkSetup), so that's a good read as well.

    Also, did you set `GAZEBO_MASTER_URI`? You mentioned GAZEBO*MASTER*URI.
