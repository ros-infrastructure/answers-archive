  body_markdown: "This is a Python problem, not a ROS one.\n\n    def scaleWheel():\n\
    \        [..]\n    \n        lscaled_pub = rospy.Publisher(\"lwheel_scaled\",\
    \ Int16, queue_size=10)\n        rscaled_pub = rospy.Publisher(\"rwheel_scaled\"\
    , Int16, queue_size=10) \n    \n        [..]\n    \n    def lwheelCallback(msg):\n\
    \        lscaled_pub.publish( msg.data * -1 * scale)\n    \n    def rwheelCallback(msg):\n\
    \        rscaled_pub.publish( msg.data * -1 * scale)\n\nThe cause here is the\
    \ fact that `lscaled_pub` and `rscaled_pub` are variables local to `scaleWheel`.\n\
    \nYou cannot refer to them in other methods as those variables are not defined\
    \ in a scope that contains both `scaleWheel` and `lscaled_pub` and `rscaled_pub`.\n"

        		rscaled_pub.publish( msg.data * -1 * scale)
    
    
    if __name__ == '__main__':
        """main"""
        try:
