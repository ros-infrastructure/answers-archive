  body_markdown: "As mentioned in my comment, the convention is for angles to be measured\
    \ counter-clockwise (right-hand rule) from the x axis (see [REP 103](https://www.ros.org/reps/rep-0103.html)).\
    \  With a 48\xB0 field of view evenly split into 8 segments, each segment should\
    \ be 6\xB0 as you noted.  [This user guide](https://leddartech.com/download/user-guide-leddar-vu8-module/)\
    \ says the FoV is 47.5\xB0, so you may want to double-check.  I'll assume 48\xB0\
    \ here.  If the FoV is centered on the x-axis (forward) in the lidar frame, the\
    \ segment angles should be {21, 15, 9, 3, -3, -9, -15, -21} in degrees.  Note\
    \ that I'm assuming the segments are ordered left to right (segment 0 is left-most,\
    \ the most positive angle), which agrees with the diagram on page 41 of the linked\
    \ user guide, but that's another assumption that you should double-check.  Here's\
    \ a diagram for clarity:\n\n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/16160873401375369.png)\n\
    \n---\nUpdate from @mros:\n> I checked the sensor and the segments are ordered\
    \ right to left (not as mentioned in the datasheet). So, {-21,-15,-9,-3,3,9,15,21}\
    \ is the order (from 0 to 7)."
