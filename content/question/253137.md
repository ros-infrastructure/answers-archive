    You can consider [velodyne's implementation](https://bitbucket.org/DataspeedInc/velodyne_simulator/src/master/) which extends the default `gazebo_ros_block_laser` to publish PointCloud2

    Just run

        sudo apt install ros-melodic-velodyne-gazebo-plugins

    and replace, in your `model.sdf`, `libgazebo_ros_block_laser.so` with `libgazebo_ros_velodyne_laser.so`
