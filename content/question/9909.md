    A node was added to provide this functionality (although the documentation is lacking info about it).

    You can run it like this:

        rosrun laser_assembler point_cloud2_assembler _fixed_frame:=map cloud:=/velodyne_points

    Get the pointcloud as described [here](http://wiki.ros.org/laser_assembler#Example:_Calling_from_C.2B-.2B-). The service is called `assemble_scans2`, with [AssembleScans2](http://docs.ros.org/api/laser_assembler/html/srv/AssembleScans2.html).
