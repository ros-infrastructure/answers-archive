    \ settings:\n\nfor Ubuntu, with Velodyne Factory Settings it might look like this:\n\
    \nIn Ubuntu Network Settings IPv4 Settings:\n\nAddress          Subnet   \n192.168.1.100\
    \    16                # comment: this is your PC in the same Network like the\
    \ Lidar with IP 192.168.1.201\n192.168.3.100    16               # to get the\
    \ data stream ( u forgot to add this, in the Velodyne gui it is called Host (Destination)\
    \ and is the same under Network (Sensor) Gateway\n\n(unfortunately , I cannot\
    \ post a pic yet)\n\n\n##################################################################################\n\
    In your case above edit in Velodyne Lidar Gui the Gateway from 192.168.1.1 to\
    \ 192.168.1.12.\n\n192.168.1.12 is the 192.168.3.100 of the factory setting example.\n\
    \nTherefore, enter that address in Ubuntu 192.168.1.12 with Subnet Mask 24\n##################################################################################\n\
