  body_markdown: "There is a `pause` Launch Argument that you can set to `true` ([defined\
    \ here in the source](https://github.com/ros-simulation/gazebo_ros_pkgs/blob/foxy/gazebo_ros/launch/gzserver.launch.py#L105))\n\
    \nYour launch command could look something like this:\n\n    import os\n    from\
    \ ament_index_python.packages import get_package_share_directory\n    from launch\
    \ import LaunchDescription\n    from launch.actions import IncludeLaunchDescription\n\
    \    from launch.launch_description_sources import PythonLaunchDescriptionSource\n\
    \    \n    \n    def generate_launch_description():\n        ld = LaunchDescription()\n\
    \        gz_launch_path = os.path.join(get_package_share_directory('gazebo_ros'),\
    \ 'launch', 'gazebo.launch.py')\n        ld.add_action(\n            IncludeLaunchDescription(\n\
    \                PythonLaunchDescriptionSource(gz_launch_path), \n           \
    \     launch_arguments={'pause': 'true'}.items()\n        ))\n        return ld\n\
    \n"
