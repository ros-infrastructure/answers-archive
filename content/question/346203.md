    By default, the velocity and acceleration is set to 10% of the robot's maximum in MoveIt (starting from Noetic). You can change the values in your code with [this C++](http://docs.ros.org/api/moveit_ros_planning_interface/html/classmoveit_1_1planning__interface_1_1MoveGroupInterface.html#a0eec941ccbfa23260196196ce7a8dd17) and [this Python](http://docs.ros.org/jade/api/moveit_commander/html/classmoveit__commander_1_1move__group_1_1MoveGroupCommander.html#a020b41d385657da906d746f97dcab4a6) function, or change the default value in the `joint_limits.yaml` file in your `moveit_config` package.
