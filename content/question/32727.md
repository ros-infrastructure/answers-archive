  body_markdown: "The extrapolation limit defaults to zero and is recommended to stay\
    \ set as such.  When looking up values tf uses linear interpolation to compute\
    \ the result between the closest two data points.  If a query is within the extrapolation\
    \ limit of the closest datapoint it will use the linear interpolation to extrapolate.\
    \  \n\nNote this is very noisy and leads to very obscure bugs, and i have not\
    \ seen it used successfully in any application.    "
