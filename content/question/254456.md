    sudo nano [new_node_name].py

        rospy.init_node("serial_node")

    sudo chmod +x [new_node_name].py

    rosrun rosserial_python [new_node_name].py /dev/ttyUSB0

How do you give a name to a rosserial_arduino node? There are several [good examples](http://wiki.ros.org/rosserial_arduino/Tutorials), but none of them specify a name, resulting in the published topics and listeners appearing in the root namespace.

Normally, a node's name is specified with `ros::init(argc, argv, "some_name");` but it doesn't look like rosserial_arduino supports this.
