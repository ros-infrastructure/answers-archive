  body_markdown: "Keep your connection alive.\n\nUnregistering and registering takes\
    \ time.\n At least some milliseconds, it is done by XMLRPC and this means as the\
    \ name says, parsing an XML message on each side, then opening a port and creating\
    \ the connection.\n\n(Update:)\n\nmore detailed what happens:\n\n    First you\
    \ subscribe:\n    Node -XMLRPC -> Master (I subscribe topic xyz)\n    Master -XMLRPC\
    \ -> Node (There is a publisher X)\n    Node -XMLRPC-> NodeX (I want topic xyz)\n\
    \    NodeX -XMLRPC-> Node (I opened port Y for you)\n    Node <-ROSMSG Header->\
    \ NodeX:PortY(ROSMSG Header)\n    NodeX -ROSMSG Binary-> constantly sending when\
    \ published\n\n    Then you unsubscribe:\n    Node -XMLRPC-> NodeX (I do not want\
    \ topic xyz anymore)\n    NodeX -XMLRPC> Node (OK) \n    Close connection on PortY\
    \ (both)\n    Node -XMLRPC-> Master (I am not interested in xyz anymore)\n   \
    \ Master -XMLRPC-> OK\n\n---\n\nSo why don't you just disable the processing in\
    \ the callback itself instead of resubscribing when you do not want to have images?\n\
    \nLike\n\n    void callback(...)\n    {\n      if(image_processing_enable) \n\
    \      {\n       .... Save your image, processing ... what ever ...\n       image_processing_enable=false;\
    \ // for getting only one image. \n      }\n    }\n\nRegards,\n\nChristian\n"
