    The others are right--you didn't run catkin_make yet. Make sure you did all these steps:

        catkin_init_workspace
        cd ~/catkin_ws
        catkin_make
        echo "source ~/catkin_ws/devel/setup.bash" >> ~/.bashrc
        source ~/.bashrc
