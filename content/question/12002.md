    Add the [sensor_msgs](http://www.ros.org/wiki/sensor_msgs) package to your dependencies in your `manifest.xml` with `<depend package="sensor_msgs"/>`, then include the appropriate C++ message header file with `#include <sensor_msgs/Joy.h>`, and change the callback to

        void myCallback (const sensor_msgs::Joy::ConstPtr& msg)
        {
          for (unsigned i = 0; i < msg->axes.size(); ++i) {
            ROS_INFO("Axis %d is now at position %f", i, msg->axes[i]);
          }
        }
