  body_markdown: "I also stumbled across this problem and implemented a generic solution.\
    \ You might want to have a look at the [aliencontrol ROS package](https://github.com/acschaefer/aliencontrol).\
    \ \n\nThis package contains a node that starts any external application. Almost\
    \ more importantly, the node also takes care of a clean shutdown, no matter whether\
    \ the external application or the containing ROS node is terminated.\n\nIt is\
    \ run like so (if you wanted to start `your_script.sh`):\n\n    rosrun aliencontrol\
    \ aliencontrol /path/to/your_script.sh\n\nIf you want to embed it in your launch\
    \ script, add:\n\n    <node pkg=\"aliencontrol\" type=\"aliencontrol\" name=\"\
    aliencontrol\">\n        <param name=\"cmd\" value=\"/path/to/your_script.sh\"\
    />\n    </node>"
