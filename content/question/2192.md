  body_markdown: "A sdf file is just a text file with a sdf extension. You can create\
    \ it with any text editor (that doesn't add extra characters). You should be able\
    \ to type `vim new_sdf.sdf` in a terminal, which will open the editor. Or use\
    \ `gedit new_sdf.sdf` if you want a non terminal editor. "
