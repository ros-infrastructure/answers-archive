  body_markdown: "The camera is looking up. There is a missing optical rotation that\
    \ could be fixed by rotating the base frame of the camera:\n\n    <arg name=\"\
    pi/2\" value=\"1.5707963267948966\" />\n    <arg name=\"optical_rotate\" value=\"\
    0 0 0 -$(arg pi/2) 0 -$(arg pi/2)\" />\n    <node pkg=\"tf\" type=\"static_transform_publisher\"\
    \ name=\"camera_base_link\" args=\"$(arg optical_rotate) base_link stereo_camera\
    \ 100\" /> \n\nThen make sure to set `frame_id` parameter of rtabmap to `base_link`\
    \ (or whatever is your robot base frame).\n\ncheers,<br/>\nMathieu"
