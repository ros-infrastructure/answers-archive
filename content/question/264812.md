  body_markdown: "From [`rospy` Time wiki entry](http://wiki.ros.org/rospy/Overview/Time#Sleeping_and_Rates),\n\
    \n> `rospy.Rate(hz)`\n> \n> rospy provides a rospy.Rate\n> convenience class which\
    \ makes a best\n> effort at maintaining a particular\n> rate for a loop. For example:\n\
    > \n> \n>     r = rospy.Rate(10) # 10hz \n>     while not rospy.is_shutdown():\n\
    >         pub.publish(\"hello\")\n>         r.sleep()\n> \n> \n> In the above\
    \ example, the `Rate`\n> instance will attempt to keep the loop\n> at 10hz by\
    \ accounting for the time\n> used by any operations during the\n> loop. `Rate.sleep()`\
    \ can throw a\n> `rospy.ROSInterruptException` if the\n> sleep is interrupted\
    \ by shutdown.\n\nBasically, it allows your loops to run at (nearly) the exact\
    \ rate (in Hz) that you specify. It's a pretty standard way of looping with `ROS`.\
    \ Check out the [source code](http://docs.ros.org/jade/api/rospy/html/rospy.timer-pysrc.html#Rate.sleep)\
    \ that's linked to in the documentation that you were looking at:\n\n     87 -\
    \    def sleep(self): \n     88          \"\"\" \n     89          Attempt sleep\
    \ at the specified rate. sleep() takes into \n     90          account the time\
    \ elapsed since the last successful \n     91          sleep(). \n     92    \
    \       \n     93          @raise ROSInterruptException: if ROS shutdown occurs\
    \ before \n     94          sleep completes \n     95          @raise ROSTimeMovedBackwardsException:\
    \ if ROS time is set \n     96          backwards \n     97          \"\"\" \n\
    \     98          curr_time = rospy.rostime.get_rostime() \n     99          sleep(self._remaining(curr_time))\
    \ \n    100          self.last_time = self.last_time + self.sleep_dur \n    101\
    \   \n    102          # detect time jumping forwards, as well as loops that are\
    \ \n    103          # inherently too slow \n    104          if curr_time - self.last_time\
    \ > self.sleep_dur * 2: \n    105              self.last_time = curr_time \n\n\
    Go through the [`rospy` tutorials](http://wiki.ros.org/rospy/Tutorials) if you\
    \ haven't already. From the [writing a publisher and subscriber tutorial](http://wiki.ros.org/rospy_tutorials/Tutorials/WritingPublisherSubscriber):\n\
    \n>     rate = rospy.Rate(10) # 10hz\n>     \n> This line creates a `Rate` object\
    \ `rate`. With the help of its method\n> `sleep()`, it offers a convenient way\n\
    > for looping at the desired rate. With\n> its argument of `10`, we should expect\n\
    > to go through the loop 10 times per\n> second (as long as our processing time\n\
    > does not exceed 1/10th of a second!)"
