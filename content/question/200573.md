  body_markdown: "You'll have to manually mix in the desired plugins to achieve what\
    \ you need.\n\nPlace the following In your `local_costmap_params.yaml`\n\n   \
    \ local_costmap:\n      plugins: \n        - {name: static_map, type: \"costmap_2d::StaticLayer\"\
    }\n        - {name: obstacles, type: \"costmap_2d::ObstacleLayer\"}\n        -\
    \ {name: inflation, type: \"costmap_2d::InflationLayer\"}\n      global_frame:\
    \ odom\n      robot_base_frame: base_link\n      transform_tolerance: 5.0\n  \
    \    update_frequency: 5.0\n      publish_frequency: 2.0\n    \n      obstacles:\n\
    \          observation_sources: laser_scan_sensor\n          laser_scan_sensor:\
    \ {sensor_frame: base_link, data_type: LaserScan, topic: scan, marking: true,\
    \ clearing: true}\n\nThe `costmap_2d::StaticLayer` plugin allows you to specify\
    \ a static layer in your `local_costmap`\nThe `costmap_2d::ObstacleLayer` and\
    \ `costmap_2d::InflationLayer` does what the original local costmap does, marking\
    \ and clearing and inflating obstacles, note the similarity for the parameters.\n\
    \nMore details can be found here: \n\n- https://github.com/ros-planning/navigation/blob/melodic-devel/costmap_2d/src/costmap_2d_ros.cpp#L279\n\
    - https://wiki.ros.org/costmap_2d/Tutorials/Configuring%20Layered%20Costmaps"
