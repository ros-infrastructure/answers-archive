  body_markdown: "I figured it out :-)\nThe problem was a old attempt to install ros\
    \ from sources with *pip and easy_install*\n as it is described on http://www.ros.org/wiki/fuerte/Installation/Ubuntu/Source\
    \ . The attempt places stuff under /usr/local/bin and since I was executing some\
    \ of the commands with sudo the rights we set to root only.\nInstalling the fuerte\
    \ ros based on the ppa worked well but old binaries under /usr/local/bin where\
    \ already placed within the search path before the others and executed instead.\
    \ This leaded to the permission problems.\n\nThe solution was to remove:\ndo delete\
    \ the related old stuff\n\n    cd /usr/local/bin\n    rm -rf pip pip-2.7 rosco\
    \ rosdep rosdep-gbp-brew rosdep-source rosinstall roslocate rosversion rosws virtualenv\n\
    \    cd /usr/local/lib\n    rm -rf python2.7 \n    # sudo apt-get purge python-pip\
    \ python-dev build-essential # should not be nessesary but I dit it anyway\n \
    \   sudo apt-get install ros-fuerte-desktop\n\n\nGreetings\n\n"
