  body_markdown: "From my own experience, it seems like the answer is that one can't\
    \ apply force to a model/object, only a link. This can be solved by getting the\
    \ desired link from the model, where the names of the links can be changed in\
    \ the .world file: \n\n<code>\nthis->model->GetLink(\"body\")->SetForce(ignition::math::Vector3d(1.0,\
    \ 0.0, 0.0);\n</code>\n\nThe same goes for applying torque: \n\n<code>\nthis->model->GetLink(\"\
    body\")->SetTorque(1.0, ignition::math::Vector3d(1.0, 0.0, 0.0);\n</code>\n\n\
    Hope this helps someone else."
