  body_markdown: "For this particular situation, here is what worked for me.\n\n**Install\
    \ rtabmap first:**\n\n    $ cd ~\n    $ git clone https://github.com/introlab/rtabmap.git\
    \ rtabmap\n    $ cd rtabmap/build\n    $ cmake -DCMAKE_INSTALL_PREFIX=~/catkin_ws/devel\
    \ ..\n    $ make -j4\n    $ make install\n\nthe `DCMAKE_INSTALL_PREFIX` is what\
    \ solved my issue. I don't know why creating my *own catkin_ws* did not work but\
    \ I suspect I was missing something simple.\n\n**Install rtabmap_ros second:**\n\
    \n    $ cd ~/catkin_ws\n    $ git clone https://github.com/introlab/rtabmap_ros.git\
    \ src/rtabmap_ros\n    $ catkin_make\n\nin this second step you've used the *catkin_ws*\
    \ folder that was created by the `rtabmap` install. I added my `freenect_throttle.launch`\
    \ to `catkin_ws/src/rtabmap_ros/launch` folder and then re-ran `catkin_make` inside\
    \ the parent `catkin_ws` folder.\n\nAll documentation for `rtabmap`, `rtabmap_ros`,\
    \ and `` can be found in the following links:\n\n- [rtabmap homepage](http://introlab.github.io/rtabmap/)\n\
    - [Installing rtabmap](https://github.com/introlab/rtabmap/wiki/Installation)\n\
    - [Installing rtabmap_ros](https://github.com/introlab/rtabmap_ros)\n- [Using\
    \ rtabmap with a remote machine](http://wiki.ros.org/rtabmap_ros/Tutorials/RemoteMapping)\n\
    \n*Note: You get an issue on the freenect_throttle.launch when you first run it\
    \ because one of the xml comments is not closed correctly, close the comment and\
    \ it will run fine. I've attached what the corrected launch file below*\n\n  \
    \  <launch>\n      <include file=\"$(find freenect_launch)/launch/freenect.launch\"\
    >\n         <arg name=\"depth_registration\" value=\"True\" />\n      </include>\n\
    \    \n      <arg name=\"rate\"  default=\"5\"/>\n      <arg name=\"decimation\"\
    \  default=\"1\"/> \n      <!-- Reduce the image size, e.g., 2 means \"width/2\
    \ x height/2\". -->\n    \n      <!-- Use same nodelet used by Freenect/OpenNI\
    \ -->\n      <group ns=\"camera\">\n        <node pkg=\"nodelet\" type=\"nodelet\"\
    \ name=\"data_throttle\" args=\"load rtabmap_ros/data_throttle camera_nodelet_manager\"\
    \ output=\"screen\">\n          <param name=\"rate\" type=\"double\" value=\"\
    $(arg rate)\"/>\n          <param name=\"decimation\" type=\"int\" value=\"$(arg\
    \ decimation)\"/>\n    \n          <remap from=\"rgb/image_in\"       to=\"rgb/image_rect_color\"\
    />\n          <remap from=\"depth/image_in\"     to=\"depth_registered/image_raw\"\
    />\n          <remap from=\"rgb/camera_info_in\" to=\"rgb/camera_info\"/>\n  \
    \  \n          <remap from=\"rgb/image_out\"       to=\"data_throttled_image\"\
    />\n          <remap from=\"depth/image_out\"     to=\"data_throttled_image_depth\"\
    />\n          <remap from=\"rgb/camera_info_out\" to=\"data_throttled_camera_info\"\
    />\n        </node>\n      </group>      \n    </launch>"
