  body_markdown: "> (from the manual:) \n> The motor will not run when the operating\
    \ mode is set to 0. It will be stopped when the motor is running in one of the\n\
    supported operating modes and the operating mode is then switched to 0\n\n> Note\

    \ least I don't find the requirement in the manual at a first glance.\nThe mode\
    \ 0 in the PDO message does not correspond to mode switch, but to the default\
    \ value in the EDS.\n(Your config couples the control word and the mode in one\
    \ PDO, so both get sent)\n\nIf you want to set the initial value, just add a `ParameterValue`\
    \ with a specific mode to your EDS/DCF.\nOr use the `dcf_overlay` feature for\
    \ convenience (http://wiki.ros.org/canopen_chain_node?distro=indigo#CA-aac0b244a9b279b10a86af0a165ff7215371ab50_4).\n\

 I am trying to control [Trinamic PD-1160](http://www.trinamic.com/products/pandrives/pandrives-stepper/pd-1160) motor using ros_canopen. The motor is DS402 complient. The CANopen manual of this motor is located [here](http://www.trinamic.com/_scripts/download.php?file=_articles%2Fproducts%2Fpandrives%2Fpd-1160%2F_documentation%2FTMCM-1180_1160_1140_CANopen_manual.pdf).

My question is weather this is a configuration issue or a bug in ros_canopen.
