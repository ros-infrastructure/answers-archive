    That variable is no longer needed, and can safely be deleted from any `CMakeLists.txt` file where you find it.

    There was a time when `ROSPACK_MAKEDIST` was needed to elicit stack-specific behavior from `rosbuild`, but it was [removed long ago](https://code.ros.org/trac/ros/changeset/7768).
