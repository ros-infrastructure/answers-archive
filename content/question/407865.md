Hi, I'm using ROS2 and realsense D435i to implement a navigation application. I modified [this example](https://github.com/NVIDIA-ISAAC-ROS/isaac_ros_nvblox/blob/main/docs/tutorial-nvblox-vslam-realsense.md) which brings up the realsense node, nvblox, and VSLAM. It runs well when all nodes are in the same machine. I divided them, such as the realsense node only running on the jetson board on my robots, nvblox, and VSLAM runs in the edge server. The robot and edge server are connected with ethernet cables. Please note that I have tested that they can ping and use the talker listener examples from ROS2 well.
