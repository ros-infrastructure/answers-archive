  body_markdown: "Each message in the /velodyne_points topic contains all the data\
    \ from a complete revolution of the device.\n\nIf you write a ROS node that subscribes\
    \ to that topic, your subscription callback will be called each time a new message\
    \ arrives. That happens at 10 Hz with the device spinning at the default 600 RPM\
    \ rate.\n\nHere is an [example node that reads the point cloud](https://github.com/jack-oquin/velodyne_height_map/blob/master/src/heightmap.cpp#L188)\
    \ for each revolution, looking for points within some grid cells that significantly\
    \ differ in the Z axis. \n\nYou can figure out from that how to write your own\
    \ subscriber node."
