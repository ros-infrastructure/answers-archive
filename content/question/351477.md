  body_markdown: "To move both arms in sync, you need a planning group that includes\
    \ the joints of both robot arms in it. \n\nThere is an example configuration of\
    \ two UR5 robots in [this repository](https://github.com/o2as/ur-o2as). Look specifically\
    \ [this SRDF file](https://github.com/o2as/ur-o2as/blob/master/catkin_ws/src/o2as_moveit_config/config/o2as_base_scene.srdf),\
    \ where the planning group `front_bots` is defined which contains the two UR5\
    \ robots, and [here](https://github.com/o2as/ur-o2as/blob/master/catkin_ws/src/o2as_routines/src/o2as_routines/base.py#L147),\
    \ where the Python MoveGroup interface is instantiated.\n\nNote that you should\
    \ set two PoseTargets (one for each end effector), or sufficient joint angle targets,\
    \ and that unused joints may end up moving if you don't assign goals to them."
