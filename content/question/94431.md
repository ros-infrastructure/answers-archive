  body_markdown: "There is no general \"System Requirements\" for any given ROS distribution,\
    \ it depends on which packages you use. It's always wise to use the latest ROS\
    \ release, which in this case is ROS Hydro. This ensures you have the latest implementations\
    \ of all the tools and libraries available in ROS. \n\nYour laptop is very well\
    \ suited to running common path planning algorithms and processing Kinect data.\
    \ The Turtlebot reference platform utilizes an Atom-based netbook with 2 GB of\
    \ RAM and can run the ROS navigation stack and Kinect drivers with no problems\
    \ -- a Core 2 with 4 GB should perform much much better."
