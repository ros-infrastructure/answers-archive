    \ size.\nYou can also get size from http://docs.ros.org/en/melodic/api/sensor_msgs/html/msg/Image.html\
    \ by selecting this variable in your code.\n\n    uint32 height\n    uint32 width\n\
    \nNote: `rostopic echo /camera/image_raw` You are getting full `sensor_msgs/Image`\
    \ data over here but each image has a huge matrix so you are not able to view\
    \ the full message properly from your terminal. \n\n  \n  b.  second way to get\
    \ size. \n\n\nJust check if you are getting the `camera_info` topic. You can get\
    \ this by typing `rostopic list` then try to view information of that you will\
    \ get all details like height, width and other details which you required.\n\n\
    \    rostopic echo  <camers-info-topic>#/camera/color/camera_info\n\n\n> exact\
    \ format\n\nHave a look at this link you will get exact formate of an image message\
    \ in ROS.\n\nhttp://docs.ros.org/en/melodic/api/sensor_msgs/html/msg/Image.html"
