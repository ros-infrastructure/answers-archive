I tried adding a box to allow a gripper to hit an obstacle. However when I specify all the links of the PR2 gripper (there's several!) all the nodes that use the planning scene complain that:

If I use only two links (in this case "r_wrist_flex_link" and "r_wrist_roll_link"), IK returns with error -33 (I bet it's a collision check failing).
