  body_markdown: "You can add  `plugin.xml` in your directory `/opt/ros/melodic/share/rqt_virtual_joy`.\n\
    \n 1. Go to `rqt_virtual_joy` directory. \n\n    <pre><code>roscd rqt_vritual_joy</code></pre>\n\
    \n 2. Make file `plugin.xml`\n\n    <pre><code>sudo touch plugin.xml</code></pre>\n\
    \   \n\n 3. Edit the `plugin.xml` file with gedit (or other)\n\n    <pre><code>sudo\
    \ gedit plugin.xml</code></pre>\n\n 4. Copy and paste the contents of the `plugin.xml`\
    \ file from the [rqt_virtual_joystick github](https://github.com/aquahika/rqt_virtual_joystick)\
    \ to your  `plugin.xml`."
