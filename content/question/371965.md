 I am trying to use [this specific overload](http://docs.ros.org/en/melodic/api/roscpp/html/classros_1_1NodeHandle.html#a17ed10bb6e221d11c53a8d35058c24a0) for `advertiseService` using a custom lambda function.  My attempt is as follows

      ros::ServiceServer my_service = 
        nh.advertiseService<my_pkg::MyService>(my_service_name,
          [&](my_pkg::MyService& call) -> bool
          {
            ...
          });

I get the error

    error: no type named ‘CallbackType’ in ‘struct my_pkg::MyService’

Following the [trail](http://docs.ros.org/en/melodic/api/roscpp/html/node__handle_8h_source.html#l01190) brings me to [initBySpecType](http://docs.ros.org/en/melodic/api/roscpp/html/advertise__service__options_8h_source.html#l00104) which indeed is requesting `Spec::CallbackType` where `Spec` is `my_pkg::MyService`.

Looking at the generated header for `struct my_pkg::MyService`, it indeed is missing a `CallbackType`.

Is anyone else experiencing the same issue?

Using [another overload](http://docs.ros.org/en/melodic/api/roscpp/html/classros_1_1NodeHandle.html#ae0c911cb906fefc6dbe274fc82724842) which explicitly specifies `my_pkg::MyService::Request` and `my_pkg::MyService::Response` works.
