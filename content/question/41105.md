  body_markdown: "We have a 6D localization running in an OctoMap for our humanoid\
    \ robots. You can find details in the publication [\"Humanoid Robot Localization\
    \ in Complex Indoor Environments\"](http://hrl.informatik.uni-freiburg.de/papers/hornung10iros.pdf).\
    \ It's runnning MCL (particle filtering) and uses ray casting for the sensor model.\
    \ \n\nThe code is now published at http://ros.org/wiki/humanoid_localization\n\
    \nIt's mostly designated for humanoid robots and still being polished right now,\
    \ but I'm sure you can use much of the sensor model code as example.\n\n\nIf you\
    \ want to implement your own localization, you can use the function [castRay](http://octomap.sourceforge.net/doxygen/classoctomap_1_1OccupancyOcTreeBase.html#afc368d6ff93f40ee33eca3df0b8d1967)\
    \ in OctoMap.\n\nIn terms of map building, planning, and collision checking in\
    \ an OctoMap look at the [3d_navigation](http://www.ros.org/wiki/3d_navigation)\
    \ stack and the publication [\"Navigation in Three-Dimensional Cluttered Environments\
    \ \n  for Mobile Manipulation\"](http://hrl.informatik.uni-freiburg.de/papers/hornung12icra_3Dnav.pdf)."
