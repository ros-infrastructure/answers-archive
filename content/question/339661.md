  body_markdown: "You can use launch_ros for both cpp nodes and python nodes i guess\
    \ for. For python you have to use the setup.py to make   necessary files available\
    \ to the test and for cpp the CMakeList.txt. \n\nBelow is the code you have to\
    \ add to your CMakeList if testing a cpp package and the launch description for\
    \ the node that is to be tested: \n\nIn your CMakeList.txt include\n\n>      \n\
    >     install(FILES\n>       test/<name>_launch_testing.py\n>       DESTINATION\
    \ lib/${PROJECT_NAME})\n>     \n>     if(BUILD_TESTING)\n>        find_package(launch_testing_ament_cmake)\n\
    >       add_launch_test(test/<name>_launch_testing.py)\n>       find_package(ament_lint_auto\
    \ REQUIRED)\n>       ament_lint_auto_find_test_dependencies()\n>     endif()\n\
    \nYour generate_test_description(): inside <name>_launch_testing.py then gives\
    \ your cpp node to the test system:\n\n>     dut = Node(\n>         package='ros2_cpp_test_example',\n\
    >         executable='<name>',\n>         name='<name>',\n>     )\n>     context\
    \ = {'dut': dut}\n> \n>     return (launch.LaunchDescription([\n>         dut,\n\
    >         launch_testing.actions.ReadyToTest()]\n>         ), context\n>     )\n\
    \nBelow the launch description you can add your testcases using the class unittest.TestCase.\
    \ You can access the output of the launched nodes as described in the links you\
    \ supplied.    \n\nInside the testcases you can also start a testnode that receives/sends\
    \ messages of/to the node you want to test as shown in \nhttps://github.com/ros2/launch_ros/blob/master/launch_testing_ros/test/examples/talker_listener_launch_test.py\n\
    \nHere you can find an example package in addition to the official documentation\
    \ with Ubuntu 20.04 and Foxy: https://github.com/GitRepJo/ros2_cpp_test_example\n\
    \n"
