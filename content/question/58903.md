  body_markdown: "It's a advisable that you use an IMU to estimate the attitude (roll/pitch)\
    \ angles of the LIDAR. But provided you keep the scan plane parallel to the ground,\
    \ things can also work without one.\n\nWhat you will want to do is starting the\
    \ Hokuyo node, a static publisher for the transformation of the base frame of\
    \ your \"robot\" to your laser scanner frame and a properly set up mapping node.\
    \ The latter two you can start with this launch file:\n\n    <launch>\n    \n\
    \      <include file=\"$(find hector_mapping)/launch/mapping_default.launch\"\
    >\n        <arg name=\"base_frame\" value=\"base_frame\"/>\n        <arg name=\"\
    odom_frame\" value=\"base_frame\"/>\n      </include>\n     \n      <include file=\"\
    $(find hector_geotiff)/launch/geotiff_mapper.launch\">\n        <arg name=\"trajectory_source_frame_name\"\
    \ value=\"base_frame\"/> \n      </include>\n    \n      <node pkg=\"tf\" type=\"\
    static_transform_publisher\" name=\"base_frame_to_laser_broadcaster\" args=\"\
    0 0 0 0 0 0 base_frame laser 100\"/>\n    \n    </launch>\n\nProvided your scanner\
    \ publishes on the \"scan\" topic and uses the \"laser\" frame_id, this launch\
    \ file should work."
