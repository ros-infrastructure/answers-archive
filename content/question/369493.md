    If you run `rosservice type /compute_ik`, it should return [moveit_msgs/GetPositionIK](http://docs.ros.org/en/api/moveit_msgs/html/srv/GetPositionIK.html). You could then use `rosmsg show --raw moveit_msgs/PositionIKRequest` (which is the type of the `ik_request` field) or use the web documentation to go to [moveit_msgs/msg/PositionIKRequest](http://docs.ros.org/en/api/moveit_msgs/html/msg/PositionIKRequest.html) which includes the comments on the fields.
