  body_markdown: |+
    You need to add `rclcpp_components` as one of the dependencies inside `ament_target_dependencies`. Please do the following:

    1) First get the package

        find_package(rclcpp_components REQUIRED)


    2) Then add it to `ament_target_dependencies`


        ament_target_dependencies(
          ${PROJECT_NAME}
          rclcpp
          rclcpp_components
          hardware_interface
          lifecycle_msgs
          pluginlib
          rclcpp_lifecycle
          serial
        )

    I am sharing an example for more info. Please feel free to check the [ros2/demos/composition](https://github.com/ros2/demos/tree/rolling/composition).
