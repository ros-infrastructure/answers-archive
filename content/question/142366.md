    It appears the old way of using a PR2 controller manager is deprecated and does not work anymore in hydro (Example of a roll/pitch mount using that approach [here](https://code.google.com/p/tu-darmstadt-ros-pkg/source/browse/trunk/hlugv_common/hlugv_description/urdf/sensor_roll_pitch_mount.urdf.xacro)).

     Everything you need to know for using the new ROS Control approach should be explained in the [ROS Control with Gazebo](http://gazebosim.org/wiki/Tutorials/1.9/ROS_Control_with_Gazebo) tutorial. Essentially, you need a URDF model with 3 links (connected via two joints). If you setup the two joint axes as required for your pan/tilt unit and load the controllers as explained in the tutorial, things should work and you should be able to command the joints into desired positions.
