  body_markdown: "Basically there is a parameter in the configuration file of a costmap,\
    \ as reported in the [documentation](http://wiki.ros.org/costmap_2d): \n\n>  ~<name>/always_send_full_costmap\n\
    > (bool, default: false)\n> \n> If true the full costmap is published to \"~<name>/costmap\"\
    \ every\n> update. If false only the part of the\n> costmap that has changed is\
    \ published\n> on the \"~<name>/costmap_updates\"\n> topic.\n\nThis will force\
    \ to publish every time the full costmap. \n\n"
