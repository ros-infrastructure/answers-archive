  body_markdown: "You don't have to compile `slam_toolbox` from source to use it,\
    \ unless you want to modify the source code. You can install it with `atp`:\n\n\
    \    sudo apt update\n    sudo apt install ros-humble-slam-toolbox\n    source\
    \ /opt/ros/humble/setup.bash\n\nAfter installing it, you can use the following\
    \ launch file to use it:\n\n    ros2 launch slam_toolbox online_async_launch.py\n\
    \nYou'll probably want to see it building in `rviz2`, you can add the `/map` topic\
    \ once the file above is launched.\n\nTo save it, run \n\n    ros2 run nav2_map_server\
    \ map_saver_cli -f [name of map]\n\nIf you want to see this done step by step,\
    \ check out this video: https://youtu.be/JXnXnAXrYj8"
