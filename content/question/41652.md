    Could you try the followings?<br>
    <br>
    1. Launch a terminal.<br>
    2. Open ".bashrc". ".bashrc" is at your home directry(/home/(user-name)/.bashrc).<br>
    &nbsp;&nbsp;&nbsp;eg). <b>$gedit .bashrc</b><br>
    3. Check whether there are the following lines or not. If not, add them.<br>
    &nbsp;&nbsp;&nbsp;(<br>
    &nbsp;&nbsp;&nbsp;&nbsp;Assumption:<br>
    &nbsp;&nbsp;&nbsp;&nbsp;1. You use ros electric. If you use other ros versions, change the part "electric".<br>
    &nbsp;&nbsp;&nbsp;&nbsp;2. You made ros_workspace directry at your home directry and created beginner_tutorials package in the directry.<br>
    &nbsp;&nbsp;&nbsp;)<br>
    <b>export /opt/ros/electric/setup.bash<br>
    export ROS_PACKAGE_PATH=~/ros_workspace:/opt/ros/electric/stacks</b><br>

    *Second line is important. You need to add the directry which includes packages to environment variable.<br>

    If roscd still doesn't work well...<br>
    1. Go to beginner_tutorials directry.<br>
    &nbsp;&nbsp;&nbsp;eg). cd ~/ros_workspace/beginner_tutorials<br>
    2. Type the following command.<br>
    &nbsp;&nbsp;&nbsp;$rosmake<br>
    3. Retry "roscd".<br>
