    [getOrigin()](http://ftp.isr.ist.utl.pt/pub/roswiki/doc/unstable/api/tf/html/c++/classtf_1_1Transform.html#a55a6538f2d7762a05e5b96bc7d02562d) is a function of the tf::Transform class and as such has to be called with trailing `()`, indicating it is a function with 0 arguments.
