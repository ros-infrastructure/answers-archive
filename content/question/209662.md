  body_markdown: " \nHi,\n\nFor the \"some parts of the map disappearing\" with the\
    \ [rtabmap_ros/MapCloud](http://wiki.ros.org/rtabmap_ros#Map_Cloud_Display) rviz\
    \ plugin, you can disable its node filtering parameters to keep **all** clouds\
    \ shown:\n\n - Set \"Node filtering radius (m)\" to 0.\n - Set \"Node filtering\
    \ angle (degrees)\" to 0.\n\nThe demo stereo launch files you are referring are\
    \ working only for the specified bags (which require \"use_sim_time=true\"). On\
    \ a robot, you should remap the topics sent from the ros bag and set \"use_sim_time=false\"\
    . When simulating the clock, the TF_OLD_DATA warning can happen when you are replaying\
    \ the same rosbag: the second time, all timestamps are in the past.\n\nIn the\
    \ [demo launch file](http://wiki.ros.org/rtabmap_ros/Tutorials/StereoOutdoorMapping#Launch),\
    \ the [map_assembler](http://wiki.ros.org/rtabmap_ros#map_assembler) subscribes\
    \ to **/rtabmap/mapData_optimized** topic (note the rtabmap namespace). If mapData_optimized\
    \ is not published, map_assembler will do nothing.\n\nFor your specific question:\
    \ \" Is there any call to make to some rtabmap services (like publish_map) or\
