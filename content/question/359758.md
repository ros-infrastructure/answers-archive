I'm porting some code from ROS1 where we use [`bool ros::ServiceClient::isPersistent()`](http://docs.ros.org/melodic/api/roscpp/html/classros_1_1ServiceClient.html#aa1fe64f523d17b3d8ca4a78722b89bdc). ROS2 [`Client`](https://docs.ros2.org/latest/api/rclcpp/classrclcpp_1_1Client.html) does not have a similar API. Similarly, [`bool ros::ServiceClient::isValid()`](http://docs.ros.org/melodic/api/roscpp/html/classros_1_1ServiceClient.html#a688102be8047732bdf820c288523dff3) is not present. What would be equivalent code for ROS2? Do we just call [`async_send_request()`](https://docs.ros2.org/latest/api/rclcpp/classrclcpp_1_1Client.html#a7567297f43b72f96e8ec57fa7ff2f4e1) and hope for the best?
