  body_markdown: "There are two issues in your code :\n\n - The first one generates\
    \ the following error : `error: invalid use of non-static member function \u2018\
    bool test_services::TestServices::service_callback(const Request&, const Response&)\u2019\
    `\n\nIt says that you tried to pass a non-static member function to `advertiseService`,\
    \ which means you can't use it without an instaniated object of the class its\
    \ contained in. If you look at the [function prototype in the documentation](https://docs.ros.org/en/noetic/api/roscpp/html/classros_1_1NodeHandle.html#a0262cf4028324bbcd896b6909ab867ae)\
    \ :\n\n\n    ServiceServer ros::NodeHandle::advertiseService\t(\tconst std::string\
    \ & \tservice,\n    bool(T::*)(MReq &, MRes &) \tsrv_func,\n    T * \tobj \n \
    \   )\t\n     \\param service Service name to advertise on\n     \\param srv_func\
    \ Member function pointer to call when a message has arrived\n     \\param obj\
    \ Object to call srv_func on\n \nSo the second parameter must be a function pointer,\
    \ and the third one must be an object of your class, like this :\n\n      service_\
    \ = nodeHandle.advertiseService(\"service_name\", &TestServices::service_callback,\
    \ this);\n\n - The second issue is stated error : `error: no declaration matches\
    \ \u2018bool test_services::TestServices::service_callback(std_srvs::SetBool::Request&,\
    \ std_srvs::SetBool::Response&)\u2019`\n\nIn your `hpp` file you didn't declare\
    \ the fonction correctly :\n\n    bool service_callback(const std_srvs::SetBool::Request\
    \ &request,const std_srvs::SetBool::Response &response);\n\nYou have declared\
    \ the parameters as `const`, you need to remove them. \n\n"
