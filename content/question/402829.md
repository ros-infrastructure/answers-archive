  body_markdown: "> FILE CONTENT OF smartphone.py:\n> \n>     #!usr/bin/env python3\n\
    \nthis is not a correct [shebang](https://en.wikipedia.org/wiki/Shebang_(Unix))\
    \ (and technically also not a ROS problem).\n\nThe first line should read:\n\n\
    \    #!/usr/bin/env python3\n\nnote the first `/`, which is important.\n\nWithout\
    \ it, the path is relative to the *current working directory*, which for `roslaunch`\
    \ would be `$ROS_HOME`. There most likely isn't an `env` binary in `/home/rishav/.ros/usr/bin`."
