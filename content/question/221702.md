  body_markdown: "I finally figure out how to do this. Basicly, I added the [ft_sensor\
    \ plugin](http://docs.ros.org/jade/api/gazebo_plugins/html/group__GazeboRosFTSensor.html)\
    \ to my urdf. \n\nFollowing my code:\n\n    <gazebo reference=\"${name}_fixed_base_joint\"\
    >\n        <provideFeedback>true</provideFeedback>\n    </gazebo>\n    \n    <!--\
    \ The ft_sensor plugin -->  \n    <gazebo>\n      \t<plugin name=\"ft_sensor\"\
    \ filename=\"libgazebo_ros_ft_sensor.so\">\n     \t\t<updateRate>100.0</updateRate>\n\
    \      \t\t<topicName>ft_sensor_topic</topicName>\n     \t\t<jointName>schunk_wsg50_fixed_base_joint</jointName>\n\
    \     \t</plugin>\n    </gazebo>\n\nsome remarks:  \n\n - this plugin works with\
    \ a joint, in my case `\"${name}_fixed_base_joint\"` is the name of the joint\
    \ connecting the robot to the end-effector and it is fixed type\n - have look\
    \ at the plugin [implementation](http://docs.ros.org/jade/api/gazebo_plugins/html/gazebo__ros__ft__sensor_8cpp_source.html)\
    \ to figure out the reference frame in which the wrench is given\n\nHope this\
    \ can help. :)"

  - body_markdown: "This worked for me, below is the macro for the entire joint that\
      \ I add the sensor to\n\n     <xacro:macro name=\"fixed_joint_macro\" params=\"\
      xyz name parent child limit\">\n      <joint name=\"${name}\" type=\"prismatic\"\
      >\n       <parent link=\"${parent}\"/>\n       <child link=\"${child}\"/>\n\
      \       <origin rpy=\"0 0 0\" xyz=\"${xyz}\"/>\n       <axis xyz=\"1 0 0\"/>\n\
      \       <limit effort=\"1000\" lower=\"-0.0001\" upper=\"0.0001\" velocity=\"\
      10\"/>\n      </joint>\n    \n    <gazebo reference=\"${name}\">\n        <provideFeedback>true</provideFeedback>\n\
      \    </gazebo>\n    \n    <!-- The ft_sensor plugin -->  \n    <gazebo>\n  \
      \      <plugin name=\"ft_sensor\" filename=\"libgazebo_ros_ft_sensor.so\">\n\
      \            <updateRate>100.0</updateRate>\n            <topicName>sensor_${name}</topicName>\n\
      \            <jointName>${name}</jointName>\n        </plugin>\n    </gazebo>\n\
      \    </xacro:macro>"
