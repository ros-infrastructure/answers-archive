  body_markdown: "I agree with @gvdhoorn about avoiding relative path names. The trick\
    \ is to use [rospkg](http://wiki.ros.org/Packages#Python) to construct a path\
    \ relative to your package directory, something like this (*untested*):\n\n  \
    \  import os, rospkg\n    rp = rospkg.RosPack()\n    script_path = os.path.join(rp.get_path(\"\
    your_package\"), \"src\", \"script_name\") "
