    \ because range sensors like LRF or RGB-D sensor have limitation on distance measurement.\
    \ For example, Kinect has practical ranging limit around 0.8 \u2013 4 m.\n\nCamera\
    \ does not have the limitation, but it lacks the absolute info about scale. Also,\
    \ related tools are less.\nLSD-SLAM(Large Scale Direct SLAM) is a good one you\
    \ might want to take a look. But as far as I know, navigation with monocular is\
    \ still a problem.\n\nhttp://vision.in.tum.de/research/lsdslam\n\nHope this helps."
