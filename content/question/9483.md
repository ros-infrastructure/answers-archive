  body_markdown: "A [TransformListener](http://www.ros.org/doc/api/tf/html/classtf_1_1TransformListener.html)\
    \ class is continuously listening for incoming coordinate transforms from [TransformBroadcaster](http://www.ros.org/doc/api/tf/html/classtf_1_1TransformBroadcaster.html)s.\
    \ Any blocking call would severely disrupt the flow of information to the listener.\
    \ Therefore, \na transform listener, by default, spins its own thread. This particularly\
    \ helps with calls to functions like `tf::Transformer::waitForTransform` which\
    \ can block callbacks while it is waiting to hear back from tf.\n\n  * The API\
    \ for `tf::Transformer`, `tf::TransformListener` and `tf::TransformSender` all\
    \ use mutex locks to be threadsafe.\n  * `tf::Transformer::waitForTransform` requires\
    \ a dedicated listening thread (provided by default by [tf::TransformListener](http://www.ros.org/doc/api/tf/html/classtf_1_1TransformListener.html))\n\
    \nIf TransformListener spins a thread it will only service callbacks in the custom\
    \ callback queue for the tf topic.  "
