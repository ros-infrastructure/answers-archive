    \ the instructions* and add several instances of the **tf2_ros** package to my\
    \ Python launch file. I created static transform publishers as per **Link [1]**\
    \ below.\n\nTo understand *why* I needed to do this I went through **Link [2]**\
    \ which led to **Link [3]**.\n\nThe only real obstacle was understanding the similarities\
    \ between ROS1 and ROS2, both of which I'm still very new to at time of writing.\
    \ Once I understood how ROS2 launch files work I was able to follow **Link [4]**\
    \ to get SLAM Toolbox working with RViz and to develop a simple launch file for\
    \ a custom \"launch everything\" package.\n\n`[1]` [https://docs.ros.org/en/foxy/Tutorials/tf2.html](https://docs.ros.org/en/foxy/Tutorials/tf2.html)\n\
    \n`[2]` [https://wiki.ros.org/navigation/Tutorials/RobotSetup](https://wiki.ros.org/navigation/Tutorials/RobotSetup)\n\
    \n`[3]` [https://wiki.ros.org/navigation/Tutorials/RobotSetup/TF](https://wiki.ros.org/navigation/Tutorials/RobotSetup/TF)\n\
    \n`[4]` [https://www.robotandchisel.com/2020/08/19/slam-in-ros2/](https://www.robotandchisel.com/2020/08/19/slam-in-ros2/)\n\
    \n...\n\nIt's crude, but I simply added these three static transform publishers\
    \ to my launch file (which is a combination of one provided by an existing RPLidar\
    \ ROS2 fork and **Link [4]**) and ceased having errors completely:\n\n\n\n   \
    \ ## Somewhere higher-up...\n    ld = LaunchDescription()\n    \n    #### tf2\
    \ static transforms\n\n    ## tf2 - base_footprint to laser\n    node_tf2_fp2laser\
    \ = Node(\n        name='tf2_ros_fp_laser',\n        package='tf2_ros',\n    \
    \    executable='static_transform_publisher',\n        output='screen',\n    \
    \    arguments=['0', '0', '0', '0.0', '0.0', '0.0', 'base_footprint', 'laser'],\
    \   \n    )\n    ld.add_action(node_tf2_fp2laser)\n    \n    ## tf2 - base_footprint\
    \ to map\n    node_tf2_fp2map = Node(\n        name='tf2_ros_fp_map',\n      \
    \  package='tf2_ros',\n        executable='static_transform_publisher',\n    \
    \    output='screen',\n        arguments=['0', '0', '0', '0.0', '0.0', '0.0',\
    \ 'base_footprint', 'map'], \n    )\n    ld.add_action(node_tf2_fp2map)\n    \n\
    \    ## tf2 - base_footprint to odom\n    node_tf2_fp2odom = Node(\n        name='tf2_ros_fp_odom',\n\
    \        package='tf2_ros',\n        executable='static_transform_publisher',\n\
    \        output='screen',\n        arguments=['0', '0', '0', '0.0', '0.0', '0.0',\
    \ 'base_footprint', 'odom'],\n    )\n    ld.add_action(node_tf2_fp2odom)\n\n\n\
    \    ## Later, at the end...\n    return ld\n\n\n\n\n\n\n"
