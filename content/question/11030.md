    The computer that you're SSHing from needs to know what IP 'turtlebot' refers to is. Try finding the IP of the TurtleBot by running ifconfig in a terminal on the TurtleBot. Then, try:

        ssh turtlebot@<IP>

    If you are setting up a computer from scratch and are not using the official [TurtleBot iso](http://pr.willowgarage.com/downloads/turtlebot/turtlebot-amd64.iso), you may also need to install a server for ssh on your TurtleBot:

        sudo apt-get install openssh-server
