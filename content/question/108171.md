    \ don't have to launch minimal and 3d sensor. You can control both 3d sensor and\
    \ robot with the command below.\n\n<pre>\nroslaunch turtlebot_gazebo turtlebot_empty_world.launch\n\
    </pre>\n\nor\n\n<pre>\nroslaunch turtlebot_gazebo turtlebot_playground.launch\n\
    </pre>\n\n/camera/depth/points will give you 3d data. check with this command\
    \ \n\n<pre>\nrostopic bw /camera/depth/points \n</pre>\n\nor bringup rviz and\
    \ see.\n\n<pre>\nroslaunch turtlebot_rviz_launchers view_robot.launch\n</pre>\n"
