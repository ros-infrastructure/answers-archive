    EDIT:
    In general, the frame_id in the header of any topic (if it has a header) can be found by `rostopic echo`. For example, laser scans usually publish on `/scan` topic. So `rostopic echo /scan` will show you what is in frame_id. (You can use `rostopic echo /scan |grep frame_id` to show only that line with the id.
