  body_markdown: "As far as I'm aware, you can't redirect files like that with execl.\
    \ Here's a complete example with redirection written in C (should also compile\
    \ in C++, but change `NULL` to `nullptr`).\n\nAlso be sure to source your ROS\
    \ environment before you execute this.\n\n    #include <stdio.h>\n    #include\
    \ <sys/wait.h>\n    #include <unistd.h>\n    \n    int main(int argc, char **\
    \ argv)\n    {\n      int pid = fork();\n      if (-1 == pid) {\n        /* fork\
    \ failed */\n        perror(\"fork\");\n        return 1;\n      } else if (0\
    \ == pid) {\n        /* child process */\n        FILE * fp = fopen(\"navstackoutput.txt\"\
    , \"w\");\n        if (NULL == fp) {\n          perror(\"fopen\");\n         \
    \ return 1;\n        }\n        /* get descriptor for the file */\n        int\
    \ fd = fileno(fp);\n        /* redirect stderr to stdout */\n        dup2(fd,\
    \ 1);\n        /* redirect stdout (and stderr) to the file */\n        dup2(fd,\
    \ 2);\n        close(fd);  /* close redundant fd */\n        execlp(\"roslaunch\"\
    , \"roslaunch\", \"gazebo_ros\", \"willowgarage_world.launch\", NULL);\n     \
    \   perror(\"execlp\");  /* should never get here */\n      } else {\n       \
    \ /* parent process */\n        printf(\"Waiting for pid '%d' to exit...\\n\"\
    , pid);\n        int status;\n        int ret = waitpid(pid, &status, WUNTRACED);\n\
    \        if (0 > ret) {\n          perror(\"waitpid\");\n          return 1;\n\
    \        }\n        printf(\"Child exited with return code '%d'\\n\", status);\n\
    \      }\n\n      return 0;\n    }\n\n\nI should also note that the process will\
    \ probably hang until you manually kill it, so you should do a `kill -SIGINT [pid]`\
    \ where `pid` is the number output in the line `\"Waiting for pid '%d' to exit...\"\
    `."
