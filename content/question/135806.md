  body_markdown: "The header you want is one level too deep in the include hierarchy:\
    \ ``navfn/navfv/navfn_ros.h`` instead of ``navfn/navfn_ros.h``, etc. \n\nThat\
    \ looks like a bug in navfn to me. The Fuerte version put it where one would expect.\
    \ \n\nYou can probably work around this temporarily by adding an extra ``navfn/``\
    \ to your ``#include`` lines, but it needs to be fixed and should be [reported\
    \ as an issue](https://github.com/ros-planning/navigation/issues/new).\n\n**EDIT**:\
    \ As Dirk said, this bug has been fixed in the source tree but still not released\
    \ to the Ubuntu binary package repository. As a work-around, you can check out\
    \ the source into your workspace from the https://github.com/ros-planning/navigation.git\
    \ ``hydro-devel`` branch."
