  body_markdown: "Hi Onurcan \n\nYou are trying to wait  result before sending goal\
    \ to action server. In here \n\n    self.wait = self.client.wait_for_result()\n\
    \nYou should do that after sending goal \n\n    self.client.send_goal(self.goal)\n\
    \    self.wait = self.client.wait_for_result()\n\nand **use self.client.wait_for_result()\
    \ return** for result variable.\n\n\nIn the class init you can use client.wait_for_server()\
    \ function to wait for server."

            if result:

                rospy.logerr("Action server not available!")
                rospy.signal_shutdown("Action server not available!")

                return self.client.get_result()
