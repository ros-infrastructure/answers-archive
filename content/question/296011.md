    \ want to change the initial position of the robot on launch. you can add the\
    \ initial pose in the `xml` file. You might be using `amcl.launch.xml` in the\
    \ amcl.launch. you can add the initial pose of the robot there as\n\n        \
    \  <arg name=\"initial_pose_x\" default=\"0.0\"/> \n         <arg name=\"initial_pose_y\"\
    \ default=\"0.0\"/> \n         <arg name=\"initial_pose_a\" default=\"0.0\"/>\n\
    \         <include file=\"$(find <package>)/launch/includes/amcl.launch.xml\"\
    >\n         <arg name=\"initial_pose_x\" value=\"$(arg initial_pose_x)\"/>\n \
    \       <arg name=\"initial_pose_y\" value=\"$(arg initial_pose_y)\"/>\n     \
    \    <arg name=\"initial_pose_a\" value=\"$(arg initial_pose_a)\"/>\n        </include>\n\
    \n  The above are the parameters for amcl node.\n\n2. If you want ot track the\
    \ position of your model in `xyz plane`, you can use the `/odom` topic for same.\
    \ `odom` will give you the position and orientation of the robot. \n\nI hope,\
