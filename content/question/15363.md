  body_markdown: "I think there are a few things which need to be clarified.\n\n###\
    \ Change name inside the include tag\n\nThe uri as you put in your question is\
    \ used inside the `<include>` tag. If all you want is to have two cameras with\
    \ different names, you can add a `<name>` tag inside the include as follows:\n\
    \n    <include>\n      <name>camera_1</name>\n      <pose>1 0 0 0 0 0</pose>\n\
    \      <uri>model://camera</uri>\n    </include>\n    <include>\n      <name>camera_2</name>\n\
    \      <pose>2 0 0 0 0 0</pose>\n      <uri>model://camera</uri>\n    </include>\n\
    \n### model://\n\nURIs beginning with `model://` look for models in paths indicated\
    \ by the environment variable `GAZEBO_MODEL_PATH`.  See [this](http://gazebosim.org/tutorials?tut=components&cat=get_started)\
    \ tutorial for more information.\n\nIn case the model can't be found locally,\
    \ Gazebo looks for it on the online model database. [Here](https://bitbucket.org/osrf/gazebo_models/src/e6f90a80cd027faff5a74d32ae5c93511221cd22/camera/model.sdf?fileviewer=file-view-default)'s\
    \ the camera model in the database. Once Gazebo downloads it the first time, it\
    \ places the model under the `~/.gazebo/models/` directory so it can be found\
    \ locally in the future. If you check that directory in your computer, you should\
    \ find the camera there.\n    "
