  body_markdown: "I am Joan Pau, author of the camera1394stereo package, now maintained\
    \ by a collegue.\nThis package was created to handle binocular cameras, namely\
    \ bumblebee2 but it should work with any other IIDC camera supported by libdc1394\
    \ producing binocular stereo images using the usual way.\n\nFrom the system point\
    \ of view, a firewire IIDC stereo camera is seen as a single device (not two or\
    \ three), it has a unique GID (device identifier on the firewire bus) and a unique\
    \ set of parameters (frame rate, video mode, ...). Stereo cameras usually use\
    \ 'smartly' some video modes to transmit 2 or 3 images at a time (one for each\
    \ camera). \n\n* For 2 images they use a video mode with 16 bit depth (2 images\
    \ x 8 bits/pixel) or with 32 bit depth (2 images x 16 bits/pixel).\n* For 3 images\
    \ they use a video mode with 24 bit depth (3 images x 8 bits/pixel).\n\nDepending\
    \ on the camera each single image is either mono or has color information encoded\
    \ in Bayer pattern indicated by the manufacturer.\nFor the Bumblebee XB3 this\
    \ is described in section Stereo Image Formats here:\n\nhttp://www.ptgrey.com/support/downloads/documents/Bumblebee%20XB3%20Getting%20Started%20Manual.pdf\n\
    \nThe camera1394stereo driver is just a copy of the camera1394 one, but with the\
    \ added functionality to deinterleave the stereo image into two separated images\
    \ and publish them to two different topics (left and right) with the corresponding\
    \ camera info topic. So in your case it won't work for a stereo camera with 3\
    \ images.\n\nHowever, you can use the following approach. Use a camera1394 nodelet\
    \ to grab and publish the 24 bit depth images from the bumblebeeXB3 as if it was\
    \ a mono camera. Here you can set the frame rate and the other camera parameters.\
    \ And write a simple nodelet that subscribes to an image topic and deinterlaces\
    \ the input images, publishing 3 output images to the corresponding output image\
    \ topics (left, center and right) each one with the corresponding camera info.\
    \ This should be quite easy to implement (even though it would add some overhead,\
    \ for which I would not worry if using nodelets because images are not copied).\
    \ For the camera info part the CameraInfoManager already does the job, you just\
    \ have to use three instances (one for each output topic):\n\nhttp://www.ros.org/wiki/camera_info_manager\n\
    \nActually, it might be even useful to have this included in the image_proc chain:\
    \ a stereo_split or stereo_decompose nodelet, wich subscribes to an input image\
    \ topic and decomposes it according to the following parameters:\n\n  - number\
    \ of output images, \n  - their pixel bit depth, \n  - the stereo mode (how pixels\
    \ from each camera are merged in the stereo image)\n\nThis same nodelet should\
    \ provide the camera info topics for each of the output images, the camera info\
    \ of the original stereo image should be simply ignored.\n\nSorry for the long\
    \ response."

    \ the 24bit image published by camera1394.\n\n    class xb3ImageDeinterlacer {\n\
    \      private:\n        ros::NodeHandle leftNh,centerNh,rightNh;\n        sensor_msgs::CameraInfo\
    \ leftInfo,centerInfo,rightInfo;\n        image_transport::CameraPublisher pLeftImage,pRightImage,pCenterImage;\n\
    \n      public:\n        xb3ImageDeinterlacer(ros::NodeHandle n1, ros::NodeHandle\
    \ n2, ros::NodeHandle n3) {\n        leftNh=n1; centerNh=n2; rightNh=n3;\n   \
    \     image_transport::ImageTransport itLeft(leftNh);\n        pLeftImage = itLeft.advertiseCamera(\"\
    image\", 1000);\n        camera_info_manager::CameraInfoManager leftInfoMgr(leftNh);\n\
    \        leftInfoMgr.loadCameraInfo(\"package://xb3_driver/cal_left.yaml\");\n\
    \        leftInfo = leftInfoMgr.getCameraInfo();\n        leftInfo.header.frame_id\
    \ = \"/camera_frame\";\n\n        image_transport::ImageTransport itCenter(centerNh);\n\
    \        pCenterImage = itCenter.advertiseCamera(\"image\", 1000);\n        camera_info_manager::CameraInfoManager\
    \ centerInfoMgr(centerNh);\n        centerInfoMgr.loadCameraInfo(\"package://xb3_driver/cal_center.yaml\"\
    );\n        centerInfo = centerInfoMgr.getCameraInfo();\n        centerInfo.header.frame_id\
    \ = \"/camera_frame\";\n\n        image_transport::ImageTransport itRight(rightNh);\n\
    \        pRightImage = itRight.advertiseCamera(\"image\", 1000);\n        camera_info_manager::CameraInfoManager\
    \ rightInfoMgr(rightNh);\n        rightInfoMgr.loadCameraInfo(\"package://xb3_driver/cal_right.yaml\"\
    );\n        rightInfo = rightInfoMgr.getCameraInfo();\n        rightInfo.header.frame_id\
    \ = \"/camera_frame\";\n      }\n\n      void imageCallback(const sensor_msgs::ImagePtr&\
    \ img){\n        sensor_msgs::Image left,right,center;\n        for(unsigned int\
    \ i=0; i<img->data.size(); i+=3) {\n          right.data.push_back(img->data[i]);\n\
    \          center.data.push_back(img->data[i+1]);\n          left.data.push_back(img->data[i+2]);\n\
    \        }\n\n        leftInfo.header.stamp=left.header.stamp=img->header.stamp;\n\
    \        left.header.frame_id = \"/camera_frame\";\n        left.height=leftInfo.height;\
    \ left.width=leftInfo.width; left.step=left.width left.encoding=\"mono8\";\n \
    \       pLeftImage.publish(left,leftInfo);\n\n        centerInfo.header.stamp=center.header.stamp=img->header.stamp;\n\
    \        center.header.frame_id = \"/camera_frame\";\n        center.height=centerInfo.height;\
    \ center.width=centerInfo.width; center.step=left.width; center.encoding=\"mono8\"\
    ;\n        pCenterImage.publish(center,centerInfo);\n\n        rightInfo.header.stamp=right.header.stamp=img->header.stamp;\n\
    \        right.header.frame_id = \"/camera_frame\";\n        right.height=rightInfo.height;\
    \ right.width=rightInfo.width; right.step=left.width; right.encoding=\"mono8\"\
    ;\n        pRightImage.publish(right,rightInfo);\n      }\n    };\n\n\n    int\
    \ main(int argc, char **argv) {\n      ros::init(argc, argv, \"xb3_deinterlacer\"\
    );\n      ros::NodeHandle n;\n      ros::NodeHandle npLeft(\"xb3_left\"),npRight(\"\
    xb3_right\"),npCenter(\"xb3_center\");\n      xb3ImageDeinterlacer imgDI(npLeft,npCenter,npRight);\n\
    \      ros::Subscriber sub1 = n.subscribe(\"/camera/image_raw\", 1000, &xb3ImageDeinterlacer::imageCallback,\
    \ &imgDI);\n      ros::spin();\n      return 0;\n    }\n\ncamera1394 launch file:\n\
    \n    <launch>\n  \t<node pkg=\"nodelet\" type=\"nodelet\" name=\"camera_nodelet_manager\"\
    \ args=\"manager\" output=\"screen\"/>\n  \t<node pkg=\"nodelet\" type=\"nodelet\"\
    \ name=\"camera1394_nodelet\" args=\"load camera1394/driver camera_nodelet_manager\"\
    \ output=\"screen\">\n\t\t<param name=\"video_mode\" value=\"format7_mode3\" />\n\
    \t\t<param name=\"frame_id\" value=\"camera_frame\" />\n\t\t<param name=\"frame_rate\"\
    \ value=\"15.0\" />\n\t\t<param name=\"iso_speed\" value=\"800\" />\t\n\t\t<param\
    \ name=\"format7_color_coding\" value=\"rgb8\" />\n\t</node>  \n    </launch>"
