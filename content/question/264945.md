    \ been merged properly yet to a specific version. The main clue here was the `tf\
    \ view_frames` didn't show the `world` frame but `rqt` did. That caused a problem\

    \ below.\n\nhttps://github.com/ros/geometry/issues/136\n\nhttps://github.com/ros/geometry/pull/134\n\
    \nThe issue above - 136, mentions a workaround. To set the `use_tf_static` parameter\
    \ to `false` for the `robot_state_publisher`.\n\nIt's as simple as \n\n\n    \
    \ <arg name=\"use_tf_static\" default=\"false\"/> \n     <node name=\"robot_state_publisher\"\
    \ pkg=\"robot_state_publisher\" type=\"robot_state_publisher\" >\n           \
    \   <param name=\"use_tf_static\" value=\"$(arg use_tf_static)\"/>\n     </node>\n\
    \n\nFor now, this seems to fix the problem. I will work with this and see if there's\
    \ any issues, but for now I think this answers my original question."
