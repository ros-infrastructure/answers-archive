    \ not longer be the case.\n\n----\n\nThat's because `psutil` is missing in `OSX`'\
    \ [rosdep key](https://github.com/ros/rosdistro/blob/master/rosdep/osx-homebrew.yaml).\
    \ \n\n----\n\nHere is tentative workaround before the `rosdep` key gets updated.\
    \ Since this involves modifying protected area, **do it at your own risk**.\n\n\
    I have [a patch](https://github.com/130s/rosdistro/commit/4f844dad3602a93717169dc0ce25c1da683a0bf1)\
    \ that I haven't submitted since I haven't tested on my local Mac. If you can\
    \ try (eg. by doing the following steps) that would be great.\n\nMake a backup\
    \ and modify `/etc/ros/rosdep/sources.list.d/20-default.list` as follows:\n\n\
    \    Current: yaml https://github.com/ros/rosdistro/raw/master/rosdep/osx-homebrew.yaml\
    \ osx\n    New: yaml https://github.com/130s/rosdistro/raw/master/rosdep/osx-homebrew.yaml\
    \ osx\n\nthen run (adjust ROS distro accordingly):\n\n    $ rosdep update\n  \
    \  $ rosdep install --from-paths src --ignore-src --rosdistro hydro -y\n\nwhich\
    \ should install `psutil` via `pip`.\n\nBe sure to roll back the same file once\
    \ you've done above.\n"
