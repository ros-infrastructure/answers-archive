    The first and far most the great source to start with gtest is the [Googletest Primer](https://github.com/google/googletest/blob/master/googletest/docs/primer.md). Depending upon this there are several tutorials out there like video lectures [here](https://www.youtube.com/watch?v=nbFXI9SDfbk&t=4s) with its code [here](https://github.com/CodesBay/Google_Test_Framework) gives a head start. There are also other several examples on github like [here](https://github.com/tik0/gtest_ros_example). The guy [here](https://github.com/steup/Ros-Test-Example) have provided examples for all levels of testing unit test both in python(unittest) and c++(gtest) and than regression testing with ros in launch files. The repo also has pdf presentation with which you can understand what he tries to explain and test.
