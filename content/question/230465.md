  body_markdown: "You can run `rostopic pub` from within a launch file with:\n\n \
    \   <node pkg=\"rostopic\" type=\"rostopic\" name=\"rostopic\" args=\"pub {pub\
    \ args}\"/>\n\nwhere `{pub args}` are the arguments to `rostopic pub` to make\
    \ it publish the way you want it to.\n\nYou may also want to change `name=\"rostopic\"\
    ` to something specific to each robot, if there will be multiple copies of this\
    \ running with the same ros master. "
