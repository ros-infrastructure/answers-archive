    <rosparam param="exclude_list">
       ['(.*)Depth(.*)','(.*)theora(.*)']
    </rosparam>

     '[''(.*)Depth(.*)'',''(.*)theora(.*)'']'

rosparam get on the same list properly set from rosparam set results in no quotes at all

     [(.*)Depth(.*), (.*)theora(.*)]
