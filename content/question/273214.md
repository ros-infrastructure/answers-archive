    I assume that `VCI_OpenDevice` is in `libcontrolcan.so`. What directory is `libcontrolcan.so` located?

    CMake's `link_directories(...)` macro resolves relative paths from the source directory ([reference](https://cmake.org/cmake/help/v3.0/command/link_directories.html)). Is `<package_path>/lib/` the directory that contains `libcontrolcan.so`? If not, you'll have to provide the full path to that directory. Hardcoding a full path is a fragile solution, so I suggest you read about [How to Find Libraries in CMake](https://cmake.org/Wiki/CMake:How_To_Find_Libraries).
