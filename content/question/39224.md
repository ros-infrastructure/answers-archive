Will this satisfy the need for a feature request system using the "feature_request" tag?

People can subscribe to the feature request RSS with this link:
http://answers.ros.org/feeds/rss/?tags=feature_request

People can vote on features, comment on them, and tag them with other information too. This way, it's all integrated into the current ROS infrastructure, and doesn't clutter ros-users.
