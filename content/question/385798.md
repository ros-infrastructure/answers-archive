  body_markdown: "If you want to set up the footprint of a \"non-comercial\" robot\
    \ (DIY) you should write down the coordinates on the common costmaps yaml. \n\
    I have a rectangular sized robot with the base_link frame at the center of that\
    \ rectangle, so I have 4 coordinates written in counterclockwise direction.\n\
    So, for example, if I have something like this:\n\n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/16310873279692307.jpg)\n\
    \n\nMy footprint should be: [[-10, -20], [10, -20], [10, 20], [-10,20]].\n\nHope\
    \ this can help you!"
