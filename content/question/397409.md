  body_markdown: "The ROS devs are being tricky. \n\nWhen you call the subscribe()\
    \ method you also specify the ROS topic name. At run-time, the subscribe() method\
    \ looks up the message type for that topic and then checks to see if the argument\
    \ type of the callback function you provided is a match. If it doesn't match,\
    \ the function won't be called when a message arrives.\n\nThe roscpp code is smart\
    \ enough to check for various forms of the callback argument: const, non-const,\
    \ non-ptr, regular ptr and ::ConstPtr. For big messages, some of these are much\
    \ more efficient than others.\n"
