  body_markdown: "Here is a Python node I wrote that subscribes to quaternions, converts\
    \ quaternions to Euler angles, and then publish the Euler angles. The Euler angles\
    \ are in a custom message, `my_pkg/msg/Eulers.msg`:\n\n    Header header\n   \
    \ float64 roll\n    float64 pitch\n    float64 yaw\n\nThen create the file `my_pkg/quat_to_euler.py`:\n\
    \n    #!/usr/bin/python\n    # -*- coding: utf-8 -*-\n    \n    # Start up ROS\
    \ pieces.\n    PKG = 'my_pkg'\n    import roslib; roslib.load_manifest(PKG)\n\
    \    import rospy\n    import tf\n    \n    # ROS messages.\n    from nav_msgs.msg\
    \ import Odometry\n    from sensor_msgs.msg import Imu\n    from my_pkg.msg import\
    \ Eulers\n    \n    class QuatToEuler():\n        def __init__(self):\n      \
    \      self.got_new_msg = False\n            self.euler_msg = Eulers()\n    \n\
    \            # Create subscribers and publishers.\n            sub_imu   = rospy.Subscriber(\"\
    imu\", Imu, self.imu_callback)\n            sub_odom  = rospy.Subscriber(\"odom\"\
    , Odometry, self.odom_callback)\n            pub_euler = rospy.Publisher(\"euler\"\
    , Eulers)\n    \n            # Main while loop.\n            while not rospy.is_shutdown():\n\
    \                # Publish new data if we got a new message.\n               \
    \ if self.got_new_msg:\n                    pub_euler.publish(self.euler_msg)\n\
    \                    self.got_new_msg = False\n    \n        # Odometry callback\
    \ function.\n        def odom_callback(self, msg):\n            # Convert quaternions\
    \ to Euler angles.\n            (r, p, y) = tf.transformations.euler_from_quaternion([msg.pose.pose.orientation.x,\
    \ msg.pose.pose.orientation.y, msg.pose.pose.orientation.z, msg.pose.pose.orientation.w])\n\
    \            self.fill_euler_msg(msg, r, p, y)\n    \n        # IMU callback function.\n\
    \        def imu_callback(self, msg):\n            # Convert quaternions to Euler\
    \ angles.\n            (r, p, y) = tf.transformations.euler_from_quaternion([msg.orientation.x,\
    \ msg.orientation.y, msg.orientation.z, msg.orientation.w])\n            self.fill_euler_msg(msg,\
    \ r, p, y)\n    \n        # Fill in Euler angle message.\n        def fill_euler_msg(self,\
    \ msg, r, p, y):\n            self.got_new_msg = True\n            self.euler_msg.header.stamp\
    \ = msg.header.stamp\n            self.euler_msg.roll  = r\n            self.euler_msg.pitch\
    \ = p\n            self.euler_msg.yaw   = y\n    \n    # Main function.    \n\
    \    if __name__ == '__main__':\n        # Initialize the node and name it.\n\
    \        rospy.init_node('quat_to_euler')\n        # Go to class functions that\
    \ do all the heavy lifting. Do error checking.\n        try:\n            quat_to_euler\
    \ = QuatToEuler()\n        except rospy.ROSInterruptException: pass\n\nIn my launch\
    \ file I start it with:\n\n    <node pkg=\"my_pkg\" type=\"quat_to_euler.py\"\
    \ name=\"imu_euler_angles\">\n        <remap from=\"imu\"   to=\"microstrain/data\"\
    />\n        <remap from=\"euler\" to=\"microstrain/euler\"/>\n    </node>\n\n\
    \    <node pkg=\"my_pkg\" type=\"quat_to_euler.py\" name=\"kf_euler_angles\">\n\
    \        <remap from=\"odom\"  to=\"kf/odom\"/>\n        <remap from=\"euler\"\
    \ to=\"kf/euler\"/>\n    </node>\n\nThen you can plot your IMU roll vs. your KF\
    \ roll (for example):\n\n    rxplot /microstrain/euler/roll:/kf/euler/roll"

  body_markdown: "Hey,\nhere is a c++ solution to your problem :) just in case you\
    \ still have use for it! Needed the transformation from quaternion to rpy-angles\
    \ too so here is what I put together. Used the code fragment from [here](http://answers.ros.org/question/36977/invalid-arguments-convert-from-quaternion-to-euler/)\
    \ for the actual transformation.\n\n    /****************************************************************************\n\
    \    \n    Conversion from a quaternion to roll, pitch and yaw.\n    \n    Nodes:\n\
    \    subscribed /rotation_quaternion (message of type geometry_msgs::Quaternion)\n\
    \    published /rpy_angles (message oftype geometry_msgs::Vector3.h)\n    \n \
    \   ****************************************************************************/\n\
    \    \n    #include \"ros/ros.h\"\n    #include \"geometry_msgs/Vector3.h\"\n\
    \    #include \"geometry_msgs/Quaternion.h\"\n    #include \"tf/transform_datatypes.h\"\
    \n    #include \"LinearMath/btMatrix3x3.h\"\n    \n    // Here I use global publisher\
    \ and subscriber, since I want to access the\n    // publisher in the function\
    \ MsgCallback:\n    ros::Publisher rpy_publisher;\n    ros::Subscriber quat_subscriber;\n\
    \    \n    // Function for conversion of quaternion to roll pitch and yaw. The\
    \ angles\n    // are published here too.\n    void MsgCallback(const geometry_msgs::Quaternion\
    \ msg)\n    {\n    \t// the incoming geometry_msgs::Quaternion is transformed\
    \ to a tf::Quaterion\n    \ttf::Quaternion quat;\n    \ttf::quaternionMsgToTF(msg,\
    \ quat);\n    \n    \t// the tf::Quaternion has a method to acess roll pitch and\
    \ yaw\n    \tdouble roll, pitch, yaw;\n    \ttf::Matrix3x3(quat).getRPY(roll,\
    \ pitch, yaw);\n    \n    \t// the found angles are written in a geometry_msgs::Vector3\n\
    \    \tgeometry_msgs::Vector3 rpy;\n    \trpy.x = roll;\n    \trpy.y = pitch;\n\
    \    \trpy.z = yaw;\n    \n    \t// this Vector is then published:\n    \trpy_publisher.publish(rpy);\n\
    \    \tROS_INFO(\"published rpy angles: roll=%f pitch=%f yaw=%f\", rpy.x, rpy.y,\
    \ rpy.z);\n    }\n    \n    int main(int argc, char **argv)\n    {\n    \tros::init(argc,\
    \ argv, \"talker\");\n    \tros::NodeHandle n;\n    \trpy_publisher = n.advertise<geometry_msgs::Vector3>(\"\
    rpy_angles\", 1000);\n    \tquat_subscriber = n.subscribe(\"rotation_quaternion\"\
    , 1000, MsgCallback);\n    \n    \t// check for incoming quaternions untill ctrl+c\
    \ is pressed\n    \tROS_INFO(\"waiting for quaternion\");\n    \tros::spin();\n\
    \    \treturn 0;\n    }\n\n"
