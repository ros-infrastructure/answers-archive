  body_markdown: "Looks like the answer is to edit the vision_opencv/rosdep.yaml file\
    \ to add an entry for precise, thus getting it to use the package libopencv-dev\
    \ that you can install via Synaptic, etc.  For example, here's part of my vision_opencv/rosdep.yaml:\n\
    \n    opencv2.3:\n      ubuntu:\n        lucid:\n          apt:\n            packages:\
    \ [libopencv2.3-dev=2.3.1+svn6514+branch23-12~lucid]\n        maverick:\n    \
    \      apt:\n            packages: [libopencv2.3-dev=2.3.1+svn6514+branch23-12~maverick]\n\
    \        natty:\n          apt:\n            packages: [libopencv2.3-dev=2.3.1+svn6514+branch23-12~natty]\n\
    \        oneiric:\n          apt:\n            packages: [libopencv2.3-dev=2.3.1+svn6514+branch23-12~oneiric]\n\
    \        precise: \n          apt:\n            packages: [libopencv-dev]\n\n"
