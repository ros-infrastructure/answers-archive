  body_markdown: "Actually, you basically copied the answer in here as well :-)\n\n\
    > **ROS**: functionality available via ROS\n> topics and services \n> \n> **C++**:\n\
    > functionality available in C++\n> libraries\n> \n> **Python**: functionality\n\
    > available in Python modules/packages\n\nROS has client libraries, `roscpp` and\
    \ `rospy` that allow you to use ROS functionalities in C++ and Python code, respectively.\n\
    \nSo, you have a [C++ API](http://wiki.ros.org/ROS/Tutorials/WritingPublisherSubscriber(c%2B%2B)),\
    \ to e.g. use Publishers and Subscribers, as well as a [Python API](http://wiki.ros.org/ROS/Tutorials/WritingPublisherSubscriber%28python%29).\
    \ Those two are obviously different.\nFrom the outside, a topic looks, however,\
    \ the same, wether it comes from a python or a C++ node. You can manipulate this\
    \ e.g. using the `topic_tools` package, which are just ROS nodes written in either\
    \ C++ or python.\n\nHowever, this is only a very rough overview, don't get stuck\
    \ too much on this list."
