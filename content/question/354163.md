  body_markdown: "Your include command looks fine, here is an example of a launch\
    \ file that works for me:<br>\nnode_master.launch:\n\n    <launch>\n        <rosparam\
    \ command=\"load\" file=\"$(find node_master)/config/node_master.yaml\" />\n \
    \       <include file=\"$(find node_1)/launch/full.launch\"/>\n        <include\
    \ file=\"$(find node_2)/launch/full.launch\"/>\n        <include file=\"$(find\
    \ node_3)/launch/full.launch\"/>\n    </launch>\n\nnode_1/launch/full.launch:\n\
    \n       <launch>\n            <node name=\"node_1_node\" pkg=\"node_1\" type=\"\
    node_1_node\" output=\"screen\"/>\n            <rosparam command=\"load\" file=\"\
    $(find node_1)/config/param.yaml\" />\n        </launch>  \n\nBut I think you\
    \ are using this wrong:<br>\nAfter including the launch file of *tugInterface*\
    \  you are starting the node inside the same launchfile.\n<br> That node should\
    \ be instead started in the lauchfile you include, otherwise it's not needed to\
    \ include that launchfile at all. \n<br>You should be able to start that node\
    \ without including it's launchfile."
