  body_markdown: "Assume robot IP is = 192.168.1.10 and remote PC IP is 192.168.1.20\
    \  \nOn the robot (the ROS master) run the following commands and then run roscore\
    \ and any ros node\n\n    source /opt/ros/melodic/setup.bash  \n    export ROS_MASTER_URI=http://192.168.1.10:11311\
    \  \n    export ROS_IP=192.168.1.10\n\n\nOn the remote PC, apply the following\
    \ settings before running your application:\n\n    source /opt/ros/melodic/setup.bash\
    \  \n    export ROS_MASTER_URI=http://192.168.1.10:11311  \n    export ROS_IP=192.168.1.20\n\
    \nThen try to access robot topics on your remote PC.\n\n**Also**  \ncheck your\
    \ firewalls on both. You can disable your firewall for a quick test:\n\n    sudo\
    \ ufw disable\n\n "
