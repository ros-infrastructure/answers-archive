    It sounds like you were following the [turtlesim and rqt tutorial](https://index.ros.org/doc/ros2/Tutorials/Turtlesim/Introducing-Turtlesim/). This tutorial expects you have sourced your ROS 2 installation, as [described in the first tutorial](https://index.ros.org/doc/ros2/Tutorials/Configuring-ROS2-Environment/#source-the-setup-files). For example for Foxy on Ubuntu:

        source /opt/ros/foxy/setup.bash

    This command should be run in every terminal that you open when you expect to run ROS commands.

    We could probably add a reminder to run this command in the new terminal before running `rqt`.
