  body_markdown: "Okay first you have to fix how you publish that encoder data...\n\
    \nThe ROS standard is that your robot driver code should publish the encoder data\
    \ to the /joint_states topic.  <BR> \nAt a minimum you need to have the position\
    \ data in radians. <BR> Look at some other robot (simulation) models to see how\
    \ they work. <BR>\nThis joint states topic is a vector joints, with names matching\
    \ the joints in your URDF file. <BR>\nPublishing this topic correctly is the first\
    \ thing you should test with a real robot.\n\nIt sounds like your data is currently\
    \ in a different format/topic. <BR> If you can't, or don't want to modify the\
    \ driver code to publish the joint states correctly, you could create a node that\
    \ reads the drrobot_motor_* topics and re-publishes that data onto /joint_states.\
    \ <BR>\nYou can look in the code for other robots, or google \"ros joint state\
    \ publisher\" to find the code you need. \n\nNext, you need to get Rviz loading\
    \ and display your encoder data. <BR> If you are publishing a joint states topic\
    \ with joint names matching your URDF, then Rviz will display the current state\
    \ of your real robot!\n\nThen, you can look at the Warehouse... <BR>\nDownload\
    \ the motoman stack from ROS industrial. The SIA20D_Mesh_arm_navigation directories\
    \ contain 2 launch files which show you the parameters that need to be changed\
    \ for simulation VS. real robot. <BR>\nOr, Google this forum for your same question,\
    \ because it's been posted on here too!\n\n*###  Lastly, there is a useful node\
    \ called The Joint State Publisher, which is a GUI for publishing fake joint angles.\
    \ You can use this to read in your robot's URDF, and publish a fake /joint_states\
    \ topic so you can test the Warehouse with \"real robot data\" before you fix\
    \ your driver. <BR>\nUse the top 4 lines from this launch file: <BR>\nhttp://kaist-ros-pkg.googlecode.com/svn/trunk/arm_kinematics_tools/launch/fake_jointstate_pub_kinematics_solver.launch"
