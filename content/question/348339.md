    \ by \"pid\"`. It looks like the pid package is not installed in your environment.\
    \ You can automatically download al such dependencies with the `rosdep` command\
    \ as described on the [rosdep wiki](http://wiki.ros.org/rosdep). To fix your problem,\
    \ go to the root folder of your workspace (one below `src`) and enter \n\n`$ rosdep\
    \ install --from-paths src --ignore-src -r -y`.\n\nAlternatively you could also\
    \ manually install the package with\n\n`$ sudo apt install ros-melodic-pid`."
