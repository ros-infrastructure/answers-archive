  body_markdown: "Hi @yogev\n\nIn order to achieve what you want you will need to\
    \ lauch each individual robot description in different namespaces. [Here](http://wiki.ros.org/action/fullsearch/Names)\
    \ is a quick introduction for ROS names.\n\nIt would be something like:\n\n  \
    \  <?xml version=\"1.0\"?>\n    <launch>\n    <group ns=\"robot1\">\n    \t<param\
    \ name=\"robot_description\" command=\"$(find xacro)/xacro.py '$(find manipulator_h_description)/urdf/manipulator_h1.xacro'\"\
    \ />\n    \t<node pkg=\"robot_state_publisher\" type=\"state_publisher\" name=\"\
    rst_robot1\" />\n    \t<node pkg=\"joint_state_publisher\" type=\"joint_state_publisher\"\
    \ name=\"jsp_robot1\">\n    \t\t<param name=\"use_gui\" value=\"TRUE\"/>\n   \
    \ \t</node>\n    </group>\n    \n    <group ns=\"robot2\">\n    \t<param name=\"\
    robot_description2\" command=\"$(find xacro)/xacro.py '$(find manipulator_h_description)/urdf/manipulator_h2_rviz.xacro'\"\
    \ />\n    \t<node pkg=\"robot_state_publisher\" type=\"state_publisher\" name=\"\
    rst_robot2\" />\n    \t<node pkg=\"joint_state_publisher\" type=\"joint_state_publisher\"\
    \ name=\"jsp_robot2\">\n    \t\t<param name=\"use_gui\" value=\"TRUE\"/>\n   \
    \ \t</node>\n    </group>\n    </launch>\n\nHope this can help you.\n\nRegards."
