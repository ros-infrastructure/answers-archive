    As you see, the [velodyne_driver](http://ros.org/wiki/velodyne_driver) publishes `/velodyne_packets`, a device-dependent data stream that `rviz` does not understand.

    As @dornhege said, you need to run one of the [velodyne_pointcloud](http://ros.org/wiki/velodyne_pointcloud) nodes or nodelets. They will convert the raw Velodyne packets into `sensor_msgs/PointCloud2`, which `rviz` *can* display. That wiki page gives [some launch file examples](http://ros.org/wiki/velodyne_pointcloud#Launch_File_Examples) you may find helpful.

    UPDATE: version 0.9.1 with the `32e_points.launch` file has just been released. You can either check out the new version and build it from source, or wait for the Debian packages to be updated (probably a few days).
