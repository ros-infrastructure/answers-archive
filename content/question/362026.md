  body_markdown: "Hello.\n\nNext time try to do a search before ask, please!\n\nhere\
    \ you have the package http://wiki.ros.org/octomap_server.\n\nSo\n\n    sudo apt-get\
    \ install ros-melodic-octomap ros-melodic-octomap-server ros-melodic-octomap-mapping\
    \ ros-melodic-octomap-ros ros-melodic-octomap-msgs\n\nthen just run:\n\n    roslaunch\
    \ octomap_server octomap_mapping.launch\n\n\nbtw your pointcloud has to be named\
    \ cloud_in, or do a remap to change it's name to /narrow_stereo/points_filtered2.\
    \ so, in you launch file you should add:\n\n    <remap from=\"cloud_name\" to=\"\
    /narrow_stereo/points_filtered2\" />\n\nAnd you have to define the global frame\
    \ as a parameter (check the wiki) by default is /map but maybe is not your case.\
    \ \nYou have to publish also a transform between this frame and the sensor data\
    \ frame if you don't know how, here you have tutorial (http://wiki.ros.org/tf/Tutorials).\n\
    \nI think that's all! Hope it works"
