    > Is it possible to make Gazebo not add "incomplete" models and treat them as invalid?

    No, that's not currently possible. Gazebo's approach has always been to load as much as possible, and print warnings and errors to help the user debug what couldn't be loaded. We don't have a programmatic way of catching these errors though.

    Related, libSDFormat got much more strict about model loading from version 9 (used by Gazebo 11), and initially it would fail loading the entire world if there was a problem with something as small as a visual. We relaxed that on [this PR](https://osrf-migration.github.io/sdformat-gh-pages/#!/osrf/sdformat/pull-requests/655/page/1) though because that was too strict and would break too many existing simulations. So even on Gazebo 11, all you get are console messages.
