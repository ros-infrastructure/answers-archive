    `osrf_msgs` is a ros package distributed in the osrf-common debian on packages.osrfoundation.org. If you installed drcsim using apt-get (according to the [installation instructions](http://gazebosim.org/wiki/InstallDRC)), then the package should be on your system. Use the following command to search for it:
    <pre>
    $ dpkg -l | grep osrf
