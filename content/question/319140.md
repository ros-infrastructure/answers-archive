  body_markdown: |-
    - [`ros::Subscriber`](http://docs.ros.org/melodic/api/roscpp/html/classros_1_1Subscriber.html) is a generic subscriber class that can subscribe to any topic.
    - [`image_transport::Subscriber`](http://docs.ros.org/api/image_transport/html/classimage__transport_1_1Subscriber.html) is a specialized subscriber that can only subscribe to image topics, it is provided for ease of use with the `image_transport` package.

    You use them for different purposes.

    - Take a look at the tutorials if you want to learn how to use the `image_transport::Subscriber` http://wiki.ros.org/image_transport
