  body_markdown: "Destroying the node won't exit `rclpy.spin()` loop. One way to implement\
    \ this is by checking your node's self.running status in main loop and using `rclpy.spin_once()`\
    \ -function. Here is a fully working example:\n\n    #!/usr/bin/env python3\n\
    \    import rclpy\n    from rclpy.node import Node\n\n\n    class MyNode(Node):\n\
    \        def __init__(self, name):\n            super().__init__(name)\n     \
    \       self.running = True\n            self.timer = self.create_timer(0.1, self.action)\n\
    \n        def action(self):\n            print(\"Callback\")\n            self.running\
    \ = False\n            self.destroy_timer(self.timer)\n\n\n    def main(args=None):\n\
    \        rclpy.init(args=args)\n\n        my_node = MyNode(\"my_node\")\n    \
    \    while my_node.running and rclpy.ok():\n            try:\n               \
    \ rclpy.spin_once(my_node)\n            except KeyboardInterrupt:\n          \
    \      break\n            \n        my_node.destroy_node()\n        print(\"Shutting\
    \ down rclpy\")\n        rclpy.shutdown()\n\n\n    if __name__ == '__main__':\n\
    \        main()\n    \n"
