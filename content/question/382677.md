    \ --exec-prefix=/usr/local --libdir=/usr/local/lib --includedir=/usr/local/lib\n\
    and then `sudo ./b2`\n\n3. Reinstalled ROS : `sudo apt install ros-noetic-desktop-full`\
    \ as it was removed by step 1\n4. Reinstalled Ubuntu Desktop `sudo apt-get install\
    \ ubuntu-desktop` as it was removed by step 1 \n5. Changed the CPP standard to\
    \ `C++14` : `catkin config -DCMAKE_CXX_FLAGS=-std=c++14` (not sure if necessary)\n\
    \nAnd after reboot everything worked well. I'm getting many warnings, but no errors!"
