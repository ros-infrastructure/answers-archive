  body_markdown: "The `schunk_lwa4d` package reflects the (special?) configuration\
    \ that was used with Care-O-bot 4.\nAs the init service error implies node 3 could\
    \ not be reached.\n\nThis might have several reasons:\n\n* There is no node 3.\
    \ Module IDs can be set freely. The Care-O-bot convention for LWA4d is 3-9.\n\
    * Your bitrate is not correct. (Not sure if 500k or 1M is the default)\n* Your\
    \ modules are not in CANopen 402 mode. \n\nYou can check/set these things with\
    \ the software tools provided by Schunk.\n\nThe node IDs can also read with candump:\n\
    Just start `candump can0` before powering on. While boot-up the devices should\
    \ send messages with IDs `0x700` + node ID (hex!)"
