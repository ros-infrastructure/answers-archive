    You can set the intrinsic calibration parameters of your camera in the camera configuration xml belonging to your urdf model (see [here](http://answers.ros.org/question/11965/using-camera-sensor-in-gazebo) for an example). The plugin also publishes a camera info topic, that should contain the intrinsic parameters.

    The extrinsic parameters are generally known, because you select where the camera is mounted.

    Intrinsic calibration is not really required in gazebo since we do not inject any distortion to the image.  You can see how the projection matrix is setup in [`GazeboRosCamera::PublishCameraInfo()`](https://code.ros.org/svn/ros-pkg/stacks/simulator_gazebo/branches/simulator_gazebo-1.4/gazebo_plugins/src/gazebo_ros_camera.cpp).

    Extrinsic calibration is also not necessary as you should be able to access the exact pose of the camera sensor in simulation through either the ROS API or using tf.


    But if you really wanted to run through the calibration procedure, you'll have to create a checkerboard in simulation and run through [camera calibration](http://www.ros.org/wiki/camera_calibration), or you can see how the [pr2 cameras are calibrated here](http://www.ros.org/wiki/pr2_calibration/Tutorials/Calibrating%20the%20PR2%27s%20Cameras).

    Please let me know if any of the above is unclear.
