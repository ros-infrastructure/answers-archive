    \ to rdf-schema.xml, but to the fact that there simply are no drawers that your\
    \ query could return since no map has been loaded.\n\nThis problem appears since\
    \ you are using the wrong instructions: As the box at the head of this wiki page\
    \ says, the instructions on [that page](http://knowrob.org/doc/knowrob_basics)\
    \ are only valid for the catkinized version of KnowRob. Since you are using the\
    \ rosbuild-based version, you will need to follow the given link to the [previous\
    \ version](http://knowrob.org/doc/knowrob_basics?rev=1407307101).\n\nThat page\
    \ will tell you that you have to start with the mod_vis instead of the knowrob_common\
    \ package, which automatically loads an environment map, so that your query will\
    \ have results.\n\nEDIT: \nI'm not sure what the problem is. Some people seem\
