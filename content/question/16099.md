    You can add an IMU to any link on your robot's SDF like this for example:

        <link ...>
          ...
          <sensor name="imu_sensor" type="imu">
            <pose>0 0 0 0 0 0</pose>
            <always_on>1</always_on>
            <update_rate>1000.0</update_rate>
          </sensor>
        </link>

    Then you can check its output with:

        gz topic -e /gazebo/default/<modelname>/<linkname>/imu_sensor/imu
