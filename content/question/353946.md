  body_markdown: "The best would be to create parameters in your python script. Examples\
    \ [here](http://wiki.ros.org/rospy/Overview/Parameter%20Server)  (Make them private\
    \ with  `~`)\n \n\nFor example in my node I have : \n\n    self.target_frame =\
    \ rospy.get_param(\"~target_frame\", \"map\")\n\nAnd  I can start it like this\
    \ in in my launchfile :\n\n    <node pkg=\"robot_platform\" type=\"test.py\" name=\"\
    test\" output=\"screen\">\n        <param name=\"target_frame\" value=\"test\"\
    \ />\n    </node>\n\n\nThis method is very good because it allows you to use the\
    \ parameter server to set your parameters also and load them from a yaml file\
    \ for example.\n\nYou can read more about the parameter server  [here](http://wiki.ros.org/Parameter%20Server)"

          user_current_place = rospy.get_param("~user_current_place")
