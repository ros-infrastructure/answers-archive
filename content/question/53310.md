  body_markdown: |-
    Since you followed the tutorial on IDEs you should have an autogenerated Eclipse project. So in this case you have to change the setting related to a build process in relevant `CMakeLists.txt` file, not in Eclipse project settings.

    To link additional libraries add `target_link_libraries` directive to your `CMakeLists.txt`:
    <code><pre>rosbuild_add_executable(my_node src/my_node.cpp)
    target_link_libraries(my_node GL GLU glut opencv_core opencv_gpu)</pre></code>

    In general, though, you may want to use `find_package` routine -- many of the libraries has relevant "find" modules for CMake. In case there is no such module you can always fall back to `FindPkgConfig` package which is a wrapper for system `pkg-config` utility. Please see [here](http://www.cmake.org/Wiki/CMake:How_To_Find_Libraries) for more details.
