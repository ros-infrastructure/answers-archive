  body_markdown: "If the package you want to build is a rosbuild package (it has a\
    \ `manifest.xml` and not a `package.xml`) then you need to put one of its containing\
    \ folders in the `ROS_PACKAGE_PATH`. Imagine you have something like this:\n\n\
    \    % tree /tmp/my_workspace\n    /tmp/my_workspace\n    \u2514\u2500\u2500 my_package\n\
    \        \u2514\u2500\u2500 manifest.xml\n        \u2514\u2500\u2500 ...\n   \
    \ \n    1 directory, 1 file\n\nAnd you want to build `my_package`, then you should\
    \ put at least the `my_workspace` folder on the `ROS_PACKAGE_PATH`:\n\n    $ export\
    \ ROS_PACKAGE_PATH=/tmp/my_workspace:$ROS_PACKAGE_PATH\n\nThat will allow `rosmake`\
    \ to find your package and try to build it.\n\nAlso you should do that export\
    \ line after sourcing any other `setup.bash` files, e.g. `source /opt/ros/hydro/setup.bash`."
