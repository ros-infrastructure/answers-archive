  body_markdown: "Okay I found the answer by myself.\n\nThere is a ROS SERVICE called\
    \ /gazebo/spawn_sdf_model. \nWe need some parameters for this service and I wrote\
    \ a MATLAB .m test file to spawn and remove all models I need (for test purposes).\n\
    \nIf you need to write a Python Script for that, check out this answer:\nhttps://answers.ros.org/question/337065/what-is-the-correct-way-to-spawn-a-model-to-gazebo-using-a-python-script/\n\
    \nHeres my MATLAB script:\n\n    % initlize ROS in MATLAB\n    rosinit;\n    disp(\"\
    Initilizing ROS, wait please ...\")\n    pause(2)\n    disp(\"Connected to ROS\
    \ Master\\n\\n\")\n    \n    % List with all file name numbers\n    model_num_list\
    \ = [\"001\", \"002\",\"003\",\"004\"];\n    % iterate through every track\n \
    \   for n_track = 1:length(model_num_list)\n        % model name\n        me_track\
    \ = \"MA_\" + string(model_num_list(n_track));\n        % path to model editor\
    \ model sdf\n        sdf_path = \"/home/amo/model_editor_models/\" + me_track\
    \ + \"/model.sdf\";\n        % read sdf as textfile\n        sdf_table = table2array(readtable(sdf_path,\
    \ 'FileType', \"text\"));\n        % we need to send the sdf in string format\
    \ --> empty string\n        sdf_string = \"\";\n        % iterate through every\
    \ line of the sdf\n        for n_sdf = 1:length(sdf_table)\n            % attach\
    \ line to string\n            sdf_string = strcat(sdf_string, sdf_table{n_sdf},\
    \ \"\\n\");\n        end\n        % initiate spawn service\n        track_spawn_client\
    \ = rossvcclient('/gazebo/spawn_sdf_model');\n        track_spawn_service = rosmessage(track_spawn_client);\n\
    \        % Parameters of service\n        track_spawn_service.ModelName = me_track;\
    \ % model name\n        track_spawn_service.ModelXml = sdf_string; % created string\
    \ of sdf\n        track_spawn_service.RobotNamespace = \"/\" + me_track; % namespace\
    \ of robot\n        track_spawn_service.ReferenceFrame = 'world'; % referenceframe\n\
    \        response = call(track_spawn_client,track_spawn_service); % call service\n\
    \        \n        \n        input(\"ENTER to remove Track\")\n        \n    \
    \    %%% REMOVE SPAWNED TRACK %%%\n        % initiate spawn service\n        track_remove_client\
    \ = rossvcclient('/gazebo/delete_model');\n        track_remove_service = rosmessage(track_remove_client);\n\
    \        % Parameters of service\n        track_remove_service.ModelName = me_track;\
    \ % model name\n        call(track_remove_client, track_remove_service); % call\
    \ service\n    end\n\n"
