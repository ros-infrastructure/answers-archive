    `rostopic echo`ing a PointCloud2 will not produce useful output in the data field. What you're seeing is a serialized format which is intended to be deserialized before use. If you want to save point cloud data for later you should use either [rosbag record](http://www.ros.org/wiki/rosbag/Commandline#record), which you can later play back as ROS messages, or [cloud_to_pcd](http://www.ros.org/wiki/pcl_ros#pointcloud_to_pcd) which saves pcd files.
