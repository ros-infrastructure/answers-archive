  body_markdown: "rosdep install attempts to install system dependencies via apt.\n\
    \nIf that fails on Debian, you need to install system dependencies another way.\
    \ \n\nIf rospkg is the only dependency rosdep misses for diagnostic_updater, and\
    \ you have installed it via pip, then you should be good to go (perform the next\
    \ build step).\n\nSo rosdep is just blind for your pip installation of rospkg.\n\
    \nRemember to get the latest of rospkg from pip, though."

I'm trying to compile diagnostic_updater on a ARM device (running Linaro 12.08) using groovy. The command I'm using to compile is 

    rosdep install diagnostic_updater

The error I'm encountering is 

    ERROR: the following rosdeps failed to install
    apt: command [sudo apt-get install python-rospkg] failed

The reason the command is failing is because python-rospkg doesn't exist as a debian package for ROS. I had acquired rospkg through pip.

Is there are work around I can use to build the package?
