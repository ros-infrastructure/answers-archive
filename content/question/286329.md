  body_markdown: "After understanding the implementation of screw joint in pr2's torso\
    \ part. It is clear that URDF don't support screw joint, so to add the functionality\
    \ of the same we have to use gazebo tags since SDF (For those who don't know:Under\
    \ the hood gazebo converts urdf to sdf before spawning) totally supports it. \n\
    \nYou also need to specify prismatic and continuous joints. Refer to pr2.urdf\
    \ for full understanding.\nFollowing is the snippet from the mentioned above.\n\
    \ \n\n    <gazebo>\n    <joint name=\"torso_lift_screw_torso_lift_joint\" type=\"\
    screw\">\n      <parent>torso_lift_link</parent>\n      <child>torso_lift_motor_screw_link</child>\n\
    \      <axis>\n        <xyz>0 0 1</xyz>\n      </axis>\n      <thread_pitch>3141.6</thread_pitch>\n\
    \      </joint>\n     </gazebo>\n     <transmission name=\"torso_lift_trans\"\
    \ type=\"pr2_mechanism_model/SimpleTransmission\">\n       <actuator name=\"torso_lift_motor\"\
    />\n    <joint name=\"torso_lift_joint\"/>\n    <mechanicalReduction>-47641.53</mechanicalReduction>\n\
    \    <simulated_actuated_joint name=\"torso_lift_motor_screw_joint\" simulated_reduction=\"\
    3141.6\"/>\n        </transmission>"
