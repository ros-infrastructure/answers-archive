title: Does `lockstep` argument only affect sensor plugin?
upvote_count: 0

 Gazebo [offers an option](http://gazebosim.org/tutorials?tut=lockstep_physics_sensors&cat=sensors), `--lockstep` to update sensor readings using  the exactly `upate_rate` defined by sensor plugin description.  Does other kinds of plugins, such as world or model plugin, can be affected by this option?  

I think  it can. Because these plugins also define the`OnUpdate` method, which in my opinion it is affected by the `upate_rate` parameter.
