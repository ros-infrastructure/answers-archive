  body_markdown: "You error comes from your second launch file :\n\n    <node pkg=\"\
    tf\" type=\"static_transform_publisher\" name=\"link1_broadcaster\" args=\"0 0\
    \ 0 0 0 0 0 base_link laser_1 100\" />\n    <node pkg=\"tf\" type=\"static_transform_publisher\"\
    \ name=\"link2_broadcaster\" args=\"0 0 0 0 0 0 0 hokuyo_2 laser_2 100\" />\n\n\
    Here you specify as arguments `7` zeros meaning you define the position and orientation\
    \ using 3 postion coordiantes and a quaternion : `{x; y; z; q_x; q_y; q_z; q_w}`.\
    \ The problem is that a default quaternion is not 4 zeros but the field `q_w`\
    \ has to be set to `1`. ([Here](https://quaternions.online/) is an online visualizer\
    \ for quaternions that I find really useful).\n\nSo you have two options : \n\n\
    \ - Propperly initialize your two quaternions :\n\n        <node pkg=\"tf\" type=\"\
    static_transform_publisher\" name=\"link1_broadcaster\" args=\"0 0 0 0 0 0 1 base_link\
    \ laser_1 100\" />\n        <node pkg=\"tf\" type=\"static_transform_publisher\"\
    \ name=\"link2_broadcaster\" args=\"0 0 0 0 0 0 1 hokuyo_2 laser_2 100\" />\n\n\
    \ - Change the argument and use roll, pitch and yaw instead of a quaternion arguments\
    \ are then `{x; y; z; roll; pitch; yaw}` :\n\n        <node pkg=\"tf\" type=\"\
    static_transform_publisher\" name=\"link1_broadcaster\" args=\"0 0 0 0 0 0 base_link\
    \ laser_1 100\" />\n        <node pkg=\"tf\" type=\"static_transform_publisher\"\
    \ name=\"link2_broadcaster\" args=\"0 0 0 0 0 0 hokuyo_2 laser_2 100\" />\n\n"
