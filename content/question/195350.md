  body_markdown: "In C++ you have:\n\n    moveit_msgs::PlanningOptions options;\n\
    \    options.replan = true;\n    options.replan_attempts = y;\n    \n    moveit_msgs::PickupGoal\
    \ goal;\n    goal.planning_options = options;\n\nOr in you case:\n\n    group_->allowReplanning(true);\n\
    \nIn python you have:\n\n    group = moveit_commander.MoveGroupCommander(blablabla)\n\
    \    group.allow_replanning(True)\n\nThere is no attribute in the Python API for\
    \ the number of attempts but if you need to change it you can implement it yourself\
    \ in move_group.py"
