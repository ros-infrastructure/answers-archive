  body_markdown: "I had the same problem. It ended up being Raspbian Stretch is 32\
    \ bit architecture as indicated by stretch/main armhf. The repositories that have\
    \ ros-lunar-desktop-full are in 64 bit which is not armhf. You are able to install\
    \ the bare bones version of ROS onto Stretch which allows you to communicate to\
    \ and from the Pi.\n\nTo be able to get 64 bit on the Pi I installed a new image\
    \ from the following: https://github.com/bamarni/pi64/blob/master/README.md then\
    \ I proceeded as normal to get it to install ros-lunar-desktop. I hope this helps. "
