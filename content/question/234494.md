    \                        \n    [url \"git@github.com:\"]                     \
    \                                                                   \n      insteadOf\
    \ = https://github.com/     \n\n                                             \
    \                           \nThen just make sure that you've added the your ssh\
    \ key from the computer you are on to your github profile."

    The solution I'm personally using is to [create an OAuth token](https://help.github.com/articles/git-automation-with-oauth-tokens/) to use instead of a password, and then use a password manager to store it. The advantage over using `~/.config/bloom` is that it doesn't work only for bloom, but for all git commands (just like @jbinney 's solution). Of course if you're not already using pass anyway, @jbinney 's solution is much easier to set up.

I tried following these instructions: 
http://wiki.ros.org/bloom/Tutorials/GithubManualAuthorization

and have a `~/.config/bloom` file with my private github token. However, bloom still fails to authenticate:

    ==> git push --dry-run

    Password for 'https://felixduvallet@github.com': 
    remote: Invalid username or password.
    fatal: Authentication failed for 'https://github.com/felixduvallet/grasp-synergy-release.git/'
    Cannot push to remote release repository.

Is there a way to diagnose the bloom+github authentication by itself?
