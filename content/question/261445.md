    If you want to import data from ROS into MATLAB, you are probably best off recording [Rosbag](http://wiki.ros.org/rosbag). Check out the tutorials to figure out how to use it. When you have recorded the bag file, it should not be a big problem to import in into MATLAB using the [MATLAB rosbag](https://www.mathworks.com/help/robotics/ref/rosbag.html?s_tid=gn_loc_drop). [Here's](https://www.mathworks.com/help/robotics/examples/work-with-rosbag-logfiles.html) some more documentation.

    For some more info about importing bag files into matlab, [look over here](http://answers.ros.org/questions/query:matlab%20rosbag/), there have been a number of questions on the topic.

    Hope that helps.
