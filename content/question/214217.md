  body_markdown: "Hi,   \n`base_footprint` is located at ground level directly below\
    \ `base_link` or `base_footprint` is the projection of `base_link` on the ground.\
    \ You can use this information to find `base_footprint` from `base_link`.   \n\
    \nUpdate: I dont think you need to write a new node for it. You can use [static_transform_publisher](http://wiki.ros.org/tf#static_transform_publisher)\
    \ to publish the transform between `base_link` and `base_footprint`.  \nExample\
    \ : \n\n    <node pkg=\"tf\" type=\"static_transform_publisher\" name=\"base_link_footprint\"\
    \ args=\"0 0 z 0.0 0.0 0.0 /base_footprint /base_link 100\" />\nwhere `base_footprint`\
    \ is `z` below `base_link`. You can put this directly in any launch file or modify\
    \ accordingly to run it from the terminal.\n\nHope it helps.\n\n\n"
