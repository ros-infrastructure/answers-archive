  body_markdown: "Remove OpenCv Opencv2 etc. from your run and build depends (in package.xml)\
    \ as well as from the line find_package( catkin REQUIRED COMPONENTS ....  (in\
    \ CMakeLists.txt)\n\nWith catkin in groovy/hydro OpenCV is always embedded as\
    \ stand-alone package using:\n\n    find_package( OpenCV REQUIRED ) \n\n(Note\
    \ than I've added the REQUIRED)\n\nNote that you have also to add OpenCV include\
    \ directories like\n\n    include_directories(  ${catkin_INCLUDE_DIRS}  ${OpenCV_INCLUDE_DIRS}\
    \ )\n\nand for each of your execs/libs you created as target like\n\n    add_executable(\
    \ my_exec my_cpp_file.cpp )\n\nyou need to link against both catkin and OpenCV\
    \ libs:\n\n    target_link_libraries ( my_exec ${OpenCV_LIBRARIES} ${catkin_LIBRARIES}\
    \ )\n\n\n\n\n"
