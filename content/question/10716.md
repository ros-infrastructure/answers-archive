  body_markdown: "EROS is a project devoted to enabling easy cross compiling of ROS\
    \ projects for non-X86 architectures.  It assumes that you are running a full\
    \ Linux distro on your ARM.  \n\nrosserial on the other hand allows you to communicate\
    \ using ros on platforms that do not have a full linux stack. It is meant to send\
    \ messages over serial to a computer.  Our primary platform for rosserial is Arduino\
    \ which runs on an 8-bit microcontroller.  \n\nIf you are using a Gumstix Overo\
    \ or similar platform, you want to use EROS.  "
