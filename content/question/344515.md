  - body_markdown: "@pedroexe Here is how created the point cloud map from the recorded\
      \ rosbag (The rosbag contained the recorded velodyne lidar data). \n\n 1. First\
      \ open the **simulation** tab in ARM and load your .bag file. Wait for the .bag\
      \ file to load. Hit play and pause immediately after that.\n 2. Now go to **setup\
      \ tab and load TF and Vehicle Model** (click on those buttons until they turn\
      \ blue).\n 3. Go to computing tab and select **ndt_map**. \n 4. Go back to **simulation\
      \ and hit pause** now. You should see the ndt_computing in the terminal.\n 5.\
      \ Wait for all the points to be processed. You could see something like this\
      \ with Processed/Input.\n\n     Sequence number: 7376\n    Number of scan points:\
      \ 22288 points.\n\n 6. Once you see that all the points are processed, go back\
      \ to computing tab and **click on  [app] beside ndt_map**.\n 7. Select your\
      \ .pcd output file location and click on '**PCD OUTPUT**' button.\n 8. Wait\
      \ for a while until .pcd file is ready.\n\nPlease let me know if you have any\
      \ questions!"
