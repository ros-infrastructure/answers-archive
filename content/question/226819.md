  body_markdown: "Check out the example Python script at the bottom of the tutorial\
    \ you linked. Notice that both `imgmsg_to_cv2` and `cv2_to_imgmsg` are methods\
    \ that belong to the `cv_bridge.CvBridge` class. Your code needs to mimic this\
    \ structure. First instantiate an instance of `cv_bridge.CvBridge`, and then call\
    \ the `cv2_to_imgmsg` method. Something like:\n\n    #!/usr/bin/env python\n \
    \   \n    import rospy\n    from sensor_msgs.msg import Image\n    import cv2\n\
    \    import numpy as np\n    from cv_bridge import CvBridge, CvBridgeError\n \
    \   \n    def webcam_pub():\n        pub = rospy.Publisher('webcam/image_raw',\
    \ Image, queue_size=1)\n        rospy.init_node('webcam_pub', anonymous=True)\n\
    \        rate = rospy.Rate(60) # 60hz\n    \n        cam = cv2.VideoCapture(0)\n\
    \        bridge = CvBridge()\n    \n        if not cam.isOpened():\n         \
    \    sys.stdout.write(\"Webcam is not available\")\n             return -1\n \
    \   \n        while not rospy.is_shutdown():\n            ret, frame = cam.read()\n\
    \            msg = bridge.cv2_to_imgmsg(frame, encoding=\"bgr8\")\n    \n    \
    \        if ret:\n                rospy.loginfo(\"Capturing image failed.\")\n\
    \    \n            pub.publish(msg)\n            rate.sleep()\n    \n    \n  \
    \  if __name__ == '__main__':\n        try:\n            webcam_pub()\n    except\
    \ rospy.ROSInterruptException:\n        pass\n\n"
