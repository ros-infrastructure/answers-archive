  body_markdown: "Is the model in a ROS package?  If yes, make sure you have\n\n \
    \     <export>\n        <gazebo_ros gazebo_media_path=\"${prefix}\"/>\n      \
    \  <gazebo_ros gazebo_model_path=\"${prefix}\"/>\n      </export>\n\nin the `package.xml`\
    \ or else gazebo won't be able to find the model files.  Make sure the `model_path`\
    \ and `media_path` points to the directory where the model directories are found.\
    \  i.e. if your directory structure is as follows\n\n    .\n    \u2514\u2500\u2500\
    \ my_package/\n        \u251C\u2500\u2500 package.xml\n        \u251C\u2500\u2500\
    \ CMakeLists.txt\n        \u2514\u2500\u2500 some_subdirectory/\n            \u2514\
    \u2500\u2500 models/\n                \u2514\u2500\u2500 velodyne_VLP16/\n   \
    \                 \u251C\u2500\u2500 model.sdf\n                    \u251C\u2500\
    \u2500 model.config\n                    \u2514\u2500\u2500 ... other files ...\n\
    \nyou should replace `${prefix}` with `${prefix}/some_subdirectory/models`\n\n\
    \  "
