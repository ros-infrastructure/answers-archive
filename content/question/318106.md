I am packaging a ROS node with bloom, following the following [answer](https://answers.ros.org/question/173804/generate-deb-from-ros-package/) and am receiving a 'file changed as we read it' error at the final step. If I re-run the command everything works fine (as far as I can tell) and the deb package is produced in /src. Any ideas on why this is being produced? 

Environment: Ubuntu Xenial, ROS Kinect, bloom 0.7.2-1, debhelper 9.20160115ubuntu3, fakeroot 1.20.2-1ubuntu1

`bloom-generate rosdebian --os-name ubuntu --os-version xenial --ros-distro kinetic`

`fakeroot debian/rules binary`

Errors out the first time:

> dpkg-deb --build debian/ros-kinetic-test-node .. <br>
dpkg-deb: building package 'ros-kinetic-test-node' in '../ros-kinetic-test-node_0.7.0-0xenial_amd64.deb'.
tar: .: file changed as we read it <br>
dpkg-deb: error: subprocess tar -cf returned error exit status 1 <br>
dh_builddeb: dpkg-deb --build debian/ros-kinetic-test-node .. returned exit code 2 <br>
debian/rules:22: recipe for target 'binary' failed <br>
make: *** [binary] Error 1 <br>

Running `fakeroot debian/rules binary` again right after, seems to package the .deb fine:

> dh binary -v --buildsystem=cmake <br>
   dh_builddeb -O-v -O--buildsystem=cmake <br>
	dpkg-deb --build debian/ros-kinetic-test-node .. <br>
dpkg-deb: building package 'ros-kinetic-test-node' in '../ros-kinetic-test-node_0.7.0-0xenial_amd64.deb'.
