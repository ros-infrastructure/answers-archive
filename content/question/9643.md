The aim is then to find a grasping point using the kinect camera so a robot arm is able to grasp a piece of cloth. A good example could be this [image](http://wwwdelivery.superstock.com/WI/223/4029/PreviewComp/SuperStock_4029R-202615.jpg) where the folds will give a high deviation and thus a good grasping point.

My problem is that I cant find a good indeep tutorial how to use the PCL library and I wonder if someone has some good links or explanation how to process pointcloids with the PCL library.
