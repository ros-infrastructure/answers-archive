  body_markdown: "Ignition math provides cmake package configuration files so, assuming\
    \ you're using version 6, you can call `find_package(ignition-math6 REQUIRED)`\
    \ and link against the library via `target_link_libraries(ACE ignition-math6::ignition-math6)`\n\
    \ \nYou can find an example CMakeLists.txt file at https://bitbucket.org/ignitionrobotics/ign-math/src/default/examples/CMakeLists.txt"
