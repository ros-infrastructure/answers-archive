  body_markdown: "Hello, if you write the code for the sensor publication, you can\
    \ declare the min and max value every time you publish the distance or set these\
    \ values when you declare the sensor.\n\nDeclaration:\n\n    range_msg.radiation_type\
    \ = sensor_msgs::Range::ULTRASOUND;\n    range_msg.header.frame_id =  frameid;\n\
    \    range_msg.field_of_view = 0.2; \n    range_msg.min_range = 0.0; // modification\
    \ on min-max distance are made here.\n    range_msg.max_range = 2.0;\n\nPublisher:\n\
    \n    range_msg.range = measure;\n    range_msg.header.stamp = nh.now();\n   \
    \ pub_range.publish(&range_msg);\n\n"
