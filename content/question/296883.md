    Did you try giving the static IP? You can try this:<br>



    In the right side of the top bar click the connection menu and select **Edit connections**.<br>
    Choose the wired connection and click **Edit**, then choose the  **IPv4Settings** tab and change the Method to **Manual**. There you can add an IP like 192.168.1.50 by clicking the **Add** button.<br>
    Then you should be able to ssh using the default static IP:

        ssh administrator@192.168.1.11
