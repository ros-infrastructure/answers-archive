  body_markdown: "If I were you, instead of trying to do this directly in RVIZ of\
    \ Gazebo I would look at how to process the costmap in a custom node, and from\
    \ there extract the information you want.\n\nMaps in ROS are represented as [Occupancy\
    \ Grids](http://docs.ros.org/api/nav_msgs/html/msg/OccupancyGrid.html). This stores\
    \ a discretized (i.e. cells) representation of the environment. From this representation,\
    \ with the correct logic in a roscpp or rospy node, you can extract the information\
    \ you want. Here is an example in the ROS nav stack [Global Planner Costmap](https://github.com/ros-planning/navigation/blob/3bddac0bca09e2a344206e35651324c5e73c972d/global_planner/src/planner_core.cpp#L96)\
    \ which manipulates this discretized representation in c++. [Costmap2D](http://docs.ros.org/kinetic/api/costmap_2d/html/costmap__2d__ros_8h_source.html)\
    \ is not exactly a occupancy grid but the concept/representation is similar. \n\
    \nOnce you have the grid available to you in c++, I imagine you can produce the\
    \ logic required to generate the result you want."
