  body_markdown: "I believe it's because you have the `clearing_rotation_allowed`\
    \ parameter set to `false`. It won't rotate to clear the cost map and replan,\
    \ it'll just give up like you're seeing. \n\nFrom [the wiki](http://wiki.ros.org/move_base#Parameters),\
    \ the `clearing_rotation_allowed` parameter\n\n> Determines whether or not the\
    \ robot\n> will attempt an in-place rotation when\n> attempting to clear out space.\
    \ Note:\n> This parameter is only used when the\n> default recovery behaviors\
    \ are in use,\n> meaning the user has not set the\n> recovery_behaviors parameter\
    \ to\n> anything custom."
