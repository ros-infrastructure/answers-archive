  body_markdown: "Hello there,\n\nYou have to add 2 python paths into your [settings.json](https://code.visualstudio.com/docs/getstarted/settings#_languagespecific-editor-settings)\
    \ file into VS Code. \n\nThese are the paths:\nThe first path is for all packages\
    \ of your local workspace and the second is for the global package. \n\n\n   \
    \ {\n        \"python.autoComplete.extraPaths\": [\n            \"/home/<pc-name>/<ws-name>/devel/lib/python3/dist-packages\"\
    ,\n            \"/opt/ros/noetic/lib/python3/dist-packages\"\n        ]\n    }\n\
    \n\nIf you are using CPP then you have to add the path in the c_cpp_properties.json\
    \ file.\n\nThe location of setting and c_cpp_properties JSON files will be :\n\
    \n     \"~/<work-space>/devel/include\"\n\nJust to note for **Pycharm Users**:\
    \ if you are using Pycharm then give this both paths by following these steps:\
    \ \n\n1. Go to settings.\n2. Project: src > Project Structure > On the right-hand\
    \ side click on  + Add Content Root and locate both paths. \n\nTry this you will\
    \ be able to solve your problem and if you have any issues feel free to drop a\
    \ comment."
