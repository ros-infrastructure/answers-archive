  body_markdown: "First you could try with a simple command line and make sure everything\
    \ works:\n\n    $ rosrun rosserial_python serial_node.py _baud:=57600 _port:=/dev/ttyACM0\n\
    \nThen you make a catkin package in your catkin workspace, add a folder with a\
    \ name `launch` in your package.\n\nInside your launch folder, your launch file\
    \ `run_arduino.launch` should be created (right click -> new document -> empty\
    \ document)\n\nHere's the corresponding launch file:\n\n    <launch>\n    \t<node\
    \ name=\"serial_node\" \t\tpkg=\"rosserial_python\" \t\ttype=\"serial_node.py\"\
    >\n    \t<param name=\"port\" \t\t\t    type=\"string\"\t\t\t    value=\"/dev/ttyACM0\"\
    />\n    \t<param name=\"baud\" \t\t\t    type=\"int\"\t\t\t        value=\"57600\"\
    />\n        </node>\n    </launch>\n\nAfter creating a launch file, what you simply\
    \ do is going to your package directory, where you have you launch file and use\
    \ the following command to start the arduino node: \n\n    $ roslaunch /your_catkinpackage/launchFolder/run_arduino.launch\n\
    \n"
