    \ can check it at the [urdf wiki page](http://wiki.ros.org/urdf). Personnally\
    \ I use :\n\n    check_urdf /PATH/TO/URDF \n\nWhen running this with your urdf\
    \ the output is :\n\n    Error:   joint limit: no effort\n             at line\
    \ 146 in /build/urdfdom-UJ3kd6/urdfdom-0.4.1/urdf_parser/src/joint.cpp\n    Error:\
    \   Could not parse limit element for joint [steering_joint_left_1]\n        \
    \     at line 494 in /build/urdfdom-UJ3kd6/urdfdom-0.4.1/urdf_parser/src/joint.cpp\n\
    \    Error:   joint xml is not initialized correctly\n             at line 207\
    \ in /build/urdfdom-UJ3kd6/urdfdom-0.4.1/urdf_parser/src/model.cpp\n    ERROR:\
    \ Model Parsing the xml failed\n\nEventhough the lines are not the ones from the\
    \ urdf file it can directly tells you that something is wrong with a `limit` tag\
    \ within a `joint` tag. After a quick search in the file you'll see that at the\
    \ lines 327 and 349 you miss the attributes `effort` and `velocity` within the\
    \ `limit` tag. \n\nAfter correcting that, the output of the previous command is\
    \ now :\n\n    Error:   Failed to find root link: Two root links found: [body]\
    \ and [suspension_main_right_2]\n             at line 238 in /build/urdfdom-UJ3kd6/urdfdom-0.4.1/urdf_parser/src/model.cpp\n\
    \    ERROR: Model Parsing the xml failed\n\nThis error means that there are two\
    \ links in your urdf that are not a child of any other link. You can only have\
    \ one link like that : it's called the `root link`. The tools tells you that `body`\
    \ and `suspension_main_right_2` are defined as root links. So all you have to\
    \ do is correct your urdf to set a parent to `suspension_main_right_2`.\n\nOnce\
    \ you've done it you can print the graph of your link with :\n\n    urdf_to_graphiz\
    \ /PATH/TO/URDF\n\n**Note :** After I did it (by setting the parent of `suspension_main_right_2`\
    \ to `body`) your graph looks odd to me, is it intended to have `suspension_left_1`\
