  body_markdown: "I ran into the same problem while running *markers.launch*. The\
    \ key being the error message stating a type mismatch in the topics. I believe\
    \ it has something to do with the order of arguments while initializing the `ar_track_alvar`\
    \ node. \n\nTo fix it, change\n\n      <node name=\"ar_track_alvar\" pkg=\"ar_track_alvar\"\
    \n            type=\"individualMarkersNoKinect\" respawn=\"false\" output=\"screen\"\
    \ \n            args=\"$(arg marker_size) $(arg max_new_marker_error) \\\n   \
    \               $(arg max_track_error) $(arg cam_image_topic)  \\\n          \
    \        $(arg cam_info_topic) $(arg output_frame)\" />\nto\n\n      <node name=\"\
    ar_track_alvar\" pkg=\"ar_track_alvar\"\n            type=\"individualMarkersNoKinect\"\
    \ respawn=\"false\" output=\"screen\"> \n            <param name=\"marker_size\"\
    \ttype=\"double\" value=\"$(arg marker_size)\"/>\n            <param name=\"max_new_marker_error\"\
    \ttype=\"double\" value=\"$(arg max_new_marker_error)\"/>\n            <param\
    \ name=\"max_track_error\"\ttype=\"double\" value=\"$(arg max_track_error)\"/>\n\
    \            <param name=\"output_frame\"\ttype=\"string\" value=\"$(arg output_frame)\"\
    />\n    \n            <remap from=\"camera_image\" to=\"$(arg cam_image_topic)\"\
    />\n            <remap from=\"camera_info\" to=\"$(arg cam_info_topic)\"/>\n \
    \     </node> \nUsing parameter names and remap makes sure that the arguments\
    \ are parsed correctly.\n"
