    `sdh.urdf.xacro` is a [xacro](http://ros.org/wiki/xacro) file, you need to convert it into [urdf](http://ros.org/wiki/urdf) first.  You'll need some code somewhere that makes use of the `cob_sdh_v0` macro described in the xacro file.  For example, when the gripper is attached to the arm [arm_sdh.urdf.xacro](https://github.com/ipa320/cob_common/blob/master/cob_description/ros/robots/arm_sdh.urdf.xacro), it is invoked by following code blocks:

        <!-- cob sdh-->
        <include filename="$(find cob_description)/ros/urdf/sdh_v0/sdh.urdf.xacro" />
        <!-- sdh -->
        <xacro:cob_sdh_v0 name="sdh" parent="arm_7_link">
          <origin xyz="0 0 0" rpy="0 3.1415926 0" />
        </xacro:cob_sdh_v0>

    I suggest taking a look at the tutorials in xacro and urdf packages first.

    John

    \n           xmlns:xacro=\"http://playerstage.sourceforge.net/gazebo/xmlschema/#interface\"\
    \n           name=\"sdh\" >\n      \n      <!-- The following included files set\
