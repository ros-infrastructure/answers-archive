    **EXPERIMENTAL**

    Checkout [this simulator_gazebo hydro branch](https://code.ros.org/svn/ros-pkg/stacks/simulator_gazebo/branches/hydro/gazebo).
    Despite the branch name, build against groovy.

        sudo apt-get install ros-groovy-urdfdom*

    Next, checkout [gazebo `deprecated_parser_sdf_1.2_support` branch](https://bitbucket.org/osrf/gazebo/src/35ef436fc81970b00b07d8cf549f58bf5b0de364/?at=deprecated_parser_sdf_1.2_support) and compile.  This has actually been merged with the latest default tip of gazebo.  Set install target to `/usr`.

        cmake -DCMAKE_MODULE_PATH=/opt/ros/groovy/share -DCMAKE_INSTALL_PREFIX=/usr ..

    Lastly, go to the simulator_gazebo groovy overlay, and do a rosmake.
