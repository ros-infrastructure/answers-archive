    The `Connection to reverse interface dropped.` messages indicate that the remote (the robot) closes its socket connection to port 50001. A `tcpdump` could help, e.g.

    ```
    sudo tcpdump port 50001
    ```

    This will show each package sent through port 50001 (both directions). From this you might see, whether the port is properly closed or connection is lost. This might be a good point to actually take this to an issue in the driver's repository...
