  body_markdown: |2
        ROS_INFO("%s", msg.data);

    For `std_msgs::Int8`, the `data` field is of the `int8` type (see the [msg doc](http://docs.ros.org/api/std_msgs/html/msg/Int8.html)). The `%s` format string is for strings (or `char*`), so that won't work. Try `%d`.
