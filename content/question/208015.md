  body_markdown: "You can run any number of nodes within an activity.\nSimply do something\
    \ like this (assuming your activity is a `RosActivity`):\n\n    @Override\n  \
    \  protected void init(NodeMainExecutor nodeMainExecutor) {\n        NodeConfiguration\
    \ nodeConfiguration = NodeConfiguration.newPublic(getRosHostname());\n       \
    \ nodeConfiguration.setMasterUri(getMasterUri());\n\n        nodeConfiguration.setNodeName(\"\
    node_1\");\n        MyNode myNode1 = new MyNode();     // Something that extends\
    \ AbstractNodeMain\n        nodeMainExecutor.execute(myNode1, nodeConfiguration);\n\
    \n        nodeConfiguration.setNodeName(\"node_2\");\n        MyNode myNode2 =\
    \ new MyNode();\n        nodeMainExecutor.execute(myNode2, nodeConfiguration);\
    \     // And so on...\n    }\n\n        "
