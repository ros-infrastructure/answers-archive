  body_markdown: "I've just modified the chatter C++ example code here so that it\
    \ subscribes to two different topics using a single callback, as I was trying\
    \ to describe above.\n\n    #include \"ros/ros.h\"\n    #include \"std_msgs/String.h\"\
    \n    \n    void chatterCallback(const std_msgs::String::ConstPtr& msg, std::string\
    \ topicName)\n    {\n      ROS_INFO(\"I heard: [%s] on topic \\\"%s\\\"\", msg->data.c_str(),\
    \ topicName.c_str());\n    }\n    \n    int main(int argc, char **argv)\n    {\n\
    \      ros::init(argc, argv, \"listener\");\n    \n      ros::NodeHandle n;\n\
    \    \n      ros::Subscriber sub1 = n.subscribe<std_msgs::String>(\"chatter\"\
    , 1, boost::bind(&chatterCallback, _1, \"chatter\"));\n      ros::Subscriber sub2\
    \ = n.subscribe<std_msgs::String>(\"other_chatter\", 1, boost::bind(&chatterCallback,\
    \ _1, \"other_chatter\"));\n    \n      ros::spin();\n    \n      return 0;\n\
    \    }\n\nHopefully this will give you a simple ROS 1 example you can adapt to\
    \ your needs.\n"
