 Hello,
when following the tutorial at https://docs.ros.org/en/foxy/Tutorials/Writing-A-Simple-Cpp-Publisher-And-Subscriber.html I realized that ```void topic_callback(const std_msgs::msg::String::SharedPtr msg)``` always takes the SharedPtr of the message as an argument. Why isn't it common to just take the message as an argument for the callback, this would look like this ```void topic_callback(const std_msgs::msg::String msg)```? When thinking about it I guess the difference is that one is call by reference and the other one call by value. Is using SharedPtr increasing memory efficiency?
