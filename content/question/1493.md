After reading [this thread on the Gazebo-list](http://kforge.ros.org/pipermail/gazebo-list/2013-February/004404.html) about plugins residing inside the Gazebo ROS node, I found out that my plugin is running fine without the ros::init() call.

The tutorials (e.g. [here for 1.3](http://gazebosim.org/wiki/Tutorials/1.3/ros_enabled_model_plugin#Model_Plugin)) however make use of this initialisation. So now I wonder, if it is necessary or not?

Since, the plugin is loaded into the Gazebo node, it would make sense to me, that ros::init is not needed (similar to nodelets in ROS).
