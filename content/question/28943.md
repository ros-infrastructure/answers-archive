    I intended to write a real tutorial, but given the lack of time and somebody recently [asking the same question](https://answers.ros.org/question/414609/how-to-add-image-texture-to-gazebo-as-material-through-blender-settings/), I decided to quickly write down the necessary steps as a guide.
    It might not be 100% accurate as I tested this only on one model and it's a few weeks ago so it's based on memory. But it should get you started.

    You need to:

     1. Apply textures in Blender,
     2. "Bake" them into several images (albedo map, normal map, roughness map, etc), and
     3. Load these with your model.

    </br>

    **Applying textures:**

    Depending on the complexity of your models, this can be involved. For more info google for "blender UV mapping". The UV mapping defines how a 2D texture image is mapped to the surfaces of your model. Here are a few relevant videos:

    - [UV Unwrapping for Beginners](https://www.youtube.com/watch?v=qa_1LjeWsJg)
    - [Blender Texturing tutorial](https://www.youtube.com/watch?v=EK6-tWUGljY&t=5s)
    - [26 Essential Blender Tips for UV Unwrapping Subdivision Surfaces](https://www.youtube.com/watch?v=8qv6DbWr6zw)

    </br>

    **Baking:**

    Baking is the process of creating a set of images, *specific for your model* (according to the defined UV mapping), that contain the information on how the model should look (albedo, roughness, etc).

    If I recall correctly, default baking in Blender has to be done manually for each map, so you want to use an add-on instead. There is [this free add-on](https://github.com/Aetheris743/Blender-PBR-Texture-Exporter), or there are several commercially available alternatives, such as [SimpleBake](https://blendermarket.com/products/simplebake---simple-pbr-and-other-baking-in-blender-2), which have some more whistles and bells. The free plugin worked for me (though tested only for one, rather simple model).

    The model-specific baked images then need to be specified in the sdf, so they are loaded for your DAE model. See the example mentioned in the comment of @azeey .

    </br>

    **About textures:**

    You can find textures online, e.g. from [BlenderKit](https://www.blenderkit.com/), or if you are modeling a physical object you could define your own textures from pictures, but that involves several steps, e.g. to make the images seamless and to create the texture maps. See e.g. following video's:

    - [Seamless textures](https://www.youtube.com/watch?v=DWvMpmLLggc)
    - [Make normal maps](https://www.youtube.com/watch?v=fAIB9cGjy5I)
    - [Gloss and specular maps](https://www.youtube.com/watch?v=h5I0k3xifdg)
    - Etc.

    You would then use these maps to define your texture in Blender (see e.g. [this video](https://www.youtube.com/watch?v=MeW_Cy1TqRc)), apply the texture to your model, and then do the baking step to generate the texture maps (specific to your model) to load in the SDF.
