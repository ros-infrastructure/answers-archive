  body_markdown: "The problem is solved...\n\nIt seems that the roslib package isn't\
    \ a dependency of roscpp anymore. Adding the roslib package as dependency to my\
    \ package makes it linkable.\n\n**roscpp manifest.xml in electric**\n\n    ...\n\
    \    <depend package=\"roslib\"/>\n    ...\n\n**roscpp manifest.xml in fuerte**\n\
    \n    <package>\n      <description brief=\"ROS C++ client library\">\n    \n\
    \    ...\n    \n      </description>\n      <author>Morgan Quigley mquigley@cs.stanford.edu,\
    \ Josh Faust jfaust@willowgarage.com, Brian Gerkey gerkey@willowgarage.com, Troy\
    \ Straszheim straszheim@will$\n      <license>BSD</license>\n      <review status=\"\
    Doc reviewed\"/>\n      <url>http://ros.org/wiki/roscpp</url>\n      <depend package=\"\
    roslang\"/>\n      <export>\n        <cpp cflags=\"`PKG_CONFIG_PATH=${prefix}/../../lib/pkgconfig\
    \ pkg-config --cflags roscpp`\"\n             lflags=\"`PKG_CONFIG_PATH=${prefix}/../../lib/pkgconfig\
    \ pkg-config --libs roscpp`\"/>\n        <roslang cmake=\"${prefix}/rosbuild/roscpp.cmake\"\
    />\n      </export>\n      <rosdep name=\"pkg-config\"/>\n    \n    </package>\n\
    \nThanks anyway!"
