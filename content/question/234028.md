  body_markdown: "If your data is always going to be a 4x5 array, you could create\
    \ a custom message that contained an array of 20 integers and then do a little\
    \ math to determine how to translate (row,col) access to entries in the 1D array\
    \ (correct way to do this would depend on if you wanted to use column-major or\
    \ row-major storage). This would work fine, but could definitely be error prone.\n\
    \nAn alternative would be to create a custom message containing arrays of, e.g.,\
    \ 5 integers that would represent rows, then create another custom message that\
    \ contained an array of length 4 of the first message. In C++, this would become\
    \ a `std::vector< std::vector<int> >`. This would also work fine.\n\nThere is\
    \ no reason you can't use the `Int32MultiArray` from std_msgs, and you certainly\
    \ don't have to use `push_back`. You could just initialize a `std::vector` of\
    \ length 20 for the `data` field. Here's an example:\n\n    #include \"ros/ros.h\"\
    \n    #include \"std_msgs/Int32MultiArray.h\"\n    #include \"std_msgs/MultiArrayDimension.h\"\
    \n    #include <iostream>\n    #include <vector>\n    #include <array>\n    \n\
    \    #define H (4)\n    #define W (5)\n    \n    \n    int main(int argc, char\
    \ **argv)\n    {\n    \tros::init(argc, argv, \"talker\");\n    \tros::NodeHandle\
    \ n;\n    \tros::Publisher pub = n.advertise<std_msgs::Int32MultiArray>(\"matrix_pub\"\
    , 1);\n    \tros::Rate loop_rate(10);\n    \tstd_msgs::Int32MultiArray dat;\n\
    \    \tint array[H][W] = {\n    \t\t{0, 1, 2, 3, 4},\n    \t\t{10, 11, 12, 13,\
    \ 14},\n    \t\t{20, 21, 22, 23, 24},\n    \t\t{30, 31, 32, 33, 34}};\n    \n\
    \    \t// fill out message:\n    \tdat.layout.dim.push_back(std_msgs::MultiArrayDimension());\n\
    \    \tdat.layout.dim.push_back(std_msgs::MultiArrayDimension());\n    \tdat.layout.dim[0].label\
    \ = \"height\";\n    \tdat.layout.dim[1].label = \"width\";\n    \tdat.layout.dim[0].size\
    \ = H;\n    \tdat.layout.dim[1].size = W;\n    \tdat.layout.dim[0].stride = H*W;\n\
    \    \tdat.layout.dim[1].stride = W;\n    \tdat.layout.data_offset = 0;\n    \t\
    std::vector<int> vec(W*H, 0);\n    \tfor (int i=0; i<H; i++)\n    \t\tfor (int\
    \ j=0; j<W; j++)\n    \t\t\tvec[i*W + j] = array[i][j];\n    \tdat.data = vec;\n\
    \    \n    \twhile (ros::ok())\n    \t{\n    \t\tpub.publish(dat);\n    \t\tloop_rate.sleep();\n\
    \    \t}\n    \n    \treturn 0;\n    }\n\n"
