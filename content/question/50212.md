  body_markdown: "Let's say you want to install the first stack you mentioned: `cob_environments`.\
    \  Assuming you are on an officially supported version of Ubuntu and [your repositories\
    \ are setup correctly](http://www.ros.org/wiki/fuerte/Installation/Ubuntu), you\
    \ could first check if there are pre-built binaries available. For the `cob_environments`\
    \ package, I could run\n\n    apt-cache search ros.*cob\n\nin a terminal.  On\
    \ my system, I can see that there is a package called `ros-fuerte-cob-environments`.\
    \  I could install this using `apt-get`, and the stack (plus all of its dependencies\
    \ would be installed).  For many users, if prebuilt binaries are available, this\
    \ is the way to go.\n\nIn general when a stack or package is not available through\
    \ your package manager you need to do the following things:\n\n 1. Get a local\
    \ copy of the source code, and make sure it is in your `ROS_PACKAGE_PATH`\n 2.\
    \ Check that you have all of the dependencies for that stack/package installed\n\
    \ 3. Install any missing dependencies.  Tools like `apt-get` and `rosdep` are\
    \ very useful for this!\n 4. Compile the code\n\nFor the `cob-environments` stack,\
    \ the only dependency that you likely don't have (assuming you have a \"full-desktop\"\
    \ install of ROS) is `cob_common`  This can be seen by looking at the dependencies\
    \ link on the right side of [this page](http://www.ros.org/wiki/cob_environments#).\
    \  I'm going to walk you through installing `cob_environments`.\n\n 1. To get\
    \ a copy of the source code, we will use `git`.  So first navigate to a directory\
    \ that is on your `ROS_PACKAGE_PATH`, then run this command (you will need git\
    \ installed)\n\n        git clone https://github.com/ipa320/cob_environments\n\
    \n 2. We are going to use `rosmake` to try and build this package.  \n\n     \
    \   rosmake cob_environments\n\n 3. If you don't have `cob_common`, this will\
    \ error out, and you will need to clone `cob_common` and build that before you\
    \ can build `cob_environments`.\n\n        git clone https://github.com/ipa320/cob_common\n\
    \        rosmake cob_common\n\n 4. You should now be able to re-run `rosmake cob_environments`.\
    \  If the process completes successfully, you should now have the stack successfully\
    \ installed!\n\nNote the process with SVN or CVS or Mercurial would be basically\
    \ the same, but the actual commands for obtaining a copy of the repository would\
    \ be slightly different.\n\n\n"

    Create a development environment using rosws:
    http://mirror.umd.edu/roswiki/doc/api/rosinstall/html/

    Then do this:

        $ roslocate info cob_environments | rosws merge -
        $ rosws update

    this will take care of the details. The same goes for velodyne:

        $ roslocate info velodyne | rosws merge -
        $ rosws update
