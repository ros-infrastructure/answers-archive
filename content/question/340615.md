  body_markdown: |-
    ROS 2 is targeting Python3 only. `python-packaging` refers to the Python 2 package.
    The rosdep key should be `python3-packaging` (the same applies to all `python-*` dependencies in you `package.xml`.

    If the key doesn't exist in [rosdep](https://github.com/ros/rosdistro/blob/master/rosdep/python.yaml), you can contribute it following [these instructions](https://github.com/ros/rosdistro/blob/master/CONTRIBUTING.md#rosdep-rules-contributions)

    HTH
