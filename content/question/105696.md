    It looks to me like the source version is dropping frames since it cannot keep up with the update speed. The problem is that the source checkout and compilation in catkin is by default done without any optimizations, as described in [this related question](http://answers.ros.org/question/71965/catkin-compiled-code-runs-3x-slower/).

    If you instead run `catkin_make -DCMAKE_BUILD_TYPE=Release` it should work better.
