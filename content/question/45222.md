    \ Fuerte installation instructions, you should already have it.  This is the ideal\
    \ way to find packages that aren't available through apt-get.\n\nIf not, use the\
    \ following command:\n\n    sudo apt-get install python-rosinstall\n\nYou can\
    \ then do the following:\n\n    # Initialize a workspace\n    rosws init ~/robotino_testing\n\
    \    \n    # Source that workspace\n    cd ~/robotino_testing && source ./setup.bash\n\
    \    \n    # Merge your OS install\n    rosws merge /opt/ros/fuerte\n    \n  \
    \  # Find the robotino repository and merge it locally\n    roslocate info robotino\
    \ | rosws merge -\n    roslocate info robotino_kinect | rosws merge -\n    roslocate\
    \ info simple_grasping | rosws merge -\n    \n    # Update your workspace\n  \
    \  rosws update\n\nNow you can just `rosmake` the packages that you are interested\
