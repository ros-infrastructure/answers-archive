  body_markdown: "The master branch cannot work directly for ROS hydro version. \n\
    \nBut we could install the ros-hydro-gps-common from the Synaptic Package Manager.\n\
    \nAnd then $git clone https://github.com/ethz-asl/ethzasl_xsens_driver.git \n\
    $catkin_make  \n\nAfter that, it should work\n\nTo use the xsens_driver, the USB\
    \ access shall be changed to the administrator \n\n$sudo chmod 777 /dev/ttyUSB0\n\
    \nThen the xsens_driver could be launched and the imu data could be viewed by\
    \ the following command.\n\n$roslaunch xsens_driver xsens_driver.launch\n$rostopic\
    \ echo /imu/data\n"
