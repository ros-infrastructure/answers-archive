    This looks like you have mismatched versions of code. The Diamondback version of camera_calibration does an `import cv`, not an `import cv2` (source is [here](https://code.ros.org/svn/ros-pkg/stacks/image_pipeline/tags/diamondback/camera_calibration/src/camera_calibration/calibrator.py)). However, trunk (i.e. E-Turtle development) does do an `import cv2` (source is [here](https://code.ros.org/svn/ros-pkg/stacks/image_pipeline/trunk/camera_calibration/src/camera_calibration/calibrator.py)). So if you were running all Diamondback code, there shouldn't have been an `import cv2` in the first place. The rest of your errors likely follow from E-Turtle using a newer version of OpenCV than Diamondback.

    Make sure that all of your code is checked out from Diamondback tags or branches and not image_pipeline trunk.
