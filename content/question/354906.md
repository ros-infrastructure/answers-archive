TurtleBot3 is not included in noetic distribution. O'Reilly's book, Programming Robots with ROS A Practical Introduction to the Robot Operating System", uses TurtleBot as a teaching vehicle throughout the book. For beginners, TurtleBot is a vary valuable learning tool. Therefore, noetic beginners are out of luck as far as exercising TurtleBot/TurtleBot3 is concerned as it is not a trivial task to port TurtleBot3's source code into noetic due to the drastic difference between Python 2 and Python 3. Does anyone know if there is something in noetic distribution one can use as a substitute for TurtleBot3?
