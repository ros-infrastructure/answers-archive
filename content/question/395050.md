    I am almost one year late but leaving my answer here hoping that it will be helpful to someone in the future.

    I recently run into the same problem on an Ubuntu 18.04 LTS machine with ROS Melodic.
    We managed to solve the issue thanks to [this](https://github.com/ros/ros_comm/pull/1772) closed thread in the `ros_comm` Github thread.
    The quickest fix is for you to locate the `/opt/ros/kinetic/lib/python2.7/dist-packages/message_filters/__init__.py` file in your system and change the problematic line as follows:

    <code>
    <strike>for vv in itertools.product(*[zip(*s)[0] for s in stamps]):</strike>
    </code>

    <code>
    for vv in itertools.product(*[next(iter(zip(*s))) for s in stamps]):
    </code>

    as done in [`627b5af`](https://github.com/ros/ros_comm/commit/627b5afa3b49040d7934dcd715bae87c815890bc) commit to `ros_comm`.
