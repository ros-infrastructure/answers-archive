    You could look through the codes of some of these [robots](http://www.ros.org/wiki/Robots). I personally referred quite a bit to the [turtlebot](http://www.ros.org/wiki/Robots/TurtleBot)'s because the tutorial is quite complete.

    My own experience in working on differential drive robot: [here](http://answers.ros.org/question/12599/ros-beginning?answer=18686#post-id-18686). I did not start with the robot model though. That came quite late into the development because I was eager to see things moving.

    I would think the topic cmd_vel (geometry_msgs/Twist) is a good starting point, since both the teleop and navigation uses it to control the robot.
