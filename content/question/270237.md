    Your existing node that does things with a color red will become the dynamic reconfigure server, which will allow other clients to connect to it and tell it to change those HSV values.

    The client could be the [rqt dynamic reconfigure plugin](http://wiki.ros.org/rqt_reconfigure), so you don't need to write your own client unless you want to control those values through a script or code rather than the rqt gui.
