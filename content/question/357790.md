  body_markdown: "`gazebo_ros_` ROS package does not contain any launcher that is\
    \ called `gazebo.launch`. \nIt's default launcher is `empty_world.launch`. It\
    \ would be better if you used this launcher as a template, change the necessary\
    \ arguments and save this as a new launcher (e.g. `gazebo.launch`) in your `base_2links`\
    \ package.\n\nAfter you complete this and source your workspace, you'll be able\
    \ to run it with\n`roslaunch base_2links gazebo.launch`"
