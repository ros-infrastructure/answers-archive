  body_markdown: ">  Moreover, I\u2019m willing to write a tutorial on ROS Wiki of\
    \ this package based in my experience since there is none.\n\nThis would be highly\
    \ appreciated!\n\n> In this step, I just need to change PDOmapping=0 to PDOmapping=1\
    \ of each object in the eds file?\n\nNo. Please do not touch the `PDOmapping`\
    \ flags. They just reflect the device's support for mapping the respective object.\n\
    `ros_canopen` uses this flag for config validation only.\n\nThe actually PDO mapping\
    \ is configured in the `ParameterValue`s of the objects `1600` to `17FF` (RPDO\
    \ of the device, sent by `ros_canopen`) and `1A00` to  `1BFF` (TPDO of the device,\
    \ read by `ros_canopen`).\n(https://www.can-cia.org/can-knowledge/canopen/pdo-protocol/)\n\
    \nFor each item, you have to specify the number of entries (`sub0`) and the mapping\
    \ values (`sub1` to `subN`), which encode the target object and its size.\nThe\
    \ [canopen_402](http://wiki.ros.org/canopen_402) wiki lists these values for common\
    \ objects.\nAn example can be found [here](https://github.com/ipa320/canopen_test_utils/blob/kinetic-devel/config/Elmo.dcf#L748-L775).\n\
    \nIn general I would recommend to use a tool like `CANeds` to configure the PDO\
    \ mapping and to check the file for errors.\n\nSpecial care must be taken, because\
    \ `ros_canopen` assumes that the device uses the mapping as encoded in `DefaultValue`\
    \ and sometimes these values are wrong.\nOn the other hand, if you are lucky,\
    \ the defaults already fit your needs and you don't have to change anything.\n\
    \n> What about the \u201CDrive operation modes\" in this webpage? What are those?\
    \ \n\nCANopen 402 supports different modes for their control loops. The vary in\
    \ input types (position, velocity), velocity profiles (ramps) and data managements\
    \ (set points, cyclic).\nThe supported operation modes are reflected (bit-wise)\
    \ in object `6502`, which is mandatory for CANopen 402 drives, if I am not mistaken.\n\
    \n\n> And do I have to use them to control my motor controller?\n\nYes, otherwise\
    \ the motor will not run."
