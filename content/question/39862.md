Hi<br>
The following posts describe how to set the initial distance/orientation of the static camera view when your Gazebo .world file loads:<br>
http://answers.ros.org/question/11178/initial-view-after-gazebo-starts/   <br>http://answers.ros.org/question/12658/how-to-change-gazebo-gui-focal-lengthfov/
<br>using a block in your .world file like this:

       <rendering:gui>
        <type>fltk</type>
        <size>480 320</size>
        <pos>0 0</pos>
        <frames>
          <row height="100%">
            <camera width="100%">
              <xyz>0.3 0 3</xyz>
              <rpy>0 90 90</rpy>
            </camera>
          </row>
        </frames>
      </rendering:gui>


but it seems like this code is being ignored by my Gazebo.  <br>No matter what parameters I change, Gazebo always loads with the robot model at the same distance and orientation. Its annoying having to zoom-in, unlike Rviz.

Is anyone able to change their default Gazebo camera view?  @marcus-bader is this still working for you?
