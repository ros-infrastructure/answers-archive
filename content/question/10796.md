  body_markdown: "This is not a recommended practice.  You can have a [unary stack](http://www.ros.org/reps/rep-0109.html)\
    \ where a package is also a stack.  Most of the tools are robust to it, however\
    \ there are several edge cases which this will break.  Most obvious is roscd,\
    \ as well as indexing and documentation will be broken as packages and stacks\
    \ share a namespace.  Getting REP 109 to work was hard.  The package and stack\
    \ are obviously at different scopes, they should be able to be named differently.\
    \  "
