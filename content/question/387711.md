    I am not sure I understand how you want to get this difference from a topic. But to calculate the distance between 2 GPS points you could use a Python package like [geopy](https://github.com/geopy/geopy)

    As shown in the repo, a simple example:

        from geopy.distance import geodesic
        newport_ri = (41.49008, -71.312796)
        cleveland_oh = (41.499498, -81.695391)
        print(geodesic(newport_ri, cleveland_oh).miles)
        538.390445368
