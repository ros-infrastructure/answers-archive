    Please check again the [Subscriber Tutorial](http://wiki.ros.org/ROS/Tutorials/WritingPublisherSubscriber(c%2B%2B)#roscpp_tutorials.2BAC8-Tutorials.2BAC8-WritingPublisherSubscriber.Writing_the_Subscriber_Node) and try to understand it. Especially read carefully the the paragraph where the commands are described.

    Instead of what you did here:

        void vx_odom (const vx_pub::vx_msg &vx_msg)

    you have to put in the respective message type into the callback function. So for you it would be:

        void vx_odom (const std_msgs::Float64::ConstPtr& vx_msg)
