    This code has some issues:

    Typically the arduino publishes to the `joint_state` topic to report the current joint values, and it subscribes to a `joint_cmd` topic to determine the new value for one or more joints. For a ros system, it's very non-standard to take set-joint-value commands from the joint_state topic.

    In your while loops, I see nothing updating `motorOut`, so not sure what's going on there. How do the loops exit?

    Also, when publishing, you assign an `int` array to an `int16 *`. It'd be cleaner and more robust to make these types consistent rather than rely on some specific arduino characteristic (e.g. a 2-byte int.)
