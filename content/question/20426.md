  body_markdown: "> 1) Should I increase the mu1,mu2 to achieve that?\n\nSure, try\

    \ from a table (like this: https://www.engineeringtoolbox.com/friction-coefficients-d_778.html)\

    \ fdir1 = 0 0 0 correct?\n\nI don't think so. \n\n[fdir1 should be a 3-tuple specifying\
    \ direction of mu1 in the collision local reference frame](http://sdformat.org/spec?ver=1.5&elem=collision#ode_fdir1).\
    \ \n\nBetter to leave it blank and just accept the Gazebo default.\n\n> 4) Can\
    \ I set physics parameters during the gazebo simulation (like the mu1, mu2 parameters)\n\
