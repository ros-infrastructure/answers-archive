  body_markdown: "You might want to check out HOG detector for OpenCV which tries\
    \ to detect standing pedestrians, although you're going to get a lot of false\
    \ positives and missed detections from it. Also, it seems they only have documentation\
    \ on the website for the [GPU implementation](http://docs.opencv.org/modules/gpu/doc/object_detection.html)\
    \ (i.e. using CUDA) and you'll have to look elsewhere for examples of the CPU\
    \ implementation. \n\nAnother possibility to check out is the OpenCV [face detector](http://docs.opencv.org/trunk/doc/py_tutorials/py_objdetect/py_face_detection/py_face_detection.html).\
    \ Some ROS packages that use this are [face_detector](http://wiki.ros.org/face_detector)\
    \ (uses stereo images though) and [pi_face_tracker](http://wiki.ros.org/pi_face_tracker?distro=groovy)\
    \ (for Groovy though).\n\nIn general, detecting people from a moving robot with\
    \ a monocular camera is still a very difficult and open problem. If your camera\
    \ is stationary then the problem can be simplified through background subtraction\
    \ but I don't have any references for that. \n\nFor help with using OpenCV in\
    \ ROS, checkout the [vision_opencv](http://wiki.ros.org/vision_opencv) package.\n\
    \nEdit: I uploaded my implementation of both of these in a ROS package on Github:\
    \ https://github.com/angusleigh/hog_haar_person_detection_ros\n"
