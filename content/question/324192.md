  body_markdown: "What do you mean you spawned different turtles using ROSSERVICE,\
    \ did you use something like this?\n\n    rosservice call /spawn 2 7 0.2 \"another_turtle\"\
    \n\nIn that case, every time you spawn a new turtle, you will be able to move\
    \ it independently publishing command velocities under the namespace of the new\
    \ turtles, in the example above it would be:\n\n    /another_turtle/cmd_vel\n\n\
    Therefore, you can move it by:\n\n    rostopic pub /another_turtle/cmd_vel geometry_msgs/Twist\
    \ \"linear:\n      x: 2.0\n      y: 0.0\n      z: 0.0\n    angular:\n      x:\
    \ 0.0\n      y: 0.0\n      z: 0.0\"\n\nThen, if you want to move and control all\
    \ the turtles to different waypoints, you need to write a program which:\n\n-\
    \ Checks where the turtles are.\n- Compute, for each turtle, a way to get to their\
    \ goal. \n- Follow their paths and coordinate their movements if necessary (your\
    \ planner may be able to do so already)"
