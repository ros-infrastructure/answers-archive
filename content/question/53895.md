  body_markdown: "The tutorial code is using the [ros parameter server](http://www.ros.org/wiki/roscpp/Overview/Parameter%20Server).\
    \  The parameter server stores different kinds of variables and makes them available\
    \ to running nodes.  \n\nTo load a yaml config file onto the parameter server,\
    \ you'd either load it with the [rosparam load xml tag](http://www.ros.org/wiki/roslaunch/XML/rosparam)\
    \ in a launch file or use the [rosparam command line program](http://www.ros.org/wiki/rosparam)."
