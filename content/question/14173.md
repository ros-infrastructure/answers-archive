  body_markdown: "Currently the model editor doesn't support inserting pure sensors.\
    \ I ticketed an [issue](https://bitbucket.org/osrf/gazebo/issues/2032/insert-sensors-in-model-editor)\
    \ for this. \n\nWhat you can do now is inserting a model which has a sensor, like\
    \ a depth camera is inserted in [this](http://gazebosim.org/tutorials?cat=guided_b&tut=guided_b3)\
    \ tutorial. For a ray sensor, you could insert the [hokuyo](https://bitbucket.org/osrf/gazebo_models/src/736aeb82196bf0800ee02cf1727391b6efbb6323/hokuyo/?at=default)\
    \ model for example. The downside is that you can't edit its properties.\n\nYou\
    \ could also do a combination of model editor + text editor. Create all the parts\
    \ you can with the model editor, and after the SDF is saved, text-edit that to\
    \ add a sensor."
