 Hi all,

I have been trying to use one launch file to call several nodes across different machines but I encountered difficulty when I want to include remote launch files (adding machine tag into every single node is simply impossible in my case). 

It is clear as shown in <a href="http://wiki.ros.org/roslaunch/XML">roslaunch/XML</a> and <a href="http://wiki.ros.org/roslaunch/XML/machine">roslaunch/machine</a> that by using the machine tag within a node tag, the corresponding node on a determined machine can be activated. But so far, I found little documentation as with launch files. Disappointedly I only found <a href="http://answers.ros.org/question/41413/how-to-include-a-launch-file-on-a-remote-machine-from-a-launch-file/">this question post</a> and <a href="http://answers.ros.org/question/81296/include-files-on-remote-machine-in-a-launch-file-groovy/">this one</a> with inconclusive answer or a big "NO". 
I wonder, then, how people solve the problem of calling remote launch files if they cannot even use machine tag to achieve that? If there is unfortunately no way to do so, then the machine tag directly contradicts the architecture philosophy of launch file design as shown <a href="http://wiki.ros.org/roslaunch/Tutorials/Roslaunch%20tips%20for%20larger%20projects">here</a>. 

Thus, please show me how you get around such problem. Thank you in advance!
