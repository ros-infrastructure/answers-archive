    @sparksmith answer is likely right.  If you need to use `openni2_launch` to get your Xtion to work at all, you could use [openni2_tracker](https://github.com/ros-drivers/openni2_tracker) instead.  The base repo actually doesn't do much (it seems due to licensing issues with NITE2), but github user @nxdefiant submitted a [pull request](https://github.com/ros-drivers/openni2_tracker/pull/3) that mostly provides the functionality of the original `openni_tracker`.

    The other solution would be to get your Asus to work with `openni_launch` and then use `openni_tracker`.  See my answer [here](http://answers.ros.org/question/109411/asus-xtion-problems-with-ubuntu-1204-running-ros-fuerte/#109831) for how you might do that.
