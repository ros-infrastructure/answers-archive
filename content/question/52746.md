  body_markdown: "I can\xB4t tell you why this doesn't work in this case, but as a\
    \ general remark: Depening on what you're trying to achieve I guess going the\
    \ way that was proposed in the other question could be a much better idea.\nWhat\
    \ you would usually want to do is to write some code for your conveyor that monitors\
    \ contacts and excerts forces on objects in touch. That way your conveyor stays\
    \ where it is, which makes a lot more sense in larger scenarios with multiple\
    \ conveyors. \nI have done similar stuff years ago [B21 ICIM Factory](http://www.youtube.com/watch?v=R4DqXzMDk00).\
    \ There we had palletized conveyors which meant i was setting up a rigid link\
    \ between the pallet and the conveyor until the pallet runs into the end of the\
    \ conveyor where the link would be destroyed and the next conveyor takes over.\
    \ So this is not a physical simulation, but it was working to model the factory\
    \ at the level we needed."
