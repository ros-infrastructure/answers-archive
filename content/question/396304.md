I can do:

    sync.registerCallback(std::bind(&Foo::callback, this, std::placeholders::_1, std::placeholders::_2));

This works as expected. However, if I have:

    template<class MessageT1, class MessageT2, class TS, class C>
    void registerCallbackForSync2(TS &timeSync, C &callback)
    {
         auto lambdaCallback = [callback](typename MessageT1::ConstSharedPtr msg1,
                                          typename MessageT2::ConstSharedPtr msg2) {
            beforeCallback<MessageT1, MessageT2>(msg1, msg2);
            callback(msg1, msg2);
            afterCallback<MessageT1, MessageT2>(msg1, msg2);
        };

        timeSync.registerCallback(lambdaCallback);
    }

    // Call with
    registerCallback(sync, std::bind(&Foo::callback, this, std::placeholders::_1, std::placeholders::_2));

I get a huge mess of errors about `.../message_filters/signal9.h:280:267: error: no matching function for call to ‘message_filters::Signal9<...` and `.../message_filters/signal9.h:264:14: note:   template argument deduction/substitution failed`, but I cannot see what is wrong.

I have almost identical code for overriding `create_subscription()` and its callback function which works perfectly. If I do `timeSync.registerCallback(callback);` that works fine too, so it's not just my templating.

I've read [this answer](https://answers.ros.org/question/308386/ros2-add-arguments-to-callback/?answer=308404#post-id-308404) and [this GitHub issue](https://github.com/ros2/rclcpp/issues/583), but it's not helping, and it seems to be a fixed issue since as I note above `create_subscription()` is fine.
