  body_markdown: "I figured it out:\n\nSince I was porting the code from ROS1, they\
    \ initiated their node like this:  \n\n    class OPEN_VRnode\n    {\n      public:\n\
    \        OPEN_VRnode(int rate);\n        ~OPEN_VRnode();\n        bool Init();\n\
    \        void Run();\n        void Shutdown();\n        bool setOriginCB(const\
    \ std::shared_ptr<std_srvs::srv::Empty::Request> req, std::shared_ptr<std_srvs::srv::Empty::Response>\
    \ res);\n        void set_feedback(const sensor_msgs::msg::JoyFeedback::ConstPtr\
    \ msg);\n        rclcpp::Node:: nh_;\n        VRInterface vr_;\n...\n\n    OPEN_VRnode::OPEN_VRnode(int\
    \ rate)\n      : loop_rate_(rate)\n      , nh_(\"open_vr_node\")\n      , vr_()\n\
    \      , world_offset_({0, 0, 0})\n      , world_yaw_(0)\n    {\n\nBut this resulted\
    \ in no `shared_ptr` being created, so then later in the code when I ran `rclcpp::spin_some(nh_.get_shared_from_this());`\
    \ there was no valid shared ptr to pass to spin_some.  \n  \nFixed the issue by\
    \ changing `nh_` to `nh_ptr_` and the type from `rclcpp::Node` to `rclcpp::Node::SharedPtr`\
    \ and then initializing it in the class constructor.\n\nFull code can be found\
    \ on my repository:  \nhttps://github.com/NU-Haptics-Lab/open_vr_ros/tree/ros2\
    \  \n"
