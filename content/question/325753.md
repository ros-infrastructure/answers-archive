    Quaternions represent rotations and cannot be observed directly. But it's possible to see how a quaternion affects, for example, a coordinate frame. So, to visualize a quaternion, you could publish [tf messages](https://docs.ros.org/melodic/api/geometry_msgs/html/msg/TransformStamped.html) with the quaternion values you have, and use [TF display](https://wiki.ros.org/rviz/DisplayTypes/TF) in RViz to see the result. A quaternion "in isolation" can be treated as a "quaternion with attached position" but with the position set to the origin or to any other fixed point in space.
