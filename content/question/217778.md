    `tf::StampedTransform` is derived from `tf::Transform` (see implementation of `tf::StampedTransform` [here](http://docs.ros.org/api/tf/html/c++/transform__datatypes_8h_source.html#l00081) and the docs of `tf::Transform` [here](http://docs.ros.org/api/tf/html/c++/classtf_1_1Transform.html)).

    `getRPY` is actually not a function of any of those clases, but of the `Matrix3x3` Type, which is a member of `tf::Transform` that you get via the `getBasis()` function. The docs of `Matrix3x3` can be found [here](http://docs.ros.org/api/tf/html/c++/classtf_1_1Matrix3x3.html).
