  body_markdown: "You can look at the pr2 description in the pr2_description package.\
    \ They have some urdf and xacro files for describing cameras. You'd want to use\
    \ the prosilica_gc2450 files for a single camera (the wge100 is for stereo I believe).\
    \ My camera configuration looks like this:\n\n     <gazebo reference=\"${name}_head\"\
    >\n    \t<sensor:camera name=\"${name}_sensor\">\n      \t\t<imageFormat>R8G8B8</imageFormat>\n\
    \      \t\t<imageSize>704 480</imageSize>\n      \t\t<hfov>45</hfov>\n      \t\
    \t<nearClip>0.1</nearClip>\n      \t\t<farClip>100</farClip>\n      \t\t<updateRate>20.0</updateRate>\n\
    \      \t\t<controller:gazebo_ros_prosilica name=\"${name}_controller\" plugin=\"\
    libgazebo_ros_prosilica.so\">\n        \t\t<alwaysOn>true</alwaysOn>\n       \
    \ \t\t<updateRate>20.0</updateRate>\n        \t\t<imageTopicName>/ptz/image_raw</imageTopicName>\n\
    \        \t\t<cameraInfoTopicName>/ptz/camera_info</cameraInfoTopicName>\n   \
    \     \t\t<pollServiceName>/ptz/request_image</pollServiceName>\n        \t\t\
    <frameName>${name}_head</frameName>\n        \t\t<CxPrime>1224.5</CxPrime>\n \
    \       \t\t<Cx>1224.5</Cx>\n        \t\t<Cy>1025.5</Cy>\n       \t\t\t<focal_length>2955</focal_length>\n\
    \        \t\t<distortion_k1>0.0</distortion_k1>\n        \t\t<distortion_k2>0.0</distortion_k2>\n\
    \        \t\t<distortion_k3>0.0</distortion_k3>\n        \t\t<distortion_t1>0.0</distortion_t1>\n\
    \        \t\t<distortion_t2>0.0</distortion_t2>\n        \t\t<interface:camera\
    \ name=\"${name}_iface\" />\n      \t\t</controller:gazebo_ros_prosilica>\n  \
    \  \t</sensor:camera>\n  \t</gazebo>\n\nAs far as making it move, that's a little\
    \ more complicated. If you're just looking to make it pan/tilt in place, that's\
    \ not so bad. But if you're looking to move it around on the robot, that's not\
    \ going to be as easy. \n\nIf you want to make a pan/tile camera, you could model\
    \ the camera much like the pr2's head, but with only a single camera. You can\
    \ see how they set up two joint controllers using the [pr2_controllers](http://ros.org/wiki/pr2_controllers)\
    \ stack to manipulate them. I wrote a teleop program, modeled after the pr2's\
    \ teleop node that publishes to my camera joint controllers. This enables me to\
    \ quickly adjust the camera as I see fit. \n\nIf you're trying to make the camera\
    \ change its position on the robot's frame, then you'd have to experiment with\
    \ some slider joints and some more joint controllers. "
