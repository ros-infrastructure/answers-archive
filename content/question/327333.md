    Jade has been EOL since May 2017 ([wiki/Distributions](http://wiki.ros.org/Distributions)), with the final package repository sync in September 2017 ([discourse announcement](https://discourse.ros.org/t/final-jade-sync-2017-09-03/2559)).

    > When was ros-jade removed? I feel like it was available in April of 2019.

    A breach of security of `build.ros.org` was detected around April/May ([discourse post](https://discourse.ros.org/t/security-issue-on-ros-build-farm/9342)), as a precaution, all packages for supported distributions have been rebuilt and as part of the cleanup, all packages of no-longer supported ROS releases (which would include Jade) have been moved to the [snapshot repository](http://wiki.ros.org/SnapshotRepository) ([discourse post](https://discourse.ros.org/t/security-issue-on-ros-build-farm/9342/8) by @nuclearsandwich ).

    If you still want to/need to use ROS Jade, you'll have to install it from the snapshot repositories. The linked wiki page explains how to set that up.
