    This is covered in detail in [this answer](http://answers.ros.org/question/36600/how-to-tell-remote-machines-not-to-start-separate-roscores-when-using-roslaunch-fuerte-regression/).

    Problem is ros_comm version together with actual shell variable.
    Updating ros_comm and correctly setting the env variable ROS_MASTER_URI corrects the problem.
