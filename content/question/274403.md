  body_markdown: "Hi @rozoalex,\n\nThe error is \"probably\" on your `CMakeLists.txt`,\
    \ but since it wasn't provided, I'll show you the steps to `make custom action`\
    \ from zero (which can be useful for more people), as [shown in this video](https://youtu.be/_YckBpMna7A).\n\
    \nSince the name of your package is `turtlebot3_console_controller` and the action\
    \ name is `Motor.action`, we are going to use the same names for simplicity.\n\
    \n1. Create the Catkin Workspace:\n---\n\tmkdir ~/catkin_ws/src/ -p\n\tcd ~/catkin_ws/src/\n\
    \tcatkin_init_workspace\n\n2. Create your package named `turtlebot3_console_controller`\
    \ that depends on the packages `actionlib_msgs` and `std_msgs`:\n---\n\tcd ~/catkin_ws/src/\n\
    \tcatkin_create_pkg turtlebot3_console_controller actionlib_msgs std_msgs\n\n\
    3. Create the `Motor.action` on `turtlebot3_console_controller/action`:\n---\n\
    \tcd ~/catkin_ws/src/\n\tmkdir -p turtlebot3_console_controller/action\n\ttouch\
    \ turtlebot3_console_controller/action/Motor.action\n\n4. Add to `Motor.action`\
    \ the content provided on the question:\n---\n\t\n\t# This is an action definition\
    \ file, which has three parts: the goal\n\t# the result, and the feedback.\n\t\
    # Part 1: the goal.\n\t#\n\t# The angle in degree the robot to turn, sent by client\
    \ main\n\tfloat64 angle\n\t---\n\t# Part 2: the result, sent by action server\
    \ unpon completion\n\t#\n\t# How much time used\n\tduration time_elapsed\n\t#\
    \ How many updates thrown in total\n\tuint32 updates_n\n\t---\n\t# Part 3: the\
    \ feedback,to be sent periodically by server\n\t#\n\t# The amount of time elapsed\
    \ from the start\n\tduration time_elapsed\n\n5. Change `add_action_files` and\
    \ `generate_messages` from `turtlebot3_console_controller/CMakeLists.txt` to be\
    \ able to compile the action file. At the end, the `CMakeLists.txt` will be like\
    \ we have below:\n---\n\n\tcmake_minimum_required(VERSION 2.8.3)\n\tproject(turtlebot3_console_controller)\n\
    \n\tfind_package(catkin REQUIRED COMPONENTS\n\t  actionlib_msgs\n\t  std_msgs\n\
    \t)\n\n\tadd_action_files(\n\t   FILES\n\t   Motor.action\n\t)\n\n\tgenerate_messages(\n\
    \t   DEPENDENCIES\n\t   actionlib_msgs#   std_msgs\n\t)\n\n\tcatkin_package(\n\
    \t#  INCLUDE_DIRS include\n\t#  LIBRARIES turtlebot3_console_controller\n\t# \
    \ CATKIN_DEPENDS actionlib_msgs std_msgs\n\t#  DEPENDS system_lib\n\t)\n\n\tinclude_directories(\n\
    \t  ${catkin_INCLUDE_DIRS}\n\t)\n\n6. Compile your package:\n---\n\tcd ~/catkin_ws/src/\n\
    \tcatkin_make\n\nOk, now your custom action should be compiled.\n\nTo confirm\
    \ it was compiled, you can create a test file named `node.py` that just imports\
    \ your custom action by following the steps below:\n\n7. Create your test file\
    \ named `node.py`:\n---\n\tcd ~/catkin_ws/src/\n\ttouch turtlebot3_console_controller/src/node.py\n\
    \n8. Add the content below to `node.py`:\n---\n\t#! /usr/bin/env python\n\n\t\
    from turtlebot3_console_controller.msg import MotorGoal, MotorResult, MotorFeedback\n\
    \n\tprint 'Ok, it worked!!!'\n\n9. Run your `node.py` to confirm your custom action\
    \ was compiled without any problem.\n---\n\n\trosrun turtlebot3_console_controller\
    \ node.py\n\nAfter running `node.py` you should seee the message \"`Ok, it worked!!!`\"\
    .\n\nIn the [video](https://youtu.be/_YckBpMna7A) mentioned at the beginning we\
    \ just follow the steps described here.\n\nHope it helps."
