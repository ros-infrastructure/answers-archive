It would be very useful to be able to apply a feedforward torque in addition to PID control:<BR>
torque = kp x positionerror + kv x velocityerror + ki x integratederror + torqueff<BR>
torqueff could be a constant or have a trajectory, as does desired position and velocity.

I see in the list of robot\_mechanism\_controllers <BR>
http://www.ros.org/wiki/robot\_mechanism\_controllers<BR>
JointEffortController mode, which supports torque control but does not include PID control, and<BR>
JointTrajectoryActionController and JointPostionController which support PID control but not feedforward torques.<BR>
Is there a controller that supports both?

I see there used to be an ArmDynamicsController that looks like it had the right properties.<BR>
Google arm\_dynamics\_controller.cpp
