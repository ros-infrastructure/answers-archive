    Contributors: @PeteBlackerThe3rd , @mgruhler

    I wrote an email to Sick and I asked for the connections with ROS.
    They said s300 doesn't have ROS support from Sick. But if you want to use the raw data with ROS:

     - You **CAN** only use the RS422 output with a proper converter ([Isolated Converter](http://www.vscom.de/usb-com-plus-iso.html) - [CircuitBoard Converter](https://www.digikey.com/product-detail/en/ftdi-future-technology-devices-international-ltd/USB-COM422-PLUS1/768-1035-ND/2139297))
     - You **CAN'T** use the configuration port with using the [RS232 to USB cable](https://www.sick.com/ag/en/dsl-8u04g02m025km1/p/p314713). This is just for configuration.
     - You **CAN'T** use the [EFI](https://www.sick.com/media/pdf/4/64/864/IM0032864.PDF) interface to acquire raw data. This is only for Flexi Soft Controllers.


    Sick has an official ROS package named [sick_safetyscanners](http://wiki.ros.org/sick_safetyscanners) for [microscan3](https://www.sick.com/ag/en/opto-electronic-protective-devices/safety-laser-scanners/microscan3-core/c/g295658) series safety laser scanners.

    After I tried the s300 with the converter, I'll update the answer.

    Thank you,

    Ermanas.
