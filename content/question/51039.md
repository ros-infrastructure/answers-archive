  body_markdown: |-
    Stage generates simulated time, which begins at zero (Jan. 1, 1970).

    I don't know how to change that.

    If you run another node in the same ROS graph with [/use_sim_time](http://www.ros.org/wiki/Clock#Using_Simulation_Time_from_the_.2BAC8-clock_Topic) set, it should generate compatible timestamps with the messages stage publishes.
