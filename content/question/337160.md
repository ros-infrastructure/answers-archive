  body_markdown: "There are several ways to install a ROS package, like rosbag2, and\
    \ it depends on your platform.\nSee the [ROS 2 installation instructions](https://index.ros.org/doc/ros2/Installation/)\
    \ for details regarding your platform.\n\nAssuming you are using Linux (Ubuntu)\
    \ and ROS Eloquent, the easiest way is to follow the [binary installation instructions](https://index.ros.org/doc/ros2/Installation/Eloquent/Linux-Install-Debians/)\
    \ and install rosbag2 with apt (replacing `eloquent` with the ROS distro name\
    \ you are using.):\n\n    sudo apt install ros-eloquent-rosbag2\n\nIf you want\
    \ to build rosbag2 from source. There are two options: overlay an existing ROS\
    \ installation or [build everything from source](https://index.ros.org/doc/ros2/Installation/Eloquent/Linux-Development-Setup/).\
    \ For creating an overlay workspace, I recommend checking out the [Creating a\
    \ Workspace](https://index.ros.org/doc/ros2/Tutorials/Workspace/Creating-A-Workspace/)\
    \ tutorial for details.\nBased on the error you got, I guess you need install\
    \ the `test_msgs` dependency (again, replacing `eloquent` with the ROS distro\
    \ you are using):\n        \n    sudo apt install ros-eloquent-test-msgs\n\nIt\
    \ sounds like you're looking for the overlay option, where you don't have to build\
    \ everything from source."
