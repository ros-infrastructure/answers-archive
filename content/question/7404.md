    There is dart support on OSX. You need to add an additional homebrew tap:

    <pre><code>
    brew tap dartsim/dart
    brew install dartsim --core-only
    </code></pre>

    There is not yet a `--with-dartsim` option for gazebo due to some [issues with homebrew](https://github.com/Homebrew/homebrew/issues/26179#issuecomment-36323938). If you install dartsim before gazebo, then gazebo will find it.
