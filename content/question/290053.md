https://frankaemika.github.io/docs/ros_introduction.html
The gripper Operation franka_gripper::HomingAction() is working with:
     
     actionlib::SimpleActionClient<franka_gripper::HomingAction> ac("franka_gripper/homing", true);
     ROS_INFO("Waiting for action server to start.");
     bool success=ac.isServerConnected(); //will wait for infinite time
     if (success)
       {ROS_INFO("Verbindung hergestellt");}
     ac.waitForServer(); 
     ROS_INFO("Action server started, sending goal.");
     franka_gripper::HomingGoal goal;
     ac.sendGoal(goal);

> ac.sendGoal(width, speed);

which is not working. Analogously to the tutorial (http://wiki.ros.org/actionlib_tutorials/Tutorials/SimpleActionClient) I used goal.order= in different variation like 

> goal.order {width, speed};
