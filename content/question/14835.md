    Some good steps would be:

    1. Go through several Gazebo [tutorials](http://gazebosim.org/tutorials). There is an ever growing number of them, so it might be hard to know where to start from. A good starting point could be the [beginner](http://gazebosim.org/tutorials?cat=guided_b&tut=guided_b1) guided tutorials and then continue to the [intermediate](http://gazebosim.org/tutorials?cat=guided_i&tut=guided_i1) ones.

    1. If you'll need to model the robot from scratch, be sure to check a few of the [build a robot](http://gazebosim.org/tutorials?cat=build_robot) tutorials, which go into more detail than the intermediate ones.

    1. If you'll need to control the robot, be sure to check the [write a plugin](http://gazebosim.org/tutorials?cat=write_plugin) tutorials. You might be specially interested in "model plugins".

    1. If you'll be using ROS, go through the [connect to ROS](http://gazebosim.org/tutorials?cat=connect_ros) ones.

    1. Finally, once you've got the general ideas and want to get specific about humanoids, it's a good idea to look at existing projects, so you can see what approaches were taken and how the models were tuned and controlled. One example is the [Atlas](https://bitbucket.org/osrf/drcsim/src/194be8500fef81593f79607a21ee2badd9700a0e/atlas_description/?at=default) robot used in DRCSim, but you can find several others if you search for them.

    1. Oh and of course, be sure to ask questions here if you ever feel stuck ;) Have fun!
