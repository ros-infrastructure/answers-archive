    I ran into the same issue attempting to install ros-indigo-gazebo-ros: I'd previously been working through the Gazebo tutorials and had installed Gazebo 4, per the instructions. Then came to realize that Indigo needs Gazebo 2, as explained [here](http://wiki.ros.org/indigo/Installation/Ubuntu). As a previous post mentioned, you need to remove Gazebo 4 and install Gazebo 2:

        sudo apt-get remove gazebo4
        sudo apt-get install libsdformat1
        sudo apt-get install gazebo2
    Not sure if the second step was actually necessary; I was just chasing the dependency warnings. Hope that helps.

    \ It requires libsdformat-dev (and therefore libsdformat1) that has version >=1.4.11-1\
    \ but <2.0.0 which is *almost* unable to satisfy. However I found those versions\
    \ of those dependencies that perfectly matches and allow you to install gazebo2.\n\
    \ \nhttps://launchpad.net/ubuntu/trusty/amd64/libsdformat1/1.4.11-1ubuntu0.1\n\
    \nhttps://launchpad.net/ubuntu/trusty/amd64/libsdformat-dev/1.4.11-1ubuntu0.1\n\
    \nHowever remember to remove the existing updated versions of those libraries\
    \ before installing packages above:\n\n    sudo apt-get remove libsdformat-dev\n\
    \    sudo apt-get remove libsdformat1\n\nOtherwise Ubuntu Software Center would\
    \ tell you about dependency problems and won't allow you to install.\n\nAfter\
    \ installing the 2 libs above you can now install gazebo2 which is supposed to\
    \ work best with ROS indigo.\n\n    sudo apt-get install gazebo2\n    sudo apt-get\
