    The tutorial you referenced is for Gazebo versions 6.0+. Gazebo 6 will be released in the end of July 2015.

    Until then, the most convenient way to edit an existing model is to make changes directly to the SDF file and insert the model again into the scene to see the changes, as explained in [this](http://gazebosim.org/tutorials?tut=build_robot&cat=build_robot) tutorial.

    An alternative is to build Gazebo [from source](http://gazebosim.org/tutorials?tut=install_from_source&cat=install) (with `hg up default`) and use the Model Editor from the tutorial you referenced, but since you'd be using our development branch, be aware that there might be unknown bugs.
