  body_markdown: "There are no spaces in your data which makes it an invalid YAML.\
    \ I am [quoting from the ROS 2 (Foxy) documentation](https://docs.ros.org/en/foxy/Tutorials/Beginner-CLI-Tools/Understanding-ROS2-Topics/Understanding-ROS2-Topics.html#ros2-topic-pub):\n\
    \n> It\u2019s important to note that this\n> argument needs to be input in YAML\n\
    > syntax.\n\n# ROS 2\nWe can use the following command in ROS 2:\n\n    ravi@dell:~$\
    \ ros2 topic pub --once /topic geometry_msgs/msg/Pose \"{position: {x: 0.2, y:\
    \ 0.1, z: 0.3}, orientation: {x: 0.0, y: 0.0, z: 0.0, w: 1.0}}\"\n    publisher:\
    \ beginning loop\n    publishing #1: geometry_msgs.msg.Pose(position=geometry_msgs.msg.Point(x=0.2,\
    \ y=0.1, z=0.3), orientation=geometry_msgs.msg.Quaternion(x=0.0, y=0.0, z=0.0,\
    \ w=1.0))\n\n# ROS 1\nAlthough the question uses ROS 2 commands, it is tagged\
    \ with ROS 1, i.e., noetic. Therefore, below is the equivalent ROS 1 command:\n\
    \n    ravi@dell:~$ rostopic pub --once /topic geometry_msgs/Pose \"{position:\
    \ {x: 0.2, y: 0.1, z: 0.3}, orientation: {x: 0.0, y: 0.0, z: 0.0, w: 1.0}}\"\n\
    \    publishing and latching message for 3.0 seconds\n\nFeel free to check the\
    \ [ROS 1 documentation.](http://wiki.ros.org/rostopic#rostopic_pub)\n"
