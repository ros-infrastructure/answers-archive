  body_markdown: "The easiest way would probably be just to forward rostopic echo\
    \ output with the -p flag to some output file.\n\nLets say the name of your \"\
    geometry_msgs/TransformStamped\" topic is \"/turtlebot/stamped_transform\". Then\
    \ entering the command: \n\n$` rostopic echo -p /turtlebot/stamped_transform/transform/translation\
    \ > xyz_output.csv` \n\nwill produce a text file xyz_output.csv with the data\
    \ formated like the example below.\n\n    %time,field.x,field.y,field.z\n    1531725938918082952,-354.547943115,-41.9697914124,-33.9759483337\n\
    \    1531725939051723003,-354.530578613,-41.9656219482,-33.9720916748\n    1531725939181190967,-354.52633667,-41.9511375427,-33.9718017578\n\
    \n\nYou can extract this data straight from the bag files as well. As described\
    \ in the answers for [this](https://answers.ros.org/question/9102/how-to-extract-data-from-bag/?answer=13122#post-id-13122)\
    \ question. \n\n$ `rostopic echo -b file.bag -p /turtlebot/stamped_transform/transform/translation\
    \ > data.csv`\n\nThe -p flag for rostopic will format the data for csv, you can\
    \ read more about the different flags in the ros wiki page.\n\n[http://wiki.ros.org/rostopic#rostopic_echo](http://wiki.ros.org/rostopic#rostopic_echo)\n\
    \n$` rostopic echo -p /turtlebot/stamped_transform/transform/translation/x > x_output.csv`\
    \ \n\nWill output:\n\n    %time,field\n    1531729453445930957,-354.554626465\n\
    \    1531729453510648012,-354.544036865\n    1531729453645477056,-354.537231445"
