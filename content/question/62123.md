    Check out the wiki page for [pcl_ros](http://www.ros.org/wiki/pcl_ros).  In particular, it depends on what ROS message type you'd like to publish.  If your PCD contains generic pointCloud data, then it looks like you could probably use `pcd_to_pointcloud`, which publises ROS [PointCloud2](http://www.ros.org/doc/api/sensor_msgs/html/msg/PointCloud2.html) messages:

         $ rosrun pcl_ros pcd_to_pointcloud <file.pcd> [ <interval> ]
