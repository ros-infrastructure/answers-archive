  body_markdown: "In case someone finds this useful, here is how I solved it:\n\n\
    Convert the sensor msg to a PointCloud<PointXYZ>, this removes all fields except\
    \ xyz, then convert back to a sensor msg.\n\nAn example:\n\n  \n\n      sensor_msgs::PointCloud2\
    \ msg; // contains x,y,z and other fields such as intensity\n      pcl::PointCloud<pcl::PointXYZ>\
    \ tmp;\n      pcl::fromROSMsg( msg, tmp );\n      // Here you could perform operations\
    \ on the point cloud\n      pcl::toROSMsg( tmp, msg );"

Thus, I need to erase the data points themselves.

What would be the best way to achieve this? Is there even a function like pcl::removeField() that I failed to see?
