  body_markdown: "1. If Your robot models and names are same, you need to cover in\
    \ a namespace each of them. As far as I know, There is no tutorial exists for\
    \ converting any robot's packege to namespaced one in `indigo`. I'll write later.\
    \ But You can start by following [this](http://answers.ros.org/question/236625/how-do-i-control-2-pr2-robots-in-gazebo-at-the-same-time/?answer=236631#post-id-236631)\
    \ answer.\n\n2. If their models aren't same, Directly start from this 2nd section.\
    \ *(But I don't think so. Because everyone is naming topics  by same way.)* Just\
    \ publish to their own velocity topics simultaneously. or You can use their own\
    \ `move_base` topics to do it.\n\nAfter following stages in the link above, You\
    \ must create launch files before section 2 above. You need one gazebo process,\
    \ sample launch file, `world.launch`;\n\n    <launch>\n      <arg name=\"world\"\
    \  default=\"milvus_repo\"/>  \n      <arg name=\"world_path\" default=\"$(find\
    \ mrp2_gazebo)/worlds/\"/>             \n      <arg name=\"gui\" default=\"true\"\
    />\n      <arg name=\"debug\" default=\"false\"/>\n      <arg name=\"paused\"\
    \ default=\"false\"/>\n      <env name=\"GAZEBO_MODEL_PATH\" value=\"$(find mrp2_gazebo)/models:$(optenv\
    \ GAZEBO_MODEL_PATH)\" />\n\n      <include file=\"$(find gazebo_ros)/launch/empty_world.launch\"\
    >\n        <arg name=\"world_name\" value=\"$(arg world_path)$(arg world).world\"\
    />\n        <arg name=\"gui\" value=\"$(arg gui)\"/>\n        <arg name=\"debug\"\
    \ value=\"$(arg debug)\"/>\n        <arg name=\"paused\" value=\"$(arg paused)\"\
    />\n      </include>\n    </launch>\n\nThen start one of the robots with its namespace\
    \ via `robot1.launch`;\n\n    <launch>\n    \t<arg name=\"robot_name\" default=\"\
    robot1\" />\n    \t<group ns=\"$(arg robot_name)\">\n    \t\t<include file=\"\
    $(find mrp2_gazebo)/launch/include/single_mrp2.launch\" >\n    \t\t\t<arg name=\"\
    init_pose\" value=\"-x 3.0 -y 0.0 -z 0.0 -R 0.0 -P 0.0 -Y 0.0\" />\n    \t\t\t\
    <arg name=\"robot_name\" value=\"$(arg robot_name)\" />\n    \t\t</include>\n\
    \    \t\t<include file=\"$(find mrp2_control)/launch/controls.launch\" >\n   \
    \ \t\t\t<arg name=\"robot_name\" value=\"$(arg robot_name)\" />\n    \t\t\t<arg\
    \ name=\"sim\" value=\"true\" />\n    \t\t</include>\n    \t</group>\n    </launch>\n\
    \n`single_mrp2.launch` contains `mrp2.launch` and some teleop and diagnostic launches.\
    \ If you have a running robot without namespace, you probably have these ones.\
    \ (And if you will use these ones in first try, some remapping operations may\
    \ be needed in inside of them). `mrp2.launch` file:\n\n    <launch>\n    \t<arg\
    \ name=\"robot\"  default=\"full\"/>\n    \t<arg name=\"gzpose\" default=\"\"\
    />\n    \t<arg name=\"robot_name\" default=\"robot1\"/>\n    \t<!-- PARSE ROBOT\
    \ MODEL -->\n    \t<include file=\"$(find mrp2_description)/launch/description.launch\"\
    \ >\n    \t\t<arg name=\"robot\" value=\"$(arg robot)\"/>\n    \t\t<arg name=\"\
    robot_name\" value=\"$(arg robot_name)\"/>\n    \t</include>\n    \t<!-- SPAWN\
    \ IN GAZEBO -->\n    \t<node pkg=\"gazebo_ros\" type=\"spawn_model\" name=\"$(anon\
    \ spawn_model)\"\n    \t\t  args=\"-urdf -param robot_description $(arg gzpose)\
    \ -model mrp2_$(arg robot_name)\" />\n    \t<remap from=\"odom\" to=\"$(arg robot_name)/odom\"\
    />\n    </launch>\n\nFinally, here is the description file, also be sure the joints\
    \ and frames are different, (You must edit your urdf files for this) `description.launch`;\n\
    \n    <launch>\n    \t<arg name=\"config\" default=\"base\" />\n    \t<arg name=\"\
    robot\" default=\"full\" />\n    \t<arg name=\"robot_name\" default=\"robot1\"\
    />\n    \t<param name=\"robot_description\" command=\"$(find xacro)/xacro.py '$(find\
    \ mrp2_description)/robots/mrp2_$(arg robot).urdf.xacro' robot_name:=$(arg robot_name)\"\
    \ />\n    \t<node name=\"robot_state_publisher_$(arg robot_name)\" pkg=\"robot_state_publisher\"\
    \ type=\"robot_state_publisher\">\n    \t\t<param name=\"use_tf_static\" value=\"\
    true\"/>\n    \t\t<remap from=\"/joint_states\" to=\"/$(arg robot_name)/joint_states\"\
    \ />\n    \t</node>\n    </launch>\n\nAfter following steps carefully, and after\
    \ remapping some topics like  this: `<remap from=\"odom\" to=\"$(arg robot_name)/odom\"\
    />`, Do same steps for each robot. (Just change robot name from `robot1` to `robot2`\
    \ or may be `optimus_prime`) Your robots will move simultaneously."
