When using 3rd party client libraries in ros2, is there any method, either existing or planned, to allow post-install generation of messages (so as to not require building everything from source)? I.e. I have geometry_msgs installed from binary, and it has installed both .msg files and python and c++ message files. Now if I want to use rcl_dotnet, it would be nice to be able to be able to generate C# msg files, rather than having to rebuild from source. I'm not an expert in build systems and I'm unsure how difficult something like this would be to implement. I do think it would be fitting with the idea of ROS2 trying to be more friendly to 3rd party libraries and allow for simpler workflow when using client libraries other than the official C++ and Python clients.
