  body_markdown: "I actually solved the problem, well technically the problem wasn't\
    \ a recognition problem. The problem was the environment variables of ROS on Windows\
    \ 10 does not get updated for the new terminal windows.\n\nWell this is dumb I\
    \ must say, but it is what it is. \n\nSo if you made a mistake like me and decided\
    \ to use ROS on Windows 10, the procedure below is what you must do to work properly.\n\
    \nSo, after using catkin_make you need to call setup.bat which is in the \\devel\
    \ folder but, BEFORE calling setup.bat you must open several terminal windows\
    \ to use later or you can only use current terminal for the catkin package operations.\
    \ \n\nYou can check if the the environment variable is updated by using command:\n\
    \necho %ROS_PACKAGE_PATH% \n\nAnd you will see that in the new terminal windows\
    \ It will only print out:\n\nC:\\opt\\ros\\melodic\\x64\\share\n\nwhile in the\
    \ previously open terminals it will print out:\n\nC:/Users/<your user name>/<your\
    \ catkin folder>/src;C:\\opt\\ros\\melodic\\x64\\share"
