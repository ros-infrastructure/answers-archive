  body_markdown: "Parameters are per node in ROS 2. There is no a global parameter\
    \ server like ROS 1. It is possible to set a param on a node with `ros2 param\
    \ set`\n\n    $ ros2 run demo_nodes_cpp parameter_blackboard &\n    ...\n    $\
    \ ros2 param set /parameter_blackboard foo bar\n    Set parameter successful\n\
    \    $ ros2 param list /parameter_blackboard\n      foo\n      use_sim_time\n\n\
    \nIf you'd like to set a parameter on all running nodes, you'll need to enumerate\
    \ them and set the parameter on each one. If you would like to set a parameter\
    \ on a lot of nodes that you're launching, the parameter [should be passed into\
    \ each `launch_ros.actions.Node`](https://github.com/ros2/launch_ros/blob/c86ee0b7c74af84c3b54eebede1501b7735431df/launch_ros/launch_ros/actions/node.py#L61).\n\
    \n    import launch\n    import launch_ros\n    \n    \n    def generate_launch_description():\n\
    \        use_sim_time = launch.substitutions.LaunchConfiguration('use_sim_time',\
    \ default=False)\n    \n        return launch.LaunchDescription(\n           \
    \ [\n                launch_ros.actions.Node(\n                    package='demo_nodes_cpp',\
    \ node_executable='talker',\n                    node_name='talker',\n       \
    \             parameters=[{'use_sim_time': use_sim_time}]),\n                launch_ros.actions.Node(\n\
    \                    package='demo_nodes_cpp', node_executable='listener',\n \
    \                   node_name='listener',\n                    parameters=[{'use_sim_time':\
    \ use_sim_time}]),\n            ])\n\nI used a `LaunchConfiguration` in this example.\
    \ You can give it a value on the command line\n\n    $ ros2 launch example_launch.py\
    \ use_sim_time:=True\n    ...\n    $ ros2 param get /listener use_sim_time\n \
    \   Boolean value is: True\n\n"
