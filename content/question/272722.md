    \ for [muxing](http://wiki.ros.org/yocs_cmd_vel_mux) the navigation commands.\
    \ If you really are supposed to be publishing to the `/mobile_base/commands/velocity`\
    \ topic then please update your question with the results of `rostopic list`.\
    \ \n\nAs a side note, please take a look at the [environment variables page on\
    \ the wiki](http://wiki.ros.org/ROS/EnvironmentVariables). If you're going to\
    \ be using an IP  instead of a host name then you should use `ROS_IP` *not* `ROS_HOSTNAME`.\
