  body_markdown: |-
    Many parameters in `move_base` as well as the `costmap`s can be configured using `dynamic_reconfigure`. I cannot guarantee that all you need are there, but most should be.

    You can use the `rqt_reconfigure` [(wiki)](http://wiki.ros.org/rqt_reconfigure) for a GUI solution to changing the parameter on the fly. Or you need to implement a `dynamic_reconfigure_client` [in C++ (pretty much undocumented)](https://github.com/ros/dynamic_reconfigure/pull/78/files), wherever you need it.
