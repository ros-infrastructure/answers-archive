    The first result in Google for `DiffDriveBaseController` leads me to [fetchrobotics/robot_controllers](https://github.com/fetchrobotics/robot_controllers).

    This repository contains the source for the [robot_controllers::DiffDriveBaseController](https://github.com/fetchrobotics/robot_controllers/blob/2cab89f872f60712e80d8ed9d64129104738df7a/robot_controllers/src/diff_drive_base.cpp) class, which, as part of its initialisation, reads in a `publish_tf` ROS parameter ([here](https://github.com/fetchrobotics/robot_controllers/blob/2cab89f872f60712e80d8ed9d64129104738df7a/robot_controllers/src/diff_drive_base.cpp#L98)).

    There doesn't appear to be any documentation for this controller (the [wiki page](http://wiki.ros.org/robot_controllers) actually points to the API documentation, which doesn't mention any of this), so this is the best I can do.

    If this is not sufficient, I would suggest to ask Fetch about this. They should know.
