  body_markdown: "Assuming you are looking for C++ solution, here is what the Wiki\
    \ page on [Callbacks and Spinning](http://wiki.ros.org/roscpp/Overview/Callbacks%20and%20Spinning)\
    \ says:\n\n> roscpp does not try to specify a\n> threading model for your application.\n\
    > This means that while roscpp may use\n> threads behind the scenes to do\n> network\
    \ management, scheduling etc.,\n> it will never expose its threads to\n> your\
    \ application. roscpp does,\n> however, allow your callbacks to be\n> called from\
    \ any number of threads if\n> that's what you want.\n\nPlease also see [this question\
    \ with answers](http://answers.ros.org/question/10328/multiple-threads-in-single-ros-node/).\n\
    \nIn short: you can choose any threading library you like; ROS nodes and callbacks\
    \ are thread-safe. However, to avoid extra dependencies it is a good idea to use\
    \ Boost threads (ROS utilises Boost for many internal components).\n\nHere are\
    \ [the docs and examples](http://www.boost.org/doc/libs/1_54_0/doc/html/thread/thread_management.html)\
    \ for Boost threads. Also, if c++11 compiler is available then you can try [std::thread](hhttp://en.cppreference.com/w/cpp/thread/thread/join#Example).\
    \ Or you even can use [POSIX Threads](https://en.wikipedia.org/wiki/POSIX_Threads#Example).\n\
    \nEDIT:\n\nThe following example uses Boost threads with ROS. It publishes empty\
    \ messages to two topics with different rates, which you can easily check with\
    \ `rostopic hz <topic_name>`.\n\n    #include <ros/ros.h>\n    #include <std_msgs/Empty.h>\n\
    \    #include <boost/thread/thread.hpp>\n    \n    void do_stuff(int* publish_rate)\n\
    \    {\n      ros::NodeHandlePtr node = boost::make_shared<ros::NodeHandle>();\n\
    \      ros::Publisher pub_b = node->advertise<std_msgs::Empty>(\"topic_b\", 10);\n\
    \    \n      ros::Rate loop_rate(*publish_rate);\n      while (ros::ok())\n  \
    \    {\n        std_msgs::Empty msg;\n        pub_b.publish(msg);\n        loop_rate.sleep();\n\
    \      }\n    }\n    \n    int main(int argc, char** argv)\n    {\n      int rate_b\
    \ = 1; // 1 Hz\n    \n      ros::init(argc, argv, \"mt_node\");\n    \n      //\
    \ spawn another thread\n      boost::thread thread_b(do_stuff, &rate_b);\n   \
    \ \n      ros::NodeHandlePtr node = boost::make_shared<ros::NodeHandle>();\n \
    \     ros::Publisher pub_a = node->advertise<std_msgs::Empty>(\"topic_a\", 10);\n\
    \    \n      ros::Rate loop_rate(10); // 10 Hz\n      while (ros::ok())\n    \
    \  {\n        std_msgs::Empty msg;\n        pub_a.publish(msg);\n        loop_rate.sleep();\n\
    \    \n        // process any incoming messages in this thread\n        ros::spinOnce();\n\
    \      }\n    \n      // wait the second thread to finish\n      thread_b.join();\n\
    \    \n      return 0;\n    }"
