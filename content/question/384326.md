  body_markdown: "All dynamically reconfigurable parameters through rqt can also be\
    \ listed and updated through python API of dynamic_reconfigure package a simple\
    \ tutorial can be found in the link below\n\nhttp://wiki.ros.org/hokuyo_node/Tutorials/UsingDynparamToChangeHokuyoLaserParameters#PythonAPI\n\
    \nYou simply get and set desired parameters as follows.\n\n    import dynamic_reconfigure.client\n\
    \n    client = dynamic_reconfigure.client.Client(<node_to_reconfigure>, timeout\
    \ = 10)\n    parameters = client.get_configuration()\n    params = { 'my_string_parameter'\
    \ : 'value', 'my_int_parameter' : 5 }\n    config = client.update_configuration(params)\n\
    \n    \n\n"
