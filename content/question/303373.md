  body_markdown: "I finally found and answer to this on the [Github Issues](https://github.com/ros/ros_comm/issues/380)\n\
    Here is an example code of a callback receiving data from 3 topics simultaneously\
    \ and unsubscribing after 40 messages are received:\n\n    #!/usr/bin/env python\n\
    \    import message_filters\n    import rospy\n    from sensor_msgs.msg import\
    \ Image, LaserScan, PointCloud2\n    \n    \n    def image_cb(depth_img, intensity_img,\
    \ cloud):\n        global subs, counter\n        rospy.loginfo_throttle(1, \"\
    Receiving data\")\n        counter += 1\n        if counter > 40:\n          \
    \  rospy.loginfo(\"100 samples, trying to unsubscribe\")\n            [sub.sub.unregister()\
    \ for sub in subs]\n    \n    counter = 0\n    rospy.init_node(\"test\")\n   \
    \ depth_sub = message_filters.Subscriber(\"/pico_flexx_rear/image_depth\", Image)\n\
    \    intensity_sub = message_filters.Subscriber(\"/pico_flexx_rear/image_mono16\"\
    ,\n                                               Image)\n    cloud_sub = message_filters.Subscriber(\"\
    /pico_flexx_rear/points\",\n                                           PointCloud2)\n\
    \    subs = [depth_sub, intensity_sub, cloud_sub]\n    ts = message_filters.ApproximateTimeSynchronizer(subs,\
    \ 10, 1)\n    ts.registerCallback(image_cb)\n    rospy.spin()\n\nAs you see here,\
    \ one could just iterate over the message_filters.Subscriber variable and call\
    \ the  message_filters.Subscriber.sub.unregister() function in order to unsubscribe.\n\
    \n"
