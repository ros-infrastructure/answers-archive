  body_markdown: "Instead of manually terminating the node, I found out that actually\
    \ the state machine did not terminate automatically (as it should) because there\
    \ was a blocked spin. \n\nThe solution I found was to add the \"Grip\" state in\
    \ a MultiThreadedExecutor, using a ReentrantCallback, and then spin_once:\n\n\
    In the state:\n\n    self.executor = rclpy.executors.MultiThreadedExecutor()\n\
    \    self.executor.add_node(self.grasp_node)\n    self.executor.spin_once(self.grasp_node)\n\
    \nthe subscriber:\n\n    self.__node.create_subscription(Bool, 'vacuum_pump_center',\
    \ self.__control_center_vacuum_pump, 1, callback_group=ReentrantCallbackGroup())\n\
    \nThen I destroyed the node and rclpy.shutdown()\n\nThis achieved the desired\
    \ result: the state machine spins once, it goes through the callback, and then\
    \ terminates."
