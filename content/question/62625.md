    \  If using a `catkin` workspace, and `catkin_make` to build, then the C++ message\
    \ definition should be in *~/Dropbox/RoboticsResearch/Bablumer/trunk/catkin_ws/devel/include/beginner_tutorials*,\
    \ and the Python message definition should be exactly where you found it.  This\
    \ isn't really in inconvenience thanks to the internal workings of `catkin_make`,\
    \ and the `setup.bash` files that are provided in your workspace.  If you `#include`\
    \ the C++ file in a piece of source code, as long as the `package.xml` and `CMakeLists.txt`\
    \ files are correct, then catkin will know how to find that file.  The same is\
    \ true for importing modules in Python.    "
