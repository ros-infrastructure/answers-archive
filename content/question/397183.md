Hi,
I found some problems with my xacro files after package upgade.

I built my robot URDF with the following files:

 - a .utils.xacro file, containing macros, as for example:

         <xacro:macro name="build_delta" params="namespace parent *origin">
        <xacro:qbdelta.build_base_delta namespace="${namespace}" parent="${parent}">
          <xacro:insert_block name="origin"/>
        </xacro:qbdelta.build_base_delta>
        <xacro:qbdelta.build_end_effector namespace="${namespace}"/>
        <gazebo>
          <plugin name="qb_move_gazebo_plugin" filename="libqb_move_gazebo_plugin.so"/>
        </gazebo>
      </xacro:macro>

 - a .urdf.xacro file:

    <xacro:include filename="$(find qb_move_description)/urdf/qbmove.utils.xacro" ns="qbmove"/>
      <xacro:include filename="$(find qb_chain_description)/urdf/qbchain.utils.xacro" ns="qbdelta"/>
    
      <link name="root_link"/>
      <xacro:qbdelta.build_delta namespace="delta" parent="root">
        <origin xyz="0 0 0.3" rpy="0 3.14 3.14"/>
      </xacro:qbdelta.build_delta>

Other macros(build_base_delta, build_end_effector, ...) are included in .utils.xacro file.

This structure works before package upgrade, but when the version was upgraded to 1.13.15(ros melodic) it stopped working ancd the following error occurs:

    unknown macro name: qbdelta.build_base_delta

Can someone help me with this issue?
