  body_markdown: "To fix this error, need to install the missing package rqt_virtual_joystick:\n\
    \nhttps://github.com/aquahika/rqt_virtual_joystick\n\nSuggested installation:\n\
    \n    mkdir -p joystick_ws/src\n    cd joystick_ws/src\n    git clone https://github.com/aquahika/rqt_virtual_joystick\n\
    \    cd ..\n    catkin_make\n    echo 'source ~/joystick_ws/devel/setup.bash'\
    \ >> ~/.bashrc\n    source ~/.bashrc\n    \nTo test: `rosrun rqt_virtual_joy rqt_virtual_joy`\n\
    Notice that the package is rqt_virtual_joy\n\n\n\n\n"
