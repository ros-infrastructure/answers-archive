  body_markdown: "Hi, I typically use a launch file with the following:\n\n    <node\
    \ pkg=\"rosbag\" type=\"record\" name=\"rosbag_record_sensors\" output=\"screen\"\
    \n          args=\"--buffsize=0 \n                -e '(.*)you_want_this(.*)|(.*)and_this(.*)'\n\
    \                -x '(.*)you_dont_want_this(.*)|(.*)neither_that(.*)'\"/>\n\n\
    Separation is done using `|`."
