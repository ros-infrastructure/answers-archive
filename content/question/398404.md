  body_markdown: "From https://www.cplusplus.com/reference/cstdlib/rand/, `rand()`:\n\
    \n> Returns a pseudo-random integral\n> number in the range between 0 and\n> RAND_MAX.\n\
    > \n> This number is generated by an\n> algorithm that returns a sequence of\n\
    > apparently non-related numbers each\n> time it is called. This algorithm uses\n\
    > a seed to generate the series, which\n> should be initialized to some\n> distinctive\
    \ value using function\n> [srand](https://www.cplusplus.com/reference/cstdlib/srand/).\n\
    \nBy default, a seed value of 1 is used. Hence, every time you start your program,\
    \ that seed is used and you will always get the same pseudo random sequence. This\
    \ can be useful for debugging, but frustrating if you're expecting something that\
    \ appears random. \n\n[A common approach](https://stackoverflow.com/questions/4736485/srandtime0-and-random-number-generation)\
    \ is to seed the random number generator with the current time, e.g.:\n\n    srand(time(0));\
    \ \n"
