  body_markdown: "If both topics publish the same message type, you can definitely\
    \ use the same callback for both subscriptions, although you won't be able to\
    \ tell which message came from which topic.\n\nOtherwise, you could always delegate\
    \ the work to a third function, like this:\n\n    void processInt (int a)\n  \
    \  {\n      // Lots of computation here\n    }\n    \n    void callback1 (MyMessageConstPtr\
    \ msg)\n    {\n      processInt (msg->int_value);\n    }\n    \n    void callback2\
    \ (MyOtherMessageConstPtr msg)\n    {\n      processInt (msg->other_int_value);\n\
    \    }\n    \n    int main (int argc, char** argv)\n    {\n      ros::init (argc,\
    \ argv, \"my_node\");\n      ros::NodeHandle node;\n      ros::Subscriber s1 =\
    \ node.subscribe<MyMessage>(\"topic1\", 1, callback1);\n      ros::Subscriber\
    \ s2 = node.subscribe<MyOtherMessage>(\"topic2\", 1, callback2);\n      ros::spin();\n\
    \      return 0;\n    }\n\n"
