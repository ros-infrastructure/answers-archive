In the [stage SimulatingOneRobot tutorial](http://www.ros.org/wiki/stage/Tutorials/SimulatingOneRobot), it mentions to install teleop_base.  I couldn't find that package, does it still exist?

I managed to control the erratic robot via:

    $ roslaunch turtlebot_teleop keyboard_teleop.launch

So it looks like the  [stage SimulatingOneRobot tutorial](http://www.ros.org/wiki/stage/Tutorials/SimulatingOneRobot) should be updated to use this command, or whatever the most appropriate command for controlling the erratic robot.
