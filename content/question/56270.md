  body_markdown: "Create a tf point from your Eigen point, query the tf server for\
    \ the right transform, and then apply the transform.\n\nHere's some code to get\
    \ you started. (I haven't actually compiled this)\n\n    #include <tf/transform_listener.h>\n\
    \    #include <tf/transform_datatypes.h>\n\n    // the point, in the camera frame\n\
    \    tf::Vector3 point(x, y, z);\n    \n    // request the transform between the\
    \ two frames\n    tf::TransformListener listener;\n    tf::StampedTransform transform;\n\
    \n    // the time to query the server is the stamp of the incoming message\n \
    \   ros::Time time = cloud_cup->header.stamp;\n\n    // frame of the incoming\
    \ message\n    std::string frame = cloud_cup->header.frame_id;\n\n    try{\n \
    \     listener.waitForTransform(\"/base_link\", frame, time, ros::Duration(3.0));\n\
    \      listener.lookupTransform(\"/base_link\", frame, time, transform);\n   \
    \ }\n    catch (tf::TransformException ex) {\n      ROS_WARN(\"Base to camera\
    \ transform unavailable %s\", ex.what());\n    }\n\n    // the point, in the base\
    \ link frame\n    tf::Vector3 point_bl = transform * point;\n\nIf the transform\
    \ doesn't change, you probably want to cache it once, and then apply it to your\
    \ data without querying it over and over."
