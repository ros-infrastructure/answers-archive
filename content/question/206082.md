    It's not <code>ros::time</code>, it's <code>ros::Time</code> (capitalizing the 'T' is necessary).

    You can use the <code>toSec</code> method of a <code>Time</code> instance to get the time as a double (see the <a href="http://wiki.ros.org/roscpp/Overview/Time#Converting_Time_and_Duration_Instances">Time Overview</a> wiki).

    The API for <code>Time</code> can be found <a href="http://docs.ros.org/api/rostime/html/classros_1_1Time.html">here</a>, while the API for its superclass <code>TimeBase</code> can be found <a href="http://docs.ros.org/api/rostime/html/classros_1_1TimeBase.html">here</a>.

    An example of using <code>ROS_INFO</code> for the <code>last_real</code> member of a received <code>TimerEvent</code> instance <i>tEvent</i> might look like so:
    <pre><code>void callback1(const ros::TimerEvent& tEvent) {
      ROS_INFO("Event last_real time: %f", tEvent.last_real.toSec());
    }</code></pre>
