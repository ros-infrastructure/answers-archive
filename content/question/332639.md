    Has you have mentioned in your tags, rosserial-windows should work for your case: [tutorial](https://wiki.ros.org/rosserial_windows/Tutorials/Hello%20World).

    Note that we also developed [rosserial_qt](https://github.com/1r0b1n0/rosserial_qt) that is based on Qt libraries to be portable and used on Windows.

    But if you only want to send TCP packets to windows, you will have to write a ROS node that subscribe to a topic and send some data in a TCP socket that will be read from Windows.
