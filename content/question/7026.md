  body_markdown: "Answering my own question in case someone wants finds this post\
    \ and wants to implement ackermann steering on their model. I just got it working\
    \ today.\n\nBasically, the two needed plugins are DRCVehiclePlugin.cc and DRCVehicleROSPlugin.cpp\
    \ (with drcsim_gazebo installed). I kept the structure of my vehicle model to\
    \ be very similar as the vehicle for DRC so that the plugin labels would easily\
    \ work.\n\nThe important sections of the source code from [https://bitbucket.org/osrf/drcsim/src/70bd0c879aadd22140d4b0ee301c92175a6b269e?at=default](https://bitbucket.org/osrf/drcsim/src/70bd0c879aadd22140d4b0ee301c92175a6b269e?at=default)\
    \ \nare here:\n\n`drcsim/drcsim_gazebo/launch/atlas_drc_vehicle_fire_hose.launch`\
    \ (this is just relevant because it launches the vehicle)\n`drcsim/drcsim_model_resources/worlds/atlas_drc_vehicle_fire_hose.world`\
    \ (where the vehicle's world file is located)\n`drcsim/drcsim_model_resources/gazebo_models/drc_vehicle_xp900/model.sdf`\
    \ (the model file- under the plugin section, you can get rid of the non-relevant\
    \ parts like fnr_switch as long as you modify the plugin cpp/cc files. you can\
    \ also get rid of the mudseat plugin)\n`drcsim/drcsim_gazebo_ros_plugins/` (for\
    \ the .h header file and .cpp file for DRCVehicleROSPlugin)\n`drcsim/drcsim_gazebo_plugins/`\
    \ (for the .hh header file and .cc file for DRCVehiclePlugin)\n\nI was able to\
    \ modify the plugins so that they were just bare-bones ackermann steering related\
    \ (without the Atlas stuff or the rest).\n\nHope this helps someone, because it\
    \ took me a long time to get this working!"
