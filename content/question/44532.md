    In general, I think you may want to look at the differences between [packages and nodes](http://answers.ros.org/question/9133/packages-vs-nodes/) and how [nodes](http://www.ros.org/wiki/Nodes) are a subset of [packages](http://www.ros.org/wiki/Packages). I believe you are trying to run the [openni_camera_deprecated](http://www.ros.org/wiki/openni_camera_deprecated) node, and looking at that page it seems that node is deprecated, meaning it is no longer being developed. If you wanted to run that node then you would install the [openni_kinect](http://www.ros.org/wiki/openni_kinect) package. Since it is deprecated though, it is recommended that you use [openni_launch](http://www.ros.org/wiki/openni_launch) and [openni_camera](http://www.ros.org/wiki/openni_camera) in Electric and later. There is some ambiguity here, because when you go to the page for the recommended packages it says they are available for Fuerte and later.

    The end result is that you should try to install the `ros-electric-openni-kinect` package with

        sudo apt-get install ros-electric-openni-kinect

    Then, try running with one of the provided launch files. Also, there is a lot of documentation that will help you get started on those pages above.
