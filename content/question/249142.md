  body_markdown: |-
    You can use [this dev branch of create_autonomy](https://github.com/autonomylab/create_autonomy/) (**EDIT: merged**) as a reference. This assumes that libcreate is installed as a catkin package (currently by cloning libcreate into your workspace and building with catkin). Then, in your package.xml you can add build/run dependencies to libcreate, include/link in your CMakeLists.txt ([example](https://github.com/AutonomyLab/create_autonomy/blob/90e597ea4d85cde1ec32a1d43ea2dd0b4cbf481c/ca_driver/CMakeLists.txt)), and include the header `create/create.h` and make API calls in your code ([example](https://github.com/AutonomyLab/create_autonomy/blob/90e597ea4d85cde1ec32a1d43ea2dd0b4cbf481c/ca_driver/include/create_driver/create_driver.h#L36)). Hope it helps.
