  body_markdown: "I don't think there is a direct way to achieve this. But you could\
    \ easily write a wrapper script and put it into a ros package. The script could\
    \ look like this:\n\n    \n    #!/bin/bash\n    exec $1 ${@:2}\n\nA corresponding\
    \ launch entry, assuming that the script is called `launch_system_cmd.sh` and\
    \ lies in package `mypackage`, would look like this:\n\n    <node name=\"shell_cmd\"\
    \ type=\"launch_system_cmd.sh\" pkg=\"mypackage\"\n          args=\"/bin/echo\
    \ foo\" />\n\nPlease note that roslaunch will pass an additional parameter that\
    \ sets the name for nodes and if necessary topic remappings. The output of the\
    \ above command should be something like\n\n    foo __name:=shell_cmd\n\nYou might\
    \ need to extend the wrapper script to get rid of those additional parameters."
