  body_markdown: "Well I solved it like this:\n\n\n    1.- cd to the /sandbox directory\
    \ that has been created by rosws\n    2.- Add the repository to the overlay, e.g.\
    \ it is added to ~/working_space/sandbox/.rosinstall\n        \n        rosws\
    \ set  -y depthimage_to_laserscan  --git https://github.com/ros-perception/depthimage_to_laserscan.git\
    \ \n    \n    3.- update the rosws\n        rosws update depthimage_to_laserscan\n\
    \    4.- source ~/.bashrc \n    5.- cd to depthimage_to_laserscan and run cmake\
    \ . and make\n\n\nThe launch file may look like this:\n\n\n  \n\n      <launch>\n\
    \    <include file=\"$(find openni_launch)/launch/openni.launch\"/> \n       \
    \ <node pkg=\"depthimage_to_laserscan\" type=\"depthimage_to_laserscan\" name=\"\
    depthimage_to_laserscan\" args=\"image:=/camera/depth/image_raw\" respawn=\"true\"\
    > \n           <!--param name=\"output_frame_id\" value=\"/camera_depth_frame\"\
    /-->\n           <param name=\"scan_height\" value=\"290\"/> \n            <param\
    \ name=\"scan_time\" value=\"0.125\"/>\n            <param name=\"range_min\"\
    \ value=\"0.80\"/>\n            <param name=\"range_max\" value=\"3.0\"/>\n  \
    \          <param name=\"min_height\" value=\".10\"/>\n            <param name=\"\
    max_height\" value=\"2.0\"/>\n            <remap from=\"/scan\" to=\"/scan_xtion\"\
    />\t\n        </node>\n        </launch>\n\n   \nThen run:\n\n    rosrun rviz\
    \ rviz and the fake kinect can be seen under the topic /scan_xtion\n\n\nCheers"
