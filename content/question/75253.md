  body_markdown: "Hi NKN, unfortunately there is not much documentation about UWSim\
    \ yet, just what there is on the wiki:\n\n http://www.irs.uji.es/uwsim/wiki/\n\
    \nHowever, it comes with a set of examples that should be self explanatory, being\
    \ gotoAbsolutePosition one of them. It requires a nav_msgs/Odometry topic where\
    \ UWSim is publishing its current pose (via a PATToROSOdom interface), and another\
    \ nav_msgs/Odometry topic where UWSim is listening for position update messages\
    \ (via a ROSOdomToPAT interface).\n\nYour scene xml file must include these interfaces\
    \ and specify the topics, e.g:\n\n    <ROSOdomToPAT>\n      <topic> /pose_update\
    \ </topic>\n      <vehicleName> your_vehicle_name </vehicleName>\n    </ROSOdomToPAT>\n\
    \    \n    <PATToROSOdom>\n      <topic> /current_pose </topic>\n      <vehicleName>\
    \ your_vehicle_name </vehicleName>\n    </PATToROSOdom>\n\nNote that the default\
    \ cirs.xml scene does not include the PATToROSOdom, so you need to add it explicitly\
    \ if you want to use the gotoAbsolutePosition example.\n\nThen, with UWSim running,\
    \ you should be able to do:\n\n    rosrun UWSim gotoVehiclePose /current_pose\
    \ /pose_update 10 0 0 0 0 0\n\nHope that helps!"
