    You could try a *from source* installation (ie: compile everything yourself), but it is a rather tedious process and more complicated.

    See [wiki/indigo/Installation/Source](http://wiki.ros.org/indigo/Installation/Source).

    As Indigo is not supposed to run on Ubuntu Precise (see [REP-0003](http://www.ros.org/reps/rep-0003.html#indigo-igloo-may-2014)), you could run into dependency issues. Those you will have to solve. Note that some dependencies might not be installable and / or compilable under Precise.
