    \ which is also a parameter of the node and it is set to \"laser\" by default.<br><br>\n\
    1. To change this you can use the dynamic reconfigure<br>\n\n    rosrun dynamic_reconfigure\
    \ reconfigure_gui\n\nor set the parameter in the launch file adding the line \n\
    \n    <param name=\"frame_id\" value=\"/base_laser\"/>\n2. Check the [rviz Coordinate\
