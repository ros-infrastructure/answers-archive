    I had to use [the workaround for getting GLX 1.4](https://wiki.x2go.org/doku.php/wiki:development:glx-xlib-workaround) working. Here's a mini-tutorial provided by a [X2Go developer](https://www.mail-archive.com/x2go-dev@lists.x2go.org/msg06249.html):

    1. copy build`/src/gallium/targets/libgl-xlib` to some safe place
    2. write a small wrapper called `~/x2goglx` with this content:

    >     > #!/bin/sh LD_LIBRARY_PATH=<your directory>/libgl-xlib:${LD_LIBRARY_PATH}
    >     > exec "$@"

    Replace `<your directory>` with the path to where you copied the above
    directory to

    Then

        $ chmod u+rx ~/x2goglx

    Then test with (should show OpenGL 1.4)

        $ ~/x2goglx glxinfo

    Then run gazebo:

        $ ~/x2goglx gazebo
