  body_markdown: "Get the current joint values from your moveGroup (C++ version):\n\
    \  \n\n    std::vector<double> joints;\n    joints = moveGroup.getCurrentJointValues();\n\
    \nSet whatever joint you want to change:\n\n    joints.at(y) = x.x;\n\nSend the\
    \ move command:\n\n    moveGroup.setJointValueTarget(joints);\n    moveGroup.move();"
  comments:
  - body_markdown: |-
      +1 This is probably the simplest way to do it.
      However, note that this actually sends target values for *all* joints in the group, using the current values as target. This is slightly different (depending on the driver) compared to requesting only *one* joint to move.
