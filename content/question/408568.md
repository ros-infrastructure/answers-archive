Hi,

I have created a custom message `TorqueTerms.msg` in my catkin package `my_package` following all the instructions from [here](http://wiki.ros.org/ROS/Tutorials/CreatingMsgAndSrv#Creating_a_msg) and I am able to find it by `rosmsg show my_package/TorqueTerms`. However when I try to use this message in a rospy node of the same package I get the error:

    ModuleNotFoundError: No module named 'my_package.msg'

The executable `my_node.py` I run is:

    #!/usr/bin/env python
    import numpy as np
    import rospy
    from my_package.msg import TorqueTerms

    if __name__ == "__main__":
        rospy.init_node('my_node', anonymous=False)
        torquePub = rospy.Publisher('/custom_topic', TorqueTerms, queue_size=10)
    
        try:
            rospy.spin()
        except rospy.ROSInterruptException:
            pass

The structure of my ros package is:

    ├── my_package
    │   ├── package.xml
    │   ├── CMakeLists.txt
    │   ├── setup.py
    │   ├── msg
    │   │   └── TorqueTerms.msg
    │   ├── src
    │   │   └── my_node.py
    │   │   ├── my_package
    │   │   │   └── __init__.py
    │   │   │   └── some_script.py


where my `setup.py` is:

    from distutils.core import setup
    from catkin_pkg.python_setup import generate_distutils_setup
    d = generate_distutils_setup(
        packages=['my_package'],
        package_dir={'': 'src'}
    )
    setup(**d)

and the `__init__.py` is empty as suggested [here](https://www.theconstructsim.com/ros-qa-import-python-modules-different-ros-packages/).These two files were added in order to be able to import code from this package into other packages.

My `CMakeLists.txt` is:

    cmake_minimum_required(VERSION 3.0.2)
    project(my_package)
    
    find_package(catkin REQUIRED COMPONENTS
      message_generation
      rospy
      geometry_msgs
      std_msgs
      sensor_msgs
    )
    
    ## Generate messages in the 'msg' folder
    add_message_files( DIRECTORY msg
      FILES
      TorqueTerms.msg
    )
    
    ## Generate added messages and services with any dependencies listed here
    generate_messages(
      DEPENDENCIES
      std_msgs  # Or other packages containing msgs
    )
    
    catkin_package(
      CATKIN_DEPENDS message_runtime rospy geometry_msgs std_msgs sensor_msgs
    )
    
    include_directories(
    #  include
      ${catkin_INCLUDE_DIRS}
    )
and my `package.xml` is:

    <?xml version="1.0"?>
    <package format="2">
      <name>my_package</name>
      <version>0.0.0</version>
    
      <build_depend>message_generation</build_depend>
      <build_export_depend>message_runtime</build_export_depend>
      <exec_depend>message_runtime</exec_depend>
      <exec_depend>message_generation</exec_depend>
    
      <buildtool_depend>catkin</buildtool_depend>
      <build_depend>rospy</build_depend>
      <build_export_depend>rospy</build_export_depend>
      <exec_depend>rospy</exec_depend>
    
      <build_depend>geometry_msgs</build_depend>
      <build_export_depend>geometry_msgs</build_export_depend>
      <exec_depend>geometry_msgs</exec_depend>
    
      <build_depend>sensor_msgs</build_depend>
      <build_export_depend>sensor_msgs</build_export_depend>
      <exec_depend>sensor_msgs</exec_depend>
    
      <build_depend>std_msgs</build_depend>
      <build_export_depend>std_msgs</build_export_depend>
      <exec_depend>std_msgs</exec_depend>
    </package>

Strangely I am able to import the module `my_package.msg` in the script of a different ros package but not in `my_node.py`. It seems that the setup.py I have "hides" the my_package.msg from my python scripts in the same package. Any suggestion on how to solve the issue?
