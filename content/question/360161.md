    The `get_entity_state` service is provided by the `libgazebo_ros_state.so` plugin. Did you load that?

    [Here](https://github.com/ros-simulation/gazebo_ros_pkgs/blob/c071749932a541a5b8aced23c3414724a8cd1949/gazebo_ros/worlds/gazebo_ros_state_demo.world#L41-L49)'s an example on how to load it from your SDF world.

    There isn't a way to load that plugin from a launch file yet, see [this issue](https://github.com/ros-simulation/gazebo_ros_pkgs/issues/1157).

    [Here](https://github.com/ros-simulation/gazebo_ros_pkgs/wiki/ROS-2-Migration:-Entity-states)'s more information on entity states on Gazebo + ROS 2.
