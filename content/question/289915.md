  body_markdown: "Two possibilities:\n\n 1. Use instance variables inside your state1\
    \ Class\n 2. Pass data between state instances with userdata\n\nor some combination\
    \ of the 2...\n\ne.g. #1:\n\n    import rospy\n    from smach import State\n \
    \   \n    class State1(State):\n        def __init__(self):\n            State.__init__(self,\
    \ outcomes=['still_working', 'done'])\n            \n            rate = rospy.Rate(200)\
    \  # Loop at 200 Hz\n\n            self._in_progress = False\n            self._prev_data\
    \ = None\n            # etc. etc.\n    \n        def execute(self):\n        \
    \    # entry\n            current_data = []\n            if self._in_progress:\n\
    \                current_data = self._prev_data\n            \n            sensor_input\
    \ = False\n            while not sensor_input and not rospy.is_shutdown():\n\n\
    \                 # do a bit of work here\n                 current_data.append(do_just_a_bit_of_work())\n\
    \              \n                 if check_if_work_done():\n                 \
    \    self._in_progress = False\n                     self._prev_data = None\n\
    \                     return 'done'\n\n                 if check_for_sensor_input():\n\
    \                     self._in_progress = True\n                     self._prev_data\
    \ = current_data\n                     return 'still_working'\n\n            \
    \     rate.sleep()\n\n----------\nFor #2, state1 would pass out different userdata\
    \ values based on whether or not it had completed before being interrupted. You'd\
    \ probably want a state3 that would determine the next transition after state2\
    \ based on the userdata dictionary.\n                 \n       \n\n        "
