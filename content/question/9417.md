  body_markdown: "the bumblebee stereo camera only transmits stereo images when configured\
    \ to send images in format7 mode3.\n\nabout the second part, the node bumblebee1394\
    \ loads a number of parameters from the parameter server. if you start the node\
    \ with the command: \"rosrun bumblebee1394 bumblebee1394\" you start it with its\
    \ default parameters. this means it takes iso speed 400, 30 fps and 640x480 mono\
    \ 8 bit images. \nthe bumblebee1394 folder also contains a launch file which you\
    \ can use as example on now to set you own settings on the parameter server."
