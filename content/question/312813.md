    > ELF: not found (cut) Syntax error: ")" unexpected

    This may be a typical error when platform a binary is built for is not what you're running on (e.g. [ref on unix.stackexchange.com](https://unix.stackexchange.com/questions/336436/syntax-error-unexpected-when-execute-a-compiled-c-program)). My guess is you're getting that error because you're on Jetson Tx2, which is ARM-based IIRC and I doubt QtCreator's binary is built for.
