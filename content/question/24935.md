 I have build a model by myself, it's a folder named "My_Model", it has correct .config and .sdf file. I can include it by moving the folder to default GAZEBO_MODEL_PATH, and write 
"
<include>
      <uri>model://My_Model</uri>
</include>
" 
in the .world file. It works.

But what if I don't move this folder to the default path, and I don't want to modify the default GAZEBO_MODEL_PATH, how can I include it? 
For example, its absolute path is /home/idontwan/Documents/My_Model, how should I write the script?
