  body_markdown: "It absolutely is possible, and there are 3 main things you need\
    \ need to do.\n\n## Create Python Action Server ##\nThis is pretty straight forward\
    \ with lots of resources and demonstrations on how to set up an action client.\
    \ I found this page on [actionlib](http://wiki.ros.org/actionlib) to be the most\
    \ helpful. It demonstrates setting up your Catkin package structure, creating\
    \ .action files as well as a Python simple action server. \n\n## Create Matlab\
    \ Action Client ##\nEven simpler is creating a Matlab action client to send goals\
    \ to the Python action server. There are various overloaded signatures of the\
    \ function as can be seen in the [rosactionclient](https://www.mathworks.com/help/ros/ref/simpleactionclient.html)\
    \ documentation. My preference is to use the function signature\n\n```\n[client,goalMsg]\
    \ = rosactionclient(actionname)\n```\n\nThis sets us up with a client to send\
    \ goals to the action server as well as a blank goal message that we can modify\
    \ and send. There is an example of its use on the aforementioned documentation\
    \ page.\n\n## Facilitate Custom Messages in Matlab ##\nAction servers may require\
    \ the use of custom ROS messages (stored in .action files). Matlab has access\
    \ to a lot of built in messages as can be seen with the command ```rosmsg list```.\
    \ If you do not see the your action server's messages in the returned list then\
    \ you need to follow these instructions for [ROS Custom Message Support](https://www.mathworks.com/help/ros/ug/ros-custom-message-support.html).\
    \ I was not able to run these instructions on a Mac, but I was able to successfully\
    \ run them on a Linux machine. Once I had the directory of generated messages\
    \ on my Linux machine I was able to copy them to my Mac and they worked perfectly."
