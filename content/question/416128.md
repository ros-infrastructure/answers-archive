    Make sure [ros2cli](https://index.ros.org/p/ros2cli/github-ros2-ros2cli) package, which provides `ros2` command capability, is installed. E.g. on my Ubuntu Focal with ROS Galactic:

        # apt-cache policy ros-$ROS_DISTRO-ros2cli
        ros-galactic-ros2cli:
          Installed: 0.13.5-1focal.20221207.074558
          Candidate: 0.13.5-1focal.20221207.074558
