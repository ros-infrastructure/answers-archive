  body_markdown: "You should have a look at the [ROS Navigation Stack](http://wiki.ros.org/navigation),\
    \ that contains the components to implement a full autonomous navigation.\n\n\
    Among these packages, the one responsible for moving the robot is [MoveBase](http://wiki.ros.org/move_base).\n\
    This provides you API for moving the robot toward a goal. This goal could be computed\
    \ in local coordinates and it could easily represent the concept of \"X meters\
    \ in front of the robot\".\nThe \"problem\" is that you will also need a localization\
    \ package in order to understand when the robot has really traveled that distance.\n\
    Something very simple could be dead reckoning, i.e. just looking at the wheel\
    \ encoders.\n\nThe Navigation stack contains tutorial for setting up all what\
    \ you need.\n\nHowever, in an extremely oversimplified scenario, if you know that\
    \ your robot moves at 1m/s you can create a function that publishes the \"move\
    \ forward command\" that you are executing through the keyboard for the required\
    \ amount of time to cover your distance.\nThis \"command\" will be a message of\
    \ type `geometry_msgs/Twist` on topic `cmd_vel`.\n\n\n\nEDIT:\n\nI don't advise\
    \ you to run something as \"move randomly for 30 seconds\" on a turtlebot, if\
    \ you don't want to crash it against a wall.\nAnyhow, you can do something like\n\
    \n\n    import rospy\n    from geometry_msgs.msg import Twist\n    \n    pub =\
    \ rospy.Publisher('cmd_vel', Twist, queue_size=10)\n    rospy.init_node('node_name')\n\
    \    r = rospy.Rate(30) # 30hz\n    \n    total_time = 10 #seconds\n    start_time\
    \ = time.time()\n    \n    while not rospy.is_shutdown() or (time.time() - start_time\
    \ < total_time):\n    \n        msg = Twist()\n        \n        # here you should\
    \ fill the msg fields\n        # http://docs.ros.org/api/geometry_msgs/html/msg/Twist.html\n\
    \        # you can fill it randomly or with a direction in mind\n    \n      \
    \  pub.publish(msg)\n        r.sleep()"
