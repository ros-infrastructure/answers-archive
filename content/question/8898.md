    \ Also note that the [Building Editor](http://gazebosim.org/tutorials?tut=building_editor&cat=build_world)\

    \ on Gazebo 5, so several features differ from Gazebo 2.2.\n\nYou could always\
    \ edit your world's SDF directly or load it into Gazebo with \n\n    gazebo <your\
    \ world>.world\n\nthen [modify](http://gazebosim.org/tutorials?tut=build_world&cat=build_world)\
    \ it and then save a new copy."
