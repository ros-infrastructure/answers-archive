  body_markdown: "Hello @katsostak,\n\nLet's say you have created a bash script including\
    \ all package init. I am just providing an example instead of whoami and date\
    \ command think it is your script. \n\nMini batch script: `abc.sh`\n\n    #!/bin/bash\n\
    \    whoami\n    date\n\nYou first need to `chmod +x abc.sh`\n\nYou can execute\
    \ it in 2 ways:\n1. `bash abc.sh`\n2. `./abc.sh`\n\n> Ideally I would want this\
    \ bash script to be executed the first time someone uses catkin_make on the workspace\
    \ after my package has been cloned on the src folder of the workspace.\n\nCMake\
    \ Solution\n\n It is also possible to add a \"post build\" command for a target\
    \ in CMake with [add_custom_command](https://cmake.org/cmake/help/v3.0/command/add_custom_command.html)\
    \ using the \"POST_BUILD COMMAND\" option:\n\n    add_custom_command(TARGET doc\n\
    \        POST_BUILD COMMAND your_script.sh\n    )\n\n(I am not sure if this will\
    \ work as intended for the target, maybe you have to experiment a bit.)"
