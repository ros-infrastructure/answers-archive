  body_markdown: "Have you looked at [troubleshooting rviz](http://ros.org/wiki/rviz/Troubleshooting)?\
    \ It is likely you just need to set OGRE_RTT_MODE\n\nThe relevant section says:\n\
    \n> Various OpenGL or Ogre things can go\n> wrong during startup. One of them\n\
    > seems to relate to the\n> render-to-texture system. Ogre\n> supports 3 different\
    \ modes, and rviz\n> uses the \"PBuffer\" mode by default.\n> Some users have\
    \ reported some modes\n> cause a segfault during startup, but\n> it is not clear\
    \ which should be used\n> when.\n> \n> If you have a problem and want to try\n\
    > another \"RTT mode\", run rviz with the\n> environment variable OGRE_RTT_MODE\
    \ set\n> to either \"Copy\", \"PBuffer\", or \"FBO\".\n> For example:\n>\n>  \
    \   export OGRE_RTT_MODE=Copy"
