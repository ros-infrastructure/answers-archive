  body_markdown: "The `<visual>` and `<collision>` elements of your wheel links do\
    \ not line up:\n\nTo see this, \n\n 1. Load your model in Gazebo.\n 2. Select\
    \ `View` > `Show collision`.\n 3. Select `View` > `Transparent`.  \n     *(You\
    \ can learn about the other View options in the [Gazebo GUI Tutorial](http://gazebosim.org/tutorials?cat=guided_b&tut=guided_b2))*\n\
    \n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/1554174277161614.png)\n\
    \n----------\nLooking at your wheel link macro, the `<visual>` element is rolled\
    \ by pi/2 radians but the `<collision>` element is not...\n\nBroken:\n\n     \
    \ <xacro:macro name=\"wheel_position_macro\" params=\"prefix suffix reflect1 reflect2\"\
    >\n        <link name=\"${prefix}_${suffix}_wheel\">\n          <visual>\n   \
    \         <origin xyz=\"0 0 0\" rpy=\"${pi/2} 0 0\"/>\n            <geometry>\n\
    \              <cylinder radius=\"${wheel_diameter/2}\" length=\"${wheel_thickness}\"\
    />\n            </geometry>\n            <material name=\"black\"/>\n        \
    \  </visual>\n          <collision>\n            <geometry>\n              <cylinder\
    \ radius=\"${wheel_diameter/2}\" length=\"${wheel_thickness}\"/>\n           \
    \ </geometry>  \n            ...\n          </collision>\n          <xacro:default_inertial\
    \ mass=\"${wheel_mass}\"/>\n        </link>\n        ...\n      </xacro:macro>\n\
    \nFixed:\n\n      <xacro:macro name=\"wheel_position_macro\" params=\"prefix suffix\
    \ reflect1 reflect2\">\n        <link name=\"${prefix}_${suffix}_wheel\">\n  \
    \        <visual>\n            <origin xyz=\"0 0 0\" rpy=\"${pi/2} 0 0\"/>\n \
    \           <geometry>\n              <cylinder radius=\"${wheel_diameter/2}\"\
    \ length=\"${wheel_thickness}\"/>\n            </geometry>\n            <material\
    \ name=\"black\"/>\n          </visual>\n          <collision>\n            <origin\
    \ xyz=\"0 0 0\" rpy=\"${pi/2} 0 0\"/>\n            <geometry>\n              <cylinder\
    \ radius=\"${wheel_diameter/2}\" length=\"${wheel_thickness}\"/>\n           \
    \ </geometry>  \n            ...\n          </collision>\n          <xacro:default_inertial\
    \ mass=\"${wheel_mass}\"/>\n        </link>\n        ...\n      </xacro:macro>\n\
    \n*(You can learn more about URDF XML at http://wiki.ros.org/urdf/XML/link)*\n\
    \n----------\nOne final note:\n\nThe inertial values are too high. Check out the\
    \ [Inertial parameters of triangle meshes](http://gazebosim.org/tutorials?tut=inertia&cat=build_robot)\
    \ tutorial."
