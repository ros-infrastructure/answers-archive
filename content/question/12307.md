  body_markdown: "`gazebo6` from the OSRF repository declared conflict with `gazebo2`,\
    \ so updating your system from just `gazebo2` to `gazebo6` should work out-of-the-box.\n\
    \nThis situation is not the same if you have installed packages that depends on\
    \ `gazebo2` like `ros-indigo-gazebo-ros-pkgs`. What I would recommend, two options:\n\
    \n1. Use aptitude (package manager, it propose solutions to conflict situations)\n\
    \n        apt-get install aptitude\n        aptitude install libgazebo6-dev\n\n\
    2. Clean up sdformat first, install later\n \n        apt-get remove '.*sdf.*'\n\
    \        apt-get install libgazebo6-dev\n\nBoth should resolve the situation.\n"
