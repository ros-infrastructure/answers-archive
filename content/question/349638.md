  body_markdown: "Edit: actually did a quick search and found this to be helpful:\n\
    http://wiki.ros.org/rosbag/Tutorials/Exporting%20image%20and%20video%20data\n\n\
    \nIt would be awesome if dealing with images could be so easy! Unfortunately that\
    \ is not the case :/\n\nA few things:\n1) The */image_raw/compressed topic is\
    \ actually of the rosmsg type sensor_msgs/CompressedImage. \n\n    lol@lel:~$\
    \ rosmsg info sensor_msgs/CompressedImage                                    \
    \                                  \n    std_msgs/Header header\n      uint32\
    \ seq\n      time stamp\n      string frame_id\n    string format\n    uint8[]\
    \ data\n\nThe data field is the actual payload, which needs to be converted into\
    \ a jpg/png as per the official structure: https://en.wikipedia.org/wiki/JPEG#Syntax_and_structure\n\
    \nOne way to do this is to use the cv_bridge to subscribe to the image topic,\
    \ and then save to jpg/png on every run of the callback. (really there should\
    \ be a node to do this .. but I can't find one :/ if you find one, please share!)\n\
    \nOnce you have all of those jpgs, then can you coallate them into an mp4 video\
    \ https://stackoverflow.com/questions/22965569/convert-from-jpg-to-mp4-by-ffmpeg\n\
    \nI hope this helps.\nGood luck!"
