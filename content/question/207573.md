    Yes, the packages in ROS-Industrial can be installed on ROS Indigo.

    At present (2015-04-22) the [industrial_core](http://wiki.ros.org/industrial_core), [abb](http://wiki.ros.org/abb) and [universal_robot](http://wiki.ros.org/universal_robot) packages have been officially released and can be installed using `sudo apt-get install ..`.

    The [fanuc](http://wiki.ros.org/fanuc) and [motoman](http://wiki.ros.org/motoman) packages have not yet been released, but can be build from source. The Indigo page for [fanuc_driver](http://wiki.ros.org/fanuc_driver?distro=indigo) lists the steps required to do that. The same steps can be used for the motoman packages, see [How can I use Motoman stack with ROS Indigo?](http://answers.ros.org/question/191233/how-can-i-use-motoman-stack-with-ros-indigo/) for more info.

    The `ros-industrial-DISTRO-desktop` package has not been released into Indigo yet, so that is why you cannot install it using `apt-get`.
