    Registering two partially overlapping point clouds is a very challenging task and the ICP algorithm doesn't always find a good solution, as you have discovered with the error messages you've seen.

    These failures are usually caused by an insufficient overlap between the two clouds or the initial starting point for ICP being too far away from the correct solution.

    I'd recommend reading up on ICP [here](https://en.wikipedia.org/wiki/Iterative_closest_point) and [here](https://www.mrpt.org/Iterative_Closest_Point_%28ICP%29_and_other_matching_algorithms) if you haven't already. You may be able to improve performance be estimating the point normals and including these in the matching algorithm depending on the implementation of ICP you're using.
