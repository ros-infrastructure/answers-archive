    If you're logging from the command line, you can pass the `--record-path` flag.

    If you're doing it through the C++ API, you can pass the [path](http://osrf-distributions.s3.amazonaws.com/gazebo/api/11.0.0/classgazebo_1_1util_1_1LogRecord.html#aa00651928e9fe26bdce96e0d90124084) to `LogRecord::Start`.

    If you're triggering it through a message, you can use the `base_path` [field](http://osrf-distributions.s3.amazonaws.com/gazebo/msg-api/9.0.0/log__control_8proto.html).

    If you're using ROS 1, pass `extra_gazebo_args:="--record-path <path>"` to `empty_world.launch`.

    If you're using ROS 2, pass `record_path` to `gzserver.launch.py`.
