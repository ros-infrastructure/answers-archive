  body_markdown: "Typically, I'll name my dummy link \"base_link\",   \nand add a\
    \ fixed joint between \"base_link\" and the robot's chassis/mount, etc.\n\nIn\
    \ this case, \"base_link\" does not map to any physical robot structure (chassis,\
    \ arm mount, etc.) but simply represents the robot's base coordinate frame.\n\n\
    For a fixed robot (relative world_frame for RViz/Gazebo),   \nI'll add an additional\
    \ \"world_link\" and a fixed joint from \"world_link\" to \"base_link\"\n\n----------\n\
    In your case, I'd suggest renaming your current \"base_link\" to something more\
    \ descriptive (e.g. \"square_base\", \"chassis\") and then adding an \"empty\"\
    \ \"base_link\" as shown in the examples below.\n\n----------\nExample *(mobile\
    \ robot)*:\n\n    <?xml version=\"1.0\" ?>\n    <robot name=\"Mobile_Robot\">\
    \ \n      \n      <link name=\"base_link\" />\n    \n      <joint name=\"base_link_to_chassis\"\
    \ type=\"fixed\">\n        <parent link=\"base_link\"/>\n        <child link=\"\
    chassis\"/>\n      </joint>\n    \n      <link name=\"chassis\">\n        <inertial>\n\
    \        ...\n        </inertial>\n        <visual>\n        ...\n        </visual>\n\
    \        <collision>\n        ...\n        </collision>\n       </link>\n    \n\
    \       ...\n    </robot>\n\n----------\nExample *(fixed robot)*:\n\n    <?xml\
    \ version=\"1.0\" ?>\n    <robot name=\"Fixed_Robot\"> \n      \n      <link name=\"\
    world\" />\n    \n      <joint name=\"world_to_base_link=\" type=\"fixed\">\n\
    \        <parent link=\"world\"/>\n        <child link=\"base_link\"/>\n     \
    \ </joint>\n    \n      <link name=\"base_link\" />\n    \n      <joint name=\"\
    base_link_to_chassis\" type=\"fixed\">\n        <parent link=\"base_link\"/>\n\
    \        <child link=\"chassis\"/>\n      </joint>\n    \n      <link name=\"\
    chassis\">\n        <inertial>\n        ...\n        </inertial>\n        <visual>\n\
    \        ...\n        </visual>\n        <collision>\n        ...\n        </collision>\n\
    \       </link>\n    \n       ...\n    </robot>\n\n"
