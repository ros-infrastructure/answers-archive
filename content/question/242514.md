I'm continuing the [discussion](http://answers.ros.org/question/242263/3d-map-with-rtab-sick-imu-and-husky-a200/) of my previous [topic](http://answers.ros.org/question/242263/3d-map-with-rtab-sick-imu-and-husky-a200/) by focusing on the RTAB results.
I'm using `robot_localization` to obtain filtered odometry from wheel encoders, IMU (xsens Mti-10) and visual odometry (RealSense R200).
The IMU sensor is mounting on the center of the robot while the RSense is mounted on a vertical axis 116 centimeters above the IMU.

I launch the Husky [base.launch](http://www.dronyx.com/bags/husky/base.launch) node in order to start the teleoperation and the locomotion node; in addition, the base node also launch [control.launch](http://www.dronyx.com/bags/husky/control.launch) file which launch `robot_localization`.
[Control.launch](http://www.dronyx.com/bags/husky/control.launch) file loads parameters from [localization.yaml](http://www.dronyx.com/bags/husky/localization.yaml) for IMU and wheel_encoders and I added also the `odom1` which should be generated by `rgbd_odometry` from `rtabmap_ros` package.
At the bottom of [control.launch](http://www.dronyx.com/bags/husky/control.launch) file, I also added the transformation for my sensors:

    <node pkg="tf" type="static_transform_publisher"  name="base_to_realsense"
          args="0.3 1.16 0 1.5707963 0 -1.5707963 /base_link /realsense_frame 100" />
     <node pkg="tf" type="static_transform_publisher"  name="base_to_laser"
          args="0.3 0.6 0.1 0 0 0 /base_link /laser 100" />
    <node pkg="tf" type="static_transform_publisher"  name="base_to_color"
          args="0 0 0.6 1.5707963 0 -1.5707963 /base_link /camera_color_optical_frame 100" />
    <node pkg="tf" type="static_transform_publisher"  name="color_to_depth"
