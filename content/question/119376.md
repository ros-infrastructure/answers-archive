    ROS has nice and powerful releasing envionment.

    "Releasing" your package allows you to install your package via debian binary (ie. via `apt-get` on Ubuntu). You can start from looking at "Get Involved" wiki page and specifically at [Release Binary Packages](http://wiki.ros.org/Get%20Involved#Release_Binary_Packages) section, where its [tutorial using bloom](http://www.ros.org/wiki/bloom/Tutorials/) is linked from.

    Before starting that tutorial, you have to have at least your package publicly accessible on a distributed revision control system such as github, code.google.com, bitbucket etc. Being comfortable with [SCM](http://en.wikipedia.org/wiki/Source_code_management) tools (eg. git, svn, hg) would be very helpful (or almost required) if you're not yet.
