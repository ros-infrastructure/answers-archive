    I suspect you're using two different leaf sizes.  The tutorial you linked to shows a leaf size of 0.1 ([line 26](http://wiki.ros.org/pcl/Tutorials/hydro?action=AttachFile&do=view&target=example_voxelgrid.cpp#CA-5363a4b052e6ed8ce999f6f27559e46c6e754e51_26)):

        sor.setLeafSize (0.1, 0.1, 0.1);

    The default leaf size for the nodelet is 0.01 as seen in the [config file, line 13](https://github.com/strawlab/perception_pcl/blob/ee2cb0ecdecd54ba0f754766bfe91de54b40bccd/pcl_ros/cfg/VoxelGrid.cfg#L13):

        gen.add ("leaf_size", double_t, 0, "The size of a leaf (on x,y,z) used for downsampling.", 0.01, 0, 1.0)

    As shown in [this tutorial](http://wiki.ros.org/pcl_ros/Tutorials/VoxelGrid%20filtering), you can set the leaf size for the nodelet in the launch file for comparison, but to change your code to match the nodelet, try changing line 26 to:

        sor.setLeafSize (0.01, 0.01, 0.01);

    If that doesn't work, please post both your code and the launch file you're using for comparison.
