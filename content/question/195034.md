  body_markdown: "I was looking for the exact formula to calculate the real world\
    \ X,Y,Z values by the depth image and finally I got it.\n\nFirst of all, it appears\
    \ that the values in the depth image are not giving the distance between any point\
    \ in the real world and the origin of the Kinect. It appears that it is the distance\
    \ between the point and Kinect's XY plane (the plane which is parallel to the\
    \ front surface of Kinect). So, if Kinect is looking at a wall, all the depth\
    \ values give about the same value. It doesn't matter the real distance between\
    \ a point on the wall and Kinect's origin.\n\nI found the calculations in the\
    \ **NuiSkeleton.h** file:\n[https://code.google.com/p/stevenhickson-code/source/browse/trunk/blepo/external/Microsoft/Kinect/NuiSkeleton.h?r=14](https://code.google.com/p/stevenhickson-code/source/browse/trunk/blepo/external/Microsoft/Kinect/NuiSkeleton.h?r=14)\n\
    \nFor the Z axis, in line *625*, it says:\n\n    FLOAT fSkeletonZ = static_cast<FLOAT>(usDepthValue\
    \ >> 3) / 1000.0f;\n\nYou don't have to worry about the bitshift operation because\
    \ in the description of the method it says:\n\n    /// <param name=\"usDepthValue\"\
    >\n    /// The depth value (in millimeters) of the depth image pixel, shifted\
    \ left by three bits. The left\n    /// shift enables you to pass the value from\
    \ the depth image directly into this function.\n    /// </param>\n\nSo, you can\
    \ use the equation:\n\n    FLOAT fSkeletonZ = static_cast<FLOAT>(usDepthValue)\
    \ / 1000.0f;\nthe unit is in meters (because of the division by 1000).\n\nFor\
    \ X and Y axes, line *633* and *634* gives:\n\n    FLOAT fSkeletonX = (lDepthX\
    \ - width/2.0f) * (320.0f/width) * NUI_CAMERA_DEPTH_IMAGE_TO_SKELETON_MULTIPLIER_320x240\
    \ * fSkeletonZ;\n\n    FLOAT fSkeletonY = -(lDepthY - height/2.0f) * (240.0f/height)\
    \ * NUI_CAMERA_DEPTH_IMAGE_TO_SKELETON_MULTIPLIER_320x240 * fSkeletonZ;\n\nThe\
    \ calculation of the Y axis starts with a minus sign because in a picture (like\
    \ depth image) the Y value increases when you go down but in real world coordinates,\
    \ conventionally, Y increases when you go up.\n\nFor the *NUI_CAMERA_DEPTH_IMAGE_TO_SKELETON_MULTIPLIER_320x240*\
    \ constant, line *349* defines:\n\n    #define NUI_CAMERA_DEPTH_IMAGE_TO_SKELETON_MULTIPLIER_320x240\
    \ (NUI_CAMERA_DEPTH_NOMINAL_INVERSE_FOCAL_LENGTH_IN_PIXELS)\n\na short Googling\
    \ gives this page:\n[http://msdn.microsoft.com/en-us/library/hh855368.aspx](http://msdn.microsoft.com/en-us/library/hh855368.aspx)\n\
    where it says \n\n    NUI_CAMERA_DEPTH_NOMINAL_INVERSE_FOCAL_LENGTH_IN_PIXELS\t\
    (3.501e-3f)\n\nSo, using these formulas gives you the real world coordinates within\
    \ the coordinate frame given in the image:\n![image description](http://pille.iwr.uni-heidelberg.de/~kinect01/img/pinhole-camera.png)\n\
    \n(ref: [http://pille.iwr.uni-heidelberg.de/~kinect01/doc/reconstruction.html](http://pille.iwr.uni-heidelberg.de/~kinect01/doc/reconstruction.html))"
