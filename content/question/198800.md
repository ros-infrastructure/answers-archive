  body_markdown: "I think both of the options you propose are valid.\n\nFor 1): wstool\
    \ is ros-agnostic; it just uses the rosinstall file to ensure that the repositories\
    \ listed there are checked out and up to date. (rosinstall is similar, but it\
    \ also invokes rosbuild after doing the checkout, which makes it unsuitable for\
    \ what you're trying to do).\n\ncatkin_make isn't designed to build pure cmake\
    \ packages (it requires that each package have a package.xml), but you can build\
    \ a workspace containing both catkin and non-catkin cmake packages using `catkin_make_isolated`\
    \ or `catkin build`. \n\nFor 2): catkin_make is ROS-agnostic; it's just a convenience\
    \ wrapper around cmake, and it accepts all of the same flags that cmake does.\
    \ I haven't tried it, but it should work fine with a cmake toolchain file. Note\
    \ that since you would be building all of your packages in a single workspace,\
    \ it won't be possible to pass different toolchain files to different packages."
