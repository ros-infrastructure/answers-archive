    It looks like you're seeing [this issue](https://github.com/ros2-gbp/rmw_implementation-release/issues/1), and the fix [is in the process of being released](https://github.com/ros2-gbp/rmw_implementation-release/issues/1#issuecomment-498419498).

    The opensplice packages can be [temporarily removed using dpkg](https://askubuntu.com/questions/17745/how-to-remove-a-deb-without-removing-its-dependencies).

    `sudo dpkg --remove --force-depends ros-dashing-rmw-opensplice-cpp ros-dashing-rosidl-typesupport-opensplice-cpp ros-dashing-rosidl-typesupport-opensplice-c`

    Before you upgrade or install other packages you'll want to reinstall the opensplice packages that were force uninstalled using

    `sudo apt-get install --fix-broken`
