    One thing to check is the path to your mesh: `cwd` for a node is *not* where there source file is located, but by default is `~/.ros`. So relative paths tend to not work so well.

    Just to test, I'd replace it with an absolute path.

    For a proper solution, you could use [rospkg](http://wiki.ros.org/rospkg) or [catkin_pkg](http://wiki.ros.org/catkin_pkg) to first get the path to the pkg where the resource is located, then concatenate that with the relative path you have now.

    Alternatively, you could set the `cwd` of your node to the pkg dir that contains the resource. See [roslaunch/XML/node - Attributes](http://wiki.ros.org/roslaunch/XML/node#Attributes) for that.
