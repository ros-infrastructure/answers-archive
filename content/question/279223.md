    It would appear that the `leg_detector` package (and some others) have been removed from the `people` metapackage (temporarily) as they don't build on Kinetic (or really: with OpenCV3).

    See [wg-perception/people#47](https://github.com/wg-perception/people/issues/47) and [wg-perception/people#53](https://github.com/wg-perception/people/pull/53) for some related discussion and a PR.

    Note: you can always use the [package status page](http://repositories.ros.org/status_page/ros_kinetic_default.html) (this is the one for Kinetic) to see whether a package should be available.

    [Here](http://repositories.ros.org/status_page/ros_kinetic_default.html?q=people) is the status for all packages in `people`.
