  body_markdown: "Two things.\n\n 1. \n> V-REP publishes TF tree:\n> map->odom->base_link->sparton.\
    \ I\n> checked tf and it's being made\n> correctly.\n\n It is `ekf_localization_node`'s\
    \ job to publish the *odom*->*base_link* transform or the *map*->*odom* transform\
    \ (depending on what you have `world_frame` set to). If some other node is publishing\
    \ them, that's a problem.\n\n 2. Get rid of the forward slashes in the `frame_id`\
    \ fields of your input messages. `ekf_localization_node` uses `tf2`, and so it\
    \ automatically strips leading forward slashes from your `*_frame` parameters\
    \ in the launch file. See [this](http://wiki.ros.org/tf2/Migration#Removal_of_support_for_tf_prefix).\n\
    \n "
