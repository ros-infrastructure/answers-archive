    It seems that "use_gui" parameter is not supported in Noetic. The following is what I find in the forum:
    pls refer to [this](https://answers.ros.org/question/363410/joint_state_publisher-window-is-not-shown/).

    >  "you should install the
    > 'joint_state_publisher_gui' package
    > instead and run that. This backwards
    > compatibility option will be removed
    > in Noetic."

    Your launch file is all right in Kinetic and before, but that parameter has been removed in Noetic. So if you wanna show its window, just open a new terminal with the workplace source bash and run:

        Rosrun joint_state_publisher_gui joint_state_publisher_gui
    Then you will see it works.
