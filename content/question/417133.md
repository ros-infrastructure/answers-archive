Hi all. <br>
I was reviewing stuff about nodes' `Clock` and `Time` in general, to use in a project.
I think I understand the difference between using an "external/custom" `Clock` and the one owned by a `Node`, especially when used in simulations.

Now, since I plan to use multiple nodes in my project which will have to exchange data carrying out a timestamp, I thought about making all of their clock stick to the system clock. This way I'm sure they have the same reference point and they are "synchronized" (or rather, as mush as they can be). <br>
Is there a way to accomplish this? Following questions and PRs online I've seen [this line](https://github.com/intel/ros2_intel_realsense/blob/74efb28ba4c4c41d5aaf588c969372616d6f5928/realsense_ros2_camera/src/realsense_camera_node.cpp#L104) being used in a *RealSense* project, but I'm not sure that's what I want or something custom, since I cannot find any reference for it.
