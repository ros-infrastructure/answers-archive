  body_markdown: "You need to include package name with your message type. The exact\
    \ syntax is:\n\n    PackageName/VariableType variable_name\n\nAs described [here](https://answers.ros.org/question/103906/creating-custom-message-using-ros-message-or-custom-message/)\
    \  PackageName/ is left out when referring to message from the same package.\n\
    \nWith this I was able to create the service in my package:\n\n    mbs@mbs-rosPC:~$\
    \ rossrv show mbs_msgs/APMDetection \n    ---\n    std_msgs/Header header\n  \
    \    uint32 seq\n      time stamp\n      string frame_id\n    string class_name\n\
    \    int32 class_index\n    geometry_msgs/Polygon bounding_box\n      geometry_msgs/Point32[]\
    \ points\n        float32 x\n        float32 y\n        float32 z"
