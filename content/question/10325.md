  body_markdown: "Many seem to be having a lot of issues utilizing openni_tracker.\
    \  Hopefully this helps:\n\nI am using ROS Hydro on Ubuntu 12.04 with a Microsoft\
    \ Kinect.  From top to bottom, this is what worked for me:\n\n    sudo apt-get\
    \ install ros-<ros_distro>-openni-camera\n    sudo apt-get install ros-<ros_distro>-openni-launch\n\
    \    sudo apt-get install ros-<ros_distro>-openni-tracker\n\nGo to [this Dropbox](http://www.dropbox.com/sh/jsygeyx8dwa49w6/AAA-XmOWcz9svJBZQ_VKMS3ha)\
    \ from isura (Thanks) and download `NITE-Bin-Linux-x64-v1.5.2.23.tar.zip`.\nExtract\
    \ the zip and tar into a temporary folder (i.e., ~/tmp).\n\n    cd ~/tmp/NITE-Bin-Dev-Linux-x64-v1.5.2.23/\n\
    \    sudo ./install.sh\n\nEnsure your Microsoft Kinect is properly connected,\
    \ then run:\n\n    roslaunch openni_launch openni_launch camera:=openni\nIn a\
    \ separate terminal window run:\n\n    rosrun openni_tracker openni_tracker\n\
    In another terminal window run:\n\n    rosrun rviz rviz\n\nIn Rviz, change Global\
    \ Options > Fixed Frame to openni_depth_optical_frame. \n\n\"Add\" the visualization\
    \ (bottom left) PointCloud2. \n\nChange PointCloud2 >Topic to /openni/depth_registered/points\
    \ (but whatever you pick works). \n\n\"Add\" the visualization (bottom left) TF.\n\
    \nStand in front of the Microsoft Kinect and make the \"Psi Pose\".  Axes should\
    \ appear on all your joints.\n\nI hope this helps you.  There are a lot of different\
    \ versions of NITE out there and this is the one that happened to work for me."
