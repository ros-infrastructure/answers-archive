  body_markdown: "While on Gazebo-classic all features are enabled at all times, even\
    \ if users don't need them, on Ignition users can turn on only the features they\
    \ need. \n\nRight now, all necessary features must be explicitly enabled on the\
    \ SDF file. We're already [working](https://bitbucket.org/ignitionrobotics/ign-gazebo/pull-requests/537/)\
    \ on a way for Ignition to load a few default plugins if the user doesn't specify\
    \ any, but this will only be available in the upcoming minor releases.\n\nUntil\
    \ then, you should include all world plugins that you need, like `Physics` and\
    \ `SceneBroadcaster`. [Here](https://bitbucket.org/ignitionrobotics/ign-gazebo/src/dd4ff2a4c1112a8727c12a2e927e87ca64392611/examples/worlds/empty.sdf#lines-60)'s\
    \ a good list to start with:\n\n\n    <!-- Runs physics -->\n    <plugin\n   \
    \   filename=\"libignition-gazebo-physics-system.so\"\n      name=\"ignition::gazebo::systems::Physics\"\
    >\n    </plugin>\n\n    <!-- Broadcasts the server state to the GUI -->\n    <plugin\n\
    \      filename=\"libignition-gazebo-scene-broadcaster-system.so\"\n      name=\"\
    ignition::gazebo::systems::SceneBroadcaster\">\n    </plugin>\n\n    <!-- Supports\
    \ commands like spawning and teleporting entities -->\n    <plugin\n      filename=\"\
    libignition-gazebo-user-commands-system.so\"\n      name=\"ignition::gazebo::systems::UserCommands\"\
    >\n    </plugin>\n"
