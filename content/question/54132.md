    They install in /opt/ros/groovy/bin. That should be directly accessible from your shell $PATH, if it was set up correctly, but it is not the correct place for **rosrun** to find it.

    This looks like a bug. Several packages, converted to catkin, are mistakenly installing executables in inappropriate places. You should probably [open an issue](https://github.com/ros-perception/perception_pcl/issues) to get that resolved.
