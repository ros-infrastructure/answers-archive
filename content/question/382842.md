    The standard libboost library in ubuntu 20 is 1.65.1, and the ros packages from `apt` are built using that exact version. It is unwise of you to install a different version of the libboost library on your computer. It will make it very difficult to use many of the binary ros packages available from `apt` and other places, as you have just discovered.

    You could re-compile everything from source code, and it would work, but it is a lot of effort.

    To increase visibility I posting my comment as an answer (we received quite some complaints).

    - ROS Noetic works with the [Ubuntu 20.04 tarball](https://github.com/cyberbotics/webots/releases/download/R2021b/webots-R2021b-x86-64.tar.bz2).
    - ROS Melodic works with [the Debian package](https://github.com/cyberbotics/webots/releases/download/R2021b/webots_2021b_amd64.deb) and the [Ubuntu 18.04 tarball](https://github.com/cyberbotics/webots/releases/download/R2021b/webots-R2021b-x86-64_ubuntu-18.04.tar.bz2).

    As of Webots R2021c (or R2022a), ROS Noetic will work with the Debian package (but ROS Melodic will not).

    Under-the-hood: Cyberbotics uses a CI based on Ubuntu 18.04 to build the Debian package. Since the `ros` controller comes as a precompiled binary it is linked against Ubuntu 18.04/Melodic libraries (some of which don't exist on Ubuntu 20.04/Noetic). Cyberbotics have upgraded the CI to use Ubuntu 20.04 (see [cyberbotics/webots#3507](https://github.com/cyberbotics/webots/pull/3507)) for Webots R2021c (or R2022a), so in the future Noetic users will not have any more issues with the Debian packages.
