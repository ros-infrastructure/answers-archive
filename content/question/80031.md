  body_markdown: "I found the solution: I was declaring my point cloud as\n\n    namespace\
    \ velodyne {\n    struct PointType : pcl::PointXYZRGB { ... };\n    struct PointCloud\
    \ : pcl::PointCloud<PointType> { ... };\n    }\n\nbut if I use a typedef instead\
    \ then my compilation error disappears:\n\n    namespace velodyne {\n    struct\
    \ PointType : pcl::PointXYZRGB { ... };\n    typedef PointCloud<PointType> PointCloud;\n\
    \    }\n\nEDIT: Actually, I am now declaring my point type following PCL's model:\
    \ it does not inherit from pcl::PointXYZRGB but rather copies the body of pcl::PointXYZRGB.\
    \ In the end it looks as follows:\n\n    namespace velodyne\n    {\n    struct\
    \ EIGEN_ALIGN16 _PointType\n    {\n      PCL_ADD_POINT4D;\n      PCL_ADD_RGB;\n\
    \      ...\n      EIGEN_MAKE_ALIGNED_OPERATOR_NEW\n    };\n    \n    struct EIGEN_ALIGN16\
    \ PointType : public _PointType\n    {\n      inline PointType () {  ... }\n \
    \   }\n    \n    } // namespace velodyne\n    \n    POINT_CLOUD_REGISTER_POINT_STRUCT\
    \ (velodyne::_PointType,\n        (float, x, x)\n        (float, y, y)\n     \
    \   (float, z, z)\n        (uint32_t, rgb, rgb)\n        ...\n    )\n    POINT_CLOUD_REGISTER_POINT_WRAPPER(velodyne::PointType,\
    \ velodyne::_PointType)\n    \n    namespace velodyne {    \n    typedef pcl::PointCloud<PointType>\
    \ PointCloud;\n    typedef boost::shared_ptr<PointCloud> PointCloudPtr;\n    typedef\
    \ boost::shared_ptr<PointCloud const> PointCloudConstPtr;\n    } // namespace\
    \ velodyne\n\n"
