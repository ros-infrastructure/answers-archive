  body_markdown: "When you open Gazebo, you spin up two processes: \n\n* a server\
    \ `gzserver` for simulating the physics, rendering, and sensors\n\n* a client\
    \ `gzclient` that provides a graphical interface to visualize and interact with\
    \ the simulation\n\nIt's also possible to run these processes separately.\n\n\
    You can read more on Gazebo's architecture on [this](http://gazebosim.org/tutorials?tut=architecture&cat=get_started)\
    \ tutorial."
