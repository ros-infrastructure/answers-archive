  body_markdown: "To access information from another function, you have to store it\
    \ in a higher-level scope.  One way is with the keyword `global`:\n\n    z = 0\
    \  # global variable defined outside of function\n\n    def add_1(x):\n      \
    \  global z\n        z = x + 1\n    \n    print(z)  # output: 0\n    add_1(5)\n\
    \    print(z)  # output: 6\n\nAnother--often better--option is to create a class\
    \ and define member variables:\n\n    class MyClass(object):\n        def __init__(self):\n\
    \            self.z = 0\n        \n        def add_1(self, x):\n            self.z\
    \ = x + 1\n        \n    my_object = MyClass()\n    print(my_object.z)  # output:\
