  body_markdown: "Your turtlebot's URDF should already have joints defined which implicitly\
    \ define the `base_scan` -> `base_link` transformation. These should all be fixed\
    \ joints so it will be a `static` transform. As long as you have a [`robot_state_publisher`](https://docs.ros.org/en/foxy/Tutorials/URDF/Using-URDF-with-Robot-State-Publisher.html)\
    \ node using the URDF, that transformation will be published on /tf_static. \n\
    \nIf you need to perform the frame conversion somewhere in your code to get the\
    \ instantaneous positions in the `base_link` frame, you can look at `tf2_ros`'s\
    \ [`buffer_interface`](https://github.com/ros2/geometry2/blob/4d9745e0feb4338f885b1966804c0072daaeb51e/tf2_ros_py/tf2_ros/buffer_interface.py#L74).\
    \ But many applications (e.g. `rviz`) will be able to do these transformations\
    \ automatically if the `robot_state_publisher` is running. "
