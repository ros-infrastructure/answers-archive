  body_markdown: "You are missing 2 things:\n\n1) \nIn addition to `add_service_files`\
    \ you need to call `generate_messages` (Typically just decomment this in the default\
    \ generated CMakeLists.txt):\n\n    ## Generate added messages and services with\
    \ any dependencies listed here\n    generate_messages(\n      DEPENDENCIES\n \
    \     std_msgs  # and/or other packages containing depended messages\n    )\n\n\
    If you added this your code will compile 'most of the times'. However, the srv\
    \ headers need to be compiled before your exec target and the order of command\
    \ evaluation is not yet fixed. In order to fix the order you add:\n\n2)\n\n  \
    \  add_dependencies( sam_semantic_map_builder_bin ${PROJECT_NAME}_generate_messages_cpp\
    \ )\n\nafter `add_executable`. This makes your exec depending on the <>generate_messages_cpp\
    \ thereby only allowing the exec target to be compiled after the msg headers are\
    \ generated............\n\n\n"
