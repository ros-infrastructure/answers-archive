    In robotics, a twist is a 6x1 column vector of linear and angular velocities. In ROS, this is implemented as a [Twist message](https://docs.ros.org/en/melodic/api/geometry_msgs/html/msg/Twist.html), which you can see for yourself by entering the following in a terminal:

    > rosmsg show geometry_msgs/Twist

    An [interactive marker](http://wiki.ros.org/interactive_markers) is another ROS tool to interface with robots through [rviz](http://wiki.ros.org/rviz). You can drag around this marker, and generally a robot will try to follow it. The server you mentioned publishes twists (velocity commands) to get to the interactive marker pose (position command).

    Here is the [source code](https://github.com/ros-visualization/interactive_marker_twist_server), and here is a [video](https://www.myzhar.com/blog/new-video-teleoperation-using-ros-rviz-interactive-marker-twist-server/) I found of someone using it to drive their robot. Note that this server is configured to work with differential-wheeled (AKA tank-drive or skid-steer) robots.
