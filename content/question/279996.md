  body_markdown: "This is actually not as hard as you're making it, but you probably\
    \ want to take a step back and look at this from first principals. \n\nFirstly\
    \ the ODE integrator is intended to be used on a function so that the ODE function\
    \ can choose to sample the function at different points in order to estimate the\
    \ integral. This is not the case in your system because samples are only available\
    \ when they're measured.\n\nA more appropriate integration method would be the\
    \ [Trapezoidal Rule](https://en.wikipedia.org/wiki/Trapezoidal_rule) which can\
    \ work with an arbitrary set of samples. This is fairly simple to code from first\
    \ principals because you're basically calculating the area of a rectangle and\
    \ a right angle triangle each time step."
