    \n> The scale member means different\n> things for these marker types. The\n>\
    \ POINTS marker uses the x and y members\n> for width and height respectively,\n\
    > while the LINE_STRIP and LINE_LIST\n> markers only use the x component,\n> which\
    \ defines the line width. Scale\n> values are in meters.\n\nThe marker types to\
    \ POINTS, LINE_STRIP and LINE_LIST.\n\n      68     // POINTS markers use x and\
    \ y scale for width/height respectively\n      69     points.scale.x = 0.2;\n\
    \      70     points.scale.y = 0.2;\n      71 \n      72     // LINE_STRIP/LINE_LIST\
    \ markers use only the x component of scale, for the line width\n      73    \
    \ line_strip.scale.x = 0.1;\n      74     line_list.scale.x = 0.1;\n\n"
