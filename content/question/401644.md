  body_markdown: "To convert Twist message to PWM that's what I've done\n\n 1. I've\
    \ created a test script that sends PWM duty cycle signal from the lowest to highest\
    \ at specific time intervals (e.g. 1sec, 2sec and son on).\n 2. For each event\
    \ (e.g. PWM 50 for 2sec) I've measured the distance covered by the robot.\n 3.\
    \ With distances (x) and duty cycles (y) I've calculated the slope(m) and y-intercept(b)\
    \ values of a linear equation y = mx + b\n 4. With the linear function I can calculate\
    \ the duty cycle needed. So, for instance from the Twist linear.x velocity message\
    \ value, defined as meters/second, I can derive the duty cycle. Note that when\
    \ the robot goes from a stop state to a moving state some initial friction needs\
    \ to be considered.\n\n\nExample\n\n\n    def calc_vel(self, x, z): # x and z\
    \ are coming from Twist \n        t = self.track #distance between wheels\n  \
    \      \n        r_vel = x + ((z * t) /2)\n        l_vel = x - ((z * t) /2)\n\
    \        \n        dc_r = calc_duty_cycle(r_vel)\n        dc_l = calc_duty_cycle(dc_l)\n\
    \        \n        return dc_r, dc_l\n    \n    def calc_duty_cycle(self, vel):\n\
    \        # linear equation variables defined by experimentation\n        M_SLOPE\
    \ = 50\n        Y_INTERCEPT = 2\n        \n        return M_SLOPE * vel + Y_INTERCEPT"
