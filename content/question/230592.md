  body_markdown: "you need to change the **package_dir** in `setup.py` from \"**src**\"\
    \ to \"**scripts**\". And **packages** in `setup.py` should be \"**middle_abstraction**\"\
    , the directory that contains the python file.\n\n    ## ! DO NOT MANUALLY INVOKE\
    \ THIS setup.py, USE CATKIN INSTEAD\n    \n    from distutils.core import setup\n\
    \    from catkin_pkg.python_setup import generate_distutils_setup\n    \n    #\
    \ fetch values from package.xml\n    setup_args = generate_distutils_setup(\n\
    \        packages=['middle_abstraction'],#python pkg name\n        package_dir={'':\
    \ 'scripts'},\n        requires=['std_msgs', 'rospy', 'message_filters', 'gps_common',\
    \ 'sensor_msgs']\n    )\n    \n    setup(**setup_args) \n\nthen create a  **__init__.py**\
    \ file in the directory **middle_abstraction**, and don't forget to uncomment\
    \ the `catkin_python_setup()` statement in **CMakeLists.txt** file.\n\nThen after\
    \ `catkin_make`, you can import the file like this\n\n**a.py**\n\n     import\
    \ sys\n     sys.path.append(\"..\")\n     import middle_abstraction.function_unit"
