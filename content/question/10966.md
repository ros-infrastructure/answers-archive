  body_markdown: |-
    The <code>base_local_planner::CostmapModel</code> will help you do these footprint checks pretty easily. You can check out the documentation <a href="http://www.ros.org/doc/api/base_local_planner/html/classbase__local__planner_1_1CostmapModel.html">here</a>. Basically, you'll create the <code>CostmapModel</code> object by passing it a reference to a <code>costmap_2d::Costmap2D</code> object, and then call <code>footprintCost</code> on it. If the cost is negative, that footprint position is in collision with an object. I should also mention that this is the internal API of the navigation stack, so stability isn't guaranteed, but things haven't changed with that code in awhile so you should probably be OK.
