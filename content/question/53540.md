    \ <NAME_OF_LIBRARY_TO_LINK>)` in your CmakeLists.txt.  There wasn't any ros-specific\
    \ cmake macro for using an installed library in a node in rosbuild, and if I understand\
    \ correctly, the new catkin build system does not use ANY ros-specific macros.\
