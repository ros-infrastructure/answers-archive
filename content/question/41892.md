  body_markdown: "I assume you want to get the corners of your robot in the map frame.\n\
    \nThe easiest way to do that is to use tf's transformPose. Create for poses in\
    \ the robot's base_link frame and transform all of them to map. Have a look at\
    \ the following code snippet (assuming that you already have an instance of `tf::TransformListener`\
    \ bound to the variable `transform_listener`):\n\n    tf::Stamped<tf::Pose> corner1(\n\
    \        tf::Pose(tf::Quaternion(0, 0, 0, 1), tf::Vector3(0.30, -0.45, 0.0)),\n\
    \        ros::Time(0), \"base_link\");\n    tf::Stamped<tf::Pose> corner2(\n \
    \       tf::Pose(tf::Quaternion(0, 0, 0, 1), tf::Vector3(0.30, 0.45, 0.0)),\n\
    \        ros::Time(0), \"base_link\");\n    tf::Stamped<tf::Pose> corner3(\n \
    \       tf::Pose(tf::Quaternion(0, 0, 0, 1), tf::Vector3(-0.30, -0.45, 0.0)),\
    \ \n        ros::Time(0), \"base_link\");\n    tf::Stamped<tf::Pose> corner4(\n\
    \        tf::Pose(tf::Quaternion(0, 0, 0, 1), tf::Vector3(-0.30, 0.45, 0.0)),\
    \ \n        ros::Time(0), \"base_link\");\n\n    tf::Stamped<tf::Pose> transformed_corner_1;\n\
    \    transform_listener.transformPose(\"map\", corner_1, transformed_corner_1);\n\
    \    tf::Stamped<tf::Pose> transformed_corner_2;\n    transform_listener.transformPose(\"\
    map\", corner_2, transformed_corner_2);\n    tf::Stamped<tf::Pose> transformed_corner_3;\n\
    \    transform_listener.transformPose(\"map\", corner_3, transformed_corner_3);\n\
    \    tf::Stamped<tf::Pose> transformed_corner_1;\n    transform_listener.transformPose(\"\
    map\", corner_4, transformed_corner_4);"
