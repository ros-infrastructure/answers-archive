    That should be pretty easy to do in Python (and only slightly more difficult in C++). For the subscription part, you can start with the [subscriber example](http://wiki.ros.org/ROS/Tutorials/WritingPublisherSubscriber%28python%29), but adapt it to subscribe to [rosgraph_msgs/Log](http://docs.ros.org/api/rosgraph_msgs/html/msg/Log.html) messages on `/rosout_agg` instead of `std_msgs/String` messages on `/chatter`. There's some more details about rosout on [the wiki page](http://wiki.ros.org/rosout). For the file writing part, you can either use an XML or HTML writer in Python (a search engine will turn up many) or use regular file I/O and hand-code the HTML.
