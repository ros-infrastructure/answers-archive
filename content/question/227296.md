  body_markdown: "Hi!\n\nThere are two different possibilities than can cause this\
    \ error.\n\n 1. You have not installed the control_toolbox package. To do this\
    \ the following command should be enough.\n\n    `sudo apt-get install ros-indigo-control-toolbox`\n\
    \n 2. If this is not the case and you already have installed it. Then there is\
    \ a problem with the sourcing of that package. You have to make sure that the\
    \ route where that package is installed is in the $ROS_PACKAGE_PATH. Just do a\
    \ `echo  $ROS_PACKAGE_PATH`  to see the paths in your ROS_PACKAGE_PATH.\n\nI hope\
    \ this helps!\n\n \n\n"
