  body_markdown: |2+
     1. The state estimation nodes have no concept of sensor parameters. It also has no concept of inter-sensor relationships. It assumes that your sensor outputs one of the [supported message types](http://docs.ros.org/lunar/api/robot_localization/html/index.html), and that those sensor messages conform to [ROS standards](http://www.ros.org/reps/rep-0103.html).
     2. No. One of the key features of the package is that it can support an arbitrary number of sensors with varying frequencies.
