  body_markdown: "The old queue_size parameter not in the create_subscription method.\n\
    Now it is integrated inside the rclcpp::Qos data structure as \"depth\" field.\n\
    \nThere are a few built-in quality of services policies that you may want to use.\
    \ These have some predefined values for its fields. For example, SensorDataQoS\
    \ defines depth=10. Nonetheless, you could override this value using the Qos::keep_last(depth)\
    \ method.\n\nFor example:\n\n     rclcpp::SensorDataQoS qos;\n     qos.keep_last(*queueSize);\n\
    \     int queueSize = 10;\n     auto sub = node->create_subscription<MessageType>(\"\
    topicName\", qos, callbackfn); \n\nReferences:\n- https://index.ros.org/doc/ros2/Concepts/About-Quality-of-Service-Settings/\n\
    - http://docs.ros2.org/dashing/api/rclcpp/classrclcpp_1_1QoS.html\n \n"
