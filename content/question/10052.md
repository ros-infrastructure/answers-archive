    Yes, you can do it with opencv's [drawing functions](http://opencv.willowgarage.com/documentation/cpp/core_drawing_functions.html). Use [cvbridge](http://www.ros.org/wiki/cv_bridge/Tutorials/UsingCvBridgeToConvertBetweenROSImagesAndOpenCVImages) to create cv::Mat from sensor_msg::image without copying.

    If you use pyqt anyway, why not use the drawing functions of qt? You can convert the images to QImage (e.g. as it is done [here (c++)](http://www.ros.org/doc/api/rgbdslam/html/openni__listener_8cpp_source.html#l00319) from an opencv image) and use a QPainter, constructed with the image as parameter to use drawEllipse.
