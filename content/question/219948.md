    Another feasible approach would be using a small single board computer (SBC) as the main robot controller (using the Raspberry Pi2 with ROS for instance is pretty painless by now). The footprint of such SBCs is very small and you are then free to either add a display to the SBC directly, or via Ethernet connect a tablet/small netbook/whatever with whatever OS suits you (for instance having a UI running in a [browser via robot web tools](http://robotwebtools.org/tools.html)). The advantage would be that you could avoid experiments with installing Ubuntu/ROS on a tablet this way.
