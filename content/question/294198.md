    *extract_images* can only save images with bgr8 encoding. You could try using [image_saver](http://wiki.ros.org/image_view#image_view.2BAC8-diamondback.image_saver) which provide option for setting encoding of the image topic, something like so:

        rosrun image_view image_saver _encoding:=16UC1 image:=/camera/depth/image_raw
