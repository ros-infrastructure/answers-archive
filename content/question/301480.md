  body_markdown: "Yes it is possible to do exactly what you want. The package you'll\
    \ be using is [ros_type_introspection](http://wiki.ros.org/ros_type_introspection)\
    \ this allows you to dynamically access the meta information of a message and\
    \ extract the values from any message type.\n\nThere is tutorial that shows you\
    \ how to do exactly what you're asking about [here](http://wiki.ros.org/ros_type_introspection/Tutorials/GenericTopicSubscriber).\
    \ \n\nThe only limitation of this technique is that you can't automatically create\
    \ the original ros message type objects, you'd have to code for each one individually.\
    \ \n\nHope this helps.\n\n\n"
