    Yes.

    Almost all AMD processors are `amd64` architecture based, which is one of the supported architectures in ROS 2.

    See for instance the Foxy Fitroy description in [REP 2000: ROS 2 Releases and Target Platforms](https://www.ros.org/reps/rep-2000.html#foxy-fitzroy-may-2020-may-2023), which states that `amd64` is a *Tier 1* supported architecture.

    Note: whether the *performance* of the CPU you select will be sufficient for your use-cases we cannot say, as we do not know what those are.
