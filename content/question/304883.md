    If you have a turtlebot ( from https://www.turtlebot.com/ ) then you probably want to find the install instructions for your model of turtlebot and follow them.

    If you have a different robot or you're trying to use turtlesim to control a real robot, you probably want to write your own ROS node to convert Twist messages to motor commands. This looks like an [excellent tutorial](https://admin.insights.ubuntu.com/2018/03/09/your-first-robot-the-driver-4-5/) that goes through the basics.
