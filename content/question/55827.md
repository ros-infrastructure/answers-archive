  body_markdown: "The easiest solution would be to launch the `openni_launch` with\
    \ the `camera` argument set.  See the documentation at the bottom of [this page](http://www.ros.org/wiki/openni_launch).\
    \  So the following command \n\n    roslaunch openni_launch openni.launch camera:=openni\n\
    \nwill set the first word of all of the frames associated with your Kinect to\
    \ be \"openni\" instead of \"camera\". This should merge your `tf` tree.\n"
