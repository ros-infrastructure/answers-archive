    \   export ROS_MASTER_URI=http://My IP Adress of my master computer:11311\n\n\
    This is corect.\n\n>     export ROS_HOSTNAME=My IP Adress of my master computer\n\
    >     export ROS_IP=My IP Adress of my master computer\n\nThis is not really correct\
    \ (or at least: not really needed): if you're specifying IP addresses, *only*\
    \ use `ROS_IP`. If you're using hostnames everywhere, *only* set `ROS_HOSTNAME`.\n\
    \nSo remove the `export ROS_HOSTNAME=..` line.\n\n> And i have my second computer,\
    \ the slave, where talker.py is running.\n> I wrote on the file bashrc those 3\
    \ lines :\n> \n>     export ROS_MASTER_URI=http://My IP Adress of my master computer:11311\n\
    \nThis is correct.\n\n>     export ROS_HOSTNAME=My IP Adress of my master computer\n\
    \nThis is incorrect.\n\nApart from what I mentioned earlier about not setting\
    \ `ROS_HOSTNAME` to an IP address, you're also using the \"adress of [your] master\
    \ computer\".\n\nBoth `ROS_HOSTNAME` as well as `ROS_IP` must be set to the hostname\
    \ and IP address of the machine itself, *not* of any other machine in your network.\n\
    \n*Only* `ROS_MASTER_URI` could contain an IP address or hostname of another machine,\
    \ and then only when the master is actually running on some other host (such as\
    \ in your case).\n\n>     export ROS_IP=My IP Adress of my slave computer\n\n\
    This would again be correct.\n"
