    So after reading a ton of source code and docs, it turns out that only **some** of the linters provided in the [ament_lint](https://github.com/ament/ament_lint) repo support any kind of "exclude" feature. They are:

     - [ament_cmake_flake8](https://github.com/ament/ament_lint/blob/898bfbf241ca5922307b9f6540eb6105e1fae09c/ament_cmake_flake8/cmake/ament_flake8.cmake)
     - [ament_cmake_copyright](https://github.com/ament/ament_lint/blob/c01b035957dda939e8cffd33f431d26bd83ce233/ament_cmake_copyright/cmake/ament_copyright.cmake#L22)
     - [ament_cpplint](https://github.com/ament/ament_lint/blob/c01b035957dda939e8cffd33f431d26bd83ce233/ament_cpplint/ament_cpplint/main.py#L81)
     - [ament_cmake_cpplint](https://github.com/ament/ament_lint/blob/c01b035957dda939e8cffd33f431d26bd83ce233/ament_cmake_cpplint/cmake/ament_cpplint.cmake#L29)
     - [ament_cmake_uncrustify](https://github.com/ament/ament_lint/blob/c01b035957dda939e8cffd33f431d26bd83ce233/ament_cmake_uncrustify/cmake/ament_uncrustify.cmake#L34)
     - [ament_cmake_cppcheck](https://github.com/ament/ament_lint/blob/c01b035957dda939e8cffd33f431d26bd83ce233/ament_cmake_cppcheck/cmake/ament_cppcheck.cmake#L28)

    Everything else doesn't seem to have any exclude feature implemented (although don't let me stop you from implementing this feature if you have the time).

    As for actually *implementing* these exclusions, you have two methods:

     1. Set `AMENT_LINT_AUTO_FILE_EXCLUDE` if you're using [ament_lint_auto](https://github.com/ament/ament_lint/blob/c01b035957dda939e8cffd33f431d26bd83ce233/ament_lint_auto/doc/index.rst) - see the readme for implementation details
     2. Setting the exclude paths explicitly, when you manually call the linter in your CMakeLists file e.g:

            file(GLOB_RECURSE EXCLUDE_FILES
                build/*
                install/*
            )
            ament_cmake_cpplint(EXCLUDE ${EXCLUDE_FILES})

    For further reading, here are some relevant issues from the repo:

     - [EXCLUDE argument inconsistency #354](https://github.com/ament/ament_lint/issues/354)
     - [[ament_lint_auto] General file exclusion lists #343](https://github.com/ament/ament_lint/issues/343)
     - [ament_cmake_flake8 ignores value of AMENT_LINT_AUTO_FILE_EXCLUDE #423](https://github.com/ament/ament_lint/issues/423)

## The Problem (TL;DR) ##

I'm trying to run a series of tests and linters with `colcon test`. But for some reason, colcon or CMake (not sure which) seems to test a bunch of build files, which are auto-generated and generate a ton of errors that have nothing to do with my source code, but clutter the test output, making it very difficult to actually figure out if the source code needs to be fixed.

How do I explicitly tell colcon test what folders to test (or not)?
