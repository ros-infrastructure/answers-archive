    Solved!

    I needed to add some repositories on Ubuntu before the installation. You should go to Software and Update/Ubuntu software and mark all the options and select the correct server country for the installation. In my case:
    - Check -> Canonical-supported free and open-source software (main)
    - Check -> Community-maintained free and open-source software (universe)
    - Check -> Proprietary drivers for devices (restricted)
    - Check -> Software restricted by copyright or legal issues (multiverse)
    Download from: http://es-mirrors.evowise.com/ubuntu
    The last link depends of the region that you live
