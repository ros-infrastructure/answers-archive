  body_markdown: "I recently took over maintenance for `rosdoc_lite`, but am not yet\
    \ familiar with the code. Please bear with me while trying to figure this out.\n\
    \nDoxygen is invoked with a [template file that sets CALL_GRAPH = NO](https://github.com/ros-infrastructure/rosdoc_lite/blob/master/src/rosdoc_lite/templates/doxy.template#L1680).\
    \ I don't see any option for overriding that template file or replacing it with\
    \ one of your own. Some variables, such as FILE_PATTERNS, can have [per-package\
    \ values](http://www.ros.org/wiki/Doxygen#rosdoc:_Default_Doxygen_Settings) defined\
    \ in `rosdoc.yaml`, but CALL_GRAPH is not one of them.\n\nThe comments immediately\
    \ before recommend enabling caller graphs only for selected functions, using the\
    \ `\\callergraph` command. Is that an option for you?\n\n**UPDATE**: the main\
    \ purpose of `rosdoc_lite` is automatically generating documentation for packages\
    \ listed on the ROS wiki or similar destinations. The main reason for running\
    \ it locally is to check updates to those docs before committing them. \n\nIf\
    \ your documentation goals differ, running Doxygen directly may make more sense."
