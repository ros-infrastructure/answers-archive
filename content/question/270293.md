    I'm not aware of any. The [lidar-lite-ros-scanner-driver](https://github.com/r3n33/lidar-lite-ros-scanner-driver) appears to use an Arduino that performs the i2c interfacing and then data is transmitted to a ROS PC via USB (Serial). There is code for interfacing the sensor via a Pi out there (Python code [here](https://www.raspberrypi.org/forums/viewtopic.php?f=91&t=179248) for instance), so if you want to interface directly, you might have to write some code yourself.
