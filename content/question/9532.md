  body_markdown: "I believe you're talking about the queue size parameter in roscpp.\
    \  From the [roscpp overview](http://www.ros.org/wiki/roscpp/Overview/Publishers%20and%20Subscribers):\n\
    \n**for publishing**\n> queue_size [required]\n> \n> This is the size of the outgoing\n\
    > message queue. If you are publishing\n> faster than roscpp can send the\n> messages\
    \ over the wire, roscpp will\n> start dropping old messages. A value\n> of 0 here\
    \ means an infinite queue,\n> which can be dangerous.\n\n**for subscribing**\n\
    \n> queue_size\n> \n> This is the incoming message queue size roscpp will use\
    \ for your\n> callback. If messages are arriving too\n> fast and you are unable\
    \ to keep up,\n> roscpp will start throwing away\n> messages. A value of 0 here\
    \ means an\n> infinite queue, which can be\n> dangerous."
