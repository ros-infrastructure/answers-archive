    Hello [@osilva](https://answers.ros.org/users/84086/osilva/), I believe what you are referring to is integration of Groot with the Nav2 stack.

    You can however install groot on foxy following the documentation [here](https://github.com/BehaviorTree/Groot#compilation-instructions-ros). Just use colcon build --packages-select groot instead of catkin_make

    You can then run it with:

        ./<your-workspace-path>/build/groot/Groot
