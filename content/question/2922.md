    My first guess is that you're using a non-NVIDIA GPU.  There are [reports](https://bitbucket.org/osrf/drcsim/issue/283/drcsim-recently-stopped-working-with-intel) that the change in drcsim 2.6 to using the GPU for laser scan generation causes gazebo to crash immediately on Intel GPUs.

    There's a [proposed patch](https://bitbucket.org/osrf/drcsim/pull-request/317/files-for-cpu-lidar/diff) that adds launch files to let you bring up simulation using the CPU-based laser.  You might try that.

    I had this problem with the latest (stable) version of gazebo (1.8.0) and drcsim (2.6.1).  I also had an error about the connection manager - possibly also related to this question [[link]](http://answers.gazebosim.org/question/2388/drcsim-drcsim-nightly-cant-roslaunch-either/).
