    > ... how to write a callback without using `ROS_INFO` ...

    [Here](http://wiki.ros.org/ROS/Tutorials/WritingPublisherSubscriber%28c%2B%2B%29) you go. Please note that `ROS_INFO` is not doing any magic. Just, assume `ROS_INFO( ... )` equivalent of `printf( ... )`. If you do not need any printing/logging, do not use `ROS_INFO`.

    > I just need to store these data in new variables and nothing more ...

    Create 2 global/class variables, say x and y, and then assign x and y to the values received inside the callback.
