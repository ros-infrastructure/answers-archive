  body_markdown: "The robot variant doesn't include ros_control however:\n\nYou can\
    \ download the zip for ros_control from git and include the extracted `ros_control-hydro-devel`\
    \ folder with your other source folders in `~/ws_catkin/src` during the install.\
    \ Catkin will pick it up during make call. \n\n    ./src/catkin/bin/catkin_make_isolated\
    \ --install\n\nOtherwise outside of installation, see the catkin [Tutorial](http://wiki.ros.org/catkin/Tutorials/using_a_workspace)\
    \ on building and using catkin packages in a workspace."
