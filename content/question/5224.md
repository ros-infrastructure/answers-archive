    By default Gazebo doesn't publish joint states. You would have to write a [Model Plugin](http://gazebosim.org/wiki/Tutorials/1.9/plugins) that outputs the joint state for a model every iteration.

    Start by looking at an existing plugin, like the [JointTrajectoryPlugin](https://bitbucket.org/osrf/gazebo/src/6f357235d464f26f5ffc61f90e17e67f788703f5/plugins/JointTrajectoryPlugin.cc?at=default).
