    \ to put in your robot.\n\nThen you have to export it to .obj NOT .dae.\n\nThen\
    \ open the .obj file with MESHLAB and save it to .dae. You should try opening\
    \ the file again with meshlab because it gives some crazy error about not having\
    \ a notexture.png file. Copy random .png file and call it notexture.png.\n\nThen\
    \ add your mesh to the .urdf file and the folder with the textures. They should\
    \ be .png textures.\n\nAnd its done!\n\n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/14248773423934803.png)"
