  body_markdown: "A topic is \"created\" (and will show up when using ROS introspection\
    \ tools such as `rostopic`) as soon as a publisher or subscriber to that topic\
    \ is created within a ROS node. From the [Python](http://wiki.ros.org/ROS/Tutorials/WritingPublisherSubscriber%28python%29)\
    \ and [C++](http://wiki.ros.org/ROS/Tutorials/WritingPublisherSubscriber%28c%2B%2B%29)\
    \  creating a publisher/subscriber tutorials:\n\nC++:\n\n    ros::Publisher chatter_pub\
    \ = n.advertise<std_msgs::String>(\"chatter\", 1000);\n\nPython:\n    \n    pub\
    \ = rospy.Publisher('chatter', String, queue_size=10)"
