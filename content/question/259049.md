    \ and [package.xml](https://github.com/ros-visualization/rviz/blob/kinetic-devel/package.xml)\
    \ of the [rviz](https://github.com/ros-visualization/rviz) package\n\n**[UPDATE]**\
    \ \n\nIf what you want is to substitute OpenGL for your own awesome implementation\
    \ of GL (lets call it myAwesomeGL) I would do the following:\n\n- Create (if you\
    \ don't already have it) a FindMyAwesomeGL.cmake file and install it so that cmake\
    \ can find it.\n- In the file package.xml substitute:\n\nthis\n\n    <build_depend>opengl</build_depend>\n\
    \    ...\n    <run_depend>opengl</run_depend>\n\nfor\n\n    <build_depend>myawesomegl</build_depend>\n\
    \    ...\n    <run_depend>myawesomegl</run_depend>\n\n- In the file CMakeLists.txt\
    \ substitute:\n\nthis:\n\n    find_package(OpenGL REQUIRED)\n\nfor this \n\n \
    \   find_package(MyAwesomeGL REQUIRED)\n\nand int all CMakeLists.txt in all subsequent\
    \ directories substitute all occurrences of\n\n    ${OPENGL_INCLUDE_DIR}\n   \
    \ ${OPENGL_LIBRARIES}\n\nfor\n\n    ${MYAWESOMEGL_INCLUDE_DIR}\n    ${MYAWESOMEGL_LIBRARIES}"
