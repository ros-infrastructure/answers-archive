  body_markdown: "I don't like waiting for updates on Ubuntu either.\n\nThe main problems\
    \ you will face for working with ROS on Archlinux are:\n\n1. ROS refers to \"\
    python2\" as \"python\" in its script files.\n(This most likely explains most\
    \ of the errors you are facing.)\n2. Many ROS packages do not compile with GCC\
    \ 4.6.\n\nThe fix is to preferentially use python2 in lieu of python and gcc-4.5\
    \ in lieu of gcc-4.6.\n\n    # install GNU compilers 4.5  \n    yaourt -S python2\
    \ gcc45  \n      \n    mkdir /usr/local/bin/alt  \n      \n    ln -s /usr/bin/python2\
    \ /usr/local/bin/alt/python  \n    ln -s /usr/bin/gcc-4.5 /usr/local/bin/alt/gcc\
    \  \n    ln -s /usr/bin/g++-4.5 /usr/local/bin/alt/g++  \n      \n    export PATH=/usr/local/bin/alt:$PATH\
    \  \n\nYou would want to put the last line in an initialization script that you\
    \ run every time before using ROS in a new terminal. Don't add this to your /etc/profile.d/\
    \ as it will break some packages in Archlinux.\n\nAdditionally, the dependencies\
    \ are not detected very well, so you have to determine which libraries are missing\
    \ from the error logs.\n\nFor more information, see my other [post](http://evorobo.blogspot.com/2011/07/robotics-operating-system.html).\n\
    \nEdit:\nPromoting gcc-4.5 and g++-4.5 does not appear to work, as configure refers\
    \ to them by the exact path: /usr/bin/gcc\n\nInstead, you have to edit the CMakeLists.txt\
    \ file for each package that fails to compile with gcc 4.6.\n\nAdd the following\
    \ lines **after** the rosbuild directives (if any).\n\n    set (CMAKE_C_COMPILER\
    \ gcc-4.5)  \n    set (CMAKE_CXX_COMPILER g++-4.5)  "
