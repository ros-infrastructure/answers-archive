  body_markdown: "The plugin should be in a lib that can be loaded by another process,\
    \ it should not implement the process itself. I. e. there should not be a main()\
    \ in your process and you should create a library rather than an executable.\n\
    \n This means remove your main and change\n\n\n    add_executable(Project_node\
    \ \n            src/System/system.cpp \n            src/Gui/gui.cpp     \n   \
    \         ${MOC_SRC_H} \n            ${MOC_GUI_H}\n    )       \n\nfor \n\n  \
    \  add_library(rqt_project \n            src/System/system.cpp \n            src/Gui/gui.cpp\
    \     \n            ${MOC_SRC_H} \n            ${MOC_GUI_H}\n    )\n\nin your\
    \ CMakeLists.txt. Note that `rqt_project` will correspond to an output library\
    \ file named `librqt_project.so`. This in turn is loaded because in your plugin.xml\
    \ you state: `<library path=\"lib/librqt_project\">`, i. e. the postfix of the\
    \ library path in plugin.xml must correspond with the target name of  add_library\
    \ in the CMakeLists.txt.\n\nYou can launch your plugin then via rgt_gui (it should\
    \ appear there amongst the plugins) or standalone using a script like the one\
    \ mentioned here:\nhttp://answers.ros.org/question/124706/how-to-run-a-newly-created-rqt-plugin/#191986\n\
    \n\n\nEdit:\n\nMaybe you have to add a group tag to make your plugin appear in\
    \ rqt_gui, e. g.:\n\n    <library path=\"lib/libfoobar\">\n      <class name=\"\
    foo/Bar\" type=\"foo::Bar\" base_class_type=\"rqt_gui_cpp::Plugin\">\n       \
    \ <description>\n          A GUI plugin to view a sensor_msgs/Image topic in an\
    \ foobar manner.\n        </description>\n        <qtgui>\n          <group>\n\
    \            <label>Visualization</label>\n            <icon type=\"theme\">folder</icon>\n\
    \            <statustip>Plugins related to visualization.</statustip>\n      \
    \    </group>\n          <label> blub image view</label>\n          <icon type=\"\
    theme\">image-x-generic</icon>\n          <statustip>A GUI plugin to view foobar\
    \ topic in some manner.</statustip>\n        </qtgui>\n      </class>\n    </library>\n\
    \n"
