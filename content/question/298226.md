    Check [this past answer too](https://answers.ros.org/question/195391/there-is-an-example-of-a-working-example-of-serial-port-on-ros-indigo-and-c/)\
    \ btw.\n\nSo you in order to get the data in ROS, you need to make a wrapper for\
    \ your sensor, if you know it's serial communication check the serial support\
    \ for ROS here.\n\nAlso the guy from the answer made a nice simple example of\
    \ ROS [serial communication here](https://github.com/garyservin/serial-example/blob/master/src/serial_example_node.cpp)\n\
    \nFrom his code:\n\n    #include <ros/ros.h>\n    #include <serial/serial.h>\n\
    \    #include <std_msgs/String.h>\n    #include <std_msgs/Empty.h>\n    \n   \
    \ serial::Serial ser;\n    \n    void write_callback(const std_msgs::String::ConstPtr&\
    \ msg){\n        ROS_INFO_STREAM(\"Writing to serial port\" << msg->data);\n \
    \       ser.write(msg->data);\n    }\n        \n    int main (int argc, char**\
    \ argv){\n        ros::init(argc, argv, \"serial_example_node\");\n        ros::NodeHandle\
    \ nh;\n    \n        ros::Subscriber write_sub = nh.subscribe(\"write\", 1000,\
    \ write_callback);\n        ros::Publisher read_pub = nh.advertise<std_msgs::String>(\"\
    read\", 1000);\n    \n        try\n        {\n            ser.setPort(\"/dev/ttyACM0\"\
    );\n            ser.setBaudrate(9600);\n            serial::Timeout to = serial::Timeout::simpleTimeout(1000);\n\
    \            ser.setTimeout(to);\n            ser.open();\n        }\n       \
    \ catch (serial::IOException& e)\n        {\n            ROS_ERROR_STREAM(\"Unable\
    \ to open port \");\n            return -1;\n        }\n    \n        if(ser.isOpen()){\n\
    \            ROS_INFO_STREAM(\"Serial Port initialized\");\n        }else{\n \
    \           return -1;\n        }\n    \n        ros::Rate loop_rate(5);\n   \
    \     while(ros::ok()){\n    \n            ros::spinOnce();\n    \n          \
    \  if(ser.available()){\n                ROS_INFO_STREAM(\"Reading from serial\
    \ port\");\n                std_msgs::String result;\n                result.data\
    \ = ser.read(ser.available());\n                ROS_INFO_STREAM(\"Read: \" <<\
    \ result.data);\n                read_pub.publish(result);\n            }\n  \
    \          loop_rate.sleep();\n    \n        }\n    }\n\nI think it doesn't get\
    \ any simpler than that. Once you read the data from the serial port you can use\
    \ it in your project.\nGood luck and happy coding!"
