  body_markdown: |-
    Create a catkin [workspace](http://wiki.ros.org/catkin/Tutorials/create_a_workspace) and in the `src` directory under it clone the project and the velodyne_pointcloud package. Since the project and driver packages depend on pcl and velodyne packages you will need to install them. You can see exactly on which packages the project depend in their `package.xml` files. These packages you can install using the `sudo apt install` command:<br>

        sudo apt install ros-kinetic-pcl-ros
        sudo apt install ros-kinetic-pcl-conversions
        sudo apt install ros-kinetic-velodyne-driver
        sudo apt install ros-kinetic-velodyne-driver
        sudo apt install ros-kinetic-velodyne-msgs

    ass well as other packages listed in the [package.xml](https://github.com/ros-drivers/velodyne/blob/master/velodyne_pointcloud/package.xml).
