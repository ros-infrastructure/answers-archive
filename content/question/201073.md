  body_markdown: "Yes, it is definitely possible (and very common) to use external\
    \ libraries in ROS nodes. Depending on the language and library you want to use,\
    \ the required steps will change somewhat, but in general ROS tries to follow\
    \ the typical usage patterns of the language (e.g., CMake for C++, etc.).\n\n\
    However, for libraries that extremely popular to use with ROS, such as OpenCV,\
    \ pre-baked distributions are already built for several platforms. This is done\
    \ so that you don't have to build (and continually update) it yourself, and to\
    \ guarantee a consistent library version for other packages in the ROS build farm\
    \ that also require OpenCV. \n\nFor example, if you're using ROS Indigo on Ubuntu,\
    \ you can just do this:\n\n    sudo apt-get install ros-indigo-vision-opencv\n\
    \nAnd then you can follow the [documentation and tutorials on the ROS vision_opencv\
    \ page](http://wiki.ros.org/vision_opencv) for examples on how to use it.\n"
