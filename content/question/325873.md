  body_markdown: "This will be a lot of work so make sure it is worth it. \n\n 1.\
    \ Import your point cloud into Meshlab or CloudCompare and generate a mesh from\
    \ it. [Here](https://github.com/awhitty/zephyr-3d/wiki/Turning-Point-Clouds-Into-3D-Collada-Objects)\
    \ is an example tutorial.\n 2. Export the model as a .dae (collada object).\n\
    \ 3. Import the model into gazebo  following this [tutorial](http://gazebosim.org/tutorials/?tut=import_mesh)\
    \ \n 4. Make sure the collision model is the same as the visual model.\n\nGood\
    \ luck and I hope you have a good computer. To be entirely honest, if you world\
    \ is simply the inside of a building then I would suggest you model it by hand\
    \ following [this tutorial](http://gazebosim.org/tutorials?cat=build_world&tut=building_editor)."
