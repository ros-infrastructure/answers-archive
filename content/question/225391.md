    Hi,

    RTAB-Map can use laser scans to refine odometry transformations (e.g., wheel odometry). So yes, if you have a LiDAR, this will improve the map. See [Kinect+Odom+2D laser](http://wiki.ros.org/rtabmap_ros/Tutorials/SetupOnYourRobot#Kinect_.2B-_Odometry_.2B-_2D_laser) configuration for example (many RTAB-Map videos used this configuration). Visual odometry is not used in this configuration to avoid the problems you mentioned (the environment has many white walls).
