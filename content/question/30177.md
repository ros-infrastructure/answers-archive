    If there aren't too many args to the launch, you can write a ros node that simply uses system process calls (eg, using python's [subprocess](http://docs.python.org/library/subprocess.html) module) to execute the roslaunch command as you would from the command line.

    Since you can pass <machine> tags as args to nodes, the node could run the launch command remotely.
