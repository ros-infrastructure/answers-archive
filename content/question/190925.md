    According to the [ARM Hydro status page](http://packages.namniart.com/repos/status/hydro.html?q=sicktoolbox), the sick packages should be installable through apt (they're currently marked as outdated because I'm working on updated builds).

        sudo apt-get install ros-hydro-sicktoolbox-wrapper

        deb http://packages.namniart.com/repos/ros raring main
