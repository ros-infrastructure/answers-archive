    \ which is in the same `turtlebot_gazebo` package. You must first launch the simulation,\
    \ then map your environment with `roslaunch turtlebot3_slam turtlebot3_slam.launch`,\
    \ save the map with `rosrun map_server map_saver`, and finally use the launch\
    \ file `roslaunch turtlebot3_navigation turtlebot3_navigation.launch map_file:=$HOME/map.yaml`.\
