    \ You should copy the launch file to a package you've created (any package will\
    \ do). Then change the line \n\n>     <arg name=\"world_name\" value=\"$(find\
    \ turtlebot_gazebo)/worlds/empty.world\"/>\nto \n\n>     <arg name=\"world_name\"\
    \ value=\"worlds/willowgarage.world\"/>\n\nI just tested it and it works fine\
    \ on my computer. Good luck!"
