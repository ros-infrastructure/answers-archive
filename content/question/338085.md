    \ of URDF parsers, even if indeed this is technically left unspecified in the\
    \ URDF \"specification\". Unfortunately, there is no issue tracker for the URDF\
    \ specification itself (see https://github.com/ros/urdfdom_headers/issues/62),\
    \ so no obvious place to debug this. Furthermore, note that even your definition\
    \ are not completely unambiguous, as a definition for the meaning of the elements\
    \ of the matrix and by the matrix itself should be provided to avoid confusion.\
    \ \n\nHowever, in my experience without a better reference the KDL URDF parser,\
    \ one of the first libraries that uses this URDF tags, may be a good reference.\
