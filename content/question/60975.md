  body_markdown: "Now is an old thread. But i answer anyway for the next noob like\
    \ that could end up here. \n\nTo pass list parameters to a nodes you should use\
    \ the tag '**rosparam**' instead of\n'param'. You could see how to use it [here](http://wiki.ros.org/roslaunch/XML/rosparam).\n\
    \nOn my launch file the joint_state_publisher looks like that:\n    \n    <node\
    \ name=\"joint_state_publisher\" pkg=\"joint_state_publisher\" type=\"joint_state_publisher\"\
    >\n        <rosparam param=\"source_list\">[\"my_controller/robot/joint_states\"\
    ]</rosparam>\n    </node>\n\nIt worked and I'm now visualizing on rviz my real\
    \ robol state. Note that you could put whatever you want instead of my_controller/robot/joint_states."
