    To access the share directory of a package in a generic way you can use [the ament index](https://github.com/ament/ament_index). In particular, `get_package_share_directory` [from ament_index_python](https://github.com/ament/ament_index/blob/d9f7f2783dedc5687a5bdaf3ce5252dce5c073c5/ament_index_python/ament_index_python/packages.py#L56), or [from ament_index_cpp](https://github.com/ament/ament_index/blob/d9f7f2783dedc5687a5bdaf3ce5252dce5c073c5/ament_index_cpp/include/ament_index_cpp/get_package_share_directory.hpp#L25) might be what you're looking for.

    There are other useful things that can be done with the ament index, for example [the composition demo](https://github.com/ros2/ros2/wiki/Composition) package ["registers" node components in the ament index](https://github.com/ros2/demos/blob/78b23ccd31a470ef21b2ec8d858aa5a0542e41db/composition/CMakeLists.txt#L41) and then [looks up the available node components](https://github.com/ros2/demos/blob/78b23ccd31a470ef21b2ec8d858aa5a0542e41db/composition/src/api_composition.cpp#L89) at run-time without recursively crawling the file system. [The ament index docs](https://github.com/ament/ament_cmake/blob/master/ament_cmake_core/doc/resource_index.md) have more info on the design.

    Hope that helps!
