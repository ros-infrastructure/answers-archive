    We don't have a file transport. But if you want to send a png you should use the [CompressedImage](http://docs.ros.org/latest/api/sensor_msgs/html/msg/CompressedImage.html) message which is designed to send png and jpeg messages.

    There are also tools for [compressed image transport](https://index.ros.org/p/compressed_image_transport/#eloquent)
