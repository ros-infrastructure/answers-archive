    The [basic_controls](http://wiki.ros.org/rviz/Tutorials/Interactive%20Markers%3A%20Getting%20Started#basic_controls) example in the [interactive_marker_tutorials](https://github.com/ros-visualization/visualization_tutorials/tree/indigo-devel/interactive_marker_tutorials) package has a [moving marker](https://github.com/ros-visualization/visualization_tutorials/blob/indigo-devel/interactive_marker_tutorials/scripts/basic_controls.py#L394-L416). There is a tf broadcaster that uses a timer to [repeatedly update the transform](https://github.com/ros-visualization/visualization_tutorials/blob/indigo-devel/interactive_marker_tutorials/scripts/basic_controls.py#L49-L53) between `base_link` and `moving_frame`. The moving marker uses `moving_frame` as its frame_id, and if you set the `base_link` frame as the fixed frame in rviz, you'll see the moving marker move in a sinusoidal pattern (even though its pose in the `moving_frame` frame is fixed).
