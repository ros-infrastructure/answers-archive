    \nThe solution is:\n\n    # Build eigen in order to remove it correctly\n    cd\
    \ && wget http://bitbucket.org/eigen/eigen/get/3.2.8.tar.gz #Download Eigen\n\
    \    mkdir eigen && tar --strip-components=1 -xzvf 3.2.8.tar.gz  -C eigen\n  \
    \  cd eigen && mkdir build && cd build && cmake .. && make\n\n    # Option1 to\
    \ remove eigen: To check what are installed and remove them\n    sudo make install\n\
    \    sudo rm -rf /usr/local/include/eigen3 /usr/local/share/pkgconfig/eigen3.pc\
    \ /usr/local/include/eigen3\n\n    # Option2 to remove eigen: To remove all files\
    \ listed in install_manifest.txt\n    sudo xargs rm < install_manifest.txt\n \
    \   \n    # Install dependency using rosdep\n    cd autoware.ai\n    rosdep update\n\
    \    rosdep install -y --from-paths src --ignore-src --rosdistro $ROS_DISTRO\n\
    \n    # Clean build files and rebuild Autoware\n    rm -rf build/ install/ log/\n\
    \    colcon build --cmake-args -DCMAKE_BUILD_TYPE=Release"
