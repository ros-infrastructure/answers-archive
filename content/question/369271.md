  body_markdown: "From the documentation:\n> Parameters:  \n> wx - The x world coordinate\
    \  \n> wy - The y world coordinate  \n> mx - Will be set to the associated map\
    \ x coordinate  \n> my - Will be set to the associated map y coordinate\n\nEssentially,\
    \ the world coordinates are in meters and the map coordinates are in pixels. \
    \ This function doesn't transform between frames in the tf tree; it converts physical\
    \ coordinates (e.g., [meters] in the `map` frame) into image coordinates in the\
    \ current `costmap` image, using an origin shift and scaling by the `costmap`\
    \ resolution.  Here's the function implementation for clarity:\n\n    00548  \
    \ bool Costmap2D::worldToMap(double wx, double wy, unsigned int& mx, unsigned\
    \ int& my) const {\n    00549     if(wx < origin_x_ || wy < origin_y_)\n    00550\
    \       return false;\n    00551 \n    00552     mx = (int) ((wx - origin_x_)\
    \ / resolution_);\n    00553     my = (int) ((wy - origin_y_) / resolution_);\n\
    \    00554 \n    00555     if(mx < size_x_ && my < size_y_)\n    00556       return\
    \ true;\n    00557 \n    00558     return false;\n    00559   }"

 The  `worldToMap` function is defined as follows in the official [documentation](http://docs.ros.org/en/electric/api/costmap_2d/html/classcostmap__2d_1_1Costmap2D.html) - `worldToMap (double wx, double wy, unsigned int &mx, unsigned int &my) const`. 

What are the variables `mx` and `my`? I am not sure but `wx` and `wy` represent the points that we want to transform to the map frame.
