  body_markdown: "Hi \n\nAs far as I know ( based on my previous experience )\n\n\
    \ 1. First, you need to create a CAD model of the robot.\n 2. Create URDF of the\
    \ model.\n 3. In your ROS (Raspberry Pi) open Moveit and upload the urdf.\n 4.\
    \ Define all the joints and necessary things in moveit and create the moveit configuration\
    \ file.\n 5. Now roslaunch this configuration file (demo.launch usually) which\
    \ opens your model in Rviz.\n 6. Rviz will be publishing the joint angles to the\
    \ jointstates topic.\n 7. In your hardware microcontroller (eg. Arduino if you\
    \ are using ) write a node to subscribe to this jointstates topic.\n 8. All the\
    \ computation will be done by ros and the final commands are given to the arm\
    \ (hardware).\n 9. You can see your arm moving to the desired position as seen\
    \ in Rviz simulation.\n\nI hope you got a rough idea of the entire procedure."
