  body_markdown: "The transforms are only available if you use the package: [Robot\
    \ State Publisher](http://wiki.ros.org/robot_state_publisher). \n\nThis package\
    \ uses your URDF to generate a TF tree. The URDF by itself can't do such a thing.\n\
    \nIf you still have any questions after visiting the robot state publisher page.\
    \ Please, comment below and I make a more complete answer.\n\n__________ EDIT\
    \ __________ \n\nFirst of all, you need at least two files: `robot.launch` and\
    \ (`robot.urdf` or `robot.urdf.xacro`)\n\nIn the launch file, you must load the\
    \ `robot_description` parameter and run `robot_state_publisher`:\n\n`robot.launch:`\n\
    \n    <launch>\n      <param name=\"robot_description\" command=\"$(find xacro)/xacro\
    \ --inorder '$(find birhex_description)/urdf/tutorial.urdf.xacro'\"/>\n      <node\
    \ pkg=\"rviz\" type=\"rviz\" name=\"rviz\" />\n      <node name=\"robot_state_publisher\"\
    \ pkg=\"robot_state_publisher\" type=\"robot_state_publisher\" />\n    </launch>\n\
    \nIn this example, I also included RViz but it isn't crucial.\n\nIn the image\
    \ below we have the TF tree and the model in Rviz.\nRemember, to be able to visualize\
    \ the model in Rviz you must add the display type: **Robot Model**\n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/15864830347810253.png)\n\
    \nAnd this must solve your problems with **No tf data.**.\n\nHowever with Visual\
    \ Code URDF preview, I'm open with the 3D Format .dae and it's working properly.\
    \ Could you please provide your STL model?"
