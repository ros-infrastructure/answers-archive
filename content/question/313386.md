  body_markdown: "DWB searches for the footprint [here](https://github.com/locusrobotics/robot_navigation/blob/master/nav_2d_utils/src/footprint.cpp#L46)\n\
    \nYou'll want to set the `footprint` parameter somewhere in your namespace. Right\
    \ now, I'm guessing you have the parameter `/move_base/DWBLocalPlanner/critics/ObstacleFootprint`\
    \ set to the footprint above. What you want is for the footprint to be set anywhere\
    \ in those namespaces, including \n\n * `/footprint`\n * `/move_base/footprint`\n\
    \ * `/move_base/DWBLocalPlanner/footprint`\n * `/move_base/DWBLocalPlanner/critics/footprint`\n\
    \ * `/move_base/DWBLocalPlanner/critics/ObstacleFootprint/footprint`\n\n`/move_base/footprint`\
    \ is traditional, since it allows anything in `move_base` to use the same footprint."
