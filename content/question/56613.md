    \ of hosts on emulator\n\nTo solve the problem follow these steps...\n\nWith the\
    \ emulator arleady opened, run:\n\n    cd adt-bundle/sdk/platform-tools/\n   \
    \ \n    ./adb -s  emulator-5554 remount\n\nTo remount the filesystem so its not\
    \ read only and you\u2019ll be able to change the hosts file. \n\nThen run:\n\n\
    \    ./adb -s  emulator-5554 pull /etc/hosts\n\nThis gets the current hosts file\
    \ from the device. Edit it in whatever text editor, it\u2019s been pulled to the\
    \ current working dir. \nI used gedit.\ngedit hosts\n\nand add the following line\n\
    \n    10.0.2.2   machineName\n\nin my case\n\n    10.0.2.2   rocha\n\n\nFinally\
    \ run:\n\n    ./adb -s  emulator-5554 push hosts /etc/hosts\n\n"
