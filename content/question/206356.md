    Hi, I've just now seen this question. One of the known issues is that we don't have a way to make pluginlib work on Android. The current solution is to hard-code the plugins you want to use and rebuild. You can see [here](https://github.com/creativa77/roscpp_android/blob/master/patches/move_base.patch) and [here](https://github.com/creativa77/roscpp_android/blob/master/patches/costmap_2d.patch)

     You would also need to check the the link order of the output libraries modyfing your generated [Android.mk](https://github.com/creativa77/roscpp_android/blob/master/files/Android.mk.move_base).

    Let me know if you need any help with this!
