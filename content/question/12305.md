  body_markdown: "Hi,\nLike there is 1 subscriber and 1 publisher in the tutorial.\n\
    Try to write 2 chatters. i.e each chatter should be able to listen and also talk.\n\
    In the subscriber of the tutorial add a publisher with different topic. Here is\
    \ example code. I haven't executed it but it should be simple enough to understand.\n\
    \n    #include \"ros/ros.h\"\n    #include \"std_msgs/String.h\"\n    #include\
    \ <sstream>\n\n    void chatterCallback(const std_msgs::String::ConstPtr& msg)\n\
    \    {\n      ROS_INFO(\"I heard: [%s]\", msg->data.c_str());\n    }\n    \n \
    \   int main(int argc, char **argv)\n    {\n    \n      ros::init(argc, argv,\
    \ \"listener\");   \n      ros::NodeHandle n;   \n      ros::Subscriber sub =\
    \ n.subscribe(\"chatter\", 1000, chatterCallback);\n      ros::Publisher chatter_pub\
    \ = n.advertise<std_msgs::String>(\"different_chatter\", 1000);\n\n      ros::Rate\
    \ loop_rate(10);   \n      \n      int count = 0;\n      while (ros::ok())\n \
    \     {\n     \n        std_msgs::String msg;\n    \n        std::stringstream\
    \ ss;\n        ss << \"hello world \" << count;\n        msg.data = ss.str();\n\
    \    \n        ROS_INFO(\"%s\", msg.data.c_str());\n    \n      \n        chatter_pub.publish(msg);\n\
    \    \n        ros::spinOnce();\n    \n        loop_rate.sleep();\n        ++count;\n\
    \      }\n    \n    \n      ros::spin();\n    \n      return 0;\n    }\n\nNow\
    \ you can write the second chatter listening to \"different_chatter\" and publishing\
    \ to \"chatter\" topics. \nHope this helps,\n\nKarthik"
