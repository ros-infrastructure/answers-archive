    Any time I need to find out the equivalent `catkin_tools` command for a `catkin_make` command (or vice versa), I consult [this really handy table](https://catkin-tools.readthedocs.io/en/latest/migration.html#cli-comparison-with-catkin-make-and-catkin-make-isolated).

    In this case, it tells me the command you want is `catkin config --install` followed by `catkin build`.

    You can check if installation has been set by just running `catkin config` and viewing the output.
