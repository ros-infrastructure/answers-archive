  body_markdown: "Hello Paul!\n\nSomewhere within the gazebo robot configuration you\
    \ will find the camera parameters like the following:\nChanging the hfov will\
    \ change you the field of view :-)\n    \n    <sensor:camera name=\"cam_front_sensor\"\
    >\n      <imageSize>640 480</imageSize>\n      <imageFormat>B8G8R8</imageFormat>\n\
    \      <hfov>90</hfov>\n      <nearClip>0.1</nearClip>\n      <farClip>100</farClip>\n\
    \      <updateRate>20.0</updateRate>\n      .....\n    </sensor:camera>\n\nYou\
    \ can compute the focal length with\n\nf = (width/2)  / tan( deg2rad(hfov)/2)\
    \ = (640/2) / tan(deg2rad(90)/2) = 320\n\nThe example above will give you a focal\
    \ length of 320. Don't forget to convert the angle to radiant\n\n\nGreetings\n\
    Markus\n ![Gazebo camera FOV vs. focal length](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/13268775812345883.gif)\n"

    Unfortunately, the camera used for rendering the gui does not have an easy way to change its FOV.

    Ticketed [feature request](https://kforge.ros.org/gazebo/trac/ticket/39) needs to be released.

    Alternatively, you can create a static camera model in the world and set its fov as Markus described, and screen capture the images separately using [image_view](http://ros.org/wiki/image_view) or [rviz](http://ros.org/wiki/rviz).
