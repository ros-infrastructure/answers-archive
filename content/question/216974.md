    \ problem and I've just added a fixed transform in the launch file between the\
    \ world frames of the two robots. \n \n\n\t<node pkg=\"tf\" type=\"static_transform_publisher\"\
    \ name=\"world_frames_connection\" args=\"0 0 0 0 0 0 /turtlebot1/world /turtlebot2/world\
    \ 100\"/>\n\nThen I obtained a single tree with two branches, one per robot. \n\
    \nHope this helps"
