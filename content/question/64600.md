  body_markdown: "The problem of integrating XCode and ROS is solved, however when\
    \ I run the code I get asserts. \n\n roscreate-pkg  is deprecated instead create\
    \ a project with \n\n    catkin_create_pkg <package_name> [depend1] [depend2]\
    \ [depend3]\n\nThis method works if you already have package that you want to\
    \ develop in XCode. To integrate XCode and ROS firstly generate Makefile for your\
    \ package\n\n    catkin_make --force-cmake -G\"Unix Makefiles\"\n\nthen follow\
    \ this procedure\n\n[Porting Unix to Mac](https://developer.apple.com/library/mac/#documentation/Porting/Conceptual/PortingUnix/preparing/preparing.html)\n\
    \nfinally, \n\n    In menu Product -> Scheme -> Edit Scheme \n    select Run tab\
    \ and specify path to your binary file \n\n\n----------\n\n\nUPDATE\n\nAn easier\
    \ solution would be \n\n    generate Xcode project directly by `catkin_make -G\"\
    Xcode\"`\n\n    then open Xcode from console by `open /Applications/Xcode.app\
    \ your_project.xcodeproj`  \n\n    finally,   In menu Product -> Scheme -> Edit\
    \ Scheme \n        select Run on the left, then select Info Tab at the top, and\
    \ choose a binary fine in Executable."
