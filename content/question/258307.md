  body_markdown: "I could not find out quickly, how the rover model from Erlerobot\
    \ generates GPS data, but you could try to use the simulated GPS device from [hector_gazebo_plugins](http://wiki.ros.org/hector_gazebo_plugins)\
    \ instead. That one works pretty well. \n\nTo install hector_gazebo_plugins use:\n\
    \n    $ sudo apt-get install ros-DISTRIBUTION-hector-gazebo-plugins\n\nAfterwards\
    \ add the following lines inside your <code>&lt;robot&gt;&lt;gazebo&gt; &lt;/gazebo&gt;&lt;/robot&gt;</code>\
    \ tags of your URDF file (or <code>&lt;model&gt; &lt;/model&gt;</code>, if you\
    \ are using SDF):\n\n    <plugin name=\"gps_controller\" filename=\"libhector_gazebo_ros_gps.so\"\
    >\n        <alwayson>true</alwayson>\n        <updaterate>1.0</updaterate>\n \
    \       <bodyname>base_link</bodyname>\n        <topicname>/fix</topicname>\n\
    \        <velocitytopicname>/fix_velocity</velocitytopicname>\n        <drift>5.0\
    \ 5.0 5.0</drift>\n        <gaussiannoise>0.1 0.1 0.1</gaussiannoise>\n      \
    \  <velocitydrift>0 0 0</velocitydrift>\n        <velocitygaussiannoise>0.1 0.1\
    \ 0.1</velocitygaussiannoise>\n    </plugin>\n\nThe hector plugin above generates\
    \ [sensor_msgs/NavSatFix](http://docs.ros.org/api/sensor_msgs/html/msg/NavSatFix.html)\
    \ messages. If ardupilot really requires [gps_common/GPSFix](http://docs.ros.org/hydro/api/gps_common/html/msg/GPSFix.html)\
    \ messages, you can use the *fix_translator* script in the [gps_common](http://wiki.ros.org/gps_common)\
    \ package to do the conversion. The best way to use the translator ist to adapt\
    \ the *fix_tanslator.launch* file to the topic names on your system."
