    So it's not a full converter per se, but there's a parser plugin [sdformat_urdf](https://github.com/ros/sdformat_urdf) which converts an SDF XML into URDF C++ DOM structures. Though there are some limitations as not all fields are compatible like for example if you have any sensors attached to a joint, it won't be parsed.
