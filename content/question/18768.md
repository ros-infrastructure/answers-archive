    \nLooks like at some point `ignition-math4` was installed from source - it has\
    \ the prefix `/usr/local/lib`. If installed via `apt` it would be in `/usr/lib`.\
    \ \n\nIt probably was built before [this pull request was merged](https://bitbucket.org/ignitionrobotics/ign-math/pull-requests/216/versioned-inline-namespaces/diff).\
    \ If the build folder is still around then do `sudo make uninstall` to uninstall\
    \ it. Otherwise you'll have to find and delete its files manually. This list is\
    \ probably incomplete:\n\n    /usr/local/share/doc/libignition-math4\n    /usr/local/lib/x86_64-linux-gnu/libignition-math4.so.4.0.0\n\
    \    /usr/local/lib/x86_64-linux-gnu/libignition-math4.so.4\n    /usr/local/lib/x86_64-linux-gnu/cmake/ignition-math4/*\n\
    \    /usr/local/include/ignition/math4/*\n\nThen I would force reinstall ignition-math4\
    \ in case something from it accidentally got deleted\n\n`sudo apt-get --reinstall\
    \ install libignition-math4*`\n"
