  body_markdown: "The error is that the `<param>` is in the top-level scope of the\
    \ launch file. In ROS 2, `<param>` tags must be contained inside of `<node>` tags.\
    \ Try changing your launch script to look more like this:\n\n    <?xml version=\"\
    1.0\"?>\n    <launch>\n    \n    <node name=\"robot_state_publisher\" pkg=\"robot_state_publisher\"\
    \ type=\"state_publisher\">\n      <param name=\"robot_description\" command=\"\
    $(find xacro)/xacro --inorder '$(find robufast_base)/launch/robufast.urdf'\" />\n\
    \    </node>\n    \n    <!--<node name=\"rviz\" pkg=\"rviz\" type=\"rviz\"/>-->\n\
    \    \n    <arg name=\"gui\" default=\"true\" />\n    \n    <node name=\"joint_state_publisher\"\
    \ pkg=\"joint_state_publisher\" type=\"joint_state_publisher\" />\n    \n    <!--\
    \ You'll need to a figure what node is consuming this parameter and pass it directly\
    \ to the node -->\n    <!--param name=\"use_gui\" value=\"$(arg gui)\"/-->\n \
    \   \n    </launch>\n\n\nThe `robot_description` parameter should be passed directly\
    \ to `robot_state_publisher`.\nAs my comment in the above code states, you'll\
    \ also need to move the `use_gui` parameter inside of tags for the node that needs\
    \ it.\n\n**The above launch script will only work with the latest version of `robot_state_publisher`\
    \ (ROS 2 Foxy or later).**\nThis is because it was changed to read the robot description\
    \ from a parameter (like in ROS 1) in https://github.com/ros/robot_state_publisher/pull/126.\n\
    \nFor ROS 2 Eloquent, or older, you'll need to pass the robot description **file**\
    \ as a **command line argument**. For example,\n\n    <node name=\"robot_state_publisher\"\
    \ pkg=\"robot_state_publisher\" type=\"state_publisher\"\n        args=\"$(find\
    \ robufast_base)/launch/robufast.urdf'\" />\n    </node>\n\nWith the caveat that\
    \ `robufast.urdf` above has already been expanded by `xacro`."

- body_markdown: |-
    robot_state_publisher needs a model of your robot (usually a [urdf](https://wiki.ros.org/urdf) file) and it expects its content to be available on the `robot_description` parameter.

    You can see [q267328](https://answers.ros.org/question/267328/how-to-put-urdf-in-parameter-server/) for an example of how to set the `robot_description` parameter.

    If your robot is described using Xacro files and not urdf you can use the following pattern instead:

        <param name="robot_description" command="$(find xacro)/xacro.py --inorder $(find pkg-name)/path/file.urdf.xacro" />
