  body_markdown: "Hi,\n\nyou can use tf directly to get odometry by setting `odom_frame_id`.\
    \ Here is an example with a zed2 camera (set those [lines](https://github.com/stereolabs/zed-ros2-wrapper/blob/b512dce6ad4565f4770273995b147122e735ca0f/zed_wrapper/config/common.yaml#L58-L60)\
    \ to false to avoid zed tf) based on this [example](https://github.com/introlab/rtabmap_ros/tree/ros2#rtabmap_ros-):\n\
    \n    ros2 launch zed_wrapper zed2.launch.py\n    ros2 run tf2_ros static_transform_publisher\
    \ 0 0 0 0 0 0 1 base_link_smooth base_link\n    ros2 launch isaac_ros_visual_odometry\
    \ isaac_ros_visual_odometry_zed2.launch.py\n    \n    ros2 launch rtabmap_ros\
    \ rtabmap.launch.py \\\n        rtabmap_args:=\"--delete_db_on_start\" \\\n  \
    \      rgb_topic:=/zed2/zed_node/rgb/image_rect_color \\\n        depth_topic:=/zed2/zed_node/depth/depth_registered\
    \ \\\n        camera_info_topic:=/zed2/zed_node/rgb/camera_info \\\n        frame_id:=base_link\
    \ \\\n        odom_frame_id:=odom \\\n        odom_tf_angular_variance:=0.001\
    \ \\\n        odom_tf_linear_variance:=0.001 \\\n        visual_odometry:=false\
    \ \\\n        approx_sync:=false \\\n        wait_imu_to_init:=true \\\n     \
    \   imu_topic:=/zed2/zed_node/imu/data \\\n        qos:=1 \\\n        rviz:=true\n\
    \nWhen using odometry from tf, we don't have a covariance, so we can adjust the\
    \ fixed covariance with `odom_tf_angular_variance` and `odom_tf_linear_variance`\
    \ parameters.\n\ncheers,<br/>\nMathieu\n"

Now the rgbd_odometry node publishes the /odom informations, which in turn are required by rtabmap.
isaac_ros_visual_odometry publishes the information in its own format, giving translation and rotation values in x,y,z direction. So unless I'm very much mistaken the information needed is present. 
Is there any known procedure on how to transpose an IMU-like message to an odometry message format or else, has anyone tried a similar approach to hardware acceleration before and has had some experience on integrating the isaac-ros GEMS to rtabmap?
