  body_markdown: "I just found out the answer to my problem. It is due to a very strange\
    \ way these things work. \n\nWhen I dump ALL the parameters\n\n    rosparam load\
    \ dump4.yaml\n\nI got the correct ways such as \n\n    keys_to_twist: {angular_scale:\
    \ 0.4, linear_scale: 0.5}\n\nbut when I do \n   rosparam load dump5.yaml\n\nI\
    \ got \n\n    {angular_scale: 0.4, linear_scale: 0.5}\n\nso when I load this file,\
    \ another set of parameters get added! So I have the original `keys_to_twist/angular_scale`\
    \ and another `angular_scale` and therefore the correct values are not set in\
    \ the parameters it should go. \n\nthe solution is to set the yaml file as\n\n\
    \     keys_to_twist: {angular_scale: 0.3, linear_scale: 0.6}\n\n\n  \n-----------------------------\n\
    \nThe funny thing I found out even later is that the loading of parameters *from\
    \ a launch file* **does  not work at all like this**\n\nIf you load the parameters\
    \ from a launch file you have to go again to \n\n    {angular_scale: 0.4, linear_scale:\
    \ 0.5}\n\notherwise you would have two times the \"key_to_twist\" part."
