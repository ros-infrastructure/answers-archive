- body_markdown: "Hi,\n\nI highly recommend you to use the `robot_state_publisher`\
    \ [package](http://wiki.ros.org/robot_state_publisher) so you can get rid of tf\
    \ problems. \n\nWhen you load your model this package will use the joints in the\
    \ URDF/Xacro to compute and publish all the TF of your robot (Including the lasers).\
    \ To link the `base_footprint` frame with `odom` frame you can implement a [node](http://wiki.ros.org/navigation/Tutorials/RobotSetup/Odom)\
    \ or a [Gazebo model plugin](http://gazebosim.org/tutorials?tut=ros_gzplugins).\n\
    \n From there you can have [AMCL](http://wiki.ros.org/amcl) for localization and\
    \ [Navigation stack](http://wiki.ros.org/navigation) to move the platform with\
    \ obstacle avoidance."
