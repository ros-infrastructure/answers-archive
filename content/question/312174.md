  body_markdown: "The [ROS time package](http://wiki.ros.org/roscpp/Overview/Time)\
    \ includes most of what you need to do this. You can get the current time in seconds\
    \ since the unix epoch using:\n\n    seconds = rospy.get_time()\n\nYour object\
    \ will need to store two properties: the time of the last callback, and if there\
    \ was a last callback (initially False)\n\nThen at the start of your callback\
    \ you can check if there was a previous callback and if so subtract the last time\
    \ from the current time to tell you the time since the previous callback. Then\
    \ at the end of the callback you can set the boolean to True and store update\
    \ the previous time. This should look something like this:\n\n    self.last_callback_time\
    \ = 0\n    self.not_first_callback = False\n\n    def callback(...):\n       \
    \ callback_time = rospy.get_time()\n        if self.not_first_callback:\n    \
    \        time_since_last_callback = rospy.get_time() - self.last_callback_time\n\
    \    \n        ...\n    \n       self.not_first_callback = True\n       self.last_callback_time\
    \ = callback_time\n\nHope this helps."

So if the time difference between callbacks is greater than 200 ms or there was no callback for 200 ms I will count back the encoders to 0.
