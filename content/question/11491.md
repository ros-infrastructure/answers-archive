    rosout collects all data from the ROS_INFO...-style macros to display not only in the terminal but also in rxconsole. Nodes connect to it by default to be able to publish there.

    If you are only concerned about the chaotic rxgraph output the "quiet" option will remove those.

  body_markdown: "Every node produces messages, possibly with loginfo, logerr etc\
    \ etc.. Even if you don't see them, there is a lot of debug messages going on\
    \ in your node. rosout collects all these messages. The advantages are in terms\
    \ of logging, and in terms of  displaying all the messages in a single place.\
    \ \n\nProbably the main reason for a centralized messages collector is to allow\
    \ wonderful tools like [rxconsole](http://www.ros.org/wiki/rxconsole) to exist\
    \ :-)"
