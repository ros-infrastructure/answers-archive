  body_markdown: "Found a solution: it's either sdformat (version 2.2) or boost, since\
    \ gazebo updates you to the latest version of boost, or a combination of the two.\
    \ It might be enough to just recompile everything with the same boost version.\n\
    \nWhat I did, step-by-step was uninstall sdf, switch back to my previous version\
    \ of boost, and rebuild everything.\n\n    brew uninstall sdformat  \n    brew\
    \ uninstall sdformat4  \n    brew uninstall sdformat3  \n    brew info boost \
    \ \n    brew switch boost 1.58.0 (your previous version may vary...)  \n    brew\
    \ install sdformat3   \n    brew link sdformat3  \n    brew install gazebo7\n\n\
    Probably it is worth trying just removing and re-installing sdformat3 with the\
    \ newest boost to fix the issue."
