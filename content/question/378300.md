    The [Navigation tutorials](http://wiki.ros.org/navigation#Tutorials) are rather extensive, including many tutorials for specific robots.  A quick internet search will find many [video Navigation tutorials](https://www.google.com/search?q=ros+navigation+tutorial&client=ubuntu&hs=76N&source=lnms&tbm=vid&sa=X&ved=2ahUKEwjsgo-hq9PwAhWiGFkFHcdJAKAQ_AUoAXoECAEQAw&biw=2180&bih=1161), tutorials for [publishing odometry](https://www.google.com/search?q=ros+odometry+tutorial&client=ubuntu&hs=Tmi&biw=2180&bih=1161&tbm=vid&ei=TcGjYLH_Bf7n5NoP8IaEiAM&oq=ros+odometry+tutorial&gs_l=psy-ab-video.3..0j0i8i30k1.162725.163818.0.164728.8.8.0.0.0.0.152.626.5j2.7.0....0...1c.1.64.psy-ab-video..2.6.551...0i7i30k1j0i8i7i30k1j0i13k1.0.WiuY96T4FmU), etc.

    If you don't see a topic with `rostopic list`, that means no nodes are publishing or subscribed to it.  For navigation, you'll need an [odometry node](http://wiki.ros.org/navigation/Tutorials/RobotSetup/Odom) to publish on `/odom`.  Your robot will also need a controller node to subscribe to `/cmd_vel`, so it can follow commands.  The controller node will be specific to the (type of) robot you have, but one common type is [differential drive](https://www.google.com/search?q=ros+differential+drive&client=ubuntu&hs=RJO&biw=2180&bih=1161&tbm=vid&ei=RsSjYKLkG6qw5NoP1L6Z-Aw&oq=ros+differential+drive&gs_l=psy-ab-video.3..0l6j0i30k1l3j0i8i30k1.23939.26008.0.26271.10.9.1.0.0.0.155.793.7j2.9.0....0...1c.1.64.psy-ab-video..2.8.630...0i13k1j0i7i30k1j0i8i7i30k1j0i8i7i10i30k1.0.3n6ahiEj0CY).

    There is a steep learning curve when starting out, so I recommend following a well-established and self-contained tutorial (e.g., [TurtleBot3](https://emanual.robotis.com/docs/en/platform/turtlebot3/overview/#overview)) before trying to implement things on a custom robot.  If you run into specific issues, feel free to ask more questions.
