    ROS core toolset (like `rosdep`) utilizes OS detection functionality that a package called [rospkg](http://wiki.ros.org/rospkg) provides. Looks like `yocto` is not supported yet by `rospkg`. There was [a PR](https://github.com/ros-infrastructure/rospkg/pull/86) that didn't get merged. You can suggest a support by opening a pull request to rospkg. I haven't found a tutorial for how to add a support for a new OS, but looking into the changes done in [some previous PRs](https://github.com/ros-infrastructure/rospkg/pulls?utf8=%E2%9C%93&q=is%3Apr+os_detect) might help. I think the core of the change should be going to happen in [os_detect.py](https://github.com/ros-infrastructure/rospkg/blob/master/src/rospkg/os_detect.py).
