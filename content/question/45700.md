  body_markdown: "ROS is the name of the operating system (like windows or ubuntu).\
    \ Electric is the specific distro (like XP and vista or precise pangolin 12.04\
    \ and oneiric ocelot 11.10). \n\nROS Fuerte is the current distro as of 10.12.12,\
    \ and it's recommended that you use that.\n\nYou should check out the [introduction\
    \ to ROS](http://www.ros.org/wiki/ROS/Introduction) and the [ROS distribution\
    \ page](http://www.ros.org/wiki/Distributions) for more info."
  comments:
  - body_markdown: |-
      So as not to confuse someone who is new to all this, remember that ROS is not an "operating system" in the common sense of the term.  It is not its own linux distribution, for example.  It still must be run on an operating system, like Ubuntu/Windows.
