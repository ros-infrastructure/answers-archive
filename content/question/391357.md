  body_markdown: "There are many ways to address this challenge for dynamic changes\
    \ to the environment, for example multi session graph based SLAM. It also depends\
    \ on what is changing in the environment, is it pedestrians walking by? Or is\
    \ it furniture moving around?\n\nTake a look at the following [paper](https://introlab.3it.usherbrooke.ca/mediawiki-introlab/images/e/eb/Labbe14-IROS.pdf)\n\
    \nSummary of the approach used: \n\n> the underlying structure of the map is\n\
    > a graph with nodes and links. The\n> nodes save odometry poses for each\n> location\
    \ in the map. The nodes also\n> contain visualization information like\n> laser\
    \ scans, RGB images, depth images\n> and visual words [17] used for loop\n> closure\
    \ detection. The links store\n> rigid geometrical transformations\n> between nodes.\
    \ There are two types of\n> links: neighbor and loop closure.\n> Neighbor links\
    \ are added between the\n> current and the previous nodes with\n> their odometry\
    \ transformation. Loop\n> closure links are added when a loop\n> closure detection\
    \ is found between the\n> current node and one from the same or\n> previous maps.\
    \ Our contribution in\n> this paper involves combining two\n> algorithms, loop\
    \ closure detection\n> [16] and graph optimization [14],\n> through a memory management\
    \ process\n> [16] that limits the number of nodes\n> available from the graph\
    \ for loop\n> closure detection and graph\n> optimization, so that they always\n\
    > satisfy online requirements.\n\nBut there are other examples of using machine\
    \ learning for object detection and remove those objects while updating SLAM,\
    \ take a look at this [paper](https://ieeexplore.ieee.org/document/8996770)\n\n"
