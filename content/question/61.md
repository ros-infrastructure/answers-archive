  body_markdown: "Try grabbing the latest Gazebo (version 1.2). The default install\
    \ will allow you drag-and-drop a hammer into simulation.\n\nHere is the SDF we\
    \ use for the hammer:\n\n    <?xml version=\"1.0\"?>\n    <gazebo version=\"1.2\"\
    >\n      <model name=\"hammer\">\n        <static>false</static>\n        <link\
    \ name=\"link\">\n          <collision name=\"collision\">\n            <geometry>\n\
    \              <mesh>\n                <uri>model://hammer/meshes/hammer.dae</uri>\n\
    \              </mesh>\n            </geometry>\n          </collision>\n    \n\
    \          <visual name=\"visual\">\n            <geometry>\n              <mesh>\n\
    \                <uri>model://hammer/meshes/hammer.dae</uri>\n              </mesh>\n\
    \            </geometry>\n          </visual>\n        </link>\n      </model>\n\
    \    </gazebo>\n\nAn improvement can be made by using simple shapes for the collision\
    \ object rather than the mesh itself."
