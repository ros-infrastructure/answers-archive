  body_markdown: "ROS 2 is a large ecosystem of packages.\n\nThe core is cross platform\
    \ compatible. But not all packages in the ecosystem are expected to be cross platform\
    \ compatible.\n\nThe information in the rosdistro file relates to the fully automated\
    \ packaging release pipeline. This is only supported on linux mostly due to the\
    \ lack of package management on Windows or MacOS. \n\nWindows and MacOS are supported\
    \ for the core and some some of the larger ecosystem. We don't have a way to test\
    \ or track compatibility for Windows and MacOS for community released packages.\
    \ If it's expected to work under Windows or MacOS it's commonly notated in the\
    \ documentation and users can build it from source.\n\nI will point out the [recent\
    \ announcement](https://medium.com/robostack/cross-platform-conda-packages-for-ros-fa1974fd1de3)\
    \ of using Conda for cross platform packaging for ROS which has been gaining some\
    \ traction too. It's ROS 1 based but there's [active efforts to support ROS 2](https://discourse.ros.org/t/macos-support-in-ros-2-galactic-and-beyond/17891/19?u=tfoote)"
