  body_markdown: "I have  find a way to define the specific 'HOME ' in the Cartesian\
    \ Plan Plugin.\n\n1. Using the rviz to plan your robot model to your desired position\
    \ and get the End_Effect link's position and orientation and each joint position\n\
    \n2. Changing the home_pose in '/moveit_cartesian_plan_plugin/src/generate_cartesian_path.cpp\
    \ \n\n   \n\n \n    \n\n    void GenerateCartesianPath::moveToHome()\n       {\n\
    \n          geometry_msgs::Pose home_pose;\n          home_pose.position.x=-0.161528;\n\
    \n          home_pose.position.y=0.258965;\n          home_pose.position.z=0.829914;\
    \    \n          home_pose.orientation.x = -0.275129;\n          home_pose.orientation.y\
    \ = 0.66813;\n          home_pose.orientation.z = -0.625876;\n          home_pose.orientation.w\
    \ = 0.293575;\n3. Compiling\n4. Start the plugin and move the each joint to your\
    \ home point approximately and click the \"Move to Home\" button\n\n\n\nI don't\
    \ know if this is a best way to change the default home point in this plugin,\
    \ but it works. So you can try or you have another convenient way to solve it."
