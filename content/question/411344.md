I am porting Python code from ROS 1 to ROS 2. The ROS 1 code made use of the 'camera_info_manager' and I made it available to python by installing the [camera_info_manager_py](https://github.com/ros-perception/camera_info_manager_py) package. When running the script using ROS 2, which contains this line 

*from camera_info_manager import CameraInfoManager*

I get the obvious 

*ModuleNotFoundError: No module named 'camera_info_manager'* 

error and there does not seem to be a camera_info_manager_py package for ROS 2. I haven't been able to find an alternative. Any suggestions?
