  body_markdown: "when you already have a 3d pointcloud you could have a look at http://www.ros.org/wiki/octomap_server\
    \ , just give this node your pointcloud2-msgs and it will generate a 2D and 3D\
    \ map out of it (the 2d map is just the downprojected 3d map)\n\njust do an apt-get\
    \ install ros-groovy-octomap*\n\nexample launch file:\n\n    <!--\n    firing\
    \ up the octomap server to generate 2D/3D occupancy maps\n    -->\n    \n    <launch>\n\
    \      <node pkg=\"octomap_server\" type=\"octomap_server_node\" name=\"octomap_server\"\
    >\n        <!-- resolution in meters per pixel -->\n        <param name=\"resolution\"\
    \ value=\"0.05\" />\n        <!-- name of the fixed frame, needs to be \"/map\"\
    \ for SLAM -->\n        <param name=\"frame_id\" type=\"string\" value=\"/map\"\
    \ />\n        <!-- max range / depth resolution of the kinect in meter -->\n \
    \       <param name=\"sensor_model/max_range\" value=\"4.0\" />\n        <param\
    \ name=\"latch\" value=\"true\" />\n        <!-- max/min height for occupancy\
    \ map, should be in meters -->\n        <param name=\"pointcloud_max_z\" value=\"\
    1.75\" />\n        <param name=\"pointcloud_min_z\" value=\"0.1\" />\n       \
    \ <!-- topic from where pointcloud2 messages are subscribed -->\n        <remap\
    \ from=\"cloud_in\" to=\"/camera/depth_registered/points\" />\n      </node>\n\
    \    </launch>"
