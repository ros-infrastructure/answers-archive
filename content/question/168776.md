  body_markdown: "you can remap \"your pointCloud2 input\" topic to cloud_in, by including\
    \ following lines to your launch file,\n\ne.g., if you are using this file:  octomap_mapping\
    \ / octomap_server / launch / octomap_mapping.launch \nwrite,\n\n      <remap\
    \ from=\"cloud_in\" to=\"/(point cloud topic) />\n\n under   <node>    </node>\n\
    \n(RGBD slam is also a nice option for mapping using kinect.) \n\n\n"
