  body_markdown: "In the current SVN (experimental version of rosbridge):\n\n    svn\
    \ co http://brown-ros-pkg.googlecode.com/svn/trunk/experimental/rosbridge\n\n\
    I have added a feature so that if you send a header (or an object containing a\
    \ header) with an empty stamp field, it will be replaced with the current rostime.\
    \ In other words:\n\n    con.publish('/heads','std_msgs/Header',{seq:42,frame_id:'foo',stamp:{}})\n\
    \nresults in something like:\n\n    seq: 43                                  \
    \                                                           \n    stamp:     \
    \                                                                            \
    \             \n      secs: 1332141768                                       \
    \                                           \n      nsecs: 325777053         \
    \                                                                         \n \
    \   frame_id: foo\n\nKeep in mind that this is purely for cases where you don't\
    \ need a very accurate timestamp. The *proper* thing to do is still to synchronize\
    \ the client and ROS runtime's clocks.\n\nIf for some reason you don't want to\
    \ run the SVN version of rosbridge, you can also use [this](http://pastebin.com/pRKtK9hg)\
    \ patch until the binary version is updated (after more time and testing)."
