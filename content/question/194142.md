    The last section of the [Installation Instructions for Indigo in Arch Linux](http://wiki.ros.org/indigo/Installation/Arch) page -- [Community](http://wiki.ros.org/indigo/Installation/Arch#Community) -- says this:

    > If you would like to contribute to packaging ROS on Arch, check [arch-ros-stacks](https://github.com/bchretien/arch-ros-stacks) on GitHub (as explained in [#1.2](http://wiki.ros.org/indigo/Installation/Arch#Adding_New_AUR_Packages)), or even [[https://wiki.archlinux.org/index.php/Talk:Ros](https://wiki.archlinux.org/index.php/Talk:Ros)].

    The [README.md](https://github.com/bchretien/arch-ros-stacks/blob/master/README.md) on the linked [Github repository](https://github.com/bchretien/arch-ros-stacks) has a [How to contribute](https://github.com/bchretien/arch-ros-stacks#how-to-contribute) section:

    > If you want to contribute, simply fork this repository, create or update some packages, and make a pull request afterwards.
