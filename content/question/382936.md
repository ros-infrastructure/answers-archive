    A few notes:

     - The URDF simply specifies how to visualize the robot - it does not include any control code or logic.
     - For gazebo you can convert your URDF into an SDF file, which tells gazebo how to visualize the robot.
     - In addition to your URDF/SDF file you'll actually need to write some code to tell Gazebo how to control the robot. I'd suggest you start by looking at the [Gazebo tutorials on building a robot](http://gazebosim.org/tutorials?cat=build_robot)
