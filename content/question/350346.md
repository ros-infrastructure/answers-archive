  body_markdown: "The way the instructions recommend handling this is version control\
    \ for each package in your workspace, and a separate metafile that stores where\
    \ each package is hosted/which branch to use\n\n\nfrom the dashing build from\
    \ source [instructions](https://index.ros.org/doc/ros2/Installation/Dashing/Linux-Development-Setup/)\n\
    \n> Create a workspace and clone all\n> repos:\n> \n>     mkdir -p ~/ros2_dashing/src\n\
    >     cd ~/ros2_dashing\n>     wget https://raw.githubusercontent.com/ros2/ros2/dashing/ros2.repos\n\
    >     vcs import src < ros2.repos\n\n\n\nhere's what the text looks like in this\
    \ .repos file\n\n      ros2/rclcpp:\n        type: git\n        url: https://github.com/ros2/rclcpp.git\n\
    \        version: dashing\n      ros2/rclpy:\n        type: git\n        url:\
    \ https://github.com/ros2/rclpy.git\n        version: dashing\n      ros2/rcpputils:\n\
    \        type: git\n        url: https://github.com/ros2/rcpputils.git\n     \
    \   version: dashing\n\n\n\n\n"
