  body_markdown: "You don't need to build rosserial_arduino.\n \nJust copy the ros_lib\
    \ folder from /rosserial/rosserial_arduino/libraries into your Arduino 'sketchbook'\
    \ folder (or alternatively the /arduino/examples folder).\n\nAfter you've done\
    \ that, the example sketches will appear at File>sketchbook>ros_lib OR File>Examples>ros_lib\
    \ on the Arduino IDE. \n\nYou can select any one of the example/tutorial sketches\
    \ and compile/upload them to your board. (Follow the corresponding Tutorial from\
    \ the wiki.)\n\nP.S. Make sure you've made the following changes:\nin ros_lib\
    \ edit ArduinoHardware.h: replace #include \"WProgram.h\" with #include \"Arduino.h\""
