    The [lifecycle demo](https://github.com/ros2/demos/tree/master/lifecycle) is a fairly complete example. You should also look at the [managed nodes](https://index.ros.org/doc/ros2/Managed-Nodes/) wiki page, which talks about the example and what is going on.

    Managed nodes can be controlled using the `ros2 lifecycle` command. Run `ros2 lifecycle -h` to get its help. It's still a little rudimentary - you have to specify a transition as text, rather than being able to say "activate node X", for example. But it does work. But the big thing for managed nodes is that the [new launch system](https://index.ros.org/doc/ros2/Launch-system/) uses them. You will be able to do things like launch all the nodes and only activate them when all nodes are actually ready to run, ensuring you don't get a half-started system.
