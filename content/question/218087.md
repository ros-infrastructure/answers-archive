    Yes, octomap is purely a mapping approach, so the robot has to be localized via some other approach. Of course, the quality of your octomap is directly coupled to the performance of the used SLAM approach.

    [In this video](https://www.youtube.com/watch?v=jgNFeDH3qFk) we use hector_mapping for localization (and 2D mapping) using a Hokuyo UTM-30LX LIDAR. Simultaneously, a octomap is generated via a Asus Xtion Pro Live sensor mounted on the robot (the colored points visible in rviz show the octomap).
