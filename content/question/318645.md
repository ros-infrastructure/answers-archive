  body_markdown: "Hi there, I was having the same challenge and I figure a solution\
    \ for this problem. I know the post is old but it may give some clues for someone\
    \ having the same troubles.\n\nSo first, the C++ file where the libCessnaPlugin.so\
    \ comes from does not use any instance of ROS. It does mention that publishes\
    \ the Pose and subscribes the motor speed but no through a ROS network since this\
    \ files doesn't call anything from there. So I found this repo (https://github.com/AurelienRoy/ardupilot_sitl_gazebo_plugin),\
    \ where there is a plugin called aircraft_plugin which in essence is the same\
    \ as the cessna_plugin but now this one does make use of a ROS node and subscribes\
    \ to a topic called motor_message. This topic used the message CommandMotorSpeed\
    \ that comes from the mav_com_mav_msgs package (I got it from here https://github.com/PX4/mav_comm).\
    \ \n\nNow, I tried to catkin_make the aircraftplugin and found several error due\
    \ to deprecated fucntions of Gazebo since I was using Gazebo 9, and this plugin\
    \ is old, so I had to change the old functions with the replacements base on this\
    \ post (https://github.com/osrf/gazebo/blob/gazebo11/Migration.md)  and then I\
    \ has able to compile the package.\n\nNow, in order to attach the plugin to the\
    \ Cessna model I added these lines in the URDF:\n\n\n      <gazebo>\n        \
    \ <plugin name=\"aircraft_plugin\" filename=\"libaircraft_plugin.so\">\n     \
    \       <commandSubTopic>/command/motor_speed</commandSubTopic>\n            <left_aileron>left_aileron_joint</left_aileron>\n\
    \            <left_flap>left_flap_joint</left_flap>\n            <right_aileron>right_aileron_joint</right_aileron>\n\
    \            <right_flap>right_flap_joint</right_flap>\n            <elevators>elevators_joint</elevators>\n\
    \            <rudder>rudder_joint</rudder>\n            <propeller>propeller_joint</propeller>\n\
    \            <propeller_link>propeller</propeller_link>\n            <propeller_max_rpm>37500</propeller_max_rpm>\n\
    \         </plugin>\n      </gazebo>\n\n\nFinally, it took me a while to know\
    \ how to publish in the topic so I could move the aricraft control surfaces, and\
    \ this format worked for me (For testing purposes)\n \n\n    rostopic pub -r 10\
    \ /command/motor_speed mav_msgs/CommandMotorSpeed '{motor_speed: [100, 100, 100,\
    \ 100, 100]}'\n\nI am still new on Gazebo ROS development, but at least this worked\
    \ for me, so I don't know if there was an easier solution, but it worked for me.\n\
    \nHope it helps.\n\n\n"
