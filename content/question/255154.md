    `chatterCallback` is used a function pointer in this context, so the function isn't being called by `advertise()`. Instead, the address of the function is stored and used later to call that function every time a new message arrives.

    Here's a [wikipedia article about function pointers](https://en.wikipedia.org/wiki/Function_pointer) and another article specifically about [using function pointers in C++](http://www.cprogramming.com/tutorial/function-pointers.html) if you want to learn more about the details.
