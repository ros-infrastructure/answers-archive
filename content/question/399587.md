Hello,

I am trying to automate and visualize a series of tasks with my custom robot. I am using PyQt5 for that and planning to connect several roslaunches to respective buttons. I would like to print the current state in a text edit slot. Currently, I am able to start roslaunch with a button press using [roslaunch API](http://wiki.ros.org/roslaunch/API%20Usage) but I am not able to capture screen output. I've tried three things:

1) Created a [QProcess](https://doc.qt.io/archives/qt-4.8/qprocess.html#readAllStandardOutput) and tried to capture all outputs. However, the roslaunch output is not a `sys` stdout type. So I would like to know if there is a way to redirect the screen output of a roslaunch as a system output or error.

        program = "roslaunch"
        args = [str(self.pkg_path)+'/launch/gui.launch']
        self.myProcess = QProcess(self)

        self.myProcess.readyReadStandardOutput.connect(self.write_process_output)
        self.myProcess.start(program, args)


2) Used `process = subprocess.Popen(...)` and tried reading terminal output with `process.stdout.read()`. I am able to read regular commands' outputs but not roslaunch. For instance `ls` command return works just fine like that:

        cmd = "ls"
        proc = subprocess.Popen(cmd, shell=True, stdout=subprocess.PIPE)
        user_list = str(proc.stdout.read())
        self.RecordPlot.recordtextEdit.setText(user_list)

3) Manually started roslaunch with uuid. But in this method, the terminal switches to the running roslaunch terminal and I am not able to switch between processes.

        name = '/launch/gui.launch'
        uuid = roslaunch.rlutil.get_or_generate_uuid(None, False)
        roslaunch.configure_logging(uuid)
        self.launch = roslaunch.parent.ROSLaunchParent(uuid, [str(self.pkg_path)+name])
        self.launch.start()

I don't know if there is any 4th way to do it or which one would be a solution. I am appreciated to any suggestions.
