    I had a similar issue, the problem for me was that I did not run apt-get update after setting up the ros sources.list and keys.

    running sudo apt-get update after setting up the sources and keys downloaded the following packages:

        Get:8 http://packages.ros.org/ros/ubuntu xenial InRelease [4,025 B]
        Get:9 http://packages.ros.org/ros/ubuntu xenial/main armhf Packages [245 kB]

    Running the following install command after that worked fine:

        sudo apt-get install ros-kinetic-desktop-full
