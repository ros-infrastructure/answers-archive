    \ are: \n\n - Signal delay Delay between the\n   simulator and the local planner\n\
    \ - Controller frequency\n\nThe speed profiler in the DecisionMaker.cpp is a closed\
    \ loop profiler, which utilize time delta. and it is runnin 50 hz. \nso when there\
    \ is no velocity signal update. no change happen into the local planner side.\
    \ \n\nThe workaround, in the FOLLOW case in the DecisionMaker.cpp , set the target\
    \ velocity to zero. and as you did, set the additional braking distance to 15+.\
    \ \n\nIf you look at my repository \"openplannet.1.13\" branch, I added a special\
    \ flag for CARLA. whenever you find this flag, you can find simulation related\
    \ workarounds. \n\nThe correct solution: \n\n1. Make sure the controller frequency\
    \ >= local planning frequency \n2. Make sure that the delay between the simulator\
    \ and the planner is less than 50 ms\n3. Change the speed profilter in the decision\
    \ maker to work as open loop and ignore feedback from the vehicle state. \n\n\
    Hope this is helpful. \n\n"
