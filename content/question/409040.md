    1. Instead of using `argc`, and `argv`, it is better to use `rosparam`. For example, `rosrun roscpp_tutorials add_two_ints_client _launch:="example string"`. Please pay attention to `_` character with `launch` param. Later, inside C++ you can use relative namespace `nh.getParam("launch", launch);`. A complete example is shown [here](https://github.com/ravijo/multiple_kinect_baxter_calibration/blob/c7f4fb18ef9d7a88b15a9a7398b1ce524a7c7565/src/save_pcd.cpp#L83-L86).
    2. Next, you do not need to use `(char*)`. The `ROS_INFO("Data %s", msg.data.c_str());` should be enough.
    3. I am not sure why you are using `atoi`. Moreover, in a C++ code, I like to see/use C++ more than C.
