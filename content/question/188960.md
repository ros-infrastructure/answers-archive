  body_markdown: "This [link](http://wiki.ros.org/rospy/Overview/Parameter%20Server)\
    \ should have all the information you need. \n\nThere are many ways to get:\n\n\
    \    global_name = rospy.get_param(\"/global_name\")\n    relative_name = rospy.get_param(\"\
    relative_name\")\n    private_param = rospy.get_param('~private_name')    \n \
    \   default_param = rospy.get_param('default_param', 'default_value')\n\n    #\
    \ fetch a group (dictionary) of parameters\n    gains = rospy.get_param('gains')\n\
    \    p, i, d = gains['P'], gains['I'], gains['D']\n\nAnd set: \n\n    rospy.set_param('a_string',\
    \ 'baz')\n    rospy.set_param('~private_int', 2)\n    rospy.set_param('list_of_floats',\
    \ [1., 2., 3., 4.])\n    rospy.set_param('bool_True', True)\n    rospy.set_param('gains',\
    \ {'p': 1, 'i': 2, 'd': 3})\n\n    rospy.get_param('gains/P') #should return 1\n\
    \nYou can do a lot of other things like delete params, check and see if a param\
    \ exists, list all params, etc. All of it is covered in that link. \n\n[This](http://wiki.ros.org/rosgui_paramedit)\
    \ might be of interest to.  It looks like someone already had something like this\
    \ but used the rx stuff (I just skimmed it, you might want to look closer). \n\
    \nLastly, if you do build a plugin, please let people know about it [ here](http://wiki.ros.org/rqt/Plugins)\
    \ to prevent duplicate efforts. I also notice on that page that the description\
    \ of the  [Node_Manager](http://wiki.ros.org/node_manager_fkie) plugin says something\
    \ about managing params, you might want to look at that to. "
