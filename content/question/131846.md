    You should just install Hydro as described [here](http://wiki.ros.org/ROS/Installation). This will install Hydro in addition to your existing Groovy installation. If you really want to, you can uninstall Groovy via "sudo apt-get remove ros-groovy-*" but you really [don't need to](http://answers.ros.org/question/10660/what-happened-if-i-install-two-version-of-ros/?answer=15729#post-id-15729). I have both versions on my computer and I switch back and forth when I need to by changing my .bashrc file from "source /opt/ros/groovy/setup.bash" to "source /opt/ros/hydro/setup.bash" along with the catkin and package paths, then restarting the terminal.

      You should NOT use the same workspace since CMake will use CMake config files from the location available in the CMAKE_PREFIX_PATH when it is configured the first time. When you then switch the ROS distro those locations will not be updated. Therefore you would end up with a mixed up workspace.
