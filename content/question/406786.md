- I'm using ROS rolling: ros-rolling-ros-core=0.10.0-1*
 
- I'm running in a Docker container with ubuntu 22.04 (x86_64)

Below is the pseudocode:

    rclcpp::Node::SharedPtr node = std::make_shared<rclcpp::Node>("test");
    std::chrono::nanoseconds interval(500);    
    rclcpp::TimerBase::SharedPtr timer = node1->create_wall_timer(interval, callback);

The callback calculates the time between each call to the timer, and this time never changes, although the interval changes. **Please note that, it works fine in ROS Galactic.**
