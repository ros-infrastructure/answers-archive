    Lunar only supports Python 2.7 (see [REP-3](http://www.ros.org/reps/rep-0003.html#lunar-loggerhead-may-2017-may-2019) and (fi) #q269143). If you want to use Anaconda, you'll have to make sure that all ROS Python packages have been installed for that as Anaconda does not use the default / system Python packages. That is most likely why you are getting that error.

    There have been quite some questions and answers about Anaconda posted/resolved recently, so a search should provide some pointers.
