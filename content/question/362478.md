  body_markdown: "There is an `rclcpp::create_timer()` free function\n\n* [Foxy code](https://github.com/ros2/rclcpp/blob/foxy/rclcpp/include/rclcpp/create_timer.hpp)\n\
    * [Foxy API documentation](http://docs.ros2.org/foxy/api/rclcpp/create__timer_8hpp.html)\n\
    git\n* [tf2_ros::BufferServer uses `rclcpp::create_timer()`](https://github.com/ros2/geometry2/blob/6788c1b78fe35e1a459a9d8f184afeb79792bd71/tf2_ros/include/tf2_ros/buffer_server.h#L95-L96)\n\
    \nThe trick to a timer that uses simulated time is to pass a clock that uses simulated\
    \ time to the `rclcpp::create_timer()` function. The [default clock on a node\
    \ is a ROS clock](http://docs.ros2.org/foxy/api/rclcpp/classrclcpp_1_1Node.html#aec0332887ae90caed727e5025cb62195)\
    \ - meaning it will use simulated time if simulated time is active. \n\n\nYou\
    \ might also be interested in \n\n* [ROS 2 Clock and Time design article](https://design.ros2.org/articles/clock_and_time.html)\n\
