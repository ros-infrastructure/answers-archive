  body_markdown: "Hi Jesus,\n\nIn ROS robots are described using a [URDF](http://wiki.ros.org/urdf),\
    \ normally stored with *.urdf* extention. That description may include the sensor/actuator\
    \ models for Gazebo as well. Some times the URDF files are generated using a script\
    \  language named [xacro](http://wiki.ros.org/xacro) (*.xacro* extension).\n\n\
    So what I would do to find the parameters passed to gazebo for any robot that\
    \ I haven't worked with before is to find any *.urdf* and *.xacro* files inside\
    \ of the robot's ROS packages.\n\nIf you have installed and compiled turtlebot3\
    \ packages from source code (https://github.com/ROBOTIS-GIT/turtlebot3) you can\
    \ go to your catkin workspace and execute the following command:\n\n    find ./\
    \ -type f \\( -iname \\*.urdf -o -iname \\*.xacro \\)\n\nAnd then dig into any\
    \ files listed on the output of the previous command.\n "
