  body_markdown: "A matlab monocular camera calibration is stored in the format of\
    \ a [cameraParameters object](https://www.mathworks.com/help/vision/ref/cameraparameters.html?searchHighlight=cameraParameters&s_tid=doc_srchtitle).\
    \ \n\nIn ROS, the calibration parameters are usually stored in a yaml file, and\
    \ then they are loaded into a [sensor_msgs/CameraInfo Message](http://docs.ros.org/api/sensor_msgs/html/msg/CameraInfo.html)\
    \ (read this documentation for more info). The format \n\nA calibration yaml file\
    \ for a monocular camera in ROS requires the following:    \n\n - **height** in\
    \ pixels\n - **width** in pixels\n - **camera_name** which should correspond to\
    \ a link name in your URDF. \n - **distortion_model** which is always just \"\
    plumb_bob\" \n - The distortion parameters D, size depending on the distortion\
    \ model. For \"plumb_bob\", the 5 parameters are: (k1, k2, t1, t2, k3). Also known\
    \ as the **distortion_coefficients**\n - Intrinsic **camera_matrix** K for the\
    \ raw (distorted) images.\n - A 3x3 **rectification_matrix** which for monocular\
    \ cameras is just an identity matrix.\n - A 3x4 **projection_matrix** which specifies\
    \ the intrinsic matrix of the processed image\n\nI tried loading your .mat file\
    \ into matlab to get the parameters out if it but unfortunately I couldn't get\
    \ a any real numbers out of it (everything was either 0's or 1's) and also I don't\
    \ think it uses the same distortion model. I'm sorry but I wasn't able to convert\
    \ your file!\n\n> Also once I have the yaml file, how\n> can this file be accepted\
    \ by\n> camera_info so that image_proc can\n> subscribe and read the parameters?\n\
    \nThe way this works in ROS is that you pass in the location of the yaml file\
    \ to the driver node you use to load your camera. In ROS there are bunch of camera\
    \ drivers depending on what type of camera it is. If it is a UVC compliant camera\
    \ you would use [libuvc_camera](http://wiki.ros.org/libuvc_camera). You pass in\
    \ the following parameter with the location of the yaml file: \n\n    <param name=\"\
    camera_info_url\" value=\"file:///tmp/cam.yaml\"/>\n\nThat driver node then publishes\
    \ BOTH the images from your camera along with the calibration information. Stereo_image_proc\
    \ can then subscribe to those images and calibration and use them to give you\
    \ the point cloud if you are doing stereo. Hope this helps!\n\nPS. The easiest\
    \ way to do this is just to calibrate your camera using the ros calibration utility\
    \ and a checkerboard. \nFollow this tutorial for a monocular camera: http://wiki.ros.org/camera_calibration/Tutorials/MonocularCalibration\n\
    \nHere is a sample camera calibration yaml for the left camera of a stereo pair:\
    \ \n\n    image_width: 640\n    image_height: 480\n    camera_name: stereo0_link\n\
    \    camera_matrix:\n      rows: 3\n      cols: 3\n      data: [734.889420, 0.000000,\
    \ 317.706196, 0.000000, 732.082689, 239.033655, 0.000000, 0.000000, 1.000000]\n\
    \    distortion_model: plumb_bob\n    distortion_coefficients:\n      rows: 1\n\
    \      cols: 5\n      data: [0.100896, 0.019699, 0.004179, -0.004728, 0.000000]\n\
    \    rectification_matrix:\n      rows: 3\n      cols: 3\n      data: [0.997520,\
    \ -0.005830, 0.070143, 0.005907, 0.999982, -0.000881, -0.070137, 0.001293, 0.997537]\n\
    \    projection_matrix:\n      rows: 3\n      cols: 4\n      data: [801.287930,\
    \ 0.000000, 255.724689, 0.000000, 0.000000, 801.287930, 235.533001, 0.000000,\
    \ 0.000000, 0.000000, 1.000000, 0.000000]"

  body_markdown: "The best way is to write a small Matlab code that will load parameters\
    \ and export them to the YAML file \n\nThere is a small bridge tool to do this\
    \  [yamlmatlab](https://github.com/ewiger/yamlmatlab)\n\n**Example for creating\
    \ yaml file from stereo calibration**\n\n    addpath(genpath('/home/adamanov/Libraries/yamlmatlab-master'));\n\
    \n    load('stereoParams.mat');\n    load('estimationErrors.mat');\n\n    %% -----------Left\
    \ Camera (=Camera_1) ----------------\n    l.image_width  = stereoParams.CameraParameters1.ImageSize(2);\n\
    \    l.image_height = stereoParams.CameraParameters1.ImageSize(1);\n    \n   \
    \ l.camera_matrix = '' ;\n    l.camera_matrix.rows = 3;\n    l.camera_matrix.cols\
    \ = 3;\n    l.camera_matrix.dt = 'd';\n    fx = stereoParams.CameraParameters1.IntrinsicMatrix(1,1);\n\
    \    fy = stereoParams.CameraParameters1.IntrinsicMatrix(2,2);\n    s =  stereoParams.CameraParameters1.IntrinsicMatrix(2,1);\n\
    \    cx = stereoParams.CameraParameters1.IntrinsicMatrix(3,1);\n    cy = stereoParams.CameraParameters1.IntrinsicMatrix(3,2);\n\
    \    \n    l.camera_matrix.data = [fx, s, cx , 0, fy, cy, 0, 0,  1];\n    \n \
    \   k1 = stereoParams.CameraParameters1.RadialDistortion(1);\n    k2 = stereoParams.CameraParameters1.RadialDistortion(2);\n\
    \    k3 = stereoParams.CameraParameters1.RadialDistortion(3);\n    p1 = stereoParams.CameraParameters1.TangentialDistortion(1);\n\
    \    p2 = stereoParams.CameraParameters1.TangentialDistortion(2);\n    \n    l.distortion_coefficients\
    \ = '';\n    l.distortion_coefficients.rows = 1;\n    l.distortion_coefficients.cols\
    \ = 5;\n    l.distortion_coefficients.dt = 'd';\n    l.distortion_coefficients.data\
    \ = [k1,k2,p1,p2,k3];\n    \n    \n    yaml.WriteYaml('camera_info_left.yaml',l)\n\
    \n\n"
