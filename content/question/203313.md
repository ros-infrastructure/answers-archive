    There doesn't seem to be an error there that I can see.

    Based on your comment, note that what you're seeing aren't necessarily <i>paths</i>. The capitalized items are <i>environment variables</i>, some of whose values are set to paths (e.g., <code>ROS_ROOT</code> is set to <code>/opt/ros/hydro/share/ros</code>), some set to other things (e.g., <code>ROS_DISTRO</code> is set to the string <code>hydro</code> and <code>ROS_MASTER_URI</code> is set to the URL <code>http://localhost:11311</code>).

    All of <code>export</code>, <code>grep</code>, and <code>|</code> (called <i>pipe</i>) are command-line commands; to learn more, read the man pages (either google the terms or, from the command line, use the <code>man</code> command).
