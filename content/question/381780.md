    I looked through the code of [gpu-voxels](https://github.com/fzi-forschungszentrum-informatik/gpu-voxels). It looks like they [made some functions to convert URDF shapes to point clouds](https://github.com/fzi-forschungszentrum-informatik/gpu-voxels/blob/master/packages/gpu_voxels/src/gpu_voxels/robot/urdf_robot/robot_link.cpp#L191).     The mesh format has to be `.binvox`, but the `binvox2bt` tool linked in the OP should be able to convert.

I want to convert 3D meshes into Octomaps, to obtain the swept volume of a robot trajectory.

The only conversion I found is [binvox2bt](https://octomap.github.io/octomap/doc/binvox2bt_8cpp.html), but this loads a mesh file directly into an octree, and does not allow transformation before conversion.

[This issue](https://github.com/fzi-forschungszentrum-informatik/gpu-voxels/issues/29) seems to imply that there are no easy solutions. Does anyone have a good project or method to point to?
