  body_markdown: "First of all, you need to add a motor to every element you want\
    \ to actuate. In your case you said you want to actuate all the wheels, so fior\
    \ 4 actuated wheels:\n\n![Wheels rotation axes](https://i.imgur.com/SIWH9N6.png)\n\
    \nthe steps are following:\n\n1) make a control package for your robot.\n\n  \
    \  /robot_control\n    - /config\n        - robot_control.yaml\n    - /launch\n\
    \        - robot_control.launch \n    -CMakeLists.txt\n    -package.xml \n\n\n\
    2) define transmissions\n\nYou want to have  8 actuators in your model. For each\
    \ wheel and for each disk. To add an actuator (for example motor) to your model,\
    \ you need to add the `transmission` tag to the joint you want to actuate. The\
    \ `transmission` tag contains the hardware interface for the joint. In this case\
    \ you would add something like this to your urdf file:\n\n\nrobot.urdf:\n\n  \
    \  <!-- Rear wheels transmission -->\n    <transmission name=\"transmission_rear_left_wheel\"\
    >\n        <type>transmission_interface/SimpleTransmission</type>\n        <joint\
    \ name=\"joint_rear_left_wheel\">\n            <hardwareInterface>hardware_interface/EffortJointInterface</hardwareInterface>\n\
    \        </joint>\n        <actuator name=\"motor_rear_left_wheel\">\n       \
    \     <hardwareInterface>hardware_interface/EffortJointInterface</hardwareInterface>\n\
    \            <mechanicalReduction>1</mechanicalReduction>\n        </actuator>\n\
    \    </transmission>\n\n    <transmission name=\"transmission_rear_right_wheel\"\
    >\n        <type>transmission_interface/SimpleTransmission</type>\n        <joint\
    \ name=\"joint_rear_right_wheel\">\n            <hardwareInterface>hardware_interface/EffortJointInterface</hardwareInterface>\n\
    \        </joint>\n        <actuator name=\"motor_rear_right_wheel\">\n      \
    \      <hardwareInterface>hardware_interface/EffortJointInterface</hardwareInterface>\n\
    \            <mechanicalReduction>1</mechanicalReduction>\n        </actuator>\n\
    \    </transmission>\n\n    <!-- Rear disks transmission -->\n    <transmission\
    \ name=\"transmission_rear_left_disk\">\n        <type>transmission_interface/SimpleTransmission</type>\n\
    \        <joint name=\"joint_rear_left_disk\">\n            <hardwareInterface>hardware_interface/EffortJointInterface</hardwareInterface>\n\
    \        </joint>\n        <actuator name=\"motor_rear_left_disk\">\n        \
    \    <hardwareInterface>hardware_interface/EffortJointInterface</hardwareInterface>\n\
    \            <mechanicalReduction>1</mechanicalReduction>\n        </actuator>\n\
    \    </transmission>\n\n    <transmission name=\"transmission_rear_right_disk\"\
    >\n        <type>transmission_interface/SimpleTransmission</type>\n        <joint\
    \ name=\"joint_rear_right_disk\">\n            <hardwareInterface>hardware_interface/EffortJointInterface</hardwareInterface>\n\
    \        </joint>\n        <actuator name=\"motor_rear_right_disk\">\n       \
    \     <hardwareInterface>hardware_interface/EffortJointInterface</hardwareInterface>\n\
    \            <mechanicalReduction>1</mechanicalReduction>\n        </actuator>\n\
    \    </transmission>\n\n    <!-- Front wheels transmission -->\n    <transmission\
    \ name=\"transmission_front_left_wheel\">\n        <type>transmission_interface/SimpleTransmission</type>\n\
    \        <joint name=\"joint_front_left_wheel\">\n            <hardwareInterface>hardware_interface/EffortJointInterface</hardwareInterface>\n\
    \        </joint>\n        <actuator name=\"motor_front_left_wheel\">\n      \
    \      <hardwareInterface>hardware_interface/EffortJointInterface</hardwareInterface>\n\
    \            <mechanicalReduction>1</mechanicalReduction>\n        </actuator>\n\
    \    </transmission>\n\n    <transmission name=\"transmission_front_right_wheel\"\
    >\n        <type>transmission_interface/SimpleTransmission</type>\n        <joint\
    \ name=\"joint_front_right_wheel\">\n            <hardwareInterface>hardware_interface/EffortJointInterface</hardwareInterface>\n\
    \        </joint>\n        <actuator name=\"motor_front_right_wheel\">\n     \
    \       <hardwareInterface>hardware_interface/EffortJointInterface</hardwareInterface>\n\
    \            <mechanicalReduction>1</mechanicalReduction>\n        </actuator>\n\
    \    </transmission>\n\n     <!-- Front disks transmission -->\n    <transmission\
    \ name=\"transmission_front_left_disk\">\n        <type>transmission_interface/SimpleTransmission</type>\n\
    \        <joint name=\"joint_front_left_disk\">\n            <hardwareInterface>hardware_interface/EffortJointInterface</hardwareInterface>\n\
    \        </joint>\n        <actuator name=\"motor_front_left_disk\">\n       \
    \     <hardwareInterface>hardware_interface/EffortJointInterface</hardwareInterface>\n\
    \            <mechanicalReduction>1</mechanicalReduction>\n        </actuator>\n\
    \    </transmission>\n\n    <transmission name=\"transmission_front_right_disk\"\
    >\n        <type>transmission_interface/SimpleTransmission</type>\n        <joint\
    \ name=\"joint_front_right_disk\">\n            <hardwareInterface>hardware_interface/EffortJointInterface</hardwareInterface>\n\
    \        </joint>\n        <actuator name=\"motor_front_right_disk\">\n      \
    \      <hardwareInterface>hardware_interface/EffortJointInterface</hardwareInterface>\n\
    \            <mechanicalReduction>1</mechanicalReduction>\n        </actuator>\n\
    \    </transmission>\n\n\n3) define controllers\n\nNow you have to write a .yaml\
    \ file where you define type of the controller for each joint and the PID parameters\
    \ (best to find experimentally in Gazebo clinet).\n\nrobot_control.yaml:\n\n \
    \   robot:\n      # Publish all joint states -----------------------------------\n\
    \      joint_state_controller:\n        type: joint_state_controller/JointStateController\n\
    \        publish_rate: 50  \n    \n      # Velocity Controllers -----------------------------------------\n\
    \      joint_rear_left_wheel_controller:\n        type: effort_controllers/JointVelocityController\n\
    \        joint: joint_rear_left_wheel\n        pid: {p: 100.0, i: 10.0, d: 0.01}\n\
    \    \n      joint_rear_right_wheel_controller:\n        type: effort_controllers/JointVelocityController\n\
    \        joint: joint_rear_right_wheel\n        pid: {p: 100.0, i: 10.0, d: 0.01}\n\
    \n      joint_front_left_wheel_controller:\n        type: effort_controllers/JointVelocityController\n\
    \        joint: joint_front_left_wheel\n        pid: {p: 100.0, i: 10.0, d: 0.01}\n\
    \    \n      joint_front_right_wheel_controller:\n        type: effort_controllers/JointVelocityController\n\
    \        joint: joint_front_right_wheel\n        pid: {p: 100.0, i: 10.0, d: 0.01}\n\
    \    \n      # Position Controllers -----------------------------------------\n\
    \      joint_rear_left_disk_controller:\n        type: effort_controllers/JointPositionController\n\
    \        joint: joint_rear_left_disk\n        pid: {p: 10.0, i: 1.0, d: 0.01}\n\
    \    \n      joint_rear_right_disk_controller:\n        type: effort_controllers/JointPositionController\n\
    \        joint: joint_rear_right_disk\n        pid: {p: 10.0, i: 1.0, d: 0.01}\n\
    \n      joint_front_left_disk_controller:\n        type: effort_controllers/JointPositionController\n\
    \        joint: joint_front_left_disk\n        pid: {p: 10.0, i: 1.0, d: 0.01}\n\
    \    \n      joint_rear_right_disk_controller:\n        type: effort_controllers/JointPositionController\n\
    \        joint: joint_front_right_disk\n        pid: {p: 10.0, i: 1.0, d: 0.01}\n\
    \n4) spawn controllers\n\nNext you need a launch file to load the controllers.\n\
    \nrobot_control.launch:\n\n    <launch>\n    \n      <!-- Load joint controller\
    \ configurations from YAML file to parameter server -->\n      <rosparam file=\"\
    $(find robot_control)/config/robot_control.yaml\" command=\"load\"/>\n    \n \
    \     <!-- load the controllers -->\n      <node name=\"controller_spawner\" pkg=\"\
    controller_manager\" type=\"spawner\" respawn=\"false\"\n        output=\"screen\"\
    \ ns=\"/robot\" args=\" joint_state_controller \n                            \
    \              joint_rear_left_wheel_controller\n                            \
    \              joint_rear_right_wheel_controller\n                           \
    \               joint_front_left_wheel_controller\n                          \
    \                joint_front_right_wheel_controller\n                        \
    \                  joint_rear_left_disk_controller\n                         \
    \                 joint_rear_right_disk_controller\n                         \
    \                 joint_front_left_disk_controller\n                         \
    \                 joint_front_right_disk_controller\"/>\n    \n      <!-- convert\
    \ joint states to TF transforms for rviz, etc -->\n      <node name=\"robot_state_publisher\"\
    \ pkg=\"robot_state_publisher\" type=\"robot_state_publisher\"\n        respawn=\"\
    false\" output=\"screen\">\n        <remap from=\"/joint_states\" to=\"robot/joint_states\"\
    \ />\n      </node>\n    \n    </launch>\n\nLaunch the simulation with your robot,\
    \ then launch the robot_control.launch file. The controllers will be loaded and\
    \ you can command them.\n\nWhy I decided for JointVelocityControllers for the\
    \ wheels:\n\nIdeally you want to achieve steady velocity for the movement of your\
    \ robot. effort_controllers/JointVelocityController controller uses PID controller\
    \ to follow given velocity value, so that the wheels rotate with the given velocity.\n\
    \nWhy I decided for JointPositionControllers for the disks:\n\nIf you want to\
    \ use disks to control the direction, you want a controller that maintains the\
    \ defined position of the joint. It figures out exactly how much effort to use,\
    \ to keep the position. For example to keep the disk at 15 degree.\n\nPossible\
    \ caveat: \nYou need to set right PID values. Those are best to set via experimentation.\
    \ When you load your model with joints defined into gazebo simulation, there is\
    \ a tab at the right side of the client, that you have to open by dragging.\n\n\
    ![side tab closed](https://i.imgur.com/m6Q8kRb.png)\n\nYou will find the Effort,\
    \ Position and Velocity tabs with PID parameters and desired value. You can try\
    \ different PID parameters and see how does your model work with them. Use the\
    \ best parameters for your controllers. \n\n![side tab opened]( https://i.imgur.com/UNY2jHf.png)\n\
    \nYou can plot the velocity or position of your robot by opening the Window tab\
    \ at the top of gazebo client and clicking Plot.\n\n![plot tab](https://i.imgur.com/O0f0buQ.png)\n\
    \n![plot window opened](https://i.imgur.com/GIRl0ZR.png)\n\nInside the plot window,\
    \ navigate to Model tab and choose the desired variable to plot."

    Just regarding the pictures in this comment thread, the reason the robot in those pictures do not move forward is because the joint is set to rotate around the incorrect axis. You can see in in the first picture, there is a small arrow on the axis which is set as the axis of rotation. In the world coordinate system it is the z axis in those pictures. But you need the wheels to rotate in the y axis in order to move robot forward (assuming the standard robot coordinate system where x axis is aligned with the robot heading direction).
