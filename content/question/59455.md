    A ROS API Documentation per-se doesn't exist.

    ROS is composed of many many different modules (I suggest you check the [original PDF](http://pub1.willowgarage.com/~konolige/cs225B/docs/quigley-icra2009-ros.pdf)) each of which doing a very small part of the work.

    The nearest thing to a baseline ROS API is [roscpp](http://www.ros.org/wiki/roscpp) which is the foundation of ROS.
    In this page (as on most other pages) on the top right you'll find a link [Code API](http://ros.org/doc/groovy/api/roscpp/html) which will take you to the relevant doxygen.

    Good luck learning ROS!
