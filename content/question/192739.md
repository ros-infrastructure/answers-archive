  body_markdown: "Okay so for anyone out there with the same problem here is my solution:\n\
    \nI start from the end of the MoveIt Setup Assistant. Note that i use non-standard\
    \ joint names.\n\nJust as a caveat: This is not the best solution, simply one\
    \ that worked for me.\nI hope it is helpful.\n\n 1. Setup your controllers.yaml\
    \ such as the one below. This will include what controller is responsible for\
    \ what actuator.\n 2. Implement an ActionServer for each controller. An example\
    \ implementation is given below.\n 3. Modify the moveit_planning_execution.launch\
    \ for your system. Again, my launch file is below.\n 4. Write a launch files to\
    \ start the action server and moveit_planning_execution.launch.\n\nThe moveit_planning_execution.launch:\n\
    \n    <launch>\n      <!-- The planning and execution components of MoveIt! configured\
    \ to run -->\n      <!-- using the ROS-Industrial interface. -->\n     \n    \
    \  <!-- Non-standard joint names:\n           - Create a file <robot_moveit_dir>/config/joint_names.yaml\n\
    \               controller_joint_names: [joint_1, joint_2, ... joint_N] \n   \
    \        - Update with joint names for your robot (in order expected by rbt controller)\n\
    \           - and uncomment the following line: -->\n       <rosparam command=\"\
    load\" file=\"$(find <robot_moveit_dir>)/config/joint_names.yaml\"/>\n     \n\
    \      <!-- the \"sim\" argument controls whether we connect to a Simulated or\
    \ Real robot -->\n      <!--  - if sim=false, a robot_ip argument is required\
    \ -->\n      <arg name=\"sim\" default=\"false\" />\n      <arg name=\"robot_ip\"\
    \ unless=\"$(arg sim)\" />\n     \n      <!-- load the robot_description parameter\
    \ before launching ROS-I nodes -->\n      <include file=\"$(find <robot_moveit_dir>)/launch/planning_context.launch\"\
    \ >\n        <arg name=\"load_robot_description\" value=\"true\" />\n      </include>\n\
    \    \n      <!-- run the robot simulator and action interface nodes -->\n   \
    \   <group if=\"$(arg sim)\">\n        <include file=\"$(find industrial_robot_simulator)/launch/robot_interface_simulator.launch\"\
    \ />\n      </group>\n    \n      <!-- publish the robot state (tf transforms)\
    \ -->\n      <node name=\"robot_state_publisher\" pkg=\"robot_state_publisher\"\
    \ type=\"robot_state_publisher\" />\n    \n      <include file=\"$(find <robot_moveit_dir>)/launch/move_group.launch\"\
    >\n        <arg name=\"publish_monitored_planning_scene\" value=\"true\" />\n\
    \      </include>\n    \n      <include file=\"$(find <robot_moveit_dir>)/launch/moveit_rviz.launch\"\
    >\n        <arg name=\"config\" value=\"true\"/>\n      </include>\n    \n   \
    \   <include file=\"$(find <robot_moveit_dir>)/launch/default_warehouse_db.launch\"\
    \ />\n    \n    </launch>\n\nThe controllers.yaml:\n\n    controller_list:\n \
    \     - name: /full_ctrl\n        action_ns: joint_trajectory_action\n       \
    \ type: FollowJointTrajectory\n        default: true\n        joints: [j_gripper_wrist1,\
    \ j_wrist1_arm1, j_arm1_arm2, j_arm2_wrist2, j_wrist2_gripper2]\n\nThe example\
    \ action server (full_action_server.cpp):\n\n    //http://clopema.felk.cvut.cz/redmine/projects/clopema/wiki/Sending_trajectory_to_the_controller\n\
    \    //http://wiki.ros.org/actionlib_tutorials/Tutorials/SimpleActionServer%28ExecuteCallbackMethod%29\n\
    \    //http://wiki.ros.org/actionlib_tutorials/Tutorials/SimpleActionServer%28GoalCallbackMethod%29\n\
    \    #include <ros/ros.h>\n    #include <actionlib/server/simple_action_server.h>\n\
    \    #include <control_msgs/FollowJointTrajectoryAction.h>\n    #include <trajectory_msgs/JointTrajectory.h>\n\
    \    \n    class RobotTrajectoryFollower\n    {\n    protected:\n    \n      ros::NodeHandle\
    \ nh_;\n      // NodeHandle instance must be created before this line. Otherwise\
    \ strange error may occur.\n      actionlib::SimpleActionServer<control_msgs::FollowJointTrajectoryAction>\
    \ as_; \n      std::string action_name_;\n    \n    public:\n    \n      RobotTrajectoryFollower(std::string\
    \ name) :\n        as_(nh_, name, false),\n        action_name_(name)\n      {\n\
    \      \t//Register callback functions:\n      \tas_.registerGoalCallback(boost::bind(&RobotTrajectoryFollower::goalCB,\
    \ this));\n        as_.registerPreemptCallback(boost::bind(&RobotTrajectoryFollower::preemptCB,\
    \ this));\n        \n        as_.start();\n      }\n    \n      ~RobotTrajectoryFollower(void)//Destructor\n\
    \      {\n      }\n      \n      void goalCB()\n      {\n        // accept the\
    \ new goal\n        //goal_ = as_.acceptNewGoal()->samples;\n      }\n    \n \
    \     void preemptCB()\n      {\n        ROS_INFO(\"%s: Preempted\", action_name_.c_str());\n\
    \        // set the action state to preempted\n        as_.setPreempted();\n \
    \     }\n    };\n    \n    \n    int main(int argc, char** argv)\n    {\n    \
    \  ros::init(argc, argv, \"action_server\");\n    \n      RobotTrajectoryFollower\
    \ RobotTrajectoryFollower(\"/full_ctrl/joint_trajectory_action\");\n      ros::spin();\n\
    \    \n      return 0;\n    }\n\nRegards,\n\nChris.\n\n\n\n"
