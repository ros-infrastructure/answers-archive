  body_markdown: "You are accessing an empty list unknowingly while writing the following\
    \ statement:\n\n    BB.polygons[i].polygon.points.append(V1)\n\nThis is why the\
    \ `list index out of range` error is displayed.\n\nTo get rid of this error, you\
    \ should do the following:\n\n    # Create a PolygonArray\n    bb = PolygonArray()\
    \ # We do not use a capital letter to name an instance as a common practice.\n\
    \n    # Create a polygon\n    polygon = PolygonStamped()\n\n    # Add points to\
    \ our polygon\n    polygon.points.append(v1)\n    polygon.points.append(v2)\n\
    \    polygon.points.append(v3)\n    polygon.points.append(v4)\n\n    # add polygon\
    \ to the PolygonArray \n    bb.polygons.append(polygon)\n\nNotice that I am using\
    \ the `append` function of list in python instead of using an index, such as `i`."
