  body_markdown: "The navigation stack uses plugins for the local and global planners.\n\
    \nThe [RobotSetup Tutorial](http://www.ros.org/wiki/navigation/Tutorials/RobotSetup)\
    \ describes the basics of how to set up the navigation stack, including how to\
    \ select which path planners to use.\n\n[base_local_planner](http://www.ros.org/wiki/base_local_planner)\
    \ and [dwa_local_planner](http://www.ros.org/wiki/dwa_local_planner) can both\
    \ be used as local planners. They both work similarly, but the code for the dwa_local_planner\
    \ is much cleaner.\n\n[carrot_planner](http://www.ros.org/wiki/carrot_planner),\
    \ [navfn](http://www.ros.org/wiki/navfn) and [sbpl_lattice_planner](http://ros.org/wiki/sbpl_lattice_planner)\
    \ can all be used as global planners.  \n\nnavfn is fast, but it produces paths\
    \ with a lot of entropy, which are harder for non-holonomic robots to follow.\
    \ When configured properly, the SBPL planner can plan for very constrained bases,\
    \ including non-holonomic and ackermann-type bases."
