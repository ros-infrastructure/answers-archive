  body_markdown: "Update: a new package that handles Jacobian jogging: [jog_arm](http://wiki.ros.org/jog_arm)\n\
    \nYou can use UR's python interface, like this (bypassing ros_control). The downside\
    \ is, there won't be any collision checking. We used a 50Hz loop rate.\n\n   \
    \         // Compose a string that contains URScript velocity command\n      \
    \    sprintf(cmd_, \"speedl([%1.5f, %1.5f, %1.5f, %1.5f, %1.5f, %1.5f], 0.2, 0.1)\\\
    n\", delta.getX(), delta.getY(), delta.getZ(), 0., 0., 0.);\n          ROS_INFO_STREAM(cmd_);\n\
    \          \n          // Copy command string to ROS message string\n        \
    \  urscriptString_.data = cmd_;\n          \n          // Send the compliant motion\
    \ command to the UR5\n          velPub_.publish(urscriptString_);\n\nOur lab has\
    \ also used the Jacobian method like you were trying to do, but only on a Motoman\
    \ arm (never tried it with a UR)."
