  body_markdown: "Hey,\n\nI assume that you want to use newer version of PCL (which\
    \ was not installed with ROS). You would need to install PCL from source. Download\
    \ desired PCL repo from this [link.](http://www.pointclouds.org/downloads/source.html)\
    \ \nThen, compile it from source while setting USE_ROS param 'true'.\n\n    mkdir\
    \ build\n    cd build \n    cmake .. -DUSE_ROS=1\n    sudo make install -j\n\n\
    another way is to include standalone-pcl directory in CMakeLists.txt file of your\
    \ package using \ninclude_directories(${PCL_INCLUDE_DIRS} )\nand linking executable\
    \ with \ntarget_link_libraries(exec_name  ${catkin_LIBRARIES}  ${PCL_LIBRARIES})\n\
    \nhope this helps"
