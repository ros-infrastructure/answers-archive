  body_markdown: |-
    It seems that you only installed the hector_quadrotor stack without its dependencies. For compiling the hector_quadrotor stack, you need at least [hector_gazebo](http://ros.org/wiki/hector_gazebo), [hector_models](http://ros.org/wiki/hector_models) and [hector_common](http://ros.org/wiki/hector_common) (if you want to publish tf). Make sure to have them in your ROS_PACKAGE_PATH or, for fuerte, install them as Ubuntu package with the `sudo apt-get install ros-fuerte-hector-quadrotor` command. We are going to release hector_quadrotor for groovy soon.

    The [hector_quadrotor_demo](http://ros.org/wiki/hector_quadrotor_demo) package has been moved to a separate stack, namely [hector_quadrotor_apps](http://ros.org/wiki/hector_quadrotor_apps) some time ago. For running the demos with SLAM, you will also need the [hector_slam](http://ros.org/wiki/hector_slam) package.

    Information about required stacks was indeed incomplete in the tutorials. I have added the missing stacks in the prerequisites section. Thanks for reporting!

    *Note to me:* Probably it would be best to provide a [rosinstall](http://ros.org/wiki/rosinstall) file containing all stacks required to run the demo, so that you can checkout them with a single command.
