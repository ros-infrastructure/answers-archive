  body_markdown: "Look into the [turtlebot_description](http://wiki.ros.org/turtlebot_description)\
    \ package, which contains the files for simulated kinect. Get rid of the turtlebot\
    \ robot description and use the part which contains the kinect.  It should be\
    \ easy to copy the code for the husky robot. Also look into the [turtlebot_gazebo](http://wiki.ros.org/turtlebot_gazebo)\
    \ package which details the simulation of the turtlebot in an empty world. \n\n\
    You can use the launch file as \n\n    roslaunch turtlebot_gazebo  turtlebot_empty_world.launch\n\
    \nSimulated kinect topic is published on the `/camera /image_raw` topic and to\
    \ get the point cloud is available at `/camera/depth/points` topic. Look into\
    \ the [turtlebot_description/urdf/turtlebot_gazebo.urdf.xacro](https://github.com/turtlebot/turtlebot/blob/indigo/turtlebot_description/urdf/turtlebot_gazebo.urdf.xacro)\
    \ from which you can simulate the kinect. \n\nHope this helps\n\n"
