    I don't know of any Display plugins for RViz that visualise radar (or related) data. There was a Gazebo GSoC project ([this](https://github.com/osrf/osrf_wiki/wiki/GSoC#simulate-radar-sensor) one) that could have potentially resulted in a plugin for that, but OSRF wasn't selected for GSoC this year.

    If you can't find anything online (github fi), then I'm afraid you'll have to write your own plugin. That can be slightly involved, but should be doable. See [wiki/rviz/Tutorials](http://wiki.ros.org/rviz/Tutorials) for the introductory tutorials.

    ---

    Edit: short-term custom visualisation using markers may be sufficient, but I would recommend you *also* try and see whether you can contribute to the ongoing discussion about radar and ROS on Discourse: [Addition of Radar-Specific Message(s) to sensor_msgs](https://discourse.ros.org/t/addition-of-radar-specific-message-s-to-sensor-msgs/2724).

    After a standardised msg set, adding visualisation capabilities to tools like RViz would be a lot easier.

  body_markdown: "As far as I know there is no RViz plugin for this type of sensor.\
    \ In my work I've regularly used the [marker](http://wiki.ros.org/rviz/DisplayTypes/Marker)\
    \ message type to visualise complex information that isn't currently supported.\
    \ Using this type you can visualise any 3D color mesh data you can generate. It's\
    \ a bit tricky if you're new to ROS but I can post some code examples if you're\
    \ using C++.\n\nHere is an example code segment that creates a marker mesh message,\
    \ you'll then need to publish this message to a topic to see it in RVIZ. Once\
    \ the message has been created and setup you're basically adding a color value\
    \ then three vertices for each triangle, each triangle can be a different color\
    \ (in my example they're all the same).\n\nThis example uses a vector of Eigen::Vector3f\
    \ to represent the vertices and a vector of custom triangle structures, you can\
    \ replace this with anything you wish for your own project.\n\n    // create Mesh\
    \ message\n    visualization_msgs::Marker meshMarker;\n    \n    // setup Triangle_List\
    \ marker message\n    meshMarker.header.frame_id = \"Coordinate_frame_id\";\n\
    \    meshMarker.header.stamp = ros::Time();\n    meshMarker.ns = \"custom_mesh\"\
    ;\n    meshMarker.id = 0;\n    meshMarker.type = visualization_msgs::Marker::TRIANGLE_LIST;\n\
    \    meshMarker.action = visualization_msgs::Marker::ADD;\n    meshMarker.pose.position.x\
    \ = 0;\n    meshMarker.pose.position.y = 0;\n    meshMarker.pose.position.z =\
    \ 0;\n    meshMarker.pose.orientation.x = 0.0;\n    meshMarker.pose.orientation.y\
    \ = 0.0;\n    meshMarker.pose.orientation.z = 0.0;\n    meshMarker.pose.orientation.w\
    \ = 1.0;\n    meshMarker.scale.x = 1;\n    meshMarker.scale.y = 1;\n    meshMarker.scale.z\
    \ = 1;\n    meshMarker.color.a = 1.0;\n    \n    // create temp vertex and color\
    \ objects.\n    geometry_msgs::Point \tvertex;\n    std_msgs::ColorRGBA\tmeshColor;\n\
    \    \n    // add triangles\n    for (int f=0; f<triangles.size(); ++f)\n    {\n\
    \    \tmeshColor.r = 1.0;\n    \tmeshColor.g = 0.5;\n    \tmeshColor.b = 0.0;\n\
    \    \n    \tmeshMarker.colors.push_back(meshColor);\n    \n    \t// add triangle\
    \ to mesh\n    \tvertex.x = vertices[triangles[f].v1][0];\n    \tvertex.y = vertices[triangles[f].v1][1];\n\
    \    \tvertex.z = vertices[triangles[f].v1][2];\n    \tmeshMarker.points.push_back(vertex);\n\
    \    \n    \tvertex.x = vertices[triangles[f].v2][0];\n    \tvertex.y = vertices[triangles[f].v2][1];\n\
    \    \tvertex.z = vertices[triangles[f].v2][2];\n    \tmeshMarker.points.push_back(vertex);\n\
    \    \n    \tvertex.x = vertices[triangles[f].v3][0];\n    \tvertex.y = vertices[triangles[f].v3][1];\n\
    \    \tvertex.z = vertices[triangles[f].v3][2];\n    \tmeshMarker.points.push_back(vertex);\n\
    \    }\n\n\n"
