    > How would I go about publishing on a topic as soon as bytes are present in the file descriptor specified by the CAN Bus socket? What is the ROS2 mechanism I should look into?

    My initial response would be: there is no ROS2 mechanism for this, as it seems like a non-ROS specific requirement.

    How would you do this without ROS?

    Personally, I'd probably use `select(..)` on the file descriptor, or any other form of event-based notification, such that your publisher is unblocked when there are new frames available in the socket. If event-based is not performant enough, there are various polling approaches which could lower the overhead and jitter.

    Alternatively: use blocking reads on the socket with a configured timeout. That should make things more predictable.

    But again, this seems like a non-ROS question.
