    Edit: with the [sync of 2021-06-03](https://discourse.ros.org/t/new-packages-for-foxy-fitzroy-2021-06-03/20770), `realsense2_camera` should now be available from the main repositories.

    ---

    According to [status_page/ros_foxy_default.html?q=realsense](http://repo.ros2.org/status_page/ros_foxy_default.html?q=realsense), `realsense2_camera` is not available in the `main` repositories yet (notice the red square in the right-most column).

    That would explain why you can't install it using `apt`.

    As to *why* it isn't available, I wouldn't know.

    It seems to be available in the testing repository though. How to set that up is sort-of documented on this page: [Pre-release Testing: Debian testing repository](https://docs.ros.org/en/foxy/Installation/Prerelease-Testing.html#debian-testing-repository).
