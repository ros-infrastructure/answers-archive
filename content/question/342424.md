 In ROS 1 they used to be forbidden but are now allowed (https://github.com/ros-infrastructure/catkin_pkg/pull/199 and connected links)

In ROS 2 it used to be forbidden (for [catkin/ament packages](https://github.com/ament/ament_package/pull/51)):

    ament_package.exceptions.InvalidPackage: Invalid package manifest './src/foo/package.xml': Package name 'foo-bar' does not follow naming conventions

But seems to not be enforced since the [switch to colcon/catkin_pkg](https://github.com/ament/ament_cmake/pull/137):

    root@76e629018ac5:/ws# colcon build
    Starting >>> foo-bar 
    Finished <<< foo-bar [1.41s]                  

    Summary: 1 package finished [1.51s]

Does this mean dashes are now allowed in ROS 2 package names? If yes, is there any recommendations about using/not using them ?
