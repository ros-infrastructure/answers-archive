  - body_markdown: "Hi @LSD, thank you for your quick reply. I finally found the issue.\
      \ It seems that with the ros2 version of `gazebo_ros_pkg` the tags `<hackBaseline>`\
      \  and `<frameName>` have been renamed respectively `<hack_baseline>` and `<frame_name>`\
      \ see the code here https://github.com/ros-simulation/gazebo_ros_pkgs/blob/foxy/gazebo_ros/src/utils.cpp#L55\
      \  \n\nAs the `<frameName>` tag wasn't read/recognized, the only point I had\
      \ in rviz wasn't placed in my `camera_link_optical` frame but in the highest\
      \ parent link of my URDF, that is to say `base_footprint`. After renaming the\
      \ tag to `<frame_name>`, this point was placed at the origin of the `camera_link_optical`\
      \ frame. Then I renamed the `<hackBaseline>` tag and all the points appeared.\
      \  \n\nThe Gazebo documentation really sucks...  \nThey even refer to a `libgazebo_ros_multicamera.so`\
      \ for multicameras which doen't exist anymore, it has been included in libgazebo_ros_camera.so."
