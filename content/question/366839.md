    You could add the object to the URDF. [See here](http://wiki.ros.org/urdf/Tutorials/Adding%20Physical%20and%20Collision%20Properties%20to%20a%20URDF%20Model). That's what I would recommend since it will always be there.

    OR, in code, you could set up a Planning Scene and add the S-shaped collision object to it. There's a tutorial [here](https://ros-planning.github.io/moveit_tutorials/doc/planning_scene_ros_api/planning_scene_ros_api_tutorial.html#attach-an-object-to-the-robot). The message definition is [here](http://docs.ros.org/en/melodic/api/moveit_msgs/html/msg/CollisionObject.html).

    OR you can add the collision mesh with the RViz MotionPlanning plugin (GUI). Of course, then you would have to re-add the object manually every time you launch the robot.
