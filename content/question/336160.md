  body_markdown: "Ok so the error stems from the fact that:\nros-dashing-rosbag2-bag-v2-plugins\
    \ : depends on  ros-dashing-ros1-bridge\n\nSo you you could do \n\n    sudo apt-get\
    \ install ros-dashing-ros1-bridge\n\nyou will most likely get the error that certain\
    \ dependencies are missing and they can not be installed (all the messages for\
    \ ROS1).\nThis is because the ros1-bridge assumes a melodic install and a dashing\
    \ install, between which it can bridge.\nFrom here you have 2 solutions.\n\nSolution\
    \ 1:\njust don't install \n\n    ros-dashing-rosbag2-bag-v2-plugins\n    ros-dashing-rosbag2-bag-v2-plugins-dbgsym\n\
    \nand only install the other rosbag2 packages.\n\nSolution 2:\n\n    sudo apt-get\
    \ install ros-melodic-desktop-full\n\n    sudo apt-get install ros-dashing-ros1-bridge\n\
    \nthen try \n\n    sudo apt-get install ros-dashing-rosbag2*"
