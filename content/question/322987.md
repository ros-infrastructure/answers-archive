  body_markdown: "> Can I install ROS1 kinetic and ROS2 crystal on same pc? I am using\
    \ Ubuntu 18.04 LTS, 64-bit. \n\nThe short answer would be (for your stated configuration):\
    \ no, as Kinetic is not supported on Ubuntu Bionic (only on Xenial (16.04), see\
    \ [REP-3](http://www.ros.org/reps/rep-0003.html#kinetic-kame-may-2016-may-2021)).\
    \ The ROS buildfarm does not build any Kinetic packages for Bionic because of\
    \ that.\n\nThe longer answer would be: *maybe*.\n\nIt might be possible to build\
    \ Kinetic from source, *but* there will probably be significant incompatibilities\
    \ to overcome, such as those with Qt (4 vs 5), Ogre and potentially Boost.\n\n\
    ---\n\nAn alternative to building Kinetic from source could be to use a Docker\
    \ (or Singularity) image of Kinetic (such as `ros:kinetic` or `osrf/ros:kinetic-desktop(-full)`).\n\
    \nTechnically, that would not be an answer to your question, as it wouldn't be\
    \ exactly running on the same PC / OS, so depending on your requirements / use-cases\
    \ it wouldn't actually help you.\n\n---\n\nA second alternative could be to install\
    \ ROS Kinetic on Ubuntu Xenial and build ROS Crystal from source next to that.\
    \ REP-2000 lists Xenial as a Tier 2 platform ([here](http://www.ros.org/reps/rep-2000.html#crystal-clemmys-december-2018-december-2019))\
    \ and apart from some of the RQT plugins, Crystal should still compile on Xenial\
    \ last I heard.\n\n\n> I have projects on ROS Kinetic [..] and I am using Ubuntu\
    \ 18.04 LTS, 64-bit.\n\nBtw: this confuses me, as Kinetic cannot be installed\
    \ on Bionic. Are you already using containers?"
