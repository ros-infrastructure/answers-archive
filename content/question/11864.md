  body_markdown: "The navigation stack operates using actionlib. Thus, to communicate\
    \ with move_base, you must use actionlib's ActionClient to send commands and receive\
    \ feedback. For simplicity, you can use the following code:\n\n    typedef actionlib::SimpleActionClient<move_base_msgs::MoveBaseAction>\
    \ NavClient;\n    \n    class MyClass\n    {\n      private:\n          NavClient\
    \ nav_client_;\n      ...\n    }\n\n    MyClass::MyClass() : nav_client_(\"move_base\"\
    , true) \n    {\n      ...\n    }\n    \n    MyClass::cancelNavigation()\n   \
    \ {\n      nav_client_.cancelAllGoals();\n    }\n\nFor more advanced actionlib\
    \ usage, you can find complete documentation on actionlib [here](http://www.ros.org/wiki/actionlib).\
    \ \n"
