  body_markdown: "This is documented on the [roslaunch/XML/param](http://wiki.ros.org/roslaunch/XML/param)\
    \ page: \n\n> `textfile=\"$(find pkg-name)/path/file.txt\"`\n\n> The contents\
    \ of the file will be read and stored as a string. The file must be locally accessible,\
    \ though it is strongly recommended that you use the package-relative `$(find)/file.txt`\
    \ syntax to specify the location. \n\nSo for `robot_description`, that would be:\n\
    \n    <param name=\"robot_description\" textfile=\"$(find pkg-name)/path/file.urdf\"\
    />\n"
