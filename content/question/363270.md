    Seems you added a [zero-width space](https://en.wikipedia.org/wiki/Zero-width_space) character right in front of the `local_frontiers` name. `catkin_create_pkg` (rightfully so) [only accepts lower and upper case letters, as well as numbers at the start of the package name](https://github.com/ros-infrastructure/catkin_pkg/blob/master/src/catkin_pkg/package.py#L232).

    (you see the zero-width space when you c'n'p the command you posted above, save it to a text file and open this with e.g. vim: `catkin_create_pkg <200b>local_frontiers rospy roscpp`)
