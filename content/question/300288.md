    The documentation states that ros_control's **diff_drive_controller** works with wheel joints through a [velocity interface](http://wiki.ros.org/diff_drive_controller?distro=melodic#Hardware_interface_type). You have to implement a ros_control **hardware_interface** that interacts with the motor driver and wheel encoders of each individual wheel. This hardware interface can send commands to **each individual wheel** using the SDK or library provided by the hardware vendor.
