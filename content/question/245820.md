  body_markdown: "OK, it worked. Although approach was the same, method was different.\
    \ I followed these tutorials ([link](http://wiki.ros.org/ROSARIA/Tutorials/How%20to%20use%20ROSARIA)).\
    \ Main problem was that Raspberry Pi 3 is an arm based architecture and all of\
    \ the Aria Softwares ([link](http://robots.mobilerobots.com/wiki/Aria)) are based\
    \ on intel/amd processor based architecture. So, here is what I did. It is important\
    \ to mention that I was using ubuntu 16.06 mate and ROS-Kinetic. \n\n**The steps\
    \ are as follows.** \n\n - Follow the tutorial\n   ([link](http://wiki.ros.org/ROSARIA/Tutorials/How%20to%20use%20ROSARIA))\n\
    \   till the software installation\n   (Aria).\n - Download Aria ([link](http://robots.mobilerobots.com/ARIA/download/current/libaria_2.9.1+ubuntu16_amd64.deb))\n\
    \   \n - Go to the download directory\n  \n - run `sudo dpkg --force-all -i libaria_2.9.0+ubuntu12+gcc4.6_amd64.deb`\n\
    \ \n - run `make clean`. \n   \n - run `make -j4` \n\n***It is worth mentioning\
    \ that here in this stage, my setup was failed but just to make sure, I rant it\
    \ again and the second time it worked. It was installed by my colleague in another\
    \ machine and he experienced the same which means that it worked on second time***\n\
    \n - go to the ros workspace `cd ~/catkin_ws`\n   \n\n - Run `catkin_make --force-cmake`\n\
    \nSo, it worked. \n\nThanks to ReedHedges for helping me out. From his post above,\
    \ I got the clue to resolve this issue."
