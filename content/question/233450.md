    \ bind if you replace or add parameters.\nIt's just a matter of using the placeholders\
    \ `_1`, `_2`, ... provided by boost for forwarding the original arguments or by\
    \ providing your own ones.\n\nHere you can find another answer in which two extra\
    \ parameters are added (next to `_1`): [LINK](http://answers.ros.org/question/232204/passing-multiple-arguments-to-a-callback-c/?answer=232226#post-id-232226).\n\
    \nRegarding the difference between subscribeCamera and subscribe: both functions\
    \ provide an overload that excepts the a **boost::function** type callback, therefore\
    \ you can apply boost::bind to both of them.\n\nRefer to the [Code Doc](http://docs.ros.org/jade/api/image_transport/html/classimage__transport_1_1ImageTransport.html)\
    \ for the overloaded methods:\n\n    subscribeCamera (const std::string &base_topic,\
    \ uint32_t queue_size, const CameraSubscriber::Callback &callback, const ros::VoidPtr\
    \ &tracked_object=ros::VoidPtr(), const TransportHints &transport_hints=TransportHints())\n\
    \ \t\n    subscribe (const std::string &base_topic, uint32_t queue_size, const\
    \ boost::function< void(const sensor_msgs::ImageConstPtr &)> &callback, const\
    \ ros::VoidPtr &tracked_object=ros::VoidPtr(), const TransportHints &transport_hints=TransportHints())\n\
    \nHere the argument type `CameraSubscriber::Callback` is a typedef for a `boost::function`\
    \ object accepting both default parameters. Pass your functor created with `boost::bind`\
    \ here."
