  body_markdown: "Your `.bashrc` file is located at the user's home directory, it's\
    \ a linux thing. There isn't a different `.bashrc` file for each ros workspace.\
    \ But you have to source every one ros workspace you want to use. These \"sources\"\
    \ are happening when you open a new terminal. So remember to open a new terminal\
    \ after a `catkin_make`  \n\nExample (in my `.bashrc`):\n\n    source /opt/ros/hydro/setup.bash\n\
    \    \n    source ~/navigation_ws/devel/setup.bash\n    \n    source ~/pandora_ws/devel/setup.bash\n\
    \n P.S. When you have multiple workspaces the latter overlays the previous ones.\
    \ For example my `navigation_ws` overloads some packages that exist in `/opt/ros/hydro`"
