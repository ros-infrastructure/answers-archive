  body_markdown: "The best way in general is to record the following:\n\n 1. /tf \
    \ \n 1. /camera/rgb/image_mono OR /camera/rgb/image_color if you want color\n\
    \ 1. /camera/rgb/camera_info   \n 1. /camera/depth/image   \n 1. /camera/depth/camera_info\n\
    \n/tf is not strictly required but helpful depending on the use case. The rosbag\
    \ command is then:\n\n    rosbag record -O filename-prefix /tf /camera/rgb/image_color\
    \ /camera/rgb/camera_info /camera/depth/image /camera/depth/camera_info\n\nI still\
    \ use the openni_camera package to get the data, that would be:\n\n    roslaunch\
    \ openni_camera openni_node.launch\n\nHave a look at the file [launch/rgbdslam.launch](http://alufr-ros-pkg.googlecode.com/svn/trunk/freiburg_tools/rgbdslam/launch/rgbdslam.launch).\
    \ If necessary adapt to your choice of grayscale image: change the first parameter\
    \ to `/camera/rgb/image_mono`\n\nPlay the bagfile (but stop the openni_node first):\n\
    \n    rosbag play filename-prefix-some-date-string.bag\nHave a look at the options\
    \ (rosbag help play). Reducing the playback rate might help unless you have a\
    \ really fast computer.\n\nAlternatively, you can set the bagfile_name parameter\
    \ (see the [example config launchfile](http://alufr-ros-pkg.googlecode.com/svn/trunk/freiburg_tools/rgbdslam/launch/rgbdslam_sample_config.launch)\
    \ to your bagfile. Use an absolute path.\nThe start_paused parameter could make\
    \ things more convenient.\n\nThen run rgbdslam from the (adapted) launch file\n\
    \n    roslaunch rgbdslam rgbdslam.launch"

**Edit 3:**

I've got a fix which works for now, but I'd greatly appreciate a better solution.

I edited `createXYZRGBPointCloud` in `src/misc.cpp`:

    pointcloud_type* createXYZRGBPointCloud (const sensor_msgs::ImageConstPtr& depth_msg, 
                                             const sensor_msgs::ImageConstPtr& rgb_msg1,
                                             const sensor_msgs::CameraInfoConstPtr& cam_info) 
    {
      sensor_msgs::ImagePtr rgb_msg(new sensor_msgs::Image);
      rgb_msg->header = rgb_msg1->header;
      rgb_msg->height = rgb_msg1->height;
      rgb_msg->width = rgb_msg1->width;
      rgb_msg->encoding = rgb_msg1->encoding;
      rgb_msg->is_bigendian = rgb_msg1->is_bigendian;
      rgb_msg->step = rgb_msg1->step;
      rgb_msg->data = rgb_msg1->data;
    
      if (rgb_msg->encoding.compare("bgr8") == 0) {
        rgb_msg->encoding = "rgb8";
        for (int i=0; i<rgb_msg->data.size(); i+=3) {
          char temp_red = rgb_msg->data[i];
          rgb_msg->data[i] = rgb_msg->data[i+2];
          rgb_msg->data[i+2] = temp_red;
        }
      }
