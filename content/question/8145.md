  body_markdown: "You can start multiple `gzserver` instances on the same machine\
    \ using the `GAZEBO_MASTER_URI` environment variable. Here is an example\n\n1.\
    \ Start `gzserver` and `gzclient`. By default they operate on `localhost:11345`\n\
    \    \n    Terminal 1: `gzserver`\n\n    Terminal 2: `gzclient`\n\n2. Start a\
    \ `gzserver` and `gzclient` on a different port\n\n    Terminal 3: `GAZEBO_MASTER_URI=localhost:11346\
    \ gzserver`\n\n    Terminal 4: `GAZEBO_MASTER_URI=localhost:11346 gzclient`\n\n\
    \nHere is a shorter version:\n\nTerminal 1: `gazebo`\n\nTerminal 2: `GAZEBO_MASTER_URI=localhost:11346\
    \ gazebo`"
