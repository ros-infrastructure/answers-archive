  body_markdown: "Client-Server communication via services is a 1 to 1 communication.\n\
    When you create a client \n\n    auto client = node->create_client<ServiceT>(service_name,\
    \ qos);\n\nThis client can only send requests to the service specified by `service\
    \ name`. In order to change its service you need to create again the object.\n\
    \n\nFrom your question it looks like you want to send the same `ServiceT::Request`\
    \ object to multiple servers.\nThe `ServiceT::Request` object is not linked to\
    \ any specific server or client and it can be reused as many times you want.\n\
    \nAssuming that you created multiple clients, what you can do is\n\n    ServiceT::Request\
    \ request;\n    \n    client1->send_request(request);\n    client2->send_request(request);"
