  body_markdown: "So, what I understand is that you want to export a library to be\
    \ used by other packages, here's the answer for this.\nlet's say you have a package\
    \ called `my_library` that contains the library you want to export, and another\
    \ package called `lib_consumer` which consumes that library.\n\nThe two packages\
    \ structure:\n\n    my_library\n       include\n          the_library\n      \
    \         lib_header.hpp\n       src\n       CMakeLists.txt\n    consumer\n  \
    \     src\n          consumer.cpp\n       CMakeLists.txt\n\n\n##In the `my_library`\
    \ package, your CMakeLists.txt should be as follows:\n\nThe following line makes\
    \ you use direct inclusion in your package's (my_library src cpp files, if you\
    \ have any) (i.e #include \"lib_header.hpp\")\n\n    include_directories(include/the_library)\
    \  \n\nYou then add the library, the `set` is just for convenience if you have\
    \ multiple header files, you can do the same if you have multiple cpp files. (the\
    \ target name is my_lib)\n\n    set(HEADER_FILES include/the_library/lib_header.hpp)\n\
    \    add_library(my_lib src/lib_source.cpp ${HEADER_FILES}) \n\nThis line to export\
    \ the targets, in our case it's a library! (it passes the information to cmake\
    \ to tell it that we want to export a library (more generally a target) to be\
    \ used by some other package.\n\n    ament_export_targets(my_lib HAS_LIBRARY_TARGET)\n\
    \nInstall the include/the_library directory to the install/include/the_library\
    \ to be seen by the consumer target (we haven't talked about the consumer just\
    \ yet)\n\n    install(\n      DIRECTORY include/the_library\n      DESTINATION\
    \ include\n    )\n\nInstall and officially export the library, you may want to\
    \ search a little bit more for this one\n\n    install(\n      TARGETS my_lib\n\
    \      EXPORT my_lib\n      LIBRARY DESTINATION lib\n      ARCHIVE DESTINATION\
    \ lib\n      RUNTIME DESTINATION bin\n      INCLUDES DESTINATION include\n   \
    \ )\n\n\n##In the `consumer` package, your CMakeLists.txt should be as follows:\n\
    \n    find_package(the_library REQUIRED)\n    add_executable(consumer src/consumer.cpp)\n\
    \nYou then want to link the consumer executable to the library called my_lib exported\
    \ by `the_library` package, the syntax is as follows: package_name::exported_library_name\n\
    \n    target_link_libraries(consumer the_library::my_lib)\n\nYou then may then\
    \ want to install the `consumer` executable to be able to ros2 run it \n\n   \
    \ install(TARGETS consumer\n    DESTINATION lib/${PROJECT_NAME}/)\n\nImportant\
    \ note: in the consumer.cpp file you'd include the library as follows: \n\n`#include\
    \ \"the_library/lib_header.hpp\"`\n\nIf you'd like direct inclusion (#include\
    \ \"lib_header.hpp\")  then you need to modify the `my_library` CMakeLists as\
    \ follows:\n\n    install(\n      TARGETS my_lib\n      EXPORT my_lib\n      LIBRARY\
    \ DESTINATION lib\n      ARCHIVE DESTINATION lib\n      RUNTIME DESTINATION bin\n\
    \      INCLUDES DESTINATION include/the_library\n    )\n\nHere's the complete\
    \ code: [google drive zip](https://drive.google.com/file/d/1mTSWl00xWKStGORTazWHL7OVlJ-8qGge/view?usp=sharing)\
    \ \n\nSorry for the long answer :)"
