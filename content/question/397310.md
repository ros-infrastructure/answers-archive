  body_markdown: "I even wonder if you can cancel some specific action goal using\
    \ the rclcpp_action API nowadays (Sept 2022).\n\nThe problem is that the \"async_cancel_goal\"\
    \ requires a goal handle, but the \"send_goal\" function only provides a \"future\
    \ goal handle\". You will get the required \"goal handle\" only after the response\
    \ from the server is received. \nToo late to cancel.\n\nsee: https://github.com/ros2/rclcpp/blob/33dae5d679751b603205008fcb31755986bcee1c/rclcpp_action/include/rclcpp_action/client.hpp#L454\n\
    \nI would say that is still an open issue in the rclcpp repo:\nhttps://github.com/ros2/rclcpp/issues/747\n\
    \nBy the moment, cancelling everything is an alternative:\n\n      client_ptr->async_cancel_all_goals();"
