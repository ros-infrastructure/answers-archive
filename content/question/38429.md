  body_markdown: "This is a Cmake error as a result of a call like:\n\n    find_package(catkin\
    \ REQUIRED) \n\nin some CMakelists.txt\n\nIf you run rosinstall --catkin ...\n\
    rosinstall should generate a CMakelists.txt containing something like this in\
    \ your workspace:\n\n    if (IS_DIRECTORY ${CMAKE_SOURCE_DIR}/catkin)\n      message(STATUS\
    \ \"+++ catkin\")\n      set(CATKIN_BUILD_PROJECTS \"ALL\" CACHE STRING\n    \
    \  \"List of projects to build, or ALL for all.  Use to completely exclude certain\
    \ projects from cmake traversal.\")\n      add_subdirectory(catkin)\n    else()\n\
    \      find_package(catkin)\n    endif()\n\nSo in your case, the if statement\
    \ was false, so add_subdirectory(catkin) was not executed, which caused 'find_package(catkin\
    \ REQUIRED)', which is used in some other CMakelists.txt, to fail.\n\nThe variable\
    \ ${CMAKE_SOURCE_DIR} is set by cmake and should point to your workspace. To debug,\
    \ add a line like this to the CMakelists.txt in your workspace:\n\nmessage(STATUS\
    \ ${CMAKE_SOURCE_DIR})\n\nThe result should look like:\n\n    /build $ cmake ..\
    \ -DCMAKE_INSTALL_PREFIX=...\n    -- workspace: .../fuerte_underlay\n    -- +++\
    \ catkin\n\nSo check that in your workspace, there is a folder called 'catkin'.\
    \ Your .rosinstall file should contain the line:\n\n    - git: {local-name: catkin,\
    \ uri: 'git://github.com/wg-debs/catkin-release.git', version: debian/ros-fuerte-catkin_0.4.4_lucid}\n\
    \nand this should lead to the rosinstall command to download catkin.\nIf the error\
    \ persists, please copy more of the log you get."
