  body_markdown: "I have found the problem. It appears that my motors do not have\
    \ encoder, and apparently odometry is needed directly for `cmd_vel` to work.\n\
    \nIn case anyone wonders how to solve this, simply use `jetbot_motors/cmd_raw`\
    \ instead of `cmd_vel`. \nI've been moving jetbot using [move_base](http://wiki.ros.org/move_base?distro=melodic)\
    \ from [jackal_navigation](http://wiki.ros.org/jackal_navigation) package, and\
    \ in  move_base.launch file in launch folder I added this line:\n\n    <remap\
    \ from=\"/cmd_vel\" to=\"/jetbot_motors/cmd_raw\"/>\n\nHope this will help anyone!\n"
