    Well, the error says it all: two dimensional arrays are currently not supported.

    I see two possibilities:

    1. use one of the `MultiArray` message types in [`std_msgs`](http://wiki.ros.org/std_msgs).
    2. create your service similar to what e.g. `sensor_msgs/Image` is [doing](http://docs.ros.org/api/sensor_msgs/html/msg/Image.html), by having a 1D array for the data and an additional parameter for the length of a row, i.e.

            int32 a
            ---
            uint32 step # Full row length in bytes
            uint32[] data # actual matrix data, size is (step * rows)
