  body_markdown: "I want to answer my own question, to clarify which way I found and\
    \ what is the proper as I consider. \n\nBasically, you have to add folder with\
    \ header files and the library itself. You can do it with find_package, or manually.\
    \ \n\nThe header files you have to include in \"include_libraries\" like I did:\n\
    \ninclude_directories(\n  ${catkin_INCLUDE_DIRS}\n  ${Qt5Core_INCLUDE_DIRS}\n\
    \  ${Qt5WebSockets_INCLUDE_DIRS}\n  /usr/include\n)\n\nAnd the library itself,\
    \ you can add with \"target_link_libraries\", like this:\n\nadd_executable(driver\
    \ src/driver_node.cpp)\ntarget_link_libraries(driver ${catkin_LIBRARIES} ${CMAKE_THREAD_LIBS_INIT}\
    \ /usr/lib/aarch64-linux-gnu/libserial.so)"
