    You can first take a look at the sensors that are supported by [sdformat](http://sdformat.org/spec?ver=1.9&elem=sensor). There you can find "camera", "depth_camera" and "multicamera".
    In the following example I am using "camera" and "depth_camera" to replicate the stereo camera functionality.
    I am not aware if "multicamera" is supported by ign gazebo and how you would use it, maybe someone else can add some more information about that.

  body_markdown: "Thank you for your answers.  \nI was rather looking for how to define\
    \ a stereo camera (not how to visualize it), but the answer was interesting. \
    \ \n\nThe old way of adding stereo cameras in Gazebo classic was to:  \n- attach\
    \ a sensor to the **camera_link**  \n- set the sensor type to **multicamera**\
    \  \n- define two cameras in this sensor using the **<< camera >>** tag  \n- add\
    \ a plugin to the sensor  \n- explicitly set the baseline in the plugin using\
    \ the **<< hack_baseline >>** tag  \n\nHere is an example of stereo camera for\
    \ Gazebo classic:  \n\n    <gazebo reference=\"camera_link\">\n        <sensor\
    \ type=\"multicamera\" name=\"stereo_camera\">\n          <update_rate>10.0</update_rate>\n\
    \          <always_on>true</always_on>\n    \n          <camera name=\"left\"\
    >\n            <pose>0 0 0 0 0 0</pose>\n            <horizontal_fov>1.3962634</horizontal_fov>\n\
    \            <image>\n              <width>1024</width>\n              <height>1024</height>\n\
    \              <format>R8G8B8</format>\n            </image>\n            <clip>\n\
    \              <near>0.02</near>\n              <far>300</far>\n            </clip>\n\
    \            <noise>\n              <type>gaussian</type>\n              <mean>0.0</mean>\n\
    \              <stddev>0.0</stddev>\n            </noise>\n            <distortion>\n\
    \              <k1>0.0</k1>\n              <k2>0.0</k2>\n              <k3>0.0</k3>\n\
    \              <p1>0.0</p1>\n              <p2>0.0</p2>\n              <center>0.5\
    \ 0.5</center>\n            </distortion>\n          </camera>\n    \n       \
    \   <camera name=\"right\">\n            <pose>0 -0.12 0 0 0 0</pose>\n      \
    \      <horizontal_fov>1.3962634</horizontal_fov>\n            <image>\n     \
    \         <width>1024</width>\n              <height>1024</height>\n         \
    \     <format>R8G8B8</format>\n            </image>\n            <clip>\n    \
    \          <near>0.02</near>\n              <far>300</far>\n            </clip>\n\
    \            <noise>\n              <type>gaussian</type>\n              <mean>0.0</mean>\n\
    \              <stddev>0.0</stddev>\n            </noise>\n            <distortion>\n\
    \              <k1>0.0</k1>\n              <k2>0.0</k2>\n              <k3>0.0</k3>\n\
    \              <p1>0.0</p1>\n              <p2>0.0</p2>\n              <center>0.5\
    \ 0.5</center>\n            </distortion>\n          </camera>\n    \n       \
    \   <plugin name=\"stereo_camera_controller\" filename=\"libgazebo_ros_camera.so\"\
    >\n            <ros>\n              <namespace></namespace>\n              <argument>image_raw:=image_raw</argument>\n\
    \              <argument>camera_info:=camera_info</argument>\n            </ros>\n\
    \    \n            <camera_name>stereo_camera</camera_name>\n            <frame_name>camera_link_optical</frame_name>\n\
    \            <hack_baseline>0.12</hack_baseline>\n          </plugin>\n      \
    \  </sensor>\n      </gazebo>\n\nWith Ignition, it is a little bit different.\
    \ You have to:  \n- attach a sensor to the **camera_link** for each camera  \n\
    - set the sensor type to **camera**    \n- make them publish at the same rate\
    \ (see https://gazebosim.org/docs/citadel/comparison#sensors)  \n- add a sensor\
    \ plugin to the model/robot  \n- the baseline is set automatically thanks to the\
    \ cameras pose (see https://github.com/gazebosim/gz-sim/blob/3b6c0f2a0bc71c5ff391852615609deec3c03674/src/systems/sensors/Sensors.cc#L746-L750)\
