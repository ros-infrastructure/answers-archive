  body_markdown: "The command `<rosparam command=\"load\" file=\"$(find husky_highlevel_controller)/config/laser_enable_param.yaml\"\
    />` puts the parameters on the parameter server. The launchfile `spawn_husky.launch`\
    \ expects the data as a launch file argument, though. \n\nThis is a different\
    \ concept. Think of it as an argument of a function (launch file argument) versus\
    \ global variables (rosparam server). \n\n* https://wiki.ros.org/roslaunch/XML/arg\n\
    * https://wiki.ros.org/roslaunch/XML/rosparam\n\nYou can just put it in your launchfile,\
    \ tough:\n   \n    <include file=\"$(find husky_gazebo)/launch/spawn_husky.launch\"\
    > \n        <arg name=\"laser_enabled\" value=\"true\"/> \n    </include>"
