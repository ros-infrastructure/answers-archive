    I've never tried this, but it should be possible to `<include>` a model within another one. The SDF parser just expands the links of the included model within the parent model. You can see an example [here](https://bitbucket.org/osrf/gazebo_models/src/c9ba518c76bbb7943a9106609f6106a11331c4cb/iris_with_standoffs_demo/model.sdf?at=aero_testing_john&fileviewer=file-view-default).

    So in your case, you could make a base model which has the link that should be shared, and include that in each new model.
