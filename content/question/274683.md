  body_markdown: "You can delete the model and respawn it. Have a look at how to spawn\
    \ model [here](http://gazebosim.org/tutorials?tut=ros_roslaunch).\n\nYou can also\
    \ use python script to do it for your. In [gazebo_ros_pkgs](https://github.com/ros-simulation/gazebo_ros_pkgs)\
    \ package there is [spawn_model](https://github.com/ros-simulation/gazebo_ros_pkgs/blob/kinetic-devel/gazebo_ros/scripts/spawn_model)\
    \ python script that takes care of it (it's the same one used with `roslaunch`\
    \ command).\n\nYou can spawn model using python like this:\n\n    from gazebo_msgs.srv\
    \ import SpawnModel\n    \n    def spawn():\n        req = SpawnModelRequest()\n\
    \        req.model_name = \"model\"\n        req.model_xml = model_xml\n     \
    \   req.robot_namespace = \"namespace\"\n        req.initial_pose.position.x =\
    \ 0.0\n        req.initial_pose.position.y = 0.0\n        req.initial_pose.position.z\
    \ = 0.0\n        req.initial_pose.orientation.x = 0.0\n        req.initial_pose.orientation.y\
    \ = 0.0\n        req.initial_pose.orientation.z = 0.0\n        req.initial_pose.orientation.w\
    \ = 1.0\n        req.reference_frame = ''\n    \n        try:\n            srv\
    \ = ServiceProxy('/gazebo/spawn_sdf_model', SpawnModel)\n            resp = srv(req)\n\
    \        except ServiceException, e:\n            print(\"   Service call failed:\
    \ %s\" % e)\n            sys.exit(1)\n    \n        if resp.success:\n       \
    \     print(resp.status_message)\n            return 0\n        else:\n      \
    \      print(resp.status_message)\n            return 1\n\nWhere `model_xml` is\
    \ your `urdf` or `sdf` file.\n\nThen you can delete models like this:\n\n    def\
    \ delete():\n        try:\n            srv = ServiceProxy('/gazebo/delete_model',\
    \ DeleteModel)\n            req = DeleteModelRequest()\n            req.model_name\
    \ = \"model\"\n            resp = srv(req)\n        except ServiceException, e:\n\
    \            print(\"Service call failed: %s\" % e)\n            sys.exit(2)\n\
    \        \n        if resp.success:\n            print(resp.status_message)\n\
    \            return 0\n        else:\n            print(resp.status_message)\n\
    \            return 1\n\nSo if you want you can create your own python script\
    \ which takes care of it. Using `roslaunch` command is fine as well, but you're\
    \ limited sometimes.\n"
