An external package that my project uses relies on `roslib.message.get_message_class`.

When I compile my workspace using `catkin_make`, everything works just fine.

However, when I compile using `catkin build`, `roslib.message.get_message_class` fails for custom messages defined in one of our packages ([progressive_imagery](https://bitbucket.org/whoidsl/progressive_imagery/src/master/)), but not any of our other custom messages.

`rosmsg show` works in both cases for all messages, including those that roslib is failing on.

So ... does anybody familiar with the internals of catkin have any ideas about what the issue could be?
