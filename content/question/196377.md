    \ array of locations in the camera's reference frame that you believe to be free\
    \ space, according to the camera. \n\nWithin your custom layer, you would first\
    \ need to translate these points into the map's reference frame. This will give\
    \ you the position of the points in METERS relative to the reference frame. \n\
    \nThen to figure out which grid cells they correspond to in the costmap, for each\

    \ mx and my, the coordinates of the grid cell in the costmap (integers).\n\nThen,\
