    \ the LabJack U3 Modul. It also has a separate library.\n\n- #directory where\
    \ the library file is in\n- link_directories(/home/thomas/projects/labjack/exodrive/liblabjackusb)\n\
    - #add the cpp files of your project\n- rosbuild_add_executable(labjack src/LabJack.cpp\
    \ src/... some more files ...)\n- #link the library to the project (name of lib\
    \ file: liblabjackusb.so.2.5.2\n- target_link_libraries (labjack labjackusb)\n\
    \nAs you can see the library is written without the pre-string \"lib\" and without\
    \ the version number and type at the end. So the filename \"liblabjackusb.so.2.5.2\"\
    \ will become -> \"labjackusb\".\n\nThe command you used: include_directories(/home/user/my_lib_orocos)\
    \ is more or less to describe where the header files are. \n\nHope this helps\
