    We're currently in the process of porting Gazebo's `citysim` branch to `default` so the new features are released with Gazebo 9 in January 2018. This means that until then, things will be constantly changing and it may be tricky at times to get all features working together.

    It depends on the features you're interested in, if it is the city world and its models, it works even with Gazebo 7 or 8. All you need to do is setting `GAZEBO_MODEL_PATH` so it finds the models:

        cd /path/to/citysim
        export GAZEBO_MODEL_PATH=`pwd`/models:$GAZEBO_MODEL_PATH
        gazebo --verbose worlds/simple_city.world

    All the world objects, cars and human actors should be there, but you'll get a lot of errors about plugins not found.

    Some plugins can be compiled against Gazebo 8, so if you're really interested on them, you could copy the code and build them from source. I haven't tested, but these should build against Gazebo 8:

    * [Traffic lights GUI plugin](https://bitbucket.org/osrf/citysim/src/d258e487ca560159a3b592f77642e5bd125969c0/plugins/TrafficLightsGUIPlugin.hh?at=default&fileviewer=file-view-default)
    * [Prius Hybrid plugin](https://bitbucket.org/osrf/gazebo/src/4f8e0728b55fd2827cbab3395d792bef218a5aae/plugins/PriusHybridPlugin.hh?at=citysim&fileviewer=file-view-default)

    Other plugins and Gazebo features will need to be ported to Gazebo, this is their latest status:

    * Camera lens flare [open pull request on gazebo](https://bitbucket.org/osrf/gazebo/pull-requests/2806/add-camera-lens-flare-effect/diff)
    * Shadow improvements [open pull request on gazebo](https://bitbucket.org/osrf/gazebo/pull-requests/2805/shadow-improvements/diff)
    * [Bloom effect](https://bitbucket.org/osrf/citysim/src/d258e487ca560159a3b592f77642e5bd125969c0/plugins/BloomVisualPlugin.hh?at=default&fileviewer=file-view-default) (needs a PR to Gazebo)
    * [Joystick plugin](https://bitbucket.org/osrf/gazebo/src/4f8e0728b55fd2827cbab3395d792bef218a5aae/plugins/JoyPlugin.hh?at=citysim&fileviewer=file-view-default) (needs a PR to Gazebo)

    Regarding your question about controlling the Prius with ROS, you may want to check out the [car_demo](https://github.com/osrf/car_demo) repository.
