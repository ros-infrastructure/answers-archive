    \ to see how they relate to base_link.\n\n      <node pkg=\"tf\" type=\"static_transform_publisher\"\
    \ name=\"link0\" args=\" 0.000   0.000 0.000 0.000 0.00 0.00 base_link laser 100\"\
    \ />\n      <node pkg=\"tf\" type=\"static_transform_publisher\" name=\"link1\"\
    \ args=\" 0.250  -0.267 0.000 0.000 0.00 0.00 base_link sensor_1 100\" />\n  \
    \    <node pkg=\"tf\" type=\"static_transform_publisher\" name=\"link2\" args=\"\
    -0.250   0.267 0.000 0.000 0.00 0.00 base_link sensor_2 100\" />\n    \n     \
    \ <node name=\"LiDAR_front\" pkg=\"urg_node\" type=\"urg_node\">\n        <param\
    \ name=\"ip_address\" value=\"192.168.0.1\"/>\n        <param name=\"frame_id\"\
    \ value=\"sensor_1\"/>\n        <remap from=\"scan\" to=\"scan_1\" />\n      </node>\n\
    \      <node name=\"LiDAR_back_left\" pkg=\"urg_node\" type=\"urg_node\">\n  \
    \      <param name=\"ip_address\" value=\"192.168.0.2\"/>\n        <param name=\"\
    frame_id\" value=\"sensor_2\"/>\n        <remap from=\"scan\" to=\"scan_2\" />\n\
    \      </node>\n    \n      <node pkg=\"ira_laser_tools\" name=\"laserscan_multi_merger\"\
    \ type=\"laserscan_multi_merger\">\n        <param name=\"destination_frame\"\
    \ value=\"laser\"/>\n        <param name=\"scan_destination_topic\" value=\"/scan\"\
    />\n        <param name=\"laserscan_topics\" value =\"/scan_1 /scan_2\" />\n \
    \     </node>"

Hello everbody,

I have to implement a mobile robot which contains two lasers (sensor_1 and sensor_2). 

sensor_1 has the topic /scan_1 and sensor_2 has the topic /scan_2.

The scans from my sensors should captured in an output topic "scan" which should reference to the specified frame_ids (sensor_1 and sensor_2). 

The problem on my mobile robot is that one sensor is placed in the front left and the other sensor is placed in the back right. Therefore, I cannot use the common frame base_link for both sensors, because a map is created from the base_link and not from the respective sensors.

Is there maybe a solution for this?
