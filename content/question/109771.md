  body_markdown: "There is a problem with depth_registration topic. For using kinect\
    \ as a laser for autonomous exploration application, you just need depth data.\
    \ \n\nTo solve the above problem, you need to change the parameter `depth_registration`\
    \ to `false` in the `openni.launch` file. \nI use ROS fuerte, in my system this\
    \ file \"`openni.launch`\" is found at `/opt/ros/fuerte/stacks/openni_launch/launch$`.\
    \ Check correspondingly for your system.\n\nIf this is not working for you. Change\
    \ the parameter depth_registration to false in the kinect.launch file also and\
    \ launch `kinect.launch` separately.\n\nThank you "
