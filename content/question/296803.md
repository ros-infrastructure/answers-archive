  body_markdown: "Hello @manuelmelvin,\n\nUnfortunately, using the differential driver\
    \ gazebo plugin like this will not work. But the good news is that you can use\
    \ in a different way, like they do for Husky or Jackal robots (https://github.com/s-mostafa-a/Original-Husky).\n\
    \nBasically, it's about using the **diff_drive_controller** ([http://wiki.ros.org/diff_drive_controller](http://wiki.ros.org/diff_drive_controller))\n\
    \nBy doing this, you can set the variable **cmd_vel_timeout** as your needs.\n\
    \nI've cloned your repo and worked on one of my own, see below the main modifications\
    \ I've done or if you prefer, check in my public repository the merge I've done\
    \ to master branch ([https://bitbucket.org/theconstructcore/p3dx/commits/ed1e237e2a36a1c2d23cd5edcbed2059cf0c88f2](https://bitbucket.org/theconstructcore/p3dx/commits/ed1e237e2a36a1c2d23cd5edcbed2059cf0c88f2))\n\
    \nYet, you can run my ROSJect using this ROSDS link ([https://rds.theconstructsim.com/tc_projects/use_project_share_link/438ff787-1c07-44ff-8fb0-b7a21f4014b2](https://rds.theconstructsim.com/tc_projects/use_project_share_link/438ff787-1c07-44ff-8fb0-b7a21f4014b2))\n\
    \nOr watch this video to follow the instructions: https://www.youtube.com/watch?v=x8iedoVgv8k\n\
    \nHere it goes the modifications:\n\n**p3dx_description/urdf/pioneer3dx.gazebo**\
    \ (just comment the plugin code)\n\n    <!--\n    \t<gazebo>\n    \t\t<plugin\
    \ name=\"differential_drive_controller\" filename=\"libgazebo_ros_diff_drive.so\"\
    >\n    \t\t\t<alwaysOn>true</alwaysOn>\n    \t\t\t<updateRate>100</updateRate>\n\
    \    \t\t\t<leftJoint>base_right_wheel_joint</leftJoint>\n    \t\t\t<rightJoint>base_left_wheel_joint</rightJoint>\n\
    \    \t\t\t<wheelSeparation>0.39</wheelSeparation>\n    \t\t\t<wheelDiameter>0.15</wheelDiameter>\n\
    \    \t\t\t<torque>5</torque>\n    \t\t\t<commandTopic>${ns}/cmd_vel</commandTopic>\n\
    \    \t\t\t<odometryTopic>${ns}/odom</odometryTopic>\n    \t\t\t<odometryFrame>odom</odometryFrame>\n\
    \    \t\t\t<robotBaseFrame>base_link</robotBaseFrame>\n    \t\t</plugin>\n   \
    \ \t</gazebo>\n    \t-->\n\n**p3dx_description/urdf/pioneer3dx_wheel.xacro** (change\
    \ hardwareInterface value to **VelocityJointInterface**)\n\n\t    <transmission\
    \ name=\"${parent}_${suffix}_wheel_trans\">\n\t      <type>pr2_mechanism_model/SimpleTransmission</type>\n\
    \t      <joint name=\"base_${suffix}_wheel_joint\">\n\t      \t<hardwareInterface>VelocityJointInterface</hardwareInterface>\n\
    \t  \t  </joint>\n\t      <actuator name=\"base_${suffix}_wheel_motor\">\n\t \
    \       <mechanicalReduction>${reflect * 624/35 * 80/19}</mechanicalReduction>\n\
    \t      </actuator>\n\t    </transmission>\n\n\n**p3dx_gazebo/launch/gazebo.launch**\
    \ (Spawn the differential drive controller)\n\n    <launch>\n    \n    \t<!--\
    \ these are the arguments you can pass this launch file, for example \n    \t\t\
    paused:=true -->\n    \t<arg name=\"paused\" default=\"false\" />\n    \t<arg\
    \ name=\"use_sim_time\" default=\"true\" />\n    \t<arg name=\"gui\" default=\"\
    true\" />\n    \t<arg name=\"headless\" default=\"false\" />\n    \t<arg name=\"\
    debug\" default=\"false\" />\n    \n    \t<!-- We resume the logic in empty_world.launch,\
    \ changing only the name of \n    \t\tthe world to be launched -->\n    \t<include\
    \ file=\"$(find gazebo_ros)/launch/empty_world.launch\">\n    \t\t<!--<arg name=\"\
    world_name\" value=\"$(find p3dx_gazebo)/worlds/p3dx.world\" />-->\n    \t\t<arg\
    \ name=\"debug\" value=\"$(arg debug)\" />\n    \t\t<arg name=\"gui\" value=\"\
    $(arg gui)\" />\n    \t\t<arg name=\"paused\" value=\"$(arg paused)\" />\n   \
    \ \t\t<arg name=\"use_sim_time\" value=\"$(arg use_sim_time)\" />\n    \t\t<arg\
    \ name=\"headless\" value=\"$(arg headless)\" />\n    \t</include>\n    \t\n \
    \   \t<group ns=\"/p3dx\">\n    \t\n    \t\t<!-- Load the URDF into the ROS Parameter\
    \ Server -->\n    \t\t\n    \t\t<param name=\"robot_description\"\n    \t\t\t\
    command=\"$(find xacro)/xacro.py --inorder '$(find p3dx_description)/urdf/pioneer3dx.xacro'\"\
    \ />\n    \t\n    \t\t<!-- Run a python script to the send a service call to gazebo_ros\
    \ to spawn \n    \t\t\ta URDF robot -->\n    \t\t<node name=\"urdf_spawner\" pkg=\"\
    gazebo_ros\" type=\"spawn_model\"\n    \t\t\trespawn=\"false\" output=\"screen\"\
    \ args=\"-urdf -param robot_description -model p3dx\" />\n    \t\t\n    \t\t<rosparam\
    \ command=\"load\" file=\"$(find p3dx_control)/config/control.yaml\" />\n    \t\
    \t\n    \t\t<node name=\"base_controller_spawner\" pkg=\"controller_manager\"\
    \ type=\"spawner\"\n    \t        args=\"--namespace=/p3dx\n    \t        p3dx_joint_publisher\n\
    \    \t        p3dx_velocity_controller\n    \t        --shutdown-timeout 3\"\n\
    \    \t        output=\"screen\"/>\n    \t\n    \t\t<!-- ros_control p3rd launch\
    \ file -->\n    \t\t<!-- <include file=\"$(find p3dx_control)/launch/control.launch\"\
    \ /> -->\n    \t</group>\n    \n    </launch>\n\n**p3dx_control/config/control.yaml**\
    \ (create a new file to configure the controller)\n\n    p3dx_joint_publisher:\n\
    \      type: \"joint_state_controller/JointStateController\"\n      publish_rate:\
    \ 50\n    \n    p3dx_velocity_controller:\n      type: \"diff_drive_controller/DiffDriveController\"\
    \n      left_wheel: 'base_right_wheel_joint'\n      right_wheel: 'base_left_wheel_joint'\n\
    \      publish_rate: 50\n      pose_covariance_diagonal: [0.001, 0.001, 0.001,\
    \ 0.001, 0.001, 0.03]\n      twist_covariance_diagonal: [0.001, 0.001, 0.001,\
    \ 0.001, 0.001, 0.03]\n      cmd_vel_timeout: 0.25\n      wheel_separation : 0.39\n\
    \      wheel_radius : 0.15\n\nI hope it can help you.\n\nCheers!"
