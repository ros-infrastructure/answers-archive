    Should be given as `REEDS_SHEPP`

    both `use_rotate_to_heading` and `allow_reversing` cannot be set to true at the same time as it would result in ambiguous situations.
    for your case, you have to set  `use_rotate_to_heading` false

    Please read the documentation for more details: https://navigation.ros.org/configuration/packages/configuring-regulated-pp.html
