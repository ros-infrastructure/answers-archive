  body_markdown: "The solution was to rebuild libdc1394 library. Here is what I did,\n\
    \n1) downloaded latest version of the library, libdc1394-2.2.\n\n2) added vendors\
    \ and products codes to usb_products[] that is defined in libdc1394-2.2/dc1394/usb/control.c\
    \ \nFor flea 3, I added these two lines\n    { 0x1e10, 0x3000 },\n    { 0X1e10,\
    \ 0x3006 },\nFinally the structure looks as follows\n\n    /* This is the list\
    \ of USB vendor/products that we know support\n     * IIDC-over-USB.  Currently,\
    \ this is the only mechanism of detecting\n     * such cameras. */\n    static\
    \ struct _vendor_product_t {\n        uint16_t vendor;\n        uint16_t product;\n\
    \    } usb_products[] = {\n        { 0x1e10, 0x2000 }, // Point Grey Firefly MV\
    \ Color\n        { 0x1e10, 0x2001 }, // Point Grey Firefly MV Mono\n        {\
    \ 0x1e10, 0x2002 }, // Point Grey High Res Firefly MV Color\n        { 0x1e10,\
    \ 0x2003 }, // Point Grey High Res Firefly MV Mono\n        { 0x1e10, 0x2004 },\
    \ // Point Grey Chameleon Color\n        { 0x1e10, 0x2005 }, // Point Grey Chameleon\
    \ Mono\n        { 0x1e10, 0x3000 }, // Point Grey Flea 3\n        { 0X1e10, 0x3006\
    \ }, // Point Grey Flea 3 Color\n        { 0, 0 },\n    };\n\n3) Rebuild libdc\n\
    \n4) Build and run the following code that will allow you to get GUID. Later this\
    \ GUID should be put to camera yaml file to run camera1394.\n\n    #include <stdio.h>\n\
    \    #include <stdint.h>\n    #include <dc1394/dc1394.h>\n    #include <stdlib.h>\n\
    \    #include <inttypes.h>\n    \n    int main(int argc, char *argv[])\n    {\n\
    \        FILE* imagefile;\n        dc1394camera_t *camera;\n        unsigned int\
    \ width, height;\n        dc1394video_frame_t *frame=NULL;\n        //dc1394featureset_t\
    \ features;\n        dc1394_t * d;\n        dc1394camera_list_t * list;\n    \
    \    dc1394error_t err;\n        \n        d = dc1394_new ();\n        if (!d)\n\
    \            return 1;\n        err=dc1394_camera_enumerate (d, &list);\n    \
    \    DC1394_ERR_RTN(err,\"Failed to enumerate cameras\");\n        \n        if\
    \ (list->num == 0) {\n            dc1394_log_error(\"No cameras found\");\n  \
    \          return 1;\n        }\n        \n        camera = dc1394_camera_new\
    \ (d, list->ids[0].guid);\n        if (!camera) {\n            dc1394_log_error(\"\
    Failed to initialize camera with guid %llx\", list->ids[0].guid);\n          \
    \  return 1;\n        }\n        dc1394_camera_free_list (list);\n        \n \
    \       printf(\"Using camera with GUID %\" PRIx64\"\\n\", camera->guid);\n  \
    \  \n       dc1394_video_set_transmission(camera, DC1394_OFF);\n       dc1394_capture_stop(camera);\n\
    \       dc1394_camera_free(camera);\n       dc1394_free (d);\n       return 0;\n\
    \    }\n\nIt is useable now, although there are some issues with setting different\
    \ modes and reducing the delay. I don't have these issues on a Windows virtual\
    \ machine when I use FlyCapture."
