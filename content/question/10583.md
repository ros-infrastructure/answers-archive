    Yes. You can set the [ROSCONSOLE_CONFIG_FILE](http://www.ros.org/wiki/ROS/EnvironmentVariables#ROSCONSOLE_CONFIG_FILE) environment variable and have that point to a custom log4cxx config that sets the loggerlevels how you want it.

    I guess you want to set debug for your package enabled, then use this entry:

        log4j.logger.ros.PACKAGE=DEBUG
