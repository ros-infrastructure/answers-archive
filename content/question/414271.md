From Foxy Known Issues:
[ros2/ros2#922] Services’ performance is flaky for rclcpp nodes using eProsima Fast-RTPS or ADLINK CycloneDDS as RMW implementation. Specifically, service clients sometimes do not receive the response from servers.

This seemed to have been mentioned in 
https://github.com/ros2/rmw_cyclonedds/pull/187
https://github.com/ros2/rmw_cyclonedds/pull/209

However, I am still seeing the issue in Foxy (using Cyclone) with clients not receiving the returned response from servers. (Python client and C++ service when client requests are sent in rapid succession, with multiple other nodes running). Is this still a known issue and if so are there any good workarounds? Below is example client which is being run with demo_node_cpp server.

    import rclpy
    import threading
    import time
    from rclpy.node import Node
    from example_interfaces.srv import AddTwoInts
    
    
    class ClientThread(threading.Thread):
        def __init__(self, client):
            threading.Thread.__init__(self)
            self.client = client
            self.send_service_request_thread = None
    
        def run(self):
            while True:
                if self.send_service_request_thread is None or not self.send_service_request_thread.is_alive():
                    self.send_service_request_thread = threading.Thread(target=self.send_service_request)
                    self.send_service_request_thread.start()
    
        def send_service_request(self):
            if self.client.service_is_ready():
                req = AddTwoInts.Request()
                self.client.call(req)
            time.sleep(0.1)
    
    
    class AddNode(Node):
        def __init__(self):
            super().__init__("add_two_ints_client")
            self.client = self.create_client(AddTwoInts, "/add_two_ints")
            self.async_client = ClientThread(self.client)
            self.async_client.start()
    
    
    def main(args=None):
        rclpy.init(args=args)
        rclpy.spin(AddNode())
        rclpy.shutdown()
    
    
    if __name__ == "__main__":
        main()
