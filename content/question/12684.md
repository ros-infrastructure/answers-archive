    \ type=\"serial_node.py\" args=\"path_to_dev_file\" output=\"screen\" />\n   \
    \ <node ns=\"arduino_duemilanove\" name=\"nero_arduino_duemilanove\" pkg=\"rosserial_python\"\
    \ type=\"serial_node.py\" args=\"path_to_other_dev_file\" output=\"screen\" />\n\
    \nIn this case, I called my nodes arduino_zero and arduino_duemilanove, but you\
    \ can give them any name or namespace you want. "

  body_markdown: "I know this is a late reply, yet the information here helped me\
    \ find another alternative thus sharing it might be helpful to others. What I\
    \ did was change the init_node to :\n\n`rospy.init_node(\"serial_node\", anonymous=True)\n\
    \ rospy.loginfo(\"ROS Serial Python Node {}\".format(rospy.get_caller_id()))`\
    \ \n\nThis way every node created is unique thus you can have as many serial_nodes\
    \ as you wish. Till now I haven't found any repercussions and everything seems\
    \ to work perfectly, if you know about any issues with my solution feel free to\
    \ comment.\n\nFor those out there that do not know which file to modify, the change\
    \ was carried out on serial_node.py which could be found in your ros workspace\
    \ in rosserial/rosserial_python/nodes folder."
