    I think the problem is that you are giving a goal orientation not feasible for the turtlebot_arm. Note that you only have freedom when choosing the pitch angle. Roll must be always 0, and yaw must be the angle from the robot base to the target pose. Otherwise planning will necessarily fail.

    [Here](https://github.com/corot/thorp/blob/noetic/thorp_manipulation/src/thorp_arm_controller.cpp#L98-L101)'s how I calculate the goal orientation. `ry` is the yaw;  as we work relative to the arm base, the heading from 0, 0, 0 to the goal is the only valid yaw.
