  body_markdown: "You'll first need to convert the sensor_msgs/PointCloud2 into a\
    \ pcl::PointCloud object as below. Note you may have to change to type of the\
    \ point cloud to match what you have.\n\n    #include <pcl/conversions.h>\n  \
    \  \n    ...\n    \n    pcl::PCLPointCloud2 point_cloud2;  // Input PointCloud2\
    \ message\n    pcl::PointCloud<pcl::PointXYZ> pclObj;  // pcl version of the point\
    \ cloud\n     \n    // Do the conversion\n    pcl::fromPCLPointCloud2( point_cloud2,\
    \ pclObj);\n\nNow you can loop through the `pclObj.points` vector adding them\
    \ to a `pcl::CentroidPoint` object and then extract the centroid at the end. I\
    \ Don't think there's a direct method to get the centroid from the PointCloud2\
    \ message itself.\n\n"
