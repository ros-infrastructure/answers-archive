I'm having trouble running gazebo ignition on WSL2 22.04 since it comes up with display issues. I am using wslg  Running gazebo works fine but running anything in gazebo ignition leads to it crashing once it gets past the startup menu. I googled this problem and it seemed like people had it and fixed it by exporting `LD_PRELOAD="/usr/lib/x86_64-linux-gnu/libstdc++.so.6"` however that also did not work for me. Following [this thread](https://github.com/gazebosim/gz-sim/issues/920) did help by using CPU rendering instead of GPU rendering however it is much slower and would prefer to use GPU rendering if possible. Following [this video](https://youtu.be/DW7l9LHdK5c) and using xserver instead did not change the problem. It seems [this issue](https://github.com/gazebosim/gz-sim/issues/1116) is very similar to the problem I'm having however mine crashes once it gets past the startup menu.
