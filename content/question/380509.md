  body_markdown: "What are you using to visualize the points? If it is RVIZ, then\
    \ you need your coordinates to be in a cartesian coordinate system. Right now\
    \ it is interpreting all your lat/lon points as as x/y in meters. This means it\
    \ is interpreting that all your points are within a centimeter of each other.\n\
    \nIf you set RVIZ with the following settings, you will see that it is there,\
    \ just all in a very small space:\n\n - Fixed Frame (left panel): my_fixed_frame\n\
    \ - Distance (right panel): 0.05\n - Focal Shape Size(right panel): 0.05\n - Yaw\
    \ (right panel): 0\n - Pitch (right panel): 1.57\n - Focal Point (right panel):\
    \ 2.221;109.246;0\n\n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/16239409035438499.png)\n\
    \nYou need to convert from lat/lon to a cartesian coordinate system (such as UTM).\n\
    \nHere is one such way to do that:\n\nRead the first point in and convert to utm.\
    \ This will be the 0,0 point of my_fixed_frame. Convert all your points to utm\
    \ while adding them to `marker.points` and subtract off the utm coordinates of\
    \ the first point. This shifts the global utm coordinate of the point to a local\
    \ coordinate. Publish the `utm` to `my_fixed_frame` transform. Publish the markers.\n\
    \nSample code for that method:\n\n    #!/usr/bin/env python\n\n    from visualization_msgs.msg\
    \ import Marker\n    from geometry_msgs.msg import Point\n    import rospy\n \
    \   import pandas as pd\n    import utm\n    import tf\n\n    count = 0\n    MARKERS_MAX\
    \ = 100\n    csv_file = \"/path/to/NT-all-points.csv\"\n\n    rospy.init_node('lane_line_GT_node',\
    \ anonymous=True)\n    pub = rospy.Publisher('lane_line_GT', Marker, queue_size=10)\n\
    \    df = pd.read_csv(csv_file)\n\n    tf_bcast = tf.TransformBroadcaster()\n\n\
    \    marker = Marker()\n    marker.header.frame_id = \"my_fixed_frame\"\n    marker.type\
    \ = marker.LINE_STRIP\n    marker.action = marker.ADD\n\n    # marker scale\n\
    \    marker.scale.x = 0.03\n    marker.scale.y = 0.03\n    marker.scale.z = 0.03\n\
    \n    # marker color\n    marker.color.a = 1.0\n    marker.color.r = 1.0\n   \
    \ marker.color.g = 1.0\n    marker.color.b = 0.0\n\n    # marker orientaiton\n\
    \    marker.pose.orientation.x = 0.0\n    marker.pose.orientation.y = 0.0\n  \
    \  marker.pose.orientation.z = 0.0\n    marker.pose.orientation.w = 1.0\n\n  \
    \  # marker position\n    marker.pose.position.x = 0.0\n    marker.pose.position.y\
    \ = 0.0\n    marker.pose.position.z = 0.0\n\n    # marker line points \n    marker.points\
    \ = []\n\n    # The first lat/lon will be our 0,0 point. Convert to utm\n    utm_start\
    \ = utm.from_latlon(df.at[0, 'latitude'], df.at[0, 'longitude'])\n\n    for i\
    \ in range(0, 127, 3):\n        line_point = Point()\n        \n        # Get\
    \ the UTM point of the lat/lon at index i\n        utm_ne = utm.from_latlon(df.at[i,\
    \ 'latitude'], df.at[i, 'longitude'])\n\n        # Get the x,y of the i'th point\
    \ relative to the start point\n        line_point.x = utm_ne[0] - utm_start[0]\n\
    \        line_point.y = utm_ne[1] - utm_start[1]\n        line_point.z = 0\n\n\
    \        print(f\"[debug]: latitude: {line_point.x}; type: {type(line_point.x)}\"\
    )\n        print(f\"[debug]: longitude: {line_point.y}; type: {type(line_point.y)}\"\
    )\n\n        marker.points.append(line_point)\n\n    while not rospy.is_shutdown():\n\
    \        print('[debug] running ... ')\n        \n        # Continually publish\
    \ the utm->my_fixed_frame transform\n        tf_bcast.sendTransform(\n       \
    \     (utm_start[0],utm_start[1],0),\n            (0,0,0,1),\n            rospy.Time.now(),\n\
    \            \"my_fixed_frame\", # child\n            \"utm\")  # parent\n\n \
    \       # Publish the Marker\n        pub.publish(marker)\n\n        rospy.sleep(0.5)\n\
    \n Hope this helps!"
