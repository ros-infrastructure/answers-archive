    > Is there any built-in ROS solution for view ROS log text files in the normal stdout color?

    No, there isn't afaik.

    And I would argue that is also not needed or desirable: the log files are essentially just text files with [ANSI escape codes](http://en.wikipedia.org/wiki/ANSI_escape_code) embedded in the log lines. So any tool capable of parsing such codes should be able to read these log files, removing the need to create something ROS-specific.

    I believe this was discussed before, in #q204631 for instance. That Q&A also contains some links to tools that can strip them out and also mentions `less` that should be able to show the contents including ANSI colours.
