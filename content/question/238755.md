  body_markdown: "Yes, it is possible to generate a map using only a Kinect. \n\n\
    My suggestion would be to familiarize yourself with the various packages available,\
    \ understand what they do, what data they require, pros, cons, etc.. This requires\
    \ you do some research on your own, but it will help you.\n\nFor instance, if\
    \ you want to perform SLAM there are two packages that come to mind: [gmapping](http://wiki.ros.org/gmapping),\
    \ and [hector_mapping](http://wiki.ros.org/hector_mapping). By looking at the\
    \ published topics they both give you the map that you desire, but they differ\
    \ in the subscribed topics (i.e. the data that they require). The point I am trying\
    \ to make is that you can start filling in the gaps to be able to use these packages.\n\
    \nWith gmapping you need odometry, and if you look around there is a package called\
    \ [laser_scan_matcher](http://wiki.ros.org/laser_scan_matcher) that can \"fake\"\
    \ odometry data from laser scans. So the next step is to produce a laser scan\
    \ from the kinect, which can be achieved with [depthimage_to_laserscan](http://wiki.ros.org/depthimage_to_laserscan)\
    \ or [pointcloud_to_laserscan](http://wiki.ros.org/pointcloud_to_laserscan). \n\
    \nhector_mapping does not require odometry, but it does require scan data, which\
    \ you already know how to get from the gmapping description above.\n\nI'm not\
    \ able to give you step-by-step instructions on how to do this, and there are\
    \ obviously some steps missing in my breif description above. But if you do some\
    \ searches related to the above packages and kinect sensors you should be able\
    \ to find enough info about how to do this, as well as the pros and cons about\
    \ different approaches. After a quick look here are some similar answers that\
    \ may help you:\n\n[2D SLAM with gmapping and openni_kinect](http://answers.ros.org/question/9442/2d-slam-with-gmapping-and-openni_kinect/)\n\
    \n[how to create a 2D map from laser scan data](http://answers.ros.org/question/224916/how-to-create-a-2d-map-from-laser-scan-data/)\n\
    \n[SLAM without odometry: gmapping or hector_slam?](http://answers.ros.org/question/35924/slam-without-odometry-gmapping-or-hector_slam/)\n\
    \n\n\n"
