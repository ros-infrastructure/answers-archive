    It's very likely you haven't actually installed ROS Noetic, but a version of ROS packaged in so called [UpstreamPackages](http://wiki.ros.org/UpstreamPackages).

    This is not the current release of ROS Noetic, but a snapshot of ROS taken at some point in the past. I'd recommend you read the linked wiki page for more information.

    Did you install `ros-desktop` or `ros-desktop-full` by any chance? Or did you install `catkin` directly?

    To resolve your problem, I'd recommend following the installation instructions given on [wiki/noetic/Installation](http://wiki.ros.org/noetic/Installation).
