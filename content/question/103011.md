  body_markdown: "Just build you app using whatever pieces of Qt you need then tie\
    \ to ROS as follows.\nAdd the `find_package(Qt COMPONENTS ... REQUIRED)` in your\
    \ `CMakeLists.txt` file and  the appropriate lines for moc and resource files\
    \ as needed. For example;\n\n    FIND_PACKAGE(Qt4 REQUIRED)\n    INCLUDE(${QT_USE_FILE})\n\
    \    \n    file(GLOB QT_FORMS RELATIVE ${CMAKE_CURRENT_SOURCE_DIR} *.ui)\n   \
    \ file(GLOB QT_RESOURCES RELATIVE ${CMAKE_CURRENT_SOURCE_DIR} *.qrc)\n    file(GLOB_RECURSE\
    \ QT_MOC RELATIVE ${CMAKE_CURRENT_SOURCE_DIR} FOLLOW_SYMLINKS *.h)\n    \n   \
    \ QT4_ADD_RESOURCES(QT_RESOURCES_CPP ${QT_RESOURCES})\n    QT4_WRAP_CPP(QT_MOC_HPP\
    \ ${QT_MOC})\n    QT4_WRAP_UI(QT_FORMS_HPP ${QT_FORMS})\n\nAnd link as needed\n\
    \n    add_executable([some_binary] ${QT_SOURCES} ${QT_RESOURCES_CPP} ${QT_FORMS_HPP}\
    \ ${QT_MOC_HPP})\n\n    target_link_libraries([some_binary] ${QT_QTCORE_LIBRARY}\
    \ ... ${QT_QTGUI_LIBRARY} ${catkin_LIBRARIES} )"
