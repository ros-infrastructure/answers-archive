  body_markdown: "After not be able to use the package correctly (I need to understand\
    \ EKF), I found the test files for robot_localization :\n\n - [test1.bag](https://github.com/cra-ros-pkg/robot_localization/blob/kinetic-devel/test/test_ekf_localization_node_bag1.test)\n\
    \ - [test2.bag](https://github.com/cra-ros-pkg/robot_localization/blob/kinetic-devel/test/test_ekf_localization_node_bag2.test)\n\
    \ - [test3.bag](https://github.com/cra-ros-pkg/robot_localization/blob/kinetic-devel/test/test_ekf_localization_node_bag3.test)\n\
    \nYou have 2 way of launching these files (both require you to clone and compile\
    \ [the package on github](https://github.com/cra-ros-pkg/robot_localization/),\
    \ these file are not present with apt-get): \n\nQuick method :\n----------\nLaunch\
    \ these file like a normal .launch file : \n\n`roslaunch < your robot_localization\
    \ package path >/test/test_ekf_localization_node_bag1.test`\n\nThen subscribe\
    \ to the **/odometry/filtered** topic and look at the last message, the position\
    \ should be nearby equal to the position defined at the end of the file. Example\
    \ for bag1 : \n\n          <param name=\"final_x\" value=\"-40.0454\"/>\n    \
    \      <param name=\"final_y\" value=\"-76.9988\"/>\n          <param name=\"\
    final_z\" value=\"-2.6974\"/>\n          <param name=\"tolerance\" value=\"1.0452\"\
    />\n\n\nI recorded the 3 results for EKF in bag files : \n\n - [test1_result.bag](https://drive.google.com/file/d/0B0BRMr7Z9cxfZTJWeGJWRldBXzQ/view?usp=sharing)\
    \ \n - [test2_result.bag](https://drive.google.com/file/d/0B0BRMr7Z9cxfUzFMNFY1a3U1aEU/view?usp=sharing)\n\
    \ - [test3_result.bag](https://drive.google.com/file/d/0B0BRMr7Z9cxfTFVZdDFQRnprNGc/view?usp=sharing)\n\
    \n\n\nWith rostest\n----------\n\nRobot_localization come with a script to test\
    \ the 2 nodes (ekf and ukf) with the 3 bag files.\n\nBut this is for the default\
    \ parameters, if you want to test your own parameters, change them at the begining\
    \ of the *.test files and run the stats recorder. If the output fail, you are\
    \ probably doing something wrong. \n\nTo run the stats recorder, go to robot_localization/test/\
    \ and run `./record_all_stats.sh <output_path>` (don't forget the output_path)\
    \ , it will output :\n\n>  < output_path >/ekf(1,2,3).txt\n\n and  :\n\n>  < output_path\
    \ >/ukf(1,2,3).txt.\n\nIt will run 30 times each node for each bag file (so it\
    \ will take a very long time...) and try to ouput statistic based on your parameters\
    \ (try only. If you look at the script, it seem to run the tests 30 times only)\n\
    \n\n----------\n\n\nHave fun !\n\n\n\n\n"
