  body_markdown: "i had the same problem and i solved it. So why the exporter just\
    \ stopped ? this is because the exporter can not  create for example the axis\
    \ of a revolute joint when you leave the option \"automatically generate\". In\
    \ my case, i had defined fully 3 mates for the realated object, so the exporter\
    \ could not find the degree of freedom to assume that the part can revolve( be\
    \ free) around an axis. \nHope this helps"
