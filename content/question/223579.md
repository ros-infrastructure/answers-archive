  body_markdown: "Try changing the rviz  'Global Options' 'Fixed Frame' to my_frame.\
    \  \n\nIn the tutorial you are sending the markers position in the frame my_frame,\
    \ but rviz is set to display map, and if you have not set any transforms to connect\
    \ the frame map to my_frame  rviz can't calculate the markers position in the\
    \ map frame.\n\nAnd you need to add a markers display to rviz (maybe you have\
    \ already done this, but i can't see it in your  screenshot).\nJust follow the\
    \ Tutorials Point '5. Viewing the Markers'.\n\nTo change the Fixed Frame:\nOpen\
    \ rviz, klick on map (on the text next to Fixed Frame) and just type the new frame\
    \ name my_frame. \nI thought i could choose the frame from a list, but i just\
    \ built the tutorial program and tried it, but i had to type the name my_frame.\n\
    \nRviz is often hiding (or it is not recognizable) that you can edit a parameter\
    \ like Fixed Frame.\n\n\n\nI think you are trying to change the Fixed Frame in\
    \ Global Status, where you get the warning message. Try changing the Fixed Frame\
    \ under Global Options.\n"
