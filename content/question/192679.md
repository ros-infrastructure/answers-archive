  body_markdown: "According to [REP 3 - Target Platforms](http://www.ros.org/reps/rep-0003.html)\
    \ you can install fuerte, groovy and hydro simultaneously on a Ubuntu 12.04 machine,\
    \ so that is probably a good compromise for quickly trying things out. A good\
    \ alternative (at least for Stage) might be virtual machines. With Gazebo, that\
    \ often does not work very well due to graphics driver related issues, however.\n\
    \nYou can try to run software only documented for use with certain ROS releases\
    \ and sometimes this will work without problems, but there\xB4s always the possibility\
    \ that things don\xB4t work out due to API changes and such."
