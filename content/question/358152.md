    What you post is not the error message, but a general remark about a possible(!) solution.
    I'm not quite sure what you are trying to do, but the general, ROS-way idea is the following:

    1. define message (i.e. the `*.msg`) in package b
    1. generate the language specific message classes by compiling package b, for this, set up `CMakeLists.txt` in package b correctly. See [this](http://wiki.ros.org/ROS/Tutorials/CreatingMsgAndSrv#Creating_a_msg).
    1. define a dependency on package b in package a
    1. (as you are using C++), `#include <package_b/msg_between_a_b.h>` and use it...
