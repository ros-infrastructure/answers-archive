  body_markdown: "The message type is the name of the package plus the name of the\
    \ file. For example if your package name is `my_pkg_msgs` and the file where you\
    \ defined the message is `MyMsg.msg`, then the message type is `my_pkg_msgs.MyMsg`.\
    \ \n\nYou might want to check this [tutorial](http://wiki.ros.org/ROS/Tutorials/CreatingMsgAndSrv)\
    \ (point 3.).\n\nHope this helps.\n"
