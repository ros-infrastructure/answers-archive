    I believe the issue is that `points` in your case created as a map, instead of a list. It is a list.

    See the documentation for `JointTrajectory` [here](http://docs.ros.org/api/trajectory_msgs/html/msg/JointTrajectory.html):

        trajectory_msgs/JointTrajectoryPoint[] points

    So in YAML, I would expect this to look something like this:

        points : [
          {
             positions : [..],
             velocities : [..],
             accelerations : [..],
             effort : [..],
             time_from_start : ...
          },
          {
             positions : [..],
             velocities : [..],
             accelerations : [..],
             effort : [..],
             time_from_start : ...
          },
          ...
        ]
