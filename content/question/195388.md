    The json_prolog node reads two ROS parameters, the initial package to be loaded and an initialization goal, see [here](https://github.com/knowrob/knowrob/blob/master/json_prolog/src/java/edu/tum/cs/ias/knowrob/json_prolog/JSONPrologNode.java#L285), which you can use to pass the 'consult' or 'use_module' directive. Alternatively, as you have created your own package, you can give that package as initial_package argument when starting json_prolog, which will then load everything that is listed in your init.pl. You can have a look at other KnowRob packages for examples.

    The error you list above was however caused by a syntax error: When sending commands via json_prolog, do not add the trailing dot '.'. All commands are passed via the 'expand_goal' predicate, so they should not have the '.' inside which indicates the end of a query.
