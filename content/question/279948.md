  body_markdown: |-
    The warning was coming from `rtabmap_ros/points_xyzrgb nodelet`, caused by the `voxel_size` parameter which was set too small for the stereo point clouds. This is fixed in this [commit](https://github.com/introlab/rtabmap_ros/commit/37b85a5c7ad3538746f55fca77f131d240953e05) where `voxel_size` is now disabled by default.
