    \ The order does matter in `CMakeLists.txt`. Please see  [wiki/catkin - CMakeLists.txt\
    \ - Overall Structure and Ordering](http://wiki.ros.org/catkin/CMakeLists.txt#Overall_Structure_and_Ordering).\n\
    \nI think your package does not contain any messages/services/actions files so\
    \ you don't really need\n\n    add_dependencies(name_of_node_chatter my_package_generate_messages_cpp)\n\
    \nIf you do, you need to add `generate_messages(DEPENDENCIES ...)`. The message\
    \ generation targets are created by `generate_messages(DEPENDENCIES ...)`. Using\
    \ `add_dependencies(name_of_node_chatter my_package_generate_messages_cpp)` is\
    \ to ensure that `my_package_generate_messages_cpp` is built before the `name_of_node_chatter\
    \ ` target.\n\nIf your target depends on other messages/services/actions from\
    \ other packages, even though your package doesn't build any messages/services/actions\
    \ at compile time, you should add \n\n    add_dependencies(name_of_node_chatter\
    \ ${catkin_EXPORTED_TARGETS})\n\n More details about `add_dependencies(...)` can\
    \ be found [here](http://wiki.ros.org/catkin/CMakeLists.txt#Important_Prerequisites.2BAC8-Constraints).\n\
    \nI think it's always safe to add a dependency on `catkin_EXPORTED_TARGETS`."
