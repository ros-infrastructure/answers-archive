    Hi Guido,

    I submitted a [ticket](https://code.ros.org/trac/ros-pkg/ticket/4940) for the "deep slow voice" issue about 6 weeks ago.  In the meantime, the only way I figured out how to change the voice is as follows.  (This applies to Ubuntu 10.04 with Diamondback debian packages and Festival debian packages.)

    $ cd /usr/share/festival
    <br>
    $ sudo pico voices.scm

    (Or use whatever editor you like instead of pico.)

    Once in the editor, search for "kal_diphone" (without the quotes).  Change this to "don_diphone" (again without the quotes).

    Save changes and exit the editor.

    You should now hear a better voice when using sound_play node + say.py.

    --patrick
