    There currently isn't a way to do this, see the [open issue](https://bitbucket.org/osrf/gazebo/issues/2327/toggle-the-gui-visualization-of-light). It would be nice if someone made a pull request adding this feature :) At the very least, you could vote for that issue.

    `<pose>0 0 -1000 0 0 0</pose>`
