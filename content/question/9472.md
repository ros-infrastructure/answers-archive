  body_markdown: "Sorry about that.  At some point I added the robotis joint controller\
    \ directly to the launch file.  To fix, remove the robotis include line from your\
    \ tracker.launch file so that it looks like this:\n\n    <launch>\n        <node\
    \ name=\"tracker_command\" pkg=\"pi_tracker\" type=\"tracker_command.py\" output=\"\
    screen\">\n            <rosparam command=\"load\" file=\"$(find pi_tracker)/params/tracker_params.yaml\"\
    \ />\n        </node>\n        \n        <node name=\"tracker_base_controller\"\
    \ pkg=\"pi_tracker\" type=\"tracker_base_controller.py\" output=\"screen\">\n\
    \            <rosparam command=\"load\" file=\"$(find pi_tracker)/params/tracker_params.yaml\"\
    \ />\n        </node>\n        \n        <node name=\"tracker_joint_controller\"\
    \ pkg=\"pi_tracker\" type=\"tracker_joint_controller.py\" output=\"screen\">\n\
    \            <rosparam command=\"load\" file=\"$(find pi_tracker)/params/tracker_params.yaml\"\
    \ />\n        </node>\n    </launch>\n\nI've also updated this in the SVN repository.\n\
    \n--patrick"
