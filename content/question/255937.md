    Download common messages from here: https://github.com/ros/common_msgs and place it in *src* folder. Then run catkin_make in your workspace. It will install all common message type including geometry_msgs. If you only want geometry messages then download the [*geometry_msgs*](https://github.com/ros/common_msgs/tree/jade-devel/geometry_msgs) folder.

    git clone https://github.com/ros/common_msgs.git

    catkin_make
