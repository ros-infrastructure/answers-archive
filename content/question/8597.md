    There's a [drcsim Release Schedule](https://bitbucket.org/osrf/drcsim/wiki/DRC/ReleaseSchedule) on the gazebo wiki. Drcsim is currently supported for Ubuntu 12.04 (precise) with ROS hydro and 14.04 (trusty) with ROS indigo. The debian package currently uses gazebo4, though it can be built from source to use gazebo5. There are pull requests pending that will allow it to work with gazebo6.

    For your questions:

    1. Installing drcsim would install gazebo4, which would cause a gazebo5 debian to be removed. If you build from source, then you can have multiple gazebo versions installed into separate workspaces.

    2. Yes, if you use separate workspaces.

    3. Yes it does, if you [add the apt key for packages.osrfoundation.org](http://gazebosim.org/tutorials?tut=install_ubuntu&cat=install#Step-by-stepInstall)
