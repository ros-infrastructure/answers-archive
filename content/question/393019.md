I am trying to create an AGV (Automated Guided Vehicle). I am using a Raspberry Pi 4b (4 GB) with Ubuntu 18.04 and ROS Melodic, and I am primarily operating the Pi via SSH on my PC. The RPLidar is connected to the Pi via the USB breakout board that comes with it. My PC has Ubuntu 20.04 and ROS Noetic. The Raspberry Pi is the master on ROS network and my PC is subscribed to it. When I run Hector Slam tutorial launch files in my PC, after making the usual frame adjustments (as given [here](https://automaticaddison.com/how-to-build-an-indoor-map-using-ros-and-lidar-based-slam/)), it runs as intended on Rviz for about two minutes. The robot marker on Rviz moves when I physically move the RPLidar. Then after two minutes the marker stops moving when I physically move the RPLidar. This happens every time.

Another issue, which I think is connected to this is when I try duplicating [this project](https://yoraish.com/2021/09/08/a-full-autonomous-stack-a-tutorial-ros-raspberry-pi-arduino-slam/), the robot marker on Rviz after some time starts moving on its own in a constant speed without stopping, without the RPLidar moving physically. This is shown in the video attached to this post.

Is anyone else facing this problem (at least the first one)?
