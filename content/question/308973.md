  body_markdown: |-
    Seems like the `kinetic` version of `aruco_ros` does not publicly expose the ArUco dictionary type on `MarkerDetector` [construction](https://github.com/pal-robotics/aruco_ros/blob/kinetic-devel/aruco/src/aruco/markerdetector.cpp#L46) or through a setter function. The `melodic` version however does include a dictionary type on construction (through overloaded `int`/`string` types), see [this](https://github.com/pal-robotics/aruco_ros/blob/melodic-devel/aruco/src/aruco/markerdetector.cpp#L68) source file. Where the dictionary types are defined [here](https://github.com/pal-robotics/aruco_ros/blob/melodic-devel/aruco/src/aruco/dictionary.cpp#L2678).

    It seems like these types are specific to the `aruco_ros` package and do not have a 1-to-1 match to the dictionary types defined in the opencv2 ArUco library.
