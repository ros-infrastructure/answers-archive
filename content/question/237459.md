  body_markdown: "Hi,\n\n[RTAB-Map Tango app](https://play.google.com/store/apps/details?id=com.introlab.rtabmap&hl=en)\
    \ doesn't have ROS inputs or outputs. It is a standalone version. Indeed, it would\
    \ be nice to run it like a ROS node, publishing the map outside the tablet. I\
    \ did not play with ROS Java yet, so not sure how integrate it. \n\nI don't know\
    \ if it could be easier to build ROS CPP as static libraries to be included in\
    \ RTAB-Map app, so that no data conversion from C++ to Java would be required\
    \ to publish the messages (all mapping/visualization processing is done in C++,\
    \ only menus are in Java).\n\nIf you use ROS Java, you may have to convert C++\
    \ RTAB-Map/OpenCV/PCL classes to Java to publish them.\n\nFor your errors about\
