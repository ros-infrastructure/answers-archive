    Hi,

    The [octomap_server](http://wiki.ros.org/octomap_server) automatically publishes a 2D projection of the octomap as a `nav_msgs/OccupancyGrid` message. Therefore, you can use [map_saver](http://wiki.ros.org/map_server#map_saver) to save the 2D projection map just like any 2D SLAM algorithm.

    `octomap_server` publish `nav_msgs/OccupancyGrid`. [Link](http://wiki.ros.org/octomap_server).

    > Downprojected 2D occupancy map from the 3D map. Be sure to remap this topic if you have another 2D map server running. New / changed in octomap_mapping 0.4.4: The topic is now projected_map by default to avoid collisions with static 2D maps.
