    This seems to be [a common question.](http://answers.ros.org/question/9667/limit-scan-angle-with-laser-filter/) :)

    If you dont want to alter the laser driver, you can use the [laser_filters](http://ros.org/wiki/laser_filters) package as you already guessed.

    Example of how to use this:

        <launch>
          <node pkg="laser_filters" type="scan_to_scan_filter_chain"
              name="laser_filter">
            <rosparam command="load" file="laserscan_filter.yaml" />
          </node>
        </launch>

    With `laserscan_filter.yaml` containing:

        scan_filter_chain:
        - name: laser_cutoff
          type: laser_filters/LaserScanAngularBoundsFilter
          params:
            lower_angle: -1.60876090527
            upper_angle: 1.60876090527
