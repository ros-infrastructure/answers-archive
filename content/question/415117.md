  body_markdown: "Each callback is getting called with every message published on\
    \ `image_topic` after the callback is created, so cam_callback gets all the images\
    \ and overwrites img1.jpep repeatedly, then a second later cam_callback2 becomes\
    \ active and starts overwriting img2.jpeg repeatedly, then both callbacks are\
    \ overwriting the two different files with the same image repeatedly until the\
    \ node exits.\n\nTry putting loginfos in the callbacks to see this more clearly:\n\
    \n\n    import rospy\n    from std_msgs.msg import Float32\n    \n    \n    def\
    \ callback1(msg):\n        rospy.loginfo(f\"callback1: {msg}\")\n    \n    \n\
    \    def callback2(msg):\n        rospy.loginfo(f\"callback2: {msg}\")\n    \n\
    \    \n    rospy.init_node(\"dual_callbacks\")\n    rospy.Subscriber(\"test\"\
    , Float32, callback1)\n    rospy.sleep(3.0)\n    rospy.Subscriber(\"test\", Float32,\
    \ callback2)\n    rospy.sleep(1.0)\n\n\nrun that node, then run this one:\n\n\
    \    import rospy\n    from std_msgs.msg import Float32\n    \n    \n    rospy.init_node(\"\
    increment\")\n    pub = rospy.Publisher(\"test\", Float32, queue_size=2)\n   \
    \ rate = rospy.Rate(3.0)\n    value = 0.0\n    while not rospy.is_shutdown():\n\
