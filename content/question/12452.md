  body_markdown: "The `bullet` manifest says:\n\n * \"To eliminate ambiguity about\
    \ which API is active the `btQuaternion` constructor from Euler angles is deprecated.\
    \ Please explicitly construct it and populate it seperately from euler angles,\
    \ otherwise it is ambiguous as to what convention is being used.\"\n\nAt this\
    \ point, I would avoid using the bullet types directly, as they will change again\
    \ in Fuerte. Here's a solution using only the `tf` typedef:\n\n    // translate\
    \ roll, pitch and yaw into a Quaternion\n    tf::Quaternion q;\n    q.setRPY(pcl::deg2rad(data_set[t][6]),\
    \ \n             pcl::deg2rad(data_set[t][7]), \n             pcl::deg2rad(data_set[t][8]));\n\
    \n\nNote the reordering from (yaw, pitch, roll) to (roll, pitch, yaw)."
