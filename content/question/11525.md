    roscreate-pkg yourProjectName mrpt_common mrpt_slam mrpt_hwdrivers

    After package name you should list all dependecies.

    CaptainTrunky is right, you should just add one line to your manifest.xml.

    But the **correct package to depend on** is <code>[mrpt_libs](http://ros.org/wiki/mrpt_libs)</code>, which exports the required {c,l}flags. So it would be like:

    <code>
    &lt;depend package="mrpt_libs"/&gt;
    </code>
