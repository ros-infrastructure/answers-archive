  body_markdown: "Related to the part of the rotating lidar, I created an example\
    \ that shows how to detect the closest obstacle to the whole system at any position\
    \ of the rotation. The trick is to reference the obstacle to the `base_link` and\
    \ use the `tf` to transform from the laser reference frame to the `base_link`reference\
    \ frame.\n\nI have done this in Python, using `tf2_ros` and `tf2_geometry_msgs`.\n\
    \n1st. Initialize the tf buffer and listener somewhere in your init function\n\
    \n    buffer = tf2_ros.Buffer(rospy.Duration(1200.0)) \n    tf_listener = tf2_ros.TransformListener(self.tf_buffer)\n\
    \n2nd. Do the actual transformation\n\n    transform = buffer.lookup_transform(target_frame,\
    \ #destination frame\n                                       pose_stamped_to_transform.header.frame_id,\
    \ #source frame\n                                       rospy.Time(0), #get the\
    \ tf at first available time\n                                       rospy.Duration(1.0))\
    \ #wait for 1 second\n\n    pose_transformed = tf2_geometry_msgs.do_transform_pose(pose_stamped,\
    \ transform)\n\nYou can [watch the video here](https://youtu.be/VfugbH16d1o) that\
    \ shows a full example and how it looks in Rviz.\n\nCheers"
