  body_markdown: "Hello Ben,\n\n> I want to deploy and use on ROS ( melodic or noetic)\
    \ a simple deep learning network I developed with python ( on spyder environment).\n\
    \nThere are few steps:\n\n1. In your Keras model keep that file as a ROS node\
    \ and then check the form of data and publish it.\n2. After publishing, You can\
    \ use that data as whatever you want.\n\nJust for Example (Drone with hand signs):\
    \ I have hand sign data based on the video stream(right, left, up, and down) and\
    \ I have obtained a Keras model for it. Then I would suggest making the full model\
    \ as a single node and then publish it. After publishing let's say I subscribed\
    \ and I have a [string](http://docs.ros.org/en/melodic/api/std_msgs/html/msg/String.html)\
    \ \n and based on that particular string I can decide moments and give moments\
    \ to the drone via tf and it performs the action.\n\nIn place of string, you can\
    \ take any message like [Image](https://docs.ros.org/en/melodic/api/sensor_msgs/html/msg/Image.html),\
    \ [transformation](http://docs.ros.org/en/melodic/api/geometry_msgs/html/msg/Transform.html),\
    \ coordinate, [pointcloud](http://docs.ros.org/en/melodic/api/sensor_msgs/html/msg/PointCloud.html)\
    \ or even you can create your [custom message](http://wiki.ros.org/ROS/Tutorials/CreatingMsgAndSrv).\n\
    \nDoes this make sense? If you want in-depth understanding to write a comment.\
    \ This is just an overview.\n\n\n\n\n"
