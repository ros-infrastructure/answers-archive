  body_markdown: "ROS costmaps are typically visualized using `nav_msgs/GridCells`.\
    \ If you were to fill one of these data structures with your probabilistic map,\
    \ you would be able to visualize it in Rviz in three colors (INFLATED, OCCUPIED,\
    \ UNKNOWN).\n\nWhat I did to visualize probabilistic maps, however, was simply\
    \ to save my data structure as an image file (with OpenCV) and then view it as\
    \ a `sensor_msgs/Image`. This is a pretty hacky solution, but I needed to save\
    \ them as images anyway, so it worked for me.  \n\n**EDIT**: \n\nTo convert my\
    \ costmap-like data structure to an OpenCV image, I simply just set each costmap\
    \ cell as a pixel in an OpenCv IplImage data structure. Then, you can just [cv_bridge](http://www.ros.org/wiki/cv_bridge/Tutorials/UsingCvBridgeToConvertBetweenROSImagesAndOpenCVImages)\
    \ to convert that image to a `sensor_msgs/Image`. This is simple to do if you\
    \ know OpenCv, but you might have to do some research on the OpenCv image data\
    \ structure. It's not too complex.\n\nIt should be noted that the Image in Rviz\
    \ is in a separate window from the robot body. You won't be able to overlay one\
    \ on the other using this method. "

  body_markdown: "The rviz map plugin unfortunately currently only supports the three\
    \ discrete states unknown, occupied and free.\nSee this code snipped from visualization/rviz/src/rviz/default_plugin/[map_display.cpp](http://ros.org/doc/electric/api/rviz/html/map__display_8cpp_source.html)\
    \ (starting at line 289):\n\n\n      for( unsigned int pixel_index = 0; pixel_index\
    \ < num_pixels_to_copy; pixel_index++ )\n      {\n        unsigned char val;\n\
    \        if(msg->data[ pixel_index ] == 100)\n          val = 0;\n        else\
    \ if(msg->data[ pixel_index ] == 0)\n          val = 255;\n        else\n    \
    \      val = 127;\n    \n        pixels[ pixel_index ] = val;\n      }\n\nIt is\
    \ thus currently not possible to use [nav_msgs/OccupancyGrid.msg](http://www.ros.org/doc/api/nav_msgs/html/msg/OccupancyGrid.html)\
    \ messages and display more than these 3 states/color values in rviz. However,\
    \ one could use the existing map_display plugin as a starting point for a modified\
    \ version that displays more levels of grey. Only changing the above loop would\
    \ be necessary for that (if you want to keep using standard nav_msgs/OccupancyGrid\
    \ messages)."
