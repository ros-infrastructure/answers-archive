**Updated** based on Comment

As mentioned in the [link](http://wiki.ros.org/pluginlib), pluginlib is a C++ library for loading and unloading plugins from within a ROS package. Plugins are dynamically loadable classes that are loaded from a runtime library. So, in the
[tutorial](http://wiki.ros.org/navigation/Tutorials/Writing%20A%20Global%20Path%20Planner%20As%20Plugin%20in%20ROS), a static makePlan() method is used. I observe that the Dijkstra's algorithm has to be modified and it is defined as calcNavFnDijkstra(true). Again, calcNavFnDijkstra(true) is defined inside navfn.cpp.  So, I want to know, if I write my own navfn.cpp which is the only source file in my plugin, can the other part of navfn_ros.cpp (defined inside navfn package) can relate to the new navfn.cpp dynamically?
