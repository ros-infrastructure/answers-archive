  body_markdown: "A simple launch file that starts the Hokuyo driver and the assembler\
    \ would look something like this. First, launch the Hokuyo laser:\n\n      <node\
    \ type=\"hokuyo_node\" pkg=\"hokuyo_node\" name=\"hokuyo_node/>\n\nVerify that\
    \ you are getting correct laser data. To do that, you can run rviz, add a LaserScan\
    \ display, and set the fixed frame option to \"laser\".  \n\nThe second step is\
    \ launching the assembler. Both the hokuyo node and the assembler use `scan` as\
    \ the default topic, so no need to remap.\n\n      <node type=\"laser_scan_assembler\"\
    \ pkg=\"laser_assembler\" name=\"my_assembler\"> \n        <param name=\"fixed_frame\"\
    \ type=\"string\" value=\"base_link\"/> \n      </node> \n\nThe last step is to\
    \ add something that is publishing the correct transform between the `base_link`\
    \ and the `laser` frames. "
