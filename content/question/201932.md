    You can interpret the map as an image and do standard image processing on it, for example using OpenCV. This way, you can run different feature detectors/descriptors on the map and use those. An example of doing exactly that is provided in the [mapstitch](http://wiki.ros.org/mapstitch) package that allows aligning maps which each other. The code for converting a map to a cv:Mat is [here](https://github.com/tu-darmstadt-ros-pkg/mapstitch/blob/master/src/rosmain.cpp#L54).
