    \ value `data` between 0 and 1. Is it possible to scale `data` so it's between\
    \ 0 and 10 instead of 0 and 1?\n\nI'm going to assume you meant to write:\n\n\
    > Let's say I have a node (that I didn't write) publishing an Int32 value `data`\
    \ between 0 and 1. Is it possible to scale `data` so it's between 0 and 10 instead\
    \ of 0 and 1?\n\nAs an `Int32` can only encode integer values, so it would only\
    \ ever be `0` or `1`, nothing in between.\n\n---\n\nThis is something that can\
    \ be done using [topic_tools/transform](http://wiki.ros.org/topic_tools/transform).\n\
    \nOne of the examples on that page does something very similar:\n\n> convert an\
    \ orientation quaternion to Euler angles:\n\n>     rosrun topic_tools transform\
    \ /imu/orientation /euler geometry_msgs/Vector3 'tf.transformations.euler_from_quaternion([m.x,\
    \ m.y, m.z, m.w])' --import tf\n\nSo for your specific example, it would probably\
    \ be something like (haven't tested this):\n\n    rosrun topic_tools transform\
    \ /input /output std_msgs/Float32 'm.data * 10.0'\n\nAs to your question:\n\n\
    > I'm wondering if this can be done in a launch file, though I'm not sure.\n\n\
    > Something like:\n\n>     <remap from=\"/data\" to=\"/data\" * 10 /> \n\nNo,\
    \ that is not possible. `remap`s don't work like that."
