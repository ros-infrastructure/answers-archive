    Well, yes: ROS messages are (more precisely, are compiled into) classes, and in Python they do have a `__slots__` member, if this is what you are asking.

    The `__slots__` member basically contains the fields from the message definition. See also [the wiki](http://wiki.ros.org/msg#Client_Library_Support).

    Basically, the code you have checks if the message contains the field described by the variable  `k`. The [`std_msgs/Float32Multiarray` message](http://docs.ros.org/en/api/std_msgs/html/msg/Float32MultiArray.html) has the slots `layout` and `data`, for example.
