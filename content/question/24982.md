    I investigated this and I tracked the problem down to a publisher. I have opened an [issue](https://github.com/osrf/gazebo/issues/2724).

    Unfortunately, once the problem shows up, the Gazebo-ROS API is rendered useless. You cannot spawn or delete models through the relevant services anymore.

    You can use the `gz` tool though as a workaround.

    To delete a model, run: `gz model -m model_0 -d`<br>
    To spawn a model, run: `gz model -m model_0 -f <path_to_model>.sdf` <br>
    For more options, run: `gz help model`
