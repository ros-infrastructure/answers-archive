    Cannot tell for the v1.5, but in v1.4 you can use ROS plugins from [`gazebo`](http://ros.org/wiki/gazebo) and [`pr2_gazebo_plugins`](http://ros.org/wiki/pr2_gazebo_plugins) packages to control a kinematic chain. There are also `GazeboRosDiffdrive` plugin in [`gazebo_plugins`](http://ros.org/wiki/gazebo_plugins) package.

    So, it really depends on complexity of your system and the control goals.

    For instance, to control robotic arm with `robot_mechanism_controllers` you will need to do the following:

      1. Start `gazebo` with ROS API plugin:

            $ gazebo -s libgazebo_ros_api_plugin.so

      2. Add `pr2_controller_manager` to your SDF model file:

            <sdf>
                ...
                <model>
                    ...
                    <plugin name="controller_manager" filename="libgazebo_ros_controller_manager.so" />
                </model>
            </sdf>
      3. Now you can use ROS [`robot_mechanism_controllers`](http://www.ros.org/wiki/robot_mechanism_controllers) with your model.

    Of course you have to add the paths to these plugins to `GAZEBO_PLUGIN_PATH`.

    Above approach suits my specific needs, though you may find it more appropriate to write your own [ROS-enabled model plugin](http://gazebosim.org/wiki/Tutorials/1.5/ros_enabled_model_plugin). Also see this [tutorial](http://gazebosim.org/wiki/Tutorials/1.5/plugins/model_manipulation_plugin).

    I was unable to make it all work with v1.5, so it might be necessary to modify some sources.

  body_markdown: "Hi,\n\nI will write a short example how to listen to a ROS topic,\
    \ and control the joint regarding the position you get from the topic, the control\
    \ will be via a PID controller. [Here](http://en.wikipedia.org/wiki/PID_controller)\
    \ is some info about PID controllers.\n\nYou will change the value of the joint\
    \ target position in the Callback function, and compute the effort and apply it\
    \ on the joint in the OnUpdate() function.\n\nThen you can just create a ROS subscriber\
    \ and init the PID in your Load() function, something like:\n\n    void ROSPlugin::Load(physics::ModelPtr\
    \ _parent, sdf::ElementPtr /*_sdf*/)\n        {\n    \n    \t  int argc = 0;\n\
    \    \t  char** argv = NULL;\n    \t  ros::init(argc,argv,\"ROS plugin\");\n \
    \   \t  this->rosnode = new ros::NodeHandle();\n    \n          // Store the pointer\
    \ to the model\n          this->model = _parent;\n\n          // Store the joint\
    \ you want to control\n          this->joint = this->model->GetJoint(\"joint_name\"\
    );\n\n          // initialize the pid ( common::Pid ), \n          // you have\
    \ to see for yourself which values works best for you\n          this->jointPID\
    \ (10, 0, 0, 10, -10);\n    \n          // subscribing to the rost topic, and\
    \ calling the callback function\n    \t  this->ROS_subscriber = this->rosnode->subscribe(\"\
    /ROS_topic\", 10, &ROSPlugin::ROSCallback, this);\n    \n          // Listen to\
    \ the update event. This event is broadcast every simulation iteration.\n    \
    \      this->updateConnection = event::Events::ConnectWorldUpdateStart(boost::bind(&DataGlovePlugin::OnUpdate,\
    \ this));\n    \n        }\n\nThe callback function from the ROS topic:\n\n  \
    \  void ROSPlugin::ROSCallback(const package_name::MsgType& msg)\n    {\n    \
    \     // you update the position of where you want the joint to move\n       \
    \  this->joint_target_pos = msg.pos;\n    }\n\nThe OnUpdate() function:\n\n  \
    \  void ROSPlugin::OnUpdate()\n    {\n        // compute the steptime for the\
    \ PID\n    \tcommon::Time currTime = this->model->GetWorld()->GetSimTime();\n\
    \    \tcommon::Time stepTime = currTime - this->prevUpdateTime;\n   \t this->prevUpdateTime\
    \ = currTime;\n\n \t   // set the current position of the joint, and the target\
    \ position, \n        // and the maximum effort limit\n    \tdouble pos_target\
    \ = this->joint_target_pos;\n    \tdouble pos_curr = this->joint->GetAngle(0).Radian();\n\
    \    \tdouble max_cmd = this->joint_max_effort;\n    \n        // calculate the\
    \ error between the current position and the target one\n    \tdouble pos_err\
    \ = pos_curr - pos_target;\n    \n        // compute the effort via the PID, which\
    \ you will apply on the joint\n    \tdouble effort_cmd = this->jointPID.Update(pos_err,\
    \ stepTime);\n        \n        // check if the effort is larger than the maximum\
    \ permitted one\n    \teffort_cmd = effort_cmd > max_cmd ? max_cmd :\n    \t\t\
    \t\t(effort_cmd < -max_cmd ? -max_cmd : effort_cmd);\n\n        // apply the force\
    \ on the joint\n    \tthis->joint->SetForce(0, effort_cmd);\n    \n    }\n\n\n\
    If you have problems implementing the idea let me know.\n\nCheers,\nAndrei\n"
