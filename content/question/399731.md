    credits to @aprotyas

    This got me started with getting node names:

    Let `this` be your node instance

        const auto node_graph_interface = this->get_node_graph_interface();

        std::vector<std::string> node_names = node_graph_interface->get_node_names();


    Or, if you need namespaces too

        std::vector<std::pair<std::string, std::string>> node_names_and_namespaces =
          node_graph_interface->get_node_names_and_namespaces();
