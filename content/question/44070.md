Hi,

I have successfully installed ROS Fuerte on a Debian Squeeze machine. Along the way, I ran into problems with unmet dependencies/undefined build rules, similar to those described [here](http://answers.ros.org/question/40131/definition-for-ros-packages-on-debian-squeeze/) and [here](http://answers.ros.org/question/33002/rosdep-install-a-fails-on-debian-sqeeze/), which required some manual tweaking to resolve. A very useful post was the answer to [this](http://answers.ros.org/question/33002/rosdep-install-a-fails-on-debian-sqeeze/) question by jamuraa. 

I have read the [howto on Contributing rosdep rules](http://ros.org/doc/api/rosdep2/html/contributing_rules.html), and I would like to contribute the necessary rules, so that ROS can be built automatically on Debian through rosdep/rosmake, but I'm confused on how to do it for this particular case. The two major dependencies that currently break `rosdep install -a` are flann and pcl. Both of these dependencies are not defined in standard rosdep.yaml files, but in [this gbpdistro file](https://raw.github.com/ros/rosdistro/master/releases/fuerte.yaml). Searching the wiki yields only one reference to gbpdistro files, in [rep 125](http://ros.org/reps/rep-0125.html#gbpdistro-files).

So, my question is, what is the right way to contribute rosdep rules for installing flann and pcl on Debian, and share this with the community? Should I:

a) create a new yaml file for Debian and override the gpbdistro file, similar to the gentoo.yaml and osx-homebrew.yaml?

b) modify the gpbdistro file in some way?

Any help will be greatly appreciated.
