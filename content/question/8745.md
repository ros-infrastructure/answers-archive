    \ the COM is located acoording to this initial reference frame and use this in\

    \ and rotate them using the rpy of the same pose parameter.\n\nYou now have placed\
    \ the COM according relative to the link reference frame and aligned the axis\
    \ of the inertia matrix. \n\nNow enter the inertia matrix according to the axis\
    \ and through the COM.\n[Link to example](http://gazebosim.org/tutorials?tut=inertia&cat=build_robot)\n\
    \nPlease note that the pose parameter is under the inertial parameter and this\
