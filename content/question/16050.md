  body_markdown: "The error `invalid use of incomplete type` means the compiler knows\
    \ the class `ros::NodeHandle` exists, but it doesn't have enough information about\
    \ it to know how to call the `createTimer` method. This happens when you have\
    \ a forward declaration (A line looking like this `class ros::NodeHandle;`) but\
    \ not a class definition. The header containing the definition of `ros::NodeHandle`\
    \ hasn't been included. Add `#include <ros/ros.h>` to the top of your file. "
