    \ files. Parameters are all evaluated and loaded onto the parameter server first,\
    \ then nodes are started.\n\nDoing what you ask for would also be difficult to\
    \ implement robustly, as it's very easy to create (invisible, to `roslaunch`)\

    /params/param3\" />\n> \n> And then:\n> \n>      <node pkg=\"arg_name1\" type=\"\
    arg_name2\" name=\"arg_name3\">\n\nI'm not sure I completely understand what you're\
    \ trying to do, but putting all these details in `.yaml` files seems like something\
