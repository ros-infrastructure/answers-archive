  body_markdown: "I believe the issue is that your `macros.xacro` file doesn't have\
    \ a <robot> tag as the root element. So something like\n\n    <robot name=\"mybot_macros\"\
    \ xmlns:xacro=\"http://www.ros.org/wiki/xacro\">\n      <xacro:macro name=\"box_inertia\"\
    \ params=\"m x y z\">\n    \t<inertia  ixx=\"${m*(y*y+z*z)/12}\" ixy=\"0\" ixz=\"\
    0\"\n    \t\t\t  iyy=\"${m*(x*x+z*z)/12}\" iyz=\"0\"\n    \t\t\t  izz=\"${m*(x*x+z*z)/12}\"\
    />\n      </xacro:macro>\n    </robot>\n\nshould fix the issue."
