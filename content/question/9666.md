  body_markdown: "Hi,\n\nHere is the functions we use in our init.d file to start\
    \ / stop ros. It prints the output of the node in tty8 and tty9. It could be combined\
    \ with screen for easier use as well.\n\n    start_ros () {\n        source /opt/ros/setup.sh\n\
    \    \n    \troscore <>/dev/tty8 2>/dev/tty8 & disown\n        until rostopic\
    \ list ; do sleep 1; done\n        roslaunch YOUR_PACKAGE YOUR_LAUNCH_FILE.launch\
    \ <> /dev/tty9 2>/dev/tty9 & disown\n    }\n\n    stop_ros () {\n        source\
    \ /opt/ros/setup.sh\n\n        #killall nodes\n        for i in $( rosnode list\
    \ ); do\n\t    rosnode kill $i;\n        done\n\n        #stop roscore\n     \
    \   killall roscore\n    }\n"
