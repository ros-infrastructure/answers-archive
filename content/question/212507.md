  body_markdown: "You've named your script `random`, which overlaps with the system\
    \ python module of the same name.\n\nWhen rospy attempts to import random, it\
    \ instead imports you script, and causes your code to run before the definition\
    \ of rospy is complete.\n\nYou should name your script something else that doesn't\
    \ overlap with the system python modules. "
