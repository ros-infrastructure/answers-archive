  body_markdown: "Hi, \n\nTo give you an example: `/chatter@std_msgs/String@ignition.msgs.StringMsg`\n\
    \n - `chatter` is the ignition topic name. This topic will be created in the ROS\
    \ 2 network with the same name\n - `std_msgs/String` ROS type msgs\n - `ignition.msgs.StringMsg`:\
    \ Ignition type msgs\n\nIf you want to create a launch file, you have a look to\
    \ this [launch file](https://github.com/ignitionrobotics/ros_ign/blob/ros2/ros_ign_gazebo_demos/launch/battery.launch.py).\
    \ The key part:\n\n    # Bridge\n    bridge = Node(\n        package='ros_ign_bridge',\n\
    \        executable='parameter_bridge',\n        arguments=['/model/vehicle_blue/cmd_vel@geometry_msgs/msg/Twist@ignition.msgs.Twist',\n\
    \                   '/model/vehicle_blue/battery/linear_battery/state@sensor_msgs/msg/BatteryState@ignition.msgs.BatteryState'],\n\
    \        output='screen'\n    )\n\nHope this help\n"
