    Hey @blackbird
    Reading through the documentation [link](http://docs.ros.org/en/hydro/api/rosnode/html/) you provided, it seems `rosnode.rosnode_ping` can take `max_count`. So for example If you set `max_count=5`, the `rosnode.rosnode_ping("/my_node_name", max_count=5)` will exit after 5 pings and return `True`. If you don't mention any `max_count`, it will continue until stopped `ctrl+c`. You can also set verbose=True to see the ping time.
