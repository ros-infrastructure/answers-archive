  body_markdown: "I typically use [XACRO](http://wiki.ros.org/xacro) to combine arms\
    \ and grippers.\n\nfor example:\n\n\n    <robot name=\"myrobot\" xmlns:xacro=\"\
    http://www.ros.org/wiki/xacro\" xmlns:xi=\"http://www.w3.org/2001/XInclude\">\n\
    \    \n    <!-- myrobot urdf file -->\n    <xacro:include filename=\"$(find mypackage)/urdf/myrobotarm_no_end_effectors.urdf\"\
    />\n    \n    <!-- add any joints/links required to connect the two -->\n    \n\
    \    <xacro:include filename=\"$(find mypackage)/urdf/an_end_effector.urdf.xacro\"\
    \ />\n    \n    </robot>\n\n\nI usually write the end effector as an xacro macro\
    \ so that I can attach it to either a right or left arm or launch it standalone\
    \ to trouble shoot the URDF file if need be. \n\nHope that helps."
