    \ for how close the actual robot gets to the goal, but maybe it works for how\
    \ close the planner can get to it as well.\n\n    ~<name>/xy_goal_tolerance (double,\
    \ default: 0.10)\n    The tolerance in meters for the controller in the x & y\
    \ distance when achieving a goal\n\nalso work with \n\n    ~<name>/pdist_scale\
    \ (double, default: 0.6)\n    The weighting for how much the controller should\
    \ stay close to the path it was given, maximal possible value is 5.0\n    ~<name>/gdist_scale\
    \ (double, default: 0.8)\n    The weighting for how much the controller should\
    \ attempt to reach its local goal, also controls speed, maximal possible value\
