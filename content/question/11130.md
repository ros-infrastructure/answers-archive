  body_markdown: "If your gyro is returning values of 8 for the raw gyro rate then\
    \ you may have the same problem as the other post. Changing the calibration values\
    \ will not cause the gyro to return values of 8 for the raw values. This most\
    \ likely means that the gyro is not powered and the irobot create is reading the\
    \ noise on the line. \n\nOne of three senarios can cause the gyro not to be powered:\
    \ \n\n 1. The irobot create did not power on correctly. Try power cycling the\
    \ irobot create.\n 2. The power board is not seated properly. Try pressing down\
    \ on the power board to make sure it is properly seated on the connector. \n 3.\
    \ There is an electrical problem with the power board or irobot create. Try following\
    \ the steps listed in this question http://answers.ros.org/question/2024/turtlebot-bad-gyro-calibration\n"
