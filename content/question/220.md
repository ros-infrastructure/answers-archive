  body_markdown: "Currently effort controllers are not provided.\n\nIt's technically\
    \ possible to change the controllers to any of the `robot_mechanism_controllers`\
    \ but doing so may require tuning that is not straight forward. Though perhaps\
    \ in the case of effort controllers that may not be the case. \n\n<s>According\
    \ to: http://gazebosim.org/wiki/DRC/Roadmap DRC sim 1.1 will be released this\
    \ Friday with support for a subset of the robot_mechanism_controllers, though\
    \ what that means is not yet clear.\n\n\nNone of the [recent commits to branch\
    \ \"default\"](https://bitbucket.org/osrf/drcsim/changesets) seem to show progress\
    \ on this particular front, but it may be being developed on another branch so\
    \ we'll have to wait for Friday to see I imagine.</s>\n\n*** update:\n1.1 apparently\
    \ did not include effort controllers ***\n\n\nTo switch controllers you need to\
    \ make changes in two places:\n\n 1. the launch file where the `drc_robot_controllers-spawner`\
    \ is started\n 2. a `yaml` file with the controller parameters\n\nIn principle\
    \ it's as simple as replacing each instance of \"position\" with \"velocity\"\
    \ or \"effort\".\n\n<strike>I have an example `launch` file and `yaml` but cannot\
