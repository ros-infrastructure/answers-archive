  body_markdown: "I believe your issue is in the second-to-last line:\n\n    waypoints_pub.publish(traj);\n\
    \nSpecifically, a ROS publisher can only publish ROS messages (see [the API docs](http://docs.ros.org/kinetic/api/roscpp/html/classros_1_1Publisher.html#a580af4f9f7ab80876036d8aa25dd27d5)),\
    \ but `traj` is a `std::vector`, which explains the line your error:\n\n    error:\
    \ \u2018const class std::vector<geometry_msgs::point_<std::allocator<void> > >\u2019\
    \ has no member named \u2018__getMD5Sum\u2019 \n\nThe publisher expect the type\
    \ that you pass in to have the method `__getMD5Sum`, which `std::vector` does\
    \ not have.\n\nI expect that you are looking for some message in [trajectory_msgs](http://wiki.ros.org/trajectory_msgs?distro=melodic),\
    \ or you could make your own message that is a list of `geometry_msgs::Point`s. "
