  body_markdown: "I answer my own question. Finally the problem is that tfMessage\
    \ is not part of the standard roscore distribution. So you have to add it in the\
    \ ROSMatlab path.\n\nThe procedure is the following:\n* Download the tf.jar here:\n\
    https://github.com/rosjava/rosjava_mvn_repo/tree/master/org/ros/rosjava_messages/tf\n\
    Don't forget to download it in 'raw'.\n*  Add the jar files to <MATLAB>\\toolbox\\\
    psp\\rosmatlab\\jars\n*  Edit <\\MATLAB>\\toolbox\\local\\classpath.txt by adding\
    \ the full path to the jar file above the line \u201C# ROS-MATLAB-END\u201D\n\
    * Restart MATLAB.\n\nAnd it should work.\n\n"
