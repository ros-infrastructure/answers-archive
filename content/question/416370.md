    The issue appears to be the repository you're trying to use.

    The error message mentions:

    >     E: The repository 'http://packages.ros.org/ros/ubuntu [..]

    while the install instructions you link have:

    >     http://packages.ros.org/ros2/ubuntu

    note the `2` there in the url at the end of `ros2`.

    Without the `2`, you're trying to use the ROS 1 package repository. That doesn't support `22.04`, which is why you get that error.

    You could try editing the `/etc/apt/sources.list.d/ros2.list` file and add the missing `2` (then run `sudo apt update`). If that doesn't work either, I'd suggest removing `/etc/apt/sources.list.d/ros2.list` and following the install instructions again.
