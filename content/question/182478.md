  body_markdown: "Without knowing for certain, there may be some initialization procedures\
    \ in the TransformBroadcaster that require a non-trivial amount of time. In that\
    \ event, you don't want to initialize the TransformBroadcaster every time `poseCallback`\
    \ is called. You therefore can either declare the TransformBroadcaster as a global\
    \ variable (or a class member, if using a class), or you can just make it static. "
