  body_markdown: "Using wildcards in java classpath\n\nWild cards were introduced\
    \ from Java 6. Class path entries can contain the basename wildcard character\
    \ *, which is considered equivalent to specifying a list of all the files in the\
    \ directory with the extension .jar or .JAR. For ex. a classpath entry consisting\
    \ simply of * expands to a list of all the jar files in the current directory.\n\
    \nExample\n \njava -cp \"lib/*\" %MAINCLASS%\n where %MAINCLASS% is the class\
    \ containing your main method.\n\nHow to use a wildcard in the classpath to add\
    \ multiple jars\n\n \njava -cp \"lib/*\" -jar %MAINJAR%\n\nwhere %MAINJAR% is\
    \ the jar file to launch via its internal manifest.\n\nIf you need only specific\
    \ jars, you will need to add them individually. The classpath string does not\
    \ accept generic wildcards like Jar*, *.jar, hiber* etc.\n\nExample\n\nThe following\
    \ entry does not work:\n\n java -cp \"Halo.jar;lib/*.jar\" ni.package.MainClass\n\
    \nCorrect entry is :\n \njava -cp \"Halo.jar;lib/*\" ni.package.MainClass\n\n\
    More about....[Java Classpath](http://net-informations.com/java/basics/path.htm)\n\
