    I assume you're following this [YDLiDAR manual](https://www.ydlidar.com/Public/upload/files/2020-04-13/YDLIDAR-X2-USER%20Manual.pdf) or similar, but the `turtlebot-rviz-launchers` package is indeed outdated (its [GitHub repo](https://github.com/turtlebot/turtlebot_interactions) was last updated 6 years ago).  The [YDLiDAR GitHub documentation](https://github.com/YDLIDAR/ydlidar_ros) is a more up-to-date resource.

    As a side note, RViz is installed with the desktop ROS installations, so you may already have it.  If you don't have RViz from the ROS install and need it, Solrac3589's command is correct:

        sudo apt-get install ros-melodic-rviz
