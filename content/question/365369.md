  body_markdown: "I guess you can publish string \"play\"/\"stop\" via message [std_msgs/String](http://docs.ros.org/en/melodic/api/std_msgs/html/msg/String.html).\
    \ Then you create another node listening to this topic. Based on the string received,\
    \ this node publish topic 'cmd_vel' with message [geometry_msgs/Twist](http://docs.ros.org/en/melodic/api/geometry_msgs/html/msg/Twist.html).\
    \ If the string is \"play\", then you set some linear/angular velocity in Twist\
    \ message. This should be able to make it move. On the other side, if the string\
    \ is \"stop\", just set linear/angular velocity as 0. \n\nHope this helps, Gerry "
