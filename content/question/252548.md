    Found a solution:

        var imageTopic = new ROSLIB.Topic({
            ros : ros,
            name : '/camera/image/compressed',
            messageType : 'sensor_msgs/CompressedImage'
        });

    the compressed image can be retrieved via:

        var imagedata = "data:image/jpg;base64," + message.data;
