  body_markdown: "Below is one of multiple options. This is assuming you have a default\
    \ hydro setup running, with \"source /opt/ros/hydro/setup.bash\" in your .bashrc\
    \ file. It will also use the catkin version of hector_slam from source as it appears\
    \ you want to use catkin (?). If you don\xB4t absolutely require installation\
    \ from source \"sudo apt-get install ros-hydro-hector-slam\" should also work.\n\
    \n\nCreate a folder somewhere:\n\n    mkdir hector_slam_test\n\nEnter folder,\
    \ init workspace:\n\n    cd hector_slam_test\n    wstool init\n\nCopy the following\
    \ lines to a file named \"hector_slam_catkin.rosinstall\":\n\n    - git:\n   \
    \     uri: https://github.com/tu-darmstadt-ros-pkg/hector_slam.git\n        local-name:\
    \ src/hector_slam\n        version: catkin\n/edit: It appears the link gets screwed\
    \ up by ROS Answers. You can see the correct formatting here: http://answers.ros.org/answers/115386/revisions/\n\
    \nMerge the contents of this rosinstall file into your workspace:\n\n    wstool\
    \ merge hector_slam_catkin.rosinstall\n\nUpdate workspace (this updates/pulls\
    \ all repos belonging to the workspace):\n\n    wstool update\n\nBuild contents\
    \ of workspace:\n\n    catkin_make\n\nSource the setup file in the workspace\xB4\
    s devel folder:\n\n    source devel/setup.bash\n\n\nYou should now be able to\
    \ use hector_slam as expected. For example\n\n     roslaunch hector_slam_launch\
    \ tutorial.launch\nshould start without errors."
