  body_markdown: "The Inverse Kinematics is returning an invalid result as you are\
    \ not supplying a desired orientation for the pose. Without setting an orientation,\
    \ the default [Pose::Quaternion](https://github.com/ros/common_msgs/blob/jade-devel/geometry_msgs/msg/Pose.msg#L3)\
    \ is a vector of all zeros [0,0,0,0], which is an invalid Quaternion. I would\
    \ recommend either \n\n - read a bit on [Quaternions](http://wiki.ros.org/Tutorials/Quaternions)\
    \ in order to calculate your own <br/>\n\n-or-<br/>\n\n- move Baxter's end effector\
    \ into the\n   desired orientation with respect to\n   the base of the robot,\
    \ check\n   the arm's current Pose::Quaternion, and use that:\n\n<pre><code>\n\
    \   $ rostopic echo -n1 /robot/limb/left/endpoint_state\n    header: \n    ...\n\
    \    pose: \n      position: \n        x: 0.529521061953\n        y: 0.205000088025\n\
    \        z: -0.287943031364\n    orientation: \n        x: -0.229715175883\n \
    \       y: 0.970497091367\n        z: 0.00287481046527\n        w: 0.0731988325182\n\
    \n</code></pre>\nWhether or not the latter method will work at an arbitrary Pose::Position\
    \ is arm-configuration dependent."
