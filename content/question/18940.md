  body_markdown: "As @Peter Mitrano suggests, the **[force is applied over only 1\
    \ simulation time step](http://gazebosim.org/tutorials?tut=apply_force_torque)**,\
    \ resulting in a **small impulse** and therefore a **very small change in velocity**.\n\
    \n\n----------\nWhen I run Gazebo simulator, the default max time (step) size\
    \ is 0.001 *(1 ms)*\n\nF = m * a  \nv = a * t  \nv(t) = v(t=0) + 1/m * integral(F(t),\
    \ 0, t)\n\nIf we assume a constant F across the time step, then   \n**v(t) = v(t=0)\
    \ + (F * t)/m**\n\n----------\n*Given:*  \nv(t=0) = 0  \nF = 100 N  *(F > Fgravity)*\
    \  \nt = 0.001 s *(1 simulation time step)*  \nm = 5 kg  \n\nv(0.001) = 0 + (100\
    \ * 0.001)/5  \n**v(0.001) = 0.02 m/s** or **2 cm/s**\n\n\n----------\nThrowing\
    \ in the effects of gravity, we can determine *(roughly)* that the 5 kg sphere\
    \ in your example should - in theory - reach a maximum vertical *(+z)* height\
    \ of 0.01 m *(1 cm)* and return to a height of 0 m after 0.02 s *(20 ms)*.\n\n\
    ----------\nPhysics: http://www.physicsclassroom.com/class/momentum/Lesson-1/Momentum-and-Impulse-Connection"
