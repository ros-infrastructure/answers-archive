  body_markdown: "What you are describing is called \"running a child process\". The\
    \ most common way to do this in c++ is to use the `system()` or `popen()` calls.\
    \ Google for how to use these. \n\nHowever, you need to careful when using `system()`\
    \ call in ros because the call blocks execution until the child process exits.\
    \ This means you get really bad performance if you call it directly from a subscribe\
    \ callback. What you need to do instead is: inside the subscribe callback you\
    \ launch a new thread, then call `system()` from inside the thread."
