    As the instructions you followed say, when installing from a pre-built binary tarball you have to use `source ~/ros2_galactic/ros2-linux/setup.bash` to activate ROS. It has been installed to `~/ros2_galactic`. If you want it installed in `/opt/ros` then you need to follow [these instructions](https://docs.ros.org/en/galactic/Installation/Ubuntu-Install-Debians.html) to install using Debian packages. This works on Ubuntu, despite the name of the package format.
