  body_markdown: "Assuming you're using `xacro`, one can do something like\n\n   \
    \ from amenx_index_python import get_package_share_directory\n    from launch\
    \ import LaunchDescription\n    from launch.substitutions import Command\n   \
    \ from launch_ros.actions import Node\n    import os\n    \n    def generate_launch_description():\n\
    \        my_xacro = os.path.join(\n            get_package_share_directory(\"\
    PKG_NAME\"),\n            \"urdf\",\n            \"ROBOT_NAME.urdf.xacro\",\n\
    \        )\n    \n        return LaunchDescription(\n            [\n         \
    \       Node(\n                    package=\"joint_state_publisher\",\n      \
    \              executable=\"joint_state_publisher\",\n                    name=\"\
    joint_state_publisher\",\n                ),\n                Node(\n        \
    \            package=\"robot_state_publisher\",\n                    executable=\"\
    robot_state_publisher\",\n                    name=\"robot_state_publisher\",\n\
    \                    parameters=[\n                        {\n               \
    \             \"robot_description\": Command([\"xacro\", \" \", my_xacro]),\n\
    \                        }\n                    ],\n                ),\n     \
    \       ]\n        )\n   \nOf course it is hard to know what your problem is without\
    \ knowing more regarding the error output.\n\nNote: this code was taken from a\
    \ foxy pkg running on ubuntu 20.04."
