EDIT: After transitioning to Ubuntu 20.04 and learning ROS on Linux, I think I can answer my own question. The first problem was, that I had not installed the catkin-tools package, without which commands like `catkin build` don't work. Secondly, ROS refuses to mix catkin workspaces built using `catkin_make` and catkin-tools comands. The appropriate way would have been to use catkin build instead. Thirdly, this package does not work on Windows. After installing it, and trying to use said commands, I got the error mesage 

> ModuleNotFoundError: No module named 'fcntl'

This is because the catkin-tool package relies on some Unix commands which are not supported on Windows according to https://stackoverflow.com/questions/45228395/error-no-module-named-fcntl. In short, what I was both mixing commands that should not be mixe, with a package that was not installed and does not work on Windows. I hope this helps anyone who runs into similar problems and let me know if something is inaccurate.
