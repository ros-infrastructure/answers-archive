  body_markdown: "ROS and OpenCV are two totally independent projects. All you need\
    \ to do in ROS is to transform the image message into an opencv image using [cv_bridge](http://wiki.ros.org/cv_bridge/Tutorials/ConvertingBetweenROSImagesAndOpenCVImagesPython).\
    \ Once you have this image, you can do whatever you want with it using OpenCv\
    \ functionalities. Check the extremely extensive OpenCV documentation and tutorials\
    \ either in [Python](http://docs.opencv.org/3.0-beta/doc/py_tutorials/py_imgproc/py_table_of_contents_imgproc/py_table_of_contents_imgproc.html#py-table-of-content-imgproc)\
    \ or [C++](http://docs.opencv.org/2.4/doc/tutorials/imgproc/table_of_content_imgproc/table_of_content_imgproc.html).\
