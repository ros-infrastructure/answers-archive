    \nit is clearly mentioned that you should have already completed the introduction\
    \ to services and messages tutorial!\n\nEdit following @gvdhoom 's feedback.\n\
    \nThe service interfaces are defined in `.srv` files in a package, which are then\
    \ compiled into `.h` files by the ROS client libraries. Each service interface\
    \ consists of two components. `Request` and `Response`. For an example, the `AddTwoInts`\
    \ interface is [defined as](https://github.com/ros/ros_tutorials/blob/noetic-devel/roscpp_tutorials/srv/TwoInts.srv)\n\
    \n    int64 a\n    int64 b\n    ---\n    int64 sum\n\nThe request component is\
    \ defined above `---` in the `.srv` file and the response component below it.\
    \ This is why the service server accesses the two integers passed by the client\
    \ as `req.a` and `req.b`. The client, once the response is received into the variable\
    \ `res`, will access the sum as `res.sum`. \n\nYou can define your own service\
    \ interface with your own field names and your own data types. The data types\
    \ you can use to define custom message and service interfaces are described [here](http://wiki.ros.org/msg#Fields).\
    \ How to define custom service interfaces is explained [here](http://wiki.ros.org/ROS/Tutorials/CreatingMsgAndSrv#Creating_a_srv).\
    \ \n\nFor an example, I here is a custom service interface I have defined.\n\n\
    \    string command\n    \n    uint8[] ids\n    string addr_name\n    int32 value\n\
    \    ---\n    bool comm_result"
