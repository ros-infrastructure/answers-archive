  body_markdown: "Edit (2021-04-13): it's most likely possible to run Karel binaries\
    \ *without* `R632`.\n\nIf you are in doubt, post a comment below this answer.\n\
    \n---\n\nOriginal answer:\n\n > Is there a possibility to communicate ROS without\
    \ karel R632? \n\nThe `fanuc_driver` package has parts written in Karel. As far\
    \ as I know, you need `R632` in order to run Karel programs. Without that, communication\
    \ with the ROS side of `fanuc_driver` is impossible (again, as far as I know).\
    \ At least using socket communication.\n\nHaving said that, an alternative might\
    \ be to use a fieldbus - such as EthernetIP or Profinet - between your R-30iA\
    \ and the ROS PC, and to write `robot_state` and `motion_streaming_interface`\
    \ alternatives that use that fieldbus to communicate. This would remove the need\
    \ for Karel, as a TP program could be used to then read and write registers and\
    \ perform moves. This would all need to be developed though.\n\nIf you would be\
    \ interested in that, I'm more than happy to assist you.\n\nIn any case try to\
    \ see whether you can run Karel programs. If you can, then it might well be that\
    \ `R632` is not required after all.\n\n---\n\nEdit:\n\n> R636 socket messaging\
    \ is installed.\n\nNote that the *Requirements* section on the [fanuc_driver](http://wiki.ros.org/fanuc_driver?distro=indigo#fanuc_driver.2BAC8-indigo.Requirements)\
    \ wiki page states that `R648` (User Socket Messaging) is required. `R636` is\
    \ a different (but related) option."
