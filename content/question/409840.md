    More or less by chance I found the 'Curated List of common ROS2 packages' ([REP 2005](https://www.ros.org/reps/rep-2005.html)), which contains links per package to the [ROS Index](https://index.ros.org/), and there I found the link to the api documentation.

    Turns out that the humble API docs are at [http://docs.ros.org/en/humble/p/ ](http://docs.ros.org/en/humble/p/) as opposed to the previous ROS2 distributions at https://docs.ros2.org.
