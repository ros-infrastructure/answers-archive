    You could use the /gazebo/set_model_state topic for this.

        rostopic pub /gazebo/set_model_state gazebo_msgs/ModelState "model_name: 'YOUR_ROBOT_MODEL_NAME'
        pose:
          position:
            x: 1.0
            y: 1.0
            z: 0.0
          orientation:
            x: 0.0
            y: 0.0
            z: 0.0
            w: 0.0
        twist:
          linear:
            x: 0.0
            y: 0.0
            z: 0.0
          angular:
            x: 0.0
            y: 0.0
            z: 0.0
        reference_frame: ''"

    You can use the TAB key to autocomplete after you type in rostopic pub /gazebo/set_model_state ; after that, the only thing you need to add is your robot model name.
