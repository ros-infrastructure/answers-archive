  body_markdown: "Hi @ballubuoy,\n\nIn the first example of the ros cookbook, the\
    \ time is not extracted using a bag object. The time is obtained by calling a\
    \ subprocess executing the command `robag info my_bag.bag` and redirecting the\
    \ output into a yaml object. In the second example, after searching on the [C++\
    \ API](https://docs.ros.org/api/rosbag/html/c++/), it seems there is no way to\
    \ directly get the info from a function like in Python with `_get_yaml_info()`,\
    \ but what you can do, instead of using a subprocess is using the [View](http://docs.ros.org/diamondback/api/rosbag/html/c++/classrosbag_1_1View.html)\
    \ class like this:\n\n    #include <rosbag/bag.h>\n    #include <rosbag/view.h>\n\
    \    #include <std_msgs/Int32.h>\n    #include <std_msgs/String.h>\n    \n   \
    \ int main(int argc, char **argv)\n    {\n    \trosbag::Bag bag;\n    \tbag.open(\"\
    /path/to/my_bag.bag\", rosbag::bagmode::Read);\n    \n    \trosbag::View view(bag);\n\
    \    \n    \tros::Time bag_begin_time = view.getBeginTime();\n    \tros::Time\
    \ bag_end_time = view.getEndTime();\n    \n    \tstd::cout << \"ROS bag time:\
    \ \" << (bag_end_time-bag_begin_time).toSec() << \"(s)\" << std::endl;\n    \n\
    \    \tbag.close();\n    \n    \treturn 0;\n    }\n\nSince the bag may be not\
    \ beginning at time 0 we just extract the first time and the end time to compute\
    \ the time elapsed in the bag, the convert that `ros::Time` into secs.\n\nHope\
    \ that can help you.\n\nRegards."
