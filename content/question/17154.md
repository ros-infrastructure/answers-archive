    Not exactly a "controller", but you can use a [SpaceNav](https://bitbucket.org/osrf/gazebo/pull-requests/1168/integrated-space-navigator-joystick/diff) 3d mouse without much extra setup.

    One common way to use joysticks is through [ROS](http://wiki.ros.org/joy/Tutorials/ConfiguringALinuxJoystick). It would be nice to have more out-of-the-box plugins to use joysticks directly with Gazebo...

    Fun fact, I recently discovered that those "presentation laser pointer remotes" register just like keyboard keystrokes, and they can be used with the [KeyboardGUIPlugin](https://bitbucket.org/osrf/gazebo/src/default/plugins/KeyboardGUIPlugin.hh).
