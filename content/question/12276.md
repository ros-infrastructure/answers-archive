  body_markdown: "I had quite a hard time implementing this.\nSo here my example:\n\
    \n`/joint_commander` is the node the dynamic_reconfigure server runs in.\n\nIncludes:\n\
    \n    #include <dynamic_reconfigure/DoubleParameter.h>\n    #include <dynamic_reconfigure/Reconfigure.h>\n\
    \    #include <dynamic_reconfigure/Config.h>\n\nIn your function:\n\n    dynamic_reconfigure::ReconfigureRequest\
    \ srv_req;\n    dynamic_reconfigure::ReconfigureResponse srv_resp;\n    dynamic_reconfigure::DoubleParameter\
    \ double_param;\n    dynamic_reconfigure::Config conf;\n    \n    double_param.name\
    \ = \"kurtana_pitch_joint\";\n    double_param.value = pitch;\n    conf.doubles.push_back(double_param);\n\
    \    \n    double_param.name = \"kurtana_roll_joint\";\n    double_param.value\
    \ = yaw;\n    conf.doubles.push_back(double_param);\n    \n    srv_req.config\
    \ = conf;\n    \n    ros::service::call(\"/joint_commander/set_parameters\", srv_req,\
    \ srv_resp);"

I have looked at the [dynamic_reconfigure wiki](http://www.ros.org/wiki/dynamic_reconfigure) and the [client API](http://ros.org/doc/electric/api/dynamic_reconfigure/html/dynamic_reconfigure.client.Client-class.html) pages and I only see a way to use a Python client node to update variables on a dynamic reconfigure server.
