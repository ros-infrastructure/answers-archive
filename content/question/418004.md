  body_markdown: "If you are using ROS2 probably is a QoS issue ( Quality of service)\n\
    \nYou must open rviz2\n\n1- ros2 run rviz2 rviz2\n\n2- Go to add plugin button\
    \ and look for image or camera\n\n3- on topic select or type \"/camera/image_raw\"\
    \ or \"camera/depth\"\n\n4 - Below topic options there are QoS settings. Usually\
    \ is set to\n\"Reliable\" and you need to switch to \"Best Effort\" or the inverse.\
    \ \nDoing this change it should work and image appears.\n\n5- If you don't have\
    \ success, you need to check if camera data is publishing image data\n\nA) ros2\
    \ topic list\n\nB) ros2 topic echo /camera/depth\n\nIf data is not flowing then\
    \ you found the issue, open rqt graph and check if your node is\nNot publishing\
    \ data to your camera or subscribing and why:\n\nC) ros2 run rqt_graph rqt_ graph"
