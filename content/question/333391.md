  body_markdown: "Hello!\n\nFor what I've understood, what you want is to print just\
    \ some parts of the Odometry message, not the whole message. If that is the case,\
    \ you can achieve this with a simple subscriber to the Odometry topic and, inside\
    \ the callback, print only the desired values. It would be something like this:\n\
    \n    #include <nav_msgs/Odometry.h>\n    #include <ros/ros.h>\n    \n    void\
    \ odomCallback(const nav_msgs::Odometry::ConstPtr &msg) {\n      // ROS_INFO(\"\
    %s\", msg->header.frame_id.c_str());\n      // ROS_INFO(\"%f\", msg->twist.twist.linear.x);\n\
    \      ROS_INFO(\"%f\", msg->pose.pose.position.x);\n    }\n    \n    int main(int\
    \ argc, char **argv) {\n    \n      ros::init(argc, argv, \"odom_sub_node\");\n\
    \      ros::NodeHandle nh;\n    \n      ros::Subscriber sub = nh.subscribe(\"\
    odom\", 1000, odomCallback);\n    \n      ros::spin();\n    \n      return 0;\n\
    \    }\n\nThe most important part here is to note that the Odometry message is\
    \ in a pointer so, in order to access it, you need to do it like this:\n\n   \
    \ msg->whatever.you.want.to.print\n\nHope this helps you! Also, you can have a\
    \ look at the following post where I talk about this: http://www.theconstructsim.com/ros-qa-196-how-to-output-odometry-data/"
