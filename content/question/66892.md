  body_markdown: "If running the command with `rosrun` as in your command line example\
    \ works fine, I do not see why your `roslaunch` fails (provided both are executed\
    \ by the same user in the same environment, otherwise there might be some problem\
    \ with the device file permissions, or even the gps might associated to a different\
    \ `/dev/ttyXXX`).\n\nHowever, you may try setting the parameters using [`<param>`\
    \ tags](http://wiki.ros.org/roslaunch/XML/param) inside the [`<node>` tags](http://wiki.ros.org/roslaunch/XML/node)\
    \ (which IMHO is a better style anyway):\n\n    <launch> \n      <node pkg=\"\
    nmea_gps_driver\" type=\"nmea_gps_driver.py\" name=\"nmea_gps_launch\">\n    \
    \    <param name=\"port\" type=\"str\" value=\"/dev/ttyUSB0\" />\n        <param\
    \ name=\"baud\" type=\"int\" value=\"9600\" />\n      </node>\n    </launch>\n\
    \nMaybe that makes a difference."
