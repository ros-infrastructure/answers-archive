According to the [ROS C++ style guide](http://wiki.ros.org/CppStyleGuide#Function_.2BAC8_Methods), function names should be `camelCased` (lower-case first letter), not `CamelCased` (capital-case first letter). However, [roslint](http://wiki.ros.org/roslint) doesn't seem to complain about `CamelCased` function names. Is there a property I should manually `set()` for that?

Update: Actually, it doesn't complain even if a function name is `under_scored`
