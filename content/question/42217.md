    You can set up a callback in ROS that synchronizes messages from multiple topics with a TimeSynchronizer: http://www.ros.org/wiki/message_filters#Time_Synchronizer

    As Dan Lazewatsky says in the comments below, if the timestamps aren't identical, then you might be able to use an [ApproximateTimePolicy](http://www.ros.org/wiki/message_filters#ApproximateTime_Policy) with the TimeSynchronizer.
