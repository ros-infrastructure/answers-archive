  body_markdown: "The structure of geometry_msgs/PoseStamped is documented here: http://ros.org/doc/api/geometry_msgs/html/msg/PoseStamped.html\n\
    \nA PoseStamped message in JSON would therefore look as follows:\n\n    { \n \
    \       header: { \n            seq: <int>, \n            stamp:  {\n        \
    \        secs: <int>,\n                nsecs: <int>\n            },\n        \
    \    frame_id: <string>\n        },\n        pose: {\n            position: {\n\
    \                x: <float>,\n                y: <float>,\n                z:\
    \ <float>\n            },\n            orientation: {\n                x: <float>,\n\
    \                y: <float>,\n                z: <float>,\n                w:\
    \ <float>\n            }\n        }\n    }\n\n\nThe entire JSON message that you\
    \ would send to rosbridge to publish the message would be:\n\n    {\n        receiver:\
    \ \"/topic\",\n        type: \"geometry_msgs/PoseStamped\",\n        msg: { ...as\
    \ above... }\n    }\n\nCheers,\nJon\n                "
