  body_markdown: "A common mistake users tends to do is to subdivide the model to\
    \ minimize the shading issue, this is NOT good as it increases the poly count\
    \ of the scene without eliminating the problem!\n\nThe right solution is to tweak\
    \ the shading properties of the mesh; If you have no idea of what shading is please\
    \ read [this little introduction](https://docs.blender.org/manual/en/dev/modeling/meshes/editing/smoothing.html).\n\
    \nYou need Blender installed and the Collada I/O add-on ([this PPA](https://launchpad.net/~thomas-schiex/+archive/ubuntu/blender)\
    \ provides a Blender version with Collada support enabled).\n\nHow to fix a mesh:\n\
    ===\n\n- Import your mesh in blender:\n  `File` > `Import` > `Collada (Default)\
    \ (.dae)`\n- Select the mesh by right clicking on it in the 3D view\n- Switch\
    \ to [edit mode](https://en.wikibooks.org/wiki/Blender_3D:_Noob_to_Pro/Mesh_Edit_Mode#Introduction_to_Edit_Mode)\
    \ (`Tab`):\n- Switch to face selection (`Ctrl`+`Tab`) and select all faces (`A`)\
    \ of the model\n- Set the shading of the faces to `Smooth`:\n\n![shading menu](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/14556579374283995.png)\n\
    \n- Exit the edit mode (`Tab`)\n- Add an `EdgeSplit` modifier:\n\n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/14556580727324997.png)\n\
    \n- Tweak the split angle value: lower values means less smoothing but less artifacts,\
    \ large values (> 40\xB0) will probably create artifacts!\n- Apply the modifier\
    \ when the result satisfies you\n- Export the new Collada file\n\nResult after\
    \ the smoothing:\n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/1455658121844474.png)\n\
    \nPython script\n===\nYou can use this Python script to do the job for you;\n\
    The script only modifies the selected objects.\nAfter that you need to individually\
    \ tweak the split angle value and apply the modifier on each mesh.\n\n    import\
    \ bpy\n    import re\n    \n    # Applies only on selected objects\n    if len(bpy.context.selected_objects)\
    \ > 0:\n        for obj in bpy.context.selected_objects:\n            if obj.type\
    \ == 'MESH':\n                bpy.context.scene.objects.active = obj\n       \
    \         bpy.ops.object.editmode_toggle()\n                bpy.ops.mesh.select_all(action='SELECT')\n\
    \                bpy.ops.mesh.remove_doubles()\n                bpy.ops.mesh.faces_shade_smooth()\n\
    \                bpy.ops.object.editmode_toggle()\n                bpy.ops.object.modifier_add(type='EDGE_SPLIT')\n\
    \    \n    # Don't forget to tweak the split angle!\n\nOnce you are done tweaking\
    \ the split angle values, select all your meshes again and use this script to\
    \ apply the `EdgeSplit` modifier:\n\n    import bpy\n    import re\n    \n   \
    \ # Apply the EdgeSplit modifier on selected objects\n    if len(bpy.context.selected_objects)\
    \ > 0:\n        for obj in bpy.context.selected_objects:\n            if obj.type\
    \ == 'MESH':\n                bpy.context.scene.objects.active = obj\n       \
    \         bpy.ops.object.modifier_apply(apply_as='DATA', modifier=\"EdgeSplit\"\
    )\n\nNote that in case something didn't go well, you can easily revert the changes\
    \ with a `Remove doubles` in edit mode and switching back to flat shading."
