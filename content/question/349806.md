    > I have updated the wiki [..]. However, the changes on wiki are not reflecting on robot page

    The wiki and `robots.ros.org` do not share a common backend.

    You'll want to submit a PR to [ros-infrastructure/robots.ros.org](https://github.com/ros-infrastructure/robots.ros.org) instead.

    See also the note at the top of the page on `robots.ros.org`:

    > This is a site to showcase robots using ROS. You can browse all, by [tag](https://robots.ros.org/tags) or [category](https://robots.ros.org/categories) as well as search. If there's a robot you want to see here please [contribute](https://robots.ros.org/contributing) via [a pull request on github](https://github.com/ros-infrastructure/robots.ros.org).
