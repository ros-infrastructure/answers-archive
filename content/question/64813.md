  body_markdown: "If you subscribe to a new topic using the same callback and store\
    \ the result in the same [Subscriber object](http://ros.org/doc/groovy/api/roscpp/html/classros_1_1Subscriber.html#details),\
    \ storing that new value in the original variable should unsubscribe the other\
    \ topic.\n\n**EXAMPLE**: *untested, probably buggy*\n\n    class Reader\n    {\n\
    \    public:\n      Reader(ros::NodeHandle node)\n      {\n        node_ = node;\n\
    \        // subscribe to original topic\n        topic_ = node.subscribe(\"first_topic\"\
    , 10,\n                                &Reader::callback, (Reader *) this);\n\
    \      }\n    \n    private:\n      void callback(const std_msgs::String::ConstPtr\
    \ &msg)\n      {\n        if (msg->data == \"switch\")\n          {\n        \
    \    // subscribe to other topic\n            topic_ = node_.subscribe(\"next_topic\"\
    , 10,\n                                     &Reader::callback, (Reader *) this);\n\
    \          }\n        else\n          {\n            // log message from current\
    \ topic\n            ROS_INFO_STREAM(msg->data);\n          }\n      }\n    \n\
    \      // class variables\n      ros::NodeHandle node_;\n      ros::Subscriber\
    \ topic_;           // current topic subscription\n    };\n\n    int main(int\
    \ argc, char **argv)\n    {\n      ros::init(argc, argv, \"your_node\");\n   \
    \   ros::NodeHandle node;\n      Reader read(node);\n      ros::spin();\n    \
    \  return 0;\n    }\n\n\n"
