  body_markdown: "I could get rid of this error by installing boost library version\
    \ : 1.46.1\n\nSome more details: I was following the instructions from the link\
    \ below to install ROS (fuerte) on a arm processor having debian distribution.\n\
    \ \nhttp://www.ros.org/wiki/fuerte/Installation/Debian\n\n\nAt the following step\
    \ :\n$sudo apt-get libboost-all-dev \n\nIt installs version 1.49.0 which caused\
    \ all the troubles.\n\nSolution: \n$sudo apt-get install libboost1.46-all-dev\n\
    \n\n\nNote: If you have already installed ROS and some packages, you cannot just\
    \ uninstall 1.49.0 and install 1.46.1. Unfortunately ros binaries were linked\
    \ to 1.49.0 and it complained for missing libraries.  "
