      For al0ne, you've probably already solved your problem so I doubt you will need this, but it generally involves:

       1. Having a set of variables representing your data (in KUKA's example, they have [arrays for position, velocity, and effort for each joints](https://github.com/CentroEPiaggio/kuka-lwr/blob/260651c94c93c26d2749f604ee5454055e2bd084/lwr_hw/src/lwr_hw.cpp#L25-L28)) (these, you should update constantly through your robot hw's read/write methods)
       2. Assigning these variables to a corresponding resource handle (note in KUKA's, this is done in a loop [for each joint j](https://github.com/CentroEPiaggio/kuka-lwr/blob/260651c94c93c26d2749f604ee5454055e2bd084/lwr_hw/src/lwr_hw.cpp#L139-L140))
       3. Registering the handle(s) to the interface in your robot hw (for joint states in KUKA, step 2 and 3 have been inlined)
