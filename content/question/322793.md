Hello everybody.

I am working on a project where i have 2 USB devices connected to my pc. The manufacturer provided the ros nodes to make a connection with the devices.

Now, the problem is:
When i start both nodes in a launch file, one of them fails and gives me this message:

> serial.serialutil.SerialException:
> device reports readiness to read but
> returned no data (device disconnected
> or multiple access on port?)

I already found a way to fix this: i have to start node 1, wait for it to start up, which takes about 2 or 3 seconds, then start the second node.
Now i've looked around and noticed there is not really a standard way to add a 'delay' or a 'sleep' in a launch file.
I came across this question: https://answers.ros.org/question/233353/set-delay-between-starting-nodes-within-launch-file/
Here they made a workaround for this issue, but this is from 3 years ago.

I wonder there is a better/cleaner way to do this three years after that solution.

So i'm looking for this:

> <node name="node1" type="node1"
> pkg="pkg1" /> 
> 
> delay of 3 seconds
> 
>  <node name="node2" type="node2"
> pkg="pkg2" />

Note: node 1 is in c++ and node 2 in python, don't know if this will make a difference.
