  body_markdown: "You need to add the path of the jar file in manifest.xml in the\
    \ rosjava_pathelement tag. And you also need to add the path in ros.properties\
    \ to the classpath and jarfileset properties. Take care to use the right delimiter\
    \ (, vs :). \n\nEdit:\nSo my procedure to include external (i.e. non-ros) jar\
    \ files now is:\n\n - Create a package, e.g., \"external_jar\", create subfolder,\
    \ put jar-files there\n - Add a rosjava_pathelement tag with the relative path\
    \ to each jar file to external_jar's manifest.xml (see other rosjava manifest.xml\
    \ files for exact syntax)\n - Declare dependency on external_jar in manifest of\
    \ the package where the jar-files are needed.\n - Rosmake your package"
