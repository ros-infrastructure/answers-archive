  body_markdown: "Hello, I am new to ROS and Ubuntu and recently I was also struggling\
    \ to make the camera work for turtlebot3 waffle_pi. \nFor me, I followed this\
    \ route and now the camera is working fine in SLAM, the topics are available and\
    \ rqt_image_view also shows the live feed from the camera. \n\nI am using Ubuntu\
    \ 20.04 with ROS-noetic with a Turtlebot3 waffle_pi robot hosting a Raspberry\
    \ Pi 4 2GB SBC.\n\nThe issue here is that the raspicam_node for noetic is difficult\
    \ to set up as most methods require deleting the previous catkin_ws and building\
    \ a new one. However, I followed the last method in this [link text](http://github.com/UbiquityRobotics/raspicam_node/issues/112).\
    \ I will sum it up for you:\n\nFirst of all, make sure the camera is working using\
    \ the raspistill command and the peripherals for the camera are enabled in raspi-config.\n\
    \nTest it as:\n\n    raspistill -v -o test.jpg\n\n Clone the package from github\
    \ in your catkin_ws/src folder:\n\n     cd catkin_ws/src\n    \n    git clone\
    \ https://github.com/UbiquityRobotics/raspicam_node\n\nInstall the libraries:\n\
    \n    sudo apt install libraspberrypi-dev libraspberrypi0 libpigpiod-if-dev\n\n\
    Install some packages:\n\n    sudo apt install ros-noetic-compressed-image-transport\
    \ ros-noetic-camera-info-manager ros-noetic-diagnostic-updater\n\nAfterward, compile\
    \ the catkin_ws and source:\n\n    cd ..\n    \n    catkin_make\n    \n    source\
    \ devel/setup.bash\n\nThe next thing is running two launch files at the same time\
    \ to visualize the camera input in SLAM.\n\nFirst, run a roscore on the remote-PC:\n\
    \n    roscore\n\nOpen a secure shell with a robot and launch raspicam_node:\n\n\
    \    roslaunch raspicam_node camerav2_1280x960.launch\n\nOpen another secure shell\
    \ and bring up the robot:\n\n    roslaunch turtlebot3_bringup turtlebot3_robot.launch\n\
    \nNow in the remote PC:\n\n    roslaunch turtlebot3_slam turtlebot3_slam.launch\n\
    \nIn the new terminal window:\n\n    rqt_image_view\n\nThe image from the camera\
    \ would be visible in both Rviz (where SLAM is running) and the rqt_image_view\
    \ window. \nAlso, if you do 'rostopic list' in remote-PC, you would be able to\
    \ see the camera-related topic published by raspicam_node.\n\nThis method worked\
    \ for me. I apologize for any typos or inconvenience.\n\nThank you,\n\nMuhammad\
    \ Umar Farooq"
