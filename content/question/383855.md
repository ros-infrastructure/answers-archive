 I am using a launch file, in which i launch a rosbag record node. As an argument, I want to pass the directory in which the bag file should be saved. 

    <node pkg="rosbag" name="record" type="record" args="-o 'directory'"/>

The directory should be either located on the local hard drive of the computer, or on an external hard drive, if one is plugged in. I already wrote a bash script to check if a external hard drive is available and return the appropriate path.
Until now I did not find a way to pass the output of this script to a node tag reference of the launch file as argument. Is there any way you can e.g. first pass the output of the script to a arg tag reference, which can then be used in the node tag reference? Like

    <arg name =path default="return_value_of_bash_script"/>    
    <node pkg="rosbag" name="record" type="record" args="-o $(arg path)"/>

I know, that you can pass the output of a script to a param tag reference, but I did not find a way to do so with arg tag reference or a way to pass the value of a param tag reference to an arg tag reference.
