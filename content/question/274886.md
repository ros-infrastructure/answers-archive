  body_markdown: "This is roughly what it looks like to adapt the roscpp talker to\
    \ use a diagnosed updater and diagnosed publisher.\n\nI haven't tested that this\
    \ compiles, but it should be pretty close.\n\n    #include <ros/ros.h>\n    #include\
    \ <std_msgs/String.h>\n    \n    #include <diagnostic_updater/diagnostic_updater.h>\n\
    \    #include <diagnostic_updater/publisher.h>\n    \n    #include <sstream>\n\
    \    \n    int main(int argc, char **argv)\n    {\n      ros::init(argc, argv,\
    \ \"talker\");\n    \n      ros::NodeHandle n;\n    \n      // The Updater class\
    \ advertises to /diagnostics, and has a\n      // ~diagnostic_period parameter\
    \ that says how often the diagnostics\n      // should be published.\n      diagnostic_updater::Updater\
    \ updater;\n    \n      double desired_freq = 10.0; // desired publish frequency\n\
    \      double min_freq = 9.0; // minimum frequency before error\n      double\
    \ max_freq = 11.0; // maximum frequency before error\n      double freq_tolerance\
    \ = 0.1; // Tolerance before stating error on publish frequency, fractional percent\
    \ of desired frequencies.\n      int window_size = 100; // Number of samples to\
    \ consider in frequency\n      double min_acceptable = 0.05; // The minimum publishing\
    \ delay (in seconds) before publish times.\n      double max_acceptable = 0.15;\
    \ // Maximum delay between message publish times\n      diagnostic_updater::DiagnosedPublisher<std_msgs::String>\
    \ chatter_pub(n.advertise<std_msgs::String>(\"chatter\", 1000),\n            \
    \       updater,\n                   diagnostic_updater::FrequencyStatusParam(&min_freq_,\
    \ &max_freq_, freq_tolerance, window_size),\n                   diagnostic_updater::TimeStampStatusParam(min_acceptable,\
    \ max_acceptable)));\n    \n      ros::Rate loop_rate(desired_freq);\n    \n \
    \     int count = 0;\n      while (ros::ok())\n      {\n        std_msgs::String\
    \ msg;\n    \n        std::stringstream ss;\n        ss << \"hello world \" <<\
    \ count;\n        msg.data = ss.str();\n    \n        ROS_INFO(\"%s\", msg.data.c_str());\n\
    \    \n        chatter_pub.publish(msg);\n    \n        ros::spinOnce();\n   \
    \ \n        loop_rate.sleep();\n        ++count;\n      }\n      return 0;\n \
    \   }\n\nThe CMakeLists.txt to build this node in the beginner_tutorials package\
    \ should be:\n\n    cmake_minimum_required(VERSION 2.8.3)\n    project(beginner_tutorials)\n\
    \    \n    ## Find catkin and any catkin packages\n    find_package(catkin REQUIRED\
    \ COMPONENTS roscpp diagnostic_updater std_msgs)\n    \n    ## Declare a catkin\
    \ package\n    catkin_package()\n    \n    add_executable(talker src/talker.cpp)\n\
    \    target_link_libraries(talker ${catkin_LIBRARIES})"
