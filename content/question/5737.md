  body_markdown: "The easiest way is to create a box in SDF, and give it an angle.\
    \ For example:\n\n    <?xml version=\"1.0\" ?>\n    <sdf version=\"1.4\">\n  \
    \    <world name=\"default\">\n        <include>\n          <uri>model://ground_plane</uri>\n\
    \        </include>\n        <include>\n          <uri>model://sun</uri>\n   \
    \     </include>\n        <model name=\"box\">\n          <static>true</static>\n\
    \    \n          <pose>0 0 0.2 0 0.4 0</pose>\n          <link name=\"link\">\n\
    \            <collision name=\"collision\">\n              <geometry>\n      \
    \          <box>\n                  <size>1 0.5 .1</size>\n                </box>\n\
    \              </geometry>\n            </collision>\n            <visual name=\"\
    visual\">\n              <geometry>\n                <box>\n                 \
    \ <size>1 0.5 .1</size>\n                </box>\n              </geometry>\n \
    \           </visual>\n          </link>\n        </model>\n      </world>\n \
    \   </sdf>\n\n"
