  body_markdown: |-
    Janindu is right, rviz is just meant to visualize, not save results, even if it computes the transformations for the visualization.

    You should look for the topic which you use to visualize the data in rviz. As janindu says, you can store this data in ros bags, or just pipe them to a text file with `rostopic echo /yourtopic > yourfile`

    If it is about transformations (e.g. poses of the markers), check out the [tf command line tools](http://wiki.ros.org/tf#Command-line_Tools).

    Your question is quite similar to what I am working on right now. I also need to store some data in rviz into a file. So here is what I'll do:

    Those positions and orientations in the display panel in your [screenshot](http://answers.ros.org/upfiles/14676524199348754.png) are just child classes of [rviz::Property](http://docs.ros.org/jade/api/rviz/html/c++/classrviz_1_1Property.html).
    So a bit of a roundabout way is to create a simple panel similar to this [tutorial](http://wiki.ros.org/rviz/Tutorials/Plugins%3A%20New%20Dockable%20Panel) with a single 'save' button. And use [rviz::YamlConfigWriter](http://docs.ros.org/jade/api/rviz/html/c++/classrviz_1_1YamlConfigWriter.html) class to save it as a YAML file.

    You'll have to dive into the rviz documentations a bit though.
