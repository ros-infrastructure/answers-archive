    You can write a [world plugin](http://gazebosim.org/tutorials?tut=plugins_world&cat=write_plugin). On that example, `_parent` is a pointer to [physics::World](http://gazebosim.org/api/dev/classgazebo_1_1physics_1_1World.html). So you can use `_parent->GetModel("modelname")`, if it returns null there is no model with that name in the world.
