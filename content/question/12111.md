  body_markdown: "Gazebo uses a different message passing protocol than ROS. Currently,\
    \ Gazebo uses a combination of boost::asio and protobufs. ROS currently uses custom\
    \ messages and a custom transport library.\n\nSo, Gazebo is not compatible with\
    \ ros comm, unless you write a ros node to translate messages from gazebo to ros. "
