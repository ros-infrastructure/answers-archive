    You can listen `/move_base/status` for the status of the current goal. [Here](http://wiki.ros.org/move_base#Action_API) is the related document. You can go on with your second goal only if the first one is successful, for example.

    Moreover, if you want to try a systematic approach you can use [smach](http://wiki.ros.org/smach) to create a state machine with states and transitions etc.
