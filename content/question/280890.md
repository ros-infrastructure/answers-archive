  body_markdown: "Typically, those things somehow have to do with the permissions.\n\
    \nTo [quote the docs](http://docs.ros.org/jade/api/robot_upstart/html/install.html#permissions):\n\
    \n> It\u2019s important to understand how\n> permissions work robot_upstart:\n\
    \n> 1.The upstart job invokes its jobname-start bash script as root.\n\n> 2.The\
    \ script sets up environment variables, and then uses setuidgid to\n> execute\
    \ roslaunch as an unprivileged\n> user. This is by default the user who\n> ran\
    \ the install script, but it can\n> also be specified explicitly via a\n> flag.\n\
    \n> 3.The roslaunch which executes does not have its user\u2019s group memberships.\n\
    > This means that it will not have\n> access to serial ports with the\n> dialout\
    \ group, or locations in\n> /var/log owned by root, etc. Any\n> filesystem resources\
    \ needed by your\n> ROS nodes should be chowned to the\n> same unprivileged user\
    \ which will run\n> ROS, or should set to world\n> readable/writeable, for example\
    \ using\n> udev.\n\n"
