    \nYou write:\n\n> My message is called util.msg, it is in a file called msg within\
    \ the package file called explore [..]\n\nThere are a few discrepancies here:\n\
    \n - according to your build script, the package is actually called `explore_lite`,\
    \ not `explore`\n - the compiler output suggests it's in a directory called `m-explore`\
    \ (or the package is actually called `m-explore`)\n\nAs to why the include fails:\
    \ message header `#include` lines follow the pattern: `pkg_that_hosts_the_msg/MsgHeader.h`.\n\
    \nIn your care this should probably be `explore_lite/util.h`, not `msg/util.h`.\n\
    \nTwo additional comments:\n\n 1. it might be good to store messages in a separate\
    \ package (it will make interfacing with your package much easier, as I don't\
    \ have to build your node in order to use the messages)\n 1. try to follow [ROS\
    \ naming guidelines](http://wiki.ros.org/Names): `util` as a name does not convey\
    \ much semantics and message (file)names should start with an uppercase character"
