  body_markdown: "We see this:\n\n>     void dijkstra(const nav_msgs::OccupancyGrid&\
    \ map)\n    {\n      ...\n\n>       ros::NodeHandle n(\"~\");\n      ros::Publisher\
    \ pose_array_pub = n.advertise<geometry_msgs::PoseArray>(\"/poseArray\", 1);\n\
    \      pose_array_pub.publish(poseArray);\n    }\n\n*Never* create `NodeHandle`s,\
    \ `ros::Publisher` or `ros::Subscriber`s in the body of callbacks or in short-lived\
    \ functions.\n\nIt will not work.\n\nAlso *never* call `publish(..)` immediately\
    \ after constructing a `ros::Publisher`. There is no time for `Subscriber`s to\
    \ actually subscribe, so no one receives your message.\n\nCreate them in your\
    \ `main(..)` and pass them to your callback. Or create them as global variables\
    \ or create a class and store them as members.\n\nThen if you're only publishing\
    \ the message once, make sure there are subscribers. You can use [ros::Publisher::getNumSubscribers()](http://docs.ros.org/api/roscpp/html/classros_1_1Publisher.html#af5574532bf8a9b35efa3696a035d31fc)\
    \ for this. But if only publishing once *and* it's important your message always\
    \ arrives, then I would suggest to use a service instead of a topic.\n\n---\n\n\
    Edit:\n\n> Okay, yes. I made a publisher in mainand then I declared a global poseArray\
    \ and then published it in a loop something like this - \n\n>     while(ros::ok())\n\
    \    {\n      pose_array_pub.publish(pa);\n    }\n\nI would strongly recommend\
    \ you do not do this. For two reasons (at least):\n\n 1. you're not publishing\
    \ many, many old messages as `pa` is not updated before `publish(..)` is called\n\
    \ 1. if this is the exact code you used: you're publishing at the maximum rate\
    \ at which your PC can publish (which for a typical PC is upwards of 10kHz)\n\n\
    What I was actually suggesting was something like this:\n\n    #include <ros/ros.h>\n\
    \    \n    ...\n    \n    ros::Publisher pub;   // note: in global scope here\n\
    \    \n    ...\n    \n    void dijkstra(const nav_msgs::OccupancyGrid& map)\n\
    \    {\n      ...\n    \n      // use variable in global scope\n      pub.publish(poseArray);\n\
    \    }\n    \n    \n    int main(int argc, char **argv)\n    {\n      ros::init(argc,\
    \ argv, \"dijkstra\");\n      ros::NodeHandle n(\"~\");\n      ...\n\n      //\
    \ initialise variable in global scope\n      pub = n.advertise<geometry_msgs::PoseArray>(\"\
    /poseArray\", 1);\n\n      ...\n      ros::spin();\n    }"
