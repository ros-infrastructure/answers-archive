    I am assuming you mean the transfrom between the velodyne and the base_link (vehicle coordinates). You can use the GUI (roslaunch runtime_manager runtime_manager.launch) to set the ros parameters that NDT mappings uses for the transform between the sensor and base_link.![autoware gui, transform is highlighted in orange](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/1597696233634511.png).

    or you can just set the [rosparams](http://wiki.ros.org/rosparam) in a terminal using "rosparam set param_name value".
    The parameter names are: tf_x ,tf_y, tf_z, tf_yaw, tf_pitch, tf_roll. These could be set in a launch file also.
