  body_markdown: "I think this tutorial covers what you would like to do: \n\n - http://www.ros.org/wiki/rospy_tutorials/Tutorials/Makefile#Installing_scripts_and_exporting_modules\n\
    \n**summary:**\n \n**1.** Create setup.py in your package root directory with\
    \ these contents (where `<python_mod>` is replaced by the name of your python\
    \ module, typically the same name as your catkin package)\n\n    ## ! DO NOT MANUALLY\
    \ INVOKE THIS setup.py, USE CATKIN INSTEAD\n    \n    from distutils.core import\
    \ setup\n    from catkin_pkg.python_setup import generate_distutils_setup\n  \
    \  \n    # fetch values from package.xml\n    setup_args = generate_distutils_setup(\n\
    \        packages=['<python_mod>'],\n        package_dir={'': 'src'},\n      \
    \  requires=['std_msgs', 'rospy'])\n    )\n    \n    setup(**setup_args)\n\n\n\
    **2.** Add the following line to your CMakeLists.txt\n\n    catkin_python_setup()\n\
    \n\n**3.** Create a directory for your python scripts (if you have any python\
    \ executables)\n\n    mkdir <pkg_root>/scripts\n\n**4.** Create a directory for\
    \ your python modules\n\n    mkdir <pkg_root>/src/<python_mod>/\n\n**5.** Add\
    \ an empty `__init__.py` to your python module directory\n\n    touch <pkg_root>/src/<python_mod>/__init__.py\n\
    \n**6.** create your python mod\n\n    touch <pkg_root>/src/<python_mod>/mod1.py\n\
    \n\n**You should now be able to import this module as**\n\n   `import python_mod.mod1`\n\
    \n----------\n\nHope that helps! \n\nReference the [tutorial](http://www.ros.org/wiki/rospy_tutorials/Tutorials/Makefile#Installing_scripts_and_exporting_modules)\
    \ for details.\n"
