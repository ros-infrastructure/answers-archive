  body_markdown: "For anyone who stumbles upon this in the future, now there is a\
    \ function available in the tf_transformations library called euler_from_quaternion\
    \ in ROS2 Humble and above.\n\nYou can use it by importing it first `from tf_transformations\
    \ import euler_from_quaternion`\n\nThen convert the quaternion to roll, pitch,\
    \ yaw by\n\n`orientation_list = [orientation_q.x, orientation_q.y, orientation_q.z,\
    \ orientation_q.w]`\n        \n`(roll, pitch, yaw) = euler_from_quaternion(orientation_list)`\n\
    \       \n `self.pose_yaw = yaw`\n"
