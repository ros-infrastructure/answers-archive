  body_markdown: "I am not sure whether its possible to do it using `RVIZ` (I might\
    \ be wrong) but you can use [actionlib](http://wiki.ros.org/actionlib) to send\
    \ multiple goals. Example Code:\n\n    typedef actionlib::SimpleActionClient<move_base_msgs::MoveBaseAction>\
    \ MoveBaseClient;\n    \n    // tell the action client that we want to spin a\
    \ thread by default\n    MoveBaseClient ac(\"move_base\",true);\n    \n    std::vector<move_base_msgs::MoveBaseGoal>\
    \ plan;\n    \n    // Add multiple goals to plan of the type move_base_msgs::MoveBaseGoal\n\
    \    // Then, send it one by one:\n    \n    for (int i = 0;i<plan.size();i++){\n\
    \    \t\tac.sendGoal(plan[i]); // Current Goal\n    \t\tac.waitForResult();\n\
    \    \n    \t\tif(ac.getState() == actionlib::SimpleClientGoalState::SUCCEEDED)\n\
    \    \t\t\tROS_INFO(\"Reached Goal successfully!\");\n    \t\telse\n    \t\t\t\
    ROS_INFO(\"Failed!\");\n        }\n\nHope it helps."
