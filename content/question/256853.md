    There are dozens of simulated robot packages for Kinetic. I strongly discourage you from using Indigo -or any other version older than Kinetic- since versions before Kinetic have become extremely difficult for the maintenance. I agree that there isn't any built-in robot installed via `sudo apt-get install ros-kinetic-desktop-full`, if that is  what you are referring as *built-in*. However, you can always use:

     -  [hector-quadrotor](https://github.com/tu-darmstadt-ros-pkg/hector_quadrotor) as a Kinetic-compliant simulated UAV.

     -   [katana arm](https://github.com/uos/katana_driver) as a Kinetic-compliant manipulator.
     -   [Clearpath Husky](https://github.com/husky/husky) as a ground robot.

    Those are the robots I'm currently using, but there are plenty of [other robots](https://robots.ros.org/). Please check their tutorials and I'm sure most of them have Kinetic support. Despite the question is asked long ago, I find it useful to layout the full list of supported robots for any newcomers.
