      As advised, these two launch files are edited, if using op_global_planner.launch as an example,

      <arg name="mapSource" default="2"/> <!-- Autoware=0, Vector Map Folder=1, kml file=2 -->
      <arg name="mapFileName" default="/home/sws/.autoware/data/map/moriyama_complete_2018.kml" /> <!-- in case of kml map source -->

      By doing this, the previous vector map format .csv is replaceable with .kml.
