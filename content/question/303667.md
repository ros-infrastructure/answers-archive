    **RVIZ** is just visual tool for displaying **ROS** messages, therefore getting data from **RVIZ** means getting data from **ROS** topic. **MATLAB** has support for **ROS** (look [here](https://uk.mathworks.com/hardware-support/robot-operating-system.html)). You should be able to create subscriber (look [here](https://uk.mathworks.com/help/robotics/ref/robotics.subscriber.html)) in **MATLAB** to the given topic and do whatever you want with the data.
