  body_markdown: "If you're looking to integrate your new global planner with `move_base`,\
    \ you should check out the code for [navfn](http://www.ros.org/wiki/navfn) and\
    \ [carrot_planner](http://www.ros.org/wiki/carrot_planner). `carrot_planner` is\
    \ much simpler for a global planner and it would be a really good place to start.\
    \ There's only one source file and it's essentially a straight-line planner. \n\
    \nEssentially, your planner must implement two methods to fit the BaseGlobalPlanner\
    \ interface:\n\n    void initialize(std::string name, costmap_2d::Costmap2DROS*\
    \ costmap_ros);\n    bool makePlan(const geometry_msgs::PoseStamped& start, const\
    \ geometry_msgs::PoseStamped& goal, std::vector<\n      geometry_msgs::PoseStamped>&\
    \ plan);\n\nThe `initialize()` method acts as a replacement for the constructor.\
    \ You should do all of your construction in this method instead of in the actual\
    \ constructor. \n\nThe `makePlan()` method is the one that is called when `move_base`\
    \ asks for a new plan. "
