  body_markdown: "To translate a pose in the same frame of reference just add the\
    \ translation offsets for each axis.  For instance:\n\n    initial_pose = Pose()\n\
    \    initial_pose.position.x = 0\n    initial_pose.position.y = 0\n    initial_pose.position.z\
    \ = 0\n    \n    # translate +5 in x-axis, +2 in y-axis and -10 in z-axis\n  \
    \  initial_pose.position.x += 5\n    initial_pose.position.y += 2\n    initial_pose.position.z\
    \ += -10\n\n\ntf2 is used to transform between multiple coordinate frames, which\
    \ you said isn't what you want to do. So no need to use tf2 here."

  - body_markdown: "The pose of an Rviz markers is defined relative to the coordinate\
      \ frame set during the markers initialization.  \nFor instance here we are creating\
      \ a marker whose pose is relative to the map frame:  \n\n    marker = Marker()\n\
      \    marker.header.frame_id = \"/map\"\n\nTherefore if you offset this marker\
      \ by, say 0.4 in the x-axis, it will appear as offset with respect to the map.\n\

      \ equal to `base_link`. In this case the marker will be published at a fixed\
      \ pose with respect to the robot, and change its position with respect to the\
      \ robot when you add an offset. Is this what you are trying to accomplish?"
