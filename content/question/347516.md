    Semantic of `build_depend` did not change between package format 2 and format 3.

In the [ROS 2 tutorial for writing a simple pub/sub package](https://index.ros.org/doc/ros2/Tutorials/Writing-A-Simple-Cpp-Publisher-And-Subscriber/#add-dependencies), it says to add the following in the package.xml file:

    <exec_depend>rclcpp</exec_depend>
    <exec_depend>std_msgs</exec_depend>

But shouldn't these also have the `build_depend` tag? From my reading of [package format 3](https://www.ros.org/reps/rep-0149.html), it seems like they should also be build dependencies:

> build_depend: Declares a rosdep key or ROS package name that this package requires at build-time.

Aren't rclcpp and std_msgs required at build time?
