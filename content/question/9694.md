  body_markdown: "It turns out the \"P\" matrix in the camera_info message does this\
    \ more or less directly. I was able to do the needed transformation this way:\n\
    \nFrom the camera_info callback\n\n    m_worldToCamera = Eigen::Matrix<double,3,4,Eigen::RowMajor>(\
    \ msg->P.data() );\n\nAnd then later\n    \n    Eigen::Vector3d imgPoint;\n  \
    \  cameraPoint = m_worldToCamera * Eigen::Vector4d( point.x(), point.y(), point.z(),\
    \ 1 );\n\n    Eigen::Vector2d flatPoint;\n    flatPoint.x() = cameraPoint.x()\
    \ / cameraPoint.z();\n    flatPoint.y() = cameraPoint.y() / cameraPoint.z();"
