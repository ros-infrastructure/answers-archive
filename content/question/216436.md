  body_markdown: "I had some fun recently with this.  My solution/understanding turned\
    \ out to be three parts:\n\n- Icons (svg format in my case) need to have their\
    \ internal size at least as large as you are trying to do with the icon. (bizarre\
    \ to me).\n- In rqt_robot_dashboard, where self.max_icon_size is set in setup();\
    \ I think this dictates a \"canvas\" size per button on the dashboard.\n- In e.g.\
    \ nav_view_dash_widget.py, self.setFixedSize can scale the icons.  I ended up\
    \ doing (and then getting distracted by other things):\n\n        # Old version:\n\
    \        #self.setFixedSize(self._icons[0].actualSize(QSize(50, 30)))\n      \
    \  # New version, larger, more absolute:\n        self.setFixedSize(QSize(100,60))\n\
    \        \nCaveat: I'm working with a derived version of rqt_dash for Fetch robots,\
    \ so I've been playing with ever so slightly different code.  Nor have I fully\
    \ wrested control of the rqt_dashboard setup to my liking."
