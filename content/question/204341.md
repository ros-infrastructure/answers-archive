  body_markdown: "I just tried it myself with my robot. One thing you need are groups\
    \ in launchfiles.\n\nhttp://wiki.ros.org/roslaunch/XML/group\n\nBTW. **If you\
    \ use robot namespace tags in your model plugins, remove them!**\n\nOtherwise\
    \ your topics like for example cmd_vel will overlap.\n\nYou also need another\
    \ parameter with a different name for the other robot because I found out they\
    \ are named like the param in gazebo.\n\nPut the same launch tags (except the\
    \ parameter for the spawn and spawn position) for your robots in two tags, \n\
    \ \nFor example:\n\n    <node name=\"spawn_test_bot\" pkg=\"gazebo_ros\" type=\"\
    spawn_model\" args=\"-z 0.1 -urdf -param robot_description -model robot_description\"\
    \ respawn=\"false\" />\n  \t\n     <node name=\"spawn_test_bot\" pkg=\"gazebo_ros\"\
    \ type=\"spawn_model\" args=\"-z 0.1 -x 1 -urdf -param robot_description2 -model\
    \ robot_description2\" respawn=\"false\" />\n  \t\n\nThat seems to work for me,\
    \ but currently I just need one robot.\n\n\n\t  \t"
