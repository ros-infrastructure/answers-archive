Hello guys,

I would like to know whether I am doing something wrong or this is a common issue. I am using the **lms1xx** driver which I installed in my pc along with the **husky** pkgs. When I try to launch the .launch file I get this msg:

    ERROR: cannot launch node of type [lms1xx/LMS1xx_node]: can`t locate node [LMS1xx_node] in package [lms1xx]


I actually overcame this issue by cloning from github the driver in my catkin_ws and building it again in my work space.
After a little investigation I think that the source of the problem is the *static* object file `libLMS1xx.a` that is created by the apt-installed lms1xx pkg in the `/opt/ros/kinetic/lib` folder which is somehow unable to link the `LMS1xx_node` exec.
On the other hand, in `~/catkin_ws/devel/lib` the object file is `libLMS1xx.so` (dynamic linkin) so it works just fine.

Why is this happening and could I re-build a package located in `/opt/ros/kinetic/share` in order to create the .so obj file?

Thank you!
