  body_markdown: "TL;DR: In your Github CI, specify a container as following:\n\n\
    \    runs-on: ubuntu-20.04  # or ubuntu-latest or ubuntu-22.04\n    container:\n\
    \      image: ubuntu:focal  # for Foxy or Galactic, and \"ubuntu:jammy\" for Humble\
    \ or Rolling\n\n---\n\nI got stuck on this one, but found out what the issue was.\
    \ In your CI, you run everything directly on the Github's action runner (ubuntu-20.04\
    \ for Galactic, and ubuntu-22.04 for Humble). \n\nNow, Github runners have CMake\
    \ versions later than the system dependency's explicitly installed, and as of\
    \ August 9th 2022, they have upgraded their CMake version to CMake 3.24.0.\n\n\
    You can confirm your CMake Version by adding:\n\n    # Print CMAKE_VERSION\n \
    \   message(STATUS \"CMAKE_VERSION: ${CMAKE_VERSION}\")\n\nto your CMakeLists.txt.\
    \ If you're using the ``ubuntu-latest`` (= ``ubuntu-20.04``) github action runner,\
    \ you'll see it prints:\n\n    CMAKE_VERSION: 3.24.2\n\nCMake 3.24.0 has tweaked\
    \ its export template, so the regular expression in ament_cmake_export_targets-extra.cmake\
    \ no longer match. **This has been fixed** already in [ament_cmake #395]( https://github.com/ament/ament_cmake/pull/395)\
    \ for all active distros, but a release hasn't been made for Galactic yet. Regardless\
    \ of the release being made or not, continue reading to ensure you don't face\
    \ such issues in the future.\n\n[REP2000](https://www.ros.org/reps/rep-2000.html)\
    \ defines that the CMake version used to compile ROS packages are the same as\
    \ the system default - 3.14.3 for Ubuntu 20.04 (Focal) and 3.22.1 for Ubuntu 22.04\
    \ (Jammy). So these are the cmake versions you should be using to build your packages.\n\
    \n**Easiest way of achieving this, is by [running your jobs in a container](https://docs.github.com/en/actions/using-jobs/running-jobs-in-a-container)**\
    \ inside the Github runner, to ensure you don't have other cmake version installed.\
    \ In your Github CI file (ie. ``.github/workflows/main.yml``), instead of having\
    \ just:\n\n    runs-on: ubuntu-20.04   # or ubuntu-latest or ubuntu-22.04\n\n\
    specify a container as following:\n\n    runs-on: ubuntu-20.04   # or ubuntu-latest\
    \ or ubuntu-22.04\n    container:\n      image: ubuntu:focal   # for Foxy or Galactic,\
    \ and \"ubuntu:jammy\" for Humble or Rolling\n\nThis ensures you are building\
    \ your package in a clean ubuntu container, and not on a Github Action runner\
    \ machine with packages explicitly installed."
