    Try this:

        sudo apt-get update
        sudo apt-get install python-catkin-tools

    This has all been documented. In fact, the first Google result for "catkin tools install" is [Installing catkin_tools](http://catkin-tools.readthedocs.io/en/latest/installing.html).

    As @ahendrix added: `catkin_tools` is not installed by default, so you'll have to do that manually.
