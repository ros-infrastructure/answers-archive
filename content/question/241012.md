  body_markdown: "I'm not entirely sure what your question is, but you can use parameters\
    \ in the launch file then read them into the python script. There's a whole page\
    \ on it here: http://wiki.ros.org/rospy/Overview/Parameter%20Server.\n\nIt sounds\
    \ like you have two arguments you want to pass into the python script, which are\
    \ then used in a function, correct?\n\nYou can create a launch file like this\n\
    \n    <launch>\n      <arg name=\"arg1\" doc=\"Argument 1\" default=\"value1\"\
    \ />\n      <arg name=\"arg2\" doc=\"Argument 2\" default=\"value2\" />\n    \
    \  <node name=\"node_name\" pkg=\"pkg\" type=\"type\">\n        <param name=\"\
    ARG1\" value=\"$(arg arg1)\" />\n        <param name=\"ARG2\" value=\"$(arg arg2)\"\
    \ />\n      </node>\n    </launch>\n\nYou can then easily run the launch file\
    \ and include the two arguments on the command line, or they have default values\
    \ coded into the launch file that it can use. \n\nTo run them on the command line\
    \ you would do roslaunch pkg file.launch arg1:=value1 arg2:=value2\n\nThen you\
    \ simply have to read in the parameters using the rospy.get_param('ARG#') as seen\
    \ in the link.\n\nHope this helps!"
