  body_markdown: "> Normally i source my environment with \"source /devel/setup.bash\"\
    \ but i noticed in the tutorial that there is a period before the file location\
    \ \"source ./devel/setup.bash\" Why is that period there?\n\nA `.` (dot) in a\
    \ path refers to the \"current directory\". \n\nIt makes whatever path comes after\
    \ the dot relative to the current directory.\n\nSo `source ./devel/setup.bash`\
    \ `source`s the file `setup.bash` in a directory called `devel` that *must* be\
    \ in the current directory.\n\nHowever, all paths *not* starting with a `/` are\
    \ relative to the current working directory, so the dot is not actually necessary\
    \ here.\n\n> This is my first post so im not sure where to really ask this question.\n\
    \nIn the end this is not really a ROS question (more a general Linux one), but\
