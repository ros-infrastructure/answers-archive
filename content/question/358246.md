  body_markdown: "I recently had cause to do this.  In my case I needed to send a\
    \ status byte which contained a series of bit flags onto a specific TxPDO cobid\n\
    \nHere is my working method.  External to the method I have the Frame import\n\
    \n    from can_msgs.msg import Frame\n\nand the publisher set to the standard\
    \ outgoing Socketcan topic \"/sent_messages and set the COBID\"\n\n    file_system_status_publisher\
    \ = rospy.Publisher(\"/sent_messages\", Frame, queue_size=1)\n    TxPDO_cobid\
    \ = 0x4a3  # This is the CANOPEN TxPDO4 from a node ID of 35\n\nIn my application\
    \ I send a status packet onto the can bus on events and a slow poll.\nHere is\
    \ the method that handles that transmit\n\n    def send_status():\n\n        #\
    \ Assembles a CAN packet of a single byte that is transmitted on the calculated\
    \ TxCOBID\n        # Included bit flags\n                                # 0.\
    \ 0x01 is USB inserted\n                                # 1. 0x02 are the files\
    \ uploading\n                                # 2. 0x04 have all files uploaded\n\
    \                                # 3. 0x08 is machine ready to perform job\n \
    \   \n        # These globals are technically not required here but are given\
    \ for clarity\n\n        global is_usb_plugged_in\n        global are_files_uploading_now\n\
    \        global have_all_files_uploaded\n        global is_machine_ready_to_perform_job\n\
    \    \n        # Set the bit flags\n\n        flags = 0\n    \n        if is_usb_plugged_in:\n\
    \            flags |= 0x01\n    \n        if are_files_uploading_now:\n      \
    \      flags |= 0x02\n    \n        if have_all_files_uploaded:\n            flags\
    \ |= 0x04\n    \n        if is_machine_ready_to_perform_job:\n            flags\
    \ |= 0x08\n\n        # I am only sending one byte so I set my dlc to 1.  I left\
    \ the other parameters: \n        # header, is_rtr, is_extended, is_error etc\
    \ as default \n\n        file_system_status_message = Frame(id=TxPDO_cobid, dlc=1,\
    \ data=[flags, 0, 0, 0, 0, 0, 0, 0])    \n        file_system_status_publisher.publish(file_system_status_message)\n\
    \n\n\nHere is a candump showing it working:\n\n    xxx@my_computer:~$ candump\
    \ can0 | grep 4A3\n      can0  4A3   [1]  00\n      can0  4A3   [1]  00\n    \
    \  can0  4A3   [1]  03\n      can0  4A3   [1]  05\n      can0  4A3   [1]  05\n\
    \      can0  4A3   [1]  05\n      can0  4A3   [1]  05\n\n\nThis would seem similar\
    \ to your requirements\n\n\n\n\n\n\n"
