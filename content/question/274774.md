  body_markdown: "You should add a joint between a frame on your robot and laser to\
    \ your urdf.\n\n    <!-- need to make a placeholder link for the laser frame -->\n\
    \    <link name=\"laser\" />  \n    <joint name=\"base_to_laser\" type=\"fixed\"\
    >\n        <parent link=\"base_link\"/>\n        <child link=\"laser\"/>\n   \
    \     <origin rpy=\"0 1.57075 0\" xyz=\"0 -0.22 0.25\"/>\n    </joint>\n\nWhere\
    \ instead of the rpy (roll pitch yaw) and xyz above you insert the position of\
    \ the laser relative to base_link.  Or instead of base_link use another frame\
    \ (`lms_link`) already in your urdf that is close to where the laser is mounted.\n\
    \nTo experiment with different transforms live instead of launching and relaunching\
    \ with minor changes to the urdf you can publish a transform from the command\
    \ line (and comment out base_to_laser if it is in the urdf), then lock the values\
    \ that work best into the urdf: http://wiki.ros.org/tf#static_transform_publisher\n\
    \nIf lms_link is already the correct frame and an additional joint isn't needed\
    \ then having sicklms publish the laser_scan relative to that is an easy alternative\
    \ to the above:\n\n    rosrun sicktoolbox_wrapper sicklms _frame_id:=lms_link\n\
    \n(or provide it in a launch file with `<param name=\"frame_id\" value=\"lms_link\"\
    /> within the sicklms node launching xml)"
