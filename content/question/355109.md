  body_markdown: "Hello, I post a new autoanswer because finally I found a solution.\n\
    \n1. In FreeCAD export the model as Collada (.dae).\n2. Copy the file into your\
    \ package, in a folder called \"meshes\".\n3. Create an urdf file with the following\
    \ content:\n\n`<robot name=\"your_robot_name\">\n  <link name=\"base_link\">\n\
    \    <visual>\n      <origin rpy=\"0 0 0\" xyz=\"0 0 0\"/>\n      <geometry>\n\
    \        <mesh filename=\"package://your_package/meshes/model.dae\"/>\n      </geometry>\n\
    \    </visual>\n  </link>`\n\n(I don\xB4t know why the format of the code is wrong)\n\
    \n4. Launch the urdf file with robot_state_publisher package as normal.\n\nWith\
    \ this I can use my model of FreeCAD to see it in rviz, without create a complex\
    \ urdf file.\n\nBest regards.\nAlessandro\n\n"
