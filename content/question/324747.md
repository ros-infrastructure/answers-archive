  body_markdown: "This is certainly possible, I've built code to do this in a few\
    \ different ways. The first thing you need to decide upon is exactly how you want\
    \ to convert the point-cloud data into the grid_map. Digital elevation maps are\
    \ very different to point clouds and a lot of information will get thrown away\
    \ in the conversion.\n\nSince it's likely many points from the point-cloud will\
    \ fall within a since cell of the grid_map, you need to decide how to handle this.\
    \ You also need to decide how to deal with grid_map cell which do not contain\
    \ any points. We've found using three grid_map channels (minimum, maximum and\
    \ elevation range) as well as the basic elevation is quite useful. You can then\
    \ set the elevation channel to either the minimum or maximum depending on your\
    \ application.\n\nThat's the theory though. Firstly you'll want to add your layers\
    \ using the [add method](http://docs.ros.org/jade/api/grid_map_core/html/classgrid__map_1_1GridMap.html#a6977b45d2ddec69cd459b1994fd892d3)\
    \ as below:\n\n    myGridMap.add(\"minimum\");\n    myGridMap.add(\"maximum\"\
    );\n    myGridMap.add(\"range\");\n\nThen you'll want to loop through each point\
    \ in the cloud and add it to the grid_map. For this you'll use the [atPosition](http://docs.ros.org/jade/api/grid_map_core/html/classgrid__map_1_1GridMap.html#ac3636ac41b34c61d212fbc9e13f52ca2)\
    \ method. This method takes a layer name string and a 2D position vector, this\
    \ vector is in units of metres and uses the centre of the map as the origin. What\
    \ is not immediately obvious is that atPosition method returns a reference to\
    \ a float, so you can use it to update the map as well as get its value.\n\nSo\
    \ you'll want to extract just the X and Y elements from a point in your point-cloud,\
    \ check it's within the bounds of the grid_map. Then get the value of the grid_map\
    \ at that location, if it's a NaN then the map is empty at that point so you would\
    \ just update the elevation, min and max to the height of that point, and its\
    \ range to zero. If it's not Nan then you'd have to update the min, max and range\
    \ values appropriately. \n\n    Eigen::Vector2d point2D(point[0], point[1]);\n\
    \    \n    // Need to check point is within grid_map here!\n    \n    if (!std::isfinite(myGridMap.atPosition(\"\
    elevation\", point2D))\n    {\n       myGridMap.atPosition(\"elevation\", point2D)\
    \ = point[2];\n       myGridMap.atPosition(\"minimum\", point2D) = point[2];\n\
    \       myGridMap.atPosition(\"maxmimum\", point2D) = point[2];\n       myGridMap.atPosition(\"\
    range\", point2D) = 0;\n    }\n    else\n    {\n        if (point[2] < myGridMap.atPosition(\"\
    minimum\", point2D))\n        {\n            myGridMap.atPosition(\"minimum\"\
    , point2D) = point[2];\n            myGridMap.atPosition(\"elevation\", point2D)\
    \ = point[2];\n        }\n        if (point[2] > myGridMap.atPosition(\"maximum\"\
    , point2D))\n            myGridMap.atPosition(\"maximum\", point2D) = point[2];\n\
    \    \n        myGridMap.atPosition(\"range\", point2D) = myGridMap.atPosition(\"\
    maximum\", point2D) - myGridMap.atPosition(\"minimum\", point2D);\n    }\n\nThere\
    \ are many ways of accessing and modifying the data within a grid_map, this is\
    \ just one of them but hopefully it gives you an idea how to get started."
