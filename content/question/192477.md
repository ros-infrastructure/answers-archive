    \ won\xB4t work. Read the [link](http://eigen.tuxfamily.org/dox-devel/group__TopicUnalignedArrayAssert.html)\
    \  stated in the error message for some further info. You\xB4ll find quite a few\
    \ other questions regarding this here on ROS Answers , too.\n\nThis issue can\
    \ generally be fixed by modifying source code, but depending on the issue at hand\
    \ this might not be trivial. Luckily, this error only appears on 32bit (x86) systems,\
    \ so a relatively easy solution to get rid of it is switching to a 64bit Ubuntu\
    \ version (not sure about architectures like ARM and others)."
