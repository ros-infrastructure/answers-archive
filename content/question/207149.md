  body_markdown: "In your C++ source code you can make a call to the parameter server,\
    \ where the path to that file is stored. \n\nIn your code, with Node Handle `nh`\
    \ write:\n\n    std::string fpath;\n    nh.getParam(\"~private_param_name\", fpath);\n\
    \nAnd now in your launch file add the line (I believe this is how it works, I've\
    \ never done it this way, you might need to experiment a bit with this):\n\n \
    \   <node ...>\n        <param name=\"private_param_name\" command=\"'$(find your_package)/src/your_text_file.txt'\"\
    \n    </node>\n\nOr if you want to run from the command line\n\n`rosrun your_package_name\
    \ your_executable _private_param_name:=\"path_to_your_package/src/your_text_file.txt\"\
    `"
