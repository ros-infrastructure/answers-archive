  body_markdown: "> The error I get is: 'E: Invalid operation ros-indigo-cmvision'\n\
    \n`apt-get` is telling you that it doesn't understand what you want, as `ros-indigo-cmvision`\
    \ is not an `apt-get` command.\n\nThe correct command would be:\n\n    sudo apt-get\
    \ install ros-indigo-cmvision\n\nnote the `install` there. \n\nBut in this case\
    \ that is not going to work either, as [cmvision](http://wiki.ros.org/cmvision)\
    \ has not been released for anything but ROS Hydro (note the lack of any mention\
    \ of any other ROS release on the wiki page). If you still want to use the package,\
    \ you'll have to build it from sources. See #q252478 for some info on how to do\
    \ that. [kbogert/cmvision/indigo-devel](https://github.com/kbogert/cmvision/tree/indigo-devel)\
    \ appears to be a fork of the original `cmvision` package that has been updated\
    \ to work on ROS Indigo.\n\n\n"
