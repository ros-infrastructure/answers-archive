    >  The publisher is Groovy whist the receiver is Hydro.

    While I don't really see any changes to the `control_msgs` package between groovy and hydro (see [control_msgs/compare/groovy-devel...hydro-devel](https://github.com/ros-controls/control_msgs/compare/groovy-devel...hydro-devel)), it could well be that the MD5 of the individual messages has changed, due to changes to the code generation. That would explain the error you are seeing.

    Try again with a Groovy - Groovy, or Hydro - Hydro combination and see if that resolves your error (I'm betting it will).
