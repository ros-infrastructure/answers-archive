  body_markdown: "You will know if the Pseudo Input has been activated if the circle\
    \ next to the description has a solid dark-blue fill. If the signal if off, then\
    \ the there will be dark-blue outline with a light-blue fill. \n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/15365820338402892.png)\n\
    \nProgrammatically, you would be able to determine this when you send motion commands\
    \ to the robot. If this signal has not been enabled, then the robot will reply\
    \ with a result of ROS_RESULT_NOT_READY and a subcode of ROS_RESULT_NOT_READY_NOT_REMOTE.\
    \ Though, this reply code could also indicate that the mode-selector-switch on\
    \ the pendant has not been rotated fully clockwise into REMOTE mode."
