    There are .deb packages for groovy available that can be installed using

        sudo apt-get install ros-groovy-hector-slam

    Checking svn out and building from source should also work. There are no major changes between fuerte and groovy versions of the system and it should work just the same using both distros (case in point: We've been using it very successfully using groovy at the [RoboCup German Open 2013 a few days ago](http://www.youtube.com/watch?v=PKI378kadp8)).
