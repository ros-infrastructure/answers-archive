  body_markdown: "This is actually a needed feature for the navigation stack. The\
    \ static map was originally only intended for use with the global costmap. Since\
    \ the local map is usually in the odometry frame, if the robot was improperly\
    \ localized, it would still be able to perform collision free local navigation.\
    \ \n\nHowever, as a result, I don't think you can use a static map well in the\
    \ pre-hydro or post-hydro versions of navigation. \n\nI've opened up [an issue\
    \ on github](https://github.com/ros-planning/navigation/issues/197)"
