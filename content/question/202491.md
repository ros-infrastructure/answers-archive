    I think the easiest by far is probably making use of [ros_bridge](http://wiki.ros.org/rosbridge_suite). That will allow you to interact with a ROS node graph using JSON messages. No (direct) ROS dependencies in your C# application, and it would also make it possible to run it on Windows.

    An alternative might be to use an actual ROS *client library* in c# (or any .net language, really). [ros.net](https://github.com/uml-robotics/ROS.NET) appears to be one, although I cannot say anything about how feature complete it is.

    ---

    Edit: for video, people apparently use [mjpeg_server](http://wiki.ros.org/mjpeg_server).
