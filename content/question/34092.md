    \ installApp in the folder of the tutorial. This will create a folder install\
    \ in the build folder. THe correct call to the application is \n\n        ./rosjava_tutorial_pubsub/build/install/rosjava_tutorial_pubsub/bin/rosjava_torial_pubsub\
    \ org.ros.rosjava_tutorial_pubsub.Talker\n\n\nThe same holds for the other tutorials\
    \ and for self generated apps.\n"
