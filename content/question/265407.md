  body_markdown: "The error you quote is basically a [linking error](http://www.cprogramming.com/tutorial/compiler_linker_errors.html),\
    \ meaning the linker can't find the library that provides the binary code for\
    \ a particular symbol you use.\n\nThis is not a ROS problem.\n\nIn this case you're\
    \ not linking against the `rosbag` libraries.\n\nYou'll need to make sure that\
    \ you've added `rosbag` to the `find_package(catkin COMPONENTS ..)` (or a regular\
    \ `find_package(..)`) line in your `CMakeLists.txt`, and that you've added the\
    \ appropriate `target_link_libraries(..)` that links your executable against the\
    \ `rosbag` library.\n\nAs this is all CMake, you'll want to keep the [CMake Documentation](https://cmake.org/documentation)\
    \ at hand.\n\n---\n\nEdit:\n\n> @gvdhoorn I made CMakeLists.txt as you suggested:\
    \ like below:\n\n>     cmake_minimum_required (VERSION 2.6)\n    project (tutorial)\n\
    \    find_package(catkin REQUIRED rosbag)\n    set(SOURCES sampleOne.cpp)\n  \
    \  add_executable(test ${SOURCES})\n    target_link_libraries(test)\n\nTwo things\
    \ here:\n\n 1. if you just need `rosbag`, there is no need for `find_package(catkin\
    \ ..)`, just use `find_package(rosbag REQUIRED)` directly.\n 1. you have a `target_link_libraries(..)`\
    \ in there, but you don't actually link your `test` binary against any libraries.\n\
    \nThe last point is actually why you're still getting errors.\n\n> both source\
    \ code and CMakelists.txt is in a directory named \"cmake_example\".\n\n> Now\
    \ I ran \n\n>     cmake .\n    make\n\nPlease don't use in-source builds with\
    \ CMake.\n\n> which does not product executable named \"test\"\n\n> but if I remove\
    \ first line of source code \n\n>     rosbag::Bag bag;\n\n> it does create executable\
    \ named \"test\", which I can happily execute.\n\nWhich makes sense, as you're\
    \ not actually linking against any of `rosbag`'s libraries.\n\nTry the following:\n\
    \n    cmake_minimum_required(VERSION 2.6)\n    project (tutorial)\n    find_package(rosbag\
    \ REQUIRED)\n    include_directories(${rosbag_INCLUDE_DIRS})\n    add_executable(test\
    \ sampleOne.cpp)\n    target_link_libraries(test ${rosbag_LIBRARIES})\n\nThat\
    \ will probably work."
