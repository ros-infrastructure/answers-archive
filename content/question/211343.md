    I think this should be possible using the available tools within move_group and using them in the appropriate order.

     - Compute a circular cartesian path as
       a vector of poses
     - Compute    corresponding joint space cartesian path using the
       [cartesian path service capability](https://github.com/ros-planning/moveit_ros/blob/jade-devel/move_group/src/default_capabilities/cartesian_path_service_capability.cpp)
     - Send the path off to MoveIt!  to execute

    [It sounds](https://groups.google.com/forum/#!topic/moveit-users/MOoFxy2exT4) like this might be problematic because of missing time parametrization of the trajectory.

    As stated by @paul-jurczak, another option is looking at the [Cartesian Path Planner Plug-In for MoveIt!](http://rosindustrial.org/news/2014/9/5/cartesian-path-planner-plug-in-for-moveit)

    For DRC, we implemented our own pipeline for generating cartesian motion based on a Action request that specifies the rotation center pose and then rotates the given endeffector around it. Relevant pieces of code:

     - [Generate waypoint
       poses](https://github.com/team-vigir/vigir_manipulation_planning/blob/master/vigir_moveit_utils/include/vigir_moveit_utils/constrained_motion_utils.h#L49)
     - [Use of function inside Action
       callback](https://github.com/team-vigir/vigir_manipulation_planning/blob/master/vigir_move_group/src/manipulation_action_capability.cpp#L612)

    This likely is a bit heavyweight if you're just interested in doing  a circular motion, but might serve for inspiration.

  body_markdown: "Just solved this problem for the TIAGo robot and the panda robot.\
    \ \n\nI used ComputeCartesianPath() from the Moveit! API and created waypoints\
    \ using components of the position of the end effector with respect to the centre:\n\
    \n    for( theta in 0 to 90)\n     target_pose.position. y = r*sin(theta)\n  \
    \   target_pose.position. x = r*cos(theta)\n     waypoints.pushback(target_pose)\n\
    \n\nThen call the ComputeCartesianPath() using required syntax!\n"
