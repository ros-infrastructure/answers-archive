    Try following the steps in the [Atlas Control with Python tutorial](http://gazebosim.org/wiki/Tutorials/drcsim/2.2/Atlas_control_over_ROS_topics_with_python)

    Create a ros package with dependencies on atlas_msgs:

    `roscreate-pkg tutorial_atlas_control atlas_msgs`

    Then load the manifest at the start of your python program:

    <pre><code>
    #!/usr/bin/env python
    import roslib; roslib.load_manifest('tutorial_atlas_control')
    import rospy
    import atlas_msgs
    </code></pre>
