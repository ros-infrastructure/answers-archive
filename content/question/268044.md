  body_markdown: "Hello,\n\nWhen you use roslibjs with rosbridge, your website is\
    \ not a node, but it can be seen as a node (it just don't register with the rosmaster,\
    \ so you can't see him with \"rosnode list\"). Rosbridge act as a proxy to use\
    \ ROS functionnalities.\n \nThe easiest way to launch a remote process from your\
    \ website is to use a process management library like [std::system](http://en.cppreference.com/w/cpp/utility/program/system),\
    \ [boost::process](http://www.boost.org/doc/libs/1_64_0/doc/html/boost_process/tutorial.html#boost_process.tutorial.starting_a_process)\
    \ or [POCO](https://pocoproject.org/) ,  there are all available in ROS ([POCO\
    \ need this)](http://answers.ros.org/question/189788/how-can-use-external-library-in-ros/)\n\
    \nFor an example with std::system (will quit the callback only when the process\
    \ finish): \n\n    #include \"ros/ros.h\"\n    #include \"std_msgs/String.h\"\n\
    \    #include <sstream>\n    \n        void callback(std_msgs::String msg){\n\
    \            std::stringstream ss;\n            ss << \"roslaunch \" << msg.data;\n\
    \            std::system(ss.str().c_str());//std::system only accept c_str() a.k.a\
    \ char*\n        }\n        \n        int main(int argc, char** argv){\n     \
    \       ros::init(argc,argv,\"roslaunch_launcher\");\n            ros::NodeHandle\
    \ n;\n            ros::Subscriber sub = n.subscribe(\"/launch\", 1, callback);\n\
    \            ros::spin();\n            return 0;\n        }\n\n\nJust publish\
    \ a string in the form \"< package name > < launch file name >\" and the launch\
    \ file should be called\n\nYou also should be sure to source the correct environment\
    \ BEFORE launch this node, if you try to launch a file from an another workspace\
    \ (not sourced) or you create a package after launching this node, the loaded\
    \ environmnent will not find the launch file.\n\nAnd an example with POCO (with\
    \ a run/kill procedure): \n\n    #include <ros/ros.h>\n    #include <std_msgs/String.h>\n\
    \    #include <std_msgs/Empty.h>\n    #include \"Poco/Process.h\"\n    #include\
    \ <boost/algorithm/string/classification.hpp>\n    #include <boost/algorithm/string/split.hpp>\n\
    \    \n    \n    Poco::ProcessHandle* ph;\n    bool running = false;\n    \n \
    \   void callback_run(std_msgs::String msg){\n    \tif(!running){\n    \t\tstd::vector<std::string>\
    \ args;\n    \t\tboost::split(args, msg.data, boost::is_any_of(\" \") ); //Split\
    \ the msg.data on space and save it to a vector\n    \t\tPoco::ProcessHandle ph_running\
    \ = Poco::Process::launch(\"roslaunch\", args,0,0,0); //launch a new node\n  \
    \  \t\tph = new Poco::ProcessHandle(ph_running); // Copy the processhandler to\
    \ our global variable\n    \t\trunning = true; //Refuse new launch\n    \t\tROS_INFO_STREAM(\"\
    launched : roslaunch\" << msg.data);\n    \t}\n    \telse{\n    \t\tROS_ERROR(\"\
    A process is already running.\");\n    \t}\n    }\n    \n    void callback_kill(std_msgs::Empty\
    \ msg){\n    \tif(running){\n    \t\tPoco::Process::requestTermination(ph->id());\
    \ //send SIGINT\n                Poco::Process::wait(*ph); //Wait for roslaunch\
    \ to kill every node\n    \t\tfree(ph);  \n    \t\trunning = false;  //accept\
    \ a new launch\n    \t\tROS_INFO(\"Killed process\");\n    \t}\n    \telse{\n\
    \    \t\tROS_ERROR(\"No Process are running.\");\n    \t}\n    }\n    \n    \n\
    \    int main(int argc, char** argv){\n    \tros::init(argc, argv, \"node_runner\"\
    );\n    \tros::NodeHandle n;\n    \tros::Subscriber sub_run = n.subscribe(\"/run\"\
    ,100,callback_run);\n    \tros::Subscriber sub_kill = n.subscribe(\"/kill\",100,callback_kill);\n\
    \    \tros::spin();\n    \treturn 0;\n    }\n\n\nThis example subscribe 2 topics\
    \ : /run and /kill. Run will accept a node package a name (example : 'rqt_gui\
    \ rqt_gui') and kill accept a std_msgs/Empty.\n\nThis need a little work, as the\
    \ std::system example will block the subscriber (the function return only when\
    \ the process die)."
