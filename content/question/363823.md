I need to use a library named 'lib" which contains many .so files. 
To use them, in CmakeList.txt I set:

target_link_libraries(
NodeName 
${catkin_LIBRARIES}  

${PROJECT_SOURCE_DIR}/lib/first_file.so 

${PROJECT_SOURCE_DIR}/lib/second_file.so  
 ) 

and it worked.

The problem is that I have so many .so files in the library and it would be nightmare if we list all .so files as above.

I also tried several ways using find_library() or add_library() but all weren't successful.
