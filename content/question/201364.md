  body_markdown: |-
    There's [REP0003 - Target Platforms](http://www.ros.org/reps/rep-0003.html) for answering such questions. As you can see, there is no official support for ROS Fuerte on Ubuntu 14.04. This does not mean that it is completely impossible to run a Fuerte setup on 14.04, but that you'd have to try this yourself (building from source) and likely end up in a world of hurt due to various build issues as libraries changed etc.

    In short, I'd strongly recommend to port your code to ROS Indigo if at all possible as opposed to trying to make Fuerte run on 14.04.
