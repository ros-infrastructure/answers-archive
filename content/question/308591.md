  body_markdown: "Yes, ros_canopen utilizes SocketCAN package and many Kvaser CAN\
    \ interfaces, such as Leaf Light v2, are supported by SocketCAN.\n To install\
    \ SocketCAN drivers for Kvaser hardware:\n\n - Make sure you uninstalled linuxcan\
    \ (CANlib), since Kvaser drivers blacklist SocketCAN modules:\n    - $ cd linuxcan\n\
    \    - $ sudo make uninstall\n\n\n - Find your interface\n    - ip a\n\nNow you\
    \ should see your Kvaser device listed, e.g.    \n    - 3: can0: <NOARP,ECHO>\
    \ mtu 16 qdisc noop state DOWN group default qlen 10\n    link/can\n\nFor the\
    \ rest, I suggest you to consult \nhttps://answers.ros.org/question/250174/how-to-control-maxon-motor-by-using-ros_canopen/"
