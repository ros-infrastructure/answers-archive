  body_markdown: "You apparently only need one set of `${}` per property. So rather\
    \ than trying to double up with \n\n    <xacro:property name=\"filename\" value=\"\
    $(find package)/file.yaml\"/>\n    <xacro:property name=\"dictionary\" value=\"\
    ${load_yaml(${filename})}\"/>\n\nor\n\n`<xacro:property name=\"dictionary\" value=\"\
    ${load_yaml($(find package)/filename.yaml)}\"/>`\n\nlike I tried to do, use two\
    \ different properties, like so:\n\n    <xacro:property name=\"filename\" value=\"\
    $(find package)/file.yaml\"/>\n    <xacro:property name=\"dictionary\" value=\"\
    ${load_yaml(filename)}\"/>\n\nThe filename will be substituted already since it's\
    \ already in curly brackets. You don't need two sets.\n\nThanks to [Robert Haschke]\
    \ for this answer.\n"
