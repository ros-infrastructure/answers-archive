    I agree with [the already accepted answer](http://answers.ros.org/question/266755/install-denso-package-in-ros-kinetic/?answer=266776#post-id-266776). This is a simple Catkin workspace or Git question, may not even ROS so I suggest going through the tutorials.

    Besides that, as of July 20th 2017 the denso package will most likely not compile or run due to the missing upstream dependency. There's [an open pull request for fixing that](https://github.com/start-jsk/denso/pull/82), which you'd be appreciated if you could give a try on by like:

        cd ~/catkin_ws/src/denso    (assuming you've already cloned the repo)
        git remote add ompugao https://github.com/ompugao/denso.git
        git fetch ompugao
        git checkout kinetic-devel
        git rebase ompugao/kinetic-devel

    Then build the package in the same way as suggested.
