    There are some [tutorials](http://docs.ros.org/kinetic/api/rviz_plugin_tutorials/html/) about making your own plugins for RVIZ which will allow you to do all these things. The code for these can be found in [this git repo](https://github.com/ros-visualization/visualization_tutorials).

    You'll need to capture mouse events on the view port to be able to visually select objects and draw routes, but this is all possible. The main things you'll need to know about this will be QT for the interface and OGRE graphics engine that RVIZ uses.

    Hope this points you in the right direction.
