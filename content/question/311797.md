  body_markdown: "Anaconda has probably installed a new version of python and more\
    \ importantly updated the `PYTHONPATH` so that it no longer includes the path\
    \ of the required ROS packages. You should be able to add the necessary path back\
    \ in by adding a line to your `.bashrc` file. \n\nYour `PYTHONPATH` envrionment\
    \ variable should include a path to /opt/ros/<ros_version>/lib/python2.7/dist-packages,\
    \ if it doesn't then this may be the cause of your problem. You can check this\
    \ with the following command:\n\n    printenv PYTHONPATH\n\nIf you add `export\
    \ PYTHONPATH=$PYTHONPATH:/opt/ros/<ros_version>/lib/python2.7/dist-packages` to\
    \ your bashrc file and re-run it then this should hopefully fix your problem."
