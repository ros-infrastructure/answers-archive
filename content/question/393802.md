    You may try to specify a timeout period for `wait_for_server`.
    The following code will display a message if the connection cannot be established after waiting for 2 seconds.

        while move_base_client.wait_for_server(timeout=rospy.Duration(2.0)) === False:
            rospy.loginfo("waiting")
            # other actions
            # ...
