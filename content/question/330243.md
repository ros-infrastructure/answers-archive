    The time source

        rclcpp::TimeSource _ts;


    Is being initialized with `this`

        _ts{this}

    Which is of type `OdomNode *`, but [the only constructor that takes any arguments expects `rclcpp::Node::SharedPtr`](https://github.com/ros2/rclcpp/blob/41a99b64d347ce2ff8d5fd4ed8ebaa5cfbc5117f/rclcpp/include/rclcpp/time_source.hpp#L38).


    However, `rclcpp::Node` already creates a time source and clock. Instead of creating a time source, [use `get_clock()` or `now()` since `OdomNode` inherits from `rclcpp::Node`](https://github.com/ros2/rclcpp/blob/41a99b64d347ce2ff8d5fd4ed8ebaa5cfbc5117f/rclcpp/include/rclcpp/node.hpp#L1064-L1070).
