  body_markdown: "Hi CarolineQ,\n\nthe safety controller for Kobuki also works with\
    \ Turtlebot 2. However, you have to adapt the launch file a bit. This modified\
    \ version of ``kobuki_keyop/safe_keyop.launch`` file should allow you to drive\
    \ your turtlebot around with the safety controller watching over it.\n\n    <!--\n\
    \      Keyop configuration for working with the default Turtlebot launcher (minimal.launch).\
    \ \n     -->\n    <launch>\n      <node pkg=\"nodelet\" type=\"nodelet\" name=\"\
    kobuki_safety_controller\" args=\"load kobuki_safety_controller/SafetyControllerNodelet\
    \ mobile_base_nodelet_manager\">\n        <remap from=\"kobuki_safety_controller/cmd_vel\"\
    \ to=\"cmd_vel_mux/input/safety_controller\"/>\n        <remap from=\"kobuki_safety_controller/events/bumper\"\
    \ to=\"mobile_base/events/bumper\"/>\n        <remap from=\"kobuki_safety_controller/events/cliff\"\
    \ to=\"mobile_base/events/cliff\"/>\n        <remap from=\"kobuki_safety_controller/events/wheel_drop\"\
    \ to=\"mobile_base/events/wheel_drop\"/>\n      </node>\n      \n      <node pkg=\"\
    nodelet\" type=\"nodelet\" name=\"keyop_vel_smoother\" args=\"load yocs_velocity_smoother/VelocitySmootherNodelet\
    \ mobile_base\n    _nodelet_manager\">\n        <rosparam file=\"$(find kobuki_keyop)/param/keyop_smoother.yaml\"\
    \ command=\"load\"/>\n        <remap from=\"keyop_vel_smoother/odometry\" to=\"\
    odom\"/>\n        <remap from=\"keyop_vel_smoother/smooth_cmd_vel\" to=\"cmd_vel_mux/input/teleop\"\
    />\n      </node>\n      \n      <node pkg=\"kobuki_keyop\" type=\"keyop\" name=\"\
    keyop\" output=\"screen\">\n        <remap from=\"keyop/motor_power\" to=\"mobile_base/commands/motor_power\"\
    />\n        <remap from=\"keyop/cmd_vel\" to=\"keyop_vel_smoother/raw_cmd_vel\"\
    />\n        <param name=\"linear_vel_step\"  value=\"0.05\" type=\"double\"/>\n\
    \        <param name=\"linear_vel_max\"   value=\"1.5\"  type=\"double\"/>\n \
    \       <param name=\"angular_vel_step\" value=\"0.33\" type=\"double\"/>\n  \
    \      <param name=\"angular_vel_max\"  value=\"6.6\"  type=\"double\"/>\n   \
    \     <param name=\"wait_for_connection_\" value=\"true\" type=\"bool\"/>\n  \
    \    </node>\n    </launch>\n\nThe major difference between kobuki_node/minimal.launch\
    \ and turtlebot_bringup/minimal.launch is, that the latter already starts the\
    \ velocity muxer. That plus few adjustments to the topic remappings is all that\
    \ is needed.\n\nI suggest, you start with this launch file and adapt it to your\
    \ needs.\n\nGood luck!\n"
