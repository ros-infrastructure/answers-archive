  body_markdown: "From the man page you link:\n\n> lcm-spy collects the following\
    \ statistics for each channel: \n\n>    - Channel name \n\nThis would be *topic*\
    \ I guess in ROS: `rostopic list` / `rosservice list` (although those are not\
    \ *channels*). If you want a GUI tool: `rqt_graph`.\n\n>    - Number of messages\
    \ received \n\nThis is a bit trickier, and would need some bash scripting to keep\
    \ a running total. Perhaps another member can suggest a suitable one-liner.\n\n\
    >   - Message Rate (Hz) \n\n    rostopic hz /topic_name\n\n>   - Bandwidth (KB/s)\n\
    \n    rostopic bw /topic_name\n\nSee also [wiki/rostopic](http://wiki.ros.org/rostopic).\n\
    \nNote that these statistics are all relative to the start of a `rostopic` invocation.\n\
    \nYou might also be interested in [wiki/Topics - Topic statistics](http://wiki.ros.org/Topics#Topic_statistics)\
    \ and [rqt_graphprofiler](http://wiki.ros.org/rqt_graphprofiler).\n\n---\n\nEdit:\n\
    \n> [..] and examine the content of individual messages. \n\nThat would be `rostopic\
    \ echo /topic_name`. Be aware that this can result in *a lot* of data for high-frequency\
    \ / high-volume topics.\n"
