    We faced similar issues trying to rally point-cloud and image data across a wifi network. The issue was that you cannot convert heavy data fast enough, so rate and latency cannot both be guaranteed. We developed [slim_bridge](https://www.blackcoffeerobotics.com/blog/ros1-robots-in-a-ros2-world) to fine tune QoS, and use best effort transport for sensor data. You can find the code with dockerized version to simply plug-play [here](https://github.com/blackcoffeerobotics/slim_bridge)
