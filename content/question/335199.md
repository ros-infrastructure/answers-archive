  body_markdown: "Hello,\n\n`ROS_INFO()` will display the message in the terminal,\
    \ but `ROS_INFO()` will also send a message to `/rosout`.\nIf you create a node\
    \ that subscribe to `/rosout` and use `ROS_INFO()`, you will write an infinite\
    \ loop because : \n\n1 . Node receive message from `/rosout`\n\n2 . Node print\
    \ with `ROS_INFO()`\n\n3 . `ROS_INFO()` Send a message to `/rosout`\n\n4 . Go\
    \ back to 1\n\nFor a simple example of how to do a [subscriber](http://wiki.ros.org/ROS/Tutorials/WritingPublisherSubscriber%28c%2B%2B%29#roscpp_tutorials.2BAC8-Tutorials.2BAC8-WritingPublisherSubscriber.Writing_the_Subscriber_Node),\
    \ you can subscribe to `/rosout` and simply use `std::cout` for displaying the\
    \ message (or your favorite logging system that doesn't use /rosout).\n\nIf you\
    \ want to extract Warning, Error or Fatal level message, you can use a [message\
    \ filter](http://wiki.ros.org/message_filters), or just discarding message with\
    \ logger level less than warning in the beginning of the callback function.\n\n\
    \n\n\n"
