    Edit: for future readers: please *always* prefer to install the binary version of ROS packages, if at all possible.

    Building ROS packages from sources is **not** the recommended way to install them and should *not* be your default.

    ---

    Easiest way to find source code for released (and indexed) packages would be [index.ros.org](https://index.ros.org).

    For `turtlesim` specifically: [index.ros.org/p/turtlesim](https://index.ros.org/p/turtlesim/github-ros-ros_tutorials/):

    ![ros index](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/1625216553512835.png)

    In the screenshot:

     1. the main link to the source repository. In this case: https://github.com/ros/ros_tutorials.git
     1. the name of the branch. In this case: `galactic-devel`
     1. tabs which allow you to switch to a different ROS release. Note how *GALACTIC* is selected here. To switch to the Foxy version of the package/page, click the *FOXY* tab. The *VCS Version* field in the *Repository Summary* will automatically update to show the correct branch name (for Foxy it would switch to `foxy-devel`)
     1. a convenience button which will take you to the source repository and open the correct branch for the package version selected using the tabs (3). In this case: https://github.com/ros/ros_tutorials/tree/galactic-devel/turtlesim
