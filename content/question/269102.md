  body_markdown: "Hello, sure, you can add your own models, also with texture. Here\
    \ for example I added this table from [rail_collada_models](https://github.com/GT-RAIL/rail_collada_models/tree/develop/meshes/original_models/doll_furniture):\n\
    \n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/150343975368918.png)\n\
    \nYou need to add it to ~/.gazebo/models with a model.config file describing it.\
    \ For example for the table above you must add a directory named doll_table containing\
    \ the meshes and textures and a model.config file like:\n\n    <?xml version=\"\
    1.0\"?>\n    <model>\n      <name>Doll table</name>\n      <version>1.0</version>\n\
    \      <sdf version='1.3'>doll_table.sdf</sdf>\n    \n      <author>\n       \
    \ <name>xxxx</name>\n        <email>xxx@yyy.zzz</email>\n      </author>\n   \
    \ \n      <description>\n        A small wooden table.\n      </description>\n\
    \    </model>\n\nto ~/.gazebo/models. Just check other models there as examples\
    \ (will be empty until you include some of the models available by default in\
    \ gazebo; they get downloaded locally the first time you use them).\n\nHope this\
    \ helps!"
