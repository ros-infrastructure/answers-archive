  body_markdown: "Hi,\n\nI've been working on this also, but It's quite cumbersome.\n\
    \nAs far as I know, the tb3 models are spawned as `.sdf` models directly on the\
    \ [turtlebot3_gazebo](https://github.com/ROBOTIS-GIT/turtlebot3_simulations) world\
    \ files () whereas the `tf` is created by a robot publisher that uses a urdf \
    \ on the [trutlebot_description](https://github.com/ROBOTIS-GIT/turtlebot3/turtlebot3_description)\n\
    \nWhat I've done is the following:\n\n - Create copies of the [tb3 models](https://github.com/ROBOTIS-GIT/turtlebot3_simulations/tree/ros2/turtlebot3_gazebo/models)\
    \ with a different name (I.e tb_1_burger, tb_2_buger)\n\n - Edit the [model.sdf](https://github.com/ROBOTIS-GIT/turtlebot3_simulations/blob/ros2/turtlebot3_gazebo/models/turtlebot3_burger/model.sdf)\
    \ files on the new copies by adding the namespace tags according.\n\n - Edit the\
    \ [world file](https://github.com/ROBOTIS-GIT/turtlebot3_simulations/blob/ros2/turtlebot3_gazebo/worlds/empty_worlds/burger.model)\
    \ that you are launching to add the new models.\n\nAt this point you will have\
    \ the two robots on gazebo, but the `tf` tree will be duplicated, so now it's\
    \ time to edit the `.urdf`.  For this it's possible to create a `.xacro` file,\
    \ but depending on which ros2 version you are using that can change quite a lot.\
    \  So a long and boring way to do this is to \n\n- Create copies of the `.urdf`\
    \ files for the new robots/models. You can find them in the [turtlebot_description/urdf](https://github.com/ROBOTIS-GIT/turtlebot3/tree/ros2/turtlebot3_description/urdf)\
    \ and there you need to manually change the links, joints to include the prefix.\n\
    \n- Finally, you need to update the [robot_state_publisher.launch](https://github.com/ROBOTIS-GIT/turtlebot3_simulations/blob/ros2/turtlebot3_gazebo/launch/robot_state_publisher.launch.py)\
    \ to launch the different `.urdf` files you just created.\n\nAt this point, the\
    \ multiple tb3 models should work, but it may still be some issues I haven't detected\
    \ yet.\n\nHope this helps!\n\nMario\n\n"
