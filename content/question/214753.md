  body_markdown: "In case the joystick interfaced with ROS via [joy/joy_node](http://wiki.ros.org/joy),\
    \ you can try `~autorepeat_rate` parameter as described [here](http://docs.ros.org/api/joy/html/):\n\
    \n> **Auto-Repeat/Signal Loss**\n> \n> The joy_node takes an\n> \"~autorepeat_rate\"\
    \ parameter. If the\n> linux kernal receives no events during\n> the autorepeat\
    \ interval, it will\n> automatically repeat the last value of\n> the joystick.\
    \ This is an important\n> safety feature, and allows users to\n> recover from\
    \ a joystick that has timed\n> out."
