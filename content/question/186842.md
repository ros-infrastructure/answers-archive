  body_markdown: "Please post relevant code. There is a type mismatch. The topic is\
    \ posting the message with a particular data-type and you are subscribing to another\
    \ data-type.\n\nI think the topic by-default uses [sensor_msgs/CompressedImage](http://docs.ros.org/hydro/api/sensor_msgs/html/msg/CompressedImage.html)\
    \ while your callback has type [sensor_msgs/Image](http://docs.ros.org/hydro/api/sensor_msgs/html/msg/Image.html).\n\
    \nIf your callback has arguments\n\n`const sensor_msgs::ImageConstPtr& _msg`\n\
    \nchange that to \n\n`const sensor_msgs::CompressedImageConstPtr& _msg`\n\nBut,\
    \ of course, you should change the code inside the callback to be sure you are\
    \ doing the right things with that message.\n\nIf you are using a default ros\
    \ executable and then using that remap, it won't work at all. Because the topic\
    \ types are different.\n\nHave a great day!\n\n\n`"

      <!-- Launch the tracking node -->
      <node pkg="visp_auto_tracker" type="visp_auto_tracker" name="visp_auto_tracker" output="screen">
