  body_markdown: "To include an XML file, you need to use `FrontendLaunchDescriptionSource`\
    \ instead of `PythonLaunchDescriptionSource`, which can be imported with `from\
    \ launch.launch_description_sources import FrontendLaunchDescriptionSource`.\n\
    \nSo the correct code would be:\n\n    def generate_launch_description():\n  \
    \      return LaunchDescription([ \n            IncludeLaunchDescription(FrontendLaunchDescriptionSource(\n\
    \            os.path.join(get_package_share_directory('rosbridge_server'),\n \
    \            'launch/rosbridge_websocket_launch.xml')))\n        ])"
