    Hi,
    You can include these headers:

        #include <ar_pose/ARMarker.h>

    or

        #include <ar_pose/ARMarkers.h>

    depending if you want to work with a single or multiple markers.

    The bag files in the ar_pose page are old, and have to be fixed with a command `rosbag fix`, there is also a problem with the frame transformations (check [ar_pose track](http://robotics.ccny.cuny.edu/trac/ticket/17)), therefore I would recommend you to print a marker and test it with an USB camera or other. I think it will be easier.
    regards.
