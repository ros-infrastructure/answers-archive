  body_markdown: "I know this is a late addition, but the fix I had for this was to\
    \ have a launch file that specified the env var ROSCONSOLE_CONFIG_FILE  for the\
    \ node that needed to run with debugging\n\nif you had  a package my_node\n\n\
    \    <launch>\n     <node pkg=\"my_node\" type=\"first_node\" name=\"first_node\"\
    \ />\n      <env name=\"ROSCONSOLE_CONFIG_FILE\" value=\"$(find my_node)/launch/rosconsole.config\"\
    />  \n      <node pkg=\"my_node\" type=\"second_node\" name=\"second_node\" />\n\
    \    </launch>\n\nThe second node would have the logging enabled for the level\
    \ you requested in $(rospack find my_node)/launch/rosconsole.config"
