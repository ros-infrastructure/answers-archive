    Hi Dimitar,

    I just started on something called rxlaunch, which does exactly that.  It's still in active development, but may already be useful to you.

    ![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/13106755334575275.png)

    You can get rxlaunch from [its kforge page](https://kforge.ros.org/project/rxlaunch/services/hg/).  Just checkout the mercurial repository and run `rxlaunch.py`.  You may also need to [install PySide](http://developer.qt.nokia.com/wiki/PySide_Binaries_Linux).

    Some things that don't work yet (2011-07-14):

     - <strike>It doesn't load parameters, so you should `roslaunch` the launch file first, then use rxlaunch</strike> (fixed 2011-07-14)
     - Everything is launched locally
     - It's hard-coded to use the master at http://localhost:11311

    When things go wrong, just [file a ticket](https://code.ros.org/trac/wg-ros-pkg/newticket?keywords=rxlaunch&owner=sglaser).
