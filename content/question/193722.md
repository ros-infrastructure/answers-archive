  body_markdown: "There is no magic trick to make this work, you just initialize both\
    \ after you have called `rospy.init_node(...)`\n(Edited in response to your comment)\n\
    \n    import rospy\n    from std_msgs.msg import String\n    rospy.init_node(\"\
    One_node_to_rule_them_all\")\n    pub = rospy.Publisher(\"echo\", String)\n  \
    \  \n    def callback(input):\n            pub.publish(input.data)\n         \
    \   # The message has 2 parts, a header and the data. We only want to use the\
    \ actual data\n     \n    sub = rospy.Subscriber(\"chatter\", String, callback)\n\
    \n    pub2 = rospy.Publisher(\"chatter\", String)\n    pub2.publish(\"'Stop repeating\
    \ everything I say\")\n\nWhen you run `rostopic echo /echo` It will show the desired\
    \ output"
