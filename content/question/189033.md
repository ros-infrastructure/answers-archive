    This question has been answered before, but:

     - officially: no, there is no support for Indigo on Ubuntu Precise. See [REP-3, Indigo Igloo](http://www.ros.org/reps/rep-0003.html#indigo-igloo-may-2014)
     - unofficially: yes, but you have to build [from source](http://wiki.ros.org/indigo/Installation/Source)
     - alternatively: you could use [a chroot](http://wiki.ros.org/ROS/Tutorials/InstallingIndigoInChroot) (although this is not technically Indigo on Precise, it does let you run it on your Precise installation without having to install Trusty), but please understand the limitations of this option

  body_markdown: "Is it possible to install Indigo on ubuntu 12.04?\n\nSorry for the\
    \ spaces in the links, not enough karma.\n\nI was able to install Indigo Desktop-full\
    \ from source on Ubuntu 12.04. I basically followed the instructions posted at\
    \ http://wiki.ros.org/indigo/Installation/Source, but needed to do a few extra\
    \ steps. \n\nFirst, install the prerequisites from the installation instructions.\
    \ I already had ROS Hydro installed on my machine, and was able to install the\
    \ dependencies from apt. Once the dependencies are installed the following should\
    \ work. \n\nInstall lz4\n\n    $ sudo add-apt-repository ppa: gezakovacs/lz4\n\
    \    $ sudo apt-get update\n    $ sudo apt-get install liblz4-dev\n\nInstall OpenCV.\n\
    I initially tried using the opencv from the ubuntu repositories without success.\
    \ Building and installing the latest version of OpenCV from source worked successfully.\
    \ http://sourceforge.net/projects/opencvlibrary/files/opencv-unix/2.4.9/opencv-2.4.9.zip/download\n\
    \n\n    $ unzip opencv-2.4.9.zip \n    $ cd opencv-2.4.9/\n    $ mkdir build\n\
    \    $ cd build/\n    $ cmake ..\n    $ make -j8\n    $ sudo make install\n  \
    \  $ sudo ldconfig\n\nPerform the first steps of the installation process\n\n\
    \    $ mkdir ~/ros_catkin_ws\n    $ cd ~/ros_catkin_ws\n    $ rosinstall_generator\
    \ desktop_full --rosdistro indigo --deps --wet-only --tar > indigo-desktop-full-wet.rosinstall\n\
    \    $ wstool init -j8 src indigo-desktop-full-wet.rosinstall \n    $ rosdep update\n\
    \    $ rosdep install --from-paths src --ignore-src --rosdistro indigo -y\n\n\
    This last command will give you errors. This is because the dependencies really\
    \ are not defined. However, most of these should be opencv related due to the\
    \ fact rosdep does not know we installed it from source. \n\nInstall console_bridge\n\
    \n    $ cd src/\n    $ git clone https://github.com/ros/console_bridge.git\n \
    \   $ cd console_bridge/\n    $ mkdir build\n    $ cd build/\n    $ cmake .. \n\
    \    $ make\n    $ sudo make install\n    $ cd ../../..\n\nInstall urdfdom_headers\n\
    \n    $ cd src/\n    $ git clone https://github.com/ros/urdfdom_headers.git\n\
    \    $ cd urdfdom_headers/\n    $ mkdir build\n    $ cd build/\n    $ cmake ..\n\
    \    $ sudo make install\n    $ cd ../../..\n\nInstall urdfdom\n\n    $ cd src/\n\
    \    $ git clone https://github.com/ros/urdfdom.git\n    $ cd urdfdom\n    $ mkdir\
    \ build\n    $ cd build/\n    $ cmake ..\n    $ sudo make install\n    $ cd ../../..\n\
    \nFinally, start the build. Make sure you have not sourced any ROS setup.bash\
    \ files.\n\n    $ ./src/catkin/bin/catkin_make_isolated --install -DCMAKE_BUILD_TYPE=Release\n\
    \nYou can resume building at the package you failed at using the following command.\n\
    \n    $ ./src/catkin/bin/catkin_make_isolated --install -DCMAKE_BUILD_TYPE=Release\
    \ --from-pkg=<package name>\n\n"
