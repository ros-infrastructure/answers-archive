  body_markdown: "RViz2 sends the goal to the [action](https://docs.ros.org/en/foxy/Tutorials/Understanding-ROS2-Actions.html)\
    \ server of Nav2. Nav2 uses the feedback function of the action server to give\
    \ the ETA ([among other things](https://github.com/ros-planning/navigation2/blob/galactic/nav2_msgs/action/NavigateToPose.action)).\
    \ \n\nThe easiest way I know to get access is to write your own action client\
    \ that also sends the goal to Nav2. That way your node will be the one to receive\
    \ the feedback messages.\n\nETA: Actually, you can also simply subscribe to `/navigate_to_pose/_action/feedback`\
    \ you can also use `ros2 topic echo /navigate_to_pose/_action/feedback` to check."
