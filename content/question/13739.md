    Wow, you've integrated your physics engine with Gazebo using a system plugin, that's amazing!

    Not sure exactly how your implementation works, but here's how it works for the default physics engines:

    1. `gui::ModelListWidget` publishes a request for `physics_info` [here](https://bitbucket.org/osrf/gazebo/src/4004fbd7deede758c0ca0fbc7c906e62b0a808a4/gazebo/gui/ModelListWidget.cc?fileviewer=file-view-default#ModelListWidget.cc-198).

    2. When the running physics engine is ODE for example, `physics::ODEPhysics` fills a message with physics info [here](https://bitbucket.org/osrf/gazebo/src/4004fbd7deede758c0ca0fbc7c906e62b0a808a4/gazebo/physics/ode/ODEPhysics.cc?fileviewer=file-view-default#ODEPhysics.cc-238)

    3. `gui::ModelListWidget` checks the response corresponds to the request it sent [here](https://bitbucket.org/osrf/gazebo/src/4004fbd7deede758c0ca0fbc7c906e62b0a808a4/gazebo/gui/ModelListWidget.cc?fileviewer=file-view-default#ModelListWidget.cc-458) and fills the panel [here](https://bitbucket.org/osrf/gazebo/src/4004fbd7deede758c0ca0fbc7c906e62b0a808a4/gazebo/gui/ModelListWidget.cc?fileviewer=file-view-default#ModelListWidget.cc-2881).

    So I think you'd somehow need to subscribe to `~/request` for `physics_info` and publish your message to `~/response`. But I think you'll need to make sure the default physics engine doesn't respond first.
