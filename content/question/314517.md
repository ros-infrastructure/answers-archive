  body_markdown: "Ok, I found an answer.  You have to create a temporary logger config\
    \ file that sets the requested log debug level.  Here's an example that sets the\
    \ default logger: \n\n    $ cat tmp.cfg \n    log4j.logger.ros=DEBUG\n\nThen you\
    \ pass that using an environment variable as:\n\n    $ ROSCONSOLE_CONFIG_FILE=tmp.cfg\
    \ rqt --force-discover -v --list-plugins\nThe logger will load the config file\
    \ at startup and initialize itself to the config in that file instead of the default\
    \ level (\"warn\").\n\n"
