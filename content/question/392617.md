ROS version: Noetic, Package: turtlebot3_simulation, Operating system: Windows 10

When I launch a turtlebot3 simulation using ```roslaunch turtlebot3_fake turtlebot3_fake.launch```, everything works, but the simulation is in a tiny rectangle at the bottom left corner of the `rviz` window.

![image description](https://user-images.githubusercontent.com/30264720/145281060-a3e75698-b788-424c-9677-13c9429f974e.png)

It occupies the entire window as soon as I resize (drag bottom right corner, maximize, or snap using Windows + right/left/up/down) the `rviz` window.

[I posted this as a bug on the `turtlebot3` GitHub page](https://github.com/ROBOTIS-GIT/turtlebot3/issues/808), but was instructed to post here instead.
