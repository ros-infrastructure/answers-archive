    I haven't tested it myself, but there's a chance you could use [ternaris/rosbags](https://gitlab.com/ternaris/rosbags) for this.

    Announcement on ROS Discourse: [Rosbags - the pure python library for everything rosbag](https://discourse.ros.org/t/rosbags-the-pure-python-library-for-everything-rosbag/20944).

    There doesn't appear to be any implementation for ROS2->ROS1, but ROS1->ROS2 is there, and the library itself is capable of reading/writing both ROS1 and ROS2 bags.
