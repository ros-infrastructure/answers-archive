  body_markdown: "Update: Also check out [this tutorial](http://gazebosim.org/tutorials?tut=static_map_plugin&cat=build_world).\n\
    \nYou can create a material script, and then use that material script on a ground\
    \ plane.\n\n1. Create a new model directory:\n\n    mkdir ~/.gazebo/models/my_ground_plane\n\
    \n1. Create the materials directories: \n\n    mdkir -p ~/.gazebo/models/my_ground_plane/materials/textures\n\
    \    mdkir -p ~/.gazebo/models/my_ground_plane/materials/scripts\n\n2. Create\
    \ your material script file `~/.gazebo/models/my_ground_plane/materials/scripts/my_ground_plane.material`\
    \ with the following contents:\n\n<pre>\n    material MyGroundPlane/Image\n  \
    \  {\n      technique\n      {\n        pass\n        {\n          ambient 0.5\
    \ 0.5 0.5 1.0\n          diffuse 1.0 1.0 1.0 1.0\n          specular 0.0 0.0 0.0\
    \ 1.0 0.5\n    \n          texture_unit\n          {\n            texture MyImage.png\n\
    \            filtering trilinear\n          }\n        }\n      }\n    }\n</pre>\n\
    \n5. Copy your image to `~/.gazebo/models/my_ground_plane/materials/textures/MyImage.png`\n\
    \n6. Create a `~/.gazebo/models/my_ground_plane/model.sdf` file with the following\
    \ contents\n\n        <?xml version=\"1.0\"?>\n        <sdf version=\"1.4\">\n\
    \        <model name=\"my_ground_plane\">\n          <static>true</static>\n \
    \           <link name=\"link\">\n              <collision name=\"collision\"\
    >\n                <geometry>\n                  <plane>\n                   \
    \ <normal>0 0 1</normal>\n                    <size>100 100</size>\n         \
    \         </plane>\n                </geometry>\n                <surface>\n \
    \                 <friction>\n                    <ode>\n                    \
    \  <mu>100</mu>\n                      <mu2>50</mu2>\n                    </ode>\n\
    \                  </friction>\n                </surface>\n              </collision>\n\
    \              <visual name=\"visual\">\n                <cast_shadows>false</cast_shadows>\n\
    \                <geometry>\n                  <plane>\n                    <normal>0\
    \ 0 1</normal>\n                    <size>100 100</size>\n                  </plane>\n\
    \                </geometry>\n                <material>\n                  <script>\n\
    \                    <uri>model://my_ground_plane/materials/scripts/my_ground_plane.material</uri>\n\
    \                    <name>MyGroundPlane/Image</name>\n                  </script>\n\
    \                </material>\n              </visual>\n            </link>\n \
    \         </model>\n        </sdf>\n\n7. Create a `~/.gazebo/models/my_ground_plane/model.config`\
    \ file with the following contents\n\n      <?xml version=\"1.0\"?>  \n      <model>\n\
    \        <name>My Ground Plane</name>\n        <version>1.0</version>\n      \
    \  <sdf version=\"1.4\">model.sdf</sdf>\n        \n        <description>\n   \
    \       My textured ground plane.\n        </description>\n      </model>\n\n\
    8. In your world SDF file, use your ground plane like so:\n\n\n        <include>\n\
    \          <uri>model://my_ground_plane</uri>\n        </include>"
