  body_markdown: "I sloved the question by just now.\nI read the [documentation of\
    \ Serial::write](http://wjwwood.io/serial/doc/1.1.0/classserial_1_1_serial.html#aa020880cdff3a370ddc574f594379c3c)\
    \   and it says the first parameter of Serial::write is a const reference containing\
    \ the data to be written to the serial port, and it should be uint8_t type.\n\
    So I changed \n\n    char ask[8]={0x01,0x03,0x00,0x00,0x00,0x02,0xc4,0x0b};\n\
    to be \n\n    uint_8 ask[8]={0x01,0x03,0x00,0x00,0x00,0x02,0xc4,0x0b};\nand changed\
    \ \n \n\n    size_t bytes_wrote = my_serial.write(test_string);\n\nto be \n\n\
    \    my_serial.write(test_string,8);\n"
