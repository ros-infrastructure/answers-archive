    In `tf2` you would need to use one of the [supported datatypes](http://wiki.ros.org/tf2#Supported_Datatypes). Suppose the vector you are talking about is a `geometry_msgs/Vector3`, then you could use [this version of doTransform](http://docs.ros.org/melodic/api/tf2_geometry_msgs/html/c++/namespacetf2.html#a82ca47c6f5b0360e6c5b250dca719a78) to transform your vector using a `geometry_msgs/TransformStamped` to represent the rotation. In your case the transform would have zeros for the translational components and you would use your desired quaterion for the orientation portion. Also note, you could use the `fromMsg` and `toMsg` functions to convert between tf2 datatypes and any of the other supported datatypes.

    Also, I'll point out that the `*` operator has been overloaded in several ways for the tf2 Quaternions such that you could also directly perform [quaternion multiplication to accomplish the rotation](https://en.wikipedia.org/wiki/Quaternions_and_spatial_rotation#Using_quaternion_as_rotations) you are describing. [Example 1](http://docs.ros.org/kinetic/api/tf2/html/Quaternion_8h_source.html#l00144) and [Example 2](http://docs.ros.org/melodic/api/tf2/html/Quaternion_8h_source.html#l00373).

    ```tf2``` has a built-in function for this called ```quatRotate()```. It is defined here on line 436: [Quaternion.h](http://docs.ros.org/en/jade/api/tf2/html/Quaternion_8h_source.html#l00436).

    Usage:

        tf2::Vector3 v_orig = ... ;
        tf2::Quaternion q = ... ;
        tf2::Vector3 v_new = quatRotate(q, v_orig);

    To convert your quaternion/vector3 from the geometry_msgs format to ```tf2::Quaternion``` or ```tf2::Vector3```, do

        #include <tf2_geometry_msgs/tf2_geometry_msgs.h>

        tf2::Quaternion q;
        tf2::Vector3 v_orig;
        tf2::fromMsg(my_msg.my_orientation, q); // q is now loaded with data
        tf2::fromMsg(my_msg.my_vector, v_orig); // v_orig is now loaded with data
