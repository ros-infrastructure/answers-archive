  body_markdown: "There are a [set of tutorials](https://wiki.ros.org/sr_tactile_sensors)\
    \ on the [`sr_tactile_sensors` wiki page](https://wiki.ros.org/sr_tactile_sensors/Tutorials/Getting%20Data)\
    \ that may help you. For example, there's one that shows [how to subscribe to\
    \ the `/sr_tactile/touch/ff` topic](https://wiki.ros.org/sr_tactile_sensors/Tutorials/Getting%20Data#Accessing_the_data_in_a_different_node).\
    \ It's in C++ so I made a Python version of it (that's been combined with the\
    \ [subscriber tutorial](https://wiki.ros.org/ROS/Tutorials/WritingPublisherSubscriber%28python%29#rospy_tutorials.2BAC8-Tutorials.2BAC8-WritingPublisherSubscriber.Writing_the_Subscriber_Node):\n\
    \n    #!/usr/bin/env python\n    \n    import rospy\n    from std_msgs.msg import\
    \ Float64\n    \n    \n    def callback(msg):\n        # log the message data\
    \ to the terminal\n        rospy.loginfo(\"The value is %d\", msg.data)\n    \n\
    \    \n    def listener():\n        # start the node\n        rospy.init_node(\"\
    listener\")\n        # subscribe to the '/sr_tactile/touch/ff' topic\n       \
    \ tactile_sub = rospy.Subscriber(\"/sr_tactile/touch/ff\", Float64, callback)\n\
    \        # keep python from exiting until this node is stopped\n        rospy.spin()\n\
    \    \n    \n    if __name__ == '__main__':\n        listener()"
