    You could write a plugin which attaches a [MovableText](http://osrf-distributions.s3.amazonaws.com/gazebo/api/dev/classgazebo_1_1rendering_1_1MovableText.html) to each model visual. A GUI or System plugin would probably be best, since you need access to rendering.

    **UPDATE**

    I got curious about this and decided to write a plugin myself. [Here](https://bitbucket.org/chapulina/gazebo_plugins/src/default/FloatingModelNames/)'s the source code, and [here](https://www.youtube.com/watch?v=rsftOnKI4q4)'s a video.

    It should work if you clone the repository or copy the files and follow the build instructions in the `README` file. To use it with your world, just add the proper `<gui>` tag to your SDF file. You can customize the plugin for your needs, all it does now is attaching a name to every model in simulation.
