    \ the transform from *utm*->*odom* is always near 0 is because your IMU and EKF\
    \ orientations are almost identical (they have the same source, but the EKF output\
    \ has, of course, been filtered). So no matter which direction you're facing,\
    \ the orientation of those coordinate frames will match, and the rotational component\
    \ of their transform will be near 0. So:\n\n - If you **want** the orientation\
    \ in the *utm*->*odom* transform to be *exactly* 0, then set `use_odometry_yaw`\
    \ to *true* for `navsat_transform_node` and **make sure** `imu0_relative` is *false*\
    \ for `ekf_localization_node`.\n - If you **don't want** the orientation in the\
    \ *utm*->*odom* transform to be 0 (so that you can confirm it's working), set\
