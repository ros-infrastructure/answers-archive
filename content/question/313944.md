    \ error/warning about a quaternion issue. \nFrom the [wiki](http://wiki.ros.org/tf#static_transform_publisher)\
    \ :\n\n    static_transform_publisher x y z qx qy qz qw frame_id child_frame_id\
    \  period_in_ms\n    \n    Publish a static coordinate transform to tf using an\
    \ x/y/z offset in meters and quaternion. The period, in milliseconds, specifies\
    \ how often to send a transform. 100ms (10hz) is a good value.\n\nSo that means\
    \ you would set a quaternion to (0; 0; 0; 0) which is not a correct/existing value\
    \ for a quaternion.\n\nNote : Never hesitate to try by yourself at first, I'm\
    \ sure if you did that you would have directly spotted the quaternion issue ;)"
