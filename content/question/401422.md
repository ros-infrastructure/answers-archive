Hello everybody,

I am subscribing to a camera in RVIZ, this all works fine. I do have trouble when saving the images. I do this by calling the function get_image(name). The name I give here is the name of the image (e.g. image1.png)
What happens when I save a second image (e.g. image2.png) is that the file image1.png is also overwritten, so I get the same image under different names. What I want is to leave the old images like they are when taking new ones.

This is the python code I use:

import rospy
from sensor_msgs.msg import Image
from cv_bridge import CvBridge
import cv2
 
def callback(msg, name):
    print("Callback of " + name)

    bridge = CvBridge()
    cv2_img = bridge.imgmsg_to_cv2(msg)
    cv2.imwrite(name + '.png', cv2_img)

def get_image(name):
    print('Get image of ' + name)

    rospy.init_node('image_listener')
    rospy.Subscriber("/camera/color/image_raw", Image, callback, callback_args=name)
    rospy.wait_for_message("/camera/color/image_raw", Image)

if __name__ == '__main__':
    get_image('test1')
    get_image('test2')
    get_image('test3')

And this is the result I get:

Get image of test1
Callback of test1
Get image of test2
Callback of test1
Callback of test2
Get image of test3
Callback of test1
Callback of test2
Callback of test3

The output I would like to get:

Get image of test1
Callback of test1
Get image of test2
Callback of test2
Get image of test3
Callback of test3

What am I doing wrong here?
