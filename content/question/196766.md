  body_markdown: "For released packages you just type:\n\n> sudo apt-get install ros-\"\
    your ros\n> distro\"-\"package-name\"\n\nIf you use ROS indigo and want to install\
    \ the package image-view you just do \n\n> sudo apt-get install\n> ros-indigo-image-view\n\
    \nIf the package is not released then you will need to install it from source\
    \ code, click on the name of the package on the package's list page and find out\
    \ where the code is hosted (mostly github), clone the package's repository in\
    \ your workspace. then catkin_make. This is explained in detail in beginner's\
    \ tutorials.\n\nNow the problem with installing from source code is that you have\
    \ to take care of the dependencies by yourself. whenever you see \"Could not find\
    \ a configuration file for package xxxxx\" it means this package is missing and\
    \ is needed for compiling your code. You could also try using [rosdep](http://wiki.ros.org/ROS/Tutorials/rosdep)\
    \  which will automatically try to find all the dependencies of your package and\
    \ install them."
