 Hi, I realized that on the page of https://classic.gazebosim.org/tutorials?tut=ros_gzplugins , under Differential Drive header, there is a tag named by "publishOdom" that should publish odometry to tf. No matter it is false or true nothing was changing, and I researched the source code of libgazebo_ros_diff_drive.so and I found this plugin takes a parameter named "publishOdomTF" not "publishOdom". After changing tag to "publishOdomTF" and if I change to false it doesn't publish odometry tf and it solved. Please fix this problem. Thanks
