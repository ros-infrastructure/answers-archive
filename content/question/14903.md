    In order to get console output when running the log file, run gazebo in verbose mode:

        gazebo -p state.log --verbose

    For the `gz log` command, you must use the `-f` flag to specify the file like this:

        gz log -i -f state.log

    What exactly do you mean nothing happens when you playback the log file? On Gazebo7, when playing back a log file, the GUI should look different as shown on [this](http://gazebosim.org/tutorials?tut=logging_playback#Playbackalogfile) tutorial (note the timeline on the bottom).
