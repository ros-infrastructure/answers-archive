  body_markdown: "You can either use an existing map or create your own.\nFor creating\
    \ a new map, you can use [gmapping](http://wiki.ros.org/gmapping)\n\nFor existing\
    \ maps, you can find some examples [here](https://github.com/yujinrobot/yujin_maps)\
    \ . \n\nA map is defined by an image file where black means obstacle and white\
    \ means free (depending on some threshold on pixel intensity) and by a .YAML file\
    \ where map resolution, origin and some thresholds are defined. More information\
    \ on the [map_server page](http://wiki.ros.org/map_server)."
