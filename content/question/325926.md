    Did you wait for the bag file to finish downloading before you started playing it? Many browsers download to a temporary file first while making an empty file as a place holder for the final file name, then move the temporary file to the final file name when the download is complete. If you try to play the bag file while it's still downloading, then `rosbag` will try to play an empty file and give exactly the error you are getting.
    I have no trouble playing the bag file you indicate after waiting a while for its 2.6 GB download to complete.
