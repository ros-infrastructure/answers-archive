  body_markdown: " Hi,\n\nYou don't need to add a transform `/base_link` -> `/camera_link`.\
    \ In the tutorial, the `frame_id` is set to `/camera_link` by default. However,\
    \ the transform `/camera_link` -> `/camera_rgb_optical_frame` should exist (10\
    \ Hz). Is the following work?\n\n$ rostun tf tf_echo /camera_link /camera_rgb_optical_frame\n\
    \nIf so, I don't see the problem. The odometry error is detected from this [waitForTransform()](https://github.com/introlab/rtabmap_ros/blob/76cb4365dd3b7e189325e991c36241c8d6522736/src/OdometryROS.cpp#L299-L321):\
    \ \n\n\t// TF ready?\n\tTransform transform;\n\ttry\n\t{\n\t\tif(waitForTransform_\
    \ && !stamp.isZero() && waitForTransformDuration_ > 0.0)\n\t\t{\n\t\t\tif(!tfListener_.waitForTransform(fromFrameId,\
    \ toFrameId, stamp, ros::Duration(waitForTransformDuration_)))\n\t\t\t{\n\t\t\t\
    \tROS_WARN(\"odometry: Could not get transform from %s to %s (stamp=%f) after\
    \ %f seconds (\\\"wait_for_transform_duration\\\"=%f)!\",\n\t\t\t\t\t\tfromFrameId.c_str(),\
    \ toFrameId.c_str(), stamp.toSec(), waitForTransformDuration_, waitForTransformDuration_);\n\
    \t\t\t\treturn transform;\n\t\t\t}\n\t\t}\n\n\t\ttf::StampedTransform tmp;\n\t\
    \ttfListener_.lookupTransform(fromFrameId, toFrameId, stamp, tmp);\n\t\ttransform\
    \ = rtabmap_ros::transformFromTF(tmp);\n\t}\n\tcatch(tf::TransformException &\
    \ ex)\n\t{\n\t\tROS_WARN(\"%s\",ex.what());\n\t}\n\ncheers"
