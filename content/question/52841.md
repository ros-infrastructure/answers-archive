  body_markdown: "Yes there is a standard way. \n\nTaking [rqt python plugin tutorial](http://ros.org/wiki/rqt/Tutorials/Writing%20a%20Python%20Plugin)\
    \ as an example, you can replace `QWidget` with your main `python` modoule, give\
    \ it to [qt_gui.PluginContext.add_widget](http://ros.org/doc/api/qt_gui/html/classqt__gui_1_1plugin__context_1_1PluginContext.html#a2814e487d31fad6ae983a1e640fd0f5c)\
    \ method.\n\n----\n\nA little more about concept, `rqt` framework provides:\n\n\
    \ 1. An \"interface\" between your own python components and `rqt` itself.\n\n\
    \ 2. Standard procedures for GUI (shutdown etc.)\n\n 3. Nice features for GUI\
    \ design (ex. `loadUi` that enables to use UI definition in xml (.ui file)\n\n\
    This means you can easily utilize your own stuff without even modifying. You just\
    \ add a class that extends `qt_gui.plugin.Plugin` where you define #1 & #2 above.\
    \ Currently detailed API document doesn't exist but [API Review](http://www.ros.org/wiki/rqt/Reviews/2012-06-20_API_Review)\
    \ might give you more insight.\n"
