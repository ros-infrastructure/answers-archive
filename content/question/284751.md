    [Google Code shutdown in 2015](https://opensource.googleblog.com/2015/03/farewell-to-google-code.html) so it's no surprise that you can't access it. According to that article, Google migrated much of their code to [GitHub](http://github.com/google) and created a tool for developers to move their code as well. However,as far as I know, Google didn't migrate other's code on its own.

    - OCTOMAP-related ROS stacks have moved to [GitHub](https://github.com/OctoMap)
    - NAO-related stacks have moved to GitHub: [`nao_robot` repo](https://github.com/ahornung/nao_robot ) and [`nao_common` repo](https://github.com/ahornung/nao_common)
