  body_markdown: "You should \"play\" with a simple urdf to see what's the difference.\n\
    \nIt's all about the tf, with the origin tag of the joint you define where is\
    \ the tf and with the origin of the link you define where your object is according\
    \ to your tf. Here's an exemple :\n\nThe `joint` tag origin is `0 0 0` but the\
    \ origin of the `link1` is `0 0 1`(and you can see the tfs are at the same position)\
    \ : \n\n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/15208452835483313.png)\n\
    \nHere I set the `joint` tag origin to `0 0 1` and the origin of the `link1` is\
    \ `0 0 0` :\n\n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/15208454638059965.png)\n\
    \nThe link1 is at the same position in both case but the tf isn't. It comes in\
    \ consideration when you have different type joints if you don't correctly define\
    \ the tfs some rotations or translations could not behave as expected.\n"
