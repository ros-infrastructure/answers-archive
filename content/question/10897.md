    The IMHO cleanest approach for starting up Gazebo in cases like this is starting it in paused mode. You'll need to press the "play" button after things started up, but you'll have a very reproducible setup using only a single launch file. To start Gazebo paused, you have to provide it with the "-u" option. An example is the combination of these two launch files, using arguments: [main launch file](https://github.com/tu-darmstadt-ros-pkg/hector_centaur/blob/master/hector_centaur_scenarios/launch/exploration_door.launch#L5), [common gazebo start launch file](https://github.com/tu-darmstadt-ros-pkg/hector_nist_arenas_gazebo/blob/indigo-devel/hector_nist_arena_worlds/launch/start.launch).
