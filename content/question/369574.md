  body_markdown: "I did not check in depth but:\n\nThe odom information is publish\
    \ by the GazeboDifferentialDrive Plugin (see http://gazebosim.org/tutorials?tut=ros_gzplugins#DifferentialDrive)\
    \ the Plugin allows you to chose between WORLD and ENCODER source (set via `<odometrySource>`.\n\
    \nSee e.g. https://github.com/ros-simulation/gazebo_ros_pkgs/blob/7bf18c7ad727e0d5f3c80c4dee01fc1429c16093/gazebo_plugins/src/gazebo_ros_diff_drive.cpp#L89-L97\n\
    \nSet to the default WORLD source the Plugin uses the internal information from\
    \ Gazebo. Thus if you jump the information is immediately available to the plugin\
    \ resulting in the shown effect. \n\nTo get more realism into the simulation try\
    \ switching to the ENCODER source.\nScanning the plugin code this seems to require\
    \ a defined joint for both the left and right wheel but maybe this is already\
    \ set in your model.\n\n\n\n"
