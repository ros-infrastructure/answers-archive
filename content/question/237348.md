    No. ROS handles distributed processing &quot;out of the box&quot; (in this case, ROS nodes both on the robot and on your PC). You need to read the basic documentation and gain a working understanding of ROS nodes, the ROS master, and pub/sub functionality (at a minimum). Try starting at the [ROS core components](http://www.ros.org/core-components/) page and go from there.

    Also, directly (1st sentence) from the [rosbridge wiki page](http://wiki.ros.org/rosbridge_suite): *Rosbridge provides a JSON API to ROS functionality for non-ROS programs.* Which is quite clearly not what you need.

    \n    export ROS_MASTER_URI=http://<Place your Robot's ip here>:11311\n\nNow your\
    \ commands on this terminal, communicates with your robot. For example if you\
    \ type `rostopic list`, you will see your robot's topics. Or you can launch \n\
