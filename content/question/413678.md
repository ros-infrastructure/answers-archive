    In ROS 2 Humble, when you send out a goal with "async_send_goal", assign the returned future goal handle to a variable. When you need to query for the result, you can just call "[async_get_result](https://docs.ros2.org/latest/api/rclcpp_action/classrclcpp__action_1_1Client.html#a0213daa95ba7b1229d1371fad47b23b5)" or "[async_result](https://docs.ros2.org/latest/api/rclcpp_action/classrclcpp__action_1_1ClientGoalHandle.html)" (deprecated). For example:

        auto future_goal_handle = client_ptr_->async_send_goal(goal_msg, send_goal_options);
        rclcpp::spin_until_future_complete(node, future_goal_handle);
        auto result = client_ptr_-> async_get_result(future_goal_handle.get());
        if (result.get().code == rclcpp_action::ResultCode::SUCCEEDED)
        {
            return true;
        }

    Note that the "result" you get is a [WrappedResult](https://docs.ros2.org/latest/api/rclcpp_action/structrclcpp__action_1_1ClientGoalHandle_1_1WrappedResult.html), so if you want the result message, you need to do something like:

        result.get().result

    You can also query for goal status through the client goal handle with "[get_status](https://docs.ros2.org/latest/api/rclcpp_action/classrclcpp__action_1_1ClientGoalHandle.html#a154456949c16b697741c28705d7fdfeb)" if you are comparing with `action_client->get_state()` instead.
