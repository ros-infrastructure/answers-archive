  body_markdown: "I think you need to apply the transformation in the reverse direction.\n\
    \n    import tf\n    import tf2_geometry_msgs\n    from geometry_msgs.msg import\
    \ TransformStamped, Vector3Stamped\n\n    v = Vector3Stamped()\n    v.vector.x\
    \ = 23.7\n\n    t = TransformStamped()\n    q = tf.transformations.quaternion_inverse(tf.transformations.quaternion_from_euler(0.39,\
    \ 0, 1.64))\n\n    t.transform.rotation.x = q[0]\n    t.transform.rotation.y =\
    \ q[1]\n    t.transform.rotation.z = q[2]\n    t.transform.rotation.w = q[3]\n\
    \    \n    vt = tf2_geometry_msgs.do_transform_vector3(v, t)\n\n vt looks like\
    \ this\n\n  \n\n    header: \n      seq: 0\n      stamp: \n        secs: 0\n \
    \       nsecs:         0\n      frame_id: ''\n    vector: \n      x: -1.6388182331\n\
    \      y: -21.867875772\n      z: 8.98889782002\n\n\n\n"

      \ body frame, you need  global -> body transformation, which is the inverse\
      \ of body -> global transformation."
