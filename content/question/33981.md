  body_markdown: "Hi. I am also working with 2 Turtlebots in Gazebo (ROS Fuerte).\
    \ I was able to separate both `/cmd_vel` and `/odom` topics. Here is what I did:\n\
    \nGo to gazebo_ros_create.h and add a new private variable: \n\n    std::string\
    \ robot_namespace_;\n\nGo to gazebo_ros_create.cpp. Add the following lines in\
    \ the function `GazeboRosCreate::Load` (I added it around line 56)\n\n    this->robot_namespace_\
    \ = \"\";\n    if (_sdf->HasElement(\"robotNamespace\")) { \n      this->robot_namespace_\
    \ = _sdf->GetElement(\"robotNamespace\")->GetValueString() + \"/\";\n    }\n\n\
    With that line you are getting the namespace you assigned for the nodes (in my\
    \ case turtle_1 and turtle_2). Modify the line corresponding to `node_namespace`\
    \ in order to add the `robotNamespace` String on it:\n\n    this->node_namespace_\
    \ = \"\";\n    if (_sdf->HasElement(\"node_namespace\")) {\n      this->node_namespace_\
    \ = this->robot_namespace_ + _sdf->GetElement(\"node_namespace\")->GetValueString()\
    \ + \"/\";\n    }\n\nNow go down and find the lines in which you subscribe/advertise\
    \ the topics `/cmd_vel`, `/odom` and `/sensor_state` and change them to local\
    \ names `cmd_vel`, `odom` and `sensor_state`. The lines should now look like this:\n\
    \n\n\n    cmd_vel_sub_ = rosnode_->subscribe(\"cmd_vel\", 1, &GazeboRosCreate::OnCmdVel,\
    \ this );\n    \n    sensor_state_pub_ = rosnode_->advertise<turtlebot_node::TurtlebotSensorState>(\"\
    sensor_state\", 1);\n    odom_pub_ = rosnode_->advertise<nav_msgs::Odometry>(\"\
    odom\", 1);\n    joint_state_pub_ = rosnode_->advertise<sensor_msgs::JointState>(\"\
    joint_states\", 1);\n\nFinally, `rosmake` the package (make sure that you generate\
    \ a new library, erase the ROS_NOBUILD if needed (otherwise the library won't\
    \ be compiled and your changes won't be effective)\n\nHope it helps. If you found\
    \ other way to work around this (other than editing the source code), please let\
    \ me know.\n\nThanks!\n\nAna\n"
