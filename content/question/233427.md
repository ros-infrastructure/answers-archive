  body_markdown: "If you have already created the support package for your robot,\
    \ using the MoveIt! Setup Assistant, you should be able of moving your robot manually\
    \ through the Motion Planning plugin of MoveIt!.\n\nOnce you know your robot is\
    \ moving in the right way, you could program more complex trajectories from your\
    \ nodes.\n\nFor example, at the beginning you can use move_group for something\
    \ like this: \n\n     pose = Eigen::Translation3d(0.50, 0.30, 0.70)\n        \
    \        * Eigen::Quaterniond(0, 0, 0, 0);\n        group.setPoseTarget(pose);\n\
    \n        // check to see if plan successful\n        if (!group.plan(plan))\n\
    \        {\n            ROS_FATAL(\"Unable to create motion plan.  Aborting.\"\
    );\n            exit(-1);\n        }\n\n        // do non-blocking move request\n\
    \        group.move();\n\n Ater that, you can use this tutorial: http://docs.ros.org/indigo/api/pr2_moveit_tutorials/html/planning/src/doc/move_group_interface_tutorial.html\n"
