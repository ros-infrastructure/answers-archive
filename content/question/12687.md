  body_markdown: "Some simple operations can be done from the [command line](http://www.ros.org/wiki/rosbag/Commandline).\
    \ For example, if you just want to remove the camera info messages, you can do:\n\
    \n    rosbag filter orig.bag filtered.bag \"m._type != 'sensor_msgs/CameraInfo'\"\
    \n\nIf you need to mutate messages in a bag file or some other more complicated\
    \ operation, the easiest way is to write a Python script using the [rosbag code\
    \ API](http://www.ros.org/wiki/rosbag/Code%20API). Below is a script I used at\
    \ some point to replace the value of `header.frame_id` for all `CameraInfo` and\
    \ `Image` messages in one or more bags:\n\n    #!/usr/bin/env python\n    \n \
    \   PKG = 'sensor_msgs'\n    import roslib; roslib.load_manifest(PKG)\n    import\
    \ rospy\n    import rosrecord\n    import fileinput\n    import os\n    \n   \
    \ def fix(inbags):\n      for b in inbags:\n        print \"Trying to migrating\
    \ file: %s\"%b\n        outbag = b+'.tmp'\n        rebag = rosrecord.Rebagger(outbag)\n\
    \        try:\n          for (topic, msg, t) in rosrecord.logplayer(b, raw=False):\n\
    \            if msg._type == 'sensor_msgs/CameraInfo' or msg._type == 'sensor_msgs/Image':\n\
    \              msg.header.frame_id = 'l_forearm_cam_optical_frame'\n         \
    \     rebag.add(topic, msg, t, raw=False)\n            else:\n              rebag.add(topic,\
    \ msg, t, raw=False)\n          rebag.close()\n        except rosrecord.ROSRecordException,\
    \ e:\n          print \" Migration failed: %s\"%(e.message)\n          os.remove(outbag)\n\
    \          continue\n    \n        oldnamebase = b+'.old'\n        oldname = oldnamebase\n\
    \        i = 1\n        while os.path.isfile(oldname):\n          i=i+1\n    \
    \      oldname = oldnamebase + str(i)\n        os.rename(b, oldname)\n       \
    \ os.rename(outbag, b)\n        print \" Migration successful.  Original stored\
    \ as: %s\"%oldname\n    \n    if __name__ == '__main__':\n      import sys\n \
    \     if len(sys.argv) >= 2:\n        fix(sys.argv[1:])\n      else:\n       \
    \ print \"usage: %s bag1 [bag2 bag3 ...]\" % sys.argv[0]\n"

    \                                             \n        import rosbag        \

    \                                               \n        inbag = rosbag.Bag(orig,\
    \ 'r')                                           \n        outbag = rosbag.Bag(bag,\
    \ 'w')                                           \n        for t, msg, ts in inbag.read_messages():\
