  body_markdown: " I finally find out how to access to usb without typing sudo.\n\
    First of all, I create a new file in /etc/udev/rules.d named 10-mydevice.rules\
    \ and added this line inside:\n\n    ATTRS{idProduct}==\"[PRODUCT_ID]\", ATTRS{idVendor}==\"\
    [VENDOR ID]\", MODE=\"666\", GROUP=\"plugdev\"\n\nwhere VENDOR_ID and PRODUCT_ID\
    \ are specified by \n\n    lsusb -v\n\n \n\nThen I simply checked if my user was\
    \ part of plugdev group by typing \n\n    groups USERNAME\n\nFinally I saved and\
    \ closed my file and entered the following in the terminal window for refreshing\
    \ the rules:\n\n    sudo udevadm trigger\n\nRight now I can run my node by using\
    \ rosrun without root privileges or run the node from inside QtCreator!!!\nHope\
    \ this could help other people!\n "
