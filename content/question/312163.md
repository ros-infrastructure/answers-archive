  body_markdown: "You need to have a unique name in the `node` part of all of your\
    \ nodes, or put your nodes in a namespace.\n\nYou can see what your nodes are\
    \ named with the command `rosnode list`\n\nSo either change the `name` of your\
    \ nodes to something like this(add arguments for the second sensor if you want\
    \ or hard code the correct values):\n\njust to be clear, edit the name:  'node\
    \ pkg=\"ibeo_scala\" type=\"ibeo_scala\" **name=\"ibeo_scala\"**'\n\n    <?xml\
    \ version=\"1.0\"?>\n    <launch>\n      <arg name=\"frame_id\" default=\"ibeo_scala0\"\
    \ />\n      <arg name=\"ip_address\" default=\"10.152.42.111\" />\n      <arg\
    \ name=\"port\" default=\"12004\" />\n      <arg name=\"is_fusion\" default=\"\
    false\" />\n      <arg name=\"publish_raw_data\" default=\"false\" />\n    \n\
    \      <node pkg=\"ibeo_scala\" type=\"ibeo_scala\" name=\"ibeo_scala0\">\n  \
    \      <param name=\"sensor_frame_id\" value=\"$(arg frame_id)\" />\n        <param\
    \ name=\"ip_address\" value=\"$(arg ip_address)\" />\n        <param name=\"port\"\
    \ value=\"$(arg port)\" />\n        <param name=\"is_fusion\" value=\"$(arg is_fusion)\"\
    \ />\n        <param name=\"publish_raw_data\" value=\"$(arg publish_raw_data)\"\
    \ />\n      </node>\n    \n      <node pkg=\"ibeo_scala\" type=\"ibeo_scala\"\
    \ name=\"ibeo_scala1\">\n        <param name=\"sensor_frame_id\" value=\"ibeo_scala1\"\
    \ />\n        <param name=\"ip_address\" value=\"10.152.42.112\" />\n        <param\
    \ name=\"port\" value=\"12005\" />\n        <param name=\"is_fusion\" value=\"\
    $(arg is_fusion)\" />\n        <param name=\"publish_raw_data\" value=\"$(arg\
    \ publish_raw_data)\" />\n      </node>\n    </launch>\n\n `rosnode list` would\
    \ output something like\n\n    /rosout\n    /ibeo_scala0\n    /ibeo_scala1\n\n\
    You could also add a namespace to the node, so the relevant lines would be something\
    \ like \n\n    ....\n    <node ns=\"sensor0\" pkg=\"ibeo_scala\" type=\"ibeo_scala\"\
    \ name=\"ibeo_scala\">\n    ....\n    </node>\n    <node ns=\"sensor1\" pkg=\"\
    ibeo_scala\" type=\"ibeo_scala\" name=\"ibeo_scala\">\n    ....\n    </node>\n\
    \n `rosnode list` output in this case would be something like\n\n    /rosout\n\
    \    /sensor0/ibeo_scala\n    /sensor1/ibeo_scala\n\n**After getting the nodes\
    \ running in either way you will also need to configure rviz to use the correct\
    \ names**\n\n\n----------\nRegarding both nodes publishing to the same topic:\n\
    \nIf you ran the nodes with different names instead of namespaces then this is\
    \ expected and you would need to add [remaps](http://wiki.ros.org/roslaunch/XML/remap)\
    \ to the node. Something like:\n\n    ....\n    <node ns=\"sensor0\" pkg=\"ibeo_scala\"\
    \ type=\"ibeo_scala\" name=\"ibeo_scala\">\n    <remap from=\"as_tx/point_cloud\"\
    \ to=\"as_tx0/point_cloud\"/>\n    ....\n    </node>\n    <node ns=\"sensor1\"\
    \ pkg=\"ibeo_scala\" type=\"ibeo_scala\" name=\"ibeo_scala\">\n    <remap from=\"\
    as_tx/point_cloud\" to=\"as_tx1/point_cloud\"/>\n    ....\n    </node>\n\nif you\
    \ run the nodes in different namespaces and the node is coded sensibly you shouldn't\
    \ need to remap them, the topics should appear in the namespaces like\n\n    /sensor0/as_tx/point_cloud\n\
    \    /sensor1/as_tx/point_cloud\n\nIf they don't appear in the namespace you would\
    \ need to change the code of the node or add remaps."
