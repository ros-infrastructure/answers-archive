    Did you calibrate the cameras? You should do that first so that you get some information about the cameras themselves. ROS by default doesn't know much about the camara you are plugin in. To start with the calibration run:

    ```
    rosrun camera_calibration cameracalibrator.py --size 8x6 --square 0.108 image:=/my_camera/image camera:=/my_camera
    ```

    With the appropriate topics. You'll need a 8x6 chessboard with 108mm or the size you prefer, make sure to check the `--size` and `--square` parameters. An example chessboard panel is [this one](http://wiki.ros.org/camera_calibration/Tutorials/MonocularCalibration?action=AttachFile&do=view&target=check-108.pdf). Use it to calibrate the camaras and then you'll have some info about your cameras like distorsion and else.
