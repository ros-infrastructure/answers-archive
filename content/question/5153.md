    You can do this programmatically using the physics API if you have a pointer to the Joint object. See the [Joint::SetHighStop](http://gazebosim.org/api/2.0.0/classgazebo_1_1physics_1_1Joint.html#a59848678cdca37a851e782f170f55c2b) and [Joint::SetLowStop](http://gazebosim.org/api/2.0.0/classgazebo_1_1physics_1_1Joint.html#aeb7b0117576037c075c68cf4cf6e5282) commands. There is an example of using these commands in one of the physics tests ([test/integration/physics.cc:848](https://bitbucket.org/osrf/gazebo/src/default/test/integration/physics.cc#cl-848)).

    So my approach would be to get a pointer to the joint object, read the current joint position, then set the joint limits to be equal to the current position.

    <code><pre>
    gazebo::physics::JointPtr joint;
    joint = getTheJointPtrSomehow();
    // Get the current joint position
    gazebo::math::Angle currentPosition = joint->GetAngle(0);
    joint->SetHighStop(0, currentPosition);
    joint->SetLowStop(0, currentPosition);
    </pre></code>

    That's how I would do it currently. It would be nice to have an API that would do this automatically. Please make a feature request on the [bitbucket issue tracker](https://bitbucket.org/osrf/gazebo/issues?status=new&status=open) if you have an idea for how you would like it to work.
