  body_markdown: |
    You're not setting the `id` field (see [docs/api/visualization_msgs/Marker](http://docs.ros.org/jade/api/visualization_msgs/html/msg/Marker.html)), so it will default to `0` and makes both your markers use the same id. RViz receives a message containing a marker with the same id, and interprets it as an 'update' to the same marker it saw before. Result: you see only a single marker.
