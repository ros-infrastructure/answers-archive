  body_markdown: "Hello,\n\nIf you have hector_trajectory_server, a node that control\
    \ the robot and a node that save the file, you can do what you want with [bond](http://wiki.ros.org/bond).\n\
    \nBond allow you to make 2 nodes notified each other if one die.\nSo your software\
    \ flow will be like this : \n\nRun Hector, Controller and Logger > Bond Logger\
    \ and Controller > Wait > Controller Die and notify Logger > Logger Subscribe\
    \ to Hector Path and save to a file > Logger die > ? > Profit.\n\n\n----------\n\
    \n\nEdit : Found a second possible solution : \n\nFor cpp : Subscribe to the path\
    \ topic at the beginning but do nothing while a flag is false, then define a [custom\
    \ SIGINT handler (2.2.1)](http://wiki.ros.org/roscpp/Overview/Initialization%20and%20Shutdown),\
    \ where you put the flag to true to save the path to a file and shutdown the node\
    \ cleanly.\n\nFor Python : Do a callback where you subscribe to the topic and\
    \ save it in a file and put this callback in : `rospy.is_shutdown()` , to do some\
    \ work before shutting down ([Documentation 2.2)](http://wiki.ros.org/rospy/Overview/Initialization%20and%20Shutdown)"
