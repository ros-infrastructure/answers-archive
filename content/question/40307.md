    I had similar problems. When you run lsusb on TurtleBot laptop do you see a list of three microsoft corporation devices referring to the Kinect ?. If no, the TurtleBot is not fully up. Bring-up the TurtleBot either using minimal launch or service start and wait for the second beep from create. Now the dashboard should work properly.
