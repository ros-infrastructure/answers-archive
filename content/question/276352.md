  body_markdown: |-
    For a compressed image, the byte stream in the `data` array is the jpeg compressed representation of the image. To use it with OpenCV, this jpeg representation first has to be decompressed to a uncompressed representation. Luckily, this is made transparent by the image_transport mechanism, so this is taken care of for you if you use that. Have a look at [compressed_image_transport](http://wiki.ros.org/compressed_image_transport).

    If you're a beginner, just keep in mind that every third data value represents the color Red, every third+1 data value represents Green and every third+2 data value represents the color Blue. While imagining image_raw.data array as real image, you should think that first three data values denote the intensity of Red, Green and Blue of the first pixel, next three data values denote intensity of Red, Green and Blue of the second pixel, and so on. You can cross check this by making a simple node and running it with image_view, or you can see what I did over [here](https://github.com/Kanishk598/Ubuntu-and-ROS)
