  body_markdown: "The map is a [costmap](http://www.ros.org/wiki/costmap_2d). The\
    \ purpose behind the costmap is to have the local area around the robot freshly\
    \ mapped to prevent collision with a dynamic object. The costmap also inflates\
    \ the objects in the costmap to the user specified inflation radius. You can see\
    \ it as a published topic, even in rviz. The Odom is not the same as the localized\
    \ pose. [Odom](http://www.ros.org/wiki/navigation/Tutorials/RobotSetup/Odom) starts\
    \ when the motors turn. This is the robot's odometry frame. The robot localizes\
    \ to the global frame. "
