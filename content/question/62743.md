  body_markdown: "Launch file is useful when you want to start/launch many nodes at\
    \ once without any need to do \"rosrun for every node\".\n\nIn the package, create\
    \ a folder by the name launch and create a filename.launch file.\n\nIt always\
    \ start with \n\n\n     <launch>\n\nand if some parameters should be set then\n\
    \n    <param name=\"use_sim_time\"  value=\"true\" />\n\nTo start a node \n\n\
    \    <node pkg=\"name_of_package\" type=\"name_of_packge\" name=\"name_of_executable\"\
    \ \n    output=\"screen\"/>\n\nExample     \n   \n    <node pkg=\"sure_on_cloud\"\
    \ type=\"estimate_transform_svd\" name=\"estimate_transform_svd\" \n    output=\"\
    screen\"/>\n\nIn the above way, one can call multiple nodes from different packages.\n\
    \n\n\n\n<remap from=\"/camera/depth/image_rect_raw\" to=\"/camera/depth/image\"\
    />\n\nNodelets can also be initialized. Sorry I dont know what they are, but they\
    \ can also be initialized from the example below\n\n      <node pkg=\"nodelet\"\
    \ type=\"nodelet\" name=\"standalone_nodelet\"  args=\"manager\"/>\n\n     <node\
    \ pkg=\"nodelet\" type=\"nodelet\" name=\"point_cloud_xyz\"\n        args=\"load\
    \ depth_image_proc/point_cloud_xyz standalone_nodelet\">\n  \nSome packages have\
    \ their topics already set to specific names. They can be remapped to different\
    \ names.\n  \n    <remap from=\"/image_rect\" to=\"/camera/depth/image\"/>\n \
    \   <remap from=\"/points\" to=\"/camera/depth/points\"/>\n    <remap from=\"\
    /camera_info\" to=\"/camera/depth/camera_info\"/>\n  \n\n\n\n\n </node>\n\n</launch>"
