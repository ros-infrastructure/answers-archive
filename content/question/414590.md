    > I am a first time user of ROS and I wanted to know if i could install the ROS platform on a windows PC?

    As I wrote in #q414656, if you're just starting out (and it seems you are just starting with ROS), I would *not* recommend trying to use Windows with ROS 1.

    If this is ROS 2, you have a somewhat bigger chance of getting things working, but realistically, I would probably still recommend you get started using Ubuntu.

    While it would require installing Linux on a PC/laptop, you will have a *much* smoother experience and a (very) large community to help you out if you post questions.
