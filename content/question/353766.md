I have a node that analyzes <code>rosout_agg</code> messages to benchmark the robot's performance. I'd like to incorporate these benchmarks into a test, but it seems that the <code>rosout</code> node is not started under <code>rostest</code>, and so <code>rosout_agg</code> is never published. (If I subscribe directly to <code>rosout</code>, my node works the same under <code>rostest</code> and <code>roslaunch</code>.)

Is this the intended behavior? Is there a way to tell <code>rostest</code> that I do want <code>rosout</code> launched?
