    You can use the [Rosbag API](http://wiki.ros.org/rosbag/Code%20API) to do what you want. If you look at the bottom of the page, the Python API returns the time that the message was recorded (`t` in the example). Probably there's something equivalent in the C++ API, too.

    However, if you have the chance to repeat your experiment, it would be much better to fix the publisher of the `odom` topic so that it includes the actual time stamp in the header, and then record a fresh rosbag. This will be necessary in the long run anyways, since many nodes working with odom data expect the time stamp to be valid. Also, it will lead to more precise time stamps: you typically want to know when your sensor produced the measurement, not when rosbag recorded it.

    \ that adds the missing \"timestamp\" info to the `sensor_msgs/Imu` Message.\n\
    \n    import os\n    import sys\n    \n    import rosbag\n    \n    def print_usage():\n\
    \        print(\"Usage: fixbag.py <ros bag> <target topic>\")\n        print(\"\
    Usage: fixbag.py recorded.bag /robot/imu\")\n    \n    \n    if __name__ == \"\
    __main__\":\n        # Check CLI args\n        if len(sys.argv) != 3:\n      \
    \      print_usage()\n            exit(-1)\n    \n        bag_path = sys.argv[1]\
    \  # Path to ROS bag you want to repair\n        target_topic = sys.argv[2]  #\
    \ Target topic you want to repair\n        repair_path = bag_path.replace(\".bag\"\
    , \"-repaired.bag\")  # Output bag path\n    \n        # Open bag\n        bag\
    \ = rosbag.Bag(bag_path, 'r')\n        fix_bag = rosbag.Bag(repair_path, \"w\"\
    )  # Create a repaired bag\n        \n        # Iterate through bag\n        for\
    \ topic, msg, t in bag.read_messages():\n            # Add time back to the target\
    \ message header\n            if topic == target_topic:\n                msg.header.stamp.secs\
    \ = t.secs\n                msg.header.stamp.nsecs = t.nsecs\n    \n         \
    \   # Write message to bag\n            fix_bag.write(topic, msg, t)\n    \n \
    \       # Close bag - Very important else you'll have to reindex it\n        fix_bag.close()"
