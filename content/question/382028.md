  body_markdown: "It's automatically evaluated in the launch phase, so generally,\
    \ you don't have to care about it.\n\nIf you'd like to print the value for debugging,\
    \ you can use `OpaqueFunction`.  \nRelated: https://answers.ros.org/question/322636/ros2-access-current-launchconfiguration/\n\
    \nI put a minimal example here.\n\n    # false\n    $ ros2 launch sample.launch.py\
    \ use_sim_time:=false\n    use_sim_time: false\n\n    $ ros2 param get /publisher\
    \ use_sim_time \n    Boolean value is: False\n\n    # true\n    $ ros2 launch\
    \ sample.launch.py use_sim_time:=true\n    use_sim_time: true\n\n    $ ros2 param\
    \ get /publisher use_sim_time \n    Boolean value is: True\n\nThe launch file\
    \ is:\n\n    from launch import LaunchDescription\n    from launch.actions import\
    \ DeclareLaunchArgument, OpaqueFunction\n    from launch.substitutions import\
    \ LaunchConfiguration\n    from launch_ros.actions import Node, SetParameter\n\
    \n\n    def launch_setup(context, *args, **kwargs):\n        use_sim_time = LaunchConfiguration(\"\
    use_sim_time\")\n        print(f\"use_sim_time: {use_sim_time.perform(context)}\"\
    )\n        set_use_sim_time = SetParameter(name=\"use_sim_time\", value=use_sim_time)\n\
    \n        node = Node(\n            package=\"examples_rclcpp_minimal_publisher\"\
    ,\n            executable=\"publisher_lambda\",\n            name=\"publisher\"\
    ,\n        )\n\n        return [\n            set_use_sim_time,\n            node,\n\
    \        ]\n\n\n    def generate_launch_description():\n        return LaunchDescription(\n\
    \            [\n                DeclareLaunchArgument(\"use_sim_time\", default_value=\"\
    false\"),\n                OpaqueFunction(function=launch_setup),\n          \
    \  ]\n        )\n"
