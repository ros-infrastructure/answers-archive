    usb_cam and gscam are not appropriate for what you're trying to do; they're for using webcams that you connect to your computer using USB.

    I'm not aware of a ROS driver for the SJ4000. It looks like a fairly new camera, so I suspect no one has developed a ROS driver for it yet. You'll probably need to write your own driver.

    A few places to start:

     * Go through the ROS C++ tutorials
     * Figure out how to retrieve images from your camera. Start with the basics, and work up to a C++ program which can receive raw images and display them on screen using OpenCV.
     * Convert your program into a C++ ROS node which receives images and publishes them using [image_transport](http://wiki.ros.org/image_transport). Start with the [image_transport publisher tutorial](http://wiki.ros.org/image_transport/Tutorials/PublishingImages). Once you have that working, upgrade to the `image_transport::CameraPublisher`.
     * Read through the [camera_info_manager tutorial](http://wiki.ros.org/camera_info_manager/Tutorials/UsingCameraInfoManagerInCameraDriver%28C%2B%2B%29). This library helps your driver store and publish calibration data, which will allow you to calibrate your camera later.
