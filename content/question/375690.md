  body_markdown: "You need to install the can_msgs package to your ros workspace.\
    \ \n\n`sudo apt install ros-$ROS_DISTRO-can-msgs`\n\n`source /opt/ros/$ROS_DISTRO/setup.bash`\n\
    \nMake sure to clean up your local ros workspace (i.e. remove build/ install/\
    \ log/) before `colcon build`.\n\nTo see all the packages you have installed to\
    \ your machine: \n\n`ls /opt/ros/$ROS_DISTRO/include/` and `ls /opt/ros/$ROS_DISTRO/share`.\n"
