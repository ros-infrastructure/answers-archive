    What you mean by using  Hokuyo via WiFi?

    If it is connected to your robot or any other remote computer running ROS, you can join the same WiFi and ROS network by setting `ROS_MASTER_URI` and `ROS_IP` environment variables. Once you are connected you can get scan messages, or configure your Hokuyo using dynamic reconfigure plugin in `rqt`.
