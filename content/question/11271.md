  body_markdown: "I don't know how if it is possible in a clean way. A quick and dirty\
    \ hack for Linux would be the misuse of the launch-prefix attribute. \n\nIn your\
    \ package foo, create a file named kickstart with the content\n\n    #!/bin/bash\n\
    \    rosservice call --wait /global_localization &\n    exec \"$@\"\n\nThen, make\
    \ it executable using\n\n    chmod +x kickstart\n\nFinally, add the following\
    \ attribute to one of your <node> declarations in the launch file:\n\n    launch-prefix=\"\
    $(find foo)/kickstart\"\n\nThis will coax roslaunch into executing the kickstart\
    \ script with the real node launch command line as parameters. The script performs\
    \ the service call and executes the remainder of the command line, thus launching\
    \ the node. \n\nThe --wait parameter ensures that the service is actually available,\
    \ and the ampersand at the end of the rosservice line runs the call in the background,\
    \ so the node launch will not be delayed.\n"
