    No, you don't need `points_size` . You need to set the size of the `points` vector within the `marker` object. Since `points` is a `std::vector`, I would start with the [std::vector documentation](http://en.cppreference.com/w/cpp/container/vector).

    From the `std::vector` documentation, you should look for a method that sets the size of the vector, and you should find the [resize method](http://en.cppreference.com/w/cpp/container/vector/resize). Now you know that the proper way to set the size of `marker.points` is `marker.points.resize(2)`
