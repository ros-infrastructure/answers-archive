  body_markdown: "The std_msgs/Float64MultiArray message should do what you want:\n\
    \nhttp://docs.ros.org/api/std_msgs/html/msg/Float64MultiArray.html\n\nThe message\
    \ structure has a single field called `data` which can be treated as a `std::vector<double>`\
    \ type in your C++ node.  If you know it will be a fixed array of 9 values, just\
    \ allocate 9 elements in the vector after declaring the message variable:\n\n\
    \    std_msgs::Float64MultiArray array_msg;\n    array_msg.data.resize(9);\n\n\
    You can then publish and subscribe to a topic to transmit array messages between\
    \ your nodes.  \n\nI hope this helps!"
