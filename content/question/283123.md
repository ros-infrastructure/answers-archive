    It is new convention in catkin package format 2. Basically the `<run_depend>` tag was replaced by `<exec_depend>`.

    To define format 2 package replace `<package>` tag in your `package.xml` file with `<package format="2">`.

    For more information have a look at the documentation [here](http://docs.ros.org/jade/api/catkin/html/howto/format2/index.html) and migration guide from format 1 to format 2 [here](http://docs.ros.org/jade/api/catkin/html/howto/format2/migrating_from_format_1.html).
