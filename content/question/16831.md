    You can use [gzweb](http://gazebosim.org/gzweb) and host the simulation on a public server, so anyone with the URL will be able to interact with the simulation at the same time via web browsers.

    You can also use the usual Gazebo client (`gzclient`), but this requires more setting up on every user's side, they need a full install of Gazebo and to point `GAZEBO_MASTER_URI` to the address running `gzserver`. You can read more about these components [here](http://gazebosim.org/tutorials?tut=components).
