    \ Nevermind.\n\n**1. 'PyString_FeomString' was not declared** \n\n> error: 'PyString_FeomString'\

    \ As you are using Ubuntu 20.04, I am doubtful about `PyString_FromString` , because\
    \ the [PyString_FromString doesn't work in Python3.5](https://stackoverflow.com/q/48849047).\
    \ The workaround is to use `PyUnicode_FromString`, which is given [here](https://docs.python.org/3/c-api/unicode.html#c.PyUnicode_FromString).\n\
    \n\n**2. \"rtcm_msgs\" not found**\n\n> Could not find a package configuration\
    \ file provided by \"rtcm_msgs\" with any of the following names:\n\nThe package\
    \ [ublox/ublox_gps](https://github.com/KumarRobotics/ublox/tree/master/ublox_gps)\
    \ uses `rtcm_msgs`, which has been mentioned in the [CMakeLists.txt](https://github.com/KumarRobotics/ublox/blob/7f592601166d9ddc2e96ad6d986d449e11ce6561/ublox_gps/CMakeLists.txt#L10)\

    \ installed in your machine. Please install it using `apt` as shown below:\n\n\
