    You should use [ControllerManager](https://github.com/ros-controls/ros_control/blob/noetic-devel/controller_manager/include/controller_manager/controller_manager.h) class which provides this services. Other then that, if you want to use ros_control framework you probably need to implement your [RobotHW](https://github.com/ros-controls/ros_control/blob/noetic-devel/hardware_interface/include/hardware_interface/robot_hw.h) Class (usually implements also ControllerManager). You can use [FakeJoint](https://github.com/tork-a/fake_joint) implementation to fake the hardware. This is often used with MoveIt for off-line testing without simulation, i.e., with very rudimentary "simulation".

    Let me know if you need additional information.
