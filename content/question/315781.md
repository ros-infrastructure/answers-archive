    To my knowledge, ROS uses only URDF, which Gazebo converts to SDF as explained in [this answer](https://answers.ros.org/question/258625/connect-gazebo-sdf-model-to-ros/). If you want to control your robot with ROS and MoveIt, you will [need to use]([Another answer](https://answers.ros.org/question/228873/urdf-and-sdf/) ) URDF. I have had little or no trouble adding the gazebo-specific elements to my URDF files in the past, though.

    All the robot definition files that I know of deliver URDF files. This [blog post](https://newscrewdriver.com/2018/07/31/ros-notes-urdf-vs-gazebo-sdf/) helpfully links [this Discord thread](https://discourse.ros.org/t/urdf-ng-ros2-urdf2-discussion/511/32), which seems to imply that URDF will at least be available in ROS2 as well.

I'm using ROS Melodic and Gazebo 9.6.0.

 I've just started to learn ROS and Gazebo.

Reading the [URDF XML specifications](http://wiki.ros.org/urdf/XML), I have found that there is a [Gazebo tag](http://wiki.ros.org/urdf/XML/Gazebo). On its description said: "For full documentation of the Gazebo element, see [Using A URDF In Gazebo](http://gazebosim.org/tutorials?tut=ros_urdf&cat=connect_ros)."

On that tutorial, Using A URDF in Gazebo, they recommend to use SDF instead of URDF because: "a new format called the Simulation Description Format (SDF) was created for use in Gazebo to solve the shortcomings of URDF".

What do you recommend? Do I have to use URDF to describe the robot and its plugins or is it better to use SDF?
