    The `Twist` message as no field named `data`. I know that you took this example from the python tutorial on subscribers. That tutorial use a [String.msg](http://docs.ros.org/jade/api/std_msgs/html/msg/String.html) as you can see this as a field named `data`. The [Twist.msg](http://docs.ros.org/api/geometry_msgs/html/msg/Twist.html) as two data fields, linear and angular. which are [Vector3.msg](http://docs.ros.org/api/geometry_msgs/html/msg/Vector3.html)
    which contain 3 float64 numbers. So to clear it up to get the 'X' value, you would do the following.

        data.linear.x
