    There's a parameter `Grid/CellSize` whose value can be modified from the default 0.05 ([source code](https://github.com/introlab/rtabmap/blob/master/corelib/include/rtabmap/core/Parameters.h#L734)).

    As stated in the [documentation](http://wiki.ros.org/rtabmap_ros/#rtabmap), call the node `rtabmap` with `--params` to show all available parameters.

             <param name="Grid/CellSize" value="0.1"/>
          </node>
