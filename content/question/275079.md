  body_markdown: "From the [`robot_state_publisher` wiki](http://wiki.ros.org/robot_state_publisher):\n\
    \n> `robot_state_publisher` uses the URDF specified by the parameter `robot_description`\
    \ and the joint positions from the topic `joint_states` to calculate the forward\
    \ kinematics of the robot and publish the results via [tf](http://wiki.ros.org/tf).\n\
    \nFrom the [`joint_state_publisher` wiki](http://wiki.ros.org/joint_state_publisher):\n\
    \n> This package publishes `sensor_msgs/JointState` messages for a robot. The\
    \ package reads the `robot_description` parameter, finds all of the non-fixed\
    \ joints and publishes a `JointState` message with all those joints defined.\n\
    > \n> Can be used in conjunction with the `robot_state_publisher` node to also\
    \ publish transforms for all joint states.\n\nBasically, the `robot_state_publisher`\
    \ publishes the `tf` transforms of your robot based on its URDF file. You can\
    \ also publish the joint states using the `joint_state_publisher` or do it yourself.\
    \ Either way, the `robot_state_publisher` uses this information to calculate the\
    \ forward kinematics of your robot.\n\n---\n\n**Update:**\n\nIf you want to publish\
    \ your own `sensor_msgs/JointState` messages then take a look at [this tutorial](http://wiki.ros.org/urdf/Tutorials/Using%20urdf%20with%20robot_state_publisher#Publishing_the_State)."
