  body_markdown: "This is not ideal, but one trick is to also add a `<script><trajectory>`\
    \ with 2 waypoints that have the same pose. [Here's an example](https://github.com/osrf/citysim/blob/3928b08e2598f5ead2e9b24640fe1bde262a136d/worlds/simple_city.world#L13761-L13786):\n\
    \n      <actor name=\"talkingA\">\n        <pose>5 5 5.76 0 0 0</pose>\n     \
    \   <skin>\n          <filename>model://actor/meshes/SKIN_man_blue_shirt.dae</filename>\n\
    \        </skin>\n        <animation name=\"animation\">\n          <filename>model://actor/meshes/ANIMATION_talking_a.dae</filename>\n\
    \          \n        </animation>\n          <script>\n            <trajectory\
    \ id=\"0\" type=\"animation\">\n              \n                <waypoint>\n \
    \                 <time>100</time>\n                  <pose>5 5 5.16 0 0 0</pose>\n\
    \                </waypoint>\n              \n                <waypoint>\n   \
    \               <time>100</time>\n                  <pose>5 5 5.16 0 0 0</pose>\n\
    \                </waypoint>\n              \n            </trajectory>\n    \
    \      </script>\n      </actor>"
