    Unfortunately, this is currently a limitation of spotlights in Gazebo. There is an [issue](https://bitbucket.org/osrf/gazebo/issues/2083/point-and-spot-lights-dont-cast-shadows) ticketed for this, you could vote for it so it starts getting more attention.

    Meanwhile, you could try using directional lights, if possible.
