  body_markdown: "Hi Omer,\n\nWhat I understand from your question is that you want\
    \ to launch two instances of robot_localization for two different robots by launching\
    \ then under different name_spaces. \n\nTo launch the robot_localization node\
    \ under a name_space you can use [<group> tag](http://wiki.ros.org/roslaunch/XML/group)\
    \ or you can pass argument __ns (args=\"__ns=name_space\"). After this your launch\
    \ file would include:\n\n    <node ns=\"bot1\" pkg=\"robot_localization\" type=\"\
    ekf_localization_node\" name=\"ekf_localization\">\n      <rosparam command=\"\
    load\" file=\"$(find jackal_control)/config/robot_localization_bot1.yaml\" />\n\
    \    </node>   \n    <node ns=\"bot2\" pkg=\"robot_localization\" type=\"ekf_localization_node\"\
    \ name=\"ekf_localization\">\n     <rosparam command=\"load\" file=\"$(find jackal_control)/config/robot_localization_bot2.yaml\"\
    \ />\n    </node>\n\nafter this you would need to modify your yaml files accordingly,\
    \ \n\n\n\n    frequency: 50\n    odom0: /jackal_velocity_controller/odom   #odom\
    \ source for respective robot\n    odom0_config: [false, false, false,\n    false,\
    \ false, false,\n    true, true, true,\n    false, false, true,\n    false, false,\
    \ false]\n    odom0_differential: false\n    imu0: /imu/data #imu source for respective\
    \ bot\n    imu0_config: [false, false, false,\n    true, true, true,\n    false,\
    \ false, false,\n    true, true, true,\n    false, false, false]\n    imu0_differential:\
    \ false\n    odom_frame: odom  # fixed frame for robot (this can be same for both)\n\
    \    base_link_frame: base_link #fixed frame for robot (this should be diffenret\
    \ for both)\n    world_frame: odom #again same is fine \n\nmake sure that you\
    \ publish static transforms between IMU frame and baselink for both the robots\
    \ \n\nHope this helps."
