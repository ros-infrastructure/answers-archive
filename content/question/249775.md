  body_markdown: "The right way to decode compressedDepth is to first remove the header\
    \ from the raw data and then convert the remaining data.\n\nThis is documented\
    \ in [image_transport_plugins/compressed_depth_image_transport/src/codec.cpp](https://github.com/ros-perception/image_transport_plugins/blob/indigo-devel/compressed_depth_image_transport/src/codec.cpp).\
    \ On my machine the header size is 12 bytes. This might however be different on\
    \ other architectures since the size of an enum is not defined.\n\nThe following\
    \ python code snippet exports compressed 16UC1 and 32FC1 depth images as png file:\n\
    \n    # 'msg' as type CompressedImage\n    depth_fmt, compr_type = msg.format.split(';')\n\
    \    # remove white space\n    depth_fmt = depth_fmt.strip()\n    compr_type =\
    \ compr_type.strip()\n    if compr_type != \"compressedDepth\":\n        raise\
    \ Exception(\"Compression type is not 'compressedDepth'.\"\n                 \
    \       \"You probably subscribed to the wrong topic.\")\n    \n    # remove header\
    \ from raw data\n    depth_header_size = 12\n    raw_data = msg.data[depth_header_size:]\n\
    \    \n    depth_img_raw = cv2.imdecode(np.fromstring(raw_data, np.uint8), cv2.CV_LOAD_IMAGE_UNCHANGED)\n\
    \    if depth_img_raw is None:\n        # probably wrong header size\n       \
    \ raise Exception(\"Could not decode compressed depth image.\"\n             \
    \           \"You may need to change 'depth_header_size'!\")\n    \n    if depth_fmt\
    \ == \"16UC1\":\n        # write raw image data\n        cv2.imwrite(os.path.join(path_depth,\
    \ \"depth_\" + str(msg.header.stamp) + \".png\"), depth_img_raw)\n    elif depth_fmt\
    \ == \"32FC1\":\n        raw_header = msg.data[:depth_header_size]\n        #\
    \ header: int, float, float\n        [compfmt, depthQuantA, depthQuantB] = struct.unpack('iff',\
    \ raw_header)\n        depth_img_scaled = depthQuantA / (depth_img_raw.astype(np.float32)-depthQuantB)\n\
    \        # filter max values\n        depth_img_scaled[depth_img_raw==0] = 0\n\
    \    \n        # depth_img_scaled provides distance in meters as f32\n       \
    \ # for storing it as png, we need to convert it to 16UC1 again (depth in mm)\n\
    \        depth_img_mm = (depth_img_scaled*1000).astype(np.uint16)\n        cv2.imwrite(os.path.join(path_depth,\
    \ \"depth_\" + str(msg.header.stamp) + \".png\"), depth_img_mm)\n    else:\n \
    \       raise Exception(\"Decoding of '\" + depth_fmt + \"' is not implemented!\"\
    )"
