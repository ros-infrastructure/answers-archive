  body_markdown: "It's certainly should be possible. ROS Jade has been tested on Vivid\
    \ (15.04).\n\nHowever since Vivid has reached it's End-Of-Life there's no active\
    \ support for it from Ubuntu/Canonical or from the ROS community. \n\nFurthermore\
    \ it will require a lot of patience as binaries are not available for ARM architecture\
    \ on Vivid so you will need to compile from source.\n\nI would strongly recommend\
    \ considering using a currently supported Ubuntu distro. Such as Xenial 16.04.\
    \ And then you'll find ROS Kinetic packages available for the Odroid including\
    \ visp: http://repositories.ros.org/status_page/ros_kinetic_uxv8.html?q=visp"
