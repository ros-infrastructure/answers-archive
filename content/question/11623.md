    There are two main broken dependencies for installing electric (with the natty repository) in oneiric:

    libglut3-dev (needed for geometry funcionality)
    libopencv2.3-dev (needed for vision functionality)

    The first one can be easily (and temporally)solved installing manually libglut3-dev:
    https://launchpad.net/ubuntu/oneiric/+package/libglut3-dev

    Then electric-desktop and some basic functionality can be installed. However the electric-desktop-full cannot be installed due to the second broken dependency. A temporal solution can be install libopencv2.3-dev from some ppa like: https://launchpad.net/~gijzelaar/+archive/opencv2.3
