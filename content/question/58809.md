    \ of message that cmdvel_cb (in RosAria.cpp) needed, so I rewrote this function.\

    \ the comments on locking and unlocking the robot, so it's possible now to move\
    \ it around :)\n\nAnd my cmdvel_cb looks now like this: \n\n    void RosAriaNode::cmdvel_cb(\
    \ const geometry_msgs::Twist &msg)\n    {\n      veltime = ros::Time::now();\n\
    \      ROS_INFO( \"new speed: [%0.2f,%0.2f](%0.3f)\", msg.linear.x*1e3, msg.angular.z,\
    \ veltime.toSec() );\n    \n      robot->lock();\n      robot->setVel(msg.linear.x*1e3);\n\
    \      robot->setRotVel(msg.angular.z*180/M_PI);\n      robot->unlock();\n   \
    \ }\n\nHope this helps anyone, that would like to make use of RosAria with PeopleBot\
