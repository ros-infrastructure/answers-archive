Update:
Here's how I built ros-fuerte:
<pre>
sudo pip install -U rosinstall
rosinstall --catkin ~/ros-underlay http://ros.org/rosinstalls/fuerte-ros-full.rosinstall
cd ~/ros-underlay
mkdir build
cd build
cmake .. -DCMAKE_INSTALL_PREFIX=/opt/ros/fuerte -DSETUPTOOLS_DEB_LAYOUT=OFF
cd ..
make -j8
sudo make install
</pre>

That's pretty much what the ros wiki describes. I've left out installing necessary dependencies, of course. Running <i>rosversion ros</i> gives me 1.8.9.
