  body_markdown: "Try to set your local planner to DWA from your base_local_planner_params.yaml.\
    \ So the following line in your move_base.launch **should be removed:**\n\n  \
    \  <param name=\"base_local_planner\" value=\"dwa_local_planner/DWAPlannerROS\"\
    \ />\n\ninstead in your **base_local_planner_params.yaml** put the following:\n\
    \n    dwa: true\n\nAlthough navigation stack by default uses dynamic window approach\
    \ meaning that the value for dwa parameter is true if it is not set by user. For\
    \ more info please take a look at base_local_planner documentation: [http://wiki.ros.org/base_local_planner?distro=indigo](http://wiki.ros.org/base_local_planner?distro=indigo)\
    \  \n\nhope it helps"
