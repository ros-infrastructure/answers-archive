    gzweb's websocket server's address is currently hardcoded to 7681 so you'll probably need to manually change it to a differnt port for each gzweb you run. Here's the port number on [server side](https://bitbucket.org/osrf/gzweb/src/501c03e86181c72311dc2b70582ed6018d604ee5/gzbridge/ws_server.js?at=default&fileviewer=file-view-default#ws_server.js-37), and you'll need to update the [client side](https://bitbucket.org/osrf/gzweb/src/501c03e86181c72311dc2b70582ed6018d604ee5/gz3d/src/gziface.js?at=default&fileviewer=file-view-default#gziface.js-32) too.
