    This particular message seems to come from dynamic_reconfigure generation.

    The fix is to [change the cfg file](http://www.ros.org/wiki/dynamic_reconfigure/Tutorials/HowToWriteYourFirstCfgFile#dynamic_reconfigure.2BAC8-Tutorials.2BAC8-HowToWriteYourFirstCfgFile.2BAC8-rosbuild.The_cfg_File). In place of:

        from dynamic_reconfigure.parameter_generator import *

    catkin packages should use:

        from dynamic_reconfigure.parameter_generator_catkin import *
