  body_markdown: "Linear interpolation for tool space movements is often accomplished\
    \ by using the \u201CLinear Segments with Parobolic Blends\u201D (LSPB) method.\
    \ Such a method is required to account for physical motor limitations such as\
    \ instantaneous velocity changes. Refer to chapter five in this text in http://bayanbox.ir/view/8445052974254475991/Robot-Modeling-and-Control-Spong.pdf.\
    \ Page 177 introduces Linear Segments with Parobolic Blends. Use these equations\
    \ in tool space (Cartesian xyz).\n\nthis is also a good trajectory generation\
    \ source http://www-lar.deis.unibo.it/people/cmelchiorri/Files_Robotica/FIR_07_Traj_4.pdf\n\
    \nStep 1) define goal points (i.e. taught points..)\nStep 2) solve LSPB along\
    \ the vectors connecting the goal points (solving x, y, z components independently)\
    \ which gives all the needed waypoints\nStep 3) convert each waypoint to joint\
    \ space using IK."

    In the DRC we used piecewise linear cartesian motions to approximate circular motion. A helper function for this is [getCircularArcPoses](https://github.com/team-vigir/vigir_manipulation_planning/blob/master/vigir_moveit_utils/include/vigir_moveit_utils/constrained_motion_utils.h#L49) , which just generates poses lying on a circular arc. An example of it being called is [here](https://github.com/team-vigir/vigir_manipulation_planning/blob/264b63e53f6631ca9ffe19976fd3949630ce3600/vigir_move_group/src/manipulation_action_capability.cpp#L612). The poses are then forwarded to MoveIt's cartesian planner starting [here](https://github.com/team-vigir/vigir_manipulation_planning/blob/264b63e53f6631ca9ffe19976fd3949630ce3600/vigir_move_group/src/manipulation_action_capability.cpp#L639) and then sent to the robot for execution.
