    There could be following two issues. Please check:

    1. Please install `controller-manager` as shown below:

            sudo apt install ros-foxy-controller-manager

    2. The executable name seems `spawner.py` based on the [documentation](https://control.ros.org/foxy/doc/ros2_control/controller_manager/doc/userdoc.html#helper-scripts).

            ros2 run controller_manager spawner.py -h
