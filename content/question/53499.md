  body_markdown: "You can get unpacked data in the ROS standard [Pointcloud2](http://www.ros.org/doc/api/sensor_msgs/html/msg/PointCloud2.html)\
    \ format by using cloud_node (or its nodelet equivalent) in the velodyne_pointcloud\
    \ package. See usage and examples [here](http://www.ros.org/wiki/velodyne_pointcloud#cloud_node).\
    \ \n\nIf you have the device plugged in, the following commands should do it:\n\
    \n    rosrun velodyne_driver velodyne_node _model:=32E\n    rosrun velodyne_pointcloud\
    \ cloud_node _calibration:=calibration.yaml\n\nYou can generate the calibration.yaml\
    \ from the db.xml file provided by Velodyne using the [gen_calibration](http://www.ros.org/wiki/velodyne_pointcloud#Examples-4)\
    \ utility.\n"
