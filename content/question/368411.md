Documentation:

    This guide will explain how to connect to the Wombat and start using ROS on the robot. This guide an following guides will instruct all the way from moving the robot up until path planning. 
    
    Before getting started there are some basic requirements that must be met. 
    *  An understanding of ROS functionality
    *  A machine running either Ubuntu 16 or 18. 
    *  An ROS Melodic or Kinetic installation (full installation)
    
    ## Connecting to the Robot
    The networking infrastructure of the robot is a key component of how it operates. The robot can run completely independently but requires a network connection to debug and to send commands on the fly. The first thing we need to do is connect to the robot. The robot will broadcast a Wifi network. Connect to this network. 
    
    Network SSID: `-`
    
    Network Password: `-`
    
    ## SSH into the Robot
    To ssh into the robot from your network we will use the command below. If you want to SSH over your own local network you will need to checkout your network administration in order to find the devices IP. Use the user name and password provided. 
    
    SSH Command: `ssh username@192.168.200.230`
    
    Once you have an open SSH connection to the robot you can now browse around and explore the file system. All relevant files are located in the `wombat` directory.
    
    ## Setting up the Linux User Space
    In its current state we are able to run all of the robots software however in order to send it goals and debug its mapping system we need to set our local machines environment. To do this we need to set the following Linux environment variables.
    
    export ROS_IP= ' Your local machine IP (CHANGE THIS!!) '
    export ROS_MASTER_URI=http://wombat_cpu:11311
    source /opt/ros/melodic/setup.zsh
    
    The last command is the source command to load the ROS system. This should always be done before using any ROS system.
    
    ## Launching the Basic Robot Functions
    Before we do any mapping or fancy things we need to launch all of the robots peripherals in order for them to be accessed by other ROS nodes. These peripherals include the following. 
    *   Motor Controllers and Odometry
    *   Omron LIDAR (2)
    *   Transform Publisher
    *   RealSense Mapping Camera
    *   LIDAR filters
    *   Joystick interface
    
    All of these functions have been wrapped up in a package call `robot.launch'. Turn on the joystick and run the below command. This command must be run on the wombat AGV 
    
    cd ~/wombat
    roslaunch robot.launch
    
    In order to move the robot you must hold the **A** button while moving the left joystick. It should be noted that you have to always be moving the joystick a little bit in order to move the robot. This is in order to ensure the user is paying attention to the movements of the robot. If at any time you want to stop the robot.launch press `Ctrl + C`.
    
    Now the robots basic motion package is in place. The robot will now subscribe to the topic `/cmd_vel` and making movements according to this topic. Later the navigation software will use this topic to control the robot.
