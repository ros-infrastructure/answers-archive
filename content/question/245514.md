    I have a small robot that uses similar Pololu motors with ROS. A few considerations:

     - You might want motors with a lower gear ratio. Depending on the size of your robot, and how fast you want to move, you might want to consider the 210:1 or 150:1 motors. Also depends on your wheel size, of course.
     - You'll want wheel encoders, such as [these Hall-effect encoders from Pololu](https://www.pololu.com/product/3081).

    For my robot I use the ROS package `ros_arduino_bridge` for both the Arduino code and the Python ROS controller node. It's unclear whether you intent to have a microcontroller for the motors. I'm using a Pololu A-Star connected to a Raspberry Pi running ROS. If you were to use an A-Star, [Marco Werther's fork](https://github.com/mw46d/ros_arduino_bridge) has support for the A-Star motor controller.

    If you provide some more details about the rest of your hardware, I could provide more suggestions for a controller or ROS nodes you might want.
