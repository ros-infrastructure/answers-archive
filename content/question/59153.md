    hector_slam outputs a standard [nav_msgs/OccupancyGrid](http://www.ros.org/doc/api/nav_msgs/html/msg/OccupancyGrid.html) message. Being "the" standard for 2D map representation, this message type is used by a lot of packages providing different functionality:

     - SLAM, generating map, simutaneously
       localizing within them ([gmapping](http://www.ros.org/wiki/gmapping),
       [hector_mapping](http://www.ros.org/wiki/hector_mapping))
     - self-localization in provided
       map ([AMCL](http://www.ros.org/wiki/amcl))
     - navigation based upon map ([move_base](http://www.ros.org/wiki/move_base))
     - exploring environments ([explore](http://www.ros.org/wiki/explore),
       [hector_exploration_planner](http://www.ros.org/wiki/hector_exploration_planner))

    Note this list is not exhaustive but just a few examples off the top of my head.
