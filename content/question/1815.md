  body_markdown: "Seems like the problem could be with the location of gazebo header\
    \ files.\n\nIf they were installed from sources using no cmake variable to control\
    \ destination, they are probably in */usr/local/include*. */usr/local* should\
    \ be supplied as include path to the compiler.\n\nYou could try several solutions\
    \ or workarounds, always keep the `<common/CommonTypes.hh>` this way, do not modify\
    \ it:\n\n 1. Install gazebo from ubuntu packages. Problem locating `<common/CommonTypes.hh`>\
    \ should not appear.\n 2. Install gazebo from sources using cmake .. `-DCMAKE_INSTALL_PREFIX=/usr`\n\
    \ 3. Modify the tutorial cmake to include /usr/local\n\nHope this helps.\n "
