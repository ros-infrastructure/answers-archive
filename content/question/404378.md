  body_markdown: "You are on the right track. \n\n 1. You need to create a subscriber\
    \ as you have done it already. However, please note that the callback function\
    \ will be called automatically upon receiving data from your joystick. Therefore,\
    \ you don't need to call the callback function by yourself.\n 2. Next, you can\
    \ look up the [message definition of sensor_msgs/Joy](http://docs.ros.org/en/melodic/api/sensor_msgs/html/msg/Joy.html).\
    \ Finally, the buttons and axes array contains button measurements and axes measurements\
    \ from a joystick, respectively. In the past, I found the mappings of buttons\
    \ and axes by pressing each of them one by one while echoing the joy topic.\n\
    \ 3. Once you find the correct mapping, you should trigger the lights on/off,\
    \ etc.\n\nUpdate\n---------\nThe message you are receiving is a pointer type.\
    \ The buttons and axes are array variables. So you can iterate over them to find\
    \ their mappings. See below the code snippet:\n\n    for(const auto & button :\
    \ joy->buttons){\n        // you can print button here\n    }\n\nOnce you find\
    \ the correct mapping, say you are interested in a button at index 1, use a conditional\
    \ statement as shown below:\n\n    auto button = joy->buttons[1]\n    if (button\
    \ == 1){\n        // trigger light on here\n    }"
