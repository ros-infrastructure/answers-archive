  body_markdown: "Not sure if I understand your question correctly, but what you can\
    \ do via ROS is to use a message_filter::Syncronizer templated on an ApproximateTime\
    \ sync policy. I do this for the individual topics of one kinect, but you could\
    \ of course extend it to also subscribe to the topics of the second kinect. My\
    \ code is as follows:\n\n**Header Stuff:**\n\n    typedef message_filters::sync_policies::ApproximateTime<sensor_msgs::Image,sensor_msgs::Image,\
    \ sensor_msgs::PointCloud2> MySyncPolicy;\n        \n    message_filters::Subscriber<sensor_msgs::Image>\
    \ visual_sub_ ;\n    message_filters::Subscriber<sensor_msgs::Image> depth_sub_;\n\
    \    message_filters::Subscriber<sensor_msgs::PointCloud2> cloud_sub_;\n    message_filters::Synchronizer<MySyncPolicy>\
    \ sync_;\n\n**Constructor**\n\n    ClassName::ClassName(ros::NodeHandle nh, \n\
    \                         const char* visual_topic, \n                       \
    \  const char* depth_topic, const char* cloud_topic, \n                      \
    \   const char* detector_type, const char* extractor_type) \n    : visual_sub_\
    \ (nh, visual_topic, global_subscriber_queue_size),\n      depth_sub_(nh, depth_topic,\
    \ global_subscriber_queue_size),\n      cloud_sub_(nh, cloud_topic, global_subscriber_queue_size),\n\
    \      sync_(MySyncPolicy(global_subscriber_queue_size),  visual_sub_, depth_sub_,\
    \ cloud_sub_),\n    {\n      sync_.registerCallback(boost::bind(&ClassName::callback,\
    \ this, _1, _2, _3));\n    }\n\nI hope this snippet is complete. \n\nFor synchrounous\
    \ triggering of two kinects, I don't think you can achieve that through ROS itself.\
    \ You would need to dig into the cam driver AFAIK. "
