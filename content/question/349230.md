  body_markdown: "Looking at the changelog of the [ros1_bridge](https://github.com/ros2/ros1_bridge/blob/master/CHANGELOG.rst)\
    \ you can see that this problem was recently addressed for the dynamic bridge\
    \ in this [pull request](https://github.com/ros2/ros1_bridge/pull/282).\n\nThey\
    \ now `use hardcoded QoS (keep all, transient local) for /tf_static topic in dynamic_bridge`.\n\
    The code in the bridge to accomplish this looks like this:\n\n    auto ros2_publisher_qos\
    \ = rclcpp::QoS(rclcpp::KeepLast(10));\n    if (topic_name == \"/tf_static\")\
    \ {\n      ros2_publisher_qos.keep_all();\n      ros2_publisher_qos.transient_local();\n\
    \    }\n\nIf you don't use the dynamic bridge but the parameter bridge, you have\
    \ to add the following topics to your yaml-configuration file:\n\n    topics:\n\
    \      - {topic: \"/tf\", type: \"tf2_msgs/msg/TFMessage\"}\n      - {topic: \"\
    /tf_static\", type: \"tf2_msgs/msg/TFMessage\"}\n\nAdditionally, you will have\
    \ to make a change to the code of the bridge as the change in the QoS settings\
    \ for the `tf_static` topic was only made for the dynamic_bridge. I made it work\
    \ by changing `create_bidirectional_bridge` in `bridge.cpp` to this:\n\n    BridgeHandles\n\
    \    create_bidirectional_bridge(\n      ros::NodeHandle ros1_node,\n      rclcpp::Node::SharedPtr\
    \ ros2_node,\n      const std::string & ros1_type_name,\n      const std::string\
    \ & ros2_type_name,\n      const std::string & topic_name,\n      size_t queue_size)\n\
    \    {\n      RCLCPP_INFO(ros2_node->get_logger(), \"create bidirectional bridge\
    \ for topic \" + topic_name);\n      BridgeHandles handles;\n    \n      auto\
    \ ros2_publisher_qos = rclcpp::QoS(rclcpp::KeepLast(queue_size));\n      if (topic_name\
    \ == \"/tf_static\") {\n        RCLCPP_INFO(ros2_node->get_logger(), \"Setting\
    \ QoS to keep_all msgs for topic /tf_static.\");\n        ros2_publisher_qos.keep_all();\n\
    \        ros2_publisher_qos.transient_local();\n      }\n    \n      handles.bridge1to2\
    \ = create_bridge_from_1_to_2(\n        ros1_node, ros2_node,\n        ros1_type_name,\
    \ topic_name, queue_size, ros2_type_name, topic_name, ros2_publisher_qos);\n \
    \     handles.bridge2to1 = create_bridge_from_2_to_1(\n        ros2_node, ros1_node,\n\
    \        ros2_type_name, topic_name, queue_size, ros1_type_name, topic_name, queue_size,\n\
    \        handles.bridge1to2.ros2_publisher);\n      return handles;\n    }\n\n\
    Don't forget to recompile the bridge after the change was made.\nOnce these changes\
    \ were made it was possible to look up both dynamic and static ROS1 transforms\
    \ in ROS2 using:\n\n    ros2 run tf2_ros tf2_echo reference_frame target_frame"
