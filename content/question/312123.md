  body_markdown: "The problem arises because, when `movegroup` is sending out the\
    \ `JointTrajectoryAction/goal` msg to a foo `arm_controller`, the 'tolerance'\
    \ msg fields are empty, resulting a GOAL_TOLREANCE_VIOLATED.\n\nI also tried to\
    \ spent some time on solving this issue, after digging into `joint_trajectory_controller`\
    \ in ros_controller, i found that the param is being retrieved here: [tolerances.h](https://github.com/ros-controls/ros_controllers/blob/252594832d5e358972a28ceacdc227460ad8c718/joint_trajectory_controller/include/joint_trajectory_controller/tolerances.h#L305).\
    \ \n\nTo solve this, changes need to be made on the controller.yaml for gazebo\
    \ controller. For my case, I am using a `velocity_controllers` here, thus changing\
    \ `stopped_velocity_tolerance` from a number to 0 solved this. \n\n    arm_controller:\n\
    \      type: velocity_controllers/JointTrajectoryController\n      joints:\n \
    \        - shoulder_pan_joint\n         - shoulder_lift_joint\n         - elbow_joint\n\
    \         - wrist_1_joint\n         - wrist_2_joint\n         - wrist_3_joint\n\
    \      constraints:\n          goal_time: 0.6\n          # vel_tolerance is 0\
    \ for due to the movegroup/follow_joint_trajectory/goal tolerance is empty\n \
    \         stopped_velocity_tolerance: 0\n          shoulder_pan_joint: {trajectory:\
    \ 0.1, goal: 0.1}\n          shoulder_lift_joint: {trajectory: 0.1, goal: 0.1}\n\
    \          elbow_joint: {trajectory: 0.1, goal: 0.1}\n          wrist_1_joint:\
    \ {trajectory: 0.1, goal: 0.1}\n          wrist_2_joint: {trajectory: 0.1, goal:\
    \ 0.1}\n          wrist_3_joint: {trajectory: 0.1, goal: 0.1}\n      gains:\n\
    \          shoulder_pan_joint: {p: 100, d: 1, i: 1, i_clamp: 1}\n          shoulder_lift_joint:\
    \ {p: 100, d: 1, i: 1, i_clamp: 1}\n          elbow_joint: {p: 100, d: 1, i: 1,\
    \ i_clamp: 1}\n          wrist_1_joint: {p: 100, d: 1, i: 1, i_clamp: 1}\n   \
    \       wrist_2_joint: {p: 100, d: 1, i: 1, i_clamp: 1}\n          wrist_3_joint:\
    \ {p: 100, d: 1, i: 1, i_clamp: 1}\n      stop_trajectory_duration: 0.5\n    \
    \  state_publish_rate:  25\n      action_monitor_rate: 10\n\n\nAfter this change,\
    \ i managed to receive `SUCCESS`. Similarly, If you are using a `position_controllers`,\
    \ I believe the `goal` for each joint need to be changed to 0. Hopefully this\
    \ works for you."
