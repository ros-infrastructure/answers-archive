    The binary format of the octomap library is not an image format. It is just a compact representation of the 3D map (i.e. not a 2d map) and thus cannot just be converted to a pgm map.

    While not documented anywhere, I have an octo_to_2d utility in the map_tools package of my [sandbox repository](https://github.com/mikeferguson/sandbox). This will take a COLOR octomap in .ot format, take a slice at a specified height, and publish an appropriate map. You can then use map_saver to save the map. The source code is pretty self documenting as far as parameters and topics.
