  body_markdown: "From the [documentation](http://docs.ros.org/diamondback/api/roscpp/html/namespaceros.html#a8e5be7c61004be0d124a22c632482d36):\n\
    \n - `void ros::requestShutdown ( )`\n\n    > Request that the node shut itself\
    \ down from within a ROS thread.\n    This method signals a ROS thread to call\
    \ shutdown(). \n\n - `void ros::shutdown( )`\n\n    > Disconnects everything and\
    \ unregisters from the master. It is generally not necessary to call this function,\
    \ as the node will automatically shutdown when all NodeHandles destruct. However,\
    \ if you want to break out of a spin() loop explicitly, this function allows that.\
    \ \n\nFrom the [definition](http://docs.ros.org/diamondback/api/roscpp/html/init_8cpp_source.html#l00111):\n\
    \n> the `requestShutdown()` just sets a global bool (`g_shutdown_requested`) to\
    \ true, which is later processed in the `checkForShutdown()` method which runs\
    \ from within a mutex inside a PollManager. The point is to prevent from deadlocking\
    \ with another thread that's already in the middle of shutdown()"
