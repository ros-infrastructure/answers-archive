    Yep, just requires a few steps.

     1. Choose which camera you want to use (on a PR2, narrow_stereo might be a good choice). I'll refer to this as `camera`.
     1. Create a `[image_geometry](http://www.ros.org/wiki/image_geometry).PinholeCameraModel` using `camera/camera_info`.
     1. Let's say you have a PointStamped called `object_center` which represents the center of mass of some detected object. Transform that point into `camera`'s frame using a tf.TransformListener.
     1. Project that point onto `camera`'s image plane using your camera model's `project3dToPixel`.
