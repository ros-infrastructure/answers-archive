    The robot and The Object are independent objects, so typically are not described in the same urdf/xacro/sdf file. In gazebo, you create an instance of an object by "spawning" it into the world at some initial position. After that, the physics simulator determines the behavior of all independent objects e.g. if something crashes into your Object, it may move. If you spawn an object in mid-air, gravity will cause it to fall to the ground.

    >\n      <!--Load the macro for creating a UR10e-->\n      <xacro:include filename=\"\
    $(find ur_description)/urdf/inc/ur10e_macro.xacro\"/>\n    \n      <!--Instanciate\
    \ the UR10e-->\n      <xacro:ur10e_robot prefix=\"\" />\n    \n      <!--Let's\
    \ create a sort of table where the robot stands on-->\n      <link name=\"box\"\
    >\n        <visual>\n          <origin xyz=\"0 0 0.5\" rpy=\"0 0 0\"/>\n     \
    \     <geometry>\n            <box size=\"1 1 1\"/>\n          </geometry>\n \
    \       </visual>\n      </link>\n    \n      <!--The robot will be on the top\
    \ surface of the box in the center-->\n      <joint name=\"table_to_robot\" type=\"\
    fixed\">\n        <parent link=\"box\" />\n        <child link = \"base_link\"\
    \ />\n        <origin xyz=\"0 0 1\" rpy=\"0 0 0\" />\n      </joint>\n    </robot>\n\
    \nBasically, you create your URDF with everything \"around\" the robot and then\
    \ include the macro for creating the robot and add the statement for actually\
    \ creating the robot to your URDF. To add an item with a custom stl, please refer\
    \ to the [urdf/link docuementation](http://wiki.ros.org/urdf/XML/link)."
