    \ the tutorials [here](http://www.ros.org/wiki/household_objects_database/Tutorials/Install%20the%20household_objects%20database%20on%20your%20local%20database%20server)\
    \ to set up your database.\n\n- Launch the tabletop_complete.launch file in package\
    \ tabletop_object_detector\n- Launch the household_objects_database node\n\nI\
    \ wrote the following launch file to do this.\n\n    <launch>\n    <!-- load database\
    \ connection parameters -->\n        <rosparam command=\"load\"     \n       \
    \     file=\"$(find image_processing)/config/household_objects_params.yaml\"/>\n\
    \n    <!-- start the database wrapper node -->\n         <node pkg=\"household_objects_database\"\
    \ name=\"objects_database_node\" \n             type=\"objects_database_node\"\
    \ respawn=\"true\" output=\"screen\"/>\n            \n    <include file=\"$(find\
    \ tabletop_object_detector)/launch/tabletop_complete.launch\"/>\n    </launch>\n\
    \n- Then, you need to write a node that calls the service provided by the tabletop_node.\
    \ You can follow [this](http://www.ros.org/wiki/pr2_tabletop_manipulation_apps/Tutorials/Writing%20a%20Simple%20Pick%20and%20Place%20Application)\
    \ tutorial to do that: \n\nAlso, make sure that you publish your point clouds\
    \ to the correct topic (see tabletop_complete.launch for the topic).\n\nI think\
    \ that's all there is to it, but maybe I forgot a step because it's been a while\
    \ for me when I did this. You can contact me at w.k.h.ko@student.tudelft.nl when\
    \ you have more questions. Good luck!"
