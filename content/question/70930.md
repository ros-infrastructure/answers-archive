  body_markdown: "hi,\nyou probably want to do something like this (this is an example\
    \ that converts geometry_msgs/Twist message to turtlesim/Velocity message):\n\n\
    \    def TwistToTurtle(): #initialization\n    rospy.init_node('TwistToTurtle',anonymous=False)\n\
    \    rospy.Subscriber('cmd_vel',Twist,gotTwistCB) #subscribe to cmd_vel topic\
    \ which publishes Twist messages \n    pub = rospy.Publisher('turtle1/command_velocity',Velocity)\n\
    \    rospy.spin()\n\n    def gotTwistCB(data): #when Twist msg is received\n \
    \   #take values from data and do your job, for example:\n    outdata = Velocity()\n\
    \    outdata.linear = data.linear.x\n    outdata.angular = data.angular.z\n  \
    \  pub.publish(outdata)\n\nSO `data.linear.x/y/z` and `data.angular.x/y/z` are\
    \ the ones that you care about\n\nmore on subsribing [tutorial here](http://www.ros.org/wiki/ROS/Tutorials/WritingPublisherSubscriber%28python%29).\n\
    Also, you may want to check out [rosmsg](http://www.ros.org/wiki/rosmsg) or just\
    \ run \n\n    rosmsg -h"
