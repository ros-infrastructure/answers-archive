    \ select the device automatically based on a serial number input as a ros parameter.\
    \ \n\nUsage looks like this:\n\n`rosrun openni_tracker openni_tracker _desired_serial:=B00312327745048B`\n\
    \nNotable additions to the code include:\n\n1.  Getting the USB port number by\
    \ calling `deviceNodeInfo.GetCreationInfo()` and parsing out the value after the\
    \ last `/`.\n\n2. Calling `lsusb` via `popen` (`fp = popen(\"lsusb -v -d 045e:02ae\"\
    , \"r\");`) and parsing the output to match usb port to serial number. This depends\
    \ on the system's implementation and formatting of `lsusb` so it's probably the\
    \ most fragile part.\n\n3. Calling `ros::param::get(\"~desired_serial\", desiredSerial)`\
    \ to get the user's desired serial number from the ros parameter server.\n\nCode\
    \ is online here: https://github.com/lrperlmu/openni_tracker/tree/leah-dev . More\
