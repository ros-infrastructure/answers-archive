    It seems your X configuration is not properly set up for 3D accelerated OpenGL operation. [GLX](http://en.wikipedia.org/wiki/GLX) is the 'OpenGL Extension to the X Window System', which is required for this.

    It seems you have more problems with this particular machine / setup? I noticed [this](http://answers.ros.org/question/38228/segmentation-fault-core-dumped/) question, which seems to be related.

    I'd first sort out the OpenGL / Xorg setup on the machine (without involving ROS or rviz) and then try to tackle the rviz problems.
