  body_markdown: "If you're doing rosrun, you can use the `argv` passed into the main\
    \ function of your C++ node:\n\n    int main(int argc, char** argv)\n    {\n \
    \       ros::init(argc, argv, \"my_node\");\n\n        if (argc > 1)\n       \
    \     std::string value_from_cl = argv[1];\n    }\n\nIf you go through a launch\
    \ file, you can use [launch file args](http://wiki.ros.org/roslaunch/XML/arg)\
    \ to pass in from the command line. For example, if you have in your launch file\n\
    \n    <arg name=\"some_arg\" default=\"my_default_value\"/>\n\nthen you can run\
    \ roslaunch like\n\n    roslaunch my_package my_file.launch some_arg:=some_other_value\n\
    \nThen to get the value to your node, you can pass it directly in the `node` tag\
    \ in the launch file:\n\n    <node name=\"my_node\" pkg=\"my_package\" type=\"\
    my_node\" args=\"$(arg some_arg)\"/>\n\nYou could alternatively [set it with the\
    \ ROS parameter server](http://wiki.ros.org/roslaunch/XML#Setting_parameters),\
    \ in which case you would load it in your launch file by doing\n\n    <param name=\"\
    my_param\" value=\"$(arg some_arg)\"/>\n\nwhich can then be retrieved from the\
    \ [parameter server](http://wiki.ros.org/roscpp/Overview/Parameter%20Server) in\
    \ your C++ code with\n\n    ros::NodeHande nh;\n    std::string value_from_ps;\n\
    \    // Retrieve and set a default value if not found on parameter server    \n\
    \    nh.param<std::string>(\"my_param\", value_from_ps, \"my_default_value\");\n\
    \    // Retrieve without a default value\n    nh.getParam(\"my_param\", value_from_ps);"

    \ system. This allows the setting to be controlled when you start the node by\
    \ itself using rosrun or as part of a larger launch file. You would run your node\
    \ using the following command:\n\n    rosrun <package_name> <node_name> _topic:=<topic_name>\n\
    \nYou can then access this parameter in your node using the following code:\n\n\
    \    ros::NodeHandle n(\"~\");\n    std::string topicName;\n    n.param<std::string>(\"\
    topic\", topicName, \"default_topic\");\n    printf(\"topic is [%s]\\n\", topicName.c_str()\
    \ );\n\nHope this helps. \n\n"
