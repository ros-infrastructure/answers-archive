  body_markdown: "It is absolutely possible.  I have run 4 ASUS sensors (Kinect) from\
    \ one computer.  Each Kinect needs to be on its own bus, or you will have issues\
    \ getting all the data through.  You need to give each Kinect a unique camera\
    \ name in the launch file and create separate frames.launch files for each one.\
    \  I don't have access to the launch files right now to give you an example, but\
    \ I can get you an example launch file tomorrow.\n\n**EDIT**\n\nHere is an example\
    \ launch file that I used recently to launch two Kinects.  This should be a decent\
    \ template to get you going.  This launch file is specific to my system (the \"\
    device_id\" values are specific to my bus configurations), so it probably won't\
    \ work by simply copying and pasting.  Also, I was running this on Ubuntu 11.10\
    \ with ROS Electric:\n\nk1_2.launch\n\n    <launch>\n      <arg name=\"debug\"\
    \ default=\"false\"/>\n      <arg if=\"$(arg debug)\" name=\"launch_prefix\" value=\"\
    xterm -rv -e gdb -ex run - args\"/>\n      <arg unless=\"$(arg debug)\" name=\"\
    launch_prefix\" value=\"\"/>\n\n      <node pkg=\"openni_camera\" type=\"openni_node\"\
    \ name=\"openni_node1\" ns=\"camera1\" launch-prefix=\"$(arg launch_prefix)\"\
    \ output=\"screen\">\n        <param name=\"device_id\" value=\"004@02\"/>\n \
    \       <param name=\"rgb_frame_id\" value=\"kinect1_rgb_frame\" />\n        <param\
    \ name=\"depth_frame_id\" value=\"kinect1_depth_frame\" />\n        <param name=\"\
    use_indices\" value=\"false\" />\n        <param name=\"depth_registration\" value=\"\
    true\" />\n        <param name=\"image_mode\" value=\"2\" />\n        <param name=\"\
    depth_mode\" value=\"2\" />\n        <param name=\"debayering\" value=\"2\" />\n\
    \        <param name=\"depth_time_offset\" value=\"0\" />\n        <param name=\"\
    image_time_offset\" value=\"0\" />\n      </node>\n\n      <node pkg=\"openni_camera\"\
    \ type=\"openni_node\" name=\"openni_node2\" ns=\"camera2\" launch-prefix=\"$(arg\
    \ launch_prefix)\"  output=\"screen\">\n        <param name=\"device_id\" value=\"\
    003@05\"/> \n        <param name=\"rgb_frame_id\" value=\"kinect2_rgb_frame\"\
    \ />\n        <param name=\"depth_frame_id\" value=\"kinect2_depth_frame\" />\n\
    \        <param name=\"use_indices\" value=\"false\" />\n        <param name=\"\
    depth_registration\" value=\"true\" />\n        <param name=\"image_mode\" value=\"\
    2\" />\n        <param name=\"depth_mode\" value=\"2\" />\n        <param name=\"\
    debayering\" value=\"2\" />\n        <param name=\"depth_time_offset\" value=\"\
    0\" />\n        <param name=\"image_time_offset\" value=\"0\" />\n      </node>\n\
    \ \n    </launch>"
