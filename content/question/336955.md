      In rtabmap, `cloud_map` is assembled in a similar way, but each time we add a new cloud, the assembled one is voxelized (if we don't move, the cloud wouldn't grow). If the example was in c++, I would say just use a [pcl::VoxelGrid](http://pointclouds.org/documentation/tutorials/voxel_grid.php) filter, not sure if this function is available in [python-pcl](https://github.com/strawlab/python-pcl). You can try the `map_assembler` approach then, for which the cloud is voxelized, exactly like `cloud_map`.
