    The goals for the navigation stack are in the global frame, which is usually the  /map frame. This means that you'll always send the absolute goal, in your case 7,2 followed by 10,4.

    You can use the [actionlib interface](http://wiki.ros.org/move_base#Action_API) to the navigation stack to request navigation to the first goal, and get notified when the robot arrives there, so that you can send the next goal.

    The easiest option certainly is sending all goals in the global "/map" frame. Note that you also can send goals relative to arbitrary frames (for example relative to the robot in the "base_link" frame). The goal will always be converted to the global frame inside move_base first (see [move_base.cpp line 648](https://github.com/ros-planning/navigation/blob/hydro-devel/move_base/src/move_base.cpp#L648)).
