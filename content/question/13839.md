  body_markdown: "Q: Is it better to have nested models, or 1 model with many links?\n\
    \n**A: I would suggest you use one model with many links if you can, nested models\
    \ are quite new in Gazebo and not as well tested as links.**\n\nQ: Is the following\
    \ workflow viable? Are the alternatives?\n\n**A: Yes, I believe that's a common\
    \ workflow. Some people might prefer doing everything in a text editor, and you\
    \ can always go back to the model editor and edit it again.**\n\nQ: Whats a good\
    \ workflow to align/place links together? Is it only computing the points by hand?\n\
    \n**A: If you have simple shapes it might be easy to compute by hand, but in any\
    \ case the model editor provides the align and snap tools which should make this\
    \ easier to do graphically if you want.** "
