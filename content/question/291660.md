    \ [http://wiki.ros.org/roscpp/Overview/Parameter%20Server](http://wiki.ros.org/roscpp/Overview/Parameter%20Server).\n\
    \nFor your specific case, I think it's better if you can format your yaml file\
    \ like : \n\n    list:\n     - id: 0 \n       name: john \n       pos: [0,0,0]\n\
    \     \n     - id: 1 \n       name: anna \n       pos: [0,0,0]\n\nThis way you\
    \ can easily access the values as a dictionary after you fetch each item in the\
    \ list as a `XmlRpc::XmlRpcValue` data type.\n\n    for (int i = 0; i < list.size();\
    \ i++) {\n          XmlRpc::XmlRpcValue sublist = list[i];\n          id=sublist[\"\
    id\"];\n    }\n    \nThis is just a raw example, you should always check for format\
    \ errors before fetching data to avoid crashing your program. This is the best\
    \ way that I know of, if anyone else can offer a better alternative, I'll be happy\
    \ to learn."

I would like to define a list of items in a yaml file which I read in with ros::param::param<T>()

It works fine if I read in a normal double or string:

     ros::param::param<double>("list/pos_x",pos_x,0.0);

if my yaml file is defined as:

    list:
     - {'id': 0, 'name': 'john', 'pos':[0,0,0]}
     - {'id': 1, 'name': 'anna', 'pos':[0,0,0]}
     - {'id': 2, 'name': 'bill', 'pos':[0,0,0]}

How can i access these with ros::param?
