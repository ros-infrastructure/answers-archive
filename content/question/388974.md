  body_markdown: "Hey there,\n\nFirst, you need to create a publisher it can be either\
    \ python or cpp file. Let's take an example and create python file.\n\n    #!/usr/bin/env\
    \ python\n    import rospy\n    from geometry_msgs.msg import Pose\n    \n   \
    \ def publisher():\n        pub = rospy.Publisher('cmd_vel', Pose, queue_size=1)\n\
    \        rospy.init_node('pose_publisher', anonymous=True)\n        rate = rospy.Rate(2)\
    \ # Hz\n        while not rospy.is_shutdown():\n            p = Pose()\n     \
    \       p.position.x = 0.5\n            p.position.y = -0.1\n            p.position.z\
    \ = 1.0\n            # Make sure the quaternion is valid and normalized\n    \
    \        p.orientation.x = 0.0\n            p.orientation.y = 0.0\n          \
    \  p.orientation.z = 0.0\n            p.orientation.w = 1.0\n            pub.publish(p)\n\
    \            rate.sleep()\n    \n    if __name__ == '__main__':\n        try:\n\
    \            publisher()\n        except rospy:\n            pass\n\nYou can publish\
    \ your topic via **terminal** by: \n\n    rostopic pub -r 1000 /cmd_vel geometry_msgs/Pose\
    \ '{position: [1,2,3], orientation: [0.0,0.0,0.0,0.0]}'\n\n\nPose will be published\
    \ on  /cmd_vel topic and 1000 means every 1 sec it will be published\n\n\nNow,\
    \ the pose is published into **pose** topic. \n\n> You can view all topic by:\n\
    \n    rostopic list\n\n> You can check data for topic by: \n\n    rostopic echo\
    \ pose\n\n> You can view type by :\n\n    rostopic type /cmd_vel \n\nTerminal\
    \ or python run example response will be : **geometry_msgs/Pose**"
