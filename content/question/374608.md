  body_markdown: "[EDITED ANSWER]   \nThe thing is, when you run the example script,\
    \ it will quit immediately. Also closing any process immediately after opening\
    \ it.\n\nTo keep the process running you can modify [roslaunch API](http://wiki.ros.org/roslaunch/API%20Usage)\
    \ example and integrate it into a ROS node:  \n- import rospy to write a ROS Node\
    \  \n- Declare a node using init_node()  \n- Keep python from exiting until this\
    \ node is stopped using rospy.spin()  \n\n\nSo this is a **simple usage example**\
    \ integrated into a ROS node :\n\n    import rospy\n    import roslaunch\n   \
    \ \n    rospy.init_node('roslaunch_api_test')\n    package = 'rqt_gui'\n    executable\
    \ = 'rqt_gui'\n    \n    node = roslaunch.core.Node(package, executable)\n   \
    \ launch = roslaunch.scriptapi.ROSLaunch()\n    launch.start()\n    process =\
    \ launch.launch(node)\n    \n    rospy.spin()\n\nIf you don't want to create a\
    \ ROS node, find a different way to keep the process running, for instance:\n\n\
    \    import roslaunch\n    import time\n\n    package = 'rqt_gui'\n    executable\
    \ = 'rqt_gui'\n    \n    node = roslaunch.core.Node(package, executable)\n   \
    \ launch = roslaunch.scriptapi.ROSLaunch()\n    launch.start()\n    process =\
    \ launch.launch(node)\n\n    # keep process open for 2 seconds, then quit\n  \
    \  time.sleep(2.0)"
