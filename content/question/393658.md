  body_markdown: "Hi @self_seghiri\n\n> Gazebo is an independent project like\n> boost,\
    \ ogre or any other project used\n> by ROS. Usually, the latest major\n> version\
    \ of gazebo available at the\n> beginning of every ROS release cycle\n\nSource:\
    \ http://gazebosim.org/tutorials/?tut=ros_wrapper_versions\n\nHowever packages\
    \ developed for a particular ROS distro target particular Gazebo versions so installing\
    \ different version may work for some packages but as you have seen first hand\
    \ it creates issues with others, thus is not recommended to mix.\n\n**Guideline:**\n\
    \n - ROS Kinetic: Gazebo 7.x \n - ROS Melodic: Gazebo 9.x \n - ROS Noetic: Gazebo\
    \ 11.x\n - ROS2 Dashing: Gazebo 9.x \n - ROS2 Eloquent: Gazebo 9.x \n - ROS2 Foxy:\
    \ Gazebo 11.x"
