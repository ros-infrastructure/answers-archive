    \ should try to increase the goal tolerance from default. See this page: http://wiki.ros.org/base_local_planner.\
    \  This will make it easier for movebase to conclude you've reached the goal.\
    \ The default for yaw_goal_tolerance  is 0.05 so if you have the min theta velocity\

    \ theta to 0.05 and increase goal tolerance to 0.2 and see if that fixes it. Then\
