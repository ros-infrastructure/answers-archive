  body_markdown: "It looks like this was due to the cleanup of the debs. \n\nIf you\
    \ checkout and build the `opencv2` package from source (with e.g. `svn co https://code.ros.org/svn/ros-pkg/stacks/vision_opencv/trunk/opencv2`\
    \ and then CD into that package and type `make`), you'll find that it does download\
    \ and build the samples, but they are never moved out of the `build` directory.\
    \ Part of the deb cleanup was to remove all `build` directories from packages\
    \ so that the debs did not include a bunch of intermediate object files, only\
    \ finished executables and libraries.\n\nIf you think that the samples should\
    \ be available to deb users, filing a [ticket](https://code.ros.org/trac/ros-pkg/newticket?component=vision_opencv&type=defect&&vision_opencv)\
    \ would be the best way to get them re-included. If the samples are large, it\
    \ might be best for the build system to provide a second .deb that includes just\
    \ the samples that could be installed in addition to the standard `vision_opencv`\
    \ deb file. I can't really say whether or not the samples were intentionally kept\
    \ out to keep the debs small or if it was just an oversight."
