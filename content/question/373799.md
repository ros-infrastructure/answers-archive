    The `socketcan_bridge` [package](http://wiki.ros.org/socketcan_bridge) contains a node (`socketcan_bridge_node`) for reading CAN messages from a device and publishing them to a ROS message and vice-versa. This node stamps the CAN ROS message when it is processed on the node side, see [here](https://github.com/ros-industrial/ros_canopen/blob/melodic-devel/socketcan_bridge/src/socketcan_to_topic.cpp#L114).
