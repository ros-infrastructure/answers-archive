    Yes, you can publish the object to the planning scene with the `operation` field set to `MOVE`, as shown in the [CollisionObject message](http://docs.ros.org/en/melodic/api/moveit_msgs/html/msg/CollisionObject.html).

    You can use the `PlanningSceneInterface` in C++ for this, although the Python interface doesn't expose the `applyCollisionObject` function yet. You could add that feature and submit a pull request. :)
