  body_markdown: "With the `args` you can specify the output directory yes but you\
    \ have to specify a full path and a base name. In your question you would overwrite\
    \ the first map when saving the second one because they would have the same name\
    \ (the default one). Also you have to use the tag `remap` because `map_saver`\
    \ subscribes to a topic (`/map` by default) to get the map.\n\nHere is a launch\
    \ file that do what you want : \n\n    <launch>\n    \t<arg name=\"map_1\" default=\"\
    /topic_map_1\"/>\n        <arg name=\"map_2\" default=\"/topic_map_2\"/>\n   \
    \   <node name=\"map_saver1\" pkg=\"map_server\" type=\"map_saver\" args=\"-f\
    \ $(find your_pkg)/map_1\">\n            <remap from=\"/map\" to=\"$(arg map_1)\"\
    />\n      </node>\n      <node name=\"map_saver2\" pkg=\"map_server\" type=\"\
    map_saver\" args=\"-f $(find your_pkg)/map_2\">\n        <remap from=\"/map\"\
    \ to=\"$(arg map_2)\"/>\n      </node>\n    </launch>"
