  body_markdown: "This can be accomplished using the `LaunchService` class.\n\nBasic\
    \ example:\n\n`main.py`:\n\n    from launch import LaunchService\n    \n    from\
    \ my_launch_file import generate_launch_description\n    \n    \n    launch_service\
    \ = LaunchService()\n    launch_service.include_launch_description(generate_launch_description())\n\
    \    launch_service.run()\n\nIn this case, `generate_launch_description()` comes\
    \ from a typical ros2 launch file. For example:\n\n`my_launch_file.py`:\n\n  \
    \  from launch import LaunchDescription\n    from launch_ros.actions import Node\n\
    \    \n    def generate_launch_description():\n        rviz_node = Node(\n   \
    \         package='rviz2',\n            executable='rviz2',\n            name='my_rviz_node'\n\
    \        )\n        return LaunchDescription([\n            rviz_node,\n     \
    \   ])\n\n"
