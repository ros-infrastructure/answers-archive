    `gazebo::msgs::Physics` is generated using protobuf. The method `mutable_gravity()` is automatically generated from the field `optional Vector3d gravity` in the protobuf file. Here is an [overview of using protubuf in C++](https://developers.google.com/protocol-buffers/docs/cpptutorial). This link [describes the C++ code generated](https://developers.google.com/protocol-buffers/docs/reference/cpp-generated) from protobuf messages. And this link is the [protobuf definition in gazebo 8](https://bitbucket.org/osrf/gazebo/src/0a80f10918576cf1fc4787ebb6f1b9cb424a0c8b/gazebo/msgs/physics.proto?at=gazebo8&fileviewer=file-view-default) for the mesage you're using.
