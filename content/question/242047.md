  body_markdown: "Perhaps the `dirname` [substitution argument](http://wiki.ros.org/roslaunch/XML#substitution_args)\
    \ can do what you are looking for:\n \n> `$(dirname)` returns the absolute path\
    \ to the directory of the launch file in which it appears. This can be used in\
    \ conjunction with `eval` and `if`/`unless` to modify behaviour based on the installation\
    \ path, or simply as a convenience for referencing `launch` or `yaml` files relative\
    \ to the current file rather than relative to a package root (as with `$(find\
    \ PKG)`).\n    For example:\n> \n>     <include file=\"$(dirname)/other.launch\"\
    \ />\n> \n>  Will expect to find `other.launch` in the same directory as the launch\
    \ file which it appears in. \n\nThis does not make it relative to the package,\
    \ but relative to the `.launch` file in which this substitution is used."
