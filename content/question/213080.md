    There is preliminary VLP16 support in the ROS [velodyne driver](http://wiki.ros.org/velodyne), but it is not yet released.

    **Update:** VLP-16 support is now released as binary packages in both Indigo and Kinetic.

    Since that version is not released, you would need to build it [from source](https://github.com/ros-drivers/velodyne) in a catkin workspace. (Ask if you don't know how to do that.)

    Once you have built that driver in your catkin workspace, run these commands in separate terminal windows:

        roscore

    ...

        rosrun velodyne_driver velodyne_node _model:=VLP16 _pcap:=/your/pcap/path/data.pcap _read_once:=true

    ...

        rosrun rosbag record -O your_vlp16_070815.bag /velodyne_packets

    See the [rosbag record documentation](http://wiki.ros.org/rosbag/Commandline#record) for other options and details.
