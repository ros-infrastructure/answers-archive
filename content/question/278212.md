  body_markdown: "You still have the package that you downloaded from GitHub in your\
    \ workspace which is why when you run `rospack find ardrone_autonomy` you see\
    \ that it's located in `~/catkin_ws/src/ardrone_autonomy`.\n\nFollow these steps:\n\
    \n 1. Delete this package along with the `~/catkin_ws/build`, `~/catkin_ws/devel`,\
    \ and `~/catkin_ws/install` directories (as noted by @clyde )\n 2. Compile your\
    \ workspace again.\n 3. Now, `source` (ROS if you're not doing that already and)\
    \ your workspace:\n    \n        $ source /opt/ros/<distro>/setup.bash\n     \
    \   $ source ~/catkin_ws/devel/setup.bash\n\n 4. Run\n\n        $ roslaunch ardrone_tutorials\
    \ keyboard_controller_outdoor.launch\n\n again and `roslaunch` should be able\
    \ to find the `ardrone_driver` node. Note that to *find* and *launch* the node\
    \ you don't have to be connected to your drone. But, to *use* it you do need to\
    \ be connected to the drone.\n\nPlease update your question if this still doesn't\
    \ fix your issue.\n\n**Note:** I've moved the question's comments into this answer."
