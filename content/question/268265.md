  body_markdown: "This is because script `say.py` (must be written to be a standalone\
    \ python script and hence) accepts [sysargs](https://github.com/ros-drivers/audio_common/blob/1931af14cabf009c6d2b61a556c70f1c63a4b0d5/sound_play/scripts/say.py#L57).\
    \ When `say.py` is launched with roslaunch, addition sysargs are passed to the\
    \ script and `__name:=say` becomes the `sys.argv[1]`. \n\nThe solution for this\
    \ is to modify the `say.py` to accept `rosparam`."
