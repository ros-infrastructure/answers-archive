  body_markdown: "If you are running the gazebo_ros_laser plugin(or similar), it publishes\
    \ a `sensor_msgs/LaserScan.msg`\n to `/scan` just like a real laser in ROS. \n\
    Check out the [LaserScan Message page](http://docs.ros.org/api/sensor_msgs/html/msg/LaserScan.html)\
    \ for details on the format of the messages published by the `/scan` topic.  One\
    \ of the data elements in a `LaserScan.msg` is an array of range values:\n\n \
    \   float32[] ranges\n\nThis has the range data you're probably looking for. It's\
    \ up to you/your code to determine how to use it, what makes up an object, filter\
    \ out noise, etc. \n\nYou can find the position of the TurtleBot by subscribing\
    \ to the `/tf` topic:\n(About which see [here](http://answers.ros.org/question/159171/how-to-get-robot-position-xy-in-a-map/)\
    \ and [here](http://answers.ros.org/question/67206/getting-accurate-real-time-xy-coordinates-with-gmapping/),\
    \ and of course, [The ROS Wiki tf Tutorial](http://wiki.ros.org/tf/Tutorials))\n\
    \nIf you don't know how to work with the rospy publish/subscribe framework, there\
    \ are tutorials on ros.org:\n[Writing Publishers and Subscribers in Python](http://wiki.ros.org/ROS/Tutorials/WritingPublisherSubscriber%28python%29)\n\
    \nHTH and please mark this as an answer if it helped you!\n\n\n"
