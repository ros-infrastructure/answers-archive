Im using openai_ros to train a turtlebot to recognise the lights of a traffic light.
I wrote a python script to control the lights of the traffic light.

I initialize the world for the simulation in the TaskEnvironment with:
ROSLauncher(rospack_name="maps", launch_file_name="traffic_light_course2.launch", ros_ws_abspath=ros_ws_abspath)

In the traffic_light_course2.launch file i start a node with:
<node pkg="maps" name="traffic_lights_controller" type="contrtol_traffic_light.py" output="screen"/>
This node just publishes the state of the traffic light (green, red, yellow).

My problem is that after the first reset of the environment the node dies. I don't just want to respawn the node because that leads to other problems.

So my question is: Why dose the node die? How can I keep the node alive, so the traffic light controler is independent of the training steps and resets? 
As far as i know we just reset the controlers and the position of the robot after every step. The wold shouldn't be changed and also no ROS nodes should die.
