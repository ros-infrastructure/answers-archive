    \ an exception will be raised (I removed the parts that aren't necessary for the\
    \ question)\n\n    def wait_for_message(topic, topic_type, timeout=None):\n  \
    \      \"\"\"\n        ...\n    \n        @param timeout: timeout time in seconds\n\
    \        @type  timeout: double\n        ...\n        @raise ROSException: if\
    \ specified timeout is exceeded\n        \"\"\"\n\nSo, just call the function\
    \ like this\n\n    rospy.wait_for_message(my_topic, MyMessage, my_timeout)\n\n\
    and if `my_timeout` is exceeded a `ROSException` will be raised."
