  body_markdown: "as already mentioned previously you can see your current GAZEBO_PLUGIN_PATH\
    \ by the command `echo`&nbsp;`$GAZEBO_PLUGIN_PATH`. The path should point directly\
    \ to the folder **where the .so file is located** (for example the build folder).\n\
    \nthe `export`&nbsp;`GAZEBO_PLUGIN_PATH=\xB4pwd\xB4:$GAZEBO_PLUGIN_PATH` doesn't\
    \ overwrite the path it just append the current directory(pwd) to the variable.\
    \ (you can also use $PWD which is handier) Resulting you have a mess after several\
    \ tries. In addition, **export is just temporary** and depends on the current\
    \ terminal. (don't confuse yourself with too many tabs / terminals)\n\nTo **clean\
    \ the variable** use `unset`&nbsp;`GAZEBO_PLUGIN_PATH`\n, then check again the\
    \ variable: `echo`&nbsp;`$GAZEBO_PLUGIN_PATH` (no nothing should be returned)\n\
    \nNow you have to navigate in terminal to the folder where the .so file is located\
    \ (since pwd is the current folder). After using `export`&nbsp;`GAZEBO_PLUGIN_PATH=$PWD`\
    \ your variable should be set correctly. (overwrites existing values)\n\nIf you\
    \ want to **append your path to the variable** use `export`&nbsp;`GAZEBO_PLUGIN_PATH=$PWD:$GAZEBO_PLUGIN_PATH`.\n\
    \n(Hint: you can also **set the path directly** for example: `export`&nbsp;` GAZEBO_PLUGIN_PATH=/home/#USERNAME#/Documents/testplugin/build`)\n\
    \nTo have the GAZEBO_PLUGIN_PATH **permanent** you can include the \"export xx=xx\"\
    \ line into your `~/.bashrc` file\n\nEdit/Remark:\n\nThe default gazebo plugins\
    \ are loading since **gazebo is sourcing its default environment variables before\
    \ the start**. This is carried out using the file `/usr/share/gazebo/setup.sh`\
    \ or `/usr/share/gazebo-X.X/setup.sh`(the X.X is your respective gazebo version)\n\
    \nTo be aware of this behavior and be able to see its default values, you can\
    \ use `source`&nbsp;`/usr/share/gazebo/setup.sh`\n\nAgain, to have this permanent\
    \ in every console instance, add the line to your .bashrc file."
