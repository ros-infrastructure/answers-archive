  body_markdown: "If you have a package.xml, then you have a package using catkin.\
    \ In this case, there is no \"rosdep\" key for the package.xml. You need to do\n\
    \n     <build_depend>liblapack-dev</build_depend>\n\nThis will make sure the package\
    \ is installed when you go to build on the farm -- however, to actually get the\
    \ linker flags, etc, you will need to probably add the following in your CMakeLists.txt,\
    \ near the find_package(catkin):\n\n    find_package(LAPACK REQUIRED)\n    \n\
    Then, when linking any executable, you'll probably need:\n\n    target_link_libraries(name_of_target\
    \ ${catkin_LIBRARIES} ${LAPACK_LIBRARIES})\n\n(Note: I've not used LAPACK with\
    \ catkin, so the actual CMAKE may be a bit different, a quick google search shows\
    \ the find_package call is probably right, but I'm guessing at the name of the\
    \ _LIBRARIES portion actually exported by LAPACK... I'd check their documentation\
    \ if things still don't link)"
