    David is right , in detail , you can see the code in [worldToMap](https://github.com/ros-planning/navigation/blob/kinetic-devel/costmap_2d/include/costmap_2d/costmap_2d.h#L143) below:

          /**
           * @brief  Given two map coordinates... compute the associated index
           * @param mx The x coordinate
           * @param my The y coordinate
           * @return The associated index
           */
          inline unsigned int getIndex(unsigned int mx, unsigned int my) const
          {
            return my * size_x_ + mx;
          }
