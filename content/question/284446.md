I was running through the tutorial at: https://github.com/ros2/ros2/wiki/Ament-Tutorial. I had no issue building ROS2 from source, but when I created an overlay and tried to build it I saw the following build errors:

![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/15202706199005429.png)

It turns out the source code in the subscriber_node.cpp and publisher_node.cpp on https://github.com/ros2/examples.git is slightly different. Specifically, changing register_macro.hpp to class_loader_register_macro.h solves the issue for both files.

![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/15202726963020527.png)

I also needed to use `-DCMAKE_BUILD_TYPE=Release` to successfully compile as noted in https://github.com/ros2/examples/issues/199 .

Hopefully this helps someone else get up and running a little faster.
