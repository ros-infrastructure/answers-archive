    I think you could use the [`<collision><laser_retro>`](http://sdformat.org/spec?ver=1.7&elem=collision#collision_laser_retro) property to specify a fixed intensity value to be returned by CPU-based ray sensors. I don't think there's an equivalent for GPU ray sensors (those which see visuals instead of collisions), but I could be wrong.
