    You do not need to install the PPA. Please [purge](http://manpages.ubuntu.com/manpages/trusty/man1/ppa-purge.1.html) the PPA from your system.

    To pull in PCL as a dependency for your source package automatically, modify your package.xml [like so](https://github.com/ros-perception/pcl_conversions/commit/a868e1a16e442c135f66a9738619d290bc4ee896)

    Then go into the base of your workspace and run:

        rosdep install --from-paths src --ignore-src --rosdistro indigo -y

    Rosdep will install the correct version of everything. A good reference for how to add PCL to your CMakeLists is [here](http://wiki.ros.org/hydro/Migration#PCL)
