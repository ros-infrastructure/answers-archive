  body_markdown: "You are correct as per the tutorial:\n\n`<node pkg=\"nxt_ros\" type=\"\
    nxt_ros.py\" name=\"nxt_ros\" output=\"screen\" respawn=\"true\">\n    <rosparam\
    \ command=\"load\" file=\"$(find learning_nxt)/robot.yaml\" />\n  </node>`\n\n\
    This launch file XML takes the robot.yaml file and loads the values to the ROS\
    \ parameter server. It does this using the `<rosparam>` tags. Since it is nested\
    \ in the `<node>` tags it sets all the parameters as private names under the nxt_ros\
    \ node. \n\nHope this helps. "
