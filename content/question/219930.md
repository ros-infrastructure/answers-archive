  body_markdown: "If by parts you mean human body parts, you can use OpenNI skeleton\
    \ tracker to achieve your goal. The official ROS port is available from [here](http://wiki.ros.org/openni_tracker).\
    \ Prior to using this package, you need to install NITE library based on the instruction\
    \ provided in [openni_tracker's readme file](https://github.com/ros-drivers/openni_tracker/blob/hydro-devel/README.md).\
    \ You can check [this tutorial](https://github.com/jstnhuang/cse481c_tutorials/wiki/How-to-run-openni_tracker)\
    \ for more information. Please note that the binary installation for this package\
    \ is available only up to ROS *Hydro* which has recently been end of lifed.  You\
    \ may be able to compile `openni_tracker` from source as discussed [in this thread](http://answers.ros.org/question/194940/openni_tracker-or-openni2_tracker-for-ros-indigo/)\
    \ if you are using *Indigo*.\n\nThere seems to be a newer version of this package\
    \ based on `OpenNI2` called [openni2_tracker](https://github.com/ros-drivers/openni2_tracker).\
    \ Unfortunately there is no ROS wiki page about this package and no documentation.\
    \ \n\n"
