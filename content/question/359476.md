    We had to make a change to reflect changes to a new version of the `transport_drivers` repository (`udp_driver` and `serial_driver`) being released to the build farm. This was fixed with [this commit](https://gitlab.com/autowarefoundation/autoware.auto/AutowareAuto/-/commit/50a6256fd107b8f13d8214652aae52a1c71573a4) several months ago. Please pull the latest copy of the code with `git pull` and this should be resolved.

    Additionally, you likely have old versions of the `ade` docker images. Please follow the [General Troubleshooting Steps](https://autowarefoundation.gitlab.io/autoware.auto/AutowareAuto/installation.html#autotoc_md93) to update everything.
