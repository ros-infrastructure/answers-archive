  body_markdown: "Both `libPocoFoundation.so.50` and `libtinyxml2.so.6` come from\
    \ vendor packages, as this one https://github.com/ros2/poco_vendor\n\nThey consist\
    \ of a `CMakeLists.txt` file which install the specific third party library. \n\
    \nIn particular at build time `CMake` will check whether the library is already\
    \ installed on the system/sysroot.\nThe package will be built only if the library\
    \ is not found.\n\nThis could create problems when cross-compiling, since it may\
    \ be that your sysroot or host system includes it, but the target system does\
    \ not.\n\nAs a solution, you have either to install them in the target system\
    \ or make sure that they are not found while cross-compiling.\n\nFew days ago\
    \ there have been some commits to all these vendor packages to allow their cross-compilation\
    \ (before they were not reading the CMake Flags, thus the cross-compiled binaries\
    \ were still x86_64).\nMoreover they added a flag `FORCE_BUILD_VENDOR_PKG` which\
    \ should solve the problem:\nwith this flag enabled, the package will always be\
    \ built in the workspace, regardless of the fact if it was present in the systm\
    \ or not."

I cross-compiled the source for ROS 2 using the following [tutorial](https://index.ros.org/doc/ros2/Tutorials/Cross-compilation/#automated-cross-compilation) (on a Ubuntu 16.04 x86_64)

As I am building for a beagle-board (bbb), the examples are only for arm64 so i made these following changes in the cross_compile repository:

in [Dockerfile_ubuntu_arm](https://github.com/ros2/cross_compile/blob/master/sysroot/Dockerfile_ubuntu_arm):

    4 ARG ARM_ARCH=arm32v7
    ...
    37 RUN sh -c 'echo "deb [arch=amd64,armhf] http://repo.ros2.org/ubuntu/main \
    `lsb_release -cs` main" > /etc/apt/sources.list.d/ros2-latest.list'

and in [entry_point.sh](https://github.com/ros2/cross_compile/blob/master/entry_point.sh):

    $ export TARGET_ARCH=arm
    $ export TARGET_TRIPLE=arm-linux-gnueabihf

But after the built, I exported the ros build with:

    docker cp ros2_cc:/root/cc_ws/ros2_ws .

and send it in the home directory of my board.
