    \ which still do not exist. You probably expect cmake->makefile->make to generate\
    \ \"ptedit_1\" library. \n\nYou must add following command to CMakeList.txt. \n\
    \n    rosbuild_add_library(${PROJECT_NAME} your_source_files)\n\nThis will result\
    \ in required library. Command **target_link_libraries( ptedit_1 ${KDE4_KDEUI_LIBS}\
    \ )** must come after rosbuild command."
