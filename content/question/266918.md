  body_markdown: "Hello,\n\nI  see 3 way to display rosbag data in streaming : \n\n\
    \n----------\n1)  with [rqt_bag](http://wiki.ros.org/rqt_bag)\n\nYou can use the\
    \ executable \"rqt_bag\" (or \"rosrun rqt_bag rqt_bag\") to open a rqt GUI where\
    \ you can load a rosbag -> right click on a topic -> view -> plot -> check the\
    \ data you want on the graph on the new [rqt_plot](http://wiki.ros.org/rqt_plot)\
    \ GUI and click play.\n\nYou will see a graph of your data with a red bar (the\
    \ timeline) to see the current data. It's not a live streaming (all data appear\
    \ on the graph) but it's the easiest method.\n\n\n----------\n2) with [rqt_plot](http://wiki.ros.org/rqt_plot)\n\
    \nYou can play a bag file and open a rqt_plot at the same time with 3 terminal.\
    \ \n\nOn terminal 1, launch a roscore (command \"roscore\")\n\nOn terminal 2,\
    \ launch play your bag file (command \"rosbag play bagname\")\n\nOn terminal 3,\
    \ launch rqt_plot (command \"rqt_plot\" or \"rosrun rqt_plot rqt_plot\")\n\nOn\
    \ the rqt_plot GUI, type the topic you want to display and adjust the axes.\n\n\
    You can also use [PlotJuggler](https://github.com/facontidavide/PlotJuggler) \n\
    \n----------\n3) with [roslaunch](http://wiki.ros.org/roslaunch)\n\nYou can use\
    \ the previous method but instead of launching \"rqt_plot\", just launch rqt (with\
    \ \"rqt\" or \"rosrun rqt rqt\")\n\nThen go to plugin > visualization > Plot\n\
    \nChoose the topic you want.\n\nClick on perspective > Export... and save the\
    \ perspective file where you want (an easy path if possible).\n\nThen you need\
    \ a roslaunch file that look like this : \n\n     <launch>\n      <node name=\"\
    <name_of_your_rosbag_node>\" pkg=\"rosbag\" type=\"rosbag\" args=\"play <name_of_your_rosbag>\"\
    />\n      <node name=\"<name_of_your_gui_node>\" pkg=\"rqt\" type=\"rqt\" args=\"\
    --perspective-file <your_perspective_file>\"/>\n    </launch>\n\nThen execute\
    \ your launch file with \"roslaunch name_of_your_launch_file\".\n\nYour data in\
    \ live streaming with rqt_plot should open.\n\n\n\n"
