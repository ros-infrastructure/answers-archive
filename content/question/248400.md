  body_markdown: "According to http://wiki.ros.org/message_filters there is a TimeSequencer\
    \ that does this, but only for C++ (and not much activity here about it, some\
    \ example code is on http://stackoverflow.com/questions/34322075/ros-message-filterstimesequencer).\n\
    \nI tried this rospy.Timer based method and it looks like it is working, I don't\
    \ know if it is robust- a bunch of Timers must be created behind the scenes and\
    \ hopefully are taken care of properly:\n\n    #!/usr/bin/env python\n    \n \
    \   import functools\n    import rospy\n    \n    from std_msgs.msg import Float64\n\
    \    \n    rospy.init_node(\"delay\")\n    \n    pub = rospy.Publisher(\"delayed\"\
    , Float64, queue_size=4)\n    \n    def delayed_callback(msg, event):\n      \
    \  pub.publish(msg)\n    \n    def callback(msg):\n        timer = rospy.Timer(rospy.Duration(2.0),\n\
    \                            functools.partial(delayed_callback, msg),\n     \
    \                       oneshot=True)\n    \n    sub = rospy.Subscriber(\"input\"\
    , Float64, callback, queue_size=4)\n    \n    rospy.spin()\n"
