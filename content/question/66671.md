  body_markdown: "You can subscribe to the publication of the pose topic and store\
    \ each publication in a pose array, for example. Then you can process that array\
    \ to sum the distances between each reading.\n\n    float path_length = 0.0;\n\
    \    std::vector<geometry_msgs::PoseStamped>::iterator it = plan.poses.begin();\n\
    \    geometry_msgs::PoseStamped last_pose;\n    last_pose = *it;\n    it++;\n\
    \    for (; it!=plan.poses.end(); ++it) {\n       path_length += hypot(  (*it).pose.position.x\
    \ - last_pose.pose.position.x, \n                             (*it).pose.position.y\
    \ - last_pose.pose.position.y );\n       last_pose = *it;\n    }\n    ROS_INFO(\"\
    ... path length: %6.3f\", path_length);\n\n[source of this code](https://code.ros.org/trac/wg-ros-pkg/browser/branches/trunk_cturtle/stacks/point_cloud_perception_experimental/object_mapping/src/move_base_interface.cpp?rev=46496)\n\
