  body_markdown: "Assuming that you're intending to do some sort of processing on\
    \ the frames from the video stream...\n\nIf you use the [imread](http://www.mathworks.com/help/matlab/ref/imread.html)\
    \ method and the [mjpeg_server](http://www.ros.org/wiki/mjpeg_server) it should\
    \ still be possible to use something like `img=imread('http://localhost:8080/snapshot?topic=/IMAGE_TOPIC')`\
    \ to access the current image.\n\nI hope speed isn't a concern for your application,\
    \ it's been a while since I tried something like this, and if memory serves me\
    \ well, it took about 1-2 seconds per frame for the images that I was sending.\
    \ \n\n(As a note, I do not remember if there was any magic associated with telling\
    \ matlab the file extension since it's not included in the url)"
