  body_markdown: "Joint tag does not belong inside the transmission tag.\n\nYou define\
    \ your joints in model tags. Then you pass the transmission tags only the name\
    \ of the joint.\n\n    <joint name=\"wheel_right_joint\" type=\"revolute\">\n\
    \          <insert_block name=\"origin\" />\n          <limit effort=\"1000.0\"\
    \ lower=\"-1e+16\" upper=\"1e+16\" velocity=\"3.5\"/>\n          <axis xyz=\"\
    -1 0 0\" />\n          <joint_properties damping=\"0\" friction=\"0.0\" />\n \
    \         <parent link=\"base_link\" />\n          <child link=\"${name}_link\"\
    \ />\n    </joint>\n    \n    <transmission name=\"tran_${number}\">\n       \
    \ <type>transmission_interface/SimpleTransmission</type>\n        <joint name=\"\
    wheel_right_joint\">\n            <hardwareInterface>hardware_interface/VelocityJointInterface</hardwareInterface>\n\
    \        </joint>\n        <actuator name=\"left_wheel_actuator\">\n         \
    \   <hardwareInterface>hardware_interface/VelocityJointInterface</hardwareInterface>\n\
    \            <mechanicalReduction>7</mechanicalReduction>\n        </actuator>\n\
    \    </transmission>"
