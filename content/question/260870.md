  body_markdown: "One of the reasons for markers not appearing and IK not working\
    \ is the IK solver not being specified. You have to specify the IK solver in the\
    \ config file. This can be done manually or through the setup assistant. \n\n\
    Does your kinematics.yaml file have the following?\n\n      name_of_kinematic_chain:\n\
    \        kinematics_solver: kdl_kinematics_plugin/KDLKinematicsPlugin\n      \
    \  kinematics_solver_search_resolution: 0.05\n        kinematics_solver_timeout:\
    \ 1\n        kinematics_solver_attempts: 10\n\nIf not you could add it. Replace\
    \ the \"name_of_kinematic_chain\" with yours. \nHope it helps!"
