    The latest versions of Gazebo compiled from source support 4 physics engines: ODE, bullet, simbody and dart. Historically, Gazebo only used ODE, hence it is the default one. We are currently running tests to compare the accuracy and speed of each physics engine and will publish these in a scientific meeting.

    See also other answers [here](http://answers.gazebosim.org/question/5863/physical-engine-for-non-planar-autonomous-vehicle/) and [here](http://answers.gazebosim.org/question/5361/which-physics-engine-is-used-by-gazebosim/).
