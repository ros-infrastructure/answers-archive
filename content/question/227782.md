  body_markdown: "As a workaround, I decided to implement a `timeshift` node which\
    \ shifts the timestamp to the current hour. Here is the complete Python code and\
    \ my `ueyecam` launch file:\n\n**timeshift.py:**\n\n    #!/usr/bin/env python\n\
    \    import rospy\n    import sys\n    from sensor_msgs.msg import Image\n   \
    \ import numpy as np\n\n    def callback(data):\n        data.header.stamp +=\
    \ rospy.Duration.from_sec(np.round((rospy.Time.now() - data.header.stamp).to_sec()\
    \ / 3600.0) * 3600.0)\n        pub.publish(data)\n\n    if __name__ == \"__main__\"\
    :\n\n        if len(sys.argv) < 3:\n            raise Exception(\"Usage: %s input_topic\
    \ output_topic\" % sys.argv[0])\n\n        rospy.init_node(\"timeshift\")\n\n\
    \        pub = rospy.Publisher(sys.argv[2], Image, queue_size=1)\n        rospy.Subscriber(sys.argv[1],\
    \ Image, callback, queue_size=1)\n\n        rospy.spin()\n\n**ueyecam.launch:**\n\
    \n    <launch>    \n\n      <arg name=\"camname\" />\n\n      <node pkg=\"nodelet\"\
    \ type=\"nodelet\" name=\"nodelet_manager\" args=\"manager\" />\n\n      <node\
    \ pkg=\"nodelet\" type=\"nodelet\" name=\"$(arg camname)\" args=\"load ueye_cam/ueye_cam_nodelet\
    \ nodelet_manager\">\n        <param name=\"camera_name\" value=\"$(arg camname)\"\
    \ />\n        <param name=\"image_width\" value=\"1600\" />\n        <param name=\"\
    image_height\" value=\"1200\" />\n        <param name=\"frame_name\" value=\"\
    $(arg camname)\" />\n        <param name=\"camera_intrinsics_file\" value=\"$(find\
    \ camera)/launch/$(arg camname).yaml\" />\n        <param name=\"frame_rate\"\
    \ value=\"15\" />\n        <param name=\"exposure\" value=\"10\" />\n        <remap\
    \ from=\"~/image_raw\" to=\"~/image_raw_old\" />\n      </node>\n\n      <node\
    \ pkg=\"camera\" type=\"timeshift.py\" name=\"timeshift\" args=\"/$(arg camname)/image_raw_old\
    \ /$(arg camname)/image_raw\" />\n   \n    </launch>"
