    \ folder in the boost directory.\nI had faced this same issue while installing\
    \ Gazebo but it solved when I renamed the directory ***lib64-msvc-12.0*** to ***lib***.\
    \ \n\nPlease go to the directory **D:/Jonathan/Gazebo/gz-ws/boost_1_56_0** and\
    \ check if there exists a folder that contains .dll as well as .lib files with\
    \ names beginning as mentioned in the error message as \n\n\n - boost_system\n\
    \ - boost_filesystem\n - boost_program_options\n - boost_regex\n - boost_iostreams\n\
    \nRename that directory to lib and the ..\\configure command will install sdformat\
    \ without error.\n"
