  body_markdown: "Yes you can 'bypass' the stereo proc. \nAs explained in : http://wiki.ros.org/stereo_image_proc#stereo_image_proc\n\
    \n>This package contains nodelets for creating disparity images and point clouds\
    \ from stereo. This allows stereo_image_proc functions to be easily combined with\
    \ other nodelets, for example camera drivers or higher-level vision processing.\
    \ In fact, the stereo_image_proc node simply loads a combination of nodelets.\
    \ \n\nTo get the individual functionalities from stereo proc you need to use it's\
    \ nodelets. As of now it has three:\nDisparity, Pointcloud, and Pointcloud2. \n\
    \nUsing nodelets allows you to compose your own image pipe line. See: http://wiki.ros.org/nodelet\n\
    \nFor example, this launch file connects a few nodelets together. Currently there\
    \ are only pre-cooked nodelets. But we plan to add custom nodelets into this pipeline.\
    \ \n\n\n    <node pkg=\"nodelet\" type=\"nodelet\" name=\"nodelet_manager\" args=\"\
    manager\"/>\n    \n    <node pkg=\"nodelet\" type=\"nodelet\" name=\"left_rectifier\"\
    \n          args=\"load image_proc/rectify nodelet_manager\">\n    <remap from=\"\
    /image_mono\" to=\"/camera/left/image_raw\"/>\n    <remap from=\"/camera_info\"\
    \ to=\"/camera/left/camera_info\"/>\n    <remap from=\"/image_rect\" to=\"/camera/left/image_rect\"\
    />\n    </node>\n    \n    <node pkg=\"nodelet\" type=\"nodelet\" name=\"right_rectifier\"\
    \n          args=\"load image_proc/rectify nodelet_manager\">\n    <remap from=\"\
    /image_mono\" to=\"/camera/right/image_raw\"/>\n    <remap from=\"/camera_info\"\
    \ to=\"/camera/right/camera_info\"/>\n    <remap from=\"/image_rect\" to=\"/camera/right/image_rect\"\
    />\n    </node>\n    \n    <node pkg=\"nodelet\" type=\"nodelet\" name=\"disparity_gen\"\
    \n          args=\"load stereo_image_proc/disparity nodelet_manager\">\n    <param\
    \ name=\"approximate_sync\" value=\"true\"/>\n    <remap from=\"/left/image_rect\"\
    \ to=\"/camera/left/image_rect\"/>\n    <remap from=\"/left/camera_info\" to=\"\
    /camera/left/camera_info\"/>\n    \n    <remap from=\"/right/image_rect\" to=\"\
    /camera/right/image_rect\"/>\n    <remap from=\"/right/camera_info\" to=\"/camera/right/camera_info\"\
    />\n    <remap from=\"/disparity\" to=\"/camera/disparity\"/>\n    </node>\n\n"
