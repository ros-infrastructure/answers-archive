  body_markdown: "The problem was that I installed the Primesense drivers for v1.5,\
    \ but my OpenNI version was v2.2. I downloaded OpenNI v1.5 from [here](http://www.openni.org/openni-sdk/openni-sdk-history-2/)\
    \ instead and it worked.\n\nEDIT: Also, there is an issue with the openni_camera\
    \ package. You can leave the deb package installed, as long as your compiled sources\
    \ have priority. Use `echo $ROS_PACKAGE_PATH` and see if your source directory\
    \ is first. This is what I have:\n\n    $ echo $ROS_PACKAGE_PATH\n    /home/andrew/catkin_ws/src:/opt/ros/groovy/share:/opt/ros/groovy/stacks\n\
    \nGo to your sources directory, get the source code using git and use the `rollback_usb`\
    \ branch.\n\n    cd ~/catkin_ws/src\n    git clone https://github.com/ros-drivers/openni_camera.git\n\
    \    git checkout rollback_usb\n    \nCompile using catkin_make in the root of\
    \ your catkin directory\n\n    cd ~/catkin_ws\n    catkin_make\n\nFinally, test\
    \ it out with `roslaunch openni_launch openni.launch`.\n\nYou can read more about\
    \ this issue [here](https://github.com/ros-drivers/openni_camera/issues/18).\n\
    \nPrimesense drivers can be downloaded from the OpenNI website. I'm using v5.1.2.1\
    \ from [here](http://www.openni.org/wp-content/uploads/2012/12/Sensor-Bin-Linux-x86-v5.1.2.1.tar.zip)\
    \ (32-bit). 64-bit version is [here](http://www.openni.org/wp-content/uploads/2012/12/Sensor-Bin-Linux-x64-v5.1.2.1.tar.zip).\
    \ I think there are more recent versions over [here](http://www.openni.org/wp-content/uploads/2013/11/)\
    \ if you like, but I haven't tried them. \n\nAlternatively, if you choose to use\
    \ v2.2, then you should install the packages openni2_camera and openni2_launch\
    \ instead (see [here](https://github.com/ros-drivers))."
