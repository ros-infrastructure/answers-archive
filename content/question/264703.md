  body_markdown: "Thanks to [flexbe devs on github](https://github.com/team-vigir/flexbe_behavior_engine/issues/34),\
    \ the following steps resolve the issue:\n\n1. Open PyCharm's settings\n2. Open\
    \ your project on the left of the settings window\n3. Open Project Structure\n\
    4. Select your `[your_project_prefix]_flexbe_states` project that is created when\
    \ running `rosrun flexbe_widget create_repo [your_project_prefix]`\n5. Click on\
    \ Add Content Root\n6. Select `xenials_ws/src/flexbe_behavior_engine`\n7. Mark\
    \ that folder as source\n8. Mark the subdirectory `flexbe_core` as source\n9.\
    \ Mark the subdirectory `flexbe_core/src` as source\n10. Click on OK and wait\
    \ until PyCharm's triggers run and find the flexbe sources. "
