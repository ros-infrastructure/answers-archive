    A semantic map is a data structure, it is not a processing unit, so there are no inputs or outputs. The map consists of object instances at different poses in space and their composition of sub-parts. The objects are described as instances of more generic object classes and inherit their properties. I've already pointed you to related publications and can only recommend to read about the concepts behind semantic maps, e.g. in [1].

    You can, in principle, create semantic maps from very different input sources: In [1], RGB-D data is used, in the KnowRob tutorial at the ROS Fall School 2010, we have interfaced the [tabletop_object_detector](http://ros.org/wiki/tabletop_object_detector), you can use image-based recognition methods like the [RoboEarth object recognition system](http://ros.org/wiki/roboearth), or you can build the map yourself, manually or with the (experimental) [semantic map editor](http://ros.org/wiki/mod_semantic_map) [(some docs)](http://ias.in.tum.de/kb/wiki/index.php/Mod_semantic_map).

    Moritz

    [1] http://ias.cs.tum.edu/_media/spezial/bib/iros12semantic_mapping.pdf
