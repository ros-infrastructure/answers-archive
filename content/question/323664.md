  body_markdown: "According to [docker success center: Error pulling image : no matching\
    \ manifest](https://success.docker.com/article/error-pulling-image-no-matching-manifest)\
    \ the problem would indeed be that you're trying to `pull` an image for an unsupported\
    \ OS/arch combination.\n\n> I suspect the reason for this is the fact that I am\
    \ using a 32-bit laptop instead of 64-bit. Its there any way to pull the ros image\
    \ on a 32-bit computer?\n\nI'm not aware of official `i386` images. The tags on\
    \ [hub.docker.com/ros](https://hub.docker.com/_/ros/) also seem to suggest only\
    \ `amd64`, `arm64` and `arm` are supported. The *Supported Architectures* under\
    \ *Quick Reference* also states that:\n\n>  - Supported architectures: (more info)\n\
    > \n>   `amd64`, `arm32v7`, `arm64v8`\n\nIt should be doable to build 32bit images\
    \ yourself though: changing [this line](https://github.com/osrf/docker_images/blob/49d22242e02e9c541a9e85b657e1785617b6f470/ros/kinetic/ubuntu/xenial/ros-core/Dockerfile#L3)\
    \ to read `i386/ubuntu:xenial` *should* work.\n\nAt least for Kinetic. There are\
    \ no `i386` builds for Melodic any more (Lunar dropped this support: see [REP\
    \ 3: Architectures](http://www.ros.org/reps/rep-0003.html#architectures))."
