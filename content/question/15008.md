    You could use the [model editor](http://gazebosim.org/tutorials?tut=model_editor&cat=model_editor_top) to create it graphically.

    Or you could write [SDF](http://sdformat.org/spec) directly. Something like this:

        <model name="box">
          <pose>0 0 0.5 0 0 0</pose>
          <link name="link">
            <collision name="collision">
              <geometry>
                <box>
                  <size>1 1 1</size>
                </box>
              </geometry>
            </collision>
            <visual name="visual">
              <geometry>
                <box>
                  <size>1 1 1</size>
                </box>
              </geometry>
              <material>
                <script>Gazebo/Red</script> <!-- Green / Blue -->
              </material>
            </visual>
          </link>
        </model>

    If you're new to making Gazebo models, [this](http://gazebosim.org/tutorials?tut=model_structure&cat=build_robot) tutorial has a nice introduction.
