  body_markdown: "Sure you can. I did exactly this with lots of worlds by just creating\
    \ a catkin package called `quad_world` with a launch file in it that spawns the\
    \ quadcopter and all kinds of other stuff (I used `quadrotor_empty_world.launch`\
    \ as base). \n\nAs follows:\n`start.launch` contains:\n\n    <arg name=\"world_name\"\
    \ default=\"$(find quad_world)/worlds/tonystart124.world\" />\n    <include file=\"\
    $(find quad_world)/launch/world.launch\">\n      <arg name=\"world_name\" default=\"\
    $(arg world_name)\"/>\n    </include>\n\n    <include file=\"$(find hector_quadrotor_gazebo)/launch/spawn_quadrotor.launch\"\
    \ />\n\n`world.launch` is the following:\n    <launch>\n    \n      <!-- these\
    \ are the arguments you can pass this launch file, for example paused:=true -->\n\
    \      <arg name=\"paused\" default=\"false\"/>\n      <arg name=\"use_sim_time\"\
    \ default=\"true\"/>\n      \n      <arg name=\"headless\" default=\"false\"/>\n\
    \      <arg name=\"debug\" default=\"false\"/>\n      <arg name=\"verbose\" default=\"\
    false\" />\n    \n      <arg name=\"world_name\" />\n    \n      <!-- set use_sim_time\
    \ flag -->\n      <group if=\"$(arg use_sim_time)\">\n        <param name=\"/use_sim_time\"\
    \ value=\"true\" />\n      </group>\n    \n      <!-- set command arguments -->\n\
    \      <arg unless=\"$(arg paused)\" name=\"command_arg1\" value=\"\"/>\n    \
    \  <arg     if=\"$(arg paused)\" name=\"command_arg1\" value=\"-u\"/>\n      <arg\
    \ unless=\"$(arg headless)\" name=\"command_arg2\" value=\"\"/>\n      <arg  \
    \   if=\"$(arg headless)\" name=\"command_arg2\" value=\"-r\"/>\n      <arg unless=\"\
    $(arg verbose)\" name=\"command_arg3\" value=\"\"/>\n      <arg     if=\"$(arg\
    \ verbose)\" name=\"command_arg3\" value=\"--verbose\"/>\n      <arg unless=\"\
    $(arg debug)\" name=\"script_type\" value=\"gzserver\"/>\n      <arg     if=\"\
    $(arg debug)\" name=\"script_type\" value=\"debug\"/>\n    \n      <!-- start\
    \ gazebo server-->\n      <node name=\"gazebo\" pkg=\"gazebo_ros\" type=\"$(arg\
    \ script_type)\" respawn=\"false\" output=\"screen\"\n    \targs=\"$(arg command_arg1)\
    \ $(arg command_arg2) $(arg command_arg3) $(arg world_name)\" />\n    \t\n   \
    \   <!-- start gazebo client -->\n      <node name=\"gazebo_gui\" pkg=\"gazebo_ros\"\
    \ type=\"gzclient\" respawn=\"false\" output=\"screen\"/>\n\n    \n    </launch>\n\
    \nGood luck with your project!"
