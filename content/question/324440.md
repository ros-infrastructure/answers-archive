    \ me (Also Ubuntu 18.04 here). I issued the following commands:\n> \n>     sudo\
    \ apt-get install gcc-4.8\n>     sudo update-alternatives --install /usr/bin/gcc\
    \ gcc /usr/bin/gcc-7 40\n>     sudo update-alternatives --install /usr/bin/gcc\
    \ gcc /usr/bin/gcc-4.8 30\n> \n> Then I choose gcc 4.8 with:\n> \n>     sudo update-alternatives\
    \ --config gcc\n> \n> Repeated the same steps for g++\n> \n>     sudo apt-get\
    \ install g++-4.8\n>     sudo update-alternatives --config g++\n>     sudo update-alternatives\
    \ --install /usr/bin/g++ g++ /usr/bin/g++-7 40\n>     sudo update-alternatives\
    \ --install /usr/bin/g++ g++ /usr/bin/g++-4.8 30\n> \n> And then choosing g++\
    \ 4.8 with:\n> \n>     sudo update-alternatives --config g++\n> \n> (commands\
