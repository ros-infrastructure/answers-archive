  body_markdown: "A monocular camera  gives you a [2D projection of 3D space](http://en.wikipedia.org/wiki/Pinhole_camera_model#The_geometry_and_mathematics_of_the_pinhole_camera).\
    \ This means that if you know the location (x,y) of something in the image, there\
    \ are infinite possible locations in 3D space. Specifically, that 2D point (x,y)\
    \ defines a line in 3D space shooting out of the camera towards the object.\n\n\
    Mathematically, this projection is a linear operation, and can be represented\
    \ as a 4x3 linear operator (matrix) normally called the [camera projection matrix](http://en.wikipedia.org/wiki/Camera_matrix).\
    \ You can see that this matrix is not invertible (you can't just reverse the transform).\n\
    \nFor this reason, in order to determine which location along that line corresponds\
    \ to the original point, you need more information. In the general case, this\
    \ extra data comes from a second camera with a view of the point in question.\
    \ Then the 3D point can be reconstructed from two 2D points that are known to\
    \ correspond to the same 3D point. Such reconstruction is done using [epipolar\
    \ geometry](http://en.wikipedia.org/wiki/Epipolar_geometry).\n\nUnfortunately,\
    \ your AR drone only has a monocular camera, so stereo vision is not an option.\
    \ However, since your red ball has non-zero area, one option is to estimate the\
    \ distance to the ball by the apparent size of the ball in the image. You can\
    \ derive this from the [pinhole camera model equations](http://en.wikipedia.org/wiki/Pinhole_camera_model#The_geometry_and_mathematics_of_the_pinhole_camera)\
    \ and normal trigonometry. \n\nAll you need for this is the focal length of your\
    \ ARDrone's camera and the actual width of the ball. If you don't know it, you\
    \ can get the focal length by running the ROS [camera calibration frontend](http://www.ros.org/wiki/camera_calibration/Tutorials/MonocularCalibration)\
    \ on the images from your ARDrone."
