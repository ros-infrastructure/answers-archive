  body_markdown: "On Ubuntu at least, you should be able to install the navigation_stage\
    \ package through apt. First, follow the <a href=\"http://www.ros.org/wiki/ROS/Installation\"\
    >ROS Installation Instructions</a>. \n\nNext, you should be able to run a simple\
    \ \"<code>sudo apt-get install ros-diamondback-navigation-tutorials</code>\" to\
    \ install the navigation_tutorials stack which includes the <a href=\"http://www.ros.org/wiki/navigation_stage\"\
    >navigation_stage</a> package.\n\nIf you're not running Ubuntu, you'll want to\
    \ use <a href=\"http://www.ros.org/wiki/rosinstall\">rosinstall</a> or mercurial\
    \ directly to pull the navigation_tutorials package from https://kforge.ros.org/navigation/tutorials.\n\
    \nAfter this, it should just be a matter of running <code>move_base_multi_robot.launch</code>\
    \ to see an example of navigation with multiple robots.\n\nHope this helps."
