  body_markdown: |-
    See the [Map Management Parameters](http://www.ros.org/wiki/costmap_2d#Map_management_parameters) of the costmap_2d docs. Specifically, the `resolution` parameter is what you are looking for - it specifies the meters/cell for the costmap.

    Note that that parameter (as well as the other size related parameters like width and height) only apply to rolling maps - if you are using a static_map, these parameters are pulled from the metadata of the static map. See the [OccupancyGrid](http://www.ros.org/doc/api/nav_msgs/html/msg/OccupancyGrid.html) message for details on the information that comes along with the static_map from the map_server.
