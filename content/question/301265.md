    The map_server loads an image + YAML file to publish a nav_msgs/OccupancyGrid. You can edit the image file in any image editor (e.g. GIMP, Photoshop, etc). The [wiki page for map_server](http://wiki.ros.org/map_server) has details of how to setup the YAML file that tells map_server how to interpret the image.
