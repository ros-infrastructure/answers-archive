  body_markdown: "You may have multiple versions of rtabmap. `rtabmap-databaseViewer`\
    \ is installed with the binaries. To make it simple, remove rtabmap installed\
    \ by source, then make sure you upgrade both `ros-kinetic-rtabmap` and `ros-kinetic-rtabmap-ros`\
    \ packages to latest version: \n\n    $ sudo rm -r /usr/local/bin/rtabmap*\n \
    \   $ sudo rm -r /usr/local/lib/rtabmap*\n    $ sudo rm -r /usr/local/lib/librtabmap*\n\
    \    $ sudo rm -r /usr/local/include/rtabmap*\n    \n    $ sudo apt-get install\
    \ ros-kinetic-rtabmap-ros ros-kinetic-rtabmap\n\ncheers,<br/>\nMathieu"
