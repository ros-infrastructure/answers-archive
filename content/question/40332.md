  body_markdown: "If you are sure of the quaternion values. You can simply publish\
    \ using geometry_msgs/PoseStamped. Sample:\n\n        publisher = nh.advertise<move_base_msgs::MoveBaseActionGoal>(\"\
    move_base/goal\", 5);\n        geometry_msgs::PoseStamped GoalPose;\n    \tmove_base_msgs::MoveBaseActionGoal\
    \ Goal_Pose;\n    \t\t\n    \tGoalPose.pose.position.x = <current pose x>;\n \
    \   \tGoalPose.pose.position.y = <current pose y>;\n    \tGoalPose.pose.position.z\
    \ = <current pose z>;\n\t\n    \tGoalPose.pose.orientation.x = <desired orientation\
    \ x>;\n    \tGoalPose.pose.orientation.y = <desired orientation y>;\n    \tGoalPose.pose.orientation.z\
    \ = <desired orientation z>;\n    \tGoalPose.pose.orientation.w = <desired orientation\
    \ w>;\n    \t\t\n    \tGoal_Pose.header.seq = GoalPose.header.seq = 1;\n    \t\
    GoalPose.header.stamp = 1;\n    \tGoal_Pose.header.frame_id = GoalPose.header.frame_id\
    \ = \"/map\";\n\n    \tGoal_Pose.goal.target_pose = GoalPose;\n    \tpublisher.publish(Goal_Pose);\n\
    \nI used the above on a TurtleBot and it worked perfectly!"
