    By default, only `ROS_INFO()` level messages (and above) appear in the console output.

    You can change that on a per-logger granularity by [setting the logger level](http://ros.org/wiki/rxconsole#Logger_Levels) in `rxconsole`.

    There are also ways to set the [logger configuration](http://ros.org/wiki/rosconsole#Configuration) before a node starts running.
