  body_markdown: "Figured it out. Here's the process:\n\n    $ ign gazebo --version\n\
    \    Ignition Gazebo, version 6.14.0\n    Copyright (C) 2018 Open Source Robotics\
    \ Foundation.\n    Released under the Apache 2.0 License.\n\nROS2 - Humble.\n\
    Using fire_station download from https://github.com/osrf/gazebo_models/tree/master\
    \ which has a directory structure like this:\n\n    fire_station\n    --materials\n\
    \    --meshes\n    --model.config\n    --model.sdf\n\nAdd to .bashrc:\n\n    export\
    \ IGN_GAZEBO_RESOURCE_PATH=<full path to your models directory>\n\nin the launch.py\
    \ file:\n\n  \n\n     robot_state_publisher = Node(\n            package='robot_state_publisher',\n\
    \            executable='robot_state_publisher',\n            name='robot_state_publisher',\n\
    \            output='both',\n            parameters=[{\n                    'robot_description':Command(['xacro','\
    \ ', robot_description_file]),\n                    'use_sim_time': True\n   \
    \             }],\n        )\n    \n        spawn = Node(\n                package='ros_gz_sim',\
    \ \n                executable='create',\n                arguments=[\n      \
    \          '-name', 'mybot',\n                '-topic', '/robot_description'],\n\
    \                output='screen'\n            )\n        \n            gazebo\
    \ = ExecuteProcess(\n                cmd=['ign', 'gazebo', world_sdf_file],\n\
    \                output='screen'\n            )\n        ...\n        \n     \
    \        return LaunchDescription([\n                 gazebo,\n              \
    \   spawn,\n                 ... others like starting rviz, joint_state_publisher_gui,\
    \ ros_gz_bridge etc.\n              ])\n    \nand in world_sdf_file:\n\n    <?xml\
    \ version='1.0' encoding='ASCII'?>\n    <sdf version='1.6'>\n      <world name='world_demo'>\n\
    \    ...\n    <include>\n          <uri>\n            model://fire_station\n \
    \         </uri>\n        </include>\n    ...\n     </world>\n    </sdf>"

     <include>
     <uri>model://fire_truck</uri>
     </include>

..using a model downloaded from https://github.com/osrf/gazebo_models/tree/master/fire_truck. But, I get an error that the file cannot be found.

The docs seem to be all over the place on this issue and none of the demos have a local file for a uri as an example.
