    planning_scene_interface.applyCollisionObjects

lets planning scene to account for the added obstacles, and hence the planner (OMPL-based) will compute motion plan taking into account the obstacles. The collision objects are static.  This means that, if we add a collision object after we have invoked the motion plan computation / execution, this collision object will not be accounted for. We could see this in `rviz` and the robotic arm moving through it. 

I have created another node, that creates obstacle objects (cylinder, box etc) and publishes on the topic 

    "collision_object"

Running this node in a separate terminal, I was able to see the obstacles being added. 

My first question, 

rviz does not automatically show the new collision object that were published. Instead we have to press  `Add->moveit_ros_visualization->planning_scene` on `rviz` window. Is this the usual procedure to show published obstacles in the simulator?
