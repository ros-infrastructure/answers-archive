  body_markdown: "In general, when ROS complains that it can't find a package, I would\
    \ check the package path in the same terminal with\n\n    echo $ROS_PACKAGE_PATH\n\
    \nIf it's a custom package created by yourself,  it should be found within the\
    \ `src`  folder in one of the workspaces included in the path.\n\nIf the workspace\
    \ the package is in is not in the package path, you have to source the workspace\
    \ in the terminal you are in. \nTo avoid sourcing everytime you create a new terminal,\
    \ it's recommended to add the line `source path_to_your_workspace/catkin_ws/devel/setup.bash`\
    \ in your  ~/.bashrc file"
