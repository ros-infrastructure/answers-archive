    \ make the conversion from the urdf/xacro to sdf to see exactly the name of the\
    \ **collision element** , otherwise it doesnt work.\n\nLets say you have something\
    \ like this in your xacro/urdf:\n\n    <!-- Contact Sensor -->\n    <gazebo reference=\"\
    ${lr}_arm_fist\">\n        <sensor name=\"lowerleg_contactsensor_sensor\" type=\"\
    contact\">\n          <always_on>true</always_on>\n          <contact>\n     \
    \       <collision>${lr}_upper_arm_fixed_joint_lump__${lr}_bump_sensor_collision_collision_1</collision>\n\
    \          </contact>\n          <plugin name=\"${lr}_arm_fist_plugin\" filename=\"\
    libgazebo_ros_bumper.so\">\n            <bumperTopicName>${lr}_arm_fist_contact</bumperTopicName>\n\
    \            <frameName>${lr}_arm_fist</frameName>\n          </plugin>\n    \
    \    </sensor>\n    </gazebo>\n\nIn this example the collision elemnt name in\
    \ the final sdf is: **${lr}_upper_arm_fixed_joint_lump__${lr}_bump_sensor_collision_collision_1**.\n\
    \nThat name was selected because I went to the final SDF and saw which name was\
    \ given to the collision element of the end efector that has to register the collisions.\n\
    \nHere you have the script that transforms **xacro/urdf to sdf**, and look for\
    \ the collision element of the link element that you want to register collisions.\n\
