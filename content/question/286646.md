  body_markdown: "Most probably you don't have the rights to open the port.\nYou can\
    \ easily check with the following command `od /dev/ttyACM0`. If this does not\
    \ work, but works with `sudo od /dev/ttyACM0`, this is the reason.\n\nYou need\
    \ to add yourself to the `dialout` group: `sudo adduser <YOUR_USERNAME> dialout`,\
    \ log out and log back in. Check if you really are in the `dialout` group by checking\
    \ the output of `groups`. This should get you access. \n\nPlease report back if\
    \ this does not solve the issues, preferably with any additional details."
