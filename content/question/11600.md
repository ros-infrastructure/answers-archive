  body_markdown: "rostopic does not handle float images correctly and will instead\
    \ interpret the data as an array of unsigned characters (bytes), which is what\
    \ you see.\n\nIf you only want to have a look at what the depth image looks like,\
    \ you can display it using image_view:\n\n    rosrun image_view image_view image:=/camera/depth/image\n\
    \nIf you need access to the raw float data, you should write a small node that\
    \ subscribes and processes these float images. Check [this tutorial](http://www.ros.org/wiki/image_transport/Tutorials/SubscribingToImages)\n\
