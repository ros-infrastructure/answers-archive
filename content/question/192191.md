  body_markdown: "One example is when you have multiple nodes that have the same parameter\
    \ (e.g. \"frequency\"). How do you set each node's parameter to be different?\n\
    \nIn a launch file, when you do\n\n    <node pkg=\"some_package\" type=\"some_executable\"\
    \ name=\"some_name\" >\n        <param name=\"param_name\" value=\"some_value\"\
    \ />\n    </node>\n\nthe parameter gets resolved to `/some-name/param_name`.\n\
    \nIn order to access the `param_name` without worrying about the node name you\
    \ need  to use \n\n    ros::NodeHandle nh_private(\"~\");\n    std::string param;\n\
    \    nh_private.getParam(\"param_name\", param);\n\notherwise you won't be able\
    \ to get the parameter.\n\nHope it helps."
