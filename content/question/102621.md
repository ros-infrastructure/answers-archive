  body_markdown: "There is ROS package called `costmap_2d`. \nThe costmap_2d package\
    \ provides a configurable structure that maintains complete info about all position\
    \ in the map in the form of a occupancy grid, which helps robot navigate.\n\n\
    Particularly for your problem, there is a parameter called \"inflation_radius\"\
    : default set as 0.55m.\nI am using ROS fuerte. In my system this parameter is\
    \ found at:\n`/opt/ros/fuerte/stacks/navigation/costmap_2d/cfg/cpp/costmap_2d/`\
    \ in `Costmap2DConfig.h`\n\nFor more info, you should refer to the [costmap_2d\
    \ wiki page](http://wiki.ros.org/costmap_2d)."
