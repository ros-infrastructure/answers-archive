I have a serial device connected to my Ubuntu 22.04. I want to publish the data coming from serial to ROS2 Humble topic. I dont want to use timer rather I would like to publish as & when data comes to the serial device. I am currently accomplishing this as below. Will this cause any issues ? Asking this as I am already spinning my node & running another infinite loop to read continously from serial device.

    class CcTransmitPublisherNode(Node): 
    
        def __init__(self): 
            super().__init__("cc_transmit_pub_node")  
            self.cc_control_publisher_ = self.create_publisher(CcMessage, "cc_transmit_topic", 10)
            self.ser = serial.Serial("/dev/ttyUSB1", baudrate = 11520, parity=serial.PARITY_NONE, 
                                   stopbits=serial.STOPBITS_ONE, bytesize=serial.EIGHTBITS, 
                                   timeout=0.3)
            self.cc_controlmsg_publisher()      
         
        def cc_controlmsg_publisher(self):
            msg = CcMessage()
            while True:
                ser_data = self.ser.readline()
                msg.cc_message = ser_data.decode("utf-8")
                self.cc_control_publisher_ .publish(msg) 
    
    def main(args=None):
    
           rclpy.init(args=args)
    
           node = CcTransmitPublisherNode()  
    
           rclpy.spin(node)
    
           rclpy.shutdown()
    
    if __name__ == "__main__":
    
            main()
