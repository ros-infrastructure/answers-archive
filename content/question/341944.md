      @Amrita Suresh, you can overlay text inside the camera image using OpenCV. First convert the ROS Image message to OpenCV image using CvBridge. Add text to the image frame. Reconvert this to a ROS Image message and publish to a different topic. You can view this new topic in the RViz display window.
      Some guidance on how to use CvBridge can be seen [here](https://github.com/trunc8/ball-tracking-opencv-and-ros)
