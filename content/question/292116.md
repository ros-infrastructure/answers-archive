  body_markdown: "Hello there,\ni know that post is a little bit old. But i had the\
    \ same problem and found a workaround. My setup is a raspberry which runs ubuntu.\
    \ I used the ros distribution. Arduino was installed with the install package\
    \ from the website, not from the ubuntu repository. I found the the libraries\
    \ for the arduino compilation are stored in the /usr/share/arduino/libraries folder.\n\
    \n - user : ubuntu \n - package where the msg is defined : hw_arduino_package\n\
    \ - message in the msg folder :  stepperAction.msg\n\nSo as workaround i firsat\
    \ generate the libraries with the python script into a temp folder :\n\n    rosrun\
    \ rosserial_arduino make_libraries.py /home/ubuntu/ardtemp hw_arduino_package\n\
    \nThan i have to copy the generated package library to the arduino library folder.\n\
    \n    sudo cp -R /home/ubuntu/ardtemp/ros_lib/hw_arduino_package /usr/share/arduino/libraries/\n\
    \nAfter that it can be included in the arduino package source with \n\n    #include\
    \ <hw_arduino_package/stepperAction.h>\n\nI know that is not the best practise,\
    \ but it works for me. Maybe this would help someone."
