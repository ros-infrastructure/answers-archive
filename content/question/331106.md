    They're [environment variables](https://en.wikipedia.org/wiki/Environment_variable), so you can set them as any other environment variable on Windows: either by using [set](https://ss64.com/nt/syntax-variables.html) (or `setx`), PowerShell or by using the *Environment Variables* editing UI in the *System Properties* applet (may not be present any more in your Windows 10 version).

    See [here](https://superuser.com/questions/949560) for an SO Q&A that discusses a few different approaches.
