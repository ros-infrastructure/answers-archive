    ROS gazebo is a [third-party library](http://www.ros.org/wiki/UsingThirdPartyLibraries). The ROS package wraps the standard [gazebo](http://playerstage.sourceforge.net/gazebo/gazebo.html) implementation.

    To modify gazebo, itself, it looks like you need to create a patch for your changes (as a diff against the downloaded version), and add that to the `patches/` subdirectory.
