  body_markdown: "Since you used rosdep to install them they are selected to be installed\
    \ in the dpkg database. If you ask rosdep to simulate the install and to reinstall\
    \ you can get a list of all the system dependencies you may want to remove. Though\
    \ be careful removing them as they may be shared dependencies with other things\
    \ that you want.\n\nUse \n`rosdep install --simulate --reinstall ...`\n\nwhere\
    \ `...` is the same arguments you used to install and uninstall the packages you\
    \ don't want anymore."

After installing a ros package, when I did rosdep check <package_name> , it has displayed some missing system dependencies that were not taken care of, during apt-get install . So, I installed them using rosdep install. However when I want to remove the ros package , 

*sudo apt-get purge ros-**

*sudo apt-get purge python-ros**

*sudo apt-get autoremove*

running the above three commands seem to be removing only the ros dependencies and not the system dependencies. How do I remove the system dependencies as well in this case? Thank you.
