  body_markdown: "Assuming you are using ROS1:\nThe NodeHandles define how names are\
    \ resolved in the ROS system. See [the wiki](http://wiki.ros.org/Names) for details.\n\
    \nOne typical use case is the following:\n\nCreate a regular and a private NodeHandle:\n\
    \n    ros::NodeHandle nh();\n    ros::NodeHandle pnh(\"~\");\n\nTopics, services,\
    \ etc. typically use the regular NodeHandle `nh`. This ensures that topics etc.\
    \ are always relative to the nodes namespace. \n\nA private NodeHandle makes the\
    \ nodes name part of the namespace. This is good for parameters, as they are typically\
    \ tightly coupled to the node itself and thus having them private avoids collisions."
