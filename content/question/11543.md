  body_markdown: "Similar to [in earlier versions](http://answers.ros.org/question/618/ros-packages-for-ubuntu-1104),\
    \ you can make packages meant for natty narwhal work on oneiric ocelot.\n\nI successfully\
    \ tried the following with electric, but it should also work with diamondback.\n\
    \n - Add the latest package source (in this case: Natty) to your sources.list\
    \ ([electric](http://www.ros.org/wiki/electric/Installation/Ubuntu), [diamondback](http://www.ros.org/wiki/diamondback/Installation/Ubuntu)).\n\
    \ - Install freeglut3-dev, which replaced libglut3-dev in oneiric:\n> sudo apt-get\
    \ install freeglut3-dev\n\n - Install equivs, which will allow you to create pseudo-packages:\n\
    > sudo apt-get install equivs\n\n - Create a file *libglut3-dev.conf* for the\
    \ pseudo package linking libglut3-dev and freeglut3-dev:\n  > Section: misc\n\
    \  >\n  > Priority: optional\n  >\n  > Standards-Version: 3.6.2\n  >\n  > Package:\
    \ libglut3-dev\n  >\n  > Depends: freeglut3-dev\n  >\n  > Description: temporary\
    \ package to satisfy dependencies of Ubuntu 11.04 packages on 11.10\n\n - Convert\
    \ it to an actual package and install it:\n\n  > equivs-build libglut3-dev.conf\n\
    \  >\n  > sudo dpkg -i libglut3-dev_1.0_all.deb\n\n - You should now be able to\
    \ install the full ros desktop using one of the following\n  > sudo apt-get install\
    \ ros-electric-desktop-full\n  >\n  > sudo apt-get install ros-diamondback-desktop-full\
    \ \n\n - Now you still cannot use opencv and some other packages as they are linked\
    \ against old versions of some libraries. Download and install the following packages\
    \ taken from natty to get these to work anyway. Choose the correct link according\
    \ to your architecture:\n\n  [libavcodec52](http://packages.ubuntu.com/natty/libavcodec52)\n\
    \  [libavformat52](http://packages.ubuntu.com/natty/libavformat52)\n  [libavutil50](http://packages.ubuntu.com/natty/libavutil50)\n\
    \  [libavutil-extra-50](http://packages.ubuntu.com/natty/libavutil-extra-50)\n\
    \  [libswscale0](http://packages.ubuntu.com/natty/libswscale0)\n  [libtinyxml2.5.3](http://packages.ubuntu.com/natty/libtinyxml2.5.3)\n\
    \  [libvtk5.4](http://packages.ubuntu.com/natty/libvtk5.4)\n\n  Afterwards, install\
    \ all of these packages using\n\n  > sudo dpkg -i *.deb\n\n  wherever you downloaded\
    \ them to."
