    CentOS 6 has reached End of Life and is no longer a supported version of CentOS: https://wiki.centos.org/About/Product

    You'll probably have better luck with CentOS 7 or 8. Additionally, make sure that you enable the EPEL repository on your host - some rosdep rules reference packages from that repository: https://github.com/ros/rosdistro/blob/master/CONTRIBUTING.md#rhelcentos

    That said, there are several packages required to build ROS that are not available in the out-of-box or EPEL repositories for any version of CentOS. If cannot skip those packages and must build them, you'll need to satisfy those requirements using some other mechanism, such as a 3rd part repository or building the missing packages from source. You'd then need to skip the missing keys when invoking `rosdep` using the `--skip-keys` argument.
