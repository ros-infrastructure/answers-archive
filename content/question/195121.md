  body_markdown: "Building `rqt` or `rqt_common_plugins` from source should not be\
    \ any different from any other ROS package.  The general idea would be to obtain\
    \ copies of the package source code, put them in a workspace, install any system\
    \ dependencies, and then run `catkin_make`. Here is a set of commands that I believe\
    \ would do what you want\n\n    1 $  cd \n    2 $  mkdir -p ~/rqt_ws/src\n   \
    \ 3 $  cd rqt_ws/src\n    4 $  source /opt/ros/indigo/setup.bash\n    5 $  catkin_init_workspace\n\
    \    6 $  cd ..\n    7 $  catkin_make\n    8 $  source devel/setup.bash\n    9\
    \ $  cd src/\n    10 $  git clone https://github.com/ros-visualization/rqt\n \
    \   11 $  git clone https://github.com/ros-visualization/rqt_common_plugins\n\
    \    12 $  rosdep update\n    13 $  rosdep install --from-paths ./ --ignore-src\
    \ --rosdistro indigo -y --simulate\n    14 $  rosdep install --from-paths ./ --ignore-src\
    \ --rosdistro indigo -y\n    15 $  cd ..\n    16 $  catkin_make\n\nIn the above,\
    \ the first  8 lines are just [creating a new workspace](http://wiki.ros.org/catkin/Tutorials/create_a_workspace).\
    \ Lines 9-11 are getting copies of the two packages. Lines 12-14 are installing\
    \ any missing dependencies, and lines 15-16 are building the new workspace."
