  body_markdown: "This means something went wrong when you followed the install steps.\
    \ The `rosinstall` command should have cloned the `pal_hardware_interface` package\
    \ into your `src/` directory, so `rosdep` shouldn't try to resolve it to a system\
    \ dependency. If you follow the steps in the wiki page you've linked to exactly,\
    \ everything should work.\n\nI've verified that the following steps work on a\
    \ fresh Ubuntu Trusty installation. They are basically the steps from the wiki\
    \ page, I didn't adapt anything crucial.\n\n    sudo sh -c 'echo \"deb http://packages.ros.org/ros/ubuntu\
    \ trusty main\" > /etc/apt/sources.list.d/ros-latest.list'\n    wget http://packages.ros.org/ros.key\
    \ -O - | sudo apt-key add -\n    sudo apt-get update\n    sudo apt-get install\
    \ -y python-rosdep python-rosinstall python-catkin-tools git build-essential cmake\n\
    \    sudo rosdep init\n    rosdep update\n    \n    sudo add-apt-repository --yes\
    \ ppa:xqms/opencv-nonfree\n    sudo apt-get update\n    sudo apt-get install -y\
    \ libopencv-nonfree-dev\n    \n    # install ros-core, otherwise rosinstall complains\
    \ that /opt/ros/indigo doesn't exist\n    sudo apt-get install -y ros-indigo-ros-core\n\
    \    \n    mkdir ~/tiago_public_ws\n    cd ~/tiago_public_ws\n    wget https://raw.githubusercontent.com/pal-robotics/tiago_tutorials/master/tiago_public.rosinstall\n\
    \    rosinstall src /opt/ros/indigo tiago_public.rosinstall\n    \n    # Use rosdep\
    \ to install all dependencies\n    rosdep install --from-paths src --ignore-src\
    \ -y --rosdistro indigo --skip-keys=\"opencv2 opencv2-nonfree pal_laser_filters\
    \ speed_limit sensor_to_cloud\"\n    \n    source /opt/ros/indigo/setup.bash\n\
    \    \n    # Init catkin workspace\n    catkin init\n    # Build packages\n  \
    \  catkin build -DCMAKE_BUILD_TYPE=Release\n    source ~/tiago_public_ws/devel/setup.bash\n\
    \nHere is the [Vagrantfile](https://gist.github.com/mintar/e4d23771912343298e000e97dc8362a0)\
    \ I've created to verify that the instructions work.\n"
