  body_markdown: "Hi,\n\nnaoqi_joint_state_cpp is a c++ node. So changing your PYTHONPATH\
    \ won't help you in this matter.\n\nYou should add an environment variable AL_DIR\
    \ and link it to the folder of the naoqi c++ SDK. \n\nOtherwise when you run catkin_make\
    \ you should have the following error message : \n-- +++ processing catkin package:\
    \ 'naoqi_driver'<br>\n-- ==> add_subdirectory(naoqi_bridge/naoqi_driver)<br>\n\
    -- Using these message generators: gencpp;genlisp;genpy<br>\n-- Could not find\
    \ NAOqi's alcommon<br>\n-- Could not find NAOqi's alvision<br>\n-- Could not find\
    \ NAOqi's alproxies<br>\n-- Could not find NAOqi's alerror<br>\n-- Could not find\
    \ NAOqi's alvalue<br>\n-- Cannot find NAOqi C++ sdk; C++ nodes will NOT be built\n\
    \nThis means that the naoqi_joint_states_cpp node won't be built.\n\nHope this\
    \ helps,\n\nCheers,<br>\nMikael"
