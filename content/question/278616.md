  body_markdown: "Check out [the wiki](http://wiki.ros.org/rviz/UserGuide#Displays).\
    \ It shows you how to add topics to visualize with rviz and much more.\n\nIn short,\
    \ in rviz:\n\n 1. Click \"Add\"  towards the bottom of the \"Displays\" window.\n\
    \ 2. A new window will pop up with two tabs, click on the tab labeled \"By topic\"\
    . \n 3. You will see all the topics that rviz can visualize. Find the topic that\
    \ you want to visualize, click on it\n 4. Click \"OK\". \n\n\n----------\n\n**Update:**\n\
    \nSo, if I understand your question correctly you want to display the path that\
    \ your robot is taking. A way to do this is by subscribing to the robot's odometry\
    \ topic (`/odom`?) and then take the robot's pose and republish them as a path.\
    \ Here's a simple script that should be a decent starting point for you.\n\n \
    \   #!/usr/bin/env python\n    import rospy\n    \n    from nav_msgs.msg import\
    \ Path\n    from nav_msgs.msg import Odometry\n    from geometry_msgs.msg import\
    \ PoseStamped\n    \n    path = Path()\n    \n    def odom_cb(data):\n       \
    \ global path\n        path.header = data.header\n        pose = PoseStamped()\n\
    \        pose.header = data.header\n        pose.pose = data.pose.pose\n     \
    \   path.poses.append(pose)\n        path_pub.publish(path)\n\n    rospy.init_node('path_node')\n\
    \    \n    odom_sub = rospy.Subscriber('/odom', Odometry, odom_cb)\n    path_pub\
    \ = rospy.Publisher('/path', Path, queue_size=10)\n    \n    if __name__ == '__main__':\n\
    \        rospy.spin()"
