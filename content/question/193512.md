    \ to B=>A_new. I used it to make markers, which appear as children of the camera,\
    \ a parent of the camera.\n\nJust change the values.\n\nCheers,\n\nRabe\n\n  \
    \  #!/usr/bin/env python\n    \n    import rospy\n    import tf\n    \n    if\
    \ __name__ == '__main__':\n        rospy.init_node(\"transform_inverter\")\n \
    \       rospy.sleep(0.5)\n    \n        child_frame = rospy.get_param(\"~child_frame\"\
    )\n        parent_frame = rospy.get_param(\"~parent_frame\")\n        new_parent_name\
    \ = rospy.get_param(\"~new_parent_frame\")\n    \n        listener = tf.TransformListener()\n\
    \        broadcaster = tf.TransformBroadcaster()\n        rate = rospy.Rate(100)\n\
    \    \n        while not rospy.is_shutdown():\n            try:\n            \
    \    listener.waitForTransform(parent_frame, child_frame, rospy.Time.now(), rospy.Duration(2.0))\n\
    \                (trans, rot) = listener.lookupTransform(child_frame, parent_frame,\
    \ rospy.Time(0))\n                broadcaster.sendTransform(trans,rot, rospy.Time.now(),\
    \ parent_frame, new_parent_name)\n            except (tf.LookupException, tf.ConnectivityException,\
    \ tf.ExtrapolationException, tf.Exception):\n                rospy.loginfo(\"\
    Couldn't find a transform\")\n                continue\n\n\n"

Due to some nomenclature difference between some packages and some simulator (especially considering tf transforms) I am looking for a nice way to change the frame_id and child_frame_id of some tf transforms and republish them directly, without having to touch the source code of any package. I thought about subscribing to /tf and then checking frame_id of each incoming transform. If it is the frame_id i need then create a new transform with the same translation and rotation data but with different frames and broadcast it.
For example I have a transform being published by STDR (new 2d simulator) 

> map_static-> robot0

I want to rebroadcast it to

> odom->base_footprint

Is there something already implemented in ROS to do this?
