    @Philip is right. The publisher need some time to connect to the subscribers. Your finite loop is just to short for that. I'm not sure what you expect from you condition case in the infinite loop as that is never true.

  body_markdown: "Hi, I just want to add a more explicit code on how to use `pub.getNumSubscribers()`\
    \ answered by [@dornhege](https://answers.ros.org/users/122/dornhege/).\n\nIf\
    \ you want to publish a message, you have to make sure the connection between\
    \ subscriber and publisher is already established. This can be done by:\n\n  \
    \  ros::Publisher chatter_pub = n.advertise<std_msgs::Empty>(\"toggle_led\", 1000)\n\
    \    while (publisher.getNumSubscribers() < 1) {\n        ros::WallDuration sleep_t(0.5);\
    \    \n        sleep_t.sleep();\n    }\n    // After connection are guaranteed\
    \ to be established, we can publish messages now.\n    std_msgs::Empty msg;\n\
    \    chatter_pub.publish(msg);\n    chatter_pub.publish(msg); // Can even publish\
    \ multiple times\n\n\nIf using while-loop,  you probably do not have to worry\
    \ about this problem. Because the connection is likely to be guaranteed.\n\n"
