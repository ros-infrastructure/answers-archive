  body_markdown: "Your settings are loaded from a default configuration which is indicated\
    \ by the message \"Loading from pre-hydro parameter style\". That means that `move_base`\
    \ cannot find any plugins settings for your local or global costmap.\n\nPlugins\
    \ are loaded from the YAML files. Here's for example my YAML file for my local\
    \ costmap configuration: \n\n    local_costmap:\n      global_frame: '/map'\n\
    \      robot_base_frame: 'base_link'\n      update_frequency: 1\n      publish_frequency:\
    \ 1\n      static_map: false\n      rolling_window: false\n      width: 3\n  \
    \    height: 3\n      resolution: 0.01\n      plugins:\n       -\n         name:\
    \ footprint\n         type: \"costmap_2d::FootprintLayer\"\n       - \n      \
    \   name: obstacles\n         type: \"costmap_2d::ObstacleLayer\"\n       - \n\
    \         name: inflater\n         type: \"costmap_2d::InflationLayer\"\n\nYou\
    \ have to place the `plugins` parameter (a yaml list) inside the corresponding\
    \ namespace (local_costmap in this case). That's the important part. \n\nIn your\
    \ particular case a new entry to the `plugins` list might look like that:\n\n\
    \       - \n         name: yourlayer\n         type: \"your_layer_namespace::YourLayerClassName\"\
    \n\n"
