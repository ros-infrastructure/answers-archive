  body_markdown: "Hi, <br/><br/>\nOn Windows 10, you can source your local workspace\
    \ setup by calling `devel\\setup.bat`.\n\nTo check if your local workspace is\
    \ properly overlayed on top of your environment, run\n\n    echo %ROS_PACKAGE_PATH%\n\
    \nyou should see something like this\n\n    C:/local_workspace/src;C:\\opt\\ros\\\
    melodic\\x64\\share\n\nYou should set `ROS_MASTER_URI ` as an environment variable\
    \ on Windows 10. You either set it by using a GUI: open *Advanced system settings*,\
    \ click the button *Environment Variables*, and add new *System variables* (different\
    \ approaches to open the GUI can be found [here](https://superuser.com/questions/949560/how-do-i-set-system-environment-variables-in-windows-10)),\
    \ or set it by using the [setx](https://docs.microsoft.com/en-us/windows-server/administration/windows-commands/setx)\
    \ command. So if you want to permanently set `ROS_MASTER_URI`, the command would\
    \ be like:\n\n    setx ROS_MASTER_URI \u201Chttp://<ip>:11311/\u201D /m"
