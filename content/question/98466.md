  body_markdown: "On the one hand it is sad that I have to answer my own question\
    \ ( could no body help me for such long time? :_( ) on the other hand it is nice\
    \ to see that I have learnt something in ROS! ;-)\n\nThe direct answer to the\
    \ question is:\n**clone the repository on your personal ROS workspace**\n\nYou\
    \ should have one already created (this personal workspace is also called **overlay**).\
    \ If you followed the ROS [installation instructions of configuring a new environment](http://wiki.ros.org/ROS/Tutorials/InstallingandConfiguringROSEnvironment),\
    \ *Create a ROS workspace*, you should have already one personal workspace where\
    \ to install the packages.\n\nIn my case it is `/work/<user>/ros_fuerte_workspace`.\
    \ \n\nAnd what you should actually do in your workspace is just **install rqt\
    \ as a new package**. (There is a general answer about installing a package [here](http://answers.ros.org/question/10581/installing-ros-packages-from-source/)\
    \ ) I will give you the particular installation method using a rosinstall file.\
    \ Therefore I will provide you as well with the *rosinstall* file `rqt.rosinstall`\
    \ that you must execute **in your personal workspace** with the following command\n\
    \n(there is an important *dot* in the middle of the expression!)\n\n    rosinstall\
    \ . rqt.rosinstall\n\nThat is the code that I you should write in the file *rqt.rosinstall*\n\
    \n    #installing rqt\n    #Two stacks needed 'qt_gui_core' and 'rqt'\n    #see\
    \ http://wiki.ros.org/rqt/UserGuide/Install/Groovy last Headline \"Installing\
    \ on Fuerte\"\n    \n    - git: {local-name: qt_gui_core, uri:  'https://github.com/ros-visualization/qt_gui_core.git',\
    \ version: fuerte-devel}\n    \n    - git: {local-name: rqt, uri: 'https://github.com/ros-visualization/rqt.git',\
    \ version: fuerte-devel}\n\nThe # lines are comments, you may leave them out (but\
    \ I would keep them comments are good ;-))\n\nOn executing *rosinstall* on this\
    \ file the subfolders `rqt`  and `qt_gui_core` are created. Now you just gotta\
    \ build them! (Go inside each of them and run rosmake)\n\n    rosmake\n\n**READY!!**\
    \ now you can use *rqt* on fuerte by writing:\n\n    rosrun rqt_gui rqt_gui\n\n\
    Hallelujah! :-)\n\n "
