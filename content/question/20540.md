  body_markdown: "There are several things about Gazebo on that paper which are not\
    \ true. And a few others which may have been true several years ago, but are no\
    \ longer the case for the latest version, Gazebo 9. Since the paper doesn't mention\
    \ the version used, I'll answer based on Gazebo 9:\n\n**Freezing UI**: True, there\
    \ are occasions in which the UI is known to freeze. The number of times and the\
    \ specific situations in which it happens vastly vary according to version though.\
    \ On Gazebo 9, crashing / freezing will rarely happen during basic usage.\n\n\
    **Toolbar disappearing**: False, I've never seen this happening, but I may be\
    \ misinterpreting what it means.\n\n**Copy paste multiple objects**: True, this\
    \ is not possible.\n\n**Save scene into same file**: False, you can choose any\
    \ file when saving, even an existing one. Also, after saving the first time, just\
    \ hitting `Ctrl+S` will update the file.\n\n**Model library**: True, the library\
    \ is available online and requires an internet connection. And true, there are\
    \ times when the database is down. Users can always download the whole model database\
    \ at once by cloning https://bitbucket.org/osrf/gazebo_models/ if they don't want\
    \ to download models at runtime. But yeah, no, we don't distribute a CD ;)\n\n\
    **Model types in library**: True, models are just listed alphabetically on the\
    \ UI. We're working on improving this, check out https://ignitionfuel.org/.\n\n\
    Some other points which are mistaken:\n\n* Only DART requires a source install.\
    \ ODE, Bullet and Simbody don't. \n* Gazebo does not have a code editor.\n* The\
    \ world does return to its original state if the simulation is reset.\n* Gazebo\
    \ does output custom videos and plots.\n* Model plugins are listed on the main\
    \ window, not only on the model editor."
