  body_markdown: "Dont use that code, you have to migrate it to catkin. It has a few\
    \ steps, from \n\nhttp://wiki.ros.org/catkin/migrating_from_rosbuild\n\n> dynamic_reconfigure\n\
    >\n>For each .cfg file:\n>\n>Remove \"import roslib;roslib.load_manifest(PACKAGE)\"\
    .\n>Change \"from dynamic_reconfigure.parameter_generator import *\" to \"from\
    \ dynamic_reconfigure.parameter_generator_catkin import *\"\n>In CMakeLists.txt,\
    \ add the following before the call to catkin_package():\n>\n>generate_dynamic_reconfigure_options(cfg/DynFile1.cfg\
    \ cfg/DynFile2.cfg ...)\n\n># make sure configure headers are built before any\
    \ node using them\n>add_dependencies(example_node ${${PROJECT_NAME}_EXPORTED_TARGETS})\n\
    >For more details see: the catkin dynamic reconfigure how-to and dynamic_reconfigure\
    \ >tutorial"
