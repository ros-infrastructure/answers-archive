  body_markdown: "I have faced similar issues recently.Try removing libserial using\
    \ apt, then install the current library using the instructions\n\n Remove with\
    \ apt using \n\n    sudo apt remove libserial-dev\n\nNow install libserial using\
    \ the following steps (with sudo permissions)\n\n            mkdir serial_dir\n\
    \            cd serial_dir/ && git clone https://github.com/crayzeewulf/libserial.git\n\
    \            cd serial_dir && cd libserial && ./compile.sh\n            cd serial_dir\
    \ && cd libserial && cd build && make install \n\nNow you should be able to find\
    \ *libserial* under */usr/local/include*\n\nIn the CMakelist.txt\n\n    target_link_libraries(executableName\n\
    \      ${catkin_LIBRARIES} serial\n    )\n\nIn package.xml\n\n      <depend>libserial-dev</depend>\n\
    \n\n\nNow,try building the package and it should work..!!\n"
