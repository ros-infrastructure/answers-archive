  body_markdown: "Hi,\n\nThe camera works with the package, but you need to add a\
    \ few workarounds to the code.\n\nFirst, you need to change the code so that it\
    \ does not reject the camera. In the file pylon_camera.cpp add the following line\
    \ between line 79 and 80:\n \n<code>\nelse if ( model_name.compare(0, 3, \"puA\"\
    ) == 0 )\n                {\n                    return DART;\n              \
    \  }\n</code>\n\nThis way the code recognizes the pulse as a basler dart camera.\
    \ After compiling, you will still get an error because the code tries to access\
    \ a camera feature which is present on the dart and ace cameras but not on the\
    \ pulse. Comment the line 297 in file pylon_camera_base.hpp:\n\n<code>\n//user_output_selector_enums_\
    \ = detectAndCountNumUserOutputs();\n</code> \n\nCompile the code. Now it should\
    \ work with the camera. So far I had not any error with this workaround.\n\nI\
    \ am sure there are better solutions. But this one is quick and dirty."
