    \    \n        client = actionlib.SimpleActionClient(ns + '/move_base', MoveBaseAction)\n\
    \        client.wait_for_server()\n\nand then when you call the function,\n\n\
    \    movebase_client('Bot1', 4.0, 4.0)\n\n\n\nThis, however, does not allow me\
    \ to change the values in the launch file. For this, I had to use the param server.\n\
    In the python file, I wrote this:\n\n    x = rospy.get_param('~x_position')\n\
    \    y = rospy.get_param('~y_position')\n    \n    client = actionlib.SimpleActionClient('move_base',\
    \ MoveBaseAction)\n    client.wait_for_server()\n\n\nand then in the launch file\
    \ I could then change the values doing this:\n\n      <node pkg=\"okg\" name=\"\
    name\" type=\"name.py\" output=\"screen\">\n          <remap from=\"move_base\"\
    \       to=\"Bot1/move_base\"/>\n          <param name=\"~x_position\"      type=\"\
    double\"      value=\"2.0\"/>\n          <param name=\"~y_position\"      type=\"\
    double\"      value=\"2.0\"/>\n      </node>\n\n\n\nThanks, osilva and Geoff."
