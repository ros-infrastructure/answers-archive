  body_markdown: "You could wrap your launch files/nodes in a bash script, and make\
    \ use of a bash `trap`, which allows you to run code when ctrl+c is received.\
    \ \n\n    #!/bin/bash\n\n    on_interrupt ()\n    {\n        kill -INT $1 # Kills\
    \ the first thing you started\n        wait # for this process to end\n      \
    \  rosrun mypkg NewNode # subsequent ctrl+c will end this and the script\n   \
    \ }\n\n    roslaunch mypkg myapp.launch &\n    trap \"on_interrupt $!\" INT SIGINT\n\
    \    \n    wait\n\nThis script tells bash to run `on_interrupt` when ctrl+c is\
    \ received, passing the process ID of `roslaunch ... ` as an argument. `on_interrupt`\
    \ ends this process and runs whatever else you want to run. Hit ctrl+c again to\
    \ end.\n"
