  body_markdown: "I believe that you can find the source code as part of the *-release\
    \ repositories.\n\nFor instance, if you wanted the source code for the 1.9.30\
    \ release of Rviz in Hydro for Quantal, you can go to Github:\n\nhttps://github.com/ros-gbp/rviz-release/tree/debian/ros-hydro-rviz_1.9.30-0_quantal\n\
    \nBloom automates the creation of the specific branches and tags for the released\
    \ versions.  This is the source that the buildfarm then uses to generate the debs.\n\
    \nThe release repositories will be listed in the [`rosdistro` repository](https://github.com/ros/rosdistro/blob/master/hydro/release.yaml)\n\
    \nEdit: Forgot to mention that Github allows for downloading tarballs of git tags,\
    \ such as: \n\n`https://github.com/ros-gbp/rviz-release/archive/debian/ros-hydro-rviz_1.9.30-0_quantal.tar.gz`"
