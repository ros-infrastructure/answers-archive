  body_markdown: "Hi, \nGazebo publishes the pose and the twist of every link on /gazebo/link_states\
    \ topic.<br>\nYou should be able to plot the velocity of a given link using this\
    \ message.\n\nTo know the index of the link you want to monitor you can check\
    \ its index in the list /gazebo/link_states/name<br>\nThen you can plot /gazebo/link_states/twist[INDEX_YOU_FOUND].<br>\n\
    \nI don't know how often this message is published but it should allow you to\
    \ monitor your twist and thus know how long it takes to reach the desired velocity.\n\
    \nHope this helps,"
