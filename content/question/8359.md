  body_markdown: "I think the problem is not CMakeLists.txt cannot find out the header\
    \ file, because if it cannot find it, it will give an error like \"cannot find\
    \ header file XXXXXX\". Instead, the problem is gazebo cannot find the library\
    \ file libmodel_push.so. So you should find out where libmodel_push.so is and\
    \ export this path to env GAZEBO_PLUGIN_PATH like this:\n\n    $ export GAZEBO_PLUGIN_PATH=$GAZEBO_PLUGIN_PATH:{your\
    \ libmodel_push.so path}\nyou should replace {your libmodel_push.so path} with\
    \ the actual path. \n\nAnother tip: if you have installed gazebo_ros package,\
    \ you don't have to specify this plugin path, the library file will be automatically\
    \ put in {workspace}/devel/lib folder when you \"catkin\\_make\" your workspace.\
    \ And then gazebo_ros will find it. But remember you should run \n\n    rosrun\
    \ gazebo_ros gazebo YOUR_WORLD_FILE\n"
