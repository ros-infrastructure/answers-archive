  body_markdown: "You cannot have 2 or more nodes with the same name.  So you need\
    \ to change the name of one of your rosserial nodes, eg:\n\n    rosrun rosserial_python\
    \ serial_node.py __name:=\"node2\" ... etc\n\nNote the double underscore preceding\
    \ name.\n\nOr, as suggested, using a launch file:\n\n    <launch>\n    <!-- Launch\
    \ 2 Arduino boards -->\n    \n        <node\n    \t    pkg=\"rosserial_python\"\
    \n    \t    type=\"serial_node.py\"\n    \t    name=\"ArduinoOne\"\n    \t   \
    \ args=\"/dev/ttyACM0\"\n        ></node>\n\n        <node\n    \t    pkg=\"rosserial_python\"\
    \n    \t    type=\"serial_node.py\"\n    \t    name=\"ArduinoTwo\"\n    \t   \
    \ args=\"/dev/ttyACM1\"\n        ></node>\n    </launch>\n\nThe above requires\
    \ the Arduino boards to be /dev/ttyACM0 and /dev/ttyACM1.  This can be avoided\
    \ by using [udev rules](https://clearpathrobotics.com/blog/2015/01/udev/) to give\
    \ each board a unique symbolic name, eg:\n\n    <launch>\n    <!-- Launch the\
    \ Arduino Board with Adafruit 9-DOF IMU -->\n    \n    <node\n    \tpkg=\"rosserial_python\"\
    \n    \ttype=\"serial_node.py\"\n    \tname=\"arduino_imu_9dof\"\n    \targs=\"\
    /dev/elegooOne\"\n    \trespawn=\"true\"\n    ></node>\n        \n    </launch>\n\
    \nSo above we've given the Arduino board the symbolic name elegooOne.  Larger\
    \ Arduino boards, eg Uno, Mega, have a unique serial number that's good for udev\
    \ rules."
