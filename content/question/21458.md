  body_markdown: "Do you want to split them in the model level, or an even lower level,\
    \ like links?\n\nIf you want to split by models, you can put each model in a directory,\
    \ then include them all into the same world SDF using the `<include>` tag. You\
    \ can use the same idea to nest models into each other.\n\nIf you want a more\
    \ granular split, you won't be able to do it without using another script language,\
    \ since SDF doensn't support [top-level](http://sdformat.org/spec) tags besides\
    \ `<world>`, `<model>`, `<light>` and `<actor>`.\n\n---\n\nPersonally, I like\
    \ using ERB (`sudo apt install ruby2.3 ruby2.3-dev` or the latest available version):\n\
    \n`model.erb`:\n\n    <%\n      # Relative path from where the script is being\
    \ run to the script's directory\n      DIR = File.dirname(__FILE__)\n    \n  \
    \    # Helper function to import another erb file\n      def fromFile filename\n\
    \        return ERB.new(File.read(filename), nil, nil, '_sub01').result(binding)\n\
    \      end\n    %>\n    \n    <model name=\"model_name\">\n        <%= fromFile(DIR\
    \ + \"/link1.erb\") %>\n        <%= fromFile(DIR + \"/link2.erb\") %>\n      \
    \  <%= fromFile(DIR + \"/link3.erb\") %>\n    </model>\n\n`link1.erb`\n\n    <link\
    \ name=\"link1\">\n     ...\n    </link>\n\nThen run `erb model.erb > model.sdf`."
