    \ write your subscriber you need to import the msg \nhttp://docs.ros.org/api/sensor_msgs/html/msg/LaserScan.html\n\
    eg\n\n> from sensor_msgs.msg import LaserScan\n\nOnce your callback function is\
    \ triggered you will get back a struct that is defined by the .msg file \n\nyou\
    \ can also use the rosmsg XXX command to figure out the types of msgs packages\
