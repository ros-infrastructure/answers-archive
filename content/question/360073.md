  - body_markdown: "> it's necessary to create a directory to store the bag files\n\
      \nNot really, when you record a bag file it will be stored at the same location\
      \ as you were when doing `rosbag record`, the tutorial tells you to create the\
      \ folder bagfile and then go to this new directory to have your bagfile at this\
      \ location. If you are not in the folder `bagfiles` when issuing `rosbag record`,\
      \ it won't be stored there.\n\nYou can use the argument `-o` to add a prefix\
      \ to the bagfile name, if you specify an absolute path from then you can choose\
      \ the location : \n\n    rosbag record -a -o $HOME/bagfiles/\n\nThis command\
      \ will save your bagfile in your `~/bagfiles` folder regardless of which directory\
      \ you are currently in."
