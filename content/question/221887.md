  body_markdown: "You need to write your own packages as follows:\n\n1- TF tree publisher:\
    \ http://wiki.ros.org/navigation/Tutorials/RobotSetup/TF\n\n2- Odometry publisher:\
    \ http://wiki.ros.org/navigation/Tutorials/RobotSetup/Odom\n\n3- There must be\
    \ a node subscribing to the \"cmd_vel\" topic that is capable of taking (vx, vy,\
    \ vtheta) <==> (cmd_vel.linear.x, cmd_vel.linear.y, cmd_vel.angular.z). To do\
    \ this you create a subscriber with a call back like follows:\n\nsubscriber: \n\
    \n    ros::Subscriber sub = n.subscribe(\"cmd_vel\", 1, movecallback);\nAnd the\
    \ call back would be:\n\n    void movecallback(const geometry_msgs::Twist::ConstPtr&\
    \ vel)\n    {\n      //ROS_INFO(\"I heard: [%s]\", msg->data.c_str());\n     \
    \ geometry_msgs::Twist new_vel = *vel;\n      float v = sqrt (new_vel.linear.x\
    \ * new_vel.linear.x + new_vel.linear.y * new_vel.linear.y);\n      float vth\
    \ = new_vel.angular.z;\n      // here you need to send v and vth as linear and\
    \ angular velocities to your robot\n      }\n\nFor the rest you need to setup\
    \ launch files as described here:  http://wiki.ros.org/navigation/Tutorials/RobotSetup.\n\
    You need to also install gmapping to be able to create a map, navigation stack\
    \ do not work without a map unless you change its default to do slam.\n\nHope\
    \ it helps\nMohsen\n"
