  body_markdown: "I have had this issue with setting up GTests in ROS before.\n\n\
    You need to properly initialize the logger and set the logger level in ROS\n\n\
    To initialise the logger either\n\n    ros::init(argc, argv, \"node_name\");\n\
    \nor\n\n    ROSCONSOLE_AUTOINIT;\n\nTo set the logger level either\n\n    ros::start();\n\
    \nor\n\n    if(ros::console::set_logger_level(ROSCONSOLE_DEFAULT_NAME, ros::console::levels::Debug))\n\
    \    {\n        ros::console::notifyLoggerLevelsChanged();\n    }\n\nOf course\
    \ you can just use rosconsole directly\n\n    #include <ros/console.h>\n    #include\
    \ <log4cxx/logger.h>\n    \n    int main(int argc, char* argv[])\n    {\n    \
    \    ROSCONSOLE_AUTOINIT;\n        log4cxx::LoggerPtr my_logger = log4cxx::Logger::getLogger(ROSCONSOLE_DEFAULT_NAME);\n\
    \        my_logger->setLevel(ros::console::g_level_lookup[ros::console::levels::Debug]);\n\
    \        ROS_INFO(\"test logger);\n        exit 0;\n    }\n\n\n\n"
