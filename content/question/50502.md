Is it possible to have two different nodes with an dynamic_reconfigure::Server<T> sharing the same "resource name" in the rosgraph context?
This would be interesting to share configurations between different nodes. If someone send a config update request, then both nodes would be configured simultaneusly. 

<pre>
Node1.cpp for process 1:
---
dynamic_reconfigure::Server<MyConfigType> server1(ros::NodeHandle("/shared/name"));
server1.setCallback(myP1Callback);
...

Node2.cpp for process 2:
---
dynamic_reconfigure::Server<MyConfigType> server2(ros::NodeHandle("/shared/name"));
server2.setCallback(myP2Callback);
...
