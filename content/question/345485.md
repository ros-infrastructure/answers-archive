Hello,

I'm currently working on an autonomous robot for a contest. For it I need to pick up some cups with a gripper. This gripper is at a fixed position and robot_state_publisher is sending the static transformation of it.

The problem is : I need to move the base in order to have my gripper on the position of the cup and with a certain incidence angle to grab it.!

[Picture](https://i.snipboard.io/t4aejD.jpg)

I think I can do this with the TF package but I'm still quite new in the world of ROS and I'm not sure to understand everything.

Thanks for your time :)

**EDIT :** 

I solve the problem by adding the direction vector (from center of robot to point in question) with the vector *gripper --> center of robot*. The last one is obtain with a `Transformer::lookupTransform` and then rotating the return vector to match my incidence angle.

It's savage but it works. Maybe there is a cleaner solution ?
