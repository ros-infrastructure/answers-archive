  body_markdown: "I got the same issue ... before this error, on warnings the compiler\
    \ said something about \"Target \"gtest\" has EXCLUDE_FROM_ALL\" and I thought\
    \ that someone is telling to exclude and the error said this lib may be included!!\n\
    \nSo for a rapid test I got into the \n\n    cd ~/ros_catkin_ws/src/catkin/cmake/test\n\
    \nand edited the gtest.cmake\n\n    sudo nano gtest.cmake\n\nCommenting this line\
    \ (#) to avoid the exclusion of this files:\n\n    if(ARG_EXCLUDE_FROM_ALL)\n\
    \        #set_target_properties(${target} PROPERTIES EXCLUDE_FROM_ALL TRUE)\n\
    \    endif()\n\nand comment too \n\n    #set_target_properties(gtest gtest_main\
    \ PROPERTIES EXCLUDE_FROM_ALL 1)\n\nSave the file and try again\n\nAfter that,\
    \ the compiler compile the gtest and worked fine\n\nIts not a definitive solution,\
    \ but works well, it helps!!\n\nAnother aproach is to remove the gtest compile,\
    \ but not tested it yet\n\nThanks\n\n(PS: in this tutorial they remove the ros_lisp\
    \ (--exclude roslisp) because the \"dependency sbcl is not available in the Raspbian\"\
