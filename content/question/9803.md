  body_markdown: "You might want to convert the sensor_msgs/Image datatype to an OpenCV\
    \ image. The cv_bridge tutorial for Python shows how to do so: http://www.ros.org/wiki/cv_bridge/Tutorials/ConvertingBetweenROSImagesAndOpenCVImagesPython\n\
    \nThe below code is an example from our SVN ( http://code.google.com/p/albany-ros-pkg\
    \ ) that captures an image, blurs it, and displays it: \n\n    #!/usr/bin/env\
    \ python\n    \"\"\" \n      Example code of how to convert ROS images to OpenCV's\
    \ cv::Mat\n      This is the solution to HW2, using Python.\n \n      See also\
    \ cv_bridge tutorials: \n        http://www.ros.org/wiki/cv_bridge\n    \"\"\"\
    \n    \n    import roslib; roslib.load_manifest('ex_vision')\n    import rospy\n\
    \    \n    import cv\n    from cv_bridge import CvBridge, CvBridgeError\n    \n\
    \    from std_msgs.msg import String\n    from sensor_msgs.msg import Image\n\
    \    \n    class image_blur:\n    \n      def __init__(self):\n        # initialize\
    \ a node called hw2\n        rospy.init_node(\"hw2\")\n        \n        # create\
    \ a window to display results in\n        cv.NamedWindow(\"image_view\", 1)\n\
    \    \n        # part 2.1 of hw2 -- subscribe to a topic called image\n      \
    \  self.image_sub = rospy.Subscriber(\"image\", Image, self.callback)\n    \n\
    \      def callback(self,data):\n        \"\"\" This is a callback which recieves\
    \ images and processes them. \"\"\"\n        # convert image into openCV format\n\
    \        bridge = CvBridge()\n        try:\n          # bgr8 is the pixel encoding\
    \ -- 8 bits per color, organized as blue/green/red\n          cv_image = bridge.imgmsg_to_cv(data,\
    \ \"bgr8\")\n        except CvBridgeError, e:\n          # all print statements\
    \ should use a rospy.log_ form, don't print!\n          rospy.loginfo(\"Conversion\
    \ failed\")\n    \n        # we could do anything we want with the image here\n\
    \        # for now, we'll blur using a median blur\n        cv.Smooth(cv_image,\
    \ cv_image, smoothtype=cv.CV_MEDIAN, param1=31, param2=0, param3=0, param4=0)\n\
    \    \n        # show the image\n        cv.ShowImage(\"image_view\", cv_image)\n\
    \        cv.WaitKey(3)\n    \n    \n    if __name__ == '__main__':\n        image_blur()\n\
    \        try:  \n            rospy.spin()\n        except KeyboardInterrupt:\n\
    \            print \"Shutting down\"\n        cv.DestroyAllWindows()\n\n"
