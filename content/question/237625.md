Hi,

I have a set of self-defined rosdep rules which have been working nice until now. I need to install a package through easy_install, therefore my rosdep rule is:

     python-pkg:
       ubuntu:
         easy_install:
           packages: [my_pkg]

But this does not work:

    $ rosdep update
    $ rosdep resolve python-pkg
    #apt
    <empty_line>

I tried different combinations, such adding trusty, etc, but still rosdep is not able to find it.

Any suggestion? Thanks!


Edit: If I use pip for instance it shows the rosdep resolve as expected, but not for easy_install. I am assuming there is support as it is said [here](http://docs.ros.org/independent/api/rosdep/html/rosdep_yaml_format.html)
