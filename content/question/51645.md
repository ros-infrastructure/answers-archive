  body_markdown: "You will have to create your own node that subscribes to the map\
    \ (OccupancyGrid) from the map_server, on topic /map. Once you have that you can\
    \ find out which cells in the map are occupied. "

  - body_markdown: |-
      The [hector_map_server](http://ros.org/wiki/hector_map_server) package from the hector_slam stack contains a node, that advertises a service to retrieve the distance to the nearest obstacle, given a source frame_id and point to specify the direction. You can use it directly or take it as an example.
