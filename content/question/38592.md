  body_markdown: "try running ls -l /dev/video0 which should produce this:\n\n   \
    \ crw-rw---- 1 root video 81, 0 Jul 20 19:26 /dev/video0 \n\nif the first part\
    \ of the message looks this:\n\n    crw-rw----\n\nlike the above then you don't\
    \ have the correct permissions so type this:\n \n    sudo chmod a+rw /dev/video0\n\
    \nthe final message should look like this:\n\n    crw-rw-rw- 1 root video 81,\
    \ 0 Jul 20 19:26 /dev/video0\n\n"
