  body_markdown: "I was able to update my Turtlebot 2 (with Create 2 Base) to a 360\
    \ degree YDLidar to use for navigation.\n\nI made a copy of the minimal.launch\
    \ file in turtlebot launch folder, and renamed it. I added this to it:\n\n   \
    \ <node name=\"ydlidar_node\"  pkg=\"ydlidar\"  type=\"ydlidar_node\" output=\"\
    screen\">\n    <param name=\"port\"         type=\"string\" value=\"/dev/ydlidar\"\
    />\n    <param name=\"baudrate\"     type=\"int\"    value=\"115200\"/>\n    <param\
    \ name=\"frame_id\"     type=\"string\" value=\"laser_frame\"/>\n    <param name=\"\
    angle_fixed\"  type=\"bool\"   value=\"true\"/>\n    <param name=\"low_exposure\"\
    \  type=\"bool\"   value=\"false\"/>\n    <param name=\"heartbeat\"    type=\"\
    bool\"   value=\"false\"/>\n    <param name=\"resolution_fixed\"    type=\"bool\"\
    \   value=\"true\"/>\n    <param name=\"angle_min\"    type=\"double\" value=\"\
    -180\" />\n    <param name=\"angle_max\"    type=\"double\" value=\"180\" />\n\
    \    <param name=\"range_min\"    type=\"double\" value=\"0.08\" />\n    <param\
    \ name=\"range_max\"    type=\"double\" value=\"16.0\" />\n    <param name=\"\
    ignore_array\" type=\"string\" value=\"\" />\n    <param name=\"samp_rate\"  \
    \  type=\"int\"    value=\"9\"/>\n    <param name=\"frequency\"    type=\"double\"\
    \ value=\"7\"/>\n    </node>  \n\n    <node pkg=\"tf\" type=\"static_transform_publisher\"\
    \ name=\"base_link_to_laser4\"\n    args=\"0.0 0.0 0.2 0.0 0.0 0.0 /base_footprint\
    \ /laser_frame 40\" />\n\n\nI also added the ros-compatible ydlidar library to\
    \ the src folder. \n\nAfter a few tries I got it to work and could then map a\
    \ room very quickly with 360 degree view instead of the limited range of the kinect.\n\
    \nIf I recall, I used links like these to help me:\n\n- https://answers.ros.org/question/173122/how-to-crate-a-map-with-gmapping-and-hokuyo-laser/\n\
