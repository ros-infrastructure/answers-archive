  body_markdown: "> In tutorial it is suggested that to order some part number to\
    \ work with DX100 CONTROLLER: [..] What is use of this part number?\n\nIt's not\
    \ actually suggested, it's a requirement.\n\nFrom [motoman_driver: Requirements](http://wiki.ros.org/motoman_driver#Requirements):\n\
    \n> However, for DX100 controllers, a specific software option must be explicitly\
    \ ordered from Motoman in order to enable ROS-Industrial integration (see the\
    \ [MotoPlus Runtime License](http://wiki.ros.org/motoman_driver#MotoPlus_Runtime_License)\
    \ section below). \n\nThe *MotoPlus Runtime License* section then shows this:\n\
    \n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/1550658310143895.png)\n\
    \nThe license enables the controller to *run* a MotoPlus application, with MotoPlus\
    \ being the SDK in which MotoROS is written.\n\n> Is it sufficient if I only load\
    \ MotoROS binary in controller? \n\nNo -- as I hope is clear now -- as that would\
    \ not allow you to actually run it.\n\nFor that you'd need the license as well.\n"
