  body_markdown: "I'm not sure, how move_base handles the /move_base_simple/goal,\
    \ but if it is an action, you could try sending a fully empty GoalID message to\
    \ move_base/cancel. \nAccording to [actionlib/DetailedDescription](http://www.ros.org/wiki/actionlib/DetailedDescription)\
    \ this should cancel all goals.\n\nThe command thus should be fairly simple:\n\
    \n    rostopic pub /move_base/cancel actionlib_msgs/GoalID -- {}"
