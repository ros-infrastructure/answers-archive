    SUKF stands for Standard Uncsented Kalman Filter, which uses only one motion model.
    This is a basic implementation of UKF.

    On the other hand, IMMUKF assumes three motion models.

    Regarding IMMUKF, please check this [paper](https://repository.tudelft.nl/islandora/object/uuid%3Af536b829-42ae-41d5-968d-13bbaa4ec736).
