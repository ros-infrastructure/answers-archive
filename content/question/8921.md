    Hi,

    you can use the [`<collide_bitmask>`](http://sdformat.org/spec?ver=1.5&elem=collision#contact_collide_bitmask) tag in the `collision`.

    Here is the [tutorial](http://gazebosim.org/tutorials?tut=collide_bitmask&cat=physics).

    However you need the latest gazebo (v.6) in order to work. Meaning you need to install from source using the default branch for now.
