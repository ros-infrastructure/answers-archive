  body_markdown: "There is Rviz plugin called [Rviz Texture Quads](https://github.com/MohitShridhar/rviz_textured_quads)\
    \ that allows you to display textured images (realtime or static sensor_msgs/Image\
    \ topics) as a marker in 3D space. In addition there is a cool demo by: https://github.com/lucasw/rviz_textured_quads/tree/image_topic\
    \ that shows how to use it.\n\nAs mentioned in my comments, I found this info\
    \ from prior question #q322457 so I hate to take any credit.\n\nHowever, I'd like\
    \ to add more info to this answer. The message is structured as follows:\n\n \
    \   sensor_msgs/Image \timage  \t\t\t# texture \n    geometry_msgs/Pose \tpose\
    \   \t\t\t# 6DOF pose of the center of the quad to be displayed\n    float32 \t\
    \t\twidth\t\t    # physical width of the quad in Rviz unit (usually meters) \n\
    \    float32 \t\t\theight\t\t\t# physical height of the quad in Rviz unit (usually\
    \ meters) \n    string \t\t\t\tcaption\t\t    # [OPTIONAL] text description to\
    \ appear below the quad\n    float32 \t\t\tborder_size     # [OPTIONAL] size of\
    \ the quad border\n    float32[] \t\t\tborder_color    # [OPTIONAL] (r,g,b,a)\
    \ color value of the quad border (Size = 4) \n\nAnd please review  the [source\
    \ code](https://github.com/MohitShridhar/rviz_textured_quads/blob/master/src/mesh_display_custom.cpp)\
    \ to understand how this is achieved in case someone else may want to apply similar\
    \ concept but for different application, such as AR."
