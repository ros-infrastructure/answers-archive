    Yes, as long as you know what to send to the serial port. The C++ serial library is not migrated over to ROS2 officially (last I checked), so you will have to install the colcon-enabled branch of serial manually and import it in your code (I used the ros2 branch of [this repo](https://github.com/SunnyApp-Robotics/serial.git) )

    Then wherever in your code you just use `Serial::serial controller;` and then `controller.write();` to send messages over the serial port.
