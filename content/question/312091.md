    I believe you're running into [traclabs/trac_ik#53](https://bitbucket.org/traclabs/trac_ik/issues/53), which points to [Importing URDF throws ros::TimeNotInitializedException](https://stackoverflow.com/questions/51847900) on SO.

    In the solution/work-around given, the order of statements is different from what you show (and what I would also expect to work):

        import rospy

        ...
        from trac_ik_python.trac_ik import IK

    That should not be necessary though, and would seem to point to *something* that `trac_ik` is doing that it shouldn't (or at least not at module import time).

    If this works for you, then perhaps a comment on [traclabs/trac_ik#53](https://bitbucket.org/traclabs/trac_ik/issues/53) (which was closed as `wontfix`) would be good.
