  body_markdown: "It is defined here: [Raw Message Definition](http://docs.ros.org/api/visualization_msgs/html/msg/Marker.html),\
    \ more precisely in these lines:  \n\n    #Only used if the type specified has\
    \ some use for them (eg. POINTS, LINE_STRIP, ...)\n    geometry_msgs/Point[] points\n\
    \    #Only used if the type specified has some use for them (eg. POINTS, LINE_STRIP,\
    \ ...)\n    #number of colors must either be 0 or equal to the number of points\n\
    \    #NOTE: alpha is not yet used\n    std_msgs/ColorRGBA[] colors\n\nYou are\
    \ pushing back into **points** but you are missing to push back  into **colors**\
    \ (also member of the visualization_msgs/Marker message), defined in this line:\
    \  \n\n     std_msgs/ColorRGBA[] colors\n\nThis part you already have:\n\n   \
    \    segment.points.push_back(segment_a);\n       segment.points.push_back(segment_b);\n\
    \nThis part you are still missing:\n\n      // push back one color per segment\n\
    \      segment.colors.push_back(segment_a.color); // pass in any std_msgs::ColorRGBA\
    \ object\n      segment.colors.push_back(segment_b.color);\n\n\nThe number of\
    \ colors you push back has to match the number of points (you are calling them\
    \ segments) that you push back."
