  body_markdown: "The undefined reference error suggests there is a problem with linking.\
    \ You are including the correct header but you are not linking it.\n\nIf you change\
    \ the following in your CMakeLists.txt\n\n    find_package(catkin REQUIRED COMPONENTS\n\
    \      pluginlib\n      roscpp\n      moveit_core\n    )\n\nand change the header\
    \ to include \n\n    #include <moveit/kinematics_base/kinematics_base.h>\n\nyou\
    \ should be all set. Changing the include ensures that your system will be able\
    \ to find the right header, even if the location might move (or should you use\
    \ another ros distro)."
