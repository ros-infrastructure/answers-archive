  body_markdown: "@Jan Tromp, I haven't used pickit3d, but let me suggest one way.\
    \ Are you able to run pickit3d ros package? If you did, please type `rostopic\
    \ list` and provide the output. \n\nYou should be able to see topics which publishes\
    \ message in **sensor_msgs/Image** type. When you subscribe these topics you will\
    \ be able to get raw image datas (rgb and depth). \nYou can subscribe these topics\
    \ from the terminal to check:\n\n    rostopic echo /topic_name\n\nIf you can get\
    \ raw datas, then what you can do is to create a ros node which subscribes these\
    \ topics. After subscribing these topics, you can process these images with opencv\
    \ as you wish.\n\nHere is a code sample to subscribe an image:\n\n    #include\
    \ <ros/ros.h>\n    #include <image_transport/image_transport.h>\n    #include\
    \ <opencv2/highgui/highgui.hpp>\n    #include <cv_bridge/cv_bridge.h>\n    \n\
    \    void imageCallback(const sensor_msgs::ImageConstPtr& msg)\n    {\n      try\n\
    \      {\n        cv::imshow(\"view\", cv_bridge::toCvShare(msg, \"bgr8\")->image);\n\
    \        cv::waitKey(30);\n      }\n      catch (cv_bridge::Exception& e)\n  \
    \    {\n        ROS_ERROR(\"Could not convert from '%s' to 'bgr8'.\", msg->encoding.c_str());\n\
    \      }\n    }\n    \n    int main(int argc, char **argv)\n    {\n      ros::init(argc,\
    \ argv, \"image_listener\");\n      ros::NodeHandle nh;\n      cv::namedWindow(\"\
    view\");\n      cv::startWindowThread();\n      image_transport::ImageTransport\
    \ it(nh);\n      image_transport::Subscriber sub = it.subscribe(\"camera/image\"\
    , 1, imageCallback);\n      ros::spin();\n      cv::destroyWindow(\"view\");\n\
    \    }\n\nRealize that opencv library is already added in the topic. After this\
    \ point, there is nothing related to ROS. You can process the images with opencv\
    \ by editing this code template as if you are using opencv in normal c++ mode.\
    \ \n\nRealize that you need to edit \"camera/image\" topic name in this line with\
    \ your topic name.\n\n      image_transport::Subscriber sub = it.subscribe(\"\
    camera/image\", 1, imageCallback);\n\n Don't forget to mark this comment as answer.\
    \ Good luck!\n"
