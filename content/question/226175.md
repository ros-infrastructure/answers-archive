  body_markdown: "I'm kind of a newbie myself, but I'm working on a similar problem\
    \ and it looks like what's happening here is that your robot_description includes\
    \ both robots. The first launch file calls two versions of the spawn_husky.launch\
    \ file: one for each robot. Each robot then loads a description here:\n\n    \
    \  <param name=\"robot_description\" command=\"$(find xacro)/xacro.py '$(env HUSKY_GAZEBO_DESCRIPTION)'\n\
    Where the environment variable points to the description.gazebo.xacro file. This\
    \ file then opens the controller plug-in for both robots. But since you're calling\
    \ this part of the code twice, this might be where the problems are coming from.\
    \ Just a thought though. But here's the way I've done it:\n\nIn the spawn_husky\
    \ file\n \n\n     <param name=\"robot_description\" command=\"$(find xacro)/xacro.py\
    \ '$(find husky_gazebo)/urdf/$(arg namespace)description.gazebo.xacro'\n     \
    \   laser_enabled:=$(arg laser_enabled)\n        ur5_enabled:=$(arg ur5_enabled)\n\
    \        kinect_enabled:=$(arg kinect_enabled)\n        \" />\n\nThen I have husky1description.gazebo.xacro\
    \ and husky2description.gazebo.xacro which look like this:\n\n    <robot name=\"\
    husky_robot_gazebo\" xmlns:xacro=\"http://ros.org/wiki/xacro\">\n      <xacro:arg\
    \ name=\"laser_enabled\" default=\"true\" />\n      <xacro:arg name=\"ur5_enabled\"\
    \ default=\"false\" />\n      <xacro:arg name=\"kinect_enabled\" default=\"false\"\
    \ />\n    \n      <xacro:include filename=\"$(find mtu_husky_description)/urdf/husky.urdf.xacro\"\
    \ />\n      <xacro:include filename=\"$(find mtu_husky_gazebo)/urdf/husky1.gazebo.xacro\"\
    \ />\n    \n      <!-- Gazebo plugin for ROS Control -->\n      <gazebo>\n   \
    \     <plugin name=\"gazebo_ros_control\" filename=\"libgazebo_ros_control.so\"\
    >\n          <robotNamespace>/husky1</robotNamespace>\n        </plugin>\n   \
    \   </gazebo>\n    \n      <xacro:husky_robot />\n    \n      <xacro:husky_robot_gazebo\
    \ />\n    \n    </robot>\n\nThis works for me and allows control of both robots\
    \ independently. However, I've having an issue where it's caused the \"odom\"\
    \ frame to stop being published. So let me know if anyone has been able to figure\
    \ that one out."
