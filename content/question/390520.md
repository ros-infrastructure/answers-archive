  body_markdown: "You appear to be running into problems trying to mix [wiki/UpstreamPackages](http://wiki.ros.org/UpstreamPackages)\
    \ and regular ROS packages.\n\nNote how all packages you mention don't have the\
    \ name of the ROS version you're using in them: `python-roslaunch`, `python-roslib`\
    \ and `catkin`.\n\nIn ROS Melodic, the correct package names would be: `ros-melodic-roslaunch`,\
    \ `ros-melodic-roslib` and `ros-melodic-catkin`.\n\nYou cannot mix upstream packages\
    \ with packages from a ROS release (that's not entirely true, but if you're just\
    \ starting out, I would probably heed the advice given on the wiki page and not\
    \ attempt to do so).\nSee the linked wiki page for more information about them,\
    \ and see [\u201Cupstream packages\u201D increasingly becoming a problem](https://discourse.ros.org/t/upstream-packages-increasingly-becoming-a-problem/10902)\
    \ for a recent-ish discussion.\n\nBut your initial problem was:\n\n> When i run\
    \ the command: `roslaunch turtlebot3_bringup turtlebot3_robot.launch`\n> \n> I\
    \ get the following message: Command `roslaunch` not found, but can be installed\
    \ with: `sudo apt install python-roslaunch`\n\ndid you perhaps forget to `source\
    \ /opt/ros/melodic/setup.bash` (or the equivalent for your workspace) *before*\
    \ trying to use `roslaunch`? If you don't `source` your ROS installation (or workspace),\
    \ your shell will not be able to find `roslaunch`, which on Ubuntu causes it to\
    \ suggest installing the `python-roslaunch` package."
