  body_markdown: "I know of at least two existing packages that could provide the\
    \ functionality that you want :  \n\n- [Carrot Planner](http://wiki.ros.org/carrot_planner)\n\
    - [asr_navfn](http://wiki.ros.org/asr_navfn)\n\n---\n\n\n[Carrot Planner](http://wiki.ros.org/carrot_planner)\
    \ will move your robot straight to the goal position and stop it in front of any\
    \ obstacle.\n\nI quote from their wiki page:  \n\n> The planner takes a goal point\
    \ from an\n> external user, checks if the\n> user-specified goal is in an obstacle,\n\
    > and if it is, it walks back along the\n> vector between the user-specified goal\n\
    > and the robot until a goal point that\n> is not in an obstacle is found. It\n\
    > then passes this goal point on as a\n> plan to a local planner or controller.\n\
    > In this way, the carrot planner allows\n> the robot to get as close to a\n>\
    \ user-specified goal point as possible.\n\n\n\nTo test it you just have to add\
    \ the following code to the launch file where you start move_base:\n\n    <param\
    \ name=\"base_global_planner\" value=\"carrot_planner/CarrotPlanner\" />\n\nThis\
    \ is an exemplary launch file:\n\n\n    <?xml version=\"1.0\"?>\n    <launch>\n\
    \    \n      <!-- Start move_base (nav stack) node and load config files --> \
    \   \n      <node pkg=\"move_base\" type=\"move_base\" respawn=\"false\" name=\"\
    move_base\" output=\"screen\">\n        <rosparam file=\"$(find your_pkg)/config/costmap_common_params.yaml\"\
    \ command=\"load\" ns=\"global_costmap\" />\n        <rosparam file=\"$(find your_pkg)/config/costmap_common_params.yaml\"\
    \ command=\"load\" ns=\"local_costmap\" />\n        <rosparam file=\"$(find your_pkg)/config/local_costmap_params.yaml\"\
    \ command=\"load\" />\n        <rosparam file=\"$(find your_pkg)/config/global_costmap_params.yaml\"\
    \ command=\"load\" />\n        <rosparam file=\"$(find your_pkg)/config/base_local_planner_params.yaml\"\
    \ command=\"load\" />\n      \n        <!-- Set the global planner: -->\n    \
    \    <param name=\"base_global_planner\" value=\"carrot_planner/CarrotPlanner\"\
    \ /> \n\n      </node>\n    \n    </launch>\n\n\n---\n\nThe second option I know,\
    \ the [asr_navfn package](http://wiki.ros.org/asr_navfn), is also a global planner\
    \ that can navigate your robot to the closest free space if the desired destination\
    \ is in an obstacle. The main benefit is that it is not limited to a stright line\
    \ path, as in [Carrot Planner](http://wiki.ros.org/carrot_planner).\n\nThe image\
    \ on their wiki page is pretty self-explanatory:\n\n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/16160542435441629.png)\n\
    \nHope this helps!"
