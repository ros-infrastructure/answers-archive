    (this is the same info you'd get when running `rostopic pub --help` btw)\n\nNote\
    \ how it mentions the *latch option* and how that causes `rostopic pub` to only\
    \ publish \"*the first message*\".\n\nYou have the `-l` command line option in\
    \ your `args` attribute in the `.launch` file you show:\n\n    <node pkg=\"rostopic\"\
    \ type=\"rostopic\" name=\"arbitrary_node_name\" args=\"pub topic_name msg_type\
    \ -l -f $(find package_name)/message_details.yaml\" output=\"screen\" />\n\nThat\
    \ would be the short version of `--latch`."
