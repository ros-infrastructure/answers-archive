    \ xvf ../../ros-indigo-gmapping_1.3.7.orig.tar.gz\n$ mv ros-indigo-gmapping-1.3.7/\
    \ gmapping\n$ gedit gmapping/src/slam_gmapping.cpp\n</pre></code>\nChange line\
    \ 409 from:\n<pre><code>  if (fabs(fabs(scan.angle_min) - fabs(scan.angle_max))\
    \ > FLT_EPSILON)</pre></code>\nto:\n<pre><code>  if (fabs(fabs(scan.angle_min)\
    \ - fabs(scan.angle_max)) > 0.003) // this is the value for Kinect</pre></code>\n\
    Save and close the file. Go back to commandline:\n\n<pre><code>$ cd ..\n$ catkin_make\n\
