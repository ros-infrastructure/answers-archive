  body_markdown: "One of the easiest things is to use the [rosmsg command](http://wiki.ros.org/rosmsg).\
    \ Or, if you don't know the type of a topic is, you can use the rosmsg command\
    \ along with the rostopic command as mentioned in that link: \n\n    rostopic\
    \ type topic_name | rosmsg show\n\nAlso, if you know the type, you can probably\
    \ look it up in the [common_msgs documentation](http://wiki.ros.org/common_msgs?distro=noetic).\
    \ For example, /cmd_vel is a twist message (if you didn't know that you could\
    \ use rostopic type cmd_vel) and [twist](http://docs.ros.org/en/api/geometry_msgs/html/msg/Twist.html)\
    \ can be found in [geometry_msgs](http://wiki.ros.org/geometry_msgs?distro=noetic)"
