  body_markdown: "Ultimately, I was able to resolve my problem by specifying `rosconsole_DIR`\
    \ correctly. It took several tries to find the right value of `rosconsole_DIR`:\n\
    \n    -Drosconsole_DIR=/Users/cameroj/Projects/ros/macos/install_isolated/share/rosconsole/cmake\n\
    \nIn my case, the root of my ROS project is /Users/cameroj/Projects/ros/macos.\
    \ \n\nHaving fixed this problem for rosconsole, I had the same problem for roslib,\
    \ which was solved the same way:\n\n    -Droslib_DIR=/Users/cameroj/Projects/ros/macos/install_isolated/share/roslib/cmake\n\
    \nI hope this helps someone out there.\n\n"
