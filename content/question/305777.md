    The package `cmvision` has been released only for `ROS Hydro`. If you still want to use it on another ROS distro, you should build it from sources. [This](https://github.com/kbogert/cmvision/tree/indigo-devel) seems to be a fork of the `cmvision` package, modified to work on `ROS Indigo`, and it might work on `ROS Kinetic`, not sure though. Please also refer to [#q254172](https://answers.ros.org/question/254172/how-to-install-cmvision-package-for-ros-indigo/) for more info.
