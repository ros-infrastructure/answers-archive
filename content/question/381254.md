  body_markdown: |-
    there are missing dependencies. `usb_cam` [is released for melodic](http://repositories.ros.org/status_page/ros_melodic_default.html?q=usb_cam) so install it using apt. there is [nothing released starting](http://repositories.ros.org/status_page/ros_melodic_default.html?q=tm_) with `tm_`, so you need the `tm_hardware_interface` package from source (wherever you can get that from).

    Note that the repo you clone is quite stale (~2years old). You could ask for help there. Especially as `tm_hardware_interface` is [declared as a system dependency](https://github.com/viirya/ros-driver-techman-robot/blob/5e20a589ae5347e953db9392dcb2281d8aec3813/tm_driver/CMakeLists.txt#L134). This is probably a mistake or you'll get some proprietary library with your techman robot.

    Anyways, I suggest to use the official [Techman Repos](https://github.com/TechmanRobotInc?type=source), as long as there is no very specific need to use the other. This is also officially supported on Melodic and up-to-date...
