    \ one by one (i.e. `sudo apt install ros-kinetic-<MISSING_PACKAGE>` for ROS packages,\
    \ so `geodesy` is missing right now), or, better, use `rosdep` to automatically\
    \ install them.\n\nSee the [wiki page](http://wiki.ros.org/rosdep#Using_rosdep)\
    \ on how to use it.\n\n----\n**Edit**\n\nTo quote now the link above...\n\n> Using\
    \ rosdep\n> \n> Install dependency of a particular\n> package\n> \n> You can use\
    \ rosdep and catkin to build\n> any package in the ROS repository. Say\n> that\
    \ you want to build a package\n> called `AMAZING_PACKAGE`, that you\n> hadn't\
    \ built on your machine before.\n> \n> `rosdep install AMAZING_PACKAGE`\n> \n\
    > Install dependency of all packages in\n> the workspace\n> \n> This usecase shows\
    \ even more powerful\n> feature of rosdep.\n> \n> Go to the top directory of your\
    \ catkin\n> workspace where the source code of the\n> ROS packages you'd like\
    \ to use are.\n> Then run:\n> \n> `rosdep install --from-paths src\n> --ignore-src\
    \ -r -y`\n> \n> This command magically installs all\n> the packages that the packages\
    \ in your\n> catkin workspace depend upon but are\n> missing on your computer."
