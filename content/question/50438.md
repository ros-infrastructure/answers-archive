  body_markdown: "Household objects database is used by Tabletop object recognition.\n\
    \nTo install household objects database server, you can refer to [this page](http://www.ros.org/wiki/sql_database/Tutorials/Installing%20a%20PostgreSQL%20Server).\n\
    But I can give you steps.\n\n**To create server**\n\n1.Open a terminal, type\n\
    \n    sudo apt-get install postgresql\n\n2.After the installation, type the command\
    \ below to become user postgres\n\n    sudo su - postgres\n\nFor example, it's\
    \ like\n\n    rosfuerte@rosfuerte-K53SM:~$ sudo su - postgres\n    [sudo] password\
    \ for rosfuerte: \n    postgres@rosfuerte-K53SM:~$\n\n3.Next, type psql to enter\
    \ postgre sql interpreter, it's like\n\n    postgres@rosfuerte-K53SM:~$ psql\n\
    \    psql (9.1.6)\n    Type \"help\" for help.\n    \n    postgres=#\n\n4.Then,\
    \ add a new user willow by entering CREATE ROLE ...(Don't forget the semicolon)\n\
    \n    postgres=# CREATE ROLE willow LOGIN CREATEDB CREATEROLE PASSWORD 'willow';\n\
    \n5.Leave the interpreter\n\n    postgres=# \\q\n    postgres@rosfuerte-K53SM:~$\n\
    \n**To make connection over TCP/IP works**\n\n1.Get the paths of the files(pg_hba.conf\
    \ & postgresql.conf) you need to modify\n\n    postgres@rosfuerte-K53SM:~$ ps\
    \ auxw | grep postgresql\n    postgres  1170  0.0  0.1 132084 10400 ?        S\
    \    09:53   0:00 /usr/lib/postgresql/9.1/bin/postgres -D /var/lib/postgresql/9.1/main\
    \ -c config_file=/etc/postgresql/9.1/main/postgresql.conf\n    postgres  4095\
    \  0.0  0.0  13612   916 pts/1    S+   11:32   0:00 grep postgresql\n\n2.Modify\
    \ pg_hba.conf(usually is /etc/postgresql/9.1/main/pg_hba.conf), You need to add\
    \ these two lines in the bottom of this file\n\n    # Anybody through TCP/IP with\
    \ password\n    host    all         all         0.0.0.0   0.0.0.0     md5\n\n\
    3.Modify postgresql.conf(usually is /etc/postgresql/9.1/main/postgresql.conf),\
    \ add this line to the file\n\n    listen_addresses = '*'\n\n4.Log out postgres\
    \ user\n\n    exit\n\n5.Reboot your computer\n\n**To add object database to server**\n\
    \n1.Install PGAdmin3\n\n    sudo apt-get install pgadmin3\n\n2.Launch PGAdmin3\
    \ by enter\n\n    pgadmin3\n\n3.Press the plugin button on the upper-left of PGAdmin\
    \ GUI\n\n4.Enter the name(whatever name you want)\n\n5.Set the host, enter \"\
    localhost\"\n\n6.Enter password, which is \"willow\"\n\n7.When your GUI looks\
    \ like this, press OK\n\n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/13554724665720363.jpg)\n\
    \n8.Now you can see your server on Object Browser on the left, press right button\
    \ of the mouse on \"Databases\" under the server\n\n9.Choose \"New Database...\"\
    \n\n10.Set the name and the owner, like(you should follow the name in the picture\
    \ below)\n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/13554726933658276.jpg)\
    \ \n\n11.Press right button of the mouse on the newly added database\n\n12.Press\
    \ \"Restore...\"\n\n13.Download the database backup file by\n\n    svn export\
    \ https://code.ros.org/svn/data/trunk/household_objects/household_objects-0.6_fuerte_prerelease_1.backup\n\
    \n14.Restore the file\n\n![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/13554729518647023.jpg)\n\
    \n15.Press \"Restore\"(Restore process need some time to complete), then you finished\
    \ installing the household objects database\n\n--------------------------------------------\n\
    \nTo use this database, you first need to create a yaml file, for example, I should\
    \ create my_server.yaml\n\n    household_objects_database:\n      database_host:\
    \ localhost\n      database_port: 5432\n      database_user: willow\n      database_pass:\
    \ willow\n      database_name: household_objects\n\nTo integrate the database\
    \ with tabletop object detector, you should create a launch file(in this example,\
    \ I created a package named ricky_tabletop_object_detector, I put my_server.yaml\
    \ in ricky_tabletop_object_detector/yaml/, and put this launch file in ricky_tabletop_object_detector/launch/)\n\
    \n    <launch>\n      <!-- set stereo to true for narrow stereo, false for kinect\
    \ -->\n      <arg name=\"stereo\" default=\"true\" />\n      <arg name=\"use_slip_controllers\"\
    \ default=\"false\"/>\n      <arg name=\"use_right_arm\" default=\"true\"/>\n\
    \      <arg name=\"use_left_arm\" default=\"true\"/>\n      <arg name=\"use_task_cartesian\"\
    \ default=\"false\"/>\n      <arg name=\"log_to_warehouse\" default=\"false\"\
    />\n      <arg name=\"flatten_table\" default=\"false\"/>\n      <arg name=\"\
    kinect_frame_prefix\" default=\"/head_mount_kinect\" />\n      <arg name=\"kinect_camera_name\"\
    \ default=\"head_mount_kinect\" />\n      <arg name=\"sim\" default=\"false\"\
    />\n    \n      <!-- client for object database running on remote server at Willow\
    \ Garage -->\n      <!-- DOES NOT WORK IN TRUNK RIGHT NOW -->\n      <!--\n  \

    />\n      <node pkg=\"household_objects_database\" name=\"objects_database_node\"\

    \ value=\"$(arg log_to_warehouse)\"/>\n        <arg name=\"kinect_frame_prefix\"\
    \ value=\"$(arg kinect_frame_prefix)\"/>\n        <arg name=\"sim\" value=\"$(arg\
    \ sim)\"/>\n      </include>\n    \n      <!-- manipulation -->\n      <include\
    \ file=\"$(find pr2_object_manipulation_launch)/launch/pr2_manipulation.launch\"\
    >\n        <arg name=\"use_slip_controllers\" value=\"$(arg use_slip_controllers)\"\
    />\n        <arg name=\"use_left_arm\" value=\"$(arg use_left_arm)\"/>\n     \
    \   <arg name=\"use_right_arm\" value=\"$(arg use_right_arm)\"/>\n        <arg\
    \ name=\"use_task_cartesian\" value=\"$(arg use_task_cartesian)\"/>\n        <arg\
    \ name=\"sim\" value=\"$(arg sim)\"/>\n      </include>\n    \n      <!-- tabletop\
    \ collision map processing -->\n      <node pkg=\"tabletop_collision_map_processing\"\
    \ name=\"tabletop_collision_map_processing\" \n            type=\"tabletop_collision_map_processing_node\"\
    \ respawn=\"false\" output=\"screen\"/>\n      <param name=\"tabletop_collision_map_processing/get_model_mesh_srv\"\
    \ \n             value=\"/objects_database_node/get_model_mesh\" />\n      <param\
    \ name=\"tabletop_collision_map_processing/static_map_cloud_name\" value=\"full_cloud_filtered\"\
    \ />\n    \n      <!-- tabletop segmentation and object recognition -->\n    \
    \  <include file=\"$(find tabletop_object_detector)/launch/tabletop_complete.launch\"\
    >\n          <arg unless=\"$(arg stereo)\" name=\"tabletop_segmentation_points_input\"\
    \ value=\"$(arg kinect_camera_name)/depth_registered/points\"/>\n          <arg\
    \ if=\"$(arg stereo)\" name=\"tabletop_segmentation_points_input\" value=\"narrow_stereo_textured/points2\"\
    />\n          <arg name=\"flatten_table\" value=\"$(arg flatten_table)\"/>\n \
    \     </include>\n    \n    </launch>"
