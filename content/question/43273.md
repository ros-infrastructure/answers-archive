    The "roscore" is mostly just an XML-RPC server that helps ROS nodes on the network establish connections between each-other. It doesn't matter what platform a ROS node is running on as long as it can communicate over the network.

    I haven't worked with it myself, but [eros](http://www.ros.org/wiki/eros) might be a place to look if you're looking for truly minimal ROS installs which can communicate via XML-RPC calls with the ROS network.

    There are two other widely used options which allow devices to communicate with a ROS system without using XML-RPC calls. Those are [rosserial](http://www.ros.org/wiki/rosserial) (typically used on Arduino or other lightweight chips) and [rosbridge](http://www.ros.org/wiki/rosbridge) (typically used in web clients).
