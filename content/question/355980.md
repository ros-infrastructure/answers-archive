    From my understanding and a bit of experimentation, `ament_target_dependencies` only works for packages* found using `find_package`.  For packages that aren't coming from `find_package`, e.g. locally compiled libraries in the same package, you will need to use `target_link_libraries`.  See [this question](https://answers.ros.org/question/371562/linking-library-with-node-in-same-package/) for more details.

    \* Not sure if it's only for ROS packages found with `find_package`, or if it works for any package found that way.

 In the [tutorial for adding dependencies](https://index.ros.org/doc/ros2/Tutorials/Ament-CMake-Documentation/#adding-dependencies), it mentions
> Sometimes it will be necessary to call the target_link_libaries CMake function

What are the situations where I should use `ament_target_dependencies` and when should I use `target_link_libraries`?  I also notice that there are occasions where I need both for the dependencies to be correctly added.
