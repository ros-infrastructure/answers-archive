  body_markdown: "Same error happens in Melodic as well. Since you don't pass any\
    \ launch arguments, you can just simply start the launch file in a similar way\
    \ as specified in [wiki](http://wiki.ros.org/roslaunch/API%20Usage#Starting_a_launch_file):\n\
    \n    import rospkg\n    rospack = rospkg.RosPack()\n    ...\n    launch_path\
    \ = rospack.get_path('symeter2') + '/symeter2_nav.launch'\n    cli_args = [launch_path]\n\
    \    roslaunch_file = roslaunch.rlutil.resolve_launch_arguments(cli_args)\n  \
    \  launch = roslaunch.parent.ROSLaunchParent(uuid, roslaunch_file)\n\nI believe\
    \ this same solution works for Lunar as well.\n\nFor the people who receive this\
    \ error when trying to launch multiple launch files at the same time, there seems\
    \ to be error in wiki. As suggested by [@kawa](https://answers.ros.org/users/55182/kawa/),\
    \ changing \n\n    roslaunch_file = roslaunch.rlutil.resolve_launch_arguments(cli_args)\n\
    to\n    \n    roslaunch_file = roslaunch.rlutil.resolve_launch_arguments(cli_args)[0]\n\
    \nhelped me to solve the error."
