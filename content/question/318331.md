    Hi,

    yes it is possible to drop a "guess" with RVIZ using the "[2D Pose Estimate](http://wiki.ros.org/navigation/Tutorials/Using%20rviz%20with%20the%20Navigation%20Stack#A2D_Pose_Estimate)" button like in this [video](http://wiki.ros.org/navigation/Tutorials/Using%20rviz%20with%20the%20Navigation%20Stack) at 0:50. Make sure to remap the topic `initialpose` of rtabmap node and that the Fixed Frame in global options is `map`. Example (if rtabmap is started in rtabmap namespace):
    ![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/15526954296819038.png)
