    \ but just for the records let's clarify the problem and possible workaround:\n\
    \nRoot of the **problem** is to install gazebo-2.0.0 with ros-hydro-gazebo-pkgs\
    \ <strike>< 2.3.3</strike> (specially installed from packages) into the same system\
    \ since gazebo-2.0.0 breaks ABI/API.\n\n**III Update as of 17th Oct 2013:** gazebo\
    \ and ROS integration has been fixed in the official repositories. gazebo package\
    \ will bring gazebo1.9 version while gazebo-current will install gazebo-2.0. Please\
    \ read the [release mail](http://gazebosim.org/pipermail/gazebo-list/2013-October/000040.html)\
    \ for full information.\n\n**IV Update as of 22nd Oct 2013:** new document with\
    \ fully instructions about [Gazebo and ROS integration has been released](http://gazebosim.org/wiki/Install/Gazebo_and_ROS).\
    \ \n\nTo be sure you don't have the (now deprecated) gazebo package version 2.0.0\
    \ (it was in the repo during some hours) you could do an easy check by removing\
    \ the package and back to install it:\n\n       sudo apt-get update\n       sudo\
    \ apt-get remove gazebo\n       sudo apt-get install gazebo\n\nThanks to [DaveR](http://answers.gazebosim.org/users/537/daver/)\
    \ for the hint.\n\n<strike>**Proper solution** is gazebo team to release a new\

    \ to know the work on this.</strike>\n\n**Possible workarounds:**\n\n 1. Install\
    \ gazebo-1.9 and ros-$distro-pkgs from debs. They are available at [gazebosim\

    \ guide partially]() ignoring osrf-common, sandia-hand and drcsim.\n 2. [Install\
