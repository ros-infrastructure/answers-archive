    You need to remove the template parameter for the subscribe call. According to the [image_transport api docs](http://ros.org/doc/fuerte/api/image_transport/html/classimage__transport_1_1ImageTransport.html#a1c847a2c719c874f84a78a6a60b98c7f), the version of it.subscribe that accepts a `boost::function` object for the callback is not templated.
