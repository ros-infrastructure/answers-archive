    I'm closing this as a duplicate, even without pointing you to what this is a duplicate of.

    Reason is: there are plenty of Q&As which explain on which Ubuntu versions you can install ROS Melodic. There is really only one: Ubuntu Bionic or `18.04`.

    You cannot install Melodic on Focal Fossa (`20.04`).

    The only ROS 1 version which will be officially supported on Focal will be ROS Noetic. But see #q350055 for why you cannot install `desktop_full` of that yet either.
