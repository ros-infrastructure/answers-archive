  body_markdown: "I figured out the problem.  The linear filter that I used `lfilter`\
    \ accepts \"Array-Like\" objects therefore I appended the incoming signals to\
    \ empty arrays within the callback function as follows:\n\n    import rospy\n\
    \    from scipy import signal\n    from geometry_msgs.msg import WrenchStamped\n\
    \n    def callback(data):\n    \n    time = data.header.stamp.secs  +  data.header.stamp.nsecs\
    \ * 1e-9\n    \n    fx = data.wrench.force.x\n    fy = data.wrench.force.y\n \
    \   fz = data.wrench.force.z\n    tx = data.wrench.torque.x\n    ty = data.wrench.torque.y\n\
    \    tz = data.wrench.torque.z\n\n    FX = []\n    FY = []\n    FZ = []\n\n  \
    \  TX = []\n    TY = []\n    TZ = []\n\n    FX.append(fx)\n    FY.append(fy)\n\
    \    FZ.append(fz)\n\n    TX.append(tx)\n    TY.append(ty)\n    TZ.append(tz)\n\
    \n    fs = 124.956672444 #sampling frequency\n\n    fc = 55 # Cut-off frequency\
    \ of the filter\n    w = fc / (fs / 2) # Normalize the frequency\n\n    b, a =\
    \ signal.butter(5, w, 'low')\n\n\n    fx_low = signal.lfilter(b, a, FX) #Forward\
    \ filter\n    fy_low = signal.lfilter(b, a, FY)\n    fz_low = signal.lfilter(b,\
    \ a, FZ)\n\n    tx_low = signal.lfilter(b, a, TX)\n    ty_low = signal.lfilter(b,\
    \ a, TY)\n    tz_low = signal.lfilter(b, a, TZ)\n\nIt may not be best practice\
    \ but I hope it helps someone else!"
