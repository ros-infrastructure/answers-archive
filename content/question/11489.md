  body_markdown: "The base_local_planner has the build type set to \"Release\" in\
    \ the CMakeLists.txt which does not include debug symbols.  Change it to RelWithDebug\
    \ and recompile to get debugging symbols.  Usually the release type should be\
    \ commented out in released code to allow the system builder to change the build\
    \ type for the whole system.  You might want to open a ticket about this for the\
    \ base_local_planner package.  "
