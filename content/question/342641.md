    \ on why it is failing.\n\nROS Kinetic doesn't have any binary packages for Debian\
    \ Stretch (and you are using Raspbian 9 Stretch), this is why `rosdep` cannot\
    \ resolve them.\nThere is no version of ROS providing packages for Raspbian 32bits\
    \ so you need to either build ROS from source or use images built by someone.\
    \ \n\nUsually to get the sources of the missing packages to compile, I would use\
    \ the tool [rosinstall_generator](http://wiki.ros.org/rosinstall_generator#A_set_of_packages_missing_from_the_current_environment).\n\
    Unfortunately in your case the `create_autonomy` package has not been released\
    \ for Kinetic or any other distro so the tool cannot find it.\n\n\nEdit:\n\nDisclaimer:\n\
    \n - Hacky way to solve the problem\n - Not tested for this issue, but I tried\
    \ something similar on a\n   RaspberryPi 2 running Raspbian 10 and\n   ROS Melodic\
    \ and it worked\n\nThe idea is to:\n\n 1. trick rosdep into giving us a list of\
    \ `apt-get install ros-kinetic-...` commands for your dependencies\n 2. convert\
    \ them into ROS package names `[...] apt-get install ros-kinetic-my-package` ->\
    \ `my_package`\n 3. pass that list of packages to\n    `rosinstall_generator`\
    \ to get the\n    list of repos to build from source\n 4. clone them\n 5. install\
    \ any missing system\n    dependency\n 6. build the ROS packages\n\n\nSetup:\n\
    \n    source <YOUR_ROS_INSTALLATION>/setup.bash\n    mkdir -p ~/create_autonomy_ws/src\
    \ && cd ~/create_autonomy_ws/src\n    git clone https://github.com/AutonomyLab/create_autonomy\
    \ \n    mkdir -p ~/create_autonomy_dependencies_ws/src\n    cd ~/create_autonomy_ws/\n\
    \n \n(1) While Debian didnt seen any armhf packages, some other distros did e.g.\
    \ Ubuntu Xenial. We will use `--os ubuntu:xenial` and also `--simulate` for rosdep\
    \ to just give us the list of install commands.\n\n \n    rosdep install --from-paths\
    \ src --ignore-src --rosdistro kinetic -y --os=ubuntu:xenial --simulate\n\nWe\
    \ will keep only the lines with \"ros-kinetic\" in them and store them in a temporary\
    \ file\n\n    rosdep install --from-paths src --ignore-src --rosdistro kinetic\
    \ -y --os=ubuntu:xenial --simulate | grep ros-kinetic > rosdep_output\n\n(2) convert\
    \ `[...] apt-get install `ros-kinetic-my-package` to `my_package`\n\nTo convert\
    \ we want to keep everything after `ros-kinetic-` (here my-package) and then convert\
    \ `-` to `_`\n\n    sed -e 's#.*ros-kinetic-\\(\\)#\\1#' rosdep_output | sed 's/-/_/g'\
    \ > pkg_list\n\n(3) \n\n    rosinstall_generator `cat pkg_list` --deps --tar --exclude\
    \ RPP --rosdistro kinetic > ~/create_autonomy_dependencies_ws/deps_to_build.rosinstall\n\
    \n(4)\n\n    cd ~/create_autonomy_dependencies_ws/\n    wstool init -j4 src deps_to_build.rosinstall\n\
    \    \n(5)\n\n    rosdep install --from-paths src --ignore-src --rosdistro kinetic\
    \ -y\n\n(6)\n\n    catkin_make_isolated --install -DCMAKE_BUILD_TYPE=Release -DCATKIN_ENABLE_TESTING=OFF\
    \ -j2\n\n(7) source the resulting workspace\n\n    source ~/create_autonomy_dependencies_ws/install_isolated/setup.bash\n\
    \n\n(8) build the create_autonomy workspace\n\n    cd ~/create_autonomy_ws/\n\
    \    catkin_make install\n\n(9) delete temp files\n\n    rm ~/create_autonomy_dependencies_ws/deps_to_build.rosinstall\
    \ ~/create_autonomy_ws/rosdep_output ~/create_autonomy_ws/pkg_list"
