    \ a string pose request as defined in your srv. Also you are not creating your\
    \ srv request for the call properly. Check the documentation for the [std_msg/Sring](http://docs.ros.org/melodic/api/std_msgs/html/msg/String.html).\
    \ \n<br>You can try the following:<br>\n\n    word=String()\n    word.data= 'Upright'\n\
    \    srv_proxy = rospy.ServiceProxy(step.context.set_navigation_config_service_name,\
    \ String)\n    response = srv_proxy(word)\n\nThe response should be of type [sensor_msgs/JointState](http://docs.ros.org/melodic/api/sensor_msgs/html/msg/JointState.html)\
    \ and you should be able to access its data with `response.specific_field` (for\
    \ example `response.name[0]` to get the name of the first joint)."
