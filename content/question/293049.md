    The official documentation is [here](http://moveit.ros.org/documentation/plugins/#kinematicsbase), along with some links to example code. Another example is [ur_kinematics](https://github.com/ros-industrial/universal_robot/tree/ad740e0dd028cd9614b869d306dfc2da402cbc46/ur_kinematics).

    The kinematics are loaded in MoveIt via a plugin architecture (see [this pluginlib tutorial](http://wiki.ros.org/pluginlib/Tutorials/Writing%20and%20Using%20a%20Simple%20Plugin)). When you have created your plugin, you can select it in your kinematics.yaml file [like this](https://github.com/TAMS-Group/tams_ur5_setup/blob/23d912f0ef17216fc43b837b8d0a72de4c26c20f/tams_ur5_setup_moveit_config/config/kinematics.yaml):

        arm:
          kinematics_solver: ur_kinematics/UR5KinematicsPlugin
