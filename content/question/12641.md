  body_markdown: "Assuming it built successfully, you probably tried to run it in\
    \ a different terminal environment. Since the cwru-ros-pkg checkout (which contains\
    \ the xv_11_laser_driver) is not part of the system ROS installation, you'll need\
    \ to do `. ~/cwru-ros-pkg/setup.bash` in each terminal you want to use the driver\
    \ in.\n\nAlternatively, you could add `. ~/cwru-ros-pkg/setup.bash` to your ~/.bashrc\
    \ to have it automatically included in all terminals.\n\nUPDATE 1: You have to\
    \ give the driver the path to a valid serial port. If you have no /dev/ttyUSB*\
    \ devices, are you certain the serial adapter is connected properly (there may\
    \ also be some lights on the SparkFun adapter, but I don't recall if those only\
    \ light when the adapter is communicating or also just when plugged in)? Do you\
    \ have any /dev/ttyACM* devices?\n\nDirections for hooking up the laser are here:\
    \ [Connecting the XV-11 Laser to USB](http://www.ros.org/wiki/xv_11_laser_driver/Tutorials/Connecting%20the%20XV-11%20Laser%20to%20USB)\n\
    \nUPDATE 2: The root of the trouble connecting to the serial adapter was a faulty\
    \ USB cable. As far as launching things in separate terminals, that is completely\
    \ normal. Your fixed_frame in RVIZ should be `neato_laser` by default, unless\
    \ you change the `frame_id` parameter to something else. It should be available\
    \ in the drop-down menus once you subscribe to the scan topic.\n\nRegarding the\
    \ trouble receiving scans, make sure you set the topic after adding a LaserScan\
    \ display to `rviz`. The topic defaults to `/scan`. If you still get that error,\
    \ in a new terminal, run `rostopic list` and verify that `/scan` (or whatever\
    \ you may have remapped the scan topic to) is in the list. Run `rostopic hz /scan`\
    \ to make sure you are getting data (it should report data coming out at either\
    \ 5 or 10 Hz). \n\nIf you still don't get any data, try starting your driver node\
    \ with the other firmware version (see the [documentation](http://www.ros.org/wiki/xv_11_laser_driver)\
    \ for details on that parameter. For a quick check, just try `rosrun xv_11_laser_driver\
    \ neato_laser_publisher _port:=/dev/ttyUSB0 _firmware_version:=2` to see if that\
    \ gets you good looking data in `rviz`."
