  body_markdown: "To edit a ROS package using CodeBlocks, one can generate the project\
    \ file using cmake:\n\n    roscd <your_package>\n    mkdir build_codeblocks \n\
    \    cd build_codeblocks \n    cmake -G \"CodeBlocks - Unix Makefiles\" ..\n\n\
    According to http://www.cmake.org/Wiki/CMake_Generator_Specific_Information ,\n\
    you need cmake version at least 2.6.\n\nStart CodeBlocks from Terminal directly\
    \  rather than click on the app launcher.\nIn this way, codeblocks will inherit\
    \ all ROS_* variable from bash shell.\n\nThen open the your_package.cbp using\
    \ CodeBlocks. You should be able to compile without any problem.\n\nWhen Run,\
    \ remember to choose the right target, <your_pacakge> not the default \"all\"\n\
    \n\nHTH"
