    The official Gazebo version supported with Foxy is 11. This is defined on [REP-2000](https://www.ros.org/reps/rep-2000.html#foxy-fitzroy-may-2020-may-2023).

    If you already have Foxy installed, you can just install this additional package to get everything you need:

    `sudo apt install ros-foxy-gazebo-ros-pkgs`
