  body_markdown: "Try these options out:\n\n     -f, --freeze-layout   freeze the\
    \ layout of the GUI (prevent \n                           rearranging\n      \
    \                      widgets, disable undock/redock)\n    \n    -l, --lock-perspective\n\
    \                            lock the GUI to the used perspective\n          \
    \                  (hide menu bar\n                            and close buttons\
    \ of plugins)\n\n(Though when I try `rqt -l` now with the latest kinetic, lunar,\
    \ and kinetic-devel qt_gui_core I still see File and Help. That must be a regression,\
    \ [I took a screenshot a few months ago](https://github.com/ros-visualization/qt_gui_core/pull/82)\
    \ where File and Help are gone)\n\n\nThis is in the [kinetic-devel branch of qt_gui_core](https://github.com/ros-visualization/qt_gui_core):\n\
    \n    -ht, --hide-title     hide the title label, the icon, \n               \
    \             and the help button\n                            (combine with -l\
    \ and -f to \n                            eliminate the entire title\n       \
    \                     bar and reclaim the space)\n\nIt hides the title bars of\
    \ individual plugins.\n\nIf you clone https://github.com/ros-visualization/qt_gui_core.git\
    \ into your catkin_ws it will overlay the system installed qt_gui_core."
