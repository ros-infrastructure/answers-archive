  body_markdown: "Subscriber callbacks run on their own thread, so I usually update\
    \ a variable in the subscriber callback and then use that data in a main loop\
    \ running in the startup thread. Something like this:\n\n    import rospy\n  \
    \  \n    class MyNode:\n        def main(self):\n            rospy.subscriber('sometopic',\
    \ SomeMsgType, self.msgCallback)\n            self.value = None\n            self.rate\
    \ = rospy.getParam('~rate', 10.0)\n            while not rospy.is_shutdown():\n\
    \                ... do something with self.value ...\n                rate.sleep()\n\
    \        \n        def msgCallback(self, newValue):\n            self.value =\
    \ newValue\n    \n    if __name__ == '__main__':\n        try:\n            MyNode().main()\n\
    \        except rospy.ROSInterruptException:\n            pass\n"
