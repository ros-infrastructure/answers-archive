  body_markdown: "I recommend reading through  \nhttp://wiki.ros.org/urdf/XML/model,\
    \   \nhttp://wiki.ros.org/urdf/XML/joint,  \nand http://wiki.ros.org/urdf/XML/link\
    \    \nif you have not already.\n\n----------\n\njoints represent connections\
    \ between link / reference frames:  \n\n - origin rpy attribute: \"Represents\
    \ the rotation around fixed axis: first roll around x, then pitch around y and\
    \ finally yaw around z. All angles are specified in radians\" (Tait-Bryan xyz\
    \ extrinsic rotations) relative to the parent link's reference frame (effectively\
    \ the parent joint).  \n\n - origin xyz attribute: Represents the x, y, z translation\
    \ relative to the parent link's reference frame (effectively the parent joint).\n\
    \nlinks represent rigid bodies:  \n\n - origin rpy attribute: \"Represents the\
    \ rotation around fixed axis: first roll around x, then pitch around y and finally\
    \ yaw around z. All angles are specified in radians\" (Tait-Bryan xyz extrinsic\
    \ rotations) relative to the parent joint.\n\n - origin xyz attribute: Represents\
    \ the x, y, z translation relative to the parent joint.\n\n----------\n\nIf you\
    \ want to be confused: https://en.wikipedia.org/wiki/Euler_angles#Tait-Bryan_angles"
