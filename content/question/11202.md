  body_markdown: "I had the same compilation errors with rgbdslam under ubuntu 10.10\
    \ ros-electric.\n\nI had to change a few lines in the source code to get it working\
    \ (really, just going after the compiler errors and changing each expression to\
    \ something equivalent). \n\nOn line 1043 the compiler is complanining that the\
    \ argument passed to the function is a constant (cannot be changed). However,\
    \ the function expects a mutable variable. To solve it in an easy way, copy the\
    \ contents of the const float* to a new variable that is declared as float* and\
    \ pass that to the function instead. The hard but more correct way would be to\
    \ change the function to accept a pointer to constant floats instead.\n\nFor example,\
    \ replace line 1043 in graph_manager.cpp with the following two lines and try\
    \ compiling it again.\n\n     pointcloud_type ncloud=cloud_in;\n     Eigen::Map<Eigen::Vector3f>\
    \ p_in (&ncloud.points[i].x, 3, 1);\n\n I don't know how this code could have\
    \ worked earlier, maybe this is related to new versions of g++ ? "
