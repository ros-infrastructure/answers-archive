  body_markdown: "from the [docs](https://github.com/ros2/launch/blob/master/launch/launch/logging/__init__.py#L343)\
    \ you can find that there are some options for redirecting stdout and stderr to\
    \ log files and to the screen. \n\nIf you want to redirect one or both stdout\
    \ and stderr per node away from the screen, try messing with those options\n\n\
    For one of my nodes, I'm tired of seeing stuff output from it to the screen, so\
    \ I set the output param like so:\n\n    object_mapper = launch_ros.actions.Node(\n\
    \            package='object_mapper',\n            node_executable='object_mapper',\n\
    \            node_name='object_mapper',\n            output={'both': 'log'}\n\
    \    )"
