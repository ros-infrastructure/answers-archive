  body_markdown: |
    [visualization_msgs/Marker](http://docs.ros.org/api/visualization_msgs/html/msg/Marker.html) contains a `points` field, which is of type `geometry_msgs/Point[]`. That is an unbounded array (== list) of [geometry_msgs/Point](http://docs.ros.org/api/geometry_msgs/html/msg/Point.html)s.

    Lists in the ROS msg IDL are mapped to `std::vector`s for C++ (see [wiki/msg - Message Description Specification - Array handling](http://wiki.ros.org/msg#Message_Description_Specification)).

    And `std::vector` has a `push_back(..)` method that in this case will take `geometry_msgs/Point`.
