  body_markdown: "Even if this is an old question I wanted to answer it since I came\
    \ across the same problem.\n\nAccording to the [PyStyleGuide](http://wiki.ros.org/PyStyleGuide)\
    \ is a protected member of the class, thus accessing this is not the way it is\
    \ meant to be.\n\nA cleaner way to access the constants (IMHO) is to include the\
    \ classes which are accessed with the `_request_class` and `_response_class` members.\n\
    \nIn the example given above this would be:\n\n    from my_package.srv include\
    \ MySrv\n    from my_package.srv include MySrvRequest\n    from my_package.srv\
    \ include MySrvResponse\n\n    # Do something with:\n    MySrvRequest.MY_REQUEST_CONSTANT\n\
    \    MySrvResponse.MY_RESPONSE_CONSTANT\n  "

Given the file:

* foo.srv

        string service_name = foo_service
        string in
        ---
        string out

In my C++ code, `my_project::foo::Request::service_name` works as expected, but how do I do this in Python? I do:

    from my_project.srv import foo

at the head of the file, but in the code `foo.service_name`, `fooRequest.service_name`, `foo.fooRequest.service_name` all fail. I can see `service_name = 'foo_service'` in the generated `_foo.py` file, so I think it's a problem in my code, not my build process.
