    It looks like you haven't defined your service properly, I would have expected you to get an error when you try and catkin_make this.

    If you look at the [tutorial on messages and services](http://wiki.ros.org/ROS/Tutorials/CreatingMsgAndSrv#Using_rossrv), you can see that a service needs to define both the request and response parts separated by there hyphens `---` like the example shown there:

        int64 a
        int64 b
        ---
        int64 sum

    As also described in the tutorial above you need to setup your CMakeLists.txt file to make sure that this service is built too.

    Hope this helps.
