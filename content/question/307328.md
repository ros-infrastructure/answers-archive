    > and I'm using Melodic on Ubuntu 18.04 which creates .sdf files instead.

    I don't believe that is true.

    `.sdf` is  the *Simulation Description Format*, which is a format used by Gazebo.
    `.urdf` is the *Unified Robot Description Format*, used by a lot of ROS nodes.

    Melodic still uses URDF.
