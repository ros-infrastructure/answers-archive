  body_markdown: "The source of rosdep key entries are maintained on [rosdistro repository](https://github.com/ros/rosdistro/tree/master/rosdep)\
    \ and frequently updated. \n\n> Why do we need to run the update command afterwards?\n\
    \nAfter `rosdep update` you probably saw something was done at `~/.ros/rosdep/sources.cache`.\
    \ That's where the latest rosdep key entries are stored in some files that get\
    \ updated with the rosdep command."
