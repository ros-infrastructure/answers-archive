    You should have a look at the [UVC camera package ](http://wiki.ros.org/uvc_camera) or at the [lib UVC camera package](http://wiki.ros.org/libuvc_camera) since I suppose you you are using a USB camera.

    To make the node works with your camera you should check the device name is the launch file. The node will then publish the camera frames to an image topic.

    Then if you want to display them, you should either :

    - Use the [image view package](http://wiki.ros.org/image_view) to visualize your frames
    - Write a subscriber to your image topic and display them using `imshow()`. This second solution allows you to use the images for processing. You will find a simple tutorial [here](http://wiki.ros.org/image_transport/Tutorials/SubscribingToImages).
