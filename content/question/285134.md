    This is a C++ issue and not a ROS one: [KDL::Rotation::GetQuaternion(..)](http://docs.ros.org/hydro/api/orocos_kdl/html/classKDL_1_1Rotation.html#a37f92d1b2c5e9708771543c521c276c4) is not a static method, but a regular one. From the documentation:

    > Get the quaternion of this matrix

    You'll need to first create an instance of `KDL::Rotation` ('this matrix') and then invoke its `GetQuaternion(..)`.

    Note also: `x`, `y`, `z` and `w` are *output arguments*.
