  body_markdown: "find_package is for finding existing cmake packages, not the current\
    \ project. Do not include 'robot' to find_package. same with Depends - these are\
    \ the packages that your package is dependent on.\n\nYou need to create a library\
    \ first and then link it to your executable. Assuming your sources for robot are\
    \ stored in variable SOURCES and those of the executable are stored in NODE_SOURCES,\
    \ the following snippet should do the trick. you can replace those variables with\
    \ your source files.\n\n    add_library(robot ${SOURCES})\n    target_link_libraries(robot\
    \ ${catkin_LIBRARIES})\n    \n    add_executable(robot_node ${NODE_SOURCES})\n\
    \    target_link_libraries(robot_node  ${catkin_LIBRARIES} robot)"
