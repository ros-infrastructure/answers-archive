  body_markdown: "In that particular demo, the images were throttled at ~10 Hz and\
    \ the compressed topics were recorded:\n\n    <!-- Throttling messages -->\n \
    \     <group ns=\"camera\">\n        <node pkg=\"nodelet\" type=\"nodelet\" name=\"\
    data_throttle\" args=\"load rtabmap_ros/data_throttle camera_nodelet_manager\"\
    \ output=\"screen\">\n          <param name=\"rate\" type=\"double\" value=\"\
    10.0\"/>\n    \n          <remap from=\"rgb/image_in\"       to=\"rgb/image_rect_color\"\
    />\n          <remap from=\"depth/image_in\"     to=\"depth_registered/image_raw\"\
    />\n          <remap from=\"rgb/camera_info_in\" to=\"rgb/camera_info\"/>\n  \
    \  \n          <remap from=\"rgb/image_out\"       to=\"/data_throttled_image\"\
    />\n          <remap from=\"depth/image_out\"     to=\"/data_throttled_image_depth\"\
    />\n          <remap from=\"rgb/camera_info_out\" to=\"/data_throttled_camera_info\"\
    />\n        </node>\n      </group>\n\nRecord:\n\n    $ rosbag record /odom /data_throttled_image/compressed\
    \ /data_throttled_image_depth/compressedDepth /data_throttled_camera_info /tf\
    \ -O kinect\n\n**Tip 1**\n\nIf you are using [freenect_launch](https://github.com/ros-drivers/freenect_stack/blob/8572761912ca03fd109e93bf8bc85bbc590d29ab/freenect_launch/launch/freenect.launch#L10),\
    \ it may be more efficient to set `data_skip` instead of using the `data_throttle`\
    \ nodelet above:\n\n    $ roslaunch freenect_launch freenect.launch depth_registration:=true\
    \ data_skip:=3\n    $ rosbag record /odom /camera/rgb/image_rect_color/compressed\
    \ camera/depth_registered/image_raw/compressedDepth /camera/rgb/camera_info /tf\
    \ -O kinect\n\n**Tip 2**\n\nIf you don't want to save compressed images in the\
    \ rosbag, you may compress to rosbag after the recording to save some space when\
    \ storing it:\n\n    $ rosbag compress kinect.bag\n\nMake sure to decompress before\
    \ replaying it:\n\n    $ rosbag decompress kinect.bag\n    $ rosbag play --clock\
    \ kinect.bag\n\n\ncheers\n"
