  body_markdown: "The most likely explanation is that `cv_img = cv2.imread('sizeDetect.jpg')`\
    \ failed to load sizeDetect.jpg because it isn't in the same path as where the\
    \ script is being run from, and cv_img is `None`.  imread doesn't throw when it\
    \ fails, just returns None.\n\nIf sizeDetect.jpg is in the same package as your\
    \ python script you could use rospack like this:\n\n\n    import rospkg\n    \n\
    \    ...\n        rospack = rospkg.RosPack()\n        image_path = rospack.get_path('my_package_name')\
    \ + '/images/'\n        cv_img = cv2.imread(image_path + 'sizeDetect.jpg')\n\n\
    \nThis is a complete example:\n\nhttps://github.com/lucasw/rviz_textured_quads/blob/image_topic/tests/display_images_test.py"
