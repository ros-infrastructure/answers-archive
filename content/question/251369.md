    Hi,

    rtabmap doesn't fuse wheel odometry and visual odometry. There is only one odometry input to rtabmap node (so one or the other can be used). If you want to fuse odometries, look at the [robot_localization](http://docs.ros.org/kinetic/api/robot_localization/html/index.html) package for example, then use its odometrry output as the odometry input of rtabmap.
