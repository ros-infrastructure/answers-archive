  body_markdown: "Usually, to control the speeds of a UAV in rotorS, you need to publish\
    \ an array of speeds to a particular topic, right?\n\nFor Eg: To set all of the\
    \ motor speeds of 'firefly' UAV to 100, we run the command\n\n`rostopic pub /firefly/command/motor_speed\
    \ mav_msgs/Actuators '{angular_velocities: [100, 100, 100, 100, 100, 100]}'` \n\
    \nNow, the equivalent to this command, using a MATLAB script and [rospublisher](https://in.mathworks.com/help/robotics/ref/robotics.publisher.html),\
    \ is as follows:\n(This publishes messages to the ROS network.) \n\n    rosinit\n\
    \    motor_speeds = rospublisher('/firefly/command/motor_speed','mav_msgs/Actuators');\n\
    \    msg = rosmessage(motor_speeds);\n    msg.Data = '{angular_velocities: [100,\
    \ 100, 100, 100, 100, 100]}';\n    send(motor_speeds, msg);\n\nPS: Try this. Let\
    \ me know what happens. Coz, I haven't run this. I just followed that above link.\
    \ So, let me know how it goes. \n \n---\n\nUPDATE:\n\nIn case the ROS topic already\
    \ exists, follow this:\n\n    rosinit\n    motor_speeds_topic = '/firefly/command/motor_speed';\n\
    \    msg = rosmessage(motor_speeds);\n    msg.Data = '{angular_velocities: [100,\
    \ 100, 100, 100, 100, 100]}';\n    send(motor_speeds_topic, msg);\n\nChange the\
    \ value of `motor_speeds_topic` to that existing topic you want.\n\nPeace fellazz!!"
