  body_markdown: "I found a way to work it.\n\nI am using a gazebo sensor called *projection*\
    \ as code present below but when you call the texture you must add it to gazebo\
    \ root files. As I am using Gazebo 7 I create a texture and move it to folder\
    \ **/usr/share/gazebo-7/media/materials/textures** and it works as it should.\
    \ \n\nI am able to project a texture over objects surfaces and being able to see\
    \ this texture projected at camera sensor.\n\n        <gazebo reference=\"projector_sensor_link\"\
    >\n            <!--sensor type=\"projector\" name=\"projector_tester\"-->\n  \
    \          <projector name=\"projector_test\">\n                <pose>0 0 0 0\
    \ 0 0</pose>\n                <texture>your_texture.png</texture>\n          \
    \      <fov>${fov}</fov>\n                <near_clip>0.1</near_clip>\n       \
    \         <far_clip>10</far_clip>\n            </projector>\n        </gazebo>"
