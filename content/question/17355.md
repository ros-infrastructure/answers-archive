  body_markdown: "I think the bullet hinge joint error messages are likely to be false\
    \ positives. There are calls to set joint properties on joint initialization but\
    \ those don't work for the bullet case. Later on, bullet sets these properties\
    \ in it's own Init function. \n\nBut I agree the error messages are confusing\
    \ and they should not omitted on initialization.\n\nYou can test bullet hinge\
    \ joints by inserting existing models from the model database, e.g. double pendulum\
    \ or simple arm\n"
