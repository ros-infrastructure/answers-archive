    MoveIt has <del>not yet</del> been released for Melodic: see [ros/rosdistro#17942](https://github.com/ros/rosdistro/pull/17942). A `sudo apt-get install ros-melodic-moveit` should work, but you'd need to use the [shadow repositories](http://wiki.ros.org/ShadowRepository).

    However, the current consensus among maintainers is (from [here](https://github.com/ros-planning/moveit/issues/806#issuecomment-392831456)):

    > It should NOT be expected to be stable yet. Maybe calling it "beta"?

    Overall progress is tracked here: [ros-planning/moveit#806](https://github.com/ros-planning/moveit/issues/806).
