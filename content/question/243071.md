  body_markdown: "Well, generally you can disable `gcc` warnings and errors by passing\
    \ a `-Wno-..` variant of the involved warning option.\n\nIn this case that would\
    \ be `-Wno-unused-variable`.\n\nBtw, this is really not ROS specific at all, but\
    \ a simple `gcc` configuration problem, and well documented:\n\n> You can request\
    \ many specific warnings with options beginning with \u2018`-W`\u2019, for example\
    \ `-Wimplicit` to request warnings on implicit declarations. Each of these specific\
    \ warning options also has a negative form beginning \u2018`-Wno-`\u2019 to turn\
    \ off warnings; for example, `-Wno-implicit`.\n\nFrom [GCC Command Options - Warning\
    \ Options](https://gcc.gnu.org/onlinedocs/gcc/Warning-Options.html) in the GCC\
    \ manual.\n\n---\n\nEdit: suppressing these kinds of warnings and errors is typically\
    \ not a good idea. If you must do it, try to narrow the scope of the suppression\
    \ as much as possible by setting the flag on the *CMake target* using `set_target_properties(${TARGET}\
    \ PROPERTIES ...)` instead of globally using `add_definitions(..)`."
