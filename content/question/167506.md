  body_markdown: "My best guess is that when transforming from PCL2 to PCL you need\
    \ to get rid of the RGB field. \n\nIf I am not mistaken, the representation in\
    \ memory of the point cloud for PCL2 is something like:\n\n    [X0, Y0, Z0, RGB0,\
    \ X1, Y1, Z1, RGB1, ... Xn, Yn, Zn, RGBn]\n\nand for PCL is:\n\n    [X0, Y0, Z0,\
    \ X1, Y1, Z1, ... Xn, Yn, Zn]\n\nSo the only way to transform from PCL2 to PCL\
    \ is by iterating over the data on PCL2 and ignoring each 4th component (the RGB\
    \ component) and this takes time, because you can not do a simple memcpy.\n\n\
    Inside the implementation of [fromPCLPointCloud2](http://docs.pointclouds.org/1.7.0/conversions_8h_source.html#l00167)\
    \ between lines 202 and 217 you will see what I mean. "
