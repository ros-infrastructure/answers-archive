    \  Here's the process I recorded to get it to work properly.  One of the key things\
    \ I noted was no underscore in launch file or path.  I still got the issue with\
    \ the pushd, but the second command fixes it.  Hope this helps.\n \n\n       #No\
    \ underscores in the launch filename or path  \n       rosrun robot_upstart install\
    \ mystartup.launch --interface eth1\n        \n        #due to a pushd error manaul\
    \ copy\n        sudo cp mystartup.launch /etc/ros/indigo/mystartup.launch.d/\n\
    \        \n        #should start on boot, but to manually start run:\n       \
    \ mystartup.launch-start\n\n        # To Uninstall\n        sudo rm /etc/init/mystartup.launch.conf\n\
    \        sudo rm -rf /etc/ros/indigo/mystartup.launch.d/\n        sudo rm /usr/sbin/mystartup.launch-start\
    \ /usr/sbin/mystartup.launch-stop \n\n"
