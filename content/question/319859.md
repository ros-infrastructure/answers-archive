  body_markdown: "If you look at \"ROS 2.0 Target Platforms\" from REP #2000:  \n\
    http://www.ros.org/reps/rep-2000.html\n\nAs of ROS2 Crystal, you'll find the table\
    \ listing the \"Middleware Implementation Support\", where rmw_connext_cpp is\
    \ supported for \"All (targeted) Architectures except arm64\". No pre-compiled\
    \ release binaries are available for armhf (i.e. arm32v7) as its not listed among\
    \ the targeted architectures. You'd also have to contact RTI for arm32 releases\
    \ of DDS Connext, as I don't think the download for it is publicly distributed.\n\
    \nThere was a community request for arm32v7 support, however has yet to gain traction\
    \ with release maintainers:  \nhttps://discourse.ros.org/t/official-docker-images-for-ros2-crystal-and-arm32v7/6872\n\
    \nHowever, if your using a raspberry pi 3, there are arm64v8 images you could\
    \ use so you could install ROS2 from the release arm64 debains:  \nhttps://discourse.ros.org/t/installing-ubuntu-18-04-arm64v8-on-raspberry-pi-3/6094/8"
