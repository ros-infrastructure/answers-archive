  body_markdown: "When roslaunch is set to respawn a node, and it detects that that\
    \ node has stopped (for any reason), it will start a new copy of that node.\n\n\
    \ - If you kill the node by using it's pid, roslaunch will restart it\n - If you\
    \ kill the node using the process name and pkill, roslaunch will restart it\n\
    \ - If the node segfaults or stops on its own, roslaunch will restart it\n - If\
    \ you kill the node using rosnode kill, roslaunch will restart it\n\nIf you want\
    \ to stop and the node and prevent it from restarting, you need to stop roslaunch. "
