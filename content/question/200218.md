  body_markdown: "According to [this](http://ros-users.122217.n3.nabble.com/use-sim-time-td779886.html)\
    \ post on ros-users, you have to start `rosbag` with the `--clock` argument for\
    \ `use_sim_time` to work properly with `static_transform_publisher` (and probably\
    \ other nodes as well):\n\n> The output of roswtf reported the following:\n\n\
    >     \"ERROR /use_simtime is set but no publisher of /clock is present\"\n\n\
    > Setting use_simtime to true and playing the bag with the --clock option resolved\
    \ all issues. \n\nYou will probably see the same output if you start your launchfile\
    \ and then run `roswtf`.\n"
