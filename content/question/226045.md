    \ you run rosdep install rviz ?\n[Here](http://answers.ros.org/question/35741/what-is-this-rosdep-error/)\
    \ , the error is similar to yours. Look at the first answer \"*rosdep is a tool\
    \ for installing system dependencies for source packages. It does not install\
    \ the source for you*\". It means that you need to install rviz before you will\
    \ run `rosdep install rviz`. \n\nI advice you:\n\n1. to understand what [rosdep](http://wiki.ros.org/rosdep)\
    \ is\n2. to check the paths (if the error said that rosdep cant find the resources\
    \ , you need check them yourself. Maybe, you didnt install ros)\n3. to open your\
    \ terminal and run `cd` and `source /opt/ros/jade/setup.bash`\n4. to run `sudo\
    \ apt-get install ros-jade-rviz`\n\n"
