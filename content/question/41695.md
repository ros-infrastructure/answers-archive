  body_markdown: "If your robot already moves in gazebo you should do the following\
    \ steps to move your robot in rviz:\n\n1. add your robot model in rviz-> add button\
    \ -> robot model.\n2. include the p3d plugin in your robotname.gazebo.xacro file:\
    \ \n\n   <!-- p3d plugin (3D Position Interface for Ground Truth) -->\n  <xacro:if\
    \ value=\"$(arg ground_truth)\">\n    <gazebo>\n      <plugin name=\"ground_truth\"\
    \ filename=\"libgazebo_ros_p3d.so\">\n        <frameName>world</frameName>\n \
    \       <bodyName>base_footprint</bodyName>\n        <topicName>/gazebo/$(arg\
    \ robot_name)/odom</topicName>\n        <updateRate>100.0</updateRate>\n     \
    \ </plugin>\n    </gazebo>\n  </xacro:if>\n\n3. transform ground truth pose to\
    \ tf (include this in your main launch file:)\n\n    <node name=\"odom_to_tf\"\
    \ pkg=\"message_to_tf\" type=\"message_to_tf\">\n      <param name=\"odometry_topic\"\
    \ type=\"string\" value=\"/gazebo/$(arg robot_name)/odom\" />\n      <param name=\"\
    child_frame_id\" type=\"string\" value=\"base_footprint\" />\n    </node>\n\n\
    4. Now launch your project and now you should be able to select in rviz->global\
    \ options -> fixed frame world.\n\n"
