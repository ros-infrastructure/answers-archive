  body_markdown: "After you publish the four points which define a square region (to\
    \ be explored), the fifth point defines where the tree shall start (initiation\
    \ point for the detectors). This [tutorial](http://wiki.ros.org/rrt_exploration/Tutorials/singleRobot)\
    \ has a GIF image showing the sequence for publishing those five points. \n\n\
    The initial point for the detectors is not that important. It could be anywhere\
    \ in the known area (white space in the occupancy grid) of the defined region."
