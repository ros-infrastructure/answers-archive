  body_markdown: "Try running\n\n    rosrun teleop_twist_keyboard teleop_twist_keyboard.py\n\
    \n(To install : `sudo apt-get install ros-$YOURDISTRO$-teleop-twist-keyboard`)\n\
    \n It should work now. It will give additional yaw control. Or else, You can create\
    \ a separate node which publishes `/cmd_vel` topic so that the quad can use to\
    \ navigate. \nIf you can't create a node, publish the velocity using \"`rostopic\
    \ pub`\" utility\n\n    rostopic pub -1 /cmd_vel geometry_msgs/Twist -- '[0.0,\
    \ 0.0, 0.3]' '[0.0, 0.0, 0.0]'\n\nThis will give linear vertical velocity.\nTo\
    \ check: Use `rqt_plot`. Make sure that your initiated node publishes the `/cmd_Vel`\
    \ topic to Gazebo model."
