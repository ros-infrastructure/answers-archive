  body_markdown: "The `PYTHONPATH` environment variable is supposed to contain a list\
    \ of paths (or: directories).\n\nFrom [the official documentation on PYTHONPATH](https://docs.python.org/3/using/cmdline.html#envvar-PYTHONPATH)\
    \ (emphasis mine):\n\n> Augment the default search path for module files. The\
    \ format is the same as the shell\u2019s `PATH`: **one or more directory pathnames**\
    \ separated by `os.pathsep` (e.g. colons on Unix or semicolons on Windows). Non-existent\
    \ directories are silently ignored.\n> \n> In addition to normal directories,\
    \ individual `PYTHONPATH` entries may refer to zipfiles containing pure Python\
    \ modules (in either source or compiled form). Extension modules cannot be imported\
    \ from zipfiles.\n\nAs you can read: plain files are not supposed to be listed\
    \ in this environment variable.\n\nDespite its name, it's *not* \"the path to\
    \ the python executable\".\n\nIn your case, you have:\n\n - `/home/pkatsoulakos/catkin_ws/devel/lib/python3/dist-packages`\n\
    \ - `/opt/ros/noetic/lib/python3/dist-packages`\n - `/usr/bin/python3`\n - `/usr/bin/python`\n\
    \nIt's very likely `/usr/bin/python3` (and `/usr/bin/python`) are not paths, but\
    \ files.\n\nHence the complaint from `roswtf`."
