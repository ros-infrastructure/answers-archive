  body_markdown: "Hi,\n\nIf you don't need the latest version of our stacks, you can\
    \ always use the [available electric packages](http://www.ros.org/wiki/Robots/Shadow%20Robot/electric).\n\
    \nIf you need something up to date, you'll have to do a source install using [rosinstall](http://www.ros.org/wiki/rosinstall)\
    \ or [rosws](http://www.ros.org/wiki/rosinstall/Tutorials/rosws%20tutorial). Here\
    \ is a rosinstall file you can use:\n\n    - bzr:\n        uri: 'lp:sr-ros-interface'\n\
    \        local-name: shadow_robot\n\n    - bzr:\n        uri: 'lp:sr-ros-interface-ethercat'\n\
    \        local-name: shadow_robot_ethercat\n    \n    - bzr:\n        uri: 'lp:sr-config'\n\
    \        local-name: sr_config\n    \n    - bzr:\n        uri: 'lp:sr-visualization'\n\
    \        local-name: sr_visualization\n    \n    - bzr:\n        uri: 'lp:sr-teleop'\n\
    \        local-name: sr_teleop\n\nHere are a few commands to get you started with\
    \ this rosinstall file. Copy the code above into a file (let's say `/tmp/shadow_robot.rosinstall`).\n\
    \nNow let's initialise a ROS workspace (we'll create it in `~/shadow`):\n    \n\
    \    mkdir ~/shadow\n    source /opt/ros/electric/setup.bash\n    rosws init ~/shadow\
    \ /opt/ros/electric\n\nYou now have an empty workspace, we'll add the rosinstall\
    \ file to it and fetch the latest revision of the code:\n\n    source ~/shadow/setup.bash\n\
    \    rosws merge /tmp/shadow_robot.rosinstall\n    rosws up\n\nYou should now\
    \ have a workspace containing the different stacks you need. Don't forget to source\
    \ the correct setup.bash (you should probably add the line below to the ~/.bashrc)\n\
    \n    source ~/shadow/setup.bash"
