  body_markdown: "As of ROS2 `Foxy`, there are still ongoing issues/discussions regarding\
    \ this. See the following Github threads if you're interested:\n\n - [Cannot load\
    \ yaml config to composable node in dashing #715](https://github.com/ros2/rclcpp/issues/715#issuecomment-497392626)\
    \ \n - [ComposableNode.parameters with a file path does not take effect. #156](https://github.com/ros2/launch_ros/issues/156)\n\
    \n**TL;DR:** Composable Nodes are NOT treated the same as ordinary Nodes in ROS2.\
    \ The only code I've found to work is the following:\n\n    import os\n    import\
    \ yaml\n    import launch\n    from launch_ros.actions import Node\n    from ament_index_python.packages\
    \ import get_package_share_directory\n    from launch_ros.actions import ComposableNodeContainer\n\
    \    from launch_ros.descriptions import ComposableNode\n\n    def generate_launch_description():\
    \    \n\n        # Get the filepath to your config file\n        configFilepath\
    \ = os.path.join(\n            get_package_share_directory(\"my_package_name\"\
    ), \n            'my_params.yaml'\n        )                       \n\n      \
    \  # Load the parameters specific to your ComposableNode\n        with open(configFilepath,\
    \ 'r') as file:\n            configParams = yaml.safe_load(file)['my_node_name']['ros__parameters']\
    \   \n\n        # Create your ComposableNode\n        container = ComposableNodeContainer(\n\
    \            name='my_container_name',\n            namespace='',\n          \
    \  package='rclcpp_components',\n            executable='component_executable',\
    \         # This name must match your CMakelist file\n            composable_node_descriptions=[\n\
    \                ComposableNode(\n                    package='my_package_name',\n\
    \                    plugin='my_namespace::my_node_class', \n                \
    \    name='my_node_name',\n                    parameters=[configParams]\n   \
    \             )\n            ],\n            output='screen',\n        )\n\n \
    \       return launch.LaunchDescription([container])\n\nIt is honestly a real\
    \ pain that they're not treated the same way, but that's hopefully something that\
    \ will change in future ROS2 distros.\n\nAlso note that there are a lot of edits\
    \ you need to make to your CMakelists file to get your node to even compile in\
    \ a way that allows the executable to be composed. But for that you should look\
    \ at the [composition demo code](https://github.com/ros2/demos/tree/master/composition)."
