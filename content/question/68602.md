  body_markdown: "That is correct behavior. The messages are showing that device was\
    \ found and successfully calibrated.\n\nTo read coordinates and buttons states\
    \ you have to subscribe to `omni1_pose` and `omni1_button` topics respectively.\
    \ To command force to Omni use `omni1_force_feedback` topic.\n\nIf you are not\
    \ sure how to do aforementioned, please go through [beginner tutorials](http://www.ros.org/wiki/ROS/Tutorials).\n\
    \nFor a quick test you also may want to try:\n    \n    $ rostopic echo omni1_pose\n\
    \nThis will output current pose (position + orientation) of Omni end-effector\
    \ to the terminal.\n\n----------\n\n**EDIT: (summarizing comments below)**\n\n\
    On Ubuntu 12.04 and higher a JUJU Phantom Device Drivers (PDD) have to be used.\
    \ The necessary files can be found on [SensAble Developer Support Center](http://dsc.sensable.com).\n\
    \nSince original [phantom_omni](http://www.ros.org/wiki/phantom_omni) package\
    \ seems to be broken a more generic [sensable_phantom](https://github.com/bgromov/sensable_phantom)\
    \ can be used instead, both on Fuerte and Groovy. The package suppose to work\
    \ with any Phantom models (Omni, Premium 1.5, Premium 3.0 etc).\n\nTo install\
    \ the latter on Fuerte:\n\n    # Go to sandbox directory in the rosbuild workspace\n\
    \    $ roscd && cd sandbox\n\n    # Clone `rosbuild' branch of package\n    $\
    \ git clone -b rosbuild https://github.com/bgromov/sensable_phantom.git\n\n  \
    \  # Update rospack cache\n    $ rospack profile\n\n    # Compile the package\n\
    \    $ rosmake sensable_phantom\n\nP.S. Something wrong with AskBot. The link\
    \ on the `git clone` line should be without surrounding HTML-tags."
