  body_markdown: "The fix was actually to first remove the field_names from the read_points\
    \ input parameters.\n\nThat way the function output 4 values per line instead\
    \ of 3.\n\nTaking the last value of that list and doing the required bitwise operations\
    \ to retrieves the individual r,g,b values.\n\nMy code in case someone needs it\
    \ in the future is the following:\n\n    import sensor_msgs.point_cloud2 as pc2\n\
    \    import ctypes\n    import struct\n    ...............\n    # subscribe to\
    \ pointcloud topic define the function that does the parsing\n    def PointCloud(self,\
    \ PointCloud2):\n        self.lock.acquire()\n        gen = pc2.read_points(PointCloud2,\
    \ skip_nans=True)\n        int_data = list(gen)\n        for x in int_data:\n\
    \            test = x[3] \n            # cast float32 to int so that bitwise operations\
    \ are possible\n            s = struct.pack('>f' ,test)\n            i = struct.unpack('>l',s)[0]\n\
    \            # you can get back the float value by the inverse operations\n  \
    \          pack = ctypes.c_uint32(i).value\n            r = (pack & 0x00FF0000)>>\
    \ 16\n            g = (pack & 0x0000FF00)>> 8\n            b = (pack & 0x0000FF00)\n\
    \            print r,g,b # prints r,g,b values in the 0-255 range\n          \
    \              # x,y,z can be retrieved from the x[0],x[1],x[2]\n        self.lock.release()"
