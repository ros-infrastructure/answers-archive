  body_markdown: "You can try to model this combination as a revolute joint and a\
    \ prismatic joint in series with a zero-length link between them. \n\nFor example,\
    \ you would connect your base to the zero-length link using the prismatic joint\
    \ and then the child link to the zero-length link using the revolute joint."
