  body_markdown: "Had this same issue, and the fix proposed by @CIRobotics in comments\
    \ worked for me too. I'll just elaborate on the exact steps I took to resolve\
    \ it.\n\nThe issue is caused by newer versions of packages (python-pyqt5 and python-sip)\
    \ installed by the [Cura PPA](https://launchpad.net/~thopiekar/+archive/ubuntu/cura).\
    \ The following steps solved the issue for me:\n\n 1. Uninstall the newer package\
    \ versions that were installed from the PPA:\n\n    sudo apt remove python-pyqt5\
    \ pyton3-pyqt5 python-sip python3-sip sip-dev\n\n 2. Remove the PPA:\n\n    sudo\
    \ rm /etc/apt/sources.list.d/thopiekar-ubuntu-cura-xenial.list\n    sudo apt update\n\
    \n 3. Reinstall `ros-kinetic-desktop-full`\n\n    sudo apt install ros-kinetic-desktop-full\
    \ \n\n 4. Check with `sudo apt autoremove` for any other packages that were broken\
    \ by the downgrade and install or autoremove them as necessary.\n\nA more elegant\
    \ solution might be to use the `ppa-purge` tool as described [here](https://askubuntu.com/questions/307/how-can-ppas-be-removed),\
    \ however, I discovered that link after I had already fixed the issue, so I could\
    \ not try it out.\n\nOf course, the drawback of the above solution is that you\
    \ will not be able to use the Cura software on your Xenial system. I'm dual-booting\
    \ Windows, so I'll just install the Windows version. I'm currently not aware of\
    \ a more elegant solution."
