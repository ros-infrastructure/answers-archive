  body_markdown: "Not completely what are looking for, but here is one way to do in\
    \ Python. In Python, you can use `get_msg_class` from `ros2topic.api` to get the\
    \ message type and then subscribe to the topic. Here is an example:\n\n    import\
    \ rclpy\n    from rclpy.node import Node\n    from ros2topic.api import get_msg_class\n\
    \    \n    \n    class TestSubscriber(Node):\n        def __init__(self):\n  \
    \          super().__init__('test_subscriber')\n            message_type = get_msg_class(self,\
    \ '/topic_name', include_hidden_topics=True)\n            print('Message type:',\
    \ message_type)\n            self.create_subscription(message_type, '/topic_name',\
    \ self.on_message_received, 1)\n    \n        def on_message_received(self, message):\n\
    \            print(message)\n    \n    \n    def main(args=None):\n        rclpy.init(args=args)\n\
    \        test_subscriber = TestSubscriber()\n        rclpy.spin(test_subscriber)\n\
    \        test_subscriber.destroy_node()\n        rclpy.shutdown()\n    \n    \n\
    \    if __name__ == '__main__':\n        main()\n\n\nTest it by running e.g.:\n\
    \n    ros2 topic pub /topic_name std_msgs/String '{ data: test_value }'"
