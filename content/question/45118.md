  body_markdown: "As this node is a bit complex to launch and requires remapping and\
    \ argument passing. I would suggest that you write a roslaunch file. The syntax\
    \ is way easier to understand than the command line arguments (converting '~'\
    \ to '_' where needed is tricky).\n\nHere is a a roslaunch file adapted to your\
    \ needs:\n\n    <?xml version=\"1\" encoding=\"utf-8\"?>\n    <launch>\n    <node\
    \ pkg=\"nodelet\" type=\"nodelet\"\n          args=\"standalone image_proc/crop_decimate\"\
    \n          name=\"my_decimator\">\n      <param name=\"x_offset\" type=\"int\"\
    \ value=\"1\" />\n      <param name=\"y_offset\" type=\"int\" value=\"1\" />\n\
    \      <param name=\"width\" type=\"int\" value=\"639\" />\n      <param name=\"\
    height\" type=\"int\" value=\"439\" />\n\n      <!-- remap input topics -->\n\
    \      <remap from=\"camera/image_raw\" to=\"/image_rect_color\"/>\n      <remap\
    \ from=\"camera/image_info\" to=\"/gscam/camera_info\"/>\n\n      <!-- remap output\
    \ topics -->\n      <remap from=\"camera_out/image_raw\" to=\"/camera_crop/image_rect_color\"\
    />\n      <remap from=\"camera_out/image_info\" to=\"/camera_crop/camera_info\"\
    />\n    </node>\n    </launch>\n\nPlease see [the roslaunch wiki page](http://ros.org/wiki/roslaunch/XML)\
    \ for more information.\n\nHere is a complete ROS launch file which works on my\
    \ computer (Ubuntu 10.04 / Electric):\n\n    <?xml version=\"1\" encoding=\"utf-8\"\
    ?>\n    <launch>\n    \n    <node pkg=\"gscam\" type=\"gscam\"\n          name=\"\
    gscam\"\n          cwd=\"node\">\n      <env name=\"GSCAM_CONFIG\"\n         \
    \  value=\"v4l2src device=/dev/video0 ! video/x-raw-rgb,framerate=30/1 ! ffmpegcolorspace\"\
    />\n    \n    </node>\n    \n    <node pkg=\"image_proc\" type=\"image_proc\"\n\
    \          ns=\"gscam\"\n          name=\"image_proc\">\n    </node>\n    \n \
    \   <node pkg=\"nodelet\" type=\"nodelet\"\n          args=\"standalone image_proc/crop_decimate\"\
    \n          name=\"my_decimator\">\n      <param name=\"x_offset\" type=\"int\"\
    \ value=\"1\" />\n      <param name=\"y_offset\" type=\"int\" value=\"1\" />\n\
    \      <param name=\"width\" type=\"int\" value=\"639\" />\n      <param name=\"\
    height\" type=\"int\" value=\"439\" />\n    \n      <!-- remap input topics -->\n\
    \      <remap from=\"camera/image_raw\" to=\"/gscam/image_rect_color\"/>\n   \
    \   <remap from=\"camera/image_info\" to=\"/gscam/camera_info\"/>\n    \n    \
    \  <!-- remap output topics -->\n      <remap from=\"camera_out/image_raw\" to=\"\
    /camera_crop/image_rect_color\"/>\n      <remap from=\"camera_out/image_info\"\
    \ to=\"/camera_crop/camera_info\"/>\n    </node>\n    </launch>\n"
