    I don't know if something like this already exists but I suggest you to use Octomap to have a collisionMap. Maybe with that, you can then isolate obstacles easier. See this [link](http://www.ros.org/wiki/octomap_server)

    You will need to have a filter to erase the ground, this octomap server has this too.

    EDIT: If you know the object, you can use [tabletop_object_detector](http://www.ros.org/wiki/tabletop_object_detector) but I don't believe this is what you are looking for.
