    You cannot publish arbitrary C++ objects to ROS topics, but only those for which a msg definition has been generated. See the [tutorials on msg/srv](http://www.ros.org/wiki/ROS/Tutorials/CreatingMsgAndSrv). Some conversions between Eigen and corresponding msg types are available in the [eigen_conversions](http://ros.org/wiki/eigen_conversions) package. See also the [code API](http://ros.org/doc/groovy/api/eigen_conversions/html/eigen__msg_8h_source.html). Also included is a conversion from Eigen Matrix to Float64MultiArray (but not the other way around for some reason).
