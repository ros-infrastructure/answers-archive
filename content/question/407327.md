    This TypeError happens if you try to run python2 code in python3. <del>It is a hint that you are running the wrong source code for the package. You need to do a git checkout of the source code for noetic. In this package, that git branch is named `noetic-devel`.</del>

    The underlying issue here is that as of Oct 2022 the rosserial_xbee package has not been updated for python3, so it doesn't work in noetic. Additionally, the rosserial maintaniners have accepted other changes into the git repo which break it further.
