  body_markdown: "to publish an array of string, namely string_list, i do that:\n\n\
    \    std::vector<std::string> string_list\n\nSince is not possible (someone correct\
    \ me if i am wrong) to publish it like it is, create a custom message, creating\
    \ a .msg file into then msg directory of your package, like:\n\n    std::vector<std::string>\
    \ strings\n\n and do everything needed for compiling it and generate the headers\
    \ (have a look to [wiki.ros](http://wiki.ros.org/ROS/Tutorials/WritingPublisherSubscriber%28c%2B%2B%29)).\
    \ \nthen, include the header in your .cpp file and create the publisher\n\n  \
    \   ros::Publisher string_list_pub = n.advertise<my_pkg::cst_msg>(\"/string_list\"\
    ,1)\nTo access the string values, if a ` my_pkg::cst_msg msg` has been defined,\
    \ do it as msg.strings[i]\n\nCiao"
