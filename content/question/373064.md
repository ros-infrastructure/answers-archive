  body_markdown: "hi @vignesh_93,\n\nWith the PointCloud2 message type you need to\
    \ tell it what fields you want within it. It [was written in a way](http://docs.ros.org/en/noetic/api/sensor_msgs/html/msg/PointCloud2.html)\
    \ so that PointCloud2 could be used for many different types of pointclouds (xyz,\
    \ xyzi, xyzrgb, etc.).\n\n[I just recently contributed an example](https://github.com/ros/ros_tutorials/tree/noetic-devel/rospy_tutorials/010_publish_pointcloud2)\
    \ on how to publish a pointcloud2 message. You should be able to use that example\
    \ to set the fields correctly for your message type (x, y, z I think).\n\n   \
    \ #!/usr/bin/env python\n    from __future__ import print_function\n    \n   \
    \ import rospy\n    import numpy as np\n    from sensor_msgs import point_cloud2\n\
    \    from sensor_msgs.msg import PointCloud2\n    from sensor_msgs.msg import\
    \ PointField\n    from std_msgs.msg import Header\n    \n    width = 100\n   \
    \ height = 100\n    \n    def publishPC2(count):\n        fields = [PointField('x',\
    \ 0, PointField.FLOAT32, 1),\n                  PointField('y', 4, PointField.FLOAT32,\
    \ 1),\n                  PointField('z', 8, PointField.FLOAT32, 1),\n        \
    \          PointField('intensity', 12, PointField.FLOAT32, 1)]\n    \n       \
    \ header = Header()\n        header.frame_id = \"map\"\n        header.stamp =\
    \ rospy.Time.now()\n    \n        x, y = np.meshgrid(np.linspace(-2,2,width),\
    \ np.linspace(-2,2,height))\n        z = 0.5 * np.sin(2*x - count/10.0) * np.sin(2*y)\n\
    \        points = np.array([x,y,z,z]).reshape(4,-1).T\n    \n        pc2 = point_cloud2.create_cloud(header,\
    \ fields, points)\n        pub.publish(pc2)\n    \n    if __name__ == '__main__':\n\
    \        rospy.init_node('pc2_publisher')\n        pub = rospy.Publisher('points2',\
    \ PointCloud2, queue_size=100)\n        rate = rospy.Rate(10)\n    \n        count\
    \ = 0\n        while not rospy.is_shutdown():\n            publishPC2(count)\n\
    \            count += 1\n            rate.sleep()\n\nOnce you identify your fields,\
    \ you should then [use the `create_cloud` function](https://github.com/ros/ros_tutorials/blob/74cc182dce2bb7d221052d1d45fe4ad0e7705843/rospy_tutorials/010_publish_pointcloud2/publish_pointcloud2.py#L28)\
    \ rather than the one you are using above.\n\nHope this helps."

      @vignesh_93 I'll try to answer most of your questions:

      1. `count` is just an index of how many times the publisher is triggered by the rate (10Hz above)
      2. In the example above we are not reading any values but rather packing values into a message and then publishing the message.
      3. Yes we are just making a grid of points and using those for x and y
      4. z is calculated to be just a value from 1 to -1 based on its position in the grid.
      5. The `sin()` is used to just keep the values between 1 and -1
      6. The count in there is just to "move" the waves across the grid to give the pointcloud the perception of moving waves through water.
