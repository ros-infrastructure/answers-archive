    1. That launch file runs the cloud nodelet in a velodyne_nodelet manager process. The [cloud nodelet is built](https://github.com/ros-drivers/velodyne/blob/master/velodyne_pointcloud/src/conversions/CMakeLists.txt#L7) using [cloud_nodelet](https://github.com/ros-drivers/velodyne/blob/master/velodyne_pointcloud/src/conversions/cloud_nodelet.cc).cc and [convert.cc](https://github.com/ros-drivers/velodyne/blob/master/velodyne_pointcloud/src/conversions/convert.cc).

    2. The constructor must advertise the topic before the callback can publish to it.

    3. An example of reading the individual points in the message is here in [RingColors::convertPoints](https://github.com/ros-drivers/velodyne/blob/master/velodyne_pointcloud/src/conversions/colors.cc#L63), a method that reads /velodyne_points and publishes a colored cloud containing the same points in /velodyne_rings.

    **EDIT**: To run the Ring Colors nodelet, you can create your own launch file, something like this (*untested*):

        <include file="$(find velodyne_pointcloud)/launch/32e_points.launch" />
        <node pkg="nodelet" type="nodelet" name="ring_colors_nodelet"
              args="load velodyne_pointcloud/RingColorsNodelet velodyne_nodelet_manager" />
