    \ is no need to 'reconnect' to a roscore.  The roscore acts as a DNS server --\
    \ it just stores lookup information.   There is no connection that is maintained\
    \ between your node and the roscore.   \n\nIt would be helpful if you described\
    \ why you believe you need to reconnect."
