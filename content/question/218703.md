    \ it (`$ mv ~/.ros/rtabmap.db  ~/.ros/rtabmap.db.back`).\n\nYou can start new\
    \ with `$ roslaunch rtabmap_ros rgbd_mapping.launch rtabmap_args:=\"--delete_db_on_start\"\
    ` at each start or by deleting the database `~/.ros/rtabmap.db`. \n\ncheers"
