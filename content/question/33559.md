  body_markdown: |-
    You do not need to create nodes manually. Instead, build a class (for example, a View) that implements the [`NodeMain`](http://code.google.com/p/rosjava/source/browse/rosjava/src/main/java/org/ros/node/NodeMain.java) interface. In your activity's `init(NodeMainExecutor nmExecutor)` method, call

    `nmExecutor.execute(yourView, yourNodeConfig);`

    as shown on lines 48 and 51 of the [example activity](http://docs.rosjava.googlecode.com/hg/android_core/html/getting_started.html#using-rosactivity).

    Your class should implement the methods from both `NodeMain` and [`NodeListener`](http://code.google.com/p/rosjava/source/browse/rosjava/src/main/java/org/ros/node/NodeListener.java) as [shown](http://docs.rosjava.googlecode.com/hg/rosjava_core/html/getting_started.html#creating-nodes) in the rosjava documentation. You will receive the actual node object in your `onStart(ConnectedNode node)` method; you can add topic and service interactions there.

    Note that you should NOT rely on `onStart()` running immediately; if you want to interact with the node from your activity (*e.g.*, to call a service you have created), check to make sure the node has actually been created first.
