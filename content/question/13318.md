    \n     <param name=\"robot_description\" command=\"$(find xacro)/xacro.py $(find\
    \ walking_excavator_urdf)/xacro_manzi/walking_excavator.urdf.xacro\" />\n    \
    \ <node name=\"spawn_urdf\" pkg=\"gazebo_ros\" type=\"spawn_model\" args=\"-param\
    \ robot_description -urdf -x 0 -y 0 -z 1 -model robot\" /> \n\n\nso from xacro/urdf\
    \ you can directly load in ROS parameter, then use c++ code..\n\n\n    ros::NodeHandle\
    \ node;\n    std::string robot_desc_string;\n    node.param(\"robot_description\"\
    , robot_desc_string, std::string());\n    if (!kdl_parser::treeFromString(robot_desc_string,\
    \ my_tree)){\n      ROS_ERROR(\"Failed to construct kdl tree\");\n      return\
    \ false;\n    }\n\nThis way you can get the tree, can verify with \n\n    \n \
