    The only interface MoveIt! uses to communicate with the robot in gazebo is the ros-actions specified in [config/controllers.yaml](https://github.com/Sindhurakshak/SCARA/blob/master/sr_scara_hx_moveit_config/config/controllers.yaml).
    So at least there *has* to be one message sent via the topic `/sr_scara_hx/sr_scara_hx_joint_controller/follow_joint_trajectory/goal` when you start to execute a trajectory.
