  body_markdown: "1. No, you don't need to be in your workspace to run `roslaunch`,\
    \ you can `roslaunch` from anywhere.\n2. `catkin` is used to create and build\
    \ packages and `roslaunch` starts up nodes, sets parameters, etc.\n3. As @gvdhoorn\
    \ pointed out in the comments, catkin \n\n > is a wrapper around CMake that makes\
    \ building entire ROS *workspaces* easier / feasible. Package management is expressly\
    \ not part of its responsibilities.\n\n4. A node is a program and a `catkin` package\
    \ is a place that houses nodes and certain files.\n5. See #2."
