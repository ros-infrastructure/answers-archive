> sudo apt-get update

> port_name = rospy.get_param('~port','/dev/ttyUSB0')
> baud = int(rospy.get_param('~baud','57600'))

**.. Procedure A**
Edit the "arduinoHardware.h" file to match according to the "all.launch" file baud rate values

**.. Procedure B**
