    You can use point cloud library to read the incoming sensor_msgs::PointCloud/2. An [example can be found on the official ros tutorial](http://wiki.ros.org/pcl/Tutorials) page. Once you have the data, you can use `savePCDFileASCII` to save it in a format you like. Just FYI: point clouds are usually stored in .ply, .pcd, .sty or .obj formats.

        pcl::io::savePCDFileASCII ("test_pcd.pcd", cloud);
