    Ok, so the catch was that I'm using xacro instead of urdf... This [video](https://www.youtube.com/watch?v=RcrgC9o9A6A) explains everything in details, in short - when you use xacro, it will be converted to sdf where collision names will be completely different (in my case <code>bumper_collision</code> turned into <code>chassis_fixed_joint_lump__bumper_collision_collision_1</code>) so to make it work:

    Convert xacro to urdf (yes, "xacro xacro ", it's not a typo):
    <pre>rosrun xacro xacro test.urdf.xacro > test.urdf</pre>
    <br/>Convert urds to sdf:
    <pre>gz sdf -p test.urdf > test.sdf</pre>

    <br/>Get the right collision name from sdf file and use it in xacro for sensor collision
    <pre><code>&lt;collision&gt;chassis_fixed_joint_lump__bumper_collision_collision_1&lt;/collision&gt;</code></pre>
    <br/>
    Hopefully it will help somebody to not run into the same issue I did
