  body_markdown: "Yes, it is possible! \nIn order to control your robot in Gazebo\
    \ without setting up controllers, you have to follow these steps:\n\n1. Convert\
    \ your robot to a Gazebo actor. \nAn actor is a model that is not affected by\
    \ Gazebo's physics engine.\nTo this end, convert your URDF file to SDF and then\
    \ replace the `<model>` tag by `<actor>`.\n2. Write a Gazebo plugin that listens\
    \ to ROS transformations and sets the poses of the actor links accordingly.\n\
    3. Include a reference to your plugin in the SDF.\n4. Upload the SDF to Gazebo.\n\
    \nYou can do all the steps yourself, or you can download the [gazebo_tf_injector](https://github.com/acschaefer/gazebo_tf_injector)\
    \ package, which contains both the Gazebo plugin and a script to convert your\
    \ URDF to an actor SDF.\nIt also comes with lots of documentation and a ready-to-use\
    \ example, which should get you started quickly."
