  body_markdown: "Based on this [StackOverflow Q&A](https://stackoverflow.com/questions/22504708/yaml-cpp-new-api-nested-map-sequence-combinations-and-iteration),\
    \ you can use this piece of code:\n\n    YAML::Node root = /* ... */;\n    YAML::Node\
    \ node = root[\"Node\"];\n    \n    // We now have a map node, so let's iterate\
    \ through:\n    for (auto it = node.begin(); it != node.end(); ++it) {\n     \
    \ YAML::Node key = it->first;\n      YAML::Node value = it->second;\n      if\
    \ (key.Type() == YAML::NodeType::Scalar) {\n        // This should be true; do\
    \ something here with the scalar key.\n      }\n      if (value.Type() == YAML::NodeType::Map)\
    \ {\n        // This should be true; do something here with the map.\n      }\n\
    \    }\n\nto parse nested YAML like this one below\n\n    Node:\n        Foo:\n\
    \          f1 : one\n          f2 : two\n        Bar:\n          b1 : one\n  \
    \        b2 : two\n\nOther nice SO answer is [here](https://stackoverflow.com/questions/48568328/yaml-cpp-parsing-nested-maps-and-sequences-error)\
    \ - code snippet below.\n\n\n\n> This loop:\n> \n>     for (YAML::const_iterator\
    \ ti = attributes.begin(); ti !=\n> attributes.end(); ++ti)\n> \n> is iterating\
    \ over a map node.\n> Therefore, the iterator points to a\n> key/value pair. Your\
    \ next line:\n> \n>     const YAML::Node& frame = *ti;\n> \n> dereferences it\
    \ as a node. Instead,\n> you need to look at its key/value\n> nodes:\n> \n>  \
    \   const YAML::Node& key = ti->first;\n>     const YAML::Node& value = ti->second;\n\
    > \n> `yaml-cpp` allows iterators to both\n> point to nodes and key/value pairs\n\
    > because it can be a map or a sequence\n> (or a scalar), and it's implemented\
    \ as\n> a single C++ type."
