    > Can any node publish a message to the topic `/rosout`?

    Sure: every node can publish to any topic

    > which nodes publish messages to the topic `/rosout`?

    Any node using any of the [`ClientLibraries`](http://wiki.ros.org/Client%20Libraries) (which means: every).
    Check out [this section](http://wiki.ros.org/rosout#Client_APIs) as well as the links. There it is detailed how ROS logging (e.g. using `rospy.log*` and `ROS_*` end up in `/rosout`).
