  body_markdown: |-
    Looks like Ixxat supports SocketCAN for [some devices](https://www.ixxat.com/support/file-and-documents-download/drivers/socketcan-driver).
    If you can use that, everything should work as [usual](http://wiki.ros.org/socketcan_interface).

    If not, you could provide your own driver plugin for `canopen_motor_node` (for motor drives).<BR>
    Unfortunately, there is still no support for these plugins in the [bridge nodes](http://wiki.ros.org/socketcan_bridge) ([Issue](https://github.com/ros-industrial/ros_canopen/issues/252)).
