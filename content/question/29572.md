  body_markdown: "So, the topic `/move_base_simple/goal` should have the message type\
    \ [PoseStamped](http://ros.org/doc/api/geometry_msgs/html/msg/PoseStamped.html)\n\
    \nLooking at the message description, we can see that each incoming message should\
    \ have a `header` field, containing the sequence number, time stamp, and coordinate\
    \ frame_id.  Additionally, each incoming message should have a `pose` field, which\
    \ describes the cartesian (x,y,z) position and the quaternion (x,y,z,w) orientation\
    \ of the robot.\n\nI'm going to give you some example code in Python, but this\
    \ could just as easily be done in C++.\n\n    #!/usr/bin/env python\n    import\
    \ roslib; roslib.load_manifest('YOUR_PACKAGE_NAME_HERE')\n    import rospy\n \
    \   import tf.transformations\n    from geometry_msgs.msg import PoseStamped\n\
    \n    def callback(msg):\n        rospy.loginfo(\"Received at goal message!\"\
    )\n        rospy.loginfo(\"Timestamp: \" + str(msg.header.stamp))\n        rospy.loginfo(\"\
    frame_id: \" + str(msg.header.frame_id))\n        \n        # Copying for simplicity\n\
    \        position = msg.pose.position\n        quat = msg.pose.orientation\n \
    \       rospy.loginfo(\"Point Position: [ %f, %f, %f ]\"%(position.x, position.y,\
    \ position.z))\n        rospy.loginfo(\"Quat Orientation: [ %f, %f, %f, %f]\"\
    %(quat.x, quat.y, quat.z, quat.w))\n\n        # Also print Roll, Pitch, Yaw\n\
    \        euler = tf.transformations.euler_from_quaternion([quat.x, quat.y, quat.z,\
    \ quat.w])\n        rospy.loginfo(\"Euler Angles: %s\"%str(euler))  \n    \n \
    \   def listener():\n        rospy.init_node('goal_listener', anonymous=True)\n\
    \        rospy.Subscriber(\"/move_base_simple/goal\", PoseStamped, callback)\n\
    \        rospy.spin()\n    \n    if __name__ == '__main__':\n        listener()\n\
    \nIn this example, we create a node called `goal_listener` that subscribes to\
    \ the `/move_base_simple/goal` topic.  We can then create a callback function\
    \ (called `callback`), which accepts the message as a parameter `msg`.\n\nFrom\
    \ here, it is as simple as reading the named fields from the message, and using\
    \ that data in whatever way that you want in your application.  My example shows\
    \ reading all of the fields from the PoseStamped message.\n\nHope this helps."
