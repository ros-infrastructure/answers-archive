  body_markdown: "I think you can do this by using the [Master API](http://wiki.ros.org/ROS/Master_API)\
    \ to retrieve the list of service servers (using `getSystemState(..)`) and then\
    \ filtering that list by looking for all providers of any of the typical Nodelet\
    \ `manager` services ([docs](http://docs.ros.org/lunar/api/nodelet/html/index-msg.html)).\n\
    \nAfter you have that list, you could use the same approach as in #q271776 to\
    \ get their PIDs.\n\nTo figure out which nodelets are running in which specific\
    \ `manager`s, you should be able to just ask the node by invoking the `list` service\
    \ and looking at the result.\n\nAs in #q271776, the `rosgraph`, `rosnode` and\
    \ `rosservice` libraries can help, but most of it is XMLRPC, so could be done\
    \ without any ROS dependency. Invoking the service might be harder without any\
    \ ROS, but not undoable.\n\n---\n\nEdit: perhaps the `lookupService(..)` could\
    \ also be used, but I'm not sure whether the documentation for that is correct:\n\
    \n> Lookup all provider of a particular service. \n\nthis suggests that *all*\
    \ provider(s) will be returned, but the return type docs say this:\n\n> (code,\
    \ statusMessage, serviceUrl)\n> \n> service URL is provides address and port of\
    \ the service. Fails if there is no provider. \n\nSo that implies only a single\
    \ `serviceUrl` will be returned.\n\n---\n\nEdit: `rosservice find <service-type>`\
    \ does something similar, so you could probably take a look at that."

Is there a way to get the process ID of the process a ROS nodelet is running in (preferably by ROS nodelet name)? This question relates to this quiestion about [how to get the process id of a ROS node](https://answers.ros.org/question/271776/how-can-i-identify-ros-node-processes/).

With `pgrep` one can get a list of pids of nodelets if they are running in separate processes but cannot determine which pid corresponds to which nodelet:

    pgrep nodelet
    1269
    1326
    1555
    1559
    1563
    1592
