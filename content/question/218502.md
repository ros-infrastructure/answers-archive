    For DRC we developed a rviz Display type that takes in a Image message and [shape_msgs/Mesh](http://docs.ros.org/jade/api/shape_msgs/html/msg/Mesh.html). It then texture maps the image on the mesh using the OGRE texturing API. So if you publish a flat rectangle mesh to it and simultaneously select the appropriate image topic, you should basically get what you're looking for. Unfortunately, the Mesh message type doesn't provide a frame_id and the plugin code currently lives in a pretty big repo, so I'd recommend copying the plugin code and implementing your own slightly modified version of the plugin.

    Code [here](https://github.com/team-vigir/vigir_ocs_common/tree/master/vigir_ocs_rviz_plugins/vigir_ocs_rviz_plugin_mesh_display_custom).
