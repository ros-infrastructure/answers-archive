    \ tag in my xacro file.\n\nThe descripiton is above, which was copy from [wiki](http://wiki.ros.org/urdf/XML/joint#Elements)\n\
    \n> <limit> (required only for revolute\n> and prismatic joint)\n> \n> An element\
    \ can contain the following\n> attributes: lower (optional, defaults\n> to 0)\n\
    > \n> An attribute specifying the lower\n> joint limit (radians for revolute\n\
    > joints, meters for prismatic joints).\n> Omit if joint is continuous. upper\n\
    > (optional, defaults to 0)\n> \n> An attribute specifying the upper\n> joint\
    \ limit (radians for revolute\n> joints, meters for prismatic joints).\n> Omit\
    \ if joint is continuous. effort\n> (required)\n> \n> An attribute for enforcing\
    \ the maximum\n> joint effort\n\nIt seems that it is necessary to add a effort&velocity\
    \ tag into a rotate/continous joint. \n\nEven if I miss any one of these tags\
    \ in joints, it will also cause this issue."
