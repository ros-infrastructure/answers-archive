  body_markdown: "For anyone else who might need to do this:\n\nIn **CMakeLists.txt**\
    \ I had (among other things):\n\n    find_package(catkin REQUIRED COMPONENTS \
    \   \n      ros_arduino_msgs    \n    )\n\nIn **package.xml** I added:\n\n   \
    \ <build_depend>ros_arduino_msgs</build_depend>\nand\n\n    <run_depend>ros_arduino_msgs</run_depend>\n\
    \nAnd in my **C++ file** I had (among other things):\n\n    #include \"ros_arduino_msgs/Digital.h\"\
    \n    \n    int start_val = 0;\n    \n    void start(const ros_arduino_msgs::DigitalConstPtr&\
    \ msg) {\n        start_val = msg->value;\n    }\n    \n    int main(int argc,\
    \ char * argv[]) {\n        ros::init(argc, argv, \"test_node\");\n    \n    \
    \    ros::NodeHandle nh;\n        ros::Subscriber start_sub = nh.subscribe(\"\
    /arduino/sensor/start_led\",1,start);\n    \n        while(start_val==0) {\n \
    \           ros::spinOnce();\n        }\n\n        //do other things\n    }\n\
    I was just using this within another program to make sure it didn't start until\
    \ one of my LED values was 1."
