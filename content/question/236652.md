    When you run a python node, then ROS just runs the python script. it's the same as if you were to run it in the command line:

        > ./my_node.py

    So no, ROS does not compile anything. If you want to use cython, you can have a look here: https://github.com/marcoesposito1988/cython_catkin_example

    I did not try it myself.
