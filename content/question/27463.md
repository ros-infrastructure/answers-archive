    Main change probably affecting you is the update from sdformat9 to sdformat12 which, indeed, has some improvements that generates some incompatibilities. [SDFormat has its own migration guide](https://github.com/ignitionrobotics/sdformat/blob/sdf12/Migration.md). I sometimes found useful to run `ign sdf --check` (ignition-tools package) to get some hints about what's going on.

    Another useful resource is the SDFormat spec. In your case http://sdformat.org/spec?ver=1.8&elem=material says that ambient should in range 0,1 and you are using 2.0 in your file. This is not the only problem but the rest can be fixed using error output and spec.

    Good luck!
