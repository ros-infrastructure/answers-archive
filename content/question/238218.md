    The problem is that the compiler expects you to have implemented *all* methods declared in `rviz::Tool`. If you don't, you've essentially created something called an *abstract base class*.

          class RvizWaypointAssigner : public rviz::Tool
          {
          public:
            ...
            virtual void activate() ;
            virtual void deactive() ;
            ...
          };

    Looking at the `rviz::Tool` [API docs](http://docs.ros.org/jade/api/rviz/html/c++/classrviz_1_1Tool.html), the last method is actually called `deactivate()`, not `deactive()` (see the [docs](http://docs.ros.org/jade/api/rviz/html/c++/classrviz_1_1Tool.html#a6372521438aad7907332100638173b31) as well).
