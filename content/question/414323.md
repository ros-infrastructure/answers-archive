**PROBLEM**
I’m new to ROS and MoveIt.  I have very carefully followed the MoveIt tutorials and have run into the following two problems (one major and one minor).  Please note that I have built the system three times, and in each instance, I’ve run into the same issues. *Thanks in advance for any help that you can provide!*

**Major Problem**
When I run “roslaunch panda_moveit_config demo.launch rviz_tutorial:=true” RViz starts normally. Then when I select “MotionPlanning” as the  DisplayType I get the following display in RViz.  Note for the Plannging Group I specified “panda_arm”.  Only the manipulator is shown, not the Panda arm.
[panda_arm](https://drive.google.com/file/d/1nVK4jp9ewrnb-3BMvbdAqyb7X4ZQUhRf/view?usp=share_link)

When I change the Planning Group to use “panda hand”, nothing is displayed.
[panda_hand](https://drive.google.com/file/d/1NIJpIIGFwIW8mAnQe6apdYVDWmPz4vCe/view?usp=share_link)

Finally, when I change the Planning Group to use “panda_manipulator”, I see the manipulator and not the arm.  
[panda_manipulator](https://drive.google.com/file/d/1ti-3MDMi6Q9pyBf136nGjj2MqCpfxlKe/view?usp=share_link)

**Minor Problem**
In the first and the third instances, the X, Y, and Z orientation controls appear “oversized” in relation to the manipulator.  Is there any way to control the size of the orientation controls.

**ANALYSIS**
In looking at several posts, the following information was confirmed from the RViz Display:
[RViz Display Information](https://drive.google.com/file/d/1Kj55EXpFh6Yy0f9IoyifG7TNyMUbhXnt/view?usp=share_link)

To see if the Panda arm was actually defined, I turned on TF Transform Hierarchy.  In the TF section of the display I also unchecked Show Names and Show Axis, while leaving Show Arrows checked and got the following display.
[Transform Hierarchy](https://drive.google.com/file/d/15IP0MR4jU_UrlJOm1JTlh6fldy3nLb3H/view?usp=share_link)

To further see if the arm was defined in the RobotModel I checked “Collision Enabled” and got the following display.
[Collision Enabled](https://drive.google.com/file/d/1wRMKxhDNeD4pQGNwXGRxBaQiXFrKSVtV/view?usp=share_link)
