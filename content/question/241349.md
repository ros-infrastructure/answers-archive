  body_markdown: |-
    `exec "$@"` causes the shell to exec the arguments that were passed in.

    In this case, the ENTRYPOINT script is setting up the ROS environment and then executing the command that you gave it.

    The [docker documentation for ENTRYPOINT](https://docs.docker.com/engine/reference/builder/#/entrypoint) goes into more detail about what ENTRYPOINT files are and how they work.
