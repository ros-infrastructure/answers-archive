  body_markdown: "You won't get any significant  performance or usage difference with\
    \ both. I'd suggest disabling display manager from startup to improve performance\
    \ (below 18.04 tutorial has a link)\n\n16.04 is the mostly used/tested one on\
    \ Rpi. There are some [tutorial](http://thomas-messmer.com/index.php/14-free-knowledge/howtos/86-ros-melodic-on-raspberry-pi-3)s\
    \ about how to install ROS on 18.04 too but not as much as 16.04 ones. \n\nIf\
    \ you are going to write your simple nodes from scratch only, I'd suggest 18.04,\
    \ but if you are going to use packages that are older, and if you want less trouble,\
    \ go with 16.04 installations. \n\nIf you look at page history, you can see that\
    \ people updated [Installing ROS Kinetic on the Raspberry Pi (16.04)](http://wiki.ros.org/ROSberryPi/Installing%20ROS%20Kinetic%20on%20the%20Raspberry%20Pi)\
    \ in 2018 couple of times. Which means, it's still actively being used by some\
    \ people."
