    The problem seems to be on the UV mapping of your OBJ file.

    We usually use MTL files to set the material of OBJ meshes, see an example [here](https://app.ignitionrobotics.org/openrobotics/fuel/models/Ambulance). I would try to export an MTL file together with your OBJ from the modelling software you used.
