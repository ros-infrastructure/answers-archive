    You should be able to add a model in your world file, with code similar to this:

        <world>
        ...
            <include>
                <uri>model://my_model</uri>
                <pose>2.5 1.5 0.5 0 0 0</pose>
            </include>
        </world>

    Where the numbers represents the global pose and orientation.
