    \ \n\nPlease note that the files you are seeking are not present in /opt/ros/diamondback.\
    \ The debian build process removes the build subdirectory when creating the debian\
    \ archives. That means you need to check out the stack gazebo_simulation from\
    \ source. It is also important that you first call `rosmake gazebo` to actually\
    \ download and extract the gazebo sources.\n\nTo do so, the easiest way is to\
    \ use rosinstall and create an overlay and then check out the source. The following\
    \ steps should work.\n\n    source /opt/ros/diamondback/setup.bash\n    sudo apt-get\
    \ install python-setuptools\n    sudo easy_install rosinstall\n    mkdir -p ~/ros-gazebo/workspace\n\
    \    rosinstall ~/ros-gazebo /opt/ros/diamondback ~/ros-gazebo/workspace\n   \
    \ cd ~/ros-gazebo/workspace\n    svn co https://code.ros.org/svn/ros-pkg/stacks/simulator_gazebo/tags/diamondback\
    \ simulator_gazebo\n    source ~/ros-gazebo/setup.bash\n    rosmake gazebo_worlds\n\
    \nNow you should be able to find the sources you want in ~/ros-gazebo/workspace/simulator_gazebo/gazebo/build/gazebo/server/physics\n"
