    Could you clarify which particular OS you are using? Because this (emphasis mine):

    > if I look inside http://packages.ros.org/ros/ubuntu/dists/**bionic**/main/**binary-armhf**/Packages

    confuses me.

    The ROS buildfarm does not build packages of ROS Kinetic for Ubuntu Bionic, no matter the architecture, as ROS Kinetic is only supported on Ubuntu Xenial. Only ROS Melodic is built for Ubuntu Bionic. See also `REP-3` ([Platforms by Distribution: Kinetic Kame (May 2016 - May 2021)](http://www.ros.org/reps/rep-0003.html#kinetic-kame-may-2016-may-2021))

    As for support of `armhf` platforms: see #q301220 for a more extensive answer, but there are no binary packages available of ROS Kinetic for `armhf` on Melodic.

    >  Seems like all the kinetic packages have disappeared from the repo

    In reality I believe these packages have never been there.

    If you want to check: [xenial/main/binary-amd64/Packages](http://packages.ros.org/ros/ubuntu/dists/xenial/main/binary-amd64/Packages) *does* list all the available Kinetic packages for `amd64`.
