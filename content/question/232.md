  body_markdown: "Hi RoboUser,\n\nWhen you use \"world\" you are using a method that\
    \ takes more time in computation and memory. Conversely, using \"quick\" is faster\
    \ and uses less memory. \n\nHowever, \"world\" is more accurate than \"quick\"\
    . If you are simulating a big system using \"world\" it could take much more time\
    \ and use a lot of resources of your computer. (maybe this was the cause of the\
    \ crash simulating the DRC)\n\nBtw,\nYou can have more information about the ODE\
    \ solver in the [ODE page](http://www.ode.org/).\n\n"
