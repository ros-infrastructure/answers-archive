  body_markdown: "No, this is not correct.\n\n`ur_modern_driver` only provides an\
    \ action *server*.\n\nYour node(s) is (are) the action client(s).\n\n> I've put\
    \ `Joint velocities` as by-default the driver publishes `speedj` commands. \n\n\
    that is also not correct.\n\nWhen not using `ros_control`, the driver uses `servoj(..)`\
    \ in a small program that runs on the controller.\n\nWhen using `ros_control`,\
    \ it either uses `speedj(..)` when the velocity interface of the hw iface is used,\
    \ or `servoj(..)` again for the position part.\n\nThe driver also doesn't publish\
    \ anything to the controller. It's a regular TCP/IP connection over which a minimal,\
    \ custom protocol is run.\n\n---\n\nEdit: it's a bit lame, but \"read the source\"\
    \ is probably still good advice in this case: [ThomasTimm/ur_modern_driver](https://github.com/ThomasTimm/ur_modern_driver/tree/9397f47ac158fe5976719f33101334371bc15d44).\n\
    \nBut as I wrote before: you might want to look into the Zagitta fork (PR#120)."
