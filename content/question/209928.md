  body_markdown: "I guess you could create a global \"image\" variable and then if\
    \ the variable is not set yet, just use the callback to store the variable. If\
    \ the variable is set, use the callback you compare the new image with the stored\
    \ image and afterwards set the saved image to the new image.\n\nSome untested\
    \ python pseudocode:\n\n    def image_cb(msg):\n        global old_img\n     \
    \   if old_img is None:\n             old_img = msg\n             return\n   \
    \     movement_result = compare_imgs(old_img, msg)\n        old_img = msg\n\n "
