This node is almost the same if you want to use arduino too, and maps the range of -pi - + pi to e.g 2000 - 8000 in order to send the i2c driver. Also this driver has a small bug that if you keep sending the same command it will depower the servos after the timeout, so a hack was made to +-1 if same joint callback. Also the helper is a trick for servo2 to clone servo1 + command of servo2 bcs my arm has depedent joints while the urdf does not.
