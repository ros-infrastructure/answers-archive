  body_markdown: "Because there's no such thing as a sensor_msgs::CvBridge.\nHave\
    \ a look at the [cv_bridge tutorial](http://wiki.ros.org/cv_bridge/Tutorials/UsingCvBridgeToConvertBetweenROSImagesAndOpenCVImages)\n\
    \nespecially this part for an image callback:\n\n    void imageCb(const sensor_msgs::ImageConstPtr&\
    \ msg)\n    {\n     cv_bridge::CvImagePtr cv_ptr;\n     try\n     {\n      cv_ptr\
    \ = cv_bridge::toCvCopy(msg, sensor_msgs::image_encodings::BGR8);\n     }\n  \
    \   catch (cv_bridge::Exception& e)\n     {\n      ROS_ERROR(\"cv_bridge exception:\
    \ %s\", e.what());\n      return;\n     }\n\n     // Draw an example circle on\
    \ the video stream\n     if (cv_ptr->image.rows > 60 && cv_ptr->image.cols > 60)\n\
    \      cv::circle(cv_ptr->image, cv::Point(50, 50), 10, CV_RGB(255,0,0));\n\n\
    \     // Update GUI Window\n     cv::imshow(OPENCV_WINDOW, cv_ptr->image);\n \
    \    cv::waitKey(3);\n    \n     // Output modified video stream\n     image_pub_.publish(cv_ptr->toImageMsg());\n\
    \     }\n    };\n\nYou have to create a `cv_bridge::CvImagePtr` and afterwards\
    \ you can publish it as a sensor_msgs/Image again with `cv_bridge::CvImagePtr::toImageMsg()`."
