  body_markdown: "To publish an image, please allocate the shared pointer yourself.\n\
    I.e.\n\n    #include <boost/make_shared.hpp>\n \n    sensor_msgs::ImagePtr image\
    \ = boost::make_shared<sensor_msgs::Image> ();\n    image->field = something;\
    \ // fill your fields.\n    pub.publish (image);\n\n\nPlease prefer `std::copy`\
    \ over `memcpy`. It has as efficient and behave properly on all C++ types unlike\
    \ memcpy."
