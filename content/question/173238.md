    >  I would like to install it automatically by rosdep. [..] Is possible something like this? What have i to do?

    That is certainly possible. `libmodbus-dev` would become a system dependency of your package, and if there are no existing rules for it, you would have to contribute them. The rosdep documentation should clarify things for you. See the [Contributing rosdep rules](http://docs.ros.org/independent/api/rosdep/html/contributing_rules.html) section of the [rosdep](http://docs.ros.org/independent/api/rosdep/html) documentation.
