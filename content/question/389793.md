    \nClearpath also offers a GPS Navigation package:\nhttps://clearpathrobotics.com/gps-waypoint-navigation-package/\n\
    \nFinally for GPS Waypoint navigation I recommend Nick Charron Husky tutorial\
    \ that can be adapted to Jackal:\nhttps://github.com/nickcharron/waypoint_nav.\n\
    \nThe outdoor navigation package offers: \n\n- gps_waypoint to read the waypoint\n\
    \   file, convert waypoints to points in\n   the map frame and then send the goals\n\
    \   to move_base\n   \n  - gps_waypoint_continuous1 and\n   gps_waypoint_continuous2\
    \ for\n   continuous navigation between\n   waypoints using two seperate\n   controllers\n\
    \   \n   - collect_gps_waypoint to allow the\n   user to drive the robot around\
    \ and\n   collect their own waypoints\n   \n   - calibrate_heading to set the\
    \ heading\n   of the robot at startup and fix\n   issues with poor magnetometer\
    \ data\n   \n   - plot_gps_waypoints to save raw data\n   from the GPS for plotting\
    \ purposes\n   \n   - gps_waypoint_mapping to combine\n   waypoint navigation\
    \ with Mandala\n   Robotics' 3D mapping software for\n   autonomous 3D mapping"
