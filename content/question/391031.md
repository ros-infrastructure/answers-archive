  body_markdown: "Hi Marco Luis,\n\nI just want to share my experience that I had\
    \ similar error while using 'catkin_make' on Autoware.ai  (1.10) on Renesas H3\
    \ platform (aarm64).\nBasically, this log: `c++: internal compiler error: Killed\
    \ (program cc1plus)` means that your hardware was running out of memory. \nThe\
    \ solution I did was as follows:\n\n - After `catkin_make`, you will have `build`\
    \ and `devel` directories.\n - When the said error happens, you can go inside\
    \ `build` and then run `make` from inside the directory.\n - If the error persists,\
    \ you may consider to upgrade your hardware memory or if not you can free-up some\
    \ memory by killing any process(s) that you don't need or in my case in Renesas\
    \ platform, I was using headless ubuntu interface (as GUI consumes my platform's\
    \ memory resource) with terminal from a serial connection (`minicom`).\n\nI hope\
    \ this helps."
