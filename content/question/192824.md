  body_markdown: "The error:\n\n    CMake Error at rosberry_pichopter/CMakeLists.txt:94\
    \ (add_library):\n      Cannot find source file:\n\nMeans that cmake is looking\
    \ for the file and did not find it. It looks for the file relatively to the base\
    \ directory of your package (not the base directory of your catkin workspace!!!!).\
    \ I. e. the error message is fully consistent with what you mentioned:\n\nYour\
    \ source file is placed in \n\n    catkin_ws/src/rosberry_pichopter/joy/src/servo.cpp\n\
    \nCMake looks for the file in \n\n    catkin_ws/src/rosberry_pichopter/src/rosberry_pichopter/joy/src/servo.cpp\n\
    \nThe reason, I guess, is that you a have an `add_executable` or `add_library`\
    \ in your CMakeLists.txt which looks like:\n\n    add_executable( your_target\
    \ src/rosberry_pichopter/joy/src/servo.cpp )\n\nwhile it should rather look like:\n\
    \n    add_executable( your_target joy/src/servo.cpp )\n\n"
