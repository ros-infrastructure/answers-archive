  body_markdown: "Hi, \n\n  We also wanted to access the trajectories but did not\
    \ find a way to do that without modifying the code or accessing the mongodb that\
    \ saves the generated trajectories. In case you don't know how to change the source\
    \ code, here are the 4 modifications we did on the electric version (I cannot\
    \ give you a patch as our modified version contains other stuff). We modified\
    \ the planning_scene_warehouse_viewer.h by adding a button in the public slots:\
    \ section\n\n    /// @brief Called when the user publishes a trajectory\n    \
    \  void publishButtonPressed();\n\nthen in planning_scene_warehouse_viewer.cpp\n\
    \n          QPushButton* publishTrajectoryButton = new QPushButton(trajectoryBox);\n\
    \          publishTrajectoryButton->setSizePolicy(QSizePolicy::Maximum, QSizePolicy::Maximum);\n\
    \          publishTrajectoryButton->setText(\"Publish Trajectory\");\n       \
    \   publishTrajectoryButton->setToolTip(\"Publish the currently selected trajectory.\"\
    );\n\nand   \n\n    trajectoryBoxLayout->addWidget(publishTrajectoryButton);\n\
    \nand \n\n    connect(publishTrajectoryButton, SIGNAL(clicked()), this, SLOT(publishButtonPressed()));\n\
    \nand finally the function\n\n    void WarehouseViewer::publishButtonPressed()\n\
    \    {\n      if(selected_trajectory_name_ != \"\")\n      {\n        TrajectoryData&\
    \ trajectory = trajectory_map_[selected_motion_plan_name_][selected_trajectory_name_];\n\
    \        trajectory_msgs::JointTrajectory mytrajectory_msg=trajectory.getTrajectory();\n\
    \        traj_publisher_.publish(mytrajectory_msg);\n      }\n      else\n   \
    \   {\n        QMessageBox msg(QMessageBox::Warning, \"Publish Trajectory\", \"\
    No Trajectory Selected!\");\n        msg.addButton(\"Ok\", QMessageBox::AcceptRole);\n\
    \        msg.exec();\n      }\n    }\n\nand then advertized a publisher in move_arm_utils.cpp\
    \ in the publisher section\n\n    traj_publisher_ = nh_.advertise<trajectory_msgs::JointTrajectory>\
    \ (\"/generated_trajectory\", 128);\n\nand declared it in move_arm_utils.cpp near\
    \ the other publishers of the PlanningSceneEditor class\n\n    ros::Publisher\
    \ traj_publisher_;\n\nthe program will output the trajectory on /generated_trajectory\
    \ topic each time you press the button. Your node can listen to that topic.\n\n\
    Hope this helps."
