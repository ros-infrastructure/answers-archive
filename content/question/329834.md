  body_markdown: "If you dig into the [ros1_bridge](https://github.com/ros2/ros1_bridge)\
    \ source code you will find the answer. <br>\n[dynamic_bridge](https://github.com/ros2/ros1_bridge/blob/master/src/dynamic_bridge.cpp)\
    \ has the following available flags that are of interest in this case:\n\n   \
    \ --bridge-all-topics: Bridge all topics in both directions, whether or not there\
    \ is a matching subscriber.\n    --bridge-all-1to2-topics: Bridge all ROS 1 topics\
    \ to ROS 2, whether or not there is a matching subscriber.\n    --bridge-all-2to1-topics:\
    \ Bridge all ROS 2 topics to ROS 1, whether or not there is a matching subscriber.\n\
    \nRegarding your question for bridging specific topics you should look at the\
    \ [parameter_bridge](https://github.com/ros2/ros1_bridge/blob/master/src/parameter_bridge.cpp):\n\
    \n    bridge all topics listed in a ROS 1 parameter. The parameter needs to be\
    \ an array and each item needs to be a dictionary with the following keys; \n\
    \    topic: the name of the topic to bridge\n    type: the type of the topic to\
    \ bridge\n    queue_size: the queue size to use (default: 100)\nor [static_bridge](https://github.com/ros2/ros1_bridge/blob/master/src/static_bridge.cpp)\
    \ which gives an example implementation of bridging one topic.\n\n\n\n\n "
