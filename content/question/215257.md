  body_markdown: "\nYou can subscribe to `/rtabmap/cloud_map` topic to get the point\
    \ cloud.\n\n    $ rosrun pcl_ros pointcloud_to_pcd input:=rtabmap/cloud_map\n\
    \    $ pcl_viewer ###.pcd  \n\nIf the mapping is paused, you can force rtabmap\
    \ to publish the map again:\n\n    $ rosrun pcl_ros pointcloud_to_pcd input:=rtabmap/cloud_map\n\
    \    $ rosservice call /rtabmap/publish_map 1 1 0\n    $ pcl_viewer ###.pcd  \n\
    \nFor the `get_map` service error, I can't reproduce the problem with RVIZ (the\
    \ clouds are correctly downloaded and shown). If you call it from terminal, you\
    \ would see a lot of numbers printed. Note that I tested with [rtabmap_ros](http://wiki.ros.org/rtabmap_ros)\
    \ 0.10.4 (binaries on Indigo have just been released). \n\n**EDIT**\n\nTo have\
    \ the point cloud in PLY format (to open it in [MeshLab](http://meshlab.sourceforge.net/)\
    \ or any other 3D programs), you can use `pcd2ply` tool from PCL:\n\n    $ pcl_pcd2ply\
    \ ###.pcd output.ply"
