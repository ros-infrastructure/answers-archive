  body_markdown: "Hi,\nJust in case anyone wondering how to solve this there is one\
    \ non-ROS method. I used the `subprocess` package from python to do that.\n\n\
    \    import subprocess\n    process = subprocess.Popen(['/bin/sh', '-c', 'ros2\
    \ bag play '+bag_file_path+'/'])\n    process.communicate()\n    process.terminate()\n\
    \nthis way I send a command to the terminal which will run a bag file and on another\
    \ end my ROS topic will read it.  \nThis is not the best way I assume but it's\
    \ the least coding way I was able to do it. But still, if anyone has a better\
    \ solution or `ROS` solution please let me know.  \nJust to give a background\
    \ about the problem I am running the` test node` which subscribes to `topics`\
    \ and then does some testing on that data. For that, I need the `sensor data`\
    \ that I can either read from hardware or from the bag file."
