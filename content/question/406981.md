  body_markdown: "I think I am missing your *question*, but for reference, this is\
    \ to be expected if all you did was install `ros-rolling-desktop`. The `ros-DISTRO-desktop`\
    \ installation does not include `ros2_control` - it includes core ROS packages,\
    \ some tutorials, and some tools. You can see exactly what gets installed with\
    \ `apt info ros-rolling-desktop`. \n\n`ros2_control` and `ros2_controllers` are\
    \ considered too application specific to be included with the desktop installation.\
    \ That being said, they are very easily installed with `sudo apt install ros-rolling-ros2-control\
    \ ros-rolling-ros2-controllers`"
