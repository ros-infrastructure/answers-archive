  body_markdown: "This can happen if the library name for building the messages and\
    \ the package name is different.  To quote Dirk [here](https://github.com/ros2/rosidl/issues/441#issuecomment-591025515),\n\
    \n>Atm the generated library for the interfaces must have the basename `${PROJECT_NAME}`.\n\
    > \n> You have to options:\n> \n> either rename your interface target to\n> just\
    \ `${PROJECT_NAME}:`\n> \n    rosidl_generate_interfaces(${PROJECT_NAME} \"srv/MySrv.srv\"\
    )\n    rosidl_target_interfaces(my_node ${PROJECT_NAME} \"rosidl_typesupport_cpp\"\
    )\n> or explicitly set the library name:\n>\n    rosidl_generate_interfaces(${PROJECT_NAME}_srv\
    \ \"srv/MySrv.srv\" LIBRARY_NAME ${PROJECT_NAME})"
