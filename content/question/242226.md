  body_markdown: "The [python TF library](http://wiki.ros.org/tf/TfUsingPython) uses\
    \ the [transformations.py](https://github.com/ros/geometry/blob/hydro-devel/tf/src/tf/transformations.py)\
    \ module which is really nice. If you haven't used it, the main idea is it uses\
    \ 4x4 matrices to represent transformations and there are tons of functions for\
    \ linear algebra and converting to different representations. It's really just\
    \ a wrapper around numpy, but it does a good job. \n\nTo use it, I do `from tf\
    \ import transformations as t` \n\nThe whole module is just that one file I linked\
    \ to, the documentation/examples in the comments are really good. \n\nIt has `t.inverse_matrix()`instead\
    \ of `.inverse()`. Also `t.translation_from_matrix()` will do what `.getOrigin()`\
    \ does. And for `.length()` you would use `t.vector_norm()`\n\nYou can probably\
    \ figure out the rest, if not I can help in the comments. "
