    You can achieve communication with both protocols using [Dynamixel SDK](https://emanual.robotis.com/docs/en/software/dynamixel/dynamixel_sdk/overview/). It is written in both [C++](https://github.com/ROBOTIS-GIT/DynamixelSDK/tree/master/c%2B%2B)  and [Python](https://github.com/ROBOTIS-GIT/DynamixelSDK/tree/master/python) and a few other languages. Here you can find examples on how you can combine both protocols in [C++](https://github.com/ROBOTIS-GIT/DynamixelSDK/tree/master/c%2B%2B/example/protocol_combined) and [Python](https://github.com/tonnesfn/DynamixelSDK/tree/master/python/protocol_combined). A ROS based package [Dynamixel Workbench](http://wiki.ros.org/dynamixel_workbench) is provided by Robotis. This should give you an idea how you can use Dynamixel SDK for ROS specific interfaces.
