  body_markdown: "Hi again,\n\nI guess, I've solved the problem by comparing `kinect_prosilica_camera.urdf.xacro`\
    \ and `kinect_camera.urdf.xacro` files. \n\nIt turns out mesh information wasn't\
    \ scaled to the meter-scale when the kinect.dae file is generated, but mm-scale\
    \ instead. It seems scaling can be done after this file is generated by adding\
    \ scale=\"0.001 0.001 0.001\" at the end of the corresponding line in the urdf\
    \ files, as shown below,\n\n    <mesh filename=\"package://pr2_description/meshes/sensors/kinect_v0/kinect.dae\"\
    \ scale=\"0.001 0.001 0.001\"/>\n\nProbably, this has been overlooked by the developers\
    \ in the recent updates.\n\nCheers"
