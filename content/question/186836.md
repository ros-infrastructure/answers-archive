  body_markdown: "The correct format for message-type in a .msg file is \n\n    package_name/data_type_name[]\
    \ variable name\n\nWhere **data_type_name** is a message in the package **package_name**\n\
    \neg.\n\n    std_msgs/Float64[] values\n\n\nNote that this is not a regular array\
    \ in c++.\n\nAfter generating the msg file, if you look at the .h file for that\
    \ message, you will find that values is a vector of doubles.\n\n    std::vector\
    \ <double> values;"
