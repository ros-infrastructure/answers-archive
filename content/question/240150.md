  body_markdown: "Your `lines` is a numpy array of x,y coordinates for the lines the\
    \ hough transform found and not an image. You cannot visualise that using\n\n\
    \    cv2.imshow(\"image\",lines)\n\ntry\n\n    cv2.imshow(\"image\",cv_image)\n\
    \nwhich is what you draw the lines on anyway with \n\n    cv2.line(cv_image,(x1,y1),(x2,y2),(0,255,0),2)\n\
    \nEDIT:\n\nAlso if you want real-time, you want to add a `queue_size=1` to your\
    \ subscriber to prevent the lag and get real-time results. Otherwise the image\
    \ you produce will always be lagging behind the input image.\n\n    self.image_sub\
    \ = rospy.Subscriber(\"/camera/rgb/image_color\", Image, self.callback, queue_size=1)"
