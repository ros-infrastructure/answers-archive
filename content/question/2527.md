    \ gazebo)\n    endif()\n    include_directories(${GAZEBO_INCLUDE_DIRS})\n    link_directories(${GAZEBO_LIBRARY_DIRS})\n\

    \ GazeboRosP3D.\n\n* create your package just like a regular ROS package. I am\
    \ still using rosbuild by the way.\n\n* pull the gazebo\\_ros\\_p3d.h and gazebo\\\
    _ros\\_p3d.cpp from simulator\\_gazebo/gazebo\\_plugins and change the .cpp file\
    \ to include the correct header (e.g. #include `<my_gazebo_plugins/gazebo_ros_p3d.h>`\n\
    \n* change your CMakeLists.txt as described by @AndreiHaidu in his answer. Also,\
    \ add the \n\n       rosbuild\\_add\\_library(my\\_gazebo\\_ros\\_p3d src/gazebo\\\
    _ros\\_p3d.cpp)\n\n       rosbuild\\_add\\_boost\\_directories()\n\n       rosbuild\\\
    _link\\_boost(my\\_gazebo\\_ros\\_p3d thread)\n\n\n* change the manifest by adding\n\
    \n  `<depend package=\"tf\">` `<!-- this is needed for p3d plugin -->`\n\n* in\
    \ your model.sdf add \n\n    `<plugin filename=\"libmy_gazebo_ros_p3d.so\" name=\"\
    my_gazebo_ros_p3d\"> \n      <bodyName>chassis</bodyName>\n      <topicName>/ground_truth_odom</topicName>\n\
    \      <alwaysOn>true</alwaysOn>\n      <updateRate>100.0</updateRate>\n\t\t\t\
    <gaussianNoise>0.0</gaussianNoise>\n\t\t\t<frameName>map</frameName>\n      <xyzOffset>0\
    \ 0 0</xyzOffset>\n\t    <rpyOffset>0 0 0</rpyOffset>\n    </plugin>`\n\n* append\
    \ the plugin path at /usr/share/gazebo-1.7/setup.sh by modifying\n\n `export GAZEBO_PLUGIN_PATH=/usr/lib/gazebo-1.7/plugins:<your\

    Based on the plugin, you may add different packages in the manifest."
