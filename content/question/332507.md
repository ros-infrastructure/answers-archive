  body_markdown: "Hello!\n\n 1. about moriyama_path.txt\n \n This file contains the\
    \ path and speed that should be followed.\n The format is (position.x [m], position.y\
    \ [m], position.z [m], velocity [km/h] ).\n This is the oldest format supported\
    \ by Autoware.\n https://gitlab.com/autowarefoundation/autoware.ai/core_planning/blob/master/waypoint_maker/nodes/waypoint_loader/waypoint_loader_core.cpp#L123\n\
    \n A new format is now used, but it can be generated using `waypoint_saver`.\n\
    \n 2. about tf\n\n tf package is installed by default when ROS is installed.\n\
    \ http://wiki.ros.org/tf\n\n 3. about camera_lidar_calib files\n\n Please use\
    \ nic-150407.yml because it is the parameter that calibrated best. The other two\
    \ are previously used parameters. \n\n  I deleted them from the data set that\
    \ was downloaded.\n \n 4. about vector map\n\n If you have a PCD file, you can\
    \ create an HDMap with Vector Map Builder.\n It's very hard work because it's\
    \ manual work, but please try it. https://tools.tier4.jp/"
