  body_markdown: "Let's look into pf_sample_set_t type.\n\n    typedef struct _pf_sample_set_t\
    \ {\n      // The samples\n      int sample_count;\n      pf_sample_t *samples;\n\
    \    \n      // A kdtree encoding the histogram\n      pf_kdtree_t *kdtree;\n\
    \    \n      // Clusters\n      int cluster_count, cluster_max_count;\n      pf_cluster_t\
    \ *clusters;\n    \n      // Filter statistics\n      pf_vector_t mean;\n    \
    \  pf_matrix_t cov;\n      int converged; \n    } pf_sample_set_t;\n\nSample particles\
    \ are stored as an array hold by the pointer, `samples`, instead of `kdtree`.\n\
    The kdtree is for constructing weight histogram of particles.\nThe purposes of\
    \ this histogram are to provide the number of non-empty bins for KLD-sampling\
    \ and to calculate mean and covariance values from each cluster. This clustering\
    \ algorithm for the kdtree histogram seems like a type of density-based clustering\
    \ algorithms. Nodes connected to each other are labeled as a same cluster where\
    \ connectivity is determined based on neighbor nodes. In pf_kdtree.c of amcl package,\
    \ the neighbor node, `nnode`, of a node is \n\n    nkey[0] = node->key[0] + (i\
    \ / 9) - 1;\n    nkey[1] = node->key[1] + ((i % 9) / 3) - 1;\n    nkey[2] = node->key[2]\
    \ + ((i % 9) % 3) - 1;\n    nnode = pf_kdtree_find_node(self, self->root, nkey);\n\
    \nwhere `key` is the spatial information of a node. "
