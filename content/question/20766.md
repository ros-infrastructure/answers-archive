  body_markdown: "Do I understand correctly, that you are using the example from [this\
    \ article](http://gazebosim.org/tutorials?tut=elevators&cat=plugins)? And the\
    \ elevator is dependent on [OccupiedEvent plugin](http://osrf-distributions.s3.amazonaws.com/gazebo/api/dev/classgazebo_1_1OccupiedEventSource.html).\
    \ If you search through the documentation of this plugin, you will find those\
    \ lines \n\n        <plugin filename=\"libSimEventsPlugin.so\" name=\"event_plugin\"\
    >\n          <region>\n            <name>region1</name>\n            <volume>\n\
    \              <min>1.5 -1 0</min>\n              <max>2.5 1 1</max>\n       \
    \     </volume>\n          </region>\n    \n          <event>\n            <name>region1_event</name>\n\
    \            <type>occupied</type>\n            <topic>~/elevator</topic>\n  \
    \          <region>region1</region>\n            <msg_data>0</msg_data>\n    \
    \      </event>\n       </plugin>\n\nAs you can see, apart of the plugin controlling\
    \ the elevator behavior, you use also plugin giving the information to the elevator\
    \ plugin. Unless you edited also the `region1`, the elevator still scans the presence\
    \ of an object at the original area.\n\nYou would need to edit the `region1` coordinates\
    \ to match the exit of your shifted elevator."
