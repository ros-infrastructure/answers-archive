  body_markdown: "From the [wiki](http://wiki.ros.org/roscpp/Overview/Publishers%20and%20Subscribers)\
    \ :\n\n> latch [optional]\n> \n> Enables \"latching\" on a connection.\n> When\
    \ a connection is latched, the last\n> message published is saved and\n> automatically\
    \ sent to **any future\n> subscribers** that connect. This is\n> useful for slow-changing\
    \ to static\n> data like a map. Note that if there\n> are multiple publishers\
    \ on the same\n> topic, instantiated in the same node,\n> then only the last published\
    \ message\n> from that node will be sent, as\n> opposed to the last published\
    \ message\n> from each publisher on that single\n> topic.\n\nThat means that if\
    \ you publish a message with `latch=true` then every subscriber will get the message\
    \ once even if you don't publish it anymore. Your code is publishing in a `while\
    \ loop` so indeed it won't make a difference wether `latch=true` or `false` because\
    \ you always send a new message. To show the difference you need to publish data\
    \ only once (or several time but stop at some point) and then subscribe to the\
    \ topic when it's not published anymore (with `rostopic echo` for example). A\
    \ code that would show the difference could be :\n\n    ros::init(argc,argv, \"\
    Pub\");\n    ros::NodeHandle nh;\n    ros::Publisher pub_latch_true = nh.advertise<std_msgs::Int8>(\"\
    topic_latch_true\", 50, true);\n    ros::Publisher pub_latch_false = nh.advertise<std_msgs::Int8>(\"\
    topic_latch_false\", 50, false);\n    ros::Rate rate(1);\n    \n    std_msgs::Int8\
    \ msg;\n    msg.data = 2;\n    pub_latch_true.publish(msg);\n    pub_latch_false.publish(msg);\n\
    \    while(ros::ok())\n    {\n      ros::spinOnce();\n      rate.sleep();\n  \
    \  }\n    return 0;\n\nRun this node (the `while loop` is only to keep the node\
    \ alive)  and then do `rostopic echo /topic_latch_true` and `rostopic echo /topic_latch_false`,\
    \ you won't have any output for `topic_latch_false` and you will have only one\
    \ message with `topic_latch_true` (the last published message)."
