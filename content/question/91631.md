    There are no official Debian packages for Ubuntu Saucy (13.10) (see http://ros.org/reps/rep-0003.html#hydro-medusa-apr-2013).

  body_markdown: "Worry no more! Where there is a hack... there is a way!\nNow, I\
    \ have just installed Ubuntu 13.10 to later find out that it is not supported\
    \ by Hydro... Sad but true...\n\nAnyway, the thing is that the meta-package ros-hydro-desktop-full\
    \ installs also gazebo, which is a simulator that requires libogre-dev to be installed.\
    \ \nlibogre-dev on the other hand needs libboost1.49 but everyone else has already\
    \ already moved on to libboost1.53...\n\nSo what do we do?\nSimple... We compile\
    \ libogre-dev and make it look like it is native package installed!\nThis means\
    \ that you have to:\n1) Install libboost1.53-all-dev ( I install it all, so dependency\
    \ won't be a problem)\n2) Download libogre-dev source code from http://bitbucket.org/cabalistic/ogredeps\n\
    3) Cmake the project and generate the Makefile\n4) Use 'sudo checkinstall' (http://www.linuxjournal.com/content/using-checkinstall-build-packages-source)\
    \ to generate and install your libogre-dev package. BUT REMEMBER TO CHANGE THE\
    \ FOLLOWING:\n                 Name of the Package: libogre-dev\n            \
    \     Version: 1.7.4+dfsg1-7\nThis way you are tricking ubuntu's package management\
    \ system into thinking you have the original package.\nOBS: At this point, you\
    \ have installed a libogre-dev that has been compiled with libboost1.53. I don't\
    \ guarantee that gazebo will run perfectly or that it will work at all...\n\n\
    5) Proceed with ROS for Raring as described here: http://wiki.ros.org/hydro/Installation/Ubuntu\n\
    \nSee ya\n\n"
