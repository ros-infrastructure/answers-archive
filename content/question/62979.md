    \ have the `pcl_ros` package in your workspace, or you need to install all of\
    \ the debians which `pcl_ros` depends on. Since I am on a mac, I will fetch all\
    \ of the dependencies and build them from source, so I will start like this:\n\
    \n**Note: the `/tmp` directory is cleared at reboot, you may want to pick a different\
    \ directory**\n\n    cd /tmp\n    mkdir pcl_ws\n    cd pcl_ws\n    wstool init\
    \ src http://packages.ros.org/web/rosinstall/generate/raw/groovy/pcl_ros\n\nThat\
    \ downloaded `pcl_ros` and all of it's dependencies into the `src` folder, including\
    \ `pcl-1.6` which is what is released with groovy. Lets remove that version of\
    \ `pcl` so that we can replace it later:\n\n    rm -rf src/pcl\n\nIf you only\
    \ want to rebuild `pcl` and `pcl_ros` from source then run `sudo apt-get install\
    \ ros-groovy-pcl-ros` in order to get all of the dependencies you need and then\
    \ setup a workspace with `pcl_ros` in it:\n\n    # Only do this if you did the\
    \ apt-get and did not run wstool above\n    cd /tmp\n    mkdir pcl_ws\n    cd\
    \ pcl_ws\n    mkdir src\n    cd src\n    git clone https://github.com/ros-perception/perception_pcl.git\n\
    \nEither way, at this point you have the `/tmp/pcl_ws/src` folder now which contains\
    \ at least `pcl_ros`. In the `src` folder you should clone the master of `pcl`\
    \ (1.7):\n\n    cd /tmp/pcl_ws/src\n    git clone https://github.com/PointCloudLibrary/pcl.git\n\
    \nNext you need to \"ROS\"-ify the `pcl` package. First you need the `package.xml`\
    \ for `pcl`, we can get this from the released version (it hasn't changed from\
    \ 1.6 to 1.7):\n\n    cd pcl\n    wget https://raw.github.com/ros-gbp/pcl-release/release/pcl/1.6.0/package.xml\n\
    \nNext you will want to edit the `cmake/pcl_find_ros.cmake` file to hard code\
    \ the `USE_ROS` option to `ON`, here is a patch:\n\n    diff --git a/cmake/pcl_find_ros.cmake\
    \ b/cmake/pcl_find_ros.cmake\n    index cf2e1e3..b426066 100644\n    --- a/cmake/pcl_find_ros.cmake\n\
    \    +++ b/cmake/pcl_find_ros.cmake\n    @@ -25,7 +25,7 @@ endmacro(get_ros_inc_path)\n\
    \     set(ROS_DISTRO $ENV{ROS_DISTRO})\n    \n     if(ROS_DISTRO)\n    -    option(USE_ROS\
    \ \"Integrate with ROS rather than using native files\" OFF)\n    +    option(USE_ROS\
    \ \"Integrate with ROS rather than using native files\" ON)\n         message(STATUS\
    \ \"Found ROS; USE_ROS is ${USE_ROS}; ROS-Distro: ${ROS_DISTRO}\")\n         if(USE_ROS)\n\
    \             # Search for ROS\n    \n\nNow you can build your `pcl` workspace:\n\
    \n    cd /tmp/pcl_ws\n    source /opt/ros/groovy/setup.bash  # Only if you are\
    \ using debians\n    catkin_make_isolated --install  # prefix with `./src/catkin/bin/`\
    \ if not using debians\n\nNow assuming you didn't run into any build errors (I\
    \ didn't get any on my Mac just now), then you should have a folder at `/tmp/pcl_ws/install_isolated`\
    \ which you can source to utilize `pcl` and `pcl_ros`:\n\n    source /tmp/pcl_ws/install_isolated/setup.bash"
