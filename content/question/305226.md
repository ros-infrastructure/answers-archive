    \ for different ROS releases. Right below, there are some green informational\
    \ bubbles letting you know if the package has been released for that version of\
    \ ROS. Note that if that particular wiki page doesn't have a Melodic section,\
    \ that's a good sign the package hasn't been released yet.\n\nIf a package hasn't\
    \ been released yet, it's often just a matter of finding the source code for the\
    \ package, adding it to your workspace, ensuring you have the correct dependencies\
    \ (tools like `rosdep` and `rosinstall` can help greatly with this) and then running\
    \ `catkin_make`. If you're lucky, this will \"just work\", and it likely will\
