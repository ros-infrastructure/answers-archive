    , JointState, callback)\n\nThe dynamixel controller Joint State message documentation\
    \ is [here](http://docs.ros.org/api/dynamixel_msgs/html/msg/JointState.html).\
    \ If you want to access any other member, just call \"data.[member name goes here]\"\
