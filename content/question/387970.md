    Well, that's not what you asked. So please try to be more clear next time.

    `abb_driver` does not directly support YuMi. The only way to use it would be to install `abb_driver` twice, but that would need changes to the source code of `abb_driver`.

    You would then have two tasks, and indeed would probably need to duplicate some of the signals.

    But without those changes, you cannot use `abb_driver` with YuMi directly. The status of `abb_driver` is explained [here](http://wiki.ros.org/abb_driver#YuMi).
