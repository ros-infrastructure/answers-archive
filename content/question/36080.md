    \    /camera/depth/image\n    /camera/rgb/camera_info\n    /camera/rgb/image_color\n\
    \    /tf\n\nThey have all the info for use with RGBDSLAM. Then, use that package\
    \ to map with the simulated data. You can save the map in the GUI supplied with\
    \ the RGBDSLAM package. \n\nIf you are just trying to make a 2D map, then record\
    \ \n\n    /tf\n    /scan\n\nand use the gmapping package to map. Use the map_server\
    \ package to save a map. \n\nHope it helps! \n\n-Hunter A. "
