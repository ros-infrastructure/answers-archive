  body_markdown: "I can only answer your first question:\n\nTo use a VLP-16, you currently\
    \ have to [build the velodyne driver from source](http://answers.ros.org/question/226594/how-do-i-build-ros-vlp16-velodyne-driver-for-indigo-using-catkin/).\
    \ That is because the Indigo version was released *before* VLP-16 support was\
    \ added. (A new release is planned, but not yet done.)\n\nThe launch file you\
    \ need is included in the [velodyne_pointcloud](http://wiki.ros.org/velodyne_pointcloud)\
    \ package:\n\n    $ roslaunch velodyne_pointclound VLP16_points.launch\n\nYour\
    \ other questions are not really specific to Velodyne, they would apply to 3D\
    \ SLAM using any sensor that produces a point cloud. \n\nI am sure others know\
    \ more than I do about all that. I am interested in those answers, too."
