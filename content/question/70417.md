  body_markdown: "Hi,\n\nTo spawn a urdf.xacro file in gazebo you have to first convert\
    \ xacro file using xacro.py script. For example if you have robot.xacro.urdf file\
    \ in a package called robot_package then following launch file will spawn your\
    \ robot in Gazebo.\n\n    <launch>\n    <!-- Convert xacro and put on parameter\
    \ server -->\n    <param name=\"robot_description\" command=\"$(find xacro)/xacro.py\
    \ $(find robot_package)/urdf/robot.urdf.xacro\" />\n    \n    <!-- Spawn a robot\
    \ into Gazebo -->\n    <node name=\"spawn_urdf\" pkg=\"gazebo_ros\" type=\"spawn_model\"\
    \ args=\"-param robot_description -urdf -model robot\" />\n    </launch>\nNote:\
    \ Replace the node and package if you are using simulator_gazebo and not stand\
    \ alone gazebo accordingly. \nAdditionally, you can find more details in this\
    \ [tutorial](http://gazebosim.org/wiki/Tutorials/1.9/Using_roslaunch_Files_to_Spawn_Models)\
    \ and its better to ask gazebo related questions on [Gazebo sim forum](http://answers.gazebosim.org/questions/).\n\
    \nTo add color in gazebo navigate to the file gazebo.material in materials/scripts\
    \ folder of your gazebo and include your own color definition. Other colors are\
    \ defined there you can follow the pattern.\nTo assign this color to a model use\
    \ following code in your file.\n\n    <material>\n         <script>Gazebo/yourcolor</script>\n\
    \    </material> \nNote: This code is for SDF 1.4 change accordingly for your\
    \ version see documentation here[SDF](http://gazebosim.org/sdf.html).\n\n"
