  body_markdown: "You can run any program inside a ROS package using `rosrun` (or\
    \ equally, using a launch file), no matter if it's a ROS node or not. So I would\
    \ suggest you put the command(s) you use to run your program from the command\
    \ line into a shell script and use `rosrun` to run that script.\n\n**Example:**\n\
    \n`my_pkg/scripts/server.sh`:\n\n    #!/bin/sh\n    # TODO: set up CLASSPATH,\
    \ ...\n    java $1    # this won't work exactly, you need to add some more \n\
    \               # arguments to java (never can remember which)\n\n1. run from\
    \ command line:\n\n        $ rosrun my_pkg server.sh $(rospack find my_pkg)/classes/Server.class\n\
    \n2. run from launch file (`my_pkg/launch/my_stuff.launch`):\n\n        <launch>\n\
    \          <node pkg=\"my_pkg\" type=\"server.sh\" name=\"server\" args=\"$(find\
    \ my_pkg)/classes/Server.class\"/>\n        </launch>\n\n(remember to set the\
    \ executable bit on `server.sh`)"
