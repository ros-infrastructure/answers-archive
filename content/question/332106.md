    I'm assuming you are using a depth camera, there are some RGB-D SLAM algorithms, like [rtabmap_ros](http://wiki.ros.org/rtabmap_ros)

    If you want to use a 2D SLAM, you can try using the node [pointcloud_to_laserscan](http://wiki.ros.org/pointcloud_to_laserscan) or [depthimage_to_laserscan](http://wiki.ros.org/depthimage_to_laserscan), these allows you to convert a pointcloud or depthimage to a 2D scan message.
