  body_markdown: "roscore defaults to use port 11311.  If you use the environment\
    \ variable ROS_MASTER_URI (documented [here](http://www.ros.org/wiki/ROS/EnvironmentVariables#ROS_MASTER_URI)\
    \ ) to change that port the 2nd master won't conflict.  \n\nYou can also run multiple\
    \ gazebo instances inside ROS if you launch them in different namespaces.  However\
    \ there may be an issue if you try to run them on the same machine and the instances\
    \ have to share a GPU.  Running them on 2 seperate machines will definitely avoid\
    \ that.  "
