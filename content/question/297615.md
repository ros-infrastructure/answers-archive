    robot_description\" command=\"$(find xacro)/xacro --inorder $(arg model)\" />\n\
    \      <param name=\"use_gui\" value=\"$(arg gui)\"/>\n    \n      <node name=\"\
    joint_state_publisher\" pkg=\"joint_state_publisher\" type=\"joint_state_publisher\"\
    \ />\n      <node name=\"robot_state_publisher\" pkg=\"robot_state_publisher\"\
    \ type=\"state_publisher\" />\n      <node name=\"rviz\" pkg=\"rviz\" type=\"\
    rviz\" args=\"-d $(arg rvizconfig)\" required=\"true\" />\n    \n    </launch>\n\
    \nYou can create your own package or download this package and use this launch\
    \ file.\n\nTo use this launch file run\n\n    roslaunch urdf_tutorial display.launch\
    \ model:='$(find <package-name>)/urdf/myurdf.urdf'\n\nwhere `<package-name>` is\
    \ the package that contains the URDF file and `myurdf.urdf` is your URDF file."
