    I don't believe that `libdatachannel` can be targeted directly using `ament_target_dependencies` like that. Some non-ament packages work with that macro, but others do not.

    [A brief search](https://github.com/paullouisageneau/libdatachannel/blob/master/cmake/LibDataChannelConfig.cmake) leads me to suggest that using `LibDataChannel::datachannel` in place of `libdatachannel` *might* work, but if it doesn't, you might need to target `LibDataChannel::datachannel` using `target_link_libraries` instead of `ament_target_dependencies` (as it is not actually an ament package).
