    > I run "sudo apt-get install ros-kinetic-ros-base"

    ROS Kinetic is not supported on Ubuntu Bionic (18.04), but only on Ubuntu Xenial (16.04) (see [REP-3](http://www.ros.org/reps/rep-0003.html#kinetic-kame-may-2016-may-2021)).

    That is why `ros-kinetic-ros-base` is not found.

    You'll have to:

     - either downgrade to Ubuntu Xenial, or
     - install ROS Melodic
