  body_markdown: "I don't have experience with NXT, just the RCX, but I will try to\
    \ help out.\n\nYou will need a host computer to act as the remote brain.  This\
    \ computer will connect to the USB of the Kinect, and it will also connect to\
    \ the NXT over USB.  ROS does not actually run -on- the NXT, it will simply command\
    \ it from the remote computer.  \n\nThe remote computer must be Linux.  You won't\
    \ have any luck in Windows or Mac with ROS + Kinect + NXT.  I don't use an IDE.\
    \  I use GVim and vim to edit files and compile and run things from the command\
    \ line.  ROS is very friendly with the command line.  \n\nSo get Ubuntu running\
    \ and see http://www.ros.org/wiki/ROS/Installation\n\nIf you haven't gone through\
    \ the ROS tutorials I suggest you start there, it'll only take a day or two to\
    \ get through them all: http://www.ros.org/wiki/ROS/Tutorials\n\nThen figure out\
    \ how to control your NXT robot from ROS http://www.ros.org/wiki/nxt\nSo make\
    \ a ROS node to control your robot.\n\nThe next step is to get the Kinect working\
    \ http://www.ros.org/wiki/ni\n\nThen you can make a ROS node to listen to the\
    \ Kinect data and send commands to the node controlling your NXT robot."

> 
> We are currently still trying to
> figure how to interface the Kinect
> with our NXT robot.
> 
> We have read on the internet that it
> is possible to used ROS-Kinect and
> ROS-NXT. Also, we have explored the
> possibility of using C# on OpenKinect.
> However, we are unable to figure how
> to interface both the NXT and Kinect
> such that the Kinect is able to
> control the NXT. Also, may we ask
> which software/IDE/platform which we
> could use to program both the NXT and
> Kinect at the same time?
