    `joint_state_publisher` [ignores](https://github.com/ros/joint_state_publisher/blob/noetic-devel/joint_state_publisher/src/joint_state_publisher/__init__.py#L84) planar joints. I think this is because [`sensor_msgs/JointState`](https://docs.ros.org/en/lunar/api/sensor_msgs/html/msg/JointState.html) assumes a single degree of freedom for each joint. I don't see any code in [`robot_state_publisher`](https://github.com/ros/robot_state_publisher/blob/ros2/src/robot_state_publisher.cpp) to handle multi-dimensional joints either, so this may just be missing functionality.
