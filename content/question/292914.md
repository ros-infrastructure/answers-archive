  body_markdown: "Just came to know, `Realsense` can't be used with `OpenNI`. So 2nd\
    \ option is ruled out.\nhttps://github.com/BlazingForests/realsense_camera/issues/20\n\
    \nThen I tried again the very 1st method, i.e. to add the required links in the\
    \ URDF and launch the `camera node` separately. I got help from this [link](https://github.com/01org/sawr).\n\
    It finally worked with below changes:\n\nAdding 5 links in URDF as below:\n\n\
    \    1. camera_link\n    2. camera_depth_frame\n    3. camera_color_frame\n  \
    \  4. camera_depth_optical_frame\n    5. camera_color_optical_frame\n\nAnd one\
    \ more change, I added one nodelet in camera launch file, which is as below:\n\
    \n    <!-- Start nodelet manager -->\n        <node pkg=\"nodelet\" \n       \
    \       type=\"nodelet\" \n              name=\"nodelet_manager\" \n         \
    \     args=\"manager\"\n              output=\"screen\"/>\n\nWith these changes,\
    \ I was able to get point clouds in RViz with moveit environment.\n\nPlease let\
    \ me know, if somebody face problem with integrating `Intel Camera`.\n\nSaurabh"
