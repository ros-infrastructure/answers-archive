    To install Gazebo stand-alone:

        sudo apt-get install gazebo7

    But to use it with ROS:

        sudo apt-get install ros-kinetic-gazebo-ros-pkgs

    See also [gazebosim.org/Installing gazebo_ros_pkgs](http://gazebosim.org/tutorials?tut=ros_installing).
