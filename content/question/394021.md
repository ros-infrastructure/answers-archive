    This is a [known bug](https://github.com/ros2/ros2cli/issues/534). Someone found a workaround [here](https://github.com/ros2/ros2cli/issues/534#issuecomment-957516107).
    Basically you can run the following to re-enable the autocomplete.

        # argcomplete for ros2 & colcon
        eval "$(register-python-argcomplete3 ros2)"
        eval "$(register-python-argcomplete3 colcon)"
