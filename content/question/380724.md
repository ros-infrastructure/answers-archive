  body_markdown: "Since `armhf` is not officially supported ROS 2 architecture `rosdep`\
    \ will not work. You have to download the source code of each package you need.\
    \ To make the process easier you may benefit from `rosinstall_generator`:\n\n\
    \    rosinstall_generator ${PACKAGE_NAME} --deps --exclude RPP --rosdistro ${ROS_DISTRO}\
    \ > /tmp/rospkgs.repos\n    vcs import ${ROS_WS}/src < /tmp/rospkgs.repos\n\n\
    Also, here I wrote an explanation on how to cross-compile ROS 2 for `armhf`: \
    \ \nhttps://github.com/cyberbotics/epuck_ros2/tree/master/installation/cross_compile"
