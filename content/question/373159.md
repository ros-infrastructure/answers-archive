    \ a second map public with a topic other than \"map\", use the `map_topic` parameter.\n\
    \n> map_topic (string, default: \"map\")\nThis parameter is useful when you have\
    \ multiple costmap instances within a single node that you want to use different\
    \ static maps. New in navigation 1.3.1\n\nStacking cost maps can be achieved by\
    \ using the `use_maximum` parameter.\n\n> use_maximum (bool, default: false)\n\
    Only matters if the static layer is not the bottom layer. If true, only the maximum\
    \ value will be written to the master costmap.\n\nThe above is taken from the\
    \ documentation at http://wiki.ros.org/costmap_2d/hydro/staticmap.\n\nFor example,\
    \ you can use the following\n\n### global_costmap configuration yaml file\n\n\
    \    global_costmap:\n      plugins: \n        - {name: static_layer1, type: \"\
    costmap_2d::StaticLayer\"}\n        - {name: static_layer2, type: \"costmap_2d::StaticLayer\"\
    }\n    \n      static_layer1:\n        map_topic: \"map\" \n    \n      static_layer2:\n\
    \        map_topic: \"map2\"\n        use_maximum: true\n\n### Excerpt from launch\
    \ file\n\n    <node name=\"static_layer1\" pkg=\"map_server\" type=\"map_server\"\
    \ args=\"$(find XXX)/maps/YYY.yaml\"/>\n    <node name=\"static_layer2\" pkg=\"\
    map_server\" type=\"map_server\" args=\"$(find XXX)/maps/ZZZ.yaml\">\n       \
    \ <remap from=\"map\" to=\"map2\"/>\n    </node>\n"

    Maybe a different and more flexible approach is to write your own costmap layer and give it a geometry_message::polygon as input for the restricted areas. Like this you don't have to define the areas before the navigation starts, but you can change the restricted areas during navigation.

    Take a look at the [create a new layer tutorial](http://wiki.ros.org/costmap_2d/Tutorials/Creating%20a%20New%20Layer) in the wiki. Even though i must admit, that it is very low level. For more information i recommend the [costmap layer package](https://github.com/DLu/navigation_layers) from David Lu as a reference.

    I did something similar for road navigation to prevent the robot from entering the left lane when the right one is free.
