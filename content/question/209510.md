  body_markdown: "The tutorial you are referring are using topics saved in the ros\
    \ bags provided (with suffix \"throttle\"). What are the topics sent in the \"\
    /artemis/navCam\" namespace by your stereo camera? You probably not need a remap\
    \ at all for the stereo_image_proc, as well as all the republish nodes. \n\n**EDIT1**:\
    \ \nYou have two stereo odometry nodes running (rtabmap_ros/stereo_odometry and\
    \ viso2_ros/stereo_odometer). Use only one.\n\n**EDIT2**:\nMake sure that all\
    \ the rtabmap input topics you set are really published:\n\n    <remap from=\"\
    left/image_rect\" to=\"$(arg camera)/left/image_rect_color\"/>\n    <remap from=\"\
    right/image_rect\" to=\"$(arg camera)/right/image_rect_color\"/>\n    <remap from=\"\
    left/camera_info\" to=\"$(arg camera)/left/camera_info_throttle\"/>\n    <remap\
    \ from=\"right/camera_info\" to=\"$(arg camera)/right/camera_info_throttle\"/>\n\
    \    <remap from=\"odom\" to=\"$(arg camera)/odometry\"/>\n\nUsing rostopic tool\
    \ (assuming that $(arg camera)  = \"camera\"):\n\n    $ rostopic echo hz camera/left/image_rect_color\n\
    \    $ rostopic echo hz camera/right/image_rect_color\n    $ rostopic echo hz\
    \ camera/left/camera_info_throttle\n    $ rostopic echo hz camera/right/camera_info_throttle\n\
    \    $ rostopic echo hz camera/odometry\n\nIs \"throttle\" suffix still right?"
