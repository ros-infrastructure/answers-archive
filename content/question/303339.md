    \ best use `sys.argv[1:]` which returns all other args as a list and then you\
    \ can iterate through that.\n\nAnother option is to check the number of arguments\
    \ (python: `len(sys.argv)`, C++: check `argc`) and manually retrieve the respective\
    \ arguments from `argv` starting at index 1.\n\nFor ROS, depending on your usecase,\
    \ another option would be to use ROS parameters..."
