  body_markdown: "I know it's quite late to answer this but I recently did compare\
    \ two results from two SLAM packages. For the comparison I used a Python package\
    \ called [evo](https://michaelgrupp.github.io/evo/) that is meant to be used to\
    \ compare odometry and SLAM. \n\nI have described my full workflow in [this post](https://msadowski.github.io/Comparing-SLAM-with-ROS-evo/)\
    \ but in short it consists of the following steps:\n\n- Record a bag file while\
    \ the robot is moving around space\n- Replay the data while running slam packages\
    \ of your choice, record these as bag files again\n- Run a script that will convert\
    \ the logged tf to a message supported by evo on every bag file\n- Merge two bag\
    \ files\n\nWhat I was missing in my experiments is groundtruth but if you have\
    \ this information you will easily be able to add it.\n\n"
