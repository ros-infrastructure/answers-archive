  body_markdown: "> So there is two big issues that make impossible install ROS in\
    \ RPi4,\n\nI believe the issue is more that you're trying to build a version of\
    \ ROS on a platform that is not officially supported, with versions of dependencies\
    \ that are not supported (by Kinetic at least).\n\n[ros/rospack#92](https://github.com/ros/rospack/issues/92)\
    \ seems to be your exact issue.\n\nThe problem appears to be that you are attempting\
    \ to build ROS Kinetic on an unsupported platform. Kinetic is only supported on\
    \ (from [REP 3: Target Platforms - Kinetic Kame (May 2016 - May 2021)](http://www.ros.org/reps/rep-0003.html#kinetic-kame-may-2016-may-2021)):\n\
    \n> Required Support for:\n> \n>  -  Ubuntu Wily (15.10)\n>  -  Ubuntu Xenial\
    \ (16.04)\n> \n> Recommended Support for:\n> \n>  -  Debian Jessie\n\nAnd with\
    \ Boost version `1.55`. Anything else is not explicitly supported.\n\nThe comments\
    \ on [ros/rospack#92](https://github.com/ros/rospack/issues/92) seem to suggest\
    \ that the Kinetic version of `rospack` (and probably other packages) depend on\
    \ the `tr1` headers. Newer versions no longer require them ([ros/rospack#80](https://github.com/ros/rospack/pull/80)).\n\
    \nIf you have the option, I would suggest you try to build Melodic from source,\
    \ as that should be compatible with Boost `1.65`.\n\nThere is still no guarantee\
    \ though, as Melodic is not officially supported on Raspbian.\n"
