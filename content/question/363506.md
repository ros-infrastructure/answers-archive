    \nThe `frame_id` is set to `camera_link`. I don't know if it is on a robot or\
    \ it is a single camera in simulation, for a robot, you may add in the URDF the\
    \ optical rotation. Otherwise if `camera_link` is your only frame, in ros1 we\
    \ would add a static transform publisher in the launch file like this:\n\n   \
    \ <node pkg=\"tf\" type=\"static_transform_publisher\" name=\"camera_optical_rotation\"\
    \n            args=\"0 0 0 -1.5707963267948966 0 -1.5707963267948966 base_link\
    \ camera_link 100\" /> \n\nThen use `frame_id` set to `base_link` for rtabmap\
