    Yes, you only have to add a class for your hardware that implement the methods `read()`, `write()` and `time()`, then include it and call the constructor in the `ros.h` file.

    You can use some implementations as examples:

    - [rosserial_mbed](https://github.com/ros-drivers/rosserial/blob/jade-devel/rosserial_mbed/src/ros_lib/MbedHardware.h)
    - [rosserial_arduino](https://github.com/ros-drivers/rosserial/blob/jade-devel/rosserial_arduino/src/ros_lib/ArduinoHardware.h)
    - [rosserial_chibios](https://github.com/SyrianSpock/stm32f4discovery_rosserial/blob/master/src/ros_lib/ChibiOSHardware.h)
