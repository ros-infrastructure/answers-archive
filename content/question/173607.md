    The Occipital "Structure Sensor" looks like an overpriced version of the Kinect or Xtion sensor. It's only selling point seems to be a much smaller size, but it appears to uses the same technology as Kinect/Xtion, so based on [this page](http://www.ros.org/news/2014/04/occipital-committed-to-support-openni.html), it might work with the same code/packages for those sensors that use the OpenNI driver. I haven't used them though, so I can't say for sure if they'll work.
