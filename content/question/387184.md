    For planners and controllers development there is the [simple_planning_simulator](https://autowarefoundation.gitlab.io/autoware.auto/AutowareAuto/simple_planning_simulator-package-design.html). As its name indicates it is very simple and only simulates the motion of the vehicle.
    It can be launched instead of LGSVL with the command `ros2 launch simple_planning_simulator simple_planning_simulator.launch.py`.
    You can try it with the AVP demo after deactivating the `lgsvl_interface`.

    There is a ROS2 bridge for CARLA so it should be possible to make it work but could require quite a bit of work:
    https://carla.readthedocs.io/projects/ros-bridge/en/latest/ros_installation_ros2/
