  body_markdown: "> The main function of rospack is to\n> crawl through the packages\
    \ in ROS_ROOT\n> and ROS_PACKAGE_PATH, read and parse\n> the manifest.xml for\
    \ each package, and\n> assemble a complete dependency tree\n> for all packages.\n\
    \nAnd more specifically for `rospack profile`:\n\n> rospack\u2019s performance\
    \ can be\n> adversely affected by the presence of\n> very broad and/or deep directory\n\
    > structures that don\u2019t contain manifest\n> files. If such directories are\
    \ in\n> rospack\u2019s search path, it can spend a\n> lot of time crawling them\
    \ only to\n> discover that there are no packages to\n> be found. You can prevent\
    \ this latency\n> by creating a rospack_nosubdirs file\n> in such directories.\
    \ If rospack seems\n> to be running annoyingly slowly, you\n> can use the profile\
    \ command, which\n> will print out the 20 slowest trees to\n> crawl (or use profile\
    \ --length=N to\n> print the slowest N trees).\n\nSo the directories *without*\
    \ *'s are the ones that contain packages.\n\nThis can all easily be found at the\
    \ [rospack documentation](http://docs.ros.org/independent/api/rospkg/html/rospack.html)"
