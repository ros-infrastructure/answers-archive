  body_markdown: "usually the reason for message `Failed to get a plan.` is not related\
    \ to the *teb_local_planner* \nsince it means that even the global planner cannot\
    \ find a plan. \nThis happens if the goal is not reachable or if it is located\
    \ inside an obstacle. \nIt also occurs if the robot by itself is not collision\
    \ free. Here you should verify your costmap footprint.\n\nIf only the teb_local_planner\
    \ cannot find a valid plan, the error message is differently:\n\n`TebLocalPlannerROS:\
    \ trajectory is not feasible. Resetting planner...`"
