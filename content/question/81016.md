    `roslaunch` is supposed to be used with [XML launch files](http://wiki.ros.org/roslaunch/XML). However you attempting to launch a Python script.

    To run Python scripts and binary executables use [rosrun](http://wiki.ros.org/rosbash#rosrun) instead. It also might be necessary to add 'executable' flag to that script with:

        $ chmod a+x pt_keyboard.py

    Otherwise `rosrun` will not run the script.
