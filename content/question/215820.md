    \ right about pcl-kinfu depending on OpenNI. From memory the OpenNI code is only\
    \ necessary for capturing the data, and not the underlying algorithm, but unfortunately\
    \ it is considered a core dependency by the build process. Many checkboxes only\
    \ appear conditionally if certain libraries are found, therefore, if OpenNI isn't\
    \ found, the kinfu-related checkboxes won't appear.\n\nHere are my old notes if\
    \ anyone finds them useful:\n\nIn CMake, make sure the following checkboxes are\
    \ selected:\n\n - BUILD_CUDA \n - BUILD_GPU \n - BUILD_apps\n - BUILD_examples\n\
    \nSelect Configuration Manager - the following Build checkboxes at a minimum are\
    \ necessary for kinfu:\n\n - pcl_core\n - pcl_gpu_kinfu\n - pcl_gpu_containers\n\
