  body_markdown: "In general I would not use setJointPosition or setAngle if you have\
    \ the physics on, but use some sort of a controller. \nIf you want a simple one,\
    \ just use the gazebo PID controller and therefore I use dynamic reconfigure to\
    \ set the PID values, which is quite convenient for me.\n\nHere's an example of\
    \ a controller of the [drcsim car](https://bitbucket.org/osrf/drcsim/src/c7102caafb3f/plugins/DRCVehiclePlugin.cc?at=default).\n\
    \nAnd that's an example how you would get the dynamic reconfigure in. (Or you\
    \ can check out [gazebo_ros_multicamera_utils.cpp](https://bitbucket.org/osrf/drcsim/src/51e8a9a057ef/ros/atlas_msgs/gazebo_ros_multicamera_utils.cpp?at=multi_camera)\n\
    \n    dyn_srv_ = new dynamic_reconfigure::Server<some_plugins::MyConfig>(*this->rosnode_);\n\
    \    dynamic_reconfigure::Server<some_plugins::MyConfig>::CallbackType f = boost::bind(&MyClass::DynamicReconfigureCallback,\
    \ this, _1, _2);\n    dyn_srv_->setCallback(f);\n\n\n    void MyClass::DynamicReconfigureCallback(some_plugins::MyConfig\
    \ &config, uint32_t level)\n    {\n        // Wheel gains\n        oneWheelPID.SetPGain(config.p_wheel);\n\
    \        oneWheelPID.SetIGain(config.i_wheel);\n        oneWheelPID.SetDGain(config.d_wheel);\n\
    \        // Steering gains\n        oneWheelSteeringPID.SetPGain(config.p_steering);\n\
    \        oneWheelSteeringPID.SetIGain(config.i_steering);\n        oneWheelSteeringPID.SetDGain(config.d_steering);\n\
    \    }"
