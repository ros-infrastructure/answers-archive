  body_markdown: "As by today it is not possible to install `libuvc_ros` via apt-get.\n\
    Here are the steps to install `libuvc_ros` manually under ROS kinetic:\n\n   \
    \ # Install dependencies, as I wasn't able to install them via rosdep\n    sudo\
    \ apt-get install libusb-1.0-0 libusb-1.0-0-dev\n\n    # Clone libuvc_ros and\
    \ libuvc to your workspace\n    cd /path/to/your/workspace/src\n    git clone\
    \ https://github.com/ktossell/libuvc_ros.git\n    git clone https://github.com/ktossell/libuvc.git\n\
    \n    # The following instructions come from the libuvc's Readme file\n    mkdir\
    \ libuvc/build\n    cd libuvc/build\n    cmake ..\n    make && sudo make install\n\
    \n    # Run catkin\n    cd /path/to/your/workspace\n    catkin_make    "
