  body_markdown: "`copy.deepcopy` is the recommended way of creating a deep copy of\
    \ a message, according to [this ticket](https://code.ros.org/trac/ros/ticket/2430).\n\
    \n**Edit**:\nYou probably named a function copy after the import line. Python\
    \ has only one namespace for variables and functions (in contrast to Common Lisp\
    \ for instance), i.e. by naming a function `copy`, you overwrite the package `copy`.\
    \ Either do \n\n    from copy import deepcopy \n\nand just call `deepcopy`, not\
    \ `copy.deepcopy` or rename your function. You can also import the module `copy`\
    \ under a different name:\n\n    import copy as copy_module\n\nThen you can call\
    \ the deepcopy function like this:\n\n    odom_new = copy_module.deepcopy(odom_old)\n"
