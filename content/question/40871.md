    rosjava provides Java classes for creating ROS Nodes in java and communicating with any ROS node, as well as a java implementation of a ROS master.

    To run java or rosjava on a robot, you only need a standard JVM on the robot.
    You can run rosjava nodes anywhere, on the robot or remotely, and they do not need the java rosmaster to run.

    From [ros.org](http://ros.org/wiki):
