  body_markdown: " I found an answer how to do that. So there is a Point Tool in RViz\
    \ which is implemented in files `point_tool.h`, `point_tool.cpp`. The event listener\
    \ `processMouseEvent` captures **any** mouse event, and what we need to do is\
    \ to select a point the same way as it is done in the Point Tool with the only\
    \ difference that we do not listen events when the mouse pointer does not move.\
    \ Here's the basic implementation of the callback:\n\n    int PointHighlightingTool::processMouseEvent(rviz::ViewportMouseEvent\
    \ &event) {\n      int flags = 0;\n    \n      // Check if mouse moved\n     \
    \ if ((event.x == event.last_x) && (event.y == event.last_y)) {\n        return\
    \ flags;\n      }\n    \n      Ogre::Vector3 pos;\n      bool success = context_->getSelectionManager()->get3DPoint(\
    \ event.viewport, event.x, event.y, pos );\n    \n      if (success)  // A point\
    \ is found\n      {\n        // Coordinates are stored in the `pos` variable and\
    \ we can do anything we like with them from now on\n        std::ostringstream\
    \ s;\n        s.precision(3);\n        s << \" [\" << pos.x << \",\" << pos.y\
    \ << \", \" << pos.z << \"]\";\n        ROS_INFO(\"3D Point %s\", s.str().c_str());\n\
    \      }\n    \n      return flags;\n    }"
