    As far as I know, the only easy way* to concatenate a LaunchConfiguration with a string is by passing them as a list in any parameter of type "SomeSubstitutionsType" as shown [here]( https://answers.ros.org/question/358655/ros2-concatenate-string-to-launchargument/).

    *The harder convoluted way would be by using the OpaqueFunction as described in [this answer](https://answers.ros.org/question/322636/ros2-access-current-launchconfiguration/?answer=359167#post-id-359167). It's feels hackier but gives more flexibility
