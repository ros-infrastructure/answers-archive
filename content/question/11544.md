  body_markdown: "When calling a service, the server node will handle one call at\
    \ a time and queue up the rest. Therefore, it will act on them in the same order\
    \ that they were received. This is the same as if you were to publish to the same\
    \ topic from multiple sources simultaneously. The messages would be placed in\
    \ the queue in order that they are received. "
