    I'd recommend using TinyXML as it is already used by several important packages in ROS (e.g. URDF, rviz, rospack). For an example of how to use TinyXML in compilation, check out the [CMakeLists.txt](https://github.com/ros/robot_model/blob/7e0ba6c1fc5fab8f99a3a6fbb925fc40e6d683a2/kdl_parser/CMakeLists.txt) file from the [kdl_parser](http://wiki.ros.org/kdl_parser) package. A relatively self-contained example of how to read an xml file is in their [kdl_parser.cpp](https://github.com/ros/robot_model/blob/7e0ba6c1fc5fab8f99a3a6fbb925fc40e6d683a2/kdl_parser/src/kdl_parser.cpp) file.
