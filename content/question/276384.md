  body_markdown: "Hi,\n\nMaybe I found a solution, not the pretiest, not the easiest,\
    \ but it may work (but it's cpp only) : \n\n1. You can find the IP of a ROS node\
    \ by contacting the master (`rosnode info my_node` will return the ip of the node,\
    \ with many other information)\n\n2. According to [The connection header documentation](http://wiki.ros.org/ROS/Connection%20Header),\
    \ the node currently sending data can be found in the connection header.\n\n3.\
    \ You can use [Message event](http://docs.ros.org/kinetic/api/roscpp_traits/html/classros_1_1MessageEvent.html#a183e1bc02157dcc393b57e7a80fafdf3)\
    \ to get the connection header.\n\n4. To manipulate Message event, you can check\
    \ [Passthrough Filter](https://github.com/ros/ros_comm/blob/lunar-devel/utilities/message_filters/include/message_filters/pass_through.h),\
    \ just adapt the code to not let the message go through unless the IP is OK. Also\
    \ check the [message filter documentation.](http://wiki.ros.org/message_filters)\n\
    \nThe 3. and 4. are optional, if you can manage to get the connection header by\
    \ an another way, or the message event by an another way. \n\nIt may be easier\
    \ in Python but i'm not experimented enough in python to help.\n\n\n----------\n\
    \n\nEdit from [Creed comment](https://answers.ros.org/question/276384/is-there-a-way-to-determine-ip-address-of-publisher-for-each-message/?answer=276407#post-id-276407)\
    \ : \n\n\nIn CPP, use [the cpp publisher tutorial / 2.4 MessageEvent](http://wiki.ros.org/roscpp/Overview/Publishers%20and%20Subscribers#2.5)\
    \ to get message event.\n\nfor python check Creed's comment below"

 Hello,

I'm currently developing small system for monitoring and management of a mobile robot group in ROS.
One of system's features is reservation mechanism, which lets students reserve exclusive access to the robot - reserved robot only reacts to commands coming from that computer.
I want to base it on IP addresses of computers in laboratory.

Here comes my question: Is there a (ROS-based) way to determine IP address of publisher for each message coming to the robots from computers in the laboratory?
