  body_markdown: "I got it working and prepared an example on [github](https://github.com/tuw-robotics/ros2_cyclonedds_wireguard)\n\
    \nUsing Eclipse Cyclone DDS, but one has to set some variables\n\n    export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp\n\
    \    export CYCLONEDDS_URI=file:///$(pwd)/cyclonedds.xml \n\nand the cyclonedds.xml\
    \  looks like:\n\n\n    <?xml version=\"1.0\" encoding=\"UTF-8\" ?>\n    <CycloneDDS\
    \ xmlns=\"https://cdds.io/config\" xmlns:xsi=\"http://www.w3.org/2001/XMLSchema-instance\"\
    \ xsi:schemaLocation=\"https://cdds.io/config https://raw.githubusercontent.com/eclipse-cyclonedds/cyclonedds/master/etc/cyclonedds.xsd\"\
    >\n        <Domain id=\"any\">\n            <General>\n                <Interfaces>\n\
    \                    <NetworkInterface name=\"wg0\"/>\n                </Interfaces>\n\
    \            </General>\n            <Discovery>\n                <Peers>\n  \
    \              <Peer address=\"192.168.33.80\"/>\n                <Peer address=\"\
    192.168.33.51\"/>\n                </Peers>\n                <ParticipantIndex>auto</ParticipantIndex>\n\
    \            </Discovery>\n        </Domain>\n    </CycloneDDS>\n\n"
