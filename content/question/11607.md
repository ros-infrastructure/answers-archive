    The standalone PCL library is not compatible with ROS electric. This problem will be resolved in some future release.

    To run PCL with ROS, install the [perception_pcl](http://www.ros.org/wiki/perception_pcl) stack, and perhaps [perception_pcl_addons](http://www.ros.org/wiki/perception_pcl_addons).
