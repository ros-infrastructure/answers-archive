  body_markdown: |-
    There has been no concrete work done that I know about.

    There has been [some discussion](https://github.com/ros-drivers/velodyne/issues/15) of adding support for the 64E S2 model's IMU and GPS data. While the 32E could be handled in a separate driver (I believe), that is not the case for 64E models with GPS attached.

    If we're going to support one GPS, we might as well support the other.

    Help with gathering data, coding or testing would be welcome.

    **EDIT**: there is now an experimental ``gps_imu`` [branch in the source repository](https://github.com/ros-drivers/velodyne/tree/gps_imu). It's not yet ready to release, but user testing would be helpful. If you do try it, please post your results (both positive and negative) to [issue #24](https://github.com/ros-drivers/velodyne/issues/24).
