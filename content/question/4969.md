  body_markdown: "1. Look at the `turtlebot sim](http://wiki.ros.org/turtlebot_simulator)\n\
    \n2. There is some overhead with Gazebo and ROS communication, but it's negligible\
    \ compared with the performance costs of physics and sensor data generation.\n\
    \n3. Creating a maze-like environment is easy. There are a couple of approaches:\n\
    \n    a. Create a maze using boxes. \n\n    b. Create a maze in a 3d mesh editor,\
    \ such as Blender\n\n    c. Create a maze using the heightmap geometry.\n\n  \
    \  Option a will have the greatest performance, but will take the most time to\
    \ create the world. Option B will be the most inefficient, but will give you a\
    \ lot of flexibility. Option C sits between option A and B.\n\n\n4. I use 16GB\
    \ Ram and an nvidia gtx-550-Ti with good results."
