  body_markdown: "I'll answer in two parts:\n\n 1. **Sample Navigation Using SICK**\
    \    \n    Take a look at [cwru-ros-pkg](https://github.com/cwru-robotics/cwru-ros-pkg/tree/master/cwru_semi_stable)\
    \ for a complete navigation stack setup using the SICK laser. The launch files\
    \ you should look at are the `cwru_bringup_no_tele.launch` and `cwru_nav/start_nav.launch`\
    \ (though `start_nav.launch` assumes that someone has already brought up a `map_server`,\
    \ like in `cwru_nav/start_amcl_2ndfloor.launch`). You should be able to trace\
    \ the included launch files, configs and such to get an example working navigation\
    \ stack for our differential drive robots.\n 2. **Odometry for the Pioneer** \
    \   \n    Yes, you can use something like [p2os](http://www.ros.org/wiki/p2os)\
    \ to get odometry from a Pioneer. See the [Getting Started with p2os](http://www.ros.org/wiki/p2os/Tutorials/Getting%20Started%20with%20p2os)\
    \ tutorial for how to setup your Pioneer. As long as p2os outputs reasonable odometry\
    \ estimates and the required transforms, you should be able to use your SICK to\
    \ make a map with [gmapping](http://www.ros.org/wiki/gmapping)."
