  body_markdown: "In order for a package to be available as a binary package, it has\
    \ to be released into the corresponding ROS distribution.\n\nIn this case the\
    \ package that you are looking for has not been released into `noetic` yet.\n\n\
    A good first step would be to ask the maintainers of that package to create a\
    \ `noetic` release.  You can file an issue on their tracker on Github: https://github.com/strands-project/mongodb_store\
    \  \n\nThere may be reasons that this release hasn't been done yet (lack of maintainer\
    \ time, or changes between Ubuntu versions making the release non-trivial).  In\
    \ that case, it may take some time to get a release ready and available as a binary\
    \ package.\n\nIn the meantime, you may consider building that package from source\
    \ as part of your workspace.  If you find that there are things that you need\
    \ to fix in order to get it to work with `noetic` and `focal`, I'm sure that the\
    \ maintainers would appreciate a pull request with those changes."
