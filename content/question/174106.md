A question for those familiar with the Creating a New Layer (in costmap_2d/Tutorials) tutorial

to retrieve some infomation from an external publisher node.

2). Then I added to the class `SimpleLayer` the private member `ros::Subscriber sub_` and a callback function (as a private method). To initialize the subscriber I added the following line to `SimpleLayer::OnInitialize()` right before the assignment of the dynamic_reconfigure server:

`
  sub_ = nh.subscribe("the_published_topic", 1000, &SimpleLayer::MyCallbackFunction, this);

where `SimpleLayer::MyCallbackFunction` should print on screen the message published by `the_published_topic`. The plugin is
correctly installed and launching `move_base` it is alse loaded, anyway it seems that `SimpleLayer::MyCallbackFunction` is
not called during the execution (output is already set to screen).
