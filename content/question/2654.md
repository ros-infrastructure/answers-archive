    You can communicate using gztopic messages using the gazebo::transport system. There are two example programs that use gazebo::transport, [publisher](https://bitbucket.org/osrf/gazebo/src/c21a92eb17f903c63ddb1a6502942ab5e46d2836/examples/stand_alone/publisher?at=default) and [listener](https://bitbucket.org/osrf/gazebo/src/c21a92eb17f903c63ddb1a6502942ab5e46d2836/examples/stand_alone/listener?at=default). You should be able to replicate this code in your plugins using [gazebo's built-in protobuf message types](http://gazebosim.org/msgs.html) to accomplish your goal. Feel free to keep asking if you need more guidance.
