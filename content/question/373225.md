  body_markdown: "ignoring the fact you've likely not installed ROS Noetic, but an\
    \ upstream version:\n\n> where can i find a list of the packages that were used\
    \ and their version for the Noetic distribution? \n\none way to see which versions\
    \ of packages are currently part of the released set would be to visit the [Noetic\
    \ status page](http://repositories.ros.org/status_page/ros_noetic_default.html),\
    \ which lists the versions of all packages in the *Version* column.\n\nThis information\
    \ is only accurate for versions of ROS installed from `repositories.ros.org`,\
    \ not for the [UpstreamPackages](http://wiki.ros.org/UpstreamPackages).\n\nNote\
    \ that the page linked is for the `amd64` build. For RPi you'll have to look at\
    \ the pages for `arm64` or `arm32` for Debian or Ubuntu at [repositories.ros.org/status_page](http://repositories.ros.org/status_page).\n\
    \nAnd also note: *only* those OS versions get binary packages built by the ROS\
    \ buildfarm. On other OS (such as the popular Raspbian) you'll have to build from\
    \ source.\n\n---\n\nEdit: another option would be to look at the [noetic/distribution.yaml](https://github.com/ros/rosdistro/blob/7ff6b1a77cc0e171b86d8b51974ccc3f760cce3d/noetic/distribution.yaml)\
    \ file. This contains all packages released with Bloom. Part of the metadata is\
    \ the version of the released package.\n\nFor `ros_comm` for instance:\n\n   \
    \   ros_comm:\n        [..]\n        release:\n          packages:\n         \
    \ [..]\n          - ros_comm\n          [..]\n          tags:\n            release:\
    \ release/noetic/{package}/{version}\n          url: https://github.com/ros-gbp/ros_comm-release.git\n\
    \          version: 1.15.9-1\n        source:\n          [..]\n        status:\
    \ maintained\n\nwhich also shows that your version of `ros_comm` is rather old."
