    \ problem than a gazebo one...\n\nThere is no Programm called `rospy`. `rospy`\
    \ is a rospackage containing other scripts and libraries...\nOn groovy there is\
    \ an alias `rospython`(I don't know if it is there on fuerte too...) which calls\
    \ a python shell with roslibs loaded...\n\nif it is really not installed the package\
    \ `ros-fuerte-ros-comm` holds the rospy package.\nThe drcs package should install\
    \ this as a dependency so this shouldn't be a Problem.\n\nRos Python Scripts should\
    \ simply be located in a scripts folder inside your rospackage. After you created\
    \ the script you can execute it with the command \n\n`rosrun <package> <script_name>`\n\
    \n\nI hope this helps you. if you want to now more about howto build/run ROS-Script\
    \ you should have a look at some ros tutorials in the ROS wiki... (for example\
    \ [python ros subscriber](http://www.ros.org/wiki/ROS/Tutorials/WritingPublisherSubscriber%28python%29))\n\
    You probably want to look at rosbuild not catkin builds... (in some tutorials\
    \ this can be switched at the top of the tutorials)\n\nI hope this helps you...\n\
    otherwise you should look into the ros forums..."
