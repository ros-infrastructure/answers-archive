- body_markdown: |-
    The delay is calculated as `curr_rostime.to_time() - msg.header.stamp.to_time()`. In other words, it uses the current time of the subscriber node and subtracts it to the time available in the message header. Please see [here](https://github.com/ros/ros_comm/blob/2a92e3d3ccc43ce3e9eac1b4e76bb7450c564aed/tools/rostopic/src/rostopic/__init__.py#L325-L397) for the implementation. A similar discussion is available [here](https://answers.ros.org/question/377573/).

    BTW, I noticed that you are running the subscriber inside Virtual Box. If the camera publisher is running on a different machine (in your case, the host machine), then you need time synchronization. In simple words, the host and guest machine must have the same time. At present, I suspect that this time is different.
