    The CAN messages used by Autoware depend on the vehicle hardware being used. Autoware itself does not include any of this information. For vehicles that Autoware supports out-of-the-box, it is included in binary files provided by hardware manufacturers (such as the driver for the Yamaha golf carts, `ymc`). You will need to write your own CAN interface node if your hardware is not one of the supported hardware.
