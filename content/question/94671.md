    \n$rosparam set use_sim_time true\n\n$rosrun tf static_transform_publisher 0 0\
    \ 0 0 0 0 base_link laser 100\n\n$rosbag play --clock <your-ros-bag.bag>\n\nFor\
    \ slam_gmapping you need tf and laserScan. after above commands, open a new terminal\
    \ then execute $rostopic list \n\nthen look whether tf and laserScan are being\
    \ published. if you see /scan then run $rosrun gmapping slam_gmapping scan:=scan\n\
    \nif you see /base_scan then run $rosrun gmapping slam_gmapping scan:=base_scan\n\
    \nto see map in rviz run $rosrun rviz rviz \n\nthen add a map then put topic /map\
    \ \n\nto save a map run $rosrun map_server map_saver -f map1 \n\nit will save\
    \ a map named map1.pgm in current directory. \n\nLet me know whether it works\
