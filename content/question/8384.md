    \ why the service to set physics properties does not work.\nI found the reason\
    \ and this is a problem only before gazebo 3.0. From gazebo_ros the set physics\
    \ properties service calls the generic  PhysicsEngine setMaxContacts which does\
    \ not in turn call the derived ODEPhysicsEngine setMaxContacts due to a mismatch\
    \ between the arguments types between the class and its parent class (double vs\
    \ unsigned int) \nThis fix and the following probably solved the issue in gazebo\
    \ 3.0\nhttps://bitbucket.org/osrf/gazebo/diff/gazebo/physics/PhysicsEngine.hh?diff2=b15c2c925cb1&at=minor_abi_3.0\n\
    \nrecompiling gazebo2.2 from source with the double to unsigned int worked for\
    \ me, I could set max contacts with the set_physics_properties"
