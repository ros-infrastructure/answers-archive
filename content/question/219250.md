     [This](http://answers.ros.org/question/143841/how-to-save-octomap/) may be what you want to know; in a nutshell use OctoMap designated formats `.ot` or `.bt`.

    If you want to store the `PointCloud` data as its file format .pcd, there's an [old hack](http://answers.ros.org/question/9367/is-there-an-existing-implementation-to-save-an-octomap-octree-as-a-pcd-file/) that I'm not sure if this still works.

    If you don't need the 3D voxels and only need 2D map projected from OctoMap, see [this thread](http://answers.ros.org/question/74617/how-to-save-a-2dmap-obtained-from-a-topic-published-by-octomap/).
