    One way to do this is to implement a custom Gazebo plugin. We've done that in the package [diffdrive_gazebo_plugin](http://wiki.ros.org/diffdrive_gazebo_plugin). To use it, you'll have to add it to your URDF, like [here](https://github.com/uos/kurt_driver/blob/hydro/kurt_base/urdf/kurt_indoor.urdf.xacro#L60). If you want to see it in action, you can use the [kurt_empty_world.launch](https://github.com/uos/kurt_driver/blob/hydro/kurt_gazebo/launch/kurt_empty_world.launch) file to start it, and [uos_diffdrive_teleop](https://github.com/uos/uos_tools/blob/hydro/uos_diffdrive_teleop/launch/key.launch) to send Twist commands.

    Our plugin is for a six-wheeled robot, but modifying it for your four-wheeled robot shouldn't be too hard.
