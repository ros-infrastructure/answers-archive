  body_markdown: "Gazebo has a position_3d plugin that will give you the robot's height.\
    \ You can use this plugin like so:\n\n    <gazebo>\n      <controller:gazebo_ros_p3d\
    \ name=\"p3d_base_controller\" plugin=\"libgazebo_ros_p3d.so\">\n        <alwaysOn>true</alwaysOn>\n\
    \        <updateRate>100.0</updateRate>\n        <bodyName>base_link</bodyName>\n\
    \        <topicName>base_pose_ground_truth</topicName>\n        <gaussianNoise>0</gaussianNoise>\n\
    \        <frameName>map</frameName>\n        <xyzOffsets>0 0 0</xyzOffsets> \n\
    \        <rpyOffsets>0 0 0</rpyOffsets>\n        <interface:position name=\"p3d_base_position\"\
    />\n      </controller:gazebo_ros_p3d>\n    </gazebo>\n\nThis plugin will publish\
    \ a `sensor_msgs/Odometry` message that you can extract height from. "
