    This assumes you have "source /opt/ros/diamondback/setup.bash" added to the end of ~/.bashrc



     1. <blockquote>sudo gedit /opt/ros/diamondback/setup.sh</blockquote>
     2. Change line <blockquote>export ROS_PACKAGE_PATH=/opt/ros/diamondback/stacks</blockquote> to <blockquote>export ROS_PACKAGE_PATH=/opt/ros/diamondback/stacks:~/ros_packages</blockquote>
     3. <blockquote>mkdir ~/ros_packages && cd ~/ros_packages</blockquote>
     4. <blockquote>svn checkout http://brown-ros-pkg.googlecode.com/svn/trunk/experimental/gscam</blockquote>
     5. restart terminal
     6. <blockquote>rosmake --rosdep-install gscam</blockquote>

    Cheers, Bryce
