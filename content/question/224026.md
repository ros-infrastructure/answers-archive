    \ link you have given the sensor in the urdf, e.g.\n\nif your robot.urdf has this\
    \ link for your sensor:\n\n            <link name=\"sonar_backward\">\n      \
    \          <visual>\n                        <geometry>\n                    \
    \            <box size=\"0.016 0.044 0.02\"/>\n                        </geometry>\n\
    \                        <origin xyz=\"${0.016/2} 0 0\" rpy=\"0 0 0\"/>\n    \
    \                    <material name=\"green\">\n                             \
    \   <color rgba=\"0 1 0 0.8\"/>\n                        </material>\n       \
    \         </visual>\n        </link>\n\nthen your message should have set msg.header.frame_id=\"\
    sonar_backward\". Of course this also requires a running joint_state_publisher\
    \ that publishes the corresponding joints.\n\nNext you need to check your tf tree\
    \ contains a valid path from your Fixed Frame in rviz (usually odom or map) to\
    \ your sensor (sonar_backward).\n "
