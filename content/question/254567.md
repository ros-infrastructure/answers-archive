    The ROS wiki is just that, a wiki, so anyone (with an account) can create pages like that.

    The procedure would be:

     1. register for an account
     1. request editing access (<del>[ros-infrastructure/roswiki#139](https://github.com/ros-infrastructure/roswiki/issues/139)</del> [ros-infrastructure/roswiki#258](https://github.com/ros-infrastructure/roswiki/issues/258) now)
     1. create a new page
     1. link to it from the `Books` page
