  body_markdown: "If I understand your question, you'd like to have a service call\
    \ an action and send the response for the service when the action goal is finished.\n\
    \nIdeally, we could wait on the futures related to the action client inside the\
    \ service callback, but we currently can't spin from inside a callback so that's\
    \ not an option.\n\nThe only method I can think of would be to use a flag to signal\
    \ when the action is done and check it in the service callback. To illustrate,\
    \ here is a crude example:\n\n<pre><code class=\"language-python\">\nimport time\n\
    from threading import Event\n\nfrom example_interfaces.srv import AddTwoInts\n\
    from example_interfaces.action import Fibonacci\n\nimport rclpy\nfrom rclpy.action\
    \ import ActionClient\nfrom rclpy.node import Node\nfrom rclpy.callback_groups\
    \ import ReentrantCallbackGroup\nfrom rclpy.executors import MultiThreadedExecutor\n\
    \n\nclass ActionFromService(Node):\n\n    def __init__(self):\n        super().__init__('action_from_service')\n\
    \        self.action_done_event = Event()\n\n        self.callback_group = ReentrantCallbackGroup()\n\
    \        self.action_client = ActionClient(\n            self, Fibonacci, 'fibonacci',\
    \ callback_group=self.callback_group)\n        self.srv = self.create_service(\n\
    \            AddTwoInts,\n            'add_two_ints',\n            self.add_two_ints_callback,\n\
    \            callback_group=self.callback_group)\n   \n    def feedback_callback(self,\
    \ feedback):\n        self.get_logger().info('Received feedback: {0}'.format(feedback.feedback.sequence))\n\
    \n    def add_two_ints_callback(self, request, response):\n        self.get_logger().info('Request\
    \ received: {} + {}'.format(request.a, request.b))\n        if not self.action_client.wait_for_server(timeout_sec=5.0):\n\
    \            self.get_logger().error('No action server available')\n         \
    \   return response\n\n        response.sum = request.a + request.b\n\n      \
    \  goal = Fibonacci.Goal()\n        goal.order = response.sum\n\n        self.action_done_event.clear()\n\
    \n        send_goal_future = self.action_client.send_goal_async(\n           \
    \ goal, feedback_callback=self.feedback_callback)\n        send_goal_future.add_done_callback(self.goal_response_callback)\n\
    \n        # Wait for action to be done\n        self.action_done_event.wait()\n\
    \n        return response\n\n    def goal_response_callback(self, future):\n \
    \       goal_handle = future.result()\n        get_result_future = goal_handle.get_result_async()\n\
    \        get_result_future.add_done_callback(self.get_result_callback)\n\n   \
    \ def get_result_callback(self, future):\n        # Signal that action is done\n\
    \        self.action_done_event.set()\n\n\ndef main(args=None):\n    rclpy.init(args=args)\n\
    \n    action_from_service = ActionFromService()\n\n    executor = MultiThreadedExecutor()\n\
    \    rclpy.spin(action_from_service, executor)\n\n    rclpy.shutdown()\n\n\nif\
    \ __name__ == '__main__':\n    main()\n</code></pre>\n\nNote, I'm using a `MultiThreadedExecutor`\
    \ and a `ReentrantCallbackGroup` so that we can process the service request and\
    \ action callbacks in parallel. I've not included any error checking related to\
    \ the action callbacks. Hopefully this example is close to what you want to do.\n\
    \nEdit: I've updated the example to use `threading.Event()`."

Hi, I have node written in Python which is a service server. Service's callback is sending goal to action server (action that commands industrial robot to move). After successful move (robot on desired gola) the service should response with some information about robot (like data from force/torque sensor i.e.). The concept is simple (you can imagine that's a step method from openai gym).

The node is based on example from [link text](https://github.com/ros2/examples/blob/master/rclpy/actions/minimal_action_client/examples_rclpy_minimal_action_client/client.py). However, the service is responding much quicker then action. I tried using threading.Event() but node freezes at event.wait(). How can I wait for action using async conecpt?
