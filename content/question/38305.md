  body_markdown: "Hi Rydel!\n\nRegarding which topic to subscribe, the topic *camera/rgb/image_raw*\
    \ provides the raw image from the device with Bayer GRBG format (for kinect) and\
    \ the topic *camera/rgb/image_color* provides the image already in RGB format.\n\
    \nSo, between both of them, I would recommend you to subscribe to *camera/rgb/image_color*\
    \ as it is already in RGB format. But, if you calibrated your camera, it would\
    \ be even better to subscribe to the topic *camera/rgb/image_rect_color* (generated\
    \ by the package openni_launch) as it provides the color rectified image (no lens\
    \ distortion).\n\nTo handle the image the best option is to use OpenCV library,\
    \ the package cv_bridge makes it really easy to transform from ROS images to OpenCV\
    \ images. You can find a tutorial [here](http://www.ros.org/wiki/cv_bridge/Tutorials/UsingCvBridgeToConvertBetweenROSImagesAndOpenCVImages).\n\
    \nBy the way, never mind the image data being published as a 1-dimensional array,\
    \ the data is serialized when published and with cv_bridge everything is being\
    \ taken care for you. \n\nOnce you have your image in OpenCV you can, for example,\
    \ access the horizontal line in the middle of the image like this:\n\n    cv::Mat\
    \ received_image;\n    \n    /* ... Subscribe to the topic... */\n    /* ... Convert\
    \ image to OpenCV using cv_bridge ...*/  \n    \n    //the matrix middle line\
    \ will contain the horizontal line in the middle of the image\n    cv::Mat middle_line\
    \ = received_image.row(received_image.rows/2); \n\nI hope you find it helpful."
