  body_markdown: "here is an example for anyone wondering how to do it.\nhttps://github.com/HemaZ/FastRTPS-ROS2\n\
    \nFirst we need to get all the messages dependencies from ROS2 installation.\n\
    \n\nExample if we need to build sensors_msg/Image\nwe should build all of the\
    \ message dependencies.\nImage -> Header -> Time\n\n\nwe can get these messages\
    \ from\n\n    /opt/ros/dashing/share/sensor_msgs/msg/Image.idl\n    /opt/ros/dashing/share/std_msgs/msg/Header.idl\n\
    \    /opt/ros/dashing/share/builtin_interfaces/msg/Time.idl\n\nand copy them to\
    \ current directory.\n\n\nedit this line\n\n    #include \"builtin_interfaces/msg/Time.idl\"\
    \n\nin Header.idl to #include \"Time.idl\"\n\n\nedit this line in Image.idl `#include\
    \ \"std_msgs/msg/Header.idl\"` to `#include \"Header.idl\"`\n\n\ngenerate the\
    \ messages using fastrtpsgen like this\n\n    fastrtpsgen -example CMake Image.idl\n\
    \n\nedit line #37 in ImagePubSubTypes.cxx to `setName(\"sensor_msgs::msg::dds_::Image_\"\
    );`\n\n\nEdit topic name in ImagePublisher.cxx and ImageSubscriber.cxx and add\
    \ rt/ before the topic name. ie `Wparam.topic.topicName = \"rt/ImagePubSubTopic\"\
    ;`\n\n\nAdd these two lines under the above line.\n\n    Wparam.qos.m_publishMode.kind\
    \ = ASYNCHRONOUS_PUBLISH_MODE; // To handle big data\n    Wparam.historyMemoryPolicy\
    \ = rtps::PREALLOCATED_WITH_REALLOC_MEMORY_MODE;\n\nbuild the project \n\n   \
    \ mkdir build\n    cd build\n    cmake ..\n    make\n    ./Image publisher"
