  body_markdown: "I've been working with a ProPak V3 recently also. The node expects\
    \ to receive data in string formats. The first thing you could do is check with\
    \ a serial tool like [minicom](https://help.ubuntu.com/community/Minicom) or [cutecom](http://cutecom.sourceforge.net/)\
    \ that data is actually received by the computer and that it's not binary (it\
    \ might be, depending on how your GPS is configured). Don't forget to test the\
    \ GPS outside and wait a few minutes for the signal to be aquired.\n\nTo configure\
    \ the GPS I used the Novatel Connect app (Windows) to send the serial commands.\
    \ The program can also confirm that your GPS is working as it should. We used\
    \ the GPGGA mode, I think the command to enable it is as follow:\n\n    LOG COM1\
    \ GPGGA ONTIME 1\n\n \n"
