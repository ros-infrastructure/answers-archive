    Most probably, it's about the names. You need to give individual names to the included models:

        <include>
            <name>pumpkin1</name>
            <pose>-1 -.35 0 0 0 0</pose>
            <uri>model://turtlebot3_autorace/pumpkin</uri>
        </include>
        <include>
            <name>pumpkin2</name>
            <pose>0 0 0 0 0 0</pose>
            <uri>model://turtlebot3_autorace/pumpkin</uri>
        </include>
  comments:

      Furthermore, these names should not collide also with world names (and I guess with any names at all). I ran to similar problem and it was a bit more hidden, since the model was spawned, but its pose couldn't be changed, until name different from world was set - this might be actually your case also, cylinders were duplicated, but not moved.
