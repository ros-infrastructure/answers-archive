    I think there is no such a thing as "Restarting the world" in Gazebo, in fact if you use the "restart" functionality of the GUI you will need to restart the rest of the ROS architecture. An approximated solution to the problem you stated would be to implement a [World plugin](http://gazebosim.org/tutorials?tut=plugins_world), executing it every time the robot finish its tasks, setting the new pose of each model in the simulation enviroment.
