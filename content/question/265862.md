  body_markdown: "My problem turned out to be that i was exporting the wrong ROS_IP\
    \ address on the 2nd machine.  \n\nAfter editing the /etc/hosts file on the 2nd\
    \ machine to include the host machine, and exporting the ROS_MASTER_URI=http://hostalias:11311\
    \ (on the machine not running roscore) you need to export the proper ROS_IP's\
    \ on BOTH machines so ROS knows where to listen.  To do this:\n\n1. Identify the\
    \ IP address of each machine\n2. export ROS_IP=ipaddress  of each machine in any\
    \ terminal you use to communicate with ROS.  Make sure that you are exporting\
    \ the IP address of the respective machine.  My problem was that i was exporting\
    \ the host computer's IP address in both machines!  \n\nAfter taking those steps\
    \ you should be able to both publish, and subscribe to topics from a 2nd machine.\n\
    \nHope that helps!"
