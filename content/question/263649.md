  body_markdown: "If your have installed ROS desktop successfully, you don't need\
    \ to install PCL separately. You will notice that a package named pcl_ros is already\
    \ installed on your computer. Reffering [this link](http://pointclouds.org/documentation/tutorials/reading_pcd.php)\
    \ you can see that you can load a PCD file and then publish it on a topic in the\
    \ following dummy code:\n\n    #include <pcl/io/pcd_io.h>\n    #include <sensor_msgs/PointCloud2.h>\n\
    \    #include <pcl_conversions/pcl_conversions.h>\n    \n    ...\n    \n    pcl::PointCloud<pcl::PointXYZ>::Ptr\
    \ cloud (new pcl::PointCloud<pcl::PointXYZ>);\n    if (pcl::io::loadPCDFile<pcl::PointXYZ>\
    \ (\"test_pcd.pcd\", *cloud) == -1) //* load the file\n      {\n        PCL_ERROR\
    \ (\"Couldn't read file test_pcd.pcd \\n\");\n        return (-1);\n      }\n\n\
    \      ros::Publisher pub = nh.advertise<sensor_msgs::PointCloud2> (\"output\"\
    , 1);\n      sensor_msgs::PointCloud2 output;\n      pcl::toROSMsg(*cloud, output);\n\
    \      pub.publish (output);\n    \n    ...\n\n"
