  body_markdown: |-
    If you want to use `Fawkes` and `ROS` together, download the latest version of `Fawkes` from their [github directory](https://github.com/fawkesrobotics/fawkes/releases/tag/1.3.0). Then follow the steps given in their website.

        git clone git://git.fawkesrobotics.org/fawkes.git
        cd fawkes
        make all gui

    Then to start `navgraph` you should start `fawkes` just like `roscore`. After that follow instructions related with the navgraph in their website.

    For my application I find out that ros packages like [topological_navigation](http://wiki.ros.org/topological_navigation) are more helpful than navgraph.
