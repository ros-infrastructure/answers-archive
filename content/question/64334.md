  body_markdown: |-
    You can also use the images of the stereo camera to perform visual odometry. For example, [viso2_ros](http://www.ros.org/wiki/viso2_ros) is a ros package that takes stereo image as input and give you the pose of the vehicle.

    You can integrate both, visual odometry and sonar into a Kalman Filter, but I don't know any package to do this. [Robot_pose_ekf](http://www.ros.org/wiki/robot_pose_ekf) integrates visual odometry and imu.

    Hope this helps...
