  body_markdown: "1) For the sensor you need to decide whether you need a 2D map of\
    \ the environment or 3D. For 2D case you can opt for laser range finder (lidar)\
    \ and in case you need a 3D map you can utilize kinect.\n\n2) To start with mapping\
    \ there is a lot of literature available. I would recommend you to start looking\
    \ up theory for SLAM.\nSome of the links I found useful [link text](http://ais.informatik.uni-freiburg.de/teaching/ws13/mapping/)\
    \ . [Here](http://sauravag.com/)  you can find step by step progress of working\
    \ with mapping module as mentioned by Saurav.\n\n3) For completely autonomous\
    \ robot you need to look at path planning stuff too. You can have a look at [Computational\
    \ Motion planning](https://www.coursera.org/learn/robotics-motion-planning) course\
    \ at coursera for some insight. "
