    For simulation you have a very complete answer [here](http://answers.ros.org/question/41433/multiple-robots-simulation-and-navigation/?answer=41434#post-id-41434) about how to manage node namespaces and tf issues.

    Working with real robots makes it harder.
    I suggest using a roscore in each robot, so that all data is private to each robot.
    In order to share certain topics, you can use packages such as [ros-rt-wmp](http://www.ros.org/wiki/ros-rt-wmp?action=fullsearch&context=180&value=linkto%3A%22ros-rt-wmp%22), which provides a wireless communication protocol that propagate selective topics to other roscores.
