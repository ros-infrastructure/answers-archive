  - body_markdown: |-
      Then you should read it more carefully and try more to understand it??? LaserScanSpeckleFilter - this is a filter that removes speckle points in a laser scan by looking at neighbor points. Read [the code](https://github.com/ros-perception/laser_filters/blob/ros2/src/speckle_filter.cpp) with the filter mechanism in mind: this filter removes laser data points which satisfies the following: for all points `P1`, if there exists a point `P2` in `(P1 - window, P1 + window)` so that `(angle(P1, O, P2)) < min_angle` or `(angle(P1, O, P2)) > max_angle`, then remove all datapoint in `(P1 - neighbor, P1 + neighbor)`, where `O` means the origin of the laser. By computing the angle differences between successive readings and discarding those that don't fit within a user-specified range you should get filtered scan. Parameters tuning is a must there - "Err and err and err again but less and less".
