  body_markdown: "Based on the clarification made in the comments on the original\
    \ post, I think I understand the question correctly. You want to update characteristics\
    \ of a model at run time. You mention \"draw the new road\" and \"lane\". If you\
    \ only need to update visual components, then this will be easy. It is still possible\
    \ with collision elements, but slightly harder.\n\nHere is an example of a project\
    \ that updates both collision and visual elements of a model.\n\n[here's some\
    \ code](https://github.com/PeterMitrano/gzmaze/blob/master/world_plugin/MazeFactory.cc)\
    \ and \n[here's some more code](https://github.com/WPISmartmouse/2016_Solvers/blob/master/sim/SimMouse.cpp)\n\
    \n[here's a video demo](https://www.youtube.com/watch?v=gmyzxpGMjcg)\n\nI use\
    \ only visuals for creating the little indicators on the maze. [video](https://www.youtube.com/watch?v=xmSh0YhYsTA).\
    \ For visual models, I simply use the gazebo visual message. But I never remove\
    \ them, I just change their color. I'm not sure how removing them works.\n\nThere\
    \ may be better ways to do this, but the strategy I take for collision models\
    \ is to delete and regenerate the model. Actually, I do the deletion by hand in\
    \ gazebo, but you should be able to do it with code as well. Collision messages\
    \ also exist, but I have not used them. \n\nLastly, I'll point out that I got\
    \ a lot of these ideas from the gazebo model editor. Looking at the source code\
    \ for that might help you a lot in your own project. [here's the code for that](https://bitbucket.org/osrf/gazebo/src/a7d32ebe8e55d4756306da4dc661c3769acb81cf/gazebo/gui/model/?at=default)\n\
    \nUPDATE\n\nYes, you do need `sdf::init(\"root.sdf\")`.\nI don't think using `~/.gazebo/models`\
    \ will work. First, the `~` is a character expanded by bash, and may not be expanded\
    \ in that function. Second, you need to consider where readFile is relative too.\
    \ I believe it is relative to the world file you load from."
