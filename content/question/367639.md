    This is a Gazebo question, which should be asked in [that forum](https://answers.gazebosim.org/questions/), but to give you a quick answer:

    The [standard sensor plugins](http://gazebosim.org/tutorials?tut=ros_gzplugins#Pluginsavailableingazebo_plugins) aren't any particular models; they just model a generic sensor of that type.  It's up to you to define the parameters that reflect a  certain manufacturer's specifications.  There are, however, some custom plugins that are intended to accurately represent particular sensors.  The plugin a robot model uses is defined in (or referenced by) its URDF file, so look there to see the specific plugin library and parameters.
