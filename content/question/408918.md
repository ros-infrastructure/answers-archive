    > I have now installed Robot studio on a seperate Windows PC, **Robot Ware 7 is also installed**

    `abb_robot_driver` (or more specifically, `abb_librws`) is not compatible with RW7. This is mentioned in the readme of the `abb_egm_hardware_interface` package, [Requirements](https://github.com/ros-industrial/abb_robot_driver/tree/32eb0f48abfd3358cb5a4f3f043f1306a9811b24/abb_egm_hardware_interface#requirements) section:

    > RobotWare version `6.07.01` or higher (less than `7.0`).

    And in the `abb_librws` readme, [Important Notes](https://github.com/ros-industrial/abb_librws/tree/4864181c67c57f0e46809e6eacb667a161ee2d08#important-notes) section:

    > RobotWare versions `7.0` and higher are currently incompatible with abb_librws

    There is some work (in a fork of `abb_librws`) to add compatibility with RW7, but I'm not certain what the status of it is.

    Refer to [ros-industrial/abb_librws#147](https://github.com/ros-industrial/abb_librws/issues/147).
