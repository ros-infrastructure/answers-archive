  body_markdown: "If I understand you correctly, you'd like:\n\n 1. Your latest *odom*-frame\
    \ pose in the UTM frame\n 2. Your latest *odom*-frame position as a GPS coordinate\
    \ (let me know if this is not what you meant)\n\nIf I'm correct, then there are\
    \ ways of obtaining both. \n\nFor getting your odom-frame position in the UTM\
    \ frame, you can use the `broadcast_utm_transform` parameter. If that parameter\
    \ is set to *true*, `navsat_transform_node` will broadcast an *odom*->*utm* transform\
    \ that other nodes can use to convert the data into whatever format they require.\
    \ If you want to actually send out an odometry message with the UTM frame, you'll\
    \ have to write a quick node to take in the *odom* pose, transform it to *utm*,\
    \ then broadcast it.\n\nIf you want your robot's current filtered *odom* position\
    \ as a GPS coordinate, you can set the `publish_filtered_gps` parameter to *true*\
    \ in `navsat_tranform_node`. It will produce a [NavSatFix](http://docs.ros.org/api/sensor_msgs/html/msg/NavSatFix.html)\
    \ message with your current filtered pose as a GPS coordinate.\n\n**Response to\
