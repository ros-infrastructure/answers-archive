  body_markdown: "One solution would be to wrap this call into a python node for instance\
    \ system.exec and the subprocess module ([on python.org](http://docs.python.org/library/subprocess.html)).\n\
    This node can then be started by a roslaunch file.\n\nHowever, I would highly\
    \ recommend that you use rosbag instead, this is a much more reliable tool that\
    \ rostopic. For instance you can do:\n\n    <launch>\n      <node pkg=\"rosbag\"\
    \ type=\"rosbag\" name=\"rosbag_record\"\n    \targs=\"record -o /tmp/slam-map\
    \ /wide/left/image_raw /wide/left/camera_info /wide/right/image_raw /wide/right/camera_info\
    \ /rosout\"/>\n    </launch>\n\nHere you will have in `/tmp` a rosbag file beginning\
    \ with slam-map followed by the current date and time.\n\nIt is then quite straightforward\
    \ to convert a file to a csv file which can then be read by matlab or whatever\
    \ 3rd party tool you use. See the [rosbag API](http://www.ros.org/wiki/rosbag)\
    \ to know how to do so.\nI also have written a converter rosbag to csv, it is\
    \ not in a public repository but if you are interested I can post it here."
