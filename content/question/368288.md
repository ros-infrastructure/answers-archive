  body_markdown: "I solved the problem using namespace in launch file,\n \nFor example;\n\
    The robot description in parameter server is loaded as \"/iiwa/robot_description\"\
    . I wanted to add \"iiwa\" namespace using C++ script. However, I could not figure\
    \ out how to do that and I used <group> tag in launch file to give a prefix \"\
    iiwa\" to the C++ script. I worked.!\n\n\n<launch>\n\n    <group ns=\"iiwa\">\n\
    \        <node name=\"tower_cpp\" pkg=\"hanoi_tower_kuka_model\" type=\"tower_cpp\"\
    \ respawn=\"false\" output=\"screen\">\n        </node>\n    </group>\n\n</launch>"
