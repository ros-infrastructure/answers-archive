  body_markdown: "I believe the pointcloud is properly aligned, but not the container\
    \ holding the point clouds. \n\nLet's assume you have a point cloud of type `PointCloud`.\
    \ Initializaing a `std::vector` like this will cause alignemnet errors:\n\n  \
    \  std::vector<PointCloud> my_deque;\n\nThe proper way to initialize is:\n\n \
    \   std::vector<PointCloud, Eigen::aligned_allocator<PointCloud> > my_deque;\n\
    \nI assume the same holds for other types of stl containers, such as a deque.\
    \ More information [here](http://eigen.tuxfamily.org/dox/TopicStlContainers.html)"
