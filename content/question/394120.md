      This answer would be improved if it explained the general layout of the `/opt/ros` FHS prefix. See [REP 122: Filesystem Hierarchy Standard layout changes for ROS](https://www.ros.org/reps/rep-0122.html) for information.

      Headers are never present in `/opt/ros/$ROS_VERSION/share`. Only in `/opt/ros/$ROS_VERSION/include`.
