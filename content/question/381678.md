  body_markdown: "Thanks to [Photon](https://answers.ros.org/users/28317/photon/),\
    \ after consulting the official documentation ([Learning about tf and time (C++)](http://wiki.ros.org/tf/Tutorials/tf%20and%20Time%20%28C%2B%2B%29))\
    \ I found where my problem was. \n\nFirst of all I had a (wrong) preconception\
    \ that `Time(0)` and `Time::now()` refer to the very same thing and are interchangeable.\
    \ I couldn't have been more wrong about this. They are not the same.   \nThe `Time(0)`\
    \ means `\"the latest available transform in the buffer\"` while `Time::now()`,\
    \ literally fetches the frame at the exact moment, and since there is a delay\
    \ between this command being issued and the frame being fetched, we will have\
    \ some latencies in milliseconds and this will cause the lookup failure if its\
    \ not accounted for.  \nWhy is that?(based on tf2 [docs](http://wiki.ros.org/tf2/Tutorials/tf2%20and%20time%20%28C%2B%2B%29)\
    \ which I believe also applies to tf) : \n\n> Each listener has a buffer where\
    \ it\n> stores all the coordinate transforms\n> coming from the different tf\n\
    > broadcasters. When a broadcaster sends\n> out a transform, it takes some time\n\
    > before that transform gets into the\n> buffer (usually a couple of\n> milliseconds).\
    \ So, when you request a\n> frame transform at time \"now\", you\n> should wait\
    \ a few milliseconds for\n> that information to arrive.\n\nIn order to fix this\
    \ I either had to use `Time(0)` and get the **latest available transform in the\
    \ queue** or if I wanted the frame at roughly now, I had to use ` waitForTransform()`\n\
    \nSo to cut a long story short, I either had to do : \n\n     transform_listener.lookupTransform(\"\
    base_footprint\", \"odom\",ros::Time(0), transform);\n\nor: \n\n    ros::Time\
    \ now = ros::Time::now();\n    transform_listener.waitForTransform(\"base_footprint\"\
    , \n                                        \"odom\", \n                     \
    \                    now, \n                                         // the wait\
    \ duration in seconds\n                                         ros::Duration(2));\n\
    \    //note that we used 'now' here as well. if we don't, we will still face lookup\
    \ error\n    //as if nothing has changed\n    transform_listener.lookupTransform(\"\
    base_footprint\", \"odom\", now, transform);"
