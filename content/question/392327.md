    \ are running Melodic then file path would be: \n\n`/opt/ros/melodic/share/rviz/images/splash.png`\n\

    \ then `image_publisher` will print a message such as:\n\n    [ INFO] [1638830830.340437700]:\
    \ File name for publishing image is : /opt/ros/melodic/share/rviz/images/splash.png\n\
    \    [ INFO] [1638830830.348288400]: Flip horizontal image is : false\n    [ INFO]\
    \ [1638830830.349854100]: Flip flip_vertical image is : false\n\nTo visualize,\
    \ run another terminal `rqt`, under Plugins->ImageView, select from the drop down\
