  body_markdown: "You should be able to use the ccny_rgb tools with simulated Kinect\
    \ data, as long as that data comes in the same format as the OpenNI image topics.\
    \ The [visual_odometry](http://www.ros.org/wiki/ccny_rgbd/visual_odometry) and\
    \ [keyframe_mapper](http://www.ros.org/wiki/ccny_rgbd/keyframe_mapper) tools require\
    \ 3 incoming topics:\n\n * `/rgbd/rgb`: a rectified, debayered RGB image, 8UC3\
    \ encoding\n * `/rgbd/depth`: a rectified depth image, registered with the RGB\
    \ image, 16UC1 encoding (in millimeters)\n * `/rgbd/info`: CameraInfo topic (applies\
    \ to both image, since they are registered).\n\nIf the topics are coming from\
    \ the OpenNI driver, you would need to add the following remappings to the visual_odometry_node\
    \ and the keyframe_mapper_node launch files\n\n    <remap from=\"/rgbd/rgb\" \
    \  to=\"/camera/rgb/image_rect_color\"/>\n    <remap from=\"/rgbd/depth\" to=\"\
    /camera/depth_registered/image_rect_raw\"/>\n    <remap from=\"/rgbd/info\"  to=\"\
    /camera/rgb/camera_info\"/>\n\nFinally, you should choose the `fixed_frame` and\
    \ `base_frame` parameters. The defaults are `odom` and `camera_link`. In your\
    \ case, since this is a real robot, the base frame might be different - `base_link`\
    \ for example. You need to ensure that there exists a tf between the `base_frame`\
    \ and the optical frame of the camera. This transform is assumed to be static\
    \ by ccny_rgbd, and will be cached.\n\n**EDIT:** The visual odometry will publish\
    \ a tf, but this might not be what you need for your application, especially if\
    \ you are using **robot_pose_ekf** to fuse odometry sources. \n\nIf this is the\
    \ case, disable the tf publishing (using the `publish_tf` flag), and make robot_pose_ekf\
    \ subscribe to the \"odom\" topic published by \"visual_odometry_node\", of type\
    \ nav_msgs/Odometry\n\n**EDIT 2:** Still can't find what the simulated Kinect\
    \ data is exactly, but it appears the only available depth topic is 32FC1. A [ticket](https://github.com/ccny-ros-pkg/ccny_rgbd_tools/issues/8)\
    \ has been opened to enable support in ccny_rgbd.\n\n**EDIT 3:** Added support\
    \ for 32FC1 images (see [ticket](https://github.com/ccny-ros-pkg/ccny_rgbd_tools/issues/8)\
    \ for details). Also added clearer instructions in launch files which summarize\
    \ this answer here."
