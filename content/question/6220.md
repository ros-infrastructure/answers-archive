  body_markdown: |-
    You can include it in the URDF model of your robot using the `plugin` tag like this:

        <gazebo>
          <plugin name="novatel_gps_sim" filename="libhector_gazebo_ros_gps.so">
            <alwaysOn>1</alwaysOn>
            <updateRate>10.0</updateRate>
            <bodyName>base_footprint</bodyName>
            <topicName>fix</topicName>
            <velocityTopicName>fix_velocity</velocityTopicName>
            <drift>5.0 5.0 5.0</drift>
            <gaussianNoise>0.1 0.1 0.1</gaussianNoise>
            <velocityDrift>0 0 0</velocityDrift>
            <velocityGaussianNoise>0.1 0.1 0.1</velocityGaussianNoise>
          </plugin>
        </gazebo>
    [Here](https://github.com/fsuarez6/labrob/blob/master/labrob_description/urdf/labrob.urdf.xacro#L202) you can find a working example.
