    Welcome to the amusing world of ROS on OS X!

    Because there are no pre-built packages for csparse (either in MacPorts or ROS), you'll need to install it from source (see [the wiki page](http://www.ros.org/wiki/csparse)). Then, if you add `<depend package="csparse"/>` to `manifest.xml` in hogman_minimal, and issue `rosmake`, it should compile.
