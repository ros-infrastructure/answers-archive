    The ROS Velodyne driver is different from other LIDARs in that it does not publish standard [LaserScan](http://docs.ros.org/api/sensor_msgs/html/msg/LaserScan.html) messages, but [VelodyneScan](http://docs.ros.org/api/velodyne_msgs/html/msg/VelodyneScan.html) ones. These have to be converted to the standard [PointCloud2](http://docs.ros.org/api/sensor_msgs/html/msg/PointCloud2.html) message format using an additional step. How this works is described on the [velodyne_pointcloud](http://wiki.ros.org/velodyne_pointcloud) wiki page.
