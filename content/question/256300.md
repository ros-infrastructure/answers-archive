    > Unable to open camera calibration file [/home/habals/.ros/camera_info/depth_Astra_Orbbec.yaml]

    This is not a file that is provided for you, but one that you have to generate using (fi) the [camera_calibration](http://wiki.ros.org/camera_calibration) tool. That tool will perform an intrinsic calibration, which is what the node can't find. If it can't find it, it'll just use a default (ie: uncalibrated) one, which will most likely not work too well.
