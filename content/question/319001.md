    I had the same issue. This worked out for me.

    We need a simplified header file for custom messages in Arduino sketches. The usual header files in devel have boost dependencies. We can generate a simplified header file by running the following:

    `rosrun rosserial_arduino make_library.py path_to_libraries your_message_package`

    The resources I used:
    [ROS wiki](http://wiki.ros.org/rosserial_arduino/Tutorials/Adding%20Custom%20Messages)  and **Ch 7**. in  [Mastering ROS for Robotics Programming](https://www.amazon.com/Mastering-ROS-Robotics-Programming-Operating-ebook/dp/B0198DXFEW/ref=sr_1_4?keywords=Mastering+ROS+for+Robotics+Programming&qid=1667568376&qu=eyJxc2MiOiIwLjQ3IiwicXNhIjoiMC4yNyIsInFzcCI6IjAuNDEifQ%3D%3D&sr=8-4)
