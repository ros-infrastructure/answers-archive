    A [quick google](https://www.google.com/search?q=gpg:+connecting+dirmngr) suggests the `apt-key adv ..` usage is deprecated (see [ubuntu/bug/1634464](https://bugs.launchpad.net/ubuntu/+source/apt/+bug/1634464) and [ubuntu/bug/1623087, comment 8](https://bugs.launchpad.net/ubuntu/+source/enigmail/+bug/1623087/comments/8) fi - Ubuntu, but the idea seems the same).

    [debian/bug/845720](https://bugs.debian.org/cgi-bin/bugreport.cgi?bug=845720) suggests that manually installing `dirmngr` should make things work again.

    This would be at best a work-around. If you can find the currently recommended way to import keys in Debian (and I expect future Ubuntu distributions - if not already on Yakkety) and could update the wiki that would be very much appreciated.
