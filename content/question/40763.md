    It looks like your ROS_PACKAGE_PATH is not defined. Be sure to follow the [instructions for installing rosjava](http://docs.rosjava.googlecode.com/hg/rosjava_core/html/installing.html). And be sure to:

        $ cd my_ros_workspace
        $ source setup.bash

    It's best to add the `source setup.bash` line to your `bash.rc`.

    I've also filed an [issue](http://code.google.com/p/rosjava/issues/detail?id=135) to provide a more informative error message.

    I fixed the problem with damonkohler's help. I took his suggestion, and  followed the instruction for installing rosjava. I, however, still got the same error. After a little thought, I realized that since I was running the command:

    $ sudo ./gradlew install

    that the ROS_PACKAGE_PATH for the root user was undefined. The conclusion was correct. To fix the problem, I became the root user and defined my ROS_PACKAGE_PATH by using:

    $ sudo su
    $ . /home/user_name/.bashrc
    $ source /home/user_name/my_workspace/setup.sh

    After typing those commands, I was able to build rosjava.
