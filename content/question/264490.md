  body_markdown: "Here would be my idea for a rather simple approach: \nwrite a node\
    \ which:\n\n - takes as input the number of\n   images it should save\n - everytime\
    \ it's launched, records the number of requested images, saves them, and terminates\
    \ again.\n - you thus would need to launch every time you want to capture one\
    \ or several images\n\nOf course you could then start to make the node more sophisticated,\
    \ and for example use a rosservice to trigger the capturing of one or several\
    \ images, which would eliminate the need to terminate the node. But actually I\
    \ would say every time sending a rosservice request is just as much \"work\" as\
    \ starting the node everytime you want to record the images.\n"
