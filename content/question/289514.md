  body_markdown: "Haaa ! \n\nAfter digging in the [documentation of the roslaunch\
    \ API](http://docs.ros.org/diamondback/api/roslaunch/html/roslaunch.parent.ROSLaunchParent-class.html),\
    \ I was able to find a solution. \n\nThe idea is to use a `ROSLaunchParent` which\
    \ is used to start/shutdown `.launch` files. According to the documentation a\
    \ `ROSLaunchParent` can be a `roscore` instance if the parameter `is_core` is\
    \ set to `True`.\n\nSo here is my solution:\n\n    from roslaunch.parent import\
    \ ROSLaunchParent\n    \n    parent = ROSLaunchParent(run_id, [], is_core=True)\
    \     # run_id can be any string\n    parent.start()\n    # [... do other stuff\
    \ ...]\n    parent.shutdown()\n\nThe trick is to pass an empty list of roslaunch_files,\
    \ so that we just use the functionality of the class to start a roscore.\n\nHope\
    \ this helps others :)\n"

 Hello,

I am trying to automate the launch of multiple nodes with the [roslaunch API](http://wiki.ros.org/roslaunch/API%20Usage).
So far, I am able to do what I want, and my nodes are running perfectly. (I am also able to stop them).

**Now, I noticed that the roslaunch API doesn't work if no roscore is running (in a terminal).**.

So I am trying to start the roscore at the beginning of my script (before starting my nodes).
What I tried so far (also described [here](https://answers.ros.org/question/215600/how-can-i-run-roscore-from-python/?answer=223264#post-id-223264)) is:

    import subprocess
    roscore_process = subprocess.Popen('roscore')

However, I am unable to stop the roscore process with `roscore_process.kill()`.

It seems that the `roscore` program creates a parent process that spawns multiple children processes (i assume: rosmaster, parameter server, rosout...). This can also be seen with `top` or `htop`. Therefore calling `roscore_process.kill()` only kills one of the children.

Do you have any idea on how to start **and stop** a roscore ?

Thank you
