  body_markdown: "Hi,\n\nI don't think there is a dedicated function for this, but\
    \ you can easily use it like this:\n\n    // set the update rate (you can also\
    \ set it as a parameter from the sdf file)\n    this->updateRate = common::Time(0,\
    \ common::Time::SecToNano(0.75));\n\n    // initialize the prevUpdateTime\n  \
    \  this->prevUpdateTime = common::Time::GetWallTime();\n\n    void PluginClass::OnUpdate()\n\
    \    {\n      if (common::Time::GetWallTime() - this->prevUpdateTime < this->updateRate)\n\
    \        return;\n\n      ...\n\n      this->prevUpdateTime = common::Time::GetWallTime();\n\
    \    }\n\n<br>\n========UPDATE, HOW TO GET THE PARAMETER EXAMPLE=========\n<br>\n\
    in the sdf file:\n\n    <plugin name='plugin_name' filename='libplugin_name.so'>\n\
    \        <sdf_parameter_update_rate>69.0</sdf_parameter_update_rate>\n    </plugin>\n\
    \    \nin the plugin: \n\n    void PluginName::Load(physics::ModelPtr _parent,\
    \ sdf::ElementPtr _sdf)\n    ...\n    double param_update_rate;\n    \n    if\
    \ (!_sdf->HasElement(\"sdf_parameter_update_rate\"))\n    {\n        // if parameter\
    \ tag does NOT exist\n        std::cout << \"Missing parameter <sdf_parameter_update_rate>\
    \ in PluginName, default to 0\" << std::endl;\n        param_update_rate = 0;\n\
    \    }\n        // if parameter tag exists, get its value\n    else param_update_rate\
    \ = _sdf->GetElement(\"sdf_parameter_update_rate\")->GetValueDouble();\n\nand\
    \ then you use this `param_update_rate` in setting the updateRate value:\n\n \
    \   this->updateRate = common::Time(0, common::Time::SecToNano(param_update_rate));\n\
