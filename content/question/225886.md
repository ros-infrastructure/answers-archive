    \ install -f ros-groovy-openni2-launch` ... right? \n\nNo, as according to [debbuild/groovy.html?q=openni](http://www.ros.org/debbuild/groovy.html?q=openni),\
    \ that particular package was never released into Groovy. Only the `openni2_camera`\
    \ package was (see the `deb` on `packages.ros.org` [here](http://packages.ros.org/ros/ubuntu/pool/main/r/ros-groovy-openni2-camera/)\
    \ fi). The [wiki page](http://wiki.ros.org/openni2_launch) also shows this: notice\
    \ the `Released`, `Continuous integration` and `Documented` badges on the Hydro,\
    \ Indigo and Jade pages, but only the `Documented` one on the Groovy page.\n\n\
    As to options: you could try to see whether you can build the package from source\
    \ in a Groovy catkin workspace. Probably best to checkout the [groovy-devel](https://github.com/ros-drivers/openni2_launch/tree/groovy-devel)\
    \ branch. It's just a set of launch files, so it could work.\n\nAlternatively,\
    \ try to build all `openni2` packages from source, using the `hydro-devel` branch.\
    \ That will probably be a bit more involved, as things might have changed between\
    \ Groovy and Hydro in an incompatible way.\n"
