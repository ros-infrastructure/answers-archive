  body_markdown: "Hi @Qilos,\n\nTo launch a custom world you do not need to change\
    \ the `gazebo_ros` launcher, you just need to pass the world file location to\
    \ the launcher. The error is telling you that the launch file you are passing\
    \ does not exist. You will need to do something like:\n\n    <?xml version=\"\
    1.0\"?>\n    <launch>\n    \n      <!-- [...] Tutlebot things-->\n    \n     \
    \ <!-- Coordinates to spawn model -->\n      <arg name=\"x\" default=\"0.0\"/>\n\
    \      <arg name=\"y\" default=\"0.0\"/>\n      <arg name=\"z\" default=\"0.02\"\
    />\n      <arg name=\"roll\" default=\"0.0\"/>\n      <arg name=\"pitch\" default=\"\
    0.0\"/>\n      <arg name=\"yaw\" default=\"0.0\"/>\n      <arg name=\"output\"\
    \ default=\"log\"/>\n    \n      <arg name=\"world\" default=\"$(find turtlebot3_gazebo)/worlds/simpleWorld.world\"\
    />\n    \n      <include file=\"$(find gazebo_ros)/launch/empty_world.launch\"\
    >\n        <arg name=\"world_name\" value=\"$(arg world)\"/>\n      </include>\n\
    \    \n      <node name=\"urdf_spawner\" pkg=\"gazebo_ros\" type=\"spawn_model\"\
    \ respawn=\"false\" output=\"$(arg output)\"\n        args=\"-urdf -model  turtlebot3_$(arg\
    \ model) -param robot_description -x $(arg x) -y $(arg y) -z $(arg z) -R $(arg\
    \ roll) -P $(arg pitch) -Y $(arg yaw)\"/>\n    \n    </launch>\n\nPlease note\
    \ that the launch file is not changed but the `world_name` param.\n\nHope this\
    \ helps with your problem.\n\nRegards."
