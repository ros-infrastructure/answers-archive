  body_markdown: "You should try out `teb local planner` http://wiki.ros.org/teb_local_planner.\
    \ It has worked out quite well for me for >1m/s diff drive mobile robots, and\
    \ to a large extent also for omni-directional (holonomic) mobile robots https://youtu.be/VfQWa06hQlM.\
    \ \n\nYou can install it for kinetic by running:\n\n    $ sudo apt install ros-kinetic-teb-local-planner\n\
    \nAnd set your local planner in your move_base node:\n\n    <param name=\"base_local_planner\"\
    \ value=\"teb_local_planner/TebLocalPlannerROS\" />\n\nThere are many parameters\
    \ to tune, so check out the wiki for the parameters, guides, and tutorials. I\
    \ can highly recommend to use rqt dynamic reconfigure to tune the settings.\n\n\
    I have not tried it with `locomove_base`, but would be interesting to test out."
