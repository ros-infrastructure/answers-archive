    \ are not synchronized. The solution is to call the Network Time Protocol (NTP)\
    \ server everytime before launching the navigation process by using:\n\nsudo ntpdate\
    \ ntp.ubuntu.com\n\nNote that, the NTP server should be updated in both the Remote\
    \ PC and the TurtleBot: \n\nsudo apt-get install ntpdate"
