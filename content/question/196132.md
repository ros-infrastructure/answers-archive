  body_markdown: "You need to diffuse the image across the visual of your \"wall\"\
    \ model. it might be tedious to not have a stretched image, but this is the way\
    \ you can do it. Here is some sample code: \n\ninside your .gazebo/models/awesome_wall/\
    \   create a materials folders which will have two folders 'scripts' and 'textures'.\
    \ Place your .png in the textures, and in the scripts folder create a file called\
    \ wall.material which you then open and put the follow code:\n\n    material awesome_wall/wall\n\
    \    {\n     receive_shadows on\n        technique\n        {\n              \
    \  pass\n                {\n                        ambient 0.8 1.0 0.8 1.0\n\
    \                        diffuse 0.8 1.0 0.8 1.0\n                        specular\
    \ 0.1 0.1 0.1 1.0 12.5\n\n                        texture_unit\n             \
    \           {\n                                texture map_gazebo.png\n      \
    \                  }\n                }\n        }\n    }\n\nAfter you do that,\
    \ go into your sdf and replace it with this:\n\n    <?xml version=\"1.0\" ?>\n\
    \    <sdf version=\"1.4\">\n      <model name=\"awesome_wall\">\n        <static>true</static>\n\
    \        <link name=\"link\">\n          <pose>0 0 0 0 0 0</pose>\n          <must_be_base_link>1</must_be_base_link>\n\
    \          <collision name=\"collision\">\n             <geometry>\n         \
    \      <box>\n                 <size>1 1 0.005</size>  <!-- adjust this to whatever\
    \ you want -->\n              </box>\n             </geometry>\n           </collision>\n\
    \           <visual name=\"visual\">\n               <cast_shadows>false</cast_shadows>\n\
    \               <geometry>\n                 <box>\n                    <size>1\
    \ 1 0.005</size>  <!-- same size as collision -->\n                </box>\n  \
    \            </geometry>\n              <material>\n                <script>\n\
    \                    <uri>model://igvc/materials/scripts</uri>\n             \
    \       <uri>model://igvc/materials/textures</uri>\n                    <name>awesome_wall/wall</name>\n\
    \                </script>\n              </material>\n             </visual>\n\
    \            </link>\n          </model>\n        </sdf>\n\n\nOfcourse replace\
    \ awesome_wall with whatever you folder is called"
