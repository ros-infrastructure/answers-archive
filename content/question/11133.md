    Hi there,
    I had exactly the same problem on Ubuntu natty (11.04) and was finally able to solve it. In my case there was a conflict with libeigen3-dev which didnt match the expected version (Depends: libeigen3-dev (= 3.0.1-1+ros4~natty) but 3.0.2-3+natty1 is to be installed). I found the solution [here (japanese)](http://ros-robot.blogspot.com/2011/09/ros-electricpcl11.html) using google translate.
    I had to:

     - Uninstall pcl and eigen: Sudo apt-get remove libpcl-1.1 libeigen3-dev

     - Comment out all lines in: /etc/apt/sources.list.d/v-launchpad-jochen-sprickerhof-de-pcl-natty.list (may be maverick for you)

     - Run: sudo apt-get update

     - Install the ros-electric-desktop-full

    Hope that helps.
