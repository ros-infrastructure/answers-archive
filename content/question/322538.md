    The cause of the error is that the package is actually called `ur5_notebook` instead of `ur5_ROS-Gazebo` (see [here](https://github.com/lihuang3/ur5_ROS-Gazebo/blob/2f7b9b056bb41b9412f86589a60e25ba2816b78b/package.xml#L3) in the manifest). The latter is only the name of the repository (and the directory in your workspace).

    The following should work:

        rosrun ur5_notebook testmotion.py
