  body_markdown: "By default, the bag file will be in `~/.ros` folder with the name\
    \ being the date and time of starting recording. For exact name, you can add this\
    \ flag `output=\"screen\"` so it looks like this\n\n`<node name=\"record_topics_for_verification\"\
    \ pkg=\"rosbag\" type=\"record\" args=\"$(arg topics_name)\" output=\"screen\"\
    />`\n\nAfter adding this flag, you will see the bag name in rosout after you launch.\
    \ \n\nNote: the bag file will have the name of `xxx.bag.active` while being recording.\
    \ Only after you properly terminate the recording node, the file name will be\
    \ changed to `xxx.bag`"
