  body_markdown: "if you are \"just\" looking for the CMakeList.txt see below. It\
    \ also depends on your plugin what 'includes/packages' are required. In addition\
    \ you need your program to be in a catkin / ros package. (see the tutorial link\
    \ below)\n\n    cmake_minimum_required(VERSION 2.8.3)\n    project(gazebo_tutorials)\n\
    \    \n    # Load catkin and all dependencies required for this package\n    find_package(catkin\
    \ REQUIRED COMPONENTS \n      roscpp \n      gazebo_ros \n    )\n    \n    # Depend\
    \ on system install of Gazebo\n    find_package(gazebo REQUIRED)\n    \n    link_directories(${GAZEBO_LIBRARY_DIRS})\n\
    \    include_directories(${Boost_INCLUDE_DIR} ${catkin_INCLUDE_DIRS} ${GAZEBO_INCLUDE_DIRS})\n\
    \    \n    add_library(${PROJECT_NAME} src/simple_world_plugin.cpp)\n    target_link_libraries(${PROJECT_NAME}\
    \ ${catkin_LIBRARIES} ${GAZEBO_LIBRARIES})\n    \n    catkin_package(\n      DEPENDS\
    \ \n        roscpp \n        gazebo_ros \n    )\n\n\nAs mentioned previously you\
    \ should go through the tutorial. This is from where I got the above code: http://gazebosim.org/tutorials?tut=ros_plugins\n\
    \nTo understand the CMakeList file, read here: http://wiki.ros.org/catkin/CMakeLists.txt"
