  body_markdown: "Where are you getting your /scan from? You will need to first figure\
    \ out what the frame id in your scan msg is. You can do this by `rostopic echo\
    \ /scan/header` in your terminal. Then you need to make sure that a link exists\
    \ in your tf from laser_link -> base_link. You can use tf_echo or tf_monitor for\
    \ this. If a transform exists, you can subscribe to your /scan topic and in the\
    \ callback have this to transform your entire scan to base_link: (I am using [PCL](https://pointclouds.org/)\
    \ here)\n\n    tf2_ros::TransformListener* tf_listener_1;\n    tf2_ros::Buffer\
    \ tf_buffer_1;\n    geometry_msgs::TransformStamped transform_stamped;\n\n   \
    \ // Point Cloud callback\n    void cloud_cb (const sensor_msgs::PointCloud2ConstPtr&\
    \ input)\n    {\n      // initialize pcl objects\n      pcl::PointCloud<pcl::PointXYZI>::Ptr\
    \ input_cloud(new pcl::PointCloud<pcl::PointXYZI>);\n      pcl::fromROSMsg(*input,\
    \ *input_cloud);\n\n      // Transform point cloud to base_link\n      try\n \
    \     {\n        transform_stamped = tf_buffer_1.lookupTransform(\"base_link\"\
    ,\n                                                        input->header.frame_id,\n\
    \                                                        ros::Time(0),\n     \
    \                                                   ros::Duration(2));\n     \
    \ }\n      catch (tf2::TransformException &ex)\n      {\n        ROS_ERROR(\"\
    %s\",ex.what());\n        return;\n      }\n      // transform current point cloud\n\
    \      Eigen::Affine3d pc_to_base_link = tf2::transformToEigen(transform_stamped);\n\
    \      pcl::transformPointCloud(*input_cloud, *input_cloud, pc_to_base_link);\n\
    \    \n    // input_cloud is now in the base_link\n    ...\n    }\n\n\n\n\n"
