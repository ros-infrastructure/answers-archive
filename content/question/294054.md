  body_markdown: "So I figured out how to do this. I used the [Points and Lines tutorial](http://wiki.ros.org/rviz/Tutorials/Markers%3A%20Points%20and%20Lines)\
    \ as a reference and used the line strip function of the [Rviz Markers Display\
    \ types](http://wiki.ros.org/rviz/DisplayTypes/Marker).  \n\n    ros::Publisher\
    \ marker_pub;\n    void VisPoseCallback(const geometry_msgs::PoseArrayConstPtr&\
    \ msg)\n    {\n    const std::vector<geometry_msgs::Pose>& ps = msg->poses;\n\
    \    visualization_msgs::Marker line_strip;\n    line_strip.header.frame_id =\
    \ \"/whycon\";\n\n    line_strip.header.stamp = ros::Time::now();\n    line_strip.ns\
    \ = \"lines\";\n    line_strip.pose.orientation.w = 1.0;\n    line_strip.id =\
    \ 0; //tag id\n    line_strip.type = visualization_msgs::Marker::LINE_STRIP; \
    \ //tag type\n    line_strip.scale.x = 0.05;\n    line_strip.color.b = 1.0;\n\
    \    line_strip.color.a = 1.0;\n\n    geometry_msgs::Point p;\n    p.x = ps[0].position.x;\n\
    \    p.y = ps[0].position.y;\n    p.z = ps[0].position.z;\n    line_strip.points.push_back(p);\n\
    \nI repeated the position bit for each of my poses then I subscribed to my poses\
    \ message. \n\n    int main(int argc, char** argv)\n    {\n      ros::init(argc,\
    \ argv, \"VisPose\");\n      ros::NodeHandle n;\n    \n       marker_pub = n.advertise<visualization_msgs::Marker>(\"\
    line_visualization_marker\", 10);\n      ros::Rate r(100);\n      ros::Subscriber\
    \ pose_sub = n.subscribe<geometry_msgs::PoseArray>(\"/whycon/poses\", 1, &VisPoseCallback);\n\
    \    \n      ros::spin();\n    }\n   This created a box between which moves as\
    \ the poses change. \n\n"

I'm using ROS Kinetic on Ubuntu 16.04 LTS. 

I'm trying to draw a bounding box around four poses which are displayed as arrows in Rviz. I looked at using the [Rviz Basic Shapes tutorial](http://wiki.ros.org/rviz/Tutorials/Markers%3A%20Basic%20Shapes) but I don't know how to adapt that code so that the box would remain around the poses if the position of the poses changed. From what I can tell, you have to manually set specific values for the vertices of the box in the Basic Shapes tutorial. I need the vertices to be determined from the pose positions. 

The poses are output as  `<geometry_msgs/PoseArray>` and represent positions of [Whycon](https://github.com/lrse/whycon) targets tracked using a usb_cam. These targets might have to move around  for the desired application. 

Is it possible to create this box?
