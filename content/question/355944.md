    Hi,

    It seems that your are not extracting the information correctly from the `msg`. As the error message you're getting says, `AprilTagDetectionArray` does not have a `pose` attribute.

    You can see in its [message definition](http://docs.ros.org/api/apriltag_ros/html/msg/AprilTagDetectionArray.html) that it actually has an array of [`AprilTagDetection`](http://docs.ros.org/api/apriltag_ros/html/msg/AprilTagDetection.html) objects, each one containing a `PoseWithCovarianceStamped`.  So you need to adjust your code to read that.

    Hope this helps!
