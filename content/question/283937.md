  body_markdown: "In general, all you need is a node publishing a `geometry_msgs/Twist`\
    \ message on the correct topic (likely `turtle1/cmd_vel`). There are many keyboard-based\
    \ teleop nodes that could be used instead of the `turtle_teleop_key`.  For example\
    \ [teleop_twist_keyboard](http://wiki.ros.org/teleop_twist_keyboard) or [key_teleop](http://wiki.ros.org/key_teleop).\
    \ Running one of these nodes with the right remapping would allow you to control\
    \ the turtlesim using whatever the keybindings of that node are. For example after\
    \ running your `turtlesim_node` you could run\n\n    rosrun teleop_twist_keyboard\
    \ teleop_twist_keyboard.py cmd_vel:=turtle1/cmd_vel\n\nAnd then you'd be using\
    \ the keys described on the [teleop_twist_keyboard page](http://wiki.ros.org/teleop_twist_keyboard#Controls).\n\
    \nIf you really want to change the keys used in the `turtle_teleop_key` node from\
    \ the tutorial, then the only way to do that would be to have a copy of the source\
    \ code for the turtlesim package in your workspace, edit the source code, and\
    \ then recompile. The keys used for driving the turtle are [defined here](https://github.com/ros/ros_tutorials/blob/98753d885775a3347ba6d149afae0ac3df7be772/turtlesim/tutorials/teleop_turtle_key.cpp#L7-L11),\
    \ and they are processed in [this case statement](https://github.com/ros/ros_tutorials/blob/98753d885775a3347ba6d149afae0ac3df7be772/turtlesim/tutorials/teleop_turtle_key.cpp#L97-L119).\
    \ If you wanted to use \"wsad\", you could change the top defines to be:\n\n \
    \   #define KEYCODE_R 0x64\n    #define KEYCODE_L 0x61\n    #define KEYCODE_U\
    \ 0x77\n    #define KEYCODE_D 0x73\n    #define KEYCODE_Q 0x71\n \nTo read more\
    \ about why, in the original code, the arrow keys are the specific values they\
    \ are (e.g. Right=0x43), you could read the following:\n\n -  https://stackoverflow.com/a/11432632/1082525\n\
    \ - https://en.wikipedia.org/wiki/ANSI_escape_code\n - https://viewsourcecode.org/snaptoken/kilo/02.enteringRawMode.html"
