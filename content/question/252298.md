  body_markdown: "**EDIT**: there is already a nodelet existing in rtabmap_ros source\
    \ doing the work below, see this [link](https://github.com/introlab/rtabmap_ros/blob/master/src/nodelets/undistort_depth.cpp).\n\
    \nHi,\n\nUnfortunatly, since this feature is quite new, there is no existing node\
    \ yet that can distort the depth image using the distortion model. \n\nYou may\
    \ create one by subscribing to depth image and loading the *.bin generated by\
    \ the standalone. \n\n    #include \"rtabmap/core/clams/discrete_depth_distortion_model.h\"\
    \n\n    clams::DiscreteDepthDistortionModel model;\n\n    void init(const std::string\
    \ & modelPath) {\n        model.load(modelPath);\n        if(!model.isValid())\n\
    \        {\n            ROS_ERROR(\"Loaded distortion model \\\"%s\\\" is not\
    \ valid!\", modelPath.c_str());\n        }\n    }\n\n    void callback(...) {\n\
    \       cv::Mat depth = //... (cv_bridge subscription to depth msg)\n       model.undistort(depth);\n\
    \       // ... republish the depth undistorted\n    }\n\ncheers"
