  body_markdown: "I don't know if you already had it done, but for those who may get\
    \ stucked in such a problem, here is my step by step to install mav_tools and\
    \ asctec_drivers . It worked to me, for **ROS-Groovy**, after a lot of mistakes\
    \ and helps from this forum. I will start from the beginning:\n\n**First step**,\
    \ make sure you have GIT installed:\n\n    sudo apt-get install git-core\n\n**Second\
    \ step**, create a folder where you are going to have other packages from ROS,\
    \ those you can not install through apt-get... For example:\n\n    mkdir ~/rospackages\n\
    \    cd ~/rospackages\n    and download the packages, you can find the links in\
    \ Ros website. I cant publish links here.\n\n**Third step**, you need to indicate\
    \ where are the ROS packages, now you will have two folders, the original from\
    \ ROS installation, and the one you have created:\n\n    export ROS_PACKAGE_PATH=~/rospackages/:/opt/ros/groovy\n\
    \nThe **:** adds another folder, so if you have another folder to add, just write\
    \ **:** and the location. It is important that ~/rospackages comes first so, you\
    \ won't have any problems with read/write problems.\n\n**Fourth step**, now you\
    \ can do:\n\n    rosdep install mav_tools\n    rosmake mav_tools\n\nWell, I had\
    \ two erros after doing rosmake, so it leads to my final steps. If there were\
    \ no errors after rosmake, ignore the following steps:\n\n**Fifth step**, you\
    \ may have an error related to the version of rosdep, it is caused due a conflict\
    \ with the versions installed. So you will need to remove the easy-installed version:\n\
    \n    sudo rm -rf /usr/local/lib/python2.7/dist-packages/rosdep*\n\nTry again\
    \ `rosmake mav_tools`. \n\n**Sixth step**, you may have a problem related to rosgraph\
    \ and python-netifaces. Just do the following command:\n\n    rosdep update\n\n\
    Try again `rosmake mav_tools`\n\nAfter you have done it, just write:\n\n    rosdep\
    \ install asctec_drivers\n    rosmake asctec_drivers"
