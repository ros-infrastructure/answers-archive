    You need to manually calibrate each camera as [described here](http://wiki.ros.org/camera_calibration) in order for the camera_info topic to contain the correct values. The camera itself does not know it's own calibration parameters so you have to find them yourself.

    Even if both of your cameras are the same model you will need to calibrate them each separately because small manufacturing differences will affect the exact calibration values.
