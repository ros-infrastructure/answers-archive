    The main overhead is you filling/creating the message + marshalling.
    If you want to avoid your work: You can check for the `getNumSubscribers` property in a publisher to prevent doing any work (This is done, for example, in the kinect driver).

    Messages should not be stored temporarily unless the topic is latched.
