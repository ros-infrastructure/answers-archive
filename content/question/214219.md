  body_markdown: "This behaviour is intended and should prevent you from chasing version\
    \ incompatibilities for several hours.\n\n`canopen_motor_node` features the switching\
    \ between the different CANopen operation modes ([wiki](http://wiki.ros.org/canopen_motor_node#mode_switching))\
    \ at run-time.\nFor this to work a new interface was added to `ros_control` ([#200](https://github.com/ros-controls/ros_control/pull/200))\
    \ and finally got released with version 0.9.2/3.\n\nThis interface uses virtual\
    \ methods and will therefore compile even if the base class does not have these\
    \ methods.\nOf cause it will not work as expected, since the device will never\
    \ switch to the required mode.\nIn addition the new version of `canopen_402` will\
    \ not forward commands if no mode was selected and stops all motion by setting\
    \ the halt bit in the control word.\n\nBy the way, `ros_canopen` 0.6.4 and `ros_control`\
    \ 0.9.3 are available from the ROS repo and do not have to be built from source. "
