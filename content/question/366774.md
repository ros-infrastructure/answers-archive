  body_markdown: "Hi,\n\nROS Noetic uses gazebo 11 by default, and in that version\
    \ the `ignition::math::Box` template is replaced by `ignition::math::AxisAlignedBox`.\
    \  \n\nAlso, for the case of the `gazebo_version_helpers` package, there's a Noetic\
    \ branch in the main repository [https://github.com/JenniferBuehler/gazebo-pkgs/tree/noetic](https://github.com/JenniferBuehler/gazebo-pkgs/tree/noetic)\
    \ so you can use that one."
