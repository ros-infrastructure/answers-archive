    I found the solution to the problem:

    in the prosilica library (prosilica.cpp) in function <code>Camera::setWhiteBalance</code> the test, whether manual whitebalance is available

    <code>PvAttrIsAvailable(handle_, "WhitebalValueBlue")</code>

    returns 0 (ePvErrSuccess) if manual whitebalance for blue is available. since the whitebal check is

    <code>if (isauto == Manual && PvAttrIsAvailable(handle_, "WhitebalValueBlue"))</code>

    it will FAIL if the <code>PvAttrIsAvailable</code> returns <code>ePvErrSuccess</code>.

    <code>if (isauto == Manual && ePvErrSuccess == PvAttrIsAvailable(handle_, "WhitebalValueBlue"))</code>

    will solve the problem.
