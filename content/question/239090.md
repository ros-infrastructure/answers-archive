  body_markdown: "With some coding, you could add these informations in [user data](https://github.com/introlab/rtabmap/blob/eb21280f0486260b0ac94b4672200f85979f7c99/corelib/include/rtabmap/core/SensorData.h#L181)\
    \ field of the nodes. For example, if you set the `userDataRaw` variable [here](https://github.com/introlab/rtabmap_ros/blob/3d70d2fbad9471cb8386c7ab202051659e3e0786/src/CoreWrapper.cpp#L1020-L1029)\
    \ (`cv::Mat myData = ....; data.setUserDataRaw(myData)`), it will be saved in\
    \ the database and sent in output `mapData` topic. The `mapData` topic contains\
    \ the corrected graph and data of the latest node added to map (including your\
    \ [userData](https://github.com/introlab/rtabmap_ros/blob/3d70d2fbad9471cb8386c7ab202051659e3e0786/msg/NodeData.msg#L39),\
    \ the compressed user data). \n\nNote that user data cannot be used for loop closure\
    \ detection. To do so, it would require a deep change of the [rtabmap](https://github.com/introlab/rtabmap)\
    \ library.\n\ncheers"
