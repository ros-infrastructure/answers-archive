    The Raspberry Pi does not use the same binary format as standard desktop computers, so the standard ROS installation setup does not work.

    Have a look at the [ROS Indigo on Raspberry Pi instructions](http://wiki.ros.org/ROSberryPi/Installing%20ROS%20Indigo%20on%20Raspberry%20Pi).

    If you're using a Raspberry Pi 2, you can also install Ubuntu on it, and use the Ubuntu for armhf instructions: http://wiki.ros.org/indigo/Installation/UbuntuARM
