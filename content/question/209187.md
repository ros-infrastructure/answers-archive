  body_markdown: "Hi Kushal,\n\n1. You are on the right track, turtlebot_teleop is\
    \ a **ROS package** that contains a *launch file* called [keyboard_teleop.launch](https://github.com/turtlebot/turtlebot/blob/indigo/turtlebot_teleop/launch/keyboard_teleop.launch).\
    \ Said *launch file* invokes a **ROS node** called *turtlebot\\_teleop\\_keyboard*\
    \ that takes the input from the keyboard and outputs [geometry/Twist](http://docs.ros.org/api/geometry_msgs/html/msg/Twist.html)\
    \ messages to the **topic** *cmd\\_vel\\_mux/input/teleop*. Those *Twist* messages\
    \ contain the *linear* and *angular* speed that the robot should follow. Then\
    \ there is another *node* that subscribes to the same *topic* and actually moves\
    \ the robot. The *listening node* is actually a **nodelet** that depends on the\
    \ underlying hardware of your turtlebot.\n\n2. I can not think of a simple example\
    \ right now, but you can check out the [navigation stack](http://wiki.ros.org/navigation)\
    \   \n\nI hope this helps"
