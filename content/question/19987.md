  body_markdown: "Create a gazebo node:\n\n       gznode_ = gazebo::transport::NodePtr(new\
    \ gazebo::transport::Node());\nand advertise a new publisher:\n\n       pub =\
    \ gznode_->Advertise<gazebo::msgs::\"message_type\">(\"custom_topic_name\");\n\
    change  \"message_type\" and custom_topic_name to your own needs. Now you can\
    \ publish a message by:\n\n      pub->Publish(msg);\n\nThe types depend on the\
    \ Gazebo Version you are using. For all versions < 9 you need to include:\n \n\
    \      #include \"gazebo/transport/transport.hh\"\n\nand the variable declaration\
    \ look like this:\n\n     gazebo::transport::NodePtr gznode_;\n     gazebo::transport::PublisherPtr\
    \ pub;"
