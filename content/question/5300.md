I added a ROS\_INFO\_STREAM() call to gazebo\_ros\_imu.cpp:

<pre>
    if (!this->sdf->HasElement("bodyName"))
    {
      ROS_FATAL("imu plugin missing <bodyName>, cannot proceed");
      return;
    }
    else
      this->link_name_ = this->sdf->Get<std::string>("bodyName");
    ROS_INFO_STREAM("this->link_name_ = " << this->link_name_); // This prints "base_link".
</pre>

This code confirmed that the plugin is getting "base\_link" as the value of the bodyName parameter. Am I specifying the IMU plugin incorrectly in the URDF file?
