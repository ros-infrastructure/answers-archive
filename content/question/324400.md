    First: please make sure you actually need to build it from sources.

    `mavros` (and related packages) have been released for Indigo, Kinetic, Lunar and Melodic. See [wiki/mavros](http://wiki.ros.org/mavros).

    If you just want to use the packages, use `sudo apt install ros-kinetic-mavros` instead of building from source.

    As to the error message: if you're following [the source build installation instructions](https://github.com/mavlink/mavros/blob/d27e5761280fe21b6e6721c3ff4a2a999b7a4ed9/mavros/README.md#source-installation) it actually tells you to use `catkin build`, not `catkin_make`.

    `catkin_make` cannot build workspaces with non-Catkin packages in it. `catkin_tools` can.
