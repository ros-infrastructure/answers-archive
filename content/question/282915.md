  body_markdown: "I recommend using the octomap_server http://wiki.ros.org/octomap_server.\
    \   This will filter redundant points by binning them into a 3d occupancy grid.\
    \  You can watch the results in rViz as the map generates too which is handy for\
    \ debugging.  I have been using it process sonar point clouds from an ROV with\
    \ decent results.   \n\nOctomap has a nice c++ api if you prefer to do things\
    \ manually. https://github.com/OctoMap/octomap\n\n**octmap_server**\n\n 1. Start\
    \ the octomap_sever ros node\n 2. play your rosbag file back http://wiki.ros.org/rosbag/Tutorials/Recording%20and%20playing%20back%20data\n\
    \ 3. open rViz to see whats going on.  Subscribe to the occupied_cells_vis_array\
    \ topic.\n\nI included an example launch file to help you out,  you will probably\
    \ need to remap your point cloud topic to cloud_in:\n\n    <launch>\n        <node\
    \ name=\"octomap\" pkg=\"octomap_server\" type=\"octomap_server_node\">\n    \
    \        <param name=\"frame_id\" value=\"/odom\"/>\n            <param name=\"\
    resolution\" value=\".4\"/>\n        </node>\n    </launch>\n\n\n**C++**\n\nif\
    \ you want to go the c++ route with rosbag or want to read in a .pcd file you\
    \ probably want to do something like this.  You can then use octovis http://wiki.ros.org/octovis\
    \ to open the octomap and view it.\n\n    #include <octomap/octomap.h>\n    #include\
    \ <octomap/OcTree.h>\n    #include <pcl_conversions/pcl_conversions.h>\n    #include\
    \ <pcl/point_types.h>\n    #include <pcl/PCLPointCloud2.h>\n    #include <pcl/conversions.h>\n\
    \    \n    \n    int main(int argc, char *argv[])\n    {\n    \n        ros::init(argc,\
    \ argv, \"pcl2octo\");\n    \n        octomap::OcTree tree (0.1);   // declare\
    \ your octomap at 0.1 resolution\n    \n    \n        //\\/\\/\\/\\/\\/\\/\\/\\\
    /\\/\\/\\/\\/\\/\\/\\/\\/\\//\\\n        // read in your data here either rosbag\
    \ or pcl\n        // http://wiki.ros.org/rosbag/Code%20API#cpp_api\n        //\
    \ http://pointclouds.org/documentation/tutorials/pcd_file_format.php\n       \
    \ //\\/\\/\\/\\/\\/\\/\\/\\/\\/\\/\\/\\/\\/\\/\\/\\/\\/\\/\n    \n        for(/*\
    \ enter conditoins here */){  // crate a loop for each sensor measurement taken\n\
    \    \n            pcl::PointCloud<pcl::PointXYZ> pt; // populate this with the\
    \ point cloud from one sensor ping\n            octomap::point3d sensorOrigin(x,y,z);\
    \ // where x,y,z are the location of the sensor for that measurement\n    \n \
    \           for (pcl::PointCloud<pcl::PointXYZ>::const_iterator it = pt.begin();\
    \ it != pt.end(); ++it){\n              cloud.push_back(it->x, it->y, it->z);\n\
    \            }\n    \n            tree.insertPointCloud(cloud,sensorOrigin);\n\
    \        }\n        tree.writeBinary(\"simple_tree.bt\");\n    \n        return\
    \ 0;\n    \n    \n    }\n\n\nI hope that helps."
