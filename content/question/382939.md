    Hi @prakashravi, there is a tutorial how to install ROS Kinetic in Raspberry Pi including RPi 4:

    http://wiki.ros.org/ROSberryPi/Installing%20ROS%20Kinetic%20on%20the%20Raspberry%20Pi

    A couple things to consider, is ROS Kinetic eol was April 2021, so suggest to try to use Ubuntu 20.04, the installation is smoother: https://ubuntu.com/download/raspberry-pi

    Or Melodic at least has end of life of May 2023

    With regards to turtlebot2, there is also Melodic version that might be easier to work with:
    https://github.com/gaunthan/Turtlebot2-On-Melodic

    It's possible to make it work with ROS Noetic, but that will require more work. Hope this helps.
