  body_markdown: "Right, you need to use boost::bind. Try:\n\n    ros::Subscriber\
    \ sub = n.subscribe(\"topic-name\", 1000, \n        boost::bind(writeOut, _1,\
    \ boost::cref(sound)));\n\nNote that the call to `cref` is necessary because you\
    \ want to pass a const reference instead of passing `sound` by value, i.e. copying\
    \ it. If you want a normal reference, not a const reference, use `ref`.\n\n**Edit**:\
    \ I just updated my answer to explicitly qualify the namespace of cref (it should\
    \ be in namespace boost). You need to include `boost/ref.hpp`."
