    \ the rotation coefficients and convert it into quaternions, which is what RVIZ\
    \ understands. \n\nHere is the modified code [snippet](http://answers.ros.org/question/31006/how-can-a-vector3-axis-be-used-to-produce-a-quaternion/)\
    \ which does that:\n\n            tf::Vector3 axis_vector(coefficients->values[3],\
    \ coefficients->values[4], coefficients->values[5]);\n\t\t\ttf::Vector3 up_vector(1.0,\
    \ 0.0, 0.0);\n\t\t\ttf::Vector3 right_vector = axis_vector.cross(up_vector);//\n\
    \t\t\tright_vector.normalized();//\n\t\t\ttf::Quaternion q(right_vector, -1.0*acos(axis_vector.dot(up_vector)));//\n\
    \t\t\tq.normalize();//\n\t\t\tgeometry_msgs::Quaternion line_orientation;\n\t\t\
    \ttf::quaternionTFToMsg(q, line_orientation);\n\n\n[Screenshot from 2015-03-05\
