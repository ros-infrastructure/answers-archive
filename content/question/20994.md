  body_markdown: "It looks live you've made the URDF for this okay, but you'll need\
    \ to start a few more components to be able to drive this with the /cmd_vel topic.\
    \ At the moment you've just spawned a robot with controllable joints but without\
    \ anything controlling them.\n\nYou'll need to create a yaml file which contains\
    \ the configuration of the differential driver controller itself, and optionally\
    \ a joint_state_controller so that ROS can know the angle of the wheel joints.\n\
    \nThe launch file that starts the simulation will need to load the configuration\
    \ from this yaml file and start the ros_control controllers.\n\nThe YAML file\
    \ should look something like this:\n\n    # Publish all joint states -----------------------------------\n\
    \    joint_state_controller:\n      type: joint_state_controller/JointStateController\n\
    \      publish_rate: 50  \n\n    # Differential Drive Controller\n    diff_drive_controller:\n\
    \      type: \"diff_drive_controller/DiffDriveController\"\n      left_wheel:\
    \ ['left_wheel_hinge']\n      right_wheel: ['right_wheel_hinge'']\n    \n    \
    \  wheel_separation: 0.66\n      wheel_radius: 0.1\n    \n      cmd_vel_timeout:\
    \ 0.25\n      enable_odom_tf: true\n    \n      pose_covariance_diagonal: [0.001,\
    \ 0.001, 1000000.0, 1000000.0, 1000000.0, 1000.0]\n      twist_covariance_diagonal:\
    \ [0.001, 0.001, 1000000.0, 1000000.0, 1000000.0, 1000.0]\n\nYou'll need to add\
    \ the following lines to your launch file to start the controllers:\n\n      <!--\
    \ Load joint controller configurations from YAML file to parameter server -->\n\
    \      <rosparam file=\"$(find rorover_skid_steer)/config/rorover_control.yaml\"\
    \ command=\"load\"/>\n    \n      <!-- load the controllers -->\n      <node name=\"\
    controller_spawner\" pkg=\"controller_manager\" type=\"spawner\" respawn=\"false\"\
    \n        output=\"screen\" args=\"joint1_position_controller diff_drive_controller\
    \ joint_state_controller\"/>\n\nYou will have to change the joint names to match\
    \ your robot, but this should get this working for you."
