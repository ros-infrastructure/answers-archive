    \ submit a PR against `ros-planning/moveit` and get it merged.\n\n---\n\nThere\
    \ should be no need to build MoveIt from source (I'm also not entirely sure what\
    \ you'd be changing specifically in that case).\n\nThe time parameterisation is\
    \ done in a MoveIt *Planning Request Adapter*.\n\nThere are three of those, corresponding\
    \ to the three algorithms currently available:\n\n - `AddTimeParameterization`\
    \ (which applies the Iterative Parabolic Time Parameterization)\n - `AddIterativeSplineParameterization`\
    \ (the spline based approach: Iterative Spline Parameterization)\n - `AddTimeOptimalParameterization`\
    \ (using the Time-optimal Trajectory Generation library by Tobias Kunz)\n\nSo\
    \ changing the algorithm used is a matter of changing the configuration of the\
    \ planning request adapters.\n\nFor MoveIt configurations generated by the MoveIt\
    \ Setup Assistant, that can be done by editing the `ompl_planning_pipeline.launch.xml`\
    \ file.\n\nSpecifically, change [this line](https://github.com/ros-planning/moveit/blob/f842b1f852ad6ff1b8c8cf8772c327bff75f5c68/moveit_setup_assistant/templates/moveit_config_pkg_template/launch/ompl_planning_pipeline.launch.xml#L14)\
    \ and replace `AddTimeParameterization` with `AddIterativeSplineParameterization`.\n\
    \nRefer to the [Time Parameterization](https://ros-planning.github.io/moveit_tutorials/doc/time_parameterization/time_parameterization_tutorial.html)\
    \ page in the MoveIt documentation for some more info on this.\n\nAnd refer to\
    \ the [planning_request_adapters_plugin_description.xml](https://github.com/ros-planning/moveit/blob/471ebbe7918786f8d6f6ba69cce1f0001ddb2a2c/moveit_ros/planning/planning_request_adapters_plugin_description.xml#L34-L48)\
    \ file for a list of available time parameterisation planning request adapters."
