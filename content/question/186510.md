    \ since python does not need a compiler, and the executable is the own .py file.\
    \ You need to just specify the .py file. This means something like this.\n\n \
    \   <node name=\"search\" pkg=\"searching_tobot\" type=\"search.py\" output=\"\
    screen\">\n\nI had a similar problem and this worked for me. \n\nHope this helps\
