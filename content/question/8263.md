    \nSince `rendering::MovableText` inherits from `Ogre::MovableObject`, you need\
    \ to attach it to the `Ogre::SceneNode` of a Gazebo `rendering::Visual`. Something\
    \ like this for example:\n\n    // Get the user camera\n    rendering::UserCameraPtr\
    \ userCamera = gui::get_active_camera();\n\n    // Create a visual and add it\
    \ to the camera's scene\n    rendering::VisualPtr visual;\n    visual->Load();\n\
    \    userCamera->GetScene()->AddVisual(visual);\n    \n    // Create text, Obs:\
    \ Font size is in meters\n    rendering::MovableText *text;\n    text->Load(\"\
    __TEXT_OBJECT__\", \"text displayed\", \"Arial\", 0.1);\n    \n    // Create a\
    \ node for the text\n    Ogre::SceneNode *textNode = visual->GetSceneNode()->createChildSceneNode(\"\
    __TEXT_NODE__\");\n    textNode->attachObject(text);\n\n"
