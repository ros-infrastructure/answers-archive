    \n    rosdep resolve gazebo_msgs\n\nIf this is the case, in order to use the standard\
    \ ROS supported versions again, I would suggest to remove the 00-* files in `/etc/rosdep/sources.list.d`\
    \ , run `rosdep update`and launch bloom again to generate a new -release version\
