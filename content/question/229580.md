  body_markdown: "Crlt+C will be handled by the ros node logic internal and causes\
    \ ros::ok()  to no longer return true but false . After ros:ok() is not true any\
    \ more there is no need to call ros::shutdown()\n\nI think your code may look\
    \ like this\n\n     int main()\n      {\n          bool  running(false);\n   \
    \       //running is set to true by a condition statement somewhere here\n\n \
    \         // exit the main loop \n          //              if running flag is\
    \ set false, \n          //          or if ros::ok() is not ok anymore (likely\
    \ we received Crlt+C), \n          //          or if the view was stopped\n  \
    \       for(; running && ros::ok() && !viewer->wasStopped() ;)\n          {\n\
    \           // ...             ...                          ...              \
    \    ...\n           //do something\n          }\n      \n      if ( ros::ok()\
    \ )\n      {\n          // we exited the main loop because of false running value\
    \ or the viewer was stopped,\n          // no Crlt+C received, i. e. we have to\
    \ ros::shutdown() explizitly\n          ros::shutdown();\n      }\n      else\n\
    \      {\n          // nothing to be done here, ros::ok() no longer true, ros::shutdown\
    \ not needed anymore\n      }\n      return 0;\n   }"

 I have a code where I am checking for shutdown interrupt in a statement like so:

             int main()
              {
                  bool  running(false);
                  //running is set to true by a condition statement somewhere here
                 for(; running || ros::ok() || !viewer->wasStopped() ;)
	              {
                   // ...             ...                          ...                  ...
                   //do something
                  }
	          ros::shutdown();
	          return 0;
           }


However, during runtime, when I do `Ctrl + C`, I get the usual  warning  `^C[ WARN] [1458383451.748234940]: Shutdown Signal Received. Shutting down ROS!` but  the node never shuts down.

 Could I be missing something?
