  body_markdown: "There are some differences, not mentioned in http://wiki.ros.org/ROS/Tutorials/WritingServiceClient%28c%2B%2B%29).\
    \ The service must be a class member of your plugin class; however, services/publishers/subscribers\
    \ as class members are not so special to rqt; it's a quite common practise...\n\
    \nA few notes, special to rqt:\n\n - advertise your service in initPlugin\n -\
    \ use `getNodeHandle()` as NodeHandle if your service can run in a single thread\
    \ (with your GUI); note that long running services may block your GUI\n - use\
    \ `getNodeHandleMT()` as NodeHandle if your service may run asynchronously with\
    \ your GUI. Thread-safety? Your Job!!!\n - call service.shutDown() in shutDownPlugin().\
    \ Otherwise your service can be called after your GUI Plugin was unloaded which\
    \ might cause seg fault.\n\nYour code may look like:\n\nHeader:\n\n    #include\
    \ \"beginner_tutorials/AddTwoInts.h\"    \n\n      // this should be know to you\n\
    \    class YourRqtPlugin\n\n      : public rqt_gui_cpp::Plugin\n    {\n    \n\
    \      Q_OBJECT\n    \n    public:\n      // this should be know to you\n    \
    \  YourRqtPlugin();\n    \n      virtual void initPlugin(qt_gui_cpp::PluginContext&\
    \ context);\n    \n      virtual void shutdownPlugin();\n        \n    protected:\n\
    \    \n          // this is new for the service\n         bool add(beginner_tutorials::AddTwoInts::Request\
    \  &req,\n                        beginner_tutorials::AddTwoInts::Response &res);\n\
    \          // and this is new for the service\n        ros::ServiceServer service;\n\
    \    \n    };\n\nSource:\n\n\n    YourRqtPlugin::YourRqtPlugin()  : \n      rqt_gui_cpp::Plugin()\n\
    \    {\n      setObjectName(\"Qt based service server\"); // or whatever\n   \
    \ }\n    \n    void YourRqtPlugin::initPlugin(qt_gui_cpp::PluginContext& context)\n\
    \    {  \n         <<.........................>>\n             other GUI intialization\
    \ stuff\n         <<.........................>>\n          // advertise your service\
    \ in initPlugin\n          // use getNodeHandle() to get a nodehandle reference\n\
    \         service = getNodeHandle().advertiseService(\"add_two_ints\", &YourRqtPlugin::add,\
    \ this);\n    }\n      \n    void YourRqtPlugin::shutdownPlugin()\n    {\n   \
    \     // shutdown service; otherwise seg faults possible if service is called\
    \ after plugin was unloaded\n        service.shutDown();\n    }\n    \n    bool\
    \ YourRqtPlugin::add(beginner_tutorials::AddTwoInts::Request  &req,\n        \
    \                beginner_tutorials::AddTwoInts::Response &res)\n    {\n    \n\
    \         res.sum = req.a + req.b;\n         ROS_INFO(\"request: x=%ld, y=%ld\"\
    , (long int)req.a, (long int)req.b);\n         ROS_INFO(\"sending back response:\
    \ [%ld]\", (long int)res.sum);\n         return true;\n    }"
