  body_markdown: |-
    The compiler isn't compiling add.cpp because it doesn't know it needs to, and thus it can't find the definition of add(int, int). You need to make add.cpp a source file in cmake.  You would do that in [add_executable](http://www.cmake.org/cmake/help/cmake2.6docs.html#command:add_executable). It would look like this:

        add_executable(shortest_path src/main.cpp src/add.cpp)

    You should also probably put your add.h file in the include folder, especially if you want other nodes to be able to see add.h.  Keep going through the tutorials!
