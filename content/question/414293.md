  body_markdown: "You need to Install the rpi_ws281x library on the Raspberry Pi.\n\
    \n> pip install rpi-ws281x==1.1.1\n\n\nAnd write a ROS 2 node in Python that imports\
    \ the rpi_ws281x library and controls the WS2812B LED lights in response to ROS\
    \ 2 messages.\n\n\n    import rclpy\n    from std_msgs.msg import ColorRGBA\n\
    \    from rpi_ws281x import Adafruit_NeoPixel, Color\n    \n    # Define the number\
    \ of WS2812B LED lights and the pin they are connected to\n    NUM_LEDS = 30 \
    \ # Number of LED\n    LED_PIN = 18  # 0- number will form a color\n    \n   \
    \ # Initialize the WS2812B LED lights\n    strip = Adafruit_NeoPixel(NUM_LEDS,\
    \ LED_PIN)\n    strip.begin()\n    strip.show()\n    \n    # Callback function\
    \ for the color message\n    def color_callback(msg):\n        # Set the color\
    \ of all the WS2812B LED lights\n        for i in range(NUM_LEDS):\n         \
    \   strip.setPixelColor(i, Color(int(msg.r * 255), int(msg.g * 255), int(msg.b\
    \ * 255)))\n        strip.show()\n    \n    def main(args=None):\n        rclpy.init(args=args)\n\
    \        node = rclpy.create_node('minimal_subscriber')\n        subscription\
    \ = node.create_subscription(ColorRGBA, 'color', color_callback, 10)\n       \
    \ subscription  # prevent unused variable warning\n        rclpy.spin(node)\n\
    \        node.destroy_node()\n        rclpy.shutdown()\n    \n    if __name__\
    \ == '__main__':\n        main()\n\n\nI hope it helps, fell free to drop a comment\
    \ in case of questions."
