  body_markdown: "Yes, you can write a motor/actuator plugin (check out this tutorial:\
    \ http://gazebosim.org/tutorials?cat=guided_i&tut=guided_i5). Then you can add\
    \ your plugin(s)* to your URDF to control the joints you want to move.  \n\nDepends\
    \ on how your write your plugin. You can either write a plugin that controls a\
    \ single joint - which you'd then declare multiple instances of in your URDF -\
    \ or you can write a plugin that controls multiple joints.\n\nAlso, you may want\
    \ to check out ros control: http://gazebosim.org/tutorials/?tut=ros_control\n\n\
    ---\nEDIT:\nHere's some boilerplate plugin code for a joint controller:\nnamespace\
    \ gazebo\n\n    {\n      YourPlugin::YourPlugin() {}\n\n      YourPlugin::~YourPlugin()\
    \ {}\n\n       /// \\brief Load function gets called by Gazebo when the plugin\
    \ is inserted in simulation \n       /// via URDF/SDF\n       /// \\param[in]\
    \ _model A pointer to the model that this plugin is attached to.\n       /// \\\
    param[in] _sdf A pointer to the plugin's SDF element.\n       void YourPlugin::Load(physics::ModelPtr\
    \ _model, sdf::ElementPtr _sdf)\n      {\n          // Store the model ptr for\
    \ convenience.\n          this->model_ = _model;\n\n          // Get the name\
    \ of your actuator/sensor joint from the URDF/SDF\n          // Assuming:\n  \
    \        // <gazebo reference = \"SENSORLINKNAME\" />\n          //     <actuatorJoint>NAMEOFJOINT</actuatorJoint>\n\
    \          // </gazebo>\n          //\n          std::string joint_name = \"\"\
    ;\n          if ( _sdf->HasElement(\"actuatorJoint\") ) {\n              joint_name\
    \ = _sdf->Get<std::string>(\"actuatorJoint\");\n          } else {\n         \
    \     ROS_WARN_NAMED(\"your_plugin\", \"YourPlugin missing <actuatorJoint>!!!\"\
    );\n          }\n\n          // Store the actuatorjoint pointer.\n          this->joint_\
    \ = this->model_->GetJoint(joint_name);\n\n          // OTHER BOILERPLATE STUFF\n\
    \n          // Listen to the update event. This event is broadcast every\n   \
    \       // simulation iteration.\n          this->update_connection_ = event::Events::ConnectWorldUpdateBegin\
    \ (\n          boost::bind ( &YourPlugin::OnUpdate, this, _1 ) );\n      }\n\n\
    \      // SETUP GAZEBO/ROS MESSAGING\n\n      /// \\brief Function called at each\
    \ simulation interation\n      void YourPlugin::OnUpdate(const common::UpdateInfo\
    \ & _info)\n      {\n          common::Time current_time = this->model_->GetWorld()->GetSimTime();\n\
    \          current_joint_angle = this->joint_->GetAngle(0).Radian() // Get joint\
    \ angle\n\n          // DO COOL STUFF / PUBLISH JOINT ANGLE\n          // this->target_torque_\
    \ = CALL TO PID CONTROLLER HERE\n\n          this->joint_->SetForce(0, this->target_torque_);\n\
    \      }\n\n      // Tell Gazebo about this plugin, so that Gazebo can call Load\
    \ on this plugin.\n      GZ_REGISTER_MODEL_PLUGIN(YourPlugin)\n    }"
