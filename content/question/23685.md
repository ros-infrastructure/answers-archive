  body_markdown: "Using if statement. \n\n    if(height > x)\n    { \n        do plugin\
    \ job\n    }\n\nYou would need to edit the Buoyancy plugin yourself. See the source\
    \ code [here](https://bitbucket.org/osrf/gazebo/src/default/plugins/BuoyancyPlugin.cc).\
    \ The method `void BuoyancyPlugin::OnUpdate()` is called on every step to apply\
    \ some forces on the model. So if you wrap the whole code inside this function\
    \ with\n\n    if(link->WorldCoGPose().Pos().Z() < height)\n    { \n        ...\n\
    \    }\n\nthe plugin will only take an effect when the model is under this level.\n\
    \nThe API method name could differ depending on your Gazebo version which you\
    \ haven't mention in any of your questions.\n\n\n----------\nEDIT\nYou will create\
    \ the files `BuoyancyPlugin.cc` and `BuoyancyPlugin.hh` in some of your packages,\
    \ modify the said function and build it with your others plugins and packages\
    \ (using catkin_make perhaps?). Just name it differently so that gazebo knows\
    \ which plugin you are using.\n\n\n----------\nEDIT 2\n\nYou put the condition\
    \ check of the link before the link is defined. Just put the IF after the link\
    \ variable is filled with a legitimate value.\n\n    void BuoyancyPlugin1::OnUpdate()\n\
    \    { \n      for (auto link : this->model->GetLinks())\n      {\n        if(link->WorldCoGPose().Pos().Z()\
    \ < 10){ \n            VolumeProperties volumeProperties = this->volPropsMap[link->GetId()];\n\
    \            double volume = volumeProperties.volume;\n            GZ_ASSERT(volume\
    \ > 0, \"Nonpositive volume found in volume properties!\");\n    \n          \
    \  // By Archimedes' principle,\n            // buoyancy = -(mass*gravity)*fluid_density/object_density\n\
    \            // object_density = mass/volume, so the mass term cancels.\n    \
    \        // Therefore,\n            ignition::math::Vector3d buoyancy =\n    \
    \            -this->fluidDensity * volume * this->model->GetWorld()->Gravity();\n\
    \    \n            ignition::math::Pose3d linkFrame = link->WorldPose();\n   \
    \         // rotate buoyancy into the link frame before applying the force.\n\
    \            ignition::math::Vector3d buoyancyLinkFrame =\n                linkFrame.Rot().Inverse().RotateVector(buoyancy);\n\
    \    \n            link->AddLinkForce(buoyancyLinkFrame, volumeProperties.cov);\n\
    \         }\n      }\n    }"
