  body_markdown: "For ROS navigation stack, `map_server` is responsible to read the\
    \ map. So you need to go through the [map_server wiki](http://wiki.ros.org/map_server)\
    \ after reading my answer.\n\nBasically, `map_server` need two files, i.e a image\
    \ file and a YAML file. The YAML file describes the map meta-data, and names the\
    \ image file. The image file encodes the occupancy data. \n\nThe image file is\
    \ the 2D drawing of the map, it is read in via SDL image library. So most popular\
    \ image formats are widely supported, such as .pgm, .png, .jpg, etc. I don't know\
    \ if the CAD format is supported, but maybe you can convert the CAD drawing format\
    \ into regular image format. \n\nIn my project, I used the GIMP to draw a map,\
    \ and output a .pgm image.\n\n\n----------\nEDIT\n\nIn the YAML file, there is\
    \ a param named `resolution`, which is the resolution of the map, meters / pixel.\n\
    \nFor example, the image is 400x300, and resolution=0.1, then your map is 40mx30m.\n\
    \nAnd my project is not open-source yet."
