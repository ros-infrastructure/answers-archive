    \ because it's being communicated within Gazebo, not on ROS, you'd have to have\
    \ it subscribe to a ROS topic by modifying the tracked vehicle plugin (see source\
    \ code here: https://github.com/osrf/gazebo/blob/gazebo9/plugins/TrackedVehiclePlugin.cc)\n\
    2. It does all of that internally so it'd have to be modified to set the track\
    \ speeds based on your topic, not internally based on cmd_vel\n3. It can be added\
    \ to a xacro file like a normal gazebo plugin\n\nIf you want something to simulate\
    \ the physics of tracks this is probably the best plugin there is for gazebo,\
    \ otherwise, you can just use wheels and something like a diff_drive_controller\
    \ and modify that. "
