    The default planner (within OMPL that is) can be configured using the MoveIt Setup Assistant, on the *Planning Groups* tab. See [here](https://ros-planning.github.io/moveit_tutorials/doc/setup_assistant/setup_assistant_tutorial.html#step-4-add-planning-groups) for the guide.

    I'm not sure whether there is a way to set the "default planner" using any API. You should be able to set the planner to use for subsequent requests using the function you mention though, but it could be that on Indigo (you tagged the question with `indigo`) this is not supported.

    It could also be you're using an incorrect planner configuration ID (which is what `SBLkConfigDefault` is called). If you're sure `setPlannerId(..)` should work, you may want to try using just `SBL`).
