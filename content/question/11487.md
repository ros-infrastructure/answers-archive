  body_markdown: |-
    Yes, you do. The Create needs to be put in "full" mode to enable the breakers. This can be done by using the Mode button on the [TurtleBot dashboard](http://www.ros.org/wiki/turtlebot_dashboard), or by sending it motion commands (using one of the [teleoperation examples](http://www.ros.org/wiki/turtlebot_teleop/Tutorials/Teleoperation) or your own code).

    If it's still not working when it's in full mode, use the dashboard to check that breaker 0 is set. Breaker 0 should automatically be set, though.
