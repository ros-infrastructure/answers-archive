When I added another message file in the same package, the problem comes to .

when I comment like ```$rossrv md5 perception``` in console, it shows md5sum as ```9d5d0f603573839f746e2437bd9a65b9```. <br/>

I want to know why it is changed like this and how to recover its original md5sum. <br/>
