    This sounds like a problem with your tf tree. The error message points at a disconnected tree with no transform between base_link and map, which sounds like the SLAM/localization solution is not setup properly. It would be helpful if you can edit your post with some info about your tf tree (for example output of view_frames as described [here](http://www.ros.org/wiki/tf)).

    Also, using hector_mapping with the Kinect likely will not work well, if you only have a Kinect (and hopefully odometry), it is recommended to use slam_gmapping.
