    For a simpler library, you may want to check [gspeet](https://github.com/severin-lemaignan/gspeett): it's a small python library that listen (continously or not) on the microphone (using ALSA. It should work on Nao), encode the speech using the `speex` encoder (well, a google variant of it, actually -- it still requires `libspeex`), send it to Google speech API, and returns the result.

    Integration in a ROS node should be trivial, but the library itself is independant.
