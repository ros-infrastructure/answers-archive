  body_markdown: |-
    You need a tf broadcaster, check this tutorial is very easy to understand: [tf broadcaster](http://www.ros.org/wiki/tf/Tutorials/Writing%20a%20tf%20broadcaster%20%28C%2B%2B%29)<br><br>
    The IMU message publish "orientation" which is a geometry_msgs/Quaternion so, in the node where you do the tf broadcast just add a subscriber to this IMU message, get the orientation, transform it using tf::quaternionMsgToTF(geometry_msgs::Quaternion, tf::Quaternion) and pass it straight to the transform.setRotation(tf::Quaternion)<br><br>
    Take into account you have to choose well your frame_id's, if you have already a tf with the urdf file which joins laser and imu, then you should transform from, for example, "world" to "imu_link".<br><br>
    Resuming you need a node with a subscriber to the IMU message and a tf broadcaster. In this node you have to transform the imu message orientation to a tf::Quaternion and then do the rotation and publish it.
