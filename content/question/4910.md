I tried unsuccessfuly to:

- move the plugin tag up to the robot's model
- change the joints to segway_rmp400::the_joint
- both at same time
- find the patched plugin mentioned in ["question/3311/skidsteerdriveplugin"](http://answers.gazebosim.org/question/3311/skidsteerdriveplugin)

In the ["question/3311/skidsteerdriveplugin"](http://answers.gazebosim.org/question/3311/skidsteerdriveplugin) something similar happens because the plugin has the joint names hard coded. I suppose the problem is there
