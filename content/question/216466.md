  body_markdown: "For multithreaded callback queues of ROS have a look at this:\n\n\
    http://wiki.ros.org/roscpp/Overview/Callbacks%20and%20Spinning\n\nNote that if\
    \ you uses MultiThreaded or AsynchSpinners your callbacks might be called in parallel,\
    \ i. e. you will need mutexes and condition_variables to properly sync your callbacks\
    \ and avoid race conditions.\n\nEdit:\n\nIncludes:\n\n    #include <ros/ros.h>\n\
    \    #include <ros/callback_queue.h>\n\nSet up like this:\n\n    // create instances\n\
    \    ros::NodeHandle my_nh;\n    ros::CallbackQueue my_queue;\n    ros::AsyncSpinner\
    \ my_spinner( 2 /*number of threads*/, &my_queue /* spinner exclusively for my_queue\
    \ */);\n    \n    // bind the queue to the node handle\n    my_nh.setCallbackQueue(\
    \ &my_queue );\n    \n    // now advertise/subscribe using my_nh\n    ros::Subscriber\
    \ my_subscriber_foo = my_nh.subscribe( \"foo\", 1, onFooReceived );\n    ros::Subscriber\
    \ my_subscriber_bar = my_nh.subscribe( \"bar\", 1, onBarReceived );\n    \n  \
    \  // now start the spinner\n    my_spinner.start();\n\n\nYour callbacks `onFooReceived`\
    \ and `onBackReceived` can now be executed in parallel, if messages arrive such\
    \ that this is appropriate...\n"
