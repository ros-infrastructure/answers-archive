  body_markdown: "As noted in comment above, I've been struggling with this as well\
    \ on a PI 3b+.\n\nHere is what I learned.\nogg is part of the theora video codec\
    \ and transport. I guess it comes as part of ubuntu but not raspbian stretch.\n\
    \nYou need to install the source and make it.\n\nHere is what I used:\n\n    cd\
    \ ~\n    \n    wget http://downloads.xiph.org/releases/ogg/libogg-1.3.1.tar.gz\n\
    \    tar -xf libogg-1.3.1.tar.gz \n    cd libogg-1.3.1/\n    ./configure --host=arm-unknown-linux-gnueabi\
    \ --enable-static\n    make\n    sudo make install\n   \n    cd ~\n \n    wget\
    \ http://downloads.xiph.org/releases/vorbis/libvorbis-1.3.3.tar.gz\n    tar -xf\
    \ libvorbis-1.3.3.tar.gz\n    cd libvorbis-1.3.3/\n    ./configure --host=arm-unknown-linux-gnueabi\
    \ --enable-static\n    make\n    sudo make install\n\n    cd ~\n    \n    wget\
    \ http://downloads.xiph.org/releases/theora/libtheora-1.1.1.tar.bz2\n    tar -xf\
    \ libtheora-1.1.1.tar.bz2 \n    cd libtheora-1.1.1/\n    ./configure --host=arm-unknown-linux-gnueabi\
    \ --enable-static\n    make\n    sudo make install\n\nI got the info from this\
    \ link but the flow is incorrect. Do it in the order I use above.\n[https://www.codepool.biz/raspberry-pi-live-streaming-usb-webcam.html](https://www.codepool.biz/raspberry-pi-live-streaming-usb-webcam.html)\n"
