    No, this is not directly supported by `rqt_graph`.

    The graph is a regular `dot` graph though, so you could (try to) intercept it and then post-process the source of the graph.

    Using a different layout engine fi could already help.

    Alternatively you could configure *what* is included in the visualisation by using the checkboxes and the dropdown in the top part of the `rqt_graph` window.
