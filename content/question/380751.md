    From your log:

        terminate called after throwing an instance of 'boost::wrapexcept<boost::property_tree::ptree_bad_path>'
        what():  No such node (11)

    This does not have anything to do with ROS nodes or CAN nodes, but with a node that is is missing in a Boost property tree.
    The latter is used by `canopen_master` to parse the EDS/DCF file.

    So something is wrong in that file.
    Unfortunately the parser does not report any context ([yet](https://github.com/ros-industrial/ros_canopen/issues/437)?).

    Please check your file with CANeds, if possible.
