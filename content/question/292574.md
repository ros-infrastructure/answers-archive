  body_markdown: "Here's a quick example adapted from the talker.py in the tutorials:\n\
    \n    #!/usr/bin/env python\n    import rospy\n    from sensor_msgs.msg import\
    \ PointCloud2\n    import random\n    \n    def callback(data, pub):\n       \
    \ # Here would be a place to do some sort of computation to decide if you want\n\
    \        # the data republished on the new topic. I've inserted a dummy computation.:\n\
    \        if random.randint(1,10) <= 5:\n            rospy.loginfo(\"republish\
    \ this cloud!\")\n            pub.publish(data)\n        return\n        \n  \
    \  def listener():\n        rospy.init_node('pointcloud_republisher')\n      \
    \  pub = rospy.Publisher(\"pcd_points\", PointCloud2, queue_size=1)\n        rospy.Subscriber(\"\
    depth/points\", PointCloud2, callback, callback_args=(pub))\n        rospy.spin()\n\
    \    \n    if __name__ == '__main__':\n        listener()\n\nThe only real differences\
    \ are:\n\n+ In the callback you'd want to decide if this is a topic that you would\
    \ want published for the `pointcloud_to_pcd` node to save as a pcd file.\n+ I've\
    \ used the `callback_args` optional argument to the Subscriber constructor so\
    \ that we can keep using the same Publisher object for all publishing on the `pcd_points`\
    \ topic.\n    \n"
