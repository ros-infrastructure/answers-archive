      \ Model  -> right click on the link -> Open Link Inspector -> Collision tab\
      \ ->  drop down the collision -> Srurface/Friction/Mu edit value\n\nOr in [SDF](http://sdformat.org/spec?ver=1.6&elem=collision)\
      \ code:\n\n    <model>\n    ...\n       <link>\n        ...\n          <collision>\n\
      \          ... \n             <surface>\n                 <friction>\n     \
      \                <ode>\n                         <mu>1.0</mu>\n            \
