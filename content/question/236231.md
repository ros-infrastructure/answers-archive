  body_markdown: "You don't tell us, but you probably have another entity in your\
    \ system publishing joint states. The `joint_state_publisher` will then set the\
    \ sliders to those values. You can try and drag them, but the next incoming message\
    \ will set them right back to where they where. \n\nIf you tell us a little more\
    \ about the configuration of your node graph, we might be able to spot what is\
    \ wrong.\n\nAlso: the `joint_state_publisher` UI is not meant for 'controlling\
    \ a robot'. The only reason that UI exists is to provide you with an easy to change\
    \ 'debug interface' to a joint states topic (ie: you use it when you have no real\
    \ hardware which publishes real joint states). In a system with real hardware,\
    \ the `joint_state_publisher` is used, but rarely with the `use_gui` parameter\
    \ set to `true`.\n"
