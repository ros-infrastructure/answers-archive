    Hi,

    as mentioned in the readme file of [swiftnav_ros repo](https://github.com/swift-nav/swiftnav_ros), you should use a different ROS driver: [ethz_piksi_ros](https://github.com/ethz-asl/ethz_piksi_ros).

    Moreover, this driver publishes a fixed (and specified by the user) covariance, based on in which mode Piksi is at the moment (SPP, RTK Float, RTK Fix). These settings can be set here: [covariance settings](https://github.com/ethz-asl/ethz_piksi_ros/blob/master/piksi_multi_rtk_ros/cfg/piksi_multi_driver_settings.yaml#L32)
