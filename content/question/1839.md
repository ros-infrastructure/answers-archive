  body_markdown: "Hi,\n\n[Here](http://gazebosim.org/wiki/Tutorials/1.3/beginner/mesh_import)\
    \ is a tutorial how to import a mesh in gazebo. You could also create an sdf model\
    \ and import it in the *.world* file. \n\n    <include>\n      <uri>model://mesh_model</uri>\n\
    \      <pose>0 0 1 0 0 0</pose>\n    </include>\n\nIn order to load it save the\
    \ *mesh_model* in *~/.gazebo/models* folder.\n\nUPDATE\n\nOne link with many mesh\
    \ collisions visuals:\n\n        <model name=\"my_mesh_one_link\">\n         \
    \ <link name=\"mesh_link\">\n\n            <visual name=\"visual1\">\n       \
    \       <geometry>\n                <mesh><uri>file://my_mesh1.dae</uri></mesh>\n\
    \              </geometry>\n            </visual>\n            <collision name=\"\
    collision1\">\n              <geometry>\n                <mesh><uri>file://my_mesh1.dae</uri></mesh>\n\
    \              </geometry>\n            </collision>\n\n            <visual name=\"\
    visual2\">\n              <geometry>\n                <mesh><uri>file://my_mesh2.dae</uri></mesh>\n\
    \              </geometry>\n            </visual>\n            <collision name=\"\
    collision2\">\n              <geometry>\n                <mesh><uri>file://my_mesh2.dae</uri></mesh>\n\
    \              </geometry>\n            </collision>\n\n          </link>\n  \
    \      </model>\n\nFor every mesh a different link:\n\n        <model name=\"\
    my_mesh_many_links\">\n\n          <link name=\"mesh_link1\">\n            <visual\
    \ name=\"visual1\">\n              <geometry>\n                <mesh><uri>file://my_mesh1.dae</uri></mesh>\n\
    \              </geometry>\n            </visual>\n            <collision name=\"\
    collision1\">\n              <geometry>\n                <mesh><uri>file://my_mesh1.dae</uri></mesh>\n\
    \              </geometry>\n            </collision>\n          </link>\n\n  \
    \        <link name=\"mesh_link2\">\n            <visual name=\"visual2\">\n \
    \             <geometry>\n                <mesh><uri>file://my_mesh2.dae</uri></mesh>\n\
    \              </geometry>\n            </visual>\n            <collision name=\"\
    collision2\">\n              <geometry>\n                <mesh><uri>file://my_mesh2.dae</uri></mesh>\n\
    \              </geometry>\n            </collision>\n          </link>\n\n  \
    \      </model>\n\nWith the later model you can add joints between the links.\
    \ If you want them to behave statically between them use only one link.\n\n\n\
    Cheers,\nAndrei"
