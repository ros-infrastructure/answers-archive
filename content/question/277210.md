  body_markdown: "Hi @ju78iklo9 ,\n\nas mentioned in the comments, this happens because\
    \ you have the `CMakeLists.txt` on the root folder of the workspace. In your case,\
    \  `/home/ju78iklo9/catkin_ws/CMakeLists.txt`\n\nThe main `CMakeLists.txt` of\
    \ the Workspace must be on the `~/catkin_ws/src/` folder, in your case, `/home/ju78iklo9/catkin_ws/src/CMakeLists.txt`\n\
    \nYou problem is probably on the creation process of the workspace.\n\nIf you\
    \ want to create a workspace from zero, you can do the following:\n\n1. Rename\
    \ the current `~/catkin_ws` to  `~/old_catkin_ws` with: \n---\n    mv ~/catkin_ws\
    \ ~/old_catkin_ws\n\n\n2. Create the new catkin_ws from zero with:\n---\n\n\n\
    \    cd\n    mkdir catkin_ws/src -p\n    cd catkin_ws/\n    catkin_make\n\n3.\
    \ The ROS Packages you create must be on `~/catkin_ws/src`, so, if you want create\
    \ a package named `example_pkg` that depends on `roscpp` package, for example,\
    \ you would do the following:\n---\n    cd ~/catkin_ws/src/\n    catkin_create_pkg\
    \ example_pkg roscpp\n\n4. To compile the `example_pkg` package, you run:\n---\n\
    \    cd ~/catkin_ws\n    catkin_make\n\nThat is it.\n\nIf you prefer to watch\
    \ a video for a better understanding, I've created [one here](https://youtu.be/U3w_ZvaIYmI).\n\
    \nRuben.\n\n"
