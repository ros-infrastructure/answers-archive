  body_markdown: "your topic names are not matching, the subscriber is listening to\
    \ \"position\", and your publisher is publishing to \"falconPos\" they need to\
    \ match. \n\n\nIf you wanna check if the publisher is working, you can do \"`rostopic\
    \ echo +<topic_name>`\" on a sourced console, it should display the data from\
    \ your publisher. \n\nas for the the subscriber, you can check who is subscribed\
    \ to the topic by \"`rostopic info +<topic_name>`\" \n\nI see that you are not\
    \ using absolute topic names. the subscriber will add the name of this node handle\
    \ to the topic when you do `node.subscribe.(<\"topic_name\">)` \ntry `node.subscribe(<\"\
    /topic_name\">)` with the \"/\" before the topic name. \n\nusing absolutes topic\
    \ names is a bad practice, but this will get you going. after you can do remaps\
    \ on the launch file and get all fancy. \n\nGood Luck!"
