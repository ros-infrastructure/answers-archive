  body_markdown: "Let me answer my question. The tag 3D position w.r.t. camera is\
    \ available in `/tag_detections` topic. Then I use `image_geometry.PinholeCameraModel`\
    \ to project 3D point into 2D pixel location as shown [here](https://xperroni.me/projecting-points-with-ros-pinhole-camera-model.html).\
    \ My python piece of code for the mentioned repository is shown below.\n\n   \
    \ from apriltag_ros.msg import AprilTagDetectionArray\n    from image_geometry\
    \ import PinholeCameraModel\n    from sensor_msgs.msg import CameraInfo\n    \n\
    \    \n    class TagPixel:\n        def __init__(self):\n            rospy.Subscriber('tag_detections',\
    \ AprilTagDetectionArray, self.TagPoseCallback)\n            rospy.Subscriber('cgo3_camera/camera_info',\
    \ CameraInfo, self.TagePixelCallback)\n            self.pos_x = 0.0\n        \
    \    self.pos_y = 0.0\n            self.pos_z = 0.0\n    \n        def TagPoseCallback(self,\
    \ msg):\n            valid = False\n            if len(msg.detections) > 0:\n\
    \                valid = True\n            if valid:\n                self.pos_x\
    \ = -msg.detections[0].pose.pose.pose.position.y\n                self.pos_y =\
    \ -msg.detections[0].pose.pose.pose.position.z\n                self.pos_z = msg.detections[0].pose.pose.pose.position.x\n\
    \    \n        def TagePixelCallback(self, msg):\n            self.pcm = PinholeCameraModel()\n\
    \            self.pcm.fromCameraInfo(msg)\n            self.p_image = self.pcm.project3dToPixel((self.pos_x,\
    \ self.pos_y, self.pos_z))\n            rospy.loginfo(\"Pixel position is u =\
    \ %s, v = %s\", self.p_image[0], self.p_image[1])"
