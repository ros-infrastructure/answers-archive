    The RTF is not provided by the server, so each client calculates its own way. The GUI and the `gz stats` tool use the same math, which is based on the last 20 samples, but the `DiagnosticsManager` just does instantaneous calculation.

    * [TimePanel::Update()](https://bitbucket.org/osrf/gazebo/src/582827025ea59c832cc50e33d64a07ae13cad76a/gazebo/gui/TimePanel.cc?at=default&fileviewer=file-view-default#TimePanel.cc-297) - this is the one you see on the GUI

    * [StatsCommand::CB](https://bitbucket.org/osrf/gazebo/src/582827025ea59c832cc50e33d64a07ae13cad76a/tools/gz.cc?at=default&fileviewer=file-view-default#gz.cc-883) - this is the one you get from the `gz stats` command line tool

    * [DiagnosticManager::Update](https://bitbucket.org/osrf/gazebo/src/582827025ea59c832cc50e33d64a07ae13cad76a/gazebo/util/Diagnostics.cc?at=default&fileviewer=file-view-default#Diagnostics.cc-115) - this is the one on the `~/diagnostics` topic
