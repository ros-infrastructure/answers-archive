upvote_count: 0

 There is a [known issue](https://github.com/ros/genmsg/issues/50) with ROS-1 that that algo to generate the md5-sums for messages does not consider array lengths. This means that message types which only differ in the length of an array member will have the same md5-sum. Does ROS-2 fix this?
