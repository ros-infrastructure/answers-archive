    Joystick_drivers has not yet been released to indigo (ticket tracking this is located at https://github.com/ros-drivers/joystick_drivers/issues/65). You should be OK building from source, and a release should happen shortly.

    As for the full Indigo release, there is not a release date yet, but issues that need to be resolved are being discussed on the [ROS-release mailing list](http://lists.ros.org/mailman/listinfo/ros-release). The biggest blocker right now is that there are currently some issues with Gazebo integration as well as some lower level libraries that become system libraries in Ubuntu Trusty that are being worked out (https://github.com/ros/rosdistro/issues/4633)
