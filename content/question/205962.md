    The problem is that LD_LIBRARY_PATH has lost link to certain paths important for ros like the one mentioned in error /opt/ros/indigo/lib due to installation of some other files and libraries. So retain it you just need to add the path back again

    export LD_LIBRARY_PATH=/opt/ros/indigo/lib

    this had solved my problem
