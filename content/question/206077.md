  body_markdown: "You're making the subscriber much more complicated than it needs\
    \ to be.\n\n * ROS will handle subscribing to a new publisher automatically -\
    \ no need to call subscribe on every iteration\n * ros::spin() doesn't return\
    \ until your program is done - probably not what you want\n\nThe pseudocode for\
    \ a watchdog should look more like:\n\n    class Watchdog {\n      private:\n\
    \        // timer or last update time member variables\n      public:\n      \
    \  void callback(your_message & msg); // update/reset timer\n        bool check();\
    \ // check timer for timeout\n    }\n\n    int main() {\n       // ros node and\
    \ nodehandle setup\n       Watchdog watchdog;\n       ros::Subscriber sub = nh.subscribe(\"\
    topic\", 10, &watchdog, &Watchdog::callback);\n       \n       ros::Rate rate(100);\n\
    \n       while(ros::ok()) {\n          if(!watchdog.check()) {\n            //\
    \ scream loudly and/or throw things\n          }\n          // check subscriber\
    \ for correct number of publishers\n          ros::spinOnce();\n       }\n\n \
    \      return 0;\n    }\n\nMost of the implementation details are left to the\
    \ reader.\n\nNote that there are two different checks being done here:\n\n * Check\
    \ that a message was received recently (the publisher is still publishing)\n *\
    \ Check that there are still publishers connected\n\nNote also that you could\
    \ move the ros::Subscriber object to be a member of the Watchdog class, and do\
    \ the subscriber setup in the Watchdog constructor."
