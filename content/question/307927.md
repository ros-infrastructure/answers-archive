## What I'm working on
I've just added my created package `timed_roslaunch` into shadow-fixed repository according to [bloom turorial](http://wiki.ros.org/bloom/Tutorials/FirstTimeRelease).

Recently merged `rosdistro/kinetic/distribution.yaml`related to `timed_roslaunch` is [here](https://github.com/ros/rosdistro/pull/19405/files).

I firstly tested `sudo apt install ros-kinetic-timed-roslaunch` after switching repository from `ros` to `ros-shadow-fixed` by referring to [ShadowRepository Wiki Page](http://wiki.ros.org/ShadowRepository) and the install command was successfully completed.

## What's wrong
However, the package files were installed into directly under `/` not `opt/ros/kinetic/`

For example, launch files in `gazebo_ros` are installed as the following directory configuration.

- /
  - opt/
     - ros/
         - kinetic/
             - share/
                 - gazebo_ros/
                      - launch/

On the other hand, in case of `timed_roslaunch`, launch files are installed as follows.

- /
  - launch/

Also, I directly download and checked deb package named `ros-kinetic-timed-roslaunch_0.1.1-3xenial-20181107-003648-0800_amd64.deb` from [ros-shadow-fixed repository](http://packages.ros.org/ros-shadow-fixed/ubuntu/pool/main/r/ros-kinetic-timed-roslaunch/) to find the launch directory is already set ot just under root `/`.

This causes any ros commands such as `roscd`, `roslaunch` and so on cannot find `timed_roslaunch` even after `source /opt/ros/kinetic/setup.bash `

I want to change the install directory from `/` to `opt/ros/kinetic/` same as `gazebo_ros`.

Do I have to change anything when I use bloom? Does anyone know how can it be fixed?
