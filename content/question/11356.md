  body_markdown: "UPDATE:\n\nThe problem is that `kill_nodes()` takes an array of\
    \ node names, not a string.\n\n----\n\nFirst, a warning: the rosnode documentation\
    \ notes \"This library is intended for internal use only.\" That means that I\
    \ am likely to tweak the internal API in non-backwards-compatible ways.   You\
    \ may wish to copy some of the easier routines into your own code to be safe.\
    \ \n\nThere shouldn't be any permissions issues; the general technique (right\
    \ now) is to make an XMLRPC call to the node to kill.  This will change in the\
    \ future, but that's how it works now.\n\nMy only guess is that your code may\
    \ be specifying node names differently -- they have to be fully resolved names."
