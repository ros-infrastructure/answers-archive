  body_markdown: "I have made the launch file running, hope this helps.\nHere I have\
    \ (camera/depth/color/points) topic and I am using Intel Real Sense D415, you\
    \ can edit this according to your topic and simply launch the file.\n\n<launch>\n\
    \n  <group ns=\"/pcl_filters\">\n    <!-- PCL Manager -->\n    <node pkg=\"nodelet\"\
    \ type=\"nodelet\" name=\"box_filter_pcl_manager\" args=\"manager\" output=\"\
    screen\"/>\n\n    <!-- Run a passthrough filter to delimit in x direction -->\n\
    \    <node pkg=\"nodelet\" type=\"nodelet\" name=\"psx\" args=\"load pcl/PassThrough\
    \ box_filter_pcl_manager\" output=\"screen\">\n      <remap from=\"~input\" to=\"\
    /camera/depth/color/points\" />\n      <rosparam>\n        filter_field_name:\
    \ x\n        filter_limit_min: -.8\n        filter_limit_max: 0.5\n      </rosparam>\n\
    \    </node>\n\n    <!-- Run a passthrough filter to delimit in y direction -->\n\
    \    <node pkg=\"nodelet\" type=\"nodelet\" name=\"psy\" args=\"load pcl/PassThrough\
    \ box_filter_pcl_manager\" output=\"screen\">\n      <remap from=\"~input\" to=\"\
    /camera/depth/color/points\" />\n      <rosparam>\n        filter_field_name:\
    \ y\n        filter_limit_min: -1.\n        filter_limit_max: .3\n      </rosparam>\n\
    \    </node>\n\n    <!-- Run a passthrough filter to delimit in z direction -->\n\
    \    <node pkg=\"nodelet\" type=\"nodelet\" name=\"psz\" args=\"load pcl/PassThrough\
    \ box_filter_pcl_manager\" output=\"screen\">\n      <remap from=\"~input\" to=\"\
    /camera/depth/color/points\" />\n      <rosparam>\n        filter_field_name:\
    \ z\n        filter_limit_min: 0.0\n        filter_limit_max: 2.0\n      </rosparam>\n\
    \    </node>\n    \n    <node pkg=\"nodelet\" type=\"nodelet\" name=\"cropbox\"\
    \ args=\"load pcl/CropBox box_filter_pcl_manager\" output=\"screen\">\n      <remap\
    \ from=\"~input\" to=\"/camera/depth/color/points\" />\n      <rosparam>\n   \
    \     min_x: -0.75\n        max_x: 0.5\n        min_y: -0.6\n        max_y: 0.1\n\
    \        min_z: $(arg 0.1)\n        max_z: 2.0\n      </rosparam>\n    </node>\n\
    \    \n  </group>\n</launch>"
