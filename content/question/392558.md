    \ for you, but I am giving an overview of how you can connect Delta PLC with ROS.\n\
    \nLet's say you are using python [pyModbusTCP](https://pypi.org/project/pyModbusTCP/)\
    \ to connect your code with your DELTA AS228P or in CPP, and you can use [libmodbus](https://github.com/stephane/libmodbus).\
    \ \n\nCode example of Python side. \n\n    from pyModbusTCP.client import ModbusClient\n\
    \    c=ModbusClient(host='localhost',port=9999,auto_ope n=True)\n    \n    regs=c.read_holding_registers(403705,1)\n\
    \    print(\"reading register values\")\n\n    if regs:\n      print(regs)\n \
    \   else:\n      print(\"error\")\n    \n    print(\"write value to register\"\
    )\n    a=int(input())\n    c.write_single_register(403705,a)\n\nLet's say your\
    \ python or CPP code is working correctly, and you can communicate to your IO\
    \ via ethernet. Now you can directly create hardware packages based on the above\
    \ code. The hardware packages with [nodes](http://wiki.ros.org/ROS/Tutorials/UnderstandingNodes),\
    \ [topics](http://wiki.ros.org/ROS/Tutorials/UnderstandingTopics), and [services](http://wiki.ros.org/ROS/Tutorials/UnderstandingServicesParams)\
    \ can be used  based on your application requirement. \n\nI hope that will help\
    \ you. Feel free to drop a comment in case of any query."
