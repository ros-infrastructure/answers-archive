  body_markdown: "The [ServerFixture](http://osrf-distributions.s3.amazonaws.com/gazebo/api/dev/classgazebo_1_1ServerFixture.html)\
    \  and [RenderFixture](http://osrf-distributions.s3.amazonaws.com/gazebo/api/dev/classgazebo_1_1RenderingFixture.html)\
    \ classes might be useful for automating simulations. I don't know of any tutorial\
    \ that covers how to use the classes, but most of the [tests](https://bitbucket.org/osrf/gazebo/src/f4e51e8f64001beda70615ab8982a7d5a4e65b18/test/integration/?at=default)\
    \ in gazebo use them. [Here](https://bitbucket.org/osrf/gazebo/src/f4e51e8f64001beda70615ab8982a7d5a4e65b18/test/integration/pr2.cc?at=default&fileviewer=file-view-default#pr2.cc-33)\
    \ is an example of a test that spawns a PR2 and saves some pictures from its camera.\
    \  \n\nIf you are manually running the simulation but want an output at the end\
    \ of the simulation, you might be able to use [world](http://gazebosim.org/tutorials?tut=plugins_world&cat=write_plugin)\
    \ or [system](http://gazebosim.org/tutorials?tut=system_plugin&cat=write_plugin)\
    \ plugins, which are more accessible and have [tutorials](http://gazebosim.org/tutorials?cat=write_plugin)."
