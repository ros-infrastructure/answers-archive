  body_markdown: "So basically the gpu laser will only detect a link's visual. One\
    \ solution to your problem would be to simply delete the\n    \n    <visual name=\"\
    visual1\">\n    ...\n    </visual>\n\nin your sdf. But you would not be able to\
    \ see the object in the simulation. Another possibility is to delete the \n\n\
    \    <collision name=\"visual\">\n    ...\n    </collision>\n\nElement in your\
    \ sdf and use the non gpu version of the sensor. This sensor will only detect\
    \ a link's collision and you will be still able to see the object in the simulation.\
    \ To do this you also need to change the sensor type:\n\n    <sensor type=\"ray\"\
    \ name=\"hokuyo\">\n\nand the plugin:\n\n    <plugin name=\"gazebo_ros_head_hokuyo_controller\"\
    \ filename=\"libgazebo_ros_laser.so\">"

In my model I tried to give different laser_retro and transparency settings. 
In Rviz I always see that the transparent wall reflects the laser scans. 
Can anybody shed some light on this ?


----------
EDIT

I use
Gazebo version 7.4
ROS Kinetic on Ubuntu 16.04


Below is the wall that is supposed not to reflect laser scans.

      <model name="glass1">
        <static>true</static>
        <pose>7 2 1 0 0 0</pose>
        <link name="link">
          <collision name="visual">
             <laser_retro>0.5</laser_retro>
             <geometry><box><size>0.1 2 2</size></box></geometry>
          </collision>
          <visual name="visual1">
             <transparency>1</transparency>
             <geometry><box><size>0.1 2 2</size></box></geometry>
                  <material>
                  <script><name>Gazebo/RedTransparent</name></script>
                 </material>
          </visual>
        </link>
      </model>

    <gazebo reference="hokuyo_link">
    <material>Gazebo/Red</material>

     <visualize>false</visualize>

      <ray>
        <scan>
          <horizontal>
