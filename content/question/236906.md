  body_markdown: "Quoting [rospy documentation](http://wiki.ros.org/rospy/Overview/Initialization%20and%20Shutdown),\n\
    \n> rospy.on_shutdown(h)\n> \n> Register handler to be called when\n> rospy process\
    \ begins shutdown. h is a\n> function that takes no arguments. You\n> can request\
    \ a callback using\n> rospy.on_shutdown() when your node is\n> about to begin\
    \ shutdown. This will be\n> invoked before actual shutdown occurs,\n> so you can\
    \ perform service and\n> parameter server calls safely.\n> Messages are not guaranteed\
    \ to be\n> published.\n\nIsn't your callback method expecting 3 arguments `(self,\
    \ position, time)`? But the method `h()` takes no arguments (argument `self` is\
    \ provided). \n\nWhen the callback is called, the TypeError is thrown because\
    \ the callback method is called is called with insufficient number of arguments.\
    \ And I'm not sure you need those two arguments because you don't use them inside\
    \ the method anyway.\n\nInside the Trajectory class, check the `stop()` definition\
    \ to this :\n\n    def stop (self):\n            self._client.cancel_goal()\n\n\
    It will solve the problem."
