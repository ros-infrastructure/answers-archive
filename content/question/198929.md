    The `spawner` should be [taking its namespace into account](https://github.com/ros-controls/ros_control/blob/indigo-devel/controller_manager/scripts/spawner#L115-L117) when looking for its associated `controller_manager`. So if the `spawner` node and the `controller_manager` are in the *same* namespace (e.g., `/` or `/my_robot`), things should work.

     If you observe a different behavior, please [open an issue](https://github.com/ros-controls/ros_control/issues), preferably accompanied with a patch.

    >\n        <param name=\"robot_description\" textfile=\"$(find baxter_hug)/gazebo_models/humanoid/humanoid.urdf\"\
    \ />\n        <node name=\"urdf_spawner_humanoid\" pkg=\"gazebo_ros\" type=\"\
    spawn_model\" respawn=\"false\" output=\"screen\" \n            args=\"-urdf -model\
    \ humanoid -param robot_description -x 1\"/>\n\n        <!-- loads the controllers\
    \ -->\n        <rosparam file=\"$(find baxter_hug)/gazebo_models/humanoid/config.yaml\"\
    \ command=\"load\" />\n        <node name=\"controller_spawner_humanoid\" pkg=\"\
    controller_manager\" type=\"spawner\"\n            respawn=\"false\" output=\"\
    screen\" \n            args=\"leftleg_joint_position_controller joint_state_controller\
    \ --shutdown-timeout 3\"/> \n    </group>\n    </launch>\n\nAnd you need to write\
    \ the robotParam in .urdf file:\n\n    <plugin name=\"gazebo_ros_control_humanoid\"\
    \ filename=\"libgazebo_ros_control.so\">\n         <robotNamespace>/humanoid</robotNamespace>\n\
    \         <robotParam>humanoid/robot_description</robotParam>\n    </plugin>\n\
    \n    <transmission name=\"leftleg_trans\">\n        <type>transmission_interface/SimpleTransmission</type>\n\
    \        <actuator name=\"motor2\">\n          <mechanicalReduction>1</mechanicalReduction>\n\
    \        </actuator>\n        <joint name=\"LeftLeg_joint\">\n          <hardwareInterface>hardware_interface/VelocityJointInterface</hardwareInterface>\n\
    \        </joint>\n    </transmission>\n\nconfig.yaml: (Note: do not add namespace\
    \ in the beginning!!!)\n\n    leftleg_joint_position_controller:\n        type:\
    \ velocity_controllers/JointPositionController\n        joint: LeftLeg_joint\n\
    \        pid: {p: 1.0, i: 0.1, d: 0.1}\n\nFor ros-indigo, gazebo-2 this solution\
    \ fails because the joint_position_controller.cpp use urdf.initParam() while ros-kinetic\
    \ use urdf.initParamWithNodeHandle(). \n\n    // Get URDF info about joint\n \

    \     {\n        ROS_ERROR(\"Failed to parse urdf file\");\n        return false;\n\
    \      }\n\nThere is no initParamWithNodeHandle() in urdf for ros-indigo. If you\
