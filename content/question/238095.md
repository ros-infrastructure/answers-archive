  body_markdown: "Have a look at the [ros_qml](https://github.com/bgromov/ros_qml)\
    \ package. Right now the installation process is not very straight forward, but\
    \ it is definitely easier to create a graphical interface in [Qt QML](http://doc.qt.io/qt-5/qmlapplications.html),\
    \ than writing a plugin for `rqt`.\n\nPublishing a message from QML is as easy\
    \ as this:\n\n    import QtQuick 2.2\n    import QtQuick.Controls 1.2\n    import\
    \ Ros 1.0\n\n    ApplicationWindow {\n    \n      Ros {\n        id: ros\n\n \
    \       Publisher {\n          id: pub1\n          topic: Topic {\n          \
    \  name: \"/my_topic\"\n            type: \"std_msgs/Header\"\n          }\n \
    \       }\n      }\n\n      Button {\n        text: \"Publish\"\n        onClicked:\
    \ {\n          var now = ros.now()\n          ros.loginfo('Sample info message\
    \ with user data: ' + JSON.stringify(now))\n\n          var msg = {\n        \
    \    seq: 0,\n            stamp: now,\n            frame_id: 'test_frame',\n \
    \         }\n\n          pub1.publish(msg)\n        }\n      }\n    }\n\nFor more\
    \ examples, please see [examples/](https://github.com/bgromov/ros_qml/tree/master/examples)\
    \ folder.\n\n---\n\n**EDIT:**\n\n`ros_qml` is an essential part for creating QML\
    \ GUI \"connected\" to ROS. It is a QML plugin (module) that exposes ROS features,\
    \ such as publishers and subscribers. So there is no choice between Qt Quick and\
    \ `ros_qml` \u2014 you need both. Also the package sets up the proper environment\
    \ for Qt Creator, such that code-completion works fine for `ros_qml`.\n\nI believe\
    \ QML is extremely good for simple GUIs and it is usually a matter of minutes\
    \ to create an interface.\n\nIf you are confident with installing dependencies\
    \ from source (as described in [ros_qml/README.md](https://github.com/bgromov/ros_qml/blob/master/README.md)),\
    \ then I would recommend to use QML. Otherwise it might be too confusing.\n\n\
    The main hitch with installation is that PyQt 5.4 (Python module used by `ros_qml`)\
    \ is precompiled only for Python 3, while `ros_qml` is written for Python 2.7.\
    \ Therefore, PyQt has to be built from sources and linked with appropriate version\
    \ of Python.\n\nP.S. There seems to be not much interest in the package so far,\
    \ so I didn't bother to simplify the installation process yet.\n\n---\n\n**EDIT:**\n\
    \nA common approach to change robot's parameters dynamically is [dynamic_reconfigure](http://wiki.ros.org/dynamic_reconfigure)\
    \ and it is usually used in combination with [rqt_reconfigure GUI](http://wiki.ros.org/rqt_reconfigure).\
    \ The interface is quite limited, it lacks push buttons etc., but can be an alternative\
    \ to full-featured GUI."
