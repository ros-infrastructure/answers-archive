    No, RGBD SLAM only provides localization and mapping.  That is, it tries to build a map and figure out where the robot is within that map.  What you're talking about is path planning.  If you look at the diagram on [this page](http://www.ros.org/wiki/navigation/Tutorials/RobotSetup), it's the move_base package that does that planning.

    I think this would be a good question to read: [http://answers.ros.org/question/9712/how-to-use-rgbd-6d-slam-for-path-planning-and-navigation-with-kinect/](http://answers.ros.org/question/9712/how-to-use-rgbd-6d-slam-for-path-planning-and-navigation-with-kinect/).
