 Are there any packages for streaming [CompressedImage](http://docs.ros.org/indigo/api/sensor_msgs/html/msg/CompressedImage.html) data as mjpeg over http?

I've found [mjpeg_server](http://wiki.ros.org/mjpeg_server) and [web_video_server](http://wiki.ros.org/web_video_server), and while these support output as mjpeg, they only accept raw uncompressed image data as input.

My project is running on a Raspberry Pi, so computing resources are limited. I'm using [raspicam](https://github.com/fpasteau/raspicam_node) to stream image data. It supports both raw and compressed output. However, the raw node consumes 180% CPU whereas the compressed node consumes...9%, so you can imagine why I'd like to use the compressed stream.
