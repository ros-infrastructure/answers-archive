  body_markdown: "Since there does not seem to be a solution within the ROS eco system,\
    \ I wrote a script that uses rosbag decompress to go though all bag-files, detects\
    \ which are broken and then reindexes them.\n\n    #!/bin/bash\n    decompressed_bags=/media/tneumann/fd783860-83b8-4729-8ea5-eee3e08bb9c5/trash/\n\
    \    reindexed_bags=/media/tneumann/fd783860-83b8-4729-8ea5-eee3e08bb9c5/reindexed/\n\
    \    broken_bags=\"\"\n    for bag in *.bag; do\n      if [[ -n $( rosbag decompress\
    \ --output-dir=$decompressed_bags $bag 2>&1 > /dev/null ) ]]; then\n        echo\
    \ $bag\n        broken_bags=\"$broken_bags $bag\"\n      fi  \n      rm ${decompressed_bags}/${bag}\n\
    \    done\n    \n    echo -e \"Broken bag files:\\n $broken_bags\\nStart reindexing\\\
    n\"\n    mkdir broken/\n    \n    for bag in $broken_bags; do\n      mv $bag broken/\n\
    \      rosbag reindex --output-dir=$reindexed_bags broken/$bag\n    done\n\nThis\
    \ is of course not my preferred solution but it works, if your bag-files are not\
    \ compress this might not work, you can try to use \"rosbag play -i\" instead,\
    \ but this just triggers an error if you also listen on the published topics.\n\
    \nregards<br>\nTobias"
