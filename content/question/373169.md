  body_markdown: "You'll need to add a second node that you attach the \"send_recieve_canopy\"\
    \ client to instead of attaching it to the \"self\" node object. The issue I think\
    \ you're running into is that the \"self\" node cannot spin until that callback\
    \ is finished. So by creating a second private node, you can independently spin\
    \ that node inside the callback of the \"self\" node.\n\nAt least that's what\
    \ I have to do in rclcpp. So it should be very similar in rclpy.\n\nLet me know\
    \ if you need a more concrete example.\n\nEdit 1:\n\nHere an example:\n\n    import\
    \ rclpy\n    from rclpy.node import Node\n    from example_interfaces.srv import\
    \ AddTwoInts\n\n\n    class ServiceNode(Node):\n        def __init__(self):\n\
    \            super().__init__('main_node')\n            self.sub_node = rclpy.create_node('sub_node')\n\
    \            self.server = self.create_service(AddTwoInts, 'example_service',\
    \ self.add_two_ints_callback)\n            self.sub_client = self.sub_node.create_client(AddTwoInts,\
    \ 'add_two_ints')\n\n        def add_two_ints_callback(self, request: AddTwoInts.Request,\
    \ response: AddTwoInts.Response):\n            self.sub_client.wait_for_service()\n\
    \            sub_request = AddTwoInts.Request()\n            sub_request.a = request.a\n\
    \            sub_request.b = request.b\n            future = self.sub_client.call_async(sub_request)\n\
    \            rclpy.spin_until_future_complete(self.sub_node, future)\n       \
    \     if future.result() is not None:\n                result: AddTwoInts.Response\
    \ = future.result()\n                self.get_logger().info('Result of add_two_ints:\
    \ {}'.format(result.sum))\n                response.sum = result.sum\n       \
    \         return response\n            else:\n                self.get_logger().error('Exception\
    \ while calling service: {}'.format(future.exception()))\n\n\n    if __name__\
    \ == '__main__':\n        rclpy.init()\n        node = ServiceNode()\n       \
    \ rclpy.spin(node)\n        rclpy.shutdown()\n\nTo show it works, first in a terminal\
    \ start \n\n    $ ros2 run demo_nodes_cpp add_two_ints_server\n\nin another terminal\
    \ run this example node.\nIn yet another terminal run\n\n    $ ros2 run demo_nodes_cpp\
    \ add_two_ints_client -s example_service\n\nHope that answers your question."
