    \ would still crash or hang. So far I've been using `real_time_update_rate = 0.0`,\
    \ which tries to optimize the simulation as much as possible. I have ran some\
    \ experiments with limiting the `real_time_factor = real_time_update_rate * time_step`,\
    \ and this seems to remove the issue. I set the `real_time_rate` to a value that\
    \ is 4 times higher than the expected `real_time_rate` of the simulation, and\
    \ it still seems to work. I will update the answer in case I encounter failures.\n\
