    Navigation_experimental is not an executable, but rather a stack (metapackage) containing several packages related to navigation.  I suggest that you study the [navigation metapackage](http://wiki.ros.org/navigation), and follow some of the tutorials on that page. The navigation_experimental metapackage has some very specific tools that you normally would not need to use when creating basic setups using ROS.
