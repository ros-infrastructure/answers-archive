    Found a solution:
    In the 'Arduino IDE Setup' tutorial were it states 'git clone https://github.com/ros-drivers/rosserial.git' add '-b groovy-devel'. So that line should read: 'git clone https://github.com/ros-drivers/rosserial -b groovy-devel'
    This will check out the code from the goovy-delep branch.
    The rest stays the same.

    Maybe, this is worthwhile adding to this tutorial for us less experienced.
