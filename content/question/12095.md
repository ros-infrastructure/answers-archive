    Implementing a ROS client library in C# is not trivial. Some information on the client protocol can be found [here](http://www.ros.org/wiki/ROS/Technical%20Overview). What you essentially need to do is:

     - Implement the [slave API](http://www.ros.org/wiki/ROS/Slave_API) which is based on XMLRPC.

     - Implement a message generator that parses [msg](http://www.ros.org/wiki/msg) files and generates C# code for serialization an deserialization

     - Implement the [TCPROS](http://www.ros.org/wiki/ROS/TCPROS) transport.

    Also have a look at [this](http://www.ros.org/wiki/Implementing%20Client%20Libraries) wiki page and [this](http://answers.ros.org/question/10399/is-ros-able-to-support-c-language) question.
