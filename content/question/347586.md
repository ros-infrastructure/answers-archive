  body_markdown: "Based on the updated description, `rmf_traffic` is failing to build\
    \ due to missing dependencies.\n\nThe reason is that the [tutorial](https://github.com/osrf/free_fleet/blob/master/README.md)\
    \ fails to mention to install the packages dependencies before building.\n\nIn\
    \ order to install the dependencies of the packages in your workspace, it is recommended\
    \ to use `rosdep`\n\n    rosdep update\n    rosdep install --from-paths src --ignore-src\
    \ -y\n\nSo in the tutorial you are using it will look like:\n\n    cd ~/client_ws\n\
    \    source /opt/ros/melodic/setup.bash\n    \n    # Tell rosdep to ignore the\
    \ ROS 2 packages as this is the ROS 1 melodic workspace\n    touch ~/client_ws/src/free_fleet/free_fleet_examples_ros2/CATKIN_IGNORE\n\
    \    touch ~/client_ws/src/free_fleet/free_fleet_server_ros2/CATKIN_IGNORE\n\n\
    \    # install dependencies\n    rosdep update\n    rosdep install --from-paths\
    \ src --ignore-src -y --rosdistro melodic\n    \n    # build cyclonedds first\
    \ with the necessary cmake flags\n    catkin build cyclonedds --cmake-args -DBUILD_IDLC=NO\n\
    \    \n    # build the rest of the packages\n    catkin build\n\nand \n\n    cd\
    \ ~/server_ws\n    source /opt/ros/eloquent/setup.bash\n    \n    # install dependencies\n\
    \    rosdep update\n    rosdep install --from-paths src --ignore-src -y --rosdistro\
    \ eloquent\n    \n    # build cyclonedds first with the necessary cmake flags\n\
    \    colcon build --packages-select cyclonedds --cmake-args -DBUILD_IDLC=NO"
