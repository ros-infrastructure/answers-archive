    \ are [0,3] transposing them has no effect because the first dimension is zero.\n\

    \ vy.T, vz.T], dtype=np.float64)\n    >>> [[1, 2, 3]\n         [4, 5, 6]\n   \
    \      [7, 8, 9]\n\nOne solution would be:\n\n    R = np.asarray(np.column_stack((vx,\
