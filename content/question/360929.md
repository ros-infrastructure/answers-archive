  body_markdown: "The publishers for sensor_msgs, such as IMU, are created with reliability=BEST_EFFORT\
    \ and durability=VOLATILE and are incompatible with the default QoS profile. You\
    \ can inspect the QoS policy for the imu topic using:\n\n    ros2 topic info -v\
    \ /imu\n    \n    Node name: my_imu_plugin\n    Node namespace: /imu\n    Topic\
    \ type: sensor_msgs/msg/Imu\n    Endpoint type: PUBLISHER\n    GID: 01.0f.7a.c1.3b.98.3e.00.01.00.00.00.00.00.39.03.00.00.00.00.00.00.00.00\n\
    \    QoS profile:\n      Reliability: RMW_QOS_POLICY_RELIABILITY_BEST_EFFORT\n\
    \      Durability: RMW_QOS_POLICY_DURABILITY_VOLATILE\n      Lifespan: 2147483651294967295\
    \ nanoseconds\n      Deadline: 2147483651294967295 nanoseconds\n      Liveliness:\
    \ RMW_QOS_POLICY_LIVELINESS_AUTOMATIC\n      Liveliness lease duration: 2147483651294967295\
    \ nanoseconds\n\n\nRead about [QoS compatibilities](https://index.ros.org//doc/ros2/Concepts/About-Quality-of-Service-Settings/#qos-compatibilities)\
    \ to see a table of what subscriber QoS settings are compatible with publishing\
    \ QoS.  Create your subscriber with the following QoS profile:\n\n       imu_qos\
    \ = QoSProfile(\n            depth=1,\n            reliability=QoSReliabilityPolicy.BEST_EFFORT,\n\
    \            durability=QoSDurabilityPolicy.VOLATILE)\n    \n      self.imu_data\
    \ = self.create_subscription(\n            Imu,\n            'imu',\n        \
    \    self.imu_callback,\n            imu_qos)\n\nor you can use the sensor-data\
    \ preset profile instead:\n\n    imu_qos = rclpy.qos.QoSPresetProfiles.get_from_short_key('sensor_data')\n\
    \nimport these types:\n\n    from rclpy.qos import QoSDurabilityPolicy\n    from\
    \ rclpy.qos import QoSReliabilityPolicy\n    from rclpy.qos import QoSProfile"

    class IMUSubscriber(Node):

            super().__init__('imuSubscriber')
            self.subscription = self.create_subscription(
                Imu,
                'imu',
                self.listener_callback,
                10)
            self.subscription  # prevent unused variable warning
    
        def listener_callback(self, msg):
            self.get_logger().info('nanosec: %d' %(msg.header.stamp.nanosec))
    
    
    def main(args=None):
        rclpy.init(args=args)
    
        imuSubscriber = IMUSubscriber()
    
        rclpy.spin(imuSubscriber)
    
        # Destroy the node explicitly
        # (optional - otherwise it will be done automatically
        # when the garbage collector destroys the node object)
        imuSubscriber.destroy_node()
        rclpy.shutdown()
    
    
    if __name__ == '__main__':
        main()
