  body_markdown: "In order to include a python launch file, you need to use the following\
    \ `import` statement:\n\n    from launch.launch_description_sources import PythonLaunchDescriptionSource\n\
    \nSimilarly, in order to include an XML launch file, you should `import` the following\
    \ statement:\n\n    from launch_xml.launch_description_sources import XMLLaunchDescriptionSource\n\
    \nPlease see a working example below:\n\n    $ cat xml_from_py.launch.py \n  \
    \  \"\"\"Invoke XML launch file from Python Launch file.\"\"\"\n    \n    import\
    \ os\n    \n    from ament_index_python import get_package_share_directory\n \
    \   \n    from launch import LaunchDescription\n    from launch.actions import\
    \ IncludeLaunchDescription\n    from launch_xml.launch_description_sources import\
    \ XMLLaunchDescriptionSource\n    \n    \n    def generate_launch_description():\n\
    \        # include xml launch file\n        launch_include = IncludeLaunchDescription(\n\
    \            XMLLaunchDescriptionSource(\n                os.path.join(\n    \
    \                get_package_share_directory(\"demo_nodes_cpp\"),\n          \
    \          \"launch/topics/talker_listener.launch.xml\",\n                )\n\
    \            )\n        )\n    \n        return LaunchDescription([launch_include])\n\
    \nYou can `launch` it simply by the following command:\n\n    $ ros2 launch demo_nodes_cpp\
