  body_markdown: |-
    To setup transform between frames you have to **broadcast** (publish) transform instead of listening to it.

    There are two ways to do that:

      1. Use [static_transform_publisher](http://www.ros.org/wiki/tf#static_transform_publisher) -- this one is a ready to use node, that you can run from command line.
      2. Use [tf::TransformBroadcaster](http://www.ros.org/wiki/tf/Tutorials/Writing%20a%20tf%20broadcaster%20%28C%2B%2B%29) -- to create transforms in a code.

    **EDIT**: If the transform is already exist you can simply listen to it once outside of publishing cycle.
