  body_markdown: "I have not found a package that can do this already, but here is\
    \ some code to start off of if you are interested in rolling your own. Note that\
    \ it was made for a `GPSFix` message instead of a `NavSatFix`, but the fields\
    \ should be similar. Note some of the `GPGGA` fields are hard coded (such as altitude)\
    \ so it may require some modification. If you want other messages than `GPGGA`\
    \ then you would need to parse and populate those as well (see a [NMEA reference](https://gpsd.gitlab.io/gpsd/NMEA.html#_gga_global_positioning_system_fix_data)\
    \ for message structure).\n\nHope this helps.\n\n\tvoid GPSRx(const gps_common::GPSFix::ConstPtr\
    \ &msg)\n\t{\n\t  char buf[255]; // Buffer for GPGGA sentence\n\t  \n\t  // Time\
    \ conversion\n\t  uint32_t hours = msg->time / 3600;\n\t  uint32_t minutes = (msg->time\
    \ - (3600 * hours)) / 60;\n\t  float seconds = msg->time - (float)(3600 * hours)\
    \ - (float)(60 * minutes);\n\n\t  // Latitude conversion\n\t  char lat_dir;\n\t\
    \  int8_t lat_degs = msg->latitude;\n\t  float lat_mins = (msg->latitude - (float)lat_degs)\
    \ * 60.0;\n\n\t  if(lat_degs < 0 )\n\t  {\n\t\tlat_degs *= -1;\n\t\tlat_mins *=\
    \ -1;\n\t\tlat_dir = 'S';\n\t  }\n\t  else\n\t  {\n\t\tlat_dir = 'N';\n\t  }\n\
    \n\t  // Longitude conversion\n\t  char lon_dir;\n\t  int8_t lon_degs = msg->longitude;\n\
    \t  float lon_mins = (msg->longitude - (float)lon_degs) * 60.0;\n\n\t  if(lon_degs\
    \ < 0 )\n\t  {\n\t\tlon_degs *= -1;\n\t\tlon_mins *= -1;\n\t\tlon_dir = 'W';\n\
    \t  }\n\t  else\n\t  {\n\t\tlon_dir = 'E';\n\t  }\n\n\t  // Populate a GPGGA sentence\n\
    \t  uint8_t len = sprintf(buf, \"$GPGGA,%02d%02d%04.1f,%02d%018.15f,%c,%02d%018.15f,%c,1,%d,0.9,50.4,M,46.9,M,,\"\
    ,\n\t\t\t\t\t\t\thours,\n\t\t\t\t\t\t\tminutes,\n\t\t\t\t\t\t\tseconds,\n\t\t\t\
    \t\t\t\tlat_degs,\n\t\t\t\t\t\t\tlat_mins,\n\t\t\t\t\t\t\tlat_dir,\n\t\t\t\t\t\
    \t\tlon_degs,\n\t\t\t\t\t\t\tlon_mins,\n\t\t\t\t\t\t\tlon_dir,\n\t\t\t\t\t\t\t\
    msg->status.satellites_visible);\n\n\t  // Calculate checksum of sentence and\
    \ add it to the end of the sentence\n\t  uint8_t checksum = 0;\n\t  for(int i\
    \ = 1; i < len; i++)\n\t  {\n\t\tchecksum ^= buf[i];\n\t  }\n\t  sprintf(&buf[len],\
    \ \"*%02X\",checksum);\n\n\t  // Put the sentence in a ros nmea_msgs/Sentence\
    \ message and publish\n\t  nmea_msgs::Sentence nmea;\n\t  nmea.sentence = buf;\n\
    \t  nmea_pub_.publish(nmea);\n\t}\n"
