  body_markdown: "The ROS image message isn't a jpeg as a byte array; it's just values\
    \ as a byte array. There's no compression done automatically (and therefore ROSJava\
    \ will see just plain data, not compressed data). \n\nWhy are you using ROSJava\
    \ to save the image? If all you want to do is turn Image messages into files,\
    \ you can do that easily with cv_bridge in python or c++.\n\nThis sounds like\
    \ an [XY Problem](http://www.perlmonks.org/?node_id=542341). What's X?\n"
