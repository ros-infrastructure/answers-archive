  body_markdown: "According to [Patrick's comment](http://answers.ros.org/question/226/how-to-synchronize-tfmessage-and-image-messages?comment=1455#comment-1455)\
    \ we can use **image_transport::SubscriberFilter** (see the Code API). Indeed,\
    \ it's encourage over **message_transport::Subscriber< sensor_msgs::Image >**.\
    \ Thanks [Raphael](http://answers.ros.org/users/139/raphael-favier/), for your\
    \ help.\n\nIn the next code snippet we have a possible implementation. The macro\
    \ **USE_IMAGE_TRANSPORT_SUBSCRIBER_FILTER** allows to switch between both approaches.\n\
    <pre>\n<code>\n#include &lt;ros/ros.h>\n#include &lt;image_transport/image_transport.h>\n\
    #include &lt;message_filters/synchronizer.h>\n#include &lt;message_filters/sync_policies/approximate_time.h>\n\
    \n#define USE_IMAGE_TRANSPORT_SUBSCRIBER_FILTER 1\n\n#if USE_IMAGE_TRANSPORT_SUBSCRIBER_FILTER\n\
    #  include &lt;image_transport/subscriber_filter.h>\n#else\n#  include &lt;sensor_msgs/Image.h>\n\
    #  include &lt;message_filters/subscriber.h>\n#endif\n\nclass MyClass {\npublic:\n\
    \  MyClass() :\n    it_(nh_),\n#if USE_IMAGE_TRANSPORT_SUBSCRIBER_FILTER\n   \
    \ orig_image_sub_( it_, \"image/orig\", 1 ),\n    warp_image_sub_( it_, \"image/warp\"\
    , 1 ),\n#else\n    orig_image_sub_( nh_, \"image/orig\", 1 ),\n    warp_image_sub_(\
    \ nh_, \"image/warp\", 1 ),\n#endif\n    sync( MySyncPolicy( 10 ), orig_image_sub_,\
    \ warp_image_sub_ )\n  {\n    sync.registerCallback( boost::bind( &MyClass::callback,\
    \ this, _1, _2 ) );\n  }\n\n  void callback(\n    const sensor_msgs::ImageConstPtr&\
    \ orig_msg,\n    const sensor_msgs::ImageConstPtr& warp_msg\n  ){\n    // your\
    \ code here\n  }\n\nprivate:\n  ros::NodeHandle nh_;\n  image_transport::ImageTransport\
    \ it_;\n\n#if USE_IMAGE_TRANSPORT_SUBSCRIBER_FILTER\n  typedef image_transport::SubscriberFilter\
    \ ImageSubscriber;\n#else\n  typedef message_filters::Subscriber< sensor_msgs::Image\
    \ > ImageSubscriber;\n#endif\n\n  ImageSubscriber orig_image_sub_;\n  ImageSubscriber\
    \ warp_image_sub_;\n\n  typedef message_filters::sync_policies::ApproximateTime<\n\
    \    sensor_msgs::Image, sensor_msgs::Image\n  > MySyncPolicy;\n\n  message_filters::Synchronizer<\
    \ MySyncPolicy > sync;\n};\n\nint main(int argc, char** argv) {\n  ros::init(\
    \ argc, argv, \"my_node\" );\n  MyClass mc;\n  \n  while( ros::ok() ){\n    ros::spin();\n\
    \  }\n\n  return EXIT_SUCCESS;\n}\n</code>\n</pre>\n\nNote that you can syncrhonize\
    \ more messages (even of other type) by extending the **message_filters::sync_policies::ApproximateTime<\
    \ ... >** template class."
