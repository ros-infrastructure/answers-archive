    `sensor_msgs/LaserScan` should probably be `sensor_msgs.msg.LaserScan` (although you've already `import`ed it earlier, so the module name should not be needed).

    And creating `Subsciber` instances in service callbacks is not going to work most likely, and if it does, it won't work as you expect it to. You should really not do that.
