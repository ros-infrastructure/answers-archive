  body_markdown: "What you need to do for this particular service is to first load\
    \ the service:\n\n    // In your TaskContext subclass:\n    PluginLoader::Instance()->loadService(\"\
    rosparam\", this);\n\nAnd then you could dynamic_cast the service pointer:\n\n\
    \    boost::shared_ptr<RosParam> rp = boost::dynamic_pointer_cast<RosParam>( this->provides(\"\
    rosparam\") );\n    \n    rp->storeProperties(); // etc.\n\nUNFORTUNATELY, this\
    \ service was implemented fully in the .cpp file, so no header is available. What\
    \ you can do, if you don't want to submit a patch which creates a nice hpp/cpp\
    \ file and installs the hpp, you can write this as a workaround:\n\n    OperationCaller<bool(void)>\
    \ storeProperties = this->provides(\"rosparam\")->getOperation(\"storeProperties\"\
    );\n    \n    storeProperties(); // calls the Service's Operation.\n\nPeter\n"

    In my case, I used a simpler method to require the service.
    <pre>
    <code>
    // Within TaskContext class
    if (this->loadService("rosparam"))
    {
    OperationCaller<bool(void)> storeProperties = this->provides("rosparam")->getOperation("storeProperties");
    }
    </code>
    </pre>
    The benefit is that my code can try to load the service more than one time if it fails at the beginning.
