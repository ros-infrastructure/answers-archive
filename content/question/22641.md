  body_markdown: "You could use a heightmap. \n\n1. Create an PNG image where lightness\
    \ of a pixel represents its height.\n\n   ![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/15591449794007241.png)\n\
    \n2. Make a model out of your picture\n\n\n        \u2514\u2500\u2500 <your_models_folder>\n\
    \             \u251C\u2500\u2500 ...\n             \u2514\u2500\u2500 heightmap\n\
    \                  \u251C\u2500\u2500 model.config\n                  \u251C\u2500\
    \u2500 model.sdf\n                  \u2514\u2500\u2500 materials\n           \
    \           \u2514\u2500\u2500 textures\n                          \u2514\u2500\
    \u2500 heightmap.png\n\n   you can name the folder containing the model to your\
    \ liking. I use `heightmap` in this example for easier explanation.\n\n\n model.config\n\
    \n        <?xml version=\"1.0\"?>\n    \n        <model>\n           <name>Heightmap</name>\n\
    \           <version>1.0</version>\n           <sdf version=\"1.5\">model.sdf</sdf>\n\
    \    \n           <author>\n             <name>TODO</name>\n             <email>email@address.org</email>\n\
    \           </author>\n    \n           <description>\n             A hightmap\
    \ plane.\n           </description>\n         </model>\n\n\n model.sdf\n\n   \
    \     <?xml version=\"1.0\" ?>\n        <sdf version=\"1.5\">\n            <model\
    \ name=\"heightmap\">\n              <static>true</static>\n              <link\
    \ name=\"link\">\n    \n                 <collision name=\"collision\">\n    \
    \              <geometry>\n                    <heightmap>\n                 \
    \     <uri>model://heightmap/materials/textures/heightmap.png</uri>\n        \
    \              <size>32 32 .8</size>\n                      <pos>0 0 0</pos>\n\
    \                    </heightmap>\n                  </geometry>\n           \
    \     </collision>\n    \n                <visual name=\"visual\">\n         \
    \         <geometry>\n                    <heightmap>\n                      <use_terrain_paging>false</use_terrain_paging>\n\
    \    \n                      <uri>model://heightmap/materials/textures/heightmap.png</uri>\n\
    \                      <size>32 32 .8</size>\n                      <pos>0 0 0</pos>\n\
    \                                 \n                    </heightmap>\n       \
    \           </geometry>\n                </visual>\n    \n              </link>\n\
    \            </model>\n        </sdf>\n\n Where the `<size>` tags define the width,\
    \ length and height of the model. This means that my heightmap will result in\
    \ terrain 32x32 m large and 80 cm height. The highest point of the terrain will\
    \ be exactly 80 cm above the lowest. This way you can scale your model. (note\
    \ that there is `size` tag for both collisions and visuals. You need to keep them\
    \ the same.)\n\n3. include the heightmap in your WORLD file\n\n        <include>\n\
    \             <uri>model://heightmap</uri>\n        </include>\n\n4. launch the\
    \ world as you normally do.\n\nYou can then work on textures for your ramp. This\
    \ will result in black-and-yellow stripe texture, but the geometry will be there.\n\
    \n\nYou might want to use a picture like the one below for your heightmap.\n\n\
    ![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/15591473236172172.png)"
