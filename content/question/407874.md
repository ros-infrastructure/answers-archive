    Please do not copy and paste the complete documentation. It unnecessarily takes our time. Anyway, I have edited the question to make it short and straightforward. Now, back to the question, before executing the `source devel/setup.bash` command, you must run the following commands:

     1. `source /opt/ros/noetic/setup.bash`
     2. `cd ~/catkin_ws/`
     3. `catkin_make`

    All of these commands are mentioned in the [documentation](http://wiki.ros.org/ROS/Tutorials/InstallingandConfiguringROSEnvironment). Furthermore, because you are using ROS Noetic, you must replace the text `kinetic` with `noetic` throughout the documentation. In short `<distro>` is `noetic`.
