  body_markdown: "I suppose your ROS_PACKAGE_PATH is not set accordingly. \n\n1) Close\
    \ your terminal and open again which will reload your ~/.ros to default one. \n\
    2) Run the following again\n$ cd ~/\n$ mkdir ros_tutorials\n$ export ROS_PACKAGE_PATH=~/ros_tutorials:$ROS_PACKAGE_PATH\n\
    \n3) To verify whether your PATH set correctly, try 'roscd roscpp'. If it changes\
    \ to the roscpp folder then path file is set correctly.\n\n4) Now try creating\
    \ package with dependencies you wish.\n\nHope this would help you.\nNote: I am\
