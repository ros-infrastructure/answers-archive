  body_markdown: "The \"package index\" is part of the ament resource index. It's\
    \ how ROS 2 tools figure out what packages are installed. [Read about the design\
    \ of it is here](https://github.com/ament/ament_cmake/blob/2c69087f74b20a797cd1e502f3f2f3f7c407be22/ament_cmake_core/doc/resource_index.md#file-system-index-layout).\n\
    \nColcon currently creates this file automatically for `ament_python` packages,\
    \ but it won't in the future. Packages will need to install a marker file themselves.\
    \ This is just a blank file in `share/ament_index/resource_index/packages/foobar`\
    \ where `foobar` is the name of your package.\n\nThe usual way to install this\
    \ is to copy an empty file using the `data_files` argument. ([actual example in\
    \ ros2topic](https://github.com/ros2/ros2cli/blob/f6c4a5b05d172f8156645b8fcf8bd2dfa23e7bb2/ros2topic/setup.py#L12-L13)).\n\
    \nYour package layout might look like:\n\n    mypythonpkg/\n    \u251C\u2500\u2500\
    \ mypythonpkg\n    \u2502\_\_ \u2514\u2500\u2500 __init__.py\n    \u251C\u2500\
    \u2500 package.xml\n    \u251C\u2500\u2500 resource\n    \u2502\_\_ \u2514\u2500\
    \u2500 mypythonpkg\n    \u2514\u2500\u2500 setup.py\n\nAnd your `setup.py` might\
    \ have\n\n    package_name = 'mypythonpkg'\n\n    setup(\n        # ...\n    \
    \    data_files=[\n            ('share/' + package_name, ['package.xml']),\n \
    \           ('share/ament_index/resource_index/packages',\n                ['resource/'\
    \ + package_name]),\n        ],\n        # ...\n    )\n\n\nIf you're interested\
    \ in why Colcon's behavior is changing, there's more info here:\n\n* https://github.com/ament/ament_index/issues/33\n\
    * https://github.com/colcon/colcon-ros/pull/74\n* https://github.com/colcon/colcon-ros/pull/79\n\
    * https://github.com/colcon/colcon-ros/pull/82\n"
