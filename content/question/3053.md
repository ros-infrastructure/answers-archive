    Hi,

    you have to convert the sdf file to version 1.3, the command is similar to how you tried to run it, you only need to add the 'convert' parameter:

        gzsdf convert ~/<path>/empty.world

    cheers

    EDIT!

    Try using [this](https://bitbucket.org/osrf/gazebo/src/e13cd41014071569f5d2d46284083365d6878ae5/sdf/worlds/empty.world?at=default) world file, and change the sdf version to 1.3 manually. I don't know why your converter gives you this error. Also run gazebo with the path to the world file as argument:

        gazebo ~/<path>/empty.world

    <br> You should also try installing the latest version of Gazebo, which uses sdf version 1.4.
