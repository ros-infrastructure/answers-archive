  body_markdown: "Check out the [rosbag Code APIs](http://wiki.ros.org/rosbag/Code%20API).\
    \ This will allow you to isolate messages from specific topics from the rosbag.\
    \ \n\nYou can use either C++ or Python to process your rosbags and point clouds.\
    \ I'm not familiar with getting velocity or intensity data from PointCloud2 messages\
    \ but in general I find that if you want more than x,y,z data from the point clouds\
    \ then it's better to use C++. The Python API for accessing point clouds data\
    \ is more limited. Check out the [Point Cloud Library (PCL)](http://wiki.ros.org/pcl/Overview)\
    \ for processing point clouds.  "
