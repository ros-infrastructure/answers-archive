I have a problem with a ros2 node. I am using ros2-galactic.
I tried to implement a simple ros2 node publisher in python that publishes an incremented number to a topic of type geometry_msg/Pose2D. And, I tried to plot the output using rqt_graph, and everything was working fine.
So, I killed the node by just pressing CTRL+C in the terminal and killed the rqt_plot node which was open in another terminal by doing the same thing.
I then decided to create a launch file for both nodes to automatically launch them instead of running them from the terminal. However, after doing that, the rqt_graph started plotting weird results that are not the same as the ones I was getting when I manually ran each node in the terminal. 

To find out what the problem was, I checked the nodes that were running by using `ros2 node list`. It turned out that the ros2 node that was publishing the incremented number is duplicated. So, there are now 2 nodes **with the same name** that are publishing to the same topic.

But, I did not understand why this happened since I killed the node previously with CTRL+C in the terminal. 
Did I do something wrong? And, is there a way to prevent this from happening?
