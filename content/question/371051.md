I did some beginners guides and actually was able to make a Publisher/Subscriber service with a simple package.xml and a CMakeLists.txt using std_msgs. The rather easy file structure looked like this: 

    ROS/
        CMakeLists.txt
        package.xml
        setup_ros_environment.sh
        Publisher.cpp
        Subscriber.cpp
        msg/
            TestMessage.msg
        build/
