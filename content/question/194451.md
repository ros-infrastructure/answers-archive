  body_markdown: "6D RGB-D SLAM is a bit more computationally expensive. \nccny_rgbd\
    \ is comparatively very fast. \n\nBoth of these can help in localizing with respect\
    \ to your initial position or with respect to the reference frame at your starting\
    \ point.\n\nThey can help you in building a 3D map but they are not meant for\
    \ navigation.\n\nFor navigation, you can try using ROS NAVIGATION STACK \nYou\
    \ can try to create a 2D map from 3D map (created using previously mentioned methods)\
    \ and use it with ROS NAVIGATION stack for navigation \n\n\nUsing ccny_rgbd or\
    \ RGB-D SLAM with a structure sensor may not be a straightforward task.\n\nFirstly,\
    \ the depth data from the structure sensor should be registered to another external\
    \ RGB camera, if your structure camera does not provide RGB information.\n\nI\
    \ would suggest you to use Asus Xtion pro live as it works out of the box with\
    \ RGB-D SLAM or ccny_rgbd or many other algorithms are out there for RGB-D sensors.\
    \ Most of these methods need both RGB and depth information for them to work.\n\
