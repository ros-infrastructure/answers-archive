[SOLVED]EDIT2
------------

**It turns out that the error in EDIT1 had nothing to do with my original problem, which was remedied by @ahendrix. But two things now arose once the original build error was fixed, both of which were not relevant to the original error. For sake of completeness I will address them here.**

1. Don't forget to add message_filters to your project config files as shown [here](http://answers.ros.org/question/107531/linking-errors-with-message_filters-in-hydro/).
2. All references to geometry_msgs/Twist need to be updated to reflect the new type geometry_msgs/TwistStamped. For example, I had to go in and change `vel_.angular.z` to `vel_.twist.angular.z` to match the new message definition.
