    Theoretically those:
    <pre>
    ~xmin (float, default: -100.0)
    Initial map size
    ~ymin (float, default: -100.0)
    Initial map size
    ~xmax (float, default: 100.0)
    Initial map size
    ~ymax (float, default: 100.0)
    Initial map size
    ~delta (float, default: 0.05)
    Processing parameters (resolution of the map)
    </pre>
