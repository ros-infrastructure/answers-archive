    A [previous version of the hokuyo_node wiki page](http://wiki.ros.org/action/recall/hokuyo_node?action=recall&rev=102) documented the available ROS parameters; among them is one for setting the published frame id: `frame_id`.

    You can supply this parameter when you run the node with rosrun like this;

        rosrun hokuyo_node hokuyo_node scan:=/front/scan _frame_id:=/front_laser
