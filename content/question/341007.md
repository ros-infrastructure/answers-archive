  body_markdown: "There are many methods to improve odom. \n\n1 - Tune your odom -\
    \ make direct measurements of encoder counts vs movement and rotation and use\
    \ that data to improve the accuracy\n\n2 - Optimize wheels for the environment\
    \ - reduce slippage and error by using wheels appropriate for the environment\
    \ - use narrow hard wheel on a flat smooth surface etc\n\n3 - Optimize weight\
    \ distribution - place the CM in a location that makes any slip when turning low\
    \ and repeatable - the shape of your robot, wheels, rolling surface will determine\
    \ that.\n\n4 - someone else can list 3 more way to improve odom\n\n\nWith odom\
    \ optimized, there will still be drift. You will not get away from it.  Then other\
    \ methods to mitigate the error are used usually referencing fixed environment\
    \ like\n\n1 - AMCL\n\n2 - GPS\n\n3 - land marks, etc."
