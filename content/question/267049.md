  body_markdown: "Hi, I encountered the same problem.\nI finally solved it by referring\
    \ to https://qiita.com/furushchev/items/bc0d2b9d6c84741645f0\n\nThis problem is\
    \ caused by the wrong reference to System standard Python in `roslz4`.\n\n   \
    \ $ otool -L $CATKIN_WS/install_isolated/lib/python2.7/site-packages/roslz4/_roslz4.so\n\
    \nYou can find:\n\n    _roslz4.so:\n    \t_roslz4.so (compatibility version 0.0.0,\
    \ current version 0.0.0)\n    \tlibroslz4.dylib (compatibility version 0.0.0,\
    \ current version 0.0.0)\n    \t/System/Library/Frameworks/Python.framework/Versions/2.7/Python\
    \ (compatibility version 2.7.0, current version 2.7.10)\n    \t/usr/local/opt/lz4/lib/liblz4.1.dylib\
    \ (compatibility version 1.0.0, current version 1.8.1)\n    \t/usr/lib/libSystem.B.dylib\
    \ (compatibility version 1.0.0, current version 1238.0.0)\n\nso, we should change\
    \ it to the Python we currently use:\n\n    $ install_name_tool -change /System/Library/Frameworks/Python.framework/Versions/2.7/Python\
    \ /usr/local/bin/python _roslz4.so\n\nthen `rostopic` turns out to be OK for me.\n\
    \nHope I could help."
