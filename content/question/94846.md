  body_markdown: "Hi,\n\nI know it is been a long time, but if anyone is still looking,\
    \ please find the answer for changing turtlesimVelocity.h to geometry_msgs/Twist.h\
    \ below:\n\nI am using Ubuntu 16.04, ROS kinetic. Even though the answer below\
    \ is specific for those trying the tutorial to write a tf listener in C++ and\
    \ catkin_make (http://wiki.ros.org/tf/Tutorials/Writing%20a%20tf%20listener%20(C++)),\
    \ but it can be extended as well.\n\nYou need to make changes in the following\
    \ four places: (please note that the lines below \"old\" has to be replaced with\
    \ lines below \"new\")\n\n//1) old\n\n    #include <turtlesim/Velocity.h>\n//1)\
    \ new\n\n    #include <geometry_msgs/Twist.h>\n\n\n //2) old\n\n      ros::Publisher\
    \ turtle_vel = node.advertise<geometry_msgs::Twist>(\"turtle2/cmd_vel\", 10);\n\
    \  \n  //2) new\n\n      ros::Publisher turtle_vel = node.advertise<geometry_msgs::Twist>(\"\
    turtle2/cmd_vel\", 10);\n\n\n//3) old\n\n    try{\n      listener.lookupTransform(\"\
    /turtle2\", \"/turtle1\",  \n                               ros::Time(0), transform);\n\
    \    }\n    catch (tf::TransformException ex){\n      ROS_ERROR(\"tf listener:\
    \ %s\",ex.what());\n      ros::Duration(1.0).sleep();\n    }\n\n//3) new\n\n\t\
    try {\n\t\tlistener.waitForTransform(\"/turtle2\", \"/turtle1\", ros::Time(0),\
    \ ros::Duration(10.0) );\n\t\tlistener.lookupTransform(\"/turtle2\", \"/turtle1\"\
    , ros::Time(0), transform);\n\t} catch (tf::TransformException ex) {\n\t\tROS_ERROR(\"\
    %s\",ex.what());\n\t}\n\n\n//4) old\n\n\tturtlesim::Velocity vel_msg;\n\tvel_msg.angular\
    \ = 4.0 * atan2(transform.getOrigin().y(),\n                                transform.getOrigin().x());\n\
    \    vel_msg.linear = 0.5 * sqrt(pow(transform.getOrigin().x(), 2) +\n       \
    \                         pow(transform.getOrigin().y(), 2));\n\t\n//4) new\n\n\
    \    geometry_msgs::Twist vel_msg;\n    vel_msg.angular.z = 4.0 * atan2(transform.getOrigin().y(),\n\
    \                                transform.getOrigin().x());\n    vel_msg.linear.x\
    \ = 0.5 * sqrt(pow(transform.getOrigin().x(), 2) +\n                         \
    \       pow(transform.getOrigin().y(), 2));\n\n"
