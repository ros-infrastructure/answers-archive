  body_markdown: "Hi there,\n\nThe tutorial is kind of outdated. It crashes because\
    \ the following code is ran before the rendering engine is initialized\n\n   \
    \  this->userCam = gui::get_active_camera();\n\nTo make sure you initialize the\
    \ user camera after the engine has been initialized you should listen to the rendering\
    \ events, and bind a callback function to it, for example:\n\n    //////////////////////////////////////////////////\n\
    \    void  MyPlugin::Init()\n    {\n    \t// Initialize rendering related variables\
    \ only when the rendering started\n    \tthis->updateConnection = event::Events::ConnectPreRender(\n\
    \    \t\t\tboost::bind(&MyPlugin::InitAtRenderEvent, this));\n    \n    }\n\n\
    this calls the following method, which initializes the user camera, at the first\
    \ rendering event:\n\n    //////////////////////////////////////////////////\n\
    \    void MyPlugin::InitAtRenderEvent()\n    {\n    \n        // Set camera, can\
    \ be set only after the rendering started\n         this->userCam = gui::get_active_camera();\n\
    \    \n    \t// Listen to the update event.\n    \t// This event is broadcast\
    \ every simulation iteration.\n    \tthis->updateConnection = event::Events::ConnectRender(\n\
    \    \t\t\tboost::bind(&MyPlugin::OnUpdate, this));\n    }\n\nthen the `updateConnection`\
    \ is switched to call the `OnUpdate` method for every rendering event:\n\n   \
    \ //////////////////////////////////////////////////\n    void MyPlugin::OnUpdate()\n\
    \    {\n          //your code here\n          std::cout << \"Update\" << std::endl;\n\
    \    }\n\nCheers,\nAndrei"
