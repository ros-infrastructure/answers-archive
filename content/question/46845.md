  body_markdown: "I don't think that message is your fault--it's because the contact\
    \ sensor implementation is broken in the version of Gazebo that comes with Fuerte.\
    \ At least one of the bugs causing the problem is now fixed, but the fix hasn't\
    \ made it to the released version yet. It also sounds like that there might be\
    \ bugs in the bumper implementation itself (based on [this](https://bitbucket.org/osrf/gazebo/issue/141)\
    \ and [this](https://bitbucket.org/osrf/gazebo/issue/244)).\n\nEDIT: [Thomas Koletschka's\
    \ comment](https://bitbucket.org/osrf/gazebo/issue/13/contactsensor-in-gazebo-fuerte#comment-2475242)\
    \ has information about how to get a working version of Gazebo, which I've included\
    \ and expanded below.\n\n<h3>Installing a new version of Gazebo</h3>\n\n - Choose\
    \ somewhere to put your new version of Gazebo. I put mine in `~/ros/simulator_gazebo`,\
    \ and I'll assume that's the location for the rest of the instructions.\n - `$\
    \ mkdir ~/ros`\n - `$ svn co https://code.ros.org/svn/ros-pkg/stacks/simulator_gazebo/tags/simulator_gazebo-1.7.11/\
    \ ~/ros/simulator_gazebo` \n - In your ~/.bashrc (or wherever it is that you set\
    \ your ROS_PACKAGE_PATH), add ~/ros/simulator_gazebo to ROS_PACKAGE_PATH **before**\
    \ the original value.\nFor example: <br/>`export ROS_PACKAGE_PATH=~/ros/simulator_gazebo:$ROS_PACKAGE_PATH`\n\
    \ - `$ source ~/.bashrc`\n - `$ rosmake -i simulator_gazebo` (-i means put a ROS_NOBUILD\
    \ in the directories)<br/>This took about **30 minutes** to run successfully.\
    \ The first time I tried running it, I got this:<br/>\n  `-- BUILD ERRORS: These\
    \ must be resolved before compiling.`<br/>\n  `-- \tMissing: Google Protobuf Compiler\
    \ Library (libprotoc-dev)`<br/>\n  `-- \tMissing: libtar`<br/>\nso I did:<br/>\n\
    `$ sudo apt-get install libprotoc-dev libtar-dev`<br/>\nand tried again, and it\
    \ worked.\n\nWhen you launch Gazebo as usual, you'll get the new version you just\
    \ compiled, and it should have semi-working contact sensors (with the caveats\
    \ mentioned above). Be aware though that it's possible existing models you want\
    \ to use might be incompatible with this new version.\n\nEDIT 4/9/2013: The issue\
    \ seems to have been resolved as of Gazebo 1.3, which is included in the simulator-gazebo-1.7.11\
    \ tag."
