    What's happening is that you're creating a static model (`<static>true</static>`), which means the model's inertia will be ignored and it won't be affected by physics.

    But I can see how displaying the default values can be confusing. I opened an [issue](https://bitbucket.org/osrf/gazebo/issues/2286/inertial-properties-for-static-models) about this.
