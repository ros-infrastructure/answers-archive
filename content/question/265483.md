    \ [3D Perception/Configuration](http://docs.ros.org/kinetic/api/moveit_tutorials/html/doc/pr2_tutorials/planning/src/doc/perception_configuration.html)?\
    \  In particular, you need to configure a few additional launch file settings\
    \ in your MoveIt package to properly integrate the point clouds with MoveIt:\n\
    \n1) Create a `<moveit_package>/config/sensors.yaml` file:<BR>\n\n    sensors:\
    \ \n     - sensor_plugin: occupancy_map_monitor/PointCloudOctomapUpdater\n   \
    \    point_cloud_topic: /kinect/depth_registered/points\n       max_range: 5.0\n\
    \       point_subsample: 1\n       padding_offset: 0.1\n       padding_scale:\
    \ 1.0\n\n2) Edit the existing `<moveit_package>/launch/<myrobot>_moveit_sensor_manager.launch.xml`\
    \ file:\n\n\t<rosparam command=\"load\" file=\"$(find <myrobot>_moveit_config)/config/sensors.yaml\"\
    \ />\n\n3) Edit the existing `<moveit_package>/launch/sensor_manager.launch.xml`\
    \ file to set octomap config:\n\n    <param name=\"octomap_frame\" type=\"string\"\
    \ value=\"world_frame\" />\n    <param name=\"octomap_resolution\" type=\"double\"\
    \ value=\"0.025\" />\n    <param name=\"max_range\" type=\"double\" value=\"5.0\"\
    \ />\n\n"
