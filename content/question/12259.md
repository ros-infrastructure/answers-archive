 I use gazebo 2.2.6 with ROS Indigo.

I run existing gazebo world:

<code>roslaunch turtlebot_gazebo turtlebot_world.launch world_file:=/usr/share/gazebo-2.2/worlds/mud.world
</code>

Picture with terminal output is attached. Gazebo launched with black window.
![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/gazebosim/14511526887437968.png)

I can download models manually:

<code> wget http://gazebosim.org/models/model_name/model.tar.gz .</code>

<code>tar xvf model.tar.gz -C ~/.gazebo/models</code>

But it is complicated to do it manually for every world.
