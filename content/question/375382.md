  body_markdown: "Hi,\n\nsince your problem seems related to the transformation frames,\
    \ especially the **odom** to **base_link**/ **base_footprint** , I would probably\
    \ start debugging by removing the navigation part and just see what are the outputs\
    \ of hector SLAM.\n\nWith hector SLAM, you should be able to \n\n- get the occupancy\
    \ map (with the empty, obstacle, unknown cells) with the laser sensors integrated\
    \  \n- get the localization of your robot in this map\n\nThese can be checked\
    \ in RVIZ, using as fixed frame either **map** or **odom**. \n\nIf you debug the\
    \ TF tree (e.g. with rqt_tf_tree), you should see the   **map**, **odom** and\
    \ **base_link** / **base_footprint** frames. \n\nOnly then you should consider\
    \ introducing the navigation nodes. "
