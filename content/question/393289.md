[UPDATE]
I noticed that following the IKFast tutorial for ROS Noetic ([here](https://ros-planning.github.io/moveit_tutorials/doc/ikfast/ikfast_tutorial.html)), the sympy version 0.7.1 is automatically installed before generating the plugin. Thus, I did the same manually in the Dockerfile, before launching the command mentioned before and the plugin is correctly generated. 

Thus, the remaining question is why the new version of moveit_kinematics auto_create_ikfast_moveit_plugin.sh file does not allow to specify the free index (i.e. the redundant joint).
