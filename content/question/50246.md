    It apears that the transofrm from /base_footprint to /odom is being published by the diffdrive gazebo plugin from the erratic_gazebo_plugins package.  You can find the code in the function publish_odometry() in this [file](http://ua-ros-pkg.googlecode.com/svn/stacks/erratic_robot/trunk/erratic_gazebo_plugins/src/diffdrive_plugin.cpp).

    The plugin is being launched as part of the robot description .xacro [file](http://ua-ros-pkg.googlecode.com/svn/stacks/erratic_robot/trunk/erratic_description/urdf/erratic_base.xacro).
