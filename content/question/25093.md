  body_markdown: "The problem is on Gazebo's side when you are using Gazebo's ODE\
    \ default physics engine. Here is a quick fix that works for me.\n\nIn the sdf\
    \ file describing your Gazebo simulation environment, you need to set the \"physics-->ode-->constraints-->contact_max_correcting_vel\"\
    \ parameter to correspond to the maximum angular speed (rad/s) of any joint you\
    \ wish to simulate. \nFor instance, for a maximum angular speed of 10000.0 rad/s,\
    \ a simple working example of an sdf file would be\n\n    <?xml version=\"1.0\"\
    \ ?>\n    <sdf version=\"1.5\">\n    \t<world name=\"default\">\n    \t\t<physics\
    \ name='default_physics' default='0' type='ode'>\n    \t\t\t<max_step_size>0.001</max_step_size>\n\
    \    \t\t\t<real_time_factor>1</real_time_factor>\n    \t\t\t<real_time_update_rate>1000</real_time_update_rate>\n\
    \    \t\t\t<ode>\n    \t\t\t\t<constraints>\n    \t\t\t\t<contact_max_correcting_vel>10000.0</contact_max_correcting_vel>\n\
    \    \t\t\t\t</constraints>\n    \t\t\t</ode>\n    \t\t</physics>\n    \t\t<!--\
    \ A global light source -->\n    \t\t<include>\n    \t\t\t<uri>model://sun</uri>\n\
    \    \t\t</include>\n    \t\t<!-- A ground plane -->\n    \t\t<include>\n    \t\
    \t\t<uri>model://ground_plane</uri>\n    \t\t</include>\n    \t</world>\n    </sdf>\n\
    \nThis is a weird workaround, because according to the [SDFormat specifications](http://sdformat.org/spec?ver=1.6&elem=physics#ode_constraints)\
    \ , the \"contact_max_correcting_vel\" parameter corresponds to the maximum correcting\
    \ velocities allowed when resolving contacts (and has a default value of 100).\
    \ This has arguably nothing to do with the maximum angular speed of the joints\
    \ in a model.\n\nThen in [Gazebo's documentation](http://gazebosim.org/tutorials?tut=physics_params&cat=physics),\
    \ it is pointed out that\n\n> contact_max_correcting_vel This is the\n> same parameter\
    \ as the max_vel under\n> collision->surface->contact.\n> contact_max_correcting_vel\
    \ sets\n> max_vel globally.\n\nAgain, setting contact_max_correcting_vel should\
    \ have nothing to do with the maximum angular speed of joints in the model, but\
    \ I suspect that the global value set for max_vel is also used by ODE's physics\
    \ engine as the default maximum angular speed for new bodies. For more details,\
    \ check out the \"dWorldSetMaxAngularSpeed\" function in [ODE's manual](http://ode.org/wiki/index.php?title=Manual).\n"
