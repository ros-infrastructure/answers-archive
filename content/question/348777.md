  body_markdown: "Hi @kane_choigo,\n\nYou can use the [roslaunch API](http://wiki.ros.org/roslaunch/API%20Usage#Roslaunch_file_with_command_line-style_arguments)\
    \ to launch your files programatically. Besides, in the script you can import\
    \ numpy to generate random numbers that you can fetch to the launch arguments.\n\
    \nI will provide an example to solve this problem:\n\nImagine you have a launch\
    \ file named `my_launch.launch` with the `init_pose` argument under the package\
    \ `my_pkg`\n\n    <?xml version=\"1.0\"?>\n    <launch>\n      <arg name=\"init_pose\"\
    \ default=\"-x 0.0 -y 0.0 -z 0 -R 0 -P 0 -Y 0.0\"/>\n      ...\n    </launch>\n\
    \nYou can use the roslaunch API to implement a script like:\n\n    #!/usr/bin/env\
    \ python\n    import roslaunch\n    import rospy\n    import numpy as np\n   \
    \ \n    value =\"-x 0.0 -y 0.0 -z 0.0 -R 0.0 -P 0.0 -Y 0.0\"\n    \n    x_pos\
    \ = np.random.uniform(low=0.0, high=10.0)\n    y_pos = np.random.uniform(low=0.0,\
    \ high=10.0)\n    z_pos = np.random.uniform(low=0.0, high=10.0)\n    \n    R_pos\
    \ = np.random.uniform(low=0.0, high=3.14)\n    P_pos = np.random.uniform(low=0.0,\
    \ high=3.14)\n    Y_pos = np.random.uniform(low=0.0, high=3.14)\n    \n    value\
    \ = \"-x \" + str(x_pos) + \" -y \" + str(y_pos) + \" -z \" + str(z_pos) + \"\
    \ -R \" +str(R_pos) + \" -P \" + str(P_pos) + \" -Y \" +str (Y_pos)\n    \n  \
    \  arg_1 = 'init_pose:=' + value \n    \n    uuid = roslaunch.rlutil.get_or_generate_uuid(None,\
    \ False)\n    roslaunch.configure_logging(uuid)\n    \n    cli_args = ['my_pkg',\
    \ 'my_launch.launch', arg_1]\n    roslaunch_args = cli_args[2:]\n    roslaunch_file\
    \ = [(roslaunch.rlutil.resolve_launch_arguments(cli_args)[0], roslaunch_args)]\n\
    \    \n    parent = roslaunch.parent.ROSLaunchParent(uuid, roslaunch_file)\n \
    \   \n    parent.start()\n    \n    try:\n      parent.spin()\n    finally:\n\
    \      parent.shutdown()\n\n"
