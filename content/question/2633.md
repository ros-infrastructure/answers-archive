  body_markdown: "In case this happens to anyone else:\n\nThe plugin was designed\
    \ to read in a list of joint coordinates from a file. The file was placed in the\
    \ same directory as the SDF file. \n\nSo: When I ran Gazebo from the directory\
    \ containing the model & plugin, it found the plugin and found the joint file.\
    \ No problem.\n\nWhen I ran Gazebo from outside of the directory without the `GAZEBO_PLUGIN_PATH`\
    \ set, it wouldn't find the plugin, and it handled that gracefully by inserting\
    \ the model, not running the plugin and giving me a \"plugin not found\" message.\
    \ \n\nWhen I ran Gazebo from outside of the directory with the `GAZEBO_PLUGIN_PATH`\
    \ set, it found the plugin, but the plugin couldn't find the joint file and segfaulted.\
    \  This brought Gazebo down with it.  \n\nSolution: In the plugin code: Use an\
    \ absolute file path instead of a file path that was relative to the plugin. \
    \ Or, in the plugin code, handle missing joint files more gracefully. "
