  body_markdown: "first create a map_server_params.yaml file to set the ros parameters,\n\
    \n    map_server:\n        ros__parameters:\n    \tframe_id: map\t\n    \ttopic_name:\
    \ map\n    \tuse_sim_time: false\n        yaml_filename: \"/home/dastan/map.yaml\"\
    \n\nthen run the map_server node with passing the .yaml file as the input,\n\n\
    \    ros2 run nav2_map_server map_server --ros-args --params-file map_server_params.yaml\n\
    \n\nthen since all nodes in nav2 are lifecycle nodes, you need to transition them\
    \ into active mode,\n\n    ros2 lifecycle set /map_server configure\n    ros2\
    \ lifecycle set /map_server activate\n\nthen the subscriber to the /map topic\
    \ should have the **QoS of local_transient** in order to recieve the map data.\n\
    \n\n"
