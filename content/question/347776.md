    The linter ament_copyright looks for a license declaration in the CONTRIBUTING.md file of your repository.

    The list of all currently supported licenses can be found [here](https://github.com/ament/ament_lint/tree/449f24927235ee6d0592e1e4d5c21f306effaa5d/ament_copyright/ament_copyright/template). The files with a name ending in `_contributing.txt` contain the string the linter will be looking for in the CONTRIBUTING.md file.
