  body_markdown: "You can do this with **xacro** (a XML macro language): http://wiki.ros.org/xacro\n\
    \nFrom section *3. Math Expression*\n\n>  Since ROS Jade, Xacro employs python\
    \ to evaluate expressions\n> enclosed in dollared-braces (${}).\n> This allows\
    \ for more complex\n> arithmetic expressions. Also, **some\n> basic constants,\
    \ e.g. pi, are already\n> predefined**:\n> \n>     <xacro:property name=\"R\"\
    \ value=\"2\" />\n>     <xacro:property name=\"alpha\" value=\"${30/180*pi}\"\
    \ />\n>     <circle circumference=\"${2 * pi * R}\" pos=\"${sin(alpha)} ${cos(alpha)}\"\
    \ />\n\n----------\nYou might be interested in the [ROS xacro tutorial](http://wiki.ros.org/urdf/Tutorials/Using%20Xacro%20to%20Clean%20Up%20a%20URDF%20File)"
