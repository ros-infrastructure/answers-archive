  body_markdown: "I understand what you mean. You want to translate in the rotated\
    \ frame and not the original frame. Unfortunately tf2 only works with translation\
    \ and rotation being published with respect to the original frame. Because it\
    \ is a transform with respect to that particular frame.\n\nTo solve your problem\
    \ there are two ways:\n\n 1. The simple way is to create two\n    frames. A temporary\
    \ frame which\n    contains only the rotation.  And\n    then another transform\
    \ to translate\n    in this frame.\n 2. If you do not want to create a\n    temporary\
    \ frame, you can  calculate\n    what the translational vector will\n    be in\
    \ the rotated frame. And then\n    use those values instead.  To\n    illustrate:\
    \ If you want to first\n    rotate by `r,p,y` and then translate\n    in the rotated\
    \ frame by `a,b,c`. You\n    should calculate the new\n    translational values\
    \ `R * {a,b,c}`\n    where `R` is the rotation matrix constructed by the rotation\
    \ angles. \nThen you can use the tf2 package with these new values. \n\nHope this\
    \ helps!"
