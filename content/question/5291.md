  body_markdown: "According to user guide ( http://gazebosim.org/user_guide/started__models__database.html)\n\
    Gazebo uses two environment variables to find model databases.\n\n     GAZEBO_MODEL_DATABASE_URI\n\
    \     \n     This is a URI that points to an online\n     model database. The\
    \ default value is\n     http://gazebosim.org/models\n     \n     GAZEBO_MODEL_PATH\n\
    \     \n     This is a colon-separated list of  local paths that Gazebo should\
    \ search  for databases. \n      Each path should point to the directory that\
    \ contains the  database config. \n      These paths take  precedence over the\
    \ online URI database.\n\n\nBy modification of these variables, this behavior\
    \ can be avoided."
