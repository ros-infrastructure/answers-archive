  body_markdown: "Solution of the error : No matching device found.... waiting for\
    \ devices\n\nThere may be permission issue with KInect. That's why it's showing\
    \ like no devices found. In gazebo , the camera node publishes image topic. But\
    \ in real hardware it is done by Openni.launch (Kinect launch ) file. So we need\
    \ to give permission to the given port.\nGive the following commands - \n$ lsusb\n\
    \nYour device will be listed\n$ sudo chmod 777 -R /dev/bus/usb\n\nYou have given\
    \ permission to the port\n\n$ roslaunch openni_launch openni.launch"
