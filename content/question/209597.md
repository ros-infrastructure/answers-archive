  body_markdown: "As mentioned in [ROS Installation Guide for Ubuntu](http://wiki.ros.org/indigo/Installation/Ubuntu#Installation-1),\
    \ you need to install some dependencies manually for **14.04.2** . Quoting from\
    \ the page:\n\n> If you are using Ubuntu Trusty 14.04.2 and experience dependency\
    \ issues during the ROS installation, you may have to install some additional\
    \ system dependencies. **(Do not install these packages if you are using 14.04,\
    \ it will destroy your X server)**\n\n    sudo apt-get install xserver-xorg-dev-lts-utopic\
    \ mesa-common-dev-lts-utopic libxatracker-dev-lts-utopic libopenvg1-mesa-dev-lts-utopic\
    \ libgles2-mesa-dev-lts-utopic libgles1-mesa-dev-lts-utopic libgl1-mesa-dev-lts-utopic\
    \ libgbm-dev-lts-utopic libegl1-mesa-dev-lts-utopic\n\n> Alternatively, try installing\
    \ just this to fix dependency issues: **(Do not install the above packages if\
    \ you are using 14.04, it will destroy your X server)**\n\n    sudo apt-get install\
    \ libgl1-mesa-dev-lts-utopic\n\n> For more information on this issue see this\
    \ [answers.ros.org thread](http://answers.ros.org/question/203610/ubuntu-14042-unmet-dependencies/)\
    \ or this [launchpad issue](https://bugs.launchpad.net/ubuntu/+source/mesa-lts-utopic/+bug/1424059)\n\
    \n\n "
