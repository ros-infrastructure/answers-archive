    \ you need to include in the CMakeList.txt where to find the lirary, for me it\
    \ was:\n\n    FIND_LIBRARY(WIRINGPI_LIBRARY wiringPi /home/odroid/wiringPi)\n\n\
    The first parameter WIRINGPI_LIBRARY is just a name you give it which you will\
    \ then use to refer within CMakeList. Second parameter is the library name and\
    \ third parameter is the location on your system.\n\nTo use it, It depends on\
    \ whether you're working using Python or C++. \n\n1) For C++, include the library\
    \ in your code and it would be something like this:\n\n    #include \u201CwiringPi.h\u201D\
    \t\t//include the library\n\n    \u2026\u2026\u2026\n    \n    wiringPiSetup();\t\
    \t\t//library setup function\n    pinMode(11,OUTPUT);\t\t\t//set pin GPX2.1 as\
    \ output. Based on wiringPi\n    //GPIO library map \n    \n    \u2026\u2026\u2026\
    \n    \n    digitalWrite(11,data);\t\t//write data(binary) to pin\n\nAnd then\
    \ in your CMakeList.txt, add the following:\n\n    add_executable(slave src/slave.cpp)\n\
    \    target_link_libraries(slave ${CATKIN_LIBRARIES} ${WIRINGPI_LIBRARY}\n   \
    \ add_dependencies(slave beginner_tutorials_generate_messages_cpp wiringPi)\n\n\
    2) For python, I THINK its simply including the library in your code (not tested)\n\
