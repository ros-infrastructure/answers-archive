    Where to start:

    Look at the [source for the `video_recorder`](https://github.com/ros-perception/image_pipeline/blob/indigo/image_view/src/nodes/video_recorder.cpp) node in the `image_view` package (which is what is used in the tutorial that you linked to). You'll notice that `cv::VideoWriter` from OpenCV is used. Next, checkout the [API for the `cv::VideoWriter` class](http://docs.opencv.org/trunk/dd/d9e/classcv_1_1VideoWriter.html). This should be a good start for you.

  body_markdown: "You can also look at [rosbag](http://wiki.ros.org/rosbag). It allows\
    \ you to record any topic in the bag format. If you are publishing the video on\
    \ a specific topic you can record that using command line via `rosbag record <video/topic>`\n\
    \nMoreover, depending on the writing speed of the disk, rosbag may discard the\
    \ data it needs to write. In such cases, it is suggested to increase the buffer\
    \ size using `rosbag record -b <buffer number in MB> <video/topic>`. You can check\
    \ all the available command line arguments in [rosbag command line](http://wiki.ros.org/rosbag/Commandline#record).\
    \ \n\nSince it is a command line you always run this using a script and run in\
    \ even in a remote system. Hope this helps!"
