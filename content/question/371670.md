    If this requires the capability to transmit raw frames, then you should be able to just grant `CAP_NET_RAW` to the executable. See [capabilities(7)](https://man7.org/linux/man-pages/man7/capabilities.7.html).

    If it requires more capabilities, you could grant those as well.

    Or grant them to the user which runs the binary.
