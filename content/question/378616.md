running ROS Melodic on Ubuntu server 20.04, I have the need to move some python nodes from one workspace to and other.

Thus I first create the package in the destination workspace and build with carking_make.
Then, positioning in the source folder, I move the file to the destination with the below command mv ardu_info.py *~/catkin_ws4/src/ardu_listener/scripts/ardu_info.py*
when I run the script with $ python3 ardu_info.py the script run properly. Unfortunately, if I run rosrun ardu_listener ardu_info.py I have the error:
*/usr/bin/env: ‘python3\r’: No such file or directory*

Curiously: if I create the python file with $ touch ardu_info.py, then make it executable with the command chmod +x ardu_info.py, then I paste exactly the same content from the original file to the newly created one, then run it via rosrun ardu_listener ardu_info.py  --- it works just fine.

Of course, I can copy and paste the content of the files one by one but it will make a big deal of time and I would like to understand how to approach such a task also for future applications.
