    I read in ros-users someone is working a [new libfreenect-based ROS driver](http://ros.org/wiki/freenect_stack). I heard it was possible to capture audio in libfreenect, but haven't found any information on how to do it.

    I also found out about a library which supposedly supports Kinect audio capture and has an [existing ROS package](http://www.ros.org/wiki/hark), [HARK](http://winnie.kuis.kyoto-u.ac.jp/HARK/wiki.cgi?page=HARK-ROS) (an open-sourced robot audition software).

    Haven't tested this out yet, but seems like the way to go so far.
