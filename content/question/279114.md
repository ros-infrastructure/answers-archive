  body_markdown: "The #include statements in both **arm_interface.cpp** and **robot_test.cpp**\
    \ seem to be looking for a header file called **arm_interface.h** which must be\
    \ inside a directory called **armadillo_hl_interface**. Since this isn't the directory\
    \ that contains that header file it's failing. \n\nFrom your description the file\
    \ is actually located in the **omer/src/include/omer** directory so try changing\
    \ the #include in the two source files to:\n\n    #include \"omer/arm_interface.h\"\
    \n\nHopefully then it will be able to find the header files correctly."
