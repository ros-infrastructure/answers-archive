  body_markdown: "I'm pretty sure that the *Traditional processing is deprecated [..]*\
    \ warning does not have anything to do with the actual problem, which is that\
    \ `f3` is a unicode character, which cannot be encoded in an ASCII range. The\
    \ `xacro` most likely either declares an ASCII encoding in its [xml declaration](https://xmlwriter.net/xml_guide/xml_declaration.shtml),\
    \ or is missing a declaration all together and the default is to assume ASCII.\n\
    \nIn any case, look at 'position 1646': there should be an '\xF3' there (according\
    \ to [this](http://www.codetable.net/hex/f3) site anyway). Remove it (or change\
    \ the file to at least `utf-8`) and it should solve your issue.\n"
