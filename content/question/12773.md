    I found out an option for achieving smooth shading inside gazebo:
    Using Blender, "smooth shading" can be selected for all areas of your model that should be smooth shaded (I thought this was only a visualization option, but it in fact actually is a property of the mesh). Blender materials can also be used to set the color and lighting properties of the model. Then, after converting the model to triangles only (to work around gazebo not working with quad based COLLADA, as described [here](http://answers.ros.org/question/3667/modeling-urdf-files-using-blender-and-exporting-to)), the model can be exported to a .dae COLLADA model. When not specifying a material in the world file using the <material> tag, the materials of the .dae will be used.

    Example image:

    ![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/13277834262595089.png)

    /edit: Confirmation that textures work, too:

    ![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/13277882018820111.png)

Is it possible to activate smooth shading for parts of the world in gazebo? For natural environments like rolling hills, smooth shading (e.g. gouraud) looks a lot better than the default flat shading. I'd like to have something like this (example using meshlab):

![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/13276024633795811.png)

instead of this:

![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/13276024858471788.png)

The image in gazebo is done using this material:

    material Hector/Gouraud
    {
      receive_shadows on
      shading gouraud
    
      technique
      {
        pass Ambient
        {
          ambient 1.000000 1.000000 1.000000 1.000000
          diffuse 1.0 1.0 1.0 1.0
          specular 0.8 0.8 0.8 1 20
          shading gouraud
        }
    
        pass PointLight
        {
          ambient 1.000000 1.000000 1.000000 1.000000
          diffuse 1.0 1.0 1.0 1.0
          specular 0.8 0.8 0.8 1 20
          shading gouraud
        }
      }
    }

used like this in the world file:

       <model:physical name="landscape">
       <xyz>0 0 0</xyz>	
       <rpy>0 0 0</rpy>
       <static>true</static>
       <body:trimesh name="landscape_body">
         <geom:trimesh name="landscape_geom">
           <scale>1.0 1.0 1.0</scale>
           <mesh>rolling_landscape_blender_export_meshlab_resave.dae</mesh>
           <genTexCoord>true</genTexCoord>
           <visual>
             <scale>1.0 1.0 1.0</scale>
             <mesh>rolling_landscape_blender_export_meshlab_resave.dae</mesh>
    	 
    	 <!--<material>Hector/BlueBrushedAluminum</material>-->
             <material>Hector/Gouraud</material>
           </visual>
         </geom:trimesh>
       </body:trimesh>
      </model:physical>

Unfortunately, the material system has no detailed documentation that I'm aware of, so I don't know exactly what I have to do differently. The example is available in the [hector_gazebo_worlds](http://www.ros.org/wiki/hector_gazebo_worlds) package and can be started using

    roslaunch hector_gazebo_worlds rolling_landscape_120m.launch
