    A bit too little info is provided so I can only assume that you don't have `python-rospkg` installed. It's a non-ROS, standalone pkg that gets installed under `/usr/lib` instead of under `/opt` as other ROS packages, which means Python can find it without extra `PYTHONPATH` (maybe a [good read](https://stackoverflow.com/questions/7850908/what-exactly-should-be-set-in-pythonpath)).
