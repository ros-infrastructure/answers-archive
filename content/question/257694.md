  body_markdown: "Actually there is a way to change the texture from within URDF.\n\
    Put your \".material\" file inside `/media/materials/scripts/` and your texture\
    \ images inside `/media/materials/textures/`.\nUse this simple snippet for the\
    \ .material (just to make it simple, your code is right):\n\n    material YourMaterialName\n\
    \    {\n       technique\n       {\n          pass\n          {\n            \
    \ texture_unit\n             {\n              texture your_material_image.png\n\
    \              scale 1 1\n             }\n          }   \n       }\n    }\n\n\
    In your URDF, add the material to the link outside of the <link> tag, but referencing\
    \ it. Example:\n\n    <link name=\"link_name\">\n        <inertial>\n        \
    \    <mass value=\"1.0\" />\n            <origin xyz=\"0 0 0\" rpy=\"0 0 0\"/>\n\
    \            <inertia ixx=\"1e-6\" ixy=\"1e-6\" ixz=\"1e-6\"\n               \
    \      iyy=\"1e-6\" iyz=\"1e-6\"\n                     izz=\"1e-6\" />\n     \
    \   </inertial>\n    \n        <visual>\n            <geometry>\n            \
    \    <mesh filename=\"full_path_to_your_mesh/mesh.dae\"/>\n            </geometry>\n\
    \        </visual>\n    \n        <collision>\n            <geometry>\n      \
    \          <box size=\"1 1 1\" /> <!-- anything you want... -->\n            </geometry>\n\
    \        </collision>\n    </link>\n\n    <gazebo reference=\"link_name\">\n \
    \       <material>YourMaterialName</material>\n    </gazebo>\n\nThat's it. If\
    \ it still doesn't work, then you'll need to prepare your mesh. Open your mesh\
    \ using Blender, then first imagine how would you cut your solid with a scissor\
    \ in order to put all surfaces in a plane. Then, select those edges, press Ctrl+E\
    \ and select Mark Seam. The edges will become red. Split the window into 2 and\
    \ in the new window choose UV/Image Editor as the Editor Type (bottom left corner).\
    \ Then, press A to select everything, press U and choose Unwrap. At the UV/Image\
    \ Editor will appear a geometry showing all your object faces in a plane. Now\
    \ you can export to COLLADA (.dae) and put in your visual geometry mesh.\n\nIf\
    \ you could not follow up the Blender steps, take a look at this tutorial: https://youtu.be/f2-FfB9kRmE"
