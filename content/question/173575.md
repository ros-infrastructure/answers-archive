  body_markdown: "I ran into the same issue and ended up creating this script:\n\n\
    \    #!/bin/bash\n    # $0 is the script name, $1 id the first ARG, $2 is second...\n\
    \n    if [ \"$2\" = \"\" ]\n    then\n      echo \"Usage: $0 <filename> <namespace>\"\
    \n    else\n      dump_command=\"rosparam dump\"\n      load_command=\"rosparam\
    \ load\"\n  \n      FILE=\"$1\"  \n      NAMESPACE=\"$2\"\n      IS_NAMESPACE=$(rosparam\
    \ list | /bin/egrep \"$NAMESPACE\")\n\n      if [ -z \"$IS_NAMESPACE\" ];\n  \
    \    then\n        echo \"No previous Namespace found, simply loading new parameters\"\
    \n        command=\"$load_command $FILE $NAMESPACE\"\n        eval $command\n\
    \      else           \n\n        #Dumps the current parameters in the server\n\
    \        command=\"$dump_command dump_tmp.txt $NAMESPACE\"\n        eval $command\n\
    \n        #Temporarly loads the new parameters\n        command=\"$load_command\
    \ $FILE $NAMESPACE\"\n        eval $command\n\n        #Dumps the new parameters\n\
    \        command=\"$dump_command load_tmp.txt $NAMESPACE\"\n        eval $command\n\
    \n        #Appends both files\n        cat dump_tmp.txt >> load_tmp.txt\n\n  \
    \      #Loads all the new parameters\n        command=\"$load_command load_tmp.txt\
    \ $NAMESPACE\"\n        eval $command\n\n        #Remove temporary files\n   \
    \     rm load_tmp.txt\n        rm dump_tmp.txt\n      fi\n    fi\n\nI called this\
    \ script file \"rosparam_append\" and it takes as arguments the new .yaml file\
    \ to append and the namespace (if there's no namespace, the simple rosparam load\
    \ command is executed)\n\nExample:\n\n    rosparam_append [path/to/your].yaml\
    \ /[your_namespace]\n\nyou can use this script in your launch file ([from this\
    \ answer](http://answers.ros.org/question/51474/can-i-run-a-bash-script-using-roslaunch/)):\n\
    \n    <node name    = \"rosparam_append_node\" \n          pkg     = \"your-package-name\"\
    \n          type    = \"rosparam_append\"\n          args    = \"$(find your-package-name)/path/to/your.yaml\
    \ /your/namespace\"/>\n\nremember to give executable permissions to the script\
    \ with:\n\n    chmod 755 rosparam_append\n\nhope it helps"
