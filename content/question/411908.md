    \nSo if you can manage to build the drivers from source for TB3 you should be\
    \ good to go. Perhaps more advanced packages could be harder to compile, we could\
    \ help you with them.\n\nEDIT:\n\nFor these packages to work you have to set up\
    \ source build of the `kobuki-base`, clone these in your `ros2_ws/src`, with `rosdep\
    \ install` before building them - I have these commands on hand for my setup:\n\
    \n### ROS 2 setup after installation (https://docs.ros.org/en/galactic/Installation/Ubuntu-Install-Debians)\n\
    \n    echo \"source /opt/ros/humble/setup.bash\" >> ~/.bashrc\n    sudo apt install\
    \ python3-colcon-common-extensions\n    echo \"source /usr/share/colcon_cd/function/colcon_cd.sh\"\
    \ >> ~/.bashrc\n    echo \"export _colcon_cd_root=/opt/ros/humble/\" >> ~/.bashrc\n\
    \    echo \"source /usr/share/colcon_argcomplete/hook/colcon-argcomplete.bash\"\
    \ >> ~/.bashrc\n\n### Nav2 binaries\n\n       sudo apt install ros-humble-navigation2\n\
    \       sudo apt install ros-humble-nav2-bringup\n       sudo apt install ros-humble-turtlebot3*\n\
    \       sudo apt install ros-humble-turtle*\n       export TURTLEBOT3_MODEL=waffle\n\
    \       export GAZEBO_MODEL_PATH=$GAZEBO_MODEL_PATH:/opt/ros/humble/share/turtlebot3_gazebo/models\n\
    \n### Test launch\n      ros2 launch nav2_bringup tb3_simulation_launch.py\n\n\
    ### ROS 2 workspace for sources\n  \n    cd ~/tb2_ros2_nav2/\n    mkdir -p ros2_ws/src\n\
    \    cd ~/tb2_ros2_nav2/ros2_ws/src\n\n### Clone these Kobuki packages\n\n   \
    \ git clone https://github.com/kobuki-base/kobuki_core.git\n    git clone https://github.com/kobuki-base/velocity_smoother.git\n\
    \    git clone https://github.com/kobuki-base/cmd_vel_mux.git\n    git clone https://github.com/kobuki-base/kobuki_ros_interfaces.git\n\
    \    git clone https://github.com/kobuki-base/kobuki_ros.git\n\n### Important!\
    \ Install dependencies (ECL libraries, etc.)\n\n    cd ~/tb2_ros2_nav2/ros2_ws/\n\
    \    sudo rosdep install -i --from-path src --rosdistro humble -y\n\n### Build\
    \ Kobuki packages\n\n    colcon build --symlink-install"
