  body_markdown: "Hello! I am assuming you mean in URDF. If so continue reading! I\
    \ had the exact same problem with a hip joint the other day.\n\nIn order to get\
    \ two degrees of freedom, make TWO *revolute* joints in the same location connected\
    \ via a dummy link.\n\nExample in Pseudo XML:\n\n    link thigh_link\n    link\
    \ leg_link\n    \n    link placeholder\n     origin=\"0 0 0\" //NOTE: this link\
    \ has no change in location nor any geometry\n    \n    joint hip_joint_x type=\"\
    revolute\"\n     parent = \"thigh_link\"\n     child = \"placeholder\"\n     axis\
    \ xyz=\"1 0 0\"\n    /joint\n    \n    joint hip_joint_y type=\"revolute\"\n \
    \    parent = \"placeholder\"\n     child = \"leg_link\"\n     axis xyz=\"0 1\
    \ 0\"\n    /joint\n\nHope this helps!\n"
