    I have no direct experience with any Simulink <-> ROS bridges, but there are several options that might work for your use case:

     - Simulink <-> OROCOS: using the [orocos-simulink-toolbox](http://www.orocos.org/orocos/orocos-simulink-toolbox). OROCOS then has a ROS transport
     - ROS <-> Matlab: several implementations exist, see the [groovy/Planning/Matlab](http://www.ros.org/wiki/groovy/Planning/Matlab) page for an overview. From there you might be able to create an S-function block (although according to [this](http://answers.ros.org/question/12542/rosmatlab-simulink-communication) answer, that could be hard / impossible)
     - [ros_simulink](https://github.com/abubeck/ros_simulink): this one doesn't seem to be included on the Groovy planning page. Seems a bit stale (last commit: 3 years ago)
     - write your own (MEX and / or S-function) using the appropriate roscpp libraries (again, see [this](http://answers.ros.org/question/12542/rosmatlab-simulink-communication) answer for some details)
