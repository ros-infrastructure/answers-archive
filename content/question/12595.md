  body_markdown: "The first is OpenCV in C++, the second is OpenCV in the basic C\
    \ functions. The first example is calling the C++ version of OpenCv with namespaces\
    \ and all of the functions included in the namespace. The second style is simply\
    \ the OpenCV function in C. The C++ is just a wrapper for the C code, so you're\
    \ essentially calling the same functions either way. Which you use is really up\
    \ to you. I like the C functions better, mostly for the sake of simplicity and\
    \ documentation. "
