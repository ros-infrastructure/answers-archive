  body_markdown: "Hello, \nYou need to add the controller_manager node to your launch\
    \ file to be able to load controllers. Also, you will not need to load the controllers\
    \ manually with the ExecuteProcess command. However, you will need your robots\
    \ URDF to be able to launch the ros2_control hardware components. You can replace\
    \ your ExecuteProcess with this :\n\n    Node(\n        package=\"controller_manager\"\
    ,\n        executable=\"ros2_control_node\",\n        parameters=[<your_robots_urdf>,\
    \ <your_controllers_yaml_file_path>]\n    )\n\n        "
