  body_markdown: "Whatever you do in a model plugin, you should also be able to do\
    \ in a world plugin. \n\nSometimes using a model plugin is more convenient, e.g.\
    \ when new models are inserted, the model plugin will run automatically, whereas\
    \ in a world plugin you will have to monitor newly inserted models and verify\
    \ that's it's the model that you want.\n\n"
