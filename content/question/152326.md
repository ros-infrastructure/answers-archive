  body_markdown: |-
    No, this is not possible. You can only depend on catkin packages in rosbuild ones, not the other way around. See also note [here](http://wiki.ros.org/catkin/migrating_from_rosbuild#Prerequisites). There might be some very hacky ways doing it by using cmake, custom scripts and fixed paths or so, but the recommended way is converting all dependencies to catkin.
