  body_markdown: "Hi @Sebastian_ROS\n\nIf you look into `demo_gazebo.launch` and `demo_launch`\
    \ they are different and run different nodes.\nYou can find them in your system,\
    \ but for others the files look like this:\n\n[demo_launch](https://github.com/ros-planning/moveit/blob/master/moveit_setup_assistant/templates/moveit_config_pkg_template/launch/demo.launch)\n\
    \n[demo_gazebo_launch](https://github.com/ros-planning/moveit/blob/master/moveit_setup_assistant/templates/moveit_config_pkg_template/launch/demo_gazebo.launch)\n\
    \nIf you look at the control portion of the launch file:\n\nFor `demo.launch`:\n\
    \n      <!-- Choose controller manager: fake, simple, or ros_control -->\n   \
    \   <arg name=\"moveit_controller_manager\" default=\"fake\" />\n      <!-- Set\
    \ execution mode for fake execution controllers -->\n      <arg name=\"fake_execution_type\"\
    \ default=\"interpolate\" />\n\n\nAnd for `demo_gazebo_launch`:\n\n      <include\
    \ file=\"$(dirname)/demo.launch\" pass_all_args=\"true\">\n        <!-- robot\
    \ description is loaded by gazebo.launch, to enable Gazebo features -->\n    \
    \    <arg name=\"load_robot_description\" value=\"false\" />\n        <arg name=\"\
    moveit_controller_manager\" value=\"ros_control\" />\n      </include>\n\nAs you\
    \ can see the default `moveit_controller_manager` for `demo.launch` is `fake`,\
    \ whereas in `demo_gazebo.launch` the value is `ros_control`. \n\n"
