    \ containers with the `host` network driver is perhaps the simplest method. Additionally,\
    \ provisioning a container with the `host` network driver does not prevent you\
    \ from running ros master from inside that same container. Infact, such may be\
    \ necessary for other nodes outside the host machine to register themselves in\
