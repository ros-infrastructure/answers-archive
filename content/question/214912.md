    This is probably not the answer you're looking for, but in ROS 2 (think long term), it's very likely that nodes will have an (optional) standard lifecycle. See the proposed [node lifecycle](https://github.com/gbiggs/design/blob/gh-pages/articles/node_lifecycle.md) design document for more details. I believe the proposal addresses what you're asking for.

    For ROS 1, i.e. now, there is no general out-of-the-box solution that I know of. I know some projects like `ros_control` implement [project-specific](https://github.com/ros-controls/ros_control/blob/indigo-devel/controller_interface/include/controller_interface/controller_base.h#L58-L77) [solutions](https://github.com/ros-controls/ros_control/blob/indigo-devel/controller_interface/include/controller_interface/controller_base.h#L128-L144). You might want to implement a custom solution.
