    You can get a [joint's angle/position](http://osrf-distributions.s3.amazonaws.com/gazebo/api/dev/classgazebo_1_1physics_1_1Joint.html#a985d9c9f0ff03570eef9fb10142f9c54).

    A [sensor has a pose](http://osrf-distributions.s3.amazonaws.com/gazebo/api/dev/classgazebo_1_1sensors_1_1Sensor.html#ae2c6fd57bfe81802af49c5c470a8aa2f) that you can read. You can also get the [sensor's parent name (usually a link)](http://osrf-distributions.s3.amazonaws.com/gazebo/api/dev/classgazebo_1_1sensors_1_1Sensor.html#a90c529011d20e908d92aea7f91d7ede1). This name can be used to find a link and then joints in a model. Refer to gazebo's API for more help.
