  body_markdown: "I didn't have this problem, so you probably omitted an installation\
    \ step or so. ROS repositories provide `yaml-cpp0.2.6-dev`, so if you cannot install\
    \ it with\n\n    sudo apt-get install yaml-cpp0.2.6-dev\n\nit means that you probably\
    \ didn't set up your sources.list properly (read [here](http://www.ros.org/wiki/electric/Installation/Ubuntu),\
    \ depending on your Ubuntu version). Remember to set up your keys and update apt-get's\
    \ lists afterwards:\n    \n    wget http://packages.ros.org/ros.key -O - | sudo\
    \ apt-key add -\n    sudo apt-get update\n\nNow `yaml-cpp0.2.6-dev` should be\
    \ there for you.\n"
