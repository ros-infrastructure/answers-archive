    \ button you will find a file\n\n> /tmp/calibrationdata.tar.gz\n \nCopy it to\
    \ some location and then extract it as \n\n> tar -xzf calibrationdata.tar.gz\n\
    \nYou will get a left.yaml and right.yaml file. If not use <a href=\"http://wiki.ros.org/camera_calibration_parsers\"\
    >this</a> to get the files.\n\nOnce that's done you will need a launch file that\
    \ looks something like this\n<code>\n\n    <group ns=\"stereo\">\n      \n   \
    \   <node pkg=\"uvc_camera\" type=\"uvc_stereo_node\" name=\"uvc_camera_stereo\"\
    >\n        \n        <param name=\"width\" type=\"int\" value=\"640\" />\n   \
    \     <param name=\"height\" type=\"int\" value=\"480\" />\n        <param name=\"\

    \ brightness, power_line_frequency -->\n\n        <param name=\"left/device\"\
