  body_markdown: "If you need a \"screenshot\", you have two possibilities:\n\n1.\
    \ Use system-screenshot ability and take a screenshot of the image_view output.\n\
    2. Write a little Node / Nodelet which listen to a keyboard shortcut and then\
    \ write the current image to file, for e.g. with cv_bridge functionality.\n\n\
    <pre><code>\n    void save_image(const sensor_msgs::ImageConstPtr img, const std::string\
    \ prefix)\n\t{\n\t    // May want to view raw bayer data\n\t    // NB: This is\
    \ hacky, but should be OK since we have only one image CB.\n\t    if (img->encoding.find(\"\
    bayer\") != std::string::npos)\n\t      boost::const_pointer_cast<sensor_msgs::Image>(img)->encoding\
    \ = \"mono8\";\n\n\t    cv::Mat image;\n\t    try\n\t    {\n\t      image = cv_bridge::toCvShare(img,\
    \ \"bgr8\")->image;\n\t    } catch(cv_bridge::Exception)\n\t    {\n\t      ROS_ERROR(\"\
    Unable to convert %s image to bgr8\", img->encoding.c_str());\n\t    }\n\t   \
    \ std::string directory = std::string(getenv(\"HOME\")) + \"/catkin_ws/video_dumper_jpeg/\"\
    ;\n\t    std::string filename = (filename_format_ % prefix % count_ ).str();\n\
    \t    cv::imwrite(directory + filename, image);\n\t}\n</code></pre>"
