  body_markdown: "To find a solution for my issue, I decided to switch from the rosserial_python\
    \ server version to the C++ version of rosserial_server. There I first ran in\
    \ a new situation, that no connection between my arduino client and the server\
    \ could be established. The reason was, that rosserial_server sends a hangup signal\
    \ through the serial line every time it opens the interface, which continuously\
    \ resets the arduino.The solution is to inhibit the hangup signal  with *stty\
    \ -F /dev/ttyACM0 -hupcl*. I added this command to \n<par>\n{catkin_ws}/src/rosserial/rosserial_server/src/serial_node.cpp\n\
    <pre><code>\n\nint main(int argc, char* argv[])\n{\n  ros::init(argc, argv, \"\
    rosserial_server_serial_node\");\n\n  std::string port;\n  int baud;\n  ros::param::param<std::string>(\"\
    ~port\", port, \"/dev/ttyACM0\");\n  ros::param::param<int>(\"~baud\", baud, 57600);\n\
    \  system (\"stty -F /dev/ttyACM0 -hupcl\"); // Added to inhibit hangup signal\n\
    \n  boost::asio::io_service io_service;\n  rosserial_server::SerialSession serial_session(io_service,\
    \ port, baud);\n  io_service.run();\n  return 0;\n}\n</code></pre>\n\n\n     \
    \                                                                       "
