    \ this is what Ive got (I calculated these by following this [answer](https://answers.ros.org/question/263542/calibrating-camera-for-lsd-slam/\
    \ \"answer\")):\n\n    0.804 1.07 0 0 0\n    320 240\n    none\n    320 240\n\n\
    I saved these configs into a my_calib.cfg file in /lsd_slam/lsd_slam_core/calib.\
    \ \n\nThen I ran the following line: \n\n     rosrun lsd_slam_core live_slam image:=/g500/camera1\
    \ _calib='path//lsd_slam/lsd_slam_core/calib/my_calib.cfg'\n\nand after that I\
    \ ran \n\n    rosbag play *my_file*\n\nLSD_SLAM reacted and showed some signs\
