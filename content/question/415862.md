  body_markdown: "Figured out the answer on my own... I need to call the function\
    \ `rclcpp::get_logger()` rather than the `get_logger()` method of `rclcpp::Node`.\
    \ \n\nFor a test I added the following lines to the `on_init()` method:\n\n  \
    \  rclcpp::Logger loger = rclcpp::get_logger(\"test_logger\");\n    RCLCPP_INFO(logger,\
    \ \"Logging test\");\n\nWhich resulted in the output:\n\n    [ros2_control_node-1]\
    \ [INFO] [1685153874.083490048] [test_logger]: Logging test\n\nAnd that's what\
    \ I needed. Hopefully this will help someone else who doesn't read the code quite\
    \ closely enough. \n"
