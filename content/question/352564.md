  body_markdown: "In order to spawn a laser sensor in Gazebo and visualize the laser\
    \ scan in Rviz there are some steps missing. For instance:\n\nYou need an URDF\
    \ file, this is a minimal example (lets call it laser_sensor.urdf):\n\n    <?xml\
    \ version=\"1.0\"?>\n    \n    <robot name=\"cube_laser\">\n    \n      <link\
    \ name=\"base_link\">\n        <visual>\n          <geometry>\n            <box\
    \ size=\"0.2 0.2 0.2\"/>\n          </geometry>\n        </visual>\n        <collision>\n\
    \          <geometry>\n            <box size=\"0.2 0.2 0.2\"/>\n          </geometry>\n\
    \        </collision>\n      </link>\n    \n      <!-- a cube to use as laser\
    \ sensor geometry -->\n      <link name=\"hokuyo_link\">\n        <collision>\n\
    \          <origin xyz=\"0 0 0\" rpy=\"0 0 0\"/>\n          <geometry>\n     \
    \       <box size=\"0.1 0.1 0.1\"/>\n          </geometry>\n        </collision>\n\
    \        <visual>\n          <origin xyz=\"0 0 0\" rpy=\"0 0 0\"/>\n         \
    \ <geometry>\n            <box size=\"0.1 0.1 0.1\"/>\n          </geometry>\n\
    \        </visual>\n        <inertial>\n          <mass value=\"1e-5\" />\n  \
    \        <origin xyz=\"0 0 0\" rpy=\"0 0 0\"/>\n          <inertia ixx=\"1e-6\"\
    \ ixy=\"0\" ixz=\"0\" iyy=\"1e-6\" iyz=\"0\" izz=\"1e-6\" />\n        </inertial>\n\
    \      </link>\n    \n      <joint name=\"hokuyo_joint\" type=\"fixed\">\n   \
    \     <axis xyz=\"0 1 0\" />\n        <origin xyz=\"0 0 0.15\" rpy=\"0 0 0\"/>\n\
    \        <parent link=\"base_link\"/>\n        <child link=\"hokuyo_link\"/>\n\
    \      </joint>\n        \n        <!-- placeholder for laser sensor plugin-->\n\
    \        \n        </robot>\n\n\n\nYou have to add the following Gazebo tag with\
    \ a plugin that interacts with ROS (put it where the placeholder is):\n\n    \
    \  <!-- this is a laser sensor-->\n      <gazebo reference=\"hokuyo_link\">\n\
    \          <sensor type=\"ray\" name=\"laser\">\n          <pose>0 0 0 0 0 0</pose>\n\
    \          <visualize>false</visualize>\n          <update_rate>40</update_rate>\n\
    \          <ray>\n            <scan>\n              <horizontal>\n           \
    \     <samples>720</samples>\n                <resolution>1</resolution>\n   \
    \             <min_angle>-1.570796</min_angle>\n                <max_angle>1.570796</max_angle>\n\
    \              </horizontal>\n            </scan>\n            <range>\n     \
    \         <min>0.10</min>\n              <max>30.0</max>\n              <resolution>0.01</resolution>\n\
    \            </range>\n          </ray>\n          <plugin name=\"gazebo_ros_laser\"\
    \ filename=\"libgazebo_ros_laser.so\">\n            <topicName>laser/scan</topicName>\n\
    \            <frameName>hokuyo_link</frameName>\n          </plugin>\n       \
    \ </sensor>\n      </gazebo>\n\n\n`<frameName>`  **must match the name of one\
    \ link in the URDF file.**\n\n\nFire up Gazebo:  \n$ `roslaunch gazebo_ros empty_world.launch`\
    \   \n\nThen `cd` to where you saved your URDF file.  \nNext spawn the URDF model\
    \ to Gazebo:   \n\n$ `rosrun gazebo_ros spawn_model -file laser_sensor.urdf -urdf\
    \ -z 0.5 -model laser_sensor`\n\nLoad the robot model to parameter server:  \n\
    $ `rosparam set robot_description --textfile laser_sensor.urdf`\n\nTo broadcast\
    \ the robot model (from the URDF description) to the tf transform library run:\
    \  \n$ `rosrun joint_state_publisher joint_state_publisher`  \n$ `rosrun robot_state_publisher\
    \ robot_state_publisher`  \n\nTo verify that everything in running:  \n$ `rostopic\
    \ list`  \n$ `rostopic echo tf_static`  \n\nThen open Rviz.  \nSelect the drop_down\
    \ for fixed frame and type in \"base_link\".  \nFinally add a LaserScan visualization\
    \ and set the correct topic.  \n\nI can recommend starting with these tutorials:\n\
    \nBuilding a Visual Robot Model with URDF from Scratch  \nhttp://wiki.ros.org/urdf/Tutorials/Building%20a%20Visual%20Robot%20Model%20with%20URDF%20from%20Scratch\
    \  \n  \nTutorial: Using Gazebo plugins with ROS  \nhttp://gazebosim.org/tutorials?tut=ros_gzplugins#GPULaser"
