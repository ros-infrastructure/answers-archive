  body_markdown: "Maybe you should clarify you question a bit...\n\nI interpret your\
    \ question a bit, hopefully the answer you expected: Now I assume you can run\
    \ on your system the following launch\n\n    roslaunch urdf_tutorial display.launch\n\
    \nNow you would like to know where the display.launch lies in your file system.\
    \ \n\nBeing able to run \n\n    roslaunch urdf_tutorial display.launch\n\nmeans\
    \ there is a  package `urdf_tutorial` (In this case it comes along with installation;\
    \ but answer is valid for any package). On your system. You can enter \n\n   \
    \ roscd urdf_tutorial\n\nto navigate to the package folder. Now it is a good practice\
    \ to put `launch` files in the launch sub folder of the package folder. If the\
    \ package follows this you should see a `launch` folder when typing \n\n    ls\
    \ \n\nin the `urdf_tutorial` folder. And when entering the launch folder \n\n\
    \    cd launch\n\nand typing \n\n    ls\n\nyou should see the `display.launch`.\n\
    \n\nAddition:\n\nYou can also run \n\n    find -L . -name \"display.launch\"\n\
    \nin the `urdf_tutorial` folder to look for the `display.launch` (in case it is\
    \ not in the `launch` folder)\n\n\n"
