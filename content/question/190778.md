  body_markdown: "How aligned, and what are your constraints on the output? That really\
    \ makes a big difference. \n\nIf you're willing to lose some representational\
    \ accuracy, you can run the concatenated cloud through a [VoxelGrid filter](http://pointclouds.org/documentation/tutorials/voxel_grid.php),\
    \ which downsamples the cloud and leaves only one point for every x^3 size cube\
    \ (leaf). This is essentially what the octomap will do, except that the output\
    \ remains a point cloud.\n\nIf every point is perfectly aligned with every other,\
    \ which is extremely unlikely, you can insert all the points into a [Map](http://www.cplusplus.com/reference/map/map/),\
    \ using the x,y,z tuple as the key, and remove any points that double up on one\
    \ key."
