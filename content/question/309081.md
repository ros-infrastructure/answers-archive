  body_markdown: "The main issue here is that Catkin packages cannot depend on rosbuild\
    \ packages. From [wiki/catkin/migrating_from_rosbuild - Prerequisites](http://wiki.ros.org/catkin/migrating_from_rosbuild#Prerequisites):\n\
    \n> 1.1 Prerequisites\n> \n> Catkin packages cannot depend on rosbuild packages.\
    \ Therefore before migrating a package from rosbuild to catkin make sure that\
    \ all package dependencies have already been migrated to catkin.\n\nThe reason\
    \ that #q213264 goes in the other direction is because rosbuild depending on Catkin\
    \ *is* supported.\n"
