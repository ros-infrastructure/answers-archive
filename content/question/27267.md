    There is [laser_retro](http://sdformat.org/spec?ver=1.7&elem=visual#visual_laser_retro) that can be attached to a visual to give that visual a floating-point value for the intensity from LiDAR. The whole visual will give you the same intensity value though (but you can split your meshes further to give various values to various parts, a bit tedious though). I'm not sure if this works only on GPU LiDAR or also the CPU LiDAR.
