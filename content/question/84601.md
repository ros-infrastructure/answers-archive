  body_markdown: "**Is your documentation using a fixed axis or rotating axis (extrinsic\
    \ or intrinsic rotation?)**\n\nThe URDF documentation is using a **fixed axis**\
    \ rotation. This is described in more detail here: [REP 103](http://www.ros.org/reps/rep-0103.html#rotation-representation)\n\
    \nAlso, here: [Rotation Methods (ROS)](http://wiki.ros.org/geometry/RotationMethods#Fixed_Axis_vs_Euler_Angles)\n\
    \nIf your documentation is using rotating axis (intrinsic rotation) there is no\
    \ problem as `ypr` on a rotating axis is same as `rpy` on a fixed axis.\n\n**Otherwise:**\n\
    \nThe easiest way might to convert rotations between Euler angles is to use an\
    \ intermediate representation like a quaternion.\n\nIn ROS if you are using Python,\
    \ you can use the `transformations.py` module mentioned here (with a link to the\
    \ full source): [transformations.py](http://wiki.ros.org/geometry/RotationMethods#transformations.py)\n\
    \nExample Python session using this (first way is with quaternions, second with\
    \ matrices):\n\n    $ python\n    Python 2.7.3 (default, Jul  5 2013, 08:52:38)\
    \ \n    [GCC 4.6.3] on linux2\n    Type \"help\", \"copyright\", \"credits\" or\
    \ \"license\" for more information.\n    >>> import transformations\n    >>> import\
    \ math\n    >>> q=transformations.quaternion_from_euler(math.pi,0,0,'szyx')\n\
    \    >>> q\n    array([  0.00000000e+00,  -0.00000000e+00,   1.00000000e+00,\n\
    \            6.12303177e-17])\n    >>> transformations.euler_from_quaternion(q,'sxyz')\n\
    \    (0.0, -0.0, 3.141592653589793)\n    >>> m=transformations.euler_matrix(math.pi,0,0,'szyx')\n\
    \    >>> m\n    array([[ -1.00000000e+00,  -1.22460635e-16,  -0.00000000e+00,\n\
    \            0.00000000e+00],\n        [  1.22460635e-16,  -1.00000000e+00,  \
    \ 0.00000000e+00,\n            0.00000000e+00],\n        [ -0.00000000e+00,  \
    \ 0.00000000e+00,   1.00000000e+00,\n            0.00000000e+00],\n        [ \
    \ 0.00000000e+00,   0.00000000e+00,   0.00000000e+00,\n            1.00000000e+00]])\n\
    \    >>> transformations.euler_from_matrix(m,'sxyz')\n    (0.0, 0.0, 3.141592653589793)\n\
    \n"
