So,  I looked for where the error happened and found that  same ROS_ERROR code is described on line 171 in eband_local_planner_ros.cpp.
<pre>
	if(!eband_->setPlan(transformed_plan_))
	{
		ROS_ERROR("Setting plan to Elastic Band method failed!");
		return false;
	}
</pre>
If eband_.setPlan() is true, ROS_ERROR doesn't happen. But, I don't come up with the solution that it become true.
Could anyone tell me any solution if you know it? Thank you in advance!
