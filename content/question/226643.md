    \ a copy just in case. In build.gradle I changed  this:\n\n<pre><code class=\"\
    language-java\">\nbuildscript { \n  apply from: \"https://github.com/rosjava/rosjava_bootstrap/raw/indigo/buildscript.gradle\"\
    \  \n}\n</code></pre>\n\nTo this:\n\n<pre><code class=\"language-java\">\nbuildscript\
    \ {\n    def f = new File(\"buildscript.gradle\") \n    try{ \n\tnew URL(\"https://github.com/rosjava/rosjava_bootstrap/raw/indigo/buildscript.gradle\"\
    ).withInputStream{ i -> f.withOutputStream{ it << i }}    \n    } catch (all)\
    \ { \n      //do nothing, keep cached script \n    }  \n    apply from: \"buildscript.gradle\"\
    \  \n}\n</code></pre>\nSo I keep a local copy, but if available, downloads from\
