  body_markdown: "The openni drivers have changed in fuerte, and the kinect+rgbdslam.launch\
    \ launch file is looking for the electric openni_camera launch file.  You can\
    \ fix this by changing the kinect+rgbdslam.launch file as such:\n\nchange\n\n\
    \    <include file=\"$(find openni_camera)/launch/openni_node.launch\"/>\nto \n\
    \n    <include file=\"$(find openni_launch)/launch/openni.launch\"/>"
