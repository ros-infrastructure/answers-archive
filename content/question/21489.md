    Ogre, the rendering engine used by Gazebo, [only supports 1px wide lines](https://bitbucket.org/osrf/gazebo/issues/1978/its-not-possible-to-change-rendering-grids). An alternative would be to use billboards, or very thin cylinders.

    You can find an example of billboards being used on Gazebo's source code on the model editor's [JointMaker](https://bitbucket.org/osrf/gazebo/src/29a9761d43c5c2f9364cceb5fdc1abf8b93d29e8/gazebo/gui/model/JointMaker.cc?fileviewer=file-view-default#JointMaker.cc-818) for example. In this case, the billboards are the squares which get attached to both ends of the joint line.
