  body_markdown: "Hi astaranowicz,\n\nour wrapper uses the same params than the libviso2\
    \ library, which you can find [here](http://www.cvlibs.net/software/libviso2.html).\
    \ However, if you prefer to start with our default params, they were [inside a\
    \ comment](https://github.com/srv/viso2/issues/6#issuecomment-14390591) in an\
    \ issue, they are:\n\n    prefilter_size: 9\n    prefilter_cap: 31\n    correlation_window_size:\
    \ 17\n    min_disparity: 20\n    disparity_range: 96\n    uniqueness_ratio: 10\n\
    \    texture_threshold: 10 \n    speckle_size: 200\n    speckle_range: 4\n\nThese\
    \ parameter depend on the stereo camera and the environment (texture, light) you\
    \ have there. Check the parameters [in the ROS wiki](http://www.ros.org/wiki/viso2_ros?distro=fuerte#Parameters)\
    \ for more information. If you have any other question, please feel free to ask,\
    \ but with the parameters it's best to experiment.\n\nHave fun!\n\n"
