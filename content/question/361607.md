  body_markdown: "Hi @sree,\n\nI will do my best to answer properly all your questions.\n\
    \n 1. If you want to save all your goals at once and execute each sequentially\
    \ you can use a `move_base_msgs::MoveBaseGoal goal` vector and store each goal\
    \ in it. You also can read them as parameter from a yaml file with the ROS [parameter\
    \ server](http://wiki.ros.org/Parameter%20Server). Then in the code just perform\
    \ a loop for each vector goal, waiting for result and resuming in the next step\
    \ when the action server returns a success. Since the move_base is based on the\
    \ `actionlib` paradigm you will be able to check goal status and success state\
    \ in each moment, cancel goals and traverse the vector in the order you decide.\n\
    \ 2. Simulation are just approximations to real life. You can expect that you\
    \ real robot is going to behave relatively equal than in the simulation but you\
    \ need to understand that there are a lot of variables that are not present in\
    \ the simulation and can variate the output in real life. For instance, sensor\
    \ reading errors (that in simulation tend to be perfect), constrained movement\
    \ (traversed floor or any mechanical problem the robot has), etc. For this reason\
    \ you may end adjusting several params and configuration to suit not only your\
    \ robot/sensor but also you environment.\n 3. Hope solution 1. helps you with\
    \ it.\n\nRegards.\n\n**EDIT**:\n\nIn order to give a use case for the approach\
    \ 1 I will post a chunk of code.\n\n**Disclaimer**: I am not an expert on using\
    \ `action_lib` with python, the functioning is strictly different when comparing\
    \ `roscpp` and `rospy`. There may be solutions that are better and more suitable\
    \ in this environment, but as a simple example I think it would be good.\n\nFirst\
    \ of all, since you want to have a set of goals at once you can load them with\
    \ a yaml file and parameter server, this can be a good `points.yaml` config file\
    \ to parametrize all your goals:\n\n    point_list: [\n      {x_pos: 1.0, y_pos:\
    \ 1.0, z_pos: 0.0, w: 1.0},\n      {x_pos: 2.0, y_pos: 2.0, z_pos: 0.0, w: 1.0},\n\
    \      {x_pos: 3.0, y_pos: 3.0, z_pos: 0.0, w: 1.0},\n      {x_pos: 4.0, y_pos:\
    \ 4.0, z_pos: 0.0, w: 1.0}\n    ]\n\nTake into account that you can convert this\
    \ param to a simple vector instead of a dictionary.\n\nSecond, I changed the code\
    \ you linked a bit so I can iterate all the goal list, and then pass every goal\
    \ to the `move_base` server to process:\n\n    #!/usr/bin/env python\n    \n \
    \   # license removed for brevity\n    \n    import rospy\n    from move_base_msgs.msg\

    \ import *\n    \n    class GoForwardAvoid():\n        def __init__(self):\n \

    \ to do if shut down (e.g. ctrl + C or failure)\n            rospy.on_shutdown(self.shutdown)\n\
    \    \n            self._point_list = rospy.get_param('/nav_test/point_list')\n\
    \            self._sleep_timer = rospy.Rate(5.0)\n    \n        def spin(self):\n\
    \            #tell the action client that we want to spin a thread by default\n\
    \            self.move_base = actionlib.SimpleActionClient(\"move_base\", MoveBaseAction)\n\
    \            rospy.loginfo(\"wait for the action server to come up\")\n      \
    \      #allow up to 5 seconds for the action server to come up\n            self.move_base.wait_for_server(rospy.Duration(5))\n\
    \    \n            goal = MoveBaseGoal()\n            goal.target_pose.header.frame_id\
    \ = 'base_link'\n    \n            for point in self._point_list:\n          \
    \      print(\"Sending Goal: (\" + str(point['x_pos']) + \", \" + str(point['y_pos'])\

    \            goal.target_pose.header.stamp = rospy.Time.now()\n              \
    \  goal.target_pose.pose.position.x = point['x_pos']\n                goal.target_pose.pose.position.y\
    \ = point['y_pos']\n                goal.target_pose.pose.position.z = point['z_pos']\n\
    \                goal.target_pose.pose.orientation.w = point['w']\n    \n    \
    \            #start moving\n                self.move_base.send_goal(goal)\n \
    \   \n                #allow TurtleBot up to 60 seconds to complete task\n   \
    \             success = self.move_base.wait_for_result(rospy.Duration(60)) \n\
    \    \n                if not success:\n                    self.move_base.cancel_goal()\n\

    \                    state = self.move_base.get_state()\n                    if\

    \ the base moved 3 meters forward\")\n    \n        def shutdown(self):\n    \
