  body_markdown: "While your own approach works, I wouldn't recommend it, as you are\
    \ hardcoding the name of the GLUT library and making assumptions about its presence\
    \ on your system.\n\nYou only included a few lines of your `CMakeLists.txt`, so\
    \ you could already be doing this, but just as an example (only showing relevant\
    \ parts):\n\n    find_package(catkin REQUIRED ..)\n    \n    find_package(GLUT\
    \ REQUIRED)\n    find_package(OpenGL REQUIRED)\n    \n    ..\n    \n    # setup\
    \ include path for both OpenGL & GLUT (and other dependencies)\n    include_directories(\n\
    \      include \n      ${catkin_INCLUDE_DIRS}\n      ${OpenGL_INCLUDE_DIRS}\n\
    \      ${GLUT_INCLUDE_DIRS}\n      ..\n    )\n    \n    ..\n    \n    # now link\
    \ target against all required libs\n    target_link_libraries(\n      ar_track_alvar\n\
    \        ${OPENGL_LIBRARIES}\n        ${GLUT_LIBRARY}\n        ..\n        ${catkin_LIBRARIES}\n\
    \    )\n\nThen also add a `build_depend` on `glut` (which is the `rosdep` key\
    \ for Glut according to [rosindex/d/glut](http://rosindex.github.io/d/glut/)).\n\
    \nFinally, be sure to add both `OpenGL` and `GLUT` (and any other system dependencies\
    \ that you are using) to the `DEPENDS` argument of `catkin_package(..)`.\n\n\n\
    > in my package.xml i have\n> \n>     <build_depend>OpenGL</build_depend>\n\n\
    According to [rosindex/d/opengl](http://rosindex.github.io/d/opengl/), the `rosdep`\
    \ key is actually `opengl` (all lowercase).\n\n---\n\nEdit:\n\n> opengl lower\
    \ case only shows in QT library while OpenGL shows in /usr/lib/python2.7/dist-packages/OpenGL\n\
    \n`rosdep` keys do not have to correspond in any way to any 'real' library, file,\
    \ directory or package. They are simply a key into a database that maps to platform\
    \ specific pkgs.\n\nThe `rosdep` key for all packages that provide OpenGL dev\
    \ hdrs/libs on all supported platforms is really `opengl` (see [rosdep/base.yaml,\
    \ lines 2522 to 2531](https://github.com/ros/rosdistro/blob/956944905a6a66202fddc87be93175f6fddf6ac7/rosdep/base.yaml#L2522-L2531)).\n"
