  body_markdown: "Solved it.\n\nCython prints error, warning, or status messages during\
    \ the compilation and this is somehow interfering with the colcon build process.\
    \ So the solution would be to set Cython quiet so it wont print error, warning,\
    \ or status messages during the compilation like this: `cythonize(...,quiet=True)`\n\
    \nMy new setup.py\n\n\n    from setuptools import setup, find_packages, Extension\n\
    \    from Cython.Build import cythonize\n    import glob\n    package_name = 'object_detector'\n\
    \    \n    \n    \n    sourcefiles = glob.glob(\"example/*.pyx\")\n    \n    extensions\
    \ = [Extension(\"example.cythontest\", sourcefiles,define_macros=[(\"NPY_NO_DEPRECATED_API\"\
    , \"NPY_1_7_API_VERSION\")])]\n    \n    \n    setup(\n        ext_modules=cythonize(extensions,compiler_directives={'language_level'\
    \ : \"3\"},force=True,annotate=True,quiet=True),\n        name=package_name,\n\
    \        version='0.0.0',\n        packages=find_packages(exclude=['test']),\n\
    \        data_files=[\n            ('share/ament_index/resource_index/packages',\n\
