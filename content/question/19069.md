  body_markdown: "Yes, a google search does reveal that there are some models available\
    \ for simulation of the realsense camera. See these links:  \nhttps://github.com/intel/gazebo-realsense\
    \  \nhttps://github.com/SyrianSpock/realsense_gazebo_plugin\n\nTo know more about\
    \ plugins in Gazebo, take a look at the official [Tutorial: Using Gazebo plugins\
    \ with ROS](http://gazebosim.org/tutorials?tut=ros_gzplugins).\n\nThat said, for\
    \ most applications, you can probably use the generic DepthCam or Kinect plugin.\
    \ I've been using the Asus Xtion Pro simulation of the camera, based on the `libgazebo_ros_openni_kinect.so`\
    \ plugin, for emulating a realsense camera and it's working well. I based it on\
    \ [a project](https://github.com/rosbook/effective_robotics_programming_with_ros/blob/master/chapter7_tutorials/rosbook_arm_description/urdf/sensors/xtion_pro_live.gazebo.xacro)\
    \ from the book Effective Robotics Programming with ROS.\n\nTo make this plugin\
    \ emulate your camera, modify the elements in the <sensors> tag withing the <gazebo>\
    \ tag to provide parameters like your horizontal FOV, minimum depth, maximum depth,\
    \ etc. I've left those parameters default in my simulation but have modified the\
    \ topic names to be the same as my actual camera. See my files below.\n\n\n\n\
    Here is the `xtion_pro_live.gazebo.xacro` file. Note that I replaced the mesh\
    \ files with a realsense mesh, from the links above. \n    <?xml version=\"1.0\"\
    ?>\n    <robot xmlns:xacro=\"http://ros.org/wiki/xacro\">\n      <xacro:include\
    \ filename=\"$(find robot_description)/urdf/deg_to_rad.xacro\"/>\n    \n     \
    \ <xacro:macro name=\"xtion_pro_live_rgbd_camera_gazebo\" params=\"name\">\n \
    \       <gazebo reference=\"${name}_link\">\n    \n          <static>true</static>\n\
    \          <turnGravityOff>true</turnGravityOff>\n    \n          <!-- RGB + Depth\
    \ -->\n          <sensor type=\"depth\" name=\"${name}_frame_sensor2\">\n    \
    \        <always_on>true</always_on>\n            <update_rate>6.0</update_rate>\n\
    \    \n            <camera>\n              <horizontal_fov>${58.0 * deg_to_rad}</horizontal_fov>\n\
    \              <image>\n                <format>R8G8B8</format>\n            \
    \    <width>640</width>\n                <height>480</height>\n              </image>\n\
    \              <clip>\n                <near>0.05</near>\n                <far>4.0</far>\n\
    \              </clip>\n              <noise>\n                <type>gaussian</type>\n\
    \                <mean>0.0</mean>\n                <stddev>0.005</stddev>\n  \
    \            </noise>\n            </camera>\n    \n            <plugin name=\"\
    ${name}_frame_controller\" filename=\"libgazebo_ros_openni_kinect.so\">\n    \
    \          <alwaysOn>true</alwaysOn>\n              <updateRate>6.0</updateRate>\n\
    \              <cameraName>${name}</cameraName>\n              <imageTopicName>color/image_raw</imageTopicName>\n\
    \              <depthImageTopicName>depth/image_rect_raw</depthImageTopicName>\n\
    \              <cameraInfoTopicName>color/camera_info</cameraInfoTopicName>\n\
    \              <depthImageCameraInfoTopicName>depth/camera_info</depthImageCameraInfoTopicName>\n\
    \              <pointCloudTopicName>depth_registered/points</pointCloudTopicName>\n\
    \              <frameName>${name}_color_optical_frame</frameName>\n          \
    \    <pointCloudCutoff>0.05</pointCloudCutoff>\n              <rangeMax>4.0</rangeMax>\n\
    \            </plugin>\n          </sensor>\n        </gazebo>\n      </xacro:macro>\n\
    \    </robot>\n\n\nHere is the `xtion_pro_live.urdf.xacro` file:\n\n    <?xmlversion=\"\
    1.0\"?>\n    <robot xmlns:xacro=\"http://ros.org/wiki/xacro\">\n    \n      <xacro:include\
    \ filename=\"$(find robot_description)/urdf/sensors/xtion_pro_live.gazebo.xacro\"\
    />\n      <xacro:include filename=\"$(find robot_description)/urdf/deg_to_rad.xacro\"\
    />\n    \n      <xacro:macro name=\"dummy_inertial\">\n        <inertial>\n  \
    \        <origin xyz=\"0 0 0\" rpy=\"0 0 0\"/>\n          <mass value=\"0.001\"\
    />\n          <inertia ixx=\"0.00001\" ixy=\"0\" ixz=\"0\"\n                 \
    \  iyy=\"0.00001\" iyz=\"0\"\n                   izz=\"0.00001\"/>\n        </inertial>\n\
    \      </xacro:macro>\n    \n      <xacro:macro name=\"xtion_pro_live\" params=\"\
    name parent_link *origin *optical_origin\">\n    \n        <!-- frames in the\
    \ center of the camera -->\n        <joint name=\"${name}_joint\" type=\"fixed\"\
    >\n          <xacro:insert_block name=\"origin\"/>\n          <parent link=\"\
    ${parent_link}\"/>\n          <child link=\"${name}_link\"/>\n        </joint>\n\
    \    \n        <link name=\"${name}_link\">\n          <inertial>\n          \
    \  <origin xyz=\"-0.00936000000 -0.00003000000 -0.00273000000\" rpy=\"0 0 0\"\
    />\n            <mass value=\"0.21970000000\"/>\n            <inertia ixx=\"0.00000429247\"\
    \ ixy=\"0.00000000000\" ixz=\"0.00000002565\"\n                     iyy=\"0.00000008027\"\
    \ iyz=\"0.00000000000\"\n                     izz=\"0.00000427339\"/>\n      \
    \    </inertial>\n          <visual>\n            <origin xyz=\"0 0 0\" rpy=\"\
    0 0 0\"/>\n            <geometry>\n              <mesh filename=\"package://robot_description/meshes/realsense/intel_d415.dae\"\
    />\n            </geometry>\n            <material name=\"DarkGrey\"/>\n     \
    \     </visual>\n        </link>\n    \n        <joint name=\"${name}_optical_joint\"\
    \ type=\"fixed\">\n          <xacro:insert_block name=\"optical_origin\"/>\n \
    \         <parent link=\"${name}_link\"/>\n          <child link=\"${name}_optical_frame\"\
    />\n        </joint>\n    \n        <link name=\"${name}_optical_frame\">\n  \
    \        <dummy_inertial/>\n        </link>\n    \n        <!-- Depth sensor frames\
    \ -->\n        <joint name=\"${name}_depth_joint\" type=\"fixed\">\n         \
    \ <origin xyz=\"0.0 0.049 0.0\" rpy=\"0 0 0\"/>\n          <parent link=\"${name}_link\"\
    />\n          <child link=\"${name}_depth_frame\"/>\n        </joint>\n    \n\
    \        <link name=\"${name}_depth_frame\">\n          <dummy_inertial/>\n  \
    \      </link>\n    \n        <joint name=\"${name}_depth_optical_joint\" type=\"\
    fixed\">\n          <origin xyz=\"0 0 0\" rpy=\"${-90.0 * deg_to_rad} 0.0 ${-90.0\
    \ * deg_to_rad}\"/>\n          <parent link=\"${name}_depth_frame\"/>\n      \
    \    <child link=\"${name}_depth_optical_frame\"/>\n        </joint>\n    \n \
    \       <link name=\"${name}_depth_optical_frame\">\n          <dummy_inertial/>\n\
    \        </link>\n    \n        <!-- RGB sensor frames -->\n        <joint name=\"\
    ${name}_color_joint\" type=\"fixed\">\n          <origin xyz=\"0.0 0.022 0.0\"\
    \ rpy=\"0 0 0\"/>\n          <parent link=\"${name}_link\"/>\n          <child\
    \ link=\"${name}_color_frame\"/>\n        </joint>\n    \n        <link name=\"\
    ${name}_color_frame\">\n          <dummy_inertial/>\n        </link>\n    \n \
    \       <joint name=\"${name}_color_optical_joint\" type=\"fixed\">\n        \
    \  <origin xyz=\"0 0 0\" rpy=\"${-90.0 * deg_to_rad} 0.0 ${-90.0 * deg_to_rad}\"\
    />\n          <parent link=\"${name}_color_frame\"/>\n          <child link=\"\
    ${name}_color_optical_frame\"/>\n        </joint>\n    \n        <link name=\"\
    ${name}_color_optical_frame\">\n          <dummy_inertial/>\n        </link>\n\
    \    \n        <xacro:xtion_pro_live_rgbd_camera_gazebo name=\"${name}\"/>\n \
    \     </xacro:macro>\n    \n    </robot>\n\nThese 2 are xacro macros. Use them\
    \ like this in a new urdf.xacro file:\n\n    <?xml version=\"1.0\"?>\n    <robot\
    \ xmlns:xacro=\"http://ros.org/wiki/xacro\" name=\"rgbd_cam\">\n    \n      <xacro:include\
    \ filename=\"$(find robot_description)/urdf/deg_to_rad.xacro\"/>\n      <xacro:include\
    \ filename=\"$(find robot_description)/urdf/camera_mount/camera_mount.urdf.xacro\"\
    />\n      <xacro:include filename=\"$(find robot_description)/urdf/sensors/xtion_pro_live.urdf.xacro\"\
    />\n    \n      <xacro:property name=\"camera_tilt\" value=\"45.0\" />\n    \n\
    \      <!-- Define base -->\n      <xacro:camera_mount name=\"camera_mount\" />\n\
    \    \n      <!-- Define RGB-D sensor -->\n      <xacro:xtion_pro_live name=\"\
    camera\" parent_link=\"camera_mount_mounting_link\">\n        <origin xyz=\"0.03\
    \ 0 0.03\" rpy=\"0 ${camera_tilt * deg_to_rad} 0\"/>\n        <origin xyz=\"0\
    \ 0 0\" rpy=\"${-90.0 * deg_to_rad} 0 ${-90.0 * deg_to_rad}\"/>\n      </xacro:xtion_pro_live>\n\
    \    \n    </robot>\n\n\n"
