  body_markdown: "You can try as this link shows: https://github.com/robotlabor-education/robotwiki/wiki/[Simulation][Gazebo]-Gazebo-simulation-in-ROS-2\
    \ \n\nCreate a file somewhere, for example <your package>/config/params.yaml,\
    \ with the following parameters :\n\n    gazebo: \n        ros__parameters: \n\
    \            publish_rate: 100.0 \n\nThen modify your launch file some like:\n\
    \n    config_file_name = 'params.yaml' \n    \n    pkg_dir = get_package_share_directory('<your\
    \ package name>') \n    \n    config = os.path.join(pkg_dir, 'config', config_file_name)\
    \ \n    \n    gazebo = ExecuteProcess( \n    \n    cmd=['gazebo', '--verbose',\
    \ world, '-s', 'libgazebo_ros_init.so',  \n    \n    '-s', 'libgazebo_ros_factory.so',\
    \ '--pause', '--ros-args', '--params-file', config], \n    \n    output='screen',\
    \ \n    \n    ) \n\nDon't forget to edit CMakeLists.txt."
