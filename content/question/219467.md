     > How can I do that .stl keeps the textures?

    You can't. STL does not support colours or texturing.

    Collada (`.dae`) is the only format supported by both ROS (RViz) and Gazebo which does allow you to add colour information and / or textures. I'm not sure about OGRE `.mesh`.

    An alternative might be to use Gazebo Material scripts (like [in this question](http://answers.gazebosim.org/question/1706/using-custom-material-for-an-object/)) which specify a texture to be applied (info on OGRE materials [here](http://www.ogre3d.org/tikiwiki/Materials)). Note that this will not work in RViz.
