    Hello. I got same error and solve it for now.

    A cause is that there are 2 opencv library (version 4.4 and 3.2) in one probram.
    So you can avoid this problem in cvtColor() by specifying version of opencv 3.2.
    Please change this line in your CMakeLists.txt.

    FROM
    find_package(OpenCV REQUIRED)

    TO
    find_package(OpenCV 3.2 REQUIRED)


    I suppose that cv_bridge package uses opencv 3.2 and your program use another version opencv.
    I think It is a error cause.
