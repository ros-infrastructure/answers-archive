  body_markdown: "Hi,\n\nIf inputs of rtabmap node are correctly connected, you should\
    \ see a log info printed each second (and the grid_map topic should be published\
    \ each second, empty or not). If not, it is because there is one of the input\
    \ topic which is not published. You can know to which topics rtabmap is connected\
    \ when rtabmap is launched or looking in your launch file, example:\n     \n \
    \   [...]\n    /rtabmap/rtabmap subscribed to:\n       /camera/rgb/image_rect_color,\n\
    \       /camera/depth_registered/image_raw,\n       /camera/rgb/camera_info,\n\
    \       /odom,\n       /scan\n    [...]\n\nIn that case you can verify if they\
    \ are published like this:\n\n    $ rostopic hz /camera/rgb/image_rect_color\n\
    \    $ rostopic hz /camera/depth_registered/image_raw\n    $ rostopic hz /camera/rgb/camera_info\n\
    \    $ rostopic hz /odom\n    $ rostopic hz /scan\n\ncheers"
