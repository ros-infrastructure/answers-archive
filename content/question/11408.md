  body_markdown: "Basically what you want to do is load the mesh object, create an\
    \ arm_navigation_msgs::CollisionObject from that mesh object, and publish it on\
    \ the '/collision_object' topic.  The environment_server listens to this topic\
    \ and then will include the mesh object in the planning scene, making MoveArm\
    \ plan around it.\n\nIn a bit more detail, here's a sketch of some code:\n\n \
    \   #include <geometric_shapes/shape_operations.h>\n    #include <planning_environment/util/construct_object.h>\n\
    \    \n    btVector3 scale(1.0,1.0,1.0);\n    //filename is either an absolute\
    \ path or a package:// address\n    shapes::Mesh* mesh = shapes::createMeshFromFilename(filename,\
    \ &scale);\n    \n    arm_navigation_msgs::Shape object;\n    if(!planning_environment::constructObjectMsg(mesh,\
    \ object)) {\n      ROS_WARN_STREAM(\"Object construction fails\");\n    }\n \
    \   delete mesh;\n    arm_navigation_msgs::CollisionObject collision_object;\n\
    \    collision_object.operation.operation = arm_navigation_msgs::CollisionObjectOperation::ADD;\n\
    \    collision_object.header.stamp = ros::Time::now();\n    collision_object.header.frame_id\
    \ = WORLD_FRAME_ID;\n    collision_object.id = \"my_object\";\n    collision_object.shapes.push_back(object);\n\
    \    //pose comes from elsewhere and must be set\n    geometry_msgs::Pose object_recognition_pose;\n\
    \    collision_object.poses.push_back(pose);\n    \n    //publish on /collision_object\
    \ topic\n    collision_object_publisher.publish(collision_object)"
