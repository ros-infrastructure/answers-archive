  body_markdown: "Here is a solution using Eigen.\n\nThe stamped poses (poseStamp_t1\
    \ and poseStamp_t2 in your notation) have a timestamp and a pose. The timestamps\
    \ can be saved to variables t1 and t2, such as t1 = poseStamp_t1.header.stamp.toSec().\
    \ \n\nThe poses can be converted to Eigen with the function tf::poseMsgToEigen\
    \ (const geometry_msgs::Pose &m, Eigen::Affine3d &e), obtaining Eigen:Affine poses\
    \ aff1 and aff2. From here, the rotation and the translation part can be interpolated\
    \ separately. Here is how:\n\n    // C++ code\n\n    #include <Eigen/Geometry>\n\
    \n    // Take poses at times t1 and t2. Interpolate the pose at time t.\n    Eigen::Affine3d\
    \ pose_interp(double t, double t1, double t2, \n                             \
    \   Eigen::Affine3d const& aff1, Eigen::Affine3d const& aff2) {\n      // assume\
    \ here t1 <= t <= t2\n      double alpha = 0.0;\n      if (t2 != t1)\n       \
    \ alpha = (t - t1) / (t2 - t1);\n    \n      Eigen::Quaternion<double> rot1(aff1.linear());\n\
    \      Eigen::Quaternion<double> rot2(aff2.linear());\n    \n      Eigen::Vector3d\
    \ trans1 = aff1.translation();\n      Eigen::Vector3d trans2 = aff2.translation();\n\
    \    \n      Eigen::Affine3d result;\n      result.translation() = (1.0 - alpha)\
    \ * trans1 + alpha * trans2;\n      result.linear()      = rot1.slerp(alpha, rot2).toRotationMatrix();\n\
    \    \n      return result;\n    }"
