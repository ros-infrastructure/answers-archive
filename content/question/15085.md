    \ So I am posting it here for others to benefit:\n\n1. Create a publisher that\
    \ publishes an empty message using std_msg::Empty\n2. On the ROS side create a\
    \ subscriber that listens to this topic lets say \"reset_world\"\n3. Upon hearing\
    \ the request the subscriber then calls a service that resets the gazebo world.\
    \ Below is the code for that service:\n\nstd_srvs::Empty empty_packet;\nif(resetworld_client.call(empty_packet))\n\
    {\n    ROS_INFO(\"Reset World);\n}\nelse\n{\n    ROS_INFO(\"Failed to reset the\
    \ world\");\n}\n\nAnd that's it. This particular code should be in the call back\
    \ function of the subscriber that you made in ROS."
