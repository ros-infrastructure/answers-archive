  body_markdown: "I finally find out about this.\n\nSo, basically...you just run this\
    \ command after `ign service -l` and then select one you wanted to use. For me,\
    \ I used `create`, so it would be `ignition.msgs.EntityFactory,`\n\nHow do I know\
    \ that it would be ignition.msgs.EntityFactory? Well, you type in terminal, `ign\
    \ service -is /world/free_world/create`\n\nand you get the output:\n\n    Service\
    \ providers [Address, Request Message Type, Response Message Type]:\n      tcp://172.17.0.1:40725,\
    \ ignition.msgs.EntityFactory, ignition.msgs.Boolean\n\nSo, it says `ignition.msgs.EntityFactory`,\
    \ go to [msg api](https://gazebosim.org/libs/msgs) (Use this since it gives you\
    \ the latest version) and then click api and tutorials. Replace `index.html` to\
    \ `EntityFactory.html` which is like [this](https://gazebosim.org/api/msgs/8.4/classignition_1_1msgs_1_1EntityFactory.html)\n\
    \nSo, you can see where extra arguments come from.\n\nSo as for `/world` commands,\
    \ I guess each end of the line is the command. In this case, I picked `create`\
    \ out of `/world/free_world/create`. \n\nMore information is at this: https://gazebosim.org/api/gazebo/6.9/entity_creation.html\n\
    \nNow we know how to work with ign service usage. "
