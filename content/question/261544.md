  body_markdown: "Publishers only publish when you actually call the `publish` method.\
    \ Note that in the [C++ Publisher example](http://wiki.ros.org/ROS/Tutorials/WritingPublisherSubscriber%28c%2B%2B%29)\
    \ they enter a while loop that sleeps for 1/10 seconds and then calls the `publish`\
    \ method. The last argument that you tried to change is [the queue_size](http://docs.ros.org/kinetic/api/roscpp/html/classros_1_1NodeHandle.html#a6b655c04f32c4c967d49799ff9312ac6).\n\
    \nHere's a slightly modified example from the aforementioned tutorial:\n\n   \
    \ #include \"ros/ros.h\"\n    #include \"geometry_msgs/Twist.h\"\n    \n    int\
    \ main(int argc, char **argv)\n    {\n    \tros::init(argc, argv, \"talker\");\n\
    \    \tros::NodeHandle n;\n    \n    \tros::Publisher velPub = n.advertise<geometry_msgs::Twist>(\"\
    /agv1/cmd_vel\", 1);\n    \tros::Rate loop_rate(20);\n    \n    \tgeometry_msgs::Twist\
    \ msg;\n    \twhile (ros::ok())\n    \t{\n    \t\tmsg.linear.x += 0.1;\n    \t\
    \tvelPub.publish(msg);\n    \t\tros::spinOnce();\n    \t\tloop_rate.sleep();\n\
    \    \t}\n    \treturn 0;\n    }\n\n"
