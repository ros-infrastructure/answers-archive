    roscore itself won't work as it uses roslaunch, which hasn't been ported to work with Windows processes.

    You can, however, run rosmaster manually, which is the heart of roscore.  You'll have to follow the instructions for [ROS Python on Windows](http://www.ros.org/wiki/cturtle/Installation/Windows) (same link that makokal pointed to).
