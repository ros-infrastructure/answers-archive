    The package [rosidl_parser](https://index.ros.org/p/rosidl_parser/github-ros2-rosidl/#dashing) has a few test idl files:


     - [MyAction.idl](https://github.com/ros2/rosidl/blob/dashing/rosidl_parser/test/action/MyAction.idl)
     - [MyMessage.idl](https://github.com/ros2/rosidl/blob/dashing/rosidl_parser/test/msg/MyMessage.idl)
     - [MyService.idl](https://github.com/ros2/rosidl/blob/dashing/rosidl_parser/test/srv/MyService.idl)

    The [documentation for rosidl_generate_interfaces](https://github.com/ros2/rosidl/blob/66f9a0e92962778edddc2ce6522ec259d7a76331/rosidl_cmake/cmake/rosidl_generate_interfaces.cmake#L24-L34) says IDL files can be passed directly to `rosidl_generate_interfaces()`. Internally all `.action`, `.msg`, and `.srv` are converted to `.idl` files before given to the code generators, so for more examples build a message package and look in the build directory for the generated files.

    The design page [IDL -Interface Definition and Language Mapping](http://design.ros2.org/articles/idl_interface_definition.html) documents the subset of OMG IDL 4.2 supported in Dashing.

[UPDATE2]

I was able to get it to build with a few modifications.  I had to remove the long double and wchar types as well as the includes.  I also had to change the top level module name to match my package name and the next level module name from 'msg' to 'idl'.  

    module idl_msgs{
      module idl {
    
    }
    }

That compiled and gave me a working message.  The updated code is available at: [https://github.com/davidhodo/idl_msgs.git](https://github.com/davidhodo/idl_msgs.git)
