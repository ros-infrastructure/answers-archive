  body_markdown: "The ROS Groovy release on Ubuntu Precise 12.04 uses Python 2.7,\
    \ which is the default interpreter for that system. \n\nPrecise also provides\
    \ Python 3.2, which you can install, but the ROS distribution was not built to\
    \ use that. It is probably possible to get it working by building everything from\
    \ source, but I do not recommend that approach. \n\nIf you are willing to use\
    \ Python 2, things will be much easier for now. Note that handling of bytes and\
    \ strings differs between Python 2 and Python 3. It is possible to write code\
    \ that works with either, but that gets tricky. Keep it simple until you have\
    \ something that works.\n\nFirst, you need to get comfortable with basic ROS programming\
    \ in Python. [This tutorial](http://www.ros.org/wiki/ROS/Tutorials/WritingPublisherSubscriber%28python%29)\
    \ will explain how to publish ROS messages. \n\nIt's a little hard to untangle\
    \ the code you posted. If you are new to Python: beware that indentation is significant\
    \ because it defines the block structure of your program. So, be careful.\n\n\
    You should not try to create two ROS nodes in that single script. You don't need\
    \ to, anyway, one node will suffice. Your main function will probably look more\
    \ like this:\n\n    rospy.init_node('ticks')\n    lpub = rospy.Publisher('lwheel',\
    \ Int16)\n    rpub = rospy.Publisher('rwheel', Int16)\n    hz_rate = rospy.Rate(80)\n\
    \    while not rospy.is_shutdown():\n        # read left encoder\n        lpub.publish(Int16(data=int(left)))\n\
    \        # read right encoder\n        rpub.publish(Int16(data=int(right)))\n\
    \        hz_rate.sleep()\n\nThat is just a simplified overview. Your actual logic\
    \ will be more complex."
