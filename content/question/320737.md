  body_markdown: "You need to set the routing table on the Raspberry pi OS. \nFor\
    \ an example, let's say the **Hokuyo** is connected via **eth0** with IP address\
    \ 10.0.0.5/24 and the IP address of the **Raspberri Pi** is 10.0.0.4/24. ROS communication\
    \ happens via wlan0 where the IP address  of the **remote PC** is 192.168.0.5/24\
    \ and the IP address of the **Raspberri Pi** is something like 192.168.0.4/24,\
    \ then you need to setup the routing table as follows. \n\n    sudo ip route add\
    \ 192.168.0.0/24 via 192.168.0.5 dev wlan0\n\n    sudo ip route add 10.0.0.0/24\
    \ via 10.0.0.5 dev eth0\n\nYou can check if the routing table is configured properly\
    \ using `ip route show` command. \n\nAfter setting the routing table, you can\
    \ confirm that it's configured properly by pinging `10.0.0.5` and `192.168.0.5`\
    \ **from** Raspberri Pi."
