  body_markdown: "You should look at this : [Which combination of ROS/Gazebo versions\
    \ to use](http://gazebosim.org/tutorials/?tut=ros_wrapper_versions).\n\nUnder\
    \ the default Gazebo version for each ros distribution section it states :\n\n\
    > Melodic\n> \n> ROS Melodic hosts or use the 9.x\n> version of Gazebo. For a\n\
    > fully-integrated ROS system, we\n> recommend using the 9.x version of\n> Gazebo.\
    \ The way to proceed is just to\n> use the ROS repository (it will\n> automatically\
    \ install gazebo9) and do\n> not use the osrfoundation repository.\n\nThis answer\
    \ your second question, the default version for melodic is Gazebo 9 not 8.\n\n\
    > Kinetic\n> \n> ROS Kinetic hosts or use the 7.x\n> version of Gazebo. For a\n\
    > fully-integrated ROS system, we\n> recommend using the 7.x version of\n> Gazebo.\
    \ The way to proceed is just to\n> use the ROS repository (it will\n> automatically\
    \ install gazebo7) and do\n> not use the osrfoundation repository.\n\nThere is\
    \ also a section about using another Gazebo version than the default one, you\
    \ can do that by [installing from the osrfoundation repository](http://gazebosim.org/tutorials?cat=install),\
    \ but don't miss the warning :\n\n> Warning!: Using this option, you won't\n>\
    \ be able to use any ROS Ubuntu package\n> related to Gazebo from ROS deb\n> repository.\
    \ The equivalent of\n> gazebo_ros_pkgs can be installed from\n> debian packages,\
    \ but all other\n> software (such as turtlebot_gazebo)\n> must be built from source.\n\
    \nThat means that it *could* work but you would have to build all the gazebo related\
    \ package from source and if a package has a compatibility issue you might not\
    \ be able to use it at all."
