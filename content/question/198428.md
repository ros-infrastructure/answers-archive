    You're doing so many things wrong.. I don't even..

     1. You don't state which version of ROS you're using or which OS you're using.
     1. Don't use rosbuild in a catkin workspace. At this point, almost all of ROS is using catkin; there shouldn't be any need to use rosbuild at all.
     1. Why are you checking out ros_comm from source? That's a pretty serious modification to ROS, and you don't give any reason for actually needing to do so. Downgrading the version of ros_comm that you're using to one from an older version of ROS is a highly likely to introduce bugs and incompatibilities.
     1. Groovy is no longer supported, You should probably be using a newer version of ROS.

    As stated on the [installation page](http://wiki.ros.org/hydro/Installation/Ubuntu#Installation-1), ROS packages are prefixed with `ros-` and the distro name. Try:

        sudo apt-get install ros-hydro-navigation

    Or, if you're still using Groovy:

        sudo apt-get install ros-groovy-navigation
