  body_markdown: "If you are using the unstable version of gazebo:\n\n    <light type=\"\
    spot\" name=\"spot\" cast_shadows=\"false\">\n      <origin pose=\"0 0 3 0 0 0\"\
    />\n      <diffuse rgba=\"0 1 0 1\"/>\n      <specular rgba=\".2 .2 .2 1\"/>\n\
    \      <attenuation range=\"10\" constant=\"0.2\" linear=\"0.01\" quadratic=\"\
    0.0\"/>\n      <direction xyz=\"0 0 -1\"/>\n      <spot inner_angle=\"0.1\" outer_angle=\"\
    0.5\" falloff=\"1.2\"/>\n    </light>\n\nif you are using Diamondback or Electric:\n\
    \n    <model:renderable name=\"spot\">\n      <xyz>0.0 0 3</xyz>\n      <static>true</static>\n\
    \n      <light>\n        <type>spot</type>\n        <direction>0 0 -1</direction>\n\
    \        <diffuseColor>0.0 0.0 1.0</diffuseColor>\n        <specularColor>0.0\
    \ 0.0 0.1</specularColor>\n        <attenuation>.1 0.0 0.0</attenuation>\n   \
    \     <range>5</range>\n        <spotCone>8.0 10.0 2.0</spotCone> \n      </light>\n\
    \    </model:renderable>"
