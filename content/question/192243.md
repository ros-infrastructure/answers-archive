    As a general rule of thumb, use the deb installation method.

    Only build from source if you want to modify or debug the package or if you need an urgent bug fix.

    If you need to install from source, clone the repository into your [catkin workspace](http://wiki.ros.org/catkin/Tutorials/create_a_workspace) source folder and do a catkin_make. Take care of the [dependencies](http://wiki.ros.org/rosdep).
