    Your ActionServer is a regular ros node. You must create a loop inside what you call goalCB(), and do all your "server work" inside that loop. You **must** sleep inside the loop, usually using a `ros::Rate` object. The SimpleActonServer tutorial shows you how to do this: [link](http://wiki.ros.org/actionlib_tutorials/Tutorials/SimpleActionServer(ExecuteCallbackMethod)#Writing_a_Simple_Server)

    ROS will check for preempt each time you call sleep() on the Rate object, so that will work fine.

My problem with this is the main function is not working (probably because I dont have another function with callback to call this function [expected for subscriber callback]). Anyone have done action server with no subscriber? any tips or suggestion?
