  body_markdown: "AFAIK, you can use three different types of mesh here:\n\n - .dae\
    \  (Collada)\n - .mesh (Ogre)\n - .stl\n\nI just used FreeCAD to convert the STEP\
    \ file into a STL file, and it worked great.\n\n\nThe meshes you specify in the\
    \ URDF are used in a number of places, such as visualization in RViz, and collision\
    \ avoidance. \n\nIt would be great to have some documentation about the \"officially\
    \ supported\" mesh types in the wiki. At the moment, this information is scattered\
    \ across a number of pages:\n\n - [RViz Mesh Resource Marker](http://www.ros.org/wiki/rviz/DisplayTypes/Marker#Mesh_Resource_.28MESH_RESOURCE.3D10.29_.5B1.1.2B-.5D)\n\
    \ - [URDF XML reference](http://www.ros.org/wiki/urdf/XML/Link#line-67)\n - [URDF\
    \ tutorial](http://www.ros.org/wiki/urdf/Tutorials/Building%20a%20Visual%20Robot%20Model%20with%20URDF%20from%20Scratch#line-231)\n\
