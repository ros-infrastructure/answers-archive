  body_markdown: "You have a package conflict at a lower level. You'll need to recursively\
    \ try each dependency which complains until you find the lowest level conflict\
    \ and resolve that. \n\napt-get is surprisingly unhelpful doing this. Each time\
    \ you get an error like that try to explicitly install each of the Depends entries,\
    \ until you find the problem when it gives a useful error message. \n\nYou can\
    \ use\n`sudo apt-get install -o Debug::pkgProblemResolver=yes <package>` to get\
    \ more details from apt. "
