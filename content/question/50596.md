  body_markdown: "If you're trying to connect the server computer from another client\
    \ computer. You can follow [this](http://www.ros.org/wiki/ROS/NetworkSetup)\n\n\
    First, assume that your server IP is [sIP], and client IP is [cIP]. Make sure\
    \ that you can ping [sIP] from your client computer. And then type :\n\n    export\
    \ ROS_HOSTNAME=[cIP]\n    export ROS_MASTER_URI=http://[sIP]:11311\nin the terminal\
    \ of the client computer.\n\nNow you can try :\n    \n    rostopic list\nor\n\n\
    \    rosnode list\nYou should be able to see the nodes and topics existing on\
    \ the server computer. And then you can do any operation as if in the same computer.\n\
    \nActionlib is some kind of technique that is similar to service but provides\
    \ more functions. It's widely used in arm navigation and controller as I know.\
    \ This might not related to your original need."
