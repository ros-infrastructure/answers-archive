    I guess in your case `move_group` is actually a `moveit::planning_interface::MoveGroupInterface`.
    This class is only a ROS-wrapper which sends a goal to a ROS action.

    If you want to debug the planning process you have to run the `move_group` node in gdb and set a breakpoint on the function that receives the action goal.
