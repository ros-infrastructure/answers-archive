  body_markdown: "The primary thing that happens when you source your catkin workspace's\
    \ `devel/setup.bash` file is that you are setting **environment variables**.\n\
    \nFor example, you'll notice a difference in many environment variables before\
    \ & after sourcing the setup file:\n\n  - ROS_PACKAGE_PATH: This tells ROS where\
    \ to find packages, so that `rosrun <pkg> <node>` actually works.\n  - CMAKE_PREFIX_PATH:\
    \ This tells the compiler a bunch of stuff, including where to find the libraries\
    \ defined in your package.\n  - LD_LIBRARY_PATH: This is used at execution time\
    \ to dynamically load shared libraries.\n  - PYTHONPATH: This tells python where\
    \ to look for any python modules defined in your package.\n\n(There are others,\
    \ there are just the important ones).\n\n\nAs an example, this is my ROS_PACKAGE_PATH\
    \ before and after sourcing the setup file in some random catkin workspace:\n\n\
    \    $ cd /path/to/my/catkin_ws\n    $ echo $ROS_PACKAGE_PATH \n    /opt/ros/indigo/share:/opt/ros/indigo/stacks\n\
    \    $ source devel/setup.bash\n    $ echo $ROS_PACKAGE_PATH\n    /path/to/my/catkin_ws/src:/opt/ros/indigo/share:/opt/ros/indigo/stacks\n\
    \nNote the addition of my catkin workspace's `src/` directory to the ROS_PACKAGE_PATH.\
    \ This enables me to run any nodes I have defined in my workspace, otherwise only\
    \ the system-installed packages are available. (Side note: `/opt/ros/<distro>/`\
    \ basically acts as one big catkin workspace too.)\n\nNormally, you always source\
    \ the *global* `/opt/ros/<distro>/setup.bash` every time you open a terminal because\
    \ it's in your `.bashrc` file. However, since new terminal sessions don't carry\
    \ over environment variables, you need to source **your** workspace's setup file\
    \ again each time you open a new session.\n\nIf you do not want to have to source\
    \ the workspace setup file yourself each time you open a new terminal, you can\
    \ always add it to your `.bashrc` file:\n\n    echo \"source /path/to/your/workspace/devel/setup.bash\"\
    \ >> ~/.bashrc\n\nObviously this only works if you have a single catkin workspace."
