    A lot of pieces in your error output comes from `moveit`, not `moveit_pr2` etc.
    Do you need to build MoveIt! from source? Then first make sure you follow [a tutorial](http://moveit.ros.org/install/source/). Otherwise, [binary is available on Kinetic for MoveIt!](http://repositories.ros.org/status_page/ros_kinetic_default.html?q=moveit) so you might want to use it.

    For errors for `moveit_pr2`, it most likely is not compatible with the Kinetic version of MoveIt! yet. [Someone is planning a port](https://github.com/ros-planning/moveit_pr2/issues/86) so you might be appreciated if you can contribute.
