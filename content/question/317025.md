  body_markdown: "Try this:\n\n<pre><code>    \n/* Adapted from pypose:\n * Simple\
    \ 3dof leg solver. X,Y,Z are the length from the Coxa rotate to the endpoint.\
    \ \n */\n\nikSolution_t calcLegIK(s32 X, s32 Y, s32 Z) \n{\n\n    ikSolution_t\
    \ ans;\n    s32 trueX;\n    s32 im;\n    float q1, q2;\n    s32 d1, d2;\n\n  \
    \  // first, make this a 2DOF problem... by solving coxa\n    ans.coxa = radToServo(atan2(X,Y));\n\
    \    trueX = sqrt(X*X + Y*Y) - COXA_LENGTH;\n    im = sqrt(trueX*trueX + Z*Z);\
    \    // length of imaginary leg\n\n    // get femur angle above horizon...\n \
    \   q1 = atan2(Z, trueX);\n    d1 = (FEMUR_LENGTH*FEMUR_LENGTH) - (TIBIA_LENGTH*TIBIA_LENGTH)\
    \ + (im*im);\n    d2 = 2 * FEMUR_LENGTH * im;\n    q2 = acos((float)d1/(float)d2);\n\
    \    ans.femur = radToServo(q1 + q2);\n\n    // and tibia angle from femur...\n\
    \    d1 = (FEMUR_LENGTH*FEMUR_LENGTH) - (im*im) + (TIBIA_LENGTH*TIBIA_LENGTH);\n\
    \    d2 = 2* TIBIA_LENGTH * FEMUR_LENGTH;\n    ans.tibia = radToServo(acos((float)d1/(float)d2)-1.57);\n\
    \n    return ans;\n}\n</code></pre>\nHTH"
