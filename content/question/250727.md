  body_markdown: "So my workaround for this was to find anywhere where **find_package(Eigen3\
    \ REQUIRED)** is included in **CMakeList.txt** in the src directory (In each package)\n\
    \nand replace with \n\n    set(CMAKE_MODULE_PATH ${PROJECT_SOURCE_DIR})\n    find_package(Eigen3\
    \ REQUIRED)\n    include_directories(${EIGEN3_INCLUDE_DIR})\n\nSecond, Find a\
    \ copy of the **FindEigen3.cmake** file and copy it to the same place as the **CMakeList.txt**.\
    \  I found it in another package."
