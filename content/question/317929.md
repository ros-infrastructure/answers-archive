  body_markdown: "I don't think the `~` expansion has been implemented, as the parameters\
    \ exist on the nodes directly, providing just the name of the parameter (without\
    \ `~`) should be enough.\n\ne.g.\nparams.yaml:\n\n    minimal_publisher:\n   \
    \     ros__parameters:\n            some_int: 42\n\ndiff on publisher_member_function:\n\
    \n    --- a/rclpy/topics/minimal_publisher/examples_rclpy_minimal_publisher/publisher_member_function.py\n\
    \    +++ b/rclpy/topics/minimal_publisher/examples_rclpy_minimal_publisher/publisher_member_function.py\n\
    \    @@ -33,6 +33,9 @@ class MinimalPublisher(Node):\n             self.publisher_.publish(msg)\n\
    \             self.get_logger().info('Publishing: \"%s\"' % msg.data)\n      \
    \       self.i += 1\n    +        print()\n    +        print(self.get_parameter('some_int')._value)\n\
    \    +        print()\n     \n     \n     def main(args=None):\n\nin terminal:\n\
    \n    $ ros2 run examples_rclpy_minimal_publisher publisher_member_function __params:=params.yaml\n\
    \    [INFO] [minimal_publisher]: Publishing: \"Hello World: 0\"\n    \n    42\n\
    \    \n    [INFO] [minimal_publisher]: Publishing: \"Hello World: 1\"\n    \n\
    \    42\n\nHTH,"

 I've followed the tutorial here on how to pass parameters to ROS2 nodes here:

https://index.ros.org/doc/ros2/Tutorials/Node-arguments/

I've made it to the point where the following command on my command line:

    ros2 run my_package my_node __params:=/path/to/params.yaml

produces the correct result, meaning I can see the parameters on the command-line output.

However, how would you retrieve those parameters from a python script?

I've tried the following:

    rclpy.init()
    node = rclpy.create_node("my_node")
    param = node.get_parameter('~param_from_yaml')
    print(str(param.value))

The output of that is always None. What am I doing wrong or can this even my achieved?
