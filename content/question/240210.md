  body_markdown: "Clearpath was able to assist me in solving this issue. Here are\
    \ some of the things which could help solve your issue:\n\nFirstly if you have\
    \ sixad installed when you received your jackal then that needs to be removed\
    \ using: sudo apt-get purge sixad \n\nUnpair the controller: sudo bluez-test-device\
    \ remove AC:FD:93:E2:C2:0A\n\nEnsure that bluetooth is enabled: connmanctl enable\
    \ bluetooth \n\nCheck to make sure bluetooth is enabled:    sudo service bluetooth\
    \ status\n\nIf bluetooth is not enabled start the bluetooth: sudo service bluetooth\
    \ start\n\nAlso make sure the bluetootd is executable: ls -la /usr/sbin/bluetoothd\
    \ \n\nIf not make it executable: sudo chmod +x /usr/sbin/bluetoothd\n\nRestart\
    \ the bluetooth: sudo service bluetooth restart \n\nFinally, press the PS and\
    \ share button simultaneously so the controller bluetooth is enabled for pairing\
    \ and type:\nsudo ds4drv-pair\n\nHopefully that helps!!"
