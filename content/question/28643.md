  body_markdown: "By browsing github I found out how to use the NavSat plugin (ignition-gazebo-navsat-system\
    \ if that was unclear).\nSo basically you have to do something like this if you\
    \ are using SDF: \n\n    <model name=\"NavSat\">\n      <pose>0 0 0.05 0 0.0 0</pose>\n\
    \      <link name=\"link\">\n        <inertial>\n          <mass>0.1</mass>\n\
    \          <inertia>\n            <ixx>0.000166667</ixx>\n            <iyy>0.000166667</iyy>\n\
    \            <izz>0.000166667</izz>\n          </inertia>\n        </inertial>\n\
    \n        <collision name=\"collision\">\n          <geometry>\n            <box>\n\
    \              <size>0.1 0.1 0.1</size>\n            </box>\n          </geometry>\n\
    \        </collision>\n        <visual name=\"visual\">\n          <geometry>\n\
    \            <box>\n              <size>0.1 0.1 0.1</size>\n            </box>\n\
    \          </geometry>\n        </visual>\n\n        <sensor name=\"navsat\" type=\"\
    navsat\">\n          <always_on>1</always_on>\n          <update_rate>1</update_rate>\n\
    \          <topic>navsat</topic>\n        </sensor>\n      </link>\n    </model>\n\
    \nFor this to work you also need to set the spherical coordinates for navsat.\
    \ I did this is in my world SDF file, and it looks like this: \n\n    <spherical_coordinates>\n\
    \      <surface_model>EARTH_WGS84</surface_model>\n      <world_frame_orientation>ENU</world_frame_orientation>\n\
    \      <latitude_deg>-22.986687</latitude_deg>\n      <longitude_deg>-43.202501</longitude_deg>\n\
    \      <elevation>0</elevation>\n      <heading_deg>0</heading_deg>\n    </spherical_coordinates>\n\
    \nHowever, I was not able this from an URDF file, which is what I want to do.\n\
    \nEDIT:\nIf you are using ROS2 you can call the service /world/world_name/set_spherical_coordinates\
    \ service from your launch.py file to set the spherical coordinates."
