  body_markdown: "You can install youbot_driver and its ros interface (on the youbot),\
    \ using:\n\n    sudo apt-get install ros-hydro-youbot-driver\n    sudo apt-get\
    \ install ros-hydro-youbot-driver-ros-interface\n\nThen, in order to run the keyboard\
    \ program, first you need youbot_driver running, which will listen and execute\
    \ the twist commands on the youbot:\n\n    roslaunch youbot_driver_ros_interface\
    \ youbot_driver.launch\n\n And then (in a new terminal) the keyboard tele-operation\
    \ program, which publishes those commands:\n\n    rosrun youbot_driver_ros_interface\
    \ youbot_keyboard_teleop.py\n\n It will then print on screen what keys you should\
    \ press.\n\n "
