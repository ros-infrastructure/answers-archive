    One option is to create a robot model from [KDLKinematics](http://wiki.ros.org/pykdl_utils) based on the URDF. This package can compute the Jacobian and mass matrix using the following functions from [here](https://github.com/gt-ros-pkg/hrl-kdl/blob/hydro/pykdl_utils/src/pykdl_utils/kdl_kinematics.py): jacobian() and inertia(). You would have to change the end_link when calling the KDLKinematics() function for calculating jacobian() and inertia() for different chains.
