I am able to run the multi robot scenario example from the gazebo_plugins ROS pkg (indigo-devel branch) without a problem. 

However, in the gui, there is no Model Link corresponding to the camera sensor as I would expect. All other links are shown, just not the plugin link. The camera sensor link _is_ published correctly in ROS.

Looking at the [camera.xacro](https://github.com/ros-simulation/gazebo_ros_pkgs/blob/hydro-devel/gazebo_plugins/test/multi_robot_scenario/xacro/camera/camera.xacro), the pattern (`link` tags followed by `gazebo` tags with the same name) seems to be the same as for those links which _do_ show as part of the robot model.

Anything I'm missing?
