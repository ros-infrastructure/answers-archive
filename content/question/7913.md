Hello everyone.

I am wondering if it is possible to check the collision state of a static model in Gazebo.

I have been simulating manipulator-style robots in Gazebo, and I have been able to monitor robot collision through the use of contact sensors mounted on each robot link. However, these contact sensors only seem to work during a dynamic simulation. 

What I would like to achieve is to test whether a robot is in a collision state when it's <static> SDF property is set to true. When the models are static, none of the gazebo.msgs.Contacts topics seem to be active.

If anyone is interested, I am trying to set up a robotic kinematic simulation, i.e all models in the world scene are static. A robot configuration is updated, and then collision testing is done. If collision free, we then increment the time step by one and update the robot configuration accordingly and test collision again. For this type of simulation, dynamic properties such as gravity are not needed. However I cannot seem to work out how to monitor collision for a static model.

Thanks for your help, any suggestions would be greatly appreciated!
