  body_markdown: " Hi,\n\nrtabmap regenerates the disparity image for visualization,\
    \ so ignoring the parameters you set for [stereo_image_proc](http://wiki.ros.org/stereo_image_proc).\
    \ If you want to use the disparity image generated from [stereo_image_proc](http://wiki.ros.org/stereo_image_proc),\
    \ I recommend to do something similar to [Stereo A setup](http://wiki.ros.org/rtabmap_ros/Tutorials/SetupOnYourRobot#Stereo_A)\
    \ by generating a depth image from the disparity image (with [rtabmap_ros/disparity_to_depth](http://wiki.ros.org/rtabmap_ros#rtabmap_ros.2BAC8-disparity_to_depth)\
    \ nodelet) and then use [rgbd_mapping.launch](https://github.com/introlab/rtabmap_ros/blob/master/launch/rgbd_mapping.launch)\
    \ instead of [stereo_mapping.launch](https://github.com/introlab/rtabmap_ros/blob/master/launch/stereo_mapping.launch).\n\
    \n    <group ns=\"/stereo_camera\" >\n    \t<node pkg=\"stereo_image_proc\" type=\"\
    stereo_image_proc\" name=\"stereo_image_proc\"/>\n      \t<node pkg=\"nodelet\"\
    \ type=\"nodelet\" name=\"disparity2depth\" args=\"standalone rtabmap_ros/disparity_to_depth\"\
    />\n    </group>\n\nLaunch:\n\n    $ roslaunch rtabmap_ros rgbd_mapping.launch\
    \ rgb_topic:=/stereo_camera/left/image_rect_color depth_registered_topic:=/stereo_camera/depth\
    \ camera_info_topic:=/stereo_camera/left/camera_info rtabmap_args:=\"--delete_db_on_start\"\
    \n\nNote that the next rtabmap version will have [mostly the same parameters](https://github.com/introlab/rtabmap/blob/be559c181a7b46119438170f8a52d0b747d2d2a4/corelib/include/rtabmap/core/Parameters.h#L437-L445)\
    \ as stereo_image_proc to tune the regenerated disparity image."
