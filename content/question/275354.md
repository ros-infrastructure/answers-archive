  body_markdown: "I know what you're talking about - in the turtlebot demo environment,\
    \ when I drive into the white cube, the encounter pushes the cube away from the\
    \ robot.  When I run into the bookshelf, the bookshelf doesn't move.  \n\nYou\
    \ could use the gazebo service \"get_model_state\" to poll the pose of the model\
    \ you're running into (cube, bookshelf, etc.) and see if its coordinates are changing\
    \ over time (or, if you don't know which object you're running into, poll all\
    \ of the simulation's models and see if any of the models' poses are changing).\
    \  If there's no pose change, it's an object that's too heavy to be moved.  If\
    \ there's a pose change in the object model, you're able to push it.\nhttp://wiki.ros.org/gazebo"
