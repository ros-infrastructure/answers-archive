  body_markdown: "I had the same problem myself. What i found is that there are 2\
    \ packages,\n\n 1. `python-rosdistro`\n 2. `python-rosdistro-modules`\n\nthat\
    \ were recently updated. These updates can only be installed with dpkg version\
    \ 1.18 and above. \nThis version is not supported by 14.04 and does not install.\
    \ \nI have installed it in the snapdragon flight platform using the following\
    \ steps \n\n\n#Change dpkg to 1.18.4\nSince i am using the snapdragon flight platform\
    \ i am downloading the armhf build. Download the correct version for your CPU\
    \ arch\n \n\n    wget http://ports.ubuntu.com/ubuntu-ports/pool/main/d/dpkg/dpkg_1.18.4ubuntu1_armhf.deb\n\
    \    \n    wget http://ports.ubuntu.com/ubuntu-ports/pool/main/libs/libselinux/libselinux1_2.4-3build2_armhf.deb\n\
    \nHere we download dpkg1.18.4 and its dependancy and manually install them \n\n\
    \    sudo dpkg -i libselinux1_2.4-3build2_armhf.deb\n    \n    sudo dpkg --auto-deconfigure\
    \ -i dpkg_1.18.4ubuntu1_armhf.deb\n    \n    sudo apt-get -y -f install\n\nThen\
    \ we install the necessary package \n\n    sudo apt-get update\n    \n    sudo\
    \ apt-get -y install python-rosdistro\n\nInstalling `python-rosdistro` automatically\
    \ installs `python-rosdistro-modules` package as well\n\n\nThen we install apptitude\
    \ to install ros\n\n    sudo apt-get -y install aptitude\n    \n    sudo aptitude\
    \ install ros-indigo-ros-base\n\nWhile installing ROS apptitude will show there\
    \ is system dependancy errors and give you options the order of commands are\n\
    \n1. No (n)\n2. No (n)\n3. Yes (Y)\n4. Yes (Y)\n\nIf you follow this, then you\
    \ will downgrade dpkg back to the old supported version and everything will go\
    \ back to normal. I have only done this in a fresh install of ubuntu."
