    \ command is `sudo cp`.\n\n - The command should be like that:\n \n**sudo cp /path\
    \ of the file where your file exists   /path of file where you want to transfer\
    \ your file**\n\n - For example:\n\n> sudo cp\n> /home/eman/Downloads/my_robot.urdf\n\
    > /opt/ros/hydro/share/urdf_tutorial\n\nwhere **/home/eman/Downloads/my_robot.urdf**\
    \ is the path where the urdf_file ( my_robot.urdf ) exists and **/opt/ros/hydro/share/urdf_tutorial**\
    \ is the path where I want to transfer this file.\n\n  When I used this command,it\
