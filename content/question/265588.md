    I needed to export the `LD_LIBRARY_PATH` accordingly so that the source install version is used. If you build gazebo in a catkin workspace then sourcing the workspace setup file should take care of the paths.
    I added this line to .bashrc in order to use he source compiled one:

        LD_LIBRARY_PATH=$LD_LIBRARY_PATH:/usr/local/lib
