  body_markdown: "Short Answer:\n\nexport LD_PRELOAD=/opt/ros/groovy/lib/libimage_transport.so\n\
    \n(or your path to the .so file)\n\n\nLong Answer:\n\nThere seems to be a bug\
    \ in the Python-based dynamical loading system.\n\nSay you create a library \u201C\
    foo\u201D that (includes and) links to image_transport.\n\nNow you create an executable\
    \ \u201Cbar\u201D, that links dynamically to foo.so. So far no problem.\n\nbut.,\n\
    \nif you create an executable \u201Cbaz\u201D, that uses dynamical loading and\
    \ unloading of libraries\n\n...\n\nlib_handle = dlopen(\"/path/to/foo.so\", RTLD_LAZY);\n\
    \n...\nit will throw exactly this error, unless you do the workaround with preloading.\n\
    \nMaybe your problem is related to this."
