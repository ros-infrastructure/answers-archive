  body_markdown: "Hi,\n\nYes, we can use rtabmap without a camera, but global loop\
    \ closure detection will be disabled (local proximity detection still work though,\
    \ so small loop closures can be detected). **EDIT** rtabmap 0.19 minimum required.\
    \ Currently, rtabmap binaries are at 0.17.6, we should build `rtabmap/rtabmap_ros`\
    \ from [source](https://github.com/introlab/rtabmap_ros#build-from-source).\n\n\
    Here is an example following mostly the [first setup example](http://wiki.ros.org/rtabmap_ros/Tutorials/SetupOnYourRobot#Kinect_.2B-_Odometry_.2B-_2D_laser)\
    \ but without subscribing to camera:\n\n    <launch>\n      <param name=\"use_sim_time\"\
    \ value=\"true\"/> <!-- only with rosbag -->\n      \n      <group ns=\"rtabmap\"\
    >\n        <node pkg=\"rtabmap_ros\" type=\"rtabmap\" name=\"rtabmap\" output=\"\
    screen\" args=\"-d\">\n          <param name=\"subscribe_scan\"   value=\"true\"\
    />\n          <param name=\"subscribe_rgb\"    value=\"false\"/>\n          <param\
    \ name=\"subscribe_depth\"  value=\"false\"/>\n          <param name=\"frame_id\"\
    \         value=\"base_link\"/>\n          <param name=\"odom_frame_id\"    value=\"\
    odom\"/>\n          <param name=\"wait_for_transform_duration\"  value=\"1\"/>\n\
    \          <param name=\"odom_tf_linear_variance\"  value=\"0.01\"/>\n       \
    \   <param name=\"odom_tf_angular_variance\" value=\"0.05\"/>\n    \n        \
    \  <!-- RTAB-Map parameters -->\n          <param name=\"Reg/Strategy\"      \
    \        value=\"1\"/>    <!-- 1 for lidar -->\n          <param name=\"Reg/Force3DoF\"\
    \             value=\"true\"/> <!-- 2d slam -->\n          <param name=\"RGBD/NeighborLinkRefining\"\
    \ value=\"true\"/> <!-- odometry correction with scans -->\n          \n     \
    \     <remap from=\"scan\"    to=\"/scan\"/>\n        </node>\n    \n        <!--\
    \ just for visualization -->\n        <node pkg=\"rtabmap_ros\" type=\"rtabmapviz\"\
    \ name=\"rtabmapviz\" output=\"screen\"/>\n      </group>\n    </launch>\n\nExample\
    \ based on the rosbag of your other [post](https://answers.ros.org/question/321676/tuning-gmapping-parameters-or-alternative-slam-algorithm/):\n\
    \n    $ roslaunch test.launch\n    $ rosbag play --clock -s 20 realoguz5.bag\n\
    \nTo avoid warnings about two `map` frames published (one from the bag and the\
    \ other one from rtabmap), we can remove the `map` frame from the bag using this\
    \ [script](http://official-rtab-map-forum.67519.x6.nabble.com/Removing-all-map-frames-from-a-rosbag-td660.html).\
    \ Note also that in general `wait_for_transform_duration` would be lower, but\
    \ this bag seems to have some TF and topic stamps synchronization latency.\n\n\
    ![image description](https://ftp.osuosl.org/pub/ros/download.ros.org/downloads/se_migration/ros/1556326386755446.png)\n\
    \ncheers,</br>\nMathieu"
