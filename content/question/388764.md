  body_markdown: "I found a solution that worked for me. The problem are different\
    \ rmw_fastrtps versions.  \nProbably Dolly is built with a different version as\
    \ your normal ros2 foxy system.  \nTo check your available version do:\n\n   \
    \ ros2 doctor --report | grep fastrtps\n\nThe newest version for Ubuntu 20.04\
    \ and ROS2 Foxy should be:\n\n    rmw_fastrtps_shared_cpp = 1.3.1\n    rmw_fastrtps_cpp\
    \ = 1.3.1\n\nThis bug fix removes the problem: [commit](https://github.com/ros2/rmw_fastrtps/commit/1527f091d3ce1b64fcc0f352a0be17a13cd6ef16)\
    \  \nBut you have to install it on every system.\n\nTo update these packages either\
    \ do separate:\n\n    sudo apt update &&  sudo apt install ros-foxy-rmw-fastrtps-cpp\
    \ ros-foxy-rmw-fastrtps-shared-cpp\n\nor update all old packages with:\n\n   \
    \ apt update && apt  dist-upgrade\n\nA restart is required after you already encountered\
    \ the error once!"
