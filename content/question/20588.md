  body_markdown: "As far as I know, there is no way to actually prevent the element\
    \ from moving if you translate/rotate it yourself. There's the static tag which\
    \ makes the model static when affected by other objects/forces but does not prevent\
    \ you from moving the model yourself. \n\nI suggest keeping the cursor in select\
    \ mode at all times (unless of course you need to move something) to avoid accidentally\
    \ moving your static models."
