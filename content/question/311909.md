  body_markdown: "Everything that I can see happening is what we would expect.\n\n\
    In your first picture the fixed TF frame chosen in RVIZ \"map\" does not exist.\
    \ Because of this RVIZ cannot work out where the links of the robot are so it\
    \ shows them at the origin by default. This is why they appear jumbled up on top\
    \ of each other.\n\nAs you've found out if you select the base_link (or any other\
    \ link of the robot) this this will be fixed and you'll see your robot correctly\
    \ in RVIZ. I'm not sure what you mean by \n\n> but it isn enter the focus which\
    \ have yellow color\n\nThe yellow dot is simply the focal point of the camera,\
    \ which can be dragged around with the mouse to change the view in RVIZ.\n\nFinally\
    \ regarding Meshlab as far as I know this will only open simple mesh dae files.\
    \ A dae file with a kinematic structure will just be shown with each individual\
    \ mesh at the origin similar to the original view in RVIZ. In fact how could it\
    \ view the arm you haven't told it what joint positions it has?\n\nOverall image\
    \ two shows everything working correctly as we would expect. Hope this helps."
