  body_markdown: "Solved! \n\nThe issue was trying to install the windows debug package:\
    \ `ros2-galactic-20210616-windows-debug-amd64.zip`\nrather than the release package:\
    \ `ros2-galactic-20210616-windows-release-amd64.zip`. \n\nAfter installing the\
    \ release package and trying to run `ros2`, the only error received was a missing\
    \ python library `packaging`. This should probably be added to the current `python`\
    \ dependencies list. \n\nThis is what is currently on the site for `python` dependencies\
    \ (https://docs.ros.org/en/galactic/Installation/Windows-Install-Binary.html#install-dependencies):\n\
    \n    python -m pip install -U catkin_pkg cryptography empy ifcfg importlib-metadata\
    \ lark-parser lxml matplotlib netifaces numpy opencv-python PyQt5 pip pillow psutil\
    \ pycairo pydot pyparsing pyyaml rosdistro setuptools\n\nShould instead be:\n\n\
    \    python -m pip install -U catkin_pkg cryptography empy ifcfg importlib-metadata\
    \ lark-parser lxml matplotlib netifaces numpy opencv-python PyQt5 pip pillow psutil\
    \ pycairo pydot pyparsing pyyaml rosdistro setuptools packaging\n\nWould also\
    \ recommend adding a line above this install dependencies section to recommend\
    \ that people first upgrade pip. Python dependency installation (e.g. crytography,\
    \ etc.) errors out if pip is not up to date. \n\n    python -m pip install -U\
    \ pip"
