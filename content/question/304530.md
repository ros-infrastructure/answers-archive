  body_markdown: "**TL;DR**\n-----\n\n You can delete your old catkin workspace folder\
    \ and remove possible references for its previous `devel/setup.bash`.\n\n**Informational\
    \ answer**\n------------------------\n\nThe command `catkin clean` only clean\
    \ the files generated by catkin build.\n\nA catkin workspace is a folder. It contains\
    \ a `src` folder with some ROS packages inside. There can exist multiple workspaces\
    \ with different names, but only one is usually activated.\n\nTo activate a workspace,\
    \ you need to init and build  it first, generating the folders `devel` and `build`.\
    \  Then, you need to source the `setup.bash`.\n\nIf you want to know which workspace\
    \ is activated at the moment, you can check the first folder from command\n\n\
    \    echo $ROS_PACKAGE_PATH\n\nYou can find examples of workflow at [catkin-tools](https://catkin-tools.readthedocs.io/en/latest/quick_start.html)\
    \ website. It seems complicated at first, but soon you will get the hang of it\
    \ ;) \n\nCheers,\n\n"
