  body_markdown: "This is known as X11 Fowarding and you can setup your ssh to allow\
    \ X11 forwarding. You will first want to confirm X11 forwarding is enabled on\
    \ both the client and host computer:\n\nFor the client edit `/etc/ssh/sshd_config`:\n\
    \n    X11Fowarding yes\n    X11UseLocalhost no\n\nFor the host edit `/etc/ssh/ssh_config`:\n\
    \n    FowardX11 yes\n    FowardX11Trusted yes\n\nAfter this you can connect from\
    \ the client to the host with the following ssh flag\n\n    ssh -X -p SOME_PORT\
    \ user@server\n\nThe `-X` flag does the magic here, you can test this by running\
    \ a sample X application on the host computer such as `xclock` and it should run\
    \ on your local system \n"
