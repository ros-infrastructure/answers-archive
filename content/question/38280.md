    You need to either use a static_transform_publisher as [this tutorial](http://ros.org/wiki/navigation/Tutorials/RobotSetup/TF) shows or create a URDF file as [these tutorials](http://ros.org/wiki/urdf/Tutorials) show.

    **Edit**: You can find the documentation for static_transform_publisherer [here](http://ros.org/wiki/tf#static_transform_publisher). The numbers specify the position of your sensor in the robot's base, format is x, y, z, yaw, pitch, roll.

    <launch>
    	<!-- publish the static transform from the center of the robot to the laser rangefinder (required for slam_gmapping) -->
    	<node pkg="tf" type="static_transform_publisher" name="base_link_to_laser" args="0 0.1778 0 0 0 0 base_link laser 100" />
    </launch>
