  body_markdown: "You have 2 steps to figure out this problem :\n\nFirst is to go\
    \ to your `Xacro` files which are in your `robot_description` package and for\
    \ each one of them type this command at the Terminal :\n\n\" `rosrun xacro xacro\
    \ [filename.xacro/filename.urdf.xacro]` \"\n\nThen you can find out where is the\
    \ problem comes from.\n\nAnd the second step is to go to this site\n\n \" http://wiki.ros.org/xacro\
    \ \" \n\nAnd read about the new changes to convert your file and resolve the problem.\n\
    \nGood luck"
