  body_markdown: "My suggestion is to modify sdf file. Adding a sensor is fairly straightforward:\n\
    \n    <include>\n      <uri>model://<sensor></uri>\n      <pose>0.2 0 0.2 0 0\
    \ 0</pose>\n    </include>\n    <joint name=\"<sensor>_joint\" type=\"fixed\"\
    >\n      <child><sensor>::link</child>\n      <parent>chassis</parent>\n    </joint>\n\
    \nReplace <sensor> with your sensor. Make sure to create a joint that connects\
    \ the sensor link to the chassis or wherever you need to. \n\n"
