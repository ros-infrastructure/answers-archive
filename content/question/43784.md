  body_markdown: |
    Never create packages in /opt/ros nor use sudo for compiling packages.

    On the desktop, you need to create an [overlay](http://www.ros.org/wiki/fuerte/Installation/Overlays). Then copy the package containing your custom messages into it. If you copied the build directory in your package, too, you will run into compiler errors because the paths have changed. In that case, all you need to do is call `rosmake --pre-clean <your package>` to make sure that the old build directories are all removed.
