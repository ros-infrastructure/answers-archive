  body_markdown: "i have the bumblebee2 stereo camera working with the bumblebee2\
    \ node.\n\n1. ubuntu 10.04\n2. ros-diamondback-desktop-full\n3. just the dependencies\
    \ for the bumblebee2 node\n4. bumblebee2(http://www.ros.org/browse/details.php?name=bumblebee2)\n\
    5. the first change i made is shown in this answer(http://answers.ros.org/question/1096/segmentation-fault-of-bumblebee2?answer=1891#1891).\n\
    beside that i had to edit the file: \"dev_camera1394.cpp\"\nto use format_7 mode_3.\
    \ to do this search the file for: \"dc1394_video_set_mode\" and replace: \"videoMode_\"\
    \ with \"DC1394_VIDEO_MODE_FORMAT7_3\"\n\nafter that i had quite a bit of trouble\
    \ with the image tearing. this was caused by my firewire port being unable to\
    \ handle the trafic. to fix this i had to reduce the package size by adding the\
    \ following lines: \n\n> if (DC1394_SUCCESS !=\n> dc1394_format7_set_packet_size(camera_,DC1394_VIDEO_MODE_FORMAT7_3,*size*))\
    \ {\n>     ROS_WARN(\"Failed to set package size\");\n>     DMA_Success = false;\
    \ \n>}\n\nthe package size you need to set can be found by running the node than\
    \ reduce the package size using coriander(can be found in the controls tab)\n\n\
    if you dont need to get both the images from the bumblebee2 camera you only have\
    \ to make the changes in the other ros answer."
