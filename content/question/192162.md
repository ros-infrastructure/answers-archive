    All `openni_tracker` really does is send the transforms from the Kinect's `camera_depth_optical_frame` to each of the joints on the users using [tf](http://wiki.ros.org/tf). It would be pretty easy to write a simple program to do this using artificial values. Another nice alternative would be to obtain a bag file of recorded `openni_tracker` transforms. Then you could simply play that data back to simulate the data. I could make you a bag file of just `/tf` data using `openni_tracker` if you needed.
