  body_markdown: "If I see correctly, your Eclipse does not recognize ros libraries.\
    \ Follow these steps to install the Kepler Eclipse and then do a cmake compilation\
    \ in order to make it recognisable.\n\n1) http://www.eclipse.org/downloads/ From\
    \ the eclipse page, scroll down to C/C++ for Developers and download it. Then\
    \ untar it and copy it into /opt folder.\n\n2) Start eclipse by command \n\n \
    \   /opt/eclipse/./eclipse\n\n3) If it complaints for java, install openjdk-7-jre.\n\
    \n4) Now go right to your catkin workspace and create a ros package\n\n    roscreate-pkg\
    \ my_pkg_example roscpp\n\n5) Make it eclipse project\n\n    cd ~/catkin_ws/src/my_pkg_example/\n\
    \    make eclipse-project\n\n6) Now, go ahead and create the file src/myfile.cpp\
    \ and edit cmake by adding something like this to the default cmake (Assuming\
    \ your executable is in src directory)\n\n    rosbuild_add_executable(my_pkg_example\
    \ src/myfile.cpp)\n\n7) On the terminal type\n\n    cd ~/catkin_ws/src/my_pkg_example/\n\
    \    cmake .\n    make\n\n8) The last thing to do now is to go to Eclipse and\
    \ Project > Run & Debug Settings (or something like this I don't remember). Add\
    \ C/C++ Application. Select binary file which is ~/catkin_ws/src/my_pkg_example/bin/my_pkg_example.\
    \ Then hit Apply.\n\nNow your file should be correct."
