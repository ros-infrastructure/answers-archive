 Recently, when I was learning how to use catkin_make to build a ROS node, I find that some ROS package (eg tf, roscpp, std_msgs) are belongs to catkin COMPONENTS in <code>find_package()</code>.
For example
<code>
find_package(catkin REQUIRED COMPONENTS
  roscpp
  rospy
  std_msgs
  message_generation
  turtlesim
)
</code><br>
But if I use <code>find_package(catkin REQUIRED</code>, it also can give a correct directory of turtlesim.
<br>
And also in <code>catkin_package()</code>, those packages are CATKIN_DEPENDS.<br>
So I wonder do all ROS packages belong to catkin packages, And what's the different between <code>find_package(catkin REQUIRED</code> and  <code>find_package(catkin REQUIRED COMPONENTS turtlesim)</code>
