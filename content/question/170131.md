    If you don't need obstacle avoidance you can use the navigation stack without a map and without a laser scanner (We've used the configuration based on the [pr2_navigation_apps](http://wiki.ros.org/pr2_2dnav_local)). You just need to remove the base_scan sources for the costmaps.

    You may still need to use a localization package to provide the estimated position of the robot. We used the [robot_localization](http://wiki.ros.org/robot_localization) package and it worked really well.

    Hope it helps!
