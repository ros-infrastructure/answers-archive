  body_markdown: "To load your nodelets you **must** have loaded a nodelet manager\
    \ first.\n\n - Using command lines :\n\nLoad the `nodelet_manager` (you can put\
    \ the name you want but make sure all your nodelets use the same manager)\n\n\
    `rosrun nodelet nodelet manager __name:=nodelet_manager`\n\nThen you can load\
    \ your nodelets (again replace nodelet_manager with the name you chose previously),\
    \ if you have two nodelets you have to run :\n\n    rosrun nodelet nodelet load\
    \ PACKAGE_OF_YOUR_NODELET/NODELET1 nodelet_manager\n    rosrun nodelet nodelet\
    \ load PACKAGE_OF_YOUR_NODELET/NODELET2 nodelet_manager\n\n - Using launch file\
    \ :\n\n    < node pkg=\"nodelet\" type=\"nodelet\" name=\"nodelet_manager\" args=\"\
    manager\"/>\n    \n    < node pkg=\"nodelet\" type=\"nodelet\" name=\"NODELET1\"\
    \n        args=\"load PACKAGE_OF_YOUR_NODELET/NODELET1 nodelet_manager\">\n  \
    \  < /node>\n    \n    < node pkg=\"nodelet\" type=\"nodelet\" name=\"NODELET2\"\
    \n        args=\"load PACKAGE_OF_YOUR_NODELET/NODELET2 nodelet_manager\">\n  \
    \   < /node>\n\nYou can also set a parameter or remap some topics as in the tutorial.\n\
    I personnaly prefer to use launch files.\n\n\nBut always remember that the nodelet\
    \ manager is mandatory here and if by mistake you load your nodelets in two different\
    \ `nodelet_manager` you will lose the specificity of the nodelets and they will\
    \ have the same behavior as a node."
