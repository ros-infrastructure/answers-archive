  body_markdown: "Here is a way,\n\n 1. install this [robot_pose_publisher](http://wiki.ros.org/robot_pose_publisher)\n\
    \ 2. rosrun robot_pose_publisher robot_pose_publisher.\n 3. write a subscriber\
    \ for the topic '/robot_pose' with following callback_function.\n`\n\n       \
    \ import rospy\n        from rospy import logdebug\n        from geometry_msgs.msg\
    \ import Pose\n\n        def get_tf_pose_callback(pose):\n              logdebug(\"\
    robot is at : {0}\".format(pose.position))\n        \n        if __name__ == '__main__':\n\
    \              rospy.Subscriber(\"robot_pose\", Pose, get_tf_pose_callback)\n\
    \              rospy.spin()\n\n\n`\n 4. rosrun your node.\n\n"
