  body_markdown: "The roscore will start the node /rosout (can see in the $ROS_ETC_DIR/roscore.xml).\n\
    This node will forward all the messages in topic /rosout to the topic  /rosout_agg.\n\
    \nAnd the rqt_console will subscribe the /rosout_agg and show all the messages.\n\
    \nAnd the command `rosbag record -a` will record both /rosout and /rosout_agg\
    \ in the bag.\nWhen you play it, the node /rosout will forward the topic /rosout\
    \ to topic /rosout_agg again.\nThen you will have duplicated messages in the /rosout_agg,\
    \ of course, in the rqt_console.\n\nTo solve this,\n\n1) you can exclude the topic\
    \ `rosout_agg` when you record the bag;\n\n2) you can create a new roscore.xml\
    \ without the node /rosout, and update the $ROS_ETC_DIR to use this new config\
    \ when you play the bag; "
