    You can do this using the [rosbag API](http://wiki.ros.org/rosbag/Code%20API) but it's not the easiest thing in the world, there are a range of [examples here](http://wiki.ros.org/rosbag/Cookbook). If you back file only contains one or a small number of topics then you can hard code those in.

  body_markdown: "The rosbag player provides a [`pause_playback` service](https://github.com/ros/ros_comm/blob/d487d5877049d61fe2ebcc6487e9a7a72d9f0346/tools/rosbag/src/player.cpp#L121)\
    \ of type `std_srvs/SetBool`.\n\nSince the `play` will be started as anonymous\
    \ node, the service will be available as `/play_<unique_number>/pause_playback`.\n\
    \nTo pause the playback, call the service with `data: true`:\n\n    rosservice\
    \ call /play_<unique_number>/pause_playback \"data: true\" \n    success: True\n\
    \    message: \"Playback is now paused\"\n\nand to un-pause, with `data: false`:\n\
    \n    rosservice call /play_<unique_number>/pause_playback \"data: false\" \n\
    \    success: True\n    message: \"Playback is now resumed\""
