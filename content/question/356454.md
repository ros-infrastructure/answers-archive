- body_markdown: |-
    > tried to set the Laptop ROS_IP/ROS_HOSTNAME to either local IP or RasPi IP but not fixing the problem

    Set `ROS_IP` to the IP of the host. Do not set it to IPs of other computers. That would make no sense.

    Set `ROS_MASTER_URI` to `http://ip.of.rasb.pi:11311` on both machines.

    Make sure to do this *in every new terminal*, or add it to your `.bashrc`.

    Do not set `ROS_HOSTNAME` to IPs. Only use it if you have a working DNS which resolves both your laptop's hostname *and* the Pi's. Do not set both `ROS_IP` and `ROS_HOSTNAME`.
