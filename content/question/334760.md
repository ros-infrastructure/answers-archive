    \ each time you call the function. Knowing that a subscriber takes time to register\
    \ to a topic if you needed to get messages that are published at high rate you\
    \ would lose a lot of data.\n\nFinally your loop as it is wouldn't allow to add\
    \ `ros::spinOnce()` to be called at some rate because of the `cin`. Because of\
    \ `cin` your program is blocked (meaning the callback too) until you input something.\
    \ As soon as you do you start again your loop where you create a new obect and\
    \ also a new subscriber, thus a new callback so the previous message (if there\
