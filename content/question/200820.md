    \nThis indicates sourcing `devel/setup.bash` did not work as expected. `ROS_PACKAGE_PATH`\
    \ must contain the path of your catkin workspace in order for your executables\
    \ to be found by ROS.\n\nI just added a passage to the [create catkin workspace\
    \ tutorial](http://wiki.ros.org/ROS/Tutorials/InstallingandConfiguringROSEnvironment#Create_a_ROS_Workspace).\
    \ \n\n    To make sure your workspace is properly overlayed by the setup script,\
    \ make sure ROS_PACKAGE_PATH environment variable includes the directory you're\
    \ in.\n\n        $ echo $ROS_PACKAGE_PATH\n        /home/youruser/catkin_ws/src:/opt/ros/indigo/share:/opt/ros/indigo/stacks\n\
    \nSo in your case, I suggest to make sure you build and source properly. You can\
    \ try again by removing the built artifact (see [Cleaning up](http://wiki.ros.org/catkin/Tutorials/using_a_workspace#Cleaning_up))\
    \ and run `catkin_make`, and source the setup."
