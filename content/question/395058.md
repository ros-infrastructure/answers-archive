  body_markdown: "What you are looking to use are launch arguments (arg tags) and\
    \ not parameters (param tags). [Here is a link to the roslaunch arg tags](http://wiki.ros.org/roslaunch/XML/arg).\n\
    \nBasically, what you are trying to do is add an argument to your higher level\
    \ launch file that you pass down. [Here is a decent guide on them for more detail](https://campus-rover.gitbook.io/lab-notebook/faq/using-args-params-roslaunch).\n\
    \nThe answer to the question you link uses bash (command line) to generate a random\
    \ number and pass it as a launch argument to their launch file. How it would look\
    \ like for you:\n\nHigh level launch file:\n\n      <launch>\n      ... other\
    \ args ...\n      <arg name=\"x\" default=\"0\"/>\n      <arg name=\"y\" default=\"\
    0\"/>\n      <arg name=\"z\" default=\"3\"/>\n\n     ... empty world include ...\n\
    \    \n      <group ns=\"$(arg mav_name)\">\n        <include file=\"$(find rotors_gazebo)/launch/spawn_mav.launch\"\
    >\n          <arg name=\"mav_name\" value=\"$(arg mav_name)\" />\n          <arg\
    \ name=\"model\" value=\"$(find rotors_description)/urdf/$(arg mav_name)_base.xacro\"\
    \ />\n          <arg name=\"enable_logging\" value=\"$(arg enable_logging)\" />\n\
    \          <arg name=\"enable_ground_truth\" value=\"$(arg enable_ground_truth)\"\
    \ />\n          <arg name=\"log_file\" value=\"$(arg log_file)\"/>\n         \
    \ <arg name=\"x\" value=\"$(arg x)\"/>\n          <arg name=\"y\" value=\"$(arg\
    \ y)\"/>\n          <arg name=\"z\" value=\"$(arg z)\"/>\n        </include>\n\
    \      </group>\n    </launch>\n\nAnd then after that, since the arguments are\
    \ already in the `spawn_mav.launch` file, you just need to call roslaunch.\n\n\
    \    roslaunch package file.launch x:=1 y:=2 z:=3\n\nThis will spawn the robot\
    \ at 1,2,3. Change the input as you see fit. \n\nAs described in the other question\
    \ you link, you can randomize it based on some bash input.\nThe comments for the\
    \ answer mention [the roslaunch Python API](http://wiki.ros.org/roslaunch/API%20Usage).\
    \ I have not used it, but might be worth exploring to generate the random numbers\
    \ with Python.\n\n"
