    ROS is an inherently distributed network system. You can run nodes on any computer attached to the network containing your robot as long as the ROS network parameters are setup correctly. See [this page](http://wiki.ros.org/ROS/NetworkSetup) for details of setting this up. As long as the computers have a network connection then you can swap processing nodes between computers as you need.

    Is your turtle bot attached to a Wi-Fi network in your current setup? It is common for people to use a laptop or desktop with a wireless network to view sensors and send commands to the robot.
