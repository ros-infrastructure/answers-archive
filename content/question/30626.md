However, rosdep is not able to install yaml-cpp nor tinyxml on the Gumstix's ARM processor. Thus, I tried to install the packages from source:

yaml-cpp : [http://code.google.com/p/yaml-cpp/downloads/list](http://code.google.com/p/yaml-cpp/downloads/list)

tinyxml : [http://code.google.com/p/libtinyxml/](http://code.google.com/p/libtinyxml/)
