    AMCL needs a few things to work.
    1 - initial pose. You have to tell AMCL where the robot is in the map. This can be done in RVIZ pretty easily.
    2 - AMCL only updates if the robot is moving. If you don't have a node publishing ODOM topic and the ODOM-Baselink TF, then AMCL won't run.
