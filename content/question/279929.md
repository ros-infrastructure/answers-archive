  body_markdown: "I'm assuming this is the `CMakeLists.txt` of package  `B`.\n\nThus,\
    \ the `install(..` part makes no sense. Why would you want to install something\
    \ from INSIDE package `B`? Do you have a layout like `B/include/A`? Also, what\
    \ do you expect `${A}` do contain? This variable should not be set anywhere in\
    \ here.\n\nThe same holds for the `add_library` call. Why do you, in package `B`\
    \ want to build a package in `A`.\n\nThe answer you cite is correct, so please\
    \ follow this.\n\n- In pkg `A`:\n    - compile the library\n    - install the\
    \ library and Header files of pkg `A` (actually, not even required)\n    - Export\
    \ the include path and the library with the `catkin_package` call (check out the\
    \ template when you create a new package) \n- In pkg `B`:\n    - set up the `build_depend`\
    \ to pkg `A`\n    - `find_package` package `A`\n    - add `include_directories(${catkin_INCLUDE_DIRS})`\n\
    \    - include the Header in your package `B` code\n    - link against the `${catkin_LIBRARIES}`"
