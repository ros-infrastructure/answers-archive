  body_markdown: "According to [add_dependencies](https://cmake.org/cmake/help/v3.0/command/add_dependencies.html)'s\
    \ documentation:\n\n> Add a dependency between top-level\n> targets.\n> \n> `add_dependencies(<target>\
    \ [<target-dependency>]...)`\n> \n>  Make a\n> top-level <target> depend on other\n\
    > top-level targets to ensure that they\n> build before <target> does. A\n> top-level\
    \ target is one created by\n> ADD_EXECUTABLE, ADD_LIBRARY, or\n> ADD_CUSTOM_TARGET.\
    \ Dependencies added\n> to an IMPORTED target are followed\n> transitively in\
    \ its place since the\n> target itself does not build.\n> \n> See the DEPENDS\
    \ option of\n> ADD_CUSTOM_TARGET and\n> ADD_CUSTOM_COMMAND for adding\n> file-level\
    \ dependencies in custom\n> rules. See the OBJECT_DEPENDS option\n> in SET_SOURCE_FILES_PROPERTIES\
    \ to add\n> file-level dependencies to object\n> files."
