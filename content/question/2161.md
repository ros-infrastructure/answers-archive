  body_markdown: "Hi,\n\nFor the **first issue** using gazebo 1.3 most probably you\
    \ are missing the GAZEBO PATHS to the plugin. \n\nHere is an example how to add\
    \ yout package plugin library:\n\n    $ export GAZEBO_PLUGIN_PATH=/<path>/your_package/lib:${GAZEBO_PLUGIN_PATH}\n\
    \n\n<br>For the **second issue** when you run your code with gazebo 1.5, this\
    \ might appear because your code could be built against the gazebo 1.3 libraries\
    \ from groovy, that's why you get that error when you run the plugin. \n<br><br>To\
    \ avoid this when you build your package you should comment out **`<depend package=\"\
    gazebo\"/>`** line from your **`manifest.xml`** file. Afterwards in the **`CMakeLists.txt`**\
    \ file add the following lines to link against yout gazebo 1.5 libraries:\n\n\
    \    ## link to gazebo libraries \n    include (FindPkgConfig)\n    if (PKG_CONFIG_FOUND)\n\
    \      pkg_check_modules(GAZEBO gazebo)\n    endif()\n    include_directories(${GAZEBO_INCLUDE_DIRS})\n\
    \    link_directories(${GAZEBO_LIBRARY_DIRS})\n\nCheers,\nAndrei"
