  body_markdown: "Hello, first I suspect that if you want to reset the world and models\
    \ you should look at the World class Reset not the Model class Reset. If that\
    \ does not work you can reset the world using the world_control gazebo topic,\
    \ this should reset your robot models to the initial positions as well as reset\
    \ the simulation, but does not reset joint commands.\n\nE.g. supposing you have\
    \ already run the transport and initialized a node \n\n-Create a publisher for\
    \ your message:\n\ngazebo::transport::PublisherPtr reset\\_pub;\n\nreset\\_pub=node->Advertise<gazebo::msgs::WorldControl>(\"\
    ~/world\\_control\");\n\n-Create a message and set it to indicate what you want\
    \ yo control:\n\ngazebo::msgs::WorldControl w\\_ctrl;\n\nw\\_ctrl.mutable\\_reset()->set\\\
    _all(true); //I believe this is equal to indicating a world reset\n\nreset\\_pub->Publish(w\\\
    _ctrl);\n\nBTW I'm evolving controllers for robot locomotion too. \n\n\n"
