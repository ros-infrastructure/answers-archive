  body_markdown: "You probably need to resize your target point cloud (`mls_cloud`).\
    \  The constructor creates the cloud object, but doesn't know how many points\
    \ you want to store.  You can't just start assigning point data by index until\
    \ you first allocate space to store them.\n\nTry this:\n\n    pcl::PointCloud<pcl::PointXYZ>::Ptr\
    \ mls_cloud (new pcl::PointCloud<pcl::PointXYZ>); \n    mls_cloud->resize(mls_points.size());\n\
    \    \n    for (size_t i = 0; i < mls_points.points.size(); ++i) \n    { \n  \
    \      mls_cloud->points[i].x=mls_points.points[i].x; //error \n        mls_cloud->points[i].y=mls_points.points[i].y;\
    \ //error \n        mls_cloud->points[i].z=mls_points.points[i].z; //error \n\
    \    } \n\nAlternatively, you can dynamically build the cloud if you don't know\
    \ ahead-of-time how many points it will contain:\n\n    pcl::PointCloud<pcl::PointXYZ>::Ptr\
    \ mls_cloud (new pcl::PointCloud<pcl::PointXYZ>); \n    \n    for (size_t i =\
    \ 0; i < mls_points.points.size(); ++i) \n    {\n        const pcl::PointNormal\
    \ &mls_pt = mls_points.points[i];\n        pcl::PointXYZ pt(mls_pt.x, mls_pt.y,\
    \ mls_pt.z);\n        mls_cloud.push_back(pt);\n    }\n\nOr, even better, don't\
    \ re-create the wheel, and use the built-in PCL [copyPointCloud](http://docs.pointclouds.org/trunk/group__common.html#gaff182bca8d0295d727baaa1fd368c6ad)\
    \ function to convert cloud types:\n\n    pcl::PointCloud<pcl::PointXYZ>::Ptr\
    \ mls_cloud (new pcl::PointCloud<pcl::PointXYZ>);\n    copyPointCloud(cloud_xyz,\
    \ cloud_xyzrgb);"
