  body_markdown: "It's not well documented, but the [SetIO](http://docs.ros.org/kinetic/api/ur_msgs/html/srv/SetIO.html)\
    \ service should allow you to configure the tool voltage when you specify the\
    \ `FUN_SET_TOOL_VOLTAGE` for `fun`, and then setting `state` to either `0`, `12`\
    \ or `24`.\n\nSome pseudo-code (neither Python nor C++):\n\n    req = SetIO()\n\
    \    req.fun = SetIO.FUN_SET_TOOL_VOLTAGE\n    req.state = 12\n\nThis would set\
    \ the tool voltage to 12V after invoking the service.\n\n---\n\nEdit:\n\n>  I\
    \ have been looking for a long time and cannot find documentation that says if\
    \ this is possible. \n\nI've submitted [ros-industrial/universal_robot#415](https://github.com/ros-industrial/universal_robot/pull/415)\
    \ to clarify the use of `SetIO` a bit.\n\nOnce that gets merged, the code changes\
    \ slightly (constants added):\n\n    req = SetIO()\n    req.fun = SetIO.FUN_SET_TOOL_VOLTAGE\n\
    \    req.state = SetIO.STATE_TOOL_VOLTAGE_12V"
