  body_markdown: "In the end, this is not a ROS but a python question.\n\nYou cannot\
    \ have `self.command` as a parameter to a function.\n\nYou might want to read\
    \ a bit up on what `self` means in python, there are a lot of pages out there\
    \ about this. This seems to be the main reason for your issues... \n\nsome more\
    \ hints:\n\n- it might make sense to have `self` as the first parameter of your\
    \ class methods (i.e. `def fct(self, var1, var2)`)\n- `self.command` below in\
    \ the main doesn't  make sense. You are not \"inside\" the class...\n"
