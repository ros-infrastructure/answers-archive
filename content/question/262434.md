    As far as I know, referenced in both the [targeted platforms page](http://www.ros.org/reps/rep-0003.html#kinetic-kame-may-2016-may-2021) and the [installation instructions for Debian Kinetic](http://wiki.ros.org/kinetic/Installation/Debian#kinetic.2BAC8-Installation.2BAC8-DebianSources.Setup_your_sources.list), Kinetic only supports Debian Jessie. [ROS Lunar](http://www.ros.org/reps/rep-0003.html#lunar-loggerhead-may-2017-may-2019) and [Melodic](http://www.ros.org/reps/rep-0003.html#melodic-morenia-may-2018-may-2023) will support Debian Stretch, as can be seen on the [install instructions for Debian Lunar](http://wiki.ros.org/lunar/Installation/Debian). I believe you can compile Kinetic from source on Stretch, but I probably recommend going through that trouble.

    After going through the Lunar install setup for Debian Stretch, you should be able to install via

    `$ sudo apt install ros-lunar-p2os*`
