  body_markdown: "An obvious answer would be that you could use the full name of the\
    \ parameter e.g. `/foo/do_something`. \n\nI'm guessing you are looking for something\
    \ a bit fancier. If the `ROS_NAMESPACE` environment variable is set, then the\
    \ call to `rosparam` will automatically happen inside of that namespace. So you\
    \ could use the <[env](http://wiki.ros.org/roslaunch/XML/env)> tag to set that\
    \ environment variable to be the same as your node name, then the name should\
    \ get resolved correctly.\n\nI'm not exactly sure if that answers your question,\
    \ there may be other solutions as well.\n\n**EDIT**\n\nHere's an example... I\
    \ tested this and it works.\n\n*Launch File:*\n\n    <launch>\n      <node name=\"\
    foo\" pkg=\"bar\" type=\"test.sh\" output=\"screen\">\n    \t<env name=\"ROS_NAMESPACE\"\
    \ value=\"foo\" />\n    \t<param name=\"do_something\" value=\"true\" />\n   \
    \   </node>\n    </launch>\n\n*test.sh:*\n\n    #!/bin/bash\n    val=$(rosparam\
    \ get do_something)\n    echo \"PARAM = ${val}\"\n\n\n\n"

    \n    <launch>\n       <group ns=\"nest\">\n          <node name=\"wrap_shell_script\"\
    \ pkg=\"testbot_utils\" type=\"wrap_shell_script.py\" \n                output=\"\
    screen\">\n            <param name=\"pkg\" value=\"testbot_utils\" />\n      \
    \      <param name=\"script\" value=\"test.sh\" />\n            <param name=\"\
    test_param\" value=\"have_correct_namespace\" />\n          </node>\n       </group>\n\
    \    </launch>\n\nAnd the wrapper script:\n\n    #!/usr/bin/env python\n    \n\
    \    import rospy\n    import subprocess\n    \n    rospy.init_node('wrap_shell_script')\n\
    \    \n    # TODO get other script arguments?\n    #namespace = rospy.get_namespace()\n\
    \    # assume the shell script only wants private params\n    namespace = rospy.get_name()\n\
    \    \n    script = rospy.get_param(\"~script\")\n    pkg    = rospy.get_param(\"\
    ~pkg\")\n    \n    subprocess.call('ROS_NAMESPACE=' + namespace + ' rosrun ' +\
    \ pkg + ' ' + script, shell=True)\n\nSo there the wrapper assumes the script will\
    \ only want private params when it does a `rosparam get`, and the script can't\
    \ use params named pkg or script because they are in the same namespace."

 How do I duplicate the behavior in a bash script of python or c++ nodes where getting a rosparam gets it relative to the nodehandle/rospy namespace?  I'd like to launch a .sh node in a roslaunch file and set parameters in the node namespace, but how does the shell script know what that namespace is when it runs rosparam get to get it?

roslaunch file:

    <node name="foo" pkg="bar" type="test.sh">
      <param name="do_something" value="true" />
    </node>

And then test.sh:

    #!/bin/sh
    ...
    do_something=`rosparam get do_something`

But that will get /do_something, not the node namespace.
