  body_markdown: "I think I found it,\n\nThe ESP IDF CMake build system will include\
    \ the CMakeLists.txt file that is the EXTRA_COMPONENTS_DIR. \n\nThis variable\
    \ is set in the main CMakeLists.txt file in the project with\nset (EXTRA_COMPONENT_DIRS\
    \  \"./../../.\")\n\nThis is how the CMakelists.txt file is included that processes\
    \ the ROS source code which is done by calling calling in the Makefile libmocroros.mk.\
    \ \n\nIf I want to push my source code to a different directory level, I needed\
    \ to update my EXTRA_COMPONENTS_DIR, I didn't have any extra ESP components so\
    \ I didn't think it was important.\n\nThe Microros build system is leveraging\
    \ the fact that the extra component directory where it expects the CMakeLists.txt\
    \ file to exist. This allows the ROS build system to be in a different location\
    \ than your ROS app. \n\n-John"
