  body_markdown: "You cannot use rviz on its own for your purpose, since you want\
    \ to simulate a carlike robot.\nrviz is just a visualization. \n\nYou have three\
    \ options for simulating a carlike robot:\n\n1. [not recommended] Write your own\
    \ simulation model (implement the discrete equations of motion and publish the\
    \ current state to rviz)\n2. Write a gazebo plugin for your carlike robot (this\
    \ might be more advanced)\n3. Use the 2D - simulator [stage](http://wiki.ros.org/stage_ros).\n\
    \nI would prefer option 3 for your task, since stage is able to simulate your\
    \ carlike motion as well as laser/sonar range sensors. This should be enough for\
    \ your AMCL task. You can also add noise to your motion model (in the stage config),\
    \ which is great for your evaluation.\n\nIn order to setup stage, your can refer\
    \ to the following links:\n\n- [Stage wiki page](http://wiki.ros.org/stage_ros).\n\
    - [Question: Simulating a car-like robot in Stage](http://answers.ros.org/question/9470/simulating-a-car-like-robot-in-stage/)\n\
    - Checkout how the turtlebot is configured for stage (config files / launch files\
    \ etc): [Turtlebot in Stage](http://wiki.ros.org/turtlebot_stage/Tutorials/indigo/Bring%20up%20TurtleBot%20in%20stage)\n\
    - Stage manual: [Robot model](http://playerstage.sourceforge.net/doc/stage-svn/group__model__position.html)\n\
    - Stage manual: [Laser model](http://playerstage.sourceforge.net/doc/stage-svn/group__model__laser.html)\n\
    \nIf you check out the turtlebot stage package, you will find the turtlebot.inc\
    \ file (which is loaded from your stage world file):\n\n    define turtlebot position\n\
    \    (\n       pose [ 0.0 0.0 0.0 0.0 ]\n       odom_error [0.03 0.03 999999 999999\
    \ 999999 0.02]\n       size [ 0.2552 0.2552 0.40 ]\n       origin [ 0.0 0.0 0.0\
    \ 0.0 ]\n       gui_nose 1\n       drive \"diff\" # change to \"car\" for your\
    \ carlike robot [\"diff\", \"omni\" or \"car\"]\n       color \"gray\"\n     \
    \  kinect(pose [ -0.1 0.0 -0.11 0.0 ]) # replace this with laser / sonar information\n\
    \n       # ADD THE FOLLOWING PARAMETER:\n       # only used if drive is set to\
    \ \"car\"\n       wheelbase 1.0\n    )\n\nYou must also define the [wheelbase](https://en.wikipedia.org/wiki/Wheelbase).\
    \ You might better refer to the example \nin the Stage manual (see link above).\n\
    \nAfter stage is running your model, you need to command the velocity and steering\
    \ angle.\nHere you can chose either your joystick, a predefined control sequence\
    \ (programmed) or some planner as Orhangazi44 \nsuggested (e.g. [dwa_local_planner](http://wiki.ros.org/dwa_local_planner)\
    \ or [teb_local_planner](http://wiki.ros.org/teb_local_planner))."
