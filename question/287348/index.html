</launch>

<launch>

    <node pkg="rqt" type="rqt" name="rqt"/>

Yes you can do that, you have to call the node rqt_gui from the package rqt_gui like that :

<node name="rqt_gui" pkg="rqt_gui" type="rqt_gui"/>
