Answers

The compilation is not able to find the ignition-math lib headers.

Be sure that you have run the ../configure script before running cmake (as the tutorial describes it). It should bring the proper include path to get the ignition math headers into the compilation. If this does not work, please check that from your build directory you can access to the path ..\..\ign-math\build\install\%build_type%\include\ignition\math2 which is the path used in the configure script
