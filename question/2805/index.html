Is gazebo -p of state log normally 1/20th of real time speed?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/26369/is-gazebo-p-of-state-log-normally-1-20th-of-real-time-speed.

We're trying to validate the qualification log for DRCSim, and the gazebo -p playback is taking an extremely long time. We've taken over 30 minutes to replay 1:21 of simulation time, which corresponds to 3:17 of real wall clock time.

Is this normal?

Answers

We had some roscode running that was trying to talk with gazebo on restart. That slowing things down. Killing all processes on all computers first allowed gazebo to run at normal speed.
