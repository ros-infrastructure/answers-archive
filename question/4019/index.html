In Gazebo8 , you can set a good Kp,Kd first, and then use SetPosition in a update function like this.

  for (unsigned int i = 0; i < this->joints.size(); ++i)//
    {
        this->joints[i]->SetPosition(0, this->jcmd[i]);
    }
