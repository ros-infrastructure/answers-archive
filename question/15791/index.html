Dynamic of a suspended charge

Hello, I'm trying to add to my quadrotor model a suspended charge (it will be a ball suspended from a thin thread) but I don't know how to simulate its dynamic on Gazebo. Can someone help me?

Answers

You can attach the ball to the quadrotor using a ball joint, for example. If you specify realistic inertial parameters for the ball, it should behave correctly.

Here's a tutorial on how to attach things with joints:

http://gazebosim.org/tutorials?tut=add_laser&cat=build_robot

And here's the documentation on inertial parameters:

http://sdformat.org/spec?ver=1.6&elem=link#link_inertial
