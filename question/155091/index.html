This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/58848/move-base-without-map.

Hello everybody!

I am trying to implement the movebase node. However, I am not using a map. If I start the movebase node, it loads all the config files, but keeps waiting for a map. local_costmap:
