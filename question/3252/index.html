I wrote several plugins for gazebo and ROS, I believe that is necessary, when you create the ros package in which the plugin is contained, you indicate the dependancies. For example:

catkin_create_pkg <name_package> roscpp gazebo_ros

I am assuming you are writing the plugin in c++ in a ROS environment using catkin. If you have already created the package check the package.xml file in the folder of the plugin. It should contain the lines

<buildtool_depend>catkin</buildtool_depend>

<build_depend>roscpp</build_depend> 

<build_depend>gazebo_ros</build_depend>

<run_depend>roscpp</run_depend>   

<run_depend>gazebo_ros</run_depend>`
