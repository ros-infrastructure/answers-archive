Asked by Mike Scheutzow on 2022-09-12 10:21:33 UTC

If you'd like to do that you can create a custom transformer implementation for yourself and or contributed it back to the core library for the newer implementation in ROS 2. We generally don't want to do major feature changes in already released distros such as Noetic. You will need to implement a doTransform method like here: https://github.com/ros2/geometry2/blob/rolling/tf2_geometry_msgs/include/tf2_geometry_msgs/tf2_geometry_msgs.hpp
