There is no such thing as a single version for a ROS distro. Each distro consists of many packages that have completely different version numbers.

If you are refering to the latest sync and want to update this: Assuming you have followed the standard install instructions using debian packages, a simple sudo apt update && sudo apt upgrade will be sufficient.
