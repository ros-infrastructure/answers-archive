Hello limiaobo:

Let me split the answer in two points:

  • If you plan about using gazebo on MacOsX, the support is in place, but it is still quite experimental, so I would expect some failures.
  • If you plan about using gazebo with Linux on the Mac, I don't have any experience related to the FirePro D500 graphic card. Historically, Gazebo has shown problems with AMD cards, but I believe that there is people out there using this combination (Mac + gazebo), not sure if using AMD cards.

Nvidia graphic cards are the ones that currently works better with gazebo and that I would recommend.
