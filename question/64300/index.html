How to set up IMU_UM6 on UART?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/51681/how-to-set-up-imu-um6-on-uart.

I need to connect an IMUUM6 to a UART port on my BeagleBone. The default location in the imuum6 node to set the sensor is ttyUSB. How do I set this up for streaming from the UART?

Asked by TJump on 2013-06-04 05:42:39 UTC

Comments

Answers

The UART usually enumerates under a device name like /dev/ttyS0 or /dev/ttyS1.

Try changing the port parameter to the hardware UART device name in your launch file.

<launch>
    <node pkg="imu_um6" type="imu_um6_node.py" name="imu_um6_node" output="screen" respawn="true">
        <param name="port" type="string" value="/dev/ttyS0"/>
    </node>
</launch>
