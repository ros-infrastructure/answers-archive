This way you can PCD Output by command.

rostopic pub --once /config/ndt_mapping_output autoware_msgs/ConfigNdtMappingOutput "header: seq: 0 stamp: secs: 0 nsecs: 0 frame_id: '' filename: 'test.pcd' filter_res: 0.2"
