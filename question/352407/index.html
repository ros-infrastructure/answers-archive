Reset rqt_console config

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/95863/reset-rqt-console-config.

After I accidentally dragged the top of the rqtconsole, my rqtconsole now only shows a blank window (just a window with a white background). How can I reset the rqt_console configuration to restore normal behavior?

Answers

You could see whether removing ~/.config/ros.org/rqt_gui.ini helps.

Be sure to make a backup of the file first. You may want to restore it.
