At least from the ROS Distros, the package would be named ros-*VERSION*-gazebo-ros-pkgs (e.g. ros-foxy-gazebo-ros-packages). I don't believe the gazebo version number (11) is included, as different gazebo versions are fairly "tied" to different ros distros (at least with the binaries).
