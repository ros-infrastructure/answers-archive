Anything that is defined as an array in the msg file (like Marker[] markers here) will be converted to a std::vector<Marker> in c++ (see https://en.cppreference.com/w/cpp/container/vector for their methods). There are some other specialities about messages that you can find here: http://wiki.ros.org/action/show/msg?action=show#Fields
