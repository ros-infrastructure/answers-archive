"Couldn't connect to joystick at /dev/input/js0" while joystick is at js1.

I'm getting the above error while using the jetsoncar teleoperation package using joystick. "ls /dev/input" shows js0 even when there is no joystick connected. I have already set param for joynode at js1 and joy node is running fine.

Answers

after you launched the nodes, rosparam get (use rosparam list to find it). It's possible that another node may set this param back to js0 which is a problem for you. Alternatively, you can set a fixed name for your device. https://unix.stackexchange.com/questions/66901/how-to-bind-usb-device-under-a-static-name
