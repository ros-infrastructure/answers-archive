Hello

I'm starting a project that uses the gmapping package in the pioneer p3dx robot, the robot have ubuntu 12.04, ros hydro and ros groovy installed, and I dont know which of these two distro of ros use for my project, because this is my first project using ROS, and I have no clear criteria for choosing between this two distributions.

Then, which of these two distro will you recommend for my project? the gmapping package is the same in both distro?

Thanks in advance.

Answers

I would go with hydro if you have to choose one of them. If not, I would install Indigo. A new distro is generally always better, if it supports packages you need.

If you check http://wiki.ros.org/gmapping, you will see that Hydro is still in continuous integration while groovy is not.
