Answers

I just did a rosdep update for noetic and it worked as expected. I have the same version of rosdep as you do.

Debugging steps:

  1. Try the command again. It may only have been a network or server glitch.
  2. Make sure your home directory has free disk space.
  3. Make sure $HOME/.ros/rosdep/ and all the files under it are owned by your user name (not by root.)
  4. Rename the $HOME/.ros/rosdep/ directory to something else (e.g. rosdep.old) and try the command again.
