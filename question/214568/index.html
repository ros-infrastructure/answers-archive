why some launch file have extension type foo.launch.xml ?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/68889/why-some-launch-file-have-extension-type-foo-launch-xml.

I am going through moveit pr2 tutorials and I see .launch.xml extension .Why do we need two extension. For example pr2moveitcontroller_manager.launch.xml

Asked by prrraveen on 2015-07-25 17:57:49 UTC

Comments

Answers

roslaunch automatically tab-completes any files with a .launch extension. In order for launch files that are mostly used as includes to not (edited) show up on those listings, they are given a second extension .xml (which they actually are).
