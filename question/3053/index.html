Hi,

you have to convert the sdf file to version 1.3, the command is similar to how you tried to run it, you only need to add the 'convert' parameter:

gzsdf convert ~/<path>/empty.world

cheers

EDIT!

Try using this world file, and change the sdf version to 1.3 manually. I don't know why your converter gives you this error. Also run gazebo with the path to the world file as argument:

gazebo ~/<path>/empty.world


You should also try installing the latest version of Gazebo, which uses sdf version 1.4.
