This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/78928/how-do-i-feature-a-book-on-wiki-ros-org-books.

Can someone help me create a book page like http://wiki.ros.org/Books/ROS_Robotics_By_Example to be posted on http://wiki.ros.org/Books to feature a book

Comments

Answers

The ROS wiki is just that, a wiki, so anyone (with an account) can create pages like that.

The procedure would be:

  1. register for an account
  2. request editing access (ros-infrastructure/roswiki#139 ros-infrastructure/roswiki#258 now)
  3. create a new page
  4. link to it from the Books page
