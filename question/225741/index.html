How to convert geometry_msgs/Pose to geometry_msgs/PoseStamped

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/71766/how-to-convert-geometry-msgs-pose-to-geometry-msgs-posestamped.

I need to convert a message from geometrymsgs/Pose to geometrymsgs/PoseStamped. Is there ay functionality in ROS to do the same ?

Asked by mayank_m on 2016-02-03 02:32:03 UTC

Comments

Answers

geometry_msgs/PoseStamped contains two fields. header and pose.

You can create an empty PoseStamped and set pose to your geometry_msgs/Pose. If you want you can also set some fields in the header.

No black magic.
