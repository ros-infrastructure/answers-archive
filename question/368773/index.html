It's likely you ran catkin_make_isolated as root at some point (using sudo). Seeing as you now attempt to run it as a regular user, you get permission errors, as you are not allowed to access the files and/or directories owned by root.

Asked by Ayan on 2021-01-09 06:48:54 UTC

I'd suggest not to reuse the workspace you used for your initial ROS installation on your Pi, but create a new one which overlays the install space of your initial one.

If you really do want to reuse your initial workspace, then you could run something like sudo chown $USER: -R /home/pi/ros_catkin_ws, which will make $USER the owner of all the files in the workspace again.

This is not ROS-specific, but a general Linux file permission issue.
