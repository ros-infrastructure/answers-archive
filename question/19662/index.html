What is Gazebo 9.0 equivalent of gazebo::physics::Joint->GetAngle() used in Gazebo 2.0?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/28505/what-is-gazebo-9-0-equivalent-of-gazebophysicsjoint-getangle-used-in-gaze.

In Gazebo 2.0, gazebo::physics::Joint->GetAngle() is used to Get the angle of rotation of an axis(index). This method is not available in Gazebo 9.0. I would like to know what is equivalent function in Gazebo 9.0

Thanks.

Comments

Answers

According to the migration guide:

***Deprecation:*** math::Angle GetAngle(unsigned int _index) const
***Replacement:*** virtual double Position(const unsigned int _index = 0) const final
