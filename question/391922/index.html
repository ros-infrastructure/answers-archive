robot_localization get high covariance and stops publishing filtered-messages

Hello everybody,

I have a problem with robotlocalization. In my project I have two sensors: a camera (Realsense T265) and an IMU. I want to merge the two sensor data in robotlocalization. The camera gives the odom data. Therefore I connected the camera with the map-frame via tf2ros. With the static transformation of the map-frame I also add an offset and an orientation rotation. When I start my launcher the program works without any problems. However, when my robot is in a horizontal Position, the covariances are getting huge and the topic /odomertyfiltered stops publishing. If I leave the offset and rotation at zero there are no problems. I have no idea, why this could happen.

Here is my launch-file:

<launch>

<!--IMU fsm9 -->
<include file="$(find fsm_imu)/launch/fsm9.launch"/>

<!--UKF map-->

<include file="$(find datafusion)/launch/include/ukf_map.launch"/> 
<!--UKF odom-->

<include file="$(find datafusion)/launch/include/ukf_odom.launch"/> 

<!--static transformation--> 
<node pkg="tf2_ros" type="static_transform_publisher" name="map" args="0.0856 0.03341 -0.045 1.5707963267949 0.349065850398 0 map camera_odom_frame"/> 
<node pkg="tf2_ros" type="static_transform_publisher" name="imu_fsm" args="0.0244 0.03341 -0.00950 0 0 0.34906585039887 base_link imu_frame"/>

I hope you can help me.
