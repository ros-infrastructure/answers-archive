I think you would have to get someone at Willow to upload it for you. Personally, I would create a second repository on github (perhaps _test_data) and put the larger files in there. Then with github, you can use raw urls to access the large bagfiles. It's not ideal if you are changing the large bagfiles often, but it does have the added advantage that your test data is at least in the same github organization as your code, and therefore maybe easier to find than on pr.willowgarage.com
