Here is the answer sent on the google groups mailing list:

Windows support is experimental at this point. You would have better luck using a virtual machine on windows, instead of directly installing gazebo.

Gazebo 6 and 7 are fully supported, so you can choose either one. Version 7 will have newer features and bug fixes, but it hasn't been under active use as long as version 6.
