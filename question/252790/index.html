This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/78526/building-orocos-components-in-ros-kinetic.

My system has used rttrosintegration in the past to build Orocos Components in a ROS Package in ROS Indigo. We are trying to update our systems to ROS Kinetic. I can't find an rttrosintegration like package that would work in ROS Kinetic, is one being developed?

Use rtt_ros_integration package with branch 2.9 from github. This will work like a charm. follow the instructions as it is. but before that also instal ruby, gems and ruby-dev packages. if u want corba support than when building orocos_package inside underlay_isolate pakage use catkin_make_isolated --install -DCORBA ...
