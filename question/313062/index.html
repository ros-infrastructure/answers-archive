You need to make sure that both machines can exchange UDP multicast packet. A good starting point is to try running the ros2 multicast commands on both sides (see https://github.com/ros2/ros2cli/tree/7a65e1ecf02c69bf3d9624d49b17cde57f7ed16a/ros2multicast).
