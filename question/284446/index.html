Compilation Error for ROS2 Ament-Tutorial on Creating an Overlay

I was running through the tutorial at: https://github.com/ros2/ros2/wiki/Ament-Tutorial. I had no issue building ROS2 from source, but when I created an overlay and tried to build it I saw the following build errors:

It turns out the source code in the subscribernode.cpp and publishernode.cpp on https://github.com/ros2/examples.git is slightly different. Specifically, changing registermacro.hpp to classloaderregistermacro.h solves the issue for both files.

I also needed to use -DCMAKE_BUILD_TYPE=Release to successfully compile as noted in https://github.com/ros2/examples/issues/199 .

Hopefully this helps someone else get up and running a little faster.
