It seems that your rgbdslam package is at a location where you need administrative privileges to create folder. I would suggest you to try sudo rosmake rgbdslam or create an overlay at /home/ and download the rgbdslam package, make sure that overlay path is before the system default path of /opt/ros and then compile the packge
