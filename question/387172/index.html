Answers

  • I got this error while installing ros2(humble version) in windows, It got solved when I installed the module "packaging" in the specified version of python.
    • In my case, ros2(humble) wanted python version 3.8.3, and i have multiple versions of python in my pc. I switched my default python version to 3.8.3 in the system by changing the order of paths of these python versions in environment variables. then installed the module.
    • In short, make sure that you install the module in the python version asked in ros2 documentation.
    • and location is also important , path must be like this C:\python38....
