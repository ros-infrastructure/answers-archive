Unable to visualize interactive markers on web app

I'm trying out the visualizingInteractiveMarkers tutorial. For some reason, the markers are not rendering in my web app. My javascript code is as follows:

// Connect to ROS.
var ros = new ROSLIB.Ros({
  url : "ws://localhost:9090"
});

// Create the main viewer.
var viewer = new ROS3D.Viewer({
  divID : 'markers',
  width : 800,
  height : 600,
  antialias : true,
});
// Setup a client to listen to TFs.
var tfClient = new ROSLIB.TFClient({
  ros : ros,
  angularThres : 0.01,
  transThres : 0.01,
  rate : 10.0,
  fixedFrame : '/rotating_frame'
});

// Setup the marker client.
var imClient = new ROS3D.InteractiveMarkerClient({
  ros : ros,
  tfClient : tfClient,
  topic : '/basic_controls',
  camera : viewer.camera,
  rootObject : viewer.selectableObjects,
});

I made all the necessary installations and I can view the interactive markers on Rviz. But it's not rendering on the web app. What could be the reason?
