Answers

The solution was related more on the compiler for the Raspberry which for microros requires the 9.3.1 and not the 6.3.1 which is the one downloaded on ubuntu 18. The solution of the issue is here: Github. It still remain // in the node list:

ros2 node list
//
/pico_node

But now it works. The only drawbacks that due to the fact of the node "//", rqt crashes when I am trying to see the node graph:
