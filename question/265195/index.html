Eric,

As you saw in http://answers.ros.org/question/203725/problems-launching-rocon-chatter-concert-inside-of-a-docker-image/, the issue is that Zeroconf doesn't work in Docker. You can Google for "zeroconf docker" to find solutions for this issue, or use the patch to rocon that Jihoon posted on the other question to modify the concert to not use docker. Unfortunately either solution will require you to search, learn and work a little to make it work.

Good luck! Julian

Just check if the avahi package is installed or not. If it is not installed try the following link: [http://www.linuxfromscratch.org/blfs/view/systemd/basicnet/avahi.html]

If it is installed then do following: cd ~/ sudo /etc/init.d/avahi-daemon start

That's all it will work. Do roslaunch turtlebot_bringup minimal.launch/
