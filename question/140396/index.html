A short path to similar videos (given that you probably use Ubuntu for ROS) is using kdenlive (Ubuntu installation instructions here). This is a pretty comprehensive video editor that should provide the necessary features features you also see in WillowGarage´s videos (transparent overlays, title screens, picture in picture, time lapse etc.). It can be a bit buggy at times, but overall works well for most uses. While not a slick as many Willow Garage videos, most videos here have been edited with kdenlive.
