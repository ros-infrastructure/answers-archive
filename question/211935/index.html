The cable wiring is as follows: Red: COM Input + Gray: COM Output - Light Blue: IP Reset Input Orange: Synchronous Output Brown +VIN (12VDC / 24VDC) Blue: -VIN Since I plan on using the Ethernet connection for communication, I only need to connect the brown and blue cables for power.
