I have encountered problem when installing phidget

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/83020/i-have-encountered-problem-when-installing-phidget.

I have followed the step given by ros wiki. Everything was alright until to set up the udev rules for the phidgets usb devices. After enter [sh src/phidgetsdrivers/phidgetsapi/share/setup-udev.sh], I have the following error,

cp: cannot stat ‘udev/99-phidgets.rules’: No such file or directory
Phidgets udev rules file has been copied to /etc/udev/rules.d/

Any kind soul can render help to solve this issue.

Answers

The script makes an assumption about the location of the rules in relation to the working directory. https://github.com/ros-drivers/phidgets_drivers/blob/kinetic/phidgets_api/share/setup-udev.sh#L1

I'd suggest trying:

cd src/phidgets_drivers/phidgets_api/share/ && sh setup-udev.sh
