What you post is not the error message, but a general remark about a possible(!) solution. I'm not quite sure what you are trying to do, but the general, ROS-way idea is the following:

  1. define message (i.e. the *.msg) in package b
  2. generate the language specific message classes by compiling package b, for this, set up CMakeLists.txt in package b correctly. See this.
  3. define a dependency on package b in package a
  4. (as you are using C++), #include <package_b/msg_between_a_b.h> and use it...
