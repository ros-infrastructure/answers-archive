Answers

thank you @Eman.m. To fix the original issue, this is caused by the costmap_2d package being converted to use tf2 instead of tf. Difference between Kinetic and Melodic.

There is a repo that you need to build this package from source that will fix this: https://github.com/ros-planning/navigation/tree/melodic-devel/costmap_2d

Also you can consider using the wrapper: http://docs.ros.org/en/melodic/api/costmap_2d/html/classcostmap__2d_1_1Costmap2DROS.html

There is more information on this prior answer: https://answers.ros.org/question/287540/tf2-buffer-lookuptransform-fails-tf_echo-and-rostopic-echo-tf_static-work-fine/
