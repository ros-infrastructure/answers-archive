AFAIK, FastDDS will try to use shared-memory on the same host by default, but will fall back to regular UDP when needed. Perhaps @Pablogs can add something here.

And again AFAIK: iceoryx also has a DDS gateway.

I'm not sure you need to make things so complex, and this starts to look like an xy-problem: you really want to achieve zero-copy performance while not losing the ability to communicate to off-host nodes, but you ask about being able to use two RMWs at the same time. Those are different questions.
