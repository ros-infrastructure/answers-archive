If the Gazebo GUI shows bullet then I think it worked as that information is directly coming from the gazebo physics server.

The error message is coming from this line in gazebo ros pkgs. Looking at a few lines above that, it sets a few ode physics params like precon_iters, sor, etc which do not apply if you're using bullet.
