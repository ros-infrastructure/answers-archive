Your question is unfortunately not easy to understand. What do you mean by "compile the codebase without actually running the software"? The compile and execute steps are completely separate for a compiled language like C++, which is what most of Autoware is implemented in. Autoware uses CMake to manage compilation, which is in turn used via the colcon tool. If you try to edit the Makefiles generated by CMake, they will just be overwritten the next time you run CMake or colcon. Additionally, which CMakeLists.txt files you need to modify depends on which part of the code you want to fuzz, and just saying "perception" does not narrow it down much because perception is something like 80% of the work in autonomous driving. You need to start by identifying a specific library or node you want to fuzz. You do not need CUDA if you use a recent version of the source from the repository.
