Determine upload_credential_id for custom buildfarm?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/67955/determine-upload-credential-id-for-custom-buildfarm.

I'm trying to set up a custom buildfarm for use with some private repos. My latest issue is I'm not sure what uploadcredentialid should be in rosbuild_config/indigo/release-build.yaml. The docs aren't super helpful, "the ID of the credential to upload the built packages to the repository host". Which credential? How do I extract the ID?

Thanks for your help.

Answers

The credential_id is defined in the master deployment common.yaml

https://github.com/ros-infrastructure/buildfarm_deployment_config/blob/master/master/common.yaml#L14

This credential will be inserted into jenkins credential storage. (You can find the credentials via the Jenkins UI by clicking on "Credentials" at the top level, then "Global Credentials" in the Credentials page. Clicking on a specific credential you can find the ID in the url. I believe the ID is just a uuid.
