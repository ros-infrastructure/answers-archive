Check Your ~/.bashrc file ;) It's being executed every single time You start the terminal. Probably there is something like source /opt/ros/groovy/setup.bash in there. I'd still prefer adding an alias as mentioned in this answer: http://answers.ros.org/question/118901/source-catkin_wssrcsetupbash-after-each-reboot/?answer=118921#post-id-118921

Oh, and fix would be just simply changing /opt/ros/groovy/setup.bash to /opt/ros/hydro/setup.bash (in mentioned ~/.bashrc file).
