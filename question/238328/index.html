How to change Jenkins dev branch?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/74885/how-to-change-jenkins-dev-branch.

I changed the develbranch field of my Indigo release (https://github.com/rospilot/rospilot-release/blob/master/tracks.yaml), as it was previously tracking master. However, the Jenkins job (http://build.ros.org/job/Idevrospilotubuntutrusty_amd64/51/) is still tracking master instead of my indigo branch. How do I update Jenkins to use the new configuration?

Asked by cberner on 2016-06-28 21:32:14 UTC

Comments

Answers

The continuous integration uses the source definition from the rosdistro.

You should update the entry here: https://github.com/ros/rosdistro/blob/master/indigo/distribution.yaml#L10043
