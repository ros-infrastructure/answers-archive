sound_play change language

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/45773/sound-play-change-language.

I want to change the language of soundplay. Since it is based on festival, I have downloaded the relative language package and setted it as default for festival. In festival it works, but soundplay still speaks in its default english. How can I change the default soundplay language? Is it also possible to change language when soundplay node is running?

Asked by rastaxe on 2012-11-14 01:14:25 UTC

Comments

Answers

I found the solution. The method "say" in sound_play.h takes a voice as argument and if it is omitted, the default is the English one.
