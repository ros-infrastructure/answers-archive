Answers

ROS on Windows is now directly supported. Check out http://aka.ms/ros. Once you install it, you can set the ROS master to your Ubuntu computer.

After launching the command window and setting up the ROS environment with c:\opt\ros\melodic\x64\setup.bat, you can set ROS_MASTER_URI=http://<ip of your Linux Robot>:11311. You can run nodes or Tools on Windows which can interface directly with the robot. (Like using WinML on Windows against cameras and actuators on the robot).

I created this bug in the ROSOnWindows issues to track updating the rosserial_windows documentation to reference direct Windows support.

Good luck!
