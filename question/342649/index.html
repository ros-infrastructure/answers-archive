Roslaunch Lookup Args

I'm trying to create a roslaunch file that launches our cameras (intel realsense). The provided launch files allow the user to specify the desired camera using a serial number that is hard to remember and not readable. I'd like to create a camera "DNS". That is, provide easily remembered IDs to developers using them. The problem with this is I cannot find a clean way of performing the ID to serial number conversion in the launch file. Any method of loading outside configuration data only loads it to the parameter server and not the arguments of my launch script. I could write a python script that performs the lookup and then runs my launch file, but this doesn't seem ideal either.

Any tips on how to go about this?

I'm not sure this would be something I'd do in a .launch file, as it seems rather application specific and out of scope for them, but perhaps you could use the eval substitution arg:

$(eval <expression>) allows to evaluate arbitrary complex python expressions.

For example:

<param name="circumference" value="$(eval 2.* 3.1415 * arg('radius'))"/>

Will compute the circumference from the ''radius'' argument and assign the result to an appropriate parameter.

You could perhaps add a lookup table in an eval expression and use the result as a value for a param which you could then pass as an arg to an included launch file.

I'm not sure whether this could be combined with loading a .yaml first and then referencing it in an expression. That would be something to check.

Another option could be to use param with the command type.

Use an arg to pass the "camera name", then pass that as an argument to a param that in its command uses your Python script to map it to a serial nr. Note that you cannot pass the value of the param to another .launch file as an arg again unfortunately.

A third alternative could be to use the conditional if and unless. Combined with eval you could implement a lookup table that way.
