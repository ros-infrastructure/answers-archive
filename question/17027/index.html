Adding the tag for inertia under the link tag solved it for me

for example:

<inertial>
        <mass>3.0</mass>
        <pose>-0 0 0 0 0 0</pose>
        <inertia>
          <ixx>0.012</ixx>
          <iyy>0.012</iyy>
          <izz>0.02344</izz>
          <ixy>0</ixy>
          <ixz>0</ixz>
          <iyz>0</iyz>
        </inertia>
      </inertial>
