The hector_gazebo_plugins package, which is a dependency of hector_quadrotor_gazebo, comes with a GPS plugin. The default URDF configuration of the quadrotor already has that plugin and you should be able to subscribe to the /fix topic (sensor_msgs/NavSatFix). It also publishes the GPS ENU velocity as a geometry_msgs/Vector3Stamped message on the /fix_velocity topic.

The reference latitude, longitude and heading (position and orientation of the Gazebo coordinate system in WGS84) can be configured in the plugin config. If you want to override it, you have to create your custom URDF description for hector_quadrotor.

To convert the latitude, longitude and altitude back to Cartesian coordinates you could look at the geodesy package. We are using hector_pose_estimation to fuse the GPS positions and velocity into a combined localization solution together with all the other sensors.
