Dynamic message types

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/52258/dynamic-message-types.

I am new to ROS but have experience with DDS real-time pub/sub middleware. DDS has the concept of dymanic message type registration, which allows you to define a message type at run-time rather than compile time. See section 7.5.2 in: portals.omg.org/dds/sites/default/files/x-typesptc11-03-11.pdf. This allows DDS clients change the message structure without recompiling the application ( i.e. by reading message structure from IDL). Is there a similar concept in ROS?

Asked by mmcbroom on 2013-06-25 01:09:24 UTC

Answers

AFAIK: No.

Changing the structure in general would be impossible for c++ nodes. Technically that could be done for python nodes, but in that case all involved nodes would need to get that information from somewhere. I don't think there are any functionalities for doing that at runtime.

As @dornhege mentioned it is possible in python to run the generators. We have done a few prototypes of things which do this. With the modularity of nodes only the ones which want the specific message need to be restarted. So you don't need to restart the entire system, but only affected parts.
