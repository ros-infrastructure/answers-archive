Hi @devil, the command is actually - gazebo worlds/cafe.world. If this is not working then maybe you need to go into the folder and run this command to open the world correctly. Alternatively since after running the command you get an empty world, you can then go to insert and open the specific world from there. Also note that if you don't have the world / model already, Gazebo will download it from the online model database which may take some time.
