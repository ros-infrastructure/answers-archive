Bad Links on WritingPublisherSubscriber(C++) Tutorial Page

On the tutorial page for WritingPublisherSubscriber (and possibly other pages), there are URLs given for the talker.cpp, listener.cpp, and CMakeLists.txt files that should work for the tutorial. However, these URLs are incorrect, as they redirect to files within GitHub with different addresses. While this is not a big deal for someone who wishes to click through and see the file or download on the same machine as they are using to browse for the tutorial page, it becomes an issue for someone typing the URL into a different machine to download the file (with curl, for example). It took me several tries to realize that the link:

https://raw.github.com/ros/ros_tutorials/kinetic-devel/roscpp_tutorials/talker/talker.cpp

should really be:

https://raw.githubusercontent.com/ros/ros_tutorials/kinetic-devel/roscpp_tutorials/talker/talker.cpp

(Note the difference between raw.github.com and raw.githubusercontent.com.)

This goes for the other files on this page as well, and in some other tutorials. On a related note, the following two links would be really helpful on the WritingServiceClient(C++) tutorial page as well: https://raw.githubusercontent.com/ros/catkin_tutorials/master/create_package_srvclient/catkin_ws/src/beginner_tutorials/src/add_two_ints_client.cpp https://raw.githubusercontent.com/ros/catkin_tutorials/master/create_package_srvclient/catkin_ws/src/beginner_tutorials/src/add_two_ints_server.cpp
