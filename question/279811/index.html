Hello,

1. The openCR should already be pre-configured. In the documentation (http://emanual.robotis.com/docs/en/platform/turtlebot3/overview/#turtlebot3) keep pressing SW1 or SW2 for at least 3-4 seconds. If it is still not working, can you check the status of the various LEDs?

2. You will need to get the data from the sensor (by using any libraries you need) and then create a ROS Node to publish them to your main server.
