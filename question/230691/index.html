Can't change minimum laser range with asus xtion pro

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/73155/cant-change-minimum-laser-range-with-asus-xtion-pro.

I'm using an asus xtion pro camera with a turtlebot 2 and I noticed that it only registers scans that are at least 0.45 meters away even though the edge of the robot is around 0.3 meters. I changed the parameter value for "/depthimagetolaserscan/range_min" to 0.2 but this has no effect on how close it detects obstacles.

How can I change the minimum laser range?

Asked by pgigioli on 2016-03-31 17:33:25 UTC

Comments

Answers

In my experience, the Asus Xtion Pro itself has a minimum range of 0.5 meters (actually the official specifications say the minimum range is 0.8 meters) so it is not a problem with the depth_image_to_laserscan parameters.

If you need to see obstacles closer than 0.5 meters away you will need a different sensor.
