Try to implement robotic related papers (motion planning, mapping, manipulators, robot algorithms, deep learning/machine learning, IA, human robot interaction, computer vision etc..) on ROS and publish ROS packages. Try to solve a real life problem with robots for a personal project. Apply to a job where they use ROS, like for example, the Google Summer of Code but I think the application process is over.
