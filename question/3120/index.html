White wireframe box around objects

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/26468/white-wireframe-box-around-objects.

When selecting an object in Gazebo, a white wireframe box is drawn on the screen. Normally, this box outlines the object. Sometimes it is in the wrong place (seemingly offset in a direction, or rotated to some incorrect axes). What does this box represent? Is this bug isolated only to this visual display, or does it indicate something deeper?

Hello,

The white box is suppose to show what model is selected, and it's also suppose to be the bounding box around the model. It's currently not working quite right. This is a known bug, but it doesn't affect the way Gazebo works.
