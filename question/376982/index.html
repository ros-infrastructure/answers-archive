I have been able to connect between Ubuntu 20.04 LTS Desktop and Ubuntu 20.04.1 Preinstalled Server for Raspi without too many connectivity issues.

From what I've seen, the two common starting points are:

1) looking to see if you have a firewall that might be blocking the connection, or

2) if you are using a Virtual Machine for the remote PC switching to a bridged adapter connection (discussed a bit more here)

Though admittedly those approaches may be more for cases where you are unable to connect the machines, rather than if your connection is dropping... I suppose my comment is more to say that you shouldn't need to use Ubuntu 16.04, and that the problem is likely elsewhere.
