Just my personal experience. I have tested the odroid M1 module.

With Netboot which is standard supported on Odroid you can install ubuntu 20.04 or even 22.04. I choose the 22.04 and install ROS humble. If the module support ubuntu in most cases ROS will work on the module.

One think that doesn't work is the drivers of the joysticks (PS3, Xbox, Logitech) The joystick aren't detected as /dev/input/jsx.It seems to be a problem with the kernel.

For mapping and controlling of the robot the joystick it is very practical. In all honestly I now switch to a RPI 4...
