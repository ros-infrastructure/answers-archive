I think one issue with this is that NITE, the library responsible for skeleton tracking in openni_tracker, was never released on ARM (AFAIK). Meaning, openni_tracker can't be released for ARM, and you won't be able to build it yourself. http://openni.ru/openni-sdk/openni-sdk-history-2/index.html
