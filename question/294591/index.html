I'm assuming that you're having trouble with the binary builds like this one: http://build.ros.org/job/Kbin_uX64__scratch4robots__ubuntu_xenial_amd64__binary/56/console

Because it looks like you've resolved the issue in your continuous integration devel job here: http://build.ros.org/job/Kdev__scratch4robots__ubuntu_xenial_amd64/

However the binary builds are based on the last released version in the rosdistro. So to resolve the binary builds you need to tag a new release and rerun bloom on it. http://wiki.ros.org/bloom/Tutorials/ReleaseCatkinPackage
