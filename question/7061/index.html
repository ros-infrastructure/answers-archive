The gz tool was introduced in gazebo 3.0.0 (see Changelog and pull request 972). What version of gazebo are you using (gazebo --verbose or dpkg -l | grep gazebo)?

For gazebo 2 and earlier, there were separate commands like gzsdf and gztopic that were collected into the gz command in gazebo 3.
