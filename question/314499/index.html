Answers

Two things:
1) it doesn't looks like you've added the nvidia-docker runtime arg to the docker run command.
2) your ros:mykinetictutorial image might not have been amended to include the setup needed for nvidia-docker.

You may want to try rocker to do this for you, see this previous answer for more: https://answers.ros.org/question/313786/running-ros-and-its-gui-tools-through-a-docker-image/?answer=314006#post-id-314006
