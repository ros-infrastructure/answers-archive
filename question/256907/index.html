Lucas & @retepvan

Sorry for bringing up an older post, but I do have a suggestion. It's not Oculus-specific, but this package I'm working on should work: https://github.com/RViMLab/vrviz

I've only used it with the Vive (as that's all I own) so the button mappings will have to be made by yourself for the Touch controllers, as I can't really test it without having one.

VRViz uses openvr, which incidentally is also the suggestion I would give if you still want to try your hand at building one yourself. But you could try branching vrviz first, to see if you can get it to do what you want.

Cheers, John
