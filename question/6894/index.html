How can I get the timestamps for gazebo model states?

I am using ROS topics /gazebo/model _ states to find the pose of my robot. I use this as ground truth to compute the error in estimated robot position, which I get from /tf. While /tf has a timestamp, /gazebo/model _ states does not. Is there any way of knowing the time for each published model state? The time stamp would help calculate the errors accurately.

Comments

Answers

Gazebo's /gazebo/default/pose/info topic contains time stamped pose data.
