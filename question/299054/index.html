(I'll post an answer in the context of staubli_val3_driver, other readers may post different solutions)

The short answer is: we don't know. The package you found (staubli_val3_driver) has only been used with CS8 controllers. I have not received any reports from users with CS9 controllers.

It's been a while since I've worked with Staubli robots, so I don't know how bw-compatible the control software on a CS9 is. If you'd be willing to try that would be very much appreciated.

The staubli_val3_driver on the staubli_experimental repository is not compatible with CS9, but only due to the change from text interfaces to HTML-based that CS9 brings. Disabling the screenUpdate task brings it back into compatibility for the most part.

We are currently working on some improvements on the staubli_val3_driver, among them, CS9 compatibility, and -of course- would like to contribute it back to the repo once it's ready.
