Micro-Ros: Package 'micro_ros_agent' not found

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/99618/micro-ros-package-micro-ros-agent-not-found.

I am trying to install micro-ROS through the steps provided in this link: https://micro.ros.org/docs/tutorials/core/firstapplicationlinux/ However, when I tried to run Micro-ROS Agent node

ros2 run microrosagent microrosagent udp4 --port 8888

it gives:

Package 'microrosagent' not found

I believe that the command line (below) supposed to create microrosagent package

ros2 run microrossetup createagentws.sh

Answers

Make sure that you do:

ros2 run micro_ros_setup create_agent_ws.sh

ros2 run micro_ros_setup build_agent.sh

source install/local_setup.bash

before trying to run the micro-ROS agent.
