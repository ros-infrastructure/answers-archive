C++ waitForService wrongly returns false

I have a python ROS server (node A) which advertises a service, and a C++ program (node B) which first checks if the service is available and then attempts to call it. The C++ program repeats those steps regularly during runtime. I have occasionally run into an error where it wrongly reports the service as unavailable, even though the python ROS server (A) is still running normally.

I can still call the service from the command line, or a simple python script I put together to call the service.

I put in a while loop to the C++ program to debug what was happening, like this:

double timeout_s = 5.0;
if ( ! ros::service::waitForService("segmenter/segment_image", timeout_s)) {
    log()->critical("service unavailable!");

    // for now, keep trying after every prompt to try and debug the error
    while ( ! ros::service::waitForService("segmenter/segment_image", timeout_s)) {
        log()->critical("service unavailable!");
        PromptUserInput(true, "try again?");
    }
}

It appears that once the waitForService returns false once, the same thing happens on every subsequent call, and the only way to have it succeed again is by restarting node B. What could be causing this?
