What is the right way to remove a joint created by: gazebo::physics::PhysicsEngine::CreateJoint ( const std::string & _type, ModelPtr _parent = ModelPtr() ) I cannot find an equivalent removeJoint method.

Hi there,

here is an example of reseting and removing a joint:

// removing and detaching joint
this->fixedJoint->Reset();
this->fixedJoint->Detach();
this->fixedJoint->Fini();

It should probably work with only Fini() as well, but I think I had some issues at one point so I just called everything, just to be sure :)
