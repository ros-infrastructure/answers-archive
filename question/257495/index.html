ros::console::setloggerlevel(ROSCONSOLEDEFAULTNAME, ros::console::levels::Debug)

Answers

Diagnostics does not have a threshold to control if messages are sent of not. It is up the receiving nodes to decide if they want to discard e.g. info level diagnostics messages.
