Answers

As you can see here: https://github.com/ros-infrastructure/rep/blob/master/rep-0003.rst Diamondback apt packages are only provided up to Ubuntu Natty (11.04). ROS Groovy is currently the only version with apt packagesprovided for Ubuntu Quantal 12.10

You can try installing diamondback from source if you really want that, however the hokyo node should probably also work with later ROS distributions.
