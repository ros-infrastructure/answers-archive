I actually managed to get it working. My fix was to update my Ubuntu 14.04 kernel from 3.16 to 4.4. I followed the instructions for the Video4Linux backend for step 3 using the 4.4 kernels steps. Hardware wise I am using: - NVIDIA GTX 745 Video Card - I7-6700 3.40 GHz CPU - 32 GB RAM
