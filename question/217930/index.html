How to change package name after release?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/69707/how-to-change-package-name-after-release.

I've released a package named hpclrtt, for some reason i want to change the package name to microsrtt. I've done the local work in my repository. What else should i do in bloom?

Asked by sukha on 2015-09-20 20:27:31 UTC

Comments

Answers

Bloom will scan your repository when run and should release the new package and not release the old package. The pull request will change the packages indexed to the current state of your repository and it should not need any more intervention.
