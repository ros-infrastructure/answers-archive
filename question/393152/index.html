I am working on an obstacle detection robot using raspberry pi using radar and motor driver. I need to run the motor based on the subscriber data from the ultrasonic sensor. When the computations are inside callback it's causing a long time for computation. The motor movement should be spontaneous to the subscribed data. How to do that?

Chapter 11 of this book could be a good start for a more robust approach to navigation and obstacle detection in a mobile robot.

As you already noted, too much computation inside callbacks isn't enough for real-time situations.

You should try to separate the computation from fetching sensor data - do you need to compute everything each callback? Maybe some averaged data over longer period could work too? Do you need only the latest data?
