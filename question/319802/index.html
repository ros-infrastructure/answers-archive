Problem with setting origin of hector map

Hello!

I want to have the start position of my robot to be in the middle of the map when running hector slam so I have set mapstartx and mapstarty to 0.5. However, the result of this is that the middle point of the map is half a grid cell length down to the right, not in the middle. Why is it not in the middle?

In HectorMappingRos::setServiceGetMapData, I found this line:

mapOrigin.array() -= gridMap.getCellLength()*0.5f;

I removed this and now I get the expected result.
