This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/60685/make-sure-geometry-msgstwist-or-cmd-vel-units.

Hi all, I have confusion about the unit of geometrymsgs::Twist, are they m/s and rad/s? Because I saw the sample code turltebot teleop as well as kobuki teleop, they setup these parameters equal 1.0 for each press button. However I checked the specification of the turtlebot kobuki in this link , the maximum of linear velocity is just 70 cm/s, if my above opinion is right, the setup parameters in sample code is 100cm/s, it is overload the motor. So what is the true unit of geometrymsgs::Twist or cmd_vel?

Hi,

Units are in SI, so the units in the Twist message are, as you say, m/s and rad/s.

You can have a look at REP 103:Standard Units of Measure and Coordinate Conventions
