ira_laser_tools laser merge size issue

I have 3 lasers on my robot model at the front, left and right. Each one of the lasers is configured to take 50 samples. I then utilize the Ira-laser-Tool to merge all 3 lasers. I configured the laserscanmultimerger launch file as follows:

<launch>
    <node pkg="ira_laser_tools" name="sweepbot_lasers_merger" type="laserscan_multi_merger" output="screen" respawn="true">
        <param name="destination_frame" value="chasis_footprint"/>
        <param name="cloud_destination_topic" value="/merged_cloud"/>
        <param name="scan_destination_topic" value="/scans"/>
        <param name="laserscan_topics" value ="/scan_front /scan_left /scan_right" />

        <param name="angle_min" value="-1.5"/>
        <param name="angle_max" value="1.5"/>

        <param name="angle_min" value="-3.14"/>
        <param name="angle_max" value="3.14"/>
        <param name="angle_increment" value="0.0058"/>
        <param name="scan_time" value="0.0"/>
        <param name="range_min" value="0.10"/>
        <param name="range_max" value="10.0"/>
    </node>
</launch>

However, the size of the tuple returned by the merge tool is 814 instead of the 150 I was expecting since each of my lasers takes 50 samples.

Can anyone help me understand why and if I'm potentially doing something wrong ?
