In ros, a "plugin" is a dynamically-loaded library. This typically means that sometime after the ros node starts up (say, after the node reads its configuration information), it will load the library and begin making calls into it.

The navigation global planner is a plugin for the move_base ros node. It is move_base that is providing the necessary process state for your subscribe operation to succeed.
