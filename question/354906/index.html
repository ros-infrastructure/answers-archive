TurtleBot substitute

TurtleBot3 is not included in noetic distribution. Therefore, noetic beginners are out of luck as far as exercising TurtleBot/TurtleBot3 is concerned as it is not a trivial task to port TurtleBot3's source code into noetic due to the drastic difference between Python 2 and Python 3.
