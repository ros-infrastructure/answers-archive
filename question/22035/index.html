...

Answers

In file setup.sh, I changed the path in the environment variable GAZEBO_MASTER_URI from

GAZEBO_MASTER_URI=http://localhost:11345

to

GAZEBO_MASTER_URI=http://127.0.0.2:11345

then:

source setup.sh
