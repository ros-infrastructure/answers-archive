Answers

I have followed links from official ROS team to install ROS software in Ubuntu-18.

and

I run "sudo apt-get install ros-kinetic-ros-base"

ROS Kinetic is not supported on Ubuntu Bionic (18.04), but only on Ubuntu Xenial (16.04) (see REP-3).

That is why ros-kinetic-ros-base is not found.

You'll have to:

  • either downgrade to Ubuntu Xenial, or
  • install ROS Melodic
