Hydro Indigo interoperability

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/63508/hydro-indigo-interoperability.

If I have one system running ROS Hydro and another system running ROS Indigo, will nodes started on one of these systems be able to interact with nodes from the other (presuming the ROSMASTERURI is set correctly)?

In general yes, as long as the message definitions have not changed. It's not recommended, and should be heavily tested before being relied upon.
