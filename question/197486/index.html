Can map_server connect to costmap_2d directly with message or service?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/64033/can-map-server-connect-to-costmap-2d-directly-with-message-or-service.

Hi, all, I want to implement a node that implementing some functionalities based on the map which have to use the costmap2d. I hope that costmap2d should received the message from mapserver. However, I found there is no direct message exchange betweer mapserver and costmap2d, i.e. not topics or services between them. It seems that the movebase node has to launched beforehand.

Does somebody know that there is some direct way to connect them by launching only mapserver and costmap2d node?

Answers

You should be able to create an instance of costmap_2d that directly subscribes to the map. If you're using Hydro or later, make sure you are using the StaticMap layer. If you are using a version earlier than hydro, make sure ~static_map is set to true.
