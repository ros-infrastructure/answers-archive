Answers

The issue was that Gazebo was looking for the world files in /usr/local/share/gazebo However they were for some reason, installed to /usr/local/share/gazebo-9/

I copied the files to /usr/local/share/gazebo and I was able to successfully run Gazebo 9 using the command: gazebo -e dart --verbose
