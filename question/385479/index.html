How to allow a robot to establish its own network?

I have a robot that will operate in areas with no WiFi. That's a challenge for me because I need an internet connection to access the robot web-GUI which is being served from the robot itself. This all comes together using a combination of roslibjs, ros2djs, ros3djs and rosbridge.

I access the web-based GUI by typing robot_ip_address:8000 in the browser of any other device connected to the same network. This works well when there is a good WiFi connection. Will I be able to do the same if I was to add something like a dongle to the robot so that it establishes its own network?

Not sure if this is more of a hardware question than ROS, although I guess it's related to the networking side of ROS. Hope someone can point me in the right direction or offer some ideas!

This is indeed not a ROS question, but more a general "how do I setup a wireless access point that is provided by my robot?".

It should be sufficient to add some hw which allows you to make your robot a wireless access point. Either a separate piece of hw like a wireless router, or if that's too much (cost, weight, etc), a dongle which you can turn into an access point (by configuring it correctly). All of that is on the OS level, so not directly ROS related.

As soon as you can join your robot's access point with your laptop or other device(s), you should be able to use that connection to access your robot's resources -- such as the GUI you mention.
