Trouble with a part of a robot in Gazebo

I am building a robot simulation with a UR arm and a Robotiq 85 2 finger gripper. EDIT 2 (SOLVED): As I was not able to load the 2 finger gripper properly I decided to use the 3 finger hand, as long as I do not need a real robot to run my application, it is only for testing some software. At first I had the same problem loading the hand, it wobbled a lot in Gazebo. But after tweaking the controller it started to seem better. The wobble stopped just in the moment I load my own Gazebo world. It seems that the default empty world has a ground plane collision activated so it must make some kind of interference. As far as I know that had been an issue for some other people here. Their robot wobbled even in a empty world.
