Asked by delvingdeep on 2020-09-22 15:11:33 UTC

Thanks, that's very helpful. That menu looks normal; I see the same thing on mine. After you add the "Displays" panel, are you able to add visualizations ("Add" button in the lower left)? For example, you could publish a point from a new terminal with rostopic pub -r 1 /test geometry_msgs/PointStamped "{header: {seq: 0, stamp: {secs: 0, nsecs: 0}, frame_id: 'map'}, point: {x: 0.0, y: 0.0, z: 0.0}}". Then in the Displays panel, Add > By Topic > /test/PointStamped. You should see a purple sphere appear in the middle.
