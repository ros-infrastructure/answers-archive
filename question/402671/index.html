how to build rviz from source

Can't seems to find a tutorial on how to build/install rviz from github source. I modified a few lines in the source and now I would like to install this custom version of rviz. How should I go from here?

Answers

For the current stable, humble:

mkdir -p humble/src
cd humble
vcs import --input https://raw.githubusercontent.com/ros2/ros2/humble/ros2.repos src
colcon build --packages-up-to rviz2

Make sure to read https://docs.ros.org/en/humble/Installation/Alternatives/Ubuntu-Development-Setup.html
