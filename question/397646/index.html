How to detect Apriltag using visp_auto_tracker package ?

The documentation on https://wiki.ros.org/visp_auto_tracker says that it is possible to detect QR-Codes, Flashcodes or Apriltag. Which configuration should I change to be aple to detect an Apriltag ?

Answers

For detecting an April-tag one has to change the detector-type= april pattern.cfg file in visp_auto_tracker pkg. For QR-code detector-type= zbar and for flash code detector-type= dmtx.. and I think a git pull for the source code (https://github.com/lagadic/vision_visp) would be helpful, since the modification of detecting April-tag is relatively new.
