sensor_msgs in Windows

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/39153/sensor-msgs-in-windows.

I have images coming from a camera into a Windows PC (through an sdk that only works in Windows) and would like to publish the image as a message in ROS. I've used the image type from sensormsgs in Linux and would like to publish the same message in Windows, but I haven't found the sensormsgs package. Has the code for sensor_msgs been ported to Windows yet (or is it planned in the near future)?

It is possible (experimentally) to use the Fuerte version of sensor_msgs on Windows. However, the directions for building ROS Fuerte from source are still in progress.
