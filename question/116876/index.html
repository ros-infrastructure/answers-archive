Difference between scan matcher and odom frame?

Hi,

I'm using hectormapping with only laser scan data. It publishes 2 different frames one is map->odom the other one is map->scanmatcherframe. When i observe the values of them, they are exactly same (I get laserscan data from gazebo). So what is the difference of them? what if i want to implement an IMU data. which one should i use with?

thanks.

Answers

The scanmatcher_frame always provides the LIDAR pose directly in the used map frame (mainly intended for debugging). The map->odom transform will be (notably) different if the robot system provides odometry as essentially only the odometry error is corrected in that case. See the setup tutorial for info for info on how IMU data can be incorporated.
