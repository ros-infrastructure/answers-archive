How to init vcan0?

For setting up vcan, just follow the directions in the driver documentaion, section 6.4

And how to send messages using a dictionary in canopen_chain_node .

You cannot send message using a dictionary. But you can use the (currently undocumented) set_object service to write to the (remote) node object dictionary.

Asked by Dizett on 2018-02-22 07:01:58 UTC

canopen_chain_node does not expose any code API, only the generic topics (read) and the get/set_objects services. If you need more, you have to extend the chain node or use canopen_master directly. canopen_chain_node is mostly meant as base for profile implementations like canopen_motor_node.
