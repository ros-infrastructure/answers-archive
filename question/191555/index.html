Indigo is the latest version. I recommend you use it unless you do have any specific package not available in Indigo. Go for Indigo.

Most of packages` documentation is ready for Indigo as well. There will always be some leakages in documentation for latest versions. For specific packages, you can always compile for source .

Look for change log on ros website for exact difference
