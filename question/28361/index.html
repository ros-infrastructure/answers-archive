Hi!

Maybe you can try to install first lib ignition

sudo apt -y install libignition-common-dev

Also, try 

sudo apt install -f ros-humble-gazebo-ros-pkgs

I have everything working on Ubuntu 22 with ROS 2 Humble

Hope it helps!
