Does gazebosim support gyroscopic effect?

Does gazebosim support gyroscopic effect on rotating masses? If yes, which physics engine does support this?

Answers

All of Gazebo's supported physics engines support gyroscopic forces, though there are options to disable or limit gyroscopic effects since they can cause numerical instability. I'm not sure what settings are currently in use for each physics engine. We are planning to add several accuracy tests to gazebo, one of which will involve gyroscopic forces.
