Asked by SiuLam on 2013-10-15 22:16:39 UTC

It looks to me that you forgot run the step to get all dependencies needed. In particular:

 rosdep install --from-paths . --ignore-src --rosdistro hydro -y

Going into detail, the file required for your installation joint_limits_interfaceConfig.cmake can be installed using:

 sudo apt-get install ros-hydro-joint-limits-interface
