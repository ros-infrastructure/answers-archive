There is a test_ros package in ros_comm from the Fuerte release. It contains only message and service definitions. http://rosindex.github.io/p/test_ros/#fuerte-overview https://github.com/ros/ros_comm/tree/fuerte-devel/test/test_ros

It looks like test_ros was renamed to test_rosmaster. test_rosmaster has all the same service and message definitions as the old test_ros package https://github.com/ros/ros_comm/tree/indigo-devel/test/test_rosmaster

test_rosmaster is listed on the packages packages page in the wiki. http://www.ros.org/browse/details.php?distro=indigo&name=test_rosmaster

The wiki page says the website for test_rosmaster is just rosmaster http://wiki.ros.org/rosmaster
