Wow I found another solution, the one provided did not work for me! After setting thins up on three different pieces of hardware i finally found out it was a file that needed copied from src to main ros location here is the command i used please replace the username with yours. Also you must complete the groovy rosserial setup!

sudo cp -i /home//catkin_ws/src/rosserial/rosserial_python/src/rosserial_python/SerialClient.py /opt/ros/groovy/lib/python2.7/dist-packages/rosserial_python/
