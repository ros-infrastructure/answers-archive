I want to reduce the publish rate of each robot's pose topic, e.g. robot0/baseposegroundtruth, robot1/baseposegroundtruth, etc. due to my limited network bandwidth. With the number of robots increased the network is becoming congested. Is there any way to change or namely, reduce the publish rate of such stage topics so that I can release more network resources?
