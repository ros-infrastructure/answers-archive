Installing ROS Melodic in Ubuntu 18.10

I am trying to install the ROS Melodic in Ubuntu 18.10 by following the steps in http://wiki.ros.org/melodic/Installation/Ubuntu. Once I type sudo apt update i get "The repository 'http://packages.ros.org/ros/ubuntu cosmic Release' does not have a Release file." How can I fix this and successfully install ROS Melodic?

I'm going to close this as a duplicate of #q307097.

In short: Ubuntu 18.10 is not supported by ROS Melodic. Only Ubuntu 18.04 and 17.10 are.

Edit: but you can of course try building from source on 18.10 and/or use the Docker images available.

It's just that no binary packages are provided for 18.10 by the ROS buildfarm.
