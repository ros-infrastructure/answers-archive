Hi, In company I work for there's a Web UI to manually control our AGV. The Web UI uses 'rosbridgewebsocket' and inside that it initializes 'teleopkeyboard' node. There's no need to have 'linear.z' message and it causes problems for motor driver to work normally. I cannot find a way to eliminate 'linear.z' message. There's no file or anything to change teleopkeyboard node as far as I know.

rostopic echo /cmd_vel command gives this:

  x: 0.5
  y: 0.0
  z: -1.0   // this one I don't need
angular:
  x: 0.0
  y: 0.0
  z: -1.0
