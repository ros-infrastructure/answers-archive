Only ROS uses the "package://" URI. Gazebo uses either "file://full-path-to-mesh" or "model://name-of-model-in-modeldatabase/meshes/my-model-file.dae"

Asked by nkoenig on 2012-10-30 11:51:32 UTC

Answers

Only ROS uses the "package://" URI. Gazebo uses either "file://full-path-to-mesh" or "model://name-of-model-in-modeldatabase/meshes/my-model-file.dae"
