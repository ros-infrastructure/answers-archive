qHull-error when running a basic ROS-PCL example under ROS Noetic

Hi there,

I've installed ROS Noetic on a system using Manjaro Stable. Right now, I'm trying to use ROS in combination with PCL. For this, I've created and configured my catkin workspace and created a basic pcl package. Right now, I just try to run a very basic code example that's not even using pcl code. The tutorial I've used for this can be found under this link: basic pcl with ROS example

I'll post this code again so anybody can try to run it:

#include <ros/ros.h>
// PCL specific includes
#include <sensor_msgs/PointCloud2.h>
#include <pcl_conversions/pcl_conversions.h>
#include <pcl/point_cloud.h>
#include <pcl/point_types.h>

ros::Publisher pub;

void cloud_cb (const sensor_msgs::PointCloud2ConstPtr& input) {
    // Create a container for the data.
   sensor_msgs::PointCloud2 output;
   // Do data processing here...
   output = *input;
   // Publish the data.
   pub.publish (output);
}


int main (int argc, char** argv) {
   // Initialize ROS
  ros::init (argc, argv, "my_pcl_tutorial");
  ros::NodeHandle nh;
  // Create a ROS subscriber for the input point cloud
  ros::Subscriber sub = nh.subscribe ("input", 1, cloud_cb);
  // Create a ROS publisher for the output point cloud
  pub = nh.advertise<sensor_msgs::PointCloud2> ("output", 1);
  // Spin
  ros::spin ();
}

The package.xml file and the CMakeLists.txt are configured correctly according to the tutorial. I can build the package. But if I try to run this example using rosrun, I get the following error message: error while loading shared libraries: libqhull_p.so.7: cannot open shared object file: No such file or directory

Afaik this implies that the qhull library could not be found on my system. But the latest version of this library is installed (qhull 2020.1-1).

The ldd command of the binary file of the application showed that two versions of qhull seem to be needed, but only one of them seems to be installed (the newer version):

libqhull_p.so.8.0 => /usr/lib/libqhull_p.so.8.0

libqhull_p.so.7 => not found

I've tried to downgrade the qhull-package, but the error still occurs. My question now is: Is this a problem with ros noetic because it uses on an older version of qhull or did I make a mistake? Is there anyone else using Manjaro or Arch Linux having this problem? And what could I do to fix this problem? Because right now I can't run any ROS code on my system.

Thanks in advance,

Bakefish

I had the same problem today

download qhull-2019.1-4-x86_64.pkg.tar.zst from https://archive.archlinux.org/

sudo pacman -U qhull-2019.1-4-x86_64.pkg.tar.zst

back up usr/lib libqhull_p.so.7 and libqhull_p.so.7.3.2

install update to qhull 2020.1-1

move libqhull_p.so.7 and libqhull_p.so.7.3.2 to usr/lib
