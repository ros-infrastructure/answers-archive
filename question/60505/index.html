Change topic on pcd_to_pointcloud

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/50270/change-topic-on-pcd-to-pointcloud.

Hi- Does anyone know how to change the topic that a pointcloud is being published on using pcdtopointcloud? On the wiki it only says you can change the frame_id, like so:

$ rosrun pclros pcdtopointcloud cloudfile.pcd 0.1 frameid:=/odom

pcdtopointcloud publishes on the default /cloudpcd topic, but I'd like to specify my own topic. I tried changing _frameid:=/ to topic:=/mytopic but that doesn't seem to work.
