"Address already in use" when publishing sensor data under autuware.auto ADE environment

Based on ADE environment, I am following the steps in https://autowarefoundation.gitlab.io/autoware.auto/AutowareAuto/perception-stack-howto.html, after running the LGSVL simulator, when I try to connect to the sensor with:

Answers

If you are using LGSVL, you do not need to run the velodyne_cloud_node_exe. This driver is only for connecting to a real, physical sensor - not the one in simulation. If you are running LGSVL from the official Autoware docker container and you selected ROS2NativeBridge as the vehicle connection type then there should already be topics published from LGSVL under /lidar_front/points_raw and /lidar_rear/points_raw which are the outputs from the simulated lidars.
