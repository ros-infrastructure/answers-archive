Gazebo Installation error with ROS groovy

I am using ROS groovy and a platform ununtu 12.04 LTS.

I am trying to install gazebo 1.9 according to this link: http://gazebosim.org/wiki/1.9/install#Compiling_From_Source

I choose option compile from source and when I reach this command: hg clone https://bitbucket.org/osrf/gazebo

the output is: destination directory: gazebo requesting all changes adding changesets adding manifests adding file changes

and stopped I let it for an hour and no response another this and I can not complete the installation process.

What is my wrong?

Answers

It seems that you have a connection problem.

You can try the mercurial progress extension by adding this line to your .hgrc file:

[extensions]
progress =

Another thing you can try is the --debug option:

hg clone --debug https://bitbucket.org/osrf/gazebo

That might help to discover the source of the problem.
