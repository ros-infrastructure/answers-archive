imagetransport::Publisher cannot publishes compressed image and process exits when echo topic "**/compressed"

When I use imagetranport::Publisher and try to echo the topic or record the topic which is named "**/compressed", process always died and throws an error like this:

/home/hippo/catkin_ws/devel/lib/hikrobot_camera/hikrobot_camera: symbol lookup error: /opt/ros/melodic/lib//libcompressed_image_transport.so: undefined symbol: _ZN2cv6String8allocateEm

I try to search it on stackoverflow and try to debug to find what happen to my image_transport and get something like this.

$ ldd -r libcompressed_image_transport.so
...
undefined symbol: _ZN2cv6String8allocateEm  (./libcompressed_image_transport.so)
$ c++filt _ZN2cv6String8allocateEm
cv::String::allocate(unsigned long)

Please tell me what can I do for this

Answers

The most likely cause is that your ros package was compiled with an incompatible version of opencv. You must have the same version of opencv installed on your system that is used for the ros binary apt repository. For melodic, that is opencv version 3.2.0.

The fix is to install opencv 3.2.0 and do a clean bulld of your catkin workspace.
