Answers

For turtlesim, please try:

mamba update ros-noetic-turtlesim

And check it has been properly installed by:

conda list

Reference: https://github.com/RoboStack/ros-noetic/issues/158

For rqt, try: rqt_rviz instead. Reference: https://github.com/RoboStack/ros-noetic/issues/58

If the problem persists I suggest to raise an issue with the RoboStack team.
