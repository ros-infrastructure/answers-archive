Autonomous 2D navigation in unknown environment with fake landmarks published as MarkerArray message

Hi, I am pretty new user of ROS and I would like to ask for some advice about the way to implement a particular task I want to accomplish. I have an environment without a static map (so no global gridmap and/or costmap is provided). However I know the position of some obstacles, for simplicity represented as circles of different radius, in the environment. Each obstacle is represented as Marker.CYLINDER and all obstacles are collected as a MarkerArray ROS topic.

What I would like to do is to let my robot performing autonomous 2D navigation in the considered environment, avoiding these kind of obstacles. Since the obstacles are not urdf oblects and they are not saved in any .yaml file, but they only exist as MarkerArray ROS message, I cannot use the built in sensor provided by my robot platform (this is my opinion but correct me if I am wrong about this point).

Cosidering the described scenario, what could be the more suitable way to implemet a autonomous navigation algorithm? I suppose I should implement a kind of SLAM algorithm, considering the circular obstacles as landmarks. However according to what I found so far, the available packages implementing SLAM algorithms often rely on the measurements from the built in sensors of the robot platform. Other custom algorithms implementing landmark-based SLAM take into account only the landmark position, while in my case I think that also the landmark (obstacles) radius is important to make the robot correctly avoid the collision with the circular obstacles.

Do you have any auggestion about what kind of package, library, technique could be the most suitable one for this task? Thank you so much in advance.
