#include <ros/ros.h>

{ if (ofs.is_open())

int main(int argc, char **argv)

The build error is caused by the fact that msg is a pointer. You must dereference it using the -> operator.

You need to do: msg->pose.pose.x. This is called "dereferencing" the pointer.

I strongly recommend familiarizing yourself with C++ pointers: https://cplusplus.com/doc/tutorial/pointers/
