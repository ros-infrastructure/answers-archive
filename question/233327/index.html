Answers

I was only getting this problem a year ago when I was using an old version of turtlebot_arm. Using the indigo-devel branch from the official turtlebot_arm repo here https://github.com/turtlebot/turtlebot_arm doesn't throw this error for me now.

To fix this back then I traced the error back to mtk which traced back to yocs_math_toolkit. Clone https://github.com/yujinrobot/yujin_ocs into your catkin_ws and rebuild.
