shared dynamic_reconfigure_servers in different nodes

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/46589/shared-dynamic-reconfigure-servers-in-different-nodes.

Is it possible to have two different nodes with an dynamic_reconfigure::Server sharing the same "resource name" in the rosgraph context? This would be interesting to share configurations between different nodes. If someone send a config update request, then both nodes would be configured simultaneusly. 

Node1.cpp for process 1:
---
dynamic_reconfigure::Server server1(ros::NodeHandle("/shared/name"));
server1.setCallback(myP1Callback);
...

Node2.cpp for process 2:
---
dynamic_reconfigure::Server server2(ros::NodeHandle("/shared/name"));
server2.setCallback(myP2Callback);
...
