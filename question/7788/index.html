Can the directional light source simulator representation be rotated?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/27268/can-the-directional-light-source-simulator-representation-be-rotated.

In the simulator a directional light source appears as a green square with a line pointing down. The xyz position of this square changes if you modify the values, however the rpy values do not seem to be reflected by the square.

Neither does changing the values of the element change the direction the green square points.

Is this expected behavior (gz 2.2)?

Currently, the green box for directional light always points down. Changing the element will change the direction of the light, but not the green visual. Could you submit an issue for this problem to: https://bitbucket.org/osrf/gazebo/issues/new
