I believe this is answered in #q188398.

If so, please close this question as a duplicate.

To make it extra clear: you specify a list of dependencies that rosdep should ignore by adding --skip-keys to the command line you use to invoke it. Be sure to list rosdep keys, not package names used by Ubuntu/Debian/Your OS.

See also the documentation.
