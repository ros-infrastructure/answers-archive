When we say "debian," it's in reference to a binary package, a .deb file. That's the file format used by Debian Linux and Debian-based Linuxes, including Ubuntu Linux. At the moment, we're only building debians for Ubuntu. In the future, we might build debians for Debian (and other Linuxes).
