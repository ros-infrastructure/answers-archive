remote rviz does not set pose or goal

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/45627/remote-rviz-does-not-set-pose-or-goal.

I am testing navigation stack on my robot using rviz remotely. Rviz shows all the data from the robot without errors. But when I try to set robot position or goal position nothing happens. If I use rviz on the robot it works. Some weeks ago, I used rviz remotely without problems but now I cannot set position or goal despite the other data are displayed (laser, map, inflated obstacles, odometry). Any explanation/solution?

Answers

Probably a network problem. I guess you can ping your robot from the computer running rviz but not the other way around. In that case, rviz can connect to topics published on the robot, but the robot cannot connect to topics on your PC. Have a look at the network setup page.
