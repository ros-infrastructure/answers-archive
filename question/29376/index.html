I was having the same problem yesterday. I finally got it working by changing the setup.sh file in the ros folder to an older version I still had (see below). But this is not really a proper solution.

#!/bin/sh
# THIS IS A FILE AUTO-GENERATED BY rosinstall
# IT IS UNLIKELY YOU WANT TO EDIT THIS FILE BY HAND
# IF YOU WANT TO CHANGE THE ROS ENVIRONMENT VARIABLES
# USE THE rosinstall TOOL INSTEAD.
# see: http://www.ros.org/wiki/rosinstall
export ROS_ROOT=/home/erik/ros/ros
export PATH=$ROS_ROOT/bin:$PATH
export PYTHONPATH=$ROS_ROOT/core/roslib/src:$PYTHONPATH
if [ ! "$ROS_MASTER_URI" ] ; then export ROS_MASTER_URI=http://localhost:11311 ; fi
export ROS_PACKAGE_PATH=/home/erik/ros/robot_model_tutorials:/home/erik/ros/visualization_tutorials:/home/erik/ros/geometry_tutorials:/home/erik/ros/common_tutorials:/home/erik/ros/ros_tutorials:/home/erik/ros/documentation:/home/erik/ros/geometry_experimental:/home/erik/ros/robot_model_visualization:/home/erik/ros/geometry_visualization:/home/erik/ros/diagnostics_monitors:/home/erik/ros/executive_smach_visualization:/home/erik/ros/visualization:/home/erik/ros/slam_gmapping:/home/erik/ros/navigation:/home/erik/ros/vision_opencv:/home/erik/ros/laser_pipeline:/home/erik/ros/image_pipeline:/home/erik/ros/image_transport_plugins:/home/erik/ros/perception_pcl_electric_unstable:/home/erik/ros/image_common:/home/erik/ros/rx:/home/erik/ros/visualization_common:/home/erik/ros/physics_ode:/home/erik/ros/stage:/home/erik/ros/simulator_gazebo:/home/erik/ros/simulator_stage:/home/erik/ros/xacro:/home/erik/ros/executive_smach:/home/erik/ros/robot_model:/home/erik/ros/assimp:/home/erik/ros/pluginlib:/home/erik/ros/orocos_kinematics_dynamics:/home/erik/ros/nodelet_core:/home/erik/ros/geometry:/home/erik/ros/bullet:/home/erik/ros/filters:/home/erik/ros/eigen:/home/erik/ros/driver_common:/home/erik/ros/diagnostics:/home/erik/ros/common:/home/erik/ros/common_msgs:/home/erik/ros/bond_core:/home/erik/ros/common_rosdeps:/home/erik/ros/ros_comm

This was a bug (my fault) in rosinstall 0.6.2

Make sure to update rosinstall by either running sudo pip install -U rosinstall

or

sudo easy_install -U rosinstall vcstools
