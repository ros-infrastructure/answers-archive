Answers

This issue is described in the installation docs in section 4.3: http://wiki.ros.org/kinetic/Installation/OSX/Homebrew/Source You should manually create this link:

ln -s /usr/local/share/sip/Qt5 /usr/local/share/sip/PyQt5

Also check out my gist of successful ROS installation on macOS Sierra for solutions to further problems. I hope it helps somewhat. https://gist.github.com/lubiluk/361a018b267ca4e3ce10cdc68b17363d
