Answers

Use a rosinstall file at http://packages.ros.org/cgi-bin/gen_rosinstall.py?rosdistro=fuerte&variant=desktop-full&overlay=no

You can change the arguments in the URL to get what you need. The instructions in the wiki probably need to be updated.

EDIT: The above only works for overlays of core packages, the url is not suitable for source-installs.
