I'm using hectorquadrotor quadrotorwithasus.urdf.xacro (modified so to have the camera pointing in front as it is on my quad) to get a planner config to use in moveit. So what I want to ask is how do I update the robot pose on Rviz? What node do I have to created to, for example, pick the /tf info from the camera, write it to /jointstatepublisher and get a /joint_state topic?
