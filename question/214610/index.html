calc new pose according to twist

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/68900/calc-new-pose-according-to-twist.

Is there any library to do this? input geometrymsgs::Pose and geometrymsgs::Twist, output new geometry_msgs::Pose.

I found tf::addDelta(), but it's a little bit different: /// Starting from a Pose from A to B, apply a Twist with reference frame A and reference point B, during a time t. geometrymsgs::Pose addDelta(const geometrymsgs::Pose &pose, const geometrymsgs::Twist &twist, const double &t) _attribute__((deprecated)); and it's deprecated.

so is there any other library to calc new pose according to twist?

Answers

Assuming that your Pose and Twist are already in the same reference frame, simply add the linear portion of the Twist to your pose's position.

Then, convert your Pose's orientation to a tf::Quaternion. Store the angular portion of the Twist as a second quaternion using setRPY() and multiply the two Quaternions together.
