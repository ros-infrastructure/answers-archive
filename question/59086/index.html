Hi, when you build something, go to build directory and make sure you run ccmake .. from the terminal. Then check if all the libraries and include directories find the required pcl directories. The directories will be locate din /usr/include/pcl if you have downloaded PPA from http://pointclouds.org/downloads/linux.html otherwise, it will be in /usr/local/include/pcl and the libraries would be in usr/lib/ make sure that ccmake is configured with all the required libraries.. Then try to do make sudo make install
