Installing ROS on AWS EC2 Instance with Ubuntu Desktop GUI

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/67304/installing-ros-on-aws-ec2-instance-with-ubuntu-desktop-gui.

Does anyone have an installation procedure for ROS onto an AWS EC2 instance that utilizes the standard Ubuntu Desktop GUI? I have found several discussions online about using a VNC solution, but in talking to AWS, they are saying that any of these solutions of using a GUI will slow the system down significantly. I don't understand why the GUI is different and slower than a Window s Server GUI accessed through RDP.

Hi,

Typically AWS is accessed and configured via ssh. I have installed ROS on an AWS instance, but only on the command line. If you want to use windowed functions of ROS you would have to setup an X window server on your instance and use that to visualize any windows on your host PC.
