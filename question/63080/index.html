hokuyo_node, where to install with Groovy?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/51246/hokuyo-node-where-to-install-with-groovy.

I'm working to get the hokuyonode running on an embedded system (arm based BeagleBone). The ROS distribution on the Beagle is Groovy but the Hokuyonode tutorial references Fuerte (http://www.ros.org/wiki/hokuyo_node/Tutorials/UsingTheHokuyoNode).

I know the laserdriver was installed under opt/ros/fuerte/stacks in ROS Fuerte but the install locations for ROS are different in Groovy. Should the hokuyonode go in the rosws, the roscatkin_ws, or somewhere else?

Also, can just the hokuyonode be installed and not the full laserdriver package or would this require some editing of the pathways somewhere in the hokuyo_node?

Answers

You can probably install the Fuerte version in the corresponding Groovy location: /opt/ros/groovy/stacks.

It is generally safer to install all of a stack, in case there are inter-dependencies. If you are short of space, you can experiment with individual packages.
