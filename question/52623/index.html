But since no *libsensormsgs.so* shared library exists, I removed all occurrences of the -lsensor_msgs from the all linker.txt files and the libraries seem to build without any undefined references to sensormsgs symbols. ***So, does PCL really need to depend on sensormsgs?***

if that all works, move the folders back to src and try to compile it again
