Autoware pure pursuit cannot make sharp turning

I am using autoware + openplanner + pure_pursuit (forked version of Hatem's), with ROS melodic.

I found that Autoware cannot make a sharp turning while using LGSVL. As the video shows: https://youtu.be/S5q_eAClr5M

After magnifying the wheeling angle (calculated by pure_pursuit) 10 times, I got the correct turning behaviour: https://youtu.be/N4OqmO3F7ro

Here is the modified code in coreplanning/purepursuit/src/purepursuitcore.cpp, line 194:

void PurePursuitNode::publishTwistStamped(const bool& can_get_curvature, const double& kappa) const
{
  geometry_msgs::TwistStamped ts;
  ts.header.stamp = ros::Time::now();
  ts.twist.linear.x = can_get_curvature ? computeCommandVelocity() : 0;
  ts.twist.angular.z = can_get_curvature ? kappa * ts.twist.linear.x : 0;
  ts.twist.angular.z = ts.twist.angular.z * 10;
  pub1_.publish(ts);
}
void PurePursuitNode::publishCtrlCmdStamped(const bool& can_get_curvature, const double& kappa) const
{
  autoware_msgs::ControlCommandStamped ccs;
  ccs.header.stamp = ros::Time::now();
  ccs.cmd.linear_velocity = can_get_curvature ? computeCommandVelocity() : 0;
  ccs.cmd.linear_acceleration = can_get_curvature ? computeCommandAccel() : 0;
  ccs.cmd.steering_angle = can_get_curvature ? convertCurvatureToSteeringAngle(wheel_base_, kappa) : 0;
  ccs.cmd.steering_angle=ccs.cmd.steering_angle * 10;
  pub2_.publish(ccs);
}

Questions: This fix works well for sharp turning. But is it reasonable to do so ?
