The mapping for that message type is currently not implemented in ROS 2 (https://github.com/gazebosim/ros_gz/tree/galactic/ros_ign_bridge look for Actuators and see TODO). It is implemented for ROS Melodic since the corresponding ROS message mav_msgs/Actuators is available in Melodic (see https://github.com/gazebosim/ros_gz/tree/melodic/ros_ign_bridge), but not in later versions.

My recommendation would be to use the MulticopterVelocityControl system as shown in this example.
