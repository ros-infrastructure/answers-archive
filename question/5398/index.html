When to try to insert Atlas from Gazebo get this error:

Error [parser_urdf.cc:2608] Unable to call parseURDF on robot model
Error [parser.cc:273] parse as old deprecated model file failed.
Error [ModelMaker.cc:126] Unable to load file[/opt/ros/groovy/share/drcsim_model_resources/gazebo_models/environments/atlas_description/dummy.urdf]

And have problems when try to load from terminal using:

VRC_CHEATS_ENABLED=1 roslaunch atlas_utils atlas.launch

The roslaunch command changed in the latest versions and now is:

roslaunch drcsim_gazebo atlas.launch

Probably you have read an outdated documentation, could you please point me to it? Thanks.
