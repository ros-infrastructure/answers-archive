We dropped Trusty in Gazebo 8. The most recent version that you should be able to install from source or debs in Ubuntu Trusty is Gazebo 7 (branch gazebo7 on the repository). Make sure to remove your build directory before recompiling just in case.

The gazebo7 branch on https://bitbucket.org/osrf/gazebo will not depend on libqwt-qt5-dev. If you want to install gazebo from source, you'll need to clone the repository and update to the gazebo7 branch. Then try cmake, make, make install.

Asked by dbrodeur on 2017-03-27 09:13:49 UTC

Finally, I found out what was my problem. In this Gazebo tutorial (this links to the Gazebo 7 version of the tutorial as Gazebo 7 is the last version available on Ubuntu 14.04 Trusty), the first steps are the following : 

wget https://bitbucket.org/osrf/release-tools/raw/default/jenkins-scripts/lib/dependencies_archive.sh -O /tmp/dependencies.sh
ROS_DISTRO=dummy . /tmp/dependencies.sh
sudo apt-get install $(sed 's:\\ ::g' <<< $GAZEBO_BASE_DEPENDENCIES) $(sed 's:\\ ::g' <<< $BASE_DEPENDENCIES)

So I looked at the file /tmp/dependencies.sh in gedit and found out that I need to specify GAZEBO_MAJOR_VERSION=7 prior to running the script so that it does not look for libqwt-qt5-dev. So here is what I suggest to those trying to build Gazebo from source on Ubuntu 14.04. When installing the dependencies at the begining of the procedure in the tutorial, do the following instead : 

wget https://bitbucket.org/osrf/release-tools/raw/default/jenkins-scripts/lib/dependencies_archive.sh -O /tmp/dependencies.sh
ROS_DISTRO=dummy GAZEBO_MAJOR_VERSION=7 DISTRO=trusty . /tmp/dependencies.sh
sudo apt-get install $(sed 's:\\ ::g' <<< $GAZEBO_BASE_DEPENDENCIES) $(sed 's:\\ ::g' <<< $BASE_DEPENDENCIES)

Just added GAZEBO_MAJOR_VERSION=7 DISTRO=trusty to the second command line.

Then, building Gazebo from source (using gazebo7 branch) worked fine.
