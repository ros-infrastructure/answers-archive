Answers

  1. Look at the `turtlebot sim](http://wiki.ros.org/turtlebot_simulator)

  2. There is some overhead with Gazebo and ROS communication, but it's negligible compared with the performance costs of physics and sensor data generation.

  3. Creating a maze-like environment is easy. There are a couple of approaches:

    a. Create a maze using boxes.

    b. Create a maze in a 3d mesh editor, such as Blender

    c. Create a maze using the heightmap geometry.

    Option a will have the greatest performance, but will take the most time to create the world. Option B will be the most inefficient, but will give you a lot of flexibility. Option C sits between option A and B.

  4. I use 16GB Ram and an nvidia gtx-550-Ti with good results.
