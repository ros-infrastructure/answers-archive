It should be possible to check out the source code for the husky simulator from github and build it locally; but that process can be a bit of a big task for a beginner. (I think one of the later Clearpath tutorials may cover this)

If you're interested in a Jade release, waiting is not the best option. Instead, I'd suggest that you check the issue tracker on github to see if there's an issue requesting a Jade release, and if there isn't, create one.
