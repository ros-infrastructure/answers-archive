The Turtlebot4 code base is open source and includes launch and yaml config files that you might be able to repurpose on your bot.

https://github.com/turtlebot/turtlebot4/tree/galactic/turtlebot4_navigation

The manual is at https://turtlebot.github.io/turtlebot4-user-manual/software/nav2.html
