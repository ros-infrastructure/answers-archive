This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/59459/problem-with-fovis.

Hi guys

I tried to run fovis fovismonodepthodometer then I used freenectcamera to get data from my kinect

I wrote this launch file for that:

<launch>

<remap from="/camera/rgb/image_rect" to="/rgb/image_raw"/>
<remap from="/camera/rgb/camera_info" to="/rgb/camera_info"/>
<remap from="/camera/depth_registered/image_rect" to="/depth_registered/image_raw"/>
<remap from="/camera/depth_registered/camera_info" to="/depth_registered/camera_info"/>
<node
    pkg="fovis_ros"
    type="fovis_mono_depth_odometer"
    name="fovis"
    output="screen"
/>

<node
    pkg="freenect_camera"
    type="freenect_node"
    name="Driver"
    output="screen"
/>

</launch>

But I got this err:

[ERROR] [1400343285.543323291]: Depth image must be in 32bit floating point format!

This is graph of my nodes

and fovis didn't work.

any suggestion about my problem?

Answers

I used this launch file and openni.launch in openni_launch

<launch>
<remap from="/camera/rgb/image_rect" to="/camera/rgb/image_color"/>
<remap from="/camera/depth_registered/image_rect" to="/camera/depth_registered/image_raw"/>


<remap from="/camera/depth_registered/camera_info" to="/camera/depth/camera_info"/>

<remap from="/camera/depth_registered/image_rect" to="/camera/depth/image"/>


<node
    pkg="fovis_ros"
    type="fovis_mono_depth_odometer"
    name="fovis"
    output="screen"

/>


</launch>
