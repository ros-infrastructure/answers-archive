Answers

  • First problem: imageIn_ and imageIn are sensor_msgs::ImageConstPtr objects so you cant do .header . You either use ->header or create sensor_msgs::Image object from imageIn_ by doing sensor_msgs::Image image = *imageIn_; (more reading: http://answers.ros.org/question/196697/get-constptr-from-message/)
  • Second, imageOut_ is a cv_bridge::CvImage object. If you need to do some work with cv_bridge::CvImage, you will need to do a proper conversion. (follow: http://wiki.ros.org/cv_bridge/Tutorials/UsingCvBridgeToConvertBetweenROSImagesAndOpenCVImages)
