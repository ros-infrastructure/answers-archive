joint_state_publisher can be used to publish states of the joints. See this link for details: (http://wiki.ros.org/joint_state_publisher)

The data being published can then be subscribed by the robot_state_publisher, which then uses this data and the robot description within the urdf file to compute forward kinematics and generate a transform for the entire robot. The following link may also be helpful to you. (https://answers.ros.org/question/275079/joint-state-publisher-and-robot-state-publisher/)
