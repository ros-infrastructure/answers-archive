Automating simulations and rosbag recording via scripts

I am currently trying to write a bash script to automate the current process:

  • Roslaunch robot in simulation with navigation stack
  • Check for node(s) to be up
  • If nodes(s) are up; do rosservice call to give it robot a set of goals
  • Run rosbag record
  • Navigate through set of goals
  • End rosbag recording

I would like to know how to implement the condition to check if the node(s) are up before executing rosservice call and rosbag record. Either through a direct ROS command (if it exists) or a separate python/bash script to do the check(s). I am also open to other suggestions on how to implement the automation process. I will be very grateful if I can get some direction through examples. Thanks in advance.

Answers

I wrote a Python script using roslaunch to launch my launch files, rosnode to check if my node(s) are up, subprocess to do rosservice calls and rosbag record. I also included a subscriber to listen to the goals left in the goal queue before calling subprocess to kill all rosnodes. This works for a single simulation.

To run multiple simulations with the Python script, I used a bash script to call up separate terminals, export separate ROS_MASTER_URIs and ran the Python script in each terminal.
