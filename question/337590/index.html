@dinesh, in order to install the packages beyond ROS Melodic desktop_full on Windows, you will need to create a catkin workspace and checkout the source code of the desired packages. For your example, you will need to git clone https://github.com/ros-teleop/teleop_twist_keyboard into your workspace.
