You might be better off creating a new model withe desired configuration. You can easily create a simple plane in blender or whatever 3D software of your choice. Package it into a model package (by adding the relevant model.sdf and model.config and create a .world file to load into gazebo. See http://gazebosim.org/tutorials?tut=import_mesh for details
