In link below this question is answered:

Autoware.Auto still does not have implemented the Runtime Manager Interface for Autoware.Auto (It is just available for Autoware.AI). It still also does not provide the possibility to switch to different path planners and to create an automatic Benchmark from them as MoveIT framework provides.
