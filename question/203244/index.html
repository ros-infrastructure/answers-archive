How can I get the live-pointcloud in ROS to use with RVIZ?

So you want to take a previously recorded map (as .ply) and show it in RViz? As it said in the FAQ, this will only work for very small maps. You should write a small node that reads PLY and publishes PointCloud2. This will be useful: http://docs.pointclouds.org/trunk/classpcl_1_1_p_l_y_reader.html

Asked by JacoPisa on 2015-02-17 09:32:16 UTC

This is the include you need:

#include <pcl/io/ply_io.h>

You can get it like this:

sudo apt-get install libpcl-io-1.7-dev

It should be installed here:

/usr/include/pcl-1.7/pcl/io/ply_io.h
