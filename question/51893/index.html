Answers

Those are linker errors. Uncomment the linker flag block 

## Specify libraries to link a library or executable target against
# target_link_libraries(beginner_tutorials_node
#   ${catkin_LIBRARIES}
# )

That should fix it.

EdIT. The roscpp tutorials also have a catkin button that will guide you along the building process with catkin: http://www.ros.org/wiki/ROS/Tutorials/WritingPublisherSubscriber%28c%2B%2B%29
