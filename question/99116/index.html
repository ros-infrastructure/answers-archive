Ubuntu 13.10 and catkin

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/55326/ubuntu-13-10-and-catkin.

When I try anything at all with catkin, the system is unable to find it, unable to download it, unable to install it, anything at all. I need it in order to do a custom build gazebo-ros-pkgs, and I am unable to do anything with catkin because it cannot be found.

Answers

You are trying to run the catkin commands in a shell without the ROS directories added to the PATH. Specifically, you need to run either manually or in your .bashrc: source /opt/ros/hydro/setup.bash

Take a closer look at the setup tutorial: http://wiki.ros.org/ROS/Tutorials/InstallingandConfiguringROSEnvironment
