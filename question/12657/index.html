You are correct that ros-electric-perception-pcl does contain the pcl_ros package with the bag_to_pcd tool. What you are doing should work.

Since it does not, there is probably some simple mis-configuration. Please check your /etc/apt/sources.list.d/ros-latest.list, and make sure it contains "deb http://packages.ros.org/ros/ubuntu lucid main". Then, check all the other steps in the Ubuntu install instructions.

Asked by Michal on 2012-01-19 09:09:43 UTC

The problem for me was really a newer version of libeigen3-dev installed on my computer.

Using "sudo aptitude install ros-electric-desktop-all" instead of ..apt-get.. resolved the problem since aptitude worked out that it needs to downgrade libeigen3-dev and did it.
