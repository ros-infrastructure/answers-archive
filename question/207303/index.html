I'm trying to launch a gazebo server with the help of gzserver but I get this error:

Error [RTShaderSystem.cc:409] Unable to find shader lib. Shader generating will fail.Error [Server.cc:285] Could not open file[worlds/empty.world]

When I go to the directory where empty.world xml file is placed I see it exists. This is its content:

<!-- A global light source --> model://sun<!-- A ground plane --> model://groundplane<!-- Own physics settings to speed up simulation --> <maxstepsize>0.01</maxstepsize><realtimefactor>1</realtimefactor><realtimeupdaterate>1000 0 -9.8

Does someone have a clue what is wrong?

Answers

I encountered 'Error [Server.cc:285] Could not open file' when I tried launching gazebo with roslaunch gazebo_ros. I specified world_name:= (from within the directory where the .world was located). When I added the full path to the file, the error went away.
