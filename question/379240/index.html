How to quickly teleport in MoveIt?

Hi!

So I've been working on this planning problem where I need to teleport a robot arm to a specific location and check if it can reach/grasp an object. This needs to be done many times per second and the planning requests are quite easy. My current approach is to simply:

  1. publish tf world->robot that corresponds to new location.
  2. wait 0.2s to make sure moveit will use the new tf. If I don't do this, outcomes are not robust and error out.
  3. Ask moveit for a plan

The issues is that 0.2s wait. I have 1000s of request and this waiting time really accumulates. I looked into virtual joints - hoping that I could instead ask moveit to plan from an assumed starting state, but it seems they are also just based on tf.

Is there a way to tell moveit to assume a specific tf for robot root?
