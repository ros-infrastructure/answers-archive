Asked by fisc8617 on 2021-03-18 16:21:05 UTC

Hello,

The most important thing to make sure that, op_trajectory_evaluator can receive the detected objects topic.

1- check if kf_contour_track can receive the detected objects topic. 2- check if kf_contour_track can publish the tracked objects , and these objects are in the "map" frame. (open planner uses the "map" frame) 3- if kf_contour_track receive the data but doesn't publish any objects , disable the filtering options in the launch file 4- check that op_motion_predictor can receive the detected objects topic.
