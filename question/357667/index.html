navigation2: Timed out waiting for transform from base_link to map to become available

Hey Guys, I am currently trying to use navigation2 on dashing and foxy (separately) by building it from source. i have generated the map using SLAM-toolbox (https://github.com/SteveMacenski/slam_toolbox). For the navigation, I am trying to launch the navigation using either tb3simulationlaunch or bringuplaunch in (https://github.com/ros-planning/navigation2/tree/foxy-devel/nav2bringup/bringup/launch) by inputting my own map file generated through SLAM toolbox and usesimtime to be true. I got the following error in both foxy and dashing:

[worldmodel-5] [INFO] [globalcostmap.globalcostmap]: Timed out waiting for transform from baselink to map to become available, tf error: . canTransform returned after 1.125 timeout was 1.

Apparently, it is waiting for the tf map->odom. I was following this tutorial (https://navigation.ros.org/getting_started/index.html). For Dashing, i can click on "Startup” button in rviz, and then the map loads. For Foxy, the "Startup” button is not clickable, the map loads directly by launching the file so i hope this is not an error. But in both cases, the tf is not generated by giving the initial pose using "2D pose estimate" and i keep getting the above error about the missing transform.

Am i missing any step? I am not launching the AMCL separately as according to the tutorial it should be launched within the above mentioned launch files. Kindly guide if i am missing any steps. Thanks in advance.
