How to turn on generating the debug info?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/59627/how-to-turn-on-generating-the-debug-info.

Debug symbols information is missing from my node built from cpp file with catkin_make in hydro. I need it to debug the node with the gdb. How to turn on generating the debug info?

Asked by sd on 2014-05-26 06:39:39 UTC

Comments

Answers

Add the following to your CMakeLists.txt:

set (CMAKE_CXX_FLAGS "-g")

If you build the package from source you might want to set the CMAKE_BUILD_TYPE to either Debug or RelWithDebInfo (see http://www.cmake.org/Wiki/CMake_Useful_Variables) when invoking cmake:

catkin_make -DCMAKE_BUILD_TYPE=Debug
