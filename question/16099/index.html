Insert IMU in gazebo model

Hi, I am making a rover in gazebo. I have a SDF file for it. Now I want to include an IMU in the rover. I couldn't find any proper tutorials for it. Do I use hector If so how do I use it with a sdf file. If there is another way to do it how do I do it?

Answers

You can add an IMU to any link on your robot's SDF like this for example:

<link ...>
  ...
  <sensor name="imu_sensor" type="imu">
    <pose>0 0 0 0 0 0</pose>
    <always_on>1</always_on>
    <update_rate>1000.0</update_rate>
  </sensor>
</link>

Then you can check its output with:

gz topic -e /gazebo/default/<modelname>/<linkname>/imu_sensor/imu
