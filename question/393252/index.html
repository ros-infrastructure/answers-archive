Hi @infiniteGo, take a look at the gazebo plugins for RotorS for a MAV gazebo simulator: https://github.com/ethz-asl/rotors_simulator, you can adapt them to Ardrone.

Under rotors_gazebo_plugins/src folder you can see examples of GPS and odometry plugins:

namespace gazebo {

GazeboGpsPlugin::GazeboGpsPlugin() : SensorPlugin(), // node_handle_(0), random_generator_(random_device_()), pubs_and_subs_created_(false) {}

GazeboGpsPlugin::~GazeboGpsPlugin() { }
