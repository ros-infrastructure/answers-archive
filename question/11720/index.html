Even if the RoboEarth software would compile and run under ROS Diamondback, it is not recommended to do so. Some ROS packages we use changed significantly from Diamondback to Electric (e.g. the PCL library), so we cannot guarantee the software will work as expected under Diamondback.

There are instructions available to upgrade your TurtleBot drivers from Diamondback to Electric, though. See e.g. here.
