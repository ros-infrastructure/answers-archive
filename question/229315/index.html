How to let robot_pose_ekf recieve IMU data from gazebo

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/72838/how-to-let-robot-pose-ekf-recieve-imu-data-from-gazebo.

Hi all,

I'm using robotposeekf with gazebo simulator.

Now, I've encountered with a problem that the /robotposeekf only takes in /odom while the IMU data is not transferred.

To be more detailed, /gazebo published IMU data as topic: /mobilebase/sensors/imudata [sensormsgs/Imu]. However, /robotposeekf didn't subscribe this topic, instead it listen to /imudata which has no publisher! I feel it so strange and cannot understand it at all.

Can anyone tell me how to let /robotposeekf subscribe the right topic from /gazebo? FYI, in the launch file of /robotposeekf I tuned "odomused" "imuused" to "true" and "vo_used" to "false".

Any hints are welcome.

Thank you in advance.

Clack

did you try to remap /mobile_base/sensors/imu_data -> /robot_pose_ekf ?

http://wiki.ros.org/roslaunch/XML/remap

It works! Thank you so much!

But to be more precise, the command to be added in robot_pose_ekf.launch should be:

<remap from=”imu_data” to=”mobile_base/sensors/imu_data”/>
