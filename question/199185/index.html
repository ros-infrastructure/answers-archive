Loading generated maps into Gazebo

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/64538/loading-generated-maps-into-gazebo.

I've got some maps that I've generated using the gmapping/slam packages with a turtle bot. However I would prefer to be working within the simulated environment provided by Gazebo.

Is there a way I can get the pgm/yaml files generated by ROS packages such as gmapping into Gazebo? Ideally it would be loaded in as a heightmap, but even if I could just get the image in as a ground plane sort of thing that would be good.

Any ideas on how to go about doing this?

I'm not aware of a tool that can automate this (maybe the building editor for gazebo could help: http://wiki.gazebosim.org/wiki/Building_Editor). I previously used Blender to achieve what you describe. If you know how to use it, it's a few minutes of work to load the map image, trace the walls in 2D and then extrude walls from the 2D footprint, resulting in a mesh you can load in gazebo. How practical this is also depends on how often you have to do it and how complex the maps are, of course.
