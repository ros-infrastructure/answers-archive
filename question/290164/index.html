Asked by jarvisschultz on 2018-05-02 08:36:41 UTC

So, when you publish via the command line, Gazebo subscribes to that command and simulates a joint controller trying to track that command. If you want to control the arm from ROS, all you need to do is publish on those topics from any node (including the command line). This is not what the....
