I have transforms from map->odom->baselink->kinect2link->kinect2iropticalfram->cameradepthframe set up already and can visualize that in rviz. (I set map odom and baselink to the same frame ie. the transform is 0,0,0,1) the kinect depth scan to laserscan is working nicely and the costmap is generating.

Any help would be appreciated! I am running ros kinetic, ubuntu 16.04 on an Intel NUC
