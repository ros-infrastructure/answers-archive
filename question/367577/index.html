Should the gmapping wiki mention that the node subscribes to tf_static too?

I have been trying to create a map from a rosbag file for some time according to a few tutorials. These tutorials always mention that one needs to record the topics \scan and \tf when generating the bag. I did that and then replayed the bag while running the node slam_gmapping program from the gmapping package. Unfortunately, this did never create the map.

However, when I recorded the topics \scan \tf and \tf_static, I could create the map through replaying the bag. Additionally, when I type rosnode info \slam_gmapping I see the following info:

Subscriptions: 
 * /scan [unknown type]
 * /tf [tf2_msgs/TFMessage]
 * /tf_static [unknown type]

The info together with my attempts to create the map from replaying the bag made we wonder whether the wiki for gmapping should mentiond that it also subscribes to the tf_static topic?
