Hydro: Getting blank (black) screen in gazebo

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/26649/hydro-getting-blank-black-screen-in-gazebo.

I am getting a random blank (black) screen in Gazebo 1.9 under VMWare running ROS Hydro. I have run groovy and other releases and did not have this issue until hydro. Has anyone else running hydro with Gazebo 1.9 under VMWare experienced this problem. Or any insights as to how to investigate this other then going to a duel boot.
