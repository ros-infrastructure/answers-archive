Answers

As you can see, an error occurred when the function 'getattr(mod, attr_name)' is called:
 parameter 'mod' should be the path of the 'module'.
 parameter 'attr_name' should be the name of the 'object'.
For example:
 If we want to:from openai_ros.task_envs.turtlebot2.turtlebot2_wall import TurtleBot2WallEnv
 We should:getattr(openai_ros.task_envs.turtlebot2.turtlebot2_wall,TurtleBot2WallEnv)
Before you called the function:env = gym.make('TurtleBot2Maze-v0').
You should:
from gym.envs.registration import register register( id='TurtleBot2Maze-v0', entry_point='openai_ros.task_envs.turtlebot2.turtlebot2_maze:MyTurtleBot2MazeEnv', timestep_limit=timestep_limit_per_episode, ) from openai_ros.task_envs.turtlebot2.turtlebot2_maze import TurtleBot2MazeEnv
Where the id should be given as same as env = gym.make('TurtleBot2Maze-v0').
The entry_point should be given like:aaa:bbb:
 aaa is the path of the module 'turtlebot2_maze.py'
 bbb is the name of class MyTurtleBot2MazeEnv in module 'turtlebot2_maze.py'
Sometimes timestep_limit=timestep_limit_per_episode is needless,and we can:
#timestep_limit=timestep_limit_per_episode
The turtlebot2_maze.py is part of models in 'openai_ros' package , the version2 openai_ros can automatically download the model.
