Please clarify the usage relationship between Gazebo 5 and DRCSim

Here are my questions:

  1. If I first install Gazebo 5, and then install DRCSim to play with ATLAS, does DRCSim use GAZEBO 5 at all?
  2. Can GAZEBO 5 and DRCSim be installed on the same computer without interfering with each other?
  3. Will GAZEBO 5 run on Ubuntu 14.04?

Answers

There's a drcsim Release Schedule on the gazebo wiki. Drcsim is currently supported for Ubuntu 12.04 (precise) with ROS hydro and 14.04 (trusty) with ROS indigo. The debian package currently uses gazebo4, though it can be built from source to use gazebo5. There are pull requests pending that will allow it to work with gazebo6.

For your questions:

  1. Installing drcsim would install gazebo4, which would cause a gazebo5 debian to be removed. If you build from source, then you can have multiple gazebo versions installed into separate workspaces.

  2. Yes, if you use separate workspaces.

  3. Yes it does, if you add the apt key for packages.osrfoundation.org
