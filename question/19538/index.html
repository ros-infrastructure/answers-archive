heigthmaps slow down simulation

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/28495/heigthmaps-slow-down-simulation.

Im working on a proyect, and Im using heigthmaps models. When I add them to the simulatoin, Gazebo slow down a lot and even freezes. I have also realized that , the higher I set the max heigth in the sdf file , the slower the simulation is. Does anyone know why this happends?Is there any way to solve it? Im using gazebo 7 in Ubuntu 16.04.

Answers

  1. Can you try running gzserver without gzclient, does the problem still happen? You can monitor the real time factor with the command gz stats

  2. If the problem doesn't happen, you can try setting the level of detail for heightmaps for gzclient by adding this to ~/gui.ini:

    [heightmap]
lod=3

  3. You could also try reducing the definition of your heightmap
