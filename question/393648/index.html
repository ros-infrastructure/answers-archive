If you have a ros package that you want to build, you have to know which version of ros it is developed for e.g. noetic. Then you have to install that version of ros on your linux computer using apt, making sure to use the recommended release of ubuntu (that is ubuntu 20 for noetic.) Then you use rosdep to install the libraries & other ros packages needed by your package. Then you build your package.

Have you been given a ros package, or have you downloaded a random one from the internet?
