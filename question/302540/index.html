Is it true that I say: we have “/teleop_turtle” node that publishes the arrow keys pushed

yes, at a high level that is certainly what happens.

In reality though, it's not keys that get published, but geometry_msgs/Twist, so velocities (here).

Keystrokes are much too specific to this one application, while velocities generalise and can be used with all sorts of robots.

and “/turtlesim” node that shows it's subscribe by moving the turtle?

again correct.

turtlesim implements a simple simulation of a 2D platform and how that would/should move upon receiving geometry_msgs/Twist messages. In fact a lot of mobile bases with ROS compatibility use the exact same control interface as turtlesim.
