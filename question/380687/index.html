Asked by Akhil Kurup on 2021-06-21 11:22:48 UTC

The way I would approach this is similar to what you have done. The RadarScan.msg has an array of returns. Seems like you are pushing all your detection's into this vector. That is how I would approach this as well.

you might want to define the RadarReturn msg before push_back. Something like:

{
  msgRadarScan.header.stamp.sec = simTime;
  msgRadarScan.header.stamp.nsec = (simTime - msgRadarScan.header.stamp.sec)*1000000000;
  msgRadarScan.header.frame_id = "base_link";

  for (auto i = item.begin(); i != item.end(); ++i) {
    radar_msgs::RadarReturn radar_returns;
    radar_returns.range =  item[i].distance;
    radar_returns.velocity =  item[i].doppler_velocity;
    radar_returns.zimuth =  item[i].azimuth;
    radar_returns.elevation =  item[i].elevation;
    msgRadarScan.returns.push_back(radar_returns);
  }
}
