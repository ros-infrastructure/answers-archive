Running the tests with github actions seems to increase the failure rate.

I'm running ROS Noetic on Ubuntu 20.04 with GNU Make 4.2.1 and Python 3.8.10 Linux version 5.14.0-1055-oem (buildd@lcy02-amd64-045) (gcc (Ubuntu 9.4.0-1ubuntu1~20.04.1) 9.4.0, GNU ld (GNU Binutils for Ubuntu) 2.34)
