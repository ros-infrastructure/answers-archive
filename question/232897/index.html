This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/73561/couldnt-find-file-menu-in-gazebo.

My OS is ubuntu 14.04, ROS indigo, the version of Gazebo is 2.2.3 and I follow the tutorials in http://learn.turtlebot.com/. When I learned to edit map in Gazebo, I couldn't find the file menu. How can I get file menu back or is there other ways to save map?

I finally find it. As in http://gazebosim.org/tutorials?cat=guided_b&tut=guided_b2, (NOTE: Some Linux desktops hide application menus. If you don't see the menus, move your cursor to the top of the application window, and the menus should appear. ). Finally, I maximize the Gazebo window, and put the cursor to the top, GET IT!
