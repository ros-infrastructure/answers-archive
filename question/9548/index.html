There's a lot of information on that page. A simiple way to do this from their page is to use Synaptic.

  1. From the main menu open: System > Administration > Synaptic Package Manager
  2. Inside Synaptic: Open Settings >> Repositories
  3. Make sure that "restricted," "universe," and "multiverse" all have checkmarks next to them.
