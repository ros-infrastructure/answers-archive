Navigation using teb_local_planner with two Ackermann steering axis

Hello All,

We are currently working on the commissioning of an RR100 robot from the manufacturer Generation Robots. https://www.generationrobots.com/de/403763-mobiler-autonomer-forschungsroboter-rr100-research-ros-kompatibel-ugv.html

The robot has one driven axis (2 motors) and both axes are steerable. It is therefore a double Ackermann axis. On the main computer of the robot Ubuntu 18.04 with ROS Melodic is installed.

The first step of our project will focus on mapping, localization and autonomous navigation. Mapping and localization based on the integrated sensors (lidar, depth camera, IMU and GPS) is already working successfully and largely satisfactorily. For SLAM we currently use google Cartographer. We want to realize the navigation based on movebase with tbelocalplanner, because it supports car-like robots. We did all configurations based on the related tutorial and set the pivot point to the center of the robot. Based on the configurations, the robot is able to calculate an appropriate path and tries to head for the target. However, shortly before the destination it gets stuck and oscillates back and forth. Furthermore, we observe that the robot can only follow the path insufficiently. It overrides in many places. We have already tried to adjust numerous parameters (acclimx, acclimtheta, minobstacledist, inflationdist). However, this does not lead to any significant improvements.

We suspect that the reason for this limited navigation is the fact that the robot has two Ackermann axes, which is not covered by tbelocalplanner. Has anyone already implemented a ROS navigation with two Ackermann axes and can give us tips regarding the configuration? We are open to any tips!

I have attached the corresponding config files and the launch file to this post. https://github.com/APPROVEMENT/RR100.git

I thank you already now for your support!

Many greetings
