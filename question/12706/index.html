Does the simulated turtlebot in gazebo require calibration?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/37218/does-the-simulated-turtlebot-in-gazebo-require-calibration.

Hi, I would like to know if turtlebot which is simulated in gazebo requires calibration of Odometry and Gyro.

Thanks, Karthik

Asked by karthik on 2012-01-20 20:59:25 UTC

Comments

Answers

Calibration is not required, but note in simulation there's numerical errors associated with physics calculation causing the robot odometry to drift a bit as the robot drives around. The numerical error is associated with the time step size and the inner iteration steps setting if quickstep is used.
