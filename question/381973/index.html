Just had the same error, and ti was because I had the wrong branch of rviz checked out - retriever.hpp was introduced for the Galactic version of resource_retriever, so if you're on Foxy like I am (or an earlier version), then both the Galactic and Ros2 branches won't build - just check out the correct branch and it will work fine.
