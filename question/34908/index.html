This looks like there is a problem finding pr2_gazebo, but that is not your largest problem.

Gazebo from diamondback is known not to work on OS X, in fact gazebo in general does not work on OS X to my knowledge. However, there is a good chance that Gazebo 1.0.x will work on OS X in the the Fuerte version of ROS, but we are still working on that.

If you want to use gazebo at this time, my advice is to use Ubuntu, either in a VM or use bootcamp to install it along side OS X.

Sorry for the problems on OS X, but I hope this helps.
