Can Gazebo be told to ignore .svn folders or all hidden folders?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/26334/can-gazebo-be-told-to-ignore-svn-folders-or-all-hidden-folders.

My models are under SVN version control. This means a ".svn" folder is placed in all of the directories. So upon launching Gazeo, I get the error:

Error [InsertModelWidget.cc:254] model.config file is missing in directory["/home/.../WAMDatabase/.svn"].

Is there any way of telling Gazebo to ignore this file so I don't get the error? It's not a huge deal, but it'd make the legitimate errors stand out more.

Update: Bonus: ignoring the backup files created by gedit that end in "~".

Asked by Ben B on 2013-05-07 18:22:05 UTC

Answers

The model database specification does not allow for extraneous directories and files. This was done on purpose, especially for the case of version controlled files.

It's possible for Gazebo to download, and change, models within your svn repo. It's not safe to tell gazebo to use models from a version control system.
