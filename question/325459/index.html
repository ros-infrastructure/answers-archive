roslaunch kr150_moveit_config/launch/demo.launch

is this really the command you run? Depending on what the PWD is this will not work. roslaunch either accepts a path to a .launch file or a package and then a .launch file name.

So either:

roslaunch kr150_moveit_config demo.launch

or:

roslaunch ~/catkin_ws/src/kr150_moveit_config/launch/demo.launch

(assuming that is where the moveit config is).
