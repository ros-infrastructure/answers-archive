Answers

  • check your sourse list:

cd /etc/apt/sources.list.d

grep ros * | grep -v amd64

probably you will see ros2-latest.list:deb http://packages.ros.org/ros2/ubuntu bionic main

  • edit ros2-latest.list

change to

deb [arch=amd64] http://packages.ros.org/ros2/ubuntu bionic main

Thanks rwu for the answer.

I have actually resolved my issue but I think your way is more proper. It can serve as my remedy if I encounter similar issue in future. Anyway, what I did was:

I ended up downloading the deb package directly from http://security.ubuntu.com/ubuntu/pool/main/g/gcc-7/gcc-7_7.5.0-3ubuntu1~18.04_amd64.deb followed by installing it via the commands (ref: https://unix.stackexchange.com/questions/159094/how-to-install-a-deb-file-by-dpkg-i-or-by-apt)

sudo dpkg -i path_to_the_deb
sudo apt --fix-broken install
sudo apt update

Then, I was able to install ros-eloquent-desktop.
