Teb local planner doesn't move back when an obstacle approaches the robot

Hi there,

I'm using teb local planner for path planning in my project. The local and global cost maps consist of a voxel-layer, inflation layer and social navigation layer. When I set a goal, the robot navigates successfully to the goal and avoids inflated areas (grey cells in the cost map) as well as lethal areas (black cells in the cost map). But, when the robot stays at a given position and a dynamic obstacle approaches the robot from any direction, the robot just sits there until it collides with the object. I've already tried different parameters but for me it seems that teb local planner cannot deal with this situation where a dynamic object is approaching the static robot. Does someone know if there is a combination of parameters that deal with such situations? I've also tried this tutorial (http://wiki.ros.org/teb_local_planner/Tutorials/Incorporate%20dynamic%20obstacles) but it also only deals with path planning while having dynamic objects around. Not the situation where the robot is static.

Thanks for your help in advance. Best regards Peter
