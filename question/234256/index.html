However, when I remove the ~/.config/ros.org/rqt_gui.ini file and rebuild the catkin workspace, the plugin crashes with a segfault as soon as I select the frame topic. Strange enough, if I revert to the old rqt_gui.ini file (lucky that I made a copy of before removing it), the imageview plugin works again. I suspect that this is a problem of OpenCV 2 and 3, but I can not infer the relation to the `rqtgui.ini` file.

Does anybody have an idea, what is going on here?
