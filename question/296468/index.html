Hi :) ROS has Graph Resource Name to encapsulate resources such as Nodes, Topics. By using this, users can run multiple Nodes and make multiple Topics for robots. Similar questions you asked are opened in TurtleBot3 Issue page. You can find some information about how to setup multiple turtlebot3. Furthermore, we are preparing it to make more simple way to run.
