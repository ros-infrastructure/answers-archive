Publishing in different topics for each wheel

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/69328/publishing-in-different-topics-for-each-wheel.

How can I (having a 6-wheeled robot and using the DiffDrivePlugin6w from hectorgazebo plugins) make that each wheel subscribes in a different topic: Now I've been able to make that all the wheels move at the same time (they are all "answering" to the cmdvel topic), but I'd like something like cmdvelfrontleft topic,....

Answers

You would need to write a new driver for this. The DiffDrivePlugin6W takes in the /cmd_vel topic for the base_link and not for each wheel seperately! It then computes the single wheel velocities based on this command.

Thus, using this Plugin, you cannot do what you want without modification.
