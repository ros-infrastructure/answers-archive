How to create a curved road using <road> tag from SDF version 1.6 in Gazebo?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/28515/how-to-create-a-curved-road-using-road-tag-from-sdf-version-1-6-in-gazebo.

This question and its answer provides a way to create a straight road in gazebo:

http://answers.gazebosim.org/question/18565/how-to-make-a-simple-straight-road-in-gazebo/

How should I modify this to create a curved road in Gazebo?

Thanks.

Answers

You can make it out of several small segments, for example:

 <road name="my_road">
   <width>7.34</width>
   <point>0 0 0</point>
   <point>5 2 0</point>
   <point>8 5 0</point>
   <point>10 10 0</point>
 </road>
