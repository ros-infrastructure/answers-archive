You should start with the ROS tutorials to understand how topics, services and actions work. Depending on how are you going to give commands to your turtlebot (using the topic or using a service or action) you are going to need the appropriate API for that. Topics: http://wiki.ros.org/ROS/Tutorials/WritingPublisherSubscriber%28python%29 Services: http://wiki.ros.org/ROS/Tutorials/WritingServiceClient%28python%29 Action client: http://wiki.ros.org/actionlib_tutorials/Tutorials/Writing%20a%20Simple%20Action%20Client%20%28Python%29
