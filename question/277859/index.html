Answers

In apriltags_ros/apriltags/src/TagDetection.cc change line 95, cv::Matx33f ... to :

cv::Matx33d cameraMatrix( fx, 0, px,
                          0, fy, py,
                          0,  0,  1);

(Just f to d)
