I see 2 problems with model.urdf: (a) there aren't any links, and (b) if you want to embed this in another urdf file using xacro includes you'll need to remove the robot tag, as URDF allows only 1 robot. Take a look at the URDF tutorials for more: http://wiki.ros.org/urdf/Tutorials
