Hi,

it seems like you have a very old gazebo version installed (1.5) which is started when you run the launch file 

Gazebo multi-robot simulator, version 1.5.0 Copyright (C) 2013 Open Source Robotics   
Foundation. Released under the Apache 2 License. http://gazebosim.org

my guess would be you have the old package ros-groovy-simulator-gazebo installed

you can find out which executable is used to launch gazebo by typing which gazebo | xargs ls -la If I'm right this link will point to an old gazebo version(and not to the one that works with gazebo_ros which should be at least 1.9 )

if this is the case you can try the following solutions:

  • fix the links to gzclient, gzserver & gazebo manually.
  • just uninstall the conflicting package (which might cause problems if it is installed with the meta package ros-groovy-desktop-full). In this case it might be needed to reinstall gazebo-current to get the links to the executables right again

In general when installing gazebo from OSRF sources make sure that there is no old version installed from the official ros packages!
