Conversion of euler angle from a right-handed frame to another

I'm using an IMU which defines its Y axis pointing forward, X pointing to the right and Z pointing upwards, which is not consistent with the convention in REP-103.

Now I have the roll, pitch and yaw data obtained from this IMU output, but what I need is the quaternion represented in the right-handed frame with the same definition in REP-103.

How can I do this conversion?

I've worked it out. The following code solves the problem: 

tf.transformations.quaternion_from_euler( -radians(roll),radians(pitch), radians(yaw), 'syxz')
