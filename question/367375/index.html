teb planner producing inconsistent results

Hi,

I'm using the teblocalplanner package within ROS Kinetic on Ubuntu 16.04 LTS.

I'm seeing the teblocal planner produce inconsistent results when trying to fit a path from a start point to a goal point with no obstacles or viapoints in between. In the pictures below, you can see various attempts to fit a path between the left point and the center point. In between each attempt, no changes are made, including all of the parameters that govern the planner. I simply wait 10 seconds and then re-send the same pair of poses to the planner, and the results differ significantly each time. It is as if the planner is behaving as a time-varying system.

planner_->plan(pose1, pose2);

Answers

I figured out the problem. By placing a call to clear the planner just before sending a new plan, the problem was resolved. 

planner_->clearPlanner();  
planner_->plan(pose1, pose2);
