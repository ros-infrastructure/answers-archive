This project is not an easy one. However it is very funny. First of all I strong recommend you to do all the tutorials to get some basic knowledge about R.O.S. http://wiki.ros.org/ROS/Tutorials

After that I think you have to concentrate in the navigation stack. http://wiki.ros.org/navigation/Tutorials

Finally I think this is a great tutorial also and exactly what you need http://wiki.ros.org/turtlebot_gazebo/Tutorials/indigo/Make%20a%20map%20and%20navigate%20with%20it

It is better to try in a simulated environment (i.e. Gazebo) and then, after doing all of this you will know exactly what hardwarde you need to buy.
