Install ROS2 packages at specified location - source build

Hi,

I am using debian10(buster) 32 bit. Since ROS debian packages are not available for this version, i followed instructions for building ros2 from source and all the required packages are compiled and placed in install folder (in my home directory).

I would like to install the libraries, headers and share folders at /opt/ros/foxy/ (or /usr/local/) as if any other default debian installation. Is there any argument that can be passed during colcon build in order to place the packages after/while they were build ?

Answers

colcon provides an --install-base option that will place the installed files anywhere in the filesystem. Be careful with this though because the files won't be managed by the system package manager and there's no guarantee old files will get replaced if you ever reinstall, for example. If you go this route, I would advise using /opt/ros over /usr/local and fully deleting it prior to each installation.
