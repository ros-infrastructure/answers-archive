Now I tried to use aruco marker detection by using opencv's aruco marker library e.g. package simplearucodetector. (#include <opencv2/aruco.hpp>) This works and I am able to detect markers with that program. But I want to get it to work with the aruco library from ros as I want to use aruco_mapping pacakge.

I use ubuntu 16.04, ros-kinetic. And I also use the usb_cam package to get the images from the camera.
