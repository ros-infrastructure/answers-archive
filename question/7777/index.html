I had a similar issue when trying to update and run the husky simulation in indigo. I believe that the current git repo is still in devel and hence full sync is not available yet. Try cloning the urdf directory at https://github.com/husky/husky_simulator.git under the husky_gazebo folder and adding it to the /opt/ros/indigo/share/husky_gazebo folder. Make sure to change file permissions to allow writing.

Hope this helps.
