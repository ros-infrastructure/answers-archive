Move_base error: Local costmap doesn't work (robot unable to do obstacle avoidance)

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/65500/move-base-error-local-costmap-doesnt-work-robot-unable-to-do-obstacle-avoidan.

Hi!

I am using Hydro on Ubuntu 12.04. I have tried the turtlebotsimulation tutorials and all went well. I am using Kobuki robot but I have changed the laser scanner input from the kinect to a laser. The laser seems to be correct as I can see the laser in RVIZ. However, when I launch movebase, the local costmap does not seem to be reading the laser and hence the robot fails to avoid obstacles that are not on the map. The global costmap shows correctly, but there is no local costmap. I am using 100% the same settings as in turtlebot_navigation package - the only difference is that I have a laser model instead of the Kinect.

I have tried the following reference, but it still does not work.

http://answers.ros.org/question/128496/navigation-stack-cant-avoid-obstacles-in-hydro/

Any ideas? Thanks!

Answers

I figured out that after I change the min_obstacle_height of the laser from 0.25 to 0.0 in costmap_commom_params.yaml, the obstacles can be shown in the costmap now. And the robot can do obstacle avoidance. Still thank you for your reply!
