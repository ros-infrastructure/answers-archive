Robot global position

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/64945/robot-global-position.

I want to get the global position of the robot by using rostopic echo /odom/pose/pose after reading through this page https://www.packtpub.com/books/content/navigation-stack-robot-setups. However, I got the following error "WARNING topic [/odom/pose/pose/] does not appear to be published yet"

How exactly can I get the global position of the robot at any time I want?
