This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/94648/catkin-install-missing-dynamic-reconfigure-header-file.

Answers

At last found the error which was related to the .cfg file where i had imported some old method that seems to be used for rosbuild and not catkin

I imported

from dynamic_reconfigure.parameter_generator import *

while the correct import is

from dynamic_reconfigure.parameter_generator_catkin import *

Now it seems to be working fine
