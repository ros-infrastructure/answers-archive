Is it possible to install ROS natively for Windows with only VSCode and NOT Visual Studio?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/98404/is-it-possible-to-install-ros-natively-for-windows-with-only-vscode-and-not-visu.

In some professional environments, Visual Studio Community Edition is not allowed and neither are any forms of Ubuntu (whether through WSL/WSL2 or through virtualization). Is it possible to install ROS (1 or 2) natively for Windows 10 with only Visual Studio Code (VSCode) and neither Visual Studio Community nor Visual Studio Pro? None of the setup tutorials hint at this possibility. Thanks!

Answers

The Full Visual Studio installer comes with the build tooling and debuggers, which VSCode leverages. We (Azure Edge Robotics team, who maintains the VSCode ROS extension) have experimented with installing SDKs piecemeal. I created this tracking bug - https://github.com/ms-iot/vscode-ros/issues/396.
