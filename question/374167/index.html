I think that your build issues are not related to the nav2 stack, but rather to your environment. As you can see here Continuous Integration jobs are all green, so the code builds fine on the servers.

Do you really need to build from sources? nav2 stack is available from debian packages. I assume you already followed the build and install guide: https://navigation.ros.org/build_instructions/index.html
