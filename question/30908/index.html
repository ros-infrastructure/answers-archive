Determine a Node's Name/Namespace from within the Node (C++)

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/39187/determine-a-nodes-name-namespace-from-within-the-node-c.

Hello,

Is there a way to determine the name of a node and/or its namespace from within the node's C++?

Thanks!

Asked by gavinmachine on 2012-03-30 13:49:21 UTC

Comments

Answers

Use ros::this_node::getName() and ros::this_node::getNamespace().

To get just the node name without the namespace:

ros::this_node::getName().substr(ros::this_node::getNamespace().size() + 1);
