Answers

The problem is the color

    <material name="Cyan3">
        <color rgba="0 0.5 0.5 0"/>
    </material>

The alpha value is set to 0, meaning transparent. Try

    <material name="Cyan3">
        <color rgba="0 0.5 0.5 1.0"/>
    </material>
