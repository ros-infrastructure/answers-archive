Problem working with vanilla cmake packages as dependencies in caktin_ws

I have a pure cmake complex package that generates its own .cmake files that can be used to find the libraries later from other packages (including ros packages). It can be successfully built by catkin since it has a package.xml file and can also be found by ros tools like roscd and find_package.

The problem I have is that catkin operates in weird ways when setting include directories while building. Can anyone from the ROS team explain why this is the case? Here is how it goes:

when I build a ROS package in catkin_ws, the generated build rules will be different depending on the situation:

1- at least one dependency of the package to be build also exists in catkinws as source code, then catkinws/install/include will be included before /opt/ros/melodic/include

2- the package to be built has no dependencies that are in catkinws, then /opt/ros/melodic/include will be included before catkinws/install/include

I can't add my pure CMake package to find_package(catkin REQUIRED COMPONENTS complex_package) since it has a different set of .cmake files that are included later and doesn't generate a complex_packageConfig.cmake.

This results in catkin build thinking that the complex package is not in the catkinws and thus including /opt/ros/melodic before catkinws (In this case /opt/ros/melodic has an older version of complexpackage that is not compatible with the code I am trying to build, while I have the newer complexpackage source code on catkin_ws and it builds and installs fine).

This results in a build error. The only two solutions I see now are:

1- Manually generate a complexpackageConfig.cmake and add it as a static file (complexpackage can't have any ROS stuff as dependency)

2- Force catkin to always include catkin_ws/install/include before /opt/ros/melodic. But how to do that? A hint on where these includes are generated would be very helpful

I'd rather refactor stuff in catkin and go for solution 2 unless there is a good reason why catkin does it this way. Can anyone point me to the right direction on what to do?
