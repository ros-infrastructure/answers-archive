Why do gazebosim uses ODE instead of Bullet?

I heard the reason to this, is that Bullet's latest version is not working with Ubuntu. Is it true? If it would work with Ubuntu, would gazebosim uses Bullet instead of ODE? If not, please explain me why, beacuse i heared Bullet is much more reliable and faster then ODE.

Answers

The latest versions of Gazebo compiled from source support 4 physics engines: ODE, bullet, simbody and dart. Historically, Gazebo only used ODE, hence it is the default one. We are currently running tests to compare the accuracy and speed of each physics engine and will publish these in a scientific meeting.
