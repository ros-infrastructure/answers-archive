Once upon a time Gazebo had OpenAL integrated. This got removed due to lack of support. You can still find the code by cloning the Gazebo repo and updating to revision 2bf80da8fe68.

We'd love help putting OpenAL back into Gazebo. Let me know if you're interested in this effort.
