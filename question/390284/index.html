It's a broad question as there are many approached to optimize. First question you could ask yourself is, do you really need this high quality imaging for your application? If not then by resizing, you could see a major boost in efficiency. If that's not an option, the you can question the frames per second, if you can lower it, then you should see a benefit but not as significant as with resizing. You could stream a lower quality image by using for example K-means. There are many advanced tools in machine learning that can do that as well.
