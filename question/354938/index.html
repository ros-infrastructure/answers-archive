Hello

I performed the standard installation of ROS KINETIC following this tutorials (http://wiki.ros.org/catkin/Tutorials/createaworkspace ; http://wiki.ros.org/kinetic/Installation/Ubuntu). However I would like to make a small change to the movebase code, (*being more specific I would like to make a small change to the part of the code of the movebase that calls the my own global planner's makeplan method*). Should I download the movebase from github (could someone provide me with the correct link?) to my catkin workspace and recompile with catkinmake? If so, how to make ROS use this new version of movebase recompiled instead of the one that came with the standard installation?

thanks

ROS will search your ROS_PACKAGE_PATH in order, so packages in your own workspace will be found before the ones in /opt/ros... . Your self-compiled move_base will thus be used automatically instead.
