How to provide the relative path for mesh files?

The world file successfully loads along with the model when opened from the world folder. I had included the following code in the world file. 'map4.dae' exists on the same folder as the world file.

<model name="fmm_map">
   <pose>0 0 0  0 0 0</pose>
  <static>true</static>
  <link name="map1">
    <visual name="visual">
      <geometry>
        <mesh><uri>file://map4.dae</uri></mesh>
      </geometry>
    </visual>
  </link>
</model>

However on trying to open from a launch file, 

<include file="$(find gazebo_ros)/launch/empty_world.launch">
    <arg name="world_name" value="$(find p3dx_gazebo)/worlds/p3dx.world" />
</include>

it fails to open. The following error occurs. Kindly help.

File or path does not exist[""]

Answers

I was able to get it fixed.

I used 'model://' instead of 'file://'. Also the base path for the relative path is taken from the environment variable GAZEBO_MODEL_PATH.

So finally the code looked this way.

<mesh><uri>model://ua_ros_p3dx/p3dx_gazebo/worlds/map4.dae</uri></mesh>

If the mesh file is in the same package, and you have the following directory structure:

worlds

|-- p3dx.world

meshes

|-- mesh1.dae

|-- mesh2.dae

Then in your .world file you can simply: <uri>../meshes/mesh1.dae</uri>
