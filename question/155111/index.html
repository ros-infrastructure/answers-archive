This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/58852/update-the-map-server.

Does anyone know a way to update the map that mapserver uses? AFAIK, the map is set to the contents of an image file as soon as the node is launched, then remains static for the life of the node. My situation is as follows: I have two nodes this job mapper and *mapserver. *Mapper records ultrasonic range measurements into a png file, and has a service for saving updated versions of the map. How can I push updates of the map to my map_server node?? Will I have to relaunch the map_server node every time? Thanks

I think you're doing it too complicated. If your Mapper node already has a map there is no need to send that to the map server. Just publish it from the Mapper node at the /map topic.
