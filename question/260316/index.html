I had the same problem. When I checked the Ubuntu crash report I realized that the error was coming from Qt library. I had a software package which was referencing QT libs from a different path. Once I setup the environment variable LD_LIBRARY_PATH=/5.7/gcc_64/lib I was able to run rqt without segfault. Hope this helps.

I have the same issue. And I tried this it works on my system (Ubuntu 16.04.3 LTS):

  1. Remove python-sip

sudo apt remove python-sip

  1. Reinstall the ROS (This will just install the packages related to pyqt etc., which is just 41 MB). I installed kinetic so the code is

sudo apt-get install ros-kinetic-desktop-full

  1. At the end update and upgrade the system
    sudo apt-get update
    sudo apt-get upgrade
