Are Ros_Comm and Gazebo compatible?

Hi, can i use Gazebo with Roscomm? I want to run ROS on raspberry pi 2(Raspbian) and roscomm(which is non-gui version) is recommanded rather than desktop version.

Is it possible?

Asked by Reactionic on 2015-12-01 11:27:16 UTC

Comments

Answers

Gazebo uses a different message passing protocol than ROS. Currently, Gazebo uses a combination of boost::asio and protobufs. ROS currently uses custom messages and a custom transport library.

So, Gazebo is not compatible with ros comm, unless you write a ros node to translate messages from gazebo to ros.
