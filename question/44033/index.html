Answers

Try removing libassimp-dev and the other problems you are having trouble with. You likely have a newer version installed.

If this doesn't work, start the system install over. To do this without losing any data, I recommend you install as you usually would, but DO NOT format the drive. Doing so will erase your data. By not formatting the drive, you can keep the data but override the operating system files.
