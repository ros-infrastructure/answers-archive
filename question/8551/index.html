ros client/server programs with gazebo::transport

Hello

I have a Gazebo project that is in need of the ros "Services" functionality (in where a client node sends a request message to a server node, which processes it and returns a response).

I have been able to do this by simply implementing creating a 'standard' ros node and launching it from the gazebo launch file, however I was wondering if this functionality has been implemented in the gazebo::transport class? The reason I want to do this is so I have a more simple means to access gazebo objects (models, joints etc) as I would be able to create my server/client nodes natively inside gazebo plugins, and also be able to use native gazebo messages.

Has this functionality been developed? I have had a look online without much luck. I found the 

 boost::shared_ptr <msgs::Response> gazebo::transport::request(const std::string &_worldName, const std::string &_request,const std::string &_data = "")

method in the API, but I dont think that this offers what I am after. It seems to only be used for the pre-compiled gazebo service topics (i.e gazebo/set_model_state gazebo/get_world_state etc)

Any help is greatly appreciated, Cheers! Joe

If you are looking for a native bridge from gazebo transport system to the ROS transport system, I don't think that it currently exist.

For integration between a Gazebo plugin and the ROS transport layer, you can probably look at DRCSim gazebo_ros_plugins which interacts with ROS. For example, the IRobotHandPlugin.
