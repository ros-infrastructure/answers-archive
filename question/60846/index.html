I am using the new mimic tag that is included in the urdf/XML/joint element, like so (this is xacro):

    <origin xyz="0.026 .017 0" rpy="${1.04*M_PI} ${M_PI/2} ${34.58*M_PI/180}" />
    <axis xyz="1 0 0" />

    <dynamics damping="50" friction="1"/>

  ...
