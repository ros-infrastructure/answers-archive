Bool deserialization exception when using MicroROS with PlotJuggler in ROS2

I'm using MicroROS (on stm32) with ROS2 Galactic. When using PlotJuggler to visualize messages from MicroROS, I saw this error message attached below.

I did confirm that PlotJuggler (3.4.4) was having issues with the deserialization of bool in messages by replacing all bools in messages published from MicroROS to uint8_t -- then it's working. But I don't think this is an elegant solution and it will make my codebase messy.

Does anyone know if there is a solution to this issue? I've seen discussions saying that this might be caused by incompatible serialization/deserialization of bool between ROS2 and MicroROS, but haven't been able to find a solution yet.
