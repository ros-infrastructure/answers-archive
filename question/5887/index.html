Answers

Based on Andrei's comment I changed my code and now it works.

Thanks to Andrei :-)

void delete(const std::string& name){
    # Info world_ is of type physics::WorldPtr 
    physics::ModelPtr p = world_->GetModel(name);
    p->Fini();        
}
