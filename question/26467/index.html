I think it might be having problems locating the included model in the world file. Included resources are handled differently in ign-gazebo (see https://ignitionrobotics.org/api/gazebo/4.2/resources.html for details). Setting IGN_GAZEBO_RESOURCE_PATH to the directory containing tetrapod_description fixed the issue for me.

Running ign gazebo with -v 4 might show some helpful information.
