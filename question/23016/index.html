I just found this and it seems to solve this particular problem for now:

export SVGA_VGPU10=0

Not sure if that is different from turning off 3d acceleration in VMWare.

Asked by Pitosalas on 2019-06-22 08:45:18 UTC

Comments

It is different, it basically downgrades support of OpenGL to 2.1. Turning off 3D acceleration from VMWare would basically run rendering code entirely on the CPU.
