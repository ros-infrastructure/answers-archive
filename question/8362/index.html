Can you visualize the laser in Gazebo (in the Gazebo gui, press Ctrl-T then find the laser scan topic)? Also check from the command line using ros topic list to see if the topic is there and ros topic echo to dump output from the topic. If those fail, check that the model is loaded properly by inspecting the model in the gazebo gui through the model tree list on the left side.
