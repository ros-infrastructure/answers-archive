I am following this tutorial: http://wiki.ros.org/dynamixel_controllers/Tutorials/Creatingmetacontroller

When I run the command

roslaunch mydynamixeltutorial startmetacontroller.launch

Controller Manager shows following:

[WallTime: 1467285671.993447] [farmcontroller] not all dependencies started, still waiting for ['joint4controller', 'joint3controller', 'joint5_controller']...

The tutorial page doesn't talk about any dependencies. How can I fix this? I am using ROS indigo in Ubuntu 14.04

I guess there is a mistake in the tutorial itself.
