It is not clear what question you are asking us.

  • Which gazebo plugin are you referring to in the title?
  • I will point out that a robot with multiple drive wheels may not move if only 1 wheel is rotating.
  • I will also point out that for a wheeled robot using ros_control, you ordinarily should not publish messages directly to a ".../command" topic (and the standard teleop ros node does not do so.)
