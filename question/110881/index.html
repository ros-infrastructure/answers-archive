Answers

Since its Hydro release, ROS does not have Gazebo inbuilt anymore. Gazebo is now a separate standalone platform for simulations, which can be integrated and used with ROS hydro using the package gazebo_ros_pkgs. For more information you should visit gazebosim.org.
