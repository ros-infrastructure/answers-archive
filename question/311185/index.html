This has come up before. FastRTPS for example allows you to configure a list of static participants ("Static Endpoint Discovery"). That is based on IP, so those could be in any network, as long as there are routes available between those networks.

Asked by MisterblueGuy on 2018-12-20 18:33:27 UTC

In Bouncy, you need to create a DEFAULT_FASTRTPS_PROFILES.xml that looks like below 




&lt?xml version="1.0" encoding="UTF-8" ?$&gt
&ltprofiles&gt
    &ltparticipant profile_name="participant_somename" is_default_profile="true"&gt
        &ltrtps&gt
            &ltbuiltin&gt
                &ltdomainId&gt4&lt/domainId&gt
                &ltinitialPeersList&gt
                    &ltlocator&gt
                        &ltkind&gtUDPv4&lt/kind&gt
                        &ltaddress&gtX.X.X.X&lt/address&gt
                    &lt/locator&gt
                    &ltlocator&gt
                        &ltkind&gtUDPv4&lt/kind&gt
                        &ltaddress&gtY.Y.Y.Y&lt/address&gt
                    &lt/locator&gt
                    &ltlocator&gt
                        &ltkind&gtUDPv4&lt/kind&gt
                        &ltaddress&gtZ.Z.Z.Z&lt/address&gt
                    &lt/locator&gt
                &lt/initialPeersList&gt
            &lt/builtin&gt
        &lt/rtps&gt
    &lt/participant&gt
&lt/profiles&gt
Where X.X.X.X, Y.Y.Y.Y and Z.Z.Z.Z are ip addresses of the peers
