ROS2 fish shell setup?

Hi, so I understand we need to source setup.bash every time to use the ros2 CLI. Is there any script to do this in fish shell?

Asked by Jason1923 on 2021-07-30 22:09:15 UTC

Comments

Answers

You can use https://github.com/edc/bass to do that.

bass source /opt/ros/galactic/setup.bash

Also, if you launch fish after sourcing in bash, env values will be reflected.

// .bashrc
source /opt/ros/galactic/setup.bash
fish

For more advanced use cases, please take a look at my settings if you are interested. I've developed a couple of useful plugins.😀

  • https://github.com/kenji-miyake/dotfiles/blob/main/HOME/.bashrc
  • https://github.com/kenji-miyake/dotfiles/blob/main/XDG_CONFIG_HOME/fish/config.fish
  • https://github.com/kenji-miyake/dotfiles/blob/main/XDG_CONFIG_HOME/fish/fish_plugins

register-python-argcomplete --shell fish ros2 | source
