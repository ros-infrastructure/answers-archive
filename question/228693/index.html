Asked by grmarcil on 2017-04-19 13:37:49 UTC

Answers

This appears to be a bug with ROS' apt-get image-view program (version 1.12.18): https://github.com/ros-perception/image_pipeline/issues/215

I'd recommend running $ sudo apt-get update $ sudo apt-get install ros-indigo-image-view

to pull down the latest fixed package.
