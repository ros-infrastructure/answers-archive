Navigation stack should use which node map_server or map_saver

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/75973/navigation-stack-should-use-which-node-map-server-or-map-saver.

In navigation stack I am using a launch file. In that launch file mapserver package is launching mapserver node.

For creating map I am using gmapping package. In Gmapping I am using mapsaver node from mapserver package to save a map. I am in confusion that in Navigation stack which node of mapserver package I should use mapserver or map_saver.

What is the difference between mapserver and mapsaver?

Asked by Atul Divekar on 2016-08-25 02:06:11 UTC

Comments

Answers

map_saver saves a map generated by gmapping to a file on the computer. You can then use the map_server package for publishing this saved map for localization.

So in short map_saver saves a generated map, and map_server uses the saved map.
