This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/60859/package-cannot-find-nav-msgs-even-though-its-listed-as-a-dependency.

Hello, I am trying to run a ROS node for the ax2550 motor controller, found here:

https://github.com/wjwwood/ax2550

However, when I try to compile with catkin_make, I get the following error:

CMake Error at /opt/ros/hydro/share/genmsg/cmake/genmsg-extras.cmake:255 (message): Messages depends on unknown pkg: navmsgs (Missing findpackage(navmsgs?)) Call Stack (most recent call first): ax2550/CMakeLists.txt:22 (generatemessages)

Everything I can find about this error online simply indicates that I need to specify nav_msgs as a dependency to my package, but it's already there:

navmsgs</builddepend> navmsgs</rundepend>

Any ideas as to what could br going wrong?
