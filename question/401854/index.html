Looks like rcl_logging errors out on failing to create the log directory: https://github.com/ros2/rcl_logging/blob/8b31ef/rcl_logging_spdlog/src/rcl_logging_spdlog.cpp#L79-L89
Could you create this directory in the container when building the image, or point $ROS_LOG_DIR to an existing directory? Does rcl still print to stdout even if the default logging plugin fails to write to disk?

Edit: looks like it'll fail even also when attempting to create a timestamped named log file: https://github.com/ros2/rcl_logging/blob/8b31ef/rcl_logging_spdlog/src/rcl_logging_spdlog.cpp#L118-L126

Perhaps you may want to open a feature request there, and potentially a PR to include a bypass for read only filesystems.
