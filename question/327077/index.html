Time stamps in header message is always 0

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/92220/time-stamps-in-header-message-is-always-0.

Using ROS Kinetic on Ubuntu linux. For some reason, the time stamps (sec, and nsec values) in the standard header msg always come out as 0.

Does something have to be 'enabled' somewhere?

Asked by rRawCWwTKVM on 2019-06-26 16:31:03 UTC

Comments

Answers

ROS does not set the header timestamps automatically; the code that publishes the message has to set the timestamp.
