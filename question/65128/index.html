No octop map after point subsample?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/51980/no-octop-map-after-point-subsample.

If I set pointsubsample in sensorsrgbd.yaml to a value != the default 1, e.g. 0.5, my planning scene no longer contains a octomap. What can I do?

Asked by fivef on 2013-06-13 23:19:13 UTC

Comments

Answers

I have solved the problem by looking into the code:

point_subsample only takes integer values.

Setting e.g. point_subsample: 5 works
