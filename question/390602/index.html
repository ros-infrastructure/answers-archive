rosidl_typesupport_fastrtps, cdr_serialize: BoundedSequence serialised per element?

For normal unbounded vector, its cdr_serialize() is like:

cdr << ros_message.data; [which means memcopy(size * sizeof(uint8)) in fastCdr]

But for BoundedSequence,

cdr << static_cast<uint32_t>(size);
for (size_t i = 0; i < size; i++) {
  cdr << ros_message.data[i];
}

I find it is much more slower to serialize bounded vector by every single element. So why we have to serialize bounded vector like that?
