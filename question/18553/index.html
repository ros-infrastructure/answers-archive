Option to Disabe rendering in Gazebo 8?

Hi,

I am using my own tool to visualize messages from Gazebo. I am looking to run Gazebo headless without any rendering to maximize performance. I realized that the headless command-line parameter '-r' has been re-assigned at some point of development to the unrelated function of recording. Is there now no way to disable rendering? and if so, why?

Disabling rendering is a bit different from running headless.

To run headless is to run without a graphical interface. You can do it like this:

gzserver

Read more about Gazebo's components here.

Even if you run headless, there may be rendering running on gzserver in case you have rendering sensors, like cameras. If there are no such sensors, rendering will be automatically disabled.
