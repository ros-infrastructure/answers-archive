According to https://launchpad.net/ubuntu/raring/armhf/python-serial , the python-serial package should be available on Ubuntu Raring on armhf.

Raring is no longer supported by Ubuntu, so you should make sure that your apt sources are pointed to the ubuntu old-releases server.
