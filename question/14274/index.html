Answers

Take a look at the physics::Gripper class for an example. The gripper creates a fixed joint between one of its links and an object which is in contact with it for a certain time. Here are some key points in the code:

  1. A fixed joint is created, but not attached to anything yet

    this->fixedJoint =
    this->world->GetPhysicsEngine()->CreateJoint("fixed", this->model);

  2. Subscribe to contact updates

      this->contactSub = this->node->Subscribe(topic,
      &Gripper::OnContacts, this);

  3. Call OnUpdate at the end of every physics iteration

    this->connections.push_back(event::Events::ConnectWorldUpdateEnd(
      boost::bind(&Gripper::OnUpdate, this)));

  4. OnUpdate, check if the conditions for attachment have been fulfilled. That is, if the minimum number of contact points minContactCount has been satisfied for a minimum number of physics iterations attachSteps.

  5. If so, call HandleAttach, which loads the fixed joint between the gripper's palm link and the link to be grasped:

      this->fixedJoint->Load(this->palmLink,
      cc[iter->first]->GetLink(), math::Pose());
  this->fixedJoint->Init();

  6. For detaching, on HandleDetach:

    this->fixedJoint->Detach();

You could either use the existing gripper class, or copy the code and adapt it to your needs in a ModelPlugin.
