This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/98529/rclpy-subscription-getting-the-number-of-connections.

Is it possible to get the number of connections from a rclpy.Subscription object? (In ROS1 we had "subscriber.getnumconnections()")

If it is not possible, what is the alternative?
