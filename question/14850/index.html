does using lightmap result in shadows

by using lightmaps you can save information about lightning in texture. Does this mean that if there's no lightning than it results in shadows? or can you see "just" the texture?

with lightmaps, you use <lighting>false</lighting> to disable dynamic lighting, and you can also set <cast_shadows>false<cast_shadows> to prevent it from casting shadows
