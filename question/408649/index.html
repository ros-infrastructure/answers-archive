You can change the speed limits in the joint_limits.yaml in the yumi_moveit_config package. You either can increase max_velocity: or set has_velocity_limits: to false. Another parameter that can be set is velocity_scaling_factor, often its set to a value smaller then 1. But in this example it is set to its maximum 1.
