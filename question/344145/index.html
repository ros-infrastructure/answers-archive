Asked by Jock on 2020-05-09 06:42:55 UTC

Hi @Jock, My suggestion was that you rebuild autoware (not docker), with something like $ AUTOWARE_COMPILE_WITH_CUDA=1 colcon build --cmake-args -DCMAKE_BUILD_TYPE=Release (remove compile_with_cuda flag if you don't want gpu code).

Also, the path where ssdcaffe is placed is important. See details here https://autoware.readthedocs.io/en/feature-documentation_rtd/DevelopersGuide/PackagesAPI/detection/vision_ssd_detect.html
