How can I convert a math::Pose to a msgs::Pose ?

I have created a world plugin. In the plugin I want to get the pose of a model by storing it in a math::Pose variable using GetWorldPose(). Then I want to send this pose over to another program using a topic with a message type msgs::Pose. Is there any easy way to convert math::Pose to msgs::Pose?

Asked by takis on 2016-06-24 11:22:05 UTC

Comments

Answers

From gazebo math to msgs (deprecated on Gazebo 6, removed on Gazebo 7)

msgs::Pose gazebo::msgs::Convert ( const math::Pose & _p )

From msgs to gazebo math (deprecated on Gazebo 6, removed on Gazebo 7)

math::Pose gazebo::msgs::Convert ( const msgs::Pose & _p )

From ignition math to msgs (from Gazebo 6)

msgs::Pose gazebo::msgs::Convert(const ignition::math::Pose3d &_p)

From msgs to ignition math (from Gazebo 6)

ignition::math::Pose3d gazebo::msgs::ConvertIgn(const msgs::Pose &_p)
