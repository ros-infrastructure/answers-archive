Unable to locate package ros-kinetic-desktop

I have been trying to install ros on my ubuntu 18 but I keep getting a message saying unable to locate packages.

Answers

ROS Kinetic is only supported on Ubuntu Xenial (ie: 16.04), see REP-3 - Platforms by Distribution: Kinetic Kame (May 2016 - May 2021).

You cannot install Kinetic on Ubuntu 18.04.

You'll need to either downgrade to Ubuntu Xenial, or install ROS Melodic.
