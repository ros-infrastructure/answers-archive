Hi,

we have a working ros indigo node for the Create2. https://github.com/MirkoFerrati/irobotcreate2ros

You will also find a joystick demo that allows you to move the robot via teleoperation. We are still missing some features, but you should be able to move, use the LCD screen and read sensors and odometry out of the box!

Bye, Mirko
