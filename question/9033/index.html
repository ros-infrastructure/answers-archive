in addition to the stable hardware stacks, like the ones mention in tfoote's answer, you can also use the browse software feature to search for a particular driver. The ROS community has wrapped most of the common sensor and actuator drivers that you might need to build a robot.

ROS provides several drivers stacks:

  • joystick_drivers
  • laser_drivers
  • camera_drivers
  • sound_drivers
  • imu_drivers
  • kinect
  • phidgets
  • asctec_drivers

A list of tutorials can be found at: http://www.ros.org/wiki/ROS/DriverTutorials
