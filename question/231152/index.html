Understanding launch file from nav2d tutorial

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/73233/understanding-launch-file-from-nav2d-tutorial.

I have a node that I want to subscribe two topics from nav2d, I'm interested to use the /basescan and /odom topics. When I look in launch files then I can see ` <!-- Start the Operator to control the simulated robot --> <node name="Operator" pkg="nav2doperator" type="operator" > `

I know that "scan" in stage that is remapped to the "basescan" topic. But what is the remap name for /odom or /baseposegroundtruth topic ? Or where can I find it ?

Can I for example name /odom topic as <remap from="odometry" to="odom"/> ?

Answers

This will work for the scans. but not for the odometry. The Operater receives odometry information via the "tf" topic. (Which is also provided by Stage) So you just have to make sure that the frame names for "robot_frame" and "odometry_frame" are set correctly.
