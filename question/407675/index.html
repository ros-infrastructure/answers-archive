You have a few things to consider:

  • Can you ping each other IPs? Are you in the same network, e.g. 192.168.5.xx, where Jetson 1 has xx == 01, etc.?

  • Is your firewall disabled? Does it allow UDP multicasting?

More info can be found here, you can try to use DDS implementations other than default one for Foxy.
