Asked by marc wellman on 2020-08-19 03:11:16 UTC

You've installed the UpstreamPackage version of rosdep.

This is getting more and more annoying, as there have been many users "falling into this trap" lately.

See “upstream packages” increasingly becoming a problem for a discussion about this.
