Step7: There is a problem of no gzmath.hh library.

You need to change the source code in this file. There is a typo in this file.

drcsim/ros/atlasmsgs/gzmodel_teleport.cpp

Original code is 

#include <math/gzmath.hh>

should change to 

#include <gazebo/math/gzmath.hh>
