Change model position in simulation

Hi all, I need to teleport models in my simulation after their spawn. Do you know if it is possible to write a Python script or a C++ class allowing to change model position during simulation ? If it is possible do you have some advices or ideas. Thanks

Answers

In a gazebo plugin, you can 

math::Pose initPose(math::Vector3(0, 0, 1.0), math::Quaternion(0, 0, 0));
this->model->SetWorldPose(initPose);

in a python script, you can use this topic /gazebo/set_model_state
