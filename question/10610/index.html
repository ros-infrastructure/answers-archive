"rosmake teleop_base" couldn't find dependency [joy] of [teleop_base]

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/33021/rosmake-teleop-base-couldnt-find-dependency-joy-of-teleop-base.

Hi,

I am using diamondback-full-desktop ROS version on Ubuntu 10.10. I was trying to run this command $rosmake teleopbase and it says that [rospack] couldn't find dependency [joy] of [teleopbase].

Is not [joy] a part of diamondback-full-desktop or do I need to install it separately? [I have controltoolbox -which is one dependency of teleopbase]

Thanks VN

Answers

joy is part of the joystick_drivers stack. I don't think it's part of the ros-diamondback-desktop-full metapackage.

You can install it from binaries using 

sudo apt-get install ros-diamondback-joystick-drivers
