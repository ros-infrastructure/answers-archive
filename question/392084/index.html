Edit: Initially I had the problem that the robot was moving unexpectedly when planning to 'randomvalid' using rviz. The rosindustrial/universalRobots packages has a parameter for this (limited:=true) but the package I'm using (which is recommended for melodic) doesn't have this option so I modified my urdf. (so this problem is fixed, and I updated this post to focus on my pose planning problem).
