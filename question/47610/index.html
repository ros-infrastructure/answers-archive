Planning sequence of motion using arm_navigation/moveit

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/45549/planning-sequence-of-motion-using-arm-navigation-moveit.

Hi,

I would like to planning sequence of motion with planningcomponentvisualizer. In the menu handler, there are only the option: set start and set end position.I would like to add option: "set next motion" which will swap the current endstate to a new startstate and selectmarker from the new startstate to set new goal. But I don't know how to set new startstate to "current" endstate (which is KinematicState), therefore, the startstate also changes when I start move the marker to the new end_state.

Is there any way to get the current KinematicState?

Asked by Tien Thanh on 2012-11-06 12:37:01 UTC

Answers

Problem is solved:

vector< double > state_vector;

gc.end_state_->getKinematicStateValues(state_vector);

gc.start_state_->setKinematicState(state_vector);
