Yes! If you've got a sensor that you think others would find useful, then we'd like to see it. You'll want to check out the contributing guidelines for gazebo. It's a very long doc, but reading it will save you tons of time in the pull request process overall. Once you think you're ready, make a pull request, and people will look over it, try it out, and give some feedback.
