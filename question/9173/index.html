Yep, I've successfully run a cturtle computer along with a diamondback computer. However, if any of the messages you're using have changed between versions, you'll get errors.

It will work for most nodes as we did not change the protocols in this revision. The main differences that might affect you are changes to the CameraInfo message format, as well as broader rollout of the PointCloud2 format. In otherwords, you might have issues with cameras and point clouds, but that should be it.
