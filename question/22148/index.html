Answers

I uninstall the protobuf by sudo apt-get remove libprotoc-dev, remember to take a screenshot of the package uninstall with the protobuf. and reinstall the protobug by sudo apt-get install libprotoc-dev, then reinstall the package uninstall with the protobuf. The error pass.
