Use a tool like plantstudio to generate plants: http://www.kurtz-fernhout.com/PlantStudio/ The tool can be run using wine on many linux distroes. The tool is able to generate plants CAD models with the aspects you want. Use blender og meshlab to convert the CAD models from plantstudio into *.dae. Other tools that can be used are: http://vterrain.org/Plants/plantsw.html
