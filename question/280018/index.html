Hello,

if you are using this repo http://wiki.ros.org/apriltags_ros, the pull request https://github.com/RIVeR-Lab/apriltags_ros/pull/30 solved our problem but it is still not merged with master thus what you need to do is to change the code piece located inside getRelativeTransform method in TagDetection.cc file

from

  cv::Matx33f cameraMatrix(
                       fx, 0, px,
                       0, fy, py,
                       0,  0,  1);

to

  cv::Matx33d cameraMatrix(
                       fx, 0, px,
                       0, fy, py,
                       0,  0,  1);

Hope it helps
