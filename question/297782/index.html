Is there a way to undo workspace chaining?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/87981/is-there-a-way-to-undo-workspace-chaining.

From my $ROSPACKAGEPATH, I realised my workspaces have been chained together. Is there a way to undo it?

Asked by amelia on 2018-07-18 04:01:48 UTC

Comments

Answers

for catkin_make:

  • Delete build, devel and install.
  • Source /opt/ros/kinetic/setup.bash
  • catkin_make

for catkin_tools:

  • catkin clean --yes (essentially the same as above)
  • catkin config --extend /opt/ros/<DISTRO>
  • catkin build
