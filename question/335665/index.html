The wording is misleading but the tutorial is up to date for the latest version of the code. To make sure to use the version of the documentation matching the ROS distribution you are using you should use the tutorial from the corresponding branch (in your case dashing): https://github.com/ros2/sros2/blob/dashing/SROS2_Linux.md

I opened https://github.com/ros2/sros2/pull/164 to remove references to Bouncy in the tutorial.
