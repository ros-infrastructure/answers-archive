Convert ROS image to CV2 image

The default image type is 32FC1. How to export the image to CV image type? After change the format to 8UC1 and 16 UC1. The result is the same

Here is the code:

count = 0; def callback(rosimage): bridge = CvBridge() cvimage = bridge.imgmsgtocv2(rosimage, '8UC1') global count count = count +1 imgtitle = "image"+str(count)+".jpg" cv2.imwrite(imgtitle, cvimage)
