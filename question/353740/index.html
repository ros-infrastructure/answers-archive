How do I set coordinates for model in Gazebo?

In the model.sdf or world_name.world file, when I want to import a model I will have to write 0 0 0 0 0 0 to determine the x, y and z coordinates.

As I am new to gazebo, may I know which of the zeros in 0 0 .1 0 0 0 represent the x, y and z axis respectively? Why are there six variables (zeros) rather than 3, aren't there only 3 axises?

That is X-Y-Z-Roll-Pitch-Yaw (Roll,Pitch,Yaw is rotation around the X-axis, Y-axis, Z-axis in that respective order).
