can't include files from library inside different catkin package

i'm currently trying to integrate a VL53L3CX time of flight sensor into my robot. I'm currently working in ROS-noetic running on a PI4 with Ubuntu server 20.04. I found a c library that allows you to interface with the laser through the I2C available on the PI gpio. I tested the library and this works fine, i can connect to the sensor and get readings. I have now packaged the library inside a catkin package (vl53lx_api) and i'm trying to use it in a separate package where I am implementing the node. The api package seems to build fine but when it comes to compiling the node it fails because it cant find the headers from the api.

Answers

I now realise it was a dumb mistake. In trying to maintain the library original folder structure I ignored the catkin rules for include files. They were plasced into two separate subdirectories inside of the include directory

include/core
include/platform

the issue was fixed by moving them all into one subdirectory named like the project.
