Answers

For this you can use bash script. Here's an example:

#!/bin/bash

while true
    do
        forward_completed="$(rosparam get /forward_completed)"
        if [ "${forward_completed}" = true ]
        then
            rosrun you_package your_node
        fi
    done

It should give you a hint what to do.
