Raspbian packages will never be available for ROS 2 (nor ROS 1), as it's not a platform which gets binary packages (from the ROS buildfarm).

As to Bullseye: looking at REP 2000: ROS 2 Releases and Target Platforms, Bullseye is always only a "tier 3 [s]" platform, which means it's only supported for building from source (ie: apt packages will never be made available).
