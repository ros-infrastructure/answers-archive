Yes, 3DM-GX3 protocol is also supported (see this question). I am using the microstrain_3dmgx2_imu package with Microstrain 3DM-GX3-25 IMU without any issues.

So, at some point, there was a separate stack (or modifications to the GX2 stack) that we used with the GX3 version.

Now, we are using the imu_drivers version included with Electric as our driver for the 3DM-GX3-25, so I can say that it is supported.

I haven't done much investigation into all of the features of the driver, but I can say that it does output filtered orientation messages (as well as linear and angular velocity) at up to 200 Hz, from what I've seen.
