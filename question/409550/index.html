Hello,

here my problem: currently, I have a node that subscribe to a topic ('camera', it publishes the images from the camera), then execute a callback function (GrabImage) that does some stuff with the image. Relevant piece of code:

#include "monocular-slam-node.hpp"
#include <opencv2/core/core.hpp>

using ImageMsg = sensor_msgs::msg::Image;

using namespace std;    
using std::placeholders::_1;

MonocularSlamNode::MonocularSlamNode(ORB_SLAM2::System* pSLAM, const string &strVocFile, const string &strSettingsFile)
:   Node("orbslam"),
    m_SLAM(pSLAM)
{
    m_image_subscriber = this->create_subscription<ImageMsg>("camera", 10, std::bind(&MonocularSlamNode::GrabImage, this, std::placeholders::_1));    
}

void MonocularSlamNode::GrabImage(const ImageMsg::SharedPtr msg)
{
    m_cvImPtr = cv_bridge::toCvCopy(msg);
    img = m_cvImPtr->image
   //do some stuff using img  
}

So now let's say I create another topic, which publishes another image (which is actually the depth map of the 1st image), let's assume the topic name is 'depth'. I want the GrabImage function to be able to 'see' this depth map, and do some operations inside using both image and depth.

I know how to create another subscriber to the second topic 'depth', but how to make the second image visible to the GrabImage function? I'm currently stuck here and I couldn't find a solution so far. Is it even possible to do so, or I need to change the structure of the code?
