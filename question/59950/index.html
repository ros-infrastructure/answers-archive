Works fine on my Hummingboard, but yes I compiled from source which can be a pain. You'll still need a PC to run e.g. rviz or any more cpu intensive node.

Its probably easier to follow the documentation about the also ARMv7 based BeagleBone and adapt it to your board, by e.g. replacing the bootloader, kernel and devicetrees.
