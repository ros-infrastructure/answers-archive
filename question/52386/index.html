actionlib tutorial inconsistency

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/47300/actionlib-tutorial-inconsistency.

The SimpleActionServer(ExecuteCallbackMethod) tutorial has a CMakeList.txt inconsistency for Catkin/Groovy.

At one place it says:

findpackage(catkin REQUIRED COMPONENTS actionlibmsgs) Note that CMake needs to findpackage only actionlibmsgs (not messagegeneration that is referenced implicitly by actionlibmsgs).

Later it says:

findpackage(catkin REQUIRED COMPONENTS actionlib messagegeneration)

I assume the second one was not updated and the first example is correct. Please confirm.
