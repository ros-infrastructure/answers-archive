It looks like there was a regression in rosdoc_lite I've just merged the fix here: https://github.com/ros-infrastructure/rosdoc_lite/pull/95

With a rerun of the documentation job for roscpp the file is restored. Any other package that regressed due to this will recover any missing documentation the next time that there's a change.
