It's possible you can't find anything explaining "variable length arrays" with roscpp as those don't really exist.

C++ has vector, and unbounded sequences in ROS .msgs are mapped onto std::vector.

This has come up before. See #q321354 for instance for a Q&A which seems similar.

If you agree #q321354 sufficiently explains what's going on, please close your own question as a duplicate.
