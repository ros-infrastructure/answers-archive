How accurate is the current read by /svh_controller/channel_currents?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/88867/how-accurate-is-the-current-read-by-svh-controller-channel-currents.

Hello everyone!

I´m working with a real SVH 5-Finger hand from Schunk and I have performed a lot of tests regarding to the current. As it was pointed out before, there is no force feedback on the hand so the current is the only relevant variable to measure how much "effort" is applied to an object.

I´m working on developing a grasp controller based on the current of the hand, therefore I´m using the topic /svhcontroller/channelcurrents provided by the driver. My question is wether this topic is reliable enough and if it contains an accurate measurement of the current consumption. Or in other words, should I use another method to obtain the current?

Hello Charlie,

there is an error of about +- 10 mA.

We compared the current reading of the topic to the actual current between the handcontrolcircuit and single motors to get this value.
