Synchronise two bagfiles

This might be an issue for may of us working at home right now; first, a typical pipeline might look like this:

BAGFILE
|
Undistort image
|
+------------------+
|                  |
PROCESS 1          |
|                  |
PROCESS 2          |
|                  |
+-------------+OVERLAY RESULTS
                   |
                  RVIZ

PROCESS 1 and PROCESS 2 are running on remote (in the office) hardware so with a typical laptop, we just have to SSH or VNC in and flood the remote access gateway with 30 fps. PROCESS 2 outputs a bunch of rectangles (eg object recognition) and the OVERLAY RESULTS renders them to the image for display in RViz.

Now, I can download the bagfile off-peak or visit the office and copy the data to a portable SSD, and then I would like to do this:

BAGFILE<---SYNC--->BAGFILE
(Office)           (Home)
|                  |
Undistort image    Undistort image
|                  |
PROCESS 1          |
|                  |
PROCESS 2          |
|                  |
+-------------+OVERLAY RESULTS
                   |
                   RVIZ

Now, the traffic over the link is greatly reduced, becoming just a set of rectangles instead of a complete frame. Is such a system possible? How could I get two bagfiles to play back in sync?
