UDP communication over network

I am trying to publish to the topic /joy and subscribing it from a remote node (on the same machine as roscore) to teleoperate a robot by means of a joystick using the UDP protocol:

ros::init(argc, argv, "joy_to_twist");
ros::NodeHandle nh;
joy_sub = nh.subscribe("joy", 10, joy_event, ros::TransportHints().udp());

If I subscribe the topic using TCP everything goes fine (with the same hardware configuration), while the subscriber doesn't receive any message when I use UDP.
