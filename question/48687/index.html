Where did you find this command? The official knowrob basics page doesn't tell you anything about checking out a repository from svnradig. Have a look at this page for install instructions or install knowrob's debian package with apt-get:

sudo apt-get install ros-fuerte-knowrob

The page you probably got this URL from is filed under "Deprecated" in the wiki. "Deprecated" means that the information is outdated and you should not use it unless you know what you are doing. There is plenty of documentation for getting started with KnowRob (which I guess you know already, given your other posts).

The URL only works in our internal network, which can also be seen by the missing global domain of the host 'svnradig'. The links Lorenz posted are those that should be used.
