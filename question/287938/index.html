Unable to launch turtlebot3 waffle

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/86429/unable-to-launch-turtlebot3-waffle.

I have a turtlebot3 that was a burger that we are changing to a waffle. I followed the steps here: http://emanual.robotis.com/docs/en/parts/controller/opencr10/#arduino-ide to set up the ide then followed the directions here: http://emanual.robotis.com/docs/en/platform/turtlebot3/opencr_setup/#opencr-setup to upload the waffle code instead of the burger code.

Now, when we call up the tb3 using the command roslaunch turtlebot3bringup turtlebot3core.launch the turtlebot starts but fails. Here is part of the terminal output:

[INFO] [1523234365.100797]: Connecting to /dev/ttyACM0 at 115200 baud [ERROR] [1523234367.376107]: Creation of publisher failed: Checksum does not match: 427f77f85da38bc1aa3f65ffb673c94c,d537ed7b8d95065b6c83830430b93911

Then we have another error: [ERROR] [1523234371.010786]: Creation of subscriber failed: 'module' object has no attribute 'Sound'

Further in the log after 'Calibration end' we get on repeat until I control-c, [ERROR] [1523234372.879436]: Tried to publish before configured, topic id 125

I have tried using both the shell and the arduino ide methods for uploading the example code for the waffle and have gotten the same result. I have also now tried to revert it back to the burger using both methods and still receive this issue. I am using the launch files provided robotis on the pi.
