Answers

I have an another way around for installing dependencies using rosinstall_generator

  • [rosinstall_generator --deps --exclude RPP > .rosinstall]{this will create a rosinstall file with all uninstlled dependencies listed}
  • [rosinstall src/ .rosinstall]{this will install the packages mentioned in the rosinstall file}

nb: Do this in the catkin root directory
