Local planner requires protocol when it cannot resolve path

I have an issue where in certain occasions, my local planner on its way to the goal can no longer resolve a path to the goal. and then stops moving. Here is a picture to illustrate what I mean: robotstopsmoving. Because alot of the time, all it takes is for me to manually teleop the robot for a couple seconds and the robot is able to autonomously move to the goal by itself. Basically all it takes is that the robot is jolted back into motion and then the path planner resolves itself. What I'm doing right now running my protocol algorithm at the same time as my motion algorithm(which a series of goals, one at a time) via same launch file. How it works is if the robot hasn't moved in 5 seconds, the protocol(ideally takes over for a couple seconds) jolts the robot back into movement, The issue is it doesn't seem to work. I make the protocol algorithm print out "move move move" when ever it's supposed to take over movement.It does print that out but the robot doesn't move. Here is the code below:

def ClearanceTest():
    global Urgency_Report

    goal = "front_C"
    closest = 10e6
    regional_dist = 0
    maxima = {"destination": "back_C", "distance": 10e-6}
    for region in Regions_Report.items():
        regional_dist = abs(Regions_Distances[region[0]]-Regions_Distances[goal])
        #if there're no obstacles in that region
        if not len(region[1]): #If the region is empty
            #check if it's the cheapest option
            if (regional_dist < closest):
                closest = regional_dist
                maxima["distance"] = OBSTACLE_DIST
                maxima["destination"] = region[0]
        #check if it's the clearest option
        elif(max(region[1]) > maxima["distance"]):
            maxima["distance"] = max(region[1])
            maxima["destination"] = region[0]

    #calculate the cost to the chosen orientation
    regional_dist = Regions_Distances[maxima["destination"]]-Regions_Distances[goal]

    #we act whenever the clearest path is not the front_C (front center)
    Urgency_Report["act"] = (closest != 0)
    Urgency_Report["angular_vel"] = ((regional_dist/max(1, abs(regional_dist)))

                              /(180*TRANS_ANG_VEL))

def IdentifyRegions(scan):
    global Regions_Report
    for i, region in enumerate(REGIONS):

                        if x <= OBSTACLE_DIST and x != 'inf']

def Steer(velocity):
    global Urgency_Report
