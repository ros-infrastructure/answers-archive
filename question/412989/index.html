Update2: Building MoveIt2 from source shows now also CHOMP as possible planner plugin. This led me to check the moveitplanners folder and the subsequent `pilzindustrialmotionplannerfolder for the export statements of the plugins. This makes me belief, that it is still a ROS1 package, despite the fact that it is in the ROS2 branch of the repo. So as a matter of fact, PIMP will be never build withcolconin MoveIt2 and even if it would, it would not be registered as plugin, since ROS1 and ROS2 plugins are defined differently (package.xmlvsCMakeLists.txt`).
