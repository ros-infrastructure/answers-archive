Simulating UR Camera with gazebo and Universal robot simulator

I am developing an application for a Universal Robot (UR) arm that includes sensors which can be simulated with GAZEBO. Although the ROS packages and gazebo already have an option to simulate the UR arms (both CB-Series and E-Series), UR also have its own offline simulator where their arms are simulated very accurately (simulator for CB-Series and E-Series). These simulators (which are virtual machines) model the robot with its console and all its interface, it is "the same" as connecting to a robot. For my application, I am interested in using the UR simulator for the arm instead of the ROS packages. However, I still need to do the sensors simulation in GAZEBO. Is there any chance that I can take the robot state (publised in /joint_states) or the tfs published by robot_state_publisher and insert it to GAZEBO so I can position the camera as if there was an arm holding it? Is my only option to keep setting the camera position using set model state?

I agree with you that UR probably has a better dynamic model of their robot than the OSS community though. But that would be true of just about every (industrial) robot manufacturer.
