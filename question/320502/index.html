Unfortunately, Melodic doesn't support Ubuntu 18.10, it only supports Ubuntu 18.04 and 17.10. So, it looks like you will have to resinstall a different OS that is supported by ROS. As stated in this answer

[...] you can of course try building from source on 18.10 and/or use the Docker images available.

It's just that no binary packages are provided for 18.10 by the ROS buildfarm.

You can check REP 3 to see what operating systems are supported by the different versions of ROS.
