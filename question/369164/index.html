Confusion in ROS2 default middleware

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/97998/confusion-in-ros2-default-middleware.

I have noted that FastRTPS is the default middleware in ROS2 Foxy. But again, there are 2 version of FastRTPS too: a) FastRTPS dynamic (rmwfastrtpsdynamiccpp) and b) Plain FastRTPS (rmwfastrtps_cpp).

So which one exactly is the default middleware in ROS 2 Foxy Fitzroy ?

Answers

The default for Foxy Fitzroy is rmw_fastrtps_cpp.

It is the first one listed on REP 2000.
