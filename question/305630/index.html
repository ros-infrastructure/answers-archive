It's most likely an issue with the network setup of the emulator. Treat it as a regular multi-pc ROS setup. Make sure things like ROS_IP and ROS_MASTER_URI have the correct value. Make sure there is bi-directional traffic flow possible between the host and the emulator. Etc.

Asked by gvdhoorn on 2018-10-12 04:48:25 UTC

I agree with @gvdhoorn. I would add one more thing: try to ensure that the emulator is in the same network, allowing it to access the "outside world". Then, setting ROS_IP and ROS_MASTER_URI properly should do the job.
