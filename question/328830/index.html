Can cartographer publish odom?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/92627/can-cartographer-publish-odom.

Is there any way to have the cartographer publish the odom topic in localization-only mode? I'm quite happy with the 2D localization results it provides, compared to other ROS methods using my very noisy IMU and slipping encoders, but I don't get the odom from it, despite provide_odom_frame set to true. Is it even supposed to work?
