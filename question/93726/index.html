Asked by moutinoir on 2013-10-24 02:38:20 UTC

You can see it from the file CMakeLists.txt inside your package, if in the first lines there is something similar to:

include($ENV{ROS_ROOT}/core/rosbuild/rosbuild.cmake), then it's a rosbuild package, if you see something like:

find_package(catkin REQUIRED), then it's a catkin package.
