At least in Rosjava Kinetic release, the ROS master can be executed from rosjava. Take a look at the code of the MasterChooser. It has a checkbox that allows executing the master locally. The MasterChooser then sends the result to the RosActivity, which starts the ROS master if it was requested by the user (see this line: https://github.com/rosjava/android_core/blob/kinetic/android_10/src/org/ros/android/RosActivity.java#L75). You can do that in your code by default, and you won't need user input.

Note that running the ROSJava master has some limitations. It doesn't support XMLRPC multicall requests (i.e. if you launch a launchfile from your desktop against the ROSJava master, it will crash).
