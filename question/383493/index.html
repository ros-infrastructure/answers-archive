Calling install\local_setup.bat shows "The input line is too long."

I have just installed ROS2 Foxy in Windows 10 version 21H1 (OS Build 19043.1110). I followed everything step by step from Building ROS 2 on Windows . One exception was that I installed "Patch" to workaround an error that showed 1 package failed: zstd_vendor while running colcon build command. It fixed the problem. After building ros2foxy, as instructed, after commanding `call C:\dev\ros2foxy\install\local_setup.bat, it repeatedly showsThe input line is too long.` I'd be grateful if anyone could help me out.

Answers

Because I didn't use the attribute --merge-install the paths become too long for the local_setup.bat to work. And there is no way to override that limit as it is defined by the windows. I also checked the bat file. It doesn't repeat paths making it too long. Paths actually are too long. One way was to use short names and aliases. I didn't try that. I just deleted the C:\dev\ros2_foxy folder. Then again I imported the repos file and cloned from it and then used colcon build --merge-install. Now it is fine.
