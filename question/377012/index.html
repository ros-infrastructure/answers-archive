ROS CPP Snap7 Linux - Catkin/CMake finds library but does not link

I would like to use Snap7 ( Multi-platform Ethernet S7 PLC communication suite) to establish a communication between ROS and a Siemens S7 1500.

I encountered a linker problem - Although I can find the includes and the library .so file itself, using a custom FindLibSnap7.cmake, target_link_libraries is not linking against the found library. Here my approach and the outputs helping debugging:

(Note: Currently we are forced to use ROS Kinetic, so using the Snap7 Python wrapper seems like not an option cause its written in python3.)

System Setup:

Ubuntu 16.04 LTS x86 ROS Kinetic Distro

I installed the library:

  • sudo add-apt-repository ppa:gijzelaar/snap7
  • sudo apt-get update
  • sudo apt-get install libsnap71 libsnap7-dev

Result:
