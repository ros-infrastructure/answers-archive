Hello Vishal, I would like to share some knowledge on the "time_from_start" variable in trajectory_msgs. Trajectory msgs from moveit or any controller would generally be a list of points that the robot should follow. This parameter defines the time instance at which the robot should be at that particular trajectory point. (i.e, it serves as an instantaneous goal for that exact time instance after the start of trajectory)
