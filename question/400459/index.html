Are these input characters ROS arguments?

XML and arg/param will be enough: http://wiki.ros.org/roslaunch/XML/arg 'Passing an argument to an included file'

Then you can use:

roslaunch %YOUR_ROS_PKG% my_file.launch hoge:=my_value

in .launch:

roslaunch my_file.launch hoge:=my_value (.launch file is available at the current dir)
