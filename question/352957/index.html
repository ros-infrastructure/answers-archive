my code:

ros::NodeHandle priv_nh("~");

privnh.getParam ("filename", filename);

i use:

rosrun mypackage mynode _filename:=test

it is not working.

You could set the param first after starting roscore.

rosparam set filename test
rosrun my_package my_node
