According to this page, ROS Noetic can be installed on Ubuntu 20.04. Reinstall Ubuntu (ver. 20.04 and not 22.10). Then it should be able to locate the package ros-noetic-desktop-full in the official repository of Ubuntu

UPDATE: It is right, 20.04 is the right version. I typed 22.04. Noetic is for 20.04

There is no supported ROS Noetic for Ubuntu 22.04. Only 20.04 is supported. The page you link states this:

These instructions will install ROS Noetic Ninjemys, which is available for Ubuntu Focal (20.04), [..]

You could consider using the wiki/UpstreamPackages, or something like Docker, Singularity (Apptainer) or perhaps conda with Robostack.
