Launching `turtle_teleop_key` from a launch file

Starting the turtlesim node turtlesim_node automatically sets the topic name to /turtle1/*. However, I'd like to have a different topic name, which I managed to do through a launch file and remapping topics.

I'd like to do the same thing with the turtle_teleop_key node. That is, remap the /turtle1/cmd_vel to another topic such as /new_topic/cmd_vel. I am able to do that through the command line by running

ros2 run turtlesim turtle_teleop_key --ros-args --remap /turtle1/cmd_vel:=/new_topic/cmd_vel

However, to avoid writing this command every time, I wanted to put it in a launch file such as

def generate_launch_description():
return LaunchDescription([
    # Teleop keys
    Node(
        package='turtlesim',
        executable='turtle_teleop_key',
        remappings=[
            ('turtle1/cmd_vel', 'new_topic/cmd_vel')
        ]
    )
])

Unfortunately, when launching this launch file, the launch status is displayed, which overshadows the turtle_teleop_key action that takes keyboard inputs. Thus, I'm not able to provide input with the keyboard.

My questions are the following:

  1. What is the best way to remap the topics that turtle_teleop_key node subscribes to besides doing it from the command line?
  2. How can I insert user input to a node launched from a launch file, where the node accepts user input (such as keyboard input)?
