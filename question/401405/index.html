How to save map by using map_server package according to the topics?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/101834/how-to-save-map-by-using-map-server-package-according-to-the-topics.

I used the multimapmerge package to merge map from robot 1 and robot 2. But when I used rosrun map_server map_saver -f ~/map, the map is only saved the merge map which is from /map topic. But I also would like to save map from /tb3_0/map and /tb3_1/map topics. I would like to ask how to save map according to the map topics? Thank you in advance.

Answers

Try this :
rosrun map_server map_saver map:=<your_topic_name>
