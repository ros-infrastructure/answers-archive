In the same link you gave us there is a list of all the available nodelets inside the package.

Each nodelet ask for a defined topics to subscribe and gives a defined result.

Let's imagine you want to achieve a raw pointcloud without color (depth_image_proc/point_cloud_xyz)

you need to send a topic of type: 

sensor_msgs/CameraInfo with the name /camera_info (which has to be the needed data from the camera)

and another with type:

 sensor_msgs/Image with the name /image_rect (which has to be the already rectified image).

If you send that, and the node is running, it should send back a pointcloud. you could the check if its like that doing a rostopic echo, or visualizing the pointcloud directly on rviz (maybe you will need to add a wolrd tf first)

If you have more doubts do not hestitate to ask
