It appears that it doesn't compile on 11.10 Oneiric. I did see what looked like the i386 build passed earlier. In general the build farm does a best effort. If things compile it will release them. It's up to the stack maintainer to make sure they're releases build on the different platforms.

pr2_simulator was not building because pr2_ethercat_drivers were broken. Ethercat drivers are building fine on Oneiric now, but pr2_simulator job hasn't been run since they were broken. I would guess that pr2_simulator will build fine now if somebody pushes the build job through.
