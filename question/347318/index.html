The problem is most likely you are trying to use a Python interpreter (Anaconda in this case) for which the dependencies required for ROS have not been installed.

You also seem to be mixing Python 2 and Python 3.

Python 3 is not (officially) supported right now with ROS Melodic. You must have found other Q&As discussing this.
