Possible bug in move_base.launch

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/31417/possible-bug-in-move-base-launch.

Hi all, For several days, I (a relative newbie) have been trying to get the nav stack working. My map always came up offset from the robot in rviz (origin at lower left corner of map).

I finally found that the movebase.launch file in the "Setup and Configuration of the Navigation Stack on a Robot" tutorial (para. 3.5) is using a deprecated version of mapserver arguments (as noted in the mapserver code). It uses the "mapserver " form rather than the "mapserver " form. The deprecated version doesn't work properly and the associated ROSWARN message that map_server apparently should be displaying didn't show up on my terminal.

I suggest that the launch file be updated. This was pretty hard to track down.
