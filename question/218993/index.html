This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/69925/catkin-run-tests-with-stdout-output-of-rostest.

I'm using rostest by adding add_rostest in CMakelists.txt, and catkintools to build it. I know how to test specific package with `catkin runtests pkg --no-deps, but no idea to write the test's stdout to the screen likerostest --text hoge.test`.

Anyone who know about this?

Though you've probably figured this out already, you can catkin_test_results for that these days. http://docs.ros.org/jade/api/catkin/html/howto/format2/run_tests.html

UPDATE 20180529 For catkin_tools, passing workspace folder path to catkin_test_results works. Some examples:

cd ~/catkin_ws
catkin_test_results

Or

catkin_test_results --verbose ~/catkin_ws
