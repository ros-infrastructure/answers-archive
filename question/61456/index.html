I'm use the p2os (teleopkeyboard) to controll robotic and rgbdslamfreiburg to capture the point clouds, I don't have problems for to use these processes separately, the problem is when I use the two together. What must I do to rgbdslam package receive the commands to capture the point cloud (ex: "enter" key)? I have the same doubt with joystick.

I assume your problem is controlling the Pioneer remotely and using rgbdslam at the same time. You could try using rgbdslam in headless mode and use the frame service call. As for controlling the Pioneer with a joystick remotely, you can try a multiple machine setup with a desktop PC running the joystick node.
