Answers

Use the option connect_delay

rosrun sicktoolbox_wrapper sicklms _port:=/dev/ttyUSB0 _connect_delay:=30

or

rosparam set sicklms/port /dev/ttyUSB0 rosparam set sicklms/connect_delay 30 rosrun sicktoolbox_wrapper sicklms
