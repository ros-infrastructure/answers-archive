Answers

Hi found my mistake The package ros-electric-pr2-simulator was not installed. This package includes the missing lib file libgazebo_ros_controller_manager.so

Therfore running

sudo apt-get install ros-electric-pr2-simulator

solves the problem.

cheers

PS.: The same would would also happen on diamondback
