Rosbridge subscribe fails before topic is available

Description

When I start rosbridge and subscribe to a topic before the topic is available I receive the following error: [rosbridge_websocket]: New publisher discovered on topic '/mavros/local_position/pose', offering incompatible QoS. No messages will be received from it. Last incompatible policy: RELIABILITY and subsequent attempts to connect via rosbridge to the given topic don't return anything.

It seem that rosbridge is assuming the given topic is RELIABLE which causes the subscription to fail when the actual topic is broadcast as BEST_EFFORT. It seems like rosbridge should have a mechanism to specify the reliability of the given subscription.

Is there a way to subscribe to a topic with rosbridge prior to it being available with the appropriate reliability?
