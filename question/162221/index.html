I verified via "rqtgraph" that gazebo is connected to the correct topic (/cmdvel ) and via "rostopic echo /cmdvel" that data is published to the right topic. I am using 1.9Gazebo&Gazebo-ROS-packs and hydro ROS installed from binaries for this simulation.

Thank you for any help with this issue
