Answers

Neither Kinetic nor Ubuntu Xenial are currently supported by the community. If possible, you really should upgrade to a supported version of Ubuntu (either 18.04 or 20.04).

If you absolutely can not upgrade, Canonical provides paid support for 16.04, including ROS Kinetic.
