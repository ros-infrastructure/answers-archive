Answers

It's not possible to have them side-by-side because fuerte only supports Ubuntu versions up to 12.04 while the "oldest" Ubuntu version indigo supports is 13.10

See:

http://wiki.ros.org/indigo/Installation/Ubuntu
http://wiki.ros.org/fuerte/Installation/Ubuntu

If you've got a powerful machine, you can install one version to your system and the other into a virtual machine with another Ubuntu version. If you set up networking correctly, these two can communicate together (as long as the messages used have not changed).
