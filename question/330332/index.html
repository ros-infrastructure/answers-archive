What is the easiest way to dump messages of all topics in a rosbag which may be started and stopped by a trigger in c++?

(I have a program which has to decide the start and stop time of a recording.)

I wonder, is there a more smooth way to do this in a single node and without having to terminate the node? I have about one hundred different topics with various standard and custom message types, so implementing some sort of callback would only be acceptable if it was a generic, message-type independent one. Is there a way to do this?

So I know, there may be different ways to approach this. Any help is appreciated!
