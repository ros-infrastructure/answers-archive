turtlebot3 publisher not recognized

Hi All!

This week I started to learn ROS and I wrote a script that should make the turtlebot3 move in a simulated environment with gazebo. I wrote a script that publishes on 'cmdvel'. However, when I run the turtlebot3 script and the publisher.py script I noticed that my bot is not moving. I checked if the publisher was actually publishing on cmdvel. when I typed 'rostopic info cmdvel' I saw that there was no publisher, and only a subscriber called gazebo. After some digging around I noticed that my publisher script was actually publishing on /cmdvelmux/input/teleop. Below I have posted my script. I defined the publisher to be publishing on cmdvel, so I am quite lost as to why it is publishing on cmdvelmux/input/teleop. Any thoughts what is wrong with my script? Thanks!

Script:

#!/usr/bin/env python

import rospy
from geometry_msgs.msg import Twist
import sys


def move_bot(line_vel, ang_vel):
    rospy.init_node('moveturtle', anonymous = True)
    pub = rospy.Publisher('/cmd_vel', Twist, queue_size = 10)
    rate = rospy.Rate(10)
    vel = Twist()

    while not rospy.is_shutdown():

        vel.linear.x = line_vel
        vel.linear.y = 0
        vel.linear.z = 0
        vel.angular.x = 0
        vel.angular.y = 0
        vel.angular.z = line_vel

        rospy.logdebug('Publishing')
        pub.publish(vel)
        rate.sleep()

try:
    move_bot(3.0, 2.5)

except:
    print('failed')
