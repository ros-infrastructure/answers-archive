Trajectory animation for non-skeletal actors

Gazebo classic 11 supported actor class with trajectory with simpler object such as box, but now this function is not available in ignition gazebo. Relevant questions can also be found here; https://answers.gazebosim.org/question/27609/mesh-skeleton-not-found-in-actor-dae-file/ https://github.com/ignitionrobotics/ign-gazebo/issues/418

This feature hasn't been ported to Ignition yet. As a workaround, you could write a plugin that directly sets poses to the model over time using the ignition::common::PoseAnimation API, for example.
