Installing ROS from binaries and Gazebo from source

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/58881/installing-ros-from-binaries-and-gazebo-from-source.

Hi Everybody, I need to run multiple turtlebots and get access of the Gazebo source code so that I can control the turtlebots. Currently I have installed both hydro ROS and 1.9 Gazebo from pre-compiled binaries. To get access the Gazebo source code I need to reinstall Gazebo from the source. My question are: Do I need to reinstall both ROS and Gazebo from the source in order to keep them working properly? or Do I just need to reinstall Gazebo from the source. Thank you in advance for any help you can provide. Robert

Answers

If you install gazebo from source. You need to install anything that depends on it from source as well. You can still use binary ROS packages which are not related to gazebo.
