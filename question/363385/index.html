Releasing Pre-Built ROS2 packages for Windows/MacOS

Hi all, I've recently created a package that allows joystick teleop of differential drives from within Rviz2. I'd like to release this package as a pre-built binary for Windows, MacOS, and Ubuntu users. It's not clear to me how I use Bloom to get a released binary for Windows/MacOS ready. Could someone point me in the right direction?

Asked by bshah on 2020-10-14 04:38:47 UTC

Comments

Answers

Bloom and the ROS build farm do not currently support releasing for Windows or Mac. The macOS and Windows binaries for ROS 2 are built using ROS 2's CI system at https://ci.ros2.org. Those binaries only include the ROS 2 system defined by the ros2.repos.
