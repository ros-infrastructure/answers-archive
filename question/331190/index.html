You will need to update your Crystal installation to the latest Debian packages synced today (see https://discourse.ros.org/t/patch-release-and-new-packages-for-ros-2-crystal-2019-08-21/10367). The ros-crystal-rosidl-typesupport-opensplice-* packages fix this assert which happens when using the latest version of OpenSplice.
