How to solve ROS indigo PR2 kinect missing problem?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/27664/how-to-solve-ros-indigo-pr2-kinect-missing-problem.

I run pr2 empty world on ROS Hydro works with kinect. But I run pr2 empty world on ROS Indigo, the kinect is missing. I can't see kinect topics and TF. Even I try to download the latest PR2 description package on my own indigo workspace and compile success, the gazebo PR2 still can't show the kinect. How to solve this problem? Thank you very much!

Asked by sam on 2016-03-07 04:26:38 UTC

Comments

Answers

You need the set the environment variable.

export KINECT1=true

or

export KINECT2=true

and then run gazebo roslaunch pr2_gazebo pr2_empty_world.launch
