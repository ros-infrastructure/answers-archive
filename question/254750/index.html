Answers

libpcan is a library for interacting with CAN interfaces from Peak System. There are many versions of the driver that are repackaged for ROS, but the original version comes directly from Peak System, and I would start with their documentation: http://www.peak-system.com/fileadmin/media/linux/index.htm
