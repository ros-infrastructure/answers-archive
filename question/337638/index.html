Trying to run node but getting: "librosconsole.so: cannot open shared object file: No such file or directory"

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/93819/trying-to-run-node-but-getting-librosconsole-so-cannot-open-shared-object-fil.

As the title says I'm trying to run my node either with rosrun, roslaunch or running the output file directly, but I'm getting this error. When using ldd on the output file it lists librosconsole.so as well as the correct folder where it is located. The LDLIBRARYPATH does contain the adress of the folder where it is contained as well.

What is causing this and how to fix it?

Answers

The problem was that the ROS environment variables (the 'source setup.bash' things) wasn't loaded on the root user, so when I was running the package with sudo it couldn't find ROS.
