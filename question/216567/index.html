Simple nodes taking up 100% CPU

I have a bunch of nodes running on a robot and sometimes (not sure after how much runtime) very simple nodes such as topictools/relay or robotposepublisher/robotpose_publisher take up 100% CPU. A restart of the system brings it back to the normal state (less than 1% CPU for the same process). I attached a gdb session to the relay node while it was consuming 100% and every time I interrupted it it was at CallbackQueue::callAvailable() (as expected, same as when it is at normal CPU usage).

The system does not appear to be on a heavy load when this happens, memory usage is fine and the number of open file descriptors seems reasonable.

Any idea what else I could check?
