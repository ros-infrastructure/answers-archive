I was able to load your model. Note that the collisions are positioned and scaled differently from the visuals. At first it was falling through like yours, but then I exported the model path and it now collides with the ground. (cd ; export GAZEBO_MODEL_PATH=`pwd`:GAZEBO_MODEL_PATH)
