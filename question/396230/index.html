Hi @pieeer1, try the following:

  1. (Re)-Install libsuitparse:

    sudo apt-get install libsuitesparse-dev

  2. (Re)-Compiling g2o:

    cd g2o/build/ cmake .. make

  3. Install

    sudo make install
