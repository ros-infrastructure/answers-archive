Answers

As @amc-nu mentioned, you are running an older (pre-1.120-alpha.1) version of Autoware that is not compatible with Ubuntu 18.04/ROS Melodic. See the updated instructions at https://gitlab.com/autowarefoundation/autoware.ai/autoware/wikis/Source-Build to build version 1.12.0-alpha.2 or higher to work with Melodic.
