This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/101581/will-ros-noetic-support-ubuntu-22-04.

Now that Ubuntu 22.04 LTS is out and Ros Noetic is the final ROS1 distro, will it be supported on Ubuntu 22? For people with newer hardware (i.e. Alder Lake CPUs) this will definitely be a must.

Core ros components are in debian https://wiki.debian.org/DebianScience/Robotics/ROS/Packages and a few more are on the way so you can apt install them without using packages.ros.org (but if you are in 20.04 still you don't want to mix and match the debian and packages.ros.org ones). But probably a lot you want to use will need building from source.

I've had good results building everything from source on 22.04 but I expect I'll be able to swap out some of that for the debian packages next time I go through it (that process is in https://github.com/lucasw/ros_from_src but it's messy in there currently). (https://answers.ros.org/question/402081/build-ros-noetic-in-ubuntu-2204/ has a more updated answer to building from source now)

While this provides some encouraging information about whether it would be possible to build ROS Noetic on 22.04, technically this is not an answer.

The question was: "will ROS Noetic support Ubuntu 22.04?"

The only correct answer would be: "No, it will not, officially".

ROS Noetic is slated to be the last ROS 1 release, and officially will not support anything beyond Ubuntu Focal (or 20.04).

There is a community effort to keep things building though: github.com/ros-o. Not just on newer Ubuntu versions, but newer versions of other Linux OS as well.

The debian.org packages are pre-built, so can be pulled down through apt (similar to packages.ros.org for 20.04, but sometimes with name changes that make it unclear what was previously ros-noetic-foo corresponds to), so for a ros project with only core dependencies it wouldn't need to build them from scratch. I can't attest to that from experience yet though, but will update here when I do.

As I understand it ros-o and the debian.org packages are the same (minus more recent commits in ros-o that haven't been released yet)- maybe a few of the released debian.org ros packages needed no alteration to build in 22.04 (or other Linux OSes with more updated dependencies that are turning deprecations warnings into outright build failures etc.) and they didn't fork them there. I used the ros-o sources to build from scratch.

Asked by lucasw on 2022-04-30 11:01:40 UTC

Pedantic -- so please forgive me @lucasw -- but to make this crystal clear for (future) readers:

no, ROS Noetic will not officially support Ubuntu 22.04.

Refer to REP-3: Target Platforms: Noetic Ninjemys (May 2020 - May 2025), specifically the sections about supported operating systems.

This will not be changed for ROS Noetic.

You can build ROS Noetic from source on Ubuntu 22.04, as @lucasw describes.
