Asked by PerkinsJames on 2012-10-22 11:24:58 UTC

To clear up a liittle, the command roscd, rosmake, etc all look through your ROS_PACKAGE_PATH environment variable, which simply has a list of directories of your ROS packages. So if you type roscd turtlebot, it will look through ROS_PACKAGE_PATH for turtlebot and "cd" there if it finds it.

Asked by PerkinsJames on 2012-10-22 11:27:44 UTC

Also, I think if you dont have a manifest.xml file in each package (each directory listed in your ROS_PACKAGE_PATH), then roscd will not work (correct me if im wrong?). manifest.xml basically is a file that designates the directory as a ROS package with some other options.
