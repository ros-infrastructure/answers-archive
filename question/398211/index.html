ros2 galactic fast dds shared memory,how to use it?

HI, I tried to send large image data through ros2, but the performance is too bad, the interprocess communication takes about 80ms for 15MB image. After use fastrtps xml, and set mode to asynchronous, it takes about 30ms, same as ros1 .

I found someone said ros2 use fasrtps shared memory (shm) by default , is it true? But according to the performance I don't think shared memory is used .

I tried this xml to set to use shared memory. however eprosima::fastcdr::exception::NotEnoughtMemoryException occurs.

<?xml version="1.0" encoding="UTF-8" ?>


<transport_descriptors>

    <!-- We still want the default UDP transport to be present -->
    <transport_descriptor>
        <transport_id>udp_transport</transport_id>
        <type>UDPv4</type>
    </transport_descriptor>

    <!-- We want a customized version of the SHM transport -->
    <transport_descriptor>
        <transport_id>shm_transport</transport_id>
        <type>SHM</type>

        <!--
            Configure the size in bytes of the shared memory segment.
            On a Linux based system, you can get the maximum allowed value with
                $ sysctl -a | grep shmmax
        -->
        <segment_size>65536</segment_size>

        <!--
            The following value should be lower than or equal to segment_size.
            The default value is shown here.
        -->
        <maxMessageSize>65500</maxMessageSize>
    </transport_descriptor>

</transport_descriptors>

<participant profile_name="CustomParticipant"  is_default_profile="true">
    <rtps>
        <!--
            As customized versions of the default transports are used, the
            built-in ones should be disabled
        -->
        <useBuiltinTransports>false</useBuiltinTransports>

        <!-- Link the Transport Layer to the Participant -->
        <userTransports>
            <transport_id>udp_transport</transport_id>

            <!-- Comment the following line in order to disable the SHM transport -->
            <transport_id>shm_transport</transport_id>
        </userTransports>
    </rtps>
</participant>

Is there any tutorials about how to use shared memory in galactic fastrtps ? or how to solve this exception. Thanks you so much !
