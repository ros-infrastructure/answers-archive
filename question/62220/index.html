I'm currently trying to set up the navigation stack for a hexapod bot.

I already reached to sent simple goals and reach them, even if the behavior can be improved, but the baselocalplaner actually doesn't take care of my maxrotationalvel limit, which I set to 0.2. Having a look on the /cmdvel topic , the planer seems to ignore my limit and sent with the default value 1.0 rad/sec. Whereas the maxvel_x limit works fine.

Does anyone had the same problem ? Is there maybe a bug or did I do something wrong ?
