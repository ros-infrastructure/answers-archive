Hi @drtritm,

If your set up is Ubuntu Bionic (18.04) With ROS Melodic I am afraid that freenect_launch is only compatible with ROS Kinetic. So you have two possibilities: either you change your set up to be Ubuntu Xenial (16.04) with ROS Kinetic or try to use the same OS you have using Openni or trying to build from source the freenect_launch package.

With respect to the error "USB interface not supported" this may help you to find the problem. The kinect 360 only support 2.0 USB ports, so at least you have the compatibility with the rpi.

About the other error "stopping device rgb and depth stream flush", it is NOT an error but a warning as said in this post.

Finally, I recommend you to stick to Ubuntu OS instead of raspbian because of the higher compatibility. You can use PINN to install Ubuntu on the rpi.
