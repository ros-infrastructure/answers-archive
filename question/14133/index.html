A good starting point is this tutorial, where you learn how to use Model::SetLinearVel to push a model.

To control joints, you could use:

  • Model::SetJointPositions to set the position for each joint in the model.

  • Get the joint controller with Model::GetJointController and hand-pick the PID parameters with JointController::SetPositionPID.

  • You can also use the JointController directly instead of calling Model::SetJointPositions

It might be interesting to also take a look at these plugins:

  • JointTrajectoryPlugin

  • DiffDrivePlugin

  • ElevatorPlugin
