I'm guessing that you are building against the sdformat default branch. We recently removed some header file includes from sdformat (pull request 224) that broken gazebo's compilation. It has since been fixed.

The sdf3 branch of sdformat should be working properly, or if you pull the latest of gazebo5, gazebo6, or default gazebo branches that should work too. Please let me know if it doesn't.
