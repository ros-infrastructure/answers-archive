I would like to see JSON data structure as a primitive data structure for ROS message declarations as if string or array.

I think you can post this as an issue with an improvement tag here:

  • https://github.com/ros2/rcl_interfaces

or here:

  • https://github.com/ros2/rosidl

Usually the maintainers will tell you where to put it if it would be the wrong place.

Small note:

Generally, people simply encode/decode ROS messages to JSON. In this way, the message size can be easily calculated etc. For regular, unrestricted JSON file, it can change too easily. I think this could be problematic for use in ROS.

Useful resources about ROS msgs <--> JSON:

  • https://answers.ros.org/question/196365/is-there-a-general-way-to-convert-ros-messages-into-json-format/

  • https://github.com/uos/rospy_message_converter

  • https://github.com/locusrobotics/json_transport/tree/release/22
