I've had some success remotely accessing the GUI on a Jetson Nano running ROS master from my Windows host using Mobaxterm.

On Remote:

  • Download VS Code
  • Setup X11 Server

On Host:

  • Download VS Code Insiders
  • Setup Mobaxterm (https://medium.com/@lixis630/extra-setup-on-wsl-for-ros-7c539463370a)

Hope this helps. Here are some useful links:

https://www.jetsonhacks.com/2019/10/01/jetson-nano-visual-studio-code-python/

https://havedatawilltrain.com/got-nano-will-code/

https://fabianlee.org/2018/10/14/ubuntu-x11-forwarding-to-view-gui-applications-running-on-server-hosts/
