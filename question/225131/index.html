How to start gazebo_ros gazebo with DART Physics engine?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/71614/how-to-start-gazebo-ros-gazebo-with-dart-physics-engine.

I am trying to spawn a manipulator with urdf in gazebo and control using roscontrol. How do I set the physics engine to be dart? I can get gazebo to run on its own by running: gazebo -e dart. How would I do the same with rosrun gazeboros gazebo?

Asked by balakumar-s on 2016-01-26 16:33:21 UTC

Comments

Answers

Yes. You can try adding the verbose flag, in case something isn't right the error or warning is displayed in console:

rosrun gazebo_ros gazebo --verbose -e dart
