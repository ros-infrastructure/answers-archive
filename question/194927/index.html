It seems, Everything is working correctly.

Open rviz, first select frame from fixed frame to /camera_optical_depth_frame or /camera_link

Now go and add plugins by topics from list

select depth_registered--> pointcloud2 it will add one plugins for pointcloud2--> dropdown topic-->select topic to /depth_registered_points
