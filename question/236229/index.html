This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/74349/how-to-run-a-node-as-a-background-process.

So I am trying to write a program in which a main publisher node will use the system function to run multiple subscriber nodes. I would like to use something like: "rosrun &", however this doesn't work for me and the subscriber node still runs in the same terminal window. How can I change the command so that it executes in the way i described? I can't seem to figure it out. Thanks!!

Answers

Does the system() call block when it executes? If not, then the command is running in the background.

Keep in mind that "background" does not imply spawning a different terminal window or logging to disk by default. The process will use the same terminal as its parent.
