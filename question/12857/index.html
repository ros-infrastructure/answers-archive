planning_environment: How to specify link padding post-diamondback?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/37522/planning-environment-how-to-specify-link-padding-post-diamondback.

The documentation of the planning_environment package states that

"...much of the information on diamondback no longer holds"

but there is no clear distinction as to what has changed and what remains the same in the ROS API. In particular, I'm interested in knowing whether specifying individual link padding values is still supported, like so (yaml syntax):

default_robot_padding: 0.01
link_padding:
  - link: foo
    padding: 0.0

In electric's pr2armnavigation_actions, there exists such a file but seems to be unused.

TIA.

Asked by yangyangcv on 2012-11-01 15:19:47 UTC

Answers

You can still set individual link padding using the yaml method - just make sure it's getting loaded in the private namespace when you launch the environment server (or wherever else you are creating a planning_environment::CollisionModels class". The default_robot_padding value is taken from the global namespace under /robot_description_planning/default_robot_padding - if you put it in your _planning_description.yaml using the auto-generated arm navigation app than things should happen correctly.
