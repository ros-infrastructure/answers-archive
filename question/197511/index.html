Easy peezy

So the libGLEWmx.so.1.11 was present in the /libfreenect2/depend/glew/lib64/ so i just created a linker using

sudo ln -s /libfreenect2/depend/glew/lib64/libGLEWmx.so.1.11 /usr/lib/libGLEWmx.so.1.11

KaPaow ! it worked
