control manager not listing contollers

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/82687/control-manager-not-listing-contollers.

I am following this page to understand roscontrols and controllermanager. I have pr2 simulation running on gazebo with 

roslaunch pr2_moveit_config demo.launch

I can move the rightarm around and perform plan & execute for random valid states. In another terminal I try to bring up controllermanager using rosrun controller_manager controller_manager list but there is no output. I also tried rosrun rqt_controller_manager rqt_controller_manager which opens the GUI with no listings under namespace.

If I am right, then atleast a Joint Trajectory Controller should be running for the gazebo process and it should be listed by the controller manager whereas here we see no controllers to be running. Please correct me if I am wrong.

P.S : All dependencies for the controllermanager and roscontrols were met. I couldnot find pr2controllermanager for ROS Kinetic version I am using, so I am trying to work around with controller_manager

Answers

The controller_manager pkg you refer to is from ros_control. Afaik the real PR2 does not use ros_control (and neither does MoveIt's demo.launch), so you cannot use the ros_control/controller_manager to interact with the PR2 controller infrastructure there.
