rviz camera use orthographic projection

There are some camera views in rviz.

  • Orbit (default)
  • XYOrbit
  • FPS (first-person shooter)
  • Top-down Orthographic

I want the view use orthographic projection, "Top-down Orthographic" can do it, but it can only rotate in Z-direction. I want it can rotate and control camera as Orbit type.

Is there any way to do it or any example code?

Since this is a top result on Google for "rviz orthogonal view" and "rviz orthographic view" I thought this might be of interest: https://github.com/lucasw/rviz_ortho_view_controller

It is a RViz plugin that provides an ortho view camera controller. I've tested it on Noetic, and it works great for my use.
