How to filter out the robot structure in ROS?

I have a turtlebot3 base structure which was mechanically modified in a specific way to serve certain needs. The final mechanical structure of the robot consists of 5 layers, while LIDAR if placed at 3 layer (same as waffle pi). The outcome of this modification is detection of robot pillars by the LIDAR, because they intersect the LIDAR`s field of view.

I have found that is it possible to filter out the LIDAR data using standard ROS tool - laser_filters. I could configure the filtration system and filtered LIDAR stream does not detect internal structures of the robot anymore.

One problem left. When I am running turtlebot3navigation launch script, I can still observe detected obstacles on the local and global cost map. The reason for this issue is usage of not filtered data source. At the moment, /scan topic is used, but I need /scanfiltered.

How can I change LIDAR data source for global and local cost maps? Here is a link to the repo which I am trying to adapt to my needs.

Found an answer. It was just necessary to 

<remap from="scan" to="scan_filtered"/>

in move_base.launch
