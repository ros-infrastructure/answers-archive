Asked by Felix Endres on 2011-03-17 04:22:35 UTC

http://www.ros.org/wiki_dump/ doesn't exist any longer, instead rsync as described in http://wiki.ros.org/Mirrors#Setup_rsync:

rsync -azv rsync.osuosl.org::ros_wiki_mirror wiki.ros.org --bwlimit=200 --delete

It will download many files into a directory wiki.ros.org, currently totals 1.45GB.
