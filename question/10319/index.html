Multiple solutions from IK solver?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/32381/multiple-solutions-from-ik-solver.

Is it possible to obtain multiple IK solutions for all the joints of an arm from the IK Solver (pr2rightarmkinematics/getik) for one specific pose of a link (i.e. rwristroll_link)?

Asked by Nash on 2011-06-19 10:50:10 UTC

Comments

Answers

Yes, this is possible. You can call the service multiple times with a different state in the ik_seed_state each time and it should give you different solutions.
