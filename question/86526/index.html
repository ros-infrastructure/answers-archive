Asked by summer on 2017-09-20 22:19:23 UTC

This error is directly related to the content inside the launch file you created. Just make sure that all necessary hashes and brackets are included as in paragraph 2.3 under this website http://wiki.ros.org/ROS/Tutorials/UsingRqtconsoleRoslaunch#CA-91a3946a9c4cf7301bb55ec0c3f8a77f6c8f9777_8.

Also make sure when you create the file, that you have only one set of numbers on the left column. Because if you copy whats inside this paragraph on a new file, that has numbers directly embedded inside of it, creates an error in format.
