When I run this in the gui, I see the stereo images are broadcast on model/link/camera_stereo/images. But when I try and save the images using the following code

void onStereoImage(ConstImageStampedPtr &msg) {

    int width, height;
    char *data;

    width = (int) msg->image().width();
    height = (int) msg->image().height();
    data = new char[msg->image().data().length() + 1];
    memcpy(data, msg->image().data().c_str(), msg->image().data().length());
    cv::Mat image(height, width, CV_8UC3, data);

    if (debug) {
      cv::imshow("left", image);
      cv::waitKey(1);
    }

    delete data;
  }

I only get one of the images. How can I get both images in the callback above? I subscribe to the topic using the following code

int main(int argc, char **argv) {

    gazebo::client::setup(argc, argv);
    gazebo::transport::NodePtr node(new gazebo::transport::Node());
    node->Init();

    gazebo::transport::SubscriberPtr stereoSub  = node->Subscribe("~/model/link/camera_stereo/images", onStereoImage);

    while (true)
        gazebo::common::Time::MSleep(sleepTimeMs);

    gazebo::client::shutdown();
 }

Answers

The callback function should be ConstImagesStampedPtr (note Image*s*). you should then be able to loop through the camera images like what the gazebo topic viewer is doing when visualizing multicamera image data
