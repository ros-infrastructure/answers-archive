Hi it seems like there are new packages for hydro!

the debian package is called

ros-hydro-pr2-gazebo

you can start the pr2 with the command:

roslaunch pr2_gazebo pr2_empty_world.launch

but I have just found it right now and tested it, this packages seems to use the normal 1.9.5 version of gazebo...
