This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/33846/rxtools-build-error-on-osx-snow-leopard.

When I run "rosmake rxtools" - I get:

{------------------------------------------------------------------------------- ~/ros/rx/rxtools/src/rxtools/rosoutpanelswiggenerated.cpp:6149: error: expected `)' before 'void' /Users/tobymartin/ros/rx/rxtools/src/rxtools/rosoutpanelswiggenerated.cpp: In function 'void* pwxFileDialogTopwxDialog(void*)': ~/ros/rx/rxtools/src/rxtools/rosoutpanelswiggenerated.cpp:6155: error: 'wxFileDialog' was not declared in this scope ~/ros/rx/rxtools/src/rxtools/rosoutpanelswiggenerated.cpp:6155: error: expected primary-expression before 'void' ....etc.

But still, rosmake can't seem to find those headers. Anyone have any ideas?

Answers

Nevermind - I found a solution. I created a symlink in /opt/local/include wx@->wx-2.8/wx

with the command: sudo ln -s wx-2.8/wx wx
