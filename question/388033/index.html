I don't have much experience porting entire Arduino projects to ROS, I usually start the project knowing that I need ROS for various reasons and add/build my code accordingly. A couple things you mentioned are of concern for sure, that you already at 96% memory and even though rosserial is pretty light, there will be overhead to consider.

My suggestion is to take a modular approach. Rather than port all at once, port functions, create nodes, test them, make sure you are pretty happy with the outcome and keep building on it. For the long term, I think moving to ROS is the right thing to do for Arduino projects, you will be able to do so much more and the advantage it's you don't have to reinvent the wheel. Finally, in this forum, it's encouraged to ask a single question so the community can provide an answer to it. So kindly narrow the scope of your ask.
