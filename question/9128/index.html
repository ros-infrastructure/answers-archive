Answers

Ok, I solved this. The tag 1 had to be added in the two links of the two fingers. I read in the documentation that it was possible to declare it for the entire model, but it is not !

☑️ This answer was ACCEPTED on the original site.

Comments

A bit late but it does work when you declare it for the entire model. Only that you have to do it inside a gazebo tag:

  <gazebo>
        <self_collide>1</self_collide>
 </gazebo
