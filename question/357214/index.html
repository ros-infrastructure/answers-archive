Did you load both or just one? In Autoware.AI, a "vector map" (really an Aisan-format map) uses one set of nodes and a Lanelet map uses another. You can not use both at the same time. In addition, you must be localized and have a transform between the Lanelet or vector map and your point cloud map being published.
