How can I move an actor in Gazebo with ROS using keyboard? Would that be possible to do?

Answers

I haven't seen a ready-made package for it, but you should be able to implement it by:

  1. using some ROS package to capture key presses (I assume you want key presses on the terminal?)
  2. Publish key presses with ROS
  3. Have a gazebo::ModelPlugin attached to your actor which is listening to the ROS messages and controlling the actor. Here's a plugin which makes an actor walk/run to specific target points, you could adapt it to your needs.
