The first issue is because you do not have a default configuration saved. You can click through it, after you have a good rviz setup do File > Save Config. This usually happens when you start rviz for the first time. If you close rviz from the gui it asks you to save the default config.

The second error is related to tfs not being generated, this is not related to the first message.
