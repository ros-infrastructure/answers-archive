I think the bullet hinge joint error messages are likely to be false positives. There are calls to set joint properties on joint initialization but those don't work for the bullet case. Later on, bullet sets these properties in it's own Init function.

But I agree the error messages are confusing and they should not omitted on initialization.

You can test bullet hinge joints by inserting existing models from the model database, e.g. double pendulum or simple arm
