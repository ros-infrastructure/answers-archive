xb3_short/left/image_raw                                                            
xb3_short/left/camera_info                                                    
xb3_short/right/image_raw                                         
xb3_short/right/camera_info                                                      

xb3_wide/left/image_raw                                                              
xb3_wide/left/camera_info                                                          
xb3_wide/right/image_raw                                                        
xb3_wide/right/camera_info

But actually xb3short/right/imageraw and xb3wide/right/imageraw are the same images. This will result a extra space when i need to record bag files with the camera. Is there a way to record only 3 images instead of 4?
