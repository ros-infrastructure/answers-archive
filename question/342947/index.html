Answers

project(pcl_ros)

Is your package named pcl_ros? If so and unless you're modifying the existing package of the same name, avoid using that name as it's already taken by well-known library.

Your CMakeLists.txt has many targets and yet haven't mentioned the name of the .cpp file you showed, so I can't tell which target is the one in question.

undefined reference to indicates the builder (e.g. catkin, colcon, or g++ that is wrapped by them) doesn't know where the header that is declared to be included in your code can be found. I assume those in the error are the ones provided by the original pcl_ros package. So I'd:

  1. Rename your pkg to something else other than pcl_ros
  2. Add pcl_ros in find_package list.
