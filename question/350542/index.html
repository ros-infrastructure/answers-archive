Looking at the example cdr_test_0.db3 file in the rosbag2 repository unit test it does not appear to contain the IDL for either of the two published topics. The CDR serialization alone is not enough to reconstruct field names such as bool_value or byte_value. It appears that you need to come up with your own way of retrieving the full set of .msg files used to produce each bag, such as storing them alongside each bag or recording a git commit hash per bag and retrieving them from source control.

This would also imply there is no standardized way of publishing or exchanging rosbag2 files, which seems like an oversight. I hope I am missing some important piece of context about this.
