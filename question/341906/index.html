Asked by Orl on 2020-01-21 00:43:16 UTC

Cannot help further debugging anything with the LiDAR without a bagfile...

But having read again your question, I have another idea:

You are using Cartographer to build a map that is then populating the global costmap, right? So the global costmap is updated regularly from cartographer?

I'm not sure about what information you get from cartographer, but there are two things I'd try:

  1. setting unknown_cost_value = 255 seems wrong to me. 255 usually means "lethal obstacle". The combination you have right now means "obstacle is lethal when value is > 100, but actually unknown if the value is 255". I'm not sure if this makes sense. Usually, unkown is -1.
  2. You could also try setting trinary_cost_map to true to not get intermediate values (i.e. between 0 and 100). I guess this could already solve your issues.

In the end, the more I think about it, the issue is probably with the input data, i.e. the map created by Cartographer...
