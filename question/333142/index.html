boost_signals library not found

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/93295/boost-signals-library-not-found.

I am using a Fedora 30 Workstation. I want to install ROS. Tutorial/Instructions link : http://wiki.ros.org/melodic/Installation/Source.

The Step 2.1.2 Building the catkin Workspace, when I execute the given command, It fails. There are 2 errors that I can see from the terminal output

  1. Could not find the following Boost libraries: boost_signals
  2. Failed to process package 'tf2'

For the 1st error, I checked the /usr/share/cmake/Modules/FindBoost.cmake file, It has a single line referring to the signals headers : set(BoostSIGNALS_HEADERS "boost/signals2.hpp"). The file signals2.hpp exists in the boost directory, so that is not the issue. ROS, I guess, is not able to find this header file for some reason. I have also installed all the boost libraries via dnf ( boost, boost-devel, boost-python3).

For the 2nd error, I have installed the geometry libraries via dnf, it doesn't solve the issue.

Take a look at https://github.com/ros/geometry2/pull/354, which removes the signals requirement. That change hasn't been released yet, but I'm pretty sure it addresses this error.

Thank you! This worked. Basically, all instances of signals had to be removed. I also encountered a boost_python library not found - This was fixed by changing this : find_package(Boost REQUIRED python) to this : find_package(Boost REQUIRED python27) If it still fails, delete everything and do the recommended installation, instead of the full installation.
