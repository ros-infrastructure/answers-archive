Answers

I found out an option for achieving smooth shading inside gazebo: Using Blender, "smooth shading" can be selected for all areas of your model that should be smooth shaded (I thought this was only a visualization option, but it in fact actually is a property of the mesh). Blender materials can also be used to set the color and lighting properties of the model. Then, after converting the model to triangles only (to work around gazebo not working with quad based COLLADA, as described here), the model can be exported to a .dae COLLADA model. When not specifying a material in the world file using the tag, the materials of the .dae will be used.
