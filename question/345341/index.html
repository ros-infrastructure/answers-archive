You don't seem to be creating a service server anywhere, only a client. This is likely the reason why you get the message "waiting for service to become available ..."

Is there another node in your system providing the /init service ? If not you need to create a service server similar to this tutorial https://index.ros.org/doc/ros2/Tutorials/Writing-A-Simple-Cpp-Service-And-Client/#write-the-service-node
