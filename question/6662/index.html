What part of gazebosim would not work in Windows/Mac

As far as I know ODE/Bullet, OGRE are working on both Windows and Linux, so what part of gazebosim not working on other platforms yet?

Answers

Gazebo is largely working on Mac OSX (installation instructions using homebrew here). We would like to make a double-clickable dmg of gazebo, but we haven't made that work yet. There are some open issues.

Most of the Gazebo dependencies work on Windows (notable exceptions being libtar and pkg-config). We are currently working on Windows support in a piecemeal fashion, splitting out the math and transport libraries into separate repositories and using c++11 to eliminate most of the boost dependencies (since boost is more tricky to install on Windows). We have a Windows build machine testing these new libraries. It is a work in process.
