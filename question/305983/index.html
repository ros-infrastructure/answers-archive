How should nodes bond::Bond::waitUntilBroken()?

The documentation doesn't make it clear how one continues once both ends of a bond are connected.

Taking existing nodelets (in different managers), I have added on_formed and on_broken callbacks, and I can see my two ends of the bond connect after calling bond.start(). However, once I drop back to my existing code, after about 5 seconds bond::Bond::onConnectTimeout() fails and calls my on_broken() to inform me. rostopic echo /mywatchdog/bond shows me messages stop as soon as the bond is established.

This suggests to me that `bond` is synchronous, so perhaps both ends need to use `waitUntilBroken()` to keep the heatbeat ticking. How do other people handle this? Starting a thread that just calls `waitUntilBroken(-1)` seems very wasteful!

UPDATE: I've debugged a bit further, and the problem seems to be to be in the Bond::bondStatusCB function - somehow things aren't syncing up correctly, even though I have successfully shared the id between both nodes.
