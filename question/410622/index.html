Answers

You should use/implement a ROS node (using the pointcloud <--> laser scan conversions from pointcloud_to_laserscan/laserscan_to_pointcloud from there + there) that reads the laser scans from all LiDAR scanners as pointclouds and merge them into a single laser scan (360 degrees).

EDIT: Changed answer to ROS1 version.

Please check the @Mike Scheutzow comment below regarding the multi-plane lidar - you have to filter the scans first if you wanted good results.

I found more detailed information here: https://www.cvlibs.net/datasets/kitti/raw_data.php

Perhaps you should check the suggested tools:

Yani Ioannou (University of Toronto) has put together some tools for working with KITTI raw data using the PCL.
