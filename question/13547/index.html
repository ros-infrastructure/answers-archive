Answers

I never tried to do it through the gui, but you can easily specify those properties in the sdf file of the world you load, something like:

<model name='link'>
  <link name='link_name'>        
     <inertial>
      ...
      <mass>85</mass>
      ...
    </inertial>
  ...      
  </link>
  <static>1</static>
</model>

have look at this page to find out more about sdf specifications.

Hope this helps.

To make it static add a <static>true</static> tag under the <model> tag of your SDF.
For mass, you'll have to go under <inertial> of every link in the object and add a <mass> tag.

Also, for reference, use this link: http://sdformat.org/spec
