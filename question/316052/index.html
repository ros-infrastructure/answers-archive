rosrun map is not created its giving the waiting state always

Hello,

I am new to ROS I want to use bag files and generate a map with it. I am following the this tutorial https://wiki.ros.org/slam_gmapping/Tutorials/MappingFromLoggedData

I am using the bag file given in the tutorial named as basiclocalizationstage.bag. Here I am able to run the bag file but not able to generate the map by using "rosrun mapserver mapsaver -f my_map" this command. It always shows as:

[ INFO] [1550589155.317257429]: Waiting for the map

It does not comes out of it.

Answers

The bagfile you use doesn't have the topic map, if you do rostopic list while playing the bagfile you'll see :

/base_scan
/clock
/rosout
/rosout_agg
/tf

The map_saver node try to read the topic /map to save a map, since it doesn't exist it stays idle and wait for this topic to be published.
