ROS2 robot heading right with nav2

I'm currently implementing the nav2 stack on the LeoRover.

The system is composed of a jetson xavier and a raspberry pi. Only the jetson is interesting here, it's running ubuntu 20.4 and Ros Foxy.

I implemented the nav2 stack and trying to send goals to my rover, but it is always heading right, then it need to correct is orientation or rotate until getting the right orientation.

You can see in the following picture, the robot is heading right even if it should have head left (it started facing the obstacle, at the origin)
