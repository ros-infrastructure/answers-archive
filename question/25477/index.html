Regarding the second question:
To implement the spring/damper I had not to add new links to represent them, but in the revolute joint I used two dynamics properties "damping" and "friction". Thus, the behavior was got, but it is not perfect because the chosen value of damping and friction was chosen experimentally not using mathematic to get the real values.
