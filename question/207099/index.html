Kobuki : Timed out while waiting for serial data stream [/mobile_base] on Indigo

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/67009/kobuki-timed-out-while-waiting-for-serial-data-stream-mobile-base-on-indigo.

Using a turtlebot 2 on 14.04.2

I ran through the install section at http://wiki.ros.org/turtlebot/Tutorials/indigo/Turtlebot%20Installation and the network setup.

When running:

roslaunch turtlebot_bringup minimal.launch

The kobuki base makes it's startup noise, then, a few seconds later it makes it's shutdown noise. With the following error message being produced on the console:

[ERROR] [1428974938.134654823]: Kobuki : Timed out while waiting for serial data stream [/mobile_base]

I get the same error when I try the kobuki node by itself:

$ roslaunch kobuki_node minimal.launch

setting /runid to 0d2810f0-e247-11e4-8a15-0024d76aae74 process[rosout-1]: started with pid [22493] started core service [/rosout] process[mobilebasenodeletmanager-2]: started with pid [22510] process[mobilebase-3]: started with pid [22511] process[diagnosticaggregator-4]: started with pid [22546] [ERROR] [1428975556.731802475]: Kobuki : Timed out while waiting for serial data stream [/mobilebase]. [ERROR] [1428975568.331793777]: Kobuki : Timed out while waiting for serial data stream [/mobilebase].

This turtlebot was previously working in Furte.

Any ideas?

Answers

In the end, powering off, then powering back on my turtlebot laptop seemed to be the fix.

The suspicion was usb bus issues with the kinect and the kobuki on the same usb port.
