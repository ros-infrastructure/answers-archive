Is it possible to have a collaborative simulation environment in Gazebo? I mean, one where multiple users in different locations can view/interact with the simulation?

Answers

You can use gzweb and host the simulation on a public server, so anyone with the URL will be able to interact with the simulation at the same time via web browsers.

You can also use the usual Gazebo client (gzclient), but this requires more setting up on every user's side, they need a full install of Gazebo and to point GAZEBO_MASTER_URI to the address running gzserver. You can read more about these components here.
