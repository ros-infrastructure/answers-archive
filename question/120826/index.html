Are there any plans to catkinize the KnowRob packages and release them for Hydro?

Asked by ZeynSaigol on 2014-01-22 05:19:12 UTC

Comments

Answers

Not currently. KnowRob depends on rosjava_jni that is not yet catkinized (and would require more significant changes, e.g. updates to the message generator). Since the system still works using rosbuild and conversion would require much effort, this is currently not on high priority.
