Answers

OpenCV is not a valid rosdep key. That is why rosdep install .. cannot find it.

I recommend reporting this as a problem with the thinc_sim_gazebo package on the thinc_simulator issue tracker .. if it had one (it doesn't, the maintainers have disabled the issue tracker).

As a work-around: make sure you have OpenCV already installed and add the -r option to your rosdep install command. That will make rosdep ignore the keys it cannot resolve and continue with the rest.

Provided it doesn't skip anything absolutely critical, things could/should still work.
