Well, it depends on which object are you recieving the image, but in order to send it trough ROS, the default transport message is Sensor_msgs::Image (http://docs.ros.org/en/melodic/api/sensor_msgs/html/msg/Image.html)

So, you should convert it to that.

here there is an example of how to do it, for example,with cv::mat:

https://answers.ros.org/question/9765/how-to-convert-cvmat-to-sensor_msgsimageptr/

Nevertheless, this is on ROS side. you shouls find a solution for JS (i don't think it should be hard).
