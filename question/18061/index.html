According to the discussion on this issue, the problem is linking gazebo sensors to physics and has been fixed for Gazebo 7+, but that specific fix can't be backported to Gazebo 6 without breaking ABI (and won't, since Gazebo 6 is no longer supported).

One thing you could try if you reeeeally want to use Gazebo 6 would be to port the changes from this pull request to the gazebo6 branch locally on your machine.
