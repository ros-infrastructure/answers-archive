Often you get a message like this if your package index is out of date. Try calling sudo apt-get update before your apt-get install command.

Also I assume you're following the Ubuntu installation guide double check that you've followed each step.

Also this video is targeted for the TurtleBot, but follows almost exactly the same installation path.
