How to set Rviz to 60 Hz?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/71168/how-to-set-rviz-to-60-hz.

Hello, I am trying to set Rviz to 60 Hz according to David Gossow´s post here: http://ros-users.122217.n3.nabble.com/Oculus-Rift-Integration-in-RViz-td4020193.html

How can I do so? Thanks!

Answers

If you're using a newer version of ROS such as Indigo or Jade, the ability to set the frame rate is built into rviz.

In the "Displays" panel (usually on the left side of the window), within "Global Options", there should be a option for "Frame Rate", which defaults to 30. Change this value to 60.
