This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/50091/compilation-error-on-arduino-sketch-with-ros-lib.

I tried to run the ros_lib HelloWorld program on an Arduino Uno, but got the following error:

Background: I have groovy installed on my netbook . I used the instructions here with the rosbuild option to build rosserialarduino on the netbook. I then moved the roslib libraries to the relevant Arduino folder and tried to run the example sketches on the Arduino.

Go to sketchbook/libraries/ros_lib/rosserial_msgs and open Log.h using a text editor. Rplace ROSDEBUG with DEBUG save the file and your done.
