Installed packages not staying when exiting Autoware docker container and re-entering

In the docker container I'm using for my Autoware project, I'm trying to install various python packages. However, installing packages with pip3 or pip2 isn't permanent, and pip2 itself also isn't permanent, and needs to be reinstalled every time I re-enter the container. I'm creating the container using ./run.sh -b $HOME/autoware.ai, which I got from a previous question, so the container keeps files properly. I'm pretty sure I'm missing something, but I don't know what it is, and looking things up online didn't give me any leads. Thanks in advance.

Answers

Instead of installing dependencies in the container, you should really be installing the dependencies into the docker image that is used to create the docker container. This is done by modifying the source Dockerfile or writing a child dockerfile that builds from the parent image you'd like to start from. See the Dockerfile reference on Docker docs for more info: https://docs.docker.com/engine/reference/builder/

You'll then want to check how to specify the run script to use your custom docker image when spawning containers.
