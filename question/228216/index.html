Ubuntu cannot get ip address from Sick TIM561

I got one Sick TIM561 and I connect it with my laptop by Ethernet. On the Windows 7 it works well with the official SOPAS-ET that I could connect the lidar and see the scan result.

But problem is that when I switch to Ubuntu 14.04 (I installed it on the same laptop) my laptop is not able to get the IP address which means I cannot use the sick_tim package. By the SOPAS-ET I saw the default config of TIM561 which enable the DHCP.

I installed the sick_tim package and should I install any driver for linux?

Thanks

Answers

Make sure you config SickTim to static ip, the default ip is 192.168.0.1. Then make sure you have your laptop (Ubuntu) has an ip address on the same subnet, e.g. 192.168.0.2 This should work. sick_tim package has everything you need.
