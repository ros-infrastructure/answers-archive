What is the best way to master gazebo?

I am working in a humanoid robot project and my task is to do the simulation using gazebo, but i have only 6 months to master it. So I would like to know what is the best and fastest way?

Some good steps would be:

  1. Go through several Gazebo tutorials. There is an ever growing number of them, so it might be hard to know where to start from. A good starting point could be the beginner guided tutorials and then continue to the intermediate ones.

  2. If you'll need to model the robot from scratch, be sure to check a few of the build a robot tutorials, which go into more detail than the intermediate ones.

  3. If you'll need to control the robot, be sure to check the write a plugin tutorials. You might be specially interested in "model plugins".

  4. If you'll be using ROS, go through the connect to ROS ones.

  5. Finally, once you've got the general ideas and want to get specific about humanoids, it's a good idea to look at existing projects, so you can see what approaches were taken and how the models were tuned and controlled. One example is the Atlas robot used in DRCSim, but you can find several others if you search for them.

  6. Oh and of course, be sure to ask questions here if you ever feel stuck ;) Have fun!
