Answers

If you go to the page of the unstable build (http://build.ros.org/job/Lpr__openni_camera__ubuntu_xenial_amd64/2/) you will find that it has compiler warnings. That make the job unstable which on Travis GitHub is interpreted as a failure. Since that didn't prevent to build the Debian packages the release builds still pass.
