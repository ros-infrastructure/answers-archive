If you are on Ubuntu / Debian / any distro with dpkg:

user@machine:~$ dpkg -S libgazebo_ros_gpu_laser
ros-hydro-gazebo-plugins: /opt/ros/hydro/lib/libgazebo_ros_gpu_laser.so
