You can have a look at https://github.com/ros-controls/ros2_control This uses ROS 2 and has all the things setup for Windows as well (i.e. visibility macros etc). I used it for controlling an ABB robot with it. I believe with a correct hardware interface towards the UR5, you should be able to reuse some of the code.
