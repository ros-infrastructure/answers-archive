How to integrate Octomap in Gazebo?

Is it possible to use an Octomap (.ot) in Gazbeo? If yes, what is the best way to do it?

Gazebo can't load .ot files. You'll have to write a plugin that loads the files. If you just want to visualize the data, then a GUI or Visual plugin will suit your needs.
