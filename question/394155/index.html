@Trahery the scan callback() function will not be called until the next time a message is published - that may take a long time. Your code must be written in a robust way to handle that. Sleeping for a fixed amount of time is a bad approach. If your is_obstacle() function expects 185 elements in the array, then check for that and do something sensible if they are not there.
