Answers

Before I asked for help, many probable solutions were found on the internet, but none worked. While doing a completely different internet query, I stumbled on the answer. Just do the following when all else fails: sudo apt -o Dpkg::Options::="--force-overwrite" --fix-broken install

All will then work!
