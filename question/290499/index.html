If I understand your question correctly you have a mobile platform with two Lidars, a camera and a GPS receiver. You want to record this data at the same time as viewing it live in a GUI.

This is all very straightforward with ROS, we regularly do this in our lab on field trips.

@gvdhoorn makes a good point. A system like this in ROS would be a distributed set of binaries working together. They would provide a single UI though and could be started by a single command. Really importantly you could build this system entirely using existing parts (nodes)

A couple of things to clarify. Will the platform be remotely controlled via ROS?

Do you need the system to perform pose estimation from yours sensor data?
