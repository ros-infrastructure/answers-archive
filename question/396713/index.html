With ros1bridge you normally handle that with a rule.yaml file exported by the ROS2 package. However, since these packages are pulled in with apt I can't add the file directly to gpsmsgs. Would I need to build these messages from source? Or is there a solution which doesn't require as much change to my dependency management?
