Unable to change the default pose of human actors when using talk_a.dae or talk_b.dae

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/29021/unable-to-change-the-default-pose-of-human-actors-when-using-talk-a-dae-or-talk.

Below is a section of my code: -2 -4 0.2 0 0 1.57 talka.dae 1.0 <animation name="talka"> talk_a.dae

I am using Gazebo 9. I would like to load this actor at a specified pose but the pose does not seem to be applied even if I specify in the code. Any help would be appreciated. Thanks.

This is not ideal, but one trick is to also add a <script><trajectory> with 2 waypoints that have the same pose. Here's an example:

  <actor name="talkingA">
    <pose>5 5 5.76 0 0 0</pose>
    <skin>
      <filename>model://actor/meshes/SKIN_man_blue_shirt.dae</filename>
    </skin>
    <animation name="animation">
      <filename>model://actor/meshes/ANIMATION_talking_a.dae</filename>

    </animation>
      <script>
        <trajectory id="0" type="animation">

            <waypoint>
              <time>100</time>
              <pose>5 5 5.16 0 0 0</pose>
            </waypoint>

            <waypoint>
              <time>100</time>
              <pose>5 5 5.16 0 0 0</pose>
            </waypoint>

        </trajectory>
      </script>
  </actor>
