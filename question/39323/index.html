The documentation is maintained in the source code, so you can download the source code:

$  https://kforge.ros.org/vcstools/rosinstall

then make the changes in the doc subfolder. You can then create a patch to attch to your tieckt (see Lorenz' answer) like this:

$ hg diff doc
