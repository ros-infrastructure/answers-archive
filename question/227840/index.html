Asked by Mathias Lüdtke on 2016-03-02 04:38:41 UTC

Thanks, so if schunk_powercube_chain controls subscription and publishing of joint velocity/states, will I need to incorporate separate packages to handle inverse kinematics?

Asked by gracecopplestone on 2016-03-02 13:49:07 UTC

schunk_powercube_chainjust provides joint states and a velocity interface. cob_trajectory_controller provides a trajectory action on top of it. For kinematics you have to write a URDF, the tf system will give you the FK. For IK you have to use MoveIt! or any other available option.
