Gazebo7 tries to load models from my home folder at start

When starting Gazebo7 in Ubuntu Xenial: 

gazebo --verbose
It tries to load models from my home folder: 
[Err] [InsertModelWidget.cc:298] Missing model.config for model "/home/nvidia/.PyCharmCE2018.3"
[Err] [InsertModelWidget.cc:298] Missing model.config for model "/home/nvidia/.cache"
[Err] [InsertModelWidget.cc:298] Missing model.config for model "/home/nvidia/.compiz"
[Err] [InsertModelWidget.cc:298] Missing model.config for model "/home/nvidia/.config"
[Err] [InsertModelWidget.cc:298] Missing model.config for model "/home/nvidia/.dbus"
...
What's failing? Thanks

Answers

It looks like /home/nvidia is in your model path, check the GAZEBO_MODEL_PATH environment variable, and ~/.gazebo/gui.ini.

Note that you can ignore those errors, they're just telling you that if directories like /home/nvidia/.cache were to include a model, those wouldn't be shown on the left panel's insert menu.
