You can launch several launch files with several roslaunch commands in several terminal windows. The launch files can come from several workspaces but please, make sure that the messages used are know from all nodes otherwise you will get issues.

I think that the best is to use extend the workspaces, see: http://wiki.ros.org/catkin/workspaces#Overlays

The idea is to source the ROS installation (/opt/ros/melodic/setup.bash) while building the first workspace. Then source this workspace before building the second workspace. Then the packages in the first workspace will be known by the second workspace. You can then write a launch including other launch files with the include statement: http://wiki.ros.org/roslaunch/XML/include
