I found a solution. I forgot to link the library in the CMakeLists.txt file

target_link_libraries(${PROJECT_NAME} ${catkin_LIBRARIES} ${GAZEBO_LIBRARIES} ${ARMADILLO_LIBRARIES} DepthCameraPlugin )
