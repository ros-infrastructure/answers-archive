Answers

The error cannot import name 'TransformException' from 'tf2_ros' suggests that something is broken in the tf2_ros package. Or maybe it is unavailable. Please install it by using the following command:

sudo apt install ros-noetic-tf2 ros-noetic-tf2-ros
