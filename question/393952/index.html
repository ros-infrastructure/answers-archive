Getting black scans on ground using rtabmap while generating map from point cloud

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/100978/getting-black-scans-on-ground-using-rtabmap-while-generating-map-from-point-clou.

Hello, I am using laser assembler package to convert 2D laser scans to 3D point cloud and then using the point cloud to get a 2D occupancy grid map which can be provided to move base for autonomous navigation but I am getting black scans on the ground. Also the map does not get updated in rviz when I move the robot using teleop but it gets updated in rtabmap viewer. Please can anyone tell me what could be the issue and how this can be solved ? I am using this command - rosrun rtabmapros rtabmap -d _subscribedepth:=false subscribergb:=false subscribescancloud:=true scancloud:=/cloud2 odom:=/odom approxsync:=true queuesize:=500

Answers

Ok the problem has got solved, just had to set some of the grid map parameters to a certain value so that the scans do not detect the ground as obstacle and set the parameter "map_always_update" to "true" so that the map keeps updating in rviz while moving the robot using teleop.
