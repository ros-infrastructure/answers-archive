I found this link and helped me : Link in portuguese.

This command takes the encoding of the machine running the program.

Add include locale in your code: 

#include <locale.h>
#include "ros/ros.h"

 int main(int argc, char **argv) {
     setlocale( LC_ALL, "" ); 
     ROS_INFO ("调试信息");
}
