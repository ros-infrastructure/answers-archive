Comments

Problem solved. Of course it had to do with the shared library phidget21. The solution was to edit CMakeLists.txt: Exclude (comment) all parts of the phidgets-ros-pkg from compilation i didn't need and add 'target_link_libraries(advanced_servo phidget21)' (i needed only advanced_servo. Worked!
