What is the purpose of `exec "$@"` in ros_entrypoint.sh ?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/75706/what-is-the-purpose-of-exec-in-ros-entrypoint-sh.

Looking at the Dockerfiles here: https://github.com/osrf/docker_images/tree/master/ros/indigo/indigo-ros-core, what is the purpose of exec "$@", i.e., the last line in ros_entrypoint.sh ?

Asked by spmaniato on 2016-08-08 17:17:17 UTC

Comments

Answers

exec "$@" causes the shell to exec the arguments that were passed in.

In this case, the ENTRYPOINT script is setting up the ROS environment and then executing the command that you gave it.

The docker documentation for ENTRYPOINT goes into more detail about what ENTRYPOINT files are and how they work.
