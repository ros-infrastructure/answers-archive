I read the hardware spec of turtlebot3-burger and it is mentioned that "maximum translation velocity = 0.22m/s". Is it the maximum value I can give to linear 'x' component of velocity from Twist message. Or, it has different meaning?

Yes this is correct. It is possible to set larger values if you want but the locomotion node will simply clamp them to +/- 0.22.
