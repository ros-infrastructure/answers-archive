how to increase real time factor while doing simulation

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/29009/how-to-increase-real-time-factor-while-doing-simulation.

When I load an empty world in gazebo,the real time factor is close to 1,but if I load a pr2 model in the gazebo environment,the value of it decrease to 0.2.How to increase the value of real time factor when doing simulation with pr2? I tried modifying the physics link in the wrold file,but it didn't help...

Asked by Carrot12138 on 2020-05-28 21:00:37 UTC

Comments

Answers

On the left panel, go to the World Tab and click on Physics. Then change the real time update rate to 0. This will make gazebo run as fast as possible.
