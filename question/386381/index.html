pcl_ros does not have that capability. After generating the .pcd files using 

rosrun pcl_ros bag_to_pcd <input_file.bag> <topic> <output_directory>

you can use a pcd-to-text tools publicly available like THIS and THIS to convert those .pcd files into .txt files.
