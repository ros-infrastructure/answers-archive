First of all check that the Raspberry Pi is pingable. If that is the case check the ROS_DOMAIN_ID on both machines (echo $ROS_DOMAIN_ID). If the ROS_DOMAIN_ID is not equal you can set it to the same value (e.g. 1) by executing : export ROS_DOMAIN_ID=1 on both machines.
