-11 is a SEGFAULT, which is typically caused by trying to dereference uninitialised pointers, already free()d memory, dangling pointers, out-of-bounds array access etc.

This is likely not ROS specific, but a general programming problem.

However, the process crashes without giving out any error

SEGFAULTs are a) fatal errors, which your program can't respond to itself, and b) detected and managed by the OS. If a SEGFAULT is detected, your program is terminated, no part of it can run, and there is no way for you to register an "error handler" which could print anything.

But again, this is very likely not something to do with ROS.

I'd suggest building the debug version of your program, running it in a debugger (either gdb or a visual one if you prefer), waiting for it to crash and then use the debugger to figure out where things go wrong.

There isn't really anything anyone can do for you here, as it's a problem local to your specific program.
