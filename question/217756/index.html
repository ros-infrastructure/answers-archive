Unify parameters names for local planner

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/69653/unify-parameters-names-for-local-planner.

Plugin dwalocalplanner uses pathdistancebias/goaldistancebias/occdistscale, but baselocalplanner uses pdistscale/gdistscale/occdistscale with the same semantics. the configuration for some robots, as Turtlebot : it uses baselocalplanner but sets dwalocalplanner parameters.

https://github.com/turtlebot/turtlebot_apps/blob/indigo/turtlebot_navigation/param/dwa_local_planner_params.yaml

Something similar happens with other parameters mininplacerotationalvel/mininplaceveltheta or maxrotationalvel/maxveltheta

so which ı used parameter names are important for planners ?

Answers

This is where namespaces are very useful, when setting the parameters, say in a launch file you can group things

<group ns="some-namespace"> <param ....> ... </group>

This way, even if some parameters have similar names, every node gets the right params
