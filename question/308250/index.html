The vast majority of packages and libraries will still work with the newer versions. There may be a few obscure deprecated packages that will not be supported. You can check the packages wiki pages which will tell you which distro's support them.

Some clarification: if the question is: "can I still use apt-get to install everything I could install in a previous ROS release?" then the answer would be: only if the package authors/maintainers have released the pkgs for the new ROS release.
