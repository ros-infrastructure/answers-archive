ros-catkin-tools install fails, ROS for Windows Setup

Attempting to install packages for ROS for Windows, following the Setup instructions.

When attempting:

choco upgrade ros-catkin-tools -y

I get the error:

ERROR: The running command stopped.. See log for details... Failures - ros-catkin-tools (exited -1) Error while running 'C:\...\chocolateyinstall.ps1'

I have tried restarting computer, and reinstalling ros-melodic-desktop, which is successful for all except the ros-catkin-tools package.

Anyone else overcome this problem? Thanks!

I had a similar error. In my case the issue was the 'git' path (C:\Program Files\Git\cmd )was not in the PATH variable. Adding it to the path in environment variables fixed the issue.
