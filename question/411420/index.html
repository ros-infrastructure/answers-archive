Answers

The book asks for the following command line entry as shown in the error above: $ roslaunch gazebo-ros willowgarage_world.launch

However, after researching this problem in the Gazebo site, all that is needed to run/open Gazebo with the supplied world is:

$ roslaunch gazebo_ros willowgarage_world.launch

Look closely at the difference.

Problem solved.
