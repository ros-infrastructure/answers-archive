The section of code for working with mav_msgs/msg/Actuators is commented out in the ros2 branch. See https://github.com/ignitionrobotics/ros_ign/blob/5d9cfef3d58948a77b962d231e281c88ea88e188/ros_ign_bridge/include/ros_ign_bridge/convert.hpp#L341-L354. You might be able to uncomment it and build it from source.
