Hello ,everyone What is the significance of ‘Dist’,‘PID’,‘Dir’, ‘Apara’,‘r’,‘slope’,‘cant’,‘LW’,‘RW’ in dtlane vector maps?

Asked by NJUST on 2020-08-06 04:47:44 UTC

Comments

Answers

each record represent a waypoint, with Dist: never used PID: ID of the point in point.csv Dir : Orientation of the waypoint Apara, r, cant: never used LW: to point to the left waypoint (for lane change) RW: to point to the right waypoint (for lane change)
