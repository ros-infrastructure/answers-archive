how to find the stack name of the package?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/30513/how-to-find-the-stack-name-of-the-package.

Hi, I found the package 'forcecontrol' in url: http://www.ros.org/browse/details.php?name=forcecontrol And the link in wiki of that package on web doc is broken : http://www.ros.org/wiki/force_control So how to find the stack name of this package? Thank you~

Answers

If the wiki page does not exist, it's a good sign that the package is not yet released in any ROS stack. This is true for many ROS packages that are experimental or still under major development.

In the case of force_control, it looks like you have to just grab it from the URL listed next to "Source:" on the browse page.
