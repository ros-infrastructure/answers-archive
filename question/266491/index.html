Asked by 942951641@qq.com on 2020-07-07 07:56:20 UTC

It also solved my problem by lowering down the controller_frequency. I had previously 5.0 and had jerky motions only when the robot moves in negative x-direction. I lower it down to 2.5. Its a move base parameter. By default it is 20.0 which is quite high. you can add it in your move base launch file like this under move_base node:

    <param name="base_global_planner" value="global_planner/GlobalPlanner" />
    <param name="planner_frequency" value="1.0" />
    <param name="planner_patience" value="5.0" />

    <param name="base_local_planner" value="teb_local_planner/TebLocalPlannerROS" />
    <param name="controller_frequency" value="2.5" /> 
    <param name="controller_patience" value="15.0" />
