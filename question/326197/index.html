Answers

Only CUDA 9.0 is officially supported on 16.04.

On Ubuntu 18.04, only CUDA 10.0 is currently supported (It will need you to upgrade Eigen to 3.3.7).

@jxl All this information is available at the Wiki on GitHub https://github.com/autowarefoundation/autoware/wiki/Source-Build

or at Gitlab (Autoware's new home) : https://gitlab.com/autowarefoundation/autoware.ai/autoware/wikis/Source-Build
