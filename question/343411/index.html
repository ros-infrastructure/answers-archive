While it still contains some nice hints, that cheatsheet seems a bit old: the rx set of packages have been EOL since at least ROS Groovy (which became EOL in 2014).

See also the wiki page for rxplot: here.

You'll want to look at rqt_plot at least, but perhaps tools like PlotJuggler offer a more polished user experience.
