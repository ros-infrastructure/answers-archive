Answers

No, this is not supported in the official builds of ROS.

ROS Hydro supports Gazebo 1.9 on Ubuntu 12.04, 12.10 and 13.04

ROS Indigo supports Gazebo 2.0 on Ubuntu 13.10 and 14.04

Yes, you are absolutely right.

Case: ROS_HYDRO If someone wants to use other than Gazebo 1.9, it can but in this case ROS Hydro packages related to Gazebo from ROS debian repository.

Case: ROS_INDIGO If someone wants to use other than Gazebo 2.0, it can but in this case ROS Indigo packages related to Gazebo from ROS debian repository.
