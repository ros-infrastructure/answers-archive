Source: https://docs.ros2.org/foxy/api/rclpy/api/init_shutdown.html

Initialization, Shutdown, and Spinning

A collection of functions for writing a ROS program. A typical ROS program consists of the following operations:

1.  Initialization
2. Create one or more ROS nodes
3. Process node callbacks
4. Shutdown

(...) When finished with a previously initialized Context (ie. done using all ROS nodes associated with the context), the shutdown() function should be called. This will invalidate all entities derived from the context.

It seems that there are on_shutdown() callback in ROS2 too: https://docs.ros2.org/foxy/api/rclpy/api/context.html
