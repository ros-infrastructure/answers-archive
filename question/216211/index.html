Faulty camera image out of gazebo

Hi,

I set up a simple launch file which loads an empty world (sun and groundplane) and spawns three objects (container, moveable platform, camera (libgazeboroscamera.so)). This setup is correctly displayed in gazebo (5.0.1), but the image of the camera is faulty. The camera image showes everything correctly if a pixel is located over the horizon, but if a pixel is located onto the groundplane (below the horizon) it is only shown as groundplane. The only reference to the objects is the shadow of these, which also appears correctly on the groundplane on the camera image.
