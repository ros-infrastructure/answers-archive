From my experience: I've being using an ASUS with an Nvidia GT650M graphic card for some time to develop and use Gazebo. The support for hybrids (Intel + NVIDIA) graphic cards on Ubuntu was a pain until the release of Ubuntu Xenial. Starting from the Xenial release, the PRIME support works well although it still does not support the "on demand change" of the graphic card, which means that you need to choose one or another from nvidia-settings.
