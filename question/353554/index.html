ROS Melodic is not supported on Ubuntu Focal (ie: 20.04).

Only ROS Noetic is supported on Ubuntu Focal.

The error message you quote is to be expected, as there are no Melodic packages available for Focal.

This is also mentioned on the installation page you link to:

ROS Melodic installation instructions

These instructions will install the ROS Melodic Morenia distribution, which is available for Ubuntu Artful (17.10), Bionic (18.04 LTS) and Debian Stretch, among other platform options.

Note how Ubuntu Focal is not mentioned anywhere.
