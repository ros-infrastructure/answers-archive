I guess you mean cartesian path? I don't think this feature is available in Rviz, but you can use the python move group commander easily to make your robot move along cartesian paths:

http://docs.ros.org/hydro/api/pr2_moveit_tutorials/html/planning/scripts/doc/move_group_python_interface_tutorial.html#cartesian-paths

ROS-Industrial recently released the 'Cartesian Path Planner Plug-In for MoveIt!' for RViz. That would allow you to plan / play / debug Cartesian paths from within RViz, similar to how the MoveIt plugin works.

Blog posting: Cartesian Path Planner Plug-In for MoveIt! (it's not a MoveIt plugin, but an RViz plugin).
