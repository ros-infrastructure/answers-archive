vmware subscriber multiplemachines problem

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/46852/vmware-subscriber-multiplemachines-problem.

Hello, I try to connect my Ubuntu system [a] to a virtual Ubuntu machine (VMware)[b] by network. It seems to work. I can ping and ssh from one to the other machine. Furthermore when I start a roscore on [a] I can run for example "rosrun rospytutorial listener.py" on machine [b] and it finds the roscore. If I start the talker on [a] I can see on [b] the topic "/chatter" and the node "/talker3586_1356978819462".

But if I run the listener now on b it doesn't hear anything. I have no clue, where the problem is. Maybe someone can help me with that?

Some things that I have already tried: - Start a talker and listener only on machine [a] works. - Start a talker and listener only on machine b works. - Previously I had the Ubuntu system [a] also on a virtual machine and this example worked with both virtual machines [a] and [b] running in windows.

Best Jonathan
