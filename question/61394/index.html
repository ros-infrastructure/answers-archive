This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/50593/global-pose-of-robot-in-dynamic-window-approach.

The pose from is same as the pose from tf::Stampedtf::Pose ? Are these similar. Can I use the pose from the /odom topic in a function which takes a parameter of type " tf::Stampedtf::Pose " ?

Asked by Devasena Inupakutika on 2013-04-23 06:27:24 UTC

Comments

Answers

No, you have to use a transform listener to get the pose as a tf::Stamped<tf::pose> message type. If your function parameter needs nav_msgs::Odometry you use a standard ROS subscriber to get the pose as a <nav_msgs::odometry> message type.
