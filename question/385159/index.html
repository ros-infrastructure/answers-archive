Rtabmap doesn`t provide /map

Hi. From time to time I have a problem that rtabmap launch without errors, but doesn`t publish /map topic. Has anyone faced this problem and how can it be solved?

System: Ubuntu 18.04 Version: ROS Melodic

Answers

If /map TF is not published, it means rtabmap is still waiting for input topics. Look for warnings telling you that it didn't receive any topics or it cannot synchronize them.

  1. If topics are published (use rostopic hz on each topic listed in the warning), compare their rate, if the rate is very different make sure your use approx_synx:=true and increase the queue_size parameter.
  2. If rate is similar and they are all published, maybe there is an issue in the stamps of the messages (like some topics published with a not synchronized clock with other topics, this happens often when topics are coming from different computers or the sensor stamps data with their own clock, not the computer clock).
