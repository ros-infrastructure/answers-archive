Hi @saj,

I have just wondered the same and came across this post. Sadly to find a dead-end. However, some time has past since you have asked this question and in the meantime there seems to be some dev work done regarding the implementation up to ROS melodic. However, noetic is still not available.

I found that "Trossen Robotics" youtube channel had posted a video about this Here is the link: https://www.youtube.com/watch?v=edNsh7bHkhQ

Below is an excerpt from the video description, just in case it will be taken down in the future, so that the links are still out there.

This tutorial outlines how to get the kobuki_node operational on Ubuntu 20.04 / ROS Noetic. The node is necessary to run the Kobuki base, an essential component to the LoCoBot platform, but it is not yet available as a binary from the Apt store. To fix that, the video above shows what dependency packages should be installed to successfully compile and run the node.

Note: This step is done automatically in the installation script when setting up the software on the Locobot. It is only here as a reference for those who are curious.
