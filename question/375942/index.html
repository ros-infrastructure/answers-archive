moveit: How to change the initial pose for robot in Rviz?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/98784/moveit-how-to-change-the-initial-pose-for-robot-in-rviz.

I used 'moveitsetupassitant' to config my robot, but I cannot find where can I set the robot's initial pose. The question is that the robot's initial pose in simulation environment is not the same as the one in real world. So is there any way to change the initial pose when I launch the robot in 'demo.launch'?

Asked by gvdhoorn on 2021-04-12 02:38:08 UTC

Answers

Add an entry to fake_controllers.yaml referencing the named poses like this:

initial:
  - group: panda_arm
    pose: ready
  - group: hand
    pose: open

Asked by xiaozhenghong on 2021-04-12 01:25:01 UTC

The position of your real-world robot is determined by reality, not the setting in your YAML. If you want the robot to move to a certain pose, you should plan and execute a motion to it.

Also, consider using your_moveit_config_planning_execution.launch instead of demo.launch if you don't use the fake controllers.
