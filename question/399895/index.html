It is unclear from your short description what you think should happen. With wheeled robots, most users do not view a 3D rendering in rviz (like the one shown in the gazebo gui.) Instead they select a top-down view which displays a map with obstacles and the current pose of the robot. The robot is represented by a polygon that you can define.
