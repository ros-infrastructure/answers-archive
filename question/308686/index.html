According to The Python Standard Library » Built-in Exceptions a MemoryError exception is:

Raised when an operation runs out of memory [..]

Seeing as you write that your bag file is "some large bag file" and that you're running this in "VirtualBox on Windows 10", that seems like something that could happen quite easily.

How much memory have you assigned to your VM?

Note that even configuring the VM to use (much) more memory may not resolve this, as it could be that the file is just too large.
