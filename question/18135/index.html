This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/28388/publishing-to-jointtrajectorycontroller.

In gazebo tutorial about connecting ros with gazebo it seems very simple, but I can't figure out how to do this with the interface written as on the ros page. Answers

I've found the answer, it was rather trivial, 

allow_partial_joints_goal: true

needs to be added to the yaml file, then I can publish the messages through

rostopic pub /gripper/joint_trajectory_controller/command trajectory_msgs/JointTrajectory

then I can specify which joint I want to move.
