How to spawn sdf object in Ignition Gazebo?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/29092/how-to-spawn-sdf-object-in-ignition-gazebo.

How can I spawn a model into a running simulation in Ignition Gazebo? I'm looking for something like rosrun gazebo spawn_model but for Ignition.

This was the closest thing I found but I couldn't get it working so far: https://github.com/ignitionrobotics/ros_ign/issues/27#issuecomment-510046123

Answers

You already have the answer in your link above. There is an example in ros_ign_gazebo_demos:

<node
  pkg="ros_ign_gazebo"
  type="create"
  name="spawn_model"
  args="-world <world_name> -name <model_name> -param robot_description">
</node>

Hi

you can have a look in the empty.sdf world.

Inserting:

ign service -s /world/empty/create \
--reqtype ignition.msgs.EntityFactory \
--reptype ignition.msgs.Boolean \
--timeout 300 \
--req 'sdf: '\
'"<?xml version=\"1.0\" ?>'\
'<sdf version=\"1.6\">'\
'<model name=\"spawned_model\">'\
'<link name=\"link\">'\
'<visual name=\"visual\">'\
'<geometry><sphere><radius>1.0</radius></sphere></geometry>'\
'</visual>'\
'<collision name=\"visual\">'\
'<geometry><sphere><radius>1.0</radius></sphere></geometry>'\
'</collision>'\
'</link>'\
'</model>'\
'</sdf>" '\
'pose: {position: {z: 10}} '\
'name: "new_name" '\
'allow_renaming: true'

Deleting

ign service -s /world/empty/remove \
--reqtype ignition.msgs.Entity \
--reptype ignition.msgs.Boolean \
--timeout 300 \
--req 'name: "new_name" type: MODEL'
