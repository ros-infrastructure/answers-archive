Here is my link tag:

        <pose>0 0 1 0 0 0</pose>

        <inertial>
            <mass value="10" />
        </inertial>

        <collision name='collision'>
          <geometry>
        <box>
          <size>2.8 2.5 1.5</size>
        </box>
          </geometry>
        </collision>

        <visual name='visual'>
          <geometry>
        <box>
          <size>2.8 2.5 1.5</size>
        </box>
          </geometry>
        </visual>

I am starting with gazebo, so I appreciate any help.
