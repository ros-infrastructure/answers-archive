Adding header files from specific folder to library using catkin_simple

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/94422/adding-header-files-from-specific-folder-to-library-using-catkin-simple.

I'm trying to create a catkin wrapper to build a library from external files. I'm usually using catkin_simple. However, the header files here are not contained in the include directory. I'm trying to figure out where to install them so that I can use #include <AdsLib/AdsLib.h> in other catkin packages to use this library.

Looking at catkinsimple's `csinstall` macro, I tried to add my header files. However, other packages can still not find the includes.

Edit: The files exist in install/include. But it seems like the build system is looking for them in the devel or source space. Since catkinsimple is only including from the include folder, I tried to add `catkinpackage(INCLUDEDIRS ${SOURCEDIR}/AdsLib)`. But the command is executed before the external project folder is cloned, which leads to an error.

What am I missing?

Answers

I switched to the DownloadProject Cmake module, which works perfectly fine now: https://github.com/Crascit/DownloadProject

The problem was that the steps from cs_export were executed before the source code was downloaded.
