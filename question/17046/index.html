How to set <rolling_friction> in Gazebo8 with bullet engine?

I am using bullet engine in Gazebo8+Ros kinetic. However it seems invalid to set rollingfriction in world ``` 100 100 <rollingfriction>50
```

What's more, in the left side of Gazebo GUI, the Property doesn't even match SDF1.6 specification and I can't find the rolling_friction in GUI, which still looks like ODE items.

No matter start gazebo with launch file or cmdgazebo -e bullet,the Property doesn't match SDF problem exsit.

So, how to set the rolling friction?

Answers

    <collision name='collision'>
      <geometry>
        <sphere>
          <radius>0.0285</radius>
        </sphere>
      </geometry>
      <max_contacts>10</max_contacts>
      <surface>
        <bounce>
          <restitution_coefficient>0.3</restitution_coefficient>
          <threshold>0.01</threshold>
        </bounce>
        <contact>
          <ode>
            <soft_cfm>0</soft_cfm>
            <soft_erp>0</soft_erp>
            <kp>100000</kp>
            <kd>100000</kd>
            <min_depth>0</min_depth>
          </ode>
        </contact>
        <friction>
          <torsional>
            <coefficient>0.3</coefficient>
            <surface_radius>0.3</surface_radius>
            <use_patch_radius>true</use_patch_radius>
          </torsional>
          <ode>
            <mu>0.3</mu>
            <mu2>0.3</mu2>
          </ode>
        </friction>
      </surface>
    </collision>
    <velocity_decay>
      <angular>0.2</angular>
    </velocity_decay>

velocity_decay and torsional can do some help.
