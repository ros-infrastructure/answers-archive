Just running

sudo apt-get install ros-indigo-cv-bridge

should give you a working opencv install (and the cv-bridge ROS integration). A fairly minimal example of usage: https://github.com/tu-darmstadt-ros-pkg/hector_image_proc/tree/master/cv_image_proc
