How to make robot movement in rviz with moveit smoother?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/89515/how-to-make-robot-movement-in-rviz-with-moveit-smoother.

Hi

Is there a possibility to make the robot movement in rviz smoother? As you can see in the video, the planned path is relatively smooth, but the simulated movement of the robot is lagging: https://www.youtube.com/watch?v=Q2yPOtkc84M&feature=youtu.be

I created the moveit config of the robot by myself with the moveit setup assistant.

I am using kinetic with rviz version 1.12.16.

Thanks in advance

Asked by boandlgrama on 2018-11-06 08:25:29 UTC

Comments

Answers

The solution is to increse the parameter 'rate' for the joint_state_publisher. The default is only 10 Hz.

☑️ This answer was ACCEPTED on the original site.

Asked by boandlgrama on 2018-11-28 06:08:40 UTC

Comments

Which you do by adding <param name="rate" value="100"/> to the joint_state_publisher call in your demo.launch file.
