A quick search shows ROS1 Melodic and ROS2 Dashing both can be installed on Ubuntu 18.04.

If you're planning on running both at the same time, check out the accepted answer to #q355548:

You can certainly have multiple versions of ROS running but you should make sure to only source the one required in each terminal before running a launch / run command.
