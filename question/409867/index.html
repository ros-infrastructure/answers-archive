If I have to, I need to map the offset of base_link to minus of whatever the value published by /camera/imu, right?

No. The urdf (or static_transform_publisher) specifies the pose of the sensor (where it is mounted) relative to base_link. The data values output by the sensor have nothing to do with it.

Asked by tsadarsh on 2022-11-26 23:43:02 UTC

rviz is most likely waiting for missing transform tree info that you have not provided. Internally rviz needs to transform the message sensor pose from the camera_imu_optical_frame to the Fixed Frame (usually map). rviz is not reading that topic queue because it is aware that the only thing it can do is discard it (since the message is useless without the corresponding transform data.)
