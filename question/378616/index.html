Unfortunately, if I run rosrun ardulistener ardu_info.py I have the error: /usr/bin/env: ‘python3\r’: No such file or directory

Curiously: if I create the python file with $ touch arduinfo.py, then make it executable with the command chmod +x arduinfo.py, then I paste exactly the same content from the original file to the newly created one, then run it via rosrun ardulistener arduinfo.py --- it works just fine.
