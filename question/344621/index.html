Try it and see what happens. Often the list of distros something works is the list of ones that have been thoroughly tested, so the authors know it will work properly with them. For other distros they can’t know, rather than it definitely won’t. See if there is a kinetic-devel branch that has been worked on and checkout that if there is.

Jumping two long term support versions does increase the risk of incompatible changes.
