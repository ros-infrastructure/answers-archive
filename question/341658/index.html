Kinect plugin interrupting robot spawning in Gazebo

I am having a trouble of getting Kinect rostopics up in Gazebo. When spawning the robot with Kinect (only the URDF not the plugin), the robot with Kinect is correctly spawned but I don't have any Kinect-related rostopics. However, when including the Kinect plugin in order to have Kinect-related rostopics, the robot's arms collide with each other and keeps shaking itself (the final shaking pose of the robot becomes random).

This is related to the reference name of in the kinect.urdf.xacro file I included below. <gazebo reference="${prefix}_ir_frame"> is the correct one but it screws up the robot spawning. If I change it to another name, e.g., `<gazebo reference="${prefix}_ir_link">, robot spawning is fine but Kinect rostopics are not there. The ROS version I am using is ROS Kinectic in Ubuntu 16.04 and the Gazebo version is 7.16.0.

I commented out from kinect.urdf.xacro but it didn't work. I really don't get why it is happening.. I hope someone could help me out. Thanks!
