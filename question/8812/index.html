Hello,

I have had the same problem, after installing the last updates. We think that the problem comes from control_toolbox package.

Here I tell you the steps we have followed to return to the previous state:

  1. Uninstall using apt-get remove the following packages:

    ros-indigo-gazebo-ros-pkgs, ros-indigo-ros-controllers and ros-indigo-control-toolbox

  2. Download from github the following releases:

    gazebo_ros_package-2.4.8, ros_controllers-0.9.1 and control_toolbox-1.13.0

  3. Build these packages into your workspace

This worked for us, now we have the behavior that we had before installing the last updates

Hope this helps as a temporary solution while the problem is fixed
