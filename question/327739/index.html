Ubuntu Disco is not LTS. The next LTS will be Ubuntu 20.04. The next version (and probably the last) of ROS1, called Noetic Ninjemys will target Ubuntu 20.04: https://discourse.ros.org/t/planning-future-ros-1-distribution-s/6538

More info: https://discourse.ros.org/t/proposed-changes-to-the-ros-releases/4736
