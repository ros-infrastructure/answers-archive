Kinect camera with robot_localization package

I want to use the camera kinect instead of lidar with the robot_localization package. Is there any specific instructions? Thank you!

You need to use a visual odometry package, like rtabmap_ros, to produce an odometry estimate. However, if you aren't going to fuse that data with anything else, you might as well just just rtabmap_ros, and not bother with robot_localization.
