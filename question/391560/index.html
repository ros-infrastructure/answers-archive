Does anyone know where I can find this 'internal' navmsgs/Path in the code of the ROS Navigation stack? Is it movebase.cpp? navfnnode.cpp? trajectoryplanner_ros.cpp?

Answers

It's move_base.cpp.

Specifically, it is as follows.

if(!tc_->setPlan(*controller_plan_)){

ref : https://github.com/ros-planning/navigation/blob/6e9de3f16c76329fc8d218189d90e4ebe51d61c2/move_base/src/move_base.cpp#L851

controller_plan_'s definition is as follows.

std::vector<geometry_msgs::PoseStamped>* controller_plan_;

ref : https://github.com/ros-planning/navigation/blob/4a3d261daa4e7eafa40bf7e4505f8aa8678d7bd7/move_base/include/move_base/move_base.h#L216

It is different from nav_msg/Path, but if you compare it to the definition of nav_msgs/Path, you will see that it passes the same information.

std_msgs/Header header
geometry_msgs/PoseStamped[] poses

ref : http://docs.ros.org/en/noetic/api/nav_msgs/html/msg/Path.html
