Asked by David Jeang on 2013-09-27 20:55:01 UTC

Looks like a problem with the libbullet version needed by gazebo.

While ubuntu ships 2.80, gazebo uses 2.81, so you will need to install debs from the OSRF repository. Two ways:

  • Download libbullet-dev and libbullet-2.81 manually from OSRF package repository.
  • Easier: add the OSRF repository to your system and install libbullet-dev from there.
