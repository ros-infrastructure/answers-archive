Answers

Sorry; rostopic pub can only publish complete messages.

If you want to intercept and change message, you will need remap the topic at one node, and create a new node which receives on one topic, changes the message, and publishes on the other topic.

If you existing system looks like this:

Node A --> /topic --> Node B

Then you can change it to something like this:

Node A --> /topic --> Data change node --> /topic_out --> Node B

Your data change node could do the transformation based on some hardcoded values, or it could subscribe to a second topic with the sub-message type, and insert the most recent value on that topic into the topic that you're trying to modify.
