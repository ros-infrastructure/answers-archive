How to I fix libgazebo_ros_paths_plugin.so undefined symbol error?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/60365/how-to-i-fix-libgazebo-ros-paths-plugin-so-undefined-symbol-error.

I recently upgraded to the most recent packages of ROS hydro and now when I launch gazebo using "rosrun gazebo_ros gazebo" I'm getting the following error:

gzserver: symbol lookup error: /opt/ros/hydro/lib/libgazeborospathsplugin.so: undefined symbol: _ZN3ros7package10getPluginsERKSsS2RSt6vectorISsSaISsEE

gzclient: symbol lookup error: /opt/ros/hydro/lib/libgazeborospathsplugin.so: undefined symbol: _ZN3ros7package10getPluginsERKSsS2RSt6vectorISsSaISsEE

Using c++filt or http://demangler.com/, I see that the following method is undefined:

ros::package::getPlugins(std::string const&, std::string const&, std::vector >&)

Does anyone know how to fix this?

Here are the ROS / Gazebo packages I have installed on my Ubuntu 12.04.4 64-bit computer:
