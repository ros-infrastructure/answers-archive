With the disclaimer that I haven't played with Galactic too much yet, I would personally lean towards learning on Foxy. Between being an LTS release and having been out for a while, I think you'll have a better time learning ROS 2 with it. You'll be able to find more existing documentation and help for foxy, and you'll be able to work with it longer.

That said, there are a number of not-insignificant changes in the Galactic release that may sway your decision. I'd say read through, see if there are any changes that would drastically impact what you want to do in the future.
