Access Intensity data of SICK LMS 291-S05 using SICK toolbox

I wanted to inquire if anyone has tried to access range and intensity data of the SICK LMS 291-S05 using the SICK toolbox in ROS?

The SICK tool box allows to access range and intensity data (simultaneously) for LMS 211/221/291-S14 (LMS fast), however their is no mechanism for other scanners. So the question i want to ask is how to access range and intensity data (both) for other laser scanners?

I have looked into the SICK LMS Telegram listing and it provides the response 0xF5 (range + intensity) to the command 0x2B. The communication with the laser works when the command 0x2B is sent and the response 0xF5 also is returned, however the intensity values are zero.

If anyone has used or tried this and was able to get the intensity information or if anyone has suggestions on this matter, kindly let me know.
