No solution, rather a comment: Using python3 in ROS (pre-noetic) is hard! You'd have to compile everything from source to make this work properly and stumble upon hundreds of problem over and over again. A quick search for this will turn up many, many questions on that, that, in the end all (should) say:

If you need to use python3, use ROS noetic!

(personal opinion, but I'm 100% positive, that this will make your life a lot easier...)
