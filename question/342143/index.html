I did some research, just update the post here. ar_track_alvar can not be installed in ros2 environment, and there is no similar package for ros2 atm as I know. The solution can be that host ros1 and ros2 env at the same time, then use ros1_bridge to get the AR tag ID via topic by using ar_track_alvar from ros1. Another option, there is a ar marker lib for python, I might can scan AR tag manually in ros2.
