Erratic behaiour of PR2 in simulation

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/67720/erratic-behaiour-of-pr2-in-simulation.

I am using a simulated PR2 in ROS Indigo (Ubuntu 14.04). While running

roslaunch pr2gazebo pr2empty_world.launch

the head of PR2 turns back and the arms get twisted and rotates continously. Also it is not possible to control the simulated PR2 using keyboad teleop package. It was working fine untill all the ros-indigo packages were updated through synaptic package manager .

It happens when the pr2defaultcontrollers are up and running. Simulation with no controllers makes no issues.
