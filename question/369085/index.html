set orientation and position goal tolerance

I have a 4 dof robot and I need to move its end effector in the environment, but I do not know the final orientation od the robot. So the planning solver do not find the solution for small tolerances (movegroup.setgoal_tolerance(x). I would like the solver to consider only the position, not the orientation, so I would like to ask if is there a way to set the tolerance for the position and for orientation separately, or if is it possible to modify the existing solver as a way to not consider the orientation of the end effector ?

Answers

You can set set_goal_orientation_tolerance and set_goal_position_tolerance separately if you use python bindings, otherwise use getGoalOrientationTolerance / setGoalPositionTolerance if you use c++
