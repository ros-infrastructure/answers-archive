UPDATE: @ahendrix's answer seems to be correct.

Looks like debian file of rqt_plot is built but not yet synchronized into public repository. See debbuld status page http://www.ros.org/debbuild/indigo.html?q=rqt_plot I'm sure in the next public repository sync, it'll become available.

A concern and a tip:

  • However, I'm not sure why the .deb file is missing after it was once announced that rqt_plot was released Indigo Beta .

  • More about how to find the build status http://www.ros.org/news/2014/03/ros-indigo-igloo-buildfarm-running.html

It's possible that rqt_plot isn't included in the desktop-full variant for some reason. Have you tried installing it manually?

sudo apt-get install ros-indigo-rqt-plot

If it turns out that it's installable but isn't included in desktop-full, that's probably a bug in the desktop-full variant.
