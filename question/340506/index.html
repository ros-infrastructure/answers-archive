Answers

So I've figured out that I need the node name and ros_parameters lines added to the yaml. I did this at first but I didnt realize that there is a double underscore in ros_parameters. So my working yaml is:

lss_joint_publisher:
    ros__parameters:
        joints: [17,18,19]

I still dont think a SIGABRT is a good way to handle yaml errors. lol. but I am working again. :)
