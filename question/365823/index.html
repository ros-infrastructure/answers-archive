Well, that's what ROS navigation stack does. There u have several path planners that uses A* and other methods to create paths, plus controllers that execute the paths, plus maps, etc.

If what you mean is that you already create a nav_msgs/Path object yourself and want to execute, one easy option is to use move_base_flex and send your path to the exe_path action server.
