But it can't reached the goal, exactly when it drove to destionation it started rotating and didn't stop, and then localbasecontroller send the message like:The goal sent to the navfn planner is off the global costmap. Planning will always fail to this goal.

I have some thougths, that my controller can't provide desired speed of rotations. For instance when I send cmd_vel.angular.z = 1.0, my controller provides only 0.8.

The question is: Is localbasecontroller too sensitive to speed and what should I do for providing this speeds? Now I do it commonly

  double RotVel_lin = cmd_vel.linear.x / this->wheel_radius;
  double RotVel_rot = (cmd_vel.angular.z * this->wheel_sep / 2) / this->wheel_radius;

  for (int i = 0; i < NUM_JOINTS; i++)
    this->joints[i]->SetMaxForce(0, this->torque);

  // turn left wheels
  this->joints[0]->SetVelocity(0, RotVel_lin - RotVel_rot);
  this->joints[1]->SetVelocity(0, RotVel_lin - RotVel_rot);

  // turn right wheels
  this->joints[2]->SetVelocity(0, RotVel_lin + RotVel_rot);
  this->joints[3]->SetVelocity(0, RotVel_lin + RotVel_rot);
