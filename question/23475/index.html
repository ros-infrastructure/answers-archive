This is a know bug affecting Ubuntu official packages which are not the latest gazebo9 releases. More information as well as possible workarounds are available in this bug report: https://bitbucket.org/osrf/gazebo/issues/2607/error-restcc-205-during-startup-gazebo#comment-56048528

In case this is still happening after updating to gazebo9,

Try chainging https://api.ignitionfuel.org to https://fuel.ignitionrobotics.org in ~/.ignition/fuel/config.yaml

Reference: https://varhowto.com/how-to-fix-libcurl-51-ssl-no-alternative-certificate-subject-name-matches-target-host-name-api-ignitionfuel-org-gazebo-ubuntu-ros-melodic/
