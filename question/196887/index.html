I don't know if you fixed your problem yet but to install pyyaml on your virtual nao you need to use sudo easy_install pyyaml

If you want a complete tutorial to setup ROS on your NAO is available here : http://wiki.ros.org/nao/Installation/compileFromVirtualNao I didn't validated it on 1.14 because I'm using ROS Indigo which is not compatible with NAOqi < 2.0. But this should work.
