ROS2_CONTROL diff_bot hw_positions_ what it function and why we need it in diff-drive

Hi can anyone explain what the function of hwpositions and why we need it in diff-drive ros2control demo. It is important to have it in read function?
This the code "hwpositions[i] = hwpositions[1] + dt * hwcommands_[i];" in the example.

Comments

Answers

The hw_positions_ store position values of the example hardware. On a real hardware or simulation, you will also use something similar to store the values.

In the specific scenario, hw_positions_ store measured values, so yes, you will need those in the read method.

The specific code hw_positions_[i] = hw_positions_[1] + dt * hw_commands_[i]; is just of exemplary purposes to generate some “dynamics” of movement when using this trivial simulations.
