How to set viso2_ros stereo parameters?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/45181/how-to-set-viso2-ros-stereo-parameters.

Hi everybody, I'm trying to using stereo odometry with viso2ros library. How to set the distance from left camera to right camera? Which camera is related to baselink -> camera tf transformation? The right camera or the left camera?

Asked by aldo85ita on 2012-10-23 06:52:51 UTC

Comments

Answers

The base camera frame for a stereo system is the left optical frame. The viso2_ros stereo odometer reads all information including baseline from the corresponding camera info messages (i.e. <stereo>/left/camera_info and <stereo>right/camera_info). Be sure to calibrate your stereo system using the camera_calibration package!
