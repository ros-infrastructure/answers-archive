Answers

You cannot change the tags in the XML file: i.e., what's inside the <> angle brackets. Rather, you can change what's between the two tags, i.e., you can write

ABCDEF or something else. But the tags themselves are predefined and when this xml file is read, the system looks for what's between the description tags. So changing the tag itself will result in the system not understanding what you are specifying.

Instead of writing < description >The beginner_tutorials package in the command prompt, write

gedit package.xml

A window with the package.xml file will open up. In this new window you can edit the description and everything else. Then click save. Then go back to command prompt and type

cat package.xml

Now you can see your changes.

Good luck!
