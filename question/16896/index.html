This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/28244/depth-value-of-openni-camera.

Hello. I am doing simulation using opennicamera(https://github.com/ros-drivers/opennicamera) on Gazebo. I'd like to get the depth value of real type, but uint8[] will return as shown by document(http://docs.ros.org/api/sensor_msgs/html/msg/Image.html). Since 4 data was stored for one point, I converted it to float32 using union, but we could not get the correct value. What do these four data represent? Also, how can we obtain the depth value? Thank you.

there are a few related questions and answers in ROS answers, e.g. http://answers.ros.org/question/160611/how-can-i-get-depth-data-from-kinect/

I'm not sure what you mean by 4 data stored per point, maybe RGBD? The depth image topic will give you D. After converting to float32, you get depth values so there'll be a total of width*height values.
