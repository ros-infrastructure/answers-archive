You can write your own plugin, or use one of the plugins provided by hector_quadrotor.

The tele-op tool that you used makes use of a simple plugin. You can write an application that published cmd_vel messages to control the helicopter. Look through the hector-quadrotor wiki, there is a lot of information about using their software for more than tele-op.
