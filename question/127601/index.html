Is there a C++ equivalent to roslib.get_ros_home() ?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/57147/is-there-a-c-equivalent-to-roslib-get-ros-home.

In python, it's possible to use roslib.getroshome() to query the environment for the ROS_HOME environment variable, and fall back to HOME/.ros if it doesn't exist. This is very useful for finding a directory that ROS processes can use for storing their own logs or other temporary data.

Is there any equivalent to this in C++?
