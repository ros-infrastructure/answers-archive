I apologize for not posting a comprehensive question. I forgot to mention that I am working with ROS2 Foxy on a virtual machine on which I have installed Ubuntu 20.04. This issue was solved by changing the network configuration of the VM. I had to change NAT with board with bridge. With this change, by repeating exactly the same steps shown in the above guide, I was able to see my Turtlebot on Rviz.
