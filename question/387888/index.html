Hey Alexander! Fast DDS is compatible in both ROS 2 distros, so you won't have a problem. Using Fast DDS in Galactic with the environment variable should work. And also you'll be able to enjoy the features and tools of Fast DDS, such as the Monitor. You'll be able to track the performance of your DDS environment in ROS 2 with it, check out the video if you wanna know more ;)
