Answers

I have to start first the Gazebo simulator and set up a robot model like this:

roslaunch gazebo_worlds empty_world.launch
roslaunch erratic_description erratic_mobile_base.launch

And then:

roslaunch erratic_description erratic_mobile_base.launch
