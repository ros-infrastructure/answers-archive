How to migrate tf data types such as Quaternion, Vector3, Transform to tf2?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/87488/how-to-migrate-tf-data-types-such-as-quaternion-vector3-transform-to-tf2.

There is not much mentioned about tf2 datatypes on tf2ros documentation at http://docs.ros.org/latest/api/tf2ros/html/c++/. While comparing to http://docs.ros.org/latest/api/tf/html/c++/, we don't have any data types mentioned. My C++ code has plenty of tf datatypes such as 

 tf::Quaternion q(msg->pose[index].orientation.x,
                msg->pose[index].orientation.y,
                msg->pose[index].orientation.z,
                msg->pose[index].orientation.w);


 tf::Transform transform;

How will I migrate them to tf2_ros?

Answers

Please see the Supported Datatypes section of the tf2 wiki.

The tf::Quaternion is a fork of the Bullet btQuaternion which will be your easiest conversion.
