Hello:

The github repository that you mention is not the one hosting the gazebo_ros_pkgs code but all kind of metadata related to the release of binary .debs for the gazebo_ros_pkgs. You probably want the upstream repository: https://github.com/ros-simulation/gazebo_ros_pkgs

I would recommend the read of Installing gazebo_ros_pkgs tutorial which cover how to install Jade/Indigo versions of gazebo_ros_pkgs into a catkin workspace.

Update: There are Indigo gazebo7_ros_pkgs available as packages. Please read: http://gazebosim.org/tutorials?tut=ros_wrapper_versions&cat=connect_ros
