I simply meant if I can see the code of different middleware implementations. I guess not, because those are provided by specific vendors and so they would be copyrighted.

that would depend completely on whether that "middleware implementation" is open-source or not.

Some OSS middlewares with RMWs (as of Foxy, alphabetically ordered):

  • Eclipse CycloneDDS: eclipse-cyclonedds/cyclonedds (DDS): ros2/rmw_cyclonedds
  • Intel DPS: intel/dps-for-iot (non-DDS): ros2/rmw_dps
  • Continental eCAL: continental/ecal (non-DDS): continental/rmw_ecal
  • eProsima Fast DDS: eProsima/Fast-DDS (DDS): ros2/rmw_fastrtps
  • Eclipse Iceoryx: eclipse-iceoryx/iceoryx (non-DDS): ros2/rmw_iceoryx
  • OCI OpenDDS: objectcomputing/OpenDDS (DDS): oci-labs/rmw_opendds
  • Eclipse Zenoh: eclipse-zenoh/zenoh (non-DDS): esteve/rmw_zenoh (rather experimental at the moment)

and there are a few more which are open-source.
