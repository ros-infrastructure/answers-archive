There's no human model in the database yet. You can always use your own model if you have the COLLADA or STL meshes.

Also note that there's currently a pull request to gazebo_models to add couple of human models without joints to the database.

Maybe this will help: What I did was create my own models with makehuman . The only tricky part is to be sure that gazebo gets the textures correctly. This is solved putting them on the same folder as the dae. You have to export the model as dae, the light maps and the UV maps. You then edit the dae for referencing the textures localy.

I made a video giving more details if you need them: https://youtu.be/7kEmT-NE75c

Hope it helps.
