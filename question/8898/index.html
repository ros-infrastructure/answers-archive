Unfortunately, editing existing buildings is not currently supported (issue #1634). Also note that the Building Editor is specifically for buildings and not for worlds in general, and it was improved on Gazebo 5, so several features differ from Gazebo 2.2.

You could always edit your world's SDF directly or load it into Gazebo with 

gazebo <your world>.world

then modify it and then save a new copy.
