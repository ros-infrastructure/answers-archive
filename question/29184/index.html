https://gazebosim.org/docs is the best source of documentation for installing Gazebo. If you want to use ROS, there's a whole section there that describes the steps.

You said you need to install gazebo_ros, but ros-humble-ros-gz is the equivalent of gazebo_ros (which is for Gazebo-classic) for the new Gazebo. If you already have ros-humble-ros-gz installed, you just need to install Gazebo Fortress

azeey, you encountered similar issues as I did in my exploration of learning Gazebo Simulation with ROS 2. My Ubuntu 22.04 Desktop Dev machines are a x86-64 (amd64) laptop and a MAC M1 (arm64/aarch64) running Parallels Virtual Machine UB22.04/LXDE Desktop. If you were able to run "gz sim empty.sdf, it means you must have installed Gazebo SIM Garden Ver 7. A Binary installed ros_gz as you did is only compatible with the older Gazebo Fortress Ver 6. As I originally preferred to use gz-garden gazebo Ver. 7, I tried unsuccessfully to compile the repository ros_gz Humble ros_gz from source. So I abandoned that path and reverted back to using Binary Installed Gazebo Fortress and ros_gz.

From a Forum I participate ( ROS2 Simulation ), the host prepared a Gazebo Simulation Installation that works that involves deleting any previous binary installed gz-garden, ignition-fortress, ros_gz, ros-ign package instances. Then do a clean Binary Fortress and ros_gz install from: Setting up Simulation and a recently updated ros_gz Humble-Fortress from packages $ sudo apt install ros-humble-ros-gz . Note that a Gazebo Fortress ver. 6 Ignition (not ros_gz at this point) simulation example can be launched with $ ign gazebo -v 4 -r visualize_lidar.sdf, or spawn an empty world with $ ign gazebo empty.sdf (DO NOT launch $ gz sim ! on a Gazebo Fortress install) .

Then moving onto ROS 2 experimenting, there are many workable " ros bridged" with rviz2 launch examples in the above ros_gz repository, humble branch, notably "ros_gz_sim_demos/launch/joint_states.launch.py. The Gazebo Roadmap lists the next release as "Harmonic", where hopefully the gz sim and ros_gz will be easily Binary installed and run/launch compatible. Hope the helps.
