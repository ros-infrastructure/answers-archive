Changing format of debug output

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/55526/changing-format-of-debug-output.

How do I change the format of ROSINFO/ROSDEBUG, etc so that it prints out the filename and line number that it was called from?

Asked by vhwanger on 2013-11-17 10:26:35 UTC

Comments

Answers

export ROSCONSOLE_FORMAT='[${severity}] [${time}] [${file}:${line}]: ${message}'
