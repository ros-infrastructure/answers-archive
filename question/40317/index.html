Navigation costmap parameter unknown_cost_value

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/42834/navigation-costmap-parameter-unknown-cost-value.

Hello Does anyone know why the costmap2d parameter "unknowncostvalue" cannot be set to 0 or lower. My understanding is that a costmap with staticmap set to true will take in an occupancygrid from the map topic. It then uses this unknowncostvalue to set all the corresponding cells with this value as unknown space in the newly created costmap. Since occupancy grids from the map topic have values at -1 for unknown space 0 for free space and 100 for occupied space it seems I can't set the unknown space for the cost map to be the same as the unknownspace in the map. It works fine if I set the unknowncostvalue larger then 0 to 100 for example but this then sets the unknown space in the cost map to be equal to the occupied space in the map.

Answers

I think I solved the problem by setting the unknown_cost_value to 255. The cost maps have a range of 0 to 255 so a value of -1 in the occupancy grid is set as 255 in the cost map. It seems to be setting the new cost maps unknown space the same as the occupancy grid from gmappings map which is what I wanted. Thanks me :)
