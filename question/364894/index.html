I've been running into issues setting up microROS and its not clear from the docs if ros2serialexample can be used by a Python node. If I could use something like PySerial within the node, that would be excellent. Alternatively, if someone could help me understand how to use microROS with a python node, that would also be excellent.

Thanks for any and all help.
