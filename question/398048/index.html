/tf suddenly missing

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/101413/tf-suddenly-missing.

Hi, I'm using a robot run with Raspberry Pi 3, and I'm controlling it from my computer using ROSMASTERURI. As usual, after loading my robotdescription parameter and run robotstatepublisher node, I can view my robot in Rviz from /tf, but suddenly, when I re-run the process, Rviz said "no tf data", although the topic /tf still exist and there still have the robotdescription parameter. What could be the problem? I have struggled with this for days.

Answers

After a while, I found the solution. When I echo the /tf topic in my computer's terminal, nothing is displayed, but when I did that in the Pi3's terminal, those data appeared. Then I think it may be the connection problem. I realized that there were many devices using the Wifi, so I turn off some of them and restart the machine, then everything back to normal.
