[realsense-camera] Can't launch ros package realsense2_camera and librealsense from Intel® RealSense SDK at the same time

I'm trying to write a ROS node that gets a depth image from the /camera/aligneddepthtocolor/imageraw topic sent by the /camera/realsense2_camera node, and process it using OpenCV to find some point coordinates in the image.
