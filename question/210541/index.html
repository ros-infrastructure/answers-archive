Answers

It is based on the Gauss-Newton method in order to find the optimum transformation for a certain function that minimize the error between the alignment of the laser scan and the map.

For more information, see the section 3.3.2 of this paper : http://www.ncbi.nlm.nih.gov/pmc/articles/PMC4299068/
