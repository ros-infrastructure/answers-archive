Follow these instructions: http://wiki.ros.org/swiftnav_piksi I tried to use catkin_make_isolated too but couldn't get it to work, so I've dropped back to build-from-source. The problem with the libswiftnav and libsbp that have been released as ROS packages is that libswiftnav is broken - it is missing a symbol that the swiftnav_piksi driver uses - something in the lapack library.

Contact me if you have ongoing questions or problems - i'm shortly going to announce this, and the swiftnav ppl will help support it. One thing still in flux is the topic names it publishes on - follow a question I'm about to post on the topic
