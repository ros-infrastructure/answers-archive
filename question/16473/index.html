I've not seen a python parser, but there might be people out there using one.

For C++, you can use the sdformat library.

Not sure if you've seen this, but the SDF spec is here.

A clarification on reference frames in SDF:

  • top level model poses are expressed in the world frame
  • nested model poses are expressed in their parent model frame
  • link poses are expressed in their parent model frame
  • visual and collision poses are expressed in their parent link frame
  • joint poses are expressed in their child link frame
