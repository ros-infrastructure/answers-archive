Do you follow the right procedure? At first, Please check creating a new workspace on this page( http://wiki.ros.org/ROS/Tutorials/rosbuild/CreateWorkspace ) As I use Hydro, I check Getting rosbuild Package Sources on this page ( http://wiki.ros.org/catkin/Tutorials/using_rosbuild_with_catkin ). So, I worried if the package is compatible for Hydro. Anyway, I compiled the package and succeeded it. Please look at the following.
