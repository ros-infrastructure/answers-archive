It is possible to has two differents workspace?

I have my catkinws and I use catkinmake, but I want to have another and use catkin build If this possible?

Answers

Running catkin_make and catkin_build won't usually make changes outside the workspace they are run in. There is absolutely no problem with having two workspaces and running different build commands in them.
