Integrating custom inverse kinematics plugin with MoveIt

Hi, System: ROS Melodic, Ubuntu 18.04 I am trying to create a custom inverse kinematics library for my robot arm (scara-like: a prismatic joint and planar 3 revolute joints) and load it into MoveIt using the pluginlib library. The repository containing my library is available here. Briefly the steps are

  • Created a TestKinematicsPlugin class which extends kinematics::KinematicsBase
  • Implemented the methods initialize(), getPositionIK() and searchPositionIK(). Basically these are adapted from SrvKinematicsPlugin, KDL and an IKFast kinematics plugin.
  • The getPositionIK returns the searchPositionIK which calls one of my custom IK solver bool getIKSolutions(). This arm produces multiple solutions and I find the distance from the ikseedstate to produce the solution nearest to the ikseedstate.
  • Added export tag for the pluginlib export in package.xml, created a plugin_description.xml and modified the CMakeLists.txt to add this as a library
  • Modified the arm_config_pkg-->kinematics.yaml and added the kinematic_solver:analytic/InHouseKinematicsPlugin
  • Removed build and devel and did catkin_make

The main() is added as a test. The following is my terminal output
