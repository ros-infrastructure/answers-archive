Hi Robi,

it seems a credential problem. Do you have an AWS account? Make sure that you are specifying your public and secret key when you run the create_cloudsim.py tool.

Ex: ./create_cloudsim.py cloudsim@gmail.com RKIAIFWTGCDUX7NZ2BSA aRYYgTc36NFZ31KX+E3Jh40qtgS/qXsFrdW51X9G us-east-1a
