Hey! As far as I know, you cannot just add packages from ROS1 into the ROS2 workspace. (since ROS2 does not use the catkin build tool anymore) However, if you still need to use ROS1 packages, you can use ROS bride as a workaround. You can refer to this link for the same.(https://industrial-training-master.readthedocs.io/en/melodic/_source/session7/ROS1-ROS2-bridge.html)
