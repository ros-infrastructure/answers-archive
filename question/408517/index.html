Each ROS has been supported on exactly one predestined Ubuntu version. For ROS Kinetic you had Ubuntu 16.04 (Xenial).

The easiest way for you would be to built packages from source for Turtlebot2/3 with ROS Noetic. This should be possible, since I have updated my TB2s to ROS2 as well. Without changing to ROS2, it should be easier. Not every package for TB3 can work with TB2, but to be honest I haven't encountered this problem yet.

By https://wiki.ros.org/Distributions:

Release rules

  • ROS release timing is based on need and available resources
  • All future ROS 1 releases are LTS, supported for five years
  • ROS releases will drop support for EOL Ubuntu distributions, even if the ROS release is still supported.

Side effects of the release policy:

  • Every ROS release will be supported on exactly one Ubuntu LTS.
  • LTS releases will not share a common Ubuntu release with any previous releases.
  • ROS releases will not add support for new Ubuntu distributions after their release date.

Building ROS Kinetic from sources on Ubuntu 20.04 LTS may be done, but it probably won't behave properly
