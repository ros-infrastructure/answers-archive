Is Stage simulator holonomic odometry bugged?

When I move it sideways (along axis y in robot's coordinate frame) amcl thinks it moves the other way. There is no problem with movement along x axis (in robot's frame). The problem exists regardless of robot's angular orientation in global frame.

Is Stage odometry bugged?

My hypothesis is that sign in y component when computing displacement is wrong, I think it should be:

deltaglobalx = (speedx * cos(theta) - speedy * sin(theta)) * dt deltaglobaly = (speedx * sin(theta) + speedy * cos(theta)) * dt

While probably it is:

deltaglobalx = (speedx * cos(theta) + speedy * sin(theta)) * dt deltaglobaly = (speedx * sin(theta) - speedy * cos(theta)) * dt

Unfortunately, I didn't find Stage source code, is it available? Any thoughts? Maybe there is another reason I don't see?
