you had mentioned about source version and intalled binary version, but I don't know which one I am using now. could you show me how check it? and how to get and intall the source version.

Actually you should already know the version you're using -- you ran rosversion command :) That's the version of the ROS package in your ROS_PACKAGE_PATH env variable. If you additionally curious about the version of the binary package installed on Ubuntu, run something like:

dpkg -p ros-indigo-nextage-description
