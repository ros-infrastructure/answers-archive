From what you said so fa r I understand that you want to use the data from the topic of interest to visualize in the web right?

in that case, You can use ROS bridge server package and use ROSlibjs to visualize the data in the web. The data of choice can be anything. For example, you can subscribe to a topic that publishes live feed of Images from a webcam and you can visualize it in Web via rosbridge_Server and roslibjs.
