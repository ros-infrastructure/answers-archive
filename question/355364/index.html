Apart from that, have you tried to place the parameters explicitly like in the SDF? E.g.:

 <collision>
  <surface>
   <contact>
    <ode>
     <kp>1.0</kp>
     <kd>0.01</kd>
     <max_vel>0.0</max_vel>
     <min_depth>0.001</min_depth>
    </ode>
   </contact>
   <friction>
    <ode>
     <mu>0.9</mu> 
     <mu2>0.9</mu2>
    </ode>
   </friction>
  </surface>
 </collision>
</gazebo>

Asked by JoshuaElliott on 2020-06-20 08:38:07 UTC

But how are you sure that the contact tags are not being passed to the final SDF?

The flow of information usually is Xacro > URDF > SDF, since you have only a URDF file you can just try to generate the SDF file and check that indeed the tags are not being translated properly. E.g.:

gz-7.16.0 sdf -p model.urdf > model.sdf

Besides that, generally when you convert Xacro to URDF the parser usually locate the <gazebo> tags reference at the very top of the document inside the tag. There no reason to think the position of the tags are important but you can try to change the declaration position of each <gazebo> element to see if something changes.

Aprt from that, maybe is a good idea to port your description to Xacro, since as I see your code you have a lot of repeated and useless code.

Furthemore, did you tried with the tutorial model description, to be sure that the problem is not related with yout machine or enviroment.
