That's correct. according to http://wiki.ros.org/Sensors the UST-05LN/05LA Rangefinder is currently not supported.. The data presented by the currently supported UTM-30LX is fundamentally different from the UST-05LN/05LA. I suggest to reach out to the OEM for direct ROS support. In some cases, (SICK for example) the manufacturer is really good in providing supporting information about the integration and compatibility.

Therefore I suggest using an already supported model, or modifying the existing packages from supported models to suit your needs for the model you are tryin to use. Perhaps, there are unofficial github libraries working with the rangefinder you're trying.
