Have you done:

rosmake phidgets_ros

and maybe also: 

roscd phidgets_ros
make

Looks like the messages defined by the package have not been built yet.

Also, please tag your questions, that makes it easier for people to find them (thus making it more likely that you'll get an answer :)

Yup. That was the issue. For some reason it was failing to make but not throwing an error. The permissions for the "phidgets_ros" folder were set to user permissions and not for read/ write for the "adm" group. ROS wasn't able to "make" with out the proper folder permissions.
