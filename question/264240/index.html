Hi, I am using the intel euclid vision system for my research, which has ros running on it by default on booting and it has a web interface. By mistake, i changed the ROSMASTERURI on the web interface and after a reboot, nothing is running. When I ssh into the device and run roscore by myself, I see the following error:

invalid master URI: http://http://localhost:11311:11311/ The traceback for the exception was written to the log file

Clearly the ROSMASTERURI is wrong but I dont know where to change it again because putting the correct one in the bashrc also doesnt allow roscore to run by default on booting. Is there any place, other than the bashrc where the ROSMASTERURI can be set? Please me help with this issue! Since the ROSMASTERURI is set wrong, I am unable to reacess the web interface aswell!
