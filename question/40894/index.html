nxt_rviz_plugin with Rosjava

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/43053/nxt-rviz-plugin-with-rosjava.

Hi!
I'm using the nxtlejosproxy package and rviz.
I would like to use the nxtrvizplugin, which displays data from a nxtmsgs::Range message as a cone. I've set the topic to /ultrasonicsensor, but when i run the simulation I got: 

Status:Warning
   Topic No messages received

Using rostopic echo /ultrasonic_sensor I can see that the ranges detected by the ultrasonic sensor are published on the /ultrasonicsensor topic. But looking in the class ROSProxy.java I've seen that the message published on that topic is a **sensormsgs/Range** and not a nxt_msgs/Range.
Could this be the cause of the problem?And how can i solve it?

Answers

I solved publishing a message of type nxt_msgs/Range on a custom defined topic called /custom_ultrasonic_sensor and passing this topic to nxt_rviz_plugin.
