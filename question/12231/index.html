Hello, i beam my robot with set model state to move it in gazebo to different positions and then make a laserscan. now my problem is, that the odomcombined isn't updated because it doesn't move to the position only beamed. so i need to change my odomcombined, but i don't know really how. i tried it with nav_msgs::Odometry but it does not make anything. can someone help?

Answers

Odometry is guaranteed to evolve over time in a continuous matter. So when your robot jumps for some reason (either you move the model in simulation, or your localization snaps the robot back in place), the odometry will not follow this jump. See this link for more details: http://www.ros.org/reps/rep-0105.html
