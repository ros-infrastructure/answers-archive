Rxbag is not publishing

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/36363/rxbag-is-not-publishing.

Hi!

I've recorded a bag file useing rxbag --record -a -o all.bag.

When I want to play it I run rxbag all20111209101020.bag and the rxbag window opens and I can play, see the graphics, everithing. But it is not publishing the data to rostopics. What do I need to do?

Thanks.

Comments

Answers

rxbag only publishes to topics that you explicitly select. Right-click on the topics list in the rxbag window and choose the topics you're interested in (or "Publish All") in the "Publish..." popup menu.
