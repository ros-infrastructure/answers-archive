Ok, I "solved" it by using

rosrun swri_transform_util initialize_origin.py

I said "solved" because my tf tree looks weird (it is not a tree).

It looks like:

imu_link -> base_link
far_field -> origin
              -> far_field_identity
map -> map_identity
odom
