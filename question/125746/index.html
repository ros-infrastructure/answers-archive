Answers

urdf::Model::initFile(urdf_file) takes an absolute file path (see urdf::Model C++ API), so you would have to run something like ./devel/lib/testbot_description/parser /home/<user>/catkin_ws/src/testbot_description/urdf/my_robot.urdf (make sure to replace with your user name).
