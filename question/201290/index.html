I've been following the tutorials of GazeboSim. I can spawn the 'RRBot' with roslaunch rrbotgazebo rrbotworld.launch command, but if I close Gazebo, I cannot spawn the RRBot again, instead, encounter with this output;

Asked by Oguz on 2015-01-21 11:52:28 UTC

Problem solved: In rrbot_world.launch file, I commented out:

<!--<arg name="world_name" value="$(find rrbot_gazebo)/worlds/rrbot.world"/> -->

and it is now working without any problem.
