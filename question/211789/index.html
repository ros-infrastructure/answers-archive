Try this http://wiki.ros.org/laser_scan_matcher

  1. roscd ;
  2. source devel/setup.bash
  3. cd src ;
  4. git clone https://github.com/ccny-ros-pkg/scan_tools.git
  5. apt-get install libgsl0-dev
  6. cd ..
  7. catkin_make
  8. Start IT.
