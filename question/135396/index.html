This warning only says that you have no saved rviz config. You can save you current config with File-> Save Config.

I agree with Mr.fivef's answer. After you enter next command, you should save a config file.

$rosrun rviz rviz

I also had same experience, when I called a *.vcg in a *.launch with a new version rviz. The reason is that a new version rviz calls *.rviz as config file.
