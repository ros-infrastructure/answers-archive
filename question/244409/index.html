Firstly, you need a ROS driver node for URG-04LX. Both hokuyo_node and urg_node can do this. However, neither of these nodes support ROS Kinetic directly. You can refer to my question How to install hokuyo_node/urg_node on kinetic?

And for SLAM mapping, I can't tell which method is best. But I used gmapping with URG-04LX-UG01, it works well.
