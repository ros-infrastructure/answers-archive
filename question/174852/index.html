Joystick support for ROS Indigo

I understand that many ROS Indigo packages haven't been released yet. I am trying to shift to Indigo (on Ubuntu 14.04) from Hydro (on Ubuntu 12.04) and I couldn't find any packages like ros-indigo-joy OR ros-indigo-joystick-drivers which exist in Hydro version. I want to connect XBox 360 controller for input to my robot, segway-rmp, the ROS package of which depends on joystick packages (ros-hydro-joy and ros-hydro-joystick-drivers)

ROS Indigo's website says that the LTS version will be available in May. Does anybody have an idea of when will Indigo be ready for use? Also, is there any existing support for joysticks in Indigo?

Answers

Joystick_drivers has not yet been released to indigo (ticket tracking this is located at https://github.com/ros-drivers/joystick_drivers/issues/65). You should be OK building from source, and a release should happen shortly.

As for the full Indigo release, there is not a release date yet, but issues that need to be resolved are being discussed on the ROS-release mailing list. The biggest blocker right now is that there are currently some issues with Gazebo integration as well as some lower level libraries that become system libraries in Ubuntu Trusty that are being worked out (https://github.com/ros/rosdistro/issues/4633)
