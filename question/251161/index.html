This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/78141/how-to-get-the-robots-pose-in-the-rviz.

I am using moveit these days, but a problem confused me. The moveit-rviz plugin is very useful for visualization the robot's planning scene, there is a demo in the pr2moveitconfig launch file, you can use your mouse to drag the interactive marker on the robot model in Rviz. But I want to get the pose information when I drag or move the endeffector. When I use the getTargetPose, I just return the Target Pose you defined in the code, but how to get the simulation model's pose in realtime?

O I find a solution. When you use rviz as a plugin for moveit, actually you are using the interactive marker srv to send pose information between interactive marker server and RViz. The topic use here is update and feedback. So you just need to find the topics when you are running.

So use "rostopic list" command, I find there is a topic named /rviz_moveit_motion_planning_display/robot_interaction_interactive_maker_topic/feedback This is just the information I need.
