Driver for Microstrain 3DM-GX3-35

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/35026/driver-for-microstrain-3dm-gx3-35.

Does anyone know about a driver for the Microstrain 3DM-GX3-35 or used the sensor on Linux? This is a Microstrain IMU with an integrated GPS. The protocol for the 3DM-GX3-35 is different from the 3DM-GX3-25 so the microstrain3dmgx2imu will not work.

Answers

If you are only interested in the IMU part then it is possible to set the sensor to AHRS direct mode. Then it will work with the microstrain_3dmgx2_imu driver.
