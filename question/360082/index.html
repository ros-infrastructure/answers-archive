Asked by msaws on 2020-08-21 23:51:05 UTC

I had to run this 

wget http://packages.osrfoundation.org/gazebo.key -O - | sudo apt-key add -

sudo apt-get update
sudo apt-get install ros-melodic-gazebo9-ros-control

and it solved my error
