Answers

We're currently in the process of porting Gazebo's citysim branch to default so the new features are released with Gazebo 9 in January 2018. This means that until then, things will be constantly changing and it may be tricky at times to get all features working together.

It depends on the features you're interested in, if it is the city world and its models, it works even with Gazebo 7 or 8. All you need to do is setting GAZEBO_MODEL_PATH so it finds the models:

cd /path/to/citysim
export GAZEBO_MODEL_PATH=`pwd`/models:$GAZEBO_MODEL_PATH
gazebo --verbose worlds/simple_city.world

All the world objects, cars and human actors should be there, but you'll get a lot of errors about plugins not found.

Some plugins can be compiled against Gazebo 8, so if you're really interested on them, you could copy the code and build them from source. I haven't tested, but these should build against Gazebo 8:

  • Traffic lights GUI plugin
  • Prius Hybrid plugin

Other plugins and Gazebo features will need to be ported to Gazebo, this is their latest status:

  • Camera lens flare open pull request on gazebo
  • Shadow improvements open pull request on gazebo
  • Bloom effect (needs a PR to Gazebo)
  • Joystick plugin (needs a PR to Gazebo)

Regarding your question about controlling the Prius with ROS, you may want to check out the car_demo repository.
