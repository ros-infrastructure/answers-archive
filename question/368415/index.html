For understanding how an encoder works you can read this documentation on the Encoder library by Paul Stoffregen. Pay special attention to the animation with the blue disk. Encoders usually have 2 power wires (5V and GND) and 2 signal wires (A and B), the latter produce the quadrature (square) signals that you can see in Paul's animation. Connect those to the interrupt pins of your Arduino and the library should work: the function myEnc.read() should return the amount of pulses detected. You can then map this value to radians and send it to the ROS system using rosserial.
