I've been searching for a VO package that is compatible with ROS Melodic. I found SVO 2 but it is only compatible with ROS Kinetic and Ubuntu 16.04. Is there any way I can find a Melodic-compatible package for Visual Odometry? Or is there any way I can make SVO 2 compatible with Melodic?

I have been using orb_slam_2 with melodic for some time now. I am pretty sure that rtabmap should also work with melodic.

I have not used SVO2, but if it works with kinetic, it should work with melodic if you build from source. You can build most packages from source (clone the repo into your catkin_workspace and build). If you run into issues, you are welcome to post/discuss specific errors!
