I found these functions costmap_2d.cpp in ros_navigation: https://github.com/ericperko/ros_navigation/blob/master/costmap_2d/src/costmap_2d.cpp

  void Costmap2D::mapToWorld(unsigned int mx, unsigned int my, double& wx, double& wy) const {
    wx = origin_x_ + (mx + 0.5) * resolution_;
    wy = origin_y_ + (my + 0.5) * resolution_;
  }

  bool Costmap2D::worldToMap(double wx, double wy, unsigned int& mx, unsigned int& my) const {
    if(wx < origin_x_ || wy < origin_y_)
      return false;

    mx = (int) ((wx - origin_x_) / resolution_);
    my = (int) ((wy - origin_y_) / resolution_);

    if(mx < size_x_ && my < size_y_)
      return true;

    return false;
  }

  void Costmap2D::worldToMapNoBounds(double wx, double wy, int& mx, int& my) const {
    mx = (int) ((wx - origin_x_) / resolution_);
    my = (int) ((wy - origin_y_) / resolution_);
  }

Thanks. Now, I figured out the conversion: First, this image illustrates the used coordinates(if some one can put it here, I don't have enough points to upload here): http://www.mediafire.com/view/0xzdclvc9r8m93v/array_and_pixel_coorinate.png/file

How to convert from array coordinate to pixel coordinate?

pixel_x = array_y

pixel_y = height - ( array_x + 1)

so (1,5) in array coordinate is (5,6) in pixel coordinate

Asked by Eman.m on 2020-12-08 15:01:05 UTC

How to convert from pixel coordinate to world coordinate (xy plane)?

We need to apply mapToWorld

worldX = 0 + (5+0.5) * 1 = 5.5

worldY = 0 + (6+0.5) * 1 = 6.5

so (5,6) in pixel coordinate is (5.5,6.5) in world coordinate this lies in the middle of array element (1,5) or pixel (5,6)
