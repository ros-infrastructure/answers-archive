My guess is that you have another version of gazebo installed. Try sudo apt-get install gazebo7-plugin-base. It may show a very similar message. Keep trying the ones that say "not going to be installed" until you find a package that you have a different version of. Then uninstall that and gazebo should be able to install. Please update your answer with the results of the command I first suggested.

Asked by Yumlembam on 2016-06-20 23:56:29 UTC

I got the solution. Took longer as I just started using Linux. gazebo7 has depends on gazebo7-common with version 7.0.0+dfsg-2. But when gazebo7-common is installed, it always installs the latest version which is 7.2.0-1~xenial, and this has caused the install issue. When I forced installed the gazebo7-common 7.0.0+dfsg-2, I could install gazebo7 without a glitch.
