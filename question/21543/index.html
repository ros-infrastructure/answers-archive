Gazebo uses Ogre3D for rendering. It uses particle scripts to define particle systems, which can be used to simulate fire. I haven't used these before, so I don't know if there's a way to load up one of these scripts as part of a model loaded into an SDF or URDF file. You might need a Gazebo plugin that loads and activates the particle system.
