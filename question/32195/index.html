Running 'rosmake -a -t' I get some test failures attributed to 'Test Fixture Nodes ['xxx'] failed to launch. How can I determine what's wrong and fix it?

An abbreviated example:

ERRORS/FAILURES:
[robotposeekf.rostest_testtestrobotposeekfzerocovariance/testtestrobotposeekf][FAILURE] Test Fixture Nodes ['rosbag'] failed to launch PACKAGES: * robotposeekf
