Syntax for publishing to trajectory_msgs/MultiDOFJointTrajectory

Hi there I am new to ROS and I am trying to run a quad-copter system called crazyflie 2.0 on ROS. I have been going through his work via this link ("https://github.com/gsilano/CrazyS"). Currently, I am trying to hover the quad-copter and give it way point using command line rostopic pub. So far I know the type of message that I need to publish which is of the type of trajectory_msgs/MultiDOFJointTrajectory.

The problem that I have is that I am not able to understand the full syntax required to publish a full message on to the quadcopter system.

The full message type has the following details:

std_msgs/Header header
  uint32 seq
  time stamp
  string frame_id
string[] joint_names
trajectory_msgs/MultiDOFJointTrajectoryPoint[] points
  geometry_msgs/Transform[] transforms
    geometry_msgs/Vector3 translation
      float64 x
      float64 y
      float64 z
    geometry_msgs/Quaternion rotation
      float64 x
      float64 y
      float64 z
      float64 w
  geometry_msgs/Twist[] velocities
    geometry_msgs/Vector3 linear
      float64 x
      float64 y
      float64 z
    geometry_msgs/Vector3 angular
      float64 x
      float64 y
      float64 z
  geometry_msgs/Twist[] accelerations
    geometry_msgs/Vector3 linear
      float64 x
      float64 y
      float64 z
    geometry_msgs/Vector3 angular
      float64 x
      float64 y
      float64 z
  duration time_from_start

I am using the following command to publish to the topic :

rostopic pub /crazyflie2/command/trajectory trajectory_msgs/MultiDOFJointTrajectory '{header: {seq: 0, stamp: now, frame_id: ''}, joint_names: [base_link], points: [transforms:[rotation: {x: 0.0, y: 0.0, z: 0.0, w: 1.0}, translation: {x: 1.0, y: 0.0, z: 1.0}]]}'

The above command works but instead of publishing a single message it publishes two message the first contains the rotation while the second contains the translation message. This doesn't make any sense because now the quadcopter has incomplete information. I would highly appreciate if anybody can provide the proper syntax required to publish a full message, with waypoints, velocities and accelerations.

Note by default a cpp script is used to publish this message for the hovering example but I would like to first test whether I can move the quadcopter to desired positions and then develop a script to move the quadcopter in particular positions.
