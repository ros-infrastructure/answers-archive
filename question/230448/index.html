How to use <rosparam> to change values from dwa_local_planner_params.yaml?

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/73107/how-to-use-rosparam-to-change-values-from-dwa-local-planner-params-yaml.

I'm using a launch file that includes turtlebotnavigation gmappingdemo.launch and I want to set the values of certain movebase parameters. gmappingdemo.launch traces to movebase.launch.xml which traces to turtlebotnavigation/dwalocalplanner_params.yaml.

If I can "rosparam get" the parameter that I want to change, how can I set that parameter inside of my launch file that I created?

Thanks!

Answers

Figured it out. Since these parameters are global parameters, you can just use "rosparam list" to find the parameter you want to change, (in my case it was /move_base/DWAPlannerROS/max_vel_x), and then add:

<param name="/move_base/DWAPlannerROS/max_vel_x"  value="0.1"/>

to your launch file.
