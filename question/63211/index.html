Changing the size of the turtlesim window

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/51297/changing-the-size-of-the-turtlesim-window.

How can I change the canvas width and canvas height of the turtlesim window displayed on running turtlesimnode? Are there some options which can be used with the command "rosrun turtlesim turtlesimnode __name:=turtle1" to change the size of the display window.

Asked by Hemu on 2013-05-22 03:39:27 UTC

Comments

Answers

The turtlesim does not support a dynamic windows size.

This is mainly due to keeping the code as simple as possible since turtlesim is used as an example/tutorial for ROS.
