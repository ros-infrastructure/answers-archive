Looks like this is a common problem based on previous discussions. See https://answers.ros.org/question/227410/couldnt-find-an-af_inet-address-for-hostname/

A couple additional guesses 1. The export of env vars only applies to the shell in which you do it. If you run processes in another shell they won't see those env vars. 2. You might need to set ROS_HOSTNAME= on the Jetson.
