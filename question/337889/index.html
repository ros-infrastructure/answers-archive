Data from Optitrack is not getting streamed properly to vrpn_client_ros

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/93863/data-from-optitrack-is-not-getting-streamed-properly-to-vrpn-client-ros.

i'm currently using optitrack motive 1.10.1 version for tracking 3 UAVs. i'm using vrpn streaming to stream the data. im connecting the host pc (on which motive is running) to router using lan and connecting the pc running ros to the router's wifi. while im running the sample.launch in vrpnclientros package, im getting data slowly at times and quick at times. i couldn't figure out if this is due to pc issue or router issue or motive issue. i would like to know what changes in code needs to be made so that if data/packet doesn't come for any instant then that instant could be displayed. so that i could know the trend of data getting lost

Answers

First thing to try is to connect everything using cables. Getting data in bursts ("slowly at times and quick at times") seems to point to networking issues. Take out the wireless segment and see whether that improves things.
