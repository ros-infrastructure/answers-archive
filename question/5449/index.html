osrf_msgs is a ros package distributed in the osrf-common debian on packages.osrfoundation.org. If you installed drcsim using apt-get (according to the installation instructions), then the package should be on your system. Use the following command to search for it: 

$ dpkg -l | grep osrf

Asked by scpeters on 2014-02-10 17:43:41 UTC

Since last friday the drcsim packages on precise were splitted into $package-groovy and $package-hydro postfix. As a transition measure, the current osrf-common is still working and brings osrf-common-groovy to the system, which is the same behaviour that had the package before the split.

Please check that you have present in your system the proper package depending on the ROS_DISTRO that you are using (important!): osrf-common-groovy or osrf-common-hydro. I was able to reproduce your error by using ROS Hydro and have installed osrf-common-groovy.

And yes, we need to update the tutorials to latest drcsim version.
