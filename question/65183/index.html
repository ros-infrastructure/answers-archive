Image transport to android consumes high memory

This question has also been migrated to Robotics StackExchange as https://robotics.stackexchange.com/questions/52004/image-transport-to-android-consumes-high-memory.

Hello I tried to run simple imagetransport tutorial on my android 4.0 phone to display image captured by camera. It connects with the master, it displays the image, but the frame rate is extremely low and eventually device hangs itself. It seems that the app is using a lot of memory and therefore GCFOR_ALLOC pauses the execution of the program. I suppose that each image received is stored instead of being removed after the frame is used. Can anybody help me to fix this problem?
